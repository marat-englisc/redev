2e:T1be9,<div class="callout callout-note" data-callout="note">
<div class="callout-title">Кратко</div>
<div class="callout-body"><p>Preflight - предварительный <code>OPTIONS</code> request, который browser отправляет перед некоторыми cross-origin запросами. Он проверяет, разрешает ли server настоящий method, headers и credentials.</p></div>
</div>
<h2 id="вопрос">Вопрос</h2>
<p>Что такое preflight request? Какие запросы считаются простыми и когда браузер отправляет <code>OPTIONS</code>?</p>
<h2 id="когда-появляется-preflight">Когда появляется preflight?</h2>
<p>Preflight часто появляется, если request:</p>
<ul>
<li>использует method не из простых, например <code>PATCH</code> или <code>DELETE</code>;</li>
<li>отправляет <code>Authorization</code> header;</li>
<li>отправляет custom header;</li>
<li>использует не-simple <code>Content-Type</code>, например <code>application/json</code>.</li>
</ul>
<h2 id="как-выглядит-preflight">Как выглядит preflight?</h2>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="http" data-theme="mono"><code data-language="http" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-keyword)">OPTIONS</span><span style="color:var(--shiki-foreground)"> /api/orders </span><span style="color:var(--shiki-token-keyword)">HTTP</span><span style="color:var(--shiki-foreground)">/</span><span style="color:var(--shiki-token-constant)">1.1</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Origin</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> https://app.example.com</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Request-Method</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> POST</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Request-Headers</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> content-type, authorization</span></span></code></pre></figure>
<p>Server должен ответить:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="http" data-theme="mono"><code data-language="http" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-keyword)">HTTP</span><span style="color:var(--shiki-foreground)">/</span><span style="color:var(--shiki-token-constant)">1.1</span><span style="color:var(--shiki-token-constant)"> 204</span><span style="color:var(--shiki-token-string)"> No Content</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Allow-Origin</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> https://app.example.com</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Allow-Methods</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> GET, POST, PATCH, DELETE</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Allow-Headers</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> content-type, authorization</span></span>
<span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Allow-Credentials</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> true</span></span></code></pre></figure>
<p>После этого browser отправит настоящий request.</p>
<h2 id="почему-request-не-доходит-до-backend-controller">Почему request "не доходит" до backend controller?</h2>
<p>Если preflight не прошел, настоящий request не отправится. В логах controller ты его не увидишь.</p>
<p>Нужно смотреть <code>OPTIONS</code> request в Network tab.</p>
<h2 id="access-control-max-age">Access-Control-Max-Age</h2>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="http" data-theme="mono"><code data-language="http" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-string-expression)">Access-Control-Max-Age</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-string)"> 600</span></span></code></pre></figure>
<p>Этот header говорит browser, сколько секунд можно кешировать результат preflight. Это уменьшает количество <code>OPTIONS</code> requests.</p>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Простой запрос: метод <code>GET</code>, <code>HEAD</code> или <code>POST</code>, только «безопасные» headers и <code>Content-Type</code> из <code>text/plain</code>, <code>multipart/form-data</code>, <code>application/x-www-form-urlencoded</code>.</li>
<li>Preflight выполняется без cookies и без <code>Authorization</code>, поэтому сервер не должен требовать авторизацию для <code>OPTIONS</code>.</li>
<li>Chrome ограничивает <code>Access-Control-Max-Age</code> двумя часами, Firefox — сутками: большее значение будет урезано.</li>
<li>Простые запросы не защищены preflight-ом, поэтому сервер всё равно обязан проверять origin и права для state-changing запросов.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<ul>
<li>Preflight - <code>OPTIONS</code> перед настоящим request.</li>
<li>Он проверяет method, headers и origin.</li>
<li>Если preflight failed, основной request не уйдет.</li>
<li><code>Authorization</code> и <code>application/json</code> часто вызывают preflight.</li>
<li><code>Access-Control-Max-Age</code> кеширует preflight result.</li>
</ul>
