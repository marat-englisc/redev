<div class="callout-body"><p><strong>Специфичность</strong> — вес селектора, по которому каскад выбирает правило, если несколько правил задают одно свойство одному элементу. Ее записывают тройкой <code>A-B-C</code>: A — id, B — классы, атрибуты и псевдоклассы, C — теги и псевдоэлементы. Inline-стили и <code>!important</code> стоят выше специфичности. <code>:where()</code> дает 0, а <code>:is()</code>, <code>:not()</code> и <code>:has()</code> берут вес самого специфичного аргумента.</p></div>
</div>
<h2 id="вопрос">Вопрос</h2>
<p>Как рассчитывается специфичность селектора? Как выглядит формула? Как на специфичность влияют псевдоклассы и псевдоэлементы?</p>
<h2 id="формула">Формула</h2>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="plaintext" data-theme="mono"><code data-language="plaintext" data-theme="mono" style="display: grid;"><span data-line=""><span>A — количество id</span></span>
<span data-line=""><span>B — классы, атрибуты, псевдоклассы</span></span>
<span data-line=""><span>C — теги (типы элементов) и псевдоэлементы</span></span></code></pre></figure>
<p>Сравнение идет слева направо: любой селектор с одним id сильнее селектора с сотней классов. Это не десятичное число — разряды не переполняются.</p>
<h2 id="примеры">Примеры</h2>





















































<div class="table-wrap"><table><thead><tr><th>Селектор</th><th>Специфичность</th></tr></thead><tbody><tr><td><code>*</code></td><td><code>0-0-0</code></td></tr><tr><td><code>p</code></td><td><code>0-0-1</code></td></tr><tr><td><code>p::first-line</code></td><td><code>0-0-2</code></td></tr><tr><td><code>.text</code></td><td><code>0-1-0</code></td></tr><tr><td><code>[type="email"]</code></td><td><code>0-1-0</code></td></tr><tr><td><code>button.primary:hover</code></td><td><code>0-2-1</code></td></tr><tr><td><code>#app</code></td><td><code>1-0-0</code></td></tr><tr><td><code>#app .card h2</code></td><td><code>1-1-1</code></td></tr><tr><td><code>:where(#app .card) h2</code></td><td><code>0-0-1</code></td></tr><tr><td><code>:is(#app, .card) h2</code></td><td><code>1-0-1</code></td></tr><tr><td><code>.list > li:not(.active)</code></td><td><code>0-2-1</code></td></tr></tbody></table></div>
<p>Комбинаторы (пробел, <code>></code>, <code>+</code>, <code>~</code>) и универсальный селектор <code>*</code> специфичность не добавляют.</p>
<h2 id="псевдоклассы-и-псевдоэлементы">Псевдоклассы и псевдоэлементы</h2>

<h2 id="порядок-каскада">Порядок каскада</h2>
<p>Специфичность — не первый критерий. Каскад сравнивает:</p>
<ol>
<li>Происхождение и важность: <code>!important</code> пользователя > <code>!important</code> автора > обычные стили автора > стили браузера.</li>
<li>Контекст (Shadow DOM).</li>
<li>Cascade layers (<code>@layer</code>): стили вне слоев сильнее стилей в слоях.</li>
<li><strong>Специфичность</strong> (inline-стиль считается сильнее любого селектора).</li>
<li>Порядок в коде: при равной специфичности побеждает последнее правило.</li>
</ol>

<h2 id="как-управлять-специфичностью">Как управлять специфичностью</h2>
<ul>
<li>Писать селекторы из одного класса (BEM, CSS Modules).</li>
<li>Оборачивать базовые стили в <code>:where()</code>, чтобы их было легко переопределить:</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="css" data-theme="mono"><code data-language="css" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-function)">:where</span><span style="color:var(--shiki-foreground)">(</span><span style="color:var(--shiki-token-function)">.prose</span><span style="color:var(--shiki-foreground)">) </span><span style="color:var(--shiki-token-string-expression)">h2</span><span style="color:var(--shiki-foreground)"> { </span><span style="color:var(--shiki-token-constant)">margin-top</span><span style="color:var(--shiki-token-keyword)">:</span><span style="color:var(--shiki-token-constant)"> 2</span><span style="color:var(--shiki-token-keyword)">em</span><span style="color:var(--shiki-foreground)">; } </span><span style="color:var(--shiki-token-comment)">/* 0-0-1 */</span></span></code></pre></figure>
<ul>
<li>Поднимать вес без <code>!important</code> повтором класса: <code>.button.button</code> (<code>0-2-0</code>).</li>
<li>Использовать <code>@layer</code> для разделения reset, библиотек и компонентов.</li>
</ul>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Наследуемое значение не имеет специфичности: любое правило, которое прямо выбирает элемент, сильнее унаследованного.</li>
<li>В DevTools (Elements → Styles) при наведении на селектор показывается его специфичность.</li>
<li>Inline-стиль из JS (<code>element.style</code>) переопределяет все стили из CSS, кроме <code>!important</code>.</li>
<li>Высокая специфичность — главный источник «войны селекторов» и <code>!important</code>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<ul>
<li><code>A-B-C</code>: id — классы/атрибуты/псевдоклассы — теги/псевдоэлементы.</li>
<li><code>*</code> и комбинаторы — 0.</li>
<li><code>:where()</code> — 0, <code>:is()</code>/<code>:not()</code>/<code>:has()</code> — максимум аргументов.</li>
<li>Порядок важен только при равной специфичности.</li>
<li>Выше специфичности: <code>!important</code>, слои, inline-стили.</li>
</ul>
