Что такое псевдоклассы и какие они бывают?

Кратко

Псевдокласс — часть селектора с одним двоеточием, которая выбирает элемент по состоянию (:hover, :focus-visible, :checked), положению в дереве (:first-child, :nth-child()), состоянию формы (:invalid, :disabled) или логическому условию (:not(), :is(), :has()). Специфичность обычного псевдокласса равна классу — 0-1-0.

Вопрос

Что такое псевдокласс в CSS? Какие псевдоклассы вы знаете и как их группировать?

Основная идея

Псевдокласс не создает новый элемент, а уточняет, когда или какой существующий элемент выбрать.

Состояния взаимодействия

ПсевдоклассКогда срабатывает
:hoverкурсор над элементом
:activeэлемент нажимают
:focusэлемент в фокусе
:focus-visibleфокус, который нужно показать (обычно с клавиатуры)
:focus-withinфокус внутри элемента
:visited / :linkпосещенная / непосещенная ссылка
:targetэлемент, на который указывает #hash в URL

Порядок для ссылок — LVHA: :link, :visited, :hover, :active, иначе более поздние правила перебьют нужные.

Состояния форм

ПсевдоклассЧто выбирает
:checkedотмеченный checkbox, radio или option
:disabled / :enabledотключенное / активное поле
:required / :optionalобязательное / необязательное поле
:valid / :invalidпроходит / не проходит валидацию
:user-invalidневалидно после взаимодействия пользователя
:placeholder-shownпоказан placeholder (поле пустое)
:read-only / :read-writeдоступность редактирования
:indeterminateпромежуточное состояние checkbox

:invalid срабатывает сразу при загрузке на пустом обязательном поле, поэтому для показа ошибок лучше :user-invalid.

Структурные

ПсевдоклассЧто выбирает
:first-child / :last-childпервый / последний ребенок
:only-childединственный ребенок
:nth-child(2n+1)по формуле, считает всех детей
:nth-of-type(2)по формуле среди элементов того же тега
:nth-last-child(n)с конца
:emptyбез детей и текста
:rootкорень документа (html)

Логические

ПсевдоклассСмысл
:not(.a, .b)не совпадает ни с одним
:is(a, b)любой из списка
:where(a, b)любой из списка, специфичность 0
:has(> img)содержит подходящего потомка — «родительский селектор»

Специфичность

  • обычный псевдокласс — как класс: a:hover = 0-1-1;
  • :where() — 0;
  • :is(), :not(), :has() — вес самого специфичного аргумента;
  • :nth-child(2 of .item) — 0-1-0 плюс вес селектора после of.

Что важно помнить

  • :hover на touch-устройствах «залипает» после тапа — оборачивайте hover-эффекты в @media (hover: hover).
  • Не убирайте фокус: :focus-visible позволяет скрыть outline для мыши и оставить для клавиатуры.
  • :visited ограничен из соображений приватности: можно менять только цвета.
  • :has() мощный, но на очень больших DOM может быть дорогим — не используйте его для глобальных селекторов вида body:has(...) без необходимости.

Мини-шпаргалка

  • Псевдокласс — состояние или условие, одно двоеточие.
  • Группы: взаимодействие, формы, структура, логика.
  • LVHA для ссылок.
  • :focus-visible, :user-invalid, :has() — современные must-know.
  • Специфичность как у класса, кроме :where() и функциональных.
