<div class="callout-body"><p><code>delete</code> удаляет свойство объекта. Он не удаляет переменные, не очищает значение, а именно убирает ключ из объекта.</p></div>

<h2 id="прототипы">Прототипы</h2>
<p><code>delete</code> удаляет только собственное свойство объекта. Свойства прототипа он не трогает.</p>

<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li><code>delete</code> удаляет свойство объекта, но не переменную и не элемент массива «со сдвигом».</li>
<li>Возвращает <code>true</code> даже для несуществующего свойства; <code>false</code> — для неконфигурируемого (в strict mode — <code>TypeError</code>).</li>
<li>Частые <code>delete</code> замедляют объекты в V8; для динамических наборов ключей используйте <code>Map</code>.</li>
<li>Иммутабельная альтернатива — <code>const { key, ...rest } = obj</code>.</li>
</ul>
