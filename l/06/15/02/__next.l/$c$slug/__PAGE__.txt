<div class="callout-body"><p><code>configureStore</code> создает Redux store: объединяет reducers, подключает middleware по умолчанию (thunk, проверки мутаций и сериализуемости в dev-режиме) и Redux DevTools. Компонент <code>&#x3C;Provider store={store}></code> из <code>react-redux</code> делает store доступным всему дереву. В TypeScript из store выводят типы <code>RootState</code> и <code>AppDispatch</code> и создают типизированные хуки <code>useAppSelector</code> и <code>useAppDispatch</code>.</p></div>

<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Один store на приложение; разделение — через slices, а не через несколько store.</li>
<li>Проверки мутаций и сериализуемости работают только в dev и не замедляют production.</li>
<li>Несериализуемые значения (Date, Map, функции) вызывают предупреждения — храните ISO-строки и обычные объекты.</li>
<li>В Next.js App Router store создается внутри клиентского провайдера; Server Components к store доступа не имеют.</li>
<li><code>withTypes</code> появился в react-redux 9.1; раньше писали <code>TypedUseSelectorHook&#x3C;RootState></code>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p><code>configureStore({ reducer: { todos, filters } })</code> → <code>&#x3C;Provider store></code>. Типы: <code>RootState = ReturnType&#x3C;typeof store.getState></code>, <code>AppDispatch = typeof store.dispatch</code>. Хуки: <code>useSelector.withTypes&#x3C;RootState>()</code>, <code>useDispatch.withTypes&#x3C;AppDispatch>()</code>. SSR — <code>makeStore</code> на запрос.</p>
