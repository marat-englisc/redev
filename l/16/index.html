Кратко

В первую очередь здесь собраны русскоязычные материалы. Англоязычные ресурсы помечены «(англ.)» и оставлены там, где хорошей русской альтернативы нет: документация Next.js, Redux Toolkit, TanStack Query и большинства инструментов экосистемы React доступна только на английском.

Документация и справочники

  • Дока — понятные статьи по HTML, CSS, JavaScript, веб-платформе и доступности.
  • MDN Web Docs на русском — справочник по веб-технологиям, Web API, HTTP и браузерной платформе.
  • Современный учебник JavaScript — последовательное изучение языка и браузерных API с задачами.
  • TypeScript на ScriptDev — русскоязычное руководство по TypeScript.
  • Node.js для начинающих — перевод документации, справочник API и практические руководства по Node.js.
  • Vite — русскоязычное руководство по сборщику.
  • Frontskill — справочник по темам фронтенд-разработки.
  • Шпаргалка Git — основные команды Git (англ.).

React

  • Изучение React — официальное руководство на русском: компоненты, состояние, эффекты, «Thinking in React».
  • Справочник API React — все хуки, компоненты и API с примерами и типичными ошибками.
  • Серверные компоненты — React Server Components, директивы 'use client' и 'use server'.
  • React и TypeScript — официальный раздел о типизации props, хуков и событий.
  • React TypeScript Cheatsheet — шпаргалка по типизации компонентов, контекста, рефов и дженерик-компонентов (англ.).
  • React с примерами кода — русскоязычные переводы документации библиотек экосистемы React.
  • React и альтернативы в Доке — место React среди других UI-библиотек.
  • Patterns.dev — паттерны рендеринга, производительности и проектирования React-приложений (англ.).

Next.js

  • Документация Next.js — App Router, рендеринг, Data Fetching, Server Actions, Metadata и конфигурация (англ.).
  • Next.js Learn — официальный пошаговый курс: от первой страницы до дашборда с БД и авторизацией (англ.).
  • Кэширование в Next.js — уровни кэша, ревалидация и их взаимодействие; частая тема на собеседованиях (англ.).
  • Документация Vercel — деплой, Edge и Serverless функции, переменные окружения (англ.).
  • Auth.js — аутентификация в Next.js-приложениях (англ.).
  • Prisma — ORM для fullstack-приложений на Next.js (англ.).

Состояние, данные и формы

  • Redux Toolkit — официальная документация: createSlice, configureStore, RTK Query (англ.).
  • Redux Toolkit на русском — перевод документации Redux Toolkit.
  • TanStack Query — серверное состояние, кэширование и инвалидация запросов (англ.).
  • React Router — маршрутизация в SPA на React (англ.).
  • React Hook Form — производительные формы на неконтролируемых полях (англ.).
  • Zod — валидация данных и вывод типов TypeScript из схем (англ.).

Стили и UI

  • Tailwind CSS — документация utility-first CSS-фреймворка (англ.).
  • shadcn/ui — копируемые доступные компоненты на React и Tailwind CSS (англ.).

Тестирование

  • Vitest — быстрый тест-раннер, совместимый с API Jest (англ.).
  • React Testing Library — тестирование компонентов через поведение пользователя (англ.).
  • Playwright — E2E-тесты в реальных браузерах (англ.).

Архитектура

  • Feature-Sliced Design — методология структурирования фронтенд-проектов, популярная в React-командах.

Обучение и углубление знаний

  • Code Basics: JavaScript — бесплатный интерактивный курс для начинающих с упражнениями в браузере.
  • Хендбук «Основы алгоритмов» от Яндекса — теория, структуры данных и задачи с автоматической проверкой.
  • Веб-стандарты — статьи, новости и подкаст о современной веб-разработке.

Подготовка к собеседованиям

  • Hack Frontend — теория и вопросы по фронтенду.
  • SpeedrUnit — тренажёр вопросов для собеседований.
  • IT Booster — база вопросов по веб-разработке.
  • Подборки CodeRun — тематические наборы задач, включая подготовку к собеседованиям.
  • Тренировки по алгоритмам от Яндекса — лекции, разборы и домашние задания прошлых сезонов.
  • GreatFrontEnd — задачи с фронтенд-собеседований: JavaScript, React-компоненты и system design (англ.).

Практика и алгоритмы

  • CodeRun: алгоритмы — задачи на русском языке с онлайн-проверкой решений.
  • Codewars — короткие задачи разной сложности (англ.).
  • LeetCode — большая база алгоритмических задач и типовых задач с собеседований (англ.).

Доступность, безопасность и производительность

  • Гайд МТС по веб-доступности — практические требования и примеры доступных интерфейсов.
  • Безопасность веб-сайтов на MDN — базовые угрозы и способы защиты веб-приложений.
  • Производительность веб-сайтов на MDN — критический путь рендеринга, загрузка ресурсов и измерение производительности.
  • Core Web Vitals — метрики LCP, INP и CLS и способы их улучшить (англ.).

YouTube-каналы

  • As For JS — углублённые видео о JavaScript.
  • Ulbi TV — видео о React, Next.js и архитектуре фронтенд-приложений.
