<div class="callout-title">Кратко</div>
<div class="callout-body"><p>Библиотеку собирают иначе, чем приложение: нужен не один бандл для браузера, а <strong>модули для других сборщиков</strong> — ESM (и при необходимости CommonJS), <strong>типы <code>.d.ts</code></strong>, корректное поле <strong><code>exports</code></strong> в <code>package.json</code>, внешние (<code>external</code>) зависимости вместо встроенных копий, <code>peerDependencies</code> для React и пометка <strong><code>sideEffects</code></strong> для tree shaking. Сборку обычно делают через <strong>tsup</strong>, <strong>tsdown</strong> или Vite в library mode, публикацию — через <code>npm publish</code> с provenance из CI.</p></div>

<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Библиотека не должна встраивать React, а также крупные зависимости, которые есть у потребителя, — указывайте их в <code>external</code>/<code>peerDependencies</code>.</li>
<li><code>"use client"</code> в начале файлов компонентов нужен, чтобы библиотеку можно было использовать в Next.js App Router (бандлер должен сохранить директиву).</li>
<li>Не публикуйте <code>src</code> и тесты — используйте <code>files</code>.</li>
<li>Ломающие изменения — только в major-версии с описанием миграции.</li>
<li>Связанные темы: <a href="/refront/l/08/11/02/" data-internal="true">exports и conditional exports</a>, <a href="/refront/l/08/11/03/" data-internal="true">dual package hazard</a>, <a href="/refront/l/12/05/02/" data-internal="true">semver</a>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p>Библиотека: ESM (+CJS при необходимости), <code>.d.ts</code>, <code>exports</code> с <code>types</code> первым, <code>files</code>, <code>sideEffects</code>, React в <code>peerDependencies</code> и <code>external</code>. Сборка: tsup/tsdown/Vite library mode. Проверка: <code>npm pack --dry-run</code>, publint, arethetypeswrong. Публикация: <code>npm version</code>, <code>npm publish --provenance</code> из CI.</p>
