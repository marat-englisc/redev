<div class="callout-title">Кратко</div>
<div class="callout-body"><p><strong>webpack</strong> — бандлер, долго бывший стандартом фронтенд-сборки; он по-прежнему работает во многих существующих проектах (Create React App, старые Angular и Vue, корпоративные приложения) и в основе Next.js до Turbopack. Ключевые понятия: <strong>entry</strong> (откуда начать граф), <strong>output</strong> (куда и с какими именами положить результат), <strong>loaders</strong> (как превратить файл не-JS в модуль: TS, CSS, изображения), <strong>plugins</strong> (действия над всей сборкой: HTML, извлечение CSS, переменные окружения), <strong>mode</strong> (development/production) и <strong>optimization</strong> (чанки, минификация).</p></div>

<h2 id="loader-и-plugin">Loader и plugin</h2>






























<div class="table-wrap"><table><thead><tr><th></th><th>Loader</th><th>Plugin</th></tr></thead><tbody><tr><td>Работает с</td><td>отдельным файлом</td><td>всей сборкой и ее событиями</td></tr><tr><td>Задача</td><td>превратить файл в JS-модуль</td><td>генерировать файлы, менять результат, внедрять переменные</td></tr><tr><td>Где указывается</td><td><code>module.rules</code></td><td><code>plugins</code></td></tr><tr><td>Примеры</td><td><code>babel-loader</code>, <code>ts-loader</code>, <code>css-loader</code>, <code>sass-loader</code></td><td><code>HtmlWebpackPlugin</code>, <code>MiniCssExtractPlugin</code>, <code>DefinePlugin</code>, <code>BundleAnalyzerPlugin</code></td></tr></tbody></table></div>
<p>Loaders применяются <strong>справа налево</strong> (снизу вверх): <code>["style-loader", "css-loader", "sass-loader"]</code> — сначала SCSS → CSS, потом CSS → модуль, потом вставка в <code>&#x3C;style></code>.</p>
<h2 id="полезные-возможности-webpack-5">Полезные возможности webpack 5</h2>
<ul>
<li><strong>asset modules</strong> (<code>type: "asset"</code>) вместо <code>file-loader</code> и <code>url-loader</code>;</li>
<li><strong>persistent cache</strong> (<code>cache: { type: "filesystem" }</code>) — быстрые повторные сборки;</li>
<li><strong>Module Federation</strong> — загрузка модулей другого приложения в рантайме (микрофронтенды);</li>
<li><strong>tree shaking</strong> в production и <code>sideEffects</code> из <code>package.json</code>.</li>
</ul>
<h2 id="webpack-сегодня">webpack сегодня</h2>
<ul>
<li>новые проекты чаще начинают на <strong>Vite</strong>;</li>
<li><strong>Rspack</strong> — совместимая с webpack замена на Rust (те же конфиги и большинство loaders/plugins, в разы быстрее);</li>
<li>Next.js переходит на <strong>Turbopack</strong>;</li>
<li>знание webpack нужно для поддержки существующих проектов и на собеседованиях.</li>
</ul>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li><code>[contenthash]</code> в <code>filename</code> — основа долгого кеширования.</li>
<li><code>style-loader</code> для dev (быстро, HMR), <code>MiniCssExtractPlugin</code> для prod (отдельные CSS-файлы).</li>
<li><code>historyApiFallback</code> нужен SPA с клиентским роутингом, иначе перезагрузка на <code>/settings</code> даст 404.</li>
<li>Медленный webpack ускоряют: filesystem-кеш, <code>swc-loader</code>/<code>esbuild-loader</code> вместо Babel, <code>thread-loader</code>, переход на Rspack.</li>
<li>Связанные темы: <a href="/refront/l/12/02/06/" data-internal="true">сравнение бандлеров</a>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p>webpack: <code>entry</code> → <code>module.rules</code> (loaders: файл → модуль) → <code>plugins</code> (вся сборка) → <code>output</code> с <code>[contenthash]</code>. <code>mode</code>, <code>devtool</code>, <code>devServer</code>, <code>optimization.splitChunks</code>. Loaders — справа налево. Webpack 5: asset modules, filesystem cache, Module Federation. Быстрая замена — Rspack.</p>
