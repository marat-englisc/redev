<div class="callout-body"><p><strong>Полифил</strong> — код, который добавляет в старый браузер отсутствующий API: <code>Array.prototype.at</code>, <code>Object.groupBy</code>, <code>structuredClone</code>. <strong>core-js</strong> — самая полная библиотека полифилов стандартной библиотеки JavaScript. <strong>browserslist</strong> — общий список целевых браузеров проекта (<code>"> 0.5%, last 2 versions, not dead"</code>), который читают Babel, SWC, Autoprefixer, Lightning CSS и другие инструменты, чтобы решить, какой синтаксис понижать, какие полифилы и вендорные префиксы добавлять.</p></div>

<p>Для браузерных API (не стандартной библиотеки JS) часто достаточно проверки возможностей и деградации функциональности.</p>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Полифилы увеличивают бандл: узкий список браузеров = меньше кода и быстрее страница.</li>
<li><code>useBuiltIns: "usage"</code> обычно лучший выбор для приложений; библиотеки не должны глобально добавлять полифилы.</li>
<li>Не все API можно полифилить полноценно (например, Proxy или некоторые CSS-возможности).</li>
<li>Проверяйте поддержку на caniuse.com и Baseline-статус возможностей на MDN.</li>
<li>Связанные темы: <a href="/refront/l/12/03/01/" data-internal="true">Babel и SWC</a>, <a href="/refront/l/12/03/04/" data-internal="true">PostCSS и Autoprefixer</a>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p>Полифил — недостающий API в рантайме, транспиляция — новый синтаксис при сборке. core-js — полифилы JS, <code>useBuiltIns: "usage"</code>. browserslist — общий список браузеров для Babel, SWC, Autoprefixer, eslint-plugin-compat. Vite — <code>build.target</code>, legacy-плагин. Узкий список = меньше бандл.</p>
