<h2 id="babel-и-swc">Babel и SWC</h2>






























<div class="table-wrap"><table><thead><tr><th></th><th>Babel</th><th>SWC</th></tr></thead><tbody><tr><td>Язык</td><td>JavaScript</td><td>Rust</td></tr><tr><td>Скорость</td><td>базовая</td><td>в десятки раз быстрее</td></tr><tr><td>Плагины</td><td>огромная экосистема</td><td>меньше, плагины на Rust/WASM</td></tr><tr><td>Где используется</td><td>старые проекты, Jest (<code>babel-jest</code>), особые плагины</td><td>Next.js, Rspack, новые проекты</td></tr></tbody></table></div>

<h2 id="транспиляция-и-полифилы">Транспиляция и полифилы</h2>

























<div class="table-wrap"><table><thead><tr><th></th><th>Транспиляция</th><th>Полифил</th></tr></thead><tbody><tr><td>Что решает</td><td>новый <strong>синтаксис</strong> (<code>?.</code>, <code>class #private</code>, <code>async</code>)</td><td>отсутствующие <strong>API</strong> (<code>Array.prototype.at</code>, <code>Promise.withResolvers</code>, <code>structuredClone</code>)</td></tr><tr><td>Как</td><td>переписывает код при сборке</td><td>добавляет реализацию в рантайме</td></tr><tr><td>Инструмент</td><td>Babel, SWC, esbuild</td><td>core-js, отдельные полифилы</td></tr></tbody></table></div>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Транспилятор не проверяет типы TypeScript — только удаляет их; проверка — <code>tsc --noEmit</code>.</li>
<li>Чем современнее целевые браузеры, тем меньше трансформаций и меньше бандл.</li>
<li>Babel-плагины (например, для styled-components или React Compiler) иногда держат проект на Babel; для React Compiler есть и SWC-вариант.</li>
<li>Транспиляция <code>node_modules</code> обычно отключена для скорости — если библиотека поставляет новый синтаксис, а нужны старые браузеры, ее включают явно.</li>
<li>Связанные темы: <a href="/refront/l/12/03/02/" data-internal="true">полифилы и browserslist</a>, <a href="/refront/l/12/03/03/" data-internal="true">TypeScript в сборке</a>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p>Транспилятор: TS/JSX → JS, новый синтаксис → старый под browserslist. Babel — JS, плагины и presets (<code>preset-env</code>, <code>preset-react</code>, <code>preset-typescript</code>). SWC — Rust, быстрый, в Next.js и Rspack. Синтаксис — транспиляция, API — полифилы (core-js). Типы не проверяет.</p>
