Задача: flatten и unflatten объекта

Кратко

flattenObject превращает вложенный объект в плоский со «склеенными» ключами: { a: { b: 1, c: { d: 2 } } } → { "a.b": 1, "a.c.d": 2 }. unflattenObject делает обратное. Решение — рекурсивный обход с накоплением префикса пути. Обсуждают обработку массивов, пустых объектов, null и Date, а также применение: формы, query-параметры, переводы i18n, отправка вложенных данных в FormData.

Вопрос

Реализуйте flattenObject(obj) со склеиванием ключей через точку и обратную функцию unflattenObject. Как обработать массивы и пустые объекты?

flattenObject

Date и другие экземпляры классов не разворачиваются благодаря isPlainObject.

unflattenObject

Вариант с другим форматом ключей

Применение

  • значения формы с вложенными полями ↔ FormData (address.city);
  • ключи переводов i18n ("cart.title") ↔ вложенные JSON-словари;
  • сравнение конфигов и показ изменений по путям;
  • фильтры в query string (filter.price.min=100).

Доп. вопросы интервьюера

  • Сложность? O(общее число ключей).
  • Как избежать переполнения стека на огромной вложенности? итеративный обход со стеком [объект, префикс].
  • Что если в исходных ключах есть точка? выбрать другой разделитель или экранировать.
  • Как защититься от __proto__ в unflatten? пропускать опасные ключи — это вход от пользователя.

Что важно помнить

  • Пустые объекты и массивы сохраняйте как значения, иначе они пропадут при обратном преобразовании.
  • Числовой ключ в пути — признак массива при сборке обратно.
  • Не разворачивайте Date, Map и экземпляры классов.
  • Похожая задача — get и set по пути.

Мини-шпаргалка

flatten: рекурсия с префиксом prefix.key, листья — примитивы, Date, пустые объекты. unflatten: split("."), создавать [] или {} по следующему ключу. Разделитель и формат [i] по задаче, защищаться от __proto__.

Документация
