<div class="callout-title">Кратко</div>
<div class="callout-body"><p><strong><code>sleep(ms)</code></strong> — промис, который выполняется через <code>ms</code> миллисекунд: <code>await sleep(1000)</code>. <strong><code>withTimeout(promise, ms)</code></strong> — обертка, которая отклоняется ошибкой <code>TimeoutError</code>, если исходный промис не завершился за <code>ms</code>. Решение строится на <code>setTimeout</code> и <code>Promise.race</code>; важная деталь — <strong>очищать таймер</strong>, когда исходный промис завершился, и понимать, что таймаут <strong>не отменяет</strong> саму операцию: для этого нужен <code>AbortSignal</code>.</p></div>
</div>

<h2 id="доп-вопросы-интервьюера">Доп. вопросы интервьюера</h2>
<ul>
<li><strong>Почему <code>finally</code> с <code>clearTimeout</code>?</strong> иначе таймер останется в event loop: в Node.js процесс не завершится до его срабатывания, лишний <code>reject</code> уйдет в никуда.</li>
<li><strong>Насколько точен <code>sleep(1000)</code>?</strong> это минимальная задержка: если поток занят, срабатывание будет позже.</li>
<li><strong>Как сделать <code>sleep</code> синхронным?</strong> никак правильно — блокировка потока (<code>while (Date.now() &#x3C; end)</code>) замораживает интерфейс.</li>
</ul>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Таймаут через <code>race</code> не отменяет операцию — только перестает ждать.</li>
<li>Для <code>fetch</code> используйте <code>AbortSignal.timeout</code> и <code>AbortSignal.any</code>.</li>
<li>Свой класс ошибки (<code>TimeoutError</code>) позволяет отличать таймаут от других ошибок.</li>
<li>Теория: <a href="/refront/l/04/05/15/" data-internal="true">отмена промисов и AbortController</a>, <a href="/refront/l/04/05/08/" data-internal="true">setTimeout</a>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<p><code>sleep = ms => new Promise(r => setTimeout(r, ms))</code>. <code>withTimeout = Promise.race([promise, timeout])</code> + <code>finally(clearTimeout)</code>. Настоящая отмена — <code>fetch(url, { signal: AbortSignal.timeout(ms) })</code>, объединение сигналов — <code>AbortSignal.any</code>.</p>
