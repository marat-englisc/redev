Что выведет: event loop, микро- и макрозадачи

Кратко

Задачи «что выведет консоль» на event loop решаются одним правилом: сначала выполняется весь синхронный код, затем все микрозадачи (then, catch, finally, await, queueMicrotask; в Node.js еще раньше — process.nextTick), и только потом одна макрозадача (setTimeout, setInterval, события), после которой снова все микрозадачи. Executor new Promise(fn) выполняется синхронно, а код после await — как микрозадача.

Вопрос

Что выведет каждый фрагмент кода? Объясните порядок через стек вызовов, очередь микрозадач и очередь макрозадач.

Задача 1: база

Ответ

1 5 3 4 2. Синхронно 1 и 5; микрозадачи по порядку постановки — 3, 4; затем макрозадача — 2.

Задача 2: задачи внутри задач

Ответ

sync p1 p2 t1 t3 p3 t2.

  1. Синхронно: sync; в макрозадачах t1, t3; в микрозадачах p1.
  2. Микрозадача p1: печатает p1, ставит t2 в конец макрозадач и p2 в микрозадачи. Микрозадачи выполняются, пока очередь не опустеет, — p2.
  3. Макрозадача t1, микрозадач нет. Макрозадача t3 ставит p3 → p3 выполнится до следующей макрозадачи. Затем t2.

Задача 3: async/await

Ответ

start a1 b executor end a2 then timeout. Async-функция выполняется синхронно до первого await; b() тоже синхронно печатает b. Код после await (a2) встает в микрозадачи раньше, чем then, потому что был поставлен раньше. Executor промиса синхронный.

Задача 4: две цепочки

Ответ

1 3 2 4. Следующий then цепочки ставится в очередь только после выполнения предыдущего, поэтому цепочки чередуются.

Задача 5: executor и resolve

Ответ

A C D B. resolve не прерывает executor — C печатается сразу. Обработчик then — микрозадача.

Задача 6: Node.js — nextTick и setImmediate

Ответ

nextTick promise, затем timeout и immediate в непредсказуемом порядке (в главном модуле зависит от времени старта цикла). Очередь nextTick выполняется раньше промисов. Внутри I/O-колбэка setImmediate всегда раньше setTimeout(0).

Как решать

СинхронноМикрозадачаМакрозадача
executor new Promise, код async-функции до awaitthen/catch/finally, код после await, queueMicrotask, MutationObserversetTimeout, setInterval, события DOM, MessageChannel, setImmediate (Node.js)

Что важно помнить

  • setTimeout(fn, 0) — не «сразу», а «после всех микрозадач и не раньше следующего витка цикла».
  • Бесконечное добавление микрозадач блокирует рендеринг и макрозадачи.
  • Рендеринг в браузере происходит между макрозадачами — см. event loop и рендеринг.
  • Порядок в Node.js: setTimeout, setImmediate и microtasks.

Мини-шпаргалка

Синхронный код → все микрозадачи (nextTick → промисы) → одна макрозадача → все микрозадачи → … Executor — синхронный, после await — микрозадача, цепочки then чередуются, resolve не прерывает executor.
