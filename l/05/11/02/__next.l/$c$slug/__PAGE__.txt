<div class="callout-title">Кратко</div>
<div class="callout-body"><p><strong>Type guard</strong> — проверка, после которой TypeScript сужает тип. Встроенные guards — <code>typeof</code>, <code>instanceof</code>, <code>in</code>, <code>Array.isArray</code>, сравнения. <strong>Пользовательский type guard</strong> — функция, возвращающая предикат <code>value is T</code>: если она вернула <code>true</code>, в этой ветке значение считается типом <code>T</code>. TypeScript <strong>не проверяет</strong> правильность тела такой функции — ошибка в реализации даст ложное сужение.</p></div>
</div>
<h2 id="вопрос">Вопрос</h2>
<p>Что такое type guard? Как написать свою type guard function и чем она отличается от функции, возвращающей <code>boolean</code>?</p>

<p>Для данных извне надежнее схемы валидации: <code>UserSchema.safeParse(data)</code> из Zod проверяет структуру и дает тип.</p>
<h2 id="что-важно-помнить">Что важно помнить</h2>
<ul>
<li>Предикат <code>x is T</code> должен ссылаться на параметр функции.</li>
<li>Если guard вернул <code>false</code>, в ветке <code>else</code> тип сужается до «исключения» <code>T</code> из исходного union.</li>
<li>Методы класса тоже могут быть guards: <code>isLoaded(): this is LoadedState</code>.</li>
<li>Не путайте type guard (<code>x is T</code>) и assertion function (<code>asserts x is T</code>): вторая бросает ошибку вместо возврата <code>false</code>.</li>
</ul>
<h2 id="мини-шпаргалка">Мини-шпаргалка</h2>
<ul>
<li>Встроенные: <code>typeof</code>, <code>instanceof</code>, <code>in</code>, <code>Array.isArray</code>, <code>===</code>.</li>
<li>Свой guard: <code>function isX(v: unknown): v is X</code>.</li>
<li>Предикат сужает тип, <code>boolean</code> — нет.</li>
<li><code>filter((x): x is T => ...)</code> — сужение массива.</li>
<li>TS не проверяет корректность guard — для внешних данных используйте схемы.</li>
</ul>
