# Какие метрики SEO нужно знать

> [!NOTE]
> SEO-метрики делятся на уровни. **Видимость** (Search Console, Вебмастер): показы, клики, CTR, средняя позиция, запросы. **Индексация и техника**: число проиндексированных страниц, ошибки обхода, 404/5xx, Core Web Vitals. **Поведение и бизнес** (GA4, Метрика): органические сессии, вовлечённость, конверсии, выручка. Ни одна метрика не самодостаточна: позиция без кликов не приносит пользы, клики без конверсий — тоже. Смотрят цепочку «запрос → страница → показы → CTR → клики → конверсии».

## Вопрос

Какие метрики SEO нужно знать и как их интерпретировать?

## Видимость в поиске

| Метрика | Что показывает | Как интерпретировать |
| --- | --- | --- |
| Показы (Impressions) | Сколько раз URL был в выдаче | Видимость и спрос |
| Клики (Clicks) | Переходы из выдачи | Фактический трафик |
| CTR | Клики / показы | Привлекательность сниппета и соответствие запросу |
| Средняя позиция | Средняя позиция URL в выдаче | Ориентир, сильно усредняет |
| Запросы | По каким запросам показывается сайт | Понимание реального спроса |

## Индексация и техника

- Проиндексированные и исключённые страницы (с причинами).
- Ошибки обхода, 404 и 5xx.
- Цепочки редиректов.
- Core Web Vitals по группам URL (LCP, INP, CLS).
- Ошибки structured data и sitemap.

## Поведение и бизнес

- Органические сессии и пользователи.
- Вовлечённые сессии, глубина, время.
- Конверсии (key events): заявки, регистрации, покупки.
- Выручка и ассоциированные конверсии.
- Страницы входа (landing pages).

## Почему позиция — не главное

Средняя позиция зависит от страны, устройства, персонализации, элементов выдачи (карты, видео, AI-ответы) и набора запросов. Рост на 0,5 позиции может ничего не значить, а позиция 1 под AI-ответом даёт меньше кликов, чем раньше. Лучше анализировать связку:

```text
запрос → страница → показы → CTR → клики → конверсии
```

## Типичные паттерны

| Наблюдение | Гипотеза |
| --- | --- |
| Много показов, низкий CTR | Слабый title/description или запрос с другим намерением |
| Позиции 8–20 | Страница близка к росту: улучшить контент и внутренние ссылки |
| Клики упали при стабильных позициях | Сезонность или изменение выдачи (AI-ответы, новые блоки) |
| Трафик есть, конверсий нет | Не тот intent или проблемы посадочной страницы |
| Показы упали резко по всему сайту | Техническая проблема: noindex, robots, падение сервера |

## Частые ошибки

- Отчитываться только позициями.
- Сравнивать периоды без учёта сезонности.
- Не разделять брендовые и небрендовые запросы — бренд растёт от маркетинга, а не от SEO.
- Смотреть сайт целиком вместо групп страниц (категории, товары, статьи).

## Что важно помнить

- Метрики видимости — из Search Console и Вебмастера, поведения — из GA4 и Метрики.
- Конверсии важнее голого трафика.
- Технические метрики объясняют, почему видимость не растёт.

## Мини-шпаргалка

- Показы, клики, CTR, позиция, запросы.
- Индексация, ошибки, Core Web Vitals.
- Сессии, конверсии, выручка.
- Анализировать по группам страниц и с учётом сезонности.
