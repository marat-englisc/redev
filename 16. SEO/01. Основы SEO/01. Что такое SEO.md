# Что такое SEO

> [!NOTE]
> **SEO (Search Engine Optimization)** — работа над сайтом и контентом, чтобы поисковые системы могли **найти**, **понять** и **показать** страницы по релевантным запросам, а пользователи — захотели на них перейти. SEO складывается из технической доступности (обход, индексация, рендеринг), содержания (ответ на намерение пользователя), качества страницы (скорость, мобильность, доступность), доверия (ссылки, репутация) и измерения результата. Хорошее SEO начинается с пользы для людей, а не с манипуляций алгоритмами.

## Вопрос

Что такое SEO и из чего оно состоит?

## Основная идея

Задача SEO — чтобы нужные страницы появлялись в органической выдаче по нужным запросам и приводили целевых пользователей. Для этого страница должна пройти весь путь:

```text
поисковик узнал URL → скачал страницу → увидел контент → решил добавить в индекс
→ счёл лучшим ответом на запрос → пользователь кликнул → выполнил целевое действие
```

На каждом шаге что-то может сломаться, и у каждого шага свои инструменты.

## Направления SEO

| Направление | Что включает |
| --- | --- |
| Техническое SEO | robots.txt, sitemap, статус-коды, canonical, редиректы, рендеринг JS |
| On-page | title, description, заголовки, семантика, внутренние ссылки, изображения |
| Контент | Search intent, полнота и полезность, экспертность, актуальность |
| Качество страницы | Core Web Vitals, мобильная версия, доступность, HTTPS |
| Структурированные данные | Schema.org, rich results |
| Off-page | Ссылки, упоминания, репутация бренда, локальное присутствие |
| Аналитика | Search Console, Яндекс Вебмастер, GA4, Метрика, аудиты |

## Что SEO не гарантирует

- Первое место — позиции зависят от сотен сигналов и конкурентов.
- Быстрый результат — изменения отражаются в выдаче неделями и месяцами.
- Стабильность навсегда — алгоритмы, конкуренты и спрос меняются.
- Трафик от одних мета-тегов — без полезного контента они не работают.

## Роль frontend-разработчика

Разработчик определяет техническую основу: режим рендеринга (SSR, SSG, CSR), HTML-структуру, мета-теги, маршрутизацию и статус-коды, canonical, изображения, производительность, доступность, structured data. Ошибка в шаблоне страницы масштабируется на тысячи URL — поэтому SEO-требования стоит обсуждать на этапе архитектуры, а не после релиза.

## Частые ошибки

- Сводить SEO к мета-тегам и ключевым словам.
- Ждать результата через неделю после правок.
- Использовать манипулятивные приёмы (покупка ссылок, скрытый текст) — это ведёт к санкциям.
- Не измерять результат и не связывать SEO с бизнес-целями.

## Что важно помнить

- SEO = доступность + понятность + полезность + доверие + измерение.
- Техническое SEO — фундамент: без индексации контент и ссылки не работают.
- Оптимизация делается для пользователей и поисковых систем одновременно.

## Мини-шпаргалка

- Найти → обойти → проиндексировать → ранжировать → показать.
- Техника, контент, качество, доверие, аналитика.
- Гарантий топа нет.
- Frontend отвечает за техническую основу.
