# Что такое Google Search Essentials

> [!NOTE]
> **Google Search Essentials** (бывшие Webmaster Guidelines) — официальные правила появления в Google: **технические требования** (Googlebot может получить страницу, она отдаёт 200 и содержит индексируемый контент), **правила против спама** (cloaking, скрытый текст, doorway-страницы, покупка ссылок, массово сгенерированный контент, злоупотребление репутацией сайта) и **ключевые рекомендации** (полезный контент для людей, понятные заголовки и ссылки, удобство страницы). Нарушение правил грозит ручными санкциями и потерей видимости, невыполнение технических требований — тем, что страницы просто не попадут в индекс.

## Вопрос

Что такое Google Search Essentials и что в них входит?

## Три части

**1. Технические требования** — минимум, без которого страница не появится в поиске:

- Googlebot не заблокирован (robots.txt, firewall, авторизация);
- страница отдаёт HTTP 200;
- есть индексируемый контент в поддерживаемом формате (HTML, PDF, изображения).

**2. Правила против спама** — что приводит к понижению или исключению:

| Нарушение | Суть |
| --- | --- |
| Cloaking | Разный контент для пользователей и робота |
| Doorway pages | Множество почти одинаковых страниц под вариации запросов |
| Hidden text and links | Текст, видимый роботу, но скрытый от людей |
| Keyword stuffing | Перенасыщение ключевыми словами |
| Link spam | Купленные и обменные ссылки для передачи веса |
| Scaled content abuse | Массовое производство страниц без ценности, в том числе с помощью ИИ |
| Scraped content | Копирование чужого контента без добавленной ценности |
| Site reputation abuse | Размещение стороннего низкокачественного контента на авторитетном домене |
| Expired domain abuse | Покупка домена с историей ради его авторитета |
| Hacked content, malware | Взломанные страницы, вредоносный код |

**3. Ключевые рекомендации:**

- создавать полезный, надёжный контент для людей;
- использовать слова, которыми люди ищут, в заметных местах: title, заголовки, alt, текст ссылок;
- делать ссылки индексируемыми (`<a href>`), чтобы робот находил страницы;
- рассказывать о сайте там, где есть его аудитория;
- следовать рекомендациям для изображений, видео, structured data, JavaScript;
- обеспечивать хороший page experience.

## Санкции

- **Ручные меры** — сотрудник Google вручную понижает сайт; уведомление приходит в Search Console, после исправления можно отправить запрос на пересмотр.
- **Алгоритмические** — сайт теряет позиции после обновления системы (например, борьбы со спамом); уведомлений нет, восстановление — после исправления и переобхода.

## Частые ошибки

- Генерировать тысячи однотипных страниц «под город» или «под ключ».
- Покупать ссылки и считать это нормальной практикой.
- Показывать роботу пререндеренную версию, отличающуюся по содержанию от пользовательской (prerender с тем же контентом — нормально).
- Публиковать на домене сторонние партнёрские статьи без контроля качества.

## Что важно помнить

- Search Essentials — граница: что ниже — спам, что выше — нормальная оптимизация.
- Технические требования проверяются в Search Console через URL Inspection.
- У Яндекса аналогичные правила — «Рекомендации Яндекса к сайтам» и описание нарушений в Вебмастере.

## Мини-шпаргалка

- Технические требования: доступ, 200, индексируемый контент.
- Спам: cloaking, doorway, скрытый текст, ссылки, массовый контент.
- Рекомендации: полезный контент, понятные заголовки, индексируемые ссылки.
- Ручные меры — в Search Console.
