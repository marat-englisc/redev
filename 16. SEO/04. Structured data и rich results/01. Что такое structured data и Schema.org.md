# Что такое structured data и Schema.org

> [!NOTE]
> **Structured data** — машиночитаемое описание сущностей страницы: это товар с ценой и наличием, статья с автором и датой, организация с логотипом, хлебные крошки, событие, видео. **Schema.org** — общий словарь типов (`Product`, `Article`, `Organization`, `BreadcrumbList`) и свойств, который поддерживают Google, Яндекс, Bing. Предпочтительный формат — **JSON-LD** в `<script type="application/ld+json">`. Разметка снимает неоднозначность и делает страницу **eligible** (пригодной) для **rich results** — расширенных сниппетов, — но не гарантирует их и не является прямым фактором ранжирования.

## Вопрос

Что такое structured data и зачем нужна Schema.org?

## Зачем

Без разметки поисковик сам догадывается, что на странице:

```text
«Keychron K2 … 9 990 ₽ … В наличии … ★ 4.8 (124 отзыва)»
```

С разметкой он знает это точно:

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Keychron K2",
  "offers": { "@type": "Offer", "price": "9990", "priceCurrency": "RUB", "availability": "https://schema.org/InStock" },
  "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "124" }
}
```

Результат — шанс получить сниппет с ценой, наличием и звёздами, попасть в товарные блоки и точнее отвечать в AI-ответах.

## Форматы

| Формат | Как выглядит | Когда |
| --- | --- | --- |
| **JSON-LD** | Отдельный `<script type="application/ld+json">` | Рекомендуется Google, удобен во фреймворках |
| Microdata | Атрибуты `itemscope`, `itemprop` в HTML | Старые CMS |
| RDFa | Атрибуты `vocab`, `property` | Редко |

JSON-LD не смешивается с разметкой контента, поэтому его проще генерировать из данных и поддерживать.

## Часто используемые типы

| Тип | Где |
| --- | --- |
| `Organization`, `WebSite` | Сайт целиком |
| `BreadcrumbList` | Вложенные страницы |
| `Article`, `BlogPosting`, `NewsArticle` | Публикации |
| `Product`, `Offer`, `AggregateRating`, `Review` | Товары |
| `LocalBusiness` | Офлайн-точки |
| `Event` | Мероприятия |
| `VideoObject` | Видео |
| `JobPosting` | Вакансии |
| `Recipe` | Рецепты |
| `FAQPage` | Вопросы и ответы (rich result — только для авторитетных гос- и медсайтов) |

## Правила

- Разметка соответствует **видимому** контенту страницы.
- Обязательные свойства типа заполнены, рекомендуемые — по возможности.
- Данные актуальны (цена, наличие, даты).
- Никаких фейковых отзывов и скрытого контента.

Нарушение правил structured data может привести к ручным мерам, после которых rich results перестают показываться для всего сайта.

## Частые ошибки

- Считать разметку фактором ранжирования «сама по себе».
- Размечать то, чего нет на странице.
- Копировать примеры без адаптации — остаются чужие названия и URL.
- Добавлять разметку только в клиентском JS.

## Что важно помнить

- Structured data — способ однозначно описать страницу машине.
- Валидность ≠ показ rich result: решает поисковик.
- JSON-LD генерируется из тех же данных, что и UI, — так они не разойдутся.

## Мини-шпаргалка

- Schema.org — словарь, JSON-LD — формат.
- Eligible, а не гарантировано.
- Соответствие видимому контенту.
- Основные типы: Organization, Breadcrumb, Article, Product.
