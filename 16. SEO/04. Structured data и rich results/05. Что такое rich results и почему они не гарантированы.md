# Что такое rich results и почему они не гарантированы

> [!NOTE]
> **Rich results (расширенные результаты)** — результаты поиска с дополнительными элементами: цена, наличие и рейтинг товара, хлебные крошки, превью видео, даты событий, вакансии, рецепты. Structured data делает страницу **eligible** — пригодной для такого показа, — но решение принимает поисковик: он учитывает соответствие правилам, качество сайта, доверие к данным, запрос и формат выдачи. Набор поддерживаемых типов меняется: например, Google ограничил FAQ-сниппеты авторитетными сайтами здравоохранения и госорганов, убрал HowTo и блок поиска по сайту.

## Вопрос

Что такое rich results и почему валидная разметка не гарантирует их показ?

## Примеры rich results

| Тип | Что добавляется в выдачу |
| --- | --- |
| Product / Merchant listing | Цена, наличие, рейтинг, доставка |
| Review snippet | Звёзды рейтинга |
| Breadcrumb | Путь вместо URL |
| Video | Превью, длительность, ключевые моменты |
| Article | Крупное изображение, дата (в Top stories, Discover) |
| Event | Даты и место |
| JobPosting | Карточка вакансии в Google Jobs |
| Recipe | Время, калории, рейтинг |
| Organization | Логотип в панели знаний |

## Что изменилось за последние годы

- **FAQ** (2023): расширенные FAQ-сниппеты показываются только для авторитетных государственных и медицинских сайтов.
- **HowTo** (2023): больше не показывается.
- **Sitelinks search box** (2024): удалён из выдачи.
- Часть сниппетов уступает место AI-ответам.

Поэтому разметку выбирают по текущей документации Google, а не по старым статьям.

## Почему rich result может не показаться

- Разметка не соответствует правилам или видимому контенту.
- Не заполнены обязательные свойства.
- Поисковик не доверяет данным (например, рейтинг выглядит накрученным).
- Качество сайта в целом недостаточно.
- Для конкретного запроса расширенный формат не нужен.
- Тип не поддерживается в регионе или на устройстве.
- К сайту применены ручные меры за spam в structured data.

## Как повысить шансы

- Использовать поддерживаемый тип и выполнить все обязательные требования.
- Показывать размеченные данные на странице.
- Поддерживать актуальность (цены, наличие, даты).
- Улучшать качество страницы и сайта.
- Следить за отчётами «Улучшения» в Search Console.

## Отчёты

- Search Console: отчёты по каждому типу rich result (валидные, с предупреждениями, с ошибками) и фильтр «Вид в поиске» в отчёте «Эффективность» — сколько показов и кликов дали расширенные сниппеты.
- Яндекс Вебмастер: «Микроразметка» — валидатор и статистика.

## Частые ошибки

- Обещать клиенту «звёзды в выдаче» после добавления разметки.
- Размечать FAQ на каждой странице ради сниппета.
- Не проверять, поддерживается ли тип сейчас.

## Что важно помнить

- Разметка даёт право претендовать, а не гарантию.
- Набор rich results меняется — сверяйтесь с документацией.
- Rich results влияют прежде всего на CTR, а не на позицию.

## Мини-шпаргалка

- Rich result = расширенный сниппет.
- Eligible ≠ показан.
- FAQ ограничен, HowTo и sitelinks search box удалены.
- Актуальность и честность данных.
- Search Console → «Улучшения».
