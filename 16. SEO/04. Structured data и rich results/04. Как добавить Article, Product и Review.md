# Как добавить Article, Product и Review

> [!NOTE]
> **`Article`** (и подтипы `BlogPosting`, `NewsArticle`) описывает публикацию: заголовок, изображение, автор, даты публикации и обновления. **`Product`** — конкретный товар с вложенными `Offer` (цена, валюта, наличие, условия доставки и возврата) и `AggregateRating`/`Review` (рейтинг и отзывы). Отзывы размечают только **реальные и видимые** на странице; отзывы компании о самой себе (self-serving) на `Organization`/`LocalBusiness` для звёзд в выдаче не подходят. Цена и наличие в разметке должны совпадать с интерфейсом и обновляться вместе с ним.

## Вопрос

Как разметить статьи, товары и отзывы?

## Article

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "Core Web Vitals простыми словами",
  "description": "Что такое LCP, INP и CLS и как их улучшать.",
  "image": [
    "https://example.com/images/web-vitals-16x9.png",
    "https://example.com/images/web-vitals-4x3.png",
    "https://example.com/images/web-vitals-1x1.png"
  ],
  "datePublished": "2026-07-20T09:00:00+03:00",
  "dateModified": "2026-09-01T18:00:00+03:00",
  "author": [{ "@type": "Person", "name": "Анна Петрова", "url": "https://example.com/authors/anna" }]
}
</script>
```

`dateModified` обновляют только при существенных изменениях — подделка «свежести» не помогает.

## Product

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Keychron K2 Pro",
  "image": ["https://shop.example.com/images/k2-pro.webp"],
  "description": "Беспроводная механическая клавиатура 75% с горячей заменой переключателей.",
  "sku": "K2P-RGB-BR",
  "gtin13": "4710000000000",
  "brand": { "@type": "Brand", "name": "Keychron" },
  "offers": {
    "@type": "Offer",
    "url": "https://shop.example.com/products/keychron-k2-pro",
    "price": "11990",
    "priceCurrency": "RUB",
    "availability": "https://schema.org/InStock",
    "itemCondition": "https://schema.org/NewCondition",
    "priceValidUntil": "2026-12-31"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "reviewCount": "124"
  }
}
</script>
```

Для вариантов (цвета, размеры) — `ProductGroup` с `hasVariant`; для нескольких продавцов — `AggregateOffer` с `lowPrice` и `highPrice`. Расширенные товарные блоки Google (merchant listings) дополнительно используют `shippingDetails` и `hasMerchantReturnPolicy`.

## Review

```json
"review": [{
  "@type": "Review",
  "author": { "@type": "Person", "name": "Иван" },
  "datePublished": "2026-08-10",
  "reviewRating": { "@type": "Rating", "ratingValue": "5", "bestRating": "5" },
  "reviewBody": "Отличная клавиатура, батарея держит две недели."
}]
```

Отзыв размечают внутри товара, о котором он написан, и только если он виден на странице.

## Правила для e-commerce

- Product — на карточке конкретного товара, а не на категории.
- Цена и наличие синхронизированы с UI (генерировать из тех же данных).
- Рейтинг — из реальных отзывов, видимых на странице.
- Нет товара — `OutOfStock`, а не удаление разметки или фиктивная цена.

## Частые ошибки

- `Product` на странице категории со списком товаров.
- Цена в разметке отличается от цены на странице или устарела.
- Рейтинг без видимых отзывов или «звёзды» за весь магазин.
- Цена с пробелами и символом валюты.
- Отзывы компании о самой себе на `Organization`.

## Что важно помнить

- Article — для публикаций, Product — для конкретного товара, Review — для реальных отзывов.
- Разметка генерируется из данных интерфейса, иначе неизбежно расхождение.
- Нарушения в отзывах — частая причина ручных мер.

## Мини-шпаргалка

- Article: headline, image, author, datePublished, dateModified.
- Product: name, image, offers (price, priceCurrency, availability), brand, sku.
- AggregateRating/Review — только реальные и видимые.
- `OutOfStock` вместо удаления.
