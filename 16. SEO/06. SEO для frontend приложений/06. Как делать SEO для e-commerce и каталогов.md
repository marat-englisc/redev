# Как делать SEO для e-commerce и каталогов

> [!NOTE]
> SEO интернет-магазина — это управление **шаблонами** на тысячах URL: категории и подкатегории (обычно главный источник органического трафика), карточки товаров, бренды, полезные фильтры-посадочные, контент (гайды, сравнения). Ключевые задачи: решить, что индексировать (корзину, кабинет, внутренний поиск, сортировки и мусорные комбинации фильтров — нет), уникальные title и описания категорий и товаров, разметка `Product`/`Offer`/`BreadcrumbList`, политика для отсутствующих и удалённых товаров, пагинация с доступом ко всем товарам, скорость карточек и листингов. Ошибка в шаблоне умножается на весь каталог.

## Вопрос

Как делать SEO для интернет-магазинов и каталогов?

## Типы страниц и индексация

| Страница | Индексировать | Комментарий |
| --- | --- | --- |
| Главная | Да | |
| Категории и подкатегории | Да | Главные посадочные под коммерческие запросы |
| Бренды | Да, при спросе | |
| Фильтры со спросом («ноутбуки apple», «игровые ноутбуки») | Да | Отдельный «чистый» URL и уникальный контент |
| Карточки товаров | Да | |
| Гайды, сравнения, подборки | Да | Информационный трафик и ссылки |
| Сортировки, вид отображения | Нет | canonical на базовую страницу |
| Мусорные комбинации фильтров | Нет | Без ссылок, robots.txt или noindex |
| Внутренний поиск | Нет | `noindex` |
| Корзина, оформление, кабинет | Нет | Авторизация, `noindex` |

## Категория

- Уникальный title и h1: «Механические клавиатуры — купить в Москве».
- Краткий полезный текст (подбор, отличия), не простыня «для SEO» под листингом.
- Ссылки на подкатегории и популярные фильтры.
- Пагинация со ссылками на страницы, каждая — self-canonical.
- `BreadcrumbList`, при желании `ItemList`.

## Карточка товара

- Уникальный title: название, ключевая характеристика, «купить».
- Собственное описание, а не текст производителя, скопированный на сотни сайтов.
- Характеристики в HTML (таблица), а не только картинкой.
- Изображения с `alt`, несколько ракурсов.
- Отзывы и вопросы покупателей — уникальный контент.
- `Product` + `Offer` (цена, наличие) + `AggregateRating`, синхронно с UI.
- Один канонический URL независимо от категории, из которой пришёл пользователь.
- Варианты (цвет, размер): либо один URL с выбором, либо отдельные URL с canonical/`ProductGroup` — по спросу на варианты.

## Нет в наличии и удалён

| Ситуация | Решение |
| --- | --- |
| Временно нет | 200, `OutOfStock` в разметке, альтернативы, подписка на поступление |
| Снят с продажи, есть замена | 301 на новую модель или ближайшую категорию |
| Снят, замены нет, страница не нужна | 404/410 |
| Снят, но страница полезна (характеристики, отзывы) | 200 с пометкой «снят с производства» и альтернативами |

Массовые редиректы удалённых товаров на главную — soft 404.

## Производительность

Листинги и карточки — самые посещаемые шаблоны: оптимизированные изображения, `width`/`height`, LCP-изображение без lazy, кэширование HTML (SWR/ISR), осторожность со сторонними скриптами (рекомендации, чаты, аналитика).

## Merchant Center и маркетплейсы

Товарные блоки в Google (Shopping, бесплатные листинги) используют фид Merchant Center и structured data. Данные фида и сайта должны совпадать — цены, наличие, GTIN.

## Частые ошибки

- Индексация всех комбинаций фильтров.
- Пустые категории с одним SEO-текстом.
- Описания, скопированные у поставщика.
- Товар доступен по нескольким URL без canonical.
- Цена в разметке не совпадает с ценой на сайте.
- Пагинация через «Показать ещё» без URL — товары с дальних страниц не находятся.

## Что важно помнить

- Категории часто приносят больше трафика, чем отдельные товары.
- Решения о фильтрах — продуктово-SEO-шные: какие комбинации получают свою страницу.
- Шаблоны тестируют автоматически: title, canonical, разметка, статусы.

## Мини-шпаргалка

- Индексировать: категории, товары, бренды, полезные фильтры, контент.
- Не индексировать: сортировки, поиск, корзину, кабинет, мусорные фильтры.
- Product + Offer + Breadcrumb, синхронно с UI.
- Политика для отсутствующих и удалённых товаров.
- Скорость листингов и карточек.
