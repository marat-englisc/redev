# Как проводить content audit

> [!NOTE]
> **Контент-аудит** — инвентаризация страниц сайта с данными о трафике, видимости, конверсиях, ссылках и качестве, чтобы для каждой принять решение: **оставить**, **обновить**, **объединить**, **перенаправить** или **удалить/закрыть**. Он находит точки роста (страницы на позициях 8–20, страницы с показами без кликов), устаревший контент, **каннибализацию** (несколько страниц под одно намерение) и балласт, который тянет вниз оценку сайта. Обновление сильной существующей страницы часто эффективнее новой статьи.

## Вопрос

Как проводить аудит контента?

## Что собрать по каждой странице

| Данные | Источник |
| --- | --- |
| URL, тип, целевой кластер | Краулер, карта страниц |
| Title, h1, объём, дата обновления | Краулер, CMS |
| Клики, показы, CTR, позиция, запросы | Search Console |
| Сессии, вовлечённость, конверсии | GA4, Метрика |
| Внешние ссылки | Ahrefs, Search Console «Ссылки» |
| Статус индексации | Search Console |

## Матрица решений

| Ситуация | Решение |
| --- | --- |
| Хороший трафик и конверсии | Оставить, периодически обновлять |
| Показы есть, CTR низкий | Переписать title и description под намерение |
| Позиции 8–20 | Расширить, добавить примеры, внутренние ссылки |
| Устаревшая информация | Обновить факты, примеры, дату изменения |
| Несколько страниц про одно | Объединить в одну сильную, 301 со слабых |
| Нет трафика, но есть ссылки | Улучшить или 301 на релевантную страницу |
| Нет трафика, ссылок и ценности | Удалить (404/410) или `noindex` |
| Тонкие страницы-шаблоны | Наполнить или закрыть от индексации |

## Каннибализация

```text
/blog/seo-checklist
/blog/technical-seo-checklist
/blog/full-seo-checklist
```

Если все три отвечают на одно намерение, поисковик колеблется между ними, и ни одна не набирает силу. Признак в Search Console — по одному запросу чередуются разные URL. Решение — объединить контент в одну страницу и сделать 301 с остальных или развести их по разным намерениям.

## Как улучшать старый контент

- Сверить с текущей выдачей: какие подтемы и форматы у лидеров.
- Обновить факты, версии, скриншоты, примеры кода.
- Добавить собственный опыт, данные, таблицы, схемы.
- Улучшить структуру: заголовки-вопросы, оглавление, краткий ответ в начале.
- Добавить внутренние ссылки из новых материалов и на них.
- Убрать «воду» и повторы.
- Обновить title и description.

## Частые ошибки

- Массово удалять старые страницы без анализа ссылок и трафика.
- Менять дату публикации без изменения содержания.
- Объединять страницы без 301.
- Аудит без последующего плана работ.

## Что важно помнить

- Аудит ищет рост в том, что уже есть.
- Решения учитывают трафик, ссылки, конверсии и бизнес-ценность.
- Регулярность: крупный аудит раз в год, точечные проверки — ежеквартально.

## Мини-шпаргалка

- Инвентаризация: URL + GSC + GA4 + ссылки.
- Оставить / обновить / объединить / 301 / удалить.
- Каннибализация — один intent, одна страница.
- Позиции 8–20 — быстрые победы.
