# Как использовать GA4 для SEO

> [!NOTE]
> Search Console показывает, что происходит **до клика** (показы, запросы, позиции), а **Google Analytics 4** — что **после**: сессии из органического поиска, страницы входа, вовлечённость, события и **ключевые события** (конверсии), выручка. Для SEO в GA4 смотрят отчёт «Привлечение трафика» с фильтром `Organic Search`, отчёт по страницам входа, воронки и исследования; связывают GA4 с Search Console, чтобы видеть запросы рядом с поведением. Аналог для Яндекса — Метрика (с Вебвизором). Корректные данные требуют настроенных событий, исключения внутреннего трафика и учёта режима согласия на cookies.

## Вопрос

Как использовать GA4 для анализа SEO?

## GA4 и Search Console

| | Search Console | GA4 |
| --- | --- | --- |
| Что показывает | Показы, клики, CTR, позиции, запросы | Сессии, поведение, события, конверсии |
| Момент | До клика | После клика |
| Запросы | Да | Нет (только через связку с GSC) |
| Конверсии | Нет | Да |

```text
GSC:  страница /seo-audit — 10 000 показов, 500 кликов
GA4:  эти визиты дали 40 заявок, конверсия 8%
```

## Полезные отчёты

- **Привлечение → Привлечение трафика**, группа каналов `Organic Search` — сессии, вовлечённость, ключевые события по каналу.
- **Вовлечённость → Страницы входа (Landing page)** с фильтром по органике — какие страницы приводят и конвертируют.
- **Search Console** (после связки) — запросы и страницы GSC рядом с данными поведения.
- **Исследования** — воронки, пути, сегменты (органика × устройство × регион).

## Что настроить

- Ключевые события: заявка, регистрация, покупка, звонок.
- Электронная торговля (`purchase`, `add_to_cart`) для магазинов.
- Исключение внутреннего трафика и тестовых окружений.
- Связка с Search Console.
- UTM-метки для кампаний, чтобы не смешивать их с органикой.
- Consent Mode — при обязательном согласии на cookies часть данных моделируется.

## Особенности SPA

В SPA переходы происходят без перезагрузки — `page_view` должен отправляться при каждой смене маршрута. GA4 умеет это через «Расширенную статистику» (изменения истории браузера); для надёжности события отправляют из роутера:

```ts
router.afterEach((to) => {
  gtag("event", "page_view", { page_path: to.fullPath, page_title: document.title });
});
```

Важно, чтобы `document.title` уже был обновлён на момент отправки.

## Частые ошибки

- Оценивать SEO по сессиям без конверсий.
- Не исключать внутренний трафик.
- Потерянные `page_view` в SPA — заниженные показатели.
- Рекламный трафик без UTM попадает в органику или «прямые заходы».
- Сравнивать данные GA4 и GSC «в лоб»: клики ≠ сессии.

## Что важно помнить

- GSC — видимость, GA4 — результат.
- Ключевые события должны соответствовать бизнес-целям.
- В SPA отслеживание просмотров страниц — ответственность разработчика.

## Мини-шпаргалка

- Привлечение трафика → Organic Search.
- Страницы входа + ключевые события.
- Связка GA4 и Search Console.
- `page_view` на смену маршрута в SPA.
- Внутренний трафик исключить, UTM для кампаний.
