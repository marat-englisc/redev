# Как читать Google Search Console

> [!NOTE]
> **Google Search Console** — бесплатная панель, показывающая сайт глазами Google. Основные разделы: **«Эффективность»** (клики, показы, CTR, позиция по запросам, страницам, странам, устройствам, типам выдачи), **«Индексирование страниц»** (что в индексе и почему остальное исключено), **«Файлы Sitemap»**, **«Проверка URL»** (статус конкретной страницы, выбранный canonical, отрендеренный HTML), **«Основные интернет-показатели»** (Core Web Vitals по группам URL), **«Улучшения»** (structured data), **«Меры, принятые вручную»** и **«Безопасность»**. Данные — с задержкой 2–3 дня, история — 16 месяцев. Аналог для Яндекса — Вебмастер.

## Вопрос

Как читать отчёты Google Search Console?

## Эффективность

Измерения: запросы, страницы, страны, устройства, вид в поиске, даты. Метрики: клики, показы, CTR, средняя позиция.

| Наблюдение | Что проверить |
| --- | --- |
| Много показов, низкий CTR | Title, description, соответствие намерению, элементы выдачи над результатом |
| Позиции 8–20 | Расширить контент, внутренние ссылки — кандидаты на быстрый рост |
| Падение кликов при стабильных позициях | Сезонность, AI-ответы и новые блоки в выдаче |
| Резкое падение показов по всему сайту | Технические проблемы, `noindex`, robots, ручные меры |
| Одна страница ранжируется по запросам разных намерений | Возможная каннибализация или нужно разделить страницу |

Фильтр по регулярным выражениям позволяет отделить брендовые запросы: `запрос не соответствует регулярному выражению brand|бренд`.

## Индексирование страниц

Показывает проиндексированные и непроиндексированные URL с причинами:

| Причина | Смысл |
| --- | --- |
| Обнаружена, не проиндексирована | Google знает URL, но ещё не обходил (бюджет, приоритет) |
| Просканирована, но пока не проиндексирована | Обошёл, но решил не индексировать (качество, дубль) |
| Страница с переадресацией | Нормально для старых URL |
| Исключено тегом noindex | Проверить, что так задумано |
| Заблокировано в robots.txt | Проверить, что так задумано |
| Дубликат, канонический вариант не выбран пользователем | Нет canonical, Google выбрал сам |
| Google выбрал другую каноническую страницу | Сигналы противоречат вашему canonical |
| Не найдено (404) / Ложная ошибка 404 | Удалённые страницы / soft 404 |
| Ошибка сервера (5xx) | Проблемы доступности |

## Проверка URL

- Есть ли страница в индексе и когда был последний обход.
- Какой canonical указан и какой выбрал Google.
- «Проверить страницу на сайте» — отрендеренный HTML, скриншот, заблокированные ресурсы, ошибки JS.
- «Запросить индексирование» — для новых и обновлённых важных страниц (с лимитом).

## Другие отчёты

- **Sitemap** — сколько URL отправлено и найдено.
- **Основные интернет-показатели** — группы URL с плохими LCP, INP, CLS (полевые данные).
- **Улучшения** — ошибки и предупреждения structured data по типам.
- **Ссылки** — внешние и внутренние ссылки, анкоры.
- **Статистика сканирования** (Настройки) — объём обхода, коды ответов, время ответа.
- **Меры, принятые вручную** и **Проблемы безопасности**.

## Частые ошибки

- Смотреть только итоговую сумму кликов без разрезов.
- Паниковать из-за «исключённых» корзины и сортировок — это нормально.
- Игнорировать «Google выбрал другую каноническую».
- Сравнивать короткие периоды без учёта сезонности.

## Что важно помнить

- «Эффективность» — спрос и видимость, «Индексирование» — техническое здоровье.
- «Проверка URL» — главный инструмент диагностики конкретной страницы.
- Данные Search Console выборочные и с задержкой, но это единственный источник поисковых запросов от Google.

## Мини-шпаргалка

- Эффективность: клики, показы, CTR, позиция × запросы, страницы.
- Индексирование: причины исключения.
- Проверка URL: canonical, рендер, последний обход.
- CWV, Улучшения, Ссылки, Статистика сканирования.
- Регулярки для брендовых запросов.
