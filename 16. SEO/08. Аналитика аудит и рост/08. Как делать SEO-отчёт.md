# Как делать SEO-отчёт

> [!NOTE]
> SEO-отчёт объясняет **что изменилось, почему это важно и что делаем дальше**. Структура: цели периода и статус → ключевые метрики (небрендовые клики и показы, органические конверсии, индексация, Core Web Vitals) с сравнением год к году → драйверы роста и падения по разделам и страницам → выполненные работы и их эффект → риски и проблемы → план на следующий период. Факты отделяют от гипотез, графики сопровождают выводами, а технические задачи для разработчиков оформляют с URL-примерами и критериями приёмки.

## Вопрос

Как сделать полезный SEO-отчёт для команды и руководства?

## Структура

1. **Итог в трёх строках** — главное для руководства.
2. **Цели и статус** — что планировали, что достигнуто.
3. **Метрики** — клики (небрендовые отдельно), показы, CTR, конверсии, выручка из органики; сравнение с прошлым периодом и год к году.
4. **Драйверы** — какие разделы и страницы выросли и упали, почему.
5. **Техническое здоровье** — индексация, ошибки, Core Web Vitals.
6. **Выполненные работы** — что сделано и какой эффект.
7. **Риски** — проблемы, апдейты алгоритмов, конкуренты.
8. **План** — задачи на следующий период с приоритетами и владельцами.

## Как писать выводы

```text
✗ Трафик вырос на 12%.

✓ Небрендовые клики выросли на 12% г/г после обновления категорий /laptops и /monitors.
  Основной вклад — CTR по коммерческим запросам (+1,8 п.п.) после смены шаблона title.
  Конверсии из органики +9%.
```

## Факты и гипотезы

```text
Факт:     клики страницы /seo-audit выросли с 320 до 510 за 28 дней.
Гипотеза: вероятная причина — новый title и блок с чек-листом; часть роста может быть
          сезонной (в прошлом году за этот период +15%).
```

## Для разработчиков

Технические пункты оформляют как задачи:

- конкретные URL и шаблон;
- воспроизведение (как увидеть проблему);
- приоритет и ожидаемый эффект;
- критерии приёмки (`curl` возвращает 404, LCP < 2,5 с в лаборатории);
- ссылка на инструмент проверки.

## Частота и автоматизация

- Еженедельно — короткий дашборд аномалий (Looker Studio, DataLens): клики, ошибки, индексация.
- Ежемесячно — отчёт с выводами.
- Ежеквартально — стратегический обзор и пересмотр приоритетов.

## Частые ошибки

- Отчёт из графиков без выводов.
- Общий трафик без разделения бренда и не-бренда.
- Нет сравнения год к году.
- Нет плана действий.
- Приписывать рост SEO без учёта сезонности и маркетинга.

## Что важно помнить

- Отчёт ведёт к решениям, а не к красивым графикам.
- Конверсии важнее трафика.
- Факты и интерпретации разделяются явно.

## Мини-шпаргалка

- Итог → цели → метрики → драйверы → здоровье → работы → риски → план.
- Небрендовые клики, конверсии, г/г.
- Факт ≠ гипотеза.
- Задачи для разработки — с URL и критериями приёмки.
