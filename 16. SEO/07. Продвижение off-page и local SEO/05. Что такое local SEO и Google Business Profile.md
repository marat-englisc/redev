# Что такое local SEO и Google Business Profile

> [!NOTE]
> **Local SEO** — продвижение бизнеса по локальным запросам («стоматология рядом», «ремонт macbook москва») в картах и локальном блоке выдачи. Основа — карточка организации: **Google Business Profile** в Google и **Яндекс Бизнес** в Яндексе (карты, поиск, навигатор). Google ранжирует локальные результаты по трём группам факторов: **релевантность** (насколько профиль соответствует запросу), **расстояние** до пользователя и **известность** (отзывы, рейтинг, упоминания, ссылки, позиции сайта). Важны полнота профиля, совпадение NAP (название, адрес, телефон) везде, реальные отзывы и ответы на них, локальные страницы на сайте.

## Вопрос

Что такое локальное SEO и как работает карточка организации?

## Кому нужно

Бизнесу с географией: кафе, клиники, салоны, сервисы, школы, магазины с офлайн-точками, доставка в городе, агентства, юристы.

```text
стоматология рядом
курсы английского казань
ремонт macbook москва
```

## Карточка организации

| Поле | Совет |
| --- | --- |
| Название | Реальное название без ключевых слов («Стоматология Улыбка», а не «Стоматология Улыбка лечение зубов недорого») |
| Категория | Точная основная + дополнительные |
| Адрес или зона обслуживания | Совпадает с сайтом и каталогами |
| Телефон, сайт | Актуальные |
| Часы работы | Включая праздничные |
| Фото | Реальные: фасад, интерьер, команда, работы |
| Услуги и товары | С ценами, если возможно |
| Отзывы | Отвечать на все, особенно на негативные |

## Факторы локального ранжирования

| Группа | Что влияет |
| --- | --- |
| Релевантность | Категории, описание, услуги, соответствие запросу |
| Расстояние | Местоположение пользователя или города в запросе |
| Известность | Количество и качество отзывов, рейтинг, упоминания, ссылки, позиции сайта в обычной выдаче |

## NAP-консистентность

**NAP** — Name, Address, Phone. Одинаковые данные на сайте, в карточках Google и Яндекса, в каталогах (2ГИС, отраслевые справочники) помогают поисковикам уверенно связать сущность бизнеса.

## Сайт для локального SEO

- Страница контактов с адресом, картой, часами.
- Отдельные страницы для каждого филиала с уникальным контентом (не шаблонные дубли с заменой города).
- `LocalBusiness` (или подтип) в structured data с адресом, координатами и часами.
- Ссылка на сайт из карточки ведёт на соответствующую страницу филиала.

```json
{
  "@context": "https://schema.org",
  "@type": "Dentist",
  "name": "Стоматология Улыбка",
  "address": { "@type": "PostalAddress", "streetAddress": "ул. Ленина, 1", "addressLocality": "Казань", "postalCode": "420000", "addressCountry": "RU" },
  "telephone": "+7-843-000-00-00",
  "openingHours": "Mo-Fr 09:00-20:00",
  "geo": { "@type": "GeoCoordinates", "latitude": 55.79, "longitude": 49.12 }
}
```

## Частые ошибки

- Ключевые слова в названии организации — нарушение правил, риск блокировки карточки.
- Накрутка отзывов.
- Разные телефоны и адреса на разных площадках.
- Сотни страниц «услуга + город» для городов без реального присутствия (doorway-страницы).
- Не отвечать на отзывы.

## Что важно помнить

- Карточка организации часто приносит больше обращений, чем сайт.
- Отзывы — главный управляемый фактор известности.
- Для России критичен Яндекс Бизнес наравне с Google Business Profile.

## Мини-шпаргалка

- Google Business Profile + Яндекс Бизнес.
- Релевантность, расстояние, известность.
- NAP одинаковый везде.
- Реальные отзывы и ответы на них.
- `LocalBusiness` и страницы филиалов.
