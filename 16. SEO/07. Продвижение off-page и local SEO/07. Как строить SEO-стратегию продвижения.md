# Как строить SEO-стратегию продвижения

> [!NOTE]
> SEO-стратегия связывает **бизнес-цели** с действиями: цели и KPI → аудит текущего состояния (техника, контент, ссылки, конкуренты) → анализ аудитории и намерений → keyword research и **карта страниц** → технический бэклог → план контента → план продвижения и дистрибуции → аналитика → цикл улучшений. Задачи приоритизируют по формуле «влияние × уверенность / усилия», начиная с блокеров индексации и быстрых побед. Без стратегии SEO превращается в случайные правки title и публикацию статей без системы.

## Вопрос

Как построить SEO-стратегию продвижения?

## Компоненты

1. **Цели и KPI** — что должно вырасти: заявки, продажи, регистрации.
2. **Аудит** — техническое состояние, индексация, контент, ссылки, Core Web Vitals.
3. **Конкуренты** — кто в топе по целевым запросам и почему.
4. **Аудитория и intent** — какие задачи решают пользователи.
5. **Keyword research → карта страниц** — какие страницы нужны и какие есть.
6. **Технический бэклог** — исправления с приоритетами.
7. **Контент-план** — новые страницы и обновление существующих.
8. **Продвижение** — PR, партнёрства, дистрибуция, локальные профили.
9. **Аналитика и отчётность** — что измеряем и как часто.
10. **Цикл улучшений** — гипотеза → реализация → измерение.

## Пример для SaaS

```text
Цель:        заявки на демо из органики +30% за 6 месяцев.
Страницы:    продуктовые лендинги, сравнения с конкурентами, use cases, блог, документация.
Контент:     статьи под боли пользователей, коммерческие сравнения, интеграции.
Техника:     SSR для маркетинговых страниц, structured data, Core Web Vitals, sitemap, редиректы.
Продвижение: исследования рынка, страницы интеграций у партнёров, выступления.
Метрики:     органические клики, заявки на демо, конверсия посадочных, индексация.
```

## Приоритизация

```text
приоритет = влияние × уверенность / усилия
```

| Задача | Влияние | Усилия | Приоритет |
| --- | --- | --- | --- |
| Убрать `noindex` с категорий | Высокое | Низкие | Высокий |
| Исправить soft 404 на 2000 товаров | Высокое | Средние | Высокий |
| Оптимизировать LCP карточки товара | Высокое | Средние | Высокий |
| Обновить title страниц на позициях 8–20 | Среднее | Низкие | Высокий |
| Написать 40 статей без исследования ключей | Неясное | Высокие | Низкий |

Порядок: блокеры индексации → быстрые победы → системные улучшения шаблонов → новый контент → продвижение.

## SEO как цикл

```text
исследование → гипотеза → реализация → измерение (4–12 недель) → решение
```

## Роль разработчика в стратегии

- Оценка трудоёмкости технических задач.
- Внедрение в шаблоны (масштаб на весь сайт).
- SEO-проверки в CI: статусы, мета-теги, structured data, Lighthouse.
- Защита от регрессий при релизах.

## Частые ошибки

- Начинать с контента, когда сайт плохо индексируется.
- Цели вида «в топ-1» без связи с бизнесом.
- Нет приоритизации — команда тонет в списке «улучшений».
- Не измерять эффект изменений.

## Что важно помнить

- Стратегия начинается с целей бизнеса.
- Keyword research превращается в карту страниц, а не в список ключей.
- SEO — долгий итеративный процесс.

## Мини-шпаргалка

- Цели → аудит → intent → карта страниц → бэклог → контент → продвижение → аналитика.
- Влияние × уверенность / усилия.
- Сначала блокеры индексации.
- Цикл гипотез с измерением.
