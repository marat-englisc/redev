# Что такое Core Web Vitals

> [!NOTE]
> **Core Web Vitals** — три метрики пользовательского опыта, которые Google использует в оценке page experience: **LCP** (Largest Contentful Paint) — скорость загрузки главного контента, хорошо ≤ 2,5 с; **INP** (Interaction to Next Paint) — отзывчивость на действия, хорошо ≤ 200 мс (заменил FID в марте 2024); **CLS** (Cumulative Layout Shift) — визуальная стабильность, хорошо ≤ 0,1. Оценивают **75-й процентиль реальных пользователей** (полевые данные CrUX) отдельно для мобильных и десктопа. Это лёгкий фактор ранжирования — он не перевешивает релевантность, — но сильно влияет на конверсию и поведение пользователей.

## Вопрос

Что такое Core Web Vitals и как они влияют на SEO?

## Метрики и пороги

| Метрика | Что измеряет | Хорошо | Нужно улучшить | Плохо |
| --- | --- | --- | --- | --- |
| LCP | Время отрисовки самого большого элемента первого экрана | ≤ 2,5 с | 2,5–4 с | > 4 с |
| INP | Задержка от взаимодействия до следующей отрисовки | ≤ 200 мс | 200–500 мс | > 500 мс |
| CLS | Сумма неожиданных сдвигов макета | ≤ 0,1 | 0,1–0,25 | > 0,25 |

Страница считается «хорошей», если **все три** метрики в зелёной зоне для 75% визитов.

## Вспомогательные метрики

| Метрика | Что показывает |
| --- | --- |
| TTFB | Время до первого байта ответа сервера — основа LCP |
| FCP | Первая отрисовка любого контента |
| TBT | Суммарное время блокировки основного потока (лабораторный аналог INP) |

## Полевые и лабораторные данные

| | Полевые (field, RUM) | Лабораторные (lab) |
| --- | --- | --- |
| Источник | Реальные пользователи Chrome (CrUX), ваш RUM | Lighthouse, DevTools, WebPageTest |
| Что отражают | Реальные устройства, сети, поведение | Один прогон в заданных условиях |
| Где смотреть | Search Console, PageSpeed Insights, CrUX Dashboard | Lighthouse, PSI (нижняя часть) |
| INP | Есть | Нет (используют TBT) |
| Для чего | Оценка, которую видит Google | Диагностика причин |

CrUX агрегирует данные за 28 дней — улучшения отражаются в отчётах с задержкой.

## Как собирать свои данные

```ts
import { onLCP, onINP, onCLS } from "web-vitals";

function send(metric) {
  navigator.sendBeacon("/analytics", JSON.stringify({ name: metric.name, value: metric.value, id: metric.id }));
}

onLCP(send);
onINP(send);
onCLS(send);
```

Библиотека `web-vitals` измеряет метрики так же, как Chrome, и позволяет видеть их по страницам, устройствам и версиям релиза.

## Влияние на SEO

- Core Web Vitals входят в page experience — сигнал «при прочих равных».
- Отличная скорость не спасёт нерелевантную страницу, а медленная, но лучшая по содержанию, может ранжироваться выше.
- Косвенное влияние сильнее: медленные и «прыгающие» страницы хуже конвертируют и чаще закрываются.

## Частые ошибки

- Ориентироваться только на Lighthouse-балл вместо полевых данных.
- Смотреть среднее значение, а не 75-й процентиль.
- Проверять только десктоп.
- Ждать изменений в Search Console сразу после деплоя.

## Что важно помнить

- LCP — загрузка, INP — отзывчивость, CLS — стабильность.
- Оценка по полевым данным, 75-й процентиль, мобильные отдельно.
- Lighthouse — для поиска причин, RUM и CrUX — для оценки.

## Мини-шпаргалка

- LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.
- 75-й процентиль, 28 дней.
- Field (CrUX, RUM) vs lab (Lighthouse).
- INP заменил FID в 2024.
- `web-vitals` для своего мониторинга.
