# Что такое CLS и как его улучшать

> [!NOTE]
> **CLS (Cumulative Layout Shift)** — мера визуальной нестабильности: насколько видимые элементы **неожиданно** смещаются во время жизни страницы. Каждый сдвиг оценивается как доля площади экрана × расстояние смещения; сдвиги группируются в «сессии» (окно до 5 секунд с паузами меньше 1 секунды), а CLS — максимальная такая сессия. Хорошо — ≤ 0,1. Сдвиги в течение 500 мс после действия пользователя (раскрыл аккордеон) не учитываются. Главные причины — медиа и iframe без размеров, реклама и баннеры без зарезервированного места, подмена шрифтов, контент, вставляемый над видимым.

## Вопрос

Что такое CLS и как устранять сдвиги макета?

## Пример

```text
Пользователь тянется к кнопке «Купить»
→ сверху загружается рекламный баннер
→ кнопка уезжает вниз
→ палец нажимает «Удалить из корзины»
```

## Причины и решения

| Причина | Решение |
| --- | --- |
| Изображения и видео без размеров | Атрибуты `width`/`height` или CSS `aspect-ratio` |
| Реклама, iframe, embed без места | Контейнер с `min-height` под ожидаемый размер |
| Баннеры cookies, уведомления, вставляемые сверху | Показывать поверх контента (`position: fixed`) или резервировать место |
| Подмена шрифта (FOUT) с другими метриками | `font-display: optional` или подгонка fallback-шрифта (`size-adjust`, `ascent-override`) |
| Скелетон другого размера, чем контент | Скелетон тех же размеров |
| Контент, догружаемый над видимой областью | Добавлять ниже или по действию пользователя |
| Анимации через `top`/`left`/`height` | `transform` и `opacity` — они не вызывают layout |

## Размеры медиа

```html
<img src="/product.webp" alt="Рюкзак для ноутбука" width="800" height="600">
```

```css
img {
  max-width: 100%;
  height: auto;           /* браузер сохраняет пропорцию из width/height */
}

.video-embed {
  aspect-ratio: 16 / 9;
  width: 100%;
}

.ad-slot {
  min-height: 250px;      /* место под рекламу ещё до её загрузки */
}
```

## Шрифты

```css
@font-face {
  font-family: "Inter Fallback";
  src: local("Arial");
  size-adjust: 107%;
  ascent-override: 90%;
}

body {
  font-family: "Inter", "Inter Fallback", sans-serif;
}
```

Подогнанный fallback почти не отличается по метрикам от веб-шрифта, и подмена не сдвигает текст. Nuxt Fonts и `next/font` делают это автоматически.

## Back/forward cache

Страницы, которые восстанавливаются из bfcache, не дают сдвигов при возврате. Не мешайте bfcache обработчиками `unload` и `Cache-Control: no-store` без необходимости.

## Как найти сдвиги

- PageSpeed Insights → «Избегайте значительных сдвигов макета» с элементами.
- DevTools → Performance → дорожка Layout Shifts; в панели Rendering — подсветка Layout Shift Regions.
- `web-vitals/attribution` — элемент, вызвавший наибольший сдвиг.

## Частые ошибки

- Изображения без размеров «потому что CSS задаёт ширину».
- Баннер согласия на cookies, сдвигающий весь контент.
- Динамический контент (рекомендации, отзывы) вставляется над уже видимым текстом.
- Анимация высоты блоков.

## Что важно помнить

- Учитываются только неожиданные сдвиги — реакция на действие пользователя в течение 500 мс не считается.
- Место под всё, что загружается позже, резервируют заранее.
- CLS измеряется весь визит, а не только при загрузке: бесконечная лента тоже может давать сдвиги.

## Мини-шпаргалка

- CLS ≤ 0,1.
- `width`/`height`, `aspect-ratio`.
- `min-height` для рекламы и embed.
- Fallback-шрифт с метриками.
- `transform` вместо `top`/`height`.
