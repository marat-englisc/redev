# Как работает sitemap.xml

> [!NOTE]
> `sitemap.xml` — XML-файл со списком URL, которые вы хотите видеть в индексе, и датой их последнего изменения (`lastmod`). Он помогает поисковику **обнаружить** страницы — особенно новые, глубокие и плохо перелинкованные — и служит основой для отчётов об индексации. Sitemap не гарантирует индексацию. В него включают только **канонические индексируемые URL со статусом 200**. Лимит одного файла — 50 000 URL или 50 МБ, для больших сайтов используют sitemap index. Google игнорирует `priority` и `changefreq`, а `lastmod` учитывает, только если он правдив.

## Вопрос

Как работает sitemap.xml и что в него включать?

## Формат

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://shop.example.com/</loc>
    <lastmod>2026-10-01</lastmod>
  </url>
  <url>
    <loc>https://shop.example.com/keyboards/keychron-k2</loc>
    <lastmod>2026-10-20T14:30:00+03:00</lastmod>
  </url>
</urlset>
```

URL — абсолютные, с правильным протоколом и доменом, в том же формате, что и canonical (слеш на конце, регистр).

## Что включать и что нет

| Включать | Не включать |
| --- | --- |
| Главную, категории, товары, статьи | Страницы с `noindex` |
| Посадочные страницы и полезные фильтры | Редиректы и 404 |
| Ключевые страницы документации | Дубли и не-канонические URL |
| Языковые версии (с hreflang) | URL, закрытые в robots.txt |
| | Корзину, кабинет, поиск, сортировки |

## Sitemap index

```xml
<?xml version="1.0" encoding="UTF-8"?>
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap><loc>https://shop.example.com/sitemap-categories.xml</loc></sitemap>
  <sitemap><loc>https://shop.example.com/sitemap-products-1.xml</loc></sitemap>
  <sitemap><loc>https://shop.example.com/sitemap-blog.xml</loc></sitemap>
</sitemapindex>
```

Разбиение по типам страниц даёт отдельную статистику индексации для каждого — сразу видно, какой раздел проседает.

## Расширения

- **Изображения**: `<image:image><image:loc>...</image:loc></image:image>`.
- **Видео**: `<video:video>` с названием, описанием, превью.
- **Новости**: `<news:news>` для Google News.
- **Языковые версии**: `<xhtml:link rel="alternate" hreflang="en" href="..."/>`.

## Как сообщить поисковику

```text
# robots.txt
Sitemap: https://shop.example.com/sitemap.xml
```

И отправить в Search Console и Яндекс Вебмастере — там же видна статистика обработки. Старый способ «пинга» sitemap Google отключил; для мгновенного уведомления Яндекса и Bing есть IndexNow.

## Генерация во frontend-фреймворках

- Next.js: `app/sitemap.ts`, возвращающий массив URL.
- Nuxt: модуль `@nuxtjs/sitemap` (см. [урок в разделе Nuxt](<../../12. Nuxt/06. SEO и Nuxt SEO/04. Как настроить sitemap в Nuxt.md>)).
- Динамические URL (товары, статьи) берут из базы или CMS, `lastmod` — из реальной даты изменения.

## Частые ошибки

- В sitemap попадают 404, редиректы, `noindex`.
- `lastmod` равен текущей дате для всех страниц — поисковик перестаёт ему доверять.
- URL не совпадают с canonical (`http` вместо `https`, без слеша).
- Sitemap генерируется один раз и не обновляется.
- Новые важные страницы в sitemap не попадают.

## Что важно помнить

- Sitemap помогает обнаружению, но не заменяет внутренние ссылки.
- Sitemap, canonical, robots и внутренние ссылки должны указывать на одни и те же URL.
- Отчёт по sitemap в Search Console — способ увидеть, сколько отправленных страниц реально проиндексировано.

## Мини-шпаргалка

- Только канонические URL со статусом 200.
- ≤ 50 000 URL / 50 МБ на файл, иначе sitemap index.
- `lastmod` — честный, `priority`/`changefreq` игнорируются Google.
- Ссылка в robots.txt + отправка в панели вебмастера.
