# Как проводить keyword research

> [!NOTE]
> **Keyword research** — сбор и анализ запросов, которыми аудитория ищет продукт, решение или знания. Цель — не список из тысячи слов, а **карта страниц**: запросы собирают из нескольких источников, **кластеризуют** по намерению (одно намерение — одна страница), оценивают по спросу, сложности, бизнес-ценности и соответствию экспертизе, а затем сопоставляют с существующими страницами. Инструменты — Wordstat, Google Keyword Planner, Search Console, Ahrefs/Semrush/Serpstat, подсказки и блоки «Похожие запросы» в выдаче.

## Вопрос

Как проводить исследование ключевых слов?

## Процесс

```text
темы продукта → сбор запросов → чистка → кластеризация по intent → приоритизация → карта страниц
```

### 1. Темы

Начинают с продукта и аудитории, а не с инструмента:

```text
Продукт: онлайн-школа frontend
Темы: JavaScript, Vue, React, TypeScript, собеседования, пет-проекты, тестирование
```

### 2. Сбор запросов

- **Wordstat** (Яндекс) и **Keyword Planner** (Google) — частотность.
- **Search Console и Вебмастер** — по каким запросам сайт уже показывается.
- **Ahrefs, Semrush, Serpstat** — запросы конкурентов и сложность.
- Подсказки поиска, «Похожие вопросы», форумы, вопросы в поддержку.

### 3. Чистка

Убрать нецелевое: чужие бренды, другой регион, нерелевантные смыслы («vue» как фамилия).

### 4. Кластеризация

Запросы объединяют, если по ним в выдаче совпадают одни и те же страницы, — это значит, что намерение одно.

| Кластер | Запросы | Intent | Страница |
| --- | --- | --- | --- |
| Vite основы | «что такое vite», «vite это» | Informational | Статья |
| Vite + Vue настройка | «vite vue настройка», «создать проект vue vite» | Informational / практика | Гайд |
| Курс по Vue | «курс vue», «обучение vue онлайн» | Commercial | Страница курса |

### 5. Приоритизация

```text
приоритет ≈ спрос × бизнес-ценность × реалистичность × соответствие экспертизе
```

| Метрика | Что показывает |
| --- | --- |
| Частотность | Объём спроса (с учётом сезонности) |
| Сложность / конкуренция | Насколько трудно попасть в топ |
| Текущая позиция | Близость к результату (позиции 8–20 — быстрые победы) |
| Конверсионность | Вероятность целевого действия |
| Элементы выдачи | AI-ответ, видео, карта — забирают клики |

Низкочастотный коммерческий запрос часто ценнее высокочастотного информационного.

### 6. Карта страниц

Каждому кластеру — одна целевая страница: существующая (оптимизировать) или новая (создать). Этот документ становится планом контента и структурой разделов сайта.

## Частые ошибки

- Выбирать только самые частотные запросы.
- Делать отдельную страницу на каждую вариацию запроса — каннибализация и doorway-страницы.
- Собирать ключи один раз и не обновлять.
- Игнорировать запросы из Search Console, по которым сайт уже виден.

## Что важно помнить

- Результат исследования — карта страниц, а не таблица ключей.
- Кластеризуют по совпадению выдачи, а не по похожим словам.
- Запросы с длинным хвостом (длинные и конкретные) дают меньше трафика, но выше конверсию и меньше конкуренцию.

## Мини-шпаргалка

- Темы → сбор → чистка → кластеры → приоритет → карта страниц.
- Wordstat, Keyword Planner, Search Console, Вебмастер.
- Один кластер — одна страница.
- Спрос × ценность × реалистичность.
