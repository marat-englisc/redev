# Как использовать headings и semantic HTML

> [!NOTE]
> **Заголовки** `h1`–`h6` задают структуру документа: `h1` — главная тема страницы (обычно один), `h2` — разделы, `h3` — подразделы. **Семантический HTML** — теги по смыслу: `header`, `nav`, `main`, `article`, `section`, `aside`, `footer`, `a` для ссылок, `button` для действий, `ul`/`ol` для списков, `table` для таблиц. Это помогает поисковику понять, где основной контент и как он устроен, улучшает доступность для скринридеров и делает страницу удобнее для «сканирующего» чтения. Заголовки выбирают по структуре, а не по размеру шрифта.

## Вопрос

Как правильно использовать заголовки и семантический HTML для SEO?

## Структура заголовков

```html
<h1>SEO для Vue-приложений</h1>

<h2>Почему SPA бывают проблемными для SEO</h2>
  <h3>Пустой HTML до выполнения JavaScript</h3>
  <h3>Мета-теги только на клиенте</h3>

<h2>Как SSR помогает индексации</h2>

<h2>Как настроить мета-теги</h2>
```

- Один `h1`, согласованный с title.
- Уровни без пропусков: после `h2` идёт `h3`, а не `h4`.
- Заголовки-вопросы и конкретные формулировки хорошо подходят для сниппетов и AI-ответов.

HTML формально допускает несколько `h1`, но один главный заголовок проще для пользователей, скринридеров и поисковиков.

## Семантическая разметка

```html
<header>
  <nav aria-label="Основная навигация">
    <a href="/catalog">Каталог</a>
  </nav>
</header>

<main>
  <article>
    <h1>Как работает sitemap.xml</h1>
    <p>…</p>
    <section>
      <h2>Формат файла</h2>
    </section>
  </article>
  <aside>Похожие статьи</aside>
</main>

<footer>…</footer>
```

| Тег | Смысл |
| --- | --- |
| `main` | Основной контент (один на странице) |
| `article` | Самостоятельная единица: статья, карточка товара, пост |
| `section` | Тематический раздел с заголовком |
| `nav` | Блок навигации |
| `aside` | Дополнительный контент |
| `a href` | Переход по ссылке |
| `button` | Действие на странице |
| `time datetime` | Дата в машиночитаемом виде |
| `figure` + `figcaption` | Иллюстрация с подписью |

## Почему это важно для SEO

- Поисковик лучше выделяет основной контент и отделяет его от шаблонных блоков.
- Заголовки помогают понять подтемы страницы и сформировать сниппет.
- Списки и таблицы удобно цитировать в сниппетах и AI-ответах.
- Ссылки `<a href>` — путь, по которому робот находит страницы.

## Частые ошибки

- `h1` для логотипа на каждой странице, а настоящий заголовок — `div`.
- Заголовки ради размера шрифта и, наоборот, крупный `div` вместо заголовка.
- Кнопка через `div onClick`, ссылка через `span`.
- Важный текст внутри изображения.
- Пропуск уровней заголовков.

## Что важно помнить

- HTML отвечает за смысл, CSS — за внешний вид.
- Семантика одновременно помогает SEO и доступности.
- Структуру заголовков удобно проверять расширениями (HeadingsMap) или в DevTools Accessibility tree.

## Мини-шпаргалка

- Один `h1`, иерархия без пропусков.
- `main`, `article`, `section`, `nav`, `aside`.
- `a href` — навигация, `button` — действия.
- Текст — текстом, а не картинкой.
