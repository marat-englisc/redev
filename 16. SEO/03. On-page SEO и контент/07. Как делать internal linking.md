# Как делать internal linking

> [!NOTE]
> **Внутренняя перелинковка** — система ссылок между страницами сайта: навигация, хлебные крошки, ссылки в тексте, блоки «похожие материалы», ссылки из категорий на товары. Она помогает роботу **находить** страницы (discovery), показывает **иерархию и важность** (на важные страницы ведёт больше ссылок, и они ближе к главной), передаёт **контекст** через анкорный текст и помогает пользователям. Ссылки должны быть настоящими `<a href>`, с описательным текстом, а важные страницы — доступны за 3–4 клика от главной.

## Вопрос

Как строить внутреннюю перелинковку и почему она важна для SEO?

## Зачем нужны внутренние ссылки

- Робот находит новые страницы и чаще обходит важные.
- Поисковик понимает структуру и тематические связи.
- Сигналы важности распределяются по сайту.
- Анкор объясняет, о чём целевая страница.
- Пользователь находит связанные материалы и дольше остаётся на сайте.

## Анкорный текст

```html
✗ <a href="/seo/javascript-seo">читать</a>
✗ <a href="/seo/javascript-seo">здесь</a>
✓ <a href="/seo/javascript-seo">как Google обрабатывает JavaScript</a>
```

Анкор описывает цель ссылки. Не нужно делать все анкоры точным ключом — это выглядит неестественно; достаточно понятного описания.

## Где ставить ссылки

| Место | Роль |
| --- | --- |
| Главное меню | Ключевые разделы |
| Хлебные крошки | Иерархия, путь наверх |
| Текст статьи | Контекстные связи между темами |
| «Похожие материалы», «С этим товаром покупают» | Связь соседних страниц |
| Категории и пагинация | Путь к каждому товару |
| Хабы и тематические подборки | Группировка материалов по теме |
| Подвал | Только действительно важные страницы |

## Модель «хаб и спицы»

```text
                ┌── /seo/robots-txt
/seo (хаб) ─────┼── /seo/sitemap
                └── /seo/canonical
```

Хаб-страница по теме ссылается на все материалы темы, а материалы — на хаб и друг на друга. Поисковик видит тематический кластер и авторитет сайта в теме.

## Технические требования

```html
✓ <a href="/products/keychron-k2">Keychron K2</a>
✗ <span onclick="router.push('/products/keychron-k2')">Keychron K2</span>
✗ <a href="javascript:void(0)" @click="go">…</a>
✗ <a onclick="…">…</a>  <!-- без href -->
```

Во фреймворках — `<NuxtLink>`, `<Link>` из Next.js, `<RouterLink>`: они рендерят настоящий `<a href>`.

## Страницы-сироты и глубина

- **Сирота** — страница без входящих внутренних ссылок; робот может её не найти даже при наличии в sitemap.
- **Глубина** — число кликов от главной. Товар на 15-й странице пагинации глубоко; помогают фильтры-посадочные, подборки, ссылки из похожих товаров.

Найти сирот и глубину помогают краулеры (Screaming Frog, Netpeak Spider) и отчёт «Ссылки» в Search Console.

## Частые ошибки

- Все ссылки «подробнее».
- Навигация на JavaScript без `href`.
- Важные страницы глубоко в структуре.
- Сотни ссылок в подвале и мега-меню «для SEO».
- Ссылки на URL с редиректами или параметрами вместо канонических.
- Новые материалы не связаны со старыми.

## Что важно помнить

- Внутренние ссылки — то, что сайт полностью контролирует, и один из самых недооценённых инструментов.
- Ссылки должны вести на канонические URL.
- Перелинковка отражает смысловую структуру, а не просто «больше ссылок».

## Мини-шпаргалка

- `<a href>` с описательным анкором.
- Хлебные крошки, хабы, похожие материалы.
- Важное — в 3–4 кликах от главной.
- Без сирот и ссылок на редиректы.
