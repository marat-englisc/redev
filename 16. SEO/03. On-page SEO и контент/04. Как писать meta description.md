# Как писать meta description

> [!NOTE]
> `<meta name="description">` — краткое описание страницы, которое поисковик **может** использовать как текст сниппета. На позиции напрямую оно не влияет, но влияет на **CTR**: хорошее описание объясняет пользу и подтверждает, что страница отвечает на запрос. Описание должно быть уникальным, соответствовать содержанию, включать важные термины естественно и укладываться примерно в 150–160 символов. Google часто заменяет его фрагментом текста страницы, более подходящим под конкретный запрос, — это нормально.

## Вопрос

Как писать meta description и влияет ли оно на SEO?

## Пример

```html
<meta
  name="description"
  content="Разбираем SEO для frontend-приложений: SSR и SSG, мета-теги, structured data, Core Web Vitals и частые ошибки при релизах."
>
```

## Каким должно быть

- Раскрывает пользу: что человек получит на странице.
- Соответствует содержанию — не обещает того, чего нет.
- Уникально для каждой страницы.
- Включает ключевые термины естественно (в сниппете они выделяются жирным).
- Для товаров и категорий содержит конкретику: цена от, доставка, количество моделей.
- 150–160 символов: дальше обрезается.

## Примеры

```text
✗ SEO, продвижение, оптимизация, сайт, заказать, дёшево.
✓ Пошаговый чек-лист SEO-аудита: индексация, sitemap, canonical, скорость, structured data и аналитика.

✓ Keychron K2 — беспроводная механическая клавиатура 75%. Цена 9 990 ₽, доставка завтра, гарантия 2 года.
```

## Когда поисковик подменяет описание

Google и Яндекс формируют сниппет под каждый запрос. Если в тексте страницы есть фрагмент точнее отвечающий запросу, он может заменить description. Поэтому важно и описание, и сам текст: первые абзацы разделов должны содержать ясные формулировки.

Ограничить сниппет можно директивами `nosnippet`, `max-snippet` и атрибутом `data-nosnippet` на блоке.

## Description и Open Graph

Соцсети и мессенджеры используют `og:description`, а если его нет — часто `description`. Удобно генерировать оба из одного источника, но для соцсетей можно сделать текст более «продающим».

## Для больших сайтов

На тысячах товаров описания генерируют шаблоном из данных:

```text
{Название} — {ключевая характеристика}. Цена {цена} ₽, {наличие}. {Преимущество магазина}.
```

Пустое описание лучше, чем одинаковое на всех страницах: тогда поисковик хотя бы возьмёт фрагмент текста.

## Частые ошибки

- Одинаковое описание на всех страницах.
- Набор ключевых слов через запятую.
- Description не обновляется при клиентской навигации в SPA.
- Обещания, которых нет на странице, — кликают и сразу уходят.

## Что важно помнить

- Description — инструмент CTR, а не ранжирования.
- Поисковик вправе его не использовать.
- Конкретика в описании повышает кликабельность.

## Мини-шпаргалка

- Уникальное, точное, с пользой.
- 150–160 символов.
- Конкретика: цены, сроки, количество.
- Шаблоны для больших сайтов.
- В серверном HTML.
