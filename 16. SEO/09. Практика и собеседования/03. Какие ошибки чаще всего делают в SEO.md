# Какие ошибки чаще всего делают в SEO

> [!NOTE]
> Самые дорогие SEO-ошибки — **технические и массовые**: `noindex` или `Disallow: /` со staging в production, пустой HTML у SPA, soft 404, canonical на главную, смена URL без редиректов, индексация тысяч фильтров. Дальше идут **контентные** (страница не закрывает намерение, одинаковые title, каннибализация), **ошибки продвижения** (покупка ссылок, doorway-страницы, накрутка отзывов) и **аналитические** (смотреть только позиции, не учитывать сезонность, много изменений сразу). Большинство технических ошибок ловится автотестами на шаблоны и проверкой итогового HTML.

## Вопрос

Какие ошибки чаще всего допускают в SEO?

## Технические

| Ошибка | Последствие |
| --- | --- |
| `noindex` / `Disallow: /` со staging в production | Сайт выпадает из индекса |
| Пустой HTML у публичного SPA | Контент поздно или не индексируется, нет превью |
| Soft 404 (200 на несуществующие страницы) | Мусор в индексе |
| Canonical на главную или на staging | Страницы не индексируются |
| Смена URL без 301 | Потеря трафика и ссылок |
| Цепочки и петли редиректов | Потеря сигналов, медленный обход |
| Закрытые в robots.txt CSS/JS | Поисковик видит сломанную страницу |
| Индексация фильтров и сортировок | Дубли, расход crawl budget |
| Ссылки на `div` и `button` | Страницы не обнаруживаются |
| Мета-теги только на клиенте | Одинаковые сниппеты, пустые превью |

## Контентные

- Страница не соответствует намерению (статья под «купить»).
- Одинаковые title и description.
- Нет `h1` или несколько конкурирующих.
- Текст «для роботов», без конкретики и опыта.
- Описания товаров скопированы у производителя.
- Старый контент не обновляется.
- Несколько страниц под одно намерение (каннибализация).

## Продвижение

- Покупка ссылок без `sponsored`, PBN.
- Doorway-страницы под города.
- Накрутка отзывов и поведенческих факторов.
- Массовый ИИ-контент без ценности.
- Ключевые слова в названии карточки организации.

## Аналитика

- Смотреть только позиции.
- Не разделять брендовые и небрендовые запросы.
- Не связывать SEO с конверсиями.
- Сравнивать периоды без учёта сезонности.
- Много изменений одновременно — непонятно, что сработало.
- Не фиксировать даты релизов.

## Как предотвращать

- SEO-требования к шаблонам до разработки.
- Автотесты: статусы, title, canonical, robots, JSON-LD.
- Проверка `robots.txt` и `noindex` в пайплайне деплоя production.
- Lighthouse CI с порогами.
- Мониторинг Search Console и алерты на всплески ошибок.

## Что важно помнить

- Технические ошибки масштабируются на весь сайт — их проверяют первыми.
- Мета-теги важны, но не равны SEO.
- Плохой intent не исправить ключевыми словами.

## Мини-шпаргалка

- Staging-`noindex`, пустой SPA, soft 404, canonical, редиректы.
- Intent, дубли title, каннибализация.
- Ссылки, doorway, накрутки.
- Позиции без конверсий и сезонности.
- Автотесты на шаблоны.
