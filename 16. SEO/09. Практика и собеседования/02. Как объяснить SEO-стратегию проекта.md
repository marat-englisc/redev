# Как объяснить SEO-стратегию проекта

> [!NOTE]
> SEO-стратегию объясняют как **систему с приоритетами**: бизнес-цель и аудитория → техническая база (индексация, рендеринг, статусы, canonical, скорость) → карта страниц по намерениям → контент и внутренняя перелинковка → structured data → безопасное продвижение → измерение и итерации. Для frontend-разработчика важно показать, какие решения он принимает сам (режим рендеринга, шаблоны мета-тегов, правила для фильтров, проверки в CI) и как измеряет эффект. Это показывает зрелость лучше, чем набор разрозненных советов.

## Вопрос

Как объяснить SEO-стратегию проекта на собеседовании или в команде?

## Короткая структура ответа

```text
1. Цель: что должно вырасти — заявки, продажи, регистрации.
2. Техника: индексация, SSR/SSG для публичных страниц, статусы, canonical, sitemap, CWV.
3. Карта страниц: кластеры запросов по намерениям → шаблоны страниц.
4. Контент и ссылки: полезные материалы, перелинковка, structured data.
5. Продвижение: PR, партнёрства, локальные профили — без покупки ссылок.
6. Измерение: Search Console, Вебмастер, GA4 — по шаблонам, с конверсиями.
7. Итерации: гипотеза → изменение → измерение.
```

## Пример для интернет-магазина

```text
Начал бы с категорий и карточек: проверил индексацию, canonical, статусы удалённых товаров,
скорость листингов и мобильную версию. Публичные страницы — SSR с кэшем (SWR), кабинет — CSR.
Фильтры со спросом («ноутбуки apple», «игровые ноутбуки») — отдельные URL с уникальным title,
h1 и текстом; сортировки и мусорные комбинации — без индексируемых ссылок, canonical на категорию.
Product, Offer и BreadcrumbList генерируются из тех же данных, что UI.
В CI — автотесты на title, canonical, 404 и JSON-LD, Lighthouse с порогами.
Измеряю небрендовые клики и органические конверсии по категориям, год к году.
```

## Пример для контентного проекта

```text
Кластеризую темы по намерениям, строю хабы и спицы с перелинковкой,
SSG для статей с периодической пересборкой, Article и Breadcrumb разметка,
страницы авторов. Регулярный контент-аудит: обновляю статьи на позициях 8–20,
объединяю каннибализирующие материалы.
```

## Что подчеркнуть

- Сначала доступность и индексация, потом контент и продвижение.
- Решения принимаются по шаблонам страниц, а не по отдельным URL.
- Эффект измеряется конверсиями, а не позициями.
- SEO встроено в процесс разработки: требования до разработки, проверки в CI, мониторинг после релиза.

## Чего избегать

- «Добавим ключевых слов».
- «Закупим ссылки».
- «Сделаем Lighthouse 100».
- «SEO — это мета-теги».
- «Гарантирую топ-1».

## Что важно помнить

- Стратегия связывает SEO с бизнесом и приоритизирует работы.
- Технический фундамент — первая часть любой стратегии.
- Конкретный пример из опыта убедительнее общего плана.

## Мини-шпаргалка

- Цель → техника → карта страниц → контент → разметка → продвижение → измерение.
- Шаблоны, а не отдельные URL.
- SEO-проверки в CI.
- Конверсии, а не позиции.
