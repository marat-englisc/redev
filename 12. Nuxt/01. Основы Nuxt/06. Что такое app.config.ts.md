# Что такое app.config.ts

> [!NOTE]
> `app.config.ts` (в Nuxt 4 — `app/app.config.ts`) хранит **публичную** конфигурацию приложения, которая определяется на этапе сборки, но доступна реактивно в рантайме через `useAppConfig()`: тема, цвета UI-кита, настройки компонентов, названия, флаги интерфейса. В отличие от `runtimeConfig`, его **нельзя** переопределить переменными окружения, и всё в нём видно в браузере — секреты сюда не кладут.

## Вопрос

Что такое `app.config.ts` и чем он отличается от `runtimeConfig`?

## Пример

```ts
// app/app.config.ts
export default defineAppConfig({
  title: "Магазин",
  theme: {
    primary: "green",
    radius: "md",
  },
  ui: {
    button: { defaultVariants: { size: "lg" } },
  },
});
```

```vue
<script setup lang="ts">
const appConfig = useAppConfig();
</script>

<template>
  <header :class="`theme-${appConfig.theme.primary}`">
    {{ appConfig.title }}
  </header>
</template>
```

Значения реактивны: изменение в рантайме (`appConfig.theme.primary = "blue"`) обновит интерфейс, а в dev-режиме правка файла применяется через HMR без перезагрузки.

## app.config или runtimeConfig

| | `app.config.ts` | `runtimeConfig` |
| --- | --- | --- |
| Когда задаётся | При сборке | При сборке, переопределяется переменными `NUXT_*` при запуске |
| Видимость | Всегда публичный | Серверные ключи + `public` |
| Реактивность | Да | Нет (только чтение) |
| Типы данных | Любые, включая вложенные объекты и функции-фабрики модулей | Сериализуемые значения |
| Типичные данные | Тема, тексты UI, настройки компонентов | URL API, ключи, ID аналитики, секреты |

Простое правило: если значение различается между staging и production — `runtimeConfig`; если это часть дизайна и поведения UI — `app.config.ts`.

## Модули и app.config

UI-библиотеки (Nuxt UI, Nuxt Icon) читают свои настройки отсюда, а Nuxt Layers позволяют базовому слою задать `app.config`, который проект переопределит частично — объекты сливаются глубоко.

## Частые ошибки

- Хранить в `app.config.ts` токены и URL с ключами.
- Ожидать, что переменная окружения изменит значение `app.config.ts`.
- Класть сюда значения, разные для окружений, вместо `runtimeConfig`.

## Что важно помнить

- `app.config.ts` попадает в клиентский бандл целиком.
- Значения реактивны, `runtimeConfig` — нет.
- Для темы и настроек компонентов это стандартное место в экосистеме Nuxt.

## Мини-шпаргалка

- `defineAppConfig({ ... })` в `app/app.config.ts`.
- Чтение: `useAppConfig()`.
- Публично, реактивно, без переменных окружения.
- Секреты и окружения → `runtimeConfig`.
