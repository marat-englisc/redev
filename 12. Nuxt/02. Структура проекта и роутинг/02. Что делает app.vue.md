# Что делает app.vue

> [!NOTE]
> `app/app.vue` — корневой компонент Nuxt-приложения, точка входа для всех страниц. Если есть каталог `pages/`, в нём размещают `<NuxtPage />` (выводит текущую страницу), обычно внутри `<NuxtLayout>` (применяет layout). Сюда же ставят то, что нужно на каждой странице: `<NuxtLoadingIndicator>`, `<NuxtRouteAnnouncer>`, глобальные уведомления, общий `useHead`. Без каталога `pages/` приложение состоит только из `app.vue`, и Vue Router не подключается.

## Вопрос

Что делает `app.vue` и что в нём размещать?

## Типичный app.vue

```vue
<script setup lang="ts">
useHead({
  htmlAttrs: { lang: "ru" },
  titleTemplate: (title) => (title ? `${title} · Магазин` : "Магазин"),
});
</script>

<template>
  <NuxtLoadingIndicator />      <!-- полоса загрузки при переходах -->
  <NuxtRouteAnnouncer />        <!-- озвучивает смену страницы для скринридеров -->
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
  <AppToasts />
</template>
```

## Иерархия рендера

```text
app.vue
└── <NuxtLayout>          → app/layouts/default.vue (или выбранный в definePageMeta)
    └── <slot />
        └── <NuxtPage>    → app/pages/products/[id].vue
            └── <NuxtPage> (для вложенных маршрутов)
```

## Переходы между страницами

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    pageTransition: { name: "page", mode: "out-in" },
    layoutTransition: { name: "layout", mode: "out-in" },
  },
});
```

```css
.page-enter-active, .page-leave-active { transition: opacity 0.2s; }
.page-enter-from, .page-leave-to { opacity: 0; }
```

## Ключ страницы

```vue
<NuxtPage :page-key="(route) => route.fullPath" />
```

По умолчанию при переходе между `/products/1` и `/products/2` компонент страницы переиспользуется. `page-key` заставляет пересоздавать его — полезно, если страница не реагирует на смену параметров.

## Что не класть в app.vue

- Шапку и подвал конкретных разделов — это задача layouts.
- Загрузку данных для одной страницы.
- Большую бизнес-логику — её выносят в composables и plugins.

## Частые ошибки

- Забыть `<NuxtPage />` после создания `pages/` — страницы не отображаются.
- Использовать `<NuxtLayout>` с одним `<slot>` вместо `<NuxtPage>`.
- Дублировать в `app.vue` разметку, которая должна быть в layout.

## Что важно помнить

- `app.vue` монтируется один раз и не пересоздаётся при навигации.
- `<NuxtPage>` — обёртка над `<RouterView>` с поддержкой Suspense, переходов и `keepalive`.
- Для страницы ошибок есть отдельный `app/error.vue` — он рендерится вместо `app.vue`.

## Мини-шпаргалка

- `<NuxtLayout><NuxtPage /></NuxtLayout>`.
- `<NuxtLoadingIndicator>`, `<NuxtRouteAnnouncer>`.
- `app.pageTransition` — анимация переходов.
- `page-key` — пересоздание страницы при смене параметров.
