# Что такое Nuxt OG Image

> [!NOTE]
> **Nuxt OG Image** (`nuxt-og-image`, входит в Nuxt SEO) генерирует OG-картинки для превью ссылок **из Vue-компонентов**: вы описываете шаблон (заголовок, обложка, бренд), а модуль рендерит его в PNG при prerender или на лету на сервере (через Satori или headless-браузер) и сам прописывает `og:image`. Так у каждой статьи и товара появляется своё превью без ручной работы дизайнера. Сгенерированные картинки кэшируются; шрифты (особенно с кириллицей) нужно подключить явно.

## Вопрос

Что такое Nuxt OG Image и как генерировать превью для страниц?

## Подключение

```bash
npx nuxt module add og-image   # или @nuxtjs/seo
```

```ts
export default defineNuxtConfig({
  modules: ["nuxt-og-image"],
  site: { url: "https://shop.example.com", name: "Магазин" },
});
```

## Использование на странице

```vue
<script setup lang="ts">
const { data: post } = await useFetch(() => `/api/posts/${useRoute().params.slug}`);

defineOgImageComponent("BlogPost", {
  title: () => post.value?.title,
  author: () => post.value?.author,
  cover: () => post.value?.cover,
});
</script>
```

## Шаблон

```vue
<!-- app/components/OgImage/BlogPost.vue -->
<script setup lang="ts">
defineProps<{ title: string; author?: string; cover?: string }>();
</script>

<template>
  <div class="w-full h-full flex flex-col justify-between bg-slate-900 text-white p-16">
    <h1 class="text-6xl font-bold leading-tight">{{ title }}</h1>
    <p class="text-3xl opacity-80">{{ author }} · Блог Магазина</p>
  </div>
</template>
```

Компоненты из `components/OgImage/` используются как шаблоны. Поддерживается подмножество CSS (flexbox, Tailwind-классы); сложные раскладки (grid, анимации) рендерер не поддерживает. Встроенные шаблоны (`NuxtSeo` и другие) подходят для быстрого старта.

## Шрифты и кириллица

```ts
export default defineNuxtConfig({
  ogImage: {
    fonts: ["Inter:400", "Inter:700"],
  },
});
```

Без явно подключённого шрифта с кириллицей текст может отрендериться квадратами.

## Когда генерируется

| Режим | Когда | Плюсы |
| --- | --- | --- |
| Prerender | При сборке, вместе со страницами | Бесплатно в рантайме, статические файлы |
| Runtime | При первом запросе картинки, затем кэш | Работает для любых динамических страниц |

Для SSR-сайтов с тысячами страниц обычно runtime + кэш; для блога на SSG — prerender.

## Проверка

Nuxt DevTools показывает вкладку OG Image с предпросмотром для каждой страницы. Итог проверяют отладчиками соцсетей.

## Частые ошибки

- Шрифт без кириллицы.
- Неподдерживаемые CSS-свойства в шаблоне — картинка «съезжает».
- Тяжёлая runtime-генерация без кэша на каждом запросе.
- Генерировать превью для закрытых страниц, которые никто не расшарит.

## Что важно помнить

- Уникальное превью заметно повышает кликабельность ссылок в соцсетях.
- Шаблон — обычный Vue-компонент, но с ограниченным CSS.
- API модуля менялось между мажорными версиями — сверяйтесь с документацией установленной версии.

## Мини-шпаргалка

- `defineOgImageComponent("Template", props)`.
- Шаблоны в `components/OgImage/`.
- `ogImage.fonts` — шрифты с кириллицей.
- Prerender или runtime + кэш.
- Предпросмотр в Nuxt DevTools.
