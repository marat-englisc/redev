# Как настраивать canonical, Open Graph и Twitter cards

> [!NOTE]
> **Canonical** (`<link rel="canonical">`) указывает поисковику главный URL страницы, если один контент доступен по нескольким адресам (UTM-метки, сортировка, слеш на конце) — чтобы сигналы не размывались между дублями. **Open Graph** (`og:title`, `og:description`, `og:image`, `og:url`) и **Twitter cards** (`twitter:card`) управляют превью ссылки в соцсетях и мессенджерах. В Nuxt их задают через `useSeoMeta`/`useHead` при SSR; Nuxt SEO генерирует canonical и `og:url` автоматически по `site.url`. Все URL — абсолютные.

## Вопрос

Как настроить canonical, Open Graph и Twitter cards в Nuxt?

## Canonical

```ts
const route = useRoute();
const config = useRuntimeConfig();

useHead({
  link: [{ rel: "canonical", href: () => `${config.public.siteUrl}${route.path}` }],
});
```

`route.path` без query-строки: `/catalog?utm_source=x&sort=price` → canonical `/catalog`. Если параметр меняет контент существенно (пагинация `?page=2`), каждая страница пагинации обычно канонична сама себе.

С Nuxt SEO canonical добавляется автоматически, а параметры, которые нужно сохранять, перечисляют в настройках модуля.

## Open Graph

```ts
useSeoMeta({
  ogType: "article",
  ogTitle: () => post.value?.title,
  ogDescription: () => post.value?.excerpt,
  ogImage: () => `https://shop.example.com${post.value?.cover}`,
  ogImageWidth: 1200,
  ogImageHeight: 630,
  ogImageAlt: () => post.value?.title,
  ogUrl: () => `https://shop.example.com${route.path}`,
  ogSiteName: "Магазин",
  ogLocale: "ru_RU",
});
```

## Twitter / X

```ts
useSeoMeta({
  twitterCard: "summary_large_image",
  twitterTitle: () => post.value?.title,
  twitterDescription: () => post.value?.excerpt,
  twitterImage: () => `https://shop.example.com${post.value?.cover}`,
});
```

Если `twitter:*` не заданы, большинство клиентов берут значения из OG.

## Требования к OG-картинке

| Параметр | Рекомендация |
| --- | --- |
| Размер | 1200×630 (соотношение 1.91:1) |
| Формат | PNG или JPEG (WebP поддерживается не везде) |
| Вес | До ~1 МБ, лучше 100–300 КБ |
| URL | Абсолютный, доступен без авторизации |
| Текст | Крупный, в центре — края обрезаются в разных клиентах |

Генерировать картинки для каждой страницы удобно модулем [Nuxt OG Image](<08. Что такое Nuxt OG Image.md>).

## Проверка

- Facebook Sharing Debugger, LinkedIn Post Inspector, превью в Telegram (`@webpagebot` для сброса кэша).
- Исходный HTML страницы: теги должны быть в ответе сервера.

## Частые ошибки

- Canonical на главную для всех страниц — поисковик перестанет индексировать остальные.
- Canonical со staging-доменом в production.
- Относительный `og:image`.
- Мета-теги, вычисленные на клиенте после загрузки, — боты соцсетей не выполняют JS.
- Разные URL в canonical и sitemap.

## Что важно помнить

- Canonical — подсказка, а не директива: поисковик может выбрать другой URL, если сигналы противоречат.
- Боты соцсетей видят только серверный HTML — SSR здесь обязателен.
- Мессенджеры агрессивно кэшируют превью: после исправления его нужно сбросить в отладчике.

## Мини-шпаргалка

- `link rel="canonical"` — абсолютный, без лишних query.
- `ogTitle`, `ogDescription`, `ogImage` 1200×630, `ogUrl`.
- `twitterCard: "summary_large_image"`.
- Всё — при SSR, всё — абсолютными URL.
