# Как настроить sitemap в Nuxt

> [!NOTE]
> Модуль `@nuxtjs/sitemap` (входит в Nuxt SEO) генерирует `/sitemap.xml` автоматически: статические маршруты берёт из `app/pages` и prerender, а **динамические** URL (`/blog/[slug]`, `/products/[id]`) — из источников: собственного эндпоинта, который возвращает список URL (`defineSitemapEventHandler`), или удалённого API. Поддерживаются `lastmod`, изображения, hreflang для i18n и разбиение на несколько файлов для больших сайтов. Sitemap помогает поисковику **обнаружить** страницы, но не гарантирует их индексацию.

## Вопрос

Как настроить sitemap для Nuxt-приложения с динамическими страницами?

## Подключение

```bash
npx nuxt module add sitemap   # или весь @nuxtjs/seo
```

```ts
export default defineNuxtConfig({
  modules: ["@nuxtjs/sitemap"],
  site: { url: "https://shop.example.com" },
});
```

После этого `/sitemap.xml` уже содержит статические страницы.

## Динамические URL

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  sitemap: {
    sources: ["/api/__sitemap__/urls"],
  },
});
```

```ts
// server/api/__sitemap__/urls.ts
import type { SitemapUrlInput } from "#sitemap/types";

export default defineSitemapEventHandler(async () => {
  const products = await db.query.products.findMany({ columns: { slug: true, updatedAt: true } });

  return products.map((p) => ({
    loc: `/products/${p.slug}`,
    lastmod: p.updatedAt,
    images: [{ loc: `/images/products/${p.slug}.jpg` }],
  })) satisfies SitemapUrlInput[];
});
```

## Исключения

```ts
export default defineNuxtConfig({
  sitemap: {
    exclude: ["/admin/**", "/account/**", "/cart"],
  },
  routeRules: {
    "/drafts/**": { robots: false },     // с Nuxt Robots — исключится и из sitemap
  },
});
```

В sitemap должны быть только канонические, индексируемые URL со статусом 200 — без редиректов, `noindex` и дублей.

## Несколько sitemap

```ts
export default defineNuxtConfig({
  sitemap: {
    sitemaps: {
      pages: { includeAppSources: true },
      products: { sources: ["/api/__sitemap__/products"] },
      blog: { sources: ["/api/__sitemap__/posts"] },
    },
  },
});
```

Будет создан индекс `/sitemap_index.xml`. Это удобно для больших сайтов (лимит одного файла — 50 000 URL) и для анализа индексации разделов в Search Console.

## Проверка

- Открыть `/sitemap.xml` и убедиться, что URL абсолютные и с правильным доменом.
- Добавить sitemap в Google Search Console и Яндекс Вебмастер.
- Убедиться, что `robots.txt` содержит строку `Sitemap:` (Nuxt Robots добавит её сам).

## Частые ошибки

- Не задать `site.url` — относительные или localhost-адреса в sitemap.
- Включать закрытые, редиректящие или `noindex`-страницы.
- Забыть про динамические маршруты — в sitemap только статика.
- Указывать `lastmod` текущей датой для всех страниц — поисковик перестаёт доверять полю.

## Что важно помнить

- Sitemap — подсказка для обхода, особенно ценная для больших сайтов и страниц со слабой перелинковкой.
- Динамические URL приходят из источника, который вы контролируете.
- Sitemap, canonical и robots должны согласовываться между собой.

## Мини-шпаргалка

- `@nuxtjs/sitemap` + `site.url`.
- `sitemap.sources` + `defineSitemapEventHandler`.
- `exclude`, `robots: false`.
- `sitemaps: {...}` — несколько файлов.
- Только канонические URL со статусом 200.
