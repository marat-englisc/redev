# Как добавить Schema.org structured data

> [!NOTE]
> **Structured data** — машиночитаемое описание сущностей страницы (товар, статья, организация, хлебные крошки) в формате **JSON-LD** по словарю Schema.org. Оно помогает поисковику понять контент и может дать **rich results**: цену и рейтинг в сниппете, хлебные крошки, карточку статьи. В Nuxt его добавляют модулем `nuxt-schema-org` через `useSchemaOrg([defineProduct(...), defineBreadcrumb(...)])` — с типами и автоматическим связыванием в граф — или вручную через `useHead` со `script type="application/ld+json"`. Данные разметки обязаны совпадать с видимым контентом.

## Вопрос

Как добавить структурированные данные Schema.org в Nuxt-приложение?

## Через модуль

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ["nuxt-schema-org"],      // или @nuxtjs/seo
  site: { url: "https://shop.example.com", name: "Магазин" },
  schemaOrg: {
    identity: defineOrganization({ name: "Магазин", logo: "/logo.png" }),
  },
});
```

```vue
<!-- app/pages/products/[slug].vue -->
<script setup lang="ts">
const route = useRoute();
const { data: product } = await useFetch(() => `/api/products/${route.params.slug}`);

useSchemaOrg([
  defineProduct({
    name: () => product.value?.title,
    image: () => product.value?.image,
    description: () => product.value?.description,
    offers: {
      price: () => product.value?.price,
      priceCurrency: "RUB",
      availability: () => (product.value?.inStock ? "InStock" : "OutOfStock"),
    },
    aggregateRating: {
      ratingValue: () => product.value?.rating,
      reviewCount: () => product.value?.reviewsCount,
    },
  }),
  defineBreadcrumb({
    itemListElement: [
      { name: "Главная", item: "/" },
      { name: "Клавиатуры", item: "/keyboards" },
      { name: () => product.value?.title },
    ],
  }),
]);
</script>
```

Модуль сам добавит `@context`, абсолютные URL, свяжет `Product` с `WebPage` и `Organization`.

## Вручную

```ts
useHead({
  script: [{
    type: "application/ld+json",
    innerHTML: JSON.stringify({
      "@context": "https://schema.org",
      "@type": "Article",
      headline: post.value?.title,
      datePublished: post.value?.publishedAt,
      author: { "@type": "Person", name: post.value?.author },
    }),
  }],
});
```

Без модуля легко ошибиться в структуре и забыть абсолютные URL, но зависимостей меньше.

## Частые типы

| Тип | Где | Что может дать в выдаче |
| --- | --- | --- |
| `Organization`, `WebSite` | Весь сайт | Логотип, поле поиска по сайту |
| `BreadcrumbList` | Вложенные страницы | Хлебные крошки вместо URL |
| `Product` + `Offer` | Карточка товара | Цена, наличие, рейтинг |
| `Article`, `BlogPosting` | Статьи | Дата, автор, картинка |
| `FAQPage` | Страница с вопросами | В Google — только для авторитетных сайтов (гос, медицина) |
| `LocalBusiness` | Офлайн-точки | Адрес, часы работы |
| `Event` | Мероприятия | Дата и место |

## Проверка

- [Rich Results Test](https://search.google.com/test/rich-results) — подходит ли разметка для расширенных сниппетов.
- [Schema Markup Validator](https://validator.schema.org/) — корректность по словарю.
- Отчёты «Улучшения» в Google Search Console.

## Частые ошибки

- Цена или рейтинг в разметке отличаются от показанных на странице — риск ручных санкций.
- Разметка для контента, которого на странице нет (FAQ без вопросов).
- Относительные URL в `image` и `url`.
- JSON-LD добавляется только на клиенте — в HTML его нет.

## Что важно помнить

- Structured data не повышает позиции напрямую, но улучшает сниппет и CTR.
- Rich results — решение поисковика, а не гарантия.
- Разметка — отражение видимого контента, а не способ добавить скрытую информацию.

## Мини-шпаргалка

- JSON-LD по Schema.org.
- `useSchemaOrg([defineProduct(), defineBreadcrumb(), defineArticle()])`.
- `schemaOrg.identity` — организация.
- Проверка: Rich Results Test, Search Console.
- Совпадение с видимым контентом.
