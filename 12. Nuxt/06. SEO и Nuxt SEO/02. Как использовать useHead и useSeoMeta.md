# Как использовать useHead и useSeoMeta

> [!NOTE]
> `useSeoMeta({ title, description, ogTitle, ogImage, twitterCard, robots })` — типизированный способ задать мета-теги: Nuxt сам выбирает `name` или `property` и не даёт опечататься. `useHead({ htmlAttrs, link, script, meta, bodyAttrs })` — полный контроль над `<head>`: canonical, preload, JSON-LD, атрибуты `<html>`. Оба работают при SSR, поддерживают реактивные значения (геттеры `() => post.value?.title`) и объединяются по иерархии компонентов — значение страницы перекрывает layout. Глобальные значения задают в `app.head` и `titleTemplate`.

## Вопрос

Как управлять мета-тегами страницы в Nuxt через `useHead` и `useSeoMeta`?

## useSeoMeta

```vue
<script setup lang="ts">
const route = useRoute();
const { data: post } = await useFetch(() => `/api/posts/${route.params.slug}`);

useSeoMeta({
  title: () => post.value?.title,
  description: () => post.value?.excerpt,
  ogTitle: () => post.value?.title,
  ogDescription: () => post.value?.excerpt,
  ogImage: () => post.value?.cover,
  ogType: "article",
  twitterCard: "summary_large_image",
});
</script>
```

Геттеры обязательны для данных, которые могут измениться: при переходе между статьями мета-теги обновятся.

## useHead

```ts
useHead({
  htmlAttrs: { lang: "ru" },
  bodyAttrs: { class: "theme-dark" },
  link: [
    { rel: "canonical", href: "https://shop.example.com/keyboards" },
    { rel: "preconnect", href: "https://cdn.example.com" },
  ],
  script: [
    {
      type: "application/ld+json",
      innerHTML: JSON.stringify({ "@context": "https://schema.org", "@type": "Organization", name: "Shop" }),
    },
  ],
});
```

## Глобальные значения

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    head: {
      htmlAttrs: { lang: "ru" },
      titleTemplate: "%s · Магазин",
      meta: [{ name: "theme-color", content: "#0f172a" }],
      link: [{ rel: "icon", type: "image/svg+xml", href: "/favicon.svg" }],
    },
  },
});
```

Шаблон-функция — когда главной нужен заголовок без суффикса:

```ts
useHead({ titleTemplate: (t) => (t ? `${t} · Магазин` : "Магазин — техника для разработчиков") });
```

## Компоненты в шаблоне

```vue
<template>
  <Head>
    <Title>{{ post?.title }}</Title>
    <Meta name="description" :content="post?.excerpt" />
  </Head>
</template>
```

Удобно, но composables предпочтительнее: логику проще переиспользовать и тестировать.

## Порядок применения

```text
nuxt.config app.head  →  app.vue  →  layout  →  страница  →  дочерние компоненты
```

Более глубокий уровень перекрывает значения выше. Для мета-тегов, которые не нужны поисковику (например, в админке), есть `useServerSeoMeta`/`useServerHead` — они выполняются только при SSR и не увеличивают клиентский бандл.

## Частые ошибки

- Передавать `post.value?.title` значением, а не геттером — мета-теги «застынут».
- Задавать мета-теги после `onMounted` — их не будет в HTML.
- Относительный `og:image` — соцсети требуют абсолютный URL.
- Дублировать title/description на всех страницах.
- Использовать `hid`/`vmid` из Nuxt 2 — в Unhead v2 их нет, дедупликация идёт по `key`.

## Что важно помнить

- `useSeoMeta` — для мета-тегов, `useHead` — для всего остального.
- Мета-теги должны вычисляться из данных, загруженных на сервере.
- Под капотом — библиотека Unhead, общая для экосистемы Vue.

## Мини-шпаргалка

- `useSeoMeta({ title: () => ..., description, ogImage })`.
- `useHead({ htmlAttrs, link, script })`.
- `app.head.titleTemplate: "%s · Site"`.
- Геттеры для реактивных значений.
- `useServerSeoMeta` — только SSR.
