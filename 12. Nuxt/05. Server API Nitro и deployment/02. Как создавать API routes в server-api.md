# Как создавать API routes в server/api

> [!NOTE]
> Файл в `server/api` — это эндпоинт с префиксом `/api`: путь файла задаёт URL, суффикс `.get`, `.post`, `.patch`, `.delete` — HTTP-метод (без суффикса — любой). Обработчик — `defineEventHandler(event => ...)`: возвращаемое значение автоматически сериализуется в JSON (или отдаётся как текст, поток, `Buffer`). Параметры пути — `[id]` в имени файла и `getRouterParam`, catch-all — `[...slug]`. Маршруты без префикса `/api` (sitemap, RSS, вебхуки) кладут в `server/routes`. Тип ответа автоматически выводится в `useFetch` на клиенте.

## Вопрос

Как создавать API-маршруты в Nuxt?

## Соответствие файлов и URL

```text
server/
├── api/
│   ├── products.get.ts            → GET    /api/products
│   ├── products.post.ts           → POST   /api/products
│   ├── products/
│   │   ├── [id].get.ts            → GET    /api/products/:id
│   │   ├── [id].patch.ts          → PATCH  /api/products/:id
│   │   └── [id].delete.ts         → DELETE /api/products/:id
│   ├── auth/[...].ts              → /api/auth/* любой метод
│   └── health.ts                  → /api/health любой метод
└── routes/
    ├── sitemap.xml.ts             → /sitemap.xml
    └── webhooks/stripe.post.ts    → POST /webhooks/stripe
```

## CRUD-пример

```ts
// server/api/products.get.ts
export default defineEventHandler(async (event) => {
  const { page = "1" } = getQuery(event);
  return db.query.products.findMany({ limit: 20, offset: (Number(page) - 1) * 20 });
});
```

```ts
// server/api/products.post.ts
import { z } from "zod";

const schema = z.object({ title: z.string().min(1), price: z.number().positive() });

export default defineEventHandler(async (event) => {
  const body = await readValidatedBody(event, schema.parse); // 400 при невалидном теле
  const [product] = await db.insert(products).values(body).returning();
  setResponseStatus(event, 201);
  return product;
});
```

```ts
// server/api/products/[id].get.ts
export default defineEventHandler(async (event) => {
  const id = Number(getRouterParam(event, "id"));
  const product = await db.query.products.findFirst({ where: eq(products.id, id) });
  if (!product) throw createError({ statusCode: 404, statusMessage: "Product not found" });
  return product;
});
```

## Вызов с клиента

```vue
<script setup lang="ts">
const { data: products } = await useFetch("/api/products", { query: { page: 1 } });
//      ^ тип выведен из обработчика

async function create() {
  await $fetch("/api/products", { method: "POST", body: { title: "Mouse", price: 1990 } });
}
</script>
```

На сервере (при SSR) `$fetch("/api/products")` вызывает обработчик напрямую, без сетевого запроса.

## Что можно вернуть

| Возврат | Ответ |
| --- | --- |
| Объект, массив | JSON |
| Строка | `text/html` или текст |
| `null`/`undefined` | 204 No Content |
| `Buffer`, `ReadableStream` | Бинарные данные, стрим |
| `sendRedirect(event, "/x")` | Редирект |
| `throw createError(...)` | Ошибка с кодом |

## Типизация ответа

```ts
export default defineEventHandler(async (): Promise<Product[]> => { /* ... */ });
```

Явная аннотация полезна, если вывод типа из ORM слишком сложный. Даты в JSON становятся строками — Nuxt учитывает это в выведенном типе.

## Частые ошибки

- Не валидировать тело и параметры — в обработчик приходит что угодно.
- Возвращать `{ ok: false }` со статусом 200 вместо `createError`.
- Класть публичные маршруты вроде `/sitemap.xml` в `server/api` и получать `/api/sitemap.xml`.
- Импортировать серверный код из `app/` — `server/` в бандл клиента не попадает, но импорт сломает сборку.

## Что важно помнить

- Имя файла = URL + метод; это проще и нагляднее, чем регистрация маршрутов.
- `readValidatedBody`, `getValidatedQuery`, `getValidatedRouterParams` — встроенная интеграция с Zod и другими валидаторами.
- Проверка авторизации делается в каждом защищённом обработчике или в общем middleware.

## Мини-шпаргалка

- `server/api/x.get.ts` → `GET /api/x`.
- `[id]` + `getRouterParam(event, "id")`.
- `readValidatedBody(event, schema.parse)`.
- `setResponseStatus(event, 201)`, `createError({ statusCode })`.
- Без префикса `/api` — `server/routes`.
