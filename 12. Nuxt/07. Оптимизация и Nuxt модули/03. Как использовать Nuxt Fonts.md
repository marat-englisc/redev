# Как использовать Nuxt Fonts

> [!NOTE]
> `@nuxt/fonts` работает почти без настройки: он **сканирует CSS** на `font-family`, находит шрифт локально в `public/` или у провайдера (Google Fonts, Bunny, Fontshare, Fontsource, Adobe), **скачивает его к себе** (self-hosting, без запросов к сторонним доменам), генерирует `@font-face` с `font-display: swap`, добавляет `preload` и **fallback-метрики** (подстроенный системный шрифт), что почти убирает сдвиг макета (CLS) при подмене шрифта. Настраивают веса, начертания и subsets — например, `cyrillic`.

## Вопрос

Как подключать и оптимизировать веб-шрифты в Nuxt с помощью Nuxt Fonts?

## Подключение

```bash
npx nuxt module add fonts
```

```css
/* app/assets/css/main.css */
body {
  font-family: "Inter", sans-serif;
}

h1, h2 {
  font-family: "Unbounded", sans-serif;
}
```

Больше ничего не нужно: модуль найдёт `Inter` и `Unbounded`, скачает и подключит их.

## Настройка

```ts
export default defineNuxtConfig({
  modules: ["@nuxt/fonts"],
  fonts: {
    defaults: {
      weights: [400, 600, 700],
      styles: ["normal"],
      subsets: ["latin", "cyrillic"],
    },
    families: [
      { name: "Unbounded", weights: [700], provider: "google" },
      { name: "Brand Sans", src: "/fonts/brand-sans.woff2", weight: 400 },  // свой файл из public/
    ],
  },
});
```

## Что модуль делает

```text
CSS font-family: "Inter"
  → поиск: public/ → провайдеры
  → скачивание woff2 в /_fonts/ (self-hosting)
  → @font-face { font-display: swap; unicode-range: ... }
  → @font-face для fallback: Arial с size-adjust, ascent-override под метрики Inter
  → <link rel="preload"> для основных начертаний
```

Fallback-метрики делают системный шрифт геометрически похожим на загружаемый — при подмене текст почти не «прыгает».

## Почему self-hosting

- Нет DNS-запроса и соединения к fonts.googleapis.com — быстрее.
- Нет передачи IP пользователей третьей стороне — проще соответствовать GDPR.
- Шрифт кэшируется вместе с остальными ассетами сайта.

## Производительность

- Каждое начертание — отдельный файл: подключайте только используемые веса.
- Вариативный шрифт (один файл на все веса) часто выгоднее 3–4 статических.
- `subsets` уменьшают размер: для русского сайта — `latin` и `cyrillic`.
- Шрифт заголовков первого экрана влияет на LCP.

## Частые ошибки

- Указывать `font-family` в атрибуте `style` шаблона — модуль сканирует CSS, а не inline-стили.
- Подключать 8 начертаний «на всякий случай».
- Забыть `cyrillic` — кириллица отрисуется fallback-шрифтом.
- Параллельно подключать тот же шрифт через `<link>` на Google Fonts.

## Что важно помнить

- Модуль «нулевой настройки»: достаточно объявить `font-family` в CSS.
- Главные выигрыши — self-hosting, preload и fallback-метрики против CLS.
- Результат проверяют во вкладке Network и метриках LCP/CLS.

## Мини-шпаргалка

- `font-family` в CSS → шрифт подключён.
- `fonts.defaults`: `weights`, `styles`, `subsets`.
- `fonts.families` — точечная настройка и свои файлы.
- Self-hosting + `font-display: swap` + fallback-метрики.
