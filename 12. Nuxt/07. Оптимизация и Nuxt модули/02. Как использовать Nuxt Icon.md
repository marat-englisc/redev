# Как использовать Nuxt Icon

> [!NOTE]
> `@nuxt/icon` даёт компонент `<Icon name="коллекция:иконка" />` с доступом к 200 000+ иконкам **Iconify** (Lucide, Material Symbols, Heroicons, Tabler...) и собственным SVG. Иконки работают при SSR, рендерятся в режиме **CSS** (маска на `<span>`, по умолчанию) или **SVG** (inline). Чтобы иконки не загружались с внешнего API в рантайме, нужные коллекции ставят локально (`@iconify-json/lucide`) — тогда модуль отдаёт их со своего сервера и включает используемые в клиентский бандл.

## Вопрос

Как подключать иконки в Nuxt через Nuxt Icon?

## Подключение

```bash
npx nuxt module add icon
npm i -D @iconify-json/lucide @iconify-json/simple-icons
```

```ts
export default defineNuxtConfig({
  modules: ["@nuxt/icon"],
  icon: {
    mode: "css",
    cssLayer: "base",                      // при использовании Tailwind CSS v4
    serverBundle: { collections: ["lucide", "simple-icons"] },
  },
});
```

## Использование

```vue
<template>
  <button class="flex items-center gap-2">
    <Icon name="lucide:shopping-cart" size="20" />
    Корзина
  </button>

  <a href="https://github.com/org/repo" aria-label="GitHub">
    <Icon name="simple-icons:github" class="size-6 text-slate-700" />
  </a>
</template>
```

Цвет наследуется от `currentColor`, размер задаётся `size` или CSS.

## CSS и SVG режимы

| | `mode: "css"` | `mode: "svg"` |
| --- | --- | --- |
| Разметка | `<span>` с CSS-маской | Inline `<svg>` |
| Многоцветные иконки | Нет (одноцветные) | Да |
| Анимация частей иконки | Нет | Да |
| Размер HTML | Меньше | Больше |

```vue
<Icon name="logos:vue" mode="svg" />
```

## Свои SVG

```ts
export default defineNuxtConfig({
  icon: {
    customCollections: [{ prefix: "brand", dir: "./app/assets/icons" }],
  },
});
```

```vue
<Icon name="brand:logo" />   <!-- app/assets/icons/logo.svg -->
```

## Доступность

- Декоративная иконка рядом с текстом не требует подписи — модуль ставит `aria-hidden`.
- Иконка-кнопка без текста должна иметь `aria-label` на кнопке или ссылке.

## Частые ошибки

- Не установить коллекции локально — иконки грузятся с публичного API Iconify, появляется задержка и внешняя зависимость.
- Ставить пакет `@iconify/json` со всеми коллекциями (сотни мегабайт) вместо нужных.
- Ожидать многоцветную иконку в CSS-режиме.
- Иконка-кнопка без доступного имени.

## Что важно помнить

- Имя иконки: `коллекция:имя`, искать удобно на icones.js.org.
- Локальные коллекции + `serverBundle` — быстро и без внешних запросов.
- CSS-режим — оптимальный по умолчанию для одноцветных UI-иконок.

## Мини-шпаргалка

- `<Icon name="lucide:search" size="20" />`.
- `npm i -D @iconify-json/<collection>`.
- `mode: "css" | "svg"`.
- `customCollections` — свои SVG.
- `aria-label` для кнопок-иконок.
