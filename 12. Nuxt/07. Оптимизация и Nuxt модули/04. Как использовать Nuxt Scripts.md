# Как использовать Nuxt Scripts

> [!NOTE]
> `@nuxt/scripts` управляет сторонними скриптами (аналитика, чаты, карты, видео, платёжные виджеты), которые чаще всего портят INP, LCP и приватность. `useScript(src, { trigger })` загружает скрипт **по условию** — после гидрации (`onNuxtReady`), по взаимодействию, после согласия на cookies — и возвращает `proxy`, через который можно вызывать API скрипта **до его загрузки** (вызовы ставятся в очередь). Для популярных сервисов есть типизированный реестр: `useScriptGoogleAnalytics`, `useScriptYandexMetrika`, `useScriptStripe` и фасад-компоненты вроде `<ScriptYouTubePlayer>`.

## Вопрос

Как подключать сторонние скрипты в Nuxt без вреда для производительности и приватности?

## Подключение

```bash
npx nuxt module add scripts
```

## useScript

```ts
const { proxy, onLoaded, status } = useScript<{ track: (event: string) => void }>(
  "https://cdn.analytics.example/tracker.js",
  {
    trigger: "onNuxtReady",                // после гидрации, не блокирует первый рендер
    use: () => ({ track: window.tracker.track }),
  },
);

proxy.track("page_view");                   // в очереди до загрузки скрипта
onLoaded(({ track }) => track("loaded"));
```

## Триггеры

| Триггер | Когда загружается |
| --- | --- |
| `"onNuxtReady"` (по умолчанию) | После гидрации и простоя браузера |
| `"client"` | Сразу на клиенте |
| `"server"` | Тег добавляется в HTML на сервере |
| `useScriptTriggerElement({ trigger: "visible", el })` | Элемент появился в viewport |
| `useScriptTriggerConsent()` | Пользователь дал согласие |
| `Promise` / `ref<boolean>` | По вашему условию |
| `"manual"` | Только по `load()` |

## Согласие на cookies

```ts
const consent = useScriptTriggerConsent();

useScriptGoogleAnalytics({
  id: useRuntimeConfig().public.gaId,
  scriptOptions: { trigger: consent },
});

function acceptCookies() {
  consent.accept();                         // теперь аналитика загрузится
}
```

## Фасады

```vue
<template>
  <!-- показывает превью-картинку, а тяжёлый плеер грузит только по клику -->
  <ScriptYouTubePlayer video-id="dQw4w9WgXcQ" />
</template>
```

Встраивание YouTube напрямую тянет около мегабайта JS ещё до того, как пользователь захочет смотреть видео.

## Зачем это нужно

Сторонние скрипты:

- блокируют основной поток и ухудшают INP;
- конкурируют за сеть с ресурсами первого экрана (LCP);
- ставят cookies и передают данные до получения согласия;
- ломают SSR, обращаясь к `window` при импорте;
- падают и тянут за собой ошибки в консоли.

Nuxt Scripts решает загрузку и SSR-безопасность, но не отменяет вопрос «нужен ли этот скрипт вообще».

## Частые ошибки

- Подключать трекеры через `useHead({ script: [...] })` в `<head>` — блокирующая загрузка до первого рендера.
- Загружать аналитику до согласия пользователя там, где это требует закон.
- Встраивать карты и видео сразу вместо фасадов.
- Вызывать глобальный объект скрипта (`window.ym`) напрямую до загрузки.

## Что важно помнить

- Лучший сторонний скрипт — тот, которого нет; второй лучший — загруженный позже и по условию.
- `proxy` позволяет писать код, не дожидаясь загрузки скрипта.
- Эффект проверяют в Lighthouse (Third-party usage, TBT) и полевых данных INP.

## Мини-шпаргалка

- `useScript(src, { trigger })` → `proxy`, `onLoaded`, `status`.
- Триггеры: `onNuxtReady`, видимость, согласие, вручную.
- Реестр: `useScriptGoogleAnalytics`, `useScriptYandexMetrika`...
- Фасады: `<ScriptYouTubePlayer>`, `<ScriptGoogleMaps>`.
