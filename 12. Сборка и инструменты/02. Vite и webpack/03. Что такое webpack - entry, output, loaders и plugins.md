# Что такое webpack: entry, output, loaders и plugins

> [!NOTE]
> **webpack** — бандлер, долго бывший стандартом фронтенд-сборки; он по-прежнему работает во многих существующих проектах (Create React App, старые Angular и Vue, корпоративные приложения) и в основе Next.js до Turbopack. Ключевые понятия: **entry** (откуда начать граф), **output** (куда и с какими именами положить результат), **loaders** (как превратить файл не-JS в модуль: TS, CSS, изображения), **plugins** (действия над всей сборкой: HTML, извлечение CSS, переменные окружения), **mode** (development/production) и **optimization** (чанки, минификация).

## Вопрос

Что такое webpack и из чего состоит его конфигурация? Чем loader отличается от plugin?

## Минимальный конфиг

```javascript
// webpack.config.js
const path = require("node:path");
const HtmlWebpackPlugin = require("html-webpack-plugin");
const MiniCssExtractPlugin = require("mini-css-extract-plugin");

module.exports = (env, argv) => {
  const isProd = argv.mode === "production";

  return {
    entry: "./src/index.tsx",
    output: {
      path: path.resolve(__dirname, "dist"),
      filename: isProd ? "assets/[name].[contenthash].js" : "assets/[name].js",
      clean: true,
      publicPath: "/",
    },
    resolve: {
      extensions: [".tsx", ".ts", ".js"],
      alias: { "@": path.resolve(__dirname, "src") },
    },
    module: {
      rules: [
        { test: /\.[jt]sx?$/, exclude: /node_modules/, use: "babel-loader" },     // или swc-loader
        { test: /\.css$/, use: [isProd ? MiniCssExtractPlugin.loader : "style-loader", "css-loader", "postcss-loader"] },
        { test: /\.(png|jpe?g|webp|svg)$/, type: "asset" },                      // встроенные asset modules
      ],
    },
    plugins: [
      new HtmlWebpackPlugin({ template: "./public/index.html" }),
      isProd && new MiniCssExtractPlugin({ filename: "assets/[name].[contenthash].css" }),
    ].filter(Boolean),
    devtool: isProd ? "hidden-source-map" : "eval-cheap-module-source-map",
    devServer: { historyApiFallback: true, hot: true, proxy: [{ context: ["/api"], target: "http://localhost:3000" }] },
    optimization: { splitChunks: { chunks: "all" } },
  };
};
```

## Loader и plugin

| | Loader | Plugin |
| --- | --- | --- |
| Работает с | отдельным файлом | всей сборкой и ее событиями |
| Задача | превратить файл в JS-модуль | генерировать файлы, менять результат, внедрять переменные |
| Где указывается | `module.rules` | `plugins` |
| Примеры | `babel-loader`, `ts-loader`, `css-loader`, `sass-loader` | `HtmlWebpackPlugin`, `MiniCssExtractPlugin`, `DefinePlugin`, `BundleAnalyzerPlugin` |

Loaders применяются **справа налево** (снизу вверх): `["style-loader", "css-loader", "sass-loader"]` — сначала SCSS → CSS, потом CSS → модуль, потом вставка в `<style>`.

## Полезные возможности webpack 5

- **asset modules** (`type: "asset"`) вместо `file-loader` и `url-loader`;
- **persistent cache** (`cache: { type: "filesystem" }`) — быстрые повторные сборки;
- **Module Federation** — загрузка модулей другого приложения в рантайме (микрофронтенды);
- **tree shaking** в production и `sideEffects` из `package.json`.

## webpack сегодня

- новые проекты чаще начинают на **Vite**;
- **Rspack** — совместимая с webpack замена на Rust (те же конфиги и большинство loaders/plugins, в разы быстрее);
- Next.js переходит на **Turbopack**;
- знание webpack нужно для поддержки существующих проектов и на собеседованиях.

## Что важно помнить

- `[contenthash]` в `filename` — основа долгого кеширования.
- `style-loader` для dev (быстро, HMR), `MiniCssExtractPlugin` для prod (отдельные CSS-файлы).
- `historyApiFallback` нужен SPA с клиентским роутингом, иначе перезагрузка на `/settings` даст 404.
- Медленный webpack ускоряют: filesystem-кеш, `swc-loader`/`esbuild-loader` вместо Babel, `thread-loader`, переход на Rspack.
- Связанные темы: [сравнение бандлеров](<06. Чем отличаются Vite, webpack, Rspack, Turbopack, esbuild и Rollup.md>).

## Мини-шпаргалка

webpack: `entry` → `module.rules` (loaders: файл → модуль) → `plugins` (вся сборка) → `output` с `[contenthash]`. `mode`, `devtool`, `devServer`, `optimization.splitChunks`. Loaders — справа налево. Webpack 5: asset modules, filesystem cache, Module Federation. Быстрая замена — Rspack.
