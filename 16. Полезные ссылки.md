# Полезные ссылки

> [!NOTE]
> В первую очередь здесь собраны русскоязычные материалы. Codewars, LeetCode и официальная шпаргалка Git оставлены как полезные англоязычные исключения.

## Документация и справочники

- [Дока](https://doka.guide/) — понятные статьи по HTML, CSS, JavaScript, веб-платформе и доступности.
- [MDN Web Docs на русском](https://developer.mozilla.org/ru/docs/Web) — справочник по веб-технологиям, Web API, HTTP и браузерной платформе.
- [Современный учебник JavaScript](https://learn.javascript.ru/) — последовательное изучение языка и браузерных API с задачами.
- [TypeScript на ScriptDev](https://scriptdev.ru/guide/) — русскоязычное руководство по TypeScript.
- [Vue](https://ru.vuejs.org/guide/introduction.html) — официальное руководство на русском языке.
- [Vue Router](https://vue-router-ru.netlify.app/guide/) — русскоязычное руководство по маршрутизации во Vue.
- [Pinia](https://pinia-ru.netlify.app/core-concepts/) — основные концепции управления состоянием во Vue.
- [Vite](https://vite-docs-ru.vercel.app/guide/) — русскоязычное руководство по сборщику.
- [Node.js для начинающих](https://nodejsdev.ru/) — перевод документации, справочник API и практические руководства по Node.js.
- [Frontskill](https://frontskill.ru/docs) — справочник по темам фронтенд-разработки.
- [Шпаргалка Git](https://git-scm.com/cheat-sheet) — основные команды Git (англ.).

## Обучение и углубление знаний

- [Code Basics: JavaScript](https://code-basics.com/ru/languages/javascript) — бесплатный интерактивный курс для начинающих с упражнениями в браузере.
- [Хендбук «Основы алгоритмов» от Яндекса](https://education.yandex.ru/handbook/algorithms) — теория, структуры данных и задачи с автоматической проверкой.
- [Веб-стандарты](https://web-standards.ru/) — статьи, новости и подкаст о современной веб-разработке.

## Подготовка к собеседованиям

- [Hack Frontend](https://www.hackfrontend.com/ru/docs/introduction) — теория и вопросы по фронтенду.
- [SpeedrUnit](https://speedrunit.ru/questions/frontend/) — тренажёр вопросов для собеседований.
- [IT Booster](https://itbooster.ru/database/) — база вопросов по веб-разработке.
- [Подборки CodeRun](https://coderun.yandex.ru/selections) — тематические наборы задач, включая подготовку к собеседованиям.
- [Тренировки по алгоритмам от Яндекса](https://yandex.ru/yaintern/training) — лекции, разборы и домашние задания прошлых сезонов.

## Практика и алгоритмы

- [CodeRun: алгоритмы](https://coderun.yandex.ru/catalog?groups=algorithm) — задачи на русском языке с онлайн-проверкой решений.
- [Codewars](https://www.codewars.com/) — короткие задачи разной сложности (англ.).
- [LeetCode](https://leetcode.com/) — большая база алгоритмических задач и типовых задач с собеседований (англ.).

## Доступность, безопасность и производительность

- [Гайд МТС по веб-доступности](https://www.a11y.mts.ru/web) — практические требования и примеры доступных интерфейсов.
- [Безопасность веб-сайтов на MDN](https://developer.mozilla.org/ru/docs/Web/Security) — базовые угрозы и способы защиты веб-приложений.
- [Производительность веб-сайтов на MDN](https://developer.mozilla.org/ru/docs/Learn_web_development/Extensions/Performance) — критический путь рендеринга, загрузка ресурсов и измерение производительности.
