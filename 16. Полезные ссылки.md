# Полезные ссылки

> [!NOTE]
> В первую очередь здесь собраны русскоязычные материалы. Англоязычные ресурсы помечены «(англ.)» и оставлены там, где хорошей русской альтернативы нет: документация Next.js, Redux Toolkit, TanStack Query и большинства инструментов экосистемы React доступна только на английском.

## Документация и справочники

- [Дока](https://doka.guide/) — понятные статьи по HTML, CSS, JavaScript, веб-платформе и доступности.
- [MDN Web Docs на русском](https://developer.mozilla.org/ru/docs/Web) — справочник по веб-технологиям, Web API, HTTP и браузерной платформе.
- [Современный учебник JavaScript](https://learn.javascript.ru/) — последовательное изучение языка и браузерных API с задачами.
- [TypeScript на ScriptDev](https://scriptdev.ru/guide/) — русскоязычное руководство по TypeScript.
- [Node.js для начинающих](https://nodejsdev.ru/) — перевод документации, справочник API и практические руководства по Node.js.
- [Vite](https://vite-docs-ru.vercel.app/guide/) — русскоязычное руководство по сборщику.
- [Frontskill](https://frontskill.ru/docs) — справочник по темам фронтенд-разработки.
- [Шпаргалка Git](https://git-scm.com/cheat-sheet) — основные команды Git (англ.).

## React

- [Изучение React](https://ru.react.dev/learn) — официальное руководство на русском: компоненты, состояние, эффекты, «Thinking in React».
- [Справочник API React](https://ru.react.dev/reference/react) — все хуки, компоненты и API с примерами и типичными ошибками.
- [Серверные компоненты](https://ru.react.dev/reference/rsc/server-components) — React Server Components, директивы `'use client'` и `'use server'`.
- [React и TypeScript](https://ru.react.dev/learn/typescript) — официальный раздел о типизации props, хуков и событий.
- [React TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app/) — шпаргалка по типизации компонентов, контекста, рефов и дженерик-компонентов (англ.).
- [React с примерами кода](https://reactdev.ru/) — русскоязычные переводы документации библиотек экосистемы React.
- [React и альтернативы в Доке](https://doka.guide/tools/react-and-alternatives/) — место React среди других UI-библиотек.
- [Patterns.dev](https://www.patterns.dev/) — паттерны рендеринга, производительности и проектирования React-приложений (англ.).

## Next.js

- [Документация Next.js](https://nextjs.org/docs) — App Router, рендеринг, Data Fetching, Server Actions, Metadata и конфигурация (англ.).
- [Next.js Learn](https://nextjs.org/learn) — официальный пошаговый курс: от первой страницы до дашборда с БД и авторизацией (англ.).
- [Кэширование в Next.js](https://nextjs.org/docs/app/guides/caching) — уровни кэша, ревалидация и их взаимодействие; частая тема на собеседованиях (англ.).
- [Документация Vercel](https://vercel.com/docs) — деплой, Edge и Serverless функции, переменные окружения (англ.).
- [Auth.js](https://authjs.dev/) — аутентификация в Next.js-приложениях (англ.).
- [Prisma](https://www.prisma.io/docs) — ORM для fullstack-приложений на Next.js (англ.).

## Состояние, данные и формы

- [Redux Toolkit](https://redux-toolkit.js.org/) — официальная документация: `createSlice`, `configureStore`, RTK Query (англ.).
- [Redux Toolkit на русском](https://reactdev.ru/libs/redux-toolkit/) — перевод документации Redux Toolkit.
- [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview) — серверное состояние, кэширование и инвалидация запросов (англ.).
- [React Router](https://reactrouter.com/) — маршрутизация в SPA на React (англ.).
- [React Hook Form](https://react-hook-form.com/) — производительные формы на неконтролируемых полях (англ.).
- [Zod](https://zod.dev/) — валидация данных и вывод типов TypeScript из схем (англ.).

## Стили и UI

- [Tailwind CSS](https://tailwindcss.com/docs) — документация utility-first CSS-фреймворка (англ.).
- [shadcn/ui](https://ui.shadcn.com/) — копируемые доступные компоненты на React и Tailwind CSS (англ.).

## Тестирование

- [Vitest](https://vitest.dev/) — быстрый тест-раннер, совместимый с API Jest (англ.).
- [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/) — тестирование компонентов через поведение пользователя (англ.).
- [Playwright](https://playwright.dev/docs/intro) — E2E-тесты в реальных браузерах (англ.).

## Архитектура

- [Feature-Sliced Design](https://feature-sliced.design/ru/) — методология структурирования фронтенд-проектов, популярная в React-командах.

## Обучение и углубление знаний

- [Code Basics: JavaScript](https://code-basics.com/ru/languages/javascript) — бесплатный интерактивный курс для начинающих с упражнениями в браузере.
- [Хендбук «Основы алгоритмов» от Яндекса](https://education.yandex.ru/handbook/algorithms) — теория, структуры данных и задачи с автоматической проверкой.
- [Веб-стандарты](https://web-standards.ru/) — статьи, новости и подкаст о современной веб-разработке.
