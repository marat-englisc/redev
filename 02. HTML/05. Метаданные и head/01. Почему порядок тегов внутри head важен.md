# Почему порядок тегов внутри head важен?

> [!NOTE]
> Порядок тегов внутри `<head>` важен, потому что браузер читает документ сверху вниз: кодировка, viewport, preload, CSS, scripts и SEO-метаданные могут влиять на скорость, корректность отображения и поведение страницы.

## Вопрос

Почему порядок тегов внутри `head` имеет значение? Что ставить первым?

## Главное

`head` содержит служебные данные, которые браузер использует очень рано. Некоторые теги важно встретить как можно раньше.

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Документация</title>
  <link rel="stylesheet" href="/styles.css">
</head>
```

## Что лучше ставить в начале

`charset` обычно ставят первым или как можно ближе к началу.

```html
<meta charset="UTF-8">
```

Так браузер раньше понимает кодировку документа и корректно читает символы.

## Viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Этот тег важен для адаптивной верстки. Без него мобильный браузер может отображать страницу как уменьшенную desktop-версию.

## CSS

CSS в `head` помогает браузеру построить CSSOM и отрисовать страницу в правильном виде.

```html
<link rel="stylesheet" href="/styles.css">
```

Если критичные стили загрузятся поздно, пользователь может увидеть скачок оформления.

## Preload и preconnect

Ресурсные подсказки имеют смысл только если браузер встречает их рано.

```html
<link rel="preconnect" href="https://fonts.gstatic.com">
<link rel="preload" href="/hero.jpg" as="image">
```

Они помогают заранее подготовить соединение или загрузить важный ресурс.

## Скрипты

Скрипты в `head` обычно подключают с `defer` или `type="module"`.

```html
<script src="/app.js" defer></script>
```

Обычный синхронный скрипт может заблокировать парсинг HTML.

## Что важно помнить

- Рекомендуемый порядок: `charset`, `viewport`, `title`, `preconnect`, асинхронные и критичные скрипты, CSS, preload, `defer`-скрипты, SEO и OG-метаданные.
- Синхронный скрипт перед CSS ожидает его загрузки только если стоит после него — порядок влияет на блокировки.
- `<base href>` меняет базу всех относительных URL и должен стоять до любых ссылок на ресурсы.
- Инструмент capo.js показывает, насколько порядок `head` оптимален.

## Мини-шпаргалка

- `charset` ставят как можно раньше.
- `viewport` нужен для адаптивности.
- CSS обычно подключают в `head`.
- `preload` и `preconnect` полезны только при раннем обнаружении.
- Скрипты в `head` лучше делать `defer` или module.
- Порядок влияет на загрузку и первое отображение.
