# Что такое Open Graph и для чего нужны og-теги?

> [!NOTE]
> **Open Graph** — набор мета-тегов `og:*`, которые описывают, как ссылка на страницу выглядит при публикации в соцсетях, мессенджерах и других сервисах предпросмотра: заголовок, описание, картинка, URL и тип страницы.

## Вопрос

Что такое Open Graph? Для чего использовать мета-теги `og` и чем они отличаются от обычных `title` и `description`?

## Основная идея

Когда пользователь отправляет ссылку, платформа (Telegram, VK, Slack, Facebook) скачивает HTML и собирает preview-карточку:

```text
URL shared
  -> crawler reads HTML
  -> finds og-tags
  -> builds preview card
```

Без `og`-тегов сервис сам попытается выбрать заголовок, описание и картинку, и результат часто бывает неудачным. Хороший preview повышает доверие к ссылке и кликабельность — это важно для статей, товаров, лендингов и мероприятий.

## Основные og-теги

| Тег | Что задает |
| --- | --- |
| `og:title` | Заголовок карточки |
| `og:description` | Краткое описание |
| `og:image` | Картинку предпросмотра (абсолютный URL) |
| `og:url` | Канонический URL страницы |
| `og:type` | Тип объекта: `website`, `article`, `product` |
| `og:site_name` | Название сайта |
| `og:locale` | Язык, например `ru_RU` |

## Пример для статьи

```html
<head>
  <title>Семантика HTML - Frontend Notes</title>
  <meta name="description" content="Разбор семантической HTML-разметки">

  <meta property="og:type" content="article">
  <meta property="og:title" content="Семантика HTML">
  <meta property="og:description" content="Как выбирать HTML-теги по смыслу">
  <meta property="og:image" content="https://example.com/og/html-semantics.png">
  <meta property="og:image:width" content="1200">
  <meta property="og:image:height" content="630">
  <meta property="og:url" content="https://example.com/html/semantics">

  <meta name="twitter:card" content="summary_large_image">
</head>
```

## Отличие от обычных meta

```html
<meta name="description" content="Описание для поиска">
<meta property="og:description" content="Описание для карточки ссылки">
```

`title` и `description` ориентированы на поисковую выдачу, `og:*` — на предпросмотр ссылки. Open Graph не влияет на ранжирование напрямую и не заменяет SEO-теги.

## Изображение

- Задавайте абсолютный URL: `https://example.com/assets/share.png`.
- Рекомендуемый размер — 1200×630 px (соотношение примерно 1.91:1).
- Картинка должна быть доступна без авторизации, cookies и блокировок.

## Что важно помнить

- Open Graph использует атрибут `property`, а не `name`.
- Для X (Twitter) есть свои теги `twitter:card`, `twitter:image`; при их отсутствии часто берутся `og:*`.
- Платформы кешируют карточку: после изменения тегов нужно сбросить cache через их инструменты отладки (например, Facebook Sharing Debugger).
- Роботы соцсетей не выполняют JavaScript, поэтому в SPA `og`-теги должны приходить в HTML с сервера (SSR, prerender, Next.js Metadata API).

## Мини-шпаргалка

- Open Graph управляет карточкой ссылки при шаринге.
- Главные: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`.
- `property`, а не `name`.
- Картинка — абсолютный URL, 1200×630, без авторизации.
- Не заменяет `title` и `description`.
