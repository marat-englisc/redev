# Мета-теги: charset, description, robots и keywords

> [!NOTE]
> Мета-теги — элементы `<meta>` внутри `<head>`, которые описывают служебную информацию о документе. `charset` задает кодировку, `viewport` — поведение на мобильных, `description` — описание для поисковой выдачи, `robots` — инструкции для поисковых роботов, Open Graph — карточку ссылки. `keywords` устарел и на ранжирование почти не влияет.

## Вопрос

Что такое мета-теги? Что делают `meta charset`, `description`, `robots` и `keywords`?

## Основная идея

`<meta>` не показывает контент на странице. Он сообщает браузеру и внешним системам, как обрабатывать документ.

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML-формы: label, input и валидация</title>
  <meta name="description" content="Руководство по HTML-формам: label, input, validation, autocomplete и доступность.">
  <meta name="robots" content="index, follow">
</head>
```

| Meta | Назначение |
| --- | --- |
| `charset` | Кодировка документа |
| `viewport` | Масштаб и ширина на мобильных устройствах |
| `description` | Краткое описание для сниппета в поиске |
| `robots` | Инструкции для поисковых роботов |
| `og:*` | Карточка ссылки в соцсетях и мессенджерах |
| `theme-color` | Цвет интерфейса браузера на мобильных |
| `keywords` | Устаревший список ключевых слов |

## meta charset="UTF-8"

```html
<meta charset="UTF-8">
```

Кодировка определяет, как байты файла превращаются в символы. Если браузер выберет неправильную кодировку, кириллица превратится в «кракозябры». UTF-8 поддерживает практически все языки, знаки валют, математические символы и emoji, поэтому это стандартный выбор.

Тег ставят первым в `head`: спецификация требует, чтобы он находился в первых 1024 байтах документа. Кодировку также может передать сервер в header `Content-Type: text/html; charset=utf-8` — у него приоритет.

## meta name="description"

```html
<meta
  name="description"
  content="Практический конспект по HTML: структура документа, семантика, формы и доступность."
>
```

Описание может появиться в поисковой выдаче под заголовком. Оно не влияет на ранжирование напрямую, но влияет на кликабельность.

Хороший description:

- конкретен и соответствует содержимому страницы;
- уникален для каждой важной страницы;
- укладывается примерно в 150–160 символов, иначе обрежется.

Поисковик может показать не meta description, а фрагмент текста страницы, если сочтет его более подходящим под запрос.

## meta name="robots"

```html
<meta name="robots" content="noindex, nofollow">
```

| Значение | Смысл |
| --- | --- |
| `index` / `noindex` | можно / нельзя показывать страницу в поиске |
| `follow` / `nofollow` | переходить / не переходить по ссылкам |
| `noarchive` | не показывать сохраненную копию |
| `nosnippet` | не показывать текстовый сниппет |

`noindex` используют для админок, технических страниц, дублей, черновиков и внутреннего поиска. По умолчанию действует `index, follow`, поэтому явно писать его не нужно.

Важный нюанс: если страница закрыта в `robots.txt`, робот не зайдет на нее и не увидит `noindex`. `robots.txt` управляет обходом, а `meta robots` — индексацией.

`noindex` не защищает приватные данные: для этого нужна авторизация.

## meta name="keywords"

```html
<meta name="keywords" content="html, css, frontend, верстка">
```

Исторически перечислял ключевые слова, но из-за спама поисковики перестали его учитывать. Google официально его игнорирует. Вместо него работают понятный `title`, честный `description`, логичные заголовки, качественный текст и семантическая структура. В новых проектах его обычно не добавляют.

## Что важно помнить

- `name` используется для стандартных meta (`description`, `robots`, `viewport`), а Open Graph — через `property`.
- `<meta http-equiv="...">` имитирует HTTP-header (например, CSP или refresh), но настоящие headers сервера надежнее.
- В SPA мета-теги, добавленные JavaScript-ом, видят не все роботы. Для SEO их рендерят на сервере (Next.js Metadata API, SSR).
- Для управления индексацией файлов, которые не являются HTML (PDF), используют header `X-Robots-Tag`.

## Мини-шпаргалка

- `<meta>` живет в `head` и не отображается.
- `charset="UTF-8"` — первым в `head`.
- `description` — сниппет в поиске, уникальный для страницы.
- `robots` — `noindex` / `nofollow`; не путать с `robots.txt`.
- `keywords` устарел.
