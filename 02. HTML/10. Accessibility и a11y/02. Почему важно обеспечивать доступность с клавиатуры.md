# Почему важно обеспечивать доступность с клавиатуры?

> [!NOTE]
> Клавиатурная доступность нужна, чтобы пользователь мог пройти все важные сценарии без мыши: перейти по ссылкам, заполнить формы, открыть меню, нажать кнопки и закрыть модальные окна.

## Вопрос

Почему важна доступность с клавиатуры и как ее проверить?

## Главное

Многие пользователи работают с сайтом через клавиатуру: постоянно или временно. Если интерактивный элемент недоступен через `Tab`, часть интерфейса фактически недоступна.

```text
Tab -> next focusable element
Shift + Tab -> previous focusable element
Enter / Space -> activate control
Esc -> often closes modal/menu
```

## Нативные элементы помогают

```html
<button type="button">Открыть меню</button>
<a href="/profile">Профиль</a>
<input type="email" name="email">
```

Эти элементы уже умеют получать фокус и работать с клавиатуры.

## Проблема с div-кнопкой

```html
<!-- плохо -->
<div class="button" onclick="save()">Сохранить</div>
```

Такой элемент не получает фокус по умолчанию и не нажимается клавишами как кнопка.

```html
<!-- лучше -->
<button type="button">Сохранить</button>
```

## Видимый фокус

Пользователь должен видеть, где сейчас находится фокус.

```css
:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 2px;
}
```

Нельзя просто убирать outline без замены.

## Что проверять

- Можно ли пройти страницу клавишей `Tab`.
- Видно ли текущий фокус.
- Открываются ли меню и модалки с клавиатуры.
- Можно ли закрыть модалку.
- Нет ли ловушки фокуса.
- Порядок фокуса соответствует визуальной логике.

## Что важно помнить

- `tabindex="0"` добавляет элемент в порядок фокуса, `-1` позволяет фокусировать только программно, а положительные значения ломают порядок — их не используют.
- `:focus-visible` показывает фокус при навигации клавиатурой, но не при клике мышью.
- В модальном окне фокус должен оставаться внутри и возвращаться на кнопку-открыватель после закрытия; нативный `<dialog>` с `showModal()` делает это сам.
- Сложные виджеты (tabs, меню) используют roving tabindex: одна точка входа по Tab, перемещение стрелками.

## Мини-шпаргалка

- Все важные действия должны быть доступны с клавиатуры.
- Используй нативные `button`, `a`, `input`.
- Фокус должен быть видимым.
- `Tab` должен идти в логичном порядке.
- Модалки должны управлять фокусом.
- Не убирай `outline` без доступной замены.
