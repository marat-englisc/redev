# Из чего состоит HTML-документ: doctype, html, head и body?

> [!NOTE]
> HTML-документ состоит из декларации `<!doctype html>`, корневого элемента `<html>`, служебной части `<head>` и видимой части `<body>`. `<html>` оборачивает весь документ и задает язык через `lang`, `<head>` содержит метаданные и подключение ресурсов, `<body>` — весь контент, который видит пользователь.

## Вопрос

Из каких частей состоит HTML-документ? Что содержат элементы `html`, `head` и `body`? Зачем нужен `doctype`?

## Базовая структура

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет, HTML</h1>
    <p>Это видимое содержимое страницы.</p>
  </body>
</html>
```

| Часть | Назначение |
| --- | --- |
| `<!doctype html>` | Включает современный режим отображения страницы |
| `<html>` | Корневой элемент всего документа |
| `<head>` | Метаданные, заголовок вкладки, подключение CSS и служебных ресурсов |
| `<body>` | Видимый контент страницы |

## Doctype

`<!doctype html>` сообщает браузеру, что документ нужно обрабатывать как современный HTML. Это не тег, а декларация, и регистр в ней не важен.

Без doctype браузер переходит в **quirks mode**, где часть CSS и layout-правил работает иначе для совместимости со старыми сайтами: например, по-другому считается box model и высота таблиц.

## Элемент html

`<html>` — корень документа. Внутри него два элемента: `<head>` и `<body>`.

```html
<html lang="ru">
  ...
</html>
```

Атрибут `lang` помогает:

- скринридерам правильно произносить текст;
- браузеру предлагать перевод и выбирать правила переносов (`hyphens: auto`);
- поисковым системам понимать язык страницы.

Для языков, которые читаются справа налево, добавляют `dir`:

```html
<html lang="ar" dir="rtl">
```

Если на странице есть фрагмент на другом языке, `lang` можно поставить и на него: `<span lang="en">frontend</span>`.

## Head

В `<head>` находятся данные о документе, которые не отображаются как контент: `meta`, `title`, `link`, `style`, `script`, `base`.

```html
<head>
  <meta charset="UTF-8" />
  <title>Документация</title>
  <link rel="stylesheet" href="/styles.css" />
</head>
```

Видимый контент в `<head>` класть нельзя:

```html
<!-- неправильно -->
<head>
  <h1>Заголовок страницы</h1>
</head>
```

Парсер сам закроет `head` и перенесет `h1` в `body`, но такая разметка невалидна.

## Body

`<body>` содержит всё, что пользователь видит и с чем взаимодействует: заголовки и текст, навигацию, изображения, формы, таблицы.

```html
<body>
  <header>Шапка сайта</header>
  <main>
    <h1>Каталог</h1>
    <p>Выберите товар из списка.</p>
  </main>
  <footer>Контакты</footer>
</body>
```

`body` не заменяет семантические элементы: внутри него всё равно стоит использовать `header`, `main`, `footer`.

В SPA на Vue, React или Angular в `body` обычно есть контейнер, куда монтируется приложение:

```html
<body>
  <div id="app"></div>
  <script type="module" src="/src/main.js"></script>
</body>
```

## Что важно помнить

- Если пропустить `<html>`, `<head>` или `<body>`, парсер создаст их сам. Но `doctype` сам не появится — без него включится quirks mode.
- Проверить режим документа можно через `document.compatMode`: `"CSS1Compat"` — стандартный, `"BackCompat"` — quirks.
- `lang` на `<html>` — одно из базовых требований доступности (WCAG 3.1.1).
- Элементы, которые парсер встретил после `</body>`, всё равно окажутся внутри `body`.

## Мини-шпаргалка

- `doctype` включает стандартный режим.
- `<html>` — корень документа, `lang` указывать всегда.
- `<head>` — служебная информация, без видимого контента.
- `<body>` — видимый контент с семантической структурой.
- `charset` обычно `UTF-8`.
