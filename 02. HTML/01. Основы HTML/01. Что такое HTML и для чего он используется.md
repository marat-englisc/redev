# Что такое HTML и для чего он используется?

> [!NOTE]
> **HTML** (HyperText Markup Language) - это язык разметки, с помощью которого описывают структуру веб-страницы: заголовки, абзацы, ссылки, изображения, формы, списки, таблицы и смысловые области интерфейса.

## Вопрос

Что такое HTML и для чего он используется? Почему HTML не считается языком программирования?

## Главное

HTML не является языком программирования: в нем нет условий, циклов и вычислений как в JavaScript. Его задача - описать, **что находится на странице** и **какой смысл имеет каждый фрагмент**.

```html
<article>
  <h1>Что такое HTML</h1>
  <p>HTML описывает структуру документа.</p>
  <a href="/learn/html">Перейти к уроку</a>
</article>
```

Браузер читает HTML, строит дерево элементов и на его основе отображает страницу.

## Для чего используется HTML

- Создание структуры веб-страницы.
- Разметка текста: заголовки, абзацы, цитаты, списки.
- Добавление ссылок и навигации.
- Подключение изображений, видео и аудио.
- Создание форм для ввода данных.
- Описание семантики для браузеров, поисковых систем и assistive technologies.

## HTML в связке с CSS и JavaScript

```text
HTML -> структура и смысл
CSS  -> внешний вид
JS   -> поведение и интерактивность
```

Например, HTML создает кнопку, CSS делает ее красивой, а JavaScript реагирует на клик.

```html
<button class="button" type="button">
  Открыть меню
</button>
```

## Почему HTML важен

Хороший HTML делает страницу понятной не только человеку, но и браузеру. От него зависят доступность, SEO, корректная навигация с клавиатуры, работа скринридеров и устойчивость интерфейса.

## Частая ошибка

Писать все через `<div>` и `<span>`, не думая о смысле.

```html
<!-- плохо -->
<div onclick="submitForm()">Отправить</div>

<!-- лучше -->
<button type="submit">Отправить</button>
```

Во втором случае браузер сразу понимает, что это кнопка: она доступна с клавиатуры и имеет правильную семантику.

## Что важно помнить

- Актуальный стандарт — HTML Living Standard от WHATWG: он обновляется постоянно, «HTML6» не будет.
- HTML устойчив к ошибкам: браузер покажет даже невалидную разметку, поэтому ошибки легко не заметить — проверяйте валидатором.
- Хороший HTML работает без CSS и JS: это основа доступности и прогрессивного улучшения.
- В React и Vue вы по-прежнему пишете HTML: JSX и шаблоны превращаются в те же DOM-элементы.

## Мини-шпаргалка

- HTML описывает структуру страницы.
- HTML состоит из элементов и атрибутов.
- HTML не отвечает за стили и сложную логику.
- Семантический HTML помогает доступности и SEO.
- Браузер превращает HTML в DOM-дерево.
