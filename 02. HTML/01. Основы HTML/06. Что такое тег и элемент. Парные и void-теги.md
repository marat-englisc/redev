# Что такое тег и элемент? Парные и void-теги

> [!NOTE]
> **Тег** — синтаксическая конструкция в угловых скобках (`<p>`, `</p>`), из которой браузер создает **элемент**. Элемент состоит из открывающего тега с атрибутами, содержимого и закрывающего тега. **Void-элементы** (`img`, `input`, `br`, `meta`, `link`) не имеют содержимого и закрывающего тега.

## Вопрос

Что такое тег в HTML и чем он отличается от элемента? Из каких частей состоит тег? Что такое парные и непарные (void) теги?

## Тег и элемент

Тег — то, что написано в коде. Элемент — то, что получается в документе после обработки браузером.

```html
<a href="/profile" class="link">Профиль</a>
```

- `<a ...>` — открывающий тег, задает тип элемента;
- `href="/profile"` и `class="link"` — атрибуты;
- `Профиль` — содержимое;
- `</a>` — закрывающий тег;
- весь фрагмент — HTML-элемент.

Имя тега задает базовый смысл: абзац, кнопка, раздел, ссылка. Регистр имени не важен (`<P>` = `<p>`), но принято писать в нижнем регистре.

## Парные теги

Большинство элементов оборачивают содержимое: текст или другие элементы.

```html
<h1>Заголовок</h1>
<p>Абзац текста</p>
<button type="button"><span>Сохранить</span></button>
```

Вложенность формирует дерево элементов. Для некоторых парных тегов закрытие необязательно (`</li>`, `</p>`, `</td>`): парсер закроет их сам, но явно закрывать надежнее.

## Void-элементы

Void-элементы не могут иметь содержимого, поэтому закрывающего тега у них нет:

```html
<img src="/photo.jpg" alt="Фото профиля">
<input type="email" name="email">
<br>
<hr>
<meta charset="UTF-8">
<link rel="stylesheet" href="/styles.css">
```

Полный список: `area`, `base`, `br`, `col`, `embed`, `hr`, `img`, `input`, `link`, `meta`, `source`, `track`, `wbr`.

Внутрь void-элемента нельзя положить текст:

```html
<!-- неправильно -->
<input type="text">Имя</input>

<!-- правильно: подпись через label -->
<label for="name">Имя</label>
<input id="name" type="text" name="name">
```

## XHTML-синтаксис

```html
<img src="/photo.jpg" alt="Портрет" />
```

В HTML слеш в конце void-элемента не обязателен и ни на что не влияет. Он остается по привычке или из-за форматтеров и обязателен в JSX. А вот `<div />` в HTML не самозакрывающийся: браузер проигнорирует слеш и откроет `div`.

## Вложенность

Теги закрываются в обратном порядке:

```html
<!-- правильно -->
<p>Текст <strong>важный</strong></p>

<!-- неправильно -->
<p>Текст <strong>важный</p></strong>
```

Неправильная вложенность приводит к неожиданному DOM.

## Что важно помнить

- В DOM нет «тегов» — там узлы-элементы; `element.tagName` возвращает имя в верхнем регистре (`"DIV"`).
- Самозакрывающихся пользовательских элементов в HTML нет: `<my-widget />` будет открытым тегом.
- `<template>` и `<script>` имеют особые правила парсинга: их содержимое не становится обычными дочерними узлами.
- Валидатор W3C ловит неправильную вложенность и лишние закрывающие теги.

## Мини-шпаргалка

- Тег — синтаксис, элемент — результат в DOM.
- Элемент = открывающий тег + атрибуты + содержимое + закрывающий тег.
- Void-элементы: `img`, `input`, `br`, `hr`, `meta`, `link` и др. — без содержимого.
- Слеш в `<img />` не обязателен, `<div />` не закрывает div.
- Вложенность должна быть корректной.
