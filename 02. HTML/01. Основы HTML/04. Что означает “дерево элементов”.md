# Что означает “дерево элементов”?

> [!NOTE]
> **Дерево элементов** - это иерархическая структура HTML-документа, где элементы вложены друг в друга как родительские и дочерние узлы.

## Вопрос

Что такое дерево элементов? Чем отличаются родитель, ребенок, потомок и соседние элементы?

## Главное

HTML читается не как плоский текст, а как структура вложенных элементов.

```html
<article>
  <h1>Новость</h1>
  <p>Короткое описание новости.</p>
</article>
```

Упрощенное дерево:

```text
article
  h1
    "Новость"
  p
    "Короткое описание новости."
```

## Родитель, ребенок и потомок

```html
<main>
  <section>
    <h2>Популярные товары</h2>
  </section>
</main>
```

- `main` - родитель для `section`.
- `section` - ребенок `main`.
- `h2` - ребенок `section`.
- `h2` - потомок `main`, но не прямой ребенок.

## Почему это важно

Дерево элементов влияет на:

- CSS-селекторы;
- наследование CSS-свойств;
- доступность;
- работу JavaScript с DOM;
- порядок чтения контента скринридером;
- поведение layout.

## Пример с CSS

```css
main h2 {
  font-size: 24px;
}
```

Такой селектор применится к `h2`, который находится внутри `main`, даже если он вложен через `section`.

## Пример с JavaScript

```js
const section = document.querySelector("section");
const heading = section.querySelector("h2");
```

JavaScript может искать элементы внутри конкретной ветки дерева.

## Что важно помнить

- В DOM есть не только элементы, но и текстовые узлы, комментарии и пробелы: `childNodes` включает их, а `children` — только элементы.
- Соседние элементы (siblings) — дети одного родителя; к ним обращаются через `nextElementSibling` и CSS-комбинаторы `+` и `~`.
- Глубокое дерево замедляет рендеринг и пересчет стилей: Lighthouse предупреждает при очень большом DOM (больше ~1400 узлов).
- Accessibility tree строится из DOM, но содержит только значимые для assistive technologies узлы.

## Мини-шпаргалка

- HTML образует дерево вложенных элементов.
- В дереве есть родители, дети и потомки.
- DOM - объектное представление этого дерева в браузере.
- Порядок и вложенность элементов влияют на CSS, JS и доступность.
- Хорошая структура делает страницу предсказуемой.
