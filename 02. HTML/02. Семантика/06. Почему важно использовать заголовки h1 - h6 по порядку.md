# Почему важно использовать заголовки h1 - h6 по порядку?

> [!NOTE]
> Заголовки `h1`-`h6` формируют смысловую структуру страницы. Их порядок помогает пользователям, скринридерам и поисковым системам понимать иерархию контента.

## Вопрос

Почему заголовки `h1`–`h6` нужно использовать по порядку? Сколько `h1` может быть на странице?

## Главное

Заголовки - это не просто размер шрифта. Это оглавление страницы.

```html
<h1>Документация проекта</h1>
<h2>Установка</h2>
<h3>Требования</h3>
<h2>Запуск</h2>
<h3>Переменные окружения</h3>
```

Такой порядок показывает, какие темы главные, а какие вложены внутрь них.

## Почему не стоит перескакивать уровни

```html
<!-- хуже -->
<h1>Каталог</h1>
<h4>Фильтры</h4>
```

После `h1` внезапно идет `h4`. Пользователю скринридера сложнее понять, где `h2` и `h3`, и почему структура перескочила.

Лучше:

```html
<h1>Каталог</h1>
<h2>Фильтры</h2>
```

## H1

Обычно `h1` описывает главную тему страницы.

```html
<main>
  <h1>Курсы по frontend-разработке</h1>
</main>
```

На практике современные HTML-страницы могут иметь разные структуры, но для учебных и рабочих проектов правило "один понятный `h1` на страницу" остается хорошей базой.

## Заголовок не выбирают по размеру

Если нужен маленький визуальный заголовок, не стоит брать `h5` только из-за дефолтного размера. Выбери правильный уровень, а размер задай через CSS.

```html
<h2 class="card-title">Оплата</h2>
```

```css
.card-title {
  font-size: 16px;
}
```

## Польза для навигации

Многие скринридеры позволяют открыть список заголовков и быстро перейти к нужному разделу. Если структура логична, страница становится намного удобнее.

## Что важно помнить

- Алгоритм outline (уровни заголовков внутри `section`) браузеры так и не реализовали — уровень всегда определяется цифрой тега.
- Пропускать уровни вниз не стоит, а возвращаться вверх (после `h3` снова `h2`) нормально.
- Визуально скрытый заголовок (класс `visually-hidden`) помогает структуре, когда дизайн не предусматривает заголовок.
- Проверить структуру заголовков удобно расширениями вроде HeadingsMap или панелью Accessibility в DevTools.

## Мини-шпаргалка

- Заголовки описывают иерархию, а не размер текста.
- `h1` - главная тема страницы.
- После `h1` обычно идут `h2`, потом `h3` и так далее.
- Не перескакивай уровни без причины.
- Стили заголовков настраиваются CSS.
- Логичная структура помогает доступности и SEO.
