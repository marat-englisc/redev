# Почему правильная семантика улучшает навигацию для пользователей с ограничениями?

> [!NOTE]
> Правильная семантика помогает пользователям со скринридерами, клавиатурой и другими assistive technologies быстро понимать структуру страницы и переходить к нужным областям.

## Вопрос

Как семантика помогает пользователям скринридеров и клавиатуры ориентироваться на странице?

## Главное

Не все пользователи воспринимают страницу визуально. Скринридер читает структуру документа и использует семантические элементы как карту страницы.

```html
<header>...</header>
<nav aria-label="Основная навигация">...</nav>
<main>
  <h1>Настройки аккаунта</h1>
</main>
<footer>...</footer>
```

Такой документ можно быстро исследовать по landmarks и заголовкам.

## Landmarks

Семантические области вроде `header`, `nav`, `main`, `aside`, `footer` дают пользователю ориентиры.

```html
<nav aria-label="Навигация по профилю">
  <a href="/profile">Профиль</a>
  <a href="/security">Безопасность</a>
</nav>
```

Если на странице несколько `nav`, `aria-label` помогает различать их.

## Заголовки как оглавление

Скринридеры позволяют переходить по заголовкам.

```html
<h1>Личный кабинет</h1>
<h2>Профиль</h2>
<h2>Заказы</h2>
<h2>Безопасность</h2>
```

Логичная структура заголовков помогает быстро найти нужный раздел.

## Нативные элементы

Нативные интерактивные элементы уже имеют доступное поведение.

```html
<button type="button">Открыть меню</button>
<a href="/settings">Перейти в настройки</a>
```

`button` подходит для действия, `a` - для перехода. Если заменить их на `div`, придется вручную добавлять роль, фокус и обработку клавиатуры.

## Формы

Связка `label` и `input` помогает понять назначение поля.

```html
<label for="email">Email</label>
<input id="email" type="email" name="email">
```

При клике на label фокус переходит в поле, а скринридер озвучивает название поля.

## Что важно помнить

- Skip link «Перейти к основному содержимому» в начале страницы позволяет пропустить меню с клавиатуры.
- Скринридеры показывают отдельные списки заголовков, ссылок, landmarks и полей форм — пользователь прыгает по ним, а не читает всё подряд.
- Ссылки вида «Подробнее» в списке ссылок теряют контекст — делайте текст понятным вне окружения.
- Порядок в DOM должен совпадать с визуальным: `order` во Flexbox и Grid не меняет порядок чтения.

## Мини-шпаргалка

- Семантика создает карту страницы для assistive technologies.
- `main`, `nav`, `header`, `footer` помогают навигации.
- Заголовки работают как оглавление.
- `button` и `a` не стоит заменять на `div`.
- `label` должен быть связан с полем формы.
- `aria-label` полезен, когда одинаковых областей несколько.
