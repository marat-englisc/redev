# В чем разница между main и section?

> [!NOTE]
> `<main>` обозначает главное содержимое страницы, а `<section>` - тематический раздел внутри страницы или другого смыслового блока.

## Вопрос

В чем разница между `main` и `section`? А чем `section` отличается от `article` и `div`?

## Главное

`main` отвечает за уникальный основной контент конкретной страницы. `section` делит контент на логические тематические части.

```html
<main>
  <h1>Личный кабинет</h1>

  <section>
    <h2>Профиль</h2>
    ...
  </section>

  <section>
    <h2>Последние заказы</h2>
    ...
  </section>
</main>
```

## main

`<main>` содержит центральную информацию страницы. Обычно на странице должен быть один видимый `main`.

```html
<main>
  <h1>Каталог товаров</h1>
  <ProductList />
</main>
```

В `main` не включают повторяющиеся части сайта: шапку, меню, подвал, глобальную боковую панель.

## section

`<section>` группирует связанный контент. У хорошей секции обычно есть заголовок.

```html
<section aria-labelledby="delivery-title">
  <h2 id="delivery-title">Доставка</h2>
  <p>Мы доставляем заказы по всей России.</p>
</section>
```

Если блок нужен только для CSS-сетки или отступов, чаще подойдет `div`, а не `section`.

## Сравнение

| Критерий | `main` | `section` |
| --- | --- | --- |
| Роль | Основной контент страницы | Тематический раздел |
| Количество | Обычно один видимый | Может быть много |
| Заголовок | Обычно содержит `h1` | Желательно содержит заголовок |
| Повторяемость | Не для повторяющихся блоков сайта | Можно использовать внутри разных частей |

## Частая ошибка

```html
<!-- плохо: section ради обертки -->
<section class="grid">
  <div>...</div>
  <div>...</div>
</section>
```

Если нет отдельной темы и заголовка, лучше:

```html
<div class="grid">
  <div>...</div>
  <div>...</div>
</div>
```

## Что важно помнить

- `article` — самостоятельный контент, который можно вынести отдельно (пост, карточка товара, комментарий); `section` — часть целого.
- `section` получает ARIA-роль `region` только при наличии доступного имени (`aria-label` или `aria-labelledby`).
- `main` нельзя вкладывать в `article`, `aside`, `header`, `footer` или `nav`.
- Ссылка «Перейти к содержимому» (skip link) обычно ведет к `main`.

## Мини-шпаргалка

- `main` - главное содержимое страницы.
- `section` - тематический раздел.
- `main` обычно один.
- `section` может быть много.
- `section` не стоит использовать только ради CSS.
- У `section` чаще всего должен быть заголовок.
