# Расскажите о семантических тегах для работы с текстом?

> [!NOTE]
> Семантические текстовые теги помогают описывать смысл фрагментов текста: абзацы, заголовки, важность, акцент, цитаты, код, время, сокращения и изменения в документе.

## Вопрос

Какие семантические теги для работы с текстом вы знаете? Чем `strong` отличается от `b`, а `em` от `i`?

## Основные текстовые элементы

| Тег | Смысл |
| --- | --- |
| `<h1>`-`<h6>` | Заголовки разных уровней |
| `<p>` | Абзац текста |
| `<strong>` | Важный фрагмент |
| `<em>` | Смысловой акцент |
| `<blockquote>` | Блочная цитата |
| `<q>` | Короткая inline-цитата |
| `<code>` | Фрагмент кода |
| `<pre>` | Предформатированный текст |
| `<time>` | Дата или время |
| `<abbr>` | Сокращение |

## strong и em

`strong` означает важность, а `em` - акцент в произношении или смысле.

```html
<p>
  <strong>Важно:</strong> перед удалением проекта сделайте резервную копию.
</p>

<p>
  Я сказал <em>сегодня</em>, а не завтра.
</p>
```

Не стоит выбирать их только ради жирного или курсивного стиля. Для внешнего вида есть CSS.

## Цитаты

```html
<blockquote cite="https://example.com/article">
  <p>Хорошая разметка делает контент понятнее.</p>
</blockquote>
```

Для короткой цитаты внутри строки можно использовать `<q>`.

```html
<p>Автор назвал HTML <q>языком структуры</q>.</p>
```

## Код и предформатированный текст

```html
<p>Используйте <code>button</code> для действий.</p>
```

Для многострочного кода часто комбинируют `pre` и `code`.

```html
<pre><code>const message = "Hello";</code></pre>
```

## Даты и сокращения

```html
<time datetime="2026-08-03">3 августа 2026</time>
```

```html
<abbr title="HyperText Markup Language">HTML</abbr>
```

Эти элементы добавляют машинно-читаемый смысл.

## Что важно помнить

- `b` и `i` не устарели: `b` — привлечь внимание без важности (ключевое слово), `i` — альтернативный голос (термин, иностранное слово).
- `<mark>` выделяет релевантный фрагмент, например совпадение при поиске.
- `<del>` и `<ins>` показывают изменения в документе, `<s>` — неактуальную информацию (старая цена).
- `<br>` — только для переносов, которые являются частью содержимого (стихи, адрес), а не для отступов.

## Мини-шпаргалка

- `p` - абзац, не контейнер для всего подряд.
- `strong` - важность.
- `em` - смысловой акцент.
- `blockquote` и `q` - цитаты.
- `code` - фрагмент кода.
- `time` помогает описывать даты машинно-читаемо.
- Теги выбирают по смыслу, а стили задают CSS.
