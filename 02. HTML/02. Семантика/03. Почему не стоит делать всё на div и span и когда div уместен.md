# Почему не стоит делать всё на div и span и когда div уместен?

> [!NOTE]
> `div` — нейтральный блочный контейнер, `span` — нейтральный строчный. У них нет собственного смысла, поэтому их называют универсальными контейнерами. Они нужны для группировки и стилизации, но если строить на них всю страницу, она становится непонятной для браузера, скринридеров, поисковых систем и разработчиков.

## Вопрос

Для чего используется `div` и почему его называют универсальным контейнером? Почему не рекомендуется использовать `div` и `span` для всего контента?

## Что теряется при div-верстке

```html
<!-- плохо -->
<div class="title">Контакты</div>
<div class="button" onclick="save()">Отправить</div>

<!-- лучше -->
<h1>Контакты</h1>
<button type="submit">Отправить</button>
```

- нативное поведение элементов;
- клавиатурная доступность;
- понятная структура документа;
- навигация по landmarks и заголовкам;
- читаемость кода;
- контекст для SEO.

`div` с `onclick` не является кнопкой для браузера. Чтобы приблизить его к кнопке, нужно вручную добавить `role="button"`, `tabindex="0"`, обработку Enter и Space, состояние `disabled`. `<button>` дает всё это бесплатно.

## Когда div уместен

`div` называют универсальным, потому что он ничего не означает и может оборачивать любые части интерфейса. Он подходит, когда:

- нужно сгруппировать элементы для Flexbox или Grid;
- нужна техническая или декоративная обертка;
- компоненту нужна внутренняя layout-структура;
- нет подходящего семантического элемента.

```html
<div class="layout">
  <aside>Фильтры</aside>
  <main>Каталог</main>
</div>
```

`span` — то же самое для небольшого фрагмента внутри строки:

```html
<div class="card">
  <p>Цена: <span class="price">1990 ₽</span></p>
</div>
```

## div или section

Если блок — тематический раздел с заголовком, подходит `section`:

```html
<section aria-labelledby="faq-title">
  <h2 id="faq-title">Вопросы и ответы</h2>
  ...
</section>
```

Если блок нужен только для сетки или отступов — `div`.

## Как выбирать

- Это действие? `button`.
- Это переход? `a href`.
- Это заголовок? `h1`–`h6`.
- Это навигация? `nav`.
- Это самостоятельная карточка или статья? `article`.
- Ничего из этого, просто обертка? `div` / `span`.

## Что важно помнить

- «Div soup» часто появляется из-за компонентов: каждая обертка компонента добавляет `div`. Используйте Fragment (`<>...</>`), если обертка не нужна.
- Лишние обертки ломают Flexbox и Grid, потому что меняют прямых детей контейнера. Иногда помогает `display: contents`, но он может удалить роль элемента из accessibility tree в старых браузерах.
- `div` внутри `button` или `a` допустим только с phrasing-контентом; вложенные интерактивные элементы запрещены.
- На собеседовании хороший ответ: «div — для layout, но сначала ищу элемент со смыслом».

## Мини-шпаргалка

- `div` и `span` семантически нейтральны.
- Не заменяй ими `button`, `a`, `h1`, `nav`, `main`, `form`.
- `div` — для layout и стилизации, `span` — для фрагмента текста.
- Тематический блок с заголовком — `section`.
- Сначала тег по смыслу, потом CSS.
