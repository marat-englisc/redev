# Что делает select?

> [!NOTE]
> `<select>` создает выпадающий список или список выбора. Внутри него находятся элементы `<option>`, а выбранное значение отправляется вместе с формой.

## Вопрос

Что делает элемент `select`? Как задать вариант по умолчанию и множественный выбор?

## Главное

```html
<label for="city">Город</label>
<select id="city" name="city">
  <option value="">Выберите город</option>
  <option value="moscow">Москва</option>
  <option value="spb">Санкт-Петербург</option>
</select>
```

Если пользователь выберет Москву, форма отправит `city=moscow`.

## Option

`option` описывает один вариант выбора.

```html
<option value="card">Банковская карта</option>
```

Текст внутри `option` видит пользователь, а `value` отправляется как значение.

## selected

```html
<option value="card" selected>Банковская карта</option>
```

`selected` выбирает вариант по умолчанию.

## Multiple

```html
<label for="skills">Навыки</label>
<select id="skills" name="skills" multiple>
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js">JavaScript</option>
</select>
```

`multiple` позволяет выбрать несколько вариантов, но такой интерфейс не всегда удобен. Часто вместо него делают чекбоксы.

## Optgroup

```html
<select name="transport">
  <optgroup label="Наземный транспорт">
    <option value="bus">Автобус</option>
    <option value="tram">Трамвай</option>
  </optgroup>
  <optgroup label="Воздушный транспорт">
    <option value="plane">Самолет</option>
  </optgroup>
</select>
```

`optgroup` группирует варианты внутри списка.

## Что важно помнить

- Плейсхолдер-вариант делают через `<option value="" disabled selected>`, а с `required` пустое значение не пройдет валидацию.
- Нативный `select` плохо стилизуется; новый `appearance: base-select` постепенно решает это, а кастомный dropdown требует ARIA-паттерна listbox/combobox.
- Если у `option` нет `value`, отправится его текст.
- Для выбора из длинного списка с вводом используйте `<input list>` с `<datalist>` или combobox.

## Мини-шпаргалка

- `select` создает список выбора.
- `option` задает вариант.
- `name` нужен для отправки формы.
- `value` - отправляемое значение.
- `selected` выбирает вариант по умолчанию.
- `multiple` разрешает несколько вариантов.
- `optgroup` группирует варианты.
