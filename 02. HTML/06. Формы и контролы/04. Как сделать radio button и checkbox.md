# Как сделать radio button и checkbox в HTML?

> [!NOTE]
> Radio button создают через `<input type="radio">`, checkbox — через `<input type="checkbox">`. Радиокнопки с одинаковым `name` образуют группу, где можно выбрать только один вариант. Чекбоксы независимы: подходят для согласия, переключения настройки и множественного выбора.

## Вопрос

Как сделать простой radio button и checkbox? Чем они отличаются и когда использовать каждый?

## Radio button

```html
<fieldset>
  <legend>Способ доставки</legend>

  <label>
    <input type="radio" name="delivery" value="pickup" checked>
    Самовывоз
  </label>

  <label>
    <input type="radio" name="delivery" value="courier">
    Курьер
  </label>
</fieldset>
```

- одинаковый `name="delivery"` объединяет варианты в группу — выбрать можно только один;
- `value` — значение, которое уйдет с формой: `delivery=courier`;
- `checked` выбирает вариант по умолчанию.

Если не указать `value`, отправится `delivery=on` — значение бесполезно, поэтому `value` у radio обязателен.

## Checkbox

```html
<label>
  <input type="checkbox" name="agreement" value="yes" required>
  Я согласен с условиями
</label>
```

Отмеченный чекбокс отправит `agreement=yes`. **Неотмеченный чекбокс не отправляется вовсе** — сервер должен трактовать отсутствие поля как `false`.

Несколько чекбоксов с одним `name` дают множественный выбор:

```html
<fieldset>
  <legend>Навыки</legend>
  <label><input type="checkbox" name="skills" value="html"> HTML</label>
  <label><input type="checkbox" name="skills" value="css"> CSS</label>
  <label><input type="checkbox" name="skills" value="js"> JavaScript</label>
</fieldset>
```

Отправится `skills=html&skills=js`. В JavaScript значения читают через `formData.getAll("skills")`.

## Checkbox или radio

| Ситуация | Элемент |
| --- | --- |
| Только один вариант из группы | radio |
| Несколько вариантов | checkbox |
| Включить / выключить одну настройку | checkbox (или switch на его основе) |
| Согласие с условиями | checkbox |

## Fieldset и legend

Для группы radio или checkbox одного `label` недостаточно: скринридер должен знать вопрос, к которому относятся варианты. `<fieldset>` группирует поля, `<legend>` дает группе название — оно озвучивается при входе в группу.

## Состояние indeterminate

У чекбокса есть третье визуальное состояние — «частично выбран», например «выбрать все», когда отмечена часть пунктов. Его задают только из JavaScript:

```js
selectAll.indeterminate = true;
```

## Что важно помнить

- Обертка `<label>` вокруг input или связь `for` + `id` увеличивает область клика — это важно на мобильных.
- Внутри группы radio стрелки клавиатуры переключают выбор, а Tab переходит к следующей группе.
- Кастомные стили делают через `appearance: none` или скрытие нативного input визуально (не через `display: none`), чтобы сохранить фокус и доступность.
- В React чекбокс управляют через `checked` + `onChange`, а не `value`.
- `required` на одной радиокнопке делает обязательной всю группу.

## Мини-шпаргалка

- Radio: `type="radio"`, одинаковый `name`, обязательный `value`, один выбор.
- Checkbox: `type="checkbox"`, независимый выбор, неотмеченный не отправляется.
- `checked` — значение по умолчанию.
- Группы — в `fieldset` + `legend`.
- Несколько чекбоксов с одним `name` → `getAll`.
