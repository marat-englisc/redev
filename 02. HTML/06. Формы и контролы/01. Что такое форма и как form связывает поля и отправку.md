# Что такое форма в HTML и как она связывает поля и отправку данных?

> [!NOTE]
> **HTML-форма** собирает пользовательский ввод и отправляет его на сервер или передает JavaScript-логике. Элемент `<form>` объединяет поля, задает адрес (`action`) и способ отправки (`method`), а при submit браузер собирает значения полей по их `name`.

## Вопрос

Что такое форма в HTML и зачем она нужна? Как элемент `form` связывает поля ввода и отправку данных?

## Основная идея

Формы используют для логина, регистрации, поиска, фильтров, оплаты, комментариев и загрузки файлов.

```html
<form action="/login" method="post">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>

  <label for="password">Пароль</label>
  <input id="password" name="password" type="password" required>

  <button type="submit">Войти</button>
</form>
```

Что входит в форму:

- `<form>` — контейнер и правила отправки;
- `<label>` — подпись поля;
- `<input>`, `<textarea>`, `<select>` — поля ввода;
- `<fieldset>` и `<legend>` — группа полей с названием;
- `<button>` — отправка или другое действие.

## Роль name

`name` — ключ, под которым значение попадет в данные формы. Поле без `name` при стандартной отправке не отправляется, даже если у него есть `id`.

```html
<input name="email" type="email">
```

## action и method

| Атрибут | Что задает | По умолчанию |
| --- | --- | --- |
| `action` | адрес отправки | текущий URL |
| `method` | HTTP-метод: `get` или `post` | `get` |
| `enctype` | формат тела для `post` | `application/x-www-form-urlencoded` |

**GET** добавляет данные в URL: `/search?q=html`. Подходит для поиска и фильтров — такой страницей можно поделиться ссылкой.

**POST** отправляет данные в теле запроса. Подходит для логина, регистрации, заказов и операций, которые меняют состояние. Для файлов нужен `enctype="multipart/form-data"`.

## Форма без JavaScript

Браузер сам соберет значения и отправит запрос. Это основа прогрессивного улучшения: JavaScript делает форму удобнее, но базовый HTML уже работает. Форма также отправляется по Enter в текстовом поле.

## Форма с JavaScript

```js
const form = document.querySelector("form");

form.addEventListener("submit", async (event) => {
  event.preventDefault();
  const data = new FormData(form);

  await fetch("/api/login", { method: "POST", body: data });
});
```

`FormData` собирает значения полей так же, как браузер. Обработчик ставят на `submit` формы, а не на `click` кнопки: так работают и Enter, и встроенная валидация.

## Поля вне form

Поле можно связать с формой через атрибут `form`:

```html
<form id="profile-form"></form>

<input form="profile-form" name="firstName">
```

Это полезно для сложных layout, например кнопки отправки в шапке модального окна.

## Что важно помнить

- У `<button>` внутри формы по умолчанию `type="submit"`. Кнопки, которые не должны отправлять форму, явно помечают `type="button"`.
- `disabled`-поля не отправляются, а `readonly` — отправляются.
- Встроенная валидация (`required`, `type="email"`, `pattern`) срабатывает перед событием `submit`; `novalidate` на форме ее отключает.
- Вложенные формы запрещены: внутренний `<form>` парсер просто проигнорирует.
- `form.reset()` возвращает начальные значения, а `form.requestSubmit()` отправляет форму с валидацией и событием `submit`, в отличие от `form.submit()`.

## Мини-шпаргалка

- Форма собирает ввод; `<form>` связывает поля и отправку.
- `action` — куда, `method` — как, `name` — ключ данных.
- GET — данные в URL, POST — в теле.
- JS перехватывает `submit` и читает данные через `FormData`.
- `label` обязателен для доступности.
