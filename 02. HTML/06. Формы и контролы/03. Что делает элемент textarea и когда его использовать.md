# Что делает элемент textarea и когда его использовать?

> [!NOTE]
> `<textarea>` создает многострочное текстовое поле. Его используют для комментариев, сообщений, описаний, заметок и любого текста, который может занимать несколько строк.

## Вопрос

Что делает элемент `textarea` и чем он отличается от `input`?

## Главное

```html
<label for="message">Сообщение</label>
<textarea id="message" name="message" rows="5"></textarea>
```

В отличие от `input`, `textarea` имеет открывающий и закрывающий тег.

## Когда использовать textarea

- Комментарий.
- Сообщение в форму обратной связи.
- Описание товара.
- Биография профиля.
- Заметка.
- Причина отмены или обращения.

## Атрибуты

```html
<textarea
  id="comment"
  name="comment"
  rows="6"
  maxlength="500"
  placeholder="Опишите проблему"
  required
></textarea>
```

Частые атрибуты:

- `name` - ключ при отправке формы;
- `rows` - примерная высота в строках;
- `maxlength` - ограничение длины;
- `placeholder` - подсказка;
- `required` - обязательное поле;
- `readonly` - только чтение;
- `disabled` - отключение поля.

## Начальное значение

У `textarea` начальное значение пишется между тегами.

```html
<textarea name="bio">Frontend developer</textarea>
```

Для `input` начальное значение задают через `value`, а для `textarea` - через содержимое.

## Что важно помнить

- Пробелы и переносы внутри `<textarea>...</textarea>` становятся частью значения — не форматируйте содержимое отступами.
- Изменение размера пользователем управляется CSS `resize: vertical | none`.
- Автоматическая высота под содержимое теперь делается CSS-свойством `field-sizing: content` (в поддерживающих браузерах).
- В React у `textarea` используют `value` и `defaultValue`, а не дочерний текст.

## Мини-шпаргалка

- `textarea` - многострочное поле.
- Используется для длинного текста.
- Имеет открывающий и закрывающий тег.
- Начальное значение пишется между тегами.
- `rows` задает видимую высоту.
- `label` нужен так же, как и для `input`.
