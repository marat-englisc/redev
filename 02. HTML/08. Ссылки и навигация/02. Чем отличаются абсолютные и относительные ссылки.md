# Чем отличаются абсолютные и относительные ссылки?

> [!NOTE]
> Абсолютная ссылка содержит полный адрес ресурса, включая протокол и домен. Относительная ссылка указывает путь относительно текущего документа или корня сайта.

## Вопрос

Чем отличаются абсолютные и относительные ссылки? Как разрешается относительный путь?

## Абсолютная ссылка

```html
<a href="https://example.com/blog/html">Статья про HTML</a>
```

В ней явно указаны:

- протокол `https`;
- домен `example.com`;
- путь `/blog/html`.

Абсолютные ссылки часто используют для внешних ресурсов.

## Относительная ссылка

```html
<a href="/blog/html">Статья про HTML</a>
```

Такая ссылка ведет на страницу внутри текущего сайта.

## Виды относительных путей

| Пример | Что означает |
| --- | --- |
| `/catalog` | От корня сайта |
| `about.html` | Файл рядом с текущим документом |
| `../images/logo.svg` | Подняться на уровень выше |
| `#faq` | Фрагмент текущей страницы |

## Пример

Если текущая страница:

```text
https://site.ru/docs/html/index.html
```

то ссылка:

```html
<a href="../css/">CSS</a>
```

может вести к:

```text
https://site.ru/docs/css/
```

## Когда что использовать

- Для внешних сайтов: абсолютные URL.
- Для внутренних страниц: обычно относительные от корня.
- Для переходов по странице: `#fragment`.
- Для CDN-ресурсов: абсолютные URL.

## Что важно помнить

- Protocol-relative URL (`//cdn.example.com/a.js`) устарел — используйте явный `https://`.
- Относительный путь без `/` зависит от текущего URL: `about` на странице `/docs/` и `/docs` ведет в разные места.
- Элемент `<base href>` меняет базу всех относительных ссылок страницы, включая якоря.
- В JavaScript разрешить путь можно через `new URL('../css/', location.href)`.

## Мини-шпаргалка

- Абсолютный URL содержит протокол и домен.
- Относительный URL зависит от текущего расположения.
- `/path` считается от корня сайта.
- `../` поднимает путь на уровень выше.
- Якорь `#id` ведет к элементу на странице.
