# Что такое фрагмент(якорь) в ссылке?

> [!NOTE]
> Фрагмент, или якорь, - это часть URL после символа `#`, которая указывает браузеру на конкретный элемент страницы с соответствующим `id`.

## Вопрос

Что такое фрагмент (якорь) в URL и как он работает?

## Главное

```html
<a href="#contacts">Перейти к контактам</a>

<section id="contacts">
  <h2>Контакты</h2>
</section>
```

При клике браузер прокрутит страницу к элементу `id="contacts"`.

## Как выглядит URL

```text
https://example.com/about#contacts
```

Здесь:

- `https://example.com/about` - адрес страницы;
- `#contacts` - фрагмент;
- `contacts` - идентификатор элемента.

## Якорь на текущей странице

```html
<a href="#faq">Вопросы и ответы</a>
```

Такой переход не загружает новую страницу, а перемещает пользователя внутри текущей.

## Якорь на другой странице

```html
<a href="/docs/html#forms">Раздел про формы</a>
```

Браузер откроет страницу `/docs/html` и попробует прокрутить ее к элементу `id="forms"`.

## CSS для фиксированной шапки

Если сверху есть fixed-header, якорный переход может скрыть заголовок. Помогает `scroll-margin-top`.

```css
section {
  scroll-margin-top: 80px;
}
```

## Что важно помнить

- Фрагмент не отправляется на сервер, поэтому серверный роутинг его не видит.
- Смена hash вызывает событие `hashchange` и на этом построены hash-роутеры (`HashRouter`).
- Text fragments (`#:~:text=фраза`) позволяют сослаться на конкретный текст на странице без `id`.
- Псевдокласс `:target` стилизует элемент, на который ведет текущий фрагмент.
- Плавную прокрутку к якорю включает `scroll-behavior: smooth` (с учетом `prefers-reduced-motion`).

## Мини-шпаргалка

- Фрагмент URL начинается с `#`.
- Он связан с `id` элемента.
- `href="#top"` ведет к элементу `id="top"`.
- Якорь может вести внутри текущей или другой страницы.
- Для fixed-header полезен `scroll-margin-top`.
