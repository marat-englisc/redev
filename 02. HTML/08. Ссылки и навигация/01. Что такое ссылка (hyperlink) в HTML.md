# Что такое ссылка (hyperlink) в HTML?

> [!NOTE]
> **Ссылка** в HTML создается тегом `<a>` и позволяет перейти на другую страницу, раздел текущей страницы, файл, email-адрес, телефон или другой URL.

## Вопрос

Что такое ссылка в HTML? Какие бывают ссылки и когда использовать ссылку, а когда кнопку?

## Главное

```html
<a href="/about">О компании</a>
```

`href` указывает адрес перехода, а текст внутри ссылки объясняет пользователю, куда она ведет.

## Виды ссылок

```html
<a href="https://example.com">Внешний сайт</a>
<a href="/catalog">Страница внутри сайта</a>
<a href="#contacts">Раздел на этой странице</a>
<a href="mailto:hello@example.com">Написать письмо</a>
<a href="tel:+79990000000">Позвонить</a>
```

## Хороший текст ссылки

Текст должен быть понятен вне контекста.

```html
<!-- хуже -->
<a href="/delivery">Подробнее</a>

<!-- лучше -->
<a href="/delivery">Условия доставки</a>
```

Это важно для доступности, SEO и удобства сканирования страницы.

## target="_blank"

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Открыть внешний сайт
</a>
```

Если ссылка открывается в новой вкладке, обычно добавляют `rel="noopener noreferrer"` для безопасности и производительности.

## Ссылка или кнопка

```text
Переход на другой URL -> a
Действие на текущей странице -> button
```

```html
<a href="/profile">Перейти в профиль</a>
<button type="button">Открыть модальное окно</button>
```

## Что важно помнить

- `<a>` без `href` не является ссылкой: он не фокусируется и не имеет роли `link`.
- `href="#"` или `href="javascript:void(0)"` для действий — антипаттерн, для действий нужна кнопка.
- Атрибут `download` предлагает скачать файл, а `rel="nofollow"`, `sponsored`, `ugc` сообщают поисковикам тип ссылки.
- Современные браузеры по умолчанию применяют `noopener` для `target="_blank"`, но явный `rel` не повредит.
- Ссылка, открывающая новую вкладку, должна предупреждать об этом (иконкой или скрытым текстом).

## Мини-шпаргалка

- Ссылку создает тег `<a>`.
- Адрес задается через `href`.
- Текст ссылки должен быть конкретным.
- Для новой вкладки используют `target="_blank"` и `rel`.
- `a` - переход, `button` - действие.
- Якорные ссылки ведут к элементу с нужным `id`.
