# Какие основные категории тегов существуют в HTML5?

> [!NOTE]
> В HTML5 элементы можно группировать по назначению: метаданные, секционная разметка, текстовый контент, inline-семантика, изображения и медиа, формы, интерактивные элементы, таблицы и скрипты.

## Вопрос

Какие категории контента существуют в HTML и зачем они нужны?

## Зачем нужны категории

Категории помогают понимать, какую роль элемент играет в документе и где его можно использовать.

```text
head metadata -> служебная информация
sectioning    -> структура страницы
phrasing      -> текстовые фрагменты
forms         -> ввод данных
embedded      -> изображения и медиа
```

## Основные категории

| Категория | Примеры | Назначение |
| --- | --- | --- |
| Metadata content | `title`, `meta`, `link`, `style`, `script` | Информация о документе и подключение ресурсов |
| Sectioning content | `section`, `article`, `nav`, `aside` | Смысловые разделы документа |
| Flow content | `div`, `p`, `main`, `ul`, `form` | Основной поток содержимого страницы |
| Phrasing content | `span`, `a`, `strong`, `em`, `img`, `input` | Текст и inline-фрагменты |
| Embedded content | `img`, `video`, `audio`, `iframe`, `canvas` | Встроенные ресурсы |
| Interactive content | `a`, `button`, `details`, `input`, `select` | Элементы взаимодействия |
| Form-associated | `input`, `textarea`, `select`, `button`, `label` | Работа с формами |
| Tabular data | `table`, `thead`, `tbody`, `tr`, `th`, `td` | Табличные данные |

## Один элемент может быть в нескольких категориях

Например, `<a>` может быть phrasing content и interactive content.

```html
<a href="/docs">Документация</a>
```

`img` может быть embedded content и phrasing content.

```html
<p>
  Автор: <img src="/avatar.jpg" alt="Анна">
</p>
```

## Практический смысл

Категории влияют на допустимую вложенность. Например, нельзя класть блочный layout куда угодно только потому, что браузер "как-то отрисует".

```html
<!-- сомнительная структура -->
<p>
  Текст
  <section>Раздел</section>
</p>
```

Лучше разделять абзацы и секции явно.

## Что важно помнить

- Content model определяет, что можно вкладывать: в `p` допустим только phrasing content, поэтому `<p><div></div></p>` разорвет абзац.
- `<a>` прозрачен (transparent content model): его допустимое содержимое зависит от родителя, поэтому ссылка может оборачивать блок.
- Интерактивные элементы нельзя вкладывать друг в друга: `button` внутри `a` или `a` внутри `button` — ошибка.
- В MDN у каждого элемента есть раздел «Категории контента» и «Допустимое содержимое».

## Мини-шпаргалка

- Metadata-элементы обычно живут в `head`.
- Sectioning-элементы формируют структуру страницы.
- Phrasing-элементы работают внутри текста.
- Embedded-элементы подключают внешнее содержимое.
- Interactive-элементы участвуют во взаимодействии.
- Категории помогают не ломать вложенность.
