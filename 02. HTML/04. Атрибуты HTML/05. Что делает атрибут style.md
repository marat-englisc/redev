# Что делает атрибут style?

> [!NOTE]
> Атрибут `style` позволяет записать CSS-правила прямо на HTML-элементе. Такие стили называются inline-стилями и имеют высокий приоритет в каскаде.

## Вопрос

Что делает атрибут `style`? Когда inline-стили оправданы, а когда вредны?

## Главное

```html
<p style="color: red; font-weight: 700;">
  Важное сообщение
</p>
```

Браузер применит эти CSS-свойства прямо к конкретному элементу.

## Когда style бывает полезен

- Быстрый эксперимент.
- Динамические значения из JavaScript.
- Уникальное значение, которое не нужно переиспользовать.
- Email-шаблоны, где inline-стили часто необходимы.

```html
<div style="--progress: 65%;">
  ...
</div>
```

Иногда inline-style используют для CSS-переменных, а основную стилизацию оставляют в CSS.

## Почему не стоит злоупотреблять

Inline-стили:

- смешивают структуру и оформление;
- плохо переиспользуются;
- усложняют поддержку;
- имеют высокий приоритет;
- не позволяют удобно описывать `:hover`, media queries и сложные состояния.

```html
<!-- хуже -->
<button style="background: blue; color: white; padding: 8px;">
  Сохранить
</button>
```

```html
<!-- лучше -->
<button class="button button--primary">
  Сохранить
</button>
```

## Style и безопасность

Если значение `style` приходит от пользователя, его нельзя просто вставлять в HTML. Это может привести к проблемам безопасности и поломанной верстке.

## Что важно помнить

- Inline-стиль перебивает любые селекторы, кроме правил с `!important`.
- Строгая CSP без `'unsafe-inline'` блокирует атрибут `style` — еще одна причина держать стили в CSS.
- Из JavaScript inline-стили меняют через `element.style.color` или `style.setProperty('--progress', '65%')`.
- В React `style` — объект с camelCase-свойствами: `style={{ backgroundColor: 'red' }}`.

## Мини-шпаргалка

- `style` задает inline-CSS.
- Inline-стили имеют высокий приоритет.
- Для системных стилей лучше использовать `class`.
- `style` подходит для динамических единичных значений.
- Не вставляй пользовательский ввод в `style` без контроля.
