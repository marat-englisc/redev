# Для чего используется атрибут id?

> [!NOTE]
> Атрибут `id` задает уникальный идентификатор элемента в пределах HTML-документа. Его используют для якорных ссылок, связи `label` с полем, JavaScript-доступа и ARIA-связей.

## Вопрос

Для чего используется атрибут `id`? Почему его не рекомендуют использовать для стилизации?

## Главное

`id` должен быть уникальным на странице.

```html
<section id="contacts">
  <h2>Контакты</h2>
</section>
```

Если два элемента имеют одинаковый `id`, поведение ссылок, CSS, JavaScript и accessibility-связей может стать непредсказуемым.

## Якорные ссылки

```html
<a href="#contacts">Перейти к контактам</a>

<section id="contacts">
  <h2>Контакты</h2>
</section>
```

При клике браузер прокрутит страницу к элементу с `id="contacts"`.

## Связь label и input

```html
<label for="email">Email</label>
<input id="email" name="email" type="email">
```

`for` указывает на `id` поля. Благодаря этому клик по label переводит фокус в input, а скринридер озвучивает название поля.

## JavaScript

```js
const app = document.getElementById("app");
```

В SPA часто есть корневой контейнер:

```html
<div id="app"></div>
```

## CSS

```css
#contacts {
  scroll-margin-top: 80px;
}
```

Для стилизации обычно лучше использовать `class`, потому что `id` имеет высокую специфичность и хуже переиспользуется.

## Что важно помнить

- Элементы с `id` становятся глобальными переменными `window` — это источник неожиданных конфликтов, не полагайтесь на это.
- В компонентах одинаковый `id` легко задублировать при повторном рендере; в React для связки label и input используют `useId()`.
- `id`, начинающийся с цифры, валиден в HTML, но в CSS-селекторе его нужно экранировать: `#\31 23`.
- Связи ARIA (`aria-labelledby`, `aria-describedby`, `aria-controls`) работают только через `id`.

## Мини-шпаргалка

- `id` уникален в документе.
- Используется для якорей, `label`, ARIA и JS.
- Для повторяемых стилей чаще лучше `class`.
- Дублировать `id` нельзя.
- `id` чувствителен к точному совпадению строки.
