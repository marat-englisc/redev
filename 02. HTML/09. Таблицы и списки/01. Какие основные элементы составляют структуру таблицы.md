# Какие основные элементы составляют структуру таблицы?

> [!NOTE]
> HTML-таблица строится из `<table>`, строк `<tr>`, ячеек заголовков `<th>` и ячеек данных `<td>`. Для структуры также используют `<caption>`, `<thead>`, `<tbody>` и `<tfoot>`.

## Вопрос

Из каких элементов состоит HTML-таблица и как сделать ее доступной?

## Базовый пример

```html
<table>
  <caption>Продажи по кварталам</caption>
  <thead>
    <tr>
      <th scope="col">Квартал</th>
      <th scope="col">Выручка</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Q1</th>
      <td>1 200 000 ₽</td>
    </tr>
    <tr>
      <th scope="row">Q2</th>
      <td>1 450 000 ₽</td>
    </tr>
  </tbody>
</table>
```

## Основные элементы

| Элемент | Назначение |
| --- | --- |
| `<table>` | Контейнер таблицы |
| `<caption>` | Название или описание таблицы |
| `<thead>` | Группа строк заголовка |
| `<tbody>` | Основные данные |
| `<tfoot>` | Итоги или сводная строка |
| `<tr>` | Строка таблицы |
| `<th>` | Заголовочная ячейка |
| `<td>` | Ячейка данных |

## scope

Атрибут `scope` помогает связать заголовки с данными.

```html
<th scope="col">Цена</th>
<th scope="row">Тариф Pro</th>
```

Это особенно важно для скринридеров.

## Когда использовать таблицу

Таблица нужна для табличных данных: когда есть строки, столбцы и связь между ними.

```text
price list -> table
calendar   -> table or grid
layout     -> not table
```

Для раскладки страницы таблицы использовать не стоит.

## Что важно помнить

- Если не написать `tbody`, браузер добавит его сам — это важно для CSS-селекторов вида `table > tr`.
- `<colgroup>` и `<col>` позволяют задать ширину и фон целым столбцам.
- Широкие таблицы на мобильных оборачивают в контейнер с `overflow-x: auto` и `tabindex="0"`, чтобы их можно было прокрутить с клавиатуры.
- `display: flex` или `grid` на элементах таблицы может сломать ее семантику в некоторых браузерах.

## Мини-шпаргалка

- `table` используют для табличных данных.
- `tr` - строка.
- `th` - заголовочная ячейка.
- `td` - ячейка данных.
- `caption` дает название таблицы.
- `scope` улучшает доступность.
- Таблицы не используют для layout.
