# Что делают атрибуты colspan и rowspan?

> [!NOTE]
> `colspan` объединяет ячейку таблицы по горизонтали — она занимает несколько столбцов. `rowspan` объединяет по вертикали — ячейка занимает несколько строк. Оба атрибута работают на `td` и `th`.

## Вопрос

Что делают атрибуты `colspan` и `rowspan`? Как не сломать структуру таблицы при объединении ячеек?

## colspan

```html
<table>
  <tr>
    <th>Товар</th>
    <th>Количество</th>
    <th>Цена</th>
  </tr>
  <tr>
    <td>Книга</td>
    <td>2</td>
    <td>1200 ₽</td>
  </tr>
  <tr>
    <td colspan="2">Итого</td>
    <td>1200 ₽</td>
  </tr>
</table>
```

`colspan="2"`: ячейка «Итого» занимает два столбца, поэтому в строке всего две ячейки вместо трех. Типичные случаи — заголовки групп столбцов и строки итогов.

## rowspan

```html
<table>
  <tr>
    <th>Город</th>
    <th>Офис</th>
  </tr>
  <tr>
    <td rowspan="2">Москва</td>
    <td>Центральный</td>
  </tr>
  <tr>
    <td>Северный</td>
  </tr>
</table>
```

`rowspan="2"`: ячейка «Москва» занимает две строки. Во второй строке ячейку для первого столбца **не пишут** — место уже занято.

## Как считать ячейки

```text
colspan -> объединение по горизонтали (столбцы)
rowspan -> объединение по вертикали (строки)
```

Сумма `colspan` в каждой строке плюс ячейки, «пришедшие» сверху через `rowspan`, должна совпадать с количеством столбцов. Иначе таблица «поедет»: появятся лишние или пустые ячейки.

## Сложные заголовки

```html
<table>
  <thead>
    <tr>
      <th rowspan="2" scope="col">Сотрудник</th>
      <th colspan="2" scope="colgroup">2026</th>
    </tr>
    <tr>
      <th scope="col">Q1</th>
      <th scope="col">Q2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Анна</th>
      <td>12</td>
      <td>15</td>
    </tr>
  </tbody>
</table>
```

Для заголовка над группой столбцов используют `scope="colgroup"`, над группой строк — `scope="rowgroup"`. В очень сложных таблицах связь ячейки с заголовками задают явно: `<td headers="id1 id2">`.

## Что важно помнить

- `colspan="0"` не означает «до конца строки»: значение 0 недопустимо и трактуется как 1. А `rowspan="0"` растягивает ячейку до конца группы строк (`tbody`).
- Объединенные ячейки усложняют чтение скринридером — проверяйте таблицу с ним или упрощайте структуру.
- Объединение ячеек нельзя использовать для раскладки страницы: таблицы — только для табличных данных.
- В CSS Grid аналог — `grid-column: span 2` и `grid-row: span 2`.

## Мини-шпаргалка

- `colspan` — по горизонтали, `rowspan` — по вертикали.
- Значение — сколько столбцов или строк занимает ячейка.
- Работают на `td` и `th`.
- Под `rowspan`-ячейкой в следующих строках ячейку не пишут.
- Сложные объединения — проверять на доступность.
