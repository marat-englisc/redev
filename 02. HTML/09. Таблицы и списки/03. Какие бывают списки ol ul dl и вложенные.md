# Какие бывают списки в HTML: ol, ul, dl и вложенные

> [!NOTE]
> В HTML три вида списков. `<ol>` — нумерованный, когда важен порядок: шаги, рейтинг. `<ul>` — маркированный, когда порядок не важен: меню, характеристики. `<dl>` — список определений из пар «термин — описание». Пункты `ol` и `ul` создаются через `<li>`, а вложенный список помещают внутрь `<li>`.

## Вопрос

Что такое нумерованный, маркированный и definition список? Как правильно сделать вложенный список?

## Нумерованный список: ol

```html
<ol>
  <li>Открыть терминал</li>
  <li>Установить зависимости</li>
  <li>Запустить проект</li>
</ol>
```

`ol` (ordered list) используют, когда порядок имеет смысл: инструкция, рецепт, рейтинг, этапы процесса.

| Атрибут | Что делает |
| --- | --- |
| `start="4"` | начать нумерацию с 4 |
| `reversed` | обратный порядок |
| `type="a"` / `"A"` / `"i"` / `"I"` | буквы или римские цифры |
| `value` на `li` | задать номер конкретного пункта |

## Маркированный список: ul

```html
<nav aria-label="Разделы сайта">
  <ul>
    <li><a href="/html">HTML</a></li>
    <li><a href="/css">CSS</a></li>
    <li><a href="/js">JavaScript</a></li>
  </ul>
</nav>
```

`ul` (unordered list) — для набора пунктов без важного порядка: меню, теги, преимущества, характеристики. Внешний вид маркеров задает CSS (`list-style-type`, `::marker`), поэтому `ol` или `ul` выбирают по смыслу, а не по виду.

```text
Порядок важен     -> ol
Порядок не важен  -> ul
Пары ключ-значение -> dl
```

## Список определений: dl

```html
<dl>
  <dt>Автор</dt>
  <dd>Анна Иванова</dd>

  <dt>Дата публикации</dt>
  <dd><time datetime="2026-08-03">3 августа 2026</time></dd>
</dl>
```

`dt` — термин, `dd` — описание. Подходит для глоссария, характеристик товара, метаданных профиля и FAQ. У одного термина может быть несколько `dd`, а несколько `dt` могут относиться к одному описанию. Пары можно оборачивать в `<div>` внутри `dl` для стилизации.

## Вложенный список

Вложенный `ul` или `ol` должен находиться **внутри `li`**, к которому относится:

```html
<ul>
  <li>
    Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

Частая ошибка — положить список рядом с `li`:

```html
<!-- неправильно: прямым ребенком ul может быть только li -->
<ul>
  <li>Frontend</li>
  <ul>
    <li>HTML</li>
  </ul>
</ul>
```

Можно смешивать типы: `ul` внутри `ol` для подпунктов шага.

## Что важно помнить

- Прямыми детьми `ul` и `ol` могут быть только `li` (а также `script` и `template`).
- Скринридер объявляет «список, 3 элемента» — это помогает пользователю. Safari с VoiceOver убирает семантику списка при `list-style: none`; вернуть ее можно через `role="list"`.
- Меню навигации обычно делают как `nav > ul > li > a`.
- Хлебные крошки — `nav > ol`, потому что порядок важен.
- Счетчики CSS (`counter-reset`, `counter-increment`) позволяют сделать кастомную нумерацию, например «1.1, 1.2».

## Мини-шпаргалка

- `ol` — порядок важен, `ul` — не важен, `dl` — термин и описание.
- Пункты `ol` и `ul` — только `li`.
- `dl` состоит из `dt` и `dd`.
- Вложенный список — внутри `li`.
- Маркеры настраиваются CSS, тег выбирают по смыслу.
