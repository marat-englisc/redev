# Что делает элемент svg и чем SVG отличается от растровых изображений?

> [!NOTE]
> `<svg>` встраивает в HTML векторную графику: иконки, логотипы, схемы и диаграммы. SVG описывает изображение фигурами и путями, поэтому масштабируется без потери качества. Растровые форматы (JPEG, PNG, WebP, AVIF) состоят из пикселей и лучше подходят для фотографий.

## Вопрос

Что делает элемент `svg`? Чем SVG отличается от растровых изображений и когда что использовать?

## Основная идея

```html
<svg width="120" height="120" viewBox="0 0 120 120" role="img" aria-label="Выполнено 25%">
  <circle cx="60" cy="60" r="48" fill="#e5e7eb" />
  <path d="M60 12 A48 48 0 0 1 108 60" stroke="#2563eb" stroke-width="12" fill="none" />
</svg>
```

```text
SVG:    circle, path, line, text  -> браузер пересчитывает фигуры при любом размере
Raster: pixels, pixels, pixels    -> при увеличении изображение размывается
```

## viewBox

`viewBox="minX minY width height"` задает внутреннюю систему координат. `width` и `height` — реальный размер на странице. Благодаря `viewBox` одна и та же иконка `0 0 24 24` рисуется и в 16px, и в 64px.

## currentColor

Иконки удобно красить цветом текста:

```html
<button class="icon-button">
  <svg viewBox="0 0 24 24" width="20" height="20" aria-hidden="true">
    <path d="M5 12h14" stroke="currentColor" stroke-width="2" />
  </svg>
  Назад
</button>
```

## Способы подключения

| Способ | Стилизация CSS | Кеширование | Когда |
| --- | --- | --- | --- |
| Inline `<svg>` | полная, `currentColor` | нет, часть HTML | иконки, интерактивная графика |
| `<img src="icon.svg">` | нет | да | логотипы, иллюстрации |
| CSS `background-image` | нет | да | декор |
| `<svg><use href="sprite.svg#icon"/></svg>` | частичная | да | спрайт иконок |

## Сравнение с растром

| Критерий | SVG | Растр |
| --- | --- | --- |
| Основа | Фигуры и пути | Пиксели |
| Масштабирование | Без потери качества | Может размываться |
| Лучший сценарий | Иконки, логотипы, схемы | Фото, сложные изображения |
| Стилизация CSS | Возможна для inline SVG | Ограничена |
| Анимация | CSS и JS по отдельным элементам | Только целиком |
| DOM-доступ | Inline SVG — это элементы DOM | Один `img` |

SVG не всегда легче: сложная иллюстрация с тысячами путей весит больше JPEG и медленнее рисуется. Формат выбирают под задачу. Для фото — WebP, AVIF или JPEG.

## Доступность

```html
<!-- декоративный -->
<svg aria-hidden="true" focusable="false" viewBox="0 0 24 24">...</svg>

<!-- смысловой -->
<svg role="img" aria-labelledby="logo-title" viewBox="0 0 100 40">
  <title id="logo-title">Логотип компании</title>
  ...
</svg>
```

## Что важно помнить

- SVG-файлы от пользователей опасны: они могут содержать `<script>` и обработчики событий. Inline-вставка непроверенного SVG — XSS; при загрузке через `<img>` скрипты не выполняются.
- Перед использованием SVG из дизайн-макета его оптимизируют (SVGO): удаляют метаданные и лишние группы.
- Иконку внутри кнопки без текста называют через `aria-label` на кнопке, а саму SVG скрывают `aria-hidden`.
- В React атрибуты SVG пишутся в camelCase: `strokeWidth`, `viewBox`; SVG можно импортировать как компонент (SVGR).

## Мини-шпаргалка

- SVG — вектор, растр — пиксели.
- `viewBox` — система координат, `currentColor` — цвет текста.
- SVG для иконок, логотипов, схем; растр для фото.
- Inline SVG стилизуется CSS, `<img>` — кешируется.
- Декоративный — `aria-hidden`, смысловой — `role="img"` + имя.
