# Почему важно оптимизировать изображения перед загрузкой?

> [!NOTE]
> Изображения часто занимают большую часть веса страницы. Оптимизация уменьшает размер файлов, ускоряет загрузку, снижает расход трафика и улучшает пользовательский опыт.

## Вопрос

Почему важно оптимизировать изображения? Какие форматы и техники для этого используют?

## Главное

Большая картинка может замедлить первое отображение страницы, особенно на мобильном интернете.

```text
large image
  -> longer download
  -> slower LCP
  -> more traffic
  -> worse UX
```

## Что означает оптимизировать изображение

- Выбрать подходящий формат.
- Сжать файл без заметной потери качества.
- Уменьшить физические размеры изображения.
- Подготовить варианты для разных экранов.
- Использовать lazy loading для изображений ниже первого экрана.

## Форматы

| Формат | Когда использовать |
| --- | --- |
| `JPEG` | Фотографии, сложные изображения |
| `PNG` | Прозрачность, скриншоты, графика без потерь |
| `SVG` | Иконки, логотипы, простая векторная графика |
| `WebP` | Современный универсальный формат |
| `AVIF` | Очень хорошее сжатие, если поддержка подходит проекту |

## Размеры

Не стоит отдавать изображение 4000px шириной, если оно отображается в карточке шириной 320px.

```html
<img src="/product-640.webp" alt="Кроссовки">
```

## Responsive images

```html
<img
  src="/photo-800.webp"
  srcset="/photo-400.webp 400w, /photo-800.webp 800w, /photo-1200.webp 1200w"
  sizes="(max-width: 600px) 100vw, 600px"
  alt="Рабочее место frontend-разработчика"
>
```

Браузер сам выберет подходящий файл.

## Что важно помнить

- Изображения — самая частая причина медленного LCP; оптимизация главного изображения обычно дает самый заметный эффект.
- AVIF обычно сжимает лучше WebP, но кодируется дольше; через `<picture>` можно отдать AVIF с fallback.
- Image CDN (imgix, Cloudinary, Next.js Image) генерируют нужный размер и формат на лету.
- Сжатие проверяют визуально: Squoosh позволяет сравнить качество и размер.

## Мини-шпаргалка

- Изображения сильно влияют на скорость страницы.
- Нужно подбирать формат и размеры под реальное использование.
- Сжатие уменьшает вес страницы.
- `srcset` и `sizes` помогают адаптивности.
- `loading="lazy"` подходит для картинок ниже первого экрана.
- Оптимизация изображений часто улучшает LCP.
