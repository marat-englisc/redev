# Что делают элементы audio и video?

> [!NOTE]
> `<audio>` и `<video>` встраивают медиа на страницу. Источник задают через `src` или вложенные `<source>` с разными форматами, `controls` включает нативную панель управления, `<track>` добавляет субтитры. У `video` есть `poster`, размеры и `playsinline`.

## Вопрос

Что делают элементы `audio` и `video`? Как указать источник медиа и сделать его доступным и быстрым?

## Простой пример

```html
<audio controls src="/audio/lesson.mp3">
  Ваш браузер не поддерживает аудио.
</audio>

<video controls src="/video/demo.mp4" width="800" height="450">
  Ваш браузер не поддерживает видео.
</video>
```

Текст внутри элемента — fallback для браузеров, которые не поддерживают элемент.

## Несколько источников

```html
<video controls width="800" height="450" poster="/video/poster.jpg" preload="metadata">
  <source src="/video/demo.webm" type="video/webm">
  <source src="/video/demo.mp4" type="video/mp4">
  <track src="/video/subtitles-ru.vtt" kind="subtitles" srclang="ru" label="Русские субтитры" default>
  Ваш браузер не поддерживает видео.
</video>
```

Браузер выберет первый `<source>`, формат которого умеет воспроизводить. Атрибут `type` позволяет пропустить неподходящие варианты без загрузки.

## Атрибуты

| Атрибут | audio | video | Что делает |
| --- | :---: | :---: | --- |
| `controls` | да | да | нативная панель управления |
| `autoplay` | да | да | автозапуск (часто блокируется браузером) |
| `muted` | да | да | без звука |
| `loop` | да | да | повтор |
| `preload` | да | да | `none`, `metadata`, `auto` |
| `poster` | — | да | картинка до запуска |
| `width`, `height` | — | да | размеры, защита от layout shift |
| `playsinline` | — | да | воспроизведение внутри страницы на iOS |

## Autoplay

Браузеры блокируют автозапуск со звуком. Видео с `autoplay` запустится, только если есть `muted` (и `playsinline` для iOS):

```html
<video autoplay muted loop playsinline src="/bg.mp4"></video>
```

## Управление из JavaScript

```js
const video = document.querySelector("video");

await video.play(); // Promise: может отклониться, если автозапуск запрещен
video.pause();
video.currentTime = 30;
video.addEventListener("ended", () => console.log("Видео закончилось"));
```

## Доступность

- `<track kind="subtitles">` — перевод речи, `kind="captions"` — расшифровка речи и звуков для глухих.
- Для аудио (подкасты, лекции) нужна текстовая расшифровка.
- Не включайте автозапуск со звуком: он мешает пользователям скринридеров.
- Нативные `controls` доступны с клавиатуры; кастомный плеер требует ARIA и обработки клавиш.

## Производительность

- `preload="none"` или `metadata` для медиа ниже первого экрана;
- `poster` вместо загрузки первого кадра;
- сжатие и современные кодеки (AV1, VP9, H.265 с fallback на H.264);
- для длинных видео — потоковые протоколы (HLS, DASH) через библиотеки вроде hls.js.

## Что важно помнить

- Файлы субтитров — в формате WebVTT (`.vtt`), а не SRT.
- `play()` возвращает Promise — его отказ нужно обрабатывать, иначе в консоли будет необработанная ошибка.
- Для фонового декоративного видео добавляйте `aria-hidden="true"` и учитывайте `prefers-reduced-motion`.
- `<iframe>` с YouTube грузит много JS — используйте фасад (превью + загрузка плеера по клику).

## Мини-шпаргалка

- `audio` и `video` встраивают медиа.
- Источник: `src` или несколько `<source type>`.
- `controls` — управление, `poster` — превью, `track` — субтитры.
- Autoplay работает только с `muted`.
- `preload="metadata"` и сжатие для производительности.
