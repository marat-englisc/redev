# Что такое responsive images?

> [!NOTE]
> **Responsive images** - это подход, при котором браузер получает несколько вариантов изображения и выбирает подходящий по размеру экрана, плотности пикселей и условиям отображения.

## Вопрос

Что такое responsive images? Чем `srcset` с `w` отличается от `x`, и когда нужен `picture`?

## Главное

Одна и та же картинка может быть нужна в разных размерах: маленькая для телефона, крупная для desktop и более четкая для Retina-экранов.

```html
<img
  src="/photo-800.webp"
  srcset="/photo-400.webp 400w, /photo-800.webp 800w, /photo-1200.webp 1200w"
  sizes="(max-width: 600px) 100vw, 600px"
  alt="Команда за обсуждением проекта"
>
```

Браузер сам выбирает оптимальный файл.

## srcset

`srcset` перечисляет доступные варианты изображения.

```html
srcset="/photo-400.webp 400w, /photo-800.webp 800w"
```

`400w` и `800w` обозначают ширину файла в пикселях.

## sizes

`sizes` объясняет браузеру, какую ширину изображение займет в layout.

```html
sizes="(max-width: 600px) 100vw, 600px"
```

Это означает: на экранах до 600px изображение занимает всю ширину viewport, иначе - 600px.

## Picture

`picture` используют, когда нужны разные форматы или разные кадрирования.

```html
<picture>
  <source srcset="/hero.avif" type="image/avif">
  <source srcset="/hero.webp" type="image/webp">
  <img src="/hero.jpg" alt="Главный баннер">
</picture>
```

Браузер выберет первый поддерживаемый вариант.

## Что важно помнить

- Дескриптор `x` (`1x`, `2x`) подходит для изображений фиксированного размера, `w` с `sizes` — для резиновых.
- Без `sizes` браузер считает, что картинка занимает `100vw`, и может скачать слишком большой файл.
- `picture` с `media` нужен для art direction — другого кадрирования на мобильных, а не просто другого размера.
- Браузер может выбрать вариант меньшего разрешения при медленной сети или режиме экономии трафика.

## Мини-шпаргалка

- Responsive images экономят трафик и ускоряют загрузку.
- `srcset` дает варианты файлов.
- `sizes` описывает размер изображения в layout.
- `picture` помогает выбирать формат или кадрирование.
- `src` остается fallback.
- `alt` нужен независимо от responsive-настроек.
