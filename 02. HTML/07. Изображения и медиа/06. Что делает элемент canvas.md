# Что делает элемент canvas?

> [!NOTE]
> `<canvas>` создает область для рисования графики с помощью JavaScript. Его используют для диаграмм, игр, визуализаций, редакторов изображений и кастомной 2D/3D-графики.

## Вопрос

Что делает элемент `canvas` и чем canvas отличается от SVG?

## Главное

Сам по себе `<canvas>` ничего не рисует. Он только создает холст, а рисование выполняется через JavaScript API.

```html
<canvas id="chart" width="600" height="300">
  Ваш браузер не поддерживает canvas.
</canvas>
```

```js
const canvas = document.getElementById("chart");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "#2563eb";
ctx.fillRect(20, 20, 120, 80);
```

## 2D-контекст

`getContext("2d")` дает API для рисования линий, прямоугольников, текста, изображений и фигур.

```js
ctx.beginPath();
ctx.arc(100, 100, 40, 0, Math.PI * 2);
ctx.stroke();
```

## Canvas и DOM

Элементы, нарисованные внутри canvas, не становятся отдельными DOM-узлами.

```text
DOM sees:
  canvas

DOM does not see:
  button drawn inside canvas
  text drawn inside canvas
  chart point drawn inside canvas
```

Из-за этого доступность и интерактивность нужно продумывать отдельно.

## Когда использовать

- Графики и диаграммы.
- Игры.
- Карты и визуализации.
- Рисование и редакторы.
- Эффекты, где много пиксельной графики.

## Когда лучше не использовать

Для обычного текста, кнопок, форм и layout лучше использовать HTML и CSS. Canvas не дает нативной семантики, фокуса и доступности для нарисованных элементов.

## Что важно помнить

- Атрибуты `width` и `height` задают разрешение холста, а CSS — размер отображения; для Retina умножайте разрешение на `devicePixelRatio`.
- Canvas выгоден для тысяч объектов и пиксельной графики, SVG — для небольшого числа интерактивных объектов с доступностью.
- `OffscreenCanvas` позволяет рисовать в Web Worker и не блокировать основной поток.
- Картинка с другого origin без CORS «загрязняет» canvas: после этого `toDataURL` и `getImageData` бросят ошибку.
- Кроме 2D есть контексты `webgl`, `webgl2` и WebGPU для 3D-графики.

## Мини-шпаргалка

- `<canvas>` - холст для рисования через JS.
- Для 2D используют `getContext("2d")`.
- Нарисованные объекты не являются DOM-элементами.
- Canvas хорош для графики и игр.
- Для обычного интерфейса лучше HTML/CSS.
- Доступность canvas нужно проектировать отдельно.
