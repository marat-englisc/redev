# Что делает not-found.tsx

> [!NOTE]
> `not-found.tsx` описывает интерфейс отсутствующего ресурса. В App Router функция `notFound()` прекращает обработку текущей страницы и показывает подходящий интерфейс «не найдено».

## Вопрос

Как отличить отсутствующую статью от технической ошибки и показать понятную страницу?

## Основная идея

Динамический маршрут `/articles/[slug]` принимает множество адресов. Наличие подходящего маршрута не означает, что статья с конкретным `slug` существует.

Если поиск данных ничего не вернул, это ожидаемый случай: пользователь мог открыть старую ссылку или ошибиться в адресе. `notFound()` выражает именно такую ситуацию. Для неожиданного сбоя, например недоступности базы, предназначена обработка ошибок.

## Пример: поиск в учебном наборе статей

```tsx
// app/articles/[slug]/page.tsx
import { notFound } from "next/navigation";

const articles = [
  { slug: "react", title: "Основы React" },
  { slug: "next", title: "Основы Next.js" },
];

export default async function ArticlePage({
  params,
}: {
  params: Promise<{ slug: string }>;
}) {
  const { slug } = await params;
  const article = articles.find(item => item.slug === slug);

  if (!article) notFound();

  return <h1>{article.title}</h1>;
}
```

```tsx
// app/articles/[slug]/not-found.tsx
import Link from "next/link";

export default function ArticleNotFound() {
  return (
    <main>
      <h1>Такой статьи нет</h1>
      <Link href="/articles/react">Открыть статью о React</Link>
    </main>
  );
}
```

На `/articles/react` появится заголовок статьи. На `/articles/unknown` сработает `notFound()`, и пользователь увидит запасной экран. Данные здесь обычный массив, поэтому дополнительных сервисов не требуется.

## Что важно помнить

Корневой `app/not-found.tsx` также используется для неизвестных адресов приложения в обычной схеме маршрутизации. Для сложных схем существует отдельное соглашение `global-not-found`.

Не обещай HTTP 404 в любой ситуации: до начала streaming Next.js может отправить 404, но после отправки заголовков ответ сохраняет статус 200. Интерфейс «не найдено» все равно показывается, а Next.js добавляет `noindex`.

`notFound()` прекращает выполнение через специальное исключение. Не перехватывай его общим `catch`, если не собираешься передать дальше.

## Мини-шпаргалка

- Нет данных для ресурса → `notFound()`.
- `not-found.tsx` задает понятный запасной экран.
- Технический сбой и отсутствие ресурса — разные случаи.
- Статус ответа зависит от того, начался ли streaming.
