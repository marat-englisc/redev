# Какие файлы находятся в корне Next.js-проекта

> [!NOTE]
> **Корень проекта** — основная папка приложения, где обычно лежат зависимости, команды запуска и конфигурация. Это не то же самое, что корневая страница `/`.

## Вопрос

За что отвечают `package.json`, `next.config.ts`, `tsconfig.json` и другие файлы рядом с `app`?

## Основная идея

В корне удобно разделять исходный код и настройки инструментов. Страницы располагаются в `app` или `src/app`, а параметры сборки — в конфигурационных файлах.

Чаще всего встречаются:

- `package.json` — зависимости и команды, например запуск и сборка.
- Файл блокировки зависимостей, например `package-lock.json` или `pnpm-lock.yaml`, — фиксирует выбранные версии пакетов.
- `next.config.ts` — настройки Next.js; доступны также поддерживаемые JavaScript-варианты.
- `tsconfig.json` — настройки TypeScript и путей импортов.
- `next-env.d.ts` — автоматически создаваемые объявления типов Next.js.
- `.gitignore` — список файлов, которые не нужно добавлять в Git.
- `eslint.config.mjs` — настройки линтера, если он используется.

## Пример: команды запуска

Фрагмент `package.json` существующего проекта:

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint ."
  }
}
```

```text
project/
  package.json
  package-lock.json
  next.config.ts
  tsconfig.json
  next-env.d.ts
  .gitignore
  app/
  public/
```

`npm run dev` запускает разработку. `npm run build` готовит production-сборку, а `npm run start` запускает ее. Для `lint` нужен установленный и настроенный ESLint.

## Что важно помнить

`.next` создается инструментами Next.js и содержит результат работы сборки. `node_modules` содержит установленные пакеты. Эти папки не заменяют исходный код и обычно не добавляются в Git.

`.env.local` может хранить локальные настройки среды. Значения с префиксом `NEXT_PUBLIC_` предназначены для включения в клиентский код; секреты так называть нельзя.

`next-env.d.ts` не следует править вручную: Next.js может его пересоздать. Необязательно создавать все перечисленные конфиги заранее — часть зависит от выбранных инструментов.

В Next.js 16 команда `next lint` удалена; линтер запускают своей командой. Успешная сборка не означает, что линтер был запущен.

## Мини-шпаргалка

- `package.json` описывает команды и зависимости.
- `next.config.*` настраивает Next.js.
- `tsconfig.json` настраивает TypeScript.
- `.next` и `node_modules` создаются инструментами.
