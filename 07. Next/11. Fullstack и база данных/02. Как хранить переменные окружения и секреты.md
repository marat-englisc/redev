# Как хранить переменные окружения и секреты

> [!NOTE]
> Переменные окружения задают параметры приложения: адрес БД, домен и секрет авторизации. Значения с `NEXT_PUBLIC_` предназначены для браузера и не подходят для секретов.

## Вопрос

Куда записать пароль PostgreSQL и почему его нельзя передавать клиентскому компоненту?

## Основная идея

Секрет нужен серверу для подключения к другому сервису. Браузеру достаточно результата операции. Если передать строку подключения через props или JSON, пользователь сможет ее прочитать даже без доступа к исходникам.

В Next.js поддерживаются `.env` и `.env.local`. В учебном fullstack-примере используем `.env`: его сможет загрузить и CLI авторизации. Добавь его в `.gitignore`; в репозитории оставь `.env.example` с пустыми значениями.

## Пример: настройки учебного приложения

```dotenv
# .env — локальный файл, не добавляй в Git
DATABASE_URL=postgresql://next_app:local_password@localhost:5432/next_tasks
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_SECRET=ЗАМЕНИ_НА_СЛУЧАЙНОЕ_ЗНАЧЕНИЕ
```

Сгенерировать секрет можно в терминале:

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

Скопируй результат в `BETTER_AUTH_SECRET`. Адрес и пароль PostgreSQL здесь относятся только к локальной учебной базе из следующего материала.

```ts
// пример проверки серверной настройки
const databaseUrl = process.env.DATABASE_URL;
if (!databaseUrl) throw new Error("Не задан DATABASE_URL");
```

Так ошибка конфигурации обнаружится явно. Не выводи сам секрет в сообщение ошибки.

## Что важно помнить

Серверные модули удобно защищать `import "server-only"`: Next.js обнаружит попытку импортировать их в клиентский граф. Для кода, который одновременно загружает обычный Node.js CLI, потребуется отдельная серверная обертка — ее покажем в подключении БД.

После изменения настроек перезапусти сервер. Публичные переменные обычно подставляются при сборке; смена значения на хостинге не обязательно изменит уже собранный клиентский JavaScript. В production секреты задают средствами окружения хостинга.

## Мини-шпаргалка

- Пароль БД остается на сервере.
- `NEXT_PUBLIC_` означает доступность клиенту.
- Файлы с секретами не коммитят.
- CLI и Next.js могут по-разному загружать env-файлы.
