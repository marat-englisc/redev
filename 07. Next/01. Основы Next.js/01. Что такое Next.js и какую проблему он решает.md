# Что такое Next.js и какую проблему он решает

> [!NOTE]
> **Next.js** — фреймворк на основе React. Он объединяет создание интерфейса, маршрутизацию, серверный рендеринг и инструменты сборки в одном проекте.

## Вопрос

Зачем нужен Next.js, если интерфейс уже можно написать на React?

## Основная идея

React помогает собирать экран из компонентов. Но приложению обычно нужны и другие решения: как открыть страницу по URL, где загрузить данные, как подготовить HTML и как собрать код для публикации.

Next.js задает общие правила для этих задач. Например, в **App Router** адрес страницы определяется папками внутри `app`, а общую шапку можно вынести в `layout.tsx`. App Router — основная модель, используемая в этих материалах.

HTML можно подготовить заранее, во время сборки, или сформировать на сервере при запросе. Интерактивные элементы при этом остаются React-компонентами. **Гидратация** подключает клиентскую логику к предварительно созданному HTML.

## Пример: две страницы магазина

Для работы нужны Node.js и основы JavaScript, JSX, компонентов и props. Создай учебный проект:

```powershell
npx create-next-app@latest next-learning --use-npm
cd next-learning
npm run dev
```

Выбери собственные настройки: TypeScript — да, App Router — да, папка `src` — нет, Cache Components — нет. Остальные параметры оставь по предпочтению. Открой `http://localhost:3000`.

Если проект создан с рекомендуемыми настройками или раньше, проверь `next.config.ts`: для примеров этого раздела `cacheComponents` должен быть выключен. В Next.js 16.3 и новее также выключи `partialPrefetching`, если он включен. Эти параметры задают другую модель кэширования и предзагрузки. Сохрани остальные настройки проекта:

```ts
// next.config.ts — нужная часть конфигурации
const nextConfig = {
  // Остальные настройки проекта остаются здесь.
  cacheComponents: false,
  partialPrefetching: false,
};

export default nextConfig;
```

В созданном проекте сохрани корневой `app/layout.tsx`, замени содержимое `app/page.tsx` и добавь каталог:

```text
app/
  layout.tsx
  page.tsx
  catalog/
    page.tsx
```

```tsx
// app/page.tsx
import Link from "next/link";

export default function HomePage() {
  return (
    <main>
      <h1>Книжный магазин</h1>
      <Link href="/catalog">Открыть каталог</Link>
    </main>
  );
}
```

```tsx
// app/catalog/page.tsx
export default function CatalogPage() {
  return <h1>Каталог книг</h1>;
}
```

По адресу `/` появится главная страница, а ссылка откроет `/catalog`. Отдельную таблицу маршрутов писать не понадобилось.

## Что важно помнить

Материалы используют App Router Next.js 16 без включенного `cacheComponents`. Примеры в разных темах — самостоятельные варианты: несколько примеров `app/page.tsx` не нужно складывать в один файл. Pages Router рассматривается отдельно.

Серверные компоненты в App Router выполняются на сервере. Для состояния и обработчиков событий используют клиентские компоненты с `"use client"`. Эта директива не запрещает предварительное создание их HTML на сервере.

Next.js не гарантирует скорость или успешное SEO сам по себе: результат зависит от данных, структуры страниц и написанного кода.

## Мини-шпаргалка

- React описывает интерфейс; Next.js организует приложение вокруг него.
- `app/catalog/page.tsx` создает страницу `/catalog`.
- Серверный код и интерактивный интерфейс могут быть в одном проекте.
- Новый проект удобно изучать через App Router.
