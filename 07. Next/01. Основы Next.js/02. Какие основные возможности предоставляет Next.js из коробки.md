# Какие возможности Next.js предоставляет из коробки

> [!NOTE]
> Next.js объединяет инструменты, которые обычно нужны React-приложению: маршруты, серверный рендеринг, загрузку данных, оптимизацию ресурсов и сборку для публикации.

## Вопрос

Что уже умеет Next.js и что все равно должен написать разработчик?

## Основная идея

Представь сайт с каталогом и личным кабинетом. Фреймворк помогает создать страницы и общую оболочку, передать браузеру HTML и загрузить код интерактивных элементов. Правила покупки, права пользователя и хранение заказов остаются задачами приложения.

Основные инструменты:

- **Файловая маршрутизация:** папки и специальные файлы определяют адреса страниц.
- **Server и Client Components:** серверная загрузка данных сочетается с кнопками, формами и состоянием в браузере.
- **Разные способы рендеринга:** предварительная генерация, рендеринг при запросе и обновление сохраненного результата.
- **Серверные функции:** Route Handlers создают HTTP-обработчики, Server Actions обрабатывают изменения данных.
- **Оптимизация ресурсов:** разделение кода, компонент `Image`, инструменты для шрифтов и предзагрузка переходов.
- **Метаданные:** заголовок документа, описание, Open Graph, sitemap и robots.

## Пример: страница с метаданными и ссылкой

```tsx
// app/catalog/page.tsx
import type { Metadata } from "next";
import Link from "next/link";

export const metadata: Metadata = {
  title: "Каталог книг",
  description: "Учебники для начинающих разработчиков",
};

export default function CatalogPage() {
  return (
    <main>
      <h1>Каталог книг</h1>
      <p>Начни с основ JavaScript.</p>
      <Link href="/">На главную</Link>
    </main>
  );
}
```

Файл создает `/catalog`. Next.js добавляет метаданные в документ, а `Link` обеспечивает переход внутри приложения. У проекта должны быть корневой layout и главная страница для ссылки `/`.

## Что важно помнить

`app/api/.../route.ts` — **Route Handler** App Router; **API Route** Pages Router располагается в `pages/api`. Названия похожи, но формат кода отличается.

Наличие инструмента не означает автоматическую настройку любой задачи. Авторизацию, проверку входных данных и нужные правила кэширования задает разработчик.

Для статического экспорта используют `output: "export"` в конфигурации. Такой вариант не поддерживает возможности, которым нужен работающий сервер при запросе.

## Мини-шпаргалка

- Next.js дает общую инфраструктуру для React-приложения.
- `page.tsx` — страница, `layout.tsx` — общая оболочка.
- Метаданные, изображения и навигация имеют готовые API.
- Бизнес-правила и безопасность приложения нужно реализовать.
