# Почему Next.js хорошо подходит для SEO

> [!NOTE]
> **SEO**, Search Engine Optimization, — работа над тем, чтобы поисковая система могла найти страницу, понять ее содержание и показать по подходящим запросам. Next.js предоставляет полезные для этого инструменты.

## Вопрос

Как серверный рендеринг и метаданные помогают поисковой системе работать с сайтом?

## Основная идея

Поисковый робот переходит по URL, читает ответ и анализирует содержимое. Если основной текст уже есть в HTML, для его получения не нужно сначала выполнять клиентскую загрузку данных.

Next.js может подготовить HTML заранее или при запросе. Также он помогает описывать каждую страницу с помощью **метаданных**: заголовка документа, краткого описания и данных для предпросмотра ссылки.

Для каталога полезно, чтобы каждая книга имела собственный URL, понятный заголовок и ссылки из других страниц. Файловая маршрутизация упрощает создание таких адресов.

## Пример: описание страницы

```tsx
// app/courses/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Курсы для начинающих frontend-разработчиков",
  description: "Основы HTML, CSS и JavaScript с учебными примерами.",
  openGraph: {
    title: "Изучаем frontend",
    description: "Первые шаги в веб-разработке",
  },
};

export default function CoursesPage() {
  return (
    <main>
      <h1>Курсы по frontend</h1>
      <p>Начни с HTML, затем переходи к CSS и JavaScript.</p>
    </main>
  );
}
```

На `/courses` пользователь увидит заголовок и текст. Next.js добавит данные для `<title>` и метатегов документа. В App Router для этого используют Metadata API; `next/head` относится к Pages Router.

Для изменяемых метаданных, например названия конкретной статьи, предусмотрена функция `generateMetadata`.

## Что важно помнить

Next.js не гарантирует индексацию или высокую позицию в поиске. Важны полезность текста, доступность сайта, корректные ссылки, HTTP-статусы и отсутствие случайного запрета индексации.

`sitemap` помогает сообщить о страницах, а `robots` задает правила обхода. Ни один из них не заставляет поисковик проиндексировать страницу.

Оптимизация изображений и шрифтов может улучшить загрузку, но тяжелый код и медленный API все равно влияют на впечатление пользователя.

## Мини-шпаргалка

- Основной контент желательно предоставлять в HTML.
- Каждой странице нужны подходящие title и описание.
- App Router использует `metadata` и `generateMetadata`.
- Инструменты Next.js помогают SEO, но не обеспечивают результат автоматически.
