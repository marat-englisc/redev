# Способы получения данных в Next.js

> [!NOTE]
> **Data fetching** — получение данных из API, базы данных или другого источника. В Next.js его можно выполнять на сервере и в браузере.

## Вопрос

Какие способы загрузки данных существуют и как выбрать подходящий?

## Основная идея

В App Router страница по умолчанию является Server Component. Она может получить данные через `fetch` или библиотеку базы данных до передачи результата браузеру. Для запросов после клика, обновления графика и поиска по мере ввода можно использовать Client Component.

Место выполнения и время получения данных — разные вопросы:

| Задача | Подход |
| --- | --- |
| Показать общедоступную статью | Серверная загрузка, возможно статическая генерация |
| Получать содержимое заново при запросе | Динамический серверный рендеринг |
| Переиспользовать каталог с периодическим обновлением | Кэширование и ревалидация |
| Обновить виджет после действия пользователя | Клиентский запрос |
| Сохранить форму | Server Action или HTTP-обработчик |

Server Actions предназначены прежде всего для изменения данных, а не для основной загрузки страницы.

## Пример: загрузка записи на сервере

Пример для Next.js 16 App Router без включенного `cacheComponents`. JSONPlaceholder — открытый учебный API с тестовыми записями.

```tsx
// app/page.tsx
export default async function Page() {
  const response = await fetch(
    "https://jsonplaceholder.typicode.com/posts/1",
    { cache: "no-store" }
  );

  if (!response.ok) throw new Error("Не удалось загрузить запись");
  const post: { title: string; body: string } = await response.json();

  return <article><h1>{post.title}</h1><p>{post.body}</p></article>;
}
```

`await` ожидает ответ API. Затем сервер собирает интерфейс с полученными данными. `no-store` отключает постоянный Data Cache для этого запроса.

## Что важно помнить

Server Component может выполняться при сборке или при запросе: его название само по себе не определяет стратегию. В Pages Router используются другие API: `getStaticProps` и `getServerSideProps`; в `app` они недоступны.

## Мини-шпаргалка

- Основное содержимое удобно загружать на сервере.
- Интерактивные обновления можно загружать в браузере.
- Кэширование выбирают отдельно от места выполнения.
