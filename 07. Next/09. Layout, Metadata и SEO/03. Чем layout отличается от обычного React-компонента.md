# Чем layout отличается от обычного React-компонента

> [!NOTE]
> Layout остается React-компонентом, но файл `layout.tsx` получает специальную роль в App Router: Next.js автоматически связывает его с маршрутом и управляет вложенным содержимым.

## Вопрос

Почему недостаточно назвать обычный компонент `Layout`, чтобы получить поведение layout в Next.js?

## Основная идея

Обычный компонент включается в дерево там, где ты его импортировал и отрендерил. Имя `Layout`, `Header` или `Frame` само по себе ничего не меняет.

Специальный `app/account/layout.tsx` Next.js находит по файловому соглашению. Он автоматически оборачивает все страницы ниже `account`, получает `children` от маршрутизатора и участвует в сохранении общей ветви при навигации.

Обычный React-компонент тоже сохраняет состояние, если остается на том же месте дерева. Поэтому отличие не в том, что «обычный всегда перемонтируется», а в том, что маршрутизатор специально поддерживает общие layout между подходящими страницами.

## Пример: компонент рамки внутри layout

```tsx
// app/account/frame.tsx
import type { ReactNode } from "react";

export default function Frame({ children }: { children: ReactNode }) {
  return <section className="account-frame">{children}</section>;
}
```

```tsx
// app/account/layout.tsx
import type { ReactNode } from "react";
import Frame from "./frame";

export default function AccountLayout({ children }: { children: ReactNode }) {
  return (
    <Frame>
      <h1>Личный кабинет</h1>
      {children}
    </Frame>
  );
}
```

```tsx
// app/account/page.tsx
export default function Page() {
  return <p>Добро пожаловать в кабинет.</p>;
}
```

Next.js автоматически использует `AccountLayout` для `/account`. `Frame` участвует только потому, что layout его явно импортировал. Класс `account-frame` можно оформить CSS, но для работы структуры стили не обязательны.

## Что важно помнить

Экспорт `metadata` Next.js читает из специальных серверных `layout.tsx` и `page.tsx`, а не из любого произвольного компонента. При этом обычные React-компоненты в современных версиях React тоже могут рендерить некоторые теги метаданных; это другой механизм.

Корневой layout задает HTML-документ с `<html>` и `<body>`. Вложенные layout добавляют обычные части интерфейса без повторения этих тегов.

Если при каждом переходе требуется новое монтирование общей обертки, изучи специальный файл `template.tsx`.

## Мини-шпаргалка

- Имя компонента не задает роль маршрутизации.
- `layout.tsx` применяется автоматически.
- Обычный компонент подключают вручную.
- Сохранение state зависит от позиции и идентичности дерева.
