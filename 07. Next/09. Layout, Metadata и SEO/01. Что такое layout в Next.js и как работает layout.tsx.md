# Что такое layout в Next.js и как работает layout.tsx

> [!NOTE]
> **Layout** — общий каркас для страницы и вложенных маршрутов. В App Router он задается специальным файлом `layout.tsx` и получает вложенный интерфейс через `children`. Layout на каждом уровне `app` оборачивает содержимое ниже себя.

## Вопрос

Как один раз создать шапку для всего приложения и отдельное меню для раздела, чтобы показывать их на всех нужных страницах?

## Основная идея

Представь раздел магазина: каталог, доставка и контакты используют одно меню. Если повторять меню в каждой странице, его придется синхронно исправлять в нескольких местах. Layout размещает общий интерфейс на одном уровне над страницами.

Директория `app` содержит дерево маршрутов. Корневой `app/layout.tsx` действует на все приложение, а `app/shop/layout.tsx` — на `app/shop/page.tsx` и страницы в папках ниже `shop`.

При клиентской навигации внутри общего layout его ветвь сохраняется. Состояние клиентских компонентов в ней обычно не сбрасывается из-за перехода на соседнюю страницу. Активная страница и компоненты, зависящие от навигации, при этом обновляются.

## Пример: корневой layout и каркас раздела

```tsx
// app/layout.tsx
import type { ReactNode } from "react";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ru">
      <body>
        <header>Учебный сервис</header>
        {children}
      </body>
    </html>
  );
}
```

```tsx
// app/shop/layout.tsx
import Link from "next/link";
import type { ReactNode } from "react";

export default function ShopLayout({ children }: { children: ReactNode }) {
  return (
    <section>
      <nav>
        <Link href="/shop">Каталог</Link>{" | "}
        <Link href="/shop/delivery">Доставка</Link>
      </nav>
      <div>{children}</div>
      <footer>Вопросы: books@example.com</footer>
    </section>
  );
}
```

```tsx
// app/shop/page.tsx
export default function Page() {
  return <h2>Каталог книг</h2>;
}

// app/shop/delivery/page.tsx
export default function DeliveryPage() {
  return <p>Доставка занимает три рабочих дня.</p>;
}
```

Обе страницы раздела получат общую шапку, меню и подвал. Между ними меняется только содержимое `children`.

## Что важно помнить

- Корневой layout обязателен и содержит `<html>` и `<body>`. Во вложенных layout эти теги не повторяют.
- Layout по умолчанию — серверный компонент. Для интерактивного меню вкладывают небольшой клиентский компонент, оставляя каркас серверным.
- Layout получает `params` динамических сегментов до своего уровня (в Next.js 16 это Promise — `await params`). Параметры более глубоких сегментов ему недоступны.
- `searchParams` не является пропсом layout: параметры запроса читают на странице или в клиентском компоненте через `useSearchParams`.
- Сохранение layout относится к переходам внутри общей ветви. Полная перезагрузка или смена корневого layout создают его заново. Если обертку нужно перемонтировать при каждом переходе, используют `template.tsx`.

## Мини-шпаргалка

- `layout.tsx` оборачивает страницу и все вложенные маршруты.
- Корневой layout — с `<html>` и `<body>`.
- При навигации внутри ветви layout сохраняется вместе с состоянием.
- Нет `searchParams`; `params` — только до своего уровня.
