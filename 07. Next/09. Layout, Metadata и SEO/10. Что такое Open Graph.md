# Что такое Open Graph

> [!NOTE]
> **Open Graph, OG**, - набор метаданных, с помощью которых сервисы могут построить превью ссылки: заголовок, описание и изображение страницы.

## Вопрос

Откуда мессенджер берет картинку и текст карточки, когда пользователь отправляет ссылку?

## Основная идея

Сервис получает страницу и читает метаданные вроде `og:title`, `og:description`, `og:image` и `og:url`. На их основе он может показать карточку вместо одного адреса.

В Next.js текстовые значения задаются через `metadata.openGraph`. Изображение можно указать ссылкой либо создать специальным файлом `opengraph-image`. Итоговое отображение зависит от сервиса: он может обрезать изображение, ограничить текст или использовать сохраненное превью.

Open Graph описывает представление ссылки. Он не гарантирует место страницы в поиске или конкретную кликабельность.

## Пример: превью учебной статьи

```tsx
// app/next/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  metadataBase: new URL("https://example.com"),
  title: "Изучаем Next.js",
  openGraph: {
    title: "Изучаем Next.js с нуля",
    description: "Понятное введение в маршруты и компоненты.",
    url: "/next",
    type: "article",
  },
};

export default function Page() {
  return <h1>Изучаем Next.js с нуля</h1>;
}
```

```tsx
// app/next/opengraph-image.tsx
import { ImageResponse } from "next/og";

export const alt = "Изучаем Next.js с нуля";
export const size = { width: 1200, height: 630 };
export const contentType = "image/png";

export default function Image() {
  return new ImageResponse(
    <div style={{ display: "flex", width: "100%", height: "100%", background: "#152238", color: "white", fontSize: 72, alignItems: "center", justifyContent: "center" }}>
      Next.js с нуля
    </div>,
    size,
  );
}
```

Второй файл генерирует PNG с надписью без внешних изображений. Next.js автоматически добавляет OG-ссылку на этот ресурс. `example.com` нужно заменить реальным публичным адресом проекта.

## Что важно помнить

Ресурс превью должен быть доступен сервису извне, без входа в аккаунт. Локальный адрес разработчика сервис не сможет прочитать.

`metadataBase` помогает сформировать абсолютные адреса из относительных. Он не заменяет развертывание сайта по настоящему домену.

Обычный title и OG-title могут различаться. При новом `openGraph` в дочернем сегменте нужные родительские поля сохраняют явно: глубокого объединения нет. Для карточек X также существует отдельное поле `twitter`.

## Мини-шпаргалка

- OG описывает превью ссылки.
- `openGraph` задает текст и адреса.
- `opengraph-image` может создать изображение автоматически.
- Сервисы могут кэшировать старое превью.
