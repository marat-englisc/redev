# Как формируется итоговый title

> [!NOTE]
> Итоговый **title** документа определяется метаданными страницы и ее родительских layout. Для него есть обычная строка, значение по умолчанию, шаблон и абсолютное значение.

## Вопрос

Как добавить название сайта к заголовкам страниц и в каких случаях шаблон не применяется?

## Основная идея

Layout удобно поручить общую часть названия, например «Учебник», а странице - конкретную, например «React». Для этого `title.template` содержит `%s`, на место которого подставляется заголовок дочернего сегмента.

`title.default` задает исходное название для страниц без собственного заголовка. `title.absolute` позволяет явно отказаться от шаблонов родителей.

Next.js разрешает метаданные по цепочке от корня к странице. Для title действуют специальные правила: нельзя просто склеить все строки из всех layout.

## Пример: общий шаблон и отдельная страница

```tsx
// app/layout.tsx
import type { Metadata } from "next";
import type { ReactNode } from "react";

export const metadata: Metadata = {
  title: { default: "Учебник", template: "%s | Учебник" },
};

export default function RootLayout({ children }: { children: ReactNode }) {
  return <html lang="ru"><body>{children}</body></html>;
}
```

```tsx
// app/react/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = { title: "React" };

export default function Page() {
  return <h1>Основы React</h1>;
}
```

Получится `<title>React | Учебник</title>`. Если заменить объект страницы на `{ title: { absolute: "React без дополнений" } }`, получится ровно `React без дополнений`.

| Настройка страницы при данном Root Layout | Итог |
| --- | --- |
| Нет своего title | `Учебник` |
| `title: "React"` в дочернем сегменте | `React | Учебник` |
| `title.absolute: "React без дополнений"` | `React без дополнений` |

## Что важно помнить

Шаблон layout действует на **дочерние сегменты**, но не на `page.tsx` в том же сегменте. Например, шаблон `app/layout.tsx` не оформляет title из `app/page.tsx`, а шаблон `app/blog/layout.tsx` не оформляет title из `app/blog/page.tsx`.

При объявлении template нужен default. Шаблон в `page.tsx` не имеет эффекта: страница завершает маршрут и не задает обертку для дочерних сегментов.

Вложенный layout может установить новый шаблон для своих потомков. Все встреченные шаблоны не обязаны накапливаться в конце. Результат `generateMetadata` подчиняется тем же правилам title.

## Мини-шпаргалка

- `default` - название при отсутствии собственного.
- `template` - оформление заголовков дочерних сегментов.
- `absolute` - точное значение без родительского шаблона.
- `<h1>` и `<title>` задаются отдельно.
