# Что такое Root Layout

> [!NOTE]
> **Root Layout** - внешний layout маршрута в App Router, который задает корневой HTML-документ. В обычном проекте он находится в `app/layout.tsx`.

## Вопрос

Зачем нужен корневой layout, что в нем размещают и чем он отличается от вложенных layout?

## Основная идея

У документа есть общая основа: язык, `<html>`, `<body>`, стили, шапка и вложенное содержимое. Root Layout задает эту основу для страниц приложения.

Вложенный `app/blog/layout.tsx` может добавить меню блога, но не создает второй HTML-документ. Его содержимое вставляется внутрь корневого layout через `children`.

Часто в корне размещают базовые метаданные и действительно общие провайдеры. Если провайдер нужен только кабинету, разумнее подключить его в layout кабинета.

## Пример: документ на русском языке

```tsx
// app/layout.tsx
import type { Metadata } from "next";
import type { ReactNode } from "react";
import "./globals.css";

export const metadata: Metadata = {
  title: "Учебный сайт",
  description: "Понятные уроки frontend-разработки.",
};

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ru">
      <body>
        <header>Учимся вместе</header>
        <main>{children}</main>
      </body>
    </html>
  );
}
```

```css
/* app/globals.css */
body {
  margin: 0;
  font-family: system-ui, sans-serif;
}

main {
  max-width: 60rem;
  margin: 0 auto;
  padding: 1rem;
}
```

```tsx
// app/page.tsx
export default function Page() {
  return <h1>Добро пожаловать</h1>;
}
```

На главной странице появятся общая шапка и заголовок страницы. `lang="ru"` помогает браузеру и вспомогательным технологиям определить язык, а стили применяются ко всему документу.

## Что важно помнить

Теги `<html>` и `<body>` обязательны в корневом layout. Вручную создавать `<head>` для обычного title и description не нужно: используй Metadata API.

Глобальные стили обычно импортируют здесь ради понятной организации, но App Router допускает их импорт и в других подходящих файлах. Утверждение «CSS можно подключить только из корневого layout» неверно.

Возможны несколько Root Layout через route groups. При переходе между разными корневыми layout происходит полная загрузка документа, поэтому для начала удобнее один общий корень.

## Мини-шпаргалка

- Root Layout задает документ и получает `children`.
- Вложенные layout добавляют интерфейс внутри документа.
- Базовые metadata и общие стили удобно хранить в корне.
- Несколько корневых layout - отдельный архитектурный выбор.
