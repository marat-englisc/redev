# Как сделать регистрацию вход и выход

> [!NOTE]
> Клиентская форма отправляет учетные данные библиотеке авторизации. После успешной проверки сервер устанавливает сессию, которую последующие запросы используют автоматически.

## Вопрос

Как связать страницу входа с Better Auth и открыть защищенные задачи?

## Основная идея

Сначала настрой сервер и таблицы из темы 01. Клиент импортирует отдельный SDK, а не серверный `auth` с подключением к БД. При общем домене адрес API определяется автоматически.

## Пример: одна форма для входа и регистрации

```ts
// lib/auth-client.ts
import { createAuthClient } from "better-auth/react";
export const authClient = createAuthClient();
```

```tsx
// app/login/page.tsx
"use client";

import { useState, type FormEvent } from "react";
import { useRouter } from "next/navigation";
import { authClient } from "@/lib/auth-client";

export default function LoginPage() {
  const router = useRouter();
  const [register, setRegister] = useState(false);
  const [pending, setPending] = useState(false);
  const [message, setMessage] = useState("");

  async function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    const email = String(data.get("email") ?? "");
    const password = String(data.get("password") ?? "");
    setPending(true);
    setMessage("");
    try {
      const result = register
        ? await authClient.signUp.email({
            email, password, name: String(data.get("name") ?? ""),
          })
        : await authClient.signIn.email({ email, password });
      if (result.error) { setMessage("Проверьте данные входа"); return; }
      router.replace("/tasks");
      router.refresh();
    } catch { setMessage("Не удалось связаться с сервером"); }
    finally { setPending(false); }
  }

  return <main>
    <h1>{register ? "Регистрация" : "Вход"}</h1>
    <form onSubmit={submit}>
      {register && <label>Имя <input name="name" required maxLength={100} /></label>}
      <label>Почта <input name="email" type="email" required autoComplete="email" /></label>
      <label>Пароль <input name="password" type="password" required minLength={8}
        autoComplete={register ? "new-password" : "current-password"} /></label>
      <button disabled={pending}>{pending ? "Подождите…" : register ? "Создать аккаунт" : "Войти"}</button>
      <p role="alert">{message}</p>
    </form>
    <button disabled={pending} onClick={() => { setRegister(value => !value); setMessage(""); }}>
      {register ? "У меня уже есть аккаунт" : "Зарегистрироваться"}
    </button>
  </main>;
}
```

В минимальной конфигурации Better Auth автоматически выполняет вход после регистрации. После успеха откроется `/tasks`. `refresh` запрашивает серверный результат с новой сессией; пароль не сохраняется в state приложения или `localStorage`.

Для выхода добавь компонент в раздел задач:

```tsx
// app/tasks/logout-button.tsx
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import { authClient } from "@/lib/auth-client";

export default function LogoutButton() {
  const router = useRouter();
  const [pending, setPending] = useState(false);
  const [message, setMessage] = useState("");
  async function logout() {
    setPending(true);
    try {
      const result = await authClient.signOut();
      if (result.error) { setMessage("Не удалось выйти"); return; }
      router.replace("/login");
      router.refresh();
    } catch { setMessage("Ошибка соединения"); }
    finally { setPending(false); }
  }
  return <div>
    <button onClick={logout} disabled={pending}>Выйти</button>
    <p role="status">{message}</p>
  </div>;
}
```

Удалить надпись «Вы вошли» недостаточно: завершить нужно серверную сессию.

## Что важно помнить

Этот пример не отправляет письма подтверждения и восстановления пароля. Такие процессы настраиваются отдельно с почтовым провайдером и политикой библиотеки. Клиентский `minLength` также не заменяет серверную политику пароля.

Не сохраняй пароль в логах и не реализуй вход сравнением открытого текста в SQL. Ошибку SDK обрабатывают отдельно от ошибки сети.

## Мини-шпаргалка

- `signUp.email` создает пользователя, `signIn.email` проверяет вход.
- Сессию устанавливает сервер.
- Выход должен завершать сессию.
- Защищенные данные всегда повторно проверяются на сервере.
