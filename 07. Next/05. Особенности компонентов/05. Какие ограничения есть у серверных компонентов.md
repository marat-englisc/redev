# Ограничения серверных компонентов

> [!NOTE]
> Серверный компонент выполняется вне браузера. Он подготавливает интерфейс, но не хранит клиентское состояние и не обслуживает браузерные события.

## Вопрос

Почему в серверном компоненте нельзя использовать `useState` или `onClick` и как правильно добавить интерактивность?

## Основная идея

Клик происходит в браузере, а код серверного компонента там не выполняется. Поэтому он не может напрямую подписаться на `onClick`, читать `window` или обновлять локальный state через `useState`.

Эффекты `useEffect` и DOM-ссылки также относятся к клиентской стороне. Серверные компоненты не читают клиентский React Context: для провайдера и потребителей контекста создают клиентскую границу.

Ограничения не запрещают строить общий интерфейс. Серверный родитель может соединить серверное содержимое и клиентскую обертку через props, в том числе `children`.

## Пример: серверный текст в клиентской обертке

```tsx
// app/expandable.tsx
"use client";

import { useState, type ReactNode } from "react";

export default function Expandable({ children }: { children: ReactNode }) {
  const [open, setOpen] = useState(false);

  return (
    <section>
      <button aria-expanded={open} onClick={() => setOpen(value => !value)}>
        {open ? "Скрыть описание" : "Показать описание"}
      </button>
      {open && children}
    </section>
  );
}
```

```tsx
// app/page.tsx
import Expandable from "./expandable";

function Description() {
  return <p>Эта книга объясняет основы React на примерах.</p>;
}

export default function Page() {
  return <Expandable><Description /></Expandable>;
}
```

`Page` создает серверное содержимое `Description` и передает результат в слот `children`. `Expandable` переключает его видимость в браузере. Серверный компонент при этом не становится клиентским.

## Что важно помнить

Нельзя сохранить серверный модуль серверным, импортировав его в файл с `"use client"`. Такой импорт относится к клиентскому графу; серверные зависимости вроде доступа к файловой системе туда не подходят. Для запрещенного клиентского импорта серверный модуль можно пометить `import "server-only"`.

Обычную серверную функцию с замыканием нельзя передать как `onClick`. Для обращения к серверу используют предусмотренные интерфейсы, например Server Functions, а не переносят обработчик в серверный компонент.

Серверное содержимое примера подготавливается заранее: `open` управляет показом, а не откладывает серверную загрузку до клика.

## Мини-шпаргалка

- `useState`, эффекты, DOM и события - клиентская сторона.
- `children` позволяет вложить серверное содержимое в клиентскую обертку.
- Граф импортов определяет границы выполнения.
