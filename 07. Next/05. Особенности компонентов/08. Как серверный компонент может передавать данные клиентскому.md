# Передача данных из серверного компонента клиентскому

> [!NOTE]
> Серверный компонент передает клиентскому данные через **props**. На границе сред значения должны поддерживать сериализацию React, то есть передачу в его специальном формате.

## Вопрос

Какие значения можно передавать через серверно-клиентскую границу и как использовать их в клиентском состоянии?

## Основная идея

Сервер может получить книгу из базы и передать кнопке ее название и исходное число отметок. Браузеру не нужна вся запись базы, способ подключения или секретный ключ: только данные интерфейса.

Сериализация React шире JSON. Поддерживаются примитивы, массивы, обычные объекты с поддерживаемыми значениями, а также, например, `Date`, `Map` и `Set`. JSX и серверное содержимое через `children` тоже допускаются.

Обычные функции с замыканиями и произвольные экземпляры классов передавать нельзя. Server Functions - отдельный предусмотренный механизм передачи ссылки на серверное действие.

## Пример: начальные отметки книги

```tsx
// app/like-button.tsx
"use client";

import { useState } from "react";

type Props = { title: string; initialLikes: number };

export default function LikeButton({ title, initialLikes }: Props) {
  const [likes, setLikes] = useState(initialLikes);

  return (
    <button onClick={() => setLikes(value => value + 1)}>
      {title}: нравится {likes}
    </button>
  );
}
```

```tsx
// app/page.tsx
import LikeButton from "./like-button";

async function getBook() {
  return { id: 1, title: "Основы React", likes: 12 };
}

export default async function Page() {
  const book = await getBook();
  return <LikeButton title={book.title} initialLikes={book.likes} />;
}
```

`getBook` - учебная функция с фиксированными данными вместо базы. Кнопка начинает с `12`, затем увеличивает число локально. В браузер передаются только выбранные props, а не код функции загрузки.

## Что важно помнить

Сериализуемость не означает конфиденциальность: переданные клиенту значения доступны пользователю. Токены, пароли и закрытые поля нужно исключать до передачи.

Аргумент `useState(initialLikes)` задает начальное значение при монтировании. Если позже придут другие props, state сам по себе не переинициализируется. Для обновлений нужно заранее определить поведение интерфейса.

Клик в примере не сохраняет отметку в базе. Для сохранения потребуется серверная операция с проверкой входных данных и прав.

## Мини-шпаргалка

- Передавай данные через props.
- Используй поддерживаемые React значения, а не правило «только JSON».
- Передавай минимум открытых полей.
- Локальное состояние и серверное сохранение - отдельные задачи.
