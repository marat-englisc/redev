# Что делает директива use client

> [!NOTE]
> **`"use client"`** обозначает вход в клиентский граф модулей. Из такого файла браузер получает код для интерактивного интерфейса и его используемых зависимостей.

## Вопрос

Куда поставить директиву и почему она влияет на импортируемые модули, а не на всех визуальных потомков?

## Основная идея

Директива записывается в начале файла, перед импортами. Когда серверный компонент импортирует такой модуль, Next.js видит клиентскую границу и может отправить соответствующий JavaScript браузеру.

Компоненты и функции, которые импортируются из клиентского файла, тоже относятся к его клиентскому графу. Поэтому не нужно повторять директиву в каждом внутреннем файле. Общий модуль без серверных зависимостей может при этом использоваться и серверным, и клиентским кодом.

Иная ситуация - серверное содержимое, которое родитель передал через `children`. Оно визуально находится внутри клиентской обертки, но не становится ее клиентским импортом.

## Пример: граница вокруг счетчика

```ts
// app/format-count.ts
export function formatCount(value: number) {
  return `Выбрано книг: ${value}`;
}
```

```tsx
// app/counter.tsx
"use client";

import { useState } from "react";
import { formatCount } from "./format-count";

export default function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(value => value + 1)}>
      {formatCount(count)}
    </button>
  );
}
```

```tsx
// app/page.tsx
import Counter from "./counter";

export default function Page() {
  return <main><h1>Магазин</h1><Counter /></main>;
}
```

`Page` остается серверной. Код счетчика и используемая функция `formatCount` попадают на клиентскую сторону. После подключения React кнопка изменяет число без новой загрузки страницы.

## Что важно помнить

Директива не означает «выполнять только в браузере». При первой загрузке компонент обычно также предварительно рендерится на сервере. Доступ к `window` нужен в эффекте или обработчике.

`"use client"` не дает доступа к серверным секретам и базе данных. Модуль, предназначенный только для сервера, нельзя включать в клиентский граф.

Самостоятельному компоненту, который импортируется непосредственно из серверного файла и использует клиентские возможности, нужна собственная граница. Чем выше она расположена, тем больше зависимостей может попасть в браузер.

## Мини-шпаргалка

- Директива находится перед импортами.
- Она распространяется по используемым импортам.
- `children` не меняет серверную природу переданного содержимого.
- Начальный серверный рендеринг остается возможным.
