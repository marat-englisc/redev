# Что такое Core Web Vitals?

> [!NOTE]
> Core Web Vitals — три метрики пользовательского опыта: LCP измеряет появление крупного содержимого, INP — отзывчивость на взаимодействия, CLS — визуальную стабильность.

## Вопрос

Что измеряют LCP, INP и CLS и как читать их значения?

## Основная идея

Сайт может быстро показать заголовок, но поздно загрузить главную фотографию. Он может быстро загрузиться, но зависать при нажатиях. Поэтому метрики оценивают разные стороны использования страницы.

| Метрика | Хороший результат | Что искать при плохом значении |
| --- | --- | --- |
| LCP — Largest Contentful Paint | Не более 2,5 секунды | Медленный ответ, позднюю загрузку главного изображения |
| INP — Interaction to Next Paint | Не более 200 миллисекунд | Длинные задачи JavaScript и тяжёлые обновления интерфейса |
| CLS — Cumulative Layout Shift | Не более 0,1 | Изображения без выделенного места, поздние вставки блоков |

LCP не означает полную загрузку всех ресурсов, INP не измеряет время любого запроса к API, а CLS — безразмерная оценка смещений, не количество пикселей.

## Пример: хорошие средние значения могут скрыть проблему

Рассмотрим условные замеры LCP для двадцати загрузок, упорядоченные от быстрых к медленным:

```text
12 загрузок: 1,5 секунды
 8 загрузок: 4 секунды
```

Среднее равно 2,5 секунды, но 40% загрузок заметно медленнее целевого значения. Для оценки Core Web Vitals используют **75-й перцентиль**: показатель, ниже или на уровне которого находятся примерно 75% наблюдений. В этом примере он равен 4 секундам, поэтому LCP не проходит хороший порог.

Оценивают все три метрики, отдельно для мобильных и настольных устройств. Для INP нужны взаимодействия: если посетитель ничего не нажимал, полноценного значения может не быть.

## Как проверить в Next.js

Локально запусти production-сборку и используй Lighthouse в DevTools. Для опубликованной общедоступной страницы подойдёт PageSpeed Insights: сервис не может открыть твой `localhost`. В его отчёте различай данные реальных пользователей и лабораторный Lighthouse. При малом трафике полевых данных может не хватать.

Для поиска причин используй DevTools: Network для загрузки ресурсов и Performance для взаимодействий и смещений. Исправляй конкретную причину, затем повторяй измерение в тех же условиях.

## Что важно помнить

Один запуск на мощном ноутбуке не описывает посетителей со слабыми телефонами. Сравнивай одинаковые страницы и учитывай устройство, сеть и реальные данные. FID встречается в старых статьях; в современных Core Web Vitals его заменил INP.

## Мини-шпаргалка

- LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.
- Для полевой оценки нужен 75-й перцентиль, а не среднее.
- Лабораторный замер помогает диагностике, полевые данные показывают опыт посетителей.
