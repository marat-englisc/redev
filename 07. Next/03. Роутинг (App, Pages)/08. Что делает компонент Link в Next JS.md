# Что делает компонент Link

> [!NOTE]
> `Link` из `next/link` создает HTML-ссылку и добавляет клиентскую навигацию и предзагрузку маршрутов Next.js.

## Вопрос

Как переходить между страницами приложения и зачем использовать `Link` вместо обычной ссылки?

## Основная идея

Обычная внутренняя ссылка `<a href="/catalog">` обычно запрашивает новый HTML-документ. `Link` позволяет Next.js обработать переход внутри приложения: получить нужную часть интерфейса и обновить экран без полной перезагрузки документа.

При этом сохраняются общие layout и их состояние. Изменяемая страница может размонтироваться, поэтому обещать сохранение состояния всех компонентов нельзя.

`Link` остается настоящей ссылкой. Браузер поддерживает открытие в новой вкладке, копирование адреса и переход с клавиатуры.

## Пример: меню и динамический адрес

Предполагается, что страницы `/`, `/catalog` и `/products/[id]` существуют:

```tsx
// app/page.tsx
import Link from "next/link";

export default function HomePage() {
  const product = { id: "1", name: "Учебник React" };

  return (
    <main>
      <nav>
        <Link href="/">Главная</Link>{" "}
        <Link href="/catalog">Каталог</Link>
      </nav>
      <p>
        <Link href={`/products/${product.id}`}>{product.name}</Link>
      </p>
      <a href="https://nextjs.org/docs">Документация Next.js</a>
    </main>
  );
}
```

Нажатие «Каталог» откроет `/catalog`, а ссылка товара — `/products/1`. Для внешнего ресурса в примере использован обычный `<a>`.

## Что важно помнить

Современный `Link` **рендерит `<a>` сам**. Не вкладывай в него еще один `<a>`: получится некорректная вложенность ссылок. `className`, `target` и другие атрибуты ссылки передают прямо в `Link`.

`replace` заменяет текущую запись истории вместо добавления новой. `scroll={false}` отключает стандартное управление прокруткой при переходе. `prefetch={false}` позволяет отказаться от автоматической предзагрузки.

Для обычного перехода используй ссылку. `useRouter` нужен, когда навигация является частью действия в коде, например после успешного сохранения формы.

Переход без полной загрузки документа возможен не во всех случаях: например, между разными корневыми layout нужен новый документ.

## Мини-шпаргалка

- Импорт: `import Link from "next/link"`.
- `href` содержит адрес назначения.
- `Link` уже является HTML-ссылкой.
- Обычно он переиспользует общие части интерфейса при навигации.
