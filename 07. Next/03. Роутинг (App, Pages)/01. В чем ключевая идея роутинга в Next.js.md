# В чем ключевая идея роутинга Next.js

> [!NOTE]
> **Роутинг**, или маршрутизация, связывает адрес в браузере с нужной страницей. В Next.js эта связь в основном определяется файлами и папками проекта.

## Вопрос

Как Next.js понимает, что нужно показать по адресу `/about` или `/articles/react`?

## Основная идея

У сайта есть набор адресов. Посетитель может перейти по ссылке или сразу вставить URL в браузер. В обоих случаях приложение должно найти соответствующую страницу.

В App Router адрес строится из папок внутри `app`, а файл `page.tsx` описывает интерфейс страницы. Поэтому для добавления простого маршрута не нужно отдельно регистрировать его в массиве или компоненте маршрутизатора.

Страницы могут разделять оболочку через `layout.tsx`. Например, адреса личного кабинета используют общее меню, хотя содержимое основной области меняется.

## Пример: карта небольшого сайта

```text
app/
  layout.tsx
  page.tsx                    → /
  about/
    page.tsx                  → /about
  articles/
    [slug]/
      page.tsx                → /articles/react, /articles/next
```

```tsx
// app/page.tsx
import Link from "next/link";

export default function HomePage() {
  return (
    <main>
      <h1>Учебник frontend</h1>
      <nav>
        <Link href="/about">Об учебнике</Link>{" "}
        <Link href="/articles/react">Статья о React</Link>
      </nav>
    </main>
  );
}
```

Если создать страницы из дерева, первая ссылка откроет `/about`. Вторая попадет в шаблон `/articles/[slug]`, где значение `slug` будет равно `react`.

Квадратные скобки обозначают изменяемую часть адреса, а не буквальный текст, который должен вводить пользователь.

## Что важно помнить

Файловый роутинг и способ рендеринга решают разные задачи. Один и тот же маршрут может быть подготовлен заранее или отрендерен при запросе. Наличие `[slug]` само по себе не выбирает SSR.

Обычный файл компонента внутри `app` не становится страницей. Для UI-маршрута нужен `page.tsx`; для HTTP-ответа используют `route.ts`.

Файловая система задает основные маршруты, но Next.js также поддерживает перенаправления и переписывание адресов. Поэтому реальная схема большого проекта может быть сложнее дерева папок.

## Мини-шпаргалка

- URL определяет, какую страницу открыть.
- App Router выводит основные маршруты из структуры `app`.
- `page.tsx` описывает экран.
- Роутинг и серверный рендеринг — разные понятия.
