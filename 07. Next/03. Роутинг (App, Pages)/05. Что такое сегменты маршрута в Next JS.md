# Что такое сегменты маршрута

> [!NOTE]
> **Сегмент маршрута** — часть пути между символами `/`. В App Router обычные и динамические сегменты обычно соответствуют вложенным папкам.

## Вопрос

Из каких частей состоит `/catalog/books/42` и как получить изменяемую часть в странице?

## Основная идея

У адреса `/catalog/books/42` три сегмента: `catalog`, `books` и `42`. Первые два могут быть фиксированными папками, а последний — значением динамической папки `[id]`.

Дерево сегментов позволяет вкладывать маршруты и их интерфейсы. Например, layout для `catalog` оборачивает весь каталог, а layout для `books` — только книжный раздел.

Параметры пути и параметры строки запроса отличаются. В `/catalog/books/42?tab=reviews` значение `42` относится к пути, а `tab=reviews` задает дополнительный параметр после `?`.

## Пример: читаем оба вида параметров

```tsx
// app/catalog/books/[id]/page.tsx
export default async function BookPage({
  params,
  searchParams,
}: {
  params: Promise<{ id: string }>;
  searchParams: Promise<{ tab?: string | string[] }>;
}) {
  const { id } = await params;
  const query = await searchParams;
  const tab = Array.isArray(query.tab) ? query.tab[0] : query.tab;

  return (
    <main>
      <h1>Книга {id}</h1>
      <p>Раздел: {tab === "reviews" ? "Отзывы" : "Описание"}</p>
    </main>
  );
}
```

Открыв `/catalog/books/42?tab=reviews`, пользователь увидит «Книга 42» и «Раздел: Отзывы». Без query-параметра появится «Описание». Повторяющиеся параметры запроса могут приходить массивом, поэтому пример нормализует значение.

## Что важно помнить

В современном App Router пропсы `params` и `searchParams` — Promise. В серверной странице их читают через `await`.

`[id]` принимает один сегмент, `[...slug]` — несколько, а `[[...slug]]` допускает их отсутствие. Для catch-all значение параметра — массив строк.

Группа `(group)` и параллельный слот `@slot` помогают организовать дерево интерфейса, но не добавляют одноименную часть в URL.

Полученное из URL значение — вход пользователя. Его нужно проверять перед использованием в запросах данных. Название `id` не делает строку числом автоматически.

## Мини-шпаргалка

- `/a/b` состоит из сегментов `a` и `b`.
- `[id]` дает строку из пути через `params`.
- `?tab=reviews` читается через `searchParams`.
- Параметры не заменяют проверку данных.
