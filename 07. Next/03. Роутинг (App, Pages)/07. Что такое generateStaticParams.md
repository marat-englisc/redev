# Что такое generateStaticParams

> [!NOTE]
> `generateStaticParams` — серверная функция App Router, которая перечисляет значения динамических параметров для предварительного создания страниц.

## Вопрос

Как заранее подготовить известные статьи маршрута `/articles/[slug]`?

## Как это работает

Папка `[slug]` описывает шаблон, но не список возможных статей. `generateStaticParams` возвращает массив объектов: каждый объект задает один набор значений параметров.

Во время сборки Next.js использует этот список, чтобы подготовить соответствующие маршруты, если остальной код позволяет статический рендеринг. При наличии нескольких динамических сегментов объект должен описывать нужные значения этих сегментов.

## Пример: две заранее известные статьи

Пример для App Router без включенного `cacheComponents`:

```tsx
// app/articles/[slug]/page.tsx
import { notFound } from "next/navigation";

const articles = [
  { slug: "react", title: "Знакомство с React" },
  { slug: "next", title: "Знакомство с Next.js" },
];

export const dynamicParams = false;

export function generateStaticParams() {
  return articles.map(article => ({ slug: article.slug }));
}

export default async function ArticlePage({
  params,
}: {
  params: Promise<{ slug: string }>;
}) {
  const { slug } = await params;
  const article = articles.find(item => item.slug === slug);

  if (!article) notFound();
  return <h1>{article.title}</h1>;
}
```

Сборка подготовит `/articles/react` и `/articles/next`. `dynamicParams = false` запрещает значения вне списка, поэтому `/articles/vue` будет считаться отсутствующим маршрутом.

Учебный массив находится в том же файле: никаких скрытых функций загрузки здесь нет. В реальном проекте список можно получить из CMS или API.

## Что важно помнить

При стандартном `dynamicParams = true` дополнительные значения допускаются. Их обработка зависит от настроек и данных маршрута; не стоит автоматически называть все такие страницы SSR.

Отсутствие `generateStaticParams` также не является универсальным переключателем SSR. Способ рендеринга определяется всем маршрутом.

Функция не запускается заново при ISR-обновлении страницы. Если содержимое списка изменилось, нужно учитывать правила обработки новых путей или выполнять новую сборку.

В Pages Router для похожей задачи используют `getStaticPaths` вместе с `getStaticProps`; это другое API.

## Мини-шпаргалка

- Функция возвращает массив наборов параметров.
- Имена ключей совпадают с динамическими папками.
- `dynamicParams = false` ограничивает допустимые адреса списком.
- Предварительный список не отменяет остальных условий рендеринга.
