# Что такое динамический маршрут

> [!NOTE]
> **Динамический маршрут** содержит переменную часть пути. Один файл страницы может показывать разные ресурсы, например товары `/products/1` и `/products/2`.

## Вопрос

Как создать страницу для множества товаров, не создавая отдельный файл для каждого из них?

## Основная идея

Папка `[id]` обозначает место для одного значения. Next.js сопоставляет URL с этим шаблоном и передает значение в `params`.

Страница затем решает, какие данные соответствуют параметру. Сам роутер не знает, есть ли такой товар в базе. Поэтому нужно проверить и формат параметра, и существование нужного ресурса.

В примере ниже база заменена маленьким массивом, чтобы можно было понять весь процесс без настройки внешних сервисов.

## Пример: карточка товара

```tsx
// app/products/[id]/page.tsx
import { notFound } from "next/navigation";

const products = [
  { id: "1", name: "Учебник JavaScript", price: 900 },
  { id: "2", name: "Учебник React", price: 1200 },
];

export default async function ProductPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const product = products.find(item => item.id === id);

  if (!product) notFound();

  return (
    <main>
      <h1>{product.name}</h1>
      <p>Цена: {product.price} ₽</p>
    </main>
  );
}
```

На `/products/1` появится учебник JavaScript. На `/products/2` — учебник React. Для `/products/999` вызовется `notFound()`; собственный интерфейс можно задать в `not-found.tsx`.

В клиентском компоненте параметры пути читают через `useParams` из `next/navigation`. Пропсы серверной страницы в современном Next.js читаются через `await params`.

## Что важно помнить

Динамический **маршрут** и динамический **рендеринг** — разные понятия. `[id]` говорит, что адрес содержит параметр. Он не требует рендеринга при каждом запросе.

Заранее известные значения можно перечислить через `generateStaticParams` и подготовить страницы во время сборки. При необходимости можно настроить ISR или рендеринг при запросе.

`id` остается строкой, даже если выглядит как число. Для числового API сначала проверь формат и безопасно преобразуй значение. Для человекочитаемых адресов часто используют имя `slug`, например `/articles/first-steps`.

## Мини-шпаргалка

- `[id]` создает параметризованный сегмент.
- `await params` дает значения в серверной странице.
- Один компонент обслуживает множество URL.
- Отсутствующий ресурс обрабатывается отдельно от маршрута.
