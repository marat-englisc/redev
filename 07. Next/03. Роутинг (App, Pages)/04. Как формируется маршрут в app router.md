# Как формируется маршрут в App Router

> [!NOTE]
> URL страницы App Router получается из пути к `page.tsx` внутри `app`. Служебные имена вроде `(group)` исключаются из адреса, а `[param]` обозначает переменное значение.

## Вопрос

Как по пути файла определить адрес страницы и, наоборот, куда положить файл для нужного URL?

## Как это работает

Для обычной страницы можно пройти четыре шага:

1. Начни с папки `app` или `src/app`; ее имя в URL не включается.
2. Прочитай вложенные папки до `page.tsx`.
3. Исключи группы в круглых скобках и учти динамические сегменты.
4. Соедини части через `/`.

`page.tsx` завершает путь страницы. Layout на промежуточном уровне может оборачивать потомков, даже если на самом этом уровне нет собственной страницы.

## Пример: создаем `/shop/books`

```text
app/
  layout.tsx
  (store)/
    shop/
      layout.tsx
      books/
        page.tsx
        BookCard.tsx
```

```tsx
// app/(store)/shop/books/page.tsx
export default function BooksPage() {
  return (
    <main>
      <h1>Книги</h1>
      <p>Здесь будет список учебников.</p>
    </main>
  );
}
```

Папка `(store)` помогает организовать проект, поэтому итоговый URL — `/shop/books`. `BookCard.tsx` не создает дополнительного адреса. Если `app/(store)/shop/page.tsx` отсутствует, сам адрес `/shop` не становится страницей только из-за наличия layout.

Добавление `app/(store)/shop/books/[id]/page.tsx` даст шаблон `/shop/books/42`, где `42` — значение параметра `id`.

## Что важно помнить

Имена специальных файлов должны быть точными. `books.tsx` внутри `app/shop` не создает `/shop/books`: это правило Pages Router, а App Router требует папку `books` с `page.tsx`.

`loading.tsx`, `error.tsx`, `template.tsx` и `layout.tsx` влияют на интерфейс, но сами по себе не создают страницы. `route.ts` создает HTTP-обработчик и имеет другую роль.

Нельзя создать два разных файла страниц с одинаковым итоговым URL, даже если они находятся в разных группах. Например, `(a)/about/page.tsx` и `(b)/about/page.tsx` конфликтуют.

## Мини-шпаргалка

- `app/page.tsx` → `/`.
- `app/shop/books/page.tsx` → `/shop/books`.
- `(group)` не добавляется в адрес.
- `[id]` заменяется конкретным значением.
