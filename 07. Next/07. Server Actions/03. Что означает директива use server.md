# Директива use server

> [!NOTE]
> `"use server"` объявляет серверные функции, которые React и Next.js могут вызывать через границу между клиентом и сервером.

## Вопрос

Где писать `"use server"` и нужна ли она каждому Server Component?

## Основная идея

Директива — строка в начале файла или тела асинхронной функции. Это специальная инструкция сборщику, а не обычный вызов JavaScript.

Если поставить ее в начале отдельного модуля, его экспортируемые функции становятся серверными и должны быть асинхронными. Такой модуль можно импортировать из Client Component: браузер получит ссылку для вызова, а не реализацию с серверными зависимостями.

Директиву внутри функции можно использовать в Server Component, чтобы объявить Action рядом с формой. Создать такую встроенную Action внутри Client Component нельзя: для клиентского импорта используют отдельный модуль с директивой на уровне файла.

Обычным Server Components директива не нужна. В App Router страницы уже являются серверными по умолчанию.

## Пример: отдельный модуль с Action

Самодостаточный пример для Next.js 16 App Router. Изменяется только предпочтение текущего браузера.

```ts
// app/actions.ts
"use server";

import { cookies } from "next/headers";

export async function saveFont(formData: FormData) {
  const size = formData.get("size");
  if (size !== "normal" && size !== "large") {
    throw new Error("Недопустимый размер");
  }
  (await cookies()).set("fontSize", size, {
    path: "/",
    httpOnly: true,
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production",
  });
}
```

```tsx
// app/page.tsx
import { saveFont } from "./actions";

export default function Page() {
  return <form action={saveFont}>
    <label htmlFor="size">Размер текста</label>
    <select id="size" name="size">
      <option value="normal">Обычный</option>
      <option value="large">Крупный</option>
    </select>
    <button type="submit">Сохранить</button>
  </form>;
}
```

Action сохранит cookie. Применение размера к CSS — отдельный шаг, не включенный в пример.

## Что важно помнить

`"use server"` не создает систему доступа. Перед реальным изменением профиля, покупки или записи в базе проверяют пользователя, права и параметры внутри серверной функции.

Не экспортируй из Action-модуля обычные значения конфигурации: перенеси их в другой файл. Аргументы и результаты вызова должны поддерживать сериализацию React.

## Мини-шпаргалка

- В начале файла: серверные экспорты.
- Внутри async-функции Server Component: отдельная Action.
- Для обычного Server Component директива не требуется.
