# Вызов Server Action из Client Component

> [!NOTE]
> Client Component может импортировать Action из отдельного файла с `"use server"`. Next.js превращает такой вызов в запрос к серверу.

## Вопрос

Как вызвать серверную функцию из клиентской формы и показать результат?

## Как это работает

Клиент отвечает за интерактивность и состояние интерфейса. Action выполняет операцию на сервере. Для формы удобно использовать `useActionState`: этот хук хранит результат Action и сообщает, ожидается ли завершение запроса.

Функция для `useActionState` принимает предыдущий результат первым аргументом, а `FormData` — вторым. Ожидаемую ошибку проверки данных можно вернуть как обычный объект с сообщением.

## Пример: форма с состоянием ожидания

Создай два файла в Next.js 16 App Router. Тема сохраняется в cookie текущего браузера; защищенные записи не меняются.

```ts
// app/actions.ts
"use server";

import { cookies } from "next/headers";

export async function saveTheme(
  _previous: { message: string },
  formData: FormData
) {
  const theme = formData.get("theme");
  if (theme !== "light" && theme !== "dark") {
    return { message: "Выберите допустимую тему" };
  }
  (await cookies()).set("theme", theme, {
    path: "/",
    httpOnly: true,
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production",
  });
  return { message: "Настройка сохранена" };
}
```

```tsx
// app/ThemeForm.tsx
"use client";

import { useActionState } from "react";
import { saveTheme } from "./actions";

export default function ThemeForm() {
  const [state, formAction, pending] = useActionState(
    saveTheme,
    { message: "" }
  );

  return <form action={formAction}>
    <label htmlFor="theme">Тема</label>
    <select id="theme" name="theme">
      <option value="light">Светлая</option>
      <option value="dark">Темная</option>
    </select>
    <button type="submit" disabled={pending}>
      {pending ? "Сохраняем…" : "Сохранить"}
    </button>
    <p role="status">{state.message}</p>
  </form>;
}
```

Импортируй `ThemeForm` в `app/page.tsx` и выведи `<ThemeForm />`. Во время POST-запроса кнопка будет отключена, после ответа появится сообщение.

## Что важно помнить

Аргументы клиента недоверенные: серверная проверка нужна даже для `<select>`, ведь запрос можно подделать. Для защищенных данных внутри Action также проверяют сессию и права.

Actions можно вызывать и из обработчиков событий, но такой обработчик требует JavaScript. Гарантии прогрессивного улучшения форм нельзя переносить на любой клиентский вызов. Неожиданные серверные ошибки обрабатываются отдельно, например через `error.tsx`.

## Мини-шпаргалка

- Action импортируют из отдельного серверного модуля.
- `pending` показывает ожидание запроса.
- `useActionState` добавляет первый аргумент с предыдущим состоянием.
