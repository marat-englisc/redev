# Что такое catch-all, parallel и intercepting routes

> [!NOTE]
> Catch-all принимает несколько частей URL, parallel routes создают именованные области интерфейса, а intercepting routes позволяют показать маршрут в другом контексте при клиентском переходе.

## Вопрос

Как сделать вложенную справку или страницу, которая открывается модальным окном при переходе по ссылке?

## Основная идея

| Соглашение | Значение |
| --- | --- |
| `[id]` | Один обязательный сегмент |
| `[...slug]` | Один или несколько сегментов, значение — массив |
| `[[...slug]]` | Также допускает отсутствие сегментов |
| `@modal` | Именованный слот layout, не часть URL |
| `(.)photos` | Перехват маршрута на соответствующем уровне сегментов |

## Пример: вложенная справка

```tsx
// app/help/[[...slug]]/page.tsx — без Cache Components
export default async function Page({ params }: {
  params: Promise<{ slug?: string[] }>;
}) {
  const { slug } = await params;
  return <h1>Справка: {slug?.join(" / ") ?? "главная"}</h1>;
}
```

`/help` покажет главную справки, `/help/next/database` — «next / database». Это пока демонстрация параметров, не поиск настоящего документа.

## Пример: структура страницы с перехватом

```text
app/
  layout.tsx                  # принимает children и modal
  page.tsx                    # Link на /photos/1
  photos/[id]/page.tsx         # полная страница фотографии
  @modal/
    default.tsx               # return null для отсутствующего слота
    page.tsx                  # return null на главной
    [...catchAll]/page.tsx     # return null при уходе на другие маршруты
    (.)photos/[id]/page.tsx    # вариант содержимого внутри диалога
```

```tsx
// app/layout.tsx — альтернативный корневой layout для этой схемы
import type { ReactNode } from "react";

export default function RootLayout({ children, modal }: {
  children: ReactNode; modal: ReactNode;
}) {
  return <html lang="ru"><body>{children}{modal}</body></html>;
}
```

При переходе через `Link` Next.js может оставить исходную страницу и показать перехваченный вариант в слоте `modal`. При прямом открытии или перезагрузке `/photos/1` используется полноценная страница. Для возврата из диалога обычно используют `router.back()`.

Последняя схема — план файлов, а не готовая реализация галереи: страницы и доступный компонент диалога нужно реализовать отдельно.

## Что важно помнить

`default.tsx` задает запасное содержимое слота при полной загрузке. Без подходящего fallback можно получить 404. При мягкой навигации слоты способны сохранять активное состояние, поэтому для закрытия модального маршрута нужны соответствующие пустые страницы.

Считаются сегменты маршрута, а не буквально все папки: `@modal` не повышает уровень. Для диалога дополнительно нужны управление фокусом, закрытие клавиатурой и доступное имя.

## Мини-шпаргалка

- Catch-all дает массив частей пути.
- Parallel routes передают layout именованные slots.
- Interception различает мягкий переход и прямую загрузку.
- Для начала обычного CRUD эти механизмы необязательны.
