# Как подключать стили, изображения, шрифты и скрипты

> [!NOTE]
> Next.js предоставляет CSS Modules, `next/image`, `next/font` и `next/script`. Они помогают организовать ресурсы, но требуют подходящих размеров, порядка загрузки и проверки результата.

## Вопрос

Как оформить страницу и подключить ресурсы без случайного замедления приложения?

## Основная идея

Глобальный CSS подходит для общих правил, CSS Modules — для локальных классов компонента. Tailwind также поддерживается, но является отдельным инструментом: Next.js не требует его использования.

## Пример: карточка с локальными стилями

```css
/* app/book.module.css */
.card { padding: 1rem; border: 1px solid #ccc; border-radius: 0.5rem; }
```

```tsx
// app/page.tsx — самостоятельный пример
import Image from "next/image";
import styles from "./book.module.css";

export default function Page() {
  return <article className={styles.card}>
    <h1>Учебник Next.js</h1>
    <Image src="/book.jpg" alt="Обложка учебника" width={300} height={400} />
  </article>;
}
```

Помести свое изображение в `public/book.jpg`. Размеры позволяют выделить место заранее; для растягивающейся картинки дополнительно указывают подходящий `sizes`. Внешние изображения разрешают точными `remotePatterns` в конфигурации.

## Пример: шрифт в корневом layout

```tsx
// app/layout.tsx — самостоятельный вариант
import { Roboto } from "next/font/google";
import type { ReactNode } from "react";

const font = Roboto({ weight: "400", subsets: ["latin", "cyrillic"] });
export default function Layout({ children }: { children: ReactNode }) {
  return <html lang="ru"><body className={font.className}>{children}</body></html>;
}
```

Шрифт подготавливается при сборке и отдается приложением. Для сборки с Google-шрифтом нужен доступ к его источнику; при закрытой сети можно использовать `next/font/local` и собственный файл.

## Что важно помнить

Сторонний JavaScript подключают через `next/script` с осмысленной стратегией. `afterInteractive` подходит многим виджетам, `lazyOnload` — необязательным поздним ресурсам. Скрипт аналитики все равно расходует сеть и процессор; для некоторых продуктов также нужно учитывать согласие пользователя.

`next/image` не исправит неправильно выбранную огромную исходную картинку. Для статического экспорта стандартный серверный оптимизатор требует замены или другой настройки. Проверяй требования конкретного способа публикации.

## Мини-шпаргалка

- Общие правила — глобальный CSS, локальные классы — CSS Modules.
- Картинке нужны размеры и подходящий `sizes`.
- Шрифт подключают в общей оболочке.
- Необязательный сторонний код загружают позже.
