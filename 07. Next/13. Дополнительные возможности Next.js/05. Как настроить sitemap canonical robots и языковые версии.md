# Как настроить sitemap, canonical, robots и языковые версии

> [!NOTE]
> Метаданные помогают поисковику понять адрес и назначение страницы. Sitemap перечисляет важные публичные URL, canonical указывает предпочтительный адрес, а языковые альтернативы связывают реально существующие переводы.

## Вопрос

Что нужно для SEO помимо title и description?

## Основная идея

| Механизм | Задача |
| --- | --- |
| `alternates.canonical` | Предпочтительный URL среди эквивалентных вариантов |
| `sitemap.ts` | Список доступных для индексации публичных страниц |
| `robots.ts` | Правила обхода для поддерживающих их роботов |
| `alternates.languages` | Ссылки на языковые версии, hreflang |
| Маршрут `[lang]` | Организация самих локализованных страниц |

## Пример: публичная страница проекта

```tsx
// app/about/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  metadataBase: new URL("https://example.com"),
  title: "О проекте задач",
  alternates: { canonical: "/about" },
};
export default function Page() {
  return <h1>О проекте задач</h1>;
}
```

```ts
// app/sitemap.ts
import type { MetadataRoute } from "next";

export default function sitemap(): MetadataRoute.Sitemap {
  return [{ url: "https://example.com/about" }];
}
```

```ts
// app/robots.ts
import type { MetadataRoute } from "next";

export default function robots(): MetadataRoute.Robots {
  return {
    rules: { userAgent: "*", allow: "/", disallow: ["/api/", "/tasks"] },
    sitemap: "https://example.com/sitemap.xml",
  };
}
```

Замени `example.com` настоящим публичным доменом. В sitemap нет приватных задач. При динамическом списке публичных статей возвращают их настоящие URL и реальное время изменения, а не `new Date()` при каждом запросе.

## Что важно помнить

`robots.txt` не защищает кабинет: доступ по-прежнему проверяется сессией. Чтобы робот прочитал `noindex`, ему нельзя одновременно запрещать загрузку страницы. Canonical — сигнал предпочтения, а не обязательное перенаправление.

Для переводов нужны сами маршруты, например `/ru/about` и `/en/about`, словари интерфейса и корректный `lang` документа. Только после этого задают `alternates.languages`. Metadata API не переводит текст автоматически и не создает отсутствующие страницы.

Если используешь `[lang]`, проверяй язык по допустимому списку, учитывай fallback и адреса ссылок. Персональные данные не должны попадать в публичную sitemap даже при наличии случайно угаданного URL.

## Мини-шпаргалка

- Sitemap перечисляет публичные страницы.
- Canonical выбирает предпочтительный адрес.
- Hreflang связывает существующие переводы.
- Robots не заменяет защиту доступа.
