# Что такое CSR в Next.js

> [!NOTE]
> **CSR, Client-Side Rendering**, - вычисление интерфейса в браузере с помощью JavaScript. В Next.js оно часто дополняет начальную серверную разметку.

## Вопрос

Какая часть работы выполняется в браузере и почему `"use client"` не означает пустую страницу с сервера?

## Основная идея

Представь часы на странице. Сервер может показать заголовок и текст «Определяем время», но актуальное время браузера нужно получить после загрузки. Дальше React обновляет часы без запроса новой страницы.

Клиентские компоненты позволяют хранить состояние, реагировать на клики и обращаться к браузерным API. При первой загрузке Next.js обычно предварительно рендерит их на сервере вместе с остальной страницей. Затем браузер подключает поведение через гидратацию.

Если данные запрашиваются только внутри `useEffect`, сервер не выполняет этот эффект. Поэтому начальный HTML содержит предусмотренное разработчиком состояние загрузки, а данные появляются позднее.

## Пример: часы в браузере

```tsx
// app/clock/page.tsx
"use client";

import { useEffect, useState } from "react";

export default function Page() {
  const [time, setTime] = useState<string | null>(null);

  useEffect(() => {
    const update = () => setTime(new Date().toLocaleTimeString());
    update();
    const timer = window.setInterval(update, 1000);
    return () => window.clearInterval(timer);
  }, []);

  return (
    <main>
      <h1>Местное время</h1>
      <p>{time ?? "Определяем время…"}</p>
    </main>
  );
}
```

Первый серверный и первый клиентский рендеры одинаковы: оба показывают «Определяем время…». После запуска эффекта появляется местное время, которое обновляется каждую секунду. Функция очистки удаляет таймер при удалении компонента.

## Что важно помнить

CSR не требует делать всю страницу клиентской. Часто достаточно выделить небольшой интерактивный блок.

Контент, который загружается только в браузере, появляется позже и зависит от выполнения JavaScript. Это нужно учитывать для доступности, скорости первого отображения и индексации. Однако утверждение «все клиентские компоненты невидимы поисковикам» неверно: начальный HTML может уже содержать их содержимое.

Для рабочих запросов данных потребуются обработка ошибок и отмена устаревших запросов; библиотеки клиентского кэширования помогают управлять этим.

## Мини-шпаргалка

- CSR выполняет работу в браузере.
- `useEffect` не выполняется на сервере.
- `"use client"` допускает начальный серверный рендеринг.
- Предусматривай понятное состояние загрузки.
