# Настройка VS Code для фронтенд-разработки

> [!NOTE]
> Не нужно устанавливать все расширения подряд. Основной набор подходит почти любому проекту, а инструменты для Stylelint, Vitest, Playwright и Tailwind CSS нужны только тогда, когда соответствующая технология используется в проекте.

## Основные расширения

1. [Vue — Official](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (`Vue.volar`) — подсказки, навигация, проверка типов и форматирование Vue SFC. Для Vue 3 расширение Vetur устанавливать не нужно: оно может конфликтовать с Vue — Official.
2. [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) (`dbaeumer.vscode-eslint`) — показывает ошибки ESLint и применяет безопасные автоисправления.
3. [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) (`esbenp.prettier-vscode`) — единое форматирование JavaScript, TypeScript, Vue, HTML, CSS, JSON и Markdown.
4. [EditorConfig](https://marketplace.visualstudio.com/items?itemName=editorconfig.editorconfig) (`editorconfig.editorconfig`) — синхронизирует отступы, окончания строк и другие базовые правила между разными редакторами.

Расширения ESLint и Prettier не заменяют зависимости проекта. Для воспроизводимого результата установи `eslint` и `prettier` в `devDependencies` и храни их конфигурацию в репозитории. Если ESLint содержит стилистические правила, используй `eslint-config-prettier`, чтобы линтер и форматтер не спорили друг с другом.

## Полезные расширения по ситуации

### Удобство разработки

- [Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens) (`usernamehw.errorlens`) — выводит ошибки и предупреждения прямо возле проблемной строки.
- [Pretty TypeScript Errors](https://marketplace.visualstudio.com/items?itemName=yoavbls.pretty-ts-errors) (`yoavbls.pretty-ts-errors`) — делает длинные ошибки TypeScript более читаемыми.
- [Path Intellisense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.path-intellisense) (`christian-kohler.path-intellisense`) — дополняет пути к файлам. Для импортов JavaScript и TypeScript сначала стоит попробовать встроенные подсказки VS Code.
- [ENV](https://marketplace.visualstudio.com/items?itemName=IronGeek.vscode-env) (`IronGeek.vscode-env`) — подсветка синтаксиса файлов `.env`.

### Качество кода и тесты

- [Stylelint](https://marketplace.visualstudio.com/items?itemName=stylelint.vscode-stylelint) (`stylelint.vscode-stylelint`) — линтинг CSS, SCSS и стилей внутри Vue-компонентов.
- [Vitest](https://marketplace.visualstudio.com/items?itemName=vitest.explorer) (`vitest.explorer`) — запуск и отладка unit-тестов из панели Testing.
- [Playwright Test for VS Code](https://marketplace.visualstudio.com/items?itemName=ms-playwright.playwright) (`ms-playwright.playwright`) — запуск, запись и пошаговая отладка E2E-тестов.
- [GitLens](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens) (`eamodio.gitlens`) — история строк и файлов, blame и навигация по изменениям Git. Базовые Git-операции уже встроены в VS Code.
- [GitHub Pull Requests](https://marketplace.visualstudio.com/items?itemName=GitHub.vscode-pull-request-github) (`GitHub.vscode-pull-request-github`) — просмотр и ревью pull request без выхода из редактора.
- [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) (`bradlc.vscode-tailwindcss`) — подсказки классов и диагностика, если проект использует Tailwind CSS.

## Рекомендуемый `settings.json`

Открыть файл можно через палитру команд: `Preferences: Open User Settings (JSON)`. Пример ниже является полноценным JSON-объектом и подходит как отправная точка:

```json
{
  "editor.fontSize": 14,
  "editor.fontFamily": "JetBrains Mono, Consolas, 'Courier New', monospace",
  "editor.fontLigatures": true,
  "editor.inlayHints.fontFamily": "JetBrains Mono",
  "editor.codeLensFontFamily": "JetBrains Mono",
  "editor.quickSuggestionsDelay": 0,
  "editor.wordWrap": "bounded",
  "editor.wordWrapColumn": 100,
  "editor.rulers": [100],
  "editor.insertSpaces": true,
  "editor.tabSize": 2,
  "editor.detectIndentation": true,
  "editor.folding": true,
  "editor.stickyScroll.enabled": true,
  "editor.smoothScrolling": true,
  "editor.cursorBlinking": "expand",
  "editor.cursorSmoothCaretAnimation": "explicit",
  "editor.overtypeCursorStyle": "line-thin",
  "editor.minimap.enabled": false,
  "editor.glyphMargin": true,
  "editor.linkedEditing": true,
  "editor.colorDecorators": true,
  "editor.semanticHighlighting.enabled": true,
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": "active",
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "files.eol": "\n",
  "files.insertFinalNewline": true,
  "files.trimTrailingWhitespace": true,
  "typescript.updateImportsOnFileMove.enabled": "always",
  "javascript.updateImportsOnFileMove.enabled": "always",
  "typescript.inlayHints.parameterNames.enabled": "literals",
  "javascript.inlayHints.parameterNames.enabled": "literals",
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "typescript",
    "typescriptreact",
    "vue"
  ],
  "prettier.useEditorConfig": true,
  "debug.javascript.autoAttachFilter": "smart",
  "editor.unicodeHighlight.ambiguousCharacters": true,
  "editor.unicodeHighlight.invisibleCharacters": true,
  "editor.unicodeHighlight.allowedLocales": {
    "ru": true
  },
  "explorer.compactFolders": false,
  "scm.diffDecorations": "gutter",
  "git.autofetch": true,
  "telemetry.telemetryLevel": "off",
  "terminal.integrated.fontFamily": "JetBrains Mono",
  "terminal.integrated.fontLigatures.enabled": true,
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.cursorBlinking": true,
  "terminal.integrated.cursorStyle": "line",
  "[vue]": {
    "editor.defaultFormatter": "Vue.volar",
    "editor.formatOnSave": true
  },
  "[markdown]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.wordWrap": "on",
    "files.trimTrailingWhitespace": false
  }
}
```

Что изменено по сравнению с исходным вариантом:

- Добавлены внешние фигурные скобки — теперь фрагмент можно целиком вставить в `settings.json`.
- ESLint исправляет только собственные ошибки через `source.fixAll.eslint`, не запуская все доступные исправления без разбора.
- `editor.glyphMargin` включён, чтобы были видны точки останова, статусы тестов и другие служебные значки.
- Включена подсветка невидимых и неоднозначных Unicode-символов. Русская локаль разрешена отдельно, чтобы кириллица в документации не создавала лишний шум.
- При переименовании или перемещении файла VS Code автоматически обновляет JavaScript- и TypeScript-импорты.
- Для фронтенд-проектов выбраны два пробела. Если в команде принят другой стиль, `.editorconfig` и настройки проекта должны иметь приоритет.

## Настройки проекта

Личные параметры темы, шрифта и интерфейса лучше хранить в пользовательском `settings.json`. Общие для команды настройки форматирования и линтинга — в `.vscode/settings.json`, `.editorconfig` и конфигурациях инструментов внутри репозитория.

### Рекомендуемые расширения рабочей области

Файл `.vscode/extensions.json` позволяет VS Code предложить нужные расширения всем участникам проекта:

```json
{
  "recommendations": [
    "Vue.volar",
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "editorconfig.editorconfig",
    "DavidAnson.vscode-markdownlint",
    "yzhang.markdown-all-in-one",
    "streetsidesoftware.code-spell-checker",
    "streetsidesoftware.code-spell-checker-russian"
  ]
}
```

### Версия TypeScript из проекта

Если TypeScript установлен в `devDependencies`, открой файл `.ts` или `.vue`, выполни команду `TypeScript: Select TypeScript Version` и выбери `Use Workspace Version`. Так редактор и сборка будут использовать одну версию TypeScript.

### Профиль и синхронизация

- Создай профиль `Frontend` через `File → Preferences → Profiles`, чтобы расширения для веб-разработки не смешивались с другими наборами инструментов.
- Включи `Settings Sync`, если нужно переносить настройки, сочетания клавиш и расширения между компьютерами.
- При конфликтах расширений запусти `Help: Start Extension Bisect`: VS Code будет отключать их группами и поможет найти проблемное.

## Ошибка запуска скриптов PowerShell

Если Windows сообщает, что `npm.ps1` не может быть загружен из-за политики выполнения, сначала проверь действующие значения:

```powershell
Set-ExecutionPolicy RemoteSigned
```

## Полезные команды и сочетания клавиш

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Палитра команд | `Ctrl + Shift + P` | `Cmd + Shift + P` |
| Быстро открыть файл | `Ctrl + P` | `Cmd + P` |
| Перейти к определению | `F12` | `F12` |
| Найти все использования | `Shift + F12` | `Shift + F12` |
| Переименовать символ во всём проекте | `F2` | `F2` |
| Быстрое исправление | `Ctrl + .` | `Cmd + .` |
| Форматировать документ | `Shift + Alt + F` | `Shift + Option + F` |
| Открыть терминал | <kbd>Ctrl</kbd> + <kbd>`</kbd> | <kbd>Ctrl</kbd> + <kbd>`</kbd> |

Если подсказки Vue или TypeScript перестали обновляться, обычно помогают команды `Vue: Restart Vue and TS servers`, `TypeScript: Restart TS Server` или `Developer: Reload Window`.
