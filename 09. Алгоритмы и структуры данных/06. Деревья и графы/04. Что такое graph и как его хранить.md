# Что такое graph и как его хранить?

> [!NOTE]
> Graph - структура из вершин и ребер. Граф может быть directed/undirected, weighted/unweighted, cyclic/acyclic. В JavaScript его чаще всего хранят как adjacency list через `Map<Node, Node[]>`.

## Вопрос

Что такое граф и как его хранить: список смежности или матрица смежности?

## Термины

- Vertex/node - вершина.
- Edge - ребро.
- Directed graph - ребра имеют направление.
- Undirected graph - ребра без направления.
- Weighted graph - у ребер есть вес.
- Cycle - путь, который возвращается в уже посещенную вершину.

## Edge list

```ts
const edges: Array<[string, string]> = [
  ['A', 'B'],
  ['A', 'C'],
  ['B', 'D'],
]
```

Удобно для входных данных.

## Adjacency list

```ts
const graph = new Map<string, string[]>()

graph.set('A', ['B', 'C'])
graph.set('B', ['A', 'D'])
graph.set('C', ['A'])
graph.set('D', ['B'])
```

Чаще всего используется в задачах.

## Построение из edges

```ts
function buildGraph(edges: Array<[string, string]>): Map<string, string[]> {
  const graph = new Map<string, string[]>()

  for (const [a, b] of edges) {
    if (!graph.has(a)) graph.set(a, [])
    if (!graph.has(b)) graph.set(b, [])

    graph.get(a)!.push(b)
    graph.get(b)!.push(a)
  }

  return graph
}
```

## Matrix

Adjacency matrix:

```text
matrix[i][j] = 1, если есть ребро i -> j
```

Плюсы: быстрый check edge `O(1)`.

Минусы: память `O(V^2)`.

## Что отвечать на собеседовании?

Graph состоит из вершин и ребер. Его можно хранить как edge list, adjacency list или adjacency matrix. Для большинства JS-задач adjacency list через `Map<string, string[]>` удобнее и экономит память: `O(V + E)`. Matrix полезна, когда нужно часто проверять наличие ребра между двумя вершинами.

## Что важно помнить: частые ошибки

- Забывать добавить обе стороны в undirected graph.
- Не создавать пустой список для вершины без outgoing edges.
- Не использовать visited и уходить в цикл.
- Путать `V` и `E` в сложности.
- Использовать matrix для sparse graph без необходимости.

## Мини-шпаргалка

- Graph = vertices + edges.
- Directed - направление.
- Undirected - две стороны.
- Weighted - есть вес.
- Adjacency list - `O(V + E)`.
- Matrix - `O(V^2)`.
