# Как работают DFS и BFS для дерева?

> [!NOTE]
> DFS идет в глубину и обычно реализуется рекурсией или стеком. BFS идет по уровням и использует очередь. Для дерева оба обхода посещают каждый узел за `O(n)`, но порядок и память отличаются.

## Вопрос

Как работают DFS и BFS для дерева и чем отличаются обходы pre-order, in-order, post-order?

## DFS preorder

```ts
function preorder(root: TreeNode<number> | null, result: number[] = []): number[] {
  if (!root) return result

  result.push(root.value)
  preorder(root.left, result)
  preorder(root.right, result)

  return result
}
```

Порядок:

```text
node -> left -> right
```

## DFS inorder

```ts
function inorder(root: TreeNode<number> | null, result: number[] = []): number[] {
  if (!root) return result

  inorder(root.left, result)
  result.push(root.value)
  inorder(root.right, result)

  return result
}
```

Для BST дает значения в sorted order.

## BFS level order

```ts
function levelOrder(root: TreeNode<number> | null): number[][] {
  if (!root) return []

  const result: number[][] = []
  const queue = [root]
  let head = 0

  while (head < queue.length) {
    const levelSize = queue.length - head
    const level: number[] = []

    for (let i = 0; i < levelSize; i++) {
      const node = queue[head++]
      level.push(node.value)

      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }

    result.push(level)
  }

  return result
}
```

## Что отвечать на собеседовании?

DFS обходит дерево в глубину и подходит для рекурсивных задач: depth, path sum, validate tree. BFS обходит по уровням и использует queue: level order, minimum depth, nearest node. Оба обхода по времени `O(n)`, потому что посещают каждый узел один раз.

## Что важно помнить: частые ошибки

- Использовать `shift()` в BFS.
- Забывать base case `null`.
- Путать preorder/inorder/postorder.
- Не учитывать call stack в DFS.
- Неправильно считать `levelSize`.

## Мини-шпаргалка

- DFS - stack/recursion.
- BFS - queue.
- Preorder: node-left-right.
- Inorder: left-node-right.
- Postorder: left-right-node.
- Level order - BFS.
