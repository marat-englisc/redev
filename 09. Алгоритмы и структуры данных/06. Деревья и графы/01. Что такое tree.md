# Что такое tree?

> [!NOTE]
> Tree - иерархическая структура данных из узлов и связей parent-child. У дерева есть root, листья, высота, глубина и поддеревья. На собеседованиях чаще всего встречаются binary tree, BST и обходы DFS/BFS.

## Вопрос

Что такое tree и какие термины деревьев нужно знать?

## Базовые термины

- Root - корневой узел.
- Parent - родитель.
- Child - потомок.
- Leaf - узел без детей.
- Edge - связь между узлами.
- Depth - расстояние от root.
- Height - максимальное расстояние до листа.
- Subtree - поддерево.

## Binary tree

```ts
type TreeNode<T> = {
  value: T
  left: TreeNode<T> | null
  right: TreeNode<T> | null
}
```

У каждого узла максимум два ребенка.

## Пример обхода

```ts
function sum(root: TreeNode<number> | null): number {
  if (!root) return 0
  return root.value + sum(root.left) + sum(root.right)
}
```

Time `O(n)`, потому что посещаем каждый узел.

Space `O(h)`, где `h` - высота дерева.

## Что отвечать на собеседовании?

Tree - связная ациклическая иерархическая структура. В отличие от массива, данные организованы не линейно, а через parent-child отношения. Для binary tree каждый узел имеет максимум двух детей. Основные операции на интервью - обход, поиск глубины, проверка баланса, lowest common ancestor, работа с BST.

## Что важно помнить: частые ошибки

- Путать depth и height.
- Забывать `root = null`.
- Не учитывать recursion stack.
- Считать все деревья balanced.
- Путать tree и graph.

## Мини-шпаргалка

- Root - начало.
- Leaf - нет детей.
- Binary tree - left/right.
- Height важна для complexity.
- DFS часто рекурсивный.
- BFS идет по уровням.
