# Что такое stack?

> [!NOTE]
> Stack - структура данных по принципу LIFO: last in, first out. Последний добавленный элемент извлекается первым. В JavaScript стек удобно реализовать через `Array.push` и `Array.pop`.

## Вопрос

Что такое stack и в каких задачах он применяется?

## Пример

```ts
const stack: number[] = []

stack.push(1)
stack.push(2)
stack.push(3)

console.log(stack.pop()) // 3
console.log(stack.pop()) // 2
```

## Основные операции

| Операция | Смысл | Сложность |
| --- | --- | --- |
| `push` | добавить наверх | `O(1)` |
| `pop` | снять сверху | `O(1)` |
| `peek` | посмотреть верх | `O(1)` |
| `isEmpty` | проверить пустоту | `O(1)` |

## Generic Stack

```ts
class Stack<T> {
  private items: T[] = []

  push(value: T): void {
    this.items.push(value)
  }

  pop(): T | undefined {
    return this.items.pop()
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1]
  }

  get size(): number {
    return this.items.length
  }
}
```

## Где используется stack?

- проверка скобок;
- undo/redo;
- DFS;
- monotonic stack;
- call stack;
- парсинг выражений;
- backtracking.

## Проверка скобок

```ts
function isValid(s: string): boolean {
  const stack: string[] = []
  const pairs = new Map([
    [')', '('],
    [']', '['],
    ['}', '{'],
  ])

  for (const char of s) {
    if (!pairs.has(char)) {
      stack.push(char)
    } else if (stack.pop() !== pairs.get(char)) {
      return false
    }
  }

  return stack.length === 0
}
```

## Что отвечать на собеседовании?

Stack - LIFO-структура: последний добавленный элемент выходит первым. В JS ее обычно реализуют через массив и операции `push/pop`, которые подходят лучше, чем `unshift/shift`. Stack нужен для задач со вложенностью, откатом, DFS, скобками и монотонными структурами.

## Что важно помнить: частые ошибки

- Использовать `shift/unshift` вместо `push/pop`.
- Не проверять пустой stack.
- Путать stack и queue.
- Не учитывать память `O(n)`.
- Терять порядок при проверке скобок.

## Мини-шпаргалка

- Stack = LIFO.
- `push` добавить.
- `pop` снять.
- `peek` посмотреть.
- JS Array подходит.
- Частые задачи: brackets, DFS, undo, monotonic stack.
