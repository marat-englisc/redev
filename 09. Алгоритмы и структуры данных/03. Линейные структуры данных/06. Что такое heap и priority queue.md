# Что такое heap и priority queue?

> [!NOTE]
> Priority queue возвращает элемент с наивысшим приоритетом, а heap - популярная структура для ее реализации. В JavaScript нет встроенной priority queue, поэтому на интервью ее часто реализуют через binary heap.

## Вопрос

Что такое heap и priority queue и как их реализовать в JavaScript?

## Что такое priority queue?

Обычная очередь отдает самый старый элемент.

Priority queue отдает самый важный элемент.

Примеры:

- ближайшая вершина в Dijkstra;
- top K элементов;
- планировщик задач;
- merge K sorted lists;
- медиана потока.

## Min heap

В min heap родитель меньше или равен детям:

```text
        1
      /   \
     3     5
    / \
   7   9
```

Минимум всегда в корне.

## Индексы в массиве

Для элемента `i`:

```ts
const parent = Math.floor((i - 1) / 2)
const left = 2 * i + 1
const right = 2 * i + 2
```

## Минимальная реализация

```ts
class MinHeap {
  private heap: number[] = []

  push(value: number): void {
    this.heap.push(value)
    this.bubbleUp(this.heap.length - 1)
  }

  pop(): number | undefined {
    if (this.heap.length === 0) return undefined
    if (this.heap.length === 1) return this.heap.pop()

    const root = this.heap[0]
    this.heap[0] = this.heap.pop()!
    this.bubbleDown(0)
    return root
  }

  private bubbleUp(index: number): void {
    while (index > 0) {
      const parent = Math.floor((index - 1) / 2)
      if (this.heap[parent] <= this.heap[index]) break
      ;[this.heap[parent], this.heap[index]] = [this.heap[index], this.heap[parent]]
      index = parent
    }
  }

  private bubbleDown(index: number): void {
    while (true) {
      let smallest = index
      const left = 2 * index + 1
      const right = 2 * index + 2

      if (left < this.heap.length && this.heap[left] < this.heap[smallest]) smallest = left
      if (right < this.heap.length && this.heap[right] < this.heap[smallest]) smallest = right
      if (smallest === index) break

      ;[this.heap[index], this.heap[smallest]] = [this.heap[smallest], this.heap[index]]
      index = smallest
    }
  }
}
```

## Сложности

| Операция | Сложность |
| --- | --- |
| peek min/max | `O(1)` |
| push | `O(log n)` |
| pop | `O(log n)` |
| build heap | `O(n)` |

## Что отвечать на собеседовании?

Heap - почти полное бинарное дерево, часто хранимое в массиве. Оно позволяет быстро получить минимум или максимум. Priority queue на heap дает `push` и `pop` за `O(log n)`, `peek` за `O(1)`. В JS встроенной priority queue нет, поэтому для задач top K или Dijkstra ее реализуют вручную или используют библиотеку.

## Что важно помнить: частые ошибки

- Путать heap и binary search tree.
- Думать, что heap полностью отсортирован.
- Забывать bubble up/down.
- Ошибаться в индексах parent/children.
- Использовать сортировку после каждого push.

## Мини-шпаргалка

- Heap дает быстрый min/max.
- Min heap - минимум в корне.
- Хранится в массиве.
- Parent: `(i - 1) / 2`.
- Children: `2i + 1`, `2i + 2`.
- Push/pop - `O(log n)`.
