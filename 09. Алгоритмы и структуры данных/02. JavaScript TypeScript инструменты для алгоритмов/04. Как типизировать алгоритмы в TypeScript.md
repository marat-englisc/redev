# Как типизировать алгоритмы в TypeScript?

> [!NOTE]
> TypeScript помогает явно описывать input, output, структуры данных и generic-алгоритмы. В алгоритмах чаще всего нужны массивы, tuple-типы, `Map<K,V>`, `Set<T>`, nullable nodes, generics и comparator functions.

## Вопрос

Как типизировать алгоритмы и структуры данных в TypeScript?

## Простые типы

```ts
function sum(nums: number[]): number {
  return nums.reduce((acc, num) => acc + num, 0)
}
```

Функция явно принимает массив чисел и возвращает число.

## Tuple для ответа

```ts
function twoSum(nums: number[], target: number): [number, number] | null {
  const seen = new Map<number, number>()

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i]

    if (seen.has(need)) return [seen.get(need)!, i]
    seen.set(nums[i], i)
  }

  return null
}
```

`[number, number]` лучше, чем просто `number[]`, если ответ всегда пара.

## Node-типы

```ts
type ListNode<T> = {
  value: T
  next: ListNode<T> | null
}

type TreeNode<T> = {
  value: T
  left: TreeNode<T> | null
  right: TreeNode<T> | null
}
```

`null` явно показывает отсутствие следующего узла.

## Generic алгоритм

```ts
function first<T>(items: T[]): T | undefined {
  return items[0]
}
```

Generic сохраняет связь между входом и выходом.

## Comparator

```ts
type Comparator<T> = (a: T, b: T) => number

function minBy<T>(items: T[], compare: Comparator<T>): T | null {
  if (items.length === 0) return null

  let best = items[0]

  for (const item of items) {
    if (compare(item, best) < 0) best = item
  }

  return best
}
```

## Что отвечать на собеседовании?

В TypeScript для алгоритмов я типизирую вход и выход функции, использую tuples для фиксированных ответов, `Map<K,V>` и `Set<T>` для коллекций, nullable types для linked list/tree nodes и generics для переиспользуемых структур. Типы не меняют сложность алгоритма, но уменьшают ошибки реализации.

## Что важно помнить: частые ошибки

- Использовать `any` вместо generic.
- Возвращать `number[]`, когда нужен tuple.
- Забывать `null` для пустого списка/дерева.
- Писать `Map<any, any>`.
- Игнорировать `undefined` у `arr[0]` и `map.get`.

## Мини-шпаргалка

- `number[]` - массив чисел.
- `[number, number]` - пара.
- `T` - generic.
- `Map<K, V>` - словарь.
- `Set<T>` - множество.
- `Node | null` - nullable link.
