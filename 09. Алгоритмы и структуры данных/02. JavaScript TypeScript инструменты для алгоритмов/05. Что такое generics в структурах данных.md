# Что такое generics в структурах данных?

> [!NOTE]
> Generics позволяют писать структуры данных один раз, но сохранять тип элементов. Например, `Stack<T>` может быть стеком чисел, строк, объектов или узлов графа без потери type safety.

## Вопрос

Что такое generics в структурах данных и зачем они нужны?

## Проблема без generic

```ts
class NumberStack {
  private items: number[] = []

  push(value: number): void {
    this.items.push(value)
  }

  pop(): number | undefined {
    return this.items.pop()
  }
}
```

Работает только для чисел.

## Generic Stack

```ts
class Stack<T> {
  private items: T[] = []

  push(value: T): void {
    this.items.push(value)
  }

  pop(): T | undefined {
    return this.items.pop()
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1]
  }
}
```

Использование:

```ts
const numbers = new Stack<number>()
numbers.push(10)

const words = new Stack<string>()
words.push('hello')
```

## Generic Node

```ts
type ListNode<T> = {
  value: T
  next: ListNode<T> | null
}
```

Теперь linked list может хранить любой тип.

## Generic с constraint

```ts
function getById<T extends { id: string }>(items: T[], id: string): T | undefined {
  return items.find((item) => item.id === id)
}
```

`extends` говорит: тип может быть любым, но обязан иметь `id`.

## Что отвечать на собеседовании?

Generics нужны, чтобы структура данных была переиспользуемой и типобезопасной. `Stack<T>`, `Queue<T>`, `TreeNode<T>` или `Graph<T>` не привязаны к одному типу данных, но TypeScript все равно знает, какие значения можно добавлять и что вернется из методов.

## Что важно помнить: частые ошибки

- Использовать `any` вместо `T`.
- Создавать отдельные структуры для `number`, `string`, `User`.
- Добавлять generic, который нигде не связывает вход и выход.
- Забывать constraints, когда алгоритму нужны свойства объекта.
- Путать generic type и runtime value.

## Мини-шпаргалка

- `T` - параметр типа.
- `Stack<T>` - стек любых T.
- `T extends X` - ограничение.
- Generic сохраняет связь input/output.
- Generic исчезает в runtime.
- Type safety не меняет Big O.
