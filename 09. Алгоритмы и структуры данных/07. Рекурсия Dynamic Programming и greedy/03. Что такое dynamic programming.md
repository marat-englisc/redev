# Что такое dynamic programming?

> [!NOTE]
> Dynamic Programming, DP, - подход для задач с повторяющимися подзадачами и оптимальной подструктурой. Идея: решить каждую подзадачу один раз и переиспользовать результат.

## Вопрос

Что такое dynamic programming и как определить состояние и переходы?

## Когда нужен DP?

Два признака:

1. Overlapping subproblems - одни и те же подзадачи повторяются.
2. Optimal substructure - ответ строится из ответов меньших подзадач.

## Top-down

Memoization:

```ts
function climbStairs(n: number, memo = new Map<number, number>()): number {
  if (n <= 2) return n
  if (memo.has(n)) return memo.get(n)!

  const ways = climbStairs(n - 1, memo) + climbStairs(n - 2, memo)
  memo.set(n, ways)

  return ways
}
```

## Bottom-up

Tabulation:

```ts
function climbStairs(n: number): number {
  if (n <= 2) return n

  const dp = new Array(n + 1).fill(0)
  dp[1] = 1
  dp[2] = 2

  for (let i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2]
  }

  return dp[n]
}
```

## Space optimization

```ts
function climbStairs(n: number): number {
  if (n <= 2) return n

  let prev2 = 1
  let prev1 = 2

  for (let i = 3; i <= n; i++) {
    const current = prev1 + prev2
    prev2 = prev1
    prev1 = current
  }

  return prev1
}
```

## Что отвечать на собеседовании?

DP применяют, когда задача состоит из повторяющихся подзадач, а ответ можно построить из меньших ответов. Есть top-down подход с memoization и bottom-up подход с таблицей. Сложность обычно считается как количество states умножить на стоимость transition.

## Что важно помнить: частые ошибки

- Применять DP там, где нет повторных подзадач.
- Не определить state.
- Не определить transition.
- Не задать base cases.
- Забыть порядок заполнения bottom-up.

## Мини-шпаргалка

- State - что храним.
- Transition - как считаем.
- Base cases - старт.
- Answer - где лежит итог.
- Top-down = memo.
- Bottom-up = table.
