# Что такое backtracking?

> [!NOTE]
> Backtracking - паттерн полного перебора с откатом выбора. Он используется для permutations, combinations, subsets, задач с доской, скобками и поиском всех вариантов.

## Вопрос

Что такое backtracking и как строить перебор с откатом?

## Идея

```text
choose -> explore -> undo
```

Мы строим частичное решение, рекурсивно продолжаем, а затем откатываем выбор.

## Subsets

```ts
function subsets(nums: number[]): number[][] {
  const result: number[][] = []
  const path: number[] = []

  function dfs(index: number): void {
    if (index === nums.length) {
      result.push([...path])
      return
    }

    path.push(nums[index])
    dfs(index + 1)
    path.pop()

    dfs(index + 1)
  }

  dfs(0)
  return result
}
```

Для каждого элемента два выбора: взять или не взять.

Сложность:

```text
Time: O(2^n)
Space: O(n) без учета output
```

## Permutations

```ts
function permutations(nums: number[]): number[][] {
  const result: number[][] = []
  const path: number[] = []
  const used = new Set<number>()

  function dfs(): void {
    if (path.length === nums.length) {
      result.push([...path])
      return
    }

    for (let i = 0; i < nums.length; i++) {
      if (used.has(i)) continue

      used.add(i)
      path.push(nums[i])
      dfs()
      path.pop()
      used.delete(i)
    }
  }

  dfs()
  return result
}
```

## Что отвечать на собеседовании?

Backtracking - это DFS по дереву решений. На каждом шаге мы делаем выбор, рекурсивно исследуем последствия и откатываем выбор. Он подходит для задач, где нужно найти все комбинации, перестановки или валидные конфигурации. Сложность часто экспоненциальная, потому что мы перебираем пространство вариантов.

## Что важно помнить: частые ошибки

- Не делать копию `path` при добавлении в result.
- Забывать `pop`/undo.
- Не ставить base case.
- Не использовать pruning.
- Не учитывать экспоненциальную сложность.

## Мини-шпаргалка

- Choose.
- Explore.
- Undo.
- DFS по решениям.
- `path` хранит текущий вариант.
- `result.push([...path])`, не `path`.
- Часто `O(2^n)` или `O(n!)`.
