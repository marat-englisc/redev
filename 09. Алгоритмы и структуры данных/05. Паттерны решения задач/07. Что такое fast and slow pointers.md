# Что такое fast and slow pointers?

> [!NOTE]
> Fast and slow pointers - паттерн с двумя указателями, где один движется быстрее другого. Он часто используется для linked list: поиск середины, обнаружение цикла, определение начала цикла.

## Вопрос

Что такое fast and slow pointers и как с их помощью найти цикл в списке?

## Поиск середины linked list

```ts
type ListNode<T> = {
  value: T
  next: ListNode<T> | null
}

function middle<T>(head: ListNode<T> | null): ListNode<T> | null {
  let slow = head
  let fast = head

  while (fast && fast.next) {
    slow = slow!.next
    fast = fast.next.next
  }

  return slow
}
```

Когда `fast` дошел до конца, `slow` находится около середины.

## Detect cycle

```ts
function hasCycle<T>(head: ListNode<T> | null): boolean {
  let slow = head
  let fast = head

  while (fast && fast.next) {
    slow = slow!.next
    fast = fast.next.next

    if (slow === fast) return true
  }

  return false
}
```

Это алгоритм Floyd cycle detection.

## Когда узнавать паттерн?

- linked list;
- найти середину;
- определить cycle;
- найти начало cycle;
- удалить n-й элемент с конца;
- сравнить две половины списка.

## Что отвечать на собеседовании?

Fast and slow pointers используют два указателя с разной скоростью. Если fast двигается в два раза быстрее, то при достижении конца slow будет в середине. Если в списке есть цикл, fast рано или поздно догонит slow.

## Что важно помнить: частые ошибки

- Не проверять `fast && fast.next`.
- Сравнивать values вместо node references.
- Терять head при изменении списка.
- Не понимать, почему указатели встретятся в цикле.
- Не обрабатывать пустой список.

## Мини-шпаргалка

- Slow + fast.
- Fast часто идет по 2 шага.
- Middle list - классика.
- Cycle detection - Floyd.
- Сравнивай nodes, не values.
- Проверяй null.
