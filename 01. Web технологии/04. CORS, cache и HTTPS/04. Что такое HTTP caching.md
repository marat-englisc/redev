# Что такое HTTP caching?

> [!NOTE]
> HTTP caching позволяет browser, CDN или proxy повторно использовать response без полного запроса к серверу. Cache ускоряет интерфейс и снижает нагрузку, но требует правильных headers и стратегии invalidation.

## Вопрос

Что такое HTTP caching? Где хранятся закешированные ответы и как выбрать стратегию для статики и API?

## Где может быть cache?

```txt
Browser cache
Service Worker cache
CDN cache
Proxy cache
Backend/application cache
Database cache
```

В этом разделе речь именно об HTTP cache, которым управляют response headers.

## Зачем нужен cache?

- быстрее загрузка;
- меньше network requests;
- меньше нагрузка на API;
- стабильнее UX при медленной сети;
- дешевле CDN/static assets.

## Главный header

```http
Cache-Control: public, max-age=31536000, immutable
```

Этот header говорит, кто может кешировать response и как долго.

## Static assets

Для файлов с hash в имени:

```txt
app.8fd91c.js
styles.a12b3.css
```

можно ставить долгий cache:

```http
Cache-Control: public, max-age=31536000, immutable
```

Если файл изменится, изменится hash в имени, и browser скачает новый файл.

## API responses

Для приватных API:

```http
Cache-Control: private, max-age=60
```

Для чувствительных данных:

```http
Cache-Control: no-store
```

`no-store` особенно важен для auth responses, персональных данных и банковских страниц.

## Что важно помнить

- HTML обычно отдают с `Cache-Control: no-cache`, а hashed-ассеты — на год с `immutable`. Так пользователь быстро получает новые версии.
- Без `Cache-Control` браузер применяет эвристическое кеширование по `Last-Modified` — поведение становится непредсказуемым.
- Сбросить чужой HTTP cache с сервера нельзя: если ответ закеширован на год без hash в имени, пользователи увидят старую версию.
- Service Worker cache управляется кодом и живет отдельно от HTTP cache.

## Мини-шпаргалка

- HTTP cache управляется headers.
- Static assets с hash можно кешировать долго.
- Персональные данные нельзя бездумно public-cache-ить.
- `no-store` запрещает хранить response.
- Cache strategy должна учитывать invalidation.
