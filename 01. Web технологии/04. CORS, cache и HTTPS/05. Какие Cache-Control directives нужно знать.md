# Какие Cache-Control directives нужно знать?

> [!NOTE]
> `Cache-Control` определяет правила кеширования HTTP response. Frontend-разработчику важно понимать `max-age`, `public`, `private`, `no-store`, `no-cache`, `must-revalidate` и `immutable`.

## Вопрос

Какие директивы `Cache-Control` нужно знать? Чем `no-cache` отличается от `no-store`?

## max-age

```http
Cache-Control: max-age=3600
```

Response можно считать свежим 3600 секунд. Пока response fresh, browser может не ходить на server.

## public и private

```http
Cache-Control: public, max-age=3600
```

`public` разрешает кешировать response shared caches, например CDN.

```http
Cache-Control: private, max-age=60
```

`private` разрешает browser cache, но не shared cache. Подходит для персональных responses, если их вообще можно временно кешировать.

## no-store

```http
Cache-Control: no-store
```

Не хранить response. Используй для:

- login response;
- tokens;
- банковских данных;
- медицинских данных;
- очень чувствительных персональных данных.

## no-cache

```http
Cache-Control: no-cache
```

Название обманчивое: response можно хранить, но перед использованием нужно revalidate у server.

## immutable

```http
Cache-Control: public, max-age=31536000, immutable
```

`immutable` говорит, что ресурс не изменится в течение свежести. Хорошо для assets с content hash.

## Что важно помнить

- `s-maxage` задает срок жизни только для shared caches (CDN) и имеет приоритет над `max-age` для них.
- `stale-while-revalidate=60` позволяет отдать устаревший ответ мгновенно и обновить его в фоне — так работают многие CDN и SWR.
- `must-revalidate` запрещает отдавать устаревший ответ, если сервер недоступен.
- Директивы `Cache-Control` в request (например, `no-cache` при Ctrl+F5) — это пожелания клиента, а не правила сервера.

## Мини-шпаргалка

- `max-age` задает freshness lifetime.
- `public` можно shared-cache-ить.
- `private` только private cache, например browser.
- `no-store` не хранить вообще.
- `no-cache` хранить можно, но перед использованием проверить.
- `immutable` подходит для versioned assets.
