# Что такое HTTPS, TLS и сертификаты?

> [!NOTE]
> HTTPS - это HTTP поверх TLS. TLS шифрует соединение, проверяет подлинность сервера через сертификат и защищает данные от чтения и подмены по пути между клиентом и сервером.

## Вопрос

Что такое HTTPS и TLS? Как браузер проверяет сертификат и от чего HTTPS не защищает?

## Что дает HTTPS?

HTTPS помогает защитить:

- login/password;
- cookies;
- tokens;
- персональные данные;
- API responses;
- загружаемые scripts и assets.

Без HTTPS данные могут быть прочитаны или изменены посредником в сети.

## Что такое TLS?

TLS - криптографический протокол, который устанавливает защищенный канал.

Упрощенно:

```txt
Browser -> Server: хочу защищенное соединение
Server -> Browser: вот сертификат
Browser: проверяю сертификат
Browser + Server: договариваемся о ключах
Дальше HTTP идет внутри защищенного канала
```

## Что такое сертификат?

Сертификат связывает домен и публичный ключ сервера. Browser проверяет, что сертификат:

- выпущен доверенным Certificate Authority;
- подходит для домена;
- не истек;
- не отозван или не считается недоверенным.

## HTTPS не решает все

HTTPS защищает канал, но не исправляет:

- XSS;
- CSRF;
- SQL injection;
- плохую authorization logic;
- хранение token в небезопасном месте;
- утечку данных из frontend bundle.

## Secure cookies

Auth cookie в production должна быть `Secure`:

```http
Set-Cookie: sid=abc; HttpOnly; Secure; SameSite=Lax
```

Без `Secure` cookie может уйти по plain HTTP, если такой request возможен.

## Что важно помнить

- Бесплатные сертификаты выдает Let's Encrypt; на хостингах и CDN HTTPS часто включается автоматически.
- Цепочка доверия: сертификат сайта подписан промежуточным CA, тот — корневым, которому доверяет ОС или браузер.
- HTTPS скрывает путь, query и тело, но домен виден в DNS-запросе и SNI (если не используются DoH и ECH).
- Для локальной разработки с HTTPS удобен `mkcert`; Vite поддерживает HTTPS через плагин `@vitejs/plugin-basic-ssl`.

## Мини-шпаргалка

- HTTPS = HTTP over TLS.
- TLS шифрует канал и проверяет server identity.
- Сертификат должен подходить домену.
- HTTPS обязателен для auth и cookies.
- HTTPS не заменяет application security.
