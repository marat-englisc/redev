# Что такое preflight request?

> [!NOTE]
> Preflight - предварительный `OPTIONS` request, который browser отправляет перед некоторыми cross-origin запросами. Он проверяет, разрешает ли server настоящий method, headers и credentials.

## Вопрос

Что такое preflight request? Какие запросы считаются простыми и когда браузер отправляет `OPTIONS`?

## Когда появляется preflight?

Preflight часто появляется, если request:

- использует method не из простых, например `PATCH` или `DELETE`;
- отправляет `Authorization` header;
- отправляет custom header;
- использует не-simple `Content-Type`, например `application/json`.

## Как выглядит preflight?

```http
OPTIONS /api/orders HTTP/1.1
Origin: https://app.example.com
Access-Control-Request-Method: POST
Access-Control-Request-Headers: content-type, authorization
```

Server должен ответить:

```http
HTTP/1.1 204 No Content
Access-Control-Allow-Origin: https://app.example.com
Access-Control-Allow-Methods: GET, POST, PATCH, DELETE
Access-Control-Allow-Headers: content-type, authorization
Access-Control-Allow-Credentials: true
```

После этого browser отправит настоящий request.

## Почему request "не доходит" до backend controller?

Если preflight не прошел, настоящий request не отправится. В логах controller ты его не увидишь.

Нужно смотреть `OPTIONS` request в Network tab.

## Access-Control-Max-Age

```http
Access-Control-Max-Age: 600
```

Этот header говорит browser, сколько секунд можно кешировать результат preflight. Это уменьшает количество `OPTIONS` requests.

## Что важно помнить

- Простой запрос: метод `GET`, `HEAD` или `POST`, только «безопасные» headers и `Content-Type` из `text/plain`, `multipart/form-data`, `application/x-www-form-urlencoded`.
- Preflight выполняется без cookies и без `Authorization`, поэтому сервер не должен требовать авторизацию для `OPTIONS`.
- Chrome ограничивает `Access-Control-Max-Age` двумя часами, Firefox — сутками: большее значение будет урезано.
- Простые запросы не защищены preflight-ом, поэтому сервер всё равно обязан проверять origin и права для state-changing запросов.

## Мини-шпаргалка

- Preflight - `OPTIONS` перед настоящим request.
- Он проверяет method, headers и origin.
- Если preflight failed, основной request не уйдет.
- `Authorization` и `application/json` часто вызывают preflight.
- `Access-Control-Max-Age` кеширует preflight result.
