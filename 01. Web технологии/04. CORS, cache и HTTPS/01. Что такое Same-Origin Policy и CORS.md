# Что такое Same-Origin Policy и CORS?

> [!NOTE]
> Same-Origin Policy ограничивает доступ страницы к ресурсам другого origin. CORS - механизм на HTTP headers, с помощью которого server может разрешить browser читать cross-origin response.

## Вопрос

Что такое Same-Origin Policy? Зачем нужен CORS и от чего он защищает, а от чего — нет?

## Что такое origin?

Origin состоит из:

```txt
scheme + host + port
```

Примеры:

```txt
https://app.example.com
https://api.example.com
http://app.example.com
https://app.example.com:8443
```

Все эти origins разные, потому что отличается host, scheme или port.

## Same-Origin Policy

Browser защищает пользователя: страница с одного origin не должна свободно читать данные другого origin.

Иначе вредный сайт мог бы сделать:

```ts
fetch('https://bank.example.com/api/me', {
  credentials: 'include',
});
```

и прочитать приватные данные, если пользователь залогинен в банк.

## Что делает CORS?

CORS позволяет server явно сказать:

```http
Access-Control-Allow-Origin: https://app.example.com
```

Это значит: browser может отдать JavaScript-коду response, если request пришел с `https://app.example.com`.

Важно: CORS проверяет browser. Это не полноценная backend-авторизация.

## CORS не защищает API от всех клиентов

Postman, curl, backend services и mobile clients не обязаны соблюдать browser CORS.

```bash
curl https://api.example.com/private
```

Поэтому CORS нельзя использовать вместо authentication и authorization.

## Что важно помнить

- SOP не запрещает отправлять запросы: формы, картинки и скрипты с других origins загружаются. Он запрещает JS читать чужие ответы.
- Ошибка CORS в консоли означает, что запрос мог дойти до сервера и выполниться — заблокировано только чтение ответа.
- Самый частый способ обойти CORS в разработке — proxy в dev-сервере (Vite `server.proxy`) или BFF на том же origin.
- Загружать скрипты с CDN можно без CORS, но для `crossorigin`-атрибута, шрифтов и `canvas` нужны CORS-headers.

## Мини-шпаргалка

- Origin = scheme + host + port.
- Same-Origin Policy - browser security boundary.
- CORS разрешает browser читать cross-origin response.
- `Access-Control-Allow-Origin` должен быть выставлен сервером.
- CORS не заменяет auth.
