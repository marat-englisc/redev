# Как браузер строит страницу?

> [!NOTE]
> Browser превращает HTML, CSS и JavaScript в отображаемую страницу: строит DOM, CSSOM, render tree, считает layout, рисует pixels и выполняет scripts. Понимание этого помогает оптимизировать загрузку и избегать блокировок.

## Вопрос

Из каких этапов состоит рендеринг страницы в браузере (critical rendering path)?

## Главные этапы

```txt
HTML -> DOM
CSS -> CSSOM
DOM + CSSOM -> Render Tree
Render Tree -> Layout
Layout -> Paint
Paint -> Composite
```

## DOM

HTML превращается в DOM tree:

```html
<main>
  <h1>Hello</h1>
</main>
```

```txt
Document
  main
    h1
      "Hello"
```

## CSSOM

CSS превращается в CSSOM. Browser должен понять, какие styles применить к каким nodes.

```css
h1 {
  color: red;
}
```

## Render tree и layout

Render tree содержит видимые элементы и их styles. Потом browser считает размеры и позиции.

Layout отвечает на вопросы:

- где находится элемент;
- какой у него размер;
- как влияют fonts, images, viewport;
- что переносится на следующую строку.

## Paint и composite

Paint рисует visual parts: text, colors, borders, shadows. Composite собирает layers в итоговую картинку.

## Как JavaScript влияет?

JavaScript может:

- менять DOM;
- менять classes/styles;
- читать layout;
- блокировать parsing;
- запускать дополнительные fetch requests.

Поэтому большие scripts и частые layout reads/writes могут тормозить страницу.

## Что важно помнить

- Элементы с `display: none` не попадают в render tree, а с `visibility: hidden` попадают и занимают место.
- Анимация `transform` и `opacity` выполняется на этапе composite, без layout и paint, поэтому она плавная.
- Чтение геометрии (`offsetHeight`, `getBoundingClientRect`) после изменения стилей вызывает принудительный синхронный layout (layout thrashing).
- Производительность рендеринга удобно смотреть во вкладке Performance в DevTools.

## Мини-шпаргалка

- HTML строит DOM.
- CSS строит CSSOM.
- DOM + CSSOM дают render tree.
- Layout считает геометрию.
- Paint рисует.
- JavaScript может блокировать и менять почти все этапы.
