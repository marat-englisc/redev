# Что такое CROSS JOIN и декартово произведение

> [!NOTE]
> **Декартово произведение** — все возможные пары строк двух наборов: 100 × 1000 = 100 000 строк. `CROSS JOIN` строит его явно, без условия. Полезные применения: сетка «все комбинации» (размеры × цвета), календарная сетка «каждый день × каждый магазин» для отчётов без пропусков (вместе с `generate_series`), присоединение одной строки с параметрами или константами. Случайное декартово произведение — частый баг: старый синтаксис `FROM a, b` без `WHERE`, забытое или неверное `ON`. Признак — взрывной рост числа строк и времени выполнения.

## Вопрос

Что такое `CROSS JOIN` и когда декартово произведение полезно?

## Синтаксис

```sql
SELECT s.size, c.color
FROM sizes s
CROSS JOIN colors c;
-- S red, S blue, M red, M blue, ...

-- эквивалентно
SELECT s.size, c.color FROM sizes s, colors c;
SELECT s.size, c.color FROM sizes s JOIN colors c ON true;
```

## Отчёт без пропусков

```sql
-- выручка по каждому магазину за каждый день, включая дни без продаж
SELECT d.day::date, st.id AS store_id, COALESCE(sum(o.total), 0) AS revenue
FROM generate_series('2026-10-01'::date, '2026-10-31'::date, interval '1 day') AS d(day)
CROSS JOIN stores st
LEFT JOIN orders o
  ON o.store_id = st.id
 AND o.created_at >= d.day
 AND o.created_at <  d.day + interval '1 day'
GROUP BY d.day, st.id
ORDER BY d.day, st.id;
```

Без сетки дни без продаж просто пропадут из результата, и графики на фронтенде «склеят» соседние точки.

## Одна строка с параметрами

```sql
WITH params AS (SELECT 0.2 AS vat, now() - interval '30 days' AS since)
SELECT o.id, o.total * (1 + p.vat) AS total_with_vat
FROM orders o
CROSS JOIN params p
WHERE o.created_at >= p.since;
```

## Случайное декартово произведение

```sql
-- ✗ забыто условие между orders и users
SELECT * FROM orders o, users u WHERE o.status = 'paid';

-- ✗ условие соединяет не те столбцы
JOIN users u ON u.id = u.id
```

Признаки: число строк = произведение размеров таблиц, в `EXPLAIN` — `Nested Loop` без условия соединения.

## Частые ошибки

- Синтаксис через запятую, где легко забыть условие.
- `CROSS JOIN` двух больших таблиц.
- Строить календарную сетку в коде приложения, когда её проще сделать `generate_series`.

## Что важно помнить

- Размер результата `CROSS JOIN` = произведение размеров входов.
- Полезен для сеток комбинаций и отчётов без пропусков.
- Используйте явный синтаксис `JOIN ... ON` — так случайное произведение заметнее.

## Мини-шпаргалка

- `a CROSS JOIN b`.
- `generate_series(start, end, step)` + `CROSS JOIN` + `LEFT JOIN`.
- Одна строка параметров — безопасный `CROSS JOIN`.
- `FROM a, b` без условия — баг.
