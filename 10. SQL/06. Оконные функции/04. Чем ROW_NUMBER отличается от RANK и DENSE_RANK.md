# Чем ROW_NUMBER отличается от RANK и DENSE_RANK

> [!NOTE]
> Все три функции нумеруют строки по `ORDER BY` окна, но по-разному обрабатывают **равные значения**. `row_number()` даёт уникальные номера 1, 2, 3 — для равных строк порядок произвольный, если не добавить tie-breaker. `rank()` даёт равным одинаковый ранг и **пропускает** следующие: 1, 1, 3. `dense_rank()` — одинаковый ранг **без пропусков**: 1, 1, 2. Выбор зависит от задачи: ровно N строк на группу — `row_number`; «все, кто на первых N местах, включая делящих место» — `rank`/`dense_rank`; «N-е по величине уникальное значение» — `dense_rank`.

## Вопрос

Чем отличаются `ROW_NUMBER`, `RANK` и `DENSE_RANK`?

## Пример

```sql
SELECT name, score,
       row_number() OVER (ORDER BY score DESC) AS row_number,
       rank()       OVER (ORDER BY score DESC) AS rank,
       dense_rank() OVER (ORDER BY score DESC) AS dense_rank
FROM players;
```

```text
name  | score | row_number | rank | dense_rank
Anna  | 100   | 1          | 1    | 1
Ivan  | 100   | 2          | 1    | 1
Olga  | 90    | 3          | 3    | 2
Petr  | 80    | 4          | 4    | 3
```

## Когда что

| Задача | Функция |
| --- | --- |
| Ровно один (последний) заказ на пользователя | `row_number() = 1` |
| Пагинация, дедупликация | `row_number()` |
| Призовые места с делёжкой (два вторых места, затем четвёртое) | `rank()` |
| Вторая по величине зарплата / N-я уникальная цена | `dense_rank()` |

## Классическая задача: вторая по величине зарплата

```sql
SELECT DISTINCT salary
FROM (
  SELECT salary, dense_rank() OVER (ORDER BY salary DESC) AS dr
  FROM employees
) t
WHERE dr = 2;
```

С `row_number()` при двух одинаковых максимальных зарплатах «второй» окажется та же максимальная.

## Детерминированность row_number

```sql
-- ✗ при равных created_at номер может меняться между запусками
row_number() OVER (PARTITION BY user_id ORDER BY created_at DESC)

-- ✓ уникальный tie-breaker
row_number() OVER (PARTITION BY user_id ORDER BY created_at DESC, id DESC)
```

## Другие ранжирующие функции

| Функция | Что возвращает |
| --- | --- |
| `ntile(4)` | Номер квартиля (1–4) — разбить на N примерно равных корзин |
| `percent_rank()` | Относительный ранг от 0 до 1 |
| `cume_dist()` | Доля строк со значением ≤ текущего |

```sql
SELECT user_id, revenue, ntile(10) OVER (ORDER BY revenue DESC) AS decile FROM user_revenue;
```

Применение задач «top N в каждой группе» — в уроке [top N per group](<07. Как решить top N per group.md>).

## Частые ошибки

- `row_number` для задач с равными значениями, где нужны все «делящие место».
- `rank` для «N-го уникального значения» — из-за пропусков ранга N может не существовать.
- Нет tie-breaker у `row_number` — недетерминированный результат.

## Что важно помнить

- `row_number` — всегда уникален.
- `rank` — равные делят место, дальше пропуск.
- `dense_rank` — равные делят место, без пропусков.

## Мини-шпаргалка

- 1, 2, 3, 4 — `row_number`.
- 1, 1, 3, 4 — `rank`.
- 1, 1, 2, 3 — `dense_rank`.
- `ntile(n)` — корзины.
