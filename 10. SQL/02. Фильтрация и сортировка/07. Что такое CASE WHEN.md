# Что такое CASE WHEN

> [!NOTE]
> `CASE` — условное **выражение** SQL (аналог тернарного оператора или `switch`), которое возвращает значение. Две формы: **поисковая** `CASE WHEN условие THEN значение … ELSE значение END` и **простая** `CASE выражение WHEN значение THEN … END`. Ветки проверяются по порядку, срабатывает первая истинная; без `ELSE` результат — `NULL`. Все ветки должны возвращать совместимый тип. `CASE` используют в `SELECT` (категоризация), в агрегатах (условные счётчики — хотя в PostgreSQL удобнее `FILTER`), в `ORDER BY` (свой порядок) и в `UPDATE` (разные значения для разных строк за один запрос).

## Вопрос

Что такое `CASE WHEN` и где его использовать?

## Поисковая форма

```sql
SELECT
  id,
  total,
  CASE
    WHEN total >= 10000 THEN 'large'
    WHEN total >= 1000  THEN 'medium'
    ELSE 'small'
  END AS order_size
FROM orders;
```

Порядок важен: при `total = 15000` сработает первая ветка, хотя вторая тоже истинна.

## Простая форма

```sql
SELECT
  CASE status
    WHEN 'new'       THEN 'Новый'
    WHEN 'paid'      THEN 'Оплачен'
    WHEN 'cancelled' THEN 'Отменён'
    ELSE 'Неизвестно'
  END AS status_label
FROM orders;
```

Простая форма сравнивает через `=`, поэтому `WHEN NULL` никогда не сработает — для `NULL` нужна поисковая форма с `IS NULL`.

## Условные агрегаты

```sql
SELECT
  count(*)                                          AS total,
  count(*) FILTER (WHERE status = 'paid')           AS paid,          -- PostgreSQL
  sum(CASE WHEN status = 'paid' THEN total ELSE 0 END) AS paid_revenue  -- переносимо
FROM orders;
```

## Свой порядок сортировки

```sql
SELECT * FROM tasks
ORDER BY
  CASE priority WHEN 'critical' THEN 1 WHEN 'high' THEN 2 WHEN 'normal' THEN 3 ELSE 4 END,
  created_at;
```

## UPDATE с CASE

```sql
UPDATE products
SET price = CASE
  WHEN category = 'electronics' THEN price * 0.9
  WHEN category = 'books'       THEN price * 0.95
  ELSE price
END
WHERE category IN ('electronics', 'books');
```

Один проход по таблице вместо нескольких `UPDATE`.

## Безопасное деление

```sql
SELECT CASE WHEN visits = 0 THEN 0 ELSE orders::numeric / visits END AS conversion FROM stats;
-- короче: orders::numeric / NULLIF(visits, 0)
```

## Похожие функции

| Функция | Что делает |
| --- | --- |
| `COALESCE(a, b, c)` | Первое не-`NULL` значение |
| `NULLIF(a, b)` | `NULL`, если `a = b`, иначе `a` |
| `GREATEST(a, b)`, `LEAST(a, b)` | Максимум и минимум из аргументов |

## Частые ошибки

- Забыть `END` или `ELSE` (неожиданные `NULL`).
- Разные типы в ветках (`THEN 1 ... ELSE 'n/a'`) — ошибка.
- `CASE x WHEN NULL` — никогда не срабатывает.
- Длинные `CASE` с бизнес-логикой, которые лучше вынести в справочную таблицу.

## Что важно помнить

- `CASE` — выражение, возвращающее значение, а не управляющая конструкция.
- Срабатывает первая истинная ветка, без `ELSE` — `NULL`.
- Для условных агрегатов в PostgreSQL читабельнее `FILTER`.

## Мини-шпаргалка

- `CASE WHEN cond THEN v ... ELSE v END`.
- `CASE expr WHEN val THEN v ... END`.
- В `SELECT`, агрегатах, `ORDER BY`, `UPDATE`.
- `COALESCE`, `NULLIF`, `GREATEST`, `LEAST`.
