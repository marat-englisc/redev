# Что такое Matter.js и физические движки

> [!NOTE]
> Физический движок моделирует **твёрдые тела**: массу, трение, упругость, вращение, стопки и сочленения (шарниры, пружины, цепи) — всё то, что сложно и долго писать самому. **Matter.js** — самый популярный 2D-движок на чистом JS: `Engine` считает физику, `Bodies` создаёт тела (прямоугольник, круг, многоугольник), `Composite.add` добавляет их в мир, `Runner` запускает шаги симуляции, а встроенный `Render` годится для отладки. В настоящей игре Matter обычно отвечает только за физику, а рисуют тела PixiJS или canvas — синхронизируя `sprite.position` и `rotation` с `body` каждый кадр. Для высокой производительности и детерминизма используют **Rapier** (Rust → WebAssembly, 2D и 3D) или **Planck.js** (порт Box2D).

## Вопрос

Что такое физический движок, как работать с Matter.js и когда стоит взять движок вместо своей физики?

## Своя физика или движок

| Своя (уроки выше) | Физический движок |
| --- | --- |
| платформер, аркада, шутер | падающие стопки ящиков, «Angry Birds», рэгдоллы |
| AABB и круги без вращения | вращение тел, произвольные многоугольники |
| полный контроль над «ощущением» управления | реалистичное поведение «из коробки» |
| мало кода, быстро | больше зависимостей, нужно настраивать |

Для управляемого персонажа платформера реалистичная физика часто мешает: он скользит, падает, вращается. Поэтому персонажа пишут вручную, а движок используют для окружения.

## Hello, Matter.js

```bash
npm i matter-js
npm i -D @types/matter-js
```

```ts
import Matter from 'matter-js';

const { Engine, Render, Runner, Bodies, Composite, Mouse, MouseConstraint } = Matter;

const engine = Engine.create();             // гравитация по умолчанию: y = 1
const render = Render.create({
  element: document.body,
  engine,
  options: { width: 800, height: 600, wireframes: false, background: '#0f172a' },
});

const ground = Bodies.rectangle(400, 590, 810, 20, { isStatic: true });
const box = Bodies.rectangle(400, 200, 80, 80, { restitution: 0.3, friction: 0.5 });
const ball = Bodies.circle(450, 50, 30, { restitution: 0.9, render: { fillStyle: '#f97316' } });
const triangle = Bodies.polygon(300, 100, 3, 40);

Composite.add(engine.world, [ground, box, ball, triangle]);

// перетаскивание мышью — удобно для отладки
const mouse = Mouse.create(render.canvas);
Composite.add(engine.world, MouseConstraint.create(engine, { mouse }));

Render.run(render);
Runner.run(Runner.create(), engine);        // шаги симуляции на rAF
```

Координаты тела в Matter — **центр** (в отличие от левого верхнего угла canvas), углы — в радианах.

## Свойства тел

```ts
Bodies.rectangle(x, y, w, h, {
  isStatic: true,          // не двигается (пол, стены)
  isSensor: true,          // не сталкивается, только события (зона подбора, триггер)
  restitution: 0.8,        // упругость: 0 — без отскока, 1 — без потерь
  friction: 0.1,           // трение о поверхности
  frictionAir: 0.02,       // сопротивление воздуха
  density: 0.002,          // плотность → масса
  chamfer: { radius: 8 },  // скруглённые углы
  label: 'crate',          // для событий
  collisionFilter: { category: 0x0002, mask: 0x0001 }, // кто с кем сталкивается
});

Matter.Body.setVelocity(ball, { x: 5, y: -10 });
Matter.Body.applyForce(box, box.position, { x: 0.05, y: 0 });  // толкнуть
Matter.Body.setAngularVelocity(box, 0.2);
Matter.Body.setPosition(box, { x: 100, y: 100 });               // телепорт
```

## События столкновений

```ts
Matter.Events.on(engine, 'collisionStart', (event) => {
  for (const { bodyA, bodyB } of event.pairs) {
    const labels = [bodyA.label, bodyB.label];
    if (labels.includes('bird') && labels.includes('pig')) {
      const pig = bodyA.label === 'pig' ? bodyA : bodyB;
      Composite.remove(engine.world, pig);
      addScore(500);
    }
  }
});
```

## Сочленения

```ts
import { Constraint, Composites } from 'matter-js';

// маятник: точка в мире + тело
const pendulum = Constraint.create({ pointA: { x: 400, y: 50 }, bodyB: ball, length: 200, stiffness: 1 });

// пружина между телами
const spring = Constraint.create({ bodyA: box, bodyB: ball, stiffness: 0.02, damping: 0.05 });

// цепь/мост из прямоугольников
const bridge = Composites.stack(200, 300, 10, 1, 5, 0, (x: number, y: number) =>
  Bodies.rectangle(x, y, 40, 15));
Composites.chain(bridge, 0.5, 0, -0.5, 0, { stiffness: 0.9, length: 2 });

Composite.add(engine.world, [pendulum, spring, bridge]);
```

## Matter.js + PixiJS: физика отдельно, отрисовка отдельно

```ts
import { Application, Sprite, Assets } from 'pixi.js';
import Matter from 'matter-js';

const app = new Application();
await app.init({ resizeTo: window });
document.body.appendChild(app.canvas);

const engine = Matter.Engine.create();
const crateTex = await Assets.load('/crate.png');

const links: { body: Matter.Body; sprite: Sprite }[] = [];

function addCrate(x: number, y: number) {
  const body = Matter.Bodies.rectangle(x, y, 64, 64);
  const sprite = new Sprite(crateTex);
  sprite.anchor.set(0.5);                 // центр — как в Matter
  sprite.setSize(64, 64);
  Matter.Composite.add(engine.world, body);
  app.stage.addChild(sprite);
  links.push({ body, sprite });
}

Matter.Composite.add(engine.world, Matter.Bodies.rectangle(400, 700, 2000, 40, { isStatic: true }));
for (let i = 0; i < 20; i++) addCrate(300 + Math.random() * 200, -i * 70);

app.ticker.add((t) => {
  Matter.Engine.update(engine, Math.min(t.deltaMS, 1000 / 30)); // шаг в мс, с ограничением
  for (const { body, sprite } of links) {
    sprite.position.set(body.position.x, body.position.y);
    sprite.rotation = body.angle;
  }
});
```

Для стабильной симуляции лучше фиксированный шаг (`Engine.update(engine, 1000 / 60)` в аккумуляторе) — см. урок про delta time.

## Другие движки

| Движок | Особенности |
| --- | --- |
| **Matter.js** | чистый JS, простой API, много примеров; не самый быстрый |
| **Rapier** (`@dimforge/rapier2d`, `rapier3d`) | Rust + WASM, очень быстрый, детерминизм, 2D и 3D, используется в R3F (`@react-three/rapier`) |
| **Planck.js** | порт Box2D на JS — проверенная классика, стабильные стопки |
| **cannon-es**, **Ammo.js**, **Jolt (WASM)** | 3D-физика для Three.js/Babylon.js |
| **Phaser Arcade** | не движок твёрдых тел, а быстрые AABB — для аркад |

```ts
// Rapier 2D — для сравнения API
import RAPIER from '@dimforge/rapier2d-compat';
await RAPIER.init();
const world = new RAPIER.World({ x: 0, y: 9.81 });
const body = world.createRigidBody(RAPIER.RigidBodyDesc.dynamic().setTranslation(0, 5));
world.createCollider(RAPIER.ColliderDesc.cuboid(0.5, 0.5), body);
world.step();                                   // шаг
const { x, y } = body.translation();
```

Rapier работает в метрах, поэтому при отрисовке координаты умножают на масштаб (например, 1 м = 50 px).

## Частые ошибки

- Двигать тело через `body.position.x = …` — нарушает симуляцию; используйте `Body.setPosition`/`setVelocity`.
- Путать центр тела (Matter) и левый верхний угол (canvas/Pixi без `anchor`).
- Передавать в `Engine.update` огромный `delta` после паузы — тела проваливаются сквозь пол.
- Делать игрока платформера полностью физическим телом без настроек — скользит и переворачивается (`inertia: Infinity` запрещает вращение).
- Оставлять встроенный `Render` в продакшене — он для отладки.

## Что важно помнить

- Физический движок нужен для вращающихся тел, стопок, сочленений и реалистичного поведения.
- Matter.js: `Engine`, `Bodies`, `Composite.add`, `Runner`/`Engine.update`, `Events.on('collisionStart')`.
- Физика отдельно, отрисовка отдельно: синхронизация `position`/`angle` каждый кадр.
- Для скорости и детерминизма — Rapier, для классики Box2D — Planck.js.

## Мини-шпаргалка

```ts
const engine = Engine.create();
Composite.add(engine.world, [Bodies.rectangle(x, y, w, h, { isStatic: true }), Bodies.circle(x, y, r)]);
Engine.update(engine, 1000 / 60);
sprite.position.set(body.position.x, body.position.y); sprite.rotation = body.angle;
Events.on(engine, 'collisionStart', (e) => e.pairs);
```
