# Что такое Three.js и как сделать 3D-сцену

> [!NOTE]
> **Three.js** — самая популярная библиотека для 3D в браузере поверх WebGL (и WebGPU через `WebGPURenderer`). Любая сцена состоит из четырёх частей: **`Scene`** — контейнер объектов, **`Camera`** (обычно `PerspectiveCamera`) — откуда смотрим, **`Renderer`** — рисует сцену камерой в `<canvas>`, и **объекты** — чаще всего `Mesh` = **геометрия** (форма: `BoxGeometry`, `SphereGeometry`, загруженная модель) + **материал** (как поверхность реагирует на свет: `MeshStandardMaterial`). Для материалов с освещением нужны **источники света**. Анимация — в цикле `renderer.setAnimationLoop`, время — `THREE.Clock`. Модели загружают в формате **glTF/GLB** через `GLTFLoader`, управление камерой мышью — `OrbitControls`.

## Вопрос

Что такое Three.js и из чего состоит 3D-сцена? Как создать объект, осветить его и анимировать?

## Минимальная сцена

```bash
npm i three
npm i -D @types/three
```

```ts
import * as THREE from 'three';

// 1. сцена
const scene = new THREE.Scene();
scene.background = new THREE.Color('#0f172a');

// 2. камера: угол обзора, пропорции, ближняя и дальняя плоскости отсечения
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 100);
camera.position.set(3, 2, 5);
camera.lookAt(0, 0, 0);

// 3. рендерер
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
document.body.appendChild(renderer.domElement);

// 4. объект: геометрия + материал
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: '#38bdf8', roughness: 0.4, metalness: 0.1 }),
);
scene.add(cube);

// 5. свет — без него MeshStandardMaterial чёрный
scene.add(new THREE.AmbientLight(0xffffff, 0.4));       // равномерная подсветка
const sun = new THREE.DirectionalLight(0xffffff, 2);    // направленный, как солнце
sun.position.set(5, 10, 7);
scene.add(sun);

// 6. цикл
const clock = new THREE.Clock();
renderer.setAnimationLoop(() => {
  const dt = clock.getDelta();          // секунды с прошлого кадра
  cube.rotation.x += 0.5 * dt;
  cube.rotation.y += 1.0 * dt;
  renderer.render(scene, camera);
});

// ресайз
addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();       // обязательно после изменения параметров камеры
  renderer.setSize(innerWidth, innerHeight);
});
```

## Геометрии и материалы

| Геометрия | Материал |
| --- | --- |
| `BoxGeometry`, `SphereGeometry`, `PlaneGeometry` | `MeshBasicMaterial` — без света, просто цвет/текстура |
| `CylinderGeometry`, `ConeGeometry`, `TorusGeometry` | `MeshLambertMaterial` — дешёвый матовый |
| `CapsuleGeometry` — удобна для персонажа | `MeshStandardMaterial` — PBR: `roughness`, `metalness` |
| `BufferGeometry` — своя форма из вершин | `MeshPhysicalMaterial` — стекло, лак, ткань |

```ts
const loader = new THREE.TextureLoader();
const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(20, 20),
  new THREE.MeshStandardMaterial({ map: loader.load('/textures/grass.jpg') }),
);
floor.rotation.x = -Math.PI / 2;       // плоскость по умолчанию вертикальная
scene.add(floor);
```

## Управление камерой и модели

```ts
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;              // плавность; в цикле: controls.update()

const gltf = await new GLTFLoader().loadAsync('/models/robot.glb');
scene.add(gltf.scene);

// анимации из модели
const mixer = new THREE.AnimationMixer(gltf.scene);
mixer.clipAction(gltf.animations[0]).play();
// в цикле: mixer.update(dt)
```

glTF/GLB — «JPEG для 3D»: модели из Blender экспортируют в него. Сжатие геометрии — Draco/Meshopt, текстур — KTX2.

## Клик по объекту: Raycaster

```ts
const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

renderer.domElement.addEventListener('pointerdown', (e) => {
  // экран → нормализованные координаты -1..1
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);

  const [hit] = raycaster.intersectObjects(scene.children, true);
  if (hit) (hit.object as THREE.Mesh).material = new THREE.MeshStandardMaterial({ color: 'tomato' });
});
```

Это 3D-аналог hit testing из урока про canvas.

## Производительность

- Переиспользуйте геометрии и материалы: 1000 одинаковых кубов → `InstancedMesh` (один draw call).
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`.
- Удаляя объекты, вызывайте `geometry.dispose()`, `material.dispose()`, `texture.dispose()` — память GPU не освобождается сама.
- Тени и пост-обработка дорогие — включайте точечно.

```ts
const count = 1000;
const instanced = new THREE.InstancedMesh(new THREE.BoxGeometry(), new THREE.MeshStandardMaterial(), count);
const m = new THREE.Matrix4();
for (let i = 0; i < count; i++) {
  m.setPosition(Math.random() * 20 - 10, Math.random() * 20 - 10, Math.random() * 20 - 10);
  instanced.setMatrixAt(i, m);
}
scene.add(instanced);
```

## Частые ошибки

- Нет света при `MeshStandardMaterial` — объект чёрный.
- Забыть `camera.updateProjectionMatrix()` после изменения `aspect` — картинка растянута.
- Камера внутри объекта или объект за `far`-плоскостью — «ничего не видно». Проверьте `camera.position` и `lookAt`.
- Создавать новые геометрии/материалы в цикле.
- Не вызывать `dispose()` при удалении — утечка памяти GPU.

## Что важно помнить

- Scene + Camera + Renderer + Mesh (Geometry + Material) + Light.
- Цикл — `renderer.setAnimationLoop`, время — `Clock.getDelta()`.
- Модели — glTF/GLB через `GLTFLoader`, камера — `OrbitControls`.
- Клик по 3D-объекту — `Raycaster`.
- Много одинаковых объектов — `InstancedMesh`, удаление — `dispose()`.

## Мини-шпаргалка

```ts
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, w / h, 0.1, 100);
const renderer = new THREE.WebGLRenderer(); document.body.append(renderer.domElement);
scene.add(new THREE.Mesh(new THREE.BoxGeometry(), new THREE.MeshStandardMaterial()));
renderer.setAnimationLoop(() => renderer.render(scene, camera));
```
