# Container — свойства, дети, границы и события

> [!NOTE]
> `Container` — базовый класс всего, что есть на сцене: `Sprite`, `Graphics`, `Text`, `AnimatedSprite` наследуют его свойства. Это **трансформация** (`position`, `scale`, `rotation`/`angle`, `skew`, `pivot`, `origin`), **отображение** (`alpha`, `visible`, `renderable`, `tint`, `blendMode`, `zIndex`), **дети** (`addChild`, `removeChild`, `getChildByLabel`, `setChildIndex`, `reparentChild`), **границы и координаты** (`getBounds`, `getLocalBounds`, `toLocal`, `toGlobal`, `getGlobalPosition`, `width`/`height`, `setSize`), **эффекты** (`mask`, `filters`, `cacheAsTexture`), **события жизненного цикла** (`added`, `removed`, `childAdded`, `destroyed`) и хук `onRender`, вызываемый перед каждой отрисовкой. Большинство свойств можно передать сразу в конструктор: `new Container({ x, y, label, children })`.

## Вопрос

Какие свойства и методы есть у `Container` в PixiJS v8 и как ими пользоваться?

## Конструктор с опциями

```ts
import { Container, Sprite } from 'pixi.js';

const enemy = new Container({
  label: 'enemy',
  x: 200,
  y: 100,
  scale: 1.5,
  rotation: 0.2,
  alpha: 0.9,
  zIndex: 10,
  children: [new Sprite(bodyTex), new Sprite(gunTex)],
});
```

Это же работает для `Sprite`, `Graphics`, `Text`: `new Sprite({ texture, anchor: 0.5, x: 100 })`.

## Трансформация

| Свойство | Тип | Описание |
| --- | --- | --- |
| `x`, `y`, `position` | `number`, `ObservablePoint` | позиция относительно родителя |
| `scale` | `ObservablePoint` | масштаб; `scale = 2` или `scale.set(2, 1)`; отрицательный — отражение |
| `rotation` / `angle` | радианы / градусы | поворот |
| `skew` | `ObservablePoint` | наклон в радианах |
| `pivot` | `ObservablePoint` | точка в локальных пикселях, вокруг которой вращение/масштаб; **сдвигает** объект |
| `origin` | `ObservablePoint` | как pivot, но **не сдвигает** позицию (экспериментальное, v8.x) |
| `width`, `height` | `number` | размер в пикселях (меняет `scale`) |
| `setSize(w, h?)` / `getSize()` | | задать/получить размер за один вызов |
| `localTransform`, `worldTransform` | `Matrix` | локальная и итоговая матрицы |
| `setFromMatrix(m)` | | задать трансформацию из матрицы |

```ts
card.pivot.set(card.width / 2, card.height / 2);  // вращать вокруг центра
card.position.set(400, 300);                      // позиция центра (pivot)
card.angle = 15;

panel.setSize(300, 200);
const { width, height } = panel.getSize();
```

## Отображение

| Свойство | Описание |
| --- | --- |
| `alpha` | прозрачность 0..1, умножается на родительскую |
| `visible` | `false` — не рисуется, не обновляет трансформацию, не ловит события |
| `renderable` | `false` — не рисуется, но трансформация и границы считаются |
| `tint` | цвет-множитель, наследуется детьми |
| `blendMode` | `'normal'`, `'add'`, `'multiply'`, `'screen'`, … |
| `zIndex` | порядок внутри родителя при `sortableChildren = true` |
| `sortableChildren` | сортировать детей по `zIndex` |
| `cullable` / `cullableChildren` / `cullArea` | участие в culling (с `CullerPlugin`) |
| `label` | имя для поиска и отладки (в v7 было `name`) |

## Работа с детьми

| Метод | Назначение |
| --- | --- |
| `addChild(...children)` | добавить в конец (сверху); возвращает первого ребёнка |
| `addChildAt(child, index)` | вставить на позицию |
| `removeChild(...children)` | убрать |
| `removeChildAt(index)` / `removeChildren(begin?, end?)` | по индексу / диапазону (все, если без аргументов) |
| `removeFromParent()` | убрать себя из родителя |
| `getChildAt(i)`, `getChildIndex(c)`, `setChildIndex(c, i)` | индексы |
| `swapChildren(a, b)` | поменять местами |
| `getChildByLabel(label, deep?)` | найти по `label` (`deep = true` — рекурсивно) |
| `getChildrenByLabel(label \| RegExp, deep?)` | найти всех |
| `reparentChild(child)` | перенести в этот контейнер, **сохранив** положение на экране |
| `replaceChild(old, new)` | заменить на той же позиции |
| `children` | массив детей (не изменяйте напрямую) |
| `parent` | родитель |

```ts
const ui = app.stage.getChildByLabel('ui');
const enemies = world.getChildrenByLabel(/^enemy/, true);

// подобранный предмет «прыгает» из мира в инвентарь, не меняя положение на экране
inventory.reparentChild(item);
gsap.to(item, { x: slot.x, y: slot.y, duration: 0.3 });

world.removeChildren().forEach((c) => c.destroy()); // очистить уровень
```

## Границы и координаты

| Метод | Результат |
| --- | --- |
| `getBounds()` | `Bounds` в глобальных координатах (с учётом всех трансформаций и детей) |
| `getLocalBounds()` | границы в собственных координатах |
| `getFastGlobalBounds()` | более быстрый и менее точный вариант |
| `boundsArea` | задать границы вручную (`Rectangle`) — экономит вычисления |
| `toGlobal(point)` | локальная точка → экран |
| `toLocal(point, from?)` | экранная (или из другого контейнера) → локальная |
| `getGlobalPosition()` | позиция на экране |
| `getGlobalAlpha()`, `getGlobalTint()` | итоговые alpha и tint |

```ts
const b = enemy.getBounds();               // { x, y, width, height, minX, maxX, … }
const r = b.rectangle;                     // как Rectangle

const muzzle = gun.toGlobal({ x: 30, y: 0 });               // где дуло на экране
const local = world.toLocal(e.global);                      // клик → координаты мира
const inUi = ui.toLocal({ x: 0, y: 0 }, enemy);             // из системы enemy в систему ui
```

`getBounds()` для больших деревьев дорогой; в игровой логике используйте свои хитбоксы.

## События жизненного цикла

```ts
sprite.on('added', (parent) => console.log('добавлен в', parent.label));
sprite.on('removed', (parent) => {});
sprite.on('destroyed', () => cleanupSubscriptions());
container.on('childAdded', (child, container, index) => {});
container.on('childRemoved', (child, container, index) => {});
```

## onRender

```ts
// вызывается перед каждой отрисовкой объекта — удобно для простых «живых» объектов
coin.onRender = () => {
  coin.rotation += 0.05;
};
coin.onRender = null;    // отключить
```

Для игровой логики с `dt` всё же лучше ticker: `onRender` не получает время и не вызывается у невидимых объектов.

## Эффекты

```ts
container.mask = maskGraphics;                  // маска
container.filters = [new BlurFilter()];         // фильтры
container.cacheAsTexture(true);                 // запечь в текстуру
container.updateCacheTexture();                 // перезапечь после изменений
container.cacheAsTexture({ resolution: 2, antialias: true });
container.isRenderGroup = true;                 // отдельная render group — трансформации на GPU
```

**Render group** — контейнер, трансформация которого применяется на GPU целиком. Для мира, который двигается камерой целиком (сотни тысяч статичных спрайтов), это ускоряет каждый кадр: пересчитывается одна матрица, а не все дети.

## Уничтожение

```ts
container.destroy();                                         // только сам контейнер
container.destroy({ children: true });                      // с детьми
container.destroy({ children: true, texture: true, textureSource: true }); // и их текстуры
```

## Частые ошибки

- Менять массив `children` напрямую (`children.push`) — сцена не узнает об изменении; используйте `addChild`.
- Путать `pivot` (сдвигает объект) и `anchor` у Sprite (нормированный, только для текстуры).
- Использовать `name` и `getChildByName` из v7 — в v8 `label` и `getChildByLabel`.
- Вызывать `getBounds()` для сотен объектов каждый кадр.
- `visible = false` для объекта, у которого нужно считать границы, — используйте `renderable = false`.

## Что важно помнить

- Container — основа всех объектов: трансформация, отображение, дети, границы, эффекты.
- Опции можно передать в конструктор, включая `children`.
- `label` + `getChildByLabel` для поиска, `reparentChild` — перенос с сохранением позиции.
- `toLocal`/`toGlobal` — перевод координат, `getBounds` — дорого.
- `isRenderGroup` и `cacheAsTexture` — для больших статичных групп.

## Мини-шпаргалка

```ts
new Container({ label: 'world', x, y, children: [a, b] });
c.addChild(a); c.removeChild(a); a.removeFromParent();
c.getChildByLabel('player', true); c.reparentChild(item);
c.toLocal(e.global); c.toGlobal({ x: 0, y: 0 }); c.getBounds();
c.on('added', () => {}); c.onRender = () => {};
```
