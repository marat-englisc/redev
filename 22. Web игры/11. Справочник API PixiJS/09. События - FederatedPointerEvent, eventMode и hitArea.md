# События — FederatedPointerEvent, eventMode и hitArea

> [!NOTE]
> Система событий PixiJS повторяет DOM: события **всплывают** от объекта к `stage`, есть `stopPropagation()`, `target` и `currentTarget`, подписка — `on`/`once`/`off` (или `addEventListener`). Объект участвует в событиях, если у него подходящий **`eventMode`**: `'static'` для обычных интерактивных объектов, `'dynamic'` для движущихся под неподвижным курсором, `'passive'`/`'auto'` — не ловить самому, `'none'` — исключить из проверок вместе с детьми. Обработчик получает **`FederatedPointerEvent`**: `global` (координаты на экране), `getLocalPosition(container)`, `button`, `pointerId`, `pointerType`, модификаторы `shiftKey`/`ctrlKey`, `nativeEvent`. Форму зоны нажатия задаёт **`hitArea`** (`Rectangle`, `Circle`, `Polygon`), курсор — `cursor`. Для перетаскивания и событий вне объекта есть `globalpointermove`, `pointerupoutside`.

## Вопрос

Какие события, свойства и режимы есть в системе событий PixiJS v8 и как с ними работать?

## Свойства интерактивного объекта

| Свойство | Описание |
| --- | --- |
| `eventMode` | `'none'` \| `'passive'` \| `'auto'` \| `'static'` \| `'dynamic'` |
| `cursor` | CSS-курсор при наведении: `'pointer'`, `'grab'`, `'crosshair'`… |
| `hitArea` | своя зона попадания (`Rectangle`, `Circle`, `Ellipse`, `Polygon`, `RoundedRectangle` или объект с `contains(x, y)`) |
| `interactiveChildren` | `false` — не проверять детей (ускорение) |
| `onpointerdown`, `onclick`… | свойства-обработчики (альтернатива `on`) |

## Список событий

| Группа | События |
| --- | --- |
| Pointer (мышь + тач + перо) | `pointerdown`, `pointerup`, `pointerupoutside`, `pointermove`, `pointerover`, `pointerout`, `pointerenter`, `pointerleave`, `pointercancel`, `pointertap` |
| Глобальное движение | `globalpointermove`, `globalmousemove`, `globaltouchmove` — при любом движении, даже вне объекта |
| Мышь | `mousedown`, `mouseup`, `mousemove`, `mouseover`, `mouseout`, `click`, `rightdown`, `rightup`, `rightclick`, `mouseupoutside`, `rightupoutside` |
| Тач | `touchstart`, `touchend`, `touchmove`, `touchcancel`, `tap`, `touchendoutside` |
| Колесо | `wheel` (`FederatedWheelEvent`: `deltaX`, `deltaY`, `deltaMode`) |

Обычно хватает pointer-событий: один код для мыши и касаний.

## Поля FederatedPointerEvent

| Поле | Что содержит |
| --- | --- |
| `global` (`globalX`, `globalY`) | координаты в системе `stage` (экран Pixi) |
| `client`, `screen`, `page`, `offset` | координаты в системах DOM |
| `getLocalPosition(container)` | координаты в системе нужного контейнера |
| `movement` (`movementX/Y`) | смещение с прошлого события |
| `button`, `buttons` | какая кнопка: 0 — левая, 1 — средняя, 2 — правая |
| `pointerId`, `pointerType`, `isPrimary` | мультитач: id пальца, `'mouse'`/`'touch'`/`'pen'` |
| `pressure`, `tiltX`, `tiltY`, `twist` | данные пера |
| `altKey`, `ctrlKey`, `shiftKey`, `metaKey` | модификаторы |
| `target`, `currentTarget` | исходный объект и текущий в цепочке всплытия |
| `detail` | счётчик кликов (2 — двойной клик) |
| `nativeEvent` | исходное DOM-событие |
| `stopPropagation()`, `stopImmediatePropagation()`, `preventDefault()` | управление всплытием |

## Примеры

```ts
import { Rectangle, Circle } from 'pixi.js';

button.eventMode = 'static';
button.cursor = 'pointer';
button.on('pointertap', (e) => {
  if (e.button !== 0) return;                 // только левая кнопка
  sound.play('click');
});

// двойной клик
tile.on('pointertap', (e) => { if (e.detail === 2) openTile(tile); });

// правый клик: контекстное меню игры
app.canvas.addEventListener('contextmenu', (e) => e.preventDefault());
unit.on('rightclick', (e) => showUnitMenu(e.global));

// позиция клика внутри объекта
map.on('pointerdown', (e) => {
  const p = e.getLocalPosition(map);
  const col = Math.floor(p.x / TILE), row = Math.floor(p.y / TILE);
  placeTower(col, row);
});

// своя зона нажатия
coin.hitArea = new Circle(0, 0, 20);
smallButton.hitArea = new Rectangle(-24, -24, 48, 48);   // минимум ~44px для пальца
```

## Глобальные события на stage

```ts
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;              // ловить события на пустых местах

app.stage.on('pointermove', (e) => crosshair.position.copyFrom(e.global));
app.stage.on('wheel', (e) => {
  world.scale.set(Math.max(0.5, Math.min(3, world.scale.x * (e.deltaY > 0 ? 0.9 : 1.1))));
});
```

## Перетаскивание

```ts
function makeDraggable(obj: Container) {
  obj.eventMode = 'static';
  obj.cursor = 'grab';
  let offset = { x: 0, y: 0 };

  const onMove = (e: FederatedPointerEvent) => {
    const p = e.getLocalPosition(obj.parent!);
    obj.position.set(p.x - offset.x, p.y - offset.y);
  };
  const onUp = () => {
    obj.cursor = 'grab';
    app.stage.off('globalpointermove', onMove);
    app.stage.off('pointerup', onUp).off('pointerupoutside', onUp);
  };

  obj.on('pointerdown', (e) => {
    const p = e.getLocalPosition(obj.parent!);
    offset = { x: p.x - obj.x, y: p.y - obj.y };
    obj.cursor = 'grabbing';
    app.stage.on('globalpointermove', onMove);
    app.stage.on('pointerup', onUp).on('pointerupoutside', onUp);
  });
}
```

## Мультитач

```ts
const touches = new Map<number, Point>();
app.stage.on('pointerdown', (e) => touches.set(e.pointerId, e.global.clone()));
app.stage.on('pointermove', (e) => touches.get(e.pointerId)?.copyFrom(e.global));
app.stage.on('pointerup', (e) => touches.delete(e.pointerId));
app.stage.on('pointerupoutside', (e) => touches.delete(e.pointerId));
// два пальца — pinch-zoom по расстоянию между ними
```

## Производительность событий

```ts
// декорации и частицы — без проверок попадания
decor.eventMode = 'none';
uiPanel.interactiveChildren = false;        // панель целиком — одна зона

// отключить ненужные возможности системы событий
await app.init({ eventFeatures: { move: true, globalMove: false, click: true, wheel: false } });
```

Каждое `pointermove` заставляет PixiJS обходить дерево интерактивных объектов. Тысячи объектов с `eventMode = 'static'` — заметная нагрузка.

## Клавиатура

Клавиатуру система событий PixiJS не обрабатывает — используйте `window.addEventListener('keydown')` (урок про клавиатуру в canvas-части раздела).

## Частые ошибки

- Нет `eventMode` — события не приходят (по умолчанию `'passive'`).
- Использовать `interactive = true` и `buttonMode` из v7.
- Брать `e.global` как координаты мира при сдвинутой камере — нужно `e.getLocalPosition(world)`.
- Хранить ссылку на `e.global` после обработчика — объект события переиспользуется; копируйте `e.global.clone()`.
- Слушать `pointermove` на объекте для drag — при быстром движении курсор «соскакивает»; нужен `globalpointermove`.

## Что важно помнить

- События как в DOM: всплытие, `target`, `stopPropagation`.
- `eventMode = 'static'` + `cursor` + `hitArea`.
- `e.global` — экран, `e.getLocalPosition(container)` — локальные координаты.
- Drag — `globalpointermove` + `pointerup`/`pointerupoutside` на stage.
- `eventMode = 'none'` и `interactiveChildren = false` для производительности.

## Мини-шпаргалка

```ts
obj.eventMode = 'static'; obj.cursor = 'pointer'; obj.hitArea = new Circle(0, 0, 20);
obj.on('pointertap', (e) => e.getLocalPosition(world));
app.stage.eventMode = 'static'; app.stage.hitArea = app.screen;
app.stage.on('globalpointermove', onMove);
e.stopPropagation(); e.global.clone();
```
