# Маски, blendMode, фильтры и culling

> [!NOTE]
> Четыре механизма, которые меняют, **что и как** рисуется. **Маска** (`mask` или `setMask({ mask, inverse })`) ограничивает видимую область: `Graphics` — векторная маска через stencil-буфер, `Sprite` — альфа-маска по прозрачности текстуры; `inverse: true` показывает всё, кроме маски. **`blendMode`** задаёт смешивание с фоном: базовые `'normal'`, `'add'`, `'multiply'`, `'screen'`, `'erase'`, а сложные (`'overlay'`, `'color-dodge'`, `'difference'`…) требуют `import 'pixi.js/advanced-blend-modes'`. **Фильтры** (`filters = [...]`) — шейдерные эффекты: встроенные `AlphaFilter`, `BlurFilter`, `ColorMatrixFilter`, `DisplacementFilter`, `NoiseFilter`, свои через `Filter.from` и десятки готовых в `pixi-filters`. **Culling** не рисует объекты вне экрана: `cullable = true` + `CullerPlugin` или ручной `Culler.shared.cull(container, view)`.

## Вопрос

Как в PixiJS v8 работают маски, режимы наложения, фильтры и culling, и какие у них настройки?

## Маски

```ts
import { Graphics, Sprite } from 'pixi.js';

// векторная маска — окно круглой формы
const circleMask = new Graphics().circle(0, 0, 80).fill(0xffffff);
portrait.addChild(circleMask);       // маска двигается вместе с объектом
portrait.mask = circleMask;

// альфа-маска по текстуре — мягкие края, сложные формы
const softMask = new Sprite(Assets.get('vignette'));
scene.addChild(softMask);
scene.mask = softMask;

// инвертированная маска: «дырка» в тумане войны
fog.setMask({ mask: visionCircle, inverse: true });

// снять
portrait.mask = null;
```

| Тип маски | Как работает | Особенности |
| --- | --- | --- |
| `Graphics` | stencil-буфер | чёткие края, дёшево, можно вкладывать |
| `Sprite` | альфа-канал текстуры | мягкие края, дороже (отдельный проход) |
| `inverse: true` | наоборот | для «окон» и вырезов |

Цвет `fill` у маски не важен — учитывается только форма (или альфа для Sprite).

## blendMode

```ts
fireParticle.blendMode = 'add';      // свечение, огонь
shadow.blendMode = 'multiply';       // тень затемняет фон
lightRays.blendMode = 'screen';      // мягкое осветление
eraser.blendMode = 'erase';          // стирает под собой (вместе с RenderTexture — «ластик»)
```

| Базовые (без импорта) | Продвинутые (`import 'pixi.js/advanced-blend-modes'`) |
| --- | --- |
| `normal`, `add`, `multiply`, `screen`, `erase`, `none`, `min`, `max`, `normal-npm`, `add-npm`, `screen-npm`, `inherit` | `overlay`, `darken`, `lighten`, `color-dodge`, `color-burn`, `hard-light`, `soft-light`, `difference`, `exclusion`, `saturation`, `color`, `luminosity`, `linear-burn`, `linear-dodge`, `linear-light`, `pin-light`, `vivid-light`, `hard-mix`, `negation`, `subtract`, `divide` |

Базовые режимы — просто настройки смешивания GPU и почти бесплатны (но разные режимы прерывают батч). Продвинутые реализованы фильтрами — дороже.

## Фильтры

```ts
import { BlurFilter, ColorMatrixFilter, AlphaFilter, NoiseFilter, DisplacementFilter } from 'pixi.js';

world.filters = [new BlurFilter({ strength: 6, quality: 4 })];

const cm = new ColorMatrixFilter();
cm.desaturate();                       // чёрно-белое
cm.brightness(1.3, true);              // true — умножить на текущую матрицу (комбинировать эффекты)
cm.hue(45, true);
cm.contrast(0.4, true);
cm.reset();

ui.filters = [new AlphaFilter({ alpha: 0.5 })];  // прозрачность группы без «просвечивания» перекрытий
photo.filters = [new NoiseFilter({ noise: 0.2 })];
```

| Фильтр | Основные параметры |
| --- | --- |
| `BlurFilter` | `strength`, `quality`, `kernelSize`; `strengthX`/`strengthY` |
| `ColorMatrixFilter` | методы `desaturate`, `grayscale`, `blackAndWhite`, `brightness`, `contrast`, `saturate`, `hue`, `tint`, `sepia`, `negative`, `night`, `vintage`, `polaroid`, `technicolor`, `kodachrome`, `lsd`, `reset` |
| `AlphaFilter` | `alpha` |
| `NoiseFilter` | `noise`, `seed` |
| `DisplacementFilter` | `sprite` (карта смещения), `scale` |

Общие опции фильтров: `resolution` (можно `'inherit'` или меньше 1 для экономии), `padding` (запас по краям для размытия и свечения), `antialias`, `blendMode`.

```ts
const blur = new BlurFilter({ strength: 8 });
blur.resolution = 0.5;          // размытие в половинном разрешении — почти не видно, вдвое дешевле
blur.padding = 20;              // не обрезать края размытия
container.filterArea = new Rectangle(0, 0, 400, 300); // ограничить область обработки
```

## Свой фильтр

```ts
import { Filter, defaultFilterVert } from 'pixi.js';

const pixelate = Filter.from({
  gl: {
    vertex: defaultFilterVert,
    fragment: `
      in vec2 vTextureCoord;
      out vec4 finalColor;
      uniform sampler2D uTexture;
      uniform vec2 uBlock;            // размер «пикселя» в UV
      void main() {
        vec2 uv = floor(vTextureCoord / uBlock) * uBlock;
        finalColor = texture(uTexture, uv);
      }
    `,
  },
  resources: {
    pixelUniforms: { uBlock: { value: [0.01, 0.01], type: 'vec2<f32>' } },
  },
});

world.filters = [pixelate];
pixelate.resources.pixelUniforms.uniforms.uBlock = [0.02, 0.02];
```

Для поддержки WebGPU в `Filter.from` добавляют `gpu: { vertex, fragment }` с кодом на WGSL. Готовые фильтры `pixi-filters` (`GlowFilter`, `OutlineFilter`, `CRTFilter`, `AdvancedBloomFilter`, `DropShadowFilter`, `PixelateFilter`, `ShockwaveFilter`, `GodrayFilter`…) уже поддерживают оба рендерера.

## Culling

```ts
import { extensions, CullerPlugin, Culler, Rectangle } from 'pixi.js';

// вариант 1: автоматически перед каждым рендером Application
extensions.add(CullerPlugin);
world.cullableChildren = true;
for (const tile of tiles) tile.cullable = true;

// своя область вместо вычисления границ (быстрее)
tile.cullArea = new Rectangle(0, 0, 32, 32);

// вариант 2: вручную, например в своём цикле
Culler.shared.cull(world, app.renderer.screen);
app.renderer.render(app.stage);
```

| Свойство | Описание |
| --- | --- |
| `cullable` | объект может быть скрыт, если вне экрана |
| `cullableChildren` | проверять ли детей |
| `cullArea` | заранее заданный прямоугольник вместо `getBounds()` |
| `culled` | результат: был ли объект отброшен в последнем кадре |

Culling экономит отрисовку, но сам требует вычисления границ. Для огромных миров эффективнее хранить объекты по чанкам и добавлять на сцену только видимые.

## Что дорого, а что нет

| Механизм | Стоимость |
| --- | --- |
| `tint`, `alpha`, базовый `blendMode` | почти бесплатно |
| Маска `Graphics` | дёшево (stencil), но прерывает батч |
| Маска `Sprite` | дополнительный проход |
| Фильтр | проход рендера на каждый фильтр, прерывает батч |
| Продвинутый `blendMode` | фильтр с чтением фона |
| Culling | вычисление границ каждого `cullable`-объекта |

## Частые ошибки

- Не добавить маску на сцену (`addChild`) — она не обновляет трансформацию и ведёт себя странно.
- Использовать `'overlay'` без импорта `pixi.js/advanced-blend-modes` — режим не применяется.
- Создавать фильтр каждый кадр вместо изменения параметров существующего.
- Повесить фильтр на каждый спрайт вместо общего контейнера.
- Включить `cullable`, но не подключить `CullerPlugin` и не вызывать `Culler` — ничего не отбрасывается.

## Что важно помнить

- `mask` / `setMask({ mask, inverse })`: Graphics — stencil, Sprite — альфа.
- Базовые blend modes дешёвые; продвинутые — через импорт и дороже.
- `filters = [...]`, общие опции `resolution`, `padding`, `filterArea`; свои — `Filter.from`.
- Culling: `cullable` + `CullerPlugin` или `Culler.shared.cull`.

## Мини-шпаргалка

```ts
obj.mask = graphics; obj.setMask({ mask: g, inverse: true });
sprite.blendMode = 'add'; import 'pixi.js/advanced-blend-modes';
c.filters = [new BlurFilter({ strength: 4 })]; c.filterArea = rect;
extensions.add(CullerPlugin); sprite.cullable = true;
```
