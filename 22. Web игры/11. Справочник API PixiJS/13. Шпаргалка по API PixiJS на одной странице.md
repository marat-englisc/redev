# Шпаргалка по API PixiJS на одной странице

> [!NOTE]
> Самое нужное из PixiJS v8 в одном месте. Приложение: `new Application()` + `await app.init({ resizeTo, background })`, `app.canvas` в DOM, объекты в `app.stage`, логика в `app.ticker.add((t) => …)`. Ресурсы: `await Assets.load()` / `loadBundle()`. Объекты: `Sprite`, `AnimatedSprite`, `TilingSprite`, `NineSliceSprite`, `Graphics` (фигура → `fill`/`stroke`), `Text`/`BitmapText`, `Container` для групп, `ParticleContainer` для тысяч частиц. Ввод: `eventMode = 'static'` + `on('pointertap')`. Эффекты: `tint`, `alpha`, `blendMode`, `mask`, `filters`. Производительность: атласы, пулы, `cacheAsTexture`, culling, `BitmapText`. Отрисовка в текстуру: `RenderTexture` + `renderer.render`, скриншот — `renderer.extract`.

## Вопрос

Какие классы и вызовы PixiJS v8 используются чаще всего?

## Приложение

```ts
import { Application } from 'pixi.js';

const app = new Application();
await app.init({
  resizeTo: window, background: '#0f172a', antialias: true,
  resolution: Math.min(devicePixelRatio, 2), autoDensity: true, preference: 'webgpu',
});
document.body.appendChild(app.canvas);

app.screen.width; app.renderer.name;            // 'webgl' | 'webgpu'
app.ticker.add((t) => update(t.deltaMS / 1000));
app.stop(); app.start(); app.render();
app.destroy({ removeView: true }, { children: true });
```

## Объекты

```ts

new Sprite({ texture, anchor: 0.5, x, y });
```

## Трансформация и отображение

| Что | Как |
| --- | --- |
| Позиция | `obj.x`, `obj.position.set(x, y)` |
| Масштаб, отражение | `obj.scale.set(2)`, `obj.scale.x = -1` |
| Поворот | `obj.rotation` (рад), `obj.angle` (град) |
| Точка привязки | `sprite.anchor.set(0.5)`, `container.pivot.set(px, py)` |
| Размер | `obj.width = 64`, `obj.setSize(64, 32)` |
| Прозрачность, видимость | `obj.alpha`, `obj.visible`, `obj.renderable` |
| Цвет | `obj.tint = 0xff0000` |
| Наложение | `obj.blendMode = 'add'` |
| Порядок | `parent.sortableChildren = true; obj.zIndex = 10` |

## v7 → v8

| v7 | v8 |
| --- | --- |
| `new Application({...})` | `new Application(); await app.init({...})` |
| `app.view` | `app.canvas` |
| `beginFill(c).drawRect(...).endFill()` | `rect(...).fill(c)` |
| `lineStyle(w, c)` | `.stroke({ width, color })` |
| `new Text('hi', style)` | `new Text({ text: 'hi', style })` |
| `interactive = true`, `buttonMode` | `eventMode = 'static'`, `cursor = 'pointer'` |
| `ticker.add((delta) => …)` | `ticker.add((ticker) => ticker.deltaTime)` |
| `name`, `getChildByName` | `label`, `getChildByLabel` |
| `cacheAsBitmap` | `cacheAsTexture()` |
| `BaseTexture` | `TextureSource` |
| `@pixi/react`: `<Stage>`, `<Sprite>` | `<Application>`, `<pixiSprite>` + `extend` |

## Частые ошибки

- Код из примеров v7 в проекте на v8.
- Объект создан, но не добавлен через `addChild`.
- Нет `eventMode` — события не приходят.
- `deltaTime` принят за секунды.
- `Text.text` меняется каждый кадр вместо `BitmapText`.
- Отдельный PNG на каждый спрайт — батчинг не работает.

## Что важно помнить

- Цикл работы: `init` → `Assets.load` → объекты в `stage` → логика в `ticker`.
- Всё на сцене — `Container`: одинаковые свойства трансформации и отображения.
- Эффекты от дешёвых к дорогим: `tint`/`alpha` → `blendMode` → маски → фильтры.
- Производительность: атласы, пулы, `ParticleContainer`, culling, `cacheAsTexture`.
