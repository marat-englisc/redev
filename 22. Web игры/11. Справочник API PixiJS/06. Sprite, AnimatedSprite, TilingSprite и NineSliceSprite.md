# Sprite, AnimatedSprite, TilingSprite и NineSliceSprite

> [!NOTE]
> Четыре класса для отображения текстур. **`Sprite`** — картинка: `texture`, `anchor` (точка привязки 0..1), `tint`, плюс всё от `Container`. **`AnimatedSprite`** — покадровая анимация из массива текстур: `animationSpeed`, `loop`, `play()`, `stop()`, `gotoAndPlay(n)`, `gotoAndStop(n)`, `currentFrame`, `totalFrames`, колбэки `onComplete`, `onFrameChange`, `onLoop`. **`TilingSprite`** — текстура, повторяющаяся плиткой на заданной площади: `tilePosition`, `tileScale`, `tileRotation` — фоны, параллакс, бесконечная прокрутка. **`NineSliceSprite`** — «девятисрезная» текстура, у которой углы не растягиваются: кнопки, панели, рамки любого размера. Все они создаются через объект опций: `new Sprite({ texture, anchor: 0.5 })`.

## Вопрос

Какие свойства и методы у спрайтов разных типов в PixiJS v8 и в каких задачах использовать каждый?

## Sprite

```ts
import { Sprite, Assets } from 'pixi.js';

const tex = await Assets.load('/img/hero.png');

const hero = new Sprite({
  texture: tex,
  anchor: 0.5,           // или { x: 0.5, y: 1 }
  x: 200,
  y: 300,
  scale: 2,
  tint: 0xffffff,
  roundPixels: true,     // чёткий пиксель-арт для этого спрайта
});
```

| Свойство / метод | Описание |
| --- | --- |
| `texture` | текстура; замена на лету — смена картинки без пересоздания |
| `anchor` | `ObservablePoint` 0..1: (0,0) — левый верх, (0.5, 0.5) — центр, (0.5, 1) — низ по центру |
| `tint` | цвет-множитель (`0xff0000` — красный оттенок) |
| `roundPixels` | округление позиции при отрисовке |
| `width` / `height` | размер в пикселях (через `scale`) |
| `Sprite.from(source)` | из алиаса, URL в кеше, текстуры или canvas |

```ts
hero.texture = Assets.get('hero-hurt');   // «мигание» другой картинкой
hero.scale.x *= -1;                        // повернуться влево
hero.anchor.set(0.5, 1);                   // стоять ногами на y
```

## AnimatedSprite

```ts
import { AnimatedSprite } from 'pixi.js';

const sheet = await Assets.load('/sprites/hero.json');

const anim = new AnimatedSprite({
  textures: sheet.animations.run,   // Texture[] или [{ texture, time }]
  animationSpeed: 0.2,              // кадров анимации за тик при 60 FPS
  loop: true,
  autoPlay: true,
  anchor: 0.5,
});
```

| Свойство / метод | Описание |
| --- | --- |
| `textures` | массив кадров; можно поменять для смены анимации |
| `animationSpeed` | скорость: `0.1` ≈ 6 кадров/с, `0.25` ≈ 15 кадров/с при 60 FPS |
| `loop` | зациклить |
| `autoUpdate` | обновляться от `Ticker.shared` (по умолчанию `true`) |
| `play()`, `stop()` | старт/стоп |
| `gotoAndPlay(frame)`, `gotoAndStop(frame)` | перейти к кадру |
| `currentFrame`, `totalFrames`, `playing` | состояние |
| `onComplete` | конец анимации при `loop = false` |
| `onFrameChange(frame)` | смена кадра — шаги, удары |
| `onLoop` | новый круг анимации |
| `update(ticker)` | обновить вручную при `autoUpdate = false` |

Разная длительность кадров (например, замах дольше удара):

```ts
const attack = new AnimatedSprite([
  { texture: sheet.textures['attack_0.png'], time: 200 },  // мс
  { texture: sheet.textures['attack_1.png'], time: 60 },
  { texture: sheet.textures['attack_2.png'], time: 120 },
]);
```

Обновление от собственного игрового цикла (уважает паузу игры):

```ts
anim.autoUpdate = false;
gameTicker.add((t) => anim.update(t));
```

## TilingSprite

```ts
import { TilingSprite } from 'pixi.js';

const far = new TilingSprite({
  texture: await Assets.load('/img/mountains.png'),
  width: app.screen.width,
  height: 300,
  y: app.screen.height - 300,
});

app.ticker.add((t) => {
  far.tilePosition.x -= 20 * t.deltaMS / 1000;     // медленный дальний слой
});
```

| Свойство | Описание |
| --- | --- |
| `width`, `height` | площадь, которую заполняет плитка |
| `tilePosition` | смещение плитки — прокрутка |
| `tileScale` | масштаб плитки |
| `tileRotation` | поворот плитки |
| `applyAnchorToTexture` | учитывать `anchor` при смещении плитки |
| `clampMargin` | отступ сэмплинга по краям (убирает швы) |

Параллакс из нескольких слоёв:

```ts
const layers = [{ s: far, k: 0.2 }, { s: mid, k: 0.5 }, { s: near, k: 1 }];
app.ticker.add(() => {
  for (const { s, k } of layers) s.tilePosition.x = -camera.x * k;
});
```

## NineSliceSprite

```text
 ┌───┬─────────┬───┐
 │ 1 │    2    │ 3 │   углы 1, 3, 7, 9 — не растягиваются
 ├───┼─────────┼───┤   стороны 2, 8 — растягиваются по ширине
 │ 4 │    5    │ 6 │   стороны 4, 6 — по высоте
 ├───┼─────────┼───┤   центр 5 — в обе стороны
 │ 7 │    8    │ 9 │
 └───┴─────────┴───┘
```

```ts
import { NineSliceSprite } from 'pixi.js';

const panel = new NineSliceSprite({
  texture: Texture.from('ui/panel.png'),
  leftWidth: 16,
  topHeight: 16,
  rightWidth: 16,
  bottomHeight: 16,
  width: 320,
  height: 180,
});

panel.width = 400;   // рамка не искажается
```

| Свойство | Описание |
| --- | --- |
| `leftWidth`, `rightWidth`, `topHeight`, `bottomHeight` | размеры неизменяемых краёв в пикселях текстуры |
| `width`, `height` | итоговый размер |
| `anchor` | точка привязки |

## Что выбрать

| Задача | Класс |
| --- | --- |
| Персонаж, предмет, пуля | `Sprite` |
| Покадровая анимация, взрыв | `AnimatedSprite` |
| Фон, параллакс, вода, звёзды | `TilingSprite` |
| Кнопки, окна, полоски, рамки | `NineSliceSprite` |
| Десятки тысяч одинаковых объектов | `Particle` в `ParticleContainer` |

## Частые ошибки

- Создавать новый `Sprite` при смене картинки — достаточно поменять `texture`.
- Не вызвать `play()` у `AnimatedSprite` без `autoPlay` — показывается первый кадр.
- Масштабировать `TilingSprite` через `scale`, когда нужен `tileScale`: `scale` растягивает и площадь.
- Растягивать обычный `Sprite` для панели интерфейса — углы искажаются; нужен `NineSliceSprite`.
- Оставлять `autoUpdate = true` у анимаций, которые должны стоять на паузе вместе с игрой.

## Что важно помнить

- `Sprite`: `texture`, `anchor`, `tint`.
- `AnimatedSprite`: `textures`, `animationSpeed`, `play/stop/gotoAndPlay`, `onComplete/onFrameChange/onLoop`.
- `TilingSprite`: `tilePosition`/`tileScale` для бесконечных фонов.
- `NineSliceSprite`: растягиваемый UI без искажения углов.

## Мини-шпаргалка

```ts
new Sprite({ texture, anchor: 0.5 });
new AnimatedSprite({ textures: sheet.animations.run, animationSpeed: 0.2, autoPlay: true });
new TilingSprite({ texture, width, height }).tilePosition.x -= 1;
new NineSliceSprite({ texture, leftWidth: 16, topHeight: 16, rightWidth: 16, bottomHeight: 16 });
```
