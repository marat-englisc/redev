# Как сделать спрайтовую анимацию

> [!NOTE]
> Спрайтовая анимация — это быстрая смена кадров, как в мультфильме. Все кадры лежат в одном изображении — **спрайт-листе** (spritesheet), обычно в ряд одинаковых клеток. Анимация хранит номер текущего кадра и таймер: каждые `1 / fps` секунд таймер переключает кадр, а `drawImage` вырезает нужную клетку. Скорость анимации не должна зависеть от FPS игры, поэтому кадр меняется по накопленному `dt`, а не «каждый N-й кадр». У персонажа обычно несколько анимаций (`idle`, `run`, `jump`) — какая играет, решает его состояние.

## Вопрос

Как реализовать анимацию персонажа из спрайт-листа на canvas?

## Спрайт-лист

```text
hero.png — кадры 32×32
row 0: idle  ■ ■ ■ ■
row 1: run   ■ ■ ■ ■ ■ ■
row 2: jump  ■ ■
```

## Класс анимации

```ts
interface AnimationDef {
  row: number;        // строка в спрайт-листе
  frames: number;     // количество кадров
  fps: number;        // скорость анимации
  loop: boolean;
}

class SpriteAnimator {
  private frame = 0;
  private time = 0;
  private current: AnimationDef;
  finished = false;

  constructor(
    private image: HTMLImageElement,
    private frameW: number,
    private frameH: number,
    private animations: Record<string, AnimationDef>,
    initial: string,
  ) {
    this.current = animations[initial];
  }

  play(name: string) {
    const next = this.animations[name];
    if (next === this.current) return; // не перезапускать ту же анимацию каждый кадр
    this.current = next;
    this.frame = 0;
    this.time = 0;
    this.finished = false;
  }

  update(dt: number) {
    this.time += dt;
    const frameDuration = 1 / this.current.fps;

    while (this.time >= frameDuration) {
      this.time -= frameDuration;
      if (this.frame < this.current.frames - 1) this.frame++;
      else if (this.current.loop) this.frame = 0;
      else this.finished = true;
    }
  }

  draw(ctx: CanvasRenderingContext2D, x: number, y: number, flip = false) {
    const sx = this.frame * this.frameW;
    const sy = this.current.row * this.frameH;

    ctx.save();
    ctx.translate(x, y);
    if (flip) ctx.scale(-1, 1);
    ctx.drawImage(
      this.image,
      sx, sy, this.frameW, this.frameH,
      -this.frameW / 2, -this.frameH / 2, this.frameW, this.frameH,
    );
    ctx.restore();
  }
}
```

## Использование

```ts
const heroImg = new Image();
heroImg.src = '/sprites/hero.png';
await heroImg.decode();

const anim = new SpriteAnimator(heroImg, 32, 32, {
  idle: { row: 0, frames: 4, fps: 6, loop: true },
  run:  { row: 1, frames: 6, fps: 12, loop: true },
  jump: { row: 2, frames: 2, fps: 8, loop: false },
}, 'idle');

function update(dt: number) {
  // состояние персонажа → анимация
  if (!player.onGround) anim.play('jump');
  else if (Math.abs(player.vx) > 10) anim.play('run');
  else anim.play('idle');

  anim.update(dt);
}

function render() {
  ctx.imageSmoothingEnabled = false;          // пиксель-арт без мыла
  anim.draw(ctx, player.x, player.y, player.vx < 0);
}
```

## Атлас с JSON

Когда кадры разного размера, спрайт-лист собирают инструментами (TexturePacker, Aseprite, free-tex-packer) и получают JSON с координатами:

```json
{
  "frames": {
    "run_0.png": { "frame": { "x": 0,  "y": 0, "w": 28, "h": 32 } },
    "run_1.png": { "frame": { "x": 28, "y": 0, "w": 30, "h": 32 } }
  }
}
```

```ts
const atlas = await fetch('/sprites/hero.json').then((r) => r.json());
const runFrames = Object.keys(atlas.frames)
  .filter((k) => k.startsWith('run_'))
  .map((k) => atlas.frames[k].frame);

const f = runFrames[frameIndex];
ctx.drawImage(img, f.x, f.y, f.w, f.h, x - f.w / 2, y - f.h / 2, f.w, f.h);
```

Этот формат понимают PixiJS (`Spritesheet`, `AnimatedSprite`) и Phaser (`load.atlas`).

## События по кадрам

```ts
// звук шага на 2-м и 5-м кадре бега
const prev = this.frame;
this.update(dt);
if (this.frame !== prev && name === 'run' && (this.frame === 1 || this.frame === 4)) {
  playSound('step');
}
```

Удар мечом наносит урон не при нажатии, а на «ударном» кадре анимации — так игра ощущается честной.

## Частые ошибки

- Переключать кадр каждый игровой кадр — анимация на 144 Гц в 2,4 раза быстрее.
- Вызывать `play()` каждый кадр без проверки «уже играет» — анимация застревает на первом кадре.
- Рисовать с дробными координатами и сглаживанием — пиксель-арт «плывёт». Округляйте `Math.round(x)`.
- Делать отдельную картинку на каждый кадр — лишние запросы и переключения текстур.

## Что важно помнить

- Спрайт-лист + номер кадра + таймер.
- Кадр меняется по накопленному времени: `time >= 1 / fps`.
- Анимацию выбирает состояние объекта: `idle`/`run`/`jump`.
- Для сложных атласов используйте JSON от TexturePacker/Aseprite.

## Мини-шпаргалка

```ts
time += dt;
if (time >= 1 / fps) { time -= 1 / fps; frame = (frame + 1) % frames; }
ctx.drawImage(img, frame * fw, row * fh, fw, fh, dx, dy, fw, fh);
```
