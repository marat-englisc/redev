# Как анимировать движение — скорость, ускорение и гравитация

> [!NOTE]
> Движение в играх строится на простой физике: у объекта есть **позиция**, **скорость** (velocity) и иногда **ускорение**. Каждый `update` ускорение меняет скорость, а скорость — позицию: `vy += gravity * dt; y += vy * dt` (это метод Эйлера, его хватает для большинства игр). Гравитация — постоянное ускорение вниз, прыжок — мгновенная скорость вверх (`vy = -jumpSpeed`), трение — постепенное уменьшение скорости (`vx *= friction` или `vx -= sign * friction * dt`). Движение «к цели» и плавное следование камеры делают через **lerp** — линейную интерполяцию между текущим значением и целью.

## Вопрос

Как реализовать в игре движение, разгон, торможение, гравитацию и прыжок?

## Позиция и скорость

```ts
interface Body {
  x: number; y: number;     // позиция, px
  vx: number; vy: number;   // скорость, px/с
}

function integrate(b: Body, dt: number) {
  b.x += b.vx * dt;
  b.y += b.vy * dt;
}
```

## Разгон и торможение (платформер)

Мгновенная скорость ощущается «деревянно». Плавный разгон делает управление приятнее:

```ts
const MAX_SPEED = 220;   // px/с
const ACCEL = 1400;      // px/с² — как быстро разгоняемся
const FRICTION = 1600;   // px/с² — как быстро тормозим

function updateHorizontal(p: Body, input: { left: boolean; right: boolean }, dt: number) {
  const dir = Number(input.right) - Number(input.left); // -1, 0, 1

  if (dir !== 0) {
    p.vx += dir * ACCEL * dt;
    p.vx = Math.max(-MAX_SPEED, Math.min(MAX_SPEED, p.vx)); // clamp
  } else {
    // трение: уменьшаем скорость к нулю, не перескакивая через него
    const decel = FRICTION * dt;
    p.vx = Math.abs(p.vx) <= decel ? 0 : p.vx - Math.sign(p.vx) * decel;
  }
}
```

## Гравитация и прыжок

```ts
const GRAVITY = 1800;      // px/с², вниз = +y
const JUMP_SPEED = 620;    // начальная скорость прыжка
const MAX_FALL = 900;

function updateVertical(p: Body & { onGround: boolean }, jumpPressed: boolean, dt: number) {
  if (jumpPressed && p.onGround) {
    p.vy = -JUMP_SPEED;     // вверх — отрицательная скорость
    p.onGround = false;
  }

  p.vy = Math.min(p.vy + GRAVITY * dt, MAX_FALL); // ограничиваем скорость падения
  p.y += p.vy * dt;

  const floor = 400;
  if (p.y >= floor) {       // приземление
    p.y = floor;
    p.vy = 0;
    p.onGround = true;
  }
}
```

Высота прыжка: `h = v² / (2g)` = 620² / 3600 ≈ 107 px. Удобно подбирать скорость от нужной высоты: `v = Math.sqrt(2 * g * h)`.

### Приёмы «отзывчивого» прыжка

```ts
// 1. Прыжок переменной высоты: отпустил кнопку — гасим подъём
if (!input.jumpHeld && p.vy < 0) p.vy *= 0.5;

// 2. Coyote time: можно прыгнуть ещё ~0.1 с после схода с края
p.coyote = p.onGround ? 0.1 : p.coyote - dt;
const canJump = p.coyote > 0;

// 3. Jump buffer: нажал чуть раньше приземления — прыжок всё равно сработает
p.jumpBuffer = input.jumpPressed ? 0.1 : p.jumpBuffer - dt;
if (p.jumpBuffer > 0 && canJump) { p.vy = -JUMP_SPEED; p.jumpBuffer = 0; p.coyote = 0; }
```

## Движение под углом (вид сверху)

```ts
// направление из клавиш
let dx = Number(keys.right) - Number(keys.left);
let dy = Number(keys.down) - Number(keys.up);

// нормализация: иначе по диагонали скорость в √2 ≈ 1.41 раза больше
const len = Math.hypot(dx, dy);
if (len > 0) { dx /= len; dy /= len; }

player.x += dx * SPEED * dt;
player.y += dy * SPEED * dt;
```

## Движение к цели и «самонаводящаяся» ракета

```ts
// враг идёт к игроку с постоянной скоростью
const angle = Math.atan2(player.y - enemy.y, player.x - enemy.x);
enemy.x += Math.cos(angle) * enemy.speed * dt;
enemy.y += Math.sin(angle) * enemy.speed * dt;

// пуля летит в направлении курсора
bullet.vx = Math.cos(angle) * 800;
bullet.vy = Math.sin(angle) * 800;
```

## Lerp — плавное следование

```ts
const lerp = (a: number, b: number, t: number) => a + (b - a) * t;

// камера мягко догоняет игрока. Формула с exp не зависит от FPS
const smooth = 1 - Math.exp(-8 * dt);
camera.x = lerp(camera.x, player.x - view.w / 2, smooth);
camera.y = lerp(camera.y, player.y - view.h / 2, smooth);
```

Наивный `lerp(a, b, 0.1)` каждый кадр работает быстрее на 144 Гц, чем на 60 Гц; вариант с `Math.exp(-k * dt)` даёт одинаковую плавность.

## Частые ошибки

- Не нормализовать диагональное движение — по диагонали быстрее.
- Забыть, что вверх — это отрицательный `y`.
- Не ограничивать скорость падения — объект разгоняется и пролетает сквозь пол.
- Применять трение умножением `vx *= 0.9` без учёта `dt` — на разных FPS тормозит по-разному.
- Ставить `onGround = true` только по координате, без обнуления `vy`.

## Что важно помнить

- Ускорение → скорость → позиция, всё умноженное на `dt`.
- Гравитация — постоянное `+vy`, прыжок — `vy = -jumpSpeed`.
- Нормализуйте вектор направления.
- Coyote time и jump buffer делают управление «честным» для игрока.
- Плавное следование — `lerp` с `1 - Math.exp(-k * dt)`.

## Мини-шпаргалка

```ts
vy += GRAVITY * dt; y += vy * dt;
if (jump && onGround) vy = -Math.sqrt(2 * GRAVITY * height);
const a = Math.atan2(ty - y, tx - x); x += Math.cos(a) * s * dt;
x = lerp(x, target, 1 - Math.exp(-k * dt));
```
