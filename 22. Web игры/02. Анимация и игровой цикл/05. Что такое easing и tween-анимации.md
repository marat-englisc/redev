# Что такое easing и tween-анимации

> [!NOTE]
> **Tween** (от in-between) — анимация свойства от начального значения к конечному за заданное время: «монетка поднимается на 20 px за 0,3 с». Прогресс `t = elapsed / duration` идёт от 0 до 1, а **easing-функция** превращает его в «ощущение»: `easeOutQuad` — быстрый старт и мягкая остановка, `easeOutBack` — с перелётом, `easeOutBounce` — отскок. Tween подходит для UI, всплывающих цифр урона, появления врагов, тряски камеры — всего, что заранее известно и не зависит от физики. Готовые решения: GSAP, `@tweenjs/tween.js`, встроенные твины Phaser.

## Вопрос

Что такое tween-анимация и easing-функции, и как их применить в игре?

## Линейный tween

```ts
const lerp = (a: number, b: number, t: number) => a + (b - a) * t;

let elapsed = 0;
const duration = 0.5;

function update(dt: number) {
  elapsed = Math.min(elapsed + dt, duration);
  const t = elapsed / duration;           // 0 → 1
  coin.y = lerp(300, 250, t);             // равномерно — выглядит механически
}
```

## Easing-функции

Принимают `t` от 0 до 1 и возвращают «искривлённый» прогресс.

```ts
export const ease = {
  linear: (t: number) => t,
  inQuad: (t: number) => t * t,                       // медленный старт
  outQuad: (t: number) => 1 - (1 - t) * (1 - t),      // мягкая остановка
  inOutQuad: (t: number) => (t < 0.5 ? 2 * t * t : 1 - (-2 * t + 2) ** 2 / 2),
  outCubic: (t: number) => 1 - (1 - t) ** 3,
  outBack: (t: number) => {
    const c1 = 1.70158, c3 = c1 + 1;
    return 1 + c3 * (t - 1) ** 3 + c1 * (t - 1) ** 2; // перелёт за цель и возврат
  },
  outElastic: (t: number) =>
    t === 0 || t === 1 ? t : 2 ** (-10 * t) * Math.sin((t * 10 - 0.75) * ((2 * Math.PI) / 3)) + 1,
};

coin.y = lerp(300, 250, ease.outQuad(t));
```

```text
linear     ╱        outQuad   ╭──      outBack   ╭─╮_
          ╱                  ╱                  ╱
         ╱                  │                  │
```

| Easing | Где использовать |
| --- | --- |
| `outQuad`/`outCubic` | появление, движение к цели, всплывающий текст |
| `inQuad` | исчезновение, «падение» в начале |
| `inOutQuad` | перемещения камеры, переходы между экранами |
| `outBack` | кнопки, бонусы, «пружинящий» UI |
| `outElastic`/`outBounce` | мультяшные эффекты, приземление |

## Простой менеджер твинов

```ts
type Tween = {
  target: Record<string, number>;
  from: Record<string, number>;
  to: Record<string, number>;
  duration: number;
  elapsed: number;
  easing: (t: number) => number;
  onComplete?: () => void;
};

class Tweens {
  private list: Tween[] = [];

  add<T extends Record<string, number>>(
    target: T,
    to: Partial<T>,
    duration: number,
    easing = ease.outQuad,
    onComplete?: () => void,
  ) {
    const from: Record<string, number> = {};
    for (const key in to) from[key] = target[key];
    this.list.push({ target, from, to: to as Record<string, number>, duration, elapsed: 0, easing, onComplete });
  }

  update(dt: number) {
    for (const tw of this.list) {
      tw.elapsed = Math.min(tw.elapsed + dt, tw.duration);
      const k = tw.easing(tw.elapsed / tw.duration);
      for (const key in tw.to) tw.target[key] = tw.from[key] + (tw.to[key] - tw.from[key]) * k;
    }
    // удаляем завершённые и вызываем колбэки
    const done = this.list.filter((tw) => tw.elapsed >= tw.duration);
    this.list = this.list.filter((tw) => tw.elapsed < tw.duration);
    done.forEach((tw) => tw.onComplete?.());
  }
}
```

## Пример: всплывающий урон

```ts
function spawnDamageText(x: number, y: number, value: number) {
  const label = { x, y, alpha: 1, scale: 0.5, text: `-${value}` };
  floatingTexts.push(label);

  tweens.add(label, { y: y - 40, scale: 1 }, 0.4, ease.outBack);
  tweens.add(label, { alpha: 0 }, 0.6, ease.inQuad, () => {
    floatingTexts.splice(floatingTexts.indexOf(label), 1);
  });
}

function renderTexts() {
  for (const t of floatingTexts) {
    ctx.save();
    ctx.globalAlpha = t.alpha;
    ctx.translate(t.x, t.y);
    ctx.scale(t.scale, t.scale);
    ctx.fillText(t.text, 0, 0);
    ctx.restore();
  }
}
```

## Тряска камеры (screen shake)

```ts
let shake = 0; // 0..1 — сила

function addShake(amount: number) { shake = Math.min(1, shake + amount); }

function applyShake(dt: number) {
  const power = shake * shake;                    // квадрат — мягкое затухание
  const offsetX = (Math.random() * 2 - 1) * 12 * power;
  const offsetY = (Math.random() * 2 - 1) * 12 * power;
  ctx.translate(offsetX, offsetY);
  shake = Math.max(0, shake - dt * 2);            // затухает за 0,5 с
}
```

## Частые ошибки

- Анимировать UI и эффекты физикой там, где нужен простой tween.
- Вызывать `onComplete` и удалять твин внутри того же цикла, по которому идёт обход.
- Запускать новый tween на свойство, которое уже анимируется, — два твина «дерутся». Отменяйте предыдущий.
- Делать tween через `setTimeout`/CSS для объектов на canvas — они не синхронизированы с игровым циклом и паузой.

## Что важно помнить

- Tween = `from`, `to`, `duration`, `easing`.
- `t = elapsed / duration`, `value = lerp(from, to, easing(t))`.
- `out`-easing почти всегда выглядит лучше линейного.
- Твины обновляются в игровом цикле — тогда они уважают паузу и `dt`.

## Мини-шпаргалка

```ts
t = Math.min(elapsed / duration, 1);
value = from + (to - from) * easeOutQuad(t);
easeOutQuad = (t) => 1 - (1 - t) ** 2;
```
