# Как работать с векторами в игре

> [!NOTE]
> Вектор `{ x, y }` в игре описывает позицию, скорость, направление или силу. Базовый набор операций: **сложение** (позиция + скорость), **умножение на число** (скорость × dt), **длина** (`Math.hypot(x, y)` — расстояние), **нормализация** (направление длины 1), **скалярное произведение** `dot` (насколько векторы сонаправлены: проекции, отражение, «враг впереди или сзади») и **угол** (`Math.atan2(y, x)`). С ними решаются почти все задачи: движение к цели, отражение мяча, разлёт частиц, проверка поля зрения. Для 2D-игр на canvas хватает маленького класса `Vec2`; в больших проектах берут `gl-matrix` или математику из движка.

## Вопрос

Какие операции с векторами нужны в 2D-игре и для чего они используются?

## Класс Vec2

```ts
export class Vec2 {
  constructor(public x = 0, public y = 0) {}

  static fromAngle(angle: number, length = 1) {
    return new Vec2(Math.cos(angle) * length, Math.sin(angle) * length);
  }

  clone() { return new Vec2(this.x, this.y); }
  set(x: number, y: number) { this.x = x; this.y = y; return this; }

  add(v: Vec2) { this.x += v.x; this.y += v.y; return this; }
  sub(v: Vec2) { this.x -= v.x; this.y -= v.y; return this; }
  scale(k: number) { this.x *= k; this.y *= k; return this; }

  length() { return Math.hypot(this.x, this.y); }
  lengthSq() { return this.x * this.x + this.y * this.y; } // без корня — для сравнений

  normalize() {
    const len = this.length();
    if (len > 0) { this.x /= len; this.y /= len; }
    return this;
  }

  dot(v: Vec2) { return this.x * v.x + this.y * v.y; }
  angle() { return Math.atan2(this.y, this.x); }

  limit(max: number) {                     // ограничить длину
    const lenSq = this.lengthSq();
    if (lenSq > max * max) this.scale(max / Math.sqrt(lenSq));
    return this;
  }

  distanceTo(v: Vec2) { return Math.hypot(v.x - this.x, v.y - this.y); }
}
```

Методы **мутируют** вектор и возвращают `this` — так меньше мусора в горячем цикле. Когда нужно новое значение — `clone()`.

## Типичные задачи

### Движение

```ts
position.add(velocity.clone().scale(dt));
```

### Направление и расстояние до цели

```ts
const toTarget = target.clone().sub(enemy.pos);   // вектор от врага к цели
const dist = toTarget.length();
const dir = toTarget.normalize();                 // единичный вектор
enemy.vel = dir.scale(enemy.speed);

// сравнение расстояний без корня
if (enemy.pos.clone().sub(player.pos).lengthSq() < 100 * 100) aggro();
```

### Ограничение скорости и «руление» (steering)

```ts
// плавный поворот к цели вместо мгновенного
const desired = target.clone().sub(pos).normalize().scale(MAX_SPEED);
const steer = desired.sub(vel).limit(MAX_FORCE);  // насколько хотим изменить скорость
vel.add(steer.scale(dt)).limit(MAX_SPEED);
pos.add(vel.clone().scale(dt));
```

### Скалярное произведение: впереди или сзади

```ts
const forward = Vec2.fromAngle(guard.angle);
const toPlayer = player.pos.clone().sub(guard.pos).normalize();
const d = forward.dot(toPlayer);    // 1 — прямо перед, 0 — сбоку, -1 — сзади

const FOV = Math.cos((60 * Math.PI) / 180); // конус обзора ±60°
const sees = d > FOV && guard.pos.distanceTo(player.pos) < 250;
```

### Отражение от поверхности

Формула: `r = v − 2 (v · n) n`, где `n` — единичная нормаль поверхности.

```ts
function reflect(v: Vec2, n: Vec2) {
  const d = 2 * v.dot(n);
  return new Vec2(v.x - d * n.x, v.y - d * n.y);
}

// мяч ударился о наклонную стену
ball.vel = reflect(ball.vel, wallNormal);
```

### Перпендикуляр

```ts
const perp = new Vec2(-v.y, v.x);  // поворот на 90° — нормаль к отрезку, движение «вбок»
```

### Поворот вектора

```ts
function rotate(v: Vec2, a: number) {
  const c = Math.cos(a), s = Math.sin(a);
  return new Vec2(v.x * c - v.y * s, v.x * s + v.y * c);
}

// дробовик: 5 пуль веером
for (let i = -2; i <= 2; i++) shoot(rotate(aim, i * 0.1));
```

## Полезные функции

```ts
export const clamp = (v: number, min: number, max: number) => Math.max(min, Math.min(max, v));
export const lerp = (a: number, b: number, t: number) => a + (b - a) * t;
export const randRange = (min: number, max: number) => min + Math.random() * (max - min);
export const deg2rad = (d: number) => (d * Math.PI) / 180;

// кратчайшая разница углов (-π..π) — чтобы башня не крутилась «через всю окружность»
export const angleDiff = (a: number, b: number) => Math.atan2(Math.sin(b - a), Math.cos(b - a));
turret.angle += clamp(angleDiff(turret.angle, targetAngle), -TURN * dt, TURN * dt);
```

## Частые ошибки

- Нормализовать нулевой вектор — деление на ноль даёт `NaN`, и объект исчезает.
- Мутировать общий вектор: `pos.add(vel.scale(dt))` портит `vel`. Нужен `vel.clone().scale(dt)`.
- Считать `Math.sqrt` там, где достаточно сравнить квадраты.
- Поворачивать угол к цели простым `angle += (target - angle) * k` — на переходе через ±π объект делает полный оборот.

## Что важно помнить

- Длина — `hypot`, направление — нормализация, угол — `atan2`.
- `dot` отвечает на вопрос «насколько в одну сторону»: обзор, проекции, отражение.
- Отражение: `v − 2(v·n)n`.
- В горячем коде избегайте лишних аллокаций векторов.

## Мини-шпаргалка

```ts
len = Math.hypot(x, y); nx = x / len; ny = y / len;
dot = ax * bx + ay * by;
angle = Math.atan2(y, x); x = Math.cos(a) * r; y = Math.sin(a) * r;
reflect = v − 2 * dot(v, n) * n;
```
