# Как ускорить проверку столкновений — пространственная сетка и квадродерево

> [!NOTE]
> Наивная проверка «каждый с каждым» стоит O(n²): при 2000 объектах это ~2 млн проверок за кадр. **Пространственное разбиение** (broad phase) отсекает пары, которые заведомо далеко друг от друга. **Uniform grid / spatial hash** делит мир на клетки фиксированного размера: объект записывается в клетки, которые покрывает, и проверяется только с соседями по клеткам. Это просто и очень быстро, если объекты примерно одного размера. **Квадродерево** (quadtree) рекурсивно делит область на 4 части там, где объектов много, — удобно при неравномерной плотности и сильно разных размерах. Сетку обычно перестраивают каждый кадр — для движущихся объектов это дешевле, чем обновлять.

## Вопрос

Как ускорить проверку столкновений, когда объектов в игре тысячи? Что такое spatial hash и quadtree?

## Spatial hash

```ts
interface Body { id: number; x: number; y: number; w: number; h: number }

export class SpatialHash {
  private cells = new Map<number, Body[]>();

  constructor(private cellSize: number) {}

  // упаковываем (cx, cy) в одно число — быстрее строковых ключей
  private key(cx: number, cy: number) {
    return ((cx & 0xffff) << 16) | (cy & 0xffff);
  }

  clear() {
    this.cells.clear();
  }

  insert(b: Body) {
    const x0 = Math.floor(b.x / this.cellSize);
    const y0 = Math.floor(b.y / this.cellSize);
    const x1 = Math.floor((b.x + b.w) / this.cellSize);
    const y1 = Math.floor((b.y + b.h) / this.cellSize);

    for (let cx = x0; cx <= x1; cx++) {
      for (let cy = y0; cy <= y1; cy++) {
        const k = this.key(cx, cy);
        let cell = this.cells.get(k);
        if (!cell) this.cells.set(k, (cell = []));
        cell.push(b);
      }
    }
  }

  /** уникальные пары-кандидаты */
  *pairs(): Generator<[Body, Body]> {
    const seen = new Set<number>();
    for (const cell of this.cells.values()) {
      for (let i = 0; i < cell.length; i++) {
        for (let j = i + 1; j < cell.length; j++) {
          const a = cell[i], b = cell[j];
          const pairKey = a.id < b.id ? a.id * 100_000 + b.id : b.id * 100_000 + a.id;
          if (seen.has(pairKey)) continue;   // большой объект лежит в нескольких клетках
          seen.add(pairKey);
          yield [a, b];
        }
      }
    }
  }

  /** объекты рядом с областью — для запросов «кто в радиусе взрыва» */
  query(x: number, y: number, w: number, h: number): Set<Body> {
    const result = new Set<Body>();
    for (let cx = Math.floor(x / this.cellSize); cx <= Math.floor((x + w) / this.cellSize); cx++) {
      for (let cy = Math.floor(y / this.cellSize); cy <= Math.floor((y + h) / this.cellSize); cy++) {
        for (const b of this.cells.get(this.key(cx, cy)) ?? []) result.add(b);
      }
    }
    return result;
  }
}
```

## Использование в кадре

```ts
const grid = new SpatialHash(64);

function update(dt: number) {
  for (const e of entities) e.update(dt);

  grid.clear();
  for (const e of entities) grid.insert(e);

  for (const [a, b] of grid.pairs()) {
    if (aabb(a, b)) onCollision(a, b);   // точная проверка только для соседей
  }
}

// урон по площади
const near = grid.query(boom.x - 100, boom.y - 100, 200, 200);
for (const e of near) if (distance(e, boom) < 100) e.damage(50);
```

## Как выбрать размер клетки

- Примерно **1–2 размера типичного объекта**.
- Слишком мелкая — объект попадает в много клеток, растут накладные расходы.
- Слишком крупная — в клетке много объектов, возвращаемся к O(n²).
- Очень большие объекты (босс, лазер) иногда проверяют отдельно, не кладя в сетку.

## Квадродерево

```ts
class QuadTree {
  private items: Body[] = [];
  private children: QuadTree[] | null = null;

  constructor(
    private bounds: { x: number; y: number; w: number; h: number },
    private capacity = 8,
    private depth = 0,
    private maxDepth = 6,
  ) {}

  insert(b: Body): void {
    if (!aabb(this.bounds, b)) return;

    if (this.children) {
      for (const c of this.children) c.insert(b);
      return;
    }

    this.items.push(b);
    if (this.items.length > this.capacity && this.depth < this.maxDepth) this.split();
  }

  private split() {
    const { x, y, w, h } = this.bounds;
    const hw = w / 2, hh = h / 2, d = this.depth + 1;
    this.children = [
      new QuadTree({ x, y, w: hw, h: hh }, this.capacity, d, this.maxDepth),
      new QuadTree({ x: x + hw, y, w: hw, h: hh }, this.capacity, d, this.maxDepth),
      new QuadTree({ x, y: y + hh, w: hw, h: hh }, this.capacity, d, this.maxDepth),
      new QuadTree({ x: x + hw, y: y + hh, w: hw, h: hh }, this.capacity, d, this.maxDepth),
    ];
    for (const it of this.items) for (const c of this.children) c.insert(it);
    this.items = [];
  }

  query(area: { x: number; y: number; w: number; h: number }, out = new Set<Body>()) {
    if (!aabb(this.bounds, area)) return out;
    for (const it of this.items) if (aabb(it, area)) out.add(it);
    this.children?.forEach((c) => c.query(area, out));
    return out;
  }
}
```

## Сетка или квадродерево

| | Spatial hash / grid | Quadtree |
| --- | --- | --- |
| Реализация | проще | сложнее |
| Объекты одного размера | отлично | хорошо |
| Сильно разная плотность и размеры | хуже | лучше |
| Бесконечный мир | да (хеш) | нужны границы |
| Перестройка каждый кадр | очень дёшево | дороже |

Для тайловых карт отдельная структура не нужна: клетку под объектом вычисляют делением координаты на размер тайла (см. урок про тайлмапы).

## Частые ошибки

- Не учитывать, что большой объект лежит в нескольких клетках, — пары дублируются, урон двойной.
- Выбирать размер клетки «на глаз» без профилирования.
- Использовать строковые ключи `${x},${y}` в горячем цикле — лишние аллокации.
- Строить квадродерево без ограничения глубины — объекты в одной точке дают бесконечное деление.

## Что важно помнить

- Broad phase отсекает далёкие пары, narrow phase — точная проверка.
- Spatial hash: клетка = `floor(x / size)`, объект — в каждую покрытую клетку.
- Quadtree адаптируется к плотности, но сложнее и дороже в перестройке.
- Обе структуры полезны и для запросов «кто рядом»: взрывы, ИИ, видимость.
