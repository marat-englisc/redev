# Как подключить геймпад через Gamepad API

> [!NOTE]
> Gamepad API даёт доступ к геймпадам (Xbox, PlayStation, Switch Pro и другим) без библиотек. Главная особенность — API **опросный**: событий на нажатие кнопок нет, состояние читают каждый кадр через `navigator.getGamepads()`. События есть только на подключение и отключение (`gamepadconnected`, `gamepaddisconnected`), а сам геймпад становится видим странице после первого нажатия кнопки. У контроллеров с `mapping === 'standard'` раскладка одинаковая: `buttons[0]` — нижняя кнопка (A/✕), `axes[0..1]` — левый стик. У стиков есть «дрейф», поэтому малые значения отсекают **мёртвой зоной** (deadzone).

## Вопрос

Как поддержать геймпад в браузерной игре?

## Подключение

```ts
window.addEventListener('gamepadconnected', (e) => {
  console.log(`Геймпад ${e.gamepad.index}: ${e.gamepad.id}, mapping: ${e.gamepad.mapping}`);
  showHint('Геймпад подключён');
});

window.addEventListener('gamepaddisconnected', (e) => {
  pauseGame();                // игрок мог потерять управление
});
```

## Опрос каждый кадр

```ts
function readGamepad() {
  // в Chrome getGamepads() возвращает снимок — вызывать нужно каждый кадр заново
  const pads = navigator.getGamepads();
  return pads.find((p) => p?.connected) ?? null;
}

const DEADZONE = 0.15;
const applyDeadzone = (v: number) => (Math.abs(v) < DEADZONE ? 0 : v);

function update(dt: number) {
  const pad = readGamepad();
  if (!pad) return;

  const lx = applyDeadzone(pad.axes[0]);   // -1 влево … 1 вправо
  const ly = applyDeadzone(pad.axes[1]);   // -1 вверх … 1 вниз

  player.vx = lx * player.speed;           // аналоговое управление: слабый наклон — медленно
  player.vy = ly * player.speed;

  if (pad.buttons[0].pressed) player.jump();     // A / ✕
  const throttle = pad.buttons[7].value;         // правый курок: 0…1
}
```

## Стандартная раскладка

| Индекс | Xbox | PlayStation |
| --- | --- | --- |
| `buttons[0]` | A | ✕ |
| `buttons[1]` | B | ○ |
| `buttons[2]` | X | □ |
| `buttons[3]` | Y | △ |
| `buttons[4]`/`[5]` | LB / RB | L1 / R1 |
| `buttons[6]`/`[7]` | LT / RT (аналоговые) | L2 / R2 |
| `buttons[9]` | Menu | Options |
| `buttons[12..15]` | крестовина ↑ ↓ ← → | крестовина |
| `axes[0]`, `axes[1]` | левый стик X, Y | левый стик |
| `axes[2]`, `axes[3]` | правый стик X, Y | правый стик |

## Радиальная мёртвая зона

Отсечение по каждой оси отдельно даёт «крест»: по диагонали стик ощущается неравномерно. Лучше считать по длине вектора:

```ts
function stick(x: number, y: number, dead = 0.15) {
  const len = Math.hypot(x, y);
  if (len < dead) return { x: 0, y: 0 };
  const k = Math.min(1, (len - dead) / (1 - dead)) / len; // плавно от 0 после зоны
  return { x: x * k, y: y * k };
}
```

## Определение «нажато в этом кадре»

Событий нет, поэтому `pressed` вычисляют сравнением с прошлым кадром:

```ts
const prev: boolean[] = [];

function padPressed(pad: Gamepad, i: number) {
  const now = pad.buttons[i].pressed;
  const was = prev[i] ?? false;
  return now && !was;
}

function endFrame(pad: Gamepad | null) {
  if (!pad) return;
  pad.buttons.forEach((b, i) => (prev[i] = b.pressed));
}
```

## Объединение с клавиатурой

Удобно сводить все устройства к общим действиям:

```ts
function getMoveX() {
  const kb = Number(keys.isDown('KeyD')) - Number(keys.isDown('KeyA'));
  const pad = readGamepad();
  const gp = pad ? stick(pad.axes[0], pad.axes[1]).x : 0;
  return Math.abs(gp) > Math.abs(kb) ? gp : kb;
}
```

## Частые ошибки

- Ждать событий нажатия кнопок — их нет, нужен опрос в цикле.
- Сохранить объект `Gamepad` один раз и читать его — в Chrome он не обновляется, нужен `getGamepads()` каждый кадр.
- Не использовать мёртвую зону — персонаж медленно «ползёт» сам.
- Полагаться на индексы кнопок при `mapping !== 'standard'` — раскладка может отличаться.
- Показывать «нажмите A» до первого взаимодействия — геймпад ещё не виден странице.

## Что важно помнить

- `navigator.getGamepads()` каждый кадр.
- `buttons[i].pressed`/`.value`, `axes[i]` от −1 до 1.
- Мёртвая зона обязательна, радиальная лучше покоординатной.
- `pressed` в кадре — через сравнение с прошлым состоянием.
- Требуется безопасный контекст (HTTPS или localhost).

## Мини-шпаргалка

```ts
const pad = navigator.getGamepads().find((p) => p?.connected);
pad?.axes[0];               // левый стик X
pad?.buttons[0].pressed;    // A / ✕
addEventListener('gamepadconnected', (e) => e.gamepad.index);
```
