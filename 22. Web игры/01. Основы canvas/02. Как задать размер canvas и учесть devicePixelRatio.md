# Как задать размер canvas и учесть devicePixelRatio

> [!NOTE]
> У canvas **два размера**: атрибуты `width`/`height` — сколько реальных пикселей в буфере, и CSS-размер — сколько места элемент занимает на странице. Если они не совпадают, браузер растягивает картинку, и она мылится. На экранах с высокой плотностью (`devicePixelRatio = 2` и больше) буфер делают в `dpr` раз больше CSS-размера, а затем вызывают `ctx.scale(dpr, dpr)`, чтобы дальше рисовать в привычных CSS-пикселях. Для игр часто удобнее фиксированное **логическое разрешение** (например, 320×180) и масштабирование под окно с сохранением пропорций.

## Вопрос

Почему canvas получается размытым, как задать его размер и что делать с `devicePixelRatio`?

## Два размера

```html
<!-- буфер 300×150 (значение по умолчанию), а на экране 600×300 -->
<canvas width="300" height="150" style="width: 600px; height: 300px"></canvas>
```

Каждый пиксель буфера растянут в 2 раза — линии и текст размытые. Правило: **размер буфера = CSS-размер × devicePixelRatio**.

> [!WARNING]
> Изменение `canvas.width` или `canvas.height` **очищает холст и сбрасывает всё состояние контекста** (цвета, трансформации, шрифт). Поэтому после ресайза настройки контекста задают заново.

## Чёткий canvas на Retina

```ts
function setupCanvas(canvas: HTMLCanvasElement, cssWidth: number, cssHeight: number) {
  const dpr = window.devicePixelRatio || 1;

  canvas.style.width = `${cssWidth}px`;
  canvas.style.height = `${cssHeight}px`;
  canvas.width = Math.round(cssWidth * dpr);
  canvas.height = Math.round(cssHeight * dpr);

  const ctx = canvas.getContext('2d')!;
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0); // рисуем в CSS-пикселях
  return ctx;
}

const ctx = setupCanvas(canvas, 800, 450);
ctx.fillRect(10, 10, 100, 100); // 100 CSS-пикселей = 200 реальных при dpr = 2
```

`setTransform` вместо `scale` — чтобы повторный вызов не умножал масштаб ещё раз.

## Canvas на всё окно

```ts
function resize() {
  const dpr = window.devicePixelRatio || 1;
  const { clientWidth: w, clientHeight: h } = canvas;   // размер из CSS
  canvas.width = Math.round(w * dpr);
  canvas.height = Math.round(h * dpr);
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
}

new ResizeObserver(resize).observe(canvas);
```

```css
canvas { display: block; width: 100vw; height: 100dvh; }
```

`ResizeObserver` срабатывает и при изменении окна, и при изменении размера контейнера.

## Логическое разрешение игры

Игровую логику удобно писать под фиксированный «виртуальный экран», а при отрисовке масштабировать его под окно:

```ts
const GAME_W = 320;
const GAME_H = 180;

function fit() {
  const dpr = window.devicePixelRatio || 1;
  const scale = Math.min(innerWidth / GAME_W, innerHeight / GAME_H); // letterbox
  const cssW = GAME_W * scale;
  const cssH = GAME_H * scale;

  canvas.style.width = `${cssW}px`;
  canvas.style.height = `${cssH}px`;
  canvas.width = Math.round(cssW * dpr);
  canvas.height = Math.round(cssH * dpr);

  ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0);
  ctx.imageSmoothingEnabled = false; // для пиксель-арта: без размытия при увеличении
}

addEventListener('resize', fit);
fit();
// дальше вся игра рисует в координатах 0..320 × 0..180
```

Для пиксель-арта дополнительно:

```css
canvas { image-rendering: pixelated; }
```

## Частые ошибки

- Задавать размер только CSS-свойствами — буфер остаётся 300×150.
- Вызывать `ctx.scale(dpr, dpr)` при каждом ресайзе — масштаб накапливается; используйте `setTransform`.
- Ресайзить canvas каждый кадр — это очистка и пересоздание буфера, дорого.
- Забыть, что после смены `width`/`height` сбрасываются `imageSmoothingEnabled`, `font` и другие настройки.
- Пересчитывать координаты мыши без учёта масштаба (см. урок про ввод).

## Что важно помнить

- Буфер (`width`/`height`) и CSS-размер — разные вещи.
- Чёткость: буфер = CSS × `devicePixelRatio`, затем `setTransform(dpr, …)`.
- Смена размера буфера очищает холст и сбрасывает контекст.
- Логическое разрешение + масштаб упрощают логику и поддержку разных экранов.

## Мини-шпаргалка

```ts
const dpr = devicePixelRatio || 1;
canvas.width = cssW * dpr;
canvas.height = cssH * dpr;
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
ctx.imageSmoothingEnabled = false; // пиксель-арт
```
