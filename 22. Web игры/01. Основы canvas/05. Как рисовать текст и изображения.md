# Как рисовать текст и изображения

> [!NOTE]
> Текст рисуется через `fillText`/`strokeText`, настройки — `font`, `textAlign`, `textBaseline`; ширину строки даёт `measureText`. Картинки рисуются через `drawImage` в трёх формах: `(img, x, y)`, `(img, x, y, w, h)` и `(img, sx, sy, sw, sh, dx, dy, dw, dh)` — последняя вырезает кусок из **спрайт-листа**, на ней строятся анимации и тайлы. Картинку можно рисовать только **после загрузки** (`await img.decode()` или `onload`), иначе ничего не появится. Источником для `drawImage` может быть `Image`, другой `<canvas>`, `<video>`, `ImageBitmap`.

## Вопрос

Как вывести на canvas текст и картинку? Как нарисовать часть изображения из спрайт-листа?

## Текст

```ts
ctx.font = 'bold 24px "Press Start 2P", monospace'; // как CSS-свойство font
ctx.fillStyle = 'white';
ctx.textAlign = 'left';         // left | center | right | start | end
ctx.textBaseline = 'top';       // top | middle | alphabetic | bottom
ctx.fillText(`Score: ${score}`, 16, 16);

// обводка для читаемости поверх фона
ctx.lineWidth = 4;
ctx.strokeStyle = 'black';
ctx.strokeText('GAME OVER', canvas.width / 2, 200);
ctx.fillText('GAME OVER', canvas.width / 2, 200);
```

Текст по центру экрана:

```ts
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText('PAUSED', canvas.width / 2, canvas.height / 2);
```

Ширина для фона под текстом:

```ts
const label = 'Level 3';
const { width } = ctx.measureText(label);
ctx.fillStyle = 'rgb(0 0 0 / 0.6)';
ctx.fillRect(10, 10, width + 16, 32);
```

> [!TIP]
> Веб-шрифт должен быть загружен до отрисовки: `await document.fonts.load('24px "Press Start 2P"')`. Иначе первые кадры нарисуются запасным шрифтом.

## Загрузка изображений

```ts
function loadImage(src: string): Promise<HTMLImageElement> {
  const img = new Image();
  img.src = src;
  return img.decode().then(() => img); // decode ждёт и загрузку, и декодирование
}

const [hero, tiles] = await Promise.all([
  loadImage('/sprites/hero.png'),
  loadImage('/sprites/tiles.png'),
]);
```

Картинка с другого домена без CORS-заголовков «пачкает» canvas (`tainted`): рисовать можно, но `getImageData` и `toDataURL` бросят ошибку. Для таких ресурсов нужен `img.crossOrigin = 'anonymous'` и `Access-Control-Allow-Origin` на сервере.

## Три формы drawImage

```ts
// 1. как есть
ctx.drawImage(hero, x, y);

// 2. с масштабом
ctx.drawImage(hero, x, y, 64, 64);

// 3. кусок картинки: откуда (s*) → куда (d*)
ctx.drawImage(
  tiles,
  32, 0, 16, 16,   // sx, sy, sw, sh — квадрат 16×16 в спрайт-листе
  x, y, 32, 32,    // dx, dy, dw, dh — на экране в 2 раза больше
);
```

## Спрайт-лист

```text
tiles.png (16×16 на клетку)
┌────┬────┬────┬────┐
│ 0  │ 1  │ 2  │ 3  │   индекс → (col, row)
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │ 7  │
└────┴────┴────┴────┘
```

```ts
const TILE = 16;
const COLS = 4;

function drawTile(index: number, dx: number, dy: number) {
  const sx = (index % COLS) * TILE;
  const sy = Math.floor(index / COLS) * TILE;
  ctx.drawImage(tiles, sx, sy, TILE, TILE, dx, dy, TILE, TILE);
}
```

Один большой файл вместо десятков мелких — меньше запросов и быстрее отрисовка.

## Отражение спрайта

Отдельной картинки «смотрит влево» не нужно — достаточно отзеркалить:

```ts
function drawHero(h: { x: number; y: number; facing: 1 | -1 }) {
  ctx.save();
  ctx.translate(h.x, h.y);
  ctx.scale(h.facing, 1);           // -1 — зеркально по горизонтали
  ctx.drawImage(heroImg, -16, -16); // рисуем от центра
  ctx.restore();
}
```

## Пиксельные данные

```ts
const data = ctx.getImageData(0, 0, w, h); // Uint8ClampedArray: r, g, b, a, r, g, b, a…
for (let i = 0; i < data.data.length; i += 4) {
  const gray = (data.data[i] + data.data[i + 1] + data.data[i + 2]) / 3;
  data.data[i] = data.data[i + 1] = data.data[i + 2] = gray;
}
ctx.putImageData(data, 0, 0);
```

`getImageData` медленный (данные копируются из GPU), в игровом цикле его избегают.

## Частые ошибки

- Вызывать `drawImage` сразу после `img.src = …` — картинка ещё не загружена.
- Путать порядок аргументов в 9-аргументной форме: сначала источник (`s`), потом назначение (`d`).
- Масштабировать пиксель-арт с включённым `imageSmoothingEnabled` — получится мыло.
- Рисовать текст счёта каждый кадр с дорогими тенями — проще закешировать.

## Что важно помнить

- `fillText` + `font`/`textAlign`/`textBaseline`, ширина — `measureText`.
- Изображение рисуется только после загрузки: `await img.decode()`.
- `drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)` — основа спрайтов и тайлов.
- Отражение — `scale(-1, 1)` внутри `save`/`restore`.

## Мини-шпаргалка

```ts
ctx.font = '16px monospace'; ctx.fillText(text, x, y);
await img.decode();
ctx.drawImage(img, x, y);
ctx.drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh);
```
