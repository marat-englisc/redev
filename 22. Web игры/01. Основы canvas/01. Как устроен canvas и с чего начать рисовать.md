# Как устроен canvas и с чего начать рисовать

> [!NOTE]
> `<canvas>` — это прямоугольник из пикселей, а рисует в нём JavaScript через **контекст**: `canvas.getContext('2d')` для 2D, `webgl2`/`webgpu` для GPU-графики. Canvas работает в режиме **immediate mode**: нарисованная фигура сразу превращается в пиксели и больше не существует как объект — нет DOM-узлов, событий и «перемещения фигуры». Поэтому игра хранит состояние объектов **у себя** (массивы, классы) и каждый кадр делает одно и то же: очищает холст и заново рисует всё по текущему состоянию. Система координат: `(0, 0)` в левом верхнем углу, `x` растёт вправо, `y` — **вниз**.

## Вопрос

Как устроен `<canvas>`, что такое контекст рисования и почему для игр важен режим immediate mode?

## Минимальная заготовка

```html
<canvas id="game" width="800" height="450">
  Ваш браузер не поддерживает canvas.  <!-- fallback-контент -->
</canvas>
<script type="module" src="./main.ts"></script>
```

```ts
const canvas = document.querySelector<HTMLCanvasElement>('#game')!;
const ctx = canvas.getContext('2d')!;   // CanvasRenderingContext2D

ctx.fillStyle = '#1e293b';               // фон
ctx.fillRect(0, 0, canvas.width, canvas.height);

ctx.fillStyle = 'tomato';                // «игрок»
ctx.fillRect(100, 200, 40, 40);
```

Контекст — это объект с методами рисования и **состоянием**: текущий цвет заливки, толщина линии, шрифт, трансформация. Состояние применяется ко всем следующим вызовам, пока его не поменяют.

## Система координат

```text
(0,0) ──────────► x
  │
  │      ■ (100, 200)
  │
  ▼ y
```

Ось `y` направлена вниз — «прыжок вверх» в игре означает **уменьшение** `y`. Координаты задаются в пикселях холста, а не CSS-пикселях страницы (подробнее — в уроке про размер и `devicePixelRatio`).

## Retained mode vs immediate mode

| | DOM / SVG (retained) | Canvas (immediate) |
| --- | --- | --- |
| Что хранится | дерево элементов | только пиксели |
| Как изменить фигуру | поменять атрибут, браузер перерисует | стереть и нарисовать заново |
| События мыши | у каждого элемента | одно событие на весь холст, попадание считаете сами |
| Много объектов | тысячи узлов тормозят | тысячи фигур за кадр — норма |

Отсюда главный принцип canvas-игр: **состояние отдельно, отрисовка отдельно**.

```ts
// состояние мира — обычные данные
const player = { x: 100, y: 200, size: 40, color: 'tomato' };

// отрисовка — чистая функция от состояния
function render() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = player.color;
  ctx.fillRect(player.x, player.y, player.size, player.size);
}

player.x += 10;   // меняем данные…
render();         // …и перерисовываем кадр целиком
```

## Какие бывают контексты

| Контекст | Для чего |
| --- | --- |
| `'2d'` | 2D-рисование: фигуры, текст, картинки. Хватает для большинства казуальных игр |
| `'webgl'` / `'webgl2'` | GPU-рендеринг через шейдеры; на нём построены PixiJS, Three.js, Phaser |
| `'webgpu'` | современный GPU API, преемник WebGL |
| `'bitmaprenderer'` | быстрый показ готового `ImageBitmap` |

У одного `<canvas>` может быть только один тип контекста: после `getContext('2d')` вызов `getContext('webgl2')` вернёт `null`.

Опции 2D-контекста:

```ts
const ctx = canvas.getContext('2d', {
  alpha: false,              // непрозрачный фон — браузеру проще композитить
  willReadFrequently: false, // true, если часто вызываете getImageData
})!;
```

## Частые ошибки

- Ждать, что `ctx.fillRect` вернёт объект, который потом можно сдвинуть, — фигуры нет, есть только пиксели.
- Не очищать холст между кадрами — за движущимся объектом остаётся «шлейф».
- Задавать размер только через CSS — картинка растягивается и мылится (см. следующий урок).
- Забывать, что `y` растёт вниз, и путать знак при гравитации и прыжке.

## Что важно помнить

- Canvas — immediate mode: состояние игры хранится в JS, кадр каждый раз рисуется заново.
- Рисование идёт через контекст, у контекста есть «текущие настройки».
- `(0, 0)` — левый верхний угол, `y` вниз.
- Для GPU-графики — `webgl2`/`webgpu` или библиотеки поверх них.

## Мини-шпаргалка

```ts
const ctx = canvas.getContext('2d')!;
ctx.clearRect(0, 0, canvas.width, canvas.height); // очистить
ctx.fillStyle = 'tomato';
ctx.fillRect(x, y, w, h);                         // залитый прямоугольник
```
