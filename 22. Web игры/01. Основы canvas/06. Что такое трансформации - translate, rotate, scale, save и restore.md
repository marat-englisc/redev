# Что такое трансформации — translate, rotate, scale, save и restore

> [!NOTE]
> Трансформации меняют **систему координат**, а не фигуры: `translate(x, y)` переносит начало координат, `rotate(angle)` поворачивает оси вокруг текущего начала, `scale(sx, sy)` растягивает их. Поэтому, чтобы повернуть объект вокруг своего центра, сначала делают `translate` в центр объекта, затем `rotate`, и рисуют объект вокруг `(0, 0)`. Трансформации накапливаются, поэтому каждую отрисовку объекта оборачивают в `save()`/`restore()` — они сохраняют и восстанавливают всё состояние контекста (трансформацию, цвета, alpha, шрифт). `setTransform` задаёт матрицу целиком, `resetTransform()` сбрасывает её.

## Вопрос

Как повернуть, сдвинуть и отразить объект на canvas? Зачем нужны `save()` и `restore()`?

## Перенос, поворот, масштаб

```ts
ctx.translate(100, 50);      // теперь (0,0) — это бывшая точка (100,50)
ctx.fillRect(0, 0, 20, 20);  // нарисуется в (100, 50)

ctx.rotate(Math.PI / 4);     // оси повернуты на 45° вокруг (100, 50)
ctx.scale(2, 2);             // всё дальше в 2 раза больше
```

Порядок важен: трансформации применяются к **системе координат** в порядке вызова.

## Поворот вокруг центра объекта

```ts
// ❌ вращает вокруг (0,0) холста — квадрат улетает по дуге
ctx.rotate(angle);
ctx.fillRect(200, 150, 40, 40);

// ✅ центр объекта → поворот → рисуем от центра
ctx.save();
ctx.translate(200 + 20, 150 + 20);  // центр квадрата
ctx.rotate(angle);
ctx.fillRect(-20, -20, 40, 40);     // квадрат вокруг (0,0)
ctx.restore();
```

Удобно хранить у игровых объектов координаты **центра** — тогда отрисовка всегда одинаковая.

## save и restore

`save()` кладёт текущее состояние в стек, `restore()` достаёт последнее сохранённое.

```ts
function drawEntity(e: Entity) {
  ctx.save();
  ctx.translate(e.x, e.y);
  ctx.rotate(e.angle);
  ctx.scale(e.scale, e.scale);
  ctx.globalAlpha = e.alpha;
  ctx.drawImage(e.sprite, -e.width / 2, -e.height / 2);
  ctx.restore(); // следующий объект рисуется с чистыми настройками
}
```

Сохраняется: матрица трансформации, `fillStyle`, `strokeStyle`, `lineWidth`, `font`, `globalAlpha`, `globalCompositeOperation`, тени, `filter`, область отсечения (`clip`). **Не сохраняется** текущий путь и пиксели.

## Вложенные трансформации: «пушка на танке»

```ts
ctx.save();
ctx.translate(tank.x, tank.y);
ctx.rotate(tank.bodyAngle);
drawBody();                       // корпус

  ctx.save();
  ctx.rotate(tank.turretAngle);   // поворот относительно корпуса
  drawTurret();
  ctx.restore();

ctx.restore();
```

Так строится иерархия сцены: дочерний объект двигается вместе с родителем. В PixiJS и Three.js то же самое делают контейнеры.

## Камера через translate

```ts
ctx.save();
ctx.translate(-camera.x, -camera.y); // мир сдвигается в обратную сторону
drawWorld();                          // рисуем в мировых координатах
ctx.restore();
drawHud();                            // интерфейс — в экранных координатах
```

## Направление к цели

```ts
// повернуть пушку к курсору
tank.turretAngle = Math.atan2(mouse.y - tank.y, mouse.x - tank.x);
```

`Math.atan2(dy, dx)` возвращает угол от −π до π — ровно то, что ждёт `rotate`. Спрайт при этом должен «смотреть» вправо (вдоль оси `x`).

## setTransform и getTransform

```ts
ctx.setTransform(1, 0, 0, 1, 0, 0);   // единичная матрица = resetTransform()
ctx.setTransform(dpr, 0, 0, dpr, 0, 0); // базовый масштаб под Retina

const m = ctx.getTransform();          // DOMMatrix
const inv = m.inverse();
const world = inv.transformPoint(new DOMPoint(screenX, screenY)); // экран → мир
```

## Отсечение (clip)

```ts
ctx.save();
ctx.beginPath();
ctx.arc(100, 100, 50, 0, Math.PI * 2);
ctx.clip();                    // всё дальше рисуется только внутри круга
ctx.drawImage(avatar, 50, 50, 100, 100);
ctx.restore();                 // clip снимается только через restore
```

## Частые ошибки

- Вращать без `translate` в центр — объект крутится вокруг угла холста.
- Забыть `restore()` или вызвать `save()` больше раз, чем `restore()`, — трансформации копятся кадр за кадром, стек растёт.
- `ctx.scale(-1, 1)` без `translate` — объект уходит за левую границу.
- Пытаться «отменить» `clip()` без `restore()`.

## Что важно помнить

- Трансформации двигают систему координат, а не нарисованное.
- Поворот вокруг центра: `translate(центр)` → `rotate` → рисовать от `(-w/2, -h/2)`.
- `save`/`restore` — обязательная пара вокруг каждого объекта.
- Камера — это `translate(-camera.x, -camera.y)` перед рисованием мира.

## Мини-шпаргалка

```ts
ctx.save();
ctx.translate(x, y); ctx.rotate(a); ctx.scale(sx, sy);
ctx.drawImage(img, -w / 2, -h / 2);
ctx.restore();
Math.atan2(ty - y, tx - x); // угол к цели
```
