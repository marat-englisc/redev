# Что такое пул объектов и зачем он нужен

> [!NOTE]
> **Object pool** — заранее созданный набор объектов, которые переиспользуются вместо постоянного `new` и удаления. Пули, частицы, всплывающие цифры живут доли секунды, и если на каждый выстрел создавать новый объект, сборщик мусора периодически останавливает поток, чтобы убрать тысячи «мёртвых» объектов, — игрок видит микрофризы. Пул выдаёт неактивный объект (`acquire`), объект сбрасывается в начальное состояние, а после «смерти» возвращается в пул (`release`). Главное правило — **полностью сбрасывать** состояние при повторном использовании, иначе пуля «унаследует» скорость или цвет предыдущей.

## Вопрос

Что такое пул объектов в играх, какую проблему он решает и как его реализовать?

## Проблема

```ts
// каждый кадр при стрельбе — новые объекты
function shoot() {
  bullets.push(new Bullet(player.x, player.y, angle)); // 10 выстрелов/с
}

// взрыв — 200 частиц разом
for (let i = 0; i < 200; i++) particles.push(new Particle(x, y));

// через доли секунды они станут мусором → GC → фриз на 5–20 мс
```

В DevTools → Performance это видно как пилообразный график памяти и блоки «Minor GC»/«Major GC».

## Простой пул

```ts
export class Pool<T> {
  private free: T[] = [];

  constructor(
    private create: () => T,
    private reset: (obj: T) => void,
    prefill = 0,
  ) {
    for (let i = 0; i < prefill; i++) this.free.push(create());
  }

  acquire(): T {
    return this.free.pop() ?? this.create();   // если пул пуст — создаём новый
  }

  release(obj: T) {
    this.reset(obj);
    this.free.push(obj);
  }

  get size() { return this.free.length; }
}
```

## Пул пуль

```ts
class Bullet {
  x = 0; y = 0; vx = 0; vy = 0;
  life = 0;
  active = false;

  init(x: number, y: number, angle: number, speed = 600) {
    this.x = x;
    this.y = y;
    this.vx = Math.cos(angle) * speed;
    this.vy = Math.sin(angle) * speed;
    this.life = 1.5;                 // секунд
    this.active = true;
    return this;
  }
}

const bulletPool = new Pool(
  () => new Bullet(),
  (b) => { b.active = false; },
  100,                               // заранее 100 штук
);

const bullets: Bullet[] = [];

function shoot(angle: number) {
  bullets.push(bulletPool.acquire().init(player.x, player.y, angle));
}

function updateBullets(dt: number) {
  for (let i = bullets.length - 1; i >= 0; i--) {   // обход с конца — безопасно удалять
    const b = bullets[i];
    b.x += b.vx * dt;
    b.y += b.vy * dt;
    b.life -= dt;

    if (b.life <= 0 || outOfScreen(b)) {
      // swap-remove: O(1), порядок не важен
      bullets[i] = bullets[bullets.length - 1];
      bullets.pop();
      bulletPool.release(b);
    }
  }
}
```

## Пул фиксированного размера

Для частиц часто делают массив фиксированной длины и флаг `active`. Объекты вообще не создаются после старта:

```ts
const MAX = 2000;
const particles = Array.from({ length: MAX }, () => ({ x: 0, y: 0, vx: 0, vy: 0, life: 0, active: false }));
let cursor = 0;

function emit(x: number, y: number) {
  const p = particles[cursor];
  cursor = (cursor + 1) % MAX;       // кольцевой буфер: самые старые перезаписываются
  p.x = x; p.y = y;
  p.vx = (Math.random() - 0.5) * 200;
  p.vy = (Math.random() - 0.5) * 200;
  p.life = 1;
  p.active = true;
}

function updateParticles(dt: number) {
  for (const p of particles) {
    if (!p.active) continue;
    p.life -= dt;
    if (p.life <= 0) { p.active = false; continue; }
    p.x += p.vx * dt;
    p.y += p.vy * dt;
  }
}
```

## Другие источники мусора в цикле

Пул — не единственное, что помогает. В горячем коде (`update`/`draw` для тысяч объектов) избегайте:

```ts
// ❌ новый объект/массив/замыкание каждый кадр
const pos = { x: e.x + 1, y: e.y };
entities.filter((e) => e.active).forEach((e) => e.draw(ctx));
ctx.fillStyle = `rgb(${r}, ${g}, ${b})`;      // новая строка каждый вызов

// ✅ переиспользуем временные объекты и простые циклы
const tmp = { x: 0, y: 0 };
for (let i = 0; i < entities.length; i++) if (entities[i].active) entities[i].draw(ctx);
```

Для PixiJS-спрайтов пул ещё важнее: создание и уничтожение `Sprite` дороже, чем простого объекта. Скрывайте спрайт (`visible = false`) и возвращайте его в пул.

## Частые ошибки

- Не сбрасывать все поля — переиспользованный объект ведёт себя как предыдущий.
- Возвращать объект в пул дважды — потом его получат два владельца одновременно.
- Держать ссылку на объект после `release` (например, ракета всё ещё «целится» во врага, которого уже переиспользовали).
- Делать пул для всего подряд: для пары объектов в секунду это усложнение без выгоды.

## Что важно помнить

- Пул убирает частые аллокации и паузы сборщика мусора.
- `acquire` → `init` (полный сброс) → использование → `release`.
- Для частиц — фиксированный массив и флаг `active`.
- Профилируйте: пул нужен там, где объекты создаются десятками и сотнями в секунду.

## Мини-шпаргалка

```ts
const obj = pool.acquire().init(...);
pool.release(obj);
arr[i] = arr[arr.length - 1]; arr.pop(); // быстрое удаление без сохранения порядка
```
