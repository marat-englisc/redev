# Как описать игровой объект — класс с update и draw

> [!NOTE]
> Самый простой и понятный способ организовать игру — каждый объект (игрок, враг, пуля, монетка) это экземпляр класса с данными (позиция, скорость, размер, здоровье) и двумя методами: `update(dt)` меняет состояние, `draw(ctx)` рисует. Игра хранит массив объектов и в каждом кадре вызывает у всех `update`, а затем `draw`. Общий интерфейс (`Entity`) позволяет обрабатывать разные объекты одинаково. Удаление делают через флаг `dead`/`active` и фильтрацию **после** обновления — удалять элементы массива посреди обхода нельзя. Для небольших игр этого подхода достаточно; когда типов объектов и поведений становится много, переходят к компонентам или ECS.

## Вопрос

Как организовать игровые объекты на canvas: игрока, врагов, пули? Как их создавать, обновлять и удалять?

## Базовый класс

```ts
export abstract class Entity {
  x = 0;
  y = 0;
  vx = 0;
  vy = 0;
  width = 16;
  height = 16;
  dead = false;          // пометка на удаление

  constructor(x: number, y: number) {
    this.x = x;
    this.y = y;
  }

  update(dt: number, world: World): void {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
  }

  abstract draw(ctx: CanvasRenderingContext2D): void;

  get bounds() {           // прямоугольник для столкновений
    return { x: this.x - this.width / 2, y: this.y - this.height / 2, w: this.width, h: this.height };
  }
}
```

## Конкретные объекты

```ts
export class Player extends Entity {
  speed = 260;
  hp = 3;
  cooldown = 0;

  update(dt: number, world: World) {
    const { keys } = world.input;
    let dx = Number(keys.has('ArrowRight')) - Number(keys.has('ArrowLeft'));
    let dy = Number(keys.has('ArrowDown')) - Number(keys.has('ArrowUp'));
    const len = Math.hypot(dx, dy) || 1;
    this.vx = (dx / len) * this.speed;
    this.vy = (dy / len) * this.speed;

    this.cooldown -= dt;
    if (keys.has('Space') && this.cooldown <= 0) {
      world.spawn(new Bullet(this.x, this.y - 12));   // создание через мир
      this.cooldown = 0.2;
    }

    super.update(dt, world);
  }

  draw(ctx: CanvasRenderingContext2D) {
    ctx.fillStyle = '#38bdf8';
    ctx.beginPath();
    ctx.moveTo(this.x, this.y - 12);
    ctx.lineTo(this.x + 10, this.y + 10);
    ctx.lineTo(this.x - 10, this.y + 10);
    ctx.closePath();
    ctx.fill();
  }
}

export class Bullet extends Entity {
  width = 4;
  height = 10;
  vy = -600;

  update(dt: number, world: World) {
    super.update(dt, world);
    if (this.y < -20) this.dead = true;   // улетела за экран
  }

  draw(ctx: CanvasRenderingContext2D) {
    ctx.fillStyle = '#facc15';
    ctx.fillRect(this.x - 2, this.y - 5, 4, 10);
  }
}

export class Enemy extends Entity {
  vy = 80;
  hp = 2;

  draw(ctx: CanvasRenderingContext2D) {
    ctx.fillStyle = '#ef4444';
    ctx.fillRect(this.x - 8, this.y - 8, 16, 16);
  }
}
```

## Мир: хранит и обновляет объекты

```ts
export class World {
  entities: Entity[] = [];
  private toAdd: Entity[] = [];
  input = new Input();

  spawn(e: Entity) {
    this.toAdd.push(e);        // не добавляем прямо во время обхода
  }

  query<T extends Entity>(type: new (...args: any[]) => T): T[] {
    return this.entities.filter((e): e is T => e instanceof type);
  }

  update(dt: number) {
    for (const e of this.entities) e.update(dt, this);

    this.handleCollisions();

    // удаляем мёртвых и добавляем новых ПОСЛЕ обхода
    this.entities = this.entities.filter((e) => !e.dead);
    this.entities.push(...this.toAdd);
    this.toAdd.length = 0;
  }

  draw(ctx: CanvasRenderingContext2D) {
    for (const e of this.entities) e.draw(ctx);
  }

  private handleCollisions() {
    for (const b of this.query(Bullet)) {
      for (const en of this.query(Enemy)) {
        if (!b.dead && !en.dead && intersects(b.bounds, en.bounds)) {
          b.dead = true;
          if (--en.hp <= 0) en.dead = true;
        }
      }
    }
  }
}
```

## Порядок отрисовки (z-index)

Canvas рисует в порядке вызовов: что нарисовано позже — то сверху.

```ts
draw(ctx: CanvasRenderingContext2D) {
  const sorted = [...this.entities].sort((a, b) => a.zIndex - b.zIndex || a.y - b.y);
  for (const e of sorted) e.draw(ctx); // y-сортировка — для вида «сверху под углом»
}
```

## Композиция вместо глубокого наследования

Когда появляются «летающий стреляющий враг», «босс, который ещё и спавнит врагов», иерархия классов ломается. Поведение выносят в переиспользуемые части:

```ts
interface Behavior { update(owner: Entity, dt: number, world: World): void }

class Shooter implements Behavior {
  private timer = 0;
  constructor(private rate: number) {}
  update(owner: Entity, dt: number, world: World) {
    this.timer -= dt;
    if (this.timer <= 0) { world.spawn(new EnemyBullet(owner.x, owner.y)); this.timer = this.rate; }
  }
}

class SineMove implements Behavior {
  private t = 0;
  update(owner: Entity, dt: number) { this.t += dt; owner.vx = Math.sin(this.t * 3) * 120; }
}

class Enemy extends Entity {
  behaviors: Behavior[] = [];
  update(dt: number, world: World) {
    for (const b of this.behaviors) b.update(this, dt, world);
    super.update(dt, world);
  }
}

const boss = new Enemy(200, 50);
boss.behaviors.push(new SineMove(), new Shooter(0.5));
```

Следующий шаг этой идеи — Entity Component System.

## Частые ошибки

- Удалять объект через `splice` прямо в цикле `for…of` — пропускаются соседние элементы.
- Добавлять новые объекты в массив во время его обхода — новые объекты обновятся в этом же кадре, или цикл станет бесконечным.
- Держать ссылки на «мёртвые» объекты (цель ракеты, подписки) — утечки и баги. Проверяйте `target.dead`.
- Смешивать логику и отрисовку: двигать объект внутри `draw`.

## Что важно помнить

- Объект = данные + `update(dt)` + `draw(ctx)`.
- Мир хранит список, обновляет всех, потом рисует всех.
- Удаление — через флаг `dead` и фильтрацию после обхода; создание — через очередь.
- Порядок рисования = порядок слоёв.
- Глубокое наследование заменяют композицией поведений.

## Мини-шпаргалка

```ts
for (const e of entities) e.update(dt, world);
entities = entities.filter((e) => !e.dead).concat(spawnQueue.splice(0));
for (const e of entities) e.draw(ctx);
```
