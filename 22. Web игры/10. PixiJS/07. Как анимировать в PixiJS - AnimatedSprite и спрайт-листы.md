# Как анимировать в PixiJS — AnimatedSprite и спрайт-листы

> [!NOTE]
> В PixiJS два вида анимации. **Анимация свойств** — в колбэке `app.ticker` меняются `x`, `rotation`, `scale`, `alpha` (для плавных переходов — с easing или через GSAP). **Покадровая** — `AnimatedSprite`: принимает массив текстур (кадров), сам переключает их по тикеру; скорость задаёт `animationSpeed` (доля кадра за тик при 60 FPS: `0.15` ≈ 9 кадров/с), управление — `play()`, `stop()`, `gotoAndPlay(n)`, `loop`, `onComplete`. Кадры берутся из **спрайт-листа**: JSON-атлас, в котором поле `animations` группирует кадры по именам, — после `Assets.load('hero.json')` они доступны как `sheet.animations.run`. Смена анимации — замена `textures` и `play()`.

## Вопрос

Как в PixiJS сделать покадровую анимацию персонажа и анимацию свойств объектов?

## Анимация свойств через ticker

```ts
const coin = Sprite.from('coin.png');
coin.anchor.set(0.5);
const baseY = 200;
let time = 0;

app.ticker.add((ticker) => {
  time += ticker.deltaMS / 1000;
  coin.y = baseY + Math.sin(time * 3) * 8;   // парит
  coin.scale.x = Math.cos(time * 4);         // «вращение» монетки (сплющивание)
});
```

## Спрайт-лист с анимациями

Формат атласа (TexturePacker, Aseprite, free-tex-packer) с секцией `animations`:

```json
{
  "frames": {
    "hero_idle_0.png": { "frame": { "x": 0,  "y": 0, "w": 32, "h": 32 } },
    "hero_idle_1.png": { "frame": { "x": 32, "y": 0, "w": 32, "h": 32 } },
    "hero_run_0.png":  { "frame": { "x": 0,  "y": 32, "w": 32, "h": 32 } },
    "hero_run_1.png":  { "frame": { "x": 32, "y": 32, "w": 32, "h": 32 } }
  },
  "animations": {
    "idle": ["hero_idle_0.png", "hero_idle_1.png"],
    "run":  ["hero_run_0.png", "hero_run_1.png"]
  },
  "meta": { "image": "hero.png", "size": { "w": 64, "h": 64 }, "scale": "1" }
}
```

## AnimatedSprite

```ts
import { AnimatedSprite, Assets } from 'pixi.js';

const sheet = await Assets.load('/assets/hero.json');

const hero = new AnimatedSprite(sheet.animations.idle);
hero.anchor.set(0.5, 1);
hero.animationSpeed = 0.1;   // при 60 FPS: 0.1 кадра анимации за тик ≈ 6 кадров/с
hero.play();
app.stage.addChild(hero);
```

## Переключение анимаций по состоянию

```ts
type HeroAnim = 'idle' | 'run' | 'jump' | 'attack';

const speeds: Record<HeroAnim, number> = { idle: 0.08, run: 0.2, jump: 0.15, attack: 0.3 };
let current: HeroAnim = 'idle';

function playAnim(name: HeroAnim, loop = true) {
  if (current === name) return;          // не перезапускать каждый кадр
  current = name;
  hero.textures = sheet.animations[name];
  hero.animationSpeed = speeds[name];
  hero.loop = loop;
  hero.gotoAndPlay(0);
}

app.ticker.add(() => {
  if (state.attacking) playAnim('attack', false);
  else if (!state.onGround) playAnim('jump', false);
  else if (Math.abs(state.vx) > 5) playAnim('run');
  else playAnim('idle');

  hero.scale.x = state.vx < 0 ? -1 : 1;  // разворот без отдельных кадров
});

hero.onComplete = () => {                 // для loop = false
  if (current === 'attack') state.attacking = false;
};

hero.onFrameChange = (frame) => {         // событие на кадре: урон, звук шага
  if (current === 'attack' && frame === 2) dealDamage();
};
```

## Сетка кадров без JSON

Если спрайт-лист — просто сетка, кадры можно нарезать вручную:

```ts
import { Rectangle, Texture } from 'pixi.js';

const base = await Assets.load('/assets/explosion.png'); // 8 кадров по 64×64 в ряд
const frames = Array.from({ length: 8 }, (_, i) =>
  new Texture({ source: base.source, frame: new Rectangle(i * 64, 0, 64, 64) }),
);

const boom = new AnimatedSprite(frames);
boom.anchor.set(0.5);
boom.loop = false;
boom.animationSpeed = 0.5;
boom.onComplete = () => boom.destroy();   // текстуры общие — их не уничтожаем
boom.play();
```

## Tween-анимации

Для плавных переходов (UI, появление, всплывающий урон) удобнее tween-библиотека. GSAP анимирует любые числовые свойства, в том числе вложенные:

```ts
import { gsap } from 'gsap';

gsap.to(coin, { y: coin.y - 40, alpha: 0, duration: 0.5, ease: 'power2.out', onComplete: () => coin.destroy() });
gsap.to(button.scale, { x: 1.1, y: 1.1, duration: 0.2, yoyo: true, repeat: 1 });
gsap.fromTo(title, { alpha: 0, y: -50 }, { alpha: 1, y: 100, duration: 0.8, ease: 'back.out(1.7)' });
```

У GSAP есть официальный `PixiPlugin` для удобных записей (`pixi: { tint: 0xff0000, scale: 2 }`). Свой мини-tween можно сделать по уроку про easing, обновляя его в `app.ticker`.

## Spine и скелетная анимация

Для сложных персонажей (много анимаций, плавные переходы, смена экипировки) используют скелетную анимацию — **Spine** (`@esotericsoftware/spine-pixi-v8`) или **DragonBones**. Персонаж собирается из частей и «костей», а анимации весят в разы меньше покадровых.

## Частые ошибки

- Вызывать `gotoAndPlay(0)` / менять `textures` каждый кадр — анимация застывает на первом кадре.
- Забыть `play()` — `AnimatedSprite` показывает первый кадр и стоит.
- Путать `animationSpeed` с кадрами в секунду: это доля кадра за тик, и она зависит от `ticker.speed`.
- Уничтожать текстуры вместе с `AnimatedSprite` из общего атласа (`destroy({ texture: true })`).
- Анимировать через `setTimeout`/`setInterval` — анимации не синхронизированы с тикером и паузой.

## Что важно помнить

- Свойства — в `app.ticker.add`, с `deltaMS` или `deltaTime`.
- `AnimatedSprite(textures)` + `animationSpeed` + `play()`.
- Кадры — из `sheet.animations.<name>` JSON-атласа.
- Переключение анимаций — по состоянию и только при изменении.
- `onComplete`, `onFrameChange` — для неповторяющихся анимаций и событий по кадрам.

## Мини-шпаргалка

```ts
const sheet = await Assets.load('/hero.json');
const a = new AnimatedSprite(sheet.animations.run);
a.animationSpeed = 0.2; a.loop = true; a.play();
a.textures = sheet.animations.idle; a.gotoAndPlay(0);
a.onComplete = () => {};
```
