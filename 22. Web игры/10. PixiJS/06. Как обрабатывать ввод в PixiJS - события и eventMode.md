# Как обрабатывать ввод в PixiJS — события и eventMode

> [!NOTE]
> В отличие от canvas 2D, в PixiJS события вешаются **прямо на объекты**: `sprite.on('pointerdown', handler)`. Чтобы объект реагировал, ему задают `eventMode`: `'static'` — для кнопок и объектов, которые не двигаются сами (самый частый вариант), `'dynamic'` — для движущихся объектов, которым нужны события hover даже без движения мыши, `'passive'` (по умолчанию) — сам не ловит, но пропускает события к детям, `'none'` — полностью игнорирует, экономя проверки. События всплывают по дереву, как в DOM, используют модель Pointer Events (мышь, касание и перо — одним кодом), а `event.global` даёт координаты на экране. Клавиатуру PixiJS не обрабатывает — для неё используют обычные `keydown`/`keyup`.

## Вопрос

Как сделать объекты PixiJS интерактивными: клики, наведение, перетаскивание? Что такое `eventMode`?

## Кнопка

```ts
import { Container, Graphics, Text } from 'pixi.js';

function createButton(label: string, onClick: () => void) {
  const btn = new Container();
  const bg = new Graphics().roundRect(0, 0, 180, 48, 10).fill(0x2563eb);
  const text = new Text({ text: label, style: { fill: 0xffffff, fontSize: 20 } });
  text.anchor.set(0.5);
  text.position.set(90, 24);
  btn.addChild(bg, text);

  btn.eventMode = 'static';     // ловит события
  btn.cursor = 'pointer';       // курсор-рука

  btn.on('pointerover', () => (bg.tint = 0xbfdbfe));
  btn.on('pointerout', () => (bg.tint = 0xffffff));
  btn.on('pointerdown', () => btn.scale.set(0.96));
  btn.on('pointerup', () => btn.scale.set(1));
  btn.on('pointertap', onClick);   // «клик»: down и up на одном объекте

  return btn;
}

app.stage.addChild(createButton('Играть', startGame));
```

## eventMode

| Значение | Поведение |
| --- | --- |
| `'none'` | не ловит события, дети тоже не проверяются — для декораций и тысяч частиц |
| `'passive'` | по умолчанию: сам не ловит, дети могут |
| `'auto'` | ловит, только если есть интерактивный родитель |
| `'static'` | ловит события; для UI и неподвижных объектов |
| `'dynamic'` | как static + синтетические события hover при движении объекта под неподвижным курсором |

```ts
// много декораций — отключить проверку попаданий для всего поддерева
particlesContainer.eventMode = 'none';
// или только детей: container.interactiveChildren = false
```

## Область попадания

```ts
import { Circle, Rectangle } from 'pixi.js';

coin.hitArea = new Circle(0, 0, 24);            // круглая зона вместо прямоугольника текстуры
smallIcon.hitArea = new Rectangle(-30, -30, 60, 60); // увеличить зону для пальца на мобильных
```

Без `hitArea` PixiJS проверяет границы объекта. Явная `hitArea` ещё и быстрее.

## Клик по «пустому месту» сцены

У `stage` нет размеров, пока в нём нет объектов, поэтому для событий по всему экрану:

```ts
app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;                 // вся видимая область

app.stage.on('pointerdown', (e) => {
  const p = world.toLocal(e.global);            // экран → координаты мира (с учётом камеры)
  spawnBullet(player.x, player.y, Math.atan2(p.y - player.y, p.x - player.x));
});

app.stage.on('pointermove', (e) => {
  aim.position.copyFrom(e.global);              // прицел за курсором
});
```

## Перетаскивание

```ts
import type { FederatedPointerEvent } from 'pixi.js';

let dragTarget: Container | null = null;
const offset = { x: 0, y: 0 };

card.eventMode = 'static';
card.cursor = 'grab';
card.on('pointerdown', (e) => {
  dragTarget = card;
  const local = card.parent!.toLocal(e.global);
  offset.x = card.x - local.x;
  offset.y = card.y - local.y;
  card.parent!.addChild(card);                  // поднять наверх
  app.stage.on('globalpointermove', onDragMove); // события даже вне карты
});

function onDragMove(e: FederatedPointerEvent) {
  if (!dragTarget) return;
  const local = dragTarget.parent!.toLocal(e.global);
  dragTarget.position.set(local.x + offset.x, local.y + offset.y);
}

app.stage.on('pointerup', stopDrag);
app.stage.on('pointerupoutside', stopDrag);

function stopDrag() {
  dragTarget = null;
  app.stage.off('globalpointermove', onDragMove);
}
```

`globalpointermove` приходит при любом движении указателя, даже если он не над объектом, — то, что нужно для drag.

## Всплытие

```ts
inventory.on('pointertap', (e) => {
  console.log(e.target);        // конкретный слот, по которому кликнули
  console.log(e.currentTarget); // inventory
});

slot.on('pointertap', (e) => {
  e.stopPropagation();          // не передавать родителю
});
```

## Клавиатура

PixiJS не обрабатывает клавиши — используйте класс из урока про клавиатуру:

```ts
const keys = new Set<string>();
addEventListener('keydown', (e) => keys.add(e.code));
addEventListener('keyup', (e) => keys.delete(e.code));

app.ticker.add((t) => {
  const dt = t.deltaMS / 1000;
  if (keys.has('ArrowLeft')) player.x -= 250 * dt;
  if (keys.has('ArrowRight')) player.x += 250 * dt;
});
```

## Частые ошибки

- Забыть `eventMode = 'static'` — обработчики не вызываются.
- Использовать устаревшее `interactive = true` и `buttonMode` из v6–v7.
- Ловить клики на `stage` без `hitArea` — события приходят только над объектами.
- Брать `e.global` как мировые координаты, когда мир сдвинут камерой, — нужен `world.toLocal(e.global)`.
- Оставлять `eventMode` по умолчанию у тысяч частиц — лишние проверки попаданий при каждом движении мыши.

## Что важно помнить

- События на объектах: `obj.on('pointerdown' | 'pointertap' | 'pointerover' …)`.
- `eventMode = 'static'` для интерактивных объектов, `'none'` — для декораций.
- `hitArea` задаёт форму и размер зоны нажатия.
- `stage.hitArea = app.screen` — события по всему экрану.
- Drag — через `globalpointermove`, клавиатура — обычными DOM-событиями.

## Мини-шпаргалка

```ts
obj.eventMode = 'static'; obj.cursor = 'pointer';
obj.on('pointertap', (e) => e.global);
app.stage.eventMode = 'static'; app.stage.hitArea = app.screen;
world.toLocal(e.global);
```
