# Что такое PixiJS и когда его выбирать

> [!NOTE]
> **PixiJS** — быстрый 2D-рендерер для веба на **WebGL и WebGPU** (с v8). Он берёт на себя всю низкоуровневую работу с GPU — шейдеры, буферы, **батчинг** спрайтов — и даёт удобный **граф сцены**: объекты (`Sprite`, `Graphics`, `Text`) вкладываются в `Container`, у каждого есть `x`, `y`, `rotation`, `scale`, `alpha`, и PixiJS сам перерисовывает сцену каждый кадр. В отличие от canvas 2D, это **retained mode**: вы меняете свойства объектов, а не рисуете их вручную. PixiJS — **не игровой движок**: в нём нет физики, сцен, звука (есть отдельный `@pixi/sound`) и тайлмапов «из коробки». Его выбирают, когда нужна максимальная скорость 2D-графики и гибкость: игры, интерактивные баннеры, визуализации, редакторы.

## Вопрос

Что такое PixiJS, чем он отличается от «чистого» canvas 2D и от игровых движков вроде Phaser?

## Canvas 2D vs PixiJS

```ts
// Canvas 2D — immediate mode: рисуем всё сами каждый кадр
function render() {
  ctx.clearRect(0, 0, w, h);
  ctx.save();
  ctx.translate(bunny.x, bunny.y);
  ctx.rotate(bunny.rotation);
  ctx.drawImage(bunnyImg, -13, -18);
  ctx.restore();
}

// PixiJS — retained mode: создали объект, дальше меняем свойства
const bunny = new Sprite(texture);
bunny.anchor.set(0.5);
app.stage.addChild(bunny);

app.ticker.add((ticker) => {
  bunny.rotation += 0.05 * ticker.deltaTime;   // отрисовкой занимается PixiJS
});
```

| | Canvas 2D | PixiJS |
| --- | --- | --- |
| Модель | immediate: рисуем вызовами | retained: дерево объектов |
| Рендер | 2D-контекст | WebGL / WebGPU, батчинг |
| Объектов за кадр | тысячи | десятки и сотни тысяч |
| Иерархия, трансформации | вручную `save`/`restore` | `Container` с вложенностью |
| События на объектах | hit testing вручную | `sprite.on('pointerdown')` |
| Фильтры (blur, glow, шейдеры) | `ctx.filter`, медленно | на GPU |
| Размер | 0 КБ | заметный, но tree-shaking уменьшает |

## PixiJS vs Phaser

| | PixiJS | Phaser |
| --- | --- | --- |
| Что это | рендерер | полноценный игровой движок |
| Сцены, загрузка, звук, ввод | частично, остальное — сами | всё встроено |
| Физика | нет (подключаете Matter.js и т.п.) | Arcade Physics, Matter.js |
| Тайлмапы | плагины | встроены, Tiled из коробки |
| Гибкость и архитектура | полная свобода | «путь Phaser»: Scene, GameObject |
| Подходит | нестандартные игры, графика, UI, интеграция в приложение | классические 2D-игры, быстрый старт |

## Из чего состоит PixiJS

```text
Application ── renderer (WebGL/WebGPU)  — рисует
            ├─ ticker                  — игровой цикл на rAF
            └─ stage: Container        — корень графа сцены
                 ├─ Container (world)
                 │    ├─ Sprite (player)
                 │    ├─ Sprite (enemy) ...
                 │    └─ Graphics (bullet)
                 └─ Container (ui)
                      └─ Text (score)
Assets — загрузка текстур, спрайт-листов, шрифтов, JSON
```

## Установка

```bash
npm create pixi.js@latest   # шаблон проекта (Vite + TS)
# или в существующий проект
npm i pixi.js
```

```ts
import { Application, Assets, Sprite } from 'pixi.js';
```

## Что изменилось в v8

Если встречаете старые примеры, обратите внимание на главное:

| v7 и раньше | v8 |
| --- | --- |
| `new Application({ ... })` | `const app = new Application(); await app.init({ ... })` |
| `app.view` | `app.canvas` |
| `graphics.beginFill(c).drawRect(...).endFill()` | `graphics.rect(...).fill(c)` |
| `new Text('hi', style)` | `new Text({ text: 'hi', style })` |
| `sprite.interactive = true` | `sprite.eventMode = 'static'` |
| `ticker.add((delta) => …)` | `ticker.add((ticker) => ticker.deltaTime)` |
| `@pixi/*` пакеты по отдельности | единый пакет `pixi.js` |
| только WebGL | WebGL и WebGPU (`preference: 'webgpu'`) |

## Когда выбирать PixiJS

- Много объектов и эффектов — нужен GPU.
- Игра или анимация встраивается в существующее приложение (React, Vue), и нужен лёгкий рендерер, а не движок со своей архитектурой.
- Нестандартная графика: интерактивные инфографики, слоты, карточные игры, редакторы, анимированные лендинги.
- Хотите свою архитектуру (ECS, свои сцены) и выбирать физику и звук самостоятельно.

Когда **не** нужен: простая игра на сотню объектов (хватит canvas 2D), полноценный платформер с физикой и тайлами (быстрее начать на Phaser), 3D (Three.js).

## Частые ошибки

- Ожидать от PixiJS физику и сцены — это рендерер.
- Копировать примеры v7 в проект на v8: `beginFill`, синхронный `new Application({...})`, `app.view` уже не работают.
- Создавать новые объекты и текстуры каждый кадр вместо изменения свойств существующих.

## Что важно помнить

- PixiJS — 2D-рендерер на WebGL/WebGPU с графом сцены.
- Retained mode: меняем свойства объектов, PixiJS рисует сам.
- Батчинг делает его в разы быстрее canvas 2D на больших сценах.
- Для полноценного движка со сценами и физикой — Phaser.

## Мини-шпаргалка

```ts
const app = new Application();
await app.init({ resizeTo: window });
document.body.appendChild(app.canvas);
const sprite = Sprite.from(await Assets.load('/bunny.png'));
app.stage.addChild(sprite);
```
