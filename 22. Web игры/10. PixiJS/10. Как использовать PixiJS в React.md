# Как использовать PixiJS в React

> [!NOTE]
> Есть два способа. **Императивный**: React-компонент создаёт `Application` в `useEffect`, вставляет `app.canvas` в `div` через ref и уничтожает приложение в cleanup — игра живёт отдельно, React рисует только интерфейс вокруг. **Декларативный**: библиотека **`@pixi/react`** (v8, для React 19) превращает сцену в JSX: `<Application>` создаёт приложение, компоненты PixiJS регистрируются через `extend({ Container, Sprite, Graphics })` и используются как `<pixiSprite />`, `<pixiContainer />`, а хук `useTick` подписывается на тикер. Важное правило то же, что и для canvas: **значения, меняющиеся каждый кадр, не держат в `useState`** — используют ref и меняют свойства объекта напрямую в `useTick`.

## Вопрос

Как подключить PixiJS в React-приложение: вручную через `useEffect` и через `@pixi/react`?

## Императивно: своя обёртка

```tsx
'use client';
import { useEffect, useRef } from 'react';
import { Application, Assets, Sprite } from 'pixi.js';

export function PixiGame() {
  const hostRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const app = new Application();
    let cancelled = false;

    (async () => {
      await app.init({ resizeTo: hostRef.current!, background: '#0f172a' });
      if (cancelled) { app.destroy(true); return; }  // компонент уже размонтирован (Strict Mode)
      hostRef.current!.appendChild(app.canvas);

      const bunny = new Sprite(await Assets.load('https://pixijs.com/assets/bunny.png'));
      bunny.anchor.set(0.5);
      bunny.position.set(app.screen.width / 2, app.screen.height / 2);
      app.stage.addChild(bunny);
      app.ticker.add((t) => (bunny.rotation += 0.05 * t.deltaTime));
    })();

    return () => {
      cancelled = true;
      if (app.renderer) app.destroy({ removeView: true }, { children: true });
    };
  }, []);

  return <div ref={hostRef} className="h-[480px] w-full" />;
}
```

Флаг `cancelled` нужен, потому что `init` асинхронный: в Strict Mode эффект монтируется, размонтируется и монтируется снова, и первый `init` может завершиться уже после cleanup.

## @pixi/react

```bash
npm i pixi.js @pixi/react
```

```tsx
'use client';
import { Application, extend, useTick } from '@pixi/react';
import { Assets, Container, Graphics, Sprite, Texture } from 'pixi.js';
import { useCallback, useEffect, useRef, useState } from 'react';

// регистрируем классы PixiJS → в JSX появляются <pixiContainer>, <pixiSprite>, <pixiGraphics>
extend({ Container, Graphics, Sprite });

function Bunny({ x, y }: { x: number; y: number }) {
  const ref = useRef<Sprite>(null);
  const [texture, setTexture] = useState(Texture.EMPTY);
  const [hovered, setHovered] = useState(false);

  useEffect(() => {
    Assets.load('https://pixijs.com/assets/bunny.png').then(setTexture);
  }, []);

  // каждый кадр — без ререндера React
  useTick((ticker) => {
    if (ref.current) ref.current.rotation += 0.05 * ticker.deltaTime;
  });

  return (
    <pixiSprite
      ref={ref}
      texture={texture}
      x={x}
      y={y}
      anchor={0.5}
      scale={hovered ? 1.5 : 1}               // редкие изменения — можно через state
      eventMode="static"
      cursor="pointer"
      onPointerOver={() => setHovered(true)}
      onPointerOut={() => setHovered(false)}
    />
  );
}

function HealthBar({ value }: { value: number }) {
  const draw = useCallback((g: Graphics) => {
    g.clear();
    g.rect(0, 0, 200, 16).fill(0x1f2937);
    g.rect(0, 0, 200 * value, 16).fill(value > 0.3 ? 0x22c55e : 0xef4444);
  }, [value]);                                 // перерисовка только при изменении value

  return <pixiGraphics draw={draw} x={16} y={16} />;
}

export function Scene() {
  const parentRef = useRef<HTMLDivElement>(null);
  const [hp, setHp] = useState(1);

  return (
    <div ref={parentRef} className="h-[480px] w-full">
      <Application resizeTo={parentRef} background="#1e293b" antialias>
        <pixiContainer>
          <Bunny x={200} y={240} />
          <Bunny x={400} y={240} />
        </pixiContainer>
        <HealthBar value={hp} />
      </Application>
      <button onClick={() => setHp((v) => Math.max(0, v - 0.1))}>Урон</button>
    </div>
  );
}
```

## Правила для производительности

| Что меняется | Как обновлять |
| --- | --- |
| Каждый кадр (позиция, вращение, анимация) | `ref` + `useTick`, прямое изменение свойств |
| Редко (hover, выбор, HP, состояние меню) | props/state — нормально |
| Игровая логика с сотнями объектов | отдельный игровой мир (класс, ECS), а React-компоненты только отображают |

```tsx
// ❌ 60 ререндеров в секунду
const [x, setX] = useState(0);
useTick(() => setX((x) => x + 1));

// ✅
const ref = useRef<Sprite>(null);
useTick(() => { ref.current!.x += 1; });
```

## Доступ к приложению

```tsx
import { useApplication } from '@pixi/react';

function Hud() {
  const { app } = useApplication();       // внутри <Application>
  return <pixiText text="Score: 0" x={app.screen.width - 120} y={16} style={{ fill: 0xffffff }} />;
}
```

Для `<pixiText>` класс `Text` тоже нужно зарегистрировать через `extend`.

## TypeScript

Для типизации JSX-элементов подключите типы библиотеки (в `global.d.ts` или `tsconfig`):

```ts
// global.d.ts
import type { PixiReactElementProps } from '@pixi/react';
import type { Viewport } from 'pixi-viewport';

declare module '@pixi/react' {
  interface PixiElements {
    viewport: PixiReactElementProps<typeof Viewport>; // свои/сторонние классы
  }
}
```

Встроенные классы, зарегистрированные через `extend`, типизируются автоматически с префиксом `pixi`.

## Что выбрать

| | Императивно (`useEffect`) | `@pixi/react` |
| --- | --- | --- |
| Игра с собственным циклом и сущностями | ✅ проще и предсказуемее | возможно, но React мешает |
| Интерактивные визуализации, UI-сцены, анимированные виджеты | много ручного кода | ✅ декларативно |
| Интеграция с состоянием React | через события и колбэки | props напрямую |

Phaser в React подключают так же, как в императивном варианте: создают `Phaser.Game` в эффекте и вызывают `game.destroy(true)` в cleanup.

## Частые ошибки

- Хранить позиции объектов в `useState` и обновлять в `useTick`.
- Забыть `extend({...})` — `<pixiSprite>` не распознаётся.
- Использовать `@pixi/react` v7 (`<Stage>`, `<Sprite>`) с PixiJS v8 — нужна v8 библиотеки (`<Application>`, `<pixiSprite>`) и React 19.
- Не дожидаться `init` в императивном варианте и не обрабатывать размонтирование до окончания инициализации.
- Создавать `draw`-функцию для `pixiGraphics` без `useCallback` — фигура перерисовывается на каждый рендер.

## Что важно помнить

- Императивно: `Application` в `useEffect`, `app.destroy()` в cleanup, флаг отмены для async `init`.
- `@pixi/react`: `extend` + `<Application>` + `<pixiSprite>` + `useTick`.
- Каждый кадр — через ref, редкие изменения — через props/state.
- Сложную игровую логику держите вне React.

## Мини-шпаргалка

```tsx
extend({ Container, Sprite, Graphics });
<Application resizeTo={ref} background="#000">
  <pixiSprite texture={tex} anchor={0.5} x={100} y={100} />
</Application>
useTick((t) => { ref.current!.rotation += 0.1 * t.deltaTime; });
```
