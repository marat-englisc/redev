# Как загружать ресурсы и создавать спрайты — Assets и Sprite

> [!NOTE]
> Ресурсы в PixiJS загружаются через **`Assets`** — асинхронный загрузчик с кешем: `await Assets.load(url)` возвращает готовую `Texture` (или `Spritesheet` для JSON-атласа, шрифт, JSON). Повторная загрузка того же URL берётся из кеша. Ресурсы удобно описывать **бандлами** (`Assets.addBundle` / манифест) и грузить пачками с прогрессом, а следующий уровень — подгружать фоном (`Assets.backgroundLoad`). **`Sprite`** — объект, который рисует текстуру. Главные свойства: `position`, `anchor` (точка привязки от 0 до 1), `scale`, `rotation` (радианы), `alpha`, `tint` (окрашивание), `visible`. Одна текстура может использоваться тысячами спрайтов — память не дублируется.

## Вопрос

Как в PixiJS загрузить картинки и спрайт-листы и вывести их на сцену?

## Загрузка одной текстуры

```ts
import { Assets, Sprite } from 'pixi.js';

const texture = await Assets.load('/sprites/hero.png');
const hero = new Sprite(texture);
app.stage.addChild(hero);

// или сразу из кеша/по алиасу — после загрузки
const hero2 = Sprite.from('/sprites/hero.png');
```

`Sprite.from(url)` не загружает файл — он берёт текстуру из кеша, поэтому сначала `Assets.load`.

## Алиасы и несколько файлов

```ts
Assets.add({ alias: 'hero', src: '/sprites/hero.png' });
Assets.add({ alias: 'coin', src: '/sprites/coin.png' });

const { hero, coin } = await Assets.load(['hero', 'coin']);
const sprite = Sprite.from('hero');
```

## Бандлы и экран загрузки

```ts
await Assets.init({
  basePath: '/assets/',
  manifest: {
    bundles: [
      {
        name: 'loading',
        assets: [{ alias: 'logo', src: 'logo.png' }],
      },
      {
        name: 'game',
        assets: [
          { alias: 'atlas', src: 'atlas.json' },            // спрайт-лист: PNG подтянется сам
          { alias: 'level1', src: 'levels/level1.json' },
          { alias: 'pixelFont', src: 'fonts/pixel.woff2' },
        ],
      },
    ],
  },
});

await Assets.loadBundle('loading');             // сначала маленький бандл для экрана загрузки
showLoadingScreen();

await Assets.loadBundle('game', (progress) => { // 0..1
  progressBar.width = 300 * progress;
});

Assets.backgroundLoadBundle('level2');           // фоном, пока игрок проходит первый уровень
```

## Свойства спрайта

```ts
const s = new Sprite(texture);

s.position.set(400, 300);      // или s.x, s.y
s.anchor.set(0.5);             // центр: вращение и масштаб вокруг центра
s.anchor.set(0.5, 1);          // низ по центру — удобно для персонажей на земле
s.scale.set(2);                // в 2 раза больше
s.scale.x = -1;                // отражение по горизонтали
s.rotation = Math.PI / 4;      // радианы (или s.angle = 45 — градусы)
s.alpha = 0.5;
s.tint = 0xff0000;             // окрасить в красный (умножение цвета)
s.visible = false;             // не рисуется и не обрабатывает события
s.width = 64;                  // размер в пикселях (меняет scale)

s.texture = otherTexture;      // смена картинки без пересоздания спрайта
```

`tint` удобен для «вспышки» при уроне и для одного серого спрайта врага в разных цветах.

## Спрайт-лист (атлас)

Атлас — PNG + JSON (формат TexturePacker / free-tex-packer / Aseprite). PixiJS сам загрузит картинку, указанную в JSON:

```ts
const sheet = await Assets.load('/assets/atlas.json');  // Spritesheet

const coin = new Sprite(sheet.textures['coin.png']);
// или, т.к. кадры атласа попадают в кеш по имени:
const enemy = Sprite.from('enemy_idle_0.png');
```

Все спрайты с одного атласа рисуются **одним пакетом** — это главный способ ускорить сцену в PixiJS.

## Пиксель-арт

```ts
import { TextureStyle } from 'pixi.js';

TextureStyle.defaultOptions.scaleMode = 'nearest'; // до загрузки текстур: без размытия

// или для конкретной текстуры
texture.source.scaleMode = 'nearest';
```

Дополнительно держите позиции целыми (`Math.round`) — иначе пиксели «плывут». В `init` есть опция `roundPixels: true`.

## Повторяющийся фон: TilingSprite

```ts
import { TilingSprite } from 'pixi.js';

const bg = new TilingSprite({
  texture: await Assets.load('/assets/stars.png'),
  width: app.screen.width,
  height: app.screen.height,
});
app.stage.addChild(bg);

app.ticker.add((t) => {
  bg.tilePosition.y += 1 * t.deltaTime;  // бесконечная прокрутка звёзд
});
```

Несколько `TilingSprite` с разной скоростью — готовый параллакс.

## NineSliceSprite для UI

```ts
import { NineSliceSprite, Texture } from 'pixi.js';

// углы 12px не растягиваются — кнопка любого размера из маленькой картинки
const panel = new NineSliceSprite({
  texture: Texture.from('panel.png'),
  leftWidth: 12, topHeight: 12, rightWidth: 12, bottomHeight: 12,
});
panel.width = 300;
panel.height = 120;
```

## Выгрузка

```ts
await Assets.unloadBundle('level1');  // освободить память GPU при смене уровня
await Assets.unload('/sprites/boss.png');
```

## Частые ошибки

- `Sprite.from(url)` до `Assets.load` — пустая текстура или ошибка.
- Отдельный PNG на каждый кадр/объект вместо атласа — батчинг не работает, сотни запросов.
- Забыть `anchor` и удивляться, что спрайт вращается вокруг угла.
- Создавать `new Texture` / `Texture.from` на лету в цикле.
- Не выгружать ресурсы прошлых уровней в больших играх — растёт память GPU.

## Что важно помнить

- `Assets.load` — асинхронная загрузка с кешем, бандлы — для экранов загрузки.
- `Sprite` рисует `Texture`; одна текстура — много спрайтов.
- `anchor` задаёт точку вращения и позиционирования.
- Атласы — основа производительности.
- `TilingSprite` — фоны и параллакс, `NineSliceSprite` — растягиваемый UI.

## Мини-шпаргалка

```ts
const tex = await Assets.load('/hero.png');
const s = new Sprite(tex); s.anchor.set(0.5); app.stage.addChild(s);
const sheet = await Assets.load('/atlas.json'); new Sprite(sheet.textures['coin.png']);
await Assets.loadBundle('game', (p) => {});
```
