# Пишем мини-игру на PixiJS — космический шутер

> [!NOTE]
> Соберём всё из раздела PixiJS в одну игру: корабль летит за курсором и стреляет, сверху падают астероиды, пули их разбивают, при столкновении с кораблём теряется жизнь. Структура: `Application` + контейнеры-слои (`background`, `world`, `ui`), бесконечный звёздный фон на `TilingSprite`, объекты из `Graphics`, запечённых в текстуры (так всё батчится как спрайты), игровой цикл в `app.ticker` с `dt` в секундах, пул пуль, столкновения кругами, взрывы из частиц и счёт на `BitmapText`. Всё работает без внешних картинок — достаточно установить `pixi.js`.

## Вопрос

Как собрать небольшую законченную игру на PixiJS v8?

## Подготовка

```bash
npm create vite@latest space-shooter -- --template vanilla-ts
cd space-shooter
npm i pixi.js
```

## Шаг 1. Приложение и слои

```ts
// src/main.ts
import {
  Application, BitmapFont, BitmapText, Container, Graphics,
  Sprite, TilingSprite, type Ticker,
} from 'pixi.js';

const app = new Application();
await app.init({ resizeTo: window, background: '#020617', antialias: true });
document.body.appendChild(app.canvas);

const background = new Container();
const world = new Container();
const ui = new Container();
app.stage.addChild(background, world, ui);

app.stage.eventMode = 'static';
app.stage.hitArea = app.screen;
```

## Шаг 2. Текстуры из Graphics

```ts
const tex = (g: Graphics) => app.renderer.generateTexture(g);

const shipTex = tex(new Graphics().poly([0, -18, 14, 14, 0, 6, -14, 14]).fill(0x38bdf8));
const bulletTex = tex(new Graphics().roundRect(0, 0, 4, 14, 2).fill(0xfde047));
const rockTex = tex(
  new Graphics()
    .poly([0, -24, 18, -14, 24, 6, 10, 22, -12, 20, -24, 2, -16, -18])
    .fill(0x78716c)
    .stroke({ width: 2, color: 0xa8a29e }),
);
const sparkTex = tex(new Graphics().circle(0, 0, 3).fill(0xffffff));

// звёздное небо: маленькая текстура, которая повторяется
const starsG = new Graphics();
for (let i = 0; i < 60; i++) {
  starsG.circle(Math.random() * 256, Math.random() * 256, Math.random() * 1.5).fill({ color: 0xffffff, alpha: 0.7 });
}
const starsTex = tex(starsG.rect(0, 0, 256, 256).fill({ color: 0x000000, alpha: 0 }));
```

Все объекты — спрайты, поэтому сцена батчится в несколько draw calls.

## Шаг 3. Фон, корабль, интерфейс

```ts
const stars = new TilingSprite({ texture: starsTex, width: app.screen.width, height: app.screen.height });
background.addChild(stars);
app.renderer.on('resize', (w, h) => { stars.width = w; stars.height = h; });

const ship = new Sprite(shipTex);
ship.anchor.set(0.5);
ship.position.set(app.screen.width / 2, app.screen.height - 80);
world.addChild(ship);

BitmapFont.install({ name: 'Hud', style: { fontFamily: 'monospace', fontSize: 22, fill: 0xffffff } });
const hud = new BitmapText({ text: '', style: { fontFamily: 'Hud', fontSize: 22 } });
hud.position.set(16, 16);
ui.addChild(hud);

const message = new BitmapText({ text: '', style: { fontFamily: 'Hud', fontSize: 32 } });
message.anchor.set(0.5);
ui.addChild(message);
```

## Шаг 4. Состояние и ввод

```ts
interface Body { sprite: Sprite; vx: number; vy: number; r: number }
interface Rock extends Body { spin: number; hp: number }
interface Spark { sprite: Sprite; vx: number; vy: number; life: number }

const bullets: Body[] = [];
const rocks: Rock[] = [];
const sparks: Spark[] = [];
const bulletPool: Sprite[] = [];

const state = { score: 0, lives: 3, cooldown: 0, spawnTimer: 0, invulnerable: 0, over: false, firing: false };
const target = { x: ship.x, y: ship.y };

app.stage.on('pointermove', (e) => target.x = e.global.x);
app.stage.on('pointerdown', () => { state.firing = true; if (state.over) restart(); });
app.stage.on('pointerup', () => (state.firing = false));
addEventListener('keydown', (e) => { if (e.code === 'Space') state.firing = true; });
addEventListener('keyup', (e) => { if (e.code === 'Space') state.firing = false; });
```

## Шаг 5. Создание объектов

```ts
function shoot() {
  const s = bulletPool.pop() ?? new Sprite(bulletTex);
  s.anchor.set(0.5);
  s.visible = true;
  s.position.set(ship.x, ship.y - 20);
  world.addChild(s);
  bullets.push({ sprite: s, vx: 0, vy: -900, r: 4 });
}

function spawnRock() {
  const s = new Sprite(rockTex);
  s.anchor.set(0.5);
  const scale = 0.6 + Math.random() * 1.2;
  s.scale.set(scale);
  s.position.set(Math.random() * app.screen.width, -40);
  world.addChild(s);
  rocks.push({
    sprite: s,
    vx: (Math.random() - 0.5) * 80,
    vy: 120 + Math.random() * 120 + state.score * 0.2,   // сложность растёт со счётом
    r: 22 * scale,
    spin: (Math.random() - 0.5) * 3,
    hp: Math.ceil(scale * 2),
  });
}

function explode(x: number, y: number, count: number, tint: number) {
  for (let i = 0; i < count; i++) {
    const s = new Sprite(sparkTex);
    s.anchor.set(0.5);
    s.position.set(x, y);
    s.tint = tint;
    s.blendMode = 'add';
    world.addChild(s);
    const a = Math.random() * Math.PI * 2;
    const v = 60 + Math.random() * 240;
    sparks.push({ sprite: s, vx: Math.cos(a) * v, vy: Math.sin(a) * v, life: 0.4 + Math.random() * 0.4 });
  }
}
```

## Шаг 6. Обновление

```ts
const hit = (a: Body, b: Body) => {
  const dx = a.sprite.x - b.sprite.x, dy = a.sprite.y - b.sprite.y;
  return dx * dx + dy * dy < (a.r + b.r) ** 2;
};

function removeAt<T>(arr: T[], i: number) {
  arr[i] = arr[arr.length - 1];
  arr.pop();
}

function update(ticker: Ticker) {
  const dt = Math.min(ticker.deltaMS / 1000, 0.05);
  stars.tilePosition.y += 60 * dt;

  if (state.over) return;

  // корабль плавно следует за целью
  ship.x += (target.x - ship.x) * (1 - Math.exp(-12 * dt));
  ship.x = Math.max(20, Math.min(app.screen.width - 20, ship.x));
  ship.y = app.screen.height - 80;
  ship.rotation = (target.x - ship.x) * 0.002;    // наклон при движении

  // мигание неуязвимости
  state.invulnerable -= dt;
  ship.alpha = state.invulnerable > 0 && Math.floor(state.invulnerable * 10) % 2 ? 0.3 : 1;

  // стрельба
  state.cooldown -= dt;
  if (state.firing && state.cooldown <= 0) { shoot(); state.cooldown = 0.12; }

  // появление астероидов
  state.spawnTimer -= dt;
  if (state.spawnTimer <= 0) { spawnRock(); state.spawnTimer = Math.max(0.25, 1 - state.score / 2000); }

  // пули
  for (let i = bullets.length - 1; i >= 0; i--) {
    const b = bullets[i];
    b.sprite.y += b.vy * dt;
    if (b.sprite.y < -20) releaseBullet(i);
  }

  // астероиды
  for (let i = rocks.length - 1; i >= 0; i--) {
    const r = rocks[i];
    r.sprite.x += r.vx * dt;
    r.sprite.y += r.vy * dt;
    r.sprite.rotation += r.spin * dt;

    if (r.sprite.y > app.screen.height + 50) { r.sprite.destroy(); removeAt(rocks, i); continue; }

    // пуля попала
    for (let j = bullets.length - 1; j >= 0; j--) {
      if (!hit(r, bullets[j])) continue;
      releaseBullet(j);
      r.hp--;
      r.sprite.tint = 0xfca5a5;
      explode(r.sprite.x, r.sprite.y, 4, 0xfde047);
      break;
    }

    if (r.hp <= 0) {
      state.score += Math.round(r.r * 2);
      explode(r.sprite.x, r.sprite.y, 24, 0xf97316);
      r.sprite.destroy();
      removeAt(rocks, i);
      continue;
    }

    // столкновение с кораблём
    if (state.invulnerable <= 0 && hit(r, { sprite: ship, vx: 0, vy: 0, r: 14 })) {
      state.lives--;
      state.invulnerable = 1.5;
      explode(ship.x, ship.y, 40, 0x38bdf8);
      r.sprite.destroy();
      removeAt(rocks, i);
      if (state.lives <= 0) gameOver();
    }
  }

  // частицы
  for (let i = sparks.length - 1; i >= 0; i--) {
    const p = sparks[i];
    p.life -= dt;
    if (p.life <= 0) { p.sprite.destroy(); removeAt(sparks, i); continue; }
    p.sprite.x += p.vx * dt;
    p.sprite.y += p.vy * dt;
    p.sprite.alpha = p.life * 2;
  }

  hud.text = `SCORE ${state.score}   LIVES ${'*'.repeat(state.lives)}`;
}

function releaseBullet(i: number) {
  const s = bullets[i].sprite;
  s.visible = false;
  s.removeFromParent();
  bulletPool.push(s);
  removeAt(bullets, i);
}

app.ticker.add(update);
```

## Шаг 7. Конец и перезапуск

```ts
function gameOver() {
  state.over = true;
  ship.visible = false;
  message.text = `GAME OVER\nSCORE ${state.score}\nCLICK TO RESTART`;
  message.position.set(app.screen.width / 2, app.screen.height / 2);
}

function restart() {
  for (const r of rocks) r.sprite.destroy();
  rocks.length = 0;
  while (bullets.length) releaseBullet(bullets.length - 1);
  Object.assign(state, { score: 0, lives: 3, over: false, invulnerable: 1, spawnTimer: 1 });
  ship.visible = true;
  message.text = '';
}
```

## Что можно улучшить

| Идея | Как |
| --- | --- |
| Тысячи частиц | `ParticleContainer` + `Particle` вместо `Sprite` |
| Картинки вместо фигур | атлас + `Assets.load('atlas.json')` |
| Звук выстрелов и взрывов | `@pixi/sound` или Howler |
| Пауза с размытием | `world.filters = [new BlurFilter()]`, `app.ticker.speed = 0` |
| Тряска экрана | случайное смещение `world.position` в течение 0,2 с |
| Бонусы и волны врагов | сущности со своими `update`, FSM для врагов |
| Пул для частиц и астероидов | как для пуль |

## Частые ошибки

- Создавать `Graphics` для каждой пули — используйте текстуры из `generateTexture` и пул.
- Удалять элементы массива в прямом обходе — обходим с конца и делаем swap-remove.
- Брать `ticker.deltaTime` как секунды — скорость будет в 60 раз меньше ожидаемой.
- Забыть `stage.hitArea` — `pointermove` не приходит над пустым фоном.

## Что важно помнить

- Слои: `background`, `world`, `ui` — разные контейнеры.
- `Graphics` → `generateTexture` → `Sprite` — фигуры, которые батчатся.
- Логика в `app.ticker.add(update)`, `dt = deltaMS / 1000`.
- Пул для часто создаваемых объектов, круги для столкновений, `BitmapText` для HUD.
