# Как устроен граф сцены — Container, трансформации и zIndex

> [!NOTE]
> Сцена PixiJS — дерево: корень `app.stage`, внутри — `Container`, а в них спрайты, фигуры, текст и другие контейнеры. Трансформации **наследуются**: если сдвинуть, повернуть, отмасштабировать или сделать полупрозрачным контейнер, то же произойдёт со всеми его детьми — так устроены камера (двигаем контейнер `world`), персонаж с оружием, полоска здоровья над врагом. Порядок отрисовки — порядок детей: добавленный позже рисуется сверху; для явного управления есть `zIndex` + `sortableChildren` или `RenderLayer`. Перевод координат между системами — `toLocal`/`toGlobal`. Удаление объекта — `removeChild` (можно вернуть) или `destroy()` (освобождает ресурсы навсегда).

## Вопрос

Что такое граф сцены в PixiJS, как работают контейнеры, наследование трансформаций и порядок отрисовки?

## Иерархия

```ts
import { Container, Sprite } from 'pixi.js';

const world = new Container();       // всё, что двигается камерой
const ui = new Container();          // интерфейс поверх
app.stage.addChild(world, ui);

const tank = new Container();        // «объект» из нескольких частей
const body = Sprite.from('tank_body.png');
const turret = Sprite.from('tank_turret.png');
body.anchor.set(0.5);
turret.anchor.set(0.2, 0.5);         // точка вращения башни
tank.addChild(body, turret);
world.addChild(tank);

tank.position.set(300, 200);
tank.rotation = 0.3;                 // поворачивается весь танк
turret.rotation = 1.2;               // башня — относительно корпуса
```

```text
stage
├── world (камера: position = -camera)
│   ├── tilemap
│   ├── tank
│   │   ├── body
│   │   └── turret
│   └── enemies (Container)
└── ui
    ├── scoreText
    └── healthBar
```

## Наследуемые свойства

| Свойство | Что наследуют дети |
| --- | --- |
| `position`, `rotation`, `scale`, `skew`, `pivot` | трансформацию |
| `alpha` | прозрачность (умножается) |
| `visible` | невидимый контейнер скрывает детей |
| `tint` | окрашивание (v8: наследуется детьми) |
| `filters`, `mask` | применяются ко всему поддереву |

## Камера через контейнер

```ts
app.ticker.add(() => {
  const targetX = app.screen.width / 2 - player.x;
  const targetY = app.screen.height / 2 - player.y;
  world.x += (targetX - world.x) * 0.1;   // плавно
  world.y += (targetY - world.y) * 0.1;
});

// зум
world.scale.set(2);
```

`ui` не двигается — он не внутри `world`.

## pivot и anchor

- `anchor` есть у `Sprite`/`Text`: нормированная точка (0..1) внутри текстуры.
- `pivot` есть у любого `Container`: точка в **пикселях** локальных координат, вокруг которой вращение и масштаб.

```ts
const group = new Container();
group.addChild(a, b, c);
const bounds = group.getLocalBounds();
group.pivot.set(bounds.width / 2, bounds.height / 2); // вращать вокруг центра группы
```

## Порядок отрисовки

```ts
world.addChild(background, player, enemy);   // enemy поверх player

world.setChildIndex(player, world.children.length - 1); // поднять наверх
world.addChildAt(shadow, 0);                            // вставить в самый низ

// zIndex: сортировка по числу
world.sortableChildren = true;
player.zIndex = 10;
tree.zIndex = 5;

// вид сверху: кто ниже на экране — тот ближе
app.ticker.add(() => {
  for (const c of world.children) c.zIndex = c.y;
});
```

`RenderLayer` (v8) позволяет рисовать объект в другом слое, не меняя его родителя, — например, полоска здоровья всегда поверх всех врагов, хотя логически принадлежит врагу:

```ts
import { RenderLayer } from 'pixi.js';

const overlay = new RenderLayer();
app.stage.addChild(overlay);
enemy.addChild(healthBar);
overlay.attach(healthBar);   // трансформация от врага, порядок — от слоя
```

## Координаты: локальные и глобальные

```ts
// где на экране находится дуло пушки?
const muzzleGlobal = turret.toGlobal({ x: 40, y: 0 });

// где в мире находится точка клика?
const worldPoint = world.toLocal(event.global);

// границы объекта в глобальных координатах — для простых столкновений
const a = player.getBounds();
const b = enemy.getBounds();
const hit = a.x < b.x + b.width && a.x + a.width > b.x && a.y < b.y + b.height && a.y + a.height > b.y;
```

`getBounds()` пересчитывает трансформации дерева — для сотен проверок за кадр лучше хранить свои хитбоксы в данных сущности.

## Удаление объектов

```ts
world.removeChild(enemy);      // убрать со сцены, объект можно добавить обратно (пул)
enemy.removeFromParent();      // то же самое

enemy.destroy();               // окончательно, объект использовать нельзя
container.destroy({ children: true });  // вместе с детьми
// texture: true — уничтожить и текстуры (только если они больше никому не нужны!)
```

## Игровая сущность поверх Container

```ts
class Enemy extends Container {
  vx = 0;
  vy = 0;
  hp = 3;
  private sprite: Sprite;
  private bar = new HealthBar();

  constructor(texture: Texture) {
    super();
    this.sprite = new Sprite(texture);
    this.sprite.anchor.set(0.5);
    this.bar.position.set(-20, -30);
    this.addChild(this.sprite, this.bar);
  }

  update(dt: number) {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
  }

  hit() {
    this.hp--;
    this.bar.set(this.hp, 3);
    this.sprite.tint = 0xff4444;
    setTimeout(() => (this.sprite.tint = 0xffffff), 80); // лучше через таймер в update
  }
}
```

Наследоваться от `Container` удобно для небольших игр. В больших проектах логику держат отдельно (ECS), а объекты PixiJS — только «вид».

## Частые ошибки

- Двигать каждый объект мира для камеры вместо одного контейнера `world`.
- Класть UI внутрь `world` — интерфейс уезжает вместе с камерой.
- Включать `sortableChildren` и менять `zIndex` у тысяч объектов каждый кадр без необходимости — сортировка стоит времени.
- Вызывать `destroy({ texture: true })` для спрайта с общей текстурой атласа — пропадут все остальные спрайты.
- Путать `anchor` (0..1) и `pivot` (пиксели).

## Что важно помнить

- Сцена — дерево `Container`; трансформации, alpha, visible, фильтры наследуются.
- Камера — сдвиг и масштаб контейнера `world`, UI — отдельный контейнер.
- Порядок отрисовки = порядок детей; `zIndex` + `sortableChildren` или `RenderLayer`.
- `toLocal`/`toGlobal` — перевод координат между узлами.
- `removeChild` — убрать, `destroy` — уничтожить.

## Мини-шпаргалка

```ts
parent.addChild(child); child.removeFromParent();
container.sortableChildren = true; child.zIndex = 10;
world.toLocal(e.global); sprite.toGlobal({ x: 0, y: 0 });
obj.destroy({ children: true });
```
