# Как применять фильтры и эффекты в PixiJS

> [!NOTE]
> **Фильтр** — шейдер, который обрабатывает уже отрисованный объект или целый контейнер на GPU: размытие (`BlurFilter`), цветокоррекция (`ColorMatrixFilter`: чёрно-белое, яркость, оттенок), искажение (`DisplacementFilter`: вода, жар), шум (`NoiseFilter`). Ещё десятки готовых — в пакете **`pixi-filters`**: свечение, контур, CRT, glitch, bloom, старая плёнка. Фильтр задаётся массивом `obj.filters = [...]`; повешенный на контейнер, он применяется ко всему поддереву — так делают эффекты на весь экран (пауза с размытием, «вспышка» при уроне). Фильтры **дорогие**: каждый требует отдельного прохода рендера и прерывает батчинг, поэтому их вешают на контейнеры, а не на тысячи отдельных спрайтов. Для своих эффектов пишут собственный фильтр на GLSL/WGSL.

## Вопрос

Как в PixiJS добавить визуальные эффекты: размытие, цветокоррекцию, свечение, искажения? Как не убить этим производительность?

## Встроенные фильтры

```ts
import { BlurFilter, ColorMatrixFilter, NoiseFilter, AlphaFilter } from 'pixi.js';

// размытие фона при паузе
const blur = new BlurFilter({ strength: 8, quality: 4 });
world.filters = [blur];

// цветокоррекция
const cm = new ColorMatrixFilter();
cm.grayscale(0.3, false);     // ч/б при смерти игрока
// cm.brightness(1.2, false); cm.hue(90, false); cm.sepia(false); cm.contrast(0.5, false)
world.filters = [cm];

// убрать фильтры
world.filters = [];
```

## Эффект на весь экран

```ts
function onPause() {
  world.filters = [new BlurFilter({ strength: 6 })];
  ui.addChild(pauseMenu);
}

function onResume() {
  world.filters = [];
  pauseMenu.removeFromParent();
}
```

Фильтр на `world` размывает игру, а `ui` (меню паузы) остаётся чётким — он в другом контейнере.

## Вода и жар: DisplacementFilter

```ts
import { DisplacementFilter, Sprite, Assets } from 'pixi.js';

const mapTex = await Assets.load('/assets/displacement_map.png'); // серо-голубая шумовая текстура
mapTex.source.addressMode = 'repeat';
const dispSprite = new Sprite(mapTex);
app.stage.addChild(dispSprite);         // спрайт карты должен быть в сцене

const displacement = new DisplacementFilter({ sprite: dispSprite, scale: 30 });
waterContainer.filters = [displacement];

app.ticker.add((t) => {
  dispSprite.x += 1 * t.deltaTime;      // движение карты = «волны»
  dispSprite.y += 0.5 * t.deltaTime;
});
```

## pixi-filters: свечение, контур, CRT

```bash
npm i pixi-filters
```

```ts
import { GlowFilter, OutlineFilter, CRTFilter, AdvancedBloomFilter, ShockwaveFilter } from 'pixi-filters';

// подсветка выбранного юнита
selected.filters = [new OutlineFilter({ thickness: 3, color: 0xfacc15 })];

// неоновое свечение
neonSign.filters = [new GlowFilter({ distance: 15, outerStrength: 2, color: 0x22d3ee })];

// ретро-экран на всю игру
app.stage.filters = [new CRTFilter({ curvature: 2, lineWidth: 2, vignetting: 0.3 })];

// ударная волна от взрыва
const wave = new ShockwaveFilter({ center: { x: 400, y: 300 }, speed: 500, amplitude: 30, wavelength: 160 });
world.filters = [wave];
app.ticker.add((t) => {
  wave.time += t.deltaMS / 1000;
  if (wave.time > 1) world.filters = [];
});
```

## «Вспышка» при уроне без фильтра

Не всё требует фильтров. Простые эффекты дешевле делать свойствами:

```ts
enemy.tint = 0xff0000;              // покраснение — бесплатно, батчинг не ломается
enemy.alpha = 0.5;                  // мигание неуязвимости
sprite.blendMode = 'add';           // аддитивное смешивание для огня и свечения
```

Белая вспышка (`tint` только затемняет) — через `ColorMatrixFilter` с `brightness`, либо отдельной белой «силуэтной» текстурой поверх.

## Свой фильтр

```ts
import { Filter, GlProgram, defaultFilterVert } from 'pixi.js';

const fragment = `
  in vec2 vTextureCoord;
  out vec4 finalColor;
  uniform sampler2D uTexture;
  uniform float uTime;

  void main() {
    vec2 uv = vTextureCoord;
    uv.x += sin(uv.y * 30.0 + uTime * 5.0) * 0.005;  // волнистое искажение
    finalColor = texture(uTexture, uv);
  }
`;

const wavy = new Filter({
  glProgram: GlProgram.from({ vertex: defaultFilterVert, fragment }), // стандартный вершинный шейдер фильтра
  resources: {
    waveUniforms: { uTime: { value: 0, type: 'f32' } },
  },
});

world.filters = [wavy];
app.ticker.add((t) => {
  wavy.resources.waveUniforms.uniforms.uTime += t.deltaMS / 1000;
});
```

Для поддержки WebGPU-рендерера к фильтру добавляют и `gpuProgram` на WGSL. Готовые фильтры из `pixi-filters` уже содержат обе версии.

## Производительность

| Подход | Цена |
| --- | --- |
| `tint`, `alpha`, `blendMode` | почти бесплатно |
| Фильтр на один контейнер | один дополнительный проход |
| Фильтр на каждый из 500 спрайтов | 500 проходов, батчинг сломан — FPS падает |
| Несколько фильтров подряд | проход на каждый |

Советы:

- Вешайте фильтр на **контейнер-группу**, а не на каждый спрайт.
- Задавайте `filterArea`, если эффект нужен только в части экрана: `container.filterArea = new Rectangle(...)`.
- Для статичных объектов с фильтром — `container.cacheAsTexture(true)`: эффект считается один раз.
- `resolution` фильтра можно снизить: `blur.resolution = 0.5` — размытию высокая детализация не нужна.

## Частые ошибки

- Вешать `GlowFilter` на каждую монетку вместо готового светящегося спрайта.
- Создавать новый фильтр каждый кадр — используйте один экземпляр и меняйте его свойства.
- Не добавить спрайт карты `DisplacementFilter` в сцену — эффект не обновляется.
- Ожидать, что `tint` осветлит объект — он только умножает цвет.
- Писать фильтр только на GLSL и включить `preference: 'webgpu'`.

## Что важно помнить

- `obj.filters = [new BlurFilter(), …]` — эффекты на GPU для объекта или поддерева.
- Встроенные: Blur, ColorMatrix, Displacement, Noise, Alpha; больше — в `pixi-filters`.
- Фильтры дорогие: на контейнеры, а не на тысячи спрайтов.
- Простые эффекты — через `tint`, `alpha`, `blendMode`.

## Мини-шпаргалка

```ts
world.filters = [new BlurFilter({ strength: 8 })];
const cm = new ColorMatrixFilter(); cm.grayscale(0.3, false);
import { GlowFilter } from 'pixi-filters';
sprite.blendMode = 'add'; sprite.tint = 0xff0000;
```
