# Как передать вершины в шейдер — буферы, атрибуты и VAO

> [!NOTE]
> Данные вершин хранятся на GPU в **буферах**: `createBuffer` → `bindBuffer(ARRAY_BUFFER)` → `bufferData(типизированный массив)`. Шейдер читает их через **атрибуты** (`in vec2 aPosition`). Связь «какой атрибут, из какого буфера и в каком формате» задаёт `vertexAttribPointer(location, size, type, normalize, stride, offset)` плюс `enableVertexAttribArray`. Эту конфигурацию сохраняет **VAO** (Vertex Array Object): настроили один раз — перед отрисовкой просто `bindVertexArray(vao)`. Несколько атрибутов можно хранить в одном буфере **через чередование** (interleaved: x, y, r, g, b, x, y, …) — тогда важны `stride` и `offset`. Чтобы не дублировать вершины у соседних треугольников, используют **индексный буфер** (`ELEMENT_ARRAY_BUFFER`) и `drawElements`.

## Вопрос

Как передать в WebGL координаты и цвета вершин и нарисовать треугольник и прямоугольник?

## Треугольник с цветными вершинами

```ts
const vs = `#version 300 es
in vec2 aPosition;
in vec3 aColor;
out vec3 vColor;
void main() {
  vColor = aColor;
  gl_Position = vec4(aPosition, 0.0, 1.0);
}`;

const fs = `#version 300 es
precision mediump float;
in vec3 vColor;
out vec4 outColor;
void main() {
  outColor = vec4(vColor, 1.0);
}`;

const program = createProgram(gl, vs, fs);

// чередуем данные: x, y, r, g, b
const vertices = new Float32Array([
//  x      y     r  g  b
   0.0,  0.6,   1, 0, 0,
  -0.6, -0.5,   0, 1, 0,
   0.6, -0.5,   0, 0, 1,
]);

// 1. VAO — запомнит настройку атрибутов
const vao = gl.createVertexArray();
gl.bindVertexArray(vao);

// 2. буфер с данными
const vbo = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, vbo);
gl.bufferData(gl.ARRAY_BUFFER, vertices, gl.STATIC_DRAW);

// 3. как читать атрибуты
const FLOAT = 4;                          // байт в float32
const stride = 5 * FLOAT;                 // одна вершина = 5 чисел = 20 байт

const aPosition = gl.getAttribLocation(program, 'aPosition');
gl.enableVertexAttribArray(aPosition);
gl.vertexAttribPointer(aPosition, 2, gl.FLOAT, false, stride, 0);           // x, y с начала

const aColor = gl.getAttribLocation(program, 'aColor');
gl.enableVertexAttribArray(aColor);
gl.vertexAttribPointer(aColor, 3, gl.FLOAT, false, stride, 2 * FLOAT);      // r, g, b после x, y

gl.bindVertexArray(null);

// отрисовка
gl.clear(gl.COLOR_BUFFER_BIT);
gl.useProgram(program);
gl.bindVertexArray(vao);
gl.drawArrays(gl.TRIANGLES, 0, 3);        // режим, первая вершина, количество вершин
```

## vertexAttribPointer по шагам

```text
gl.vertexAttribPointer(location, size, type, normalized, stride, offset)

буфер:  [ x y r g b | x y r g b | x y r g b ]
         └─ stride = 20 байт ─┘
aPosition: size 2, offset 0   → читает x y
aColor:    size 3, offset 8   → читает r g b
```

| Параметр | Значение |
| --- | --- |
| `size` | сколько компонентов (1–4): `vec2` → 2 |
| `type` | `gl.FLOAT`, `gl.UNSIGNED_BYTE`, `gl.SHORT`… |
| `normalized` | для целых типов: `true` переводит 0..255 в 0..1 (удобно для цвета в `Uint8Array`) |
| `stride` | байт между началом соседних вершин (0 — «плотно, без чередования») |
| `offset` | байт от начала вершины до этого атрибута |

`bindBuffer(ARRAY_BUFFER)` в момент вызова `vertexAttribPointer` определяет, **из какого** буфера будет читать атрибут.

## Явные location в шейдере

Вместо `getAttribLocation` номера можно задать прямо в GLSL — тогда разные программы гарантированно используют одинаковую раскладку и один VAO:

```glsl
layout(location = 0) in vec2 aPosition;
layout(location = 1) in vec2 aUV;
```

## Прямоугольник и индексы

Прямоугольник = 2 треугольника = 6 вершин, из которых 2 повторяются. С индексами хранится 4 вершины:

```ts
const quad = new Float32Array([
// x     y     u  v
  -0.5,  0.5,  0, 0,   // 0 левый верх
   0.5,  0.5,  1, 0,   // 1 правый верх
   0.5, -0.5,  1, 1,   // 2 правый низ
  -0.5, -0.5,  0, 1,   // 3 левый низ
]);
const indices = new Uint16Array([0, 1, 2,   0, 2, 3]);   // два треугольника

const vao = gl.createVertexArray();
gl.bindVertexArray(vao);

gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
gl.bufferData(gl.ARRAY_BUFFER, quad, gl.STATIC_DRAW);
gl.enableVertexAttribArray(0);
gl.vertexAttribPointer(0, 2, gl.FLOAT, false, 16, 0);
gl.enableVertexAttribArray(1);
gl.vertexAttribPointer(1, 2, gl.FLOAT, false, 16, 8);

gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, gl.createBuffer()); // индексный буфер запоминается в VAO
gl.bufferData(gl.ELEMENT_ARRAY_BUFFER, indices, gl.STATIC_DRAW);

gl.bindVertexArray(null);

// отрисовка
gl.bindVertexArray(vao);
gl.drawElements(gl.TRIANGLES, 6, gl.UNSIGNED_SHORT, 0);
```

## Режимы примитивов

| Режим | Что рисует |
| --- | --- |
| `gl.TRIANGLES` | каждые 3 вершины — отдельный треугольник (основной режим) |
| `gl.TRIANGLE_STRIP` | лента: каждая новая вершина + две предыдущих |
| `gl.TRIANGLE_FAN` | веер вокруг первой вершины |
| `gl.LINES` / `gl.LINE_STRIP` / `gl.LINE_LOOP` | линии толщиной 1px (толщина почти нигде не настраивается) |
| `gl.POINTS` | точки, размер — `gl_PointSize` в вершинном шейдере |

## Обновление данных каждый кадр

```ts
// буфер под динамические данные: выделяем память один раз
gl.bindBuffer(gl.ARRAY_BUFFER, dynamicVbo);
gl.bufferData(gl.ARRAY_BUFFER, MAX_VERTICES * 16, gl.DYNAMIC_DRAW); // размер в байтах

// в кадре — переписываем только нужную часть
gl.bindBuffer(gl.ARRAY_BUFFER, dynamicVbo);
gl.bufferSubData(gl.ARRAY_BUFFER, 0, vertexData, 0, usedFloats);
```

| Подсказка `usage` | Когда |
| --- | --- |
| `STATIC_DRAW` | загрузили один раз (геометрия уровня, квад) |
| `DYNAMIC_DRAW` | меняется часто (батч спрайтов, частицы) |
| `STREAM_DRAW` | используется один-два раза |

## Частые ошибки

- Ошибка в `stride`/`offset` в **байтах**, а не в числах — вершины «взрываются» в случайные треугольники.
- Забыть `enableVertexAttribArray` — атрибут читается как константа (0, 0, 0, 1).
- Привязать `ELEMENT_ARRAY_BUFFER` при выключенном VAO, а потом ждать его внутри VAO.
- Использовать `Uint16Array` для индексов больше 65 535 — нужен `Uint32Array` и `gl.UNSIGNED_INT`.
- Вызывать `bufferData` каждый кадр с новым массивом — лишние перевыделения памяти; используйте `bufferSubData`.

## Что важно помнить

- Буфер = данные на GPU, атрибут = как шейдер их читает, VAO = сохранённая настройка.
- `vertexAttribPointer(loc, size, type, norm, stride, offset)`, всё в байтах.
- Индексный буфер + `drawElements` экономят вершины.
- Динамические данные — `DYNAMIC_DRAW` + `bufferSubData`.

## Мини-шпаргалка

```ts
const vao = gl.createVertexArray(); gl.bindVertexArray(vao);
gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
gl.bufferData(gl.ARRAY_BUFFER, data, gl.STATIC_DRAW);
gl.enableVertexAttribArray(0); gl.vertexAttribPointer(0, 2, gl.FLOAT, false, 0, 0);
gl.drawArrays(gl.TRIANGLES, 0, count);
```
