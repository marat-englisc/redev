# Основы GLSL ES 3.00 — типы, векторы и встроенные функции

> [!NOTE]
> **GLSL** — C-подобный язык шейдеров. Он строго типизирован и без автоприведения: `1` — это `int`, `1.0` — `float`, и `float x = 1;` — ошибка. Главные типы — векторы `vec2`/`vec3`/`vec4` и матрицы `mat2`/`mat3`/`mat4`; арифметика над ними покомпонентная, а `mat * vec` — умножение матрицы на вектор. Компоненты читаются через **swizzle**: `v.xy`, `color.rgb`, `v.zyx`, `v.xxxx`. Встроенные функции работают с векторами целиком: `mix` (lerp), `clamp`, `step`, `smoothstep`, `length`, `distance`, `dot`, `normalize`, `fract`, `sin`, `texture`. Во фрагментном шейдере обязательна `precision`. Ветвления (`if`) допустимы, но GPU выполняет пиксели группами, поэтому вместо условий часто используют `step`/`mix` — так код быстрее и короче.

## Вопрос

Какие типы, конструкции и встроенные функции GLSL нужно знать, чтобы писать шейдеры для WebGL 2?

## Структура шейдера

```glsl
#version 300 es              // первой строкой, WebGL 2
precision highp float;       // точность по умолчанию: lowp | mediump | highp

uniform float uTime;         // из JS, одинаково для всех
in vec2 vUV;                 // из вершинного шейдера (интерполировано)
out vec4 outColor;           // результат фрагментного шейдера

const float PI = 3.14159265;

float circle(vec2 p, float r) {     // свои функции объявляются до использования
  return step(length(p), r);
}

void main() {
  outColor = vec4(vec3(circle(vUV - 0.5, 0.3)), 1.0);
}
```

## Типы

| Тип | Описание |
| --- | --- |
| `float`, `int`, `uint`, `bool` | скаляры |
| `vec2`, `vec3`, `vec4` | векторы float |
| `ivec2..4`, `uvec2..4`, `bvec2..4` | векторы int, uint, bool |
| `mat2`, `mat3`, `mat4` | квадратные матрицы float (по столбцам) |
| `sampler2D`, `sampler2DArray`, `samplerCube` | текстуры |
| `struct`, массивы `float a[4]` | составные |

## Конструкторы и приведение

```glsl
vec2 a = vec2(1.0, 2.0);
vec3 b = vec3(a, 0.0);          // (1, 2, 0)
vec4 c = vec4(1.0);             // (1, 1, 1, 1)
vec4 d = vec4(b.xy, 0.5, 1.0);
float f = float(3);             // явное приведение int → float
int i = int(2.7);               // 2
mat2 m = mat2(1.0);             // единичная матрица
```

## Swizzle

```glsl
vec4 v = vec4(1.0, 2.0, 3.0, 4.0);

v.x;      // 1.0
v.xy;     // vec2(1, 2)
v.zyx;    // vec3(3, 2, 1) — любой порядок
v.xxxx;   // vec4(1, 1, 1, 1) — повторы
v.rgb;    // то же, что xyz — для цветов
v.st;     // то же, что xy — для текстурных координат

v.xy = vec2(0.0);   // запись в часть вектора
color.rgb *= 0.5;   // затемнить, не трогая альфу
```

Наборы `xyzw`, `rgba`, `stpq` эквивалентны, но смешивать их в одном swizzle нельзя (`v.xg` — ошибка).

## Арифметика

```glsl
vec2 a = vec2(1.0, 2.0);
vec2 b = vec2(3.0, 4.0);

a + b;        // (4, 6)   — покомпонентно
a * b;        // (3, 8)   — покомпонентно, НЕ скалярное произведение
a * 2.0;      // (2, 4)
dot(a, b);    // 11 — скалярное произведение

mat3 m;
vec3 p;
m * p;        // преобразование вектора матрицей (порядок важен!)
```

## Встроенные функции

| Функция | Что делает | Пример применения |
| --- | --- | --- |
| `mix(a, b, t)` | `a + (b - a) * t` (lerp) | плавный переход цветов |
| `clamp(x, lo, hi)` | ограничение диапазона | яркость в пределах 0..1 |
| `step(edge, x)` | `x < edge ? 0 : 1` | резкая граница без `if` |
| `smoothstep(e0, e1, x)` | плавная ступенька 0→1 между e0 и e1 | сглаженный край круга |
| `fract(x)` | дробная часть | повторяющиеся узоры, полосы |
| `mod(x, y)` | остаток | сетка, шахматная доска |
| `abs`, `sign`, `floor`, `ceil`, `min`, `max`, `pow`, `sqrt`, `exp` | как в Math | |
| `sin`, `cos`, `atan(y, x)` | тригонометрия (радианы) | волны, вращение, полярные координаты |
| `length(v)`, `distance(a, b)` | длина, расстояние | круги, свечение |
| `normalize(v)` | вектор длины 1 | направления, освещение |
| `reflect(i, n)` | отражение | блики |
| `texture(sampler, uv)` | чтение текстуры с фильтрацией | спрайты |
| `texelFetch(sampler, ivec2, lod)` | чтение конкретного пикселя | данные в текстуре |

## Встроенные переменные

| Переменная | Где | Значение |
| --- | --- | --- |
| `gl_Position` | вершинный, выход | позиция в clip space (`vec4`) |
| `gl_PointSize` | вершинный, выход | размер точки для `gl.POINTS` |
| `gl_VertexID` | вершинный, вход | номер вершины |
| `gl_InstanceID` | вершинный, вход | номер экземпляра при инстансинге |
| `gl_FragCoord` | фрагментный, вход | координаты пикселя в буфере (от левого **нижнего** угла, центр пикселя — `.5`) |
| `gl_FrontFacing` | фрагментный, вход | лицевая ли сторона треугольника |

`discard;` во фрагментном шейдере — не записывать пиксель вовсе (вырезать прозрачные части).

## Условия без if

```glsl
// с ветвлением
if (dist < radius) color = red; else color = blue;

// без ветвления — то же самое
color = mix(blue, red, step(dist, radius));

// сглаженный край круга вместо «лесенки»
float edge = 1.0 - smoothstep(radius - 0.01, radius, dist);
```

## Точность

| Квалификатор | Когда |
| --- | --- |
| `highp` | позиции, большие координаты, время — по умолчанию в вершинном шейдере |
| `mediump` | цвета, UV — хватает почти всегда, быстрее на мобильных |
| `lowp` | простые цвета |

Во фрагментном шейдере `precision` для `float` указывать обязательно. Время в `mediump` теряет точность через несколько минут — анимации начинают «дёргаться».

## Частые ошибки

- `float x = 1;` — нужна точка: `1.0`.
- `vec3 * vec3` ожидается как скалярное произведение, а это покомпонентное умножение; нужно `dot`.
- `gl_FragCoord.y` считается снизу, а в canvas — сверху.
- `smoothstep(0.3, 0.29, x)` с `edge0 >= edge1` по спецификации даёт неопределённый результат (на одних GPU работает, на других нет). Для «обратной» ступеньки пишут `1.0 - smoothstep(0.29, 0.3, x)`.
- Деление на ноль и `normalize(vec2(0))` дают `NaN` — пиксель чёрный или мигает.
- Объявлять функцию после места вызова без прототипа.

## Что важно помнить

- Строгие типы, `1.0` вместо `1`.
- Векторы и матрицы — основные типы, swizzle для доступа к компонентам.
- `mix`, `step`, `smoothstep`, `fract`, `length`, `dot` — основа большинства эффектов.
- `precision` во фрагментном шейдере обязательна.
- Вместо ветвлений часто удобнее `step`/`mix`.
