# Как загружать ресурсы и воспроизводить звук

> [!NOTE]
> Перед запуском игры все ресурсы (картинки, звуки, шрифты, JSON уровней) загружают заранее через **загрузчик**: он запускает загрузки параллельно (`Promise.all`), показывает прогресс и кеширует результат по ключу. Для звука в играх используют **Web Audio API**, а не `<audio>`: файл один раз декодируется в `AudioBuffer`, и его можно проигрывать много раз одновременно с минимальной задержкой, управлять громкостью через `GainNode`, панорамой и эффектами. Важное ограничение браузеров — **autoplay policy**: `AudioContext` стартует в состоянии `suspended`, и включить звук можно только после жеста пользователя (клик, нажатие клавиши). Поэтому у игр есть экран «Нажмите, чтобы начать».

## Вопрос

Как загрузить ресурсы игры заранее и как правильно воспроизводить звуки в браузере?

## Загрузчик ресурсов

```ts
type Manifest = {
  images: Record<string, string>;
  sounds: Record<string, string>;
  json: Record<string, string>;
};

export class Assets {
  images = new Map<string, HTMLImageElement>();
  sounds = new Map<string, AudioBuffer>();
  json = new Map<string, unknown>();

  constructor(private audio: AudioContext) {}

  async load(m: Manifest, onProgress?: (p: number) => void) {
    const tasks: Promise<void>[] = [];
    let done = 0;
    const track = <T>(p: Promise<T>) =>
      p.then((v) => { onProgress?.(++done / tasks.length); return v; });

    for (const [key, url] of Object.entries(m.images)) {
      tasks.push(track(loadImage(url)).then((img) => void this.images.set(key, img)));
    }
    for (const [key, url] of Object.entries(m.sounds)) {
      tasks.push(track(this.loadSound(url)).then((buf) => void this.sounds.set(key, buf)));
    }
    for (const [key, url] of Object.entries(m.json)) {
      tasks.push(track(fetch(url).then((r) => r.json())).then((d) => void this.json.set(key, d)));
    }

    await Promise.all(tasks);
  }

  private async loadSound(url: string) {
    const data = await fetch(url).then((r) => r.arrayBuffer());
    return this.audio.decodeAudioData(data);  // декодирование заранее, не в момент выстрела
  }

  image(key: string) {
    const img = this.images.get(key);
    if (!img) throw new Error(`Image "${key}" not loaded`);
    return img;
  }
}

function loadImage(src: string) {
  const img = new Image();
  img.src = src;
  return img.decode().then(() => img);
}
```

## Звук через Web Audio

```ts
export class Sound {
  private master: GainNode;
  private sfxGain: GainNode;
  private musicGain: GainNode;
  private music: AudioBufferSourceNode | null = null;

  constructor(private ctx: AudioContext, private assets: Assets) {
    this.master = ctx.createGain();
    this.sfxGain = ctx.createGain();
    this.musicGain = ctx.createGain();
    this.sfxGain.connect(this.master);
    this.musicGain.connect(this.master);
    this.master.connect(ctx.destination);   // master → динамики
    this.musicGain.gain.value = 0.4;
  }

  /** вызвать в обработчике клика/клавиши */
  async unlock() {
    if (this.ctx.state === 'suspended') await this.ctx.resume();
  }

  play(key: string, { volume = 1, rate = 1, pan = 0 } = {}) {
    const buffer = this.assets.sounds.get(key);
    if (!buffer) return;

    const src = this.ctx.createBufferSource();   // одноразовый узел — создаётся на каждое воспроизведение
    src.buffer = buffer;
    src.playbackRate.value = rate;

    const gain = this.ctx.createGain();
    gain.gain.value = volume;
    const panner = this.ctx.createStereoPanner();
    panner.pan.value = pan;                      // -1 слева … 1 справа

    src.connect(gain).connect(panner).connect(this.sfxGain);
    src.start();
    return src;
  }

  playMusic(key: string) {
    this.music?.stop();
    const src = this.ctx.createBufferSource();
    src.buffer = this.assets.sounds.get(key)!;
    src.loop = true;
    src.connect(this.musicGain);
    src.start();
    this.music = src;
  }

  setMuted(muted: boolean) {
    // плавно, без щелчка
    this.master.gain.setTargetAtTime(muted ? 0 : 1, this.ctx.currentTime, 0.05);
  }
}
```

```ts
const sound = new Sound(audio, assets);

startButton.addEventListener('click', async () => {
  await sound.unlock();

```

## Почему не `<audio>`

| | `new Audio(url).play()` | Web Audio |
| --- | --- | --- |
| Задержка | заметная, особенно на мобильных | минимальная |
| Один звук много раз одновременно | нужно клонировать элементы | новый `BufferSource` — дёшево |
| Громкость, панорама, эффекты | только `volume` | граф узлов: gain, panner, filter, reverb |
| Подходит | длинная фоновая музыка, подкасты | игровые эффекты |

Для длинной музыки, чтобы не декодировать весь файл в память, можно подключить `<audio>` в граф через `ctx.createMediaElementSource(audioEl)`.

## Пауза и вкладка в фоне

```ts
document.addEventListener('visibilitychange', () => {
  if (document.hidden) audio.suspend();   // останавливает все звуки и музыку
  else audio.resume();
});
```

## Библиотеки

- **Howler.js** — обёртка над Web Audio с фолбэком, спрайты звуков, простой API.
- **@pixi/sound** — звук для PixiJS, интеграция с `Assets`.
- **Phaser** — встроенные `this.load.audio` и `this.sound.play`.

```ts
import { Howl } from 'howler';
const sfx = new Howl({ src: ['/sfx/sprite.webm', '/sfx/sprite.mp3'], sprite: { jump: [0, 300], coin: [400, 250] } });
sfx.play('coin');
```

## Частые ошибки

- Запускать звук до жеста пользователя — `AudioContext` в состоянии `suspended`, звука нет.
- Пытаться переиспользовать `AudioBufferSourceNode` — `start()` можно вызвать только один раз.
- Загружать и декодировать звук в момент события — первое воспроизведение звучит с задержкой.
- Обращаться к картинке до завершения загрузки.
- Один формат на всех: Safari не всегда проигрывает `.ogg` — держите `.mp3`/`.m4a` как запасной вариант.

## Что важно помнить

- Все ресурсы грузятся до старта, параллельно, с прогрессом.
- Web Audio: `decodeAudioData` заранее, `createBufferSource` на каждое воспроизведение.
- Громкость и мьют — через `GainNode`, раздельные каналы музыки и эффектов.
- `audioContext.resume()` только по жесту пользователя.

## Мини-шпаргалка

```ts
const buf = await ctx.decodeAudioData(await (await fetch(url)).arrayBuffer());
const src = ctx.createBufferSource(); src.buffer = buf;
src.connect(gain).connect(ctx.destination); src.start();
button.onclick = () => ctx.resume();
```
