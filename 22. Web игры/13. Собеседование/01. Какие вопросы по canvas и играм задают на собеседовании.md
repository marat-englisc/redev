# Какие вопросы по canvas и играм задают на собеседовании

> [!NOTE]
> Во фронтенд-собеседованиях тема игр всплывает в вакансиях с графикой: геймдев-студии, гемблинг и слоты, edtech, интерактивные лендинги, визуализации, редакторы. Проверяют понимание основ: чем canvas отличается от DOM и SVG, как устроен игровой цикл и `requestAnimationFrame`, зачем нужен delta time, как проверять столкновения, как переводить координаты мыши, как искать узкие места производительности и избегать мусора. На уровне библиотек спрашивают, чем PixiJS отличается от Phaser и Three.js, что такое батчинг и атласы, как встроить игру в React без утечек. Сильный ответ связывает термин с последствием: «без `dt` скорость зависит от частоты монитора».

## Вопрос

Какие вопросы по canvas, игровой разработке и PixiJS задают на собеседовании и как на них отвечать?

## Canvas

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Canvas vs SVG vs DOM? | Canvas — immediate mode, пиксели, нет узлов и событий на фигурах, быстро для тысяч объектов; SVG/DOM — retained, доступность и события из коробки, тормозят на тысячах элементов |
| Почему canvas размытый? | Буфер `width/height` ≠ CSS-размер; учитываем `devicePixelRatio` и `setTransform(dpr, …)` |
| Зачем `beginPath`? | Без него новые фигуры добавляются к старому пути, и `fill` перерисовывает всё накопленное |
| Зачем `save`/`restore`? | Трансформации и стили накапливаются; пара изолирует отрисовку одного объекта |
| Как повернуть объект вокруг центра? | `translate` в центр → `rotate` → рисовать от `(-w/2, -h/2)` |
| Как узнать, куда кликнули? | Перевод `clientX` в координаты canvas с учётом `getBoundingClientRect`, масштаба и камеры; hit testing вручную, с конца списка |
| Что такое OffscreenCanvas? | Canvas без DOM: буфер для предрендера и рендеринг в Web Worker через `transferControlToOffscreen` |
| Почему `getImageData` медленный? | Копирует пиксели из GPU в CPU; бросает ошибку на «грязном» canvas с картинками без CORS |

## Игровой цикл и анимация

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Почему `requestAnimationFrame`, а не `setInterval`? | Синхронизация с экраном, пауза в фоновой вкладке, нет накопления вызовов, передаёт timestamp |
| Что такое delta time? | Время между кадрами; скорости в единицах в секунду, `x += v * dt` — одинаково на 60 и 144 Гц |
| Зачем ограничивать `dt`? | После фона или лага — огромный шаг, объекты пролетают сквозь стены |
| Что такое fixed timestep? | Физика с постоянным шагом через аккумулятор; стабильность, детерминизм; рендер с интерполяцией |
| Как сделать спрайтовую анимацию? | Спрайт-лист, номер кадра, таймер по `dt`, `drawImage` с 9 аргументами |
| Что такое easing? | Функция от прогресса 0..1, задающая характер движения: ease-out, back, bounce |

## Архитектура и физика

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Как организовать объекты? | Классы с `update`/`draw`, мир хранит список; удаление флагом и фильтрацией после обхода |
| Что такое ECS? | Entity — id, Component — данные, System — логика по набору компонентов; композиция вместо наследования |
| Зачем пул объектов? | Избежать аллокаций и пауз GC для пуль и частиц; не забывать полный сброс |
| Как сделать паузу и меню? | Менеджер сцен, стек: пауза поверх уровня, уровень не обновляется |
| Как описать поведение врага? | Конечный автомат: состояния и явные переходы вместо набора флагов |
| AABB и круги? | AABB — перекрытие по обеим осям; круги — квадрат расстояния против квадрата суммы радиусов |
| Что такое SAT? | Выпуклые фигуры не пересекаются, если есть разделяющая ось; проверяем нормали рёбер |
| Что такое tunneling? | Быстрый объект проскакивает препятствие между кадрами; подшаги, raycast, малый фиксированный шаг |
| Как ускорить коллизии для тысяч объектов? | Broad phase: spatial hash / quadtree, затем точная проверка кандидатов |
| Как приземлить персонажа на платформу? | Движение по осям раздельно, выталкивание по оси, обнуление скорости, `onGround` |

## Производительность

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Какой бюджет кадра? | 16,6 мс при 60 Гц, 8,3 мс при 120 Гц — на логику и отрисовку |
| Как ускорить canvas 2D? | Culling, кеширование в offscreen-canvas, слои, меньше смен стиля, без `shadowBlur` в цикле |
| Как найти причину лагов? | DevTools Performance: долгие кадры, Bottom-Up, GC-паузы, Memory |
| Когда переходить на WebGL? | Тысячи спрайтов, шейдеры, фильтры, 3D; обычно через PixiJS/Three.js |
| Что такое draw call и батчинг? | Команда отрисовки GPU; объединение спрайтов с одной текстуры в один вызов, поэтому атласы |

## WebGL и шейдеры

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Как устроен конвейер WebGL? | Буферы → вершинный шейдер (`gl_Position` в clip space) → растеризация → фрагментный шейдер (цвет) → смешивание и тест глубины |
| Что такое clip space? | Координаты от −1 до 1 по всем осям, `y` вверх; пиксели переводят матрицей проекции |
| Attribute, uniform, varying? | Attribute — на вершину из буфера, uniform — на весь draw call, varying (`out`/`in`) — из вершинного во фрагментный с интерполяцией |
| Зачем VAO? | Сохраняет настройку атрибутов и индексного буфера — перед отрисовкой один `bindVertexArray` |
| Почему WebGL — машина состояний? | `enable`, `bind*`, `useProgram` действуют до следующего изменения; состояние «протекает» между частями кода |
| Почему текстура чёрная? | Не загружена, нет mipmaps при фильтре по умолчанию, слот и `uniform1i` не совпадают, CORS |
| Что такое draw call и как их сократить? | Команда отрисовки; батчинг в один буфер, инстансинг (`vertexAttribDivisor` + `drawArraysInstanced`), атласы |
| Как сделать пост-эффект? | Сцена → framebuffer с текстурой → полноэкранный проход с шейдером; многопроходные — ping-pong |
| Как работает прозрачность? | `enable(BLEND)` + `blendFunc`; premultiplied — `ONE, ONE_MINUS_SRC_ALPHA`; в 3D прозрачные — после непрозрачных, от дальних к ближним |
| Что делать при потере контекста? | `preventDefault` в `webglcontextlost`, пересоздать ресурсы по `webglcontextrestored` |
| Чем WebGPU отличается от WebGL? | Неизменяемые pipeline и bind groups вместо машины состояний, command encoder, WGSL, compute-шейдеры |

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Что такое PixiJS? | 2D-рендерер на WebGL/WebGPU, граф сцены, батчинг; не движок — нет физики и сцен |
| PixiJS vs Phaser? | Рендерер против полноценного движка со сценами, физикой, тайлмапами, звуком |
| Что изменилось в PixiJS v8? | Асинхронный `app.init`, `app.canvas`, новый API Graphics (`rect().fill()`), `eventMode`, WebGPU |
| Как ускорить PixiJS? | Атласы, `ParticleContainer`, culling, `cacheAsTexture`, пулы, `BitmapText`, фильтры на контейнеры |
| Text vs BitmapText? | Text — canvas → текстура, дорогое обновление; BitmapText — глифы из атласа, для часто меняющихся чисел |
| Что такое Three.js? | 3D: Scene, Camera, Renderer, Mesh = Geometry + Material, свет, `setAnimationLoop` |
| Когда физический движок? | Вращающиеся тела, стопки, шарниры; Matter.js, Rapier, Planck.js |

## React и интеграция

| Вопрос | Опорные пункты ответа |
| --- | --- |
| Как встроить игру в React? | Игровой мир вне React state, цикл в `useEffect`, остановка в cleanup, наружу — события |
| Почему не `useState` для позиций? | Ререндер 60+ раз в секунду; меняем объекты через ref |
| Что сломает Strict Mode? | Двойной монтаж эффекта — без cleanup два цикла и два WebGL-контекста |
| Как PixiJS/Three.js в React? | `@pixi/react` (`extend`, `useTick`), React Three Fiber (`useFrame`); каждый кадр — через ref |
| Next.js и canvas? | Клиентский компонент, обращение к `window` только в эффектах, `dynamic(..., { ssr: false })` при необходимости |

## Ситуационные вопросы

### «Игра тормозит на телефоне. Ваши действия?»

Снять профиль на устройстве (remote debugging). Проверить, что занимает кадр: логика, отрисовка или GC. Типичные причины: огромный буфер из-за `dpr = 3`, тени и фильтры, сотни отдельных картинок, создание объектов в цикле, рисование невидимого. Решения: ограничить `dpr`, атласы, пулы, culling, кеширование, при необходимости — WebGL.

### «Персонаж иногда проваливается сквозь пол»

Скорее всего tunneling или огромный `dt` после лага. Ограничить `dt`, перейти на фиксированный шаг, делать подшаги для быстрых объектов, ограничить максимальную скорость падения, проверить порядок «движение → выталкивание».

### «На 144 Гц мониторе игра в два раза быстрее»

Движение привязано к кадрам, а не ко времени. Перевести скорости в единицы в секунду и умножать на `dt`, таймеры считать в секундах.

### «После перехода между страницами игра ускорилась»

Цикл не останавливается при размонтировании, и при возврате запускается второй. Хранить id `requestAnimationFrame`, отменять в cleanup, снимать слушатели, уничтожать `Application`/рендерер.
