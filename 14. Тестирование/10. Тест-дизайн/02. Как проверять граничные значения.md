# Граничные значения

> [!NOTE]
> Анализ границ проверяет места смены поведения: минимум, максимум и соседние значения. Для дискретного диапазона 18–65 полезный набор — 17, 18, 19, 64, 65, 66. Шаг зависит от типа данных и точности, поэтому универсального «плюс один» для любых полей нет.

## Вопрос

Какие значения выбрать для поля с допустимым диапазоном? Чем двухточечный анализ границ отличается от трёхточечного?

## Основная идея

Типичные дефекты возникают из-за `<` вместо `<=`, неверного округления, ограничения длины или путаницы единиц. Значения далеко от границы такие ошибки часто не обнаруживают.

## Пример

Требование: количество товара — целое число от 1 до 99 включительно.

| Значение | Ожидание | Что проверяем |
| ---: | --- | --- |
| 0 | отклонить | снаружи нижней границы |
| 1 | принять | нижняя граница |
| 2 | принять | внутри около минимума |
| 98 | принять | внутри около максимума |
| 99 | принять | верхняя граница |
| 100 | отклонить | снаружи верхней границы |

В терминологии CTFL двухточечный подход берёт границу и ближайшее значение соседнего класса: здесь 0/1 и 99/100. Трёхточечный добавляет второго соседа: 0/1/2 и 98/99/100. Всегда объясняй, какие именно значения выбраны: слово «двухточечный» без модели бывает понято по-разному.

## Не только целые числа

- Для суммы с точностью 0.01 ₽ проверяются соседние суммы с этим шагом.
- Для срока действия нужно уточнить, допустима ли операция ровно в момент окончания и чьи часы используются.
- Для строки уточняют единицу длины: байты, кодовые точки, UTF-16 code units или видимые символы. Эмодзи может занимать несколько единиц.
- Для файла важны размер в байтах и различие между MB и MiB.

## Практика с ответом

Пароль должен иметь длину 8–20 символов ASCII. Базовый трёхточечный набор: длины 7, 8, 9, 19, 20, 21. Пустая строка — дополнительный класс, а проверка набора разрешённых символов — отдельное измерение. Шесть длин не покрывают всю валидацию пароля.

## Что важно помнить

Границы дополняют классы эквивалентности. Для непрерывных величин нужен обоснованный шаг измерения; «бесконечно близкое число» нельзя ввести в реальную систему.

## Мини-шпаргалка

Определи ограничения, включённость границ и шаг. Затем проверь переходы между допустимым и недопустимым.
