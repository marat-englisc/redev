# API и подмена сети в Playwright

> [!NOTE]
> `request` выполняет HTTP-запросы без UI, а `page.route` перехватывает запросы страницы. Реальный API полезен для проверки контракта и подготовки данных; подмена — для контролируемой проверки редких ответов. Мокированный UI-тест не подтверждает работу реального backend.

## Вопрос

Как создать данные через API? Как проверить экран ошибки 500 без поломки настоящего сервера?

## API-пример

Запущен [QA Lab](<../15. Практика QA/01. Как запустить локальный учебный стенд QA.md>); запросы используют учебный Bearer token.

```ts
import { test, expect } from '@playwright/test';

test('создание и чтение задачи через API', async ({ request }) => {
  const root = 'http://127.0.0.1:3007';
  const headers = { Authorization: 'Bearer qa-a' };
  const created = await request.post(`${root}/tasks`, {
    headers, data: { title: 'Проверить API' },
  });
  expect(created.status()).toBe(201);
  const task = await created.json();
  try {
    const response = await request.get(`${root}/tasks/${task.id}`, { headers });
    expect(response.status()).toBe(200);
    expect(await response.json()).toMatchObject({
      id: task.id, title: 'Проверить API', done: false,
    });
  } finally {
    const removed = await request.delete(`${root}/tasks/${task.id}`, { headers });
    expect(removed.status()).toBe(204);
  }
});
```

Обычное сравнение `status()` не повторяет запрос. Для eventual consistency нужен явно ограниченный polling, а не ожидание, что assertion самостоятельно изменит уже полученный response.

## Мок ошибки

```ts
test('форма сообщает об ошибке сервера', async ({ page }) => {
  await page.route('**/tasks', async route => {
    if (route.request().method() === 'POST') {
      await route.fulfill({
        status: 500,
        contentType: 'application/json',
        body: JSON.stringify({ error: 'Server unavailable' }),
      });
    } else {
      await route.continue();
    }
  });
  await page.goto('http://127.0.0.1:3007');
  await page.getByLabel('Название', { exact: true }).fill('Новая задача');
  await page.getByRole('button', { name: 'Добавить', exact: true }).click();
  await expect(page.getByRole('alert')).toHaveText('Server unavailable');
});
```

Перехват регистрируется до запроса. Если нужно дождаться реального ответа, `waitForResponse` тоже создают до действия, которое его вызывает, и уточняют метод и URL.

## Что важно помнить

- Подмена всех методов `/tasks` одним JSON может случайно сломать загрузку списка.
- Service worker может влиять на перехват; учитывай конфигурацию приложения.
- API-подготовка не должна заменять проверяемое UI-действие.

## Мини-шпаргалка

`request` — реальный HTTP. `route` — управление ответом страницы. Граница проверки должна быть явной.
