# Первый тест Playwright с нуля

> [!NOTE]
> Playwright Test устанавливается в Node.js-проект и запускает тесты в браузерах. Минимальный тест получает `page`, выполняет действия через локаторы и проверяет результат через `await expect`. Для первого запуска можно создать страницу прямо в тесте, без отдельного приложения.

## Вопрос

Как начать автоматизацию на Playwright? Что означают test, page, async, await и expect?

## Подготовка

Нужны основы [JavaScript](<../../04. JavaScript/>): переменные, функции, объекты, массивы и Promise. Для учебного проекта используй поддерживаемую установленной версией Playwright версию Node.js LTS. Создай отдельную папку, чтобы не менять зависимости другого приложения.

```bash
mkdir qa-playwright
cd qa-playwright
npm init -y
npm install -D @playwright/test
npx playwright install chromium
```

В корне создай `playwright.config.ts`:

```ts
import { defineConfig } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  use: { browserName: 'chromium' },
});
```

В `tests/first.spec.ts`:

```ts
import { test, expect } from '@playwright/test';

test('кнопка увеличивает счётчик', async ({ page }) => {
  await page.setContent(`
    <button onclick="this.textContent = Number(this.textContent) + 1">0</button>
  `);
  const button = page.getByRole('button');
  await expect(button).toHaveText('0');
  await button.click();
  await expect(button).toHaveText('1');
});
```

```bash
npx playwright test
npx playwright test --headed
npx playwright test --ui
```

## Разбор

`test` регистрирует проверку. `page` — подготовленная вкладка в изолированном browser context. `async` разрешает ожидать асинхронные операции, `await` дожидается их завершения. Локатор описывает поиск, `expect` сравнивает результат с ожиданием.

Этот пример проверяет маленькую браузерную страницу, созданную самим тестом. Это упражнение с API инструмента; оно не подтверждает работу настоящего приложения. Для него дальше используем `page.goto` и [учебный стенд](<../15. Практика QA/01. Как запустить локальный учебный стенд QA.md>).

## Что важно помнить

- Playwright-примеры запускаются локально; JS-песочница сайта браузерные тесты не исполняет.
- Установка npm-пакета и установка браузерных бинарников — разные шаги.
- Отсутствующий await может закончить тест раньше проверки.
- Проверь чувствительность теста: измени ожидание на 2 и убедись, что он падает.

## Мини-шпаргалка

Node → пакет → браузер → config → spec → действие → assertion → запуск.
