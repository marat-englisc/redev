# Диалоги, iframe, файлы и вкладки

> [!NOTE]
> Для событий браузера ожидание регистрируют до действия. `frameLocator` работает с iframe, `popup` — с новой вкладкой, `download` — со скачиванием, `setInputFiles` — с загрузкой файла. Нативный JavaScript dialog и HTML-диалог проверяются разными API.

## Вопрос

Как проверить скачивание, загрузку файла и confirm? Почему ожидание новой вкладки иногда зависает?

## Событие до действия

Следующие фрагменты рассчитаны на приложение с указанными элементами; учебный QA Lab их не содержит.

```ts
const popupPromise = page.waitForEvent('popup');
await page.getByRole('link', { name: 'Открыть справку' }).click();
const popup = await popupPromise;
await expect(popup).toHaveURL(/\/help/);

const downloadPromise = page.waitForEvent('download');
await page.getByRole('button', { name: 'Скачать отчёт' }).click();
const download = await downloadPromise;
expect(download.suggestedFilename()).toBe('report.csv');
await download.saveAs(testInfo.outputPath('report.csv'));
```

Здесь нужны `test`, `expect` из `@playwright/test` и callback `async ({ page }, testInfo)`. Имя файла проверяет только метаданные; содержимое CSV и корректность строк проверяются дополнительно.

## Диалоги

```ts
page.once('dialog', async dialog => {
  expect(dialog.type()).toBe('confirm');
  await dialog.accept();
});
await page.getByRole('button', { name: 'Удалить' }).click();
```

Если обработчик нативного dialog установлен, он должен принять или отклонить его. Без обработчика Playwright автоматически отклоняет такие диалоги. HTML-диалог с `role="dialog"` — обычный DOM: ищем его через `getByRole` и нажимаем кнопку внутри.

## Файлы и iframe

```ts
await page.getByLabel('Аватар').setInputFiles('fixtures/avatar.png');
await page.frameLocator('iframe[title="Оплата"]')
  .getByLabel('Номер карты').fill('учебное значение');
```

Файл должен реально существовать. Проверяют не только выбор файла, но и загрузку, ограничения формата/размера и сохранённый результат. Для оплаты используют тестовый режим провайдера и его документированные тестовые данные.

## Что важно помнить

- После клика событие может уже произойти: поздняя подписка его пропустит.
- `page` и `popup` — разные страницы; действия направляют нужной.
- Iframe имеет собственный документ, обычный локатор родительской страницы не ищет внутри него автоматически.

## Мини-шпаргалка

Подписка → действие → событие → нужный объект страницы/файла → проверка результата.
