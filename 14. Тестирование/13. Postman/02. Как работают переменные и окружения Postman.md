# Переменные и окружения Postman

> [!NOTE]
> Переменные убирают повторяющиеся URL и данные. Окружение хранит настройки выбранного стенда. При одинаковом имени приоритет от широкого к узкому: global → collection → environment → data → local. Перед запросом нужно проверить активное окружение и итоговое значение.

## Вопрос

Как переключать одну коллекцию между стендами? Почему Postman подставил другое значение переменной?

## Пример настройки

Создай environment `QA local`:

| Переменная | Значение | Назначение |
| --- | --- | --- |
| baseUrl | `http://127.0.0.1:3007` | адрес учебного сервера |
| token | `qa-a` | учебный пользователь A |

В URL используй `{{baseUrl}}/tasks`, в Bearer Token — `{{token}}`. Смена окружения меняет настройки, сохраняя сами запросы.

## Доступ из скриптов

```js
const baseUrl = pm.environment.get('baseUrl');
pm.expect(baseUrl, 'Выбрано окружение с baseUrl').to.be.a('string');

pm.collectionVariables.set('taskId', '12');
pm.variables.set('requestNote', 'только для текущего запуска');

console.log('baseUrl:', baseUrl);
// Токен и другие секреты в консоль не выводим.
```

`pm.environment.get` читает конкретный scope. `pm.variables.get` выбирает значение с учётом приоритетов. Переменная `taskId` из data-файла может перекрыть одноимённую collection-переменную — это частая причина запроса к неверному объекту.

## Как искать проблему

Открой подсказку переменной и Postman Console, проверь URL отправленного запроса. Убедись, что выбран нужный environment, имя совпадает по регистру, а более узкий scope не содержит старое значение.

В реальном проекте разделяй безопасную конфигурацию и секреты. Postman Vault или секреты CI подходят по возможностям выбранного раннера; экспорт окружения нужно проверять перед сохранением в Git. Маскирование в интерфейсе не делает опубликованный JSON безопасным.

## Что важно помнить

- Неразрешённое `{{taskId}}` может уйти в запрос как буквальный текст.
- Значение из прошлого прогона нельзя считать подготовкой данных нового.
- Local-переменные временны в пределах соответствующего выполнения запроса или коллекции.
- Учебные `qa-a` и `qa-b` не являются реальной схемой безопасности.

## Мини-шпаргалка

Адрес — в environment. Общие настройки — в collection. Временные данные — в local. При конфликте проверь scope.
