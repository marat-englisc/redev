# Первый запрос и коллекция Postman

> [!NOTE]
> Postman позволяет отправлять HTTP-запросы, изучать ответы и выполнять проверки. Коллекция хранит связанные запросы, их настройки и скрипты. Для начала нужно понимать метод, URL, параметры, headers и body, а затем сравнивать ответ с контрактом.

## Вопрос

Как создать запрос в Postman? Чем Params отличаются от Body и зачем нужна коллекция?

## Подготовка

Запусти [учебный стенд](<../15. Практика QA/01. Как запустить локальный учебный стенд QA.md>) и используй desktop-приложение Postman либо web-приложение с локальным агентом, который имеет доступ к `127.0.0.1`. Облачный агент не обращается к твоему localhost.

## Первый запрос

1. Создай коллекцию `QA Junior Lab`.
2. Добавь запрос `Health`, метод GET, URL `http://127.0.0.1:3007/health`.
3. Нажми Send и проверь статус 200 и тело `{"status":"ok"}`.
4. Сохрани запрос в коллекции.
5. Создай `Create task`: POST `http://127.0.0.1:3007/tasks`.
6. В Authorization выбери Bearer Token и укажи учебное значение `qa-a`.
7. В Body выбери raw → JSON:

```json
{"title":"Подготовить чек-лист"}
```

Ожидается 201 и объект с `id`, `title`, `done: false`. При выборе JSON Postman добавляет соответствующий Content-Type; проверь итоговый заголовок.

## Что где находится

| Часть | Пример | Назначение |
| --- | --- | --- |
| Path | `/tasks/12` | конкретная задача |
| Params | `?done=false` | фильтр, если он поддержан контрактом |
| Headers | `Content-Type: application/json` | формат тела |
| Authorization | Bearer `qa-a` | учебная идентификация |
| Body | `{"title":"..."}` | данные создаваемой задачи |

Стенд не реализует фильтрацию `done`; пример Params объясняет расположение параметра, а не обещает поддержку на любом API.

## Что важно помнить

- Отправить запрос и проверить его результат — разные действия.
- Postman не применяет браузерную CORS-политику так же, как страница приложения.
- Не нужно выбирать form-data для JSON API, если контракт этого не требует.
- Названия вкладок могут отличаться между версиями; тестовые скрипты находятся в Scripts → Post-response.

## Мини-шпаргалка

Коллекция → запрос → метод/URL → auth/headers/body → Send → контракт и результат → Save.
