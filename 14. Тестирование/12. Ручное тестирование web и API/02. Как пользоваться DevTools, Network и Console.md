# DevTools для тестировщика

> [!NOTE]
> Network показывает запросы, ответы и время обмена; Console — сообщения и ошибки клиентского кода; Elements — DOM и стили; Application — хранилища и service worker. Вместе они помогают описать, на каком участке проявляется проблема.

## Вопрос

Кнопка «Сохранить» не работает. Как исследовать проблему в браузере и какие данные приложить к баг-репорту?

## Порядок исследования

1. Открыть DevTools до воспроизведения. В Network включить Preserve log, если действие вызывает переход.
2. Очистить список, выполнить одно действие и отфильтровать Fetch/XHR.
3. Проверить, появился ли нужный запрос, его URL и метод.
4. Изучить Payload, статус, Response и Timing.
5. Проверить Console и сопоставить события по времени.
6. Сравнить серверный ответ с состоянием интерфейса.

## Пример диагностики

| Наблюдение | Возможная область проблемы | Следующая проверка |
| --- | --- | --- |
| Запроса нет, есть TypeError | клиентский обработчик | точный стек, условия возникновения |
| Запрос отправлен с пустым ID | формирование данных | действия до отправки, состояние формы |
| Ответ 500 | сервер / зависимость | request ID и серверные логи |
| Ответ 200 с правильными данными, UI старый | обновление UI / кеш | reload и повторное чтение |
| Ответ 200, браузер сообщает CORS | политика доступа браузера | Origin, CORS headers, preflight |

Это направления исследования, а не окончательное доказательство причины. Ошибка клиента может быть следствием неожиданного серверного ответа.

## Полезные приёмы

Disable cache действует при открытых DevTools и помогает исследовать HTTP-кеш, но не очищает автоматически все виды кеширования. Offline и throttling позволяют проверить потерю сети и медленную загрузку. Application показывает cookies, localStorage и данные service worker; перед очисткой нужно понимать, что именно сбрасываем.

`Copy as cURL` помогает повторить запрос вне UI. Такой текст часто содержит авторизацию. HAR тоже может включать приватные данные: перед передачей нужно проверить и обезличить содержимое.

## Практика

Выполни сохранение профиля и запиши: метод, путь, тело запроса, статус, значимые поля ответа и видимый результат. Затем отключи сеть и повтори действие. Сравни сообщение пользователю и сохранённые данные после восстановления сети.

## Мини-шпаргалка

Действие → есть ли запрос → что отправили → что получили → что увидел пользователь → доказательства.
