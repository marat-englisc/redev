# Клиент, сервер и HTTP для тестировщика

> [!NOTE]
> Браузер отправляет HTTP-запрос, сервер возвращает статус, заголовки и тело. Интерфейс и сервер могут по-разному обрабатывать ошибку, поэтому QA проверяет и обмен по сети, и видимый результат. Метод и статус оценивают вместе с контрактом API.

## Вопрос

Что происходит после нажатия «Сохранить»? Какие части HTTP-запроса нужно уметь читать?

## Пример обмена

```http
POST /api/orders?currency=RUB HTTP/1.1
Host: shop.example.test
Content-Type: application/json
Authorization: Bearer <test-token>

{"productId":42,"quantity":2}
```

```http
HTTP/1.1 201 Created
Content-Type: application/json
Location: /api/orders/901

{"id":901,"status":"new","total":6000}
```

Путь выбирает ресурс, query передаёт параметры, заголовки — метаданные, тело — данные запроса. Path-параметр `/orders/901` и query `?status=new` имеют разное назначение. JSON различает число `2`, строку `"2"`, `null` и отсутствие ключа.

## Методы и свойства

| Метод | Типичное назначение | На что обратить внимание |
| --- | --- | --- |
| GET | прочитать ресурс | не должен запрашивать изменение бизнес-состояния |
| POST | обработать команду / создать ресурс | повтор может создать второй объект |
| PUT | заменить состояние по заданному URI | семантически идемпотентен |
| PATCH | частично изменить | идемпотентность зависит от операции |
| DELETE | удалить связь с ресурсом | идемпотентный эффект; ответы повторов могут отличаться |

Идемпотентность означает одинаковый ожидаемый эффект повторного запроса, а не обязательно одинаковое тело ответа. Для POST она может быть обеспечена контрактом и ключом идемпотентности.

## Статусы

2xx — успешная обработка по семантике конкретного кода; 3xx — перенаправления и другие указания; 4xx — проблема запроса или доступа; 5xx — сервер не выполнил корректную обработку. `401` относится к отсутствующей/неподходящей аутентификации, `403` — к отказу в доступе. Сервер может скрывать наличие ресурса через `404` по контракту.

## Что важно помнить

- `200` с неверной суммой остаётся дефектом поведения.
- `204` не содержит тела; нельзя ожидать JSON от такого ответа.
- HTTPS шифрует транспорт, но не исправляет ошибочные права доступа.
- Подробнее протокол разобран в [Web технологиях](<../../01. Web технологии/>).

## Мини-шпаргалка

Метод + URL + headers + body → status + headers + body → изменение состояния + UI.
