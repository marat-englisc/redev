# event.target и event.currentTarget

> [!NOTE]
> `event.target` — элемент, на котором событие **возникло** (самый глубокий, по которому кликнули). `event.currentTarget` — элемент, на котором сейчас **выполняется обработчик**. Они совпадают, если кликнули прямо по элементу с обработчиком, и различаются, когда событие всплыло от потомка. На этом различии построено делегирование событий.

## Вопрос

Что делает `event.target`? Чем `event.target` отличается от `event.currentTarget`?

## Пример

```html
<ul id="menu">
  <li><button data-id="1">Чайник <span>🔥</span></button></li>
</ul>
```

```javascript
menu.addEventListener("click", (event) => {
  console.log(event.target);        // <span> — если кликнули по иконке
  console.log(event.currentTarget); // <ul id="menu"> — где висит обработчик
});
```

## Сравнение

| | `event.target` | `event.currentTarget` |
| --- | --- | --- |
| Что это | источник события | элемент с обработчиком |
| Меняется при всплытии | нет | да, на каждом уровне |
| `this` в обычной функции | — | равен `currentTarget` |
| После завершения обработки | остается | становится `null` |

```javascript
menu.addEventListener("click", function (event) {
  this === event.currentTarget; // true
});
```

## Делегирование событий

Поскольку `target` указывает на исходный элемент, достаточно одного обработчика на контейнере:

```javascript
menu.addEventListener("click", (event) => {
  const button = event.target.closest("button[data-id]");
  if (!button || !menu.contains(button)) return;
  addToCart(button.dataset.id);
});
```

`closest` нужен потому, что `target` может оказаться вложенным элементом (`span`, `svg`, `path`), а не самой кнопкой.

## Асинхронный доступ

```javascript
button.addEventListener("click", async (event) => {
  await save();
  console.log(event.currentTarget); // null — обработка события уже завершена
});
```

Сохраняйте элемент в переменную до первого `await`: `const el = event.currentTarget`.

## Другие связанные свойства

- `event.relatedTarget` — для `mouseover`/`mouseout` и `focusin`/`focusout`: элемент, откуда или куда ушел курсор или фокус;
- `event.composedPath()` — полный путь события, включая Shadow DOM;
- в Shadow DOM `target` «ретаргетится» на хост-элемент для внешних слушателей.

## Что важно помнить

- В TypeScript `event.target` имеет тип `EventTarget | null` — для доступа к `value` нужно сужение или `currentTarget` с типом элемента.
- В React `event.currentTarget` в `onChange` типизирован как элемент, к которому привязан обработчик, поэтому его удобнее использовать для `value`.
- Клик по `label` генерирует второе событие `click` на связанном `input` — проверяйте `target`.
- Для элементов, которые не должны быть `target` (декоративные иконки), можно задать `pointer-events: none`.

## Мини-шпаргалка

- `target` — где возникло событие.
- `currentTarget` — где сработал обработчик.
- При всплытии `target` постоянен, `currentTarget` меняется.
- Делегирование: `event.target.closest(selector)`.
- После `await` `currentTarget` — `null`.
