# Всплытие, погружение и stopPropagation

> [!NOTE]
> Событие в DOM проходит три фазы: **погружение (capturing)** от `window` вниз к целевому элементу, **фаза цели** (target) и **всплытие (bubbling)** от цели обратно вверх. По умолчанию обработчики срабатывают на всплытии, с `{ capture: true }` — на погружении. `event.stopPropagation()` останавливает дальнейшее распространение события, а `stopImmediatePropagation()` — еще и остальные обработчики на текущем элементе.

## Вопрос

Что такое всплытие и погружение событий? Что делает `event.stopPropagation()` и когда его стоит использовать?

## Три фазы

```text
           window
             │  ▲
   capturing │  │ bubbling
             ▼  │
           document
             │  ▲
            body
             │  ▲
           <ul>
             │  ▲
            <li>  ← target phase
```

```javascript
ul.addEventListener("click", () => console.log("ul — всплытие"));
ul.addEventListener("click", () => console.log("ul — погружение"), { capture: true });
li.addEventListener("click", () => console.log("li — цель"));

// клик по li:
// ul — погружение
// li — цель
// ul — всплытие
```

`event.eventPhase`: `1` — погружение, `2` — цель, `3` — всплытие.

## Всплытие

Большинство событий всплывают: `click`, `input`, `keydown`, `submit`. Не всплывают: `focus`, `blur` (есть всплывающие `focusin`/`focusout`), `mouseenter`, `mouseleave`, `load`, `scroll` на элементах.

Всплытие позволяет повесить один обработчик на контейнер — **делегирование событий**.

## Погружение

```javascript
document.addEventListener(
  "click",
  (event) => {
    if (!isAllowed(event.target)) event.stopPropagation(); // перехват раньше всех
  },
  { capture: true },
);
```

Используется редко: для глобального перехвата, аналитики, закрытия выпадающих меню до срабатывания внутренних обработчиков.

## stopPropagation

```javascript
modal.addEventListener("click", (event) => {
  event.stopPropagation(); // клик внутри модалки не дойдет до overlay
});

overlay.addEventListener("click", closeModal);
```

| Метод | Что останавливает |
| --- | --- |
| `stopPropagation()` | передачу события следующим элементам; другие обработчики **этого** элемента сработают |
| `stopImmediatePropagation()` | передачу дальше и остальные обработчики на этом элементе |
| `preventDefault()` | действие браузера по умолчанию, но **не** распространение |

## Почему stopPropagation — крайняя мера

```javascript
// аналитика на document не узнает о кликах внутри
// закрытие dropdown по клику снаружи перестает работать
```

Вместо остановки всплытия чаще лучше проверить источник:

```javascript
overlay.addEventListener("click", (event) => {
  if (event.target === overlay) closeModal(); // клик именно по фону
});

document.addEventListener("click", (event) => {
  if (!dropdown.contains(event.target)) closeDropdown();
});
```

## Что важно помнить

- Обработчики на одном элементе и одной фазе вызываются в порядке добавления.
- В React события делегируются на корень приложения; `e.stopPropagation()` в React останавливает всплытие в React-дереве, включая порталы.
- Порталы в React всплывают по React-дереву, а не по DOM.
- `event.composedPath()` показывает весь путь, по которому пройдет событие.

## Мини-шпаргалка

- Фазы: погружение → цель → всплытие.
- По умолчанию — всплытие, `{ capture: true }` — погружение.
- `stopPropagation` — не передавать дальше.
- `stopImmediatePropagation` — и не вызывать соседние обработчики.
- Вместо остановки — проверка `event.target`.
