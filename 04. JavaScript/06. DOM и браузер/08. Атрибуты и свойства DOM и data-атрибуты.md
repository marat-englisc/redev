# Атрибуты и свойства DOM-элемента, data-атрибуты

> [!NOTE]
> **Атрибуты** — то, что написано в HTML: строки, которые читают через `getAttribute` и меняют через `setAttribute`. **Свойства** — поля DOM-объекта: `el.id`, `input.value`, `checkbox.checked`. Для стандартных атрибутов браузер создает соответствующие свойства, но они могут расходиться: атрибут `value` — начальное значение, свойство `value` — текущее. **data-атрибуты** (`data-*`) хранят пользовательские данные и доступны через `el.dataset`.

## Вопрос

Чем атрибуты отличаются от свойств DOM-элемента? Что такое data-атрибуты и как с ними работать из JavaScript?

## Атрибуты

```html
<input id="email" type="email" value="anna@example.com" disabled data-step="2">
```

```javascript
const input = document.querySelector("#email");

input.getAttribute("value");     // "anna@example.com"
input.setAttribute("placeholder", "Email");
input.hasAttribute("disabled");  // true
input.removeAttribute("disabled");
input.attributes;                // коллекция всех атрибутов
input.toggleAttribute("hidden"); // добавить или убрать булев атрибут
```

Значения атрибутов — всегда строки, имена нечувствительны к регистру.

## Свойства

```javascript
input.id;        // "email"
input.type;      // "email"
input.value;     // текущее значение поля
input.disabled;  // boolean, а не строка
input.className; // атрибут class → свойство className
label.htmlFor;   // атрибут for → свойство htmlFor
```

Свойства имеют типы: `checked` и `disabled` — boolean, `tabIndex` — число, `style` — объект.

## Где они расходятся

```javascript
// пользователь ввел "maria@example.com"
input.getAttribute("value"); // "anna@example.com" — начальное значение
input.value;                 // "maria@example.com" — текущее
input.defaultValue;          // "anna@example.com"

const link = document.querySelector('a[href="/about"]');
link.getAttribute("href");   // "/about"
link.href;                   // "https://site.ru/about" — абсолютный URL

checkbox.checked = true;     // атрибут checked не меняется
```

| | Атрибут | Свойство |
| --- | --- | --- |
| Где | HTML-разметка | объект DOM |
| Тип | всегда строка | любой тип |
| Чтение | `getAttribute` | `el.prop` |
| Нестандартные | хранятся | не создаются автоматически |
| Для форм | начальное состояние | текущее состояние |

## data-атрибуты

```html
<button data-product-id="42" data-action="add-to-cart" data-in-stock="true">
  В корзину
</button>
```

```javascript
button.dataset.productId;          // "42" — kebab-case → camelCase
button.dataset.action;             // "add-to-cart"
button.dataset.inStock === "true"; // значения — строки
button.dataset.count = 3;          // создаст атрибут data-count="3"
delete button.dataset.action;      // удалит атрибут
```

Применение: связь элемента с данными (id), делегирование событий, хуки для тестов и аналитики, состояние для CSS:

```css
[data-state="open"] { display: block; }
```

```javascript
document.addEventListener("click", (event) => {
  const button = event.target.closest("[data-action]");
  if (!button) return;
  actions[button.dataset.action](button.dataset.productId);
});
```

## Что важно помнить

- Для стандартных атрибутов обычно удобнее свойства; `getAttribute` нужен для нестандартных атрибутов и исходных значений.
- Булев атрибут удаляют `removeAttribute`, а не `setAttribute("disabled", "false")` — это всё равно `disabled`.
- В React для DOM пишут свойства в camelCase (`className`, `htmlFor`, `tabIndex`), а `data-*` и `aria-*` — как есть.
- Не храните в `data-*` чувствительные данные и большие объекты.

## Мини-шпаргалка

- Атрибут — строка в HTML, свойство — поле DOM-объекта.
- `getAttribute`/`setAttribute` против `el.value`, `el.checked`.
- Атрибут `value` — начальное, свойство `value` — текущее.
- `data-*` → `el.dataset.camelCase`, значения — строки.
- Булевы атрибуты снимают через `removeAttribute`.
