# Как заблокировать прокрутку страницы?

> [!NOTE]
> Прокрутку страницы обычно блокируют через `overflow: hidden` на `body` или `documentElement`, часто при открытии модального окна.

## Вопрос

Как запретить прокрутку страницы через JavaScript и CSS?

## Базовый способ

```css
body.is-locked {
  overflow: hidden;
}
```

```javascript
document.body.classList.add('is-locked');
document.body.classList.remove('is-locked');
```

Так страница перестает прокручиваться, пока класс активен.

## Пример для модального окна

```javascript
function openModal() {
  modal.hidden = false;
  document.body.classList.add('is-locked');
}

function closeModal() {
  modal.hidden = true;
  document.body.classList.remove('is-locked');
}
```

## Проблема скачка ширины

Когда пропадает scrollbar, контент может чуть сдвинуться. Иногда добавляют компенсацию через `padding-right`.

```javascript
const scrollbarWidth = window.innerWidth - document.documentElement.clientWidth;

document.body.style.paddingRight = `${scrollbarWidth}px`;
document.body.classList.add('is-locked');
```

При снятии блокировки стили нужно очистить.

## Мобильные нюансы

На мобильных браузерах блокировка `body` может вести себя по-разному. Для сложных модальных окон иногда используют фиксацию позиции страницы и восстановление scroll-позиции при закрытии.

## Что важно помнить

- `overflow: hidden` на `body` может сдвинуть layout из-за исчезновения полосы прокрутки — помогает `scrollbar-gutter: stable`.
- На iOS Safari `overflow: hidden` на `body` раньше не работал — использовали `position: fixed` с сохранением `scrollY`.
- Нативный `<dialog>` с `showModal()` упрощает модальные окна; `overscroll-behavior: contain` не дает прокрутке выйти наружу.
- Не забывайте возвращать прокрутку при закрытии модалки и размонтировании.

## Мини-шпаргалка

```javascript
document.body.classList.add('is-locked');    // lock
document.body.classList.remove('is-locked'); // unlock
```
