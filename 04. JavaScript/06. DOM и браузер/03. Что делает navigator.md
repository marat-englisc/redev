# Что делает navigator?

> [!NOTE]
> `navigator` хранит информацию о браузере, устройстве и доступных возможностях окружения.

## Вопрос

Для чего нужен объект `navigator`?

## Определение

`navigator` - свойство `window`, которое предоставляет данные о браузерной среде: язык, online/offline-статус, user agent, clipboard, geolocation и другие API.

Из-за приватности часть данных может быть ограничена или неточной.

## Примеры

```javascript
console.log(navigator.language);
console.log(navigator.onLine);
console.log(navigator.userAgent);
```

## Clipboard API

```javascript
await navigator.clipboard.writeText('Copied text');

const text = await navigator.clipboard.readText();
console.log(text);
```

Для некоторых методов нужны HTTPS и разрешение пользователя.

## Geolocation

```javascript
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log(position.coords.latitude);
    console.log(position.coords.longitude);
  },
  (error) => {
    console.error(error.message);
  }
);
```

Геолокация требует разрешения пользователя.

## Когда использовать

- определить язык пользователя;
- проверить состояние сети;
- работать с буфером обмена;
- запросить геолокацию;
- проверить поддержку некоторых API.

## Что важно помнить

- `navigator.userAgent` ненадежен для определения браузера — используйте feature detection.
- `navigator.onLine` и события `online`/`offline` показывают сетевое состояние, но не гарантируют доступ к серверу.
- `navigator.clipboard`, `geolocation`, `mediaDevices` требуют HTTPS и разрешений.
- `navigator.sendBeacon` надежно отправляет данные при уходе со страницы.

## Мини-шпаргалка

```javascript
navigator.language;
navigator.onLine;
navigator.clipboard;
navigator.geolocation;
```
