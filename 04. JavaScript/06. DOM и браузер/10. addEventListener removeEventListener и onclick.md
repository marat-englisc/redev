# addEventListener, removeEventListener и onclick

> [!NOTE]
> `addEventListener(type, handler, options)` подписывает функцию на событие элемента; на одно событие можно повесить сколько угодно обработчиков. `removeEventListener` удаляет обработчик, но только если передать **ту же ссылку** на функцию и те же `capture`-параметры — поэтому анонимную функцию так удалить нельзя. Свойство `onclick` хранит лишь один обработчик и перезаписывается. Современная альтернатива удалению — опция `signal` с `AbortController`.

## Вопрос

Что делают `addEventListener()` и `removeEventListener()`? Чем `onclick` отличается от `addEventListener()`? Можно ли использовать анонимную функцию как обработчик?

## addEventListener

```javascript
const button = document.querySelector("#save");

function handleClick(event) {
  console.log("Клик по", event.currentTarget);
}

button.addEventListener("click", handleClick);
button.addEventListener("click", trackClick); // второй обработчик тоже сработает
```

Опции:

| Опция | Что делает |
| --- | --- |
| `capture: true` | обработчик срабатывает на фазе погружения |
| `once: true` | удаляется после первого вызова |
| `passive: true` | обещание не вызывать `preventDefault` — ускоряет скролл |
| `signal` | удалить обработчик при `controller.abort()` |

```javascript
window.addEventListener("scroll", onScroll, { passive: true });
dialog.addEventListener("close", onClose, { once: true });
```

## removeEventListener

```javascript
button.removeEventListener("click", handleClick); // работает — та же ссылка

button.addEventListener("click", () => console.log("hi"));
button.removeEventListener("click", () => console.log("hi")); // НЕ работает — другая функция
```

Правила удаления:

- нужна та же функция по ссылке;
- `capture` должен совпадать: обработчик с `{ capture: true }` удаляется только с `{ capture: true }`;
- `bind` каждый раз создает новую функцию — сохраняйте результат в переменную.

## Анонимная функция как обработчик

```javascript
button.addEventListener("click", () => {
  save(form);
});
```

Можно, если обработчик не нужно удалять (например, живет всё время жизни страницы). Если удалять нужно — используйте именованную функцию или `signal`:

```javascript
const controller = new AbortController();

button.addEventListener("click", () => save(form), { signal: controller.signal });
window.addEventListener("resize", () => layout(), { signal: controller.signal });

controller.abort(); // оба обработчика удалены
```

## onclick и addEventListener

```javascript
button.onclick = () => console.log("первый");
button.onclick = () => console.log("второй"); // первый потерян

button.onclick = null; // удалить
```

```html
<button onclick="save()">Сохранить</button> <!-- inline-обработчик — антипаттерн -->
```

| | `onclick` | `addEventListener` |
| --- | --- | --- |
| Количество обработчиков | один | сколько угодно |
| Удаление | `el.onclick = null` | `removeEventListener` / `signal` |
| Фаза погружения | нет | `capture: true` |
| `once`, `passive` | нет | есть |
| Inline в HTML | возможно (плохо, блокируется CSP) | нет |
| Работает для всех событий | только с `on`-свойством | для любых, включая кастомные |

## Что важно помнить

- Обработчик получает объект события; `this` в обычной функции — `currentTarget`, в стрелке — внешний `this`.
- Не забывайте удалять обработчики с `window`, `document` и глобальных объектов в SPA — иначе утечки памяти и двойные срабатывания.
- В React события вешаются через пропсы (`onClick`), а ручные `addEventListener` в `useEffect` обязательно снимаются в cleanup.
- Повторный `addEventListener` с той же функцией и теми же параметрами не добавит дубликат.

## Мини-шпаргалка

- `addEventListener(type, fn, { capture, once, passive, signal })`.
- Удаление — та же ссылка на функцию и тот же `capture`.
- Анонимный обработчик не удалить через `removeEventListener` — используйте `signal`.
- `onclick` — один обработчик, перезаписывается.
- В SPA снимайте глобальные обработчики.
