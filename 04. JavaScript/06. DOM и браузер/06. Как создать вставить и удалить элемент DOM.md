# Как создать, вставить и удалить элемент DOM

> [!NOTE]
> Элемент создают через `document.createElement(tag)`, наполняют через `textContent`, атрибуты и `classList`, а вставляют методами `append`, `prepend`, `before`, `after` или `insertAdjacentElement`. Удаляют через `element.remove()` (старый способ — `parent.removeChild(el)`). Для вставки многих элементов используют `DocumentFragment`, чтобы обновить DOM за одну операцию.

## Вопрос

Как создать новый элемент и добавить его на страницу? Как удалить элемент из DOM?

## Создание

```javascript
const item = document.createElement("li");
item.textContent = "Купить хлеб";
item.className = "todo";
item.dataset.id = "42";
item.setAttribute("aria-label", "Задача: купить хлеб");

const text = document.createTextNode("просто текст");
const clone = item.cloneNode(true); // глубокая копия с детьми (без обработчиков)
```

## Вставка

```javascript
const list = document.querySelector("#todos");

list.append(item);              // в конец, принимает несколько узлов и строки
list.prepend(item);             // в начало
list.before(banner);            // перед list
list.after(footer);             // после list
list.replaceChildren(a, b);     // заменить всех детей
oldItem.replaceWith(newItem);   // заменить элемент

list.insertAdjacentElement("beforeend", item);
list.insertAdjacentHTML("afterbegin", "<li>HTML-строка</li>"); // осторожно с XSS
```

Позиции `insertAdjacent*`:

```text
<!-- beforebegin -->
<ul>
  <!-- afterbegin -->
  <li>...</li>
  <!-- beforeend -->
</ul>
<!-- afterend -->
```

Старые методы `appendChild` и `insertBefore` работают, но принимают только один узел.

Вставка существующего элемента **перемещает** его: узел не может быть в двух местах сразу.

## Массовая вставка: DocumentFragment

```javascript
const fragment = document.createDocumentFragment();

for (const todo of todos) {
  const li = document.createElement("li");
  li.textContent = todo.title;
  fragment.append(li);
}

list.append(fragment); // одна вставка — один пересчет layout
```

То же через `list.append(...items)` или `replaceChildren`.

## Шаблоны

```html
<template id="card-template">
  <article class="card"><h2></h2><p></p></article>
</template>
```

```javascript
const template = document.querySelector("#card-template");
const card = template.content.cloneNode(true);
card.querySelector("h2").textContent = product.title;
container.append(card);
```

## Удаление

```javascript
item.remove();                     // современный способ
item.parentElement.removeChild(item); // старый способ
list.replaceChildren();            // удалить всех детей
list.innerHTML = "";               // тоже очищает, но парсит строку
```

Удаленный элемент можно вставить снова, пока на него есть ссылка. Обработчики, добавленные через `addEventListener`, удалятся вместе с узлом, когда он станет недостижим для сборщика мусора.

## Безопасность

```javascript
li.textContent = userInput;   // безопасно — текст, а не HTML
li.innerHTML = userInput;     // XSS, если userInput содержит <img onerror=...>
```

## Что важно помнить

- `textContent` быстрее и безопаснее `innerHTML` для текста.
- Удаление элемента из DOM не освобождает память, если ссылка на него хранится в переменной или замыкании (detached DOM — частая утечка).
- В React и Vue DOM напрямую не меняют — это ломает синхронизацию с Virtual DOM; используйте ref только для точечных задач.
- `cloneNode` не копирует обработчики событий и значения, введенные в поля.

## Мини-шпаргалка

- Создать: `document.createElement(tag)`.
- Наполнить: `textContent`, `setAttribute`, `classList`, `dataset`.
- Вставить: `append`, `prepend`, `before`, `after`, `insertAdjacentElement`.
- Много элементов — `DocumentFragment` или `append(...items)`.
- Удалить: `el.remove()`.
