# Делегирование событий (Event Delegation)

> [!NOTE]
> Делегирование событий - прием, при котором один обработчик на родителе обрабатывает события от дочерних элементов.

## Вопрос

Что такое Event Delegation и зачем он нужен?

## Определение

Делегирование основано на всплытии событий. Вместо того чтобы вешать обработчик на каждый дочерний элемент, мы вешаем один обработчик на общего родителя и определяем, по какому элементу кликнули.

## Пример

```html
<ul class="list">
  <li data-id="1">Item 1</li>
  <li data-id="2">Item 2</li>
  <li data-id="3">Item 3</li>
</ul>
```

```javascript
const list = document.querySelector('.list');

list.addEventListener('click', (event) => {
  const item = event.target.closest('li');

  if (!item || !list.contains(item)) return;

  console.log(item.dataset.id);
});
```

Один обработчик работает для всех `li`.

## Почему это удобно

- меньше обработчиков в памяти;
- работает для элементов, добавленных позже;
- проще централизовать логику;
- удобно использовать с `data-*` атрибутами.

## Частая защита

```javascript
if (!item || !container.contains(item)) return;
```

Такая проверка защищает от кликов вне нужного контейнера.

## Попробуйте

Один обработчик на весь список: работают и кнопки исходных элементов, и кнопки добавленных позже. В консоли видно, по какому элементу кликнули.

```html run=delegation
<form id="form">
  <input name="title" placeholder="Новая задача" required />
  <button>Добавить</button>
</form>
<ul id="list">
  <li data-id="1">Разобрать всплытие <button data-action="remove">×</button></li>
  <li data-id="2">Попробовать делегирование <button data-action="remove">×</button></li>
</ul>
```

```js run=delegation
const list = document.getElementById("list");
const form = document.getElementById("form");

// один обработчик на родителе вместо обработчика на каждой кнопке
list.addEventListener("click", (event) => {
  const button = event.target.closest('[data-action="remove"]');
  if (!button || !list.contains(button)) return;

  const item = button.closest("li");
  console.log("Удаляем задачу", item.dataset.id);
  item.remove();
});

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const li = document.createElement("li");
  li.dataset.id = String(Date.now());
  li.append(form.title.value, " ");
  li.insertAdjacentHTML("beforeend", '<button data-action="remove">×</button>');
  list.append(li);
  form.reset();
});
```

## Что важно помнить

- Делегирование работает для динамически добавленных элементов без новых обработчиков.
- Используйте `event.target.closest(selector)`, потому что `target` может быть вложенным элементом.
- Не всплывающие события (`focus`, `mouseenter`) делегировать нельзя — используйте `focusin` или `mouseover`.
- React сам делегирует события на корень приложения.

## Мини-шпаргалка

```javascript
parent.addEventListener('click', (event) => {
  const target = event.target.closest(selector);
  if (!target) return;
});
```
