# Что такое indexedDB?

> [!NOTE]
> IndexedDB - асинхронная браузерная база данных для хранения больших и структурированных данных на клиенте.

## Вопрос

Чем IndexedDB отличается от `localStorage`?

## Определение

IndexedDB - встроенное хранилище браузера, похожее на клиентскую NoSQL-базу данных. В нем можно хранить объекты, файлы, blobs, большие наборы данных и создавать индексы для поиска.

В отличие от `localStorage`, IndexedDB работает асинхронно и не блокирует основной поток так же грубо.

## Когда использовать

- offline-first приложения;
- кэш больших данных;
- редакторы с локальным сохранением;
- хранение файлов и blobs;
- сложные структуры данных на клиенте.

## Пример открытия базы

```javascript
const request = indexedDB.open('app-db', 1);

request.onupgradeneeded = () => {
  const db = request.result;

  db.createObjectStore('users', { keyPath: 'id' });
};

request.onsuccess = () => {
  const db = request.result;
  console.log('DB opened', db.name);
};
```

## Основные понятия

| Термин | Значение |
| --- | --- |
| Database | база данных |
| Object store | хранилище объектов, похоже на таблицу |
| Key | ключ записи |
| Index | индекс для поиска |
| Transaction | операция чтения или записи |

## IndexedDB vs localStorage

| Критерий | IndexedDB | `localStorage` |
| --- | --- | --- |
| API | асинхронный | синхронный |
| Данные | объекты, файлы, blobs | строки |
| Объем | больше | меньше |
| Поиск | индексы | вручную |
| Сценарий | база на клиенте | простые настройки |

## Что важно помнить

- IndexedDB — асинхронная транзакционная база данных в браузере для больших объемов и структурированных данных.
- Нативный API громоздкий — используют обертки `idb` или Dexie.
- Схема меняется только в `onupgradeneeded` при увеличении версии базы.
- Данные могут быть удалены браузером при нехватке места; для надежности — `navigator.storage.persist()`.

## Мини-шпаргалка

```javascript
const request = indexedDB.open('db-name', version);
request.onupgradeneeded = setupSchema;
request.onsuccess = useDatabase;
```
