# Что такое DOM и чем он отличается от HTML

> [!NOTE]
> **DOM (Document Object Model)** — объектное представление документа в памяти браузера: дерево узлов, которое JavaScript может читать и изменять. **HTML** — исходный текст, из которого браузер строит DOM при парсинге. DOM может отличаться от HTML: парсер исправляет ошибки и добавляет пропущенные элементы, а JavaScript меняет DOM после загрузки. Исходный HTML виден в «Просмотре кода», а текущий DOM — во вкладке Elements.

## Вопрос

Что такое DOM-дерево? Чем DOM отличается от HTML?

## DOM-дерево

```html
<body>
  <h1>Каталог</h1>
  <ul id="list">
    <li>Чайник</li>
  </ul>
</body>
```

```text
document
└── html
    ├── head
    └── body
        ├── h1
        │   └── #text "Каталог"
        └── ul#list
            └── li
                └── #text "Чайник"
```

## Типы узлов

| Узел | `nodeType` | Пример |
| --- | --- | --- |
| `Element` | 1 | `<div>`, `<li>` |
| `Text` | 3 | текст и пробелы между тегами |
| `Comment` | 8 | `<!-- комментарий -->` |
| `Document` | 9 | `document` |
| `DocumentFragment` | 11 | временный контейнер, `<template>.content` |

```javascript
list.childNodes; // NodeList с текстовыми узлами-пробелами и li
list.children;   // HTMLCollection только элементов
```

## Навигация

```javascript
el.parentElement;            // родитель
el.children;                 // дети-элементы
el.firstElementChild;        // первый ребенок
el.nextElementSibling;       // следующий сосед
el.closest(".card");         // ближайший предок по селектору (включая себя)
el.contains(other);          // содержит ли
```

## Чем DOM отличается от HTML

| | HTML | DOM |
| --- | --- | --- |
| Что это | текст разметки | объекты в памяти |
| Когда существует | в файле или ответе сервера | после парсинга, живет в браузере |
| Изменяется | только редактированием файла | JavaScript-ом в runtime |
| Ошибки разметки | могут быть | исправлены парсером |
| Где смотреть | View Source | DevTools → Elements |

```html
<!-- исходный HTML -->
<table>
  <tr><td>1</td></tr>
</table>
<p>Абзац<div>блок</div></p>
```

В DOM появится `<tbody>`, которого нет в HTML, а `p` закроется перед `div` — получится два абзаца и `div` между ними.

```javascript
document.querySelector("h1").textContent = "Новый заголовок";
// DOM изменился, исходный HTML — нет
```

## Свойства и атрибуты

HTML-атрибуты становятся начальными значениями DOM-свойств, но дальше живут отдельно:

```javascript
input.getAttribute("value"); // значение из HTML
input.value;                 // текущее значение, введенное пользователем
```

## Что важно помнить

- DOM — это API, доступное не только из JavaScript: им пользуются расширения, скринридеры (через accessibility tree), инструменты тестирования.
- Частые изменения DOM вызывают пересчет стилей и layout — их группируют.
- Virtual DOM в React — легкое описание интерфейса в памяти, которое сравнивается и применяется к настоящему DOM.
- SSR присылает HTML, а React потом «гидрирует» уже построенный DOM; несовпадение дает hydration error.

## Мини-шпаргалка

- DOM — дерево объектов документа в памяти.
- Узлы: элементы, текст, комментарии, документ.
- HTML — исходный текст, DOM — его живое представление.
- DOM отличается от HTML: исправления парсера и изменения JS.
- `children` — только элементы, `childNodes` — все узлы.
