# window и document: чем они отличаются

> [!NOTE]
> `window` — глобальный объект вкладки браузера: окно, его размеры, история, адрес, таймеры, хранилища, все глобальные переменные и API. `document` — объект загруженного HTML-документа, корень DOM-дерева: через него ищут и создают элементы. `document` — свойство `window` (`window.document`), то есть документ живет внутри окна.

## Вопрос

Что такое `document` и что такое `window`? Чем `window` отличается от `document`?

## window

```javascript
window.innerWidth;           // ширина viewport
window.scrollY;              // прокрутка
window.location.href;        // текущий URL
window.history.back();       // назад по истории
window.localStorage;         // хранилище
window.setTimeout === setTimeout; // true — глобальные функции живут на window
window.matchMedia("(prefers-color-scheme: dark)").matches;
window.addEventListener("resize", onResize);
```

`window` также играет роль глобального объекта: `var` и функции верхнего уровня обычного скрипта становятся его свойствами. Универсальная ссылка на глобальный объект — `globalThis`.

## document

```javascript
document.title = "Корзина";
document.querySelector(".cart");
document.createElement("li");
document.body;               // <body>
document.documentElement;    // <html>
document.readyState;         // "loading" | "interactive" | "complete"
document.cookie;
document.activeElement;      // элемент в фокусе
document.addEventListener("DOMContentLoaded", init);
```

## Сравнение

| | `window` | `document` |
| --- | --- | --- |
| Что представляет | вкладку / окно браузера | HTML-документ (DOM) |
| Роль | глобальный объект, BOM | корень DOM |
| Примеры свойств | `innerWidth`, `location`, `history`, `navigator`, `localStorage` | `body`, `title`, `cookie`, `forms` |
| Примеры методов | `setTimeout`, `fetch`, `alert`, `scrollTo`, `open` | `querySelector`, `createElement`, `getElementById` |
| События | `resize`, `load`, `beforeunload`, `popstate`, `online` | `DOMContentLoaded`, `visibilitychange`, `selectionchange` |
| Связь | `window.document` | `document.defaultView === window` |

## BOM и DOM

```text
window (BOM — Browser Object Model)
├── document (DOM)
├── location
├── history
├── navigator
├── screen
├── localStorage / sessionStorage
└── setTimeout, fetch, alert ...
```

BOM — всё, что относится к браузеру, а не к документу. Строгого стандарта BOM нет — эти API описаны в HTML Standard и отдельных спецификациях.

## iframe

У каждого `iframe` свой `window` и свой `document`:

```javascript
const frame = document.querySelector("iframe");
frame.contentWindow;   // window внутри iframe
frame.contentDocument; // document внутри iframe (только same-origin)
```

## Что важно помнить

- При SSR (Next.js) `window` и `document` недоступны на сервере — обращайтесь к ним в `useEffect` или после проверки `typeof window !== "undefined"`.
- В Web Worker нет ни `window`, ни `document` — глобальный объект там `self`.
- `window.location.href = "..."` перезагружает страницу, а `history.pushState` — нет.
- Для событий прокрутки всей страницы слушают `window`, а не `document.body`.

## Мини-шпаргалка

- `window` — окно браузера и глобальный объект.
- `document` — DOM загруженной страницы.
- `window.document` — документ внутри окна.
- BOM: `location`, `history`, `navigator`, `screen`, storage.
- На сервере и в воркерах их нет.
