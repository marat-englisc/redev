# Proxy и ловушки (traps)

> [!NOTE]
> `Proxy` — объект-обертка, который перехватывает операции над целевым объектом: чтение, запись, удаление, проверку `in`, вызов функции и другие. Перехватчики называются **ловушками (traps)** и описываются в объекте-обработчике (`handler`). Если ловушки нет, операция проходит к цели без изменений. На Proxy построены реактивность Vue 3, MobX, Immer и валидация данных.

## Вопрос

Что делает объект `Proxy`? Что такое ловушки и какие задачи решают с помощью Proxy?

## Синтаксис

```javascript
const proxy = new Proxy(target, handler);
```

```javascript
const user = { name: "Анна" };

const logged = new Proxy(user, {
  get(target, key, receiver) {
    console.log(`чтение ${String(key)}`);
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value, receiver) {
    console.log(`запись ${String(key)} = ${value}`);
    return Reflect.set(target, key, value, receiver);
  },
});

logged.name;          // чтение name → "Анна"
logged.age = 25;      // запись age = 25
user.age;             // 25 — изменения дошли до цели
```

## Основные ловушки

| Ловушка | Перехватывает |
| --- | --- |
| `get` | чтение `obj.key` |
| `set` | запись `obj.key = v` (должна вернуть `true`) |
| `has` | оператор `in` |
| `deleteProperty` | `delete obj.key` |
| `ownKeys` | `Object.keys`, `for...in`, `Reflect.ownKeys` |
| `getOwnPropertyDescriptor` | `Object.getOwnPropertyDescriptor` |
| `defineProperty` | `Object.defineProperty` |
| `apply` | вызов функции `fn()` |
| `construct` | `new Fn()` |
| `getPrototypeOf` / `setPrototypeOf` | работа с прототипом |

## Примеры применения

```javascript
// валидация
const product = new Proxy({}, {
  set(target, key, value) {
    if (key === "price" && (typeof value !== "number" || value < 0)) {
      throw new TypeError("Цена должна быть неотрицательным числом");
    }
    target[key] = value;
    return true;
  },
});

// значения по умолчанию
const withDefaults = (obj, fallback) =>
  new Proxy(obj, { get: (t, k) => (k in t ? t[k] : fallback) });
const translations = withDefaults({ hello: "Привет" }, "—");
translations.bye; // "—"

// отрицательные индексы массива
const arr = new Proxy([1, 2, 3], {
  get: (t, k, r) => Reflect.get(t, Number(k) < 0 ? t.length + Number(k) : k, r),
});
arr[-1]; // 3

// реактивность (упрощенно, как во Vue 3)
function reactive(obj, onChange) {
  return new Proxy(obj, {
    set(t, k, v, r) {
      const result = Reflect.set(t, k, v, r);
      onChange(k, v);
      return result;
    },
  });
}
```

## Инварианты

Proxy не может «соврать» о неконфигурируемых свойствах цели: например, ловушка `get` обязана вернуть настоящее значение readonly-неконфигурируемого свойства. Нарушение инварианта бросает `TypeError`.

## Отзываемый Proxy

```javascript
const { proxy, revoke } = Proxy.revocable(target, handler);
revoke();
proxy.x; // TypeError — доступ отозван
```

## Что важно помнить

- Внутри ловушек используйте `Reflect.*` — он корректно передает `receiver` и возвращает правильные значения.
- Proxy работает медленнее прямого доступа — не используйте его в горячем коде без необходимости.
- `proxy !== target`, а встроенные объекты с внутренними слотами (`Map`, `Date`) через Proxy без адаптации ломаются: методы требуют настоящий `this`.
- Proxy поверхностный: для вложенных объектов ловушки нужно создавать рекурсивно (так делает Vue).
- Полифилить Proxy невозможно — это причина, по которой Vue 3 не поддерживает IE.

## Мини-шпаргалка

- `new Proxy(target, handler)` — перехват операций.
- Ловушки: `get`, `set`, `has`, `deleteProperty`, `ownKeys`, `apply`, `construct`.
- Нет ловушки — операция идет к цели.
- В ловушках — `Reflect`.
- Применение: валидация, логирование, значения по умолчанию, реактивность.
