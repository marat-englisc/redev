# Способы создать объект и объектный литерал

> [!NOTE]
> Объект в JavaScript создают через объектный литерал `{}` (основной способ), `new Object()`, функцию-конструктор с `new`, класс, `Object.create(proto)`, фабричную функцию, `Object.fromEntries()` или `structuredClone`/spread от существующего объекта. Объектный литерал поддерживает сокращенные свойства, методы, вычисляемые ключи, геттеры и spread.

## Вопрос

Какие способы создания объектов существуют в JavaScript? Что такое объектный литерал и какие возможности у его синтаксиса?

## Объектный литерал

```javascript
const key = "role";

const user = {
  name: "Анна",               // обычное свойство
  age,                         // shorthand: age: age
  [key]: "admin",              // вычисляемый ключ
  "full-name": "Анна Петрова", // ключ со спецсимволами — в кавычках
  greet() {                    // сокращенный метод
    return `Привет, ${this.name}`;
  },
  get isAdult() {              // геттер
    return this.age >= 18;
  },
  ...defaults,                 // копирование свойств другого объекта
};
```

Литерал — самый короткий и быстрый способ. Каждый раз создается новый объект с прототипом `Object.prototype`.

## Другие способы

| Способ | Пример | Когда использовать |
| --- | --- | --- |
| `new Object()` | `const o = new Object()` | почти никогда, литерал короче |
| Функция-конструктор | `new User("Анна")` | legacy-код до классов |
| Класс | `new User("Анна")` | много однотипных объектов с методами |
| Фабрика | `createUser("Анна")` | без `new` и `this`, с замыканиями |
| `Object.create(proto)` | `Object.create(userProto)` | явный прототип или `null` |
| `Object.fromEntries()` | `Object.fromEntries([["a", 1]])` | из пар ключ-значение, Map |
| Копирование | `{ ...obj }`, `structuredClone(obj)` | новый объект на основе существующего |
| `JSON.parse()` | `JSON.parse('{"a":1}')` | данные из строки |

```javascript
// функция-конструктор
function Product(title, price) {
  this.title = title;
  this.price = price;
}
Product.prototype.format = function () {
  return `${this.title}: ${this.price} ₽`;
};

// класс — синтаксис поверх той же модели
class ProductClass {
  constructor(title, price) {
    this.title = title;
    this.price = price;
  }
  format() {
    return `${this.title}: ${this.price} ₽`;
  }
}

// фабрика
function createProduct(title, price) {
  return {
    title,
    price,
    format: () => `${title}: ${price} ₽`,
  };
}

// без прототипа — «чистый словарь»
const dict = Object.create(null);
```

## Что выбрать

- Простые данные — литерал.
- Много объектов с общими методами — класс (методы хранятся в прототипе один раз).
- Нужна инкапсуляция без `this` — фабрика с замыканием.
- Словарь с произвольными ключами — `Map` или `Object.create(null)`.

## Что важно помнить

- `{}` в начале строки движок может понять как блок кода: стрелочная функция, возвращающая объект, пишется `() => ({ a: 1 })`.
- Порядок ключей: сначала целочисленные по возрастанию, потом строковые в порядке добавления, затем символы.
- Ключи объекта — всегда строки или символы: `obj[1]` и `obj["1"]` — одно и то же свойство.
- Методы в фабрике создаются заново для каждого объекта, а методы класса — один раз в прототипе.

## Мини-шпаргалка

- Основной способ — литерал `{}`.
- Литерал: shorthand, методы, `[вычисляемый ключ]`, `get`/`set`, `...spread`.
- Класс — для множества однотипных объектов.
- `Object.create(proto)` — явный прототип.
- `Object.fromEntries` — из массива пар.
