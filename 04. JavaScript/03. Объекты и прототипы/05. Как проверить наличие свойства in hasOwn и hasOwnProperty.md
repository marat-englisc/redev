# Как проверить наличие свойства: in, Object.hasOwn и hasOwnProperty

> [!NOTE]
> Оператор `in` проверяет, есть ли свойство в объекте **или в его цепочке прототипов**. `Object.hasOwn(obj, key)` (и устаревший `obj.hasOwnProperty(key)`) проверяет только **собственные** свойства. Сравнение `obj.key !== undefined` ненадежно: свойство может существовать со значением `undefined`.

## Вопрос

Как проверить, есть ли свойство в объекте? Что делает оператор `in`? Чем `in` отличается от `hasOwnProperty` и `Object.hasOwn`?

## Оператор in

```javascript
const user = { name: "Анна", age: undefined };

"name" in user;      // true
"age" in user;       // true — свойство есть, хотя значение undefined
"email" in user;     // false
"toString" in user;  // true — унаследовано от Object.prototype
```

`in` работает и с массивами — проверяет **индексы**, а не значения:

```javascript
const colors = ["red", "green"];
0 in colors;          // true
"red" in colors;      // false
"length" in colors;   // true
```

## Object.hasOwn и hasOwnProperty

```javascript
Object.hasOwn(user, "name");     // true
Object.hasOwn(user, "toString"); // false — не собственное

user.hasOwnProperty("name");     // true — старый способ
```

`Object.hasOwn` (ES2022) лучше, потому что `hasOwnProperty`:

- отсутствует у объектов без прототипа: `Object.create(null).hasOwnProperty` — `undefined`;
- может быть переопределен: `{ hasOwnProperty: () => true }`.

```javascript
const dict = Object.create(null);
dict.key = 1;
dict.hasOwnProperty("key");       // TypeError
Object.hasOwn(dict, "key");       // true
```

## Сравнение с undefined

```javascript
user.age !== undefined; // false, хотя свойство age существует
user?.address?.city;    // безопасное чтение, но не проверка наличия
```

## Сравнение способов

| Способ | Собственные | Унаследованные | `undefined`-значение |
| --- | --- | --- | --- |
| `key in obj` | да | да | находит |
| `Object.hasOwn(obj, key)` | да | нет | находит |
| `obj.hasOwnProperty(key)` | да | нет | находит |
| `obj[key] !== undefined` | да | да | **не находит** |
| `Object.keys(obj).includes(key)` | только перечисляемые | нет | находит |

## Что важно помнить

- Для словарей с произвольными ключами используйте `Map` — у нее `map.has(key)` без проблем с прототипом.
- `in` бросает `TypeError`, если справа примитив: `"a" in "abc"`.
- `in` можно использовать для приватных полей класса: `#field in obj` — проверка бренда.
- В TypeScript `in` сужает union-типы: `if ("email" in user)`.

## Мини-шпаргалка

- `in` — собственные и унаследованные свойства.
- `Object.hasOwn` — только собственные, современный способ.
- `hasOwnProperty` — старый, ломается на `Object.create(null)`.
- `!== undefined` не отличает отсутствие от `undefined`.
- Для массивов `in` проверяет индексы.
