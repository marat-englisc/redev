# Object.keys, Object.values и Object.entries

> [!NOTE]
> `Object.keys(obj)` возвращает массив собственных перечисляемых строковых ключей, `Object.values(obj)` — массив их значений, `Object.entries(obj)` — массив пар `[ключ, значение]`. Обратная операция — `Object.fromEntries(entries)`. Унаследованные свойства, неперечисляемые свойства и символы не попадают в результат.

## Вопрос

Что делают `Object.keys()`, `Object.values()` и `Object.entries()`? Как с их помощью перебрать или преобразовать объект?

## Примеры

```javascript
const prices = { tea: 120, coffee: 180, cake: 250 };

Object.keys(prices);    // ["tea", "coffee", "cake"]
Object.values(prices);  // [120, 180, 250]
Object.entries(prices); // [["tea", 120], ["coffee", 180], ["cake", 250]]
```

## Перебор объекта

```javascript
for (const [item, price] of Object.entries(prices)) {
  console.log(`${item}: ${price} ₽`);
}

const total = Object.values(prices).reduce((sum, p) => sum + p, 0); // 550
const isEmpty = Object.keys(obj).length === 0;
```

## Преобразование объекта

С `Object.fromEntries` объект можно обработать методами массива:

```javascript
// увеличить все цены на 10%
const raised = Object.fromEntries(
  Object.entries(prices).map(([key, price]) => [key, Math.round(price * 1.1)]),
);

// оставить дешевле 200
const cheap = Object.fromEntries(
  Object.entries(prices).filter(([, price]) => price < 200),
);

// Map → объект и обратно
const map = new Map(Object.entries(prices));
const back = Object.fromEntries(map);

// query string → объект
Object.fromEntries(new URLSearchParams("page=2&sort=price")); // { page: "2", sort: "price" }
```

## Что попадает в результат

| Свойство | `keys`/`values`/`entries` | `for...in` | `Reflect.ownKeys` |
| --- | --- | --- | --- |
| Собственное перечисляемое | да | да | да |
| Унаследованное | нет | да | нет |
| Неперечисляемое | нет | нет | да |
| Символ | нет | нет | да |

Для символов есть `Object.getOwnPropertySymbols()`, для всех собственных ключей — `Reflect.ownKeys()`.

## Порядок ключей

1. Целочисленные ключи по возрастанию.
2. Строковые ключи в порядке добавления.

```javascript
Object.keys({ b: 1, 2: 1, a: 1, 1: 1 }); // ["1", "2", "b", "a"]
```

## С массивами и строками

```javascript
Object.keys(["a", "b"]);  // ["0", "1"] — индексы строками
Object.entries("hi");     // [["0", "h"], ["1", "i"]]
```

## Что важно помнить

- Методы возвращают **новые массивы** — изменение результата не меняет объект.
- Ключи всегда строки: `Object.keys({ 1: "a" })` → `["1"]`.
- `Object.keys(null)` бросает `TypeError`, а примитивы приводятся к объектам.
- В TypeScript `Object.keys(obj)` возвращает `string[]`, а не `(keyof T)[]` — из-за структурной типизации объект может иметь лишние ключи.
- `Object.groupBy(items, fn)` (ES2024) группирует массив в объект.

## Мини-шпаргалка

- `keys` — ключи, `values` — значения, `entries` — пары.
- Только собственные перечисляемые строковые свойства.
- `Object.fromEntries` — обратно в объект.
- `entries` + `map`/`filter` + `fromEntries` — преобразование объекта.
- Порядок: целые числа по возрастанию, потом строки по добавлению.
