# Reflect и чем он отличается от Object

> [!NOTE]
> `Reflect` — встроенный объект со статическими методами для базовых операций над объектами: `Reflect.get`, `set`, `has`, `deleteProperty`, `ownKeys`, `apply`, `construct` и другими. Набор методов совпадает с ловушками `Proxy`, поэтому внутри ловушек используют `Reflect`. В отличие от похожих методов `Object`, методы `Reflect` возвращают `boolean` вместо выброса ошибок и превращают операторы (`in`, `delete`, `new`) в функции.

## Вопрос

Что делает `Reflect`? Чем `Reflect` отличается от `Object` и зачем он нужен вместе с `Proxy`?

## Методы Reflect

| Метод | Аналог |
| --- | --- |
| `Reflect.get(obj, key, receiver)` | `obj[key]` |
| `Reflect.set(obj, key, value, receiver)` | `obj[key] = value` |
| `Reflect.has(obj, key)` | `key in obj` |
| `Reflect.deleteProperty(obj, key)` | `delete obj[key]` |
| `Reflect.ownKeys(obj)` | все собственные ключи, включая символы и неперечисляемые |
| `Reflect.defineProperty(obj, key, desc)` | `Object.defineProperty` |
| `Reflect.getPrototypeOf(obj)` | `Object.getPrototypeOf` |
| `Reflect.apply(fn, thisArg, args)` | `fn.apply(thisArg, args)` |
| `Reflect.construct(Cls, args, newTarget)` | `new Cls(...args)` |

```javascript
const user = { name: "Анна" };

Reflect.has(user, "name");            // true
Reflect.ownKeys({ a: 1, [Symbol("id")]: 2 }); // ["a", Symbol(id)]
Reflect.apply(Math.max, null, [1, 5, 3]);     // 5
Reflect.construct(Date, [2026, 0, 1]);        // Date
```

## Отличия от Object

```javascript
const frozen = Object.freeze({ a: 1 });

// Object: бросает ошибку
try {
  Object.defineProperty(frozen, "b", { value: 2 });
} catch (e) {
  console.log("TypeError");
}

// Reflect: возвращает false
Reflect.defineProperty(frozen, "b", { value: 2 }); // false
Reflect.set(frozen, "a", 5);                         // false
```

| | `Object.*` | `Reflect.*` |
| --- | --- | --- |
| Неудача | бросает `TypeError` | возвращает `false` |
| Операторы как функции | нет | `has`, `deleteProperty`, `construct` |
| Первый аргумент-примитив | часто приводит к объекту | `TypeError` |
| `receiver` для геттеров | нет | есть в `get` и `set` |
| Набор методов | общие утилиты (`keys`, `assign`, `freeze`) | ровно операции, которые перехватывает Proxy |

## Reflect в Proxy

```javascript
const target = {
  _name: "Анна",
  get name() { return this._name; },
};

const proxy = new Proxy(target, {
  get(t, key, receiver) {
    return Reflect.get(t, key, receiver); // this в геттере = proxy, а не target
  },
});

const child = Object.create(proxy);
child._name = "Мария";
child.name; // "Мария" — благодаря receiver
```

Если вместо `Reflect.get(t, key, receiver)` написать `t[key]`, геттер выполнится с `this === target` и наследование сломается.

## Что важно помнить

- `Reflect` — не конструктор: `new Reflect()` бросает `TypeError`.
- `Reflect.ownKeys` — самый полный способ получить ключи объекта.
- В обычном коде `Reflect` нужен редко; его главное место — метапрограммирование и `Proxy`.
- `Reflect.metadata` из TypeScript-декораторов — сторонний полифил `reflect-metadata`, а не часть стандарта.

## Мини-шпаргалка

- `Reflect` — функции для базовых операций над объектами.
- Методы совпадают с ловушками Proxy.
- Возвращают `boolean` вместо ошибок.
- `receiver` сохраняет правильный `this` для аксессоров.
- `Reflect.ownKeys` — все собственные ключи, включая символы.
