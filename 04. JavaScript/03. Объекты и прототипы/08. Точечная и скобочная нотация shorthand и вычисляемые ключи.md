# Точечная и скобочная нотация, сокращенная запись свойств и вычисляемые ключи

> [!NOTE]
> К свойствам обращаются через точку (`obj.name`) или квадратные скобки (`obj["name"]`, `obj[key]`). Скобки нужны, когда ключ хранится в переменной, содержит пробелы и дефисы или начинается с цифры. **Сокращенная запись** `{ x, y }` создает свойства из одноименных переменных, а **вычисляемые ключи** `{ [key]: value }` позволяют задать имя свойства выражением.

## Вопрос

Что такое скобочная нотация и когда она нужна? Что такое сокращенная запись свойств `{ x, y }` и вычисляемые ключи?

## Точка и скобки

```javascript
const user = { name: "Анна", "last-name": "Петрова", "2fa": true }; // "2fa" без кавычек — SyntaxError

user.name;            // "Анна"
user["name"];         // "Анна"
user["last-name"];    // "Петрова" — через точку нельзя
user["2fa"];          // true

const field = "name";
user[field];          // "Анна" — ключ из переменной
user.field;           // undefined — ищет свойство с именем "field"
```

| Точка | Скобки |
| --- | --- |
| ключ — валидный идентификатор | любой ключ |
| имя известно заранее | имя в переменной или вычисляется |
| короче и читаемее | нужны для символов: `obj[Symbol.iterator]` |

В скобках значение приводится к строке (кроме символов): `obj[1]` и `obj["1"]` — одно свойство, а `obj[{}]` — свойство `"[object Object]"`.

## Сокращенная запись свойств

```javascript
const name = "Анна";
const age = 25;

const user = { name, age };          // { name: "Анна", age: 25 }
const old = { name: name, age: age }; // то же самое до ES6

function createPoint(x, y) {
  return { x, y };
}
```

Сокращенная запись методов:

```javascript
const counter = {
  count: 0,
  increment() { this.count++; },   // вместо increment: function () {}
};
```

## Вычисляемые ключи

```javascript
const field = "email";
const form = { [field]: "anna@example.com" };        // { email: "..." }

const i = 1;
const obj = { [`item${i}`]: "чайник" };             // { item1: "чайник" }

const id = Symbol("id");
const entity = { [id]: 42 };

// типичный обработчик формы
function handleChange(event) {
  const { name, value } = event.target;
  setForm((prev) => ({ ...prev, [name]: value }));
}
```

## Опциональная цепочка

```javascript
user?.address?.city;       // undefined вместо TypeError
user?.["last-name"];       // скобки тоже поддерживаются
user.getAvatar?.();        // вызов, только если метод есть
```

## Что важно помнить

- Ключи объекта — строки или символы; числа превращаются в строки.
- Для произвольных ключей (id из API, ввод пользователя) безопаснее `Map`: ключ `"__proto__"` в обычном объекте ведет себя особым образом.
- Деструктуризация использует ту же идею: `const { [field]: value } = obj`.
- Линтер `dot-notation` подсказывает заменить `obj["name"]` на `obj.name`.

## Мини-шпаргалка

- `obj.key` — для обычных имен, `obj[key]` — для переменных и спецсимволов.
- `{ x, y }` = `{ x: x, y: y }`.
- `{ [expr]: value }` — вычисляемый ключ.
- `method() {}` — сокращенный метод.
- `?.` и `?.[]` — безопасный доступ.
