# Объект vs массив

> [!NOTE]
> Объект хранит пары `ключ -> значение`, а массив хранит упорядоченный список значений по индексам. Массив технически тоже объект, но со специальным поведением и свойством `length`.

## Вопрос

Чем объект отличается от массива?

## Объект

Объект удобен, когда данные описывают сущность.

```javascript
const user = {
  name: "Anna",
  age: 25,
};
```

Доступ по ключу:

```javascript
user.name; // "Anna"
```

## Массив

Массив удобен, когда данные являются списком.

```javascript
const users = ["Anna", "Max", "Kate"];
```

Доступ по индексу:

```javascript
users[0]; // "Anna"
```

## Главное отличие

| Критерий | Объект | Массив |
| --- | --- | --- |
| Назначение | сущность/словарь | список |
| Ключи | строки или Symbol | числовые индексы |
| Порядок | обычно не главный смысл | важен |
| `length` | нет автоматического | есть |
| Методы | `Object.keys` и другие | `map`, `filter`, `reduce` |

## Массив - это объект

```javascript
typeof []; // "object"
```

Но проверять массив лучше так:

```javascript
Array.isArray([]); // true
```

## Когда что использовать

Объект:

```javascript
const settings = {
  theme: "dark",
  pageSize: 20,
};
```

Массив:

```javascript
const tasks = [
  "Выучить объекты",
  "Повторить массивы",
];
```

Если порядок и количество элементов важны - массив. Если важны именованные свойства - объект.

## Что важно помнить

- Массив — объект с числовыми индексами, `length` и методами `Array.prototype`.
- Для упорядоченных однотипных данных — массив, для записи с именованными полями — объект.
- Поиск по ключу в объекте или `Map` — `O(1)`, поиск по значению в массиве — `O(n)`.
- Порядок ключей объекта не всегда совпадает с порядком добавления (целочисленные ключи идут первыми).

## Мини-шпаргалка

```javascript
const user = { name: "Anna" };
const users = ["Anna", "Max"];

user.name;
users[0];

Object.keys(user);
users.map((name) => name.toUpperCase());
```
