# Как добавить, изменить и удалить свойство объекта

> [!NOTE]
> Свойство добавляют или изменяют присваиванием: `obj.key = value` или `obj[key] = value`. Удаляют оператором `delete obj.key`. Методы — это свойства со значением-функцией, поэтому их тоже можно добавлять после создания объекта. Для иммутабельного кода вместо мутации создают новый объект: `{ ...obj, key }` и `const { key, ...rest } = obj`.

## Вопрос

Как добавить новое свойство или метод в существующий объект? Как удалить свойство и что возвращает `delete`?

## Добавление и изменение

```javascript
const user = { name: "Анна" };

user.age = 25;                 // добавить
user["full-name"] = "Анна П."; // ключ со спецсимволами
const field = "city";
user[field] = "Казань";        // динамический ключ

user.name = "Мария";           // изменить существующее
```

Если свойство уже есть — значение перезаписывается, если нет — создается новое. Объект, объявленный через `const`, можно менять: `const` запрещает только переназначение переменной.

## Методы после создания

```javascript
user.greet = function () {
  return `Привет, ${this.name}`;
};

user.greet(); // "Привет, Мария"
```

Стрелка здесь не подойдет, если нужен `this`. Чтобы добавить метод всем объектам одного типа, его кладут в прототип или класс, а не в каждый объект.

## Удаление: delete

```javascript
delete user.age;      // true
"age" in user;        // false

delete user.missing;  // true — даже если свойства не было
```

`delete`:

- удаляет только **собственные** свойства, прототип не трогает;
- возвращает `false` (или бросает `TypeError` в strict mode) для неконфигурируемых свойств: `delete Object.prototype` и свойств `Object.freeze`;
- не освобождает память напрямую — объект соберет сборщик мусора, когда на него не останется ссылок;
- не подходит для массивов: `delete arr[0]` оставляет «дырку» (см. заметку о разреженных массивах).

Присваивание `user.age = undefined` не удаляет свойство: ключ остается, `"age" in user` — `true`.

## Иммутабельный подход

```javascript
const withAge = { ...user, age: 26 };          // добавить или изменить
const { password, ...safeUser } = user;        // «удалить» без мутации
const renamed = { ...rest, fullName: user.name };
```

В React и Redux используют именно такой подход: новая ссылка сигнализирует об изменении.

## Запрет изменений

```javascript
Object.freeze(user);        // нельзя добавлять, менять и удалять
Object.seal(user);          // нельзя добавлять и удалять, менять можно
Object.preventExtensions(user); // нельзя только добавлять
```

## Что важно помнить

- Частое добавление и удаление свойств замедляет объекты в V8 (меняются «скрытые классы»); для динамических наборов ключей лучше `Map`.
- `delete` на переменной (`delete x`) не работает и в strict mode — `SyntaxError`.
- `Object.defineProperty` позволяет добавить свойство с настройками: только для чтения, неперечисляемое.
- Проверка «свойство существует» — `Object.hasOwn(obj, key)`, а не `obj.key !== undefined`.

## Мини-шпаргалка

- Добавить/изменить: `obj.key = v`, `obj[key] = v`.
- Метод — свойство-функция, для `this` — обычная функция.
- Удалить: `delete obj.key`, возвращает boolean.
- Иммутабельно: `{ ...obj, key }`, `const { key, ...rest } = obj`.
- Для динамических ключей — `Map`.
