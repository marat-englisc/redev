# call, apply и bind: явное указание this

> [!NOTE]
> `call`, `apply` и `bind` позволяют явно задать `this` для функции. `fn.call(ctx, a, b)` вызывает функцию сразу с аргументами через запятую, `fn.apply(ctx, [a, b])` — с аргументами массивом, `fn.bind(ctx, a)` не вызывает функцию, а возвращает новую с навсегда привязанным `this` и частично примененными аргументами.

## Вопрос

Что делают методы `call`, `apply` и `bind`? Чем они отличаются и когда какой использовать?

## call

```javascript
function greet(greeting, punctuation) {
  return `${greeting}, ${this.name}${punctuation}`;
}

const user = { name: "Анна" };

greet.call(user, "Привет", "!"); // "Привет, Анна!"
```

## apply

```javascript
greet.apply(user, ["Здравствуйте", "."]); // "Здравствуйте, Анна."

Math.max.apply(null, [3, 7, 1]);         // 7 — классический прием до spread
Math.max(...[3, 7, 1]);                  // современная замена
```

Запоминалка: **a**pply — **a**rray, **c**all — **c**omma.

## bind

```javascript
const boundGreet = greet.bind(user, "Привет");
boundGreet("?"); // "Привет, Анна?"

const button = document.querySelector("button");
button.addEventListener("click", counter.increment.bind(counter));
```

`bind` возвращает новую функцию:

- `this` привязан навсегда — повторный `bind` и `call` его не изменят;
- переданные аргументы фиксируются в начале (частичное применение);
- при вызове через `new` привязанный `this` игнорируется.

## Сравнение

| | `call` | `apply` | `bind` |
| --- | --- | --- | --- |
| Вызывает сразу | да | да | нет, возвращает функцию |
| Аргументы | через запятую | массивом | через запятую, частично |
| Результат | результат функции | результат функции | новая функция |
| Типичное применение | заимствование метода | передать массив аргументов | колбэки, обработчики |

## Заимствование методов

```javascript
function toArray() {
  return Array.prototype.slice.call(arguments);
}

Array.prototype.map.call("abc", (char) => char.toUpperCase()); // ["A", "B", "C"]

Object.prototype.toString.call([]); // "[object Array]"
```

## Реализация bind (частый вопрос на собеседовании)

```javascript
Function.prototype.myBind = function (context, ...boundArgs) {
  const fn = this;
  return function (...args) {
    return fn.apply(context, [...boundArgs, ...args]);
  };
};

Function.prototype.myCall = function (context = globalThis, ...args) {
  const key = Symbol("fn");
  context[key] = this;
  const result = context[key](...args);
  delete context[key];
  return result;
};
```

Упрощенная версия `myBind` не поддерживает вызов через `new` — в настоящем `bind` это учтено.

## Что важно помнить

- На стрелочные функции `call`, `apply` и `bind` не влияют: у них нет своего `this`.
- В strict mode `fn.call(null)` даст `this === null`, без strict — `globalThis`.
- `bind` в `render` React-класса создает новую функцию при каждом рендере — поэтому методы привязывали в конструкторе или писали полями-стрелками.
- Каждый вызов `bind` создает новую функцию: `removeEventListener(fn.bind(x))` не удалит обработчик, добавленный другим `bind`.

## Мини-шпаргалка

- `call(ctx, a, b)` — вызов с аргументами через запятую.
- `apply(ctx, [a, b])` — вызов с массивом.
- `bind(ctx, a)` — новая функция с привязанным `this`.
- Стрелки игнорируют все три.
- Заимствование методов — главный сценарий `call`.
