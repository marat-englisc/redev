# Параметры по умолчанию

> [!NOTE]
> Параметры по умолчанию задают значение, которое используется, если аргумент не передали или передали `undefined`.

## Вопрос

Что такое параметры по умолчанию? Как с ними работать?

## Базовый пример

```javascript
function greet(name = "гость") {
  return `Привет, ${name}`;
}

greet("Anna");    // "Привет, Anna"
greet();          // "Привет, гость"
greet(undefined); // "Привет, гость"
```

Если передать `null`, значение по умолчанию не сработает.

```javascript
greet(null); // "Привет, null"
```

## Значение может быть выражением

```javascript
function createId(prefix = "user", id = Date.now()) {
  return `${prefix}-${id}`;
}
```

Выражение вычисляется при вызове функции.

## Можно ссылаться на предыдущие параметры

```javascript
function createUser(name, displayName = name) {
  return {
    name,
    displayName,
  };
}

createUser("Anna"); // { name: "Anna", displayName: "Anna" }
```

На параметры справа ссылаться нельзя до их объявления.

## С объектом настроек

Часто параметры по умолчанию используют с деструктуризацией.

```javascript
function createButton({ text = "OK", disabled = false } = {}) {
  return {
    text,
    disabled,
  };
}

createButton(); // { text: "OK", disabled: false }
```

`= {}` нужен, чтобы вызов без аргументов не упал.

## Отличие от `||`

```javascript
function setPage(page = 1) {
  return page;
}

setPage(0); // 0
```

Параметр по умолчанию не заменяет `0`, `false` или `""`, только отсутствующее значение/`undefined`.

## Что важно помнить

- Значение по умолчанию применяется только для `undefined`, но не для `null`.
- Выражение по умолчанию вычисляется при каждом вызове: `function f(arr = [])` получает новый массив каждый раз.
- Параметр по умолчанию может использовать предыдущие параметры: `(a, b = a * 2)`.
- Параметры с default-значением не учитываются в `fn.length`.

## Мини-шпаргалка

| Вызов | `function f(x = 10)` |
| --- | --- |
| `f()` | `10` |
| `f(undefined)` | `10` |
| `f(null)` | `null` |
| `f(0)` | `0` |
| `f(false)` | `false` |
| `f("")` | `""` |
