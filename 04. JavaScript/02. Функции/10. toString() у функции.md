# `toString()` у функции

> [!NOTE]
> `fn.toString()` возвращает строковое представление функции. Для обычных функций это обычно исходный текст, а для встроенных функций - строка с `[native code]`.

## Вопрос

Что делает `toString()` у функции? Как устроен этот метод?

## Базовый пример

```javascript
function sum(a, b) {
  return a + b;
}

sum.toString();
```

Результат будет похож на:

```javascript
"function sum(a, b) {\n  return a + b;\n}"
```

## Стрелочные функции

```javascript
const double = (value) => value * 2;

double.toString(); // "(value) => value * 2"
```

## Встроенные функции

```javascript
Array.prototype.map.toString();
```

Результат обычно содержит:

```javascript
"function map() { [native code] }"
```

Это значит, что функция реализована движком, а не обычным JS-кодом.

## Зачем может быть нужно

Иногда `toString()` используют:

- для отладки;
- для логирования;
- в инструментах разработки;
- в метапрограммировании;
- в тестах или учебных целях.

В обычной бизнес-логике полагаться на текст функции не стоит.

## Почему осторожно

Строковое представление может зависеть от:

- движка JavaScript;
- минификации;
- транспиляции;
- сборщика;
- формата исходного кода.

```javascript
function isNative(fn) {
  return fn.toString().includes("[native code]");
}
```

Такой код может быть хрупким.

## `Function.prototype.toString`

Метод находится в прототипе функций:

```javascript
Function.prototype.toString.call(sum);
```

Это почти то же, что:

```javascript
sum.toString();
```

## Что важно помнить

- `fn.toString()` возвращает исходный текст функции, но после минификации он нечитаем.
- Для встроенных функций возвращается `function name() { [native code] }`.
- Полагаться на текст функции в логике нельзя: сборщики и транспиляторы его меняют.
- Исторически так проверяли «нативность» API, сейчас это ненадежно.

## Мини-шпаргалка

| Функция | Что вернет |
| --- | --- |
| обычная функция | исходный текст функции |
| стрелочная функция | текст стрелочной функции |
| метод класса | текст метода |
| встроенная функция | `[native code]` |
| bound function | зависит от движка, часто `[native code]` |
