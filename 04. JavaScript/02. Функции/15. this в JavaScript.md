# this в JavaScript: контекст вызова функции

> [!NOTE]
> `this` — ссылка на контекст, с которым вызвана функция. Для обычных функций он определяется **в момент вызова**: при вызове метода `obj.method()` — это `obj`, при простом вызове `f()` — `undefined` в strict mode (или глобальный объект без него), при `new` — новый объект, при `call`/`apply`/`bind` — переданное значение. У стрелочных функций своего `this` нет: он берется из внешней области.

## Вопрос

Что такое `this` и контекст функции? Как определяется `this` внутри метода объекта и в разных способах вызова?

## Правила определения this

| Способ вызова | `this` |
| --- | --- |
| `f()` | `undefined` в strict mode / модулях, иначе `globalThis` |
| `obj.f()` | `obj` — объект перед точкой |
| `new F()` | новый создаваемый объект |
| `f.call(ctx)`, `f.apply(ctx)` | `ctx` |
| `f.bind(ctx)()` | `ctx`, навсегда |
| Стрелочная функция | `this` внешней области |
| Обработчик `addEventListener` (обычная функция) | элемент, на котором висит обработчик |
| Метод класса, вызванный отдельно | `undefined` (классы всегда в strict mode) |

Приоритет: `new` > `bind` > `call`/`apply` > вызов как метод > простой вызов.

## this внутри метода объекта

```javascript
const user = {
  name: "Анна",
  greet() {
    return `Привет, ${this.name}`;
  },
};

user.greet();            // "Привет, Анна" — this = user

const greet = user.greet;
greet();                 // TypeError или undefined — this потерян
```

`this` определяется не местом объявления метода, а тем, **как** его вызвали. Один и тот же метод может работать с разными объектами:

```javascript
const admin = { name: "Мария", greet: user.greet };
admin.greet(); // "Привет, Мария"
```

## Вложенные функции

```javascript
const team = {
  name: "Frontend",
  members: ["Анна", "Иван"],
  print() {
    this.members.forEach(function (member) {
      console.log(this.name, member); // this — undefined: обычная функция-колбэк
    });

    this.members.forEach((member) => {
      console.log(this.name, member); // "Frontend" — стрелка берет this из print
    });
  },
};
```

## this в классах

```javascript
class Counter {
  count = 0;
  increment() {
    this.count++;
  }
}

const counter = new Counter();
const button = document.querySelector("button");

button.addEventListener("click", counter.increment);        // this = button, ошибка логики
button.addEventListener("click", () => counter.increment()); // OK
button.addEventListener("click", counter.increment.bind(counter)); // OK
```

## Что важно помнить

- `this` — не «текущая функция» и не «область видимости», а значение, которое передается при вызове.
- Передача метода как колбэка (`setTimeout(obj.method)`) теряет контекст — подробно в заметке о потере контекста.
- В модулях и классах strict mode включен всегда, поэтому потерянный `this` — `undefined`, а не `window`.
- В React функциональные компоненты не используют `this`; в классовых — методы привязывали через `bind` или поля-стрелки.

## Мини-шпаргалка

- `this` определяется способом вызова.
- `obj.method()` → `this === obj`.
- Простой вызов → `undefined` (strict).
- `new` → новый объект, `call/apply/bind` → явный контекст.
- Стрелка — `this` снаружи.
