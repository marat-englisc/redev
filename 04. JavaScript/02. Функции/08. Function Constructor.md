# Function Constructor

> [!NOTE]
> `new Function()` создает функцию из строк во время выполнения. Это редко нужно и похоже на `eval`: хуже для безопасности, оптимизации и поддержки.

## Вопрос

Как работает Function Constructor (`new Function`)?

## Синтаксис

```javascript
const fn = new Function("a", "b", "return a + b");

fn(2, 3); // 5
```

Последняя строка - тело функции, предыдущие строки - имена параметров.

```javascript
new Function(arg1, arg2, ..., body);
```

## Функция создается во время выполнения

```javascript
const operation = "return value * 2";
const double = new Function("value", operation);

double(5); // 10
```

Это динамическое создание кода.

## Важное отличие от обычной функции

Функция, созданная через `new Function`, не замыкает локальную область видимости.

```javascript
function createFn() {
  const secret = 10;

  return new Function("return secret");
}

const fn = createFn();

fn(); // ReferenceError
```

Такая функция видит глобальную область, но не локальные переменные места создания.

## Почему используют редко

Проблемы похожи на `eval`:

- можно выполнить вредоносный код;
- сложно оптимизировать;
- сложнее отлаживать;
- код в строке не проверяется нормально линтерами и TypeScript;
- ухудшается читаемость.

## Что использовать вместо

Словарь функций:

```javascript
const operations = {
  double: (value) => value * 2,
  square: (value) => value ** 2,
};

operations[name]?.(10);
```

Для пользовательских формул лучше взять специализированный парсер.

## Что важно помнить

- `new Function("a", "b", "return a + b")` создает функцию из строки — это разновидность `eval`.
- Такая функция видит только глобальную область видимости, а не локальные переменные места создания.
- Строгая CSP блокирует `new Function`.
- Используется в шаблонизаторах и сериализаторах, но в обычном коде не нужен.

## Мини-шпаргалка

| Особенность | `new Function` |
| --- | --- |
| Создает функцию из строк | да |
| Выполняется в runtime | да |
| Замыкает локальные переменные | нет |
| Похож на `eval` | да |
| Рекомендуется в обычном коде | нет |
