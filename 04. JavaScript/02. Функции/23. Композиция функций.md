# Композиция функций

> [!NOTE]
> Композиция функций - это объединение нескольких функций в одну цепочку, где результат одной функции становится входом для следующей.

## Вопрос

Что такое композиция функций?

## Основная идея

Если есть две функции:

```javascript
const trim = (value) => value.trim();
const toLowerCase = (value) => value.toLowerCase();
```

их можно применить последовательно:

```javascript
const result = toLowerCase(trim("  HELLO  "));

console.log(result); // "hello"
```

Это и есть композиция: одна функция подготавливает значение для другой.

## `compose`

`compose` обычно применяет функции справа налево.

```javascript
const compose = (...fns) => {
  return (value) => fns.reduceRight((result, fn) => fn(result), value);
};

const normalize = compose(toLowerCase, trim);

normalize("  HELLO  "); // "hello"
```

Математически это похоже на:

```text
compose(f, g)(x) = f(g(x))
```

## `pipe`

`pipe` применяет функции слева направо.

```javascript
const pipe = (...fns) => {
  return (value) => fns.reduce((result, fn) => fn(result), value);
};

const normalize = pipe(trim, toLowerCase);

normalize("  HELLO  "); // "hello"
```

`pipe` часто читается проще: данные идут слева направо.

## Практический пример

```javascript
const removeSpaces = (value) => value.trim();
const normalizeCase = (value) => value.toLowerCase();
const addPrefix = (value) => `user:${value}`;

const normalizeUserId = pipe(removeSpaces, normalizeCase, addPrefix);

normalizeUserId("  ADMIN  "); // "user:admin"
```

## Зачем это нужно

- разбивать сложную обработку на маленькие функции;
- переиспользовать шаги;
- лучше тестировать каждый шаг;
- писать декларативный код;
- уменьшать вложенность вызовов.

## Подводные камни

Композиция удобна, когда функции принимают и возвращают совместимые значения.

```javascript
const getLength = (value) => value.length;
const toLowerCase = (value) => value.toLowerCase();

pipe(getLength, toLowerCase)("hello"); // TypeError
```

`getLength` возвращает число, а `toLowerCase` ожидает строку.

## Что важно помнить

- `compose(f, g)(x)` = `f(g(x))` — справа налево, `pipe(f, g)(x)` = `g(f(x))` — слева направо.
- Композиция работает лучше всего с чистыми функциями одного аргумента.
- В JavaScript есть предложение оператора `|>` (pipeline), но пока он не стандартизирован.
- Middleware в Redux и Express — тоже вид композиции функций.

## Мини-шпаргалка

| Прием | Порядок |
| --- | --- |
| `compose(f, g)(x)` | справа налево: `f(g(x))` |
| `pipe(f, g)(x)` | слева направо: `g(f(x))` |
| маленькие функции | легче комбинировать |
| чистые функции | лучше подходят для композиции |
