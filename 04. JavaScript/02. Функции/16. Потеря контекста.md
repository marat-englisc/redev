# Потеря контекста

> [!NOTE]
> Потеря контекста происходит, когда метод объекта передают или сохраняют как обычную функцию. Тогда вызов идет уже не через объект, и `this` перестает указывать на исходный объект.

## Вопрос

Как избежать потери контекста?

## Пример проблемы

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};

const fn = user.sayHi;

fn(); // this потерян
```

Метод был вызван как `fn()`, а не как `user.sayHi()`.

## Способ 1. `bind`

```javascript
const fn = user.sayHi.bind(user);

fn(); // "Hi, Anna"
```

`bind` возвращает новую функцию с закрепленным `this`.

## Способ 2. Обертка

```javascript
const fn = () => user.sayHi();

fn(); // "Hi, Anna"
```

Стрелочная функция вызывает метод через объект, поэтому контекст сохраняется.

## Способ 3. `call` или `apply`

```javascript
const fn = user.sayHi;

fn.call(user); // "Hi, Anna"
```

Этот способ подходит, если вызвать функцию нужно сразу.

## В обработчиках

```javascript
button.addEventListener("click", user.sayHi);
```

Так `this` внутри `sayHi` не будет `user`.

Варианты:

```javascript
button.addEventListener("click", user.sayHi.bind(user));
button.addEventListener("click", () => user.sayHi());
```

## В классах

```javascript
class Counter {
  constructor() {
    this.count = 0;
    this.increment = this.increment.bind(this);
  }

  increment() {
    this.count++;
  }
}
```

Так метод можно безопасно передавать как callback.

## Что важно помнить

- Контекст теряется, когда метод передается как значение: `setTimeout(obj.method)`, `arr.map(obj.method)`, деструктуризация метода.
- Решения: стрелочная обертка, `bind`, стрелочные поля класса.
- В strict mode и классах потерянный `this` — `undefined`, поэтому ошибка видна сразу.
- Методы встроенных объектов тоже теряют контекст: `const log = console.log` обычно работает, но `const push = arr.push; push(1)` — нет.

## Мини-шпаргалка

| Способ | Когда использовать |
| --- | --- |
| `method.bind(obj)` | нужно получить функцию на будущее |
| `method.call(obj)` | нужно вызвать сразу |
| `method.apply(obj, args)` | вызвать сразу с массивом аргументов |
| `() => obj.method()` | простая обертка |
| class field arrow | частый паттерн в классах |
