# Rest-параметры и arguments

> [!NOTE]
> **Rest-параметр** (`...args`) собирает оставшиеся аргументы функции в настоящий массив. `arguments` — устаревший псевдомассив со всеми аргументами: у него есть `length` и индексы, но нет методов массива, и его нет в стрелочных функциях. В современном коде используют rest, а `arguments` превращают в массив через `Array.from` или spread, если он встретился в legacy-коде.

## Вопрос

Что такое rest-параметры? Что такое `arguments`, чем он отличается от rest и как получить из него массив?

## Rest-параметры

```javascript
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

sum(1, 2, 3); // 6
sum();        // 0 — пустой массив, а не undefined

function log(level, ...messages) {
  console[level](...messages);
}
log("warn", "Мало места", "на диске");
```

Правила:

- rest может быть только **последним** параметром;
- он один на функцию;
- не учитывается в `fn.length`.

## arguments

```javascript
function oldSum() {
  console.log(arguments.length); // 3
  console.log(arguments[0]);     // 1
  arguments.map;                 // undefined — это не массив
}
oldSum(1, 2, 3);
```

| | `...rest` | `arguments` |
| --- | --- | --- |
| Тип | настоящий `Array` | псевдомассив (`Arguments`) |
| Методы массива | есть | нет |
| Что содержит | только «оставшиеся» аргументы | все аргументы |
| В стрелочных функциях | работает | нет своего (берется внешний) |
| Явность | видно в сигнатуре | скрыт |

В нестрогом режиме `arguments` еще и связан с параметрами: изменение `arguments[0]` меняет `a` — источник неожиданностей.

## Как получить массив из arguments

```javascript
function toArray() {
  const a = Array.from(arguments);
  const b = [...arguments];
  const c = Array.prototype.slice.call(arguments); // старый способ до ES6
  return a;
}
```

## Rest в деструктуризации

```javascript
const [first, ...others] = [1, 2, 3];   // others = [2, 3]
const { id, ...data } = { id: 1, name: "Анна", age: 25 }; // data без id
```

## Rest и spread

```javascript
function max(...nums) {          // rest — собирает
  return Math.max(...nums);      // spread — раскладывает
}
```

## Что важно помнить

- Rest-параметр всегда массив, поэтому проверка `if (args.length === 0)` надежна.
- Для функций с переменным числом аргументов в TypeScript пишут `(...items: string[])`.
- `arguments` мешает оптимизациям движка и запрещен в некоторых линтерах (`prefer-rest-params`).
- Параметры по умолчанию и rest можно сочетать: `function f(a = 1, ...rest) {}`.

## Мини-шпаргалка

- `...args` — массив оставшихся аргументов, последним параметром.
- `arguments` — псевдомассив всех аргументов, нет в стрелках.
- Массив из `arguments`: `Array.from(arguments)` или `[...arguments]`.
- Rest собирает, spread раскладывает.
