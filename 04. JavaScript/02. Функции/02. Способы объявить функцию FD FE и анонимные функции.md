# Способы объявить функцию: Function Declaration, Function Expression и анонимные функции

> [!NOTE]
> Функцию можно объявить через **Function Declaration** (`function f() {}`), **Function Expression** (`const f = function () {}`), стрелочную функцию, метод объекта или класса, генератор и конструктор `new Function`. FD всплывает целиком и доступна до объявления, FE создается только когда выполнение доходит до строки. **Анонимная функция** — функция без имени, обычно колбэк или FE.

## Вопрос

Какие способы объявления функций существуют? Чем Function Declaration отличается от Function Expression? Что такое анонимные функции?

## Все способы

```javascript
function declaration(a, b) { return a + b; }        // Function Declaration
const expression = function (a, b) { return a + b; }; // Function Expression (анонимная)
const named = function sum(a, b) { return a + b; };  // Named Function Expression
const arrow = (a, b) => a + b;                       // стрелочная

const obj = {
  method() {},                                        // метод
  async load() {},                                    // асинхронный метод
  *items() {},                                        // генератор
};

class Service {
  run() {}                                            // метод класса
}

function* generator() {}                              // генератор
async function fetchData() {}                         // async-функция
const dynamic = new Function("a", "b", "return a + b"); // конструктор — избегать
```

## Function Declaration и Function Expression

| | Function Declaration | Function Expression |
| --- | --- | --- |
| Синтаксис | `function f() {}` как отдельная инструкция | функция — часть выражения |
| Hoisting | доступна во всей области до объявления | только после строки присваивания |
| Имя | обязательно | необязательно |
| В блоке (strict mode) | видна в пределах блока | как обычная переменная |
| Когда удобна | основные функции модуля | колбэки, условное создание, IIFE |

```javascript
greet();            // работает — FD всплыла
function greet() {}

hello();            // ReferenceError (const в TDZ)
const hello = function () {};
```

## Анонимные функции

```javascript
setTimeout(function () {
  console.log("Через секунду");
}, 1000);

[1, 2, 3].map((n) => n * 2);
```

Анонимные функции используют, когда функция нужна один раз. Современные движки выводят имя из переменной (`const f = function () {}` → `f.name === "f"`), но у колбэков имени нет — в стеке ошибки будет `<anonymous>`.

## Named Function Expression

```javascript
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1); // fact видно только внутри функции
};
```

Имя NFE видно только внутри самой функции — это надежный способ рекурсии, даже если внешнюю переменную переназначат. Имя также появляется в стеке вызовов.

## Что выбрать

- Основные функции модуля — Function Declaration: читаемо, всплывают, имя в стеке.
- Колбэки — стрелки.
- Функции, создаваемые условно или передаваемые как значение, — FE.
- Методы — сокращенный синтаксис в объектах и классах.
- `new Function` — почти никогда: это аналог `eval`, блокируется CSP.

## Что важно помнить

- Функции — объекты первого класса: их можно передавать, возвращать, хранить в переменных и добавлять им свойства.
- У каждой функции есть `name` и `length` (количество параметров до первого с default-значением или rest).
- `export default function () {}` — допустимая анонимная Function Declaration.
- В нестрогом режиме FD внутри `if` ведет себя по-разному в разных движках — пишите в strict mode или используйте FE.

## Мини-шпаргалка

- FD: `function f() {}` — всплывает.
- FE: `const f = function () {}` — после строки присваивания.
- Стрелки — для колбэков.
- Анонимная — без имени, обычно колбэк.
- NFE — имя видно только внутри, удобно для рекурсии.
