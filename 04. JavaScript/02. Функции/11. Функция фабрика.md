# Функция-фабрика

> [!NOTE]
> Функция-фабрика - это функция, которая создает и возвращает другие значения, чаще всего объекты или функции с заранее настроенным поведением.

## Вопрос

Что такое функция-фабрика?

## Фабрика объектов

```javascript
function createUser(name, role = "user") {
  return {
    name,
    role,
    isAdmin() {
      return role === "admin";
    },
  };
}

const user = createUser("Anna");
const admin = createUser("Max", "admin");
```

Фабрика позволяет создавать похожие объекты без `new`.

## Фабрика функций

```javascript
function multiplyBy(multiplier) {
  return function (value) {
    return value * multiplier;
  };
}

const double = multiplyBy(2);
const triple = multiplyBy(3);

double(10); // 20
triple(10); // 30
```

Здесь используется замыкание: возвращенная функция помнит `multiplier`.

## Зачем нужны фабрики

- создавать похожие объекты;
- настраивать поведение через параметры;
- прятать внутреннее состояние;
- избегать ручного дублирования;
- обходиться без классов, когда они не нужны.

## Инкапсуляция состояния

```javascript
function createCounter() {
  let count = 0;

  return {
    increment() {
      count++;
      return count;
    },
    getValue() {
      return count;
    },
  };
}
```

`count` нельзя изменить напрямую снаружи.

## Что важно помнить

- Фабрика возвращает новый объект без `new` и `this` — нет проблем с потерей контекста.
- Приватность достигается замыканием, а не `#полями`.
- Методы фабрики создаются для каждого объекта заново — больше памяти, чем у методов прототипа.
- Фабрики удобны для конфигурации зависимостей (`createApiClient({ baseUrl })`) и тестирования.

## Мини-шпаргалка

```javascript
function createThing(options) {
  return {
    ...options,
    createdAt: Date.now(),
  };
}
```

| Фабрика | Возвращает |
| --- | --- |
| `createUser()` | объект |
| `multiplyBy(2)` | функцию |
| `createCounter()` | объект с замкнутым состоянием |
