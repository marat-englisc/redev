# Генераторы и yield

> [!NOTE]
> **Генератор** — функция `function*`, выполнение которой можно приостанавливать. Вызов генератора не выполняет тело, а возвращает объект-итератор. Каждый `next()` выполняет код до очередного `yield` и возвращает `{ value, done }`. `return` завершает генератор и задает `value` последнего шага с `done: true`. `yield` нельзя использовать внутри стрелочных функций — стрелка не может быть генератором.

## Вопрос

Что такое генераторы? Как работает `yield`, что возвращает генератор и можно ли использовать `yield` внутри стрелочных функций?

## Базовый пример

```javascript
function* steps() {
  console.log("старт");
  yield 1;
  yield 2;
  return 3;
}

const it = steps(); // ничего не выведено — тело еще не выполнялось

it.next(); // "старт", { value: 1, done: false }
it.next(); // { value: 2, done: false }
it.next(); // { value: 3, done: true }
it.next(); // { value: undefined, done: true }
```

## Что возвращает генератор

Вызов `steps()` возвращает **объект-генератор**, который одновременно является итератором и итерируемым объектом. Поэтому его можно перебирать:

```javascript
for (const value of steps()) {
  console.log(value); // 1, 2 — значение из return в for...of НЕ попадает
}

[...steps()];       // [1, 2]
Array.from(steps()); // [1, 2]
```

`return` используется для финального значения, которое видно только через `next()`.

## Передача значений внутрь

`yield` — выражение: значение, переданное в следующий `next(value)`, становится его результатом.

```javascript
function* dialog() {
  const name = yield "Как вас зовут?";
  const age = yield `Привет, ${name}! Сколько вам лет?`;
  return `${name}, ${age}`;
}

const d = dialog();
d.next().value;          // "Как вас зовут?"
d.next("Анна").value;    // "Привет, Анна! Сколько вам лет?"
d.next(25).value;        // "Анна, 25"
```

Аргумент первого `next()` игнорируется: генератор еще не дошел до `yield`.

## yield* и управление

```javascript
function* inner() { yield "a"; yield "b"; }
function* outer() {
  yield 1;
  yield* inner();   // делегирование другому итерируемому
  yield 2;
}
[...outer()]; // [1, "a", "b", 2]

const it = outer();
it.return("стоп");  // досрочное завершение: { value: "стоп", done: true }
it.throw(new Error("сбой")); // бросить ошибку в точку yield
```

## Где применяются

```javascript
// бесконечная последовательность — значения вычисляются лениво
function* idGenerator() {
  let id = 1;
  while (true) yield id++;
}
const ids = idGenerator();
ids.next().value; // 1

// итератор для своей структуры данных
class Range {
  constructor(from, to) { this.from = from; this.to = to; }
  *[Symbol.iterator]() {
    for (let i = this.from; i <= this.to; i++) yield i;
  }
}
[...new Range(1, 4)]; // [1, 2, 3, 4]

// постраничная загрузка
async function* fetchPages(url) {
  let next = url;
  while (next) {
    const res = await fetch(next).then((r) => r.json());
    yield res.items;
    next = res.nextPage;
  }
}
for await (const items of fetchPages("/api/products")) render(items);
```

Генераторы также лежат в основе redux-saga, а исторически — в библиотеке `co`, которая предшествовала `async/await`.

## yield в стрелочных функциях

```javascript
const gen = *() => {};       // SyntaxError: стрелка не может быть генератором

function* parent() {
  [1, 2].forEach((n) => {
    yield n;                 // SyntaxError: yield внутри обычного колбэка запрещен
  });
  for (const n of [1, 2]) yield n; // правильно
}
```

`yield` работает только непосредственно в теле функции-генератора, не во вложенных функциях.

## Что важно помнить

- Генераторы ленивые: значения вычисляются только по запросу, поэтому подходят для больших и бесконечных последовательностей.
- Генератор одноразовый: после `done: true` его нельзя перезапустить — нужно вызвать функцию заново.
- `break` в `for...of` вызывает `return()` у генератора, и выполняются блоки `finally`.
- Iterator helpers (ES2025: `.map()`, `.filter()`, `.take()` у итераторов) хорошо сочетаются с генераторами.

## Мини-шпаргалка

- `function*` → вызов возвращает итератор, тело не выполняется.
- `next()` → `{ value, done }`, выполнение до следующего `yield`.
- `return` — финальное значение с `done: true`, в `for...of` не попадает.
- `next(x)` передает `x` как результат `yield`.
- Стрелка не бывает генератором, `yield` в колбэке — `SyntaxError`.
