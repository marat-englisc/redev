# Функция высшего порядка

> [!NOTE]
> Функция высшего порядка принимает другую функцию как аргумент или возвращает функцию как результат.

## Вопрос

Что такое функция высшего порядка?

## Почему это возможно

В JavaScript функции - значения первого класса. Их можно:

- хранить в переменных;
- передавать в другие функции;
- возвращать из функций;
- хранить в объектах и массивах.

```javascript
const fn = () => "hello";
```

## Функция принимает функцию

```javascript
function repeat(times, action) {
  for (let i = 0; i < times; i++) {
    action(i);
  }
}

repeat(3, (index) => {
  console.log(index);
});
```

`repeat` - функция высшего порядка, потому что принимает `action`.

## Функция возвращает функцию

```javascript
function multiplyBy(multiplier) {
  return function (value) {
    return value * multiplier;
  };
}

const double = multiplyBy(2);

double(10); // 20
```

`multiplyBy` - функция высшего порядка, потому что возвращает функцию.

## Методы массивов

Многие методы массивов - функции высшего порядка.

```javascript
numbers.map((number) => number * 2);
numbers.filter((number) => number > 0);
numbers.reduce((sum, number) => sum + number, 0);
```

Они принимают callback.

## Декораторы

```javascript
function withLog(fn) {
  return function (...args) {
    console.log(args);
    return fn(...args);
  };
}
```

Декоратор принимает функцию и возвращает новую функцию.

## Что важно помнить

- Функция высшего порядка принимает или возвращает функцию: `map`, `filter`, `debounce`, HOC в React.
- Это возможно, потому что функции в JS — значения первого класса.
- Чрезмерная вложенность функций усложняет отладку — давайте функциям имена.
- Композиция и каррирование строятся на функциях высшего порядка.

## Мини-шпаргалка

| Случай | Пример |
| --- | --- |
| принимает функцию | `array.map(callback)` |
| возвращает функцию | `multiplyBy(2)` |
| делает обертку | `withLog(fn)` |
| создает настроенную функцию | `createValidator(options)` |
