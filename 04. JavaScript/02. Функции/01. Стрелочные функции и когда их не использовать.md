# Стрелочные функции против обычных и когда стрелки не использовать

> [!NOTE]
> Стрелочная функция — короткий синтаксис функции без собственного `this`, `arguments`, `super` и `new.target`: она берет их из внешней области видимости (лексически). Стрелку нельзя вызвать с `new`, у нее нет `prototype`. Поэтому стрелки идеальны для колбэков, но не подходят для методов объекта, обработчиков, которым нужен `this` элемента, конструкторов и функций, где нужен `arguments`.

## Вопрос

Чем стрелочные функции отличаются от обычных? Когда лучше не использовать стрелочные функции?

## Синтаксис

```javascript
const add = (a, b) => a + b;            // неявный return
const square = (x) => x * x;
const log = () => console.log("hi");
const toUser = (name) => ({ name });    // объект — в круглых скобках
const sum = (...nums) => {
  const total = nums.reduce((s, n) => s + n, 0);
  return total;                          // в фигурных скобках return обязателен
};
```

## Главные отличия

| | Обычная функция | Стрелочная функция |
| --- | --- | --- |
| `this` | зависит от способа вызова | берется из внешней области |
| `arguments` | есть | нет (используйте `...rest`) |
| Вызов с `new` | можно (если не метод класса) | `TypeError` |
| `prototype` | есть | нет |
| `call`/`apply`/`bind` меняют `this` | да | нет |
| Hoisting | Function Declaration всплывает | ведет себя как переменная |
| Может быть генератором | да | нет |

## this в стрелке

```javascript
const timer = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++; // this = timer, взят из метода start
    }, 1000);
  },
};
```

До стрелок писали `const self = this` или `.bind(this)`.

## Когда стрелки не использовать

**1. Метод объекта, которому нужен `this`:**

```javascript
const counter = {
  count: 0,
  increment: () => {
    this.count++; // this — не counter, а внешний this (undefined в модуле)
  },
};
```

Правильно: `increment() { this.count++; }`.

**2. Обработчик события, которому нужен элемент через `this`:**

```javascript
button.addEventListener("click", function () {
  this.classList.toggle("active"); // this = button
});
// со стрелкой используйте event.currentTarget
```

**3. Конструктор:**

```javascript
const User = (name) => { this.name = name; };
new User("Анна"); // TypeError: User is not a constructor
```

**4. Методы прототипа и динамический `this`** (например, методы, которые подключаются к разным объектам через `call`).

**5. Когда нужен `arguments`** — используйте rest-параметры.

**6. Рекурсивные или долгие функции**, где имя в стеке помогает отладке — стрелка, присвоенная переменной, тоже получает имя, но Function Declaration нагляднее и всплывает.

## Стрелки в классах

```javascript
class Form {
  value = "";
  handleChange = (event) => {   // поле-стрелка: this привязан к экземпляру
    this.value = event.target.value;
  };
}
```

Удобно для колбэков, но такая функция создается для каждого экземпляра и не лежит в прототипе.

## Что важно помнить

- Стрелка не «привязывает» `this` — у нее его просто нет, поэтому `bind` на нее не действует.
- `() => {}` возвращает `undefined`, а `() => ({})` — пустой объект.
- В React функциональные компоненты и колбэки обычно пишут стрелками, а `this` не нужен вовсе.
- Стрелочную функцию нельзя использовать как генератор, но можно как `async`.

## Мини-шпаргалка

- Стрелка: нет своего `this`, `arguments`, `prototype`, нельзя `new`.
- `this` — лексический, из внешней функции.
- Отлично для колбэков, `map`, `setTimeout`, промисов.
- Не для методов объекта, конструкторов и обработчиков с `this`.
- Объект из стрелки: `() => ({ ... })`.
