# Чистые функции и побочные эффекты

> [!NOTE]
> **Чистая функция** при одних и тех же аргументах всегда возвращает один и тот же результат и не имеет **побочных эффектов**. Побочный эффект — любое влияние на внешний мир: изменение аргументов или внешних переменных, запросы в сеть, работа с DOM, `localStorage`, логирование, таймеры, `Math.random()` и `Date.now()`. Чистые функции легко тестировать, кешировать и переиспользовать.

## Вопрос

Что такое чистая функция? Что такое побочные эффекты и как организовать код, где эффекты неизбежны?

## Чистая функция

```javascript
function calculateTotal(items, discount) {
  const sum = items.reduce((total, item) => total + item.price * item.qty, 0);
  return sum * (1 - discount);
}
```

- результат зависит только от аргументов;
- аргументы не изменяются;
- нет обращений к внешнему миру.

## Нечистые функции

```javascript
let total = 0;
function addToTotal(price) {
  total += price;            // меняет внешнюю переменную
}

function addItem(cart, item) {
  cart.push(item);           // мутирует аргумент
  return cart;
}

function createOrder(items) {
  return { id: Math.random(), createdAt: Date.now(), items }; // недетерминированный результат
}

function saveUser(user) {
  localStorage.setItem("user", JSON.stringify(user)); // эффект
  console.log("saved");                               // тоже эффект
}
```

## Виды побочных эффектов

| Эффект | Пример |
| --- | --- |
| Мутация аргументов и внешнего состояния | `arr.push()`, `obj.x = 1`, изменение глобальной переменной |
| Ввод-вывод | `fetch`, чтение файла, `console.log` |
| DOM и браузерные API | `document.title = ...`, `localStorage` |
| Время и случайность | `Date.now()`, `Math.random()` |
| Асинхронность | `setTimeout`, подписки |
| Исключения | `throw` тоже влияет на поток выполнения |

## Как сделать функцию чистой

```javascript
// вместо мутации — новый массив
const addItem = (cart, item) => [...cart, item];

// время и случайность — через аргументы
const createOrder = (items, id, createdAt) => ({ id, createdAt, items });
createOrder(items, crypto.randomUUID(), Date.now());
```

## Чистое ядро, эффекты на краях

Эффекты нужны любой программе. Хорошая архитектура держит **бизнес-логику чистой**, а эффекты собирает в отдельном слое:

```javascript
// чистая логика
function applyPromo(cart, promo) {
  if (cart.total < promo.minTotal) return cart;
  return { ...cart, total: cart.total - promo.amount };
}

// эффекты — снаружи
async function onApplyPromo(code) {
  const promo = await api.getPromo(code);   // эффект
  const next = applyPromo(cart, promo);     // чисто
  renderCart(next);                         // эффект
}
```

## Где это важно

- **React**: компоненты и функции рендера должны быть чистыми — Strict Mode специально вызывает их дважды, чтобы выявить побочные эффекты; эффекты живут в `useEffect` и обработчиках.
- **Redux**: редьюсеры обязаны быть чистыми.
- **Тесты**: чистую функцию проверяют без моков.
- **Мемоизация**: кешировать можно только чистую функцию.

## Что важно помнить

- Логирование формально — эффект, но на практике его допускают в «почти чистых» функциях.
- Чистота важна на уровне контракта: функция может внутри создать и мутировать локальный массив — снаружи это не видно.
- Ссылочная прозрачность: вызов чистой функции можно заменить ее результатом без изменения поведения программы.
- `Array.prototype.sort` мутирует массив — в чистом коде используйте `toSorted`.

## Мини-шпаргалка

- Чистая функция: одинаковый вход → одинаковый выход, без эффектов.
- Эффекты: мутации, сеть, DOM, storage, время, случайность, логи.
- Время и случайность передавайте аргументами.
- Чистое ядро, эффекты на краях.
- React-рендер и Redux-редьюсеры должны быть чистыми.
