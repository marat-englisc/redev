# join() и split()

> [!NOTE]
> `array.join(separator)` склеивает элементы массива в строку через разделитель (по умолчанию запятая). `string.split(separator, limit)` — обратная операция: разбивает строку на массив подстрок по разделителю или регулярному выражению. Вместе они позволяют преобразовывать текст: `str.split(" ").map(...).join(" ")`.

## Вопрос

Что делает метод массива `join()`? Что делает метод строки `split()` и как их сочетать?

## join

```javascript
const words = ["Привет", "мир"];

words.join(" ");    // "Привет мир"
words.join();       // "Привет,мир" — по умолчанию запятая
words.join("");     // "Приветмир"
[1, 2, 3].join(" + "); // "1 + 2 + 3"
```

Особые значения:

```javascript
[1, null, undefined, 2].join("-"); // "1---2" — null и undefined как пустые строки
[[1, 2], [3]].join(";");           // "1,2;3" — вложенные массивы через toString
[{ a: 1 }].join();                 // "[object Object]"
[].join();                         // ""
```

## split

```javascript
"a,b,c".split(",");          // ["a", "b", "c"]
"Привет мир".split(" ");     // ["Привет", "мир"]
"abc".split("");             // ["a", "b", "c"]
"a,b,c".split(",", 2);       // ["a", "b"] — лимит
"2026-01-15".split("-").map(Number); // [2026, 1, 15]
"  много   пробелов ".trim().split(/\s+/); // ["много", "пробелов"]
"нет".split(",");            // ["нет"] — разделитель не найден
"".split(",");               // [""] — массив с пустой строкой
```

С группой в регулярном выражении разделители попадают в результат:

```javascript
"1+2-3".split(/([+-])/); // ["1", "+", "2", "-", "3"]
```

## Комбинации

```javascript
// развернуть строку
"привет".split("").reverse().join("");  // "тевирп"

// slug из заголовка
"Новая Статья О CSS".toLowerCase().split(" ").join("-"); // "новая-статья-о-css"

// каждое слово с заглавной буквы
const capitalize = (s) => s.split(" ").map((w) => w[0].toUpperCase() + w.slice(1)).join(" ");

// CSV-строка в массив объектов (упрощенно)
const [header, ...rows] = csv.trim().split("\n");
const keys = header.split(",");
const data = rows.map((row) => Object.fromEntries(row.split(",").map((v, i) => [keys[i], v])));
```

## Что важно помнить

- `split("")` делит по UTF-16 кодовым единицам: emoji и составные символы разобьются неправильно. Используйте `[...str]` или `Intl.Segmenter`.
- Для замены всех вхождений раньше писали `str.split(a).join(b)` — теперь есть `replaceAll`.
- `join` не фильтрует пустые значения — при необходимости сначала `filter(Boolean)`.
- Для CSV с кавычками и запятыми внутри значений `split` не подходит — нужен парсер.

## Мини-шпаргалка

- `arr.join(sep)` — массив → строка, по умолчанию `,`.
- `str.split(sep, limit)` — строка → массив.
- `null`/`undefined` в `join` — пустые строки.
- `split` принимает регулярные выражения.
- Emoji — через `[...str]`, а не `split("")`.
