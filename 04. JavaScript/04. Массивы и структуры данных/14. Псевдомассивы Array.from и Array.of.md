# Псевдомассивы, Array.from и Array.of

> [!NOTE]
> **Псевдомассив** (array-like) — объект с числовыми индексами и свойством `length`, но без методов массива: `arguments`, `NodeList`, `HTMLCollection`, строки, `{ 0: "a", length: 1 }`. `Array.from(source, mapFn)` превращает псевдомассив или итерируемый объект в настоящий массив и может сразу преобразовать элементы. `Array.of(...items)` создает массив из аргументов, без ловушки `new Array(3)`.

## Вопрос

Что такое псевдомассив? Что делают `Array.from()` и `Array.of()` и чем они отличаются от `new Array()`?

## Псевдомассивы

```javascript
const arrayLike = { 0: "a", 1: "b", length: 2 };

arrayLike[0];          // "a"
arrayLike.length;      // 2
arrayLike.map;         // undefined — нет методов массива
Array.isArray(arrayLike); // false
```

Где встречаются:

| Объект | Итерируемый | Методы |
| --- | --- | --- |
| `arguments` | да | нет |
| `NodeList` (`querySelectorAll`) | да | есть `forEach` |
| `HTMLCollection` (`children`, `getElementsByClassName`) | да | нет, «живая» коллекция |
| строка | да | строковые методы |
| `{ 0: ..., length }` | нет | нет |

## Array.from

```javascript
Array.from(arrayLike);                       // ["a", "b"]
Array.from("привет");                        // ["п", "р", "и", "в", "е", "т"]
Array.from(new Set([1, 1, 2]));              // [1, 2]
Array.from(new Map([["a", 1]]));             // [["a", 1]]
Array.from(document.querySelectorAll("li")); // массив элементов

// второй аргумент — map-функция
Array.from({ length: 5 }, (_, i) => i * 2);  // [0, 2, 4, 6, 8]
Array.from("123", Number);                   // [1, 2, 3]
```

`Array.from` работает и с итерируемыми объектами, и с псевдомассивами без `Symbol.iterator`. Spread (`[...x]`) — только с итерируемыми:

```javascript
[...arrayLike]; // TypeError: arrayLike is not iterable
```

## Array.of

```javascript
Array.of(3);        // [3]
Array.of(1, 2, 3);  // [1, 2, 3]

new Array(3);       // [ <3 empty items> ] — один числовой аргумент = длина
new Array(1, 2);    // [1, 2]
new Array("3");     // ["3"]
```

`Array.of` убирает неоднозначность конструктора `Array`: аргументы всегда становятся элементами.

## Сравнение

| | `Array.from` | `Array.of` | `new Array` | `[...x]` |
| --- | --- | --- | --- | --- |
| Из псевдомассива | да | нет | нет | нет |
| Из итерируемого | да | нет | нет | да |
| Map-функция | да | нет | нет | нет |
| Из аргументов | нет | да | да, кроме одного числа | нет |

## Что важно помнить

- `HTMLCollection` «живая»: удаление элементов в цикле по ней пропускает элементы — сначала преобразуйте в массив.
- `Array.from({ length: n })` — надежный способ создать плотный массив нужной длины.
- `Array.from` поддерживает `thisArg` третьим аргументом.
- Для асинхронных итераторов есть `Array.fromAsync()`.
- В TypeScript `ArrayLike<T>` — тип псевдомассива.

## Мини-шпаргалка

- Псевдомассив — индексы + `length`, без методов массива.
- `Array.from(x, mapFn)` — из псевдомассива или итерируемого.
- `[...x]` — только из итерируемого.
- `Array.of(3)` → `[3]`, `new Array(3)` → три пустых слота.
- `Array.from({ length: n }, fn)` — заполненный массив.
