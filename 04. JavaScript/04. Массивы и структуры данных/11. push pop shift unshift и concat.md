# push, pop, shift, unshift и concat

> [!NOTE]
> `push` добавляет элементы в конец, `pop` удаляет последний, `unshift` добавляет в начало, `shift` удаляет первый. Все четыре **мутируют** массив: `push` и `unshift` возвращают новую длину, `pop` и `shift` — удаленный элемент. `concat` не мутирует: он возвращает новый массив, объединенный с аргументами. Операции с концом — `O(1)`, с началом — `O(n)`.

## Вопрос

Что делают `push()`, `pop()`, `shift()` и `unshift()`? Что они возвращают? Чем `push()` отличается от `concat()`?

## Конец массива: push и pop

```javascript
const stack = ["a", "b"];

stack.push("c");        // 3 — новая длина, stack = ["a", "b", "c"]
stack.push("d", "e");   // 5 — можно несколько
stack.pop();            // "e" — удаленный элемент
[].pop();               // undefined
```

## Начало массива: unshift и shift

```javascript
const queue = ["b", "c"];

queue.unshift("a");     // 3, queue = ["a", "b", "c"]
queue.shift();          // "a", queue = ["b", "c"]
```

`shift` и `unshift` сдвигают индексы всех элементов, поэтому на больших массивах они медленные (`O(n)`).

## Сводная таблица

| Метод | Где | Мутирует | Возвращает | Сложность |
| --- | --- | --- | --- | --- |
| `push(...items)` | конец | да | новую длину | `O(1)` |
| `pop()` | конец | да | удаленный элемент | `O(1)` |
| `unshift(...items)` | начало | да | новую длину | `O(n)` |
| `shift()` | начало | да | удаленный элемент | `O(n)` |
| `concat(...values)` | конец | нет | новый массив | `O(n)` |

## push и concat

```javascript
const a = [1, 2];

a.push([3, 4]);     // 3, a = [1, 2, [3, 4]] — массив добавлен как элемент
a.push(...[5, 6]);  // a = [1, 2, [3, 4], 5, 6] — spread раскладывает

const b = [1, 2];
const c = b.concat([3, 4], 5); // [1, 2, 3, 4, 5] — массивы «раскрываются» на один уровень
b;                             // [1, 2] — не изменился
```

| | `push` | `concat` |
| --- | --- | --- |
| Мутирует | да | нет |
| Возвращает | длину | новый массив |
| Массив-аргумент | добавляется целиком | раскладывается на элементы |
| Для React state | нет | да (или `[...arr, x]`) |

## Стек и очередь

```javascript
// стек (LIFO)
stack.push(item);
stack.pop();

// очередь (FIFO)
queue.push(item);
queue.shift(); // O(n) — для больших очередей используйте индекс головы или связный список
```

## Иммутабельные аналоги

```javascript
const added = [...items, newItem];          // вместо push
const prepended = [newItem, ...items];      // вместо unshift
const withoutLast = items.slice(0, -1);     // вместо pop
const withoutFirst = items.slice(1);        // вместо shift
```

## Что важно помнить

- `const arr = []` не мешает `push` — меняется содержимое, а не ссылка.
- Частая ошибка: `const next = arr.push(x)` — в `next` будет число, а не массив.
- `push(...hugeArray)` с сотнями тысяч элементов может превысить лимит аргументов — используйте цикл или `concat`.
- `concat` раскрывает только массивы (и объекты с `Symbol.isConcatSpreadable`), вложенные массивы не разворачиваются.

## Мини-шпаргалка

- `push`/`pop` — конец, `unshift`/`shift` — начало.
- `push`/`unshift` → длина, `pop`/`shift` → элемент.
- Все четыре мутируют.
- `concat` — новый массив, раскрывает массивы-аргументы.
- `shift`/`unshift` — `O(n)`.
