# Set и WeakSet

> [!NOTE]
> `Set` — коллекция **уникальных** значений любого типа с быстрыми `add`, `has` и `delete` (в среднем `O(1)`). Уникальность определяется алгоритмом SameValueZero: `NaN` равен `NaN`, объекты сравниваются по ссылке. `WeakSet` хранит только объекты (и незарегистрированные символы), держит их **слабо** — не мешает сборщику мусора — и не поддерживает перебор и `size`.

## Вопрос

Что такое `Set` и для чего его используют? Что такое `WeakSet` и чем он отличается от `Set`?

## Set

```javascript
const tags = new Set(["js", "css", "js"]);

tags.size;          // 2 — дубликат отброшен
tags.add("html");   // возвращает сам Set, можно цепочкой
tags.has("css");    // true
tags.delete("css"); // true
tags.clear();

for (const tag of new Set(["a", "b"])) console.log(tag); // порядок вставки сохраняется
```

## Типичные задачи

```javascript
// удаление дубликатов
const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]

// быстрая проверка вхождения вместо includes в цикле
const allowed = new Set(["admin", "editor"]);
users.filter((u) => allowed.has(u.role)); // O(n) вместо O(n·m)

// посещенные узлы при обходе графа
const visited = new Set();

// выбранные элементы в UI
const selectedIds = new Set();
```

## Операции над множествами (ES2025)

```javascript
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

a.union(b);               // Set {1, 2, 3, 4}
a.intersection(b);        // Set {2, 3}
a.difference(b);          // Set {1}
a.symmetricDifference(b); // Set {1, 4}
a.isSubsetOf(b);          // false
```

В старых окружениях: `new Set([...a].filter((x) => b.has(x)))`.

## Уникальность

```javascript
new Set([NaN, NaN]).size;     // 1
new Set([0, -0]).size;        // 1
new Set([{}, {}]).size;       // 2 — разные ссылки
new Set(["1", 1]).size;       // 2 — разные типы
```

## WeakSet

```javascript
const processed = new WeakSet();

function processOnce(node) {
  if (processed.has(node)) return;
  processed.add(node);
  // ...
}
```

Когда DOM-узел удален и на него больше нет ссылок, он исчезнет и из `WeakSet` — утечки памяти не будет.

| | `Set` | `WeakSet` |
| --- | --- | --- |
| Значения | любые | только объекты и незарегистрированные символы |
| Ссылки | сильные | слабые |
| `size`, перебор, `clear` | есть | нет |
| Методы | `add`, `has`, `delete`, `forEach`, итераторы | `add`, `has`, `delete` |
| Применение | уникальные значения, множества | пометки объектов без утечек |

Перебора у `WeakSet` нет, потому что содержимое может исчезнуть в любой момент по решению сборщика мусора.

## Что важно помнить

- `Set` не сериализуется в JSON напрямую: `JSON.stringify(new Set([1]))` → `"{}"`; преобразуйте в массив.
- В React state `Set` мутабелен: для обновления создавайте новый `new Set(prev).add(x)`.
- `has` у `Set` — `O(1)`, `includes` у массива — `O(n)`.
- `WeakSet` подходит для «брендирования» объектов и защиты от повторной обработки.

## Мини-шпаргалка

- `Set` — уникальные значения, порядок вставки.
- `add`, `has`, `delete`, `size`, `for...of`.
- Дедупликация: `[...new Set(arr)]`.
- `WeakSet` — только объекты, слабые ссылки, без перебора.
- ES2025: `union`, `intersection`, `difference`.
