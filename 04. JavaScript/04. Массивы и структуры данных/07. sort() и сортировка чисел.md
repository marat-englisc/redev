# sort() и сортировка чисел

> [!NOTE]
> `sort()` сортирует массив **на месте** (мутирует его) и возвращает ссылку на тот же массив. Без функции сравнения элементы приводятся к строкам и сравниваются посимвольно, поэтому `[10, 2, 1].sort()` дает `[1, 10, 2]`. Для чисел нужен компаратор `(a, b) => a - b`. Сортировка стабильна (с ES2019). Для иммутабельной версии используют `toSorted()`.

## Вопрос

Как работает метод `sort()`? Почему числа сортируются неправильно и как правильно отсортировать массив чисел, строк и объектов?

## Проблема сортировки по умолчанию

```javascript
[10, 2, 1, 25].sort(); // [1, 10, 2, 25] — сравнение строк "10" < "2"
["б", "а", "Б"].sort(); // ["Б", "а", "б"] — по кодам символов
```

## Функция сравнения

```javascript
const numbers = [10, 2, 1, 25];

numbers.sort((a, b) => a - b); // [1, 2, 10, 25] — по возрастанию
numbers.sort((a, b) => b - a); // [25, 10, 2, 1] — по убыванию
```

Компаратор возвращает:

| Результат | Порядок |
| --- | --- |
| `< 0` | `a` перед `b` |
| `> 0` | `b` перед `a` |
| `0` | порядок не меняется |

`a - b` работает только для чисел. Для `NaN` и `Infinity - Infinity` результат `NaN` нарушает контракт.

## Строки

```javascript
const names = ["Яна", "анна", "Борис", "ёжик"];

names.sort((a, b) => a.localeCompare(b, "ru"));
// ["анна", "Борис", "ёжик", "Яна"] — правильный алфавит с учетом регистра и ё

const collator = new Intl.Collator("ru", { numeric: true, sensitivity: "base" });
["файл10", "файл2"].sort(collator.compare); // ["файл2", "файл10"]
```

## Объекты

```javascript
const products = [
  { title: "Чайник", price: 1500 },
  { title: "Кружка", price: 300 },
  { title: "Ваза", price: 1500 },
];

products.sort((a, b) => a.price - b.price || a.title.localeCompare(b.title));
// по цене, а при равной цене — по названию
```

## Мутация и toSorted

```javascript
const original = [3, 1, 2];
const sorted = original.sort((a, b) => a - b);

sorted === original; // true — тот же массив, original изменен

const safe = original.toSorted((a, b) => b - a); // новый массив (ES2023)
const copy = [...original].sort((a, b) => a - b); // старый способ
```

В React state и props сортируйте через `toSorted` или копию.

## Стабильность

С ES2019 `sort` стабилен: элементы с равным ключом сохраняют исходный порядок. Это важно для многоуровневой сортировки таблиц.

## Что важно помнить

- `undefined` всегда уходят в конец, а «дырки» разреженного массива — после них; компаратор для них не вызывается.
- Компаратор должен быть последовательным: случайный `() => Math.random() - 0.5` не дает равномерного перемешивания — используйте алгоритм Фишера — Йетса.
- Сложность сортировки в V8 (TimSort) — `O(n log n)`.
- Возвращайте из компаратора число, а не boolean: `(a, b) => a > b` сортирует неправильно.

## Мини-шпаргалка

- `sort()` мутирует и возвращает тот же массив.
- По умолчанию — строковое сравнение.
- Числа: `(a, b) => a - b`, по убыванию — `b - a`.
- Строки: `localeCompare` или `Intl.Collator`.
- Без мутации — `toSorted()`.
