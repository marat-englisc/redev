# some() и every()

> [!NOTE]
> `some(callback)` возвращает `true`, если **хотя бы один** элемент удовлетворяет условию. `every(callback)` возвращает `true`, если условию удовлетворяют **все** элементы. Оба метода останавливаются, как только результат известен, и не изменяют массив. На пустом массиве `some` возвращает `false`, а `every` — `true`.

## Вопрос

Что делают методы `some()` и `every()`? Чем они отличаются и как ведут себя на пустом массиве?

## some

```javascript
const cart = [
  { title: "Чайник", inStock: true },
  { title: "Кружка", inStock: false },
];

cart.some((item) => !item.inStock);   // true — есть товар не в наличии
[1, 3, 5].some((n) => n % 2 === 0);   // false
```

Перебор прекращается на первом `true`.

## every

```javascript
cart.every((item) => item.inStock);   // false
[2, 4, 6].every((n) => n % 2 === 0);  // true

const isFormValid = fields.every((field) => field.value.trim() !== "");
```

Перебор прекращается на первом `false`.

## Пустой массив

```javascript
[].some(() => true);   // false — нет ни одного подходящего
[].every(() => false); // true — нет ни одного неподходящего (vacuous truth)
```

Это логично математически, но может удивить: `[].every(isValid)` — `true`, поэтому для форм без полей добавляйте проверку длины.

## Сравнение с похожими методами

| Метод | Возвращает | Останавливается |
| --- | --- | --- |
| `some` | `true`/`false` — есть ли подходящий | на первом совпадении |
| `every` | `true`/`false` — все ли подходят | на первом несовпадении |
| `find` | первый подходящий элемент или `undefined` | на первом совпадении |
| `findIndex` | индекс или `-1` | на первом совпадении |
| `includes` | есть ли конкретное значение (`SameValueZero`) | на первом совпадении |
| `filter` | массив всех подходящих | не останавливается |

```javascript
users.some((u) => u.role === "admin"); // есть ли админ
users.find((u) => u.role === "admin"); // сам админ
[NaN].includes(NaN);                   // true
[NaN].some(Number.isNaN);              // true
```

## Связь между методами

```javascript
arr.every(fn) === !arr.some((x) => !fn(x)); // закон де Моргана
```

## Что важно помнить

- Колбэк получает `(element, index, array)`.
- Пропуски в разреженных массивах не обрабатываются.
- `some` и `every` — способ «прервать» перебор, который нельзя сделать в `forEach`.
- Для проверки наличия значения примитива удобнее `includes`, для объектов — `some`.

## Мини-шпаргалка

- `some` — хотя бы один, `every` — все.
- Оба останавливаются досрочно.
- `[].some()` → `false`, `[].every()` → `true`.
- Нужен сам элемент — `find`, только факт — `some`.
