# Двумерные массивы: создание, обход и flat

> [!NOTE]
> **Двумерный массив** — массив массивов: `matrix[row][col]`. Используется для таблиц, игровых полей, сеток и матриц. Обходят его вложенными циклами или `forEach`/`map`. Из многомерного массива делают плоский через `flat(depth)` (`flat(Infinity)` — полностью), а `flatMap` сочетает `map` и `flat(1)`.

## Вопрос

Что такое двумерный массив? Как создать и обойти двумерный массив? Как получить плоский массив из многомерного?

## Создание

```javascript
const board = [
  ["X", "O", "X"],
  ["O", "X", "O"],
  ["", "", "X"],
];

board[1][2]; // "O" — строка 1, колонка 2

// матрица rows × cols, заполненная нулями
const grid = Array.from({ length: 3 }, () => Array(4).fill(0));
```

Ловушка:

```javascript
const wrong = Array(3).fill(Array(3).fill(0));
wrong[0][0] = 1;
// все строки изменились — fill положил одну и ту же ссылку на внутренний массив
```

## Обход

```javascript
// вложенные for — когда нужны индексы и ранний выход
for (let row = 0; row < board.length; row++) {
  for (let col = 0; col < board[row].length; col++) {
    console.log(row, col, board[row][col]);
  }
}

// for...of
for (const row of board) {
  for (const cell of row) console.log(cell);
}

// методы массивов
const upper = board.map((row) => row.map((cell) => cell.toLowerCase()));
const total = grid.reduce((sum, row) => sum + row.reduce((s, n) => s + n, 0), 0);

// транспонирование: строки ↔ колонки
const transposed = board[0].map((_, col) => board.map((row) => row[col]));
```

Обход по соседям — типичная задача на собеседовании (поиск островов, игра «Жизнь»):

```javascript
const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]];
const inBounds = (r, c) => r >= 0 && r < grid.length && c >= 0 && c < grid[0].length;
```

## Плоский массив из многомерного

```javascript
const nested = [1, [2, 3], [4, [5, [6]]]];

nested.flat();          // [1, 2, 3, 4, [5, [6]]] — глубина 1 по умолчанию
nested.flat(2);         // [1, 2, 3, 4, 5, [6]]
nested.flat(Infinity);  // [1, 2, 3, 4, 5, 6]

[[1, 2], [3]].flatMap((row) => row.map((n) => n * 10)); // [10, 20, 30]

// своя реализация (частый вопрос)
function flatten(arr) {
  return arr.reduce(
    (acc, item) => acc.concat(Array.isArray(item) ? flatten(item) : item),
    [],
  );
}
```

`flat` убирает дырки разреженного массива.

## Что важно помнить

- Сложность обхода матрицы — `O(rows × cols)`.
- Копия двумерного массива через `[...matrix]` поверхностная — строки общие; копируйте `matrix.map((row) => [...row])` или `structuredClone`.
- Строки могут быть разной длины («рваный» массив) — проверяйте `row.length`, а не длину первой строки.
- Для больших числовых матриц эффективнее одномерный typed array с индексом `row * cols + col`.

## Мини-шпаргалка

- Двумерный массив — массив массивов, доступ `m[row][col]`.
- Создание: `Array.from({ length: n }, () => Array(m).fill(0))`.
- Не используйте `fill` с массивом — одна ссылка на все строки.
- Обход — вложенные циклы или `map`.
- Плоский: `flat(depth)`, `flat(Infinity)`, `flatMap`.
