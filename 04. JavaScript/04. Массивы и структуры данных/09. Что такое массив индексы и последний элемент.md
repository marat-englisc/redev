# Что такое массив: индексы, длина, разные типы и последний элемент

> [!NOTE]
> Массив в JavaScript — упорядоченная коллекция значений, специальный вид объекта с числовыми индексами (с 0) и автоматическим свойством `length`. В одном массиве можно хранить значения разных типов. Обращение к несуществующему индексу возвращает `undefined` без ошибки. Последний элемент получают через `arr.at(-1)` или `arr[arr.length - 1]`.

## Вопрос

Что такое массив в JavaScript? Как работают индексы, что будет при обращении к несуществующему индексу, можно ли хранить разные типы и как получить последний элемент?

## Создание и доступ

```javascript
const fruits = ["яблоко", "груша", "слива"];

fruits[0];        // "яблоко" — индексы с нуля
fruits.length;    // 3
fruits[1] = "банан"; // изменить элемент
fruits.push("киви"); // добавить в конец
```

Способы создать массив: литерал `[]` (основной), `Array.of(1, 2)`, `Array.from(iterable)`, `new Array(3)` (пустой массив длины 3 — «дырки»).

## Массив — это объект

```javascript
typeof [];            // "object"
Array.isArray([]);    // true
Object.keys(["a", "b"]); // ["0", "1"] — индексы хранятся как строковые ключи
```

Поэтому `arr["0"]` и `arr[0]` — одно и то же, а нечисловые свойства (`arr.extra = 1`) тоже можно добавить, хотя не стоит.

## Разные типы в одном массиве

```javascript
const mixed = [1, "текст", true, null, { id: 1 }, [1, 2], () => {}];
```

Это разрешено, но на практике массивы обычно однородны: так их проще обрабатывать, а движок V8 оптимизирует массивы одного типа (packed SMI, double, elements). В TypeScript разнотипный массив описывают кортежем или union-типом.

## Несуществующий индекс

```javascript
const arr = [10, 20];

arr[5];      // undefined — без ошибки
arr[-1];     // undefined — отрицательные индексы через [] не работают
arr.at(-1);  // 20

arr[5] = 60; // массив растянется: [10, 20, <3 empty items>, 60], length 6
```

## Последний элемент

```javascript
const list = ["a", "b", "c"];

list.at(-1);              // "c" — ES2022, читается лучше всего
list[list.length - 1];    // "c" — классический способ
list.slice(-1)[0];        // "c" — создает лишний массив
list.findLast((x) => x);  // поиск с конца по условию
list.pop();               // "c", но удаляет элемент!
```

На пустом массиве все способы дают `undefined` (кроме `pop`, который тоже вернет `undefined`).

## Основные операции

| Задача | Метод |
| --- | --- |
| Добавить в конец / начало | `push` / `unshift` |
| Удалить с конца / начала | `pop` / `shift` |
| Найти элемент | `find`, `findIndex`, `includes`, `indexOf` |
| Преобразовать | `map`, `filter`, `reduce`, `flatMap` |
| Скопировать часть | `slice` |
| Изменить середину | `splice` / `toSpliced` |
| Перебрать | `for...of`, `forEach` |

## Что важно помнить

- Максимальная длина — `2^32 - 1`; индексы — целые числа от 0.
- `const` не делает массив неизменяемым: `push` работает.
- Сравнение `[1] === [1]` — `false`: массивы сравниваются по ссылке.
- `arr.at()` принимает отрицательные индексы, `arr[]` — нет.
- Строки тоже поддерживают индексы и `at()`: `"текст".at(-1)` → `"т"`.

## Мини-шпаргалка

- Массив — объект с индексами с 0 и `length`.
- Можно смешивать типы, но лучше однородные массивы.
- Несуществующий индекс → `undefined`.
- Последний элемент — `arr.at(-1)`.
- Проверка — `Array.isArray`.
