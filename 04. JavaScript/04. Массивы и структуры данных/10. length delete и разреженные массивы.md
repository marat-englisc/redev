# length, delete и разреженные массивы

> [!NOTE]
> `length` массива — не счетчик элементов, а «максимальный индекс + 1». Его можно менять вручную: уменьшение обрезает массив, увеличение добавляет пустые слоты. `delete arr[i]` удаляет значение, но не сдвигает элементы и не меняет `length` — остается «дырка». Массив с дырками называют **разреженным**, без них — **плотным**. Для удаления элементов используют `splice`, `toSpliced` или `filter`.

## Вопрос

Что будет, если изменить `length` массива вручную? Что делает `delete arr[0]` и чем `delete` отличается от `splice`? Что такое плотный и разреженный массив?

## Изменение length

```javascript
const arr = [1, 2, 3, 4, 5];

arr.length = 3;   // [1, 2, 3] — элементы 4 и 5 удалены безвозвратно
arr.length = 0;   // [] — быстрый способ очистить массив (по той же ссылке)
arr.length = 3;   // [ <3 empty items> ] — пустые слоты, а не undefined
```

`length` всегда на единицу больше максимального индекса:

```javascript
const a = [];
a[9] = "x";
a.length; // 10
```

## delete arr[i]

```javascript
const colors = ["red", "green", "blue"];
delete colors[1];

colors;          // ["red", <1 empty item>, "blue"]
colors.length;   // 3 — длина не изменилась
colors[1];       // undefined
1 in colors;     // false — слота нет
```

## delete и splice

| | `delete arr[i]` | `arr.splice(i, 1)` |
| --- | --- | --- |
| Удаляет значение | да | да |
| Сдвигает элементы | нет | да |
| Меняет `length` | нет | да |
| Результат | дырка | плотный массив |
| Возвращает | `true` | массив удаленных элементов |

```javascript
const items = ["a", "b", "c"];
items.splice(1, 1);                 // ["b"], items = ["a", "c"]
const without = items.filter((_, i) => i !== 0); // без мутации
```

## Плотные и разреженные массивы

```javascript
const dense = [1, 2, 3];          // плотный
const sparse = [1, , 3];          // разреженный: слот 1 отсутствует
const empty = new Array(3);       // три пустых слота
const filled = Array.from({ length: 3 }, (_, i) => i); // [0, 1, 2] — плотный
```

Методы по-разному обрабатывают дырки:

| Метод | Дырки |
| --- | --- |
| `forEach`, `map`, `filter`, `some`, `reduce` | пропускают |
| `for...of`, spread, `Array.from` | дают `undefined` |
| `join`, `toString` | как пустую строку |
| `toSorted`, `toReversed`, `with`, `at` | превращают в `undefined` |
| `Object.keys` | не включают |

```javascript
new Array(3).map(() => 0);        // [ <3 empty items> ] — map не вызвал колбэк
Array.from({ length: 3 }, () => 0); // [0, 0, 0]
new Array(3).fill(0);             // [0, 0, 0]
```

## Почему разреженные массивы плохи

- поведение методов непоследовательно;
- движок V8 переводит такие массивы в медленный режим хранения (dictionary elements);
- легко получить неожиданный `length`.

## Что важно помнить

- `arr.length = 0` очищает массив для всех, кто держит ссылку; `arr = []` создает новый массив.
- Создавая массив заданной длины, сразу заполняйте его: `Array.from({ length: n }, fn)` или `new Array(n).fill(v)`.
- `fill` с объектом заполняет **одной и той же ссылкой**: `new Array(3).fill({})` — три ссылки на один объект.
- В TypeScript `length` у кортежей — литеральный тип (`2`, `3`).

## Мини-шпаргалка

- `length` = максимальный индекс + 1, можно менять.
- Уменьшение `length` удаляет элементы, `length = 0` очищает.
- `delete arr[i]` оставляет дырку, длина та же.
- Удалять — `splice`/`toSpliced`/`filter`.
- Разреженные массивы — источник багов и медленнее.
