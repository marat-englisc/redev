# Иммутабельные методы массивов: toSorted, toReversed, toSpliced, with и reverse

> [!NOTE]
> ES2023 добавил копирующие версии мутирующих методов: `toSorted()` вместо `sort()`, `toReversed()` вместо `reverse()`, `toSpliced()` вместо `splice()` и `with(index, value)` вместо `arr[index] = value`. Они возвращают новый массив и не меняют исходный. `reverse()` переворачивает массив на месте и возвращает ссылку на него же.

## Вопрос

Что делают `toReversed()`, `toSorted()`, `toSpliced()` и `with()`? Чем они отличаются от `reverse()`, `sort()` и `splice()`?

## Пары методов

| Мутирующий | Иммутабельный | Что делает |
| --- | --- | --- |
| `reverse()` | `toReversed()` | обратный порядок |
| `sort(fn)` | `toSorted(fn)` | сортировка |
| `splice(start, count, ...items)` | `toSpliced(start, count, ...items)` | удалить / вставить |
| `arr[i] = value` | `with(i, value)` | заменить элемент |

## reverse и toReversed

```javascript
const steps = [1, 2, 3];

const reversed = steps.reverse();
reversed === steps; // true — исходный массив перевернут: [3, 2, 1]

const original = [1, 2, 3];
const copy = original.toReversed(); // [3, 2, 1]
original;                            // [1, 2, 3]
```

## toSorted

```javascript
const prices = [500, 100, 300];
const ascending = prices.toSorted((a, b) => a - b); // [100, 300, 500]
prices; // [500, 100, 300]
```

## toSpliced

```javascript
const todos = ["купить", "позвонить", "написать"];

todos.toSpliced(1, 1);                // ["купить", "написать"] — удалить
todos.toSpliced(1, 0, "прочитать");   // вставить на позицию 1
todos.toSpliced(-1, 1, "отправить");  // заменить последний
```

В отличие от `splice`, возвращает **новый массив**, а не удаленные элементы.

## with

```javascript
const scores = [10, 20, 30];
scores.with(1, 25);   // [10, 25, 30]
scores.with(-1, 99);  // [10, 20, 99] — отрицательный индекс с конца
scores.with(5, 1);    // RangeError — индекс вне массива
```

## Зачем это нужно

```javascript
// React: обновление state без мутации
setItems((prev) => prev.with(index, { ...prev[index], done: true }));
setItems((prev) => prev.toSpliced(index, 1));
setSorted(items.toSorted(byPrice));
```

До ES2023 то же самое писали через копию: `[...arr].reverse()`, `arr.slice().sort()`, `arr.map((x, i) => (i === index ? value : x))`.

## Особенности

- «Дырки» разреженного массива превращаются в `undefined` — результат всегда плотный.
- Методы работают и с массивоподобными объектами через `Array.prototype.toSorted.call(obj)`.
- Есть аналоги у typed arrays: `Uint8Array.prototype.toSorted`.
- Метод `toSpliced` не возвращает удаленные элементы — если они нужны, используйте `slice`.

## Что важно помнить

- Иммутабельные методы создают копию — в горячих циклах с огромными массивами это дополнительные аллокации.
- Поддерживаются всеми современными браузерами с 2023 года; для старых — полифил core-js.
- В TypeScript нужна библиотека `lib: ["ES2023"]` или новее.
- `reverse()` на строке не работает: `[...str].reverse().join("")` или `str.split("").toReversed().join("")`.

## Мини-шпаргалка

- `reverse`, `sort`, `splice` мутируют.
- `toReversed`, `toSorted`, `toSpliced`, `with` возвращают новый массив.
- `toSpliced` возвращает результат, а не удаленные элементы.
- `with(i, v)` — замена по индексу, поддерживает отрицательные индексы.
- Удобно для иммутабельного state в React.
