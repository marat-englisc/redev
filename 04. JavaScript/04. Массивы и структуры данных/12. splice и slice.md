# splice() и slice()

> [!NOTE]
> `splice(start, deleteCount, ...items)` **изменяет** массив: удаляет `deleteCount` элементов с позиции `start`, вставляет новые и возвращает массив удаленных. `slice(start, end)` **не изменяет** массив: возвращает копию части от `start` до `end` (не включая). Запоминалка: «splice» — сращивать, режет по живому; «slice» — отрезать ломтик для себя.

## Вопрос

Что делает метод `splice()`? Чем `splice()` отличается от `slice()`?

## splice

```javascript
const months = ["янв", "фев", "апр", "май"];

months.splice(2, 0, "мар");   // [] — ничего не удалено, вставлен "мар"
// months = ["янв", "фев", "мар", "апр", "май"]

months.splice(3, 1);          // ["апр"] — удален один элемент
// months = ["янв", "фев", "мар", "май"]

months.splice(1, 2, "ФЕВ");   // ["фев", "мар"] — удалено два, вставлен один
// months = ["янв", "ФЕВ", "май"]

months.splice(-1);            // ["май"] — от последнего до конца
months.splice(1);             // всё начиная с индекса 1
```

Аргументы:

- `start` — с какого индекса (отрицательный — с конца);
- `deleteCount` — сколько удалить (если не указан — до конца);
- `...items` — что вставить на это место.

## slice

```javascript
const letters = ["a", "b", "c", "d", "e"];

letters.slice(1, 3);   // ["b", "c"] — end не включается
letters.slice(2);      // ["c", "d", "e"]
letters.slice(-2);     // ["d", "e"]
letters.slice();       // полная поверхностная копия
letters;               // не изменился
```

`slice` есть и у строк: `"привет".slice(0, 3)` → `"при"`.

## Сравнение

| | `splice` | `slice` |
| --- | --- | --- |
| Мутирует исходный массив | да | нет |
| Возвращает | удаленные элементы | новый массив-фрагмент |
| Второй аргумент | количество удаляемых | индекс конца (не включая) |
| Может вставлять | да | нет |
| Есть у строк | нет | да |
| Иммутабельная альтернатива | `toSpliced` | — |

## Типичные задачи

```javascript
// удалить элемент по индексу
items.splice(index, 1);                      // мутация
const next = items.toSpliced(index, 1);      // без мутации
const next2 = items.filter((_, i) => i !== index);

// вставить элемент
items.splice(index, 0, newItem);
const inserted = [...items.slice(0, index), newItem, ...items.slice(index)];

// заменить элемент
items.splice(index, 1, updated);
const replaced = items.with(index, updated);

// пагинация
const page = items.slice((pageNumber - 1) * size, pageNumber * size);
```

## Что важно помнить

- `splice` возвращает удаленные элементы, а не измененный массив — частая ошибка при `const result = arr.splice(...)`.
- Удаление в цикле через `splice` сдвигает индексы — идите с конца или используйте `filter`.
- `splice` на середине большого массива — `O(n)`.
- `slice` делает поверхностную копию: объекты внутри общие.

## Мини-шпаргалка

- `splice(start, count, ...items)` — режет и вставляет, мутирует, возвращает удаленное.
- `slice(start, end)` — копия фрагмента, не мутирует, `end` не включается.
- Отрицательные индексы — с конца.
- Без мутации вместо `splice` — `toSpliced`, `filter`, `with`.
