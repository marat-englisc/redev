# then, catch, finally и цепочка промисов

> [!NOTE]
> `then(onFulfilled, onRejected)` подписывается на результат промиса, `catch(onRejected)` — на ошибку, `finally(onFinally)` — на завершение в любом случае. Каждый из них возвращает **новый промис**, поэтому вызовы выстраиваются в цепочку: значение, возвращенное из обработчика, передается в следующий `then`, возвращенный промис ожидается, а брошенная ошибка переходит к ближайшему `catch`.

## Вопрос

Что делают `then`, `catch` и `finally`? Как работает цепочка промисов и как в ней передаются значения и ошибки?

## Обработчики

```javascript
fetch("/api/user")
  .then((response) => response.json())   // успех
  .catch((error) => showError(error))     // ошибка на любом шаге выше
  .finally(() => hideSpinner());          // всегда
```

| Метод | Когда вызывается | Аргумент | Что передает дальше |
| --- | --- | --- | --- |
| `then(fn)` | при `fulfilled` | значение | результат `fn` |
| `then(ok, fail)` | при `fulfilled` или `rejected` | значение или ошибка | результат вызванного обработчика |
| `catch(fn)` | при `rejected` | ошибка | результат `fn` (цепочка «восстанавливается») |
| `finally(fn)` | всегда | нет аргументов | исходное значение или ошибку |

## Как работает цепочка

```javascript
Promise.resolve(1)
  .then((x) => x + 1)                      // 2
  .then((x) => new Promise((r) => setTimeout(() => r(x * 10), 100))) // ждет 100 мс → 20
  .then((x) => {
    throw new Error(`плохое значение ${x}`);
  })
  .then(() => console.log("пропущен"))     // не вызывается
  .catch((error) => {
    console.log(error.message);            // "плохое значение 20"
    return "восстановлено";
  })
  .then((x) => console.log(x));            // "восстановлено"
```

Правила:

1. Возвращаемое значение становится результатом следующего промиса.
2. Возвращенный промис «встраивается» — следующий `then` ждет его.
3. Брошенная ошибка или отклоненный промис пропускают все `then` до ближайшего `catch`.
4. После `catch` цепочка снова в состоянии успеха, если `catch` не бросил ошибку.

## Частая ошибка: забытый return

```javascript
fetch("/api/user")
  .then((res) => {
    res.json(); // без return следующий then получит undefined
  })
  .then((user) => console.log(user)); // undefined
```

## finally

```javascript
setLoading(true);
loadData()
  .then(setData)
  .catch(setError)
  .finally(() => setLoading(false));
```

`finally` не получает значение и не меняет результат цепочки — кроме случая, когда он сам бросает ошибку или возвращает отклоненный промис.

## then(ok, fail) или catch

```javascript
promise.then(ok, fail);      // fail НЕ поймает ошибку, брошенную в ok
promise.then(ok).catch(fail); // поймает и ошибки из ok
```

## Последовательная обработка массива

```javascript
const ids = [1, 2, 3];
ids.reduce(
  (chain, id) => chain.then(() => loadItem(id)),
  Promise.resolve(),
);
// или проще: for (const id of ids) await loadItem(id);
```

## Что важно помнить

- Обработчики `then` всегда вызываются асинхронно, как микрозадачи.
- Вложенные `then` внутри `then` — признак ошибки; возвращайте промис и продолжайте цепочку.
- Один `catch` в конце цепочки ловит ошибки всех шагов.
- `async/await` — синтаксис поверх тех же промисов: `await` ≈ `then`, `try/catch` ≈ `catch`.

## Мини-шпаргалка

- `then` — успех, `catch` — ошибка, `finally` — всегда.
- Каждый метод возвращает новый промис.
- Значение из обработчика → следующий `then`, промис ожидается.
- Ошибка → ближайший `catch`, после него цепочка продолжается.
- Не забывайте `return` в `then`.
