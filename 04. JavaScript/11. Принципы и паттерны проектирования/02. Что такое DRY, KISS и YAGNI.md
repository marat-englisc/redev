# Что такое DRY, KISS и YAGNI

> [!NOTE]
> **DRY** (Don't Repeat Yourself) — у каждого знания в системе должно быть одно авторитетное место. **KISS** (Keep It Simple, Stupid) — выбирать самое простое решение, которое работает. **YAGNI** (You Aren't Gonna Need It) — не писать код «на будущее», пока он не нужен. Эти принципы уравновешивают друг друга: чрезмерный DRY порождает сложные абстракции, которые нарушают KISS.

## Вопрос

Что означают DRY, KISS и YAGNI? Когда стремление к DRY вредит и что такое «неправильная абстракция»?

## DRY

Речь о **дублировании знания**, а не о похожих строках.

```typescript
// дублирование знания: правило «пароль от 8 символов» записано в трех местах
// форма регистрации, форма смены пароля, серверная валидация

// одно место — схема, которую используют и клиент, и сервер
export const passwordSchema = z.string().min(8, "Минимум 8 символов");
```

Где DRY особенно полезен: бизнес-правила, валидация, константы и токены дизайна, типы API (генерация из OpenAPI или схемы).

## Когда DRY вредит

Два куска кода выглядят одинаково, но меняются по разным причинам. Если объединить их, общая функция начинает обрастать флагами:

```typescript
// «неправильная абстракция»
function formatPrice(value: number, isCart?: boolean, isAdmin?: boolean, noCurrency?: boolean) { /* ... */ }
```

Правило трех (Rule of Three): выносите общее, когда повторение встретилось в третий раз и стало понятно, что именно общее. «Дублирование дешевле неправильной абстракции» (Sandi Metz).

## KISS

```typescript
// сложно: универсальный конфигурируемый движок для одной формы
const form = createFormEngine({ schema, plugins: [validationPlugin, maskPlugin], adapters });

// просто: решает текущую задачу
const [email, setEmail] = useState("");
const error = email.includes("@") ? null : "Некорректный email";
```

Признаки нарушения KISS: решение трудно объяснить коллеге за минуту, много уровней косвенности, абстракции ради абстракций.

## YAGNI

```typescript
// YAGNI: поддержка нескольких валют, хотя магазин работает только в рублях
interface Price { amount: number; currency: Currency; rates: ExchangeRates; }
```

Не добавляйте параметры, слои, конфиги и обобщения «на всякий случай». Когда требование появится, код будет проще изменить, если он не перегружен заранее.

YAGNI не означает отказ от продуманной архитектуры: безопасность, доступность, обработка ошибок и тесты нужны сейчас, а не «потом».

## Связанные принципы

| Принцип | Суть |
| --- | --- |
| Separation of Concerns | разные задачи — в разных модулях |
| Composition over Inheritance | собирать поведение из частей, а не наследовать |
| Principle of Least Astonishment | код ведет себя так, как ожидает читатель |
| Fail Fast | ошибки обнаруживаются как можно раньше |

## Что важно помнить

- DRY — про знание и правила, а не про совпадение текста.
- Преждевременная абстракция хуже дублирования: ее дорого разбирать.
- KISS и YAGNI помогают избегать overengineering, особенно на старте фичи.
- На код-ревью эти принципы — аргументы для обсуждения, а не догма.

## Мини-шпаргалка

DRY — одно место для каждого знания. KISS — самое простое работающее решение. YAGNI — не писать код «на будущее». Rule of Three — абстрагировать при третьем повторе. Дублирование дешевле неправильной абстракции.
