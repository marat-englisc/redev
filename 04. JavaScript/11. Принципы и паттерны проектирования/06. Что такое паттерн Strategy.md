# Что такое паттерн Strategy

> [!NOTE]
> **Strategy (Стратегия)** — поведенческий паттерн: семейство взаимозаменяемых алгоритмов выносится в отдельные объекты или функции с общим интерфейсом, и нужный выбирается во время выполнения. Код, который использует стратегию, не знает деталей алгоритма. В JavaScript стратегия — чаще всего просто **функция, переданная параметром**: компаратор в `sort`, валидатор, функция расчета скидки.

## Вопрос

Что такое паттерн Strategy? Как он помогает избавиться от больших `if/switch` и где встречается во фронтенде?

## Проблема

```typescript
function calcDelivery(type: string, weight: number) {
  if (type === "courier") return 300 + weight * 20;
  if (type === "pickup") return 0;
  if (type === "post") return 150 + weight * 35;
  // каждый новый способ — правка этой функции
}
```

## Решение: объекты-стратегии

```typescript
type DeliveryStrategy = (weight: number) => number;

const deliveryStrategies: Record<string, DeliveryStrategy> = {
  courier: (w) => 300 + w * 20,
  pickup: () => 0,
  post: (w) => 150 + w * 35,
};

function calcDelivery(type: keyof typeof deliveryStrategies, weight: number) {
  return deliveryStrategies[type](weight);
}

// новый способ — новая запись, существующий код не меняется
deliveryStrategies.drone = (w) => 500 + w * 50;
```

## Стратегия как параметр

```typescript
const byPrice = (a: Product, b: Product) => a.price - b.price;
const byRating = (a: Product, b: Product) => b.rating - a.rating;

products.toSorted(sortMode === "price" ? byPrice : byRating);
```

```typescript
type Validator = (value: string) => string | null;

const required: Validator = (v) => (v.trim() ? null : "Обязательное поле");
const email: Validator = (v) => (/^\S+@\S+$/.test(v) ? null : "Некорректный email");
const minLength = (n: number): Validator => (v) => (v.length >= n ? null : `Минимум ${n} символов`);

function validate(value: string, rules: Validator[]) {
  return rules.map((rule) => rule(value)).find(Boolean) ?? null;
}

validate("an", [required, minLength(3)]); // "Минимум 3 символов"
```

## Strategy в React

```tsx
const renderers = {
  text: (f: Field) => <input name={f.name} />,
  select: (f: Field) => <select name={f.name}>{/* options */}</select>,
  date: (f: Field) => <input type="date" name={f.name} />,
};

function FormField({ field }: { field: Field }) {
  return renderers[field.type](field);
}
```

Стратегии также передают в компоненты через props: `formatValue`, `sortFn`, `renderItem`, `filterFn`.

## Strategy и похожие паттерны

| Паттерн | Отличие |
| --- | --- |
| Factory | решает, **какой объект создать** |
| Strategy | решает, **каким алгоритмом выполнить действие** |
| State | поведение меняется само при смене внутреннего состояния объекта |
| Command | инкапсулирует **действие** как объект (для отмены, очередей) |

## Что важно помнить

- В JS стратегия обычно — функция; классы-стратегии нужны, если у алгоритма есть состояние или несколько методов.
- Паттерн реализует Open/Closed: новый алгоритм добавляется без правки вызывающего кода.
- Для двух-трех стабильных вариантов обычный `if` проще — не создавайте реестр ради реестра (KISS).
- Стратегии легко тестировать по отдельности как чистые функции.

## Мини-шпаргалка

Strategy — взаимозаменяемые алгоритмы с общим интерфейсом, выбор во время выполнения. В JS — функция-параметр или реестр `{ key: fn }` вместо `switch`. Примеры: компаратор `sort`, валидаторы, расчет доставки, рендереры полей формы.
