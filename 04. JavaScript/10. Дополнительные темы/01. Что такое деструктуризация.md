# Деструктуризация массивов и объектов

> [!NOTE]
> **Деструктуризация** — синтаксис для распаковки значений из массивов и свойств из объектов в переменные. В массивах работает по позиции (можно пропускать элементы запятыми), в объектах — по имени свойства (можно переименовывать и задавать значения по умолчанию). Rest-синтаксис собирает остаток, а деструктуризация в параметрах функции делает удобными «объекты настроек» и props в React.

## Вопрос

Что такое деструктуризация? Как деструктурировать массивы и объекты, пропускать элементы, переименовывать свойства и задавать значения по умолчанию?

## Массивы

```javascript
const rgb = [255, 128, 0];

const [red, green, blue] = rgb;
const [first, , third] = rgb;        // пропуск элементов запятой
const [head, ...tail] = rgb;         // tail = [128, 0]
const [a = 1, b = 2] = [10];         // a = 10, b = 2 — значение по умолчанию

let x = 1, y = 2;
[x, y] = [y, x];                     // обмен значений без временной переменной

const [, , last] = "abc";            // работает с любым итерируемым
const [[nested]] = [[42]];           // вложенная деструктуризация
```

Значение по умолчанию применяется только для `undefined`, но не для `null`.

## Объекты

```javascript
const user = {
  id: 1,
  name: "Анна",
  address: { city: "Казань" },
};

const { name, id } = user;                      // по имени, порядок неважен
const { name: userName } = user;                // переименование
const { role = "guest" } = user;                // по умолчанию
const { role: userRole = "guest" } = user;      // переименование + default
const { address: { city } } = user;             // вложенное (address не создается)
const { id: _, ...rest } = user;                // rest — всё кроме id

const key = "name";
const { [key]: value } = user;                  // вычисляемый ключ
```

Если вложенный объект отсутствует, будет `TypeError` — защищайтесь значением по умолчанию: `const { address: { city } = {} } = user`.

## В параметрах функции

```javascript
function createUser({ name, role = "user", notify = true } = {}) {
  return { name, role, notify };
}

createUser({ name: "Анна" });
createUser(); // работает благодаря = {}

// React
function Button({ label, variant = "primary", ...props }) {
  return <button className={variant} {...props}>{label}</button>;
}

// в колбэках
Object.entries(prices).map(([item, price]) => `${item}: ${price}`);
users.map(({ id, name }) => ({ id, name }));
```

## Полезные приемы

```javascript
const [state, setState] = useState(0);           // хуки возвращают массивы
const { data, error, isLoading } = useQuery(...); // и объекты
for (const [key, value] of map) {}               // перебор Map
const { default: Component } = await import("./Page.js");
```

## Что важно помнить

- Деструктуризация `null` или `undefined` бросает `TypeError`: `const { a } = null`.
- Присваивание в существующие переменные объекта требует скобок: `({ a, b } = obj);`.
- Массивы возвращают из хуков, чтобы было удобно переименовывать (`[count, setCount]`), объекты — когда полей много.
- Деструктуризация копирует значения поверхностно — вложенные объекты остаются ссылками.

## Мини-шпаргалка

- Массивы — по позиции, пропуск через `,`.
- Объекты — по имени, `{ a: newName = default }`.
- `...rest` собирает остаток.
- Default срабатывает только для `undefined`.
- В параметрах: `function f({ a, b } = {})`.
