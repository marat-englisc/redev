# Работа со строками

> [!NOTE]
> Строки в JavaScript - примитивные неизменяемые значения, у которых есть множество методов для поиска, изменения представления и разбиения текста.

## Вопрос

Какие основные приемы работы со строками нужно знать?

## Определение

Строка, `string`, хранит текст. Строки иммутабельны: методы не меняют исходную строку, а возвращают новую.

## Создание строки

```javascript
const name = 'Ann';
const message = `Hello, ${name}`;
```

Шаблонные строки позволяют удобно вставлять выражения через `${...}`.

## Длина и символы

```javascript
const text = 'JavaScript';

console.log(text.length); // 10
console.log(text[0]);     // 'J'
```

## Поиск

```javascript
const text = 'frontend developer';

console.log(text.includes('end'));  // true
console.log(text.startsWith('front')); // true
console.log(text.endsWith('er'));   // true
console.log(text.indexOf('dev'));   // 9
```

## Изменение представления

```javascript
const value = '  Hello  ';

console.log(value.trim());        // 'Hello'
console.log(value.toLowerCase()); // '  hello  '
console.log(value.toUpperCase()); // '  HELLO  '
```

Исходная строка не меняется.

## Разбиение и объединение

```javascript
const tags = 'js,css,html';

const list = tags.split(',');

console.log(list); // ['js', 'css', 'html']
console.log(list.join(' | ')); // 'js | css | html'
```

## Замена

```javascript
const text = 'Hello, world';

console.log(text.replace('world', 'JavaScript'));
```

Для замены всех совпадений можно использовать `replaceAll`.

## Что важно помнить

- Строки неизменяемы: все методы возвращают новую строку.
- `length` считает UTF-16 code units: у emoji может быть длина 2 и больше — для символов используйте `[...str]` или `Intl.Segmenter`.
- `localeCompare` и `Intl.Collator` нужны для правильной сортировки русских строк.
- `replaceAll`, `at`, `padStart`, `trimEnd` — современные удобные методы.

## Мини-шпаргалка

```javascript
str.trim();
str.includes(value);
str.split(separator);
str.replace(search, replacement);
str.toLowerCase();
```
