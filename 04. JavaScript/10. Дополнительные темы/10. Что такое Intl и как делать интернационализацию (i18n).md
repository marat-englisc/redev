# Что такое Intl и как делать интернационализацию (i18n)

> [!NOTE]
> **`Intl`** — встроенный API JavaScript для форматирования с учетом языка и региона (локали): чисел и валют (`NumberFormat`), дат (`DateTimeFormat`), относительного времени (`RelativeTimeFormat`), множественного числа (`PluralRules`), списков (`ListFormat`), сортировки строк (`Collator`). **i18n** (internationalization) — подготовка приложения к нескольким языкам: вынос текстов, форматирование через `Intl`, поддержка RTL. **l10n** — сам перевод и адаптация под конкретный рынок.

## Вопрос

Что такое `Intl` и какие задачи он решает? Чем i18n отличается от l10n и как организовать перевод интерфейса во frontend-приложении?

## Числа и валюты

```javascript
const price = 1234567.891;

new Intl.NumberFormat("ru-RU").format(price);
// "1 234 567,891"

new Intl.NumberFormat("ru-RU", { style: "currency", currency: "RUB" }).format(price);
// "1 234 567,89 ₽"

new Intl.NumberFormat("en-US", { style: "currency", currency: "USD" }).format(price);
// "$1,234,567.89"

new Intl.NumberFormat("ru-RU", { notation: "compact" }).format(1_500_000);
// "1,5 млн"

new Intl.NumberFormat("ru-RU", { style: "percent" }).format(0.256);
// "26 %"
```

## Даты и относительное время

```javascript
const date = new Date("2026-03-08T10:30:00Z");

new Intl.DateTimeFormat("ru-RU", { dateStyle: "long", timeZone: "Europe/Moscow" }).format(date);
// "8 марта 2026 г."

new Intl.DateTimeFormat("ru-RU", {
  weekday: "short", hour: "2-digit", minute: "2-digit", timeZone: "Europe/Moscow",
}).format(date);
// "вс, 13:30"

const rtf = new Intl.RelativeTimeFormat("ru", { numeric: "auto" });
rtf.format(-1, "day");   // "вчера"
rtf.format(3, "hour");   // "через 3 часа"
```

## Множественное число

В русском три формы: «1 файл», «2 файла», «5 файлов». `PluralRules` возвращает категорию, по которой выбирают нужную строку:

```javascript
const pr = new Intl.PluralRules("ru-RU");
const forms = { one: "файл", few: "файла", many: "файлов", other: "файла" };

function files(n) {
  return `${n} ${forms[pr.select(n)]}`;
}

files(1);   // "1 файл"
files(3);   // "3 файла"
files(11);  // "11 файлов"
files(21);  // "21 файл"
files(1.5); // "1.5 файла" (категория other)
```

## Списки и сортировка

```javascript
new Intl.ListFormat("ru", { type: "conjunction" }).format(["HTML", "CSS", "JS"]);
// "HTML, CSS и JS"

["ёж", "яблоко", "елка"].sort(new Intl.Collator("ru").compare);
// ["елка", "ёж", "яблоко"] — обычный sort() поставил бы «ё» после «я»
```

## i18n во frontend-приложении

1. **Тексты выносятся из кода** в словари по ключам:

```json
// locales/ru.json
{ "cart.title": "Корзина", "cart.items": "{count, plural, one {# товар} few {# товара} many {# товаров} other {# товара}}" }
```

2. **Библиотека перевода** подставляет строки и обрабатывает plural, переменные, форматирование: `react-i18next`, `FormatJS / react-intl` (формат ICU MessageFormat), `next-intl` для Next.js.

```jsx
import { useTranslation } from "react-i18next";

function CartTitle({ count }) {
  const { t } = useTranslation();
  return <h1>{t("cart.title")} — {t("cart.items", { count })}</h1>;
}
```

3. **Язык** определяют по URL (`/en/catalog`), настройкам пользователя или заголовку `Accept-Language`; в HTML ставят `<html lang="ru">`, для RTL — `dir="rtl"`.
4. **Верстка** готовится к разной длине текста (немецкий длиннее русского) и RTL — помогают логические свойства CSS.

## Что важно помнить

- Не склеивайте фразы из кусков: `"Удалить " + n + " файлов"` не переводится на языки с другим порядком слов — используйте шаблоны с переменными.
- Не форматируйте числа, даты и валюты вручную — только `Intl` или библиотека на его основе.
- Создание форматтера относительно дорогое: переиспользуйте экземпляр `Intl.NumberFormat`, а не создавайте его в цикле.
- Даты на сервере и клиенте могут отформатироваться по-разному (часовой пояс, локаль) — источник hydration mismatch в SSR. Указывайте `timeZone` и локаль явно.
- `toLocaleString()` и `toLocaleDateString()` используют `Intl` внутри и принимают те же опции.

## Мини-шпаргалка

`Intl.NumberFormat` — числа, валюты, проценты, compact. `DateTimeFormat` — даты с `timeZone`. `RelativeTimeFormat` — «вчера», «через 3 часа». `PluralRules` — формы слова. `ListFormat`, `Collator`. i18n: тексты в словарях, ICU-шаблоны, `react-i18next` / `react-intl` / `next-intl`, `lang` и `dir`.
