# Что такое Temporal API?

> [!NOTE]
> Temporal API - современный набор объектов для работы с датами, временем, часовыми поясами и длительностями, задуманный как замена проблемному `Date`.

## Вопрос

Зачем нужен Temporal API, если в JavaScript уже есть `Date`?

## Определение

`Temporal` решает многие проблемы старого `Date`: мутабельность, неоднозначные часовые пояса, неудобную арифметику дат и смешивание разных смыслов времени в одном объекте.

Temporal разделяет разные понятия:

- календарная дата;
- время без даты;
- точный момент времени;
- дата и время в часовом поясе;
- длительность.

## Важный статус поддержки

Temporal - современный API, но его доступность зависит от браузера и версии окружения. Перед использованием в проекте нужно проверить поддержку или подключить polyfill.

## Пример PlainDate

```javascript
const date = Temporal.PlainDate.from('2026-08-03');

const nextWeek = date.add({ days: 7 });

console.log(nextWeek.toString()); // '2026-08-10'
```

`PlainDate` описывает календарную дату без времени и часового пояса.

## Пример Instant

```javascript
const instant = Temporal.Now.instant();

console.log(instant.toString());
```

`Instant` описывает точный момент времени.

## Date vs Temporal

| `Date` | `Temporal` |
| --- | --- |
| один объект для разных задач | отдельные типы для разных задач |
| мутабельный | иммутабельный |
| неудобная работа с time zone | явная работа с time zone |
| старый API | более предсказуемый API |

## Что важно помнить

- Temporal решает проблемы `Date`: изменяемость, месяцы с нуля, неудобные часовые пояса.
- Типы разделены по смыслу: `PlainDate`, `PlainTime`, `ZonedDateTime`, `Instant`, `Duration`.
- Объекты Temporal неизменяемы — методы возвращают новые значения.
- Поддержка браузерами еще неполная; пока используют полифил или date-fns/dayjs.

## Мини-шпаргалка

```javascript
Temporal.Now.instant();
Temporal.PlainDate.from('2026-08-03');
Temporal.Duration.from({ hours: 2 });
```
