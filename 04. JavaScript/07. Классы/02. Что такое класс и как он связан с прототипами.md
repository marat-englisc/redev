# Что такое класс и как он связан с прототипами

> [!NOTE]
> **Класс** — шаблон для создания объектов с общей структурой и поведением. В JavaScript класс — синтаксис поверх функций-конструкторов и прототипов: `typeof` класса — `"function"`, методы попадают в `Class.prototype`, а наследование `extends` строит цепочку прототипов. В отличие от функции-конструктора класс нельзя вызвать без `new`, его тело всегда в strict mode, методы неперечисляемы, а объявление класса не всплывает. Класс можно объявить и как выражение: `const A = class {}`.

## Вопрос

Что такое класс в JavaScript? Чем класс отличается от функции-конструктора и как классы связаны с прототипами? Можно ли объявить класс выражением?

## Синтаксис

```javascript
class Product {
  static currency = "RUB";   // статическое поле
  discount = 0;              // поле экземпляра
  #cost;                     // приватное поле

  constructor(title, price) {
    this.title = title;
    this.price = price;
    this.#cost = price * 0.7;
  }

  get finalPrice() {         // геттер
    return this.price * (1 - this.discount);
  }

  format() {                 // метод — в Product.prototype
    return `${this.title}: ${this.finalPrice} ${Product.currency}`;
  }
}

const kettle = new Product("Чайник", 1500);
kettle.format(); // "Чайник: 1500 RUB"
```

## Класс и функция-конструктор

```javascript
// то же самое до ES6
function ProductFn(title, price) {
  this.title = title;
  this.price = price;
}
ProductFn.prototype.format = function () {
  return `${this.title}: ${this.price}`;
};
```

| | Класс | Функция-конструктор |
| --- | --- | --- |
| Вызов без `new` | `TypeError` | работает, `this` — undefined/global |
| Strict mode | всегда | только если указан |
| Методы перечисляемы | нет | да (при присваивании в prototype) |
| Hoisting | TDZ, как `let` | Function Declaration всплывает |
| Наследование | `extends`, `super` | `Object.create` + `call` вручную |
| Приватные поля `#x` | есть | нет (только замыкания) |
| Статические блоки, поля | есть | вручную |

## Связь с прототипами

```javascript
typeof Product;                                  // "function"
Object.getPrototypeOf(kettle) === Product.prototype; // true
kettle.hasOwnProperty("format");                 // false — метод в прототипе
kettle.hasOwnProperty("title");                  // true — поле экземпляра
Product.prototype.constructor === Product;       // true

class Discounted extends Product {}
Object.getPrototypeOf(Discounted.prototype) === Product.prototype; // цепочка экземпляров
Object.getPrototypeOf(Discounted) === Product;   // статика тоже наследуется
```

```text
kettle → Product.prototype → Object.prototype → null
           { format, finalPrice }
```

## Класс как выражение

```javascript
const Animal = class {
  speak() { return "..."; }
};

const Named = class Inner {
  whoAmI() { return Inner.name; } // имя Inner видно только внутри класса
};

// фабрика классов и миксины
const Serializable = (Base) => class extends Base {
  toJSON() { return { ...this }; }
};
class Order extends Serializable(Object) {}
```

## Что важно помнить

- Классы — не «настоящие» классы как в Java: под капотом прототипное наследование, поэтому методы можно менять у прототипа во время работы.
- Методы класса теряют `this` при передаче как колбэк — используйте стрелочные поля или `bind`.
- Поля экземпляра создаются для каждого объекта, методы — один раз в прототипе.
- В React классовые компоненты остались в legacy-коде; новые пишут функциями с хуками.

## Мини-шпаргалка

- Класс — синтаксис над конструкторами и прототипами.
- Методы — в `Class.prototype`, поля — в экземпляре.
- Нельзя без `new`, всегда strict, не всплывает.
- `extends` строит цепочку прототипов.
- Класс-выражение: `const A = class {}`.
