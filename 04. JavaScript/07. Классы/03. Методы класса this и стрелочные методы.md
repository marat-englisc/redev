# Методы класса, this и стрелочные методы

> [!NOTE]
> Метод объявляют в теле класса без `function`: `save() {}` — он попадает в `Class.prototype` и общий для всех экземпляров. `this` в методе указывает на объект, у которого метод вызван, и теряется при передаче метода как колбэка. **Стрелочное поле** `handle = () => {}` создается для каждого экземпляра, хранится в самом объекте и навсегда привязано к нему — удобно для обработчиков событий, но тратит больше памяти и не наследуется через `super`.

## Вопрос

Как добавить метод в класс? Чем метод класса отличается от функции в свойстве объекта? Как работает `this` внутри класса и чем стрелочные методы отличаются от обычных?

## Объявление методов

```javascript
class Cart {
  items = [];

  add(item) {                  // метод прототипа
    this.items.push(item);
    return this;               // позволяет цепочки вызовов
  }

  get total() {                // геттер
    return this.items.reduce((sum, i) => sum + i.price, 0);
  }

  static fromJSON(json) {      // статический метод — на самом классе
    return Object.assign(new Cart(), JSON.parse(json));
  }

  async checkout() {}          // асинхронный метод
  *[Symbol.iterator]() { yield* this.items; } // метод-генератор с вычисляемым именем
}

new Cart().add({ price: 100 }).add({ price: 50 }).total; // 150
```

## Метод класса и функция в свойстве

```javascript
class A {
  method() {}            // в A.prototype, один на все экземпляры
  arrow = () => {};      // в каждом экземпляре свой
}

const a1 = new A();
const a2 = new A();

a1.method === a2.method;       // true
a1.arrow === a2.arrow;         // false
Object.keys(a1);               // ["arrow"] — поле перечисляемо, метод нет
```

| | Метод прототипа | Функция-поле (стрелка) |
| --- | --- | --- |
| Где хранится | `Class.prototype` | каждый экземпляр |
| Память | одна функция на все объекты | функция на каждый объект |
| `this` | зависит от вызова | привязан к экземпляру |
| Наследование и `super.method()` | работает | `super.arrow` недоступен |
| Можно переопределить в наследнике | да | да, но как поле |
| Перечисляемость | нет | да |

## this внутри класса

```javascript
class Counter {
  count = 0;
  increment() {
    this.count++;
  }
}

const counter = new Counter();
counter.increment();               // this = counter

const inc = counter.increment;
inc();                             // TypeError: Cannot read properties of undefined
setTimeout(counter.increment, 0);  // тот же эффект
```

Тело класса всегда в strict mode, поэтому потерянный `this` — `undefined`, а не `window`.

Три решения:

```javascript
// 1. стрелка при передаче
button.addEventListener("click", () => counter.increment());

// 2. bind в конструкторе
class Counter2 {
  constructor() {
    this.increment = this.increment.bind(this);
  }
  increment() {}
}

// 3. стрелочное поле
class Counter3 {
  count = 0;
  increment = () => {
    this.count++;
  };
}
```

## Добавление метода после объявления

```javascript
Cart.prototype.clear = function () {
  this.items = [];
};
```

Технически возможно, но затрудняет поддержку — в обычном коде методы описывают в теле класса.

## Что важно помнить

- Стрелочные поля удобны для обработчиков React-классов и событий, но их нельзя вызвать через `super` и нельзя замокать через прототип в тестах.
- Методы между собой в теле класса разделяются без запятых.
- Имя метода может быть вычисляемым: `[methodName]() {}`.
- Цепочка вызовов (`return this`) — паттерн fluent interface.

## Мини-шпаргалка

- Метод — `name() {}` в теле класса, живет в прототипе.
- `this` — объект, у которого вызван метод; теряется в колбэках.
- Решения: стрелка при передаче, `bind`, стрелочное поле.
- Стрелочное поле — в каждом экземпляре, привязано навсегда, без `super`.
- Статический метод — на классе, а не на экземпляре.
