# Статические методы и свойства (static)

> [!NOTE]
> `static` объявляет метод или поле, которое принадлежит **самому классу**, а не экземплярам. Вызывается через имя класса: `User.create()`, `MathUtils.PI`. Внутри статического метода `this` — это класс (или наследник, через который вызвали). Статика наследуется через `extends`. Типичные применения: фабричные методы, утилиты, константы, счетчики и кеши на уровне класса.

## Вопрос

Что делает ключевое слово `static`? Как вызвать статический метод и для чего он нужен?

## Объявление и вызов

```javascript
class User {
  static #count = 0;              // приватное статическое поле
  static roles = ["user", "admin"];

  constructor(name) {
    this.name = name;
    User.#count++;
  }

  static create(data) {           // фабричный метод
    return new this(data.name);   // this — класс, поэтому работает и в наследниках
  }

  static get count() {
    return User.#count;
  }

  static {                        // статический блок инициализации (ES2022)
    console.log("класс User инициализирован");
  }
}

User.create({ name: "Анна" });
User.count;                       // 1
User.roles;                       // ["user", "admin"]

const anna = new User("Анна");
anna.create;                      // undefined — у экземпляра статики нет
anna.constructor.create;          // доступ через конструктор экземпляра
```

## Где используются

| Задача | Пример |
| --- | --- |
| Фабрики | `Money.fromString("100 RUB")`, `Date.now()` |
| Утилиты без состояния | `Math.max()`, `Array.isArray()`, `Object.keys()` |
| Константы | `Number.MAX_SAFE_INTEGER`, `Status.ACTIVE` |
| Общее состояние класса | счетчик экземпляров, кеш, реестр |
| Валидация и сравнение | `Money.compare(a, b)` |

## Наследование статики

```javascript
class Animal {
  static create(name) {
    return new this(name);
  }
}

class Dog extends Animal {}

const dog = Dog.create("Рекс");
dog instanceof Dog; // true — this в статическом методе = Dog
```

Внутри статического метода наследника можно вызвать `super.create()`.

## Статика и экземпляр

| | Статический | Экземпляра |
| --- | --- | --- |
| Где | на классе | в `prototype` / объекте |
| Вызов | `Class.method()` | `obj.method()` |
| `this` | класс | экземпляр |
| Доступ к полям экземпляра | только через переданный объект | да |

## Что важно помнить

- Если статический метод не использует ни класс, ни экземпляры, возможно, это просто функция модуля — класс-«мешок утилит» не нужен.
- Статическое состояние — по сути глобальное: оно общее для всего приложения и сохраняется между тестами.
- Приватные статические поля (`static #x`) доступны только через имя класса, где они объявлены: `this.#x` в наследнике бросит `TypeError`.
- В TypeScript статические члены не могут использовать параметры типа класса (`T`).

## Мини-шпаргалка

- `static` — член класса, не экземпляра.
- Вызов: `ClassName.method()`.
- `this` в статическом методе — класс.
- Статика наследуется, есть `super` для статических методов.
- Фабрики, утилиты, константы, счетчики.
