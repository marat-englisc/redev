# Приватные поля и методы класса

> [!NOTE]
> Приватные члены класса объявляют с префиксом `#`: `#balance`, `#validate()`. Они доступны только внутри тела класса, где объявлены; обращение снаружи — `SyntaxError` еще на этапе разбора кода. Приватные поля **не наследуются в смысле доступа**: наследник не видит `#field` родителя, хотя поле существует в объекте. До ES2022 приватность имитировали соглашением `_field`, замыканиями или `WeakMap`.

## Вопрос

Как объявить приватные свойства в классе? Можно ли обратиться к приватному свойству вне класса? Можно ли наследовать приватные свойства?

## Объявление

```javascript
class BankAccount {
  #balance = 0;                 // приватное поле
  static #rate = 0.05;          // приватное статическое поле

  constructor(owner) {
    this.owner = owner;
  }

  deposit(amount) {
    this.#validate(amount);
    this.#balance += amount;
  }

  get balance() {               // публичный доступ только на чтение
    return this.#balance;
  }

  #validate(amount) {           // приватный метод
    if (amount <= 0) throw new RangeError("Сумма должна быть положительной");
  }
}

const account = new BankAccount("Анна");
account.deposit(1000);
account.balance;   // 1000
```

## Доступ снаружи

```javascript
account.#balance;          // SyntaxError: Private field '#balance' must be declared in an enclosing class
account["#balance"];       // undefined — это обычное строковое свойство, а не приватное
Object.keys(account);      // ["owner"] — приватных полей нет
JSON.stringify(account);   // '{"owner":"Анна"}'
```

Приватные поля не видны в `Object.keys`, `for...in`, `JSON.stringify`, spread и Proxy. В DevTools браузер их показывает — для отладки.

## Наследование

```javascript
class SavingsAccount extends BankAccount {
  addInterest() {
    this.#balance *= 1.05; // SyntaxError — #balance не объявлен в SavingsAccount
  }
}
```

Поле `#balance` есть в объекте-наследнике (его создал родительский конструктор), но доступ к нему возможен **только** из кода класса `BankAccount`. Наследник работает через публичные или защищенные по соглашению методы родителя:

```javascript
class BankAccount2 {
  #balance = 0;
  _changeBalance(delta) { this.#balance += delta; } // «protected» по соглашению
}
```

В JavaScript нет модификатора `protected` (он есть в TypeScript только на уровне типов).

## Проверка наличия: brand check

```javascript
class Money {
  #amount;
  constructor(a) { this.#amount = a; }
  static isMoney(obj) {
    return #amount in obj; // true только для настоящих экземпляров
  }
}
```

## Сравнение способов приватности

| Способ | Настоящая приватность | Наследование доступа | Видно в DevTools |
| --- | --- | --- | --- |
| `#field` | да | нет | да |
| `_field` (соглашение) | нет | да | да |
| Замыкание в конструкторе | да | нет | нет |
| `WeakMap` вне класса | да | через общий модуль | нет |
| TypeScript `private` | только на этапе компиляции | нет | да |

## Что важно помнить

- Обращение к `#field` у объекта, у которого его нет, бросает `TypeError` — это защита от подделки объектов.
- Приватные поля несовместимы с `Proxy`: методы, обращающиеся к `#field`, ломаются, если `this` — прокси.
- `structuredClone` и spread не копируют приватные поля.
- Имена `#x` нельзя создавать динамически: `this[#name]` невозможен.

## Мини-шпаргалка

- `#field`, `#method()`, `static #x` — приватные члены.
- Доступ только внутри тела объявившего класса.
- Снаружи — `SyntaxError`.
- Наследник не имеет доступа к `#field` родителя.
- `#field in obj` — проверка подлинности экземпляра.
