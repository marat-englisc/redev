# Операторы ! и !!

> [!NOTE]
> `!` — логическое НЕ: приводит значение к boolean и инвертирует его. `!!` — двойное отрицание: приводит значение к boolean без инверсии, то есть работает как `Boolean(value)`. Falsy-значения превращаются в `false`, все остальные — в `true`.

## Вопрос

Что делает оператор `!`? Что делает двойное отрицание `!!` и чем оно отличается от `Boolean()`?

## Оператор !

```javascript
!true;      // false
!0;         // true
!"";        // true
!"текст";   // false
![];        // false — пустой массив truthy
!null;      // true
```

Сначала значение приводится к boolean, затем инвертируется.

```javascript
if (!user) {
  redirectToLogin();
}
```

## Двойное отрицание !!

```javascript
!!"hello";   // true
!!0;         // false
!!NaN;       // false
!![];        // true
!!{};        // true
!!"0";       // true — непустая строка
```

Первый `!` приводит к boolean и инвертирует, второй возвращает исходный смысл. Результат идентичен `Boolean(value)`.

```javascript
const hasItems = !!cart.items.length;
const isLoggedIn = Boolean(session);
```

## Falsy-значения

```text
false, 0, -0, 0n, "", null, undefined, NaN
```

Всё остальное — truthy, включая `"0"`, `"false"`, `[]`, `{}`, `function () {}`, `new Boolean(false)`.

## Когда это нужно

- Вернуть из функции именно `boolean`, а не произвольное значение:

```javascript
function hasPermission(user) {
  return !!user?.roles?.includes("admin");
}
```

- В JSX, чтобы не отрисовать `0`:

```jsx
{items.length && <List items={items} />}   // при длине 0 на экране «0»
{!!items.length && <List items={items} />} // ничего не отрисует
```

## Что важно помнить

- `!!` и `Boolean()` полностью эквивалентны; `Boolean()` читается понятнее, `!!` короче — это вопрос стиля команды.
- Не путайте `new Boolean(false)` (объект, truthy) и `Boolean(false)` (примитив `false`).
- `!` имеет высокий приоритет: `!a === b` означает `(!a) === b`.
- В TypeScript `!` после выражения (`value!`) — это non-null assertion, а не логический оператор.

## Мини-шпаргалка

- `!x` — инвертированный boolean.
- `!!x` = `Boolean(x)`.
- Falsy: `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`.
- `!![]` и `!!{}` — `true`.
- В JSX `!!` защищает от вывода `0`.
