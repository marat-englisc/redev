# Что такое ECMAScript и почему ES6 — самое важное обновление

> [!NOTE]
> **ECMAScript** — стандарт языка (спецификация ECMA-262), который развивает комитет TC39. JavaScript — его реализация в браузерах и Node.js вместе с Web API. С 2015 года новая версия выходит ежегодно (ES2015, ES2016...). **ES6 (ES2015)** — крупнейшее обновление в истории языка: `let`/`const`, стрелочные функции, классы, модули, промисы, деструктуризация, шаблонные строки и многое другое.

## Вопрос

Что такое ECMAScript и чем он отличается от JavaScript? Что появилось в ES6 и почему это обновление считают самым важным?

## ECMAScript и JavaScript

| Понятие | Что это |
| --- | --- |
| ECMAScript | спецификация синтаксиса и встроенных объектов (`Array`, `Promise`, `Map`) |
| JavaScript | язык, реализующий ECMAScript, + API окружения |
| Web API | `document`, `fetch`, `setTimeout` — не часть ECMAScript |
| V8, SpiderMonkey, JavaScriptCore | движки, реализующие стандарт |
| TC39 | комитет, который развивает стандарт |

## Процесс TC39

Новая возможность проходит стадии:

| Стадия | Смысл |
| --- | --- |
| 0 | идея |
| 1 | предложение с описанием проблемы |
| 2 | черновик спецификации |
| 2.7 | одобрено, ждет тестов и реализаций |
| 3 | кандидат, реализуется в движках |
| 4 | готово, войдет в ближайший стандарт |

## Что дал ES6 (ES2015)

```javascript
const items = [1, 2, 3];               // let и const, блочная область
const double = (x) => x * 2;           // стрелочные функции
const { name, ...rest } = user;        // деструктуризация и rest
const message = `Привет, ${name}`;     // шаблонные строки
function greet(name = "Гость") {}      // параметры по умолчанию

class Animal {                         // классы
  constructor(name) { this.name = name; }
}

import { api } from "./api.js";        // модули
export const config = {};

const done = new Promise((resolve) => resolve()); // промисы
const map = new Map();                 // Map, Set, WeakMap, WeakSet
const id = Symbol("id");               // символы
for (const item of items) {}           // итераторы и for...of
function* gen() { yield 1; }           // генераторы
const proxy = new Proxy({}, {});       // Proxy и Reflect
```

Почему ES6 так важен:

- после ES5 (2009) язык 6 лет почти не менялся, и ES6 накопил десятки возможностей сразу;
- появились модули — основа современных сборщиков и экосистемы npm;
- промисы стандартизировали асинхронность и подготовили `async/await` (ES2017);
- классы, `let/const` и стрелки сделали язык привычнее для разработчиков из других языков;
- после ES6 перешли на ежегодный выпуск небольших версий.

## Что появилось после ES6

| Версия | Возможности |
| --- | --- |
| ES2016 | `Array.prototype.includes`, `**` |
| ES2017 | `async/await`, `Object.entries`, `Object.values` |
| ES2018 | rest/spread для объектов, `Promise.finally`, асинхронные итераторы |
| ES2019 | `flat`, `flatMap`, `Object.fromEntries` |
| ES2020 | `?.`, `??`, `BigInt`, `Promise.allSettled`, `globalThis` |
| ES2021 | `??=`, `replaceAll`, `Promise.any` |
| ES2022 | приватные поля `#x`, top-level `await`, `at()`, `Object.hasOwn`, `cause` |
| ES2023 | `toSorted`, `toReversed`, `with`, `findLast` |
| ES2024 | `Object.groupBy`, `Promise.withResolvers` |
| ES2025 | методы `Set` (`union`, `intersection`), Iterator helpers |

## Что важно помнить

- Названия ES6 и ES2015 — одно и то же; дальше принято писать год.
- Поддержку новых возможностей проверяют на Can I Use, а для старых браузеров код транспилируют (Babel, SWC, esbuild) и подключают полифилы (core-js).
- TypeScript поддерживает предложения TC39 начиная со стадии 3.
- Не все популярные возможности — часть ECMAScript: JSX и декораторы TypeScript — нет.

## Мини-шпаргалка

- ECMAScript — стандарт, JavaScript — реализация + Web API.
- TC39, стадии 0–4, ежегодные версии.
- ES6 = ES2015: `let/const`, стрелки, классы, модули, промисы, деструктуризация.
- После ES6 — небольшие ежегодные обновления.
- Старые браузеры — транспиляция и полифилы.
