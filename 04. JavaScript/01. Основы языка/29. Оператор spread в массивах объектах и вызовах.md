# Оператор spread в массивах, объектах и вызовах функций

> [!NOTE]
> Spread (`...`) «раскладывает» итерируемый объект на отдельные элементы или свойства объекта — на отдельные свойства. Используется в литералах массивов (`[...a, ...b]`), объектов (`{ ...obj, key }`) и при вызове функций (`fn(...args)`). Spread делает **поверхностную** копию: вложенные объекты остаются общими.

## Вопрос

Что делает оператор spread? Как он работает с массивами, объектами и при вызове функций? Чем spread отличается от rest?

## Spread в массивах

```javascript
const fruits = ["яблоко", "груша"];
const more = [...fruits, "банан"];       // ["яблоко", "груша", "банан"]
const merged = [...fruits, ...more];
const copy = [...fruits];                // поверхностная копия

[..."привет"];                           // ["п", "р", "и", "в", "е", "т"]
[...new Set([1, 1, 2])];                 // [1, 2] — уникальные значения
[...document.querySelectorAll("li")];   // NodeList → массив
```

В массиве spread работает с любым **итерируемым** объектом: массив, строка, Set, Map, NodeList, генератор. Обычный объект не итерируем: `[...{ a: 1 }]` → `TypeError`.

## Spread в объектах

```javascript
const defaults = { theme: "light", pageSize: 20 };
const saved = { pageSize: 50 };

const settings = { ...defaults, ...saved };   // { theme: "light", pageSize: 50 }
const updated = { ...user, name: "Анна" };    // иммутабельное обновление
const { password, ...publicUser } = user;    // rest — убрать поле
```

- позже указанные свойства перезаписывают ранние;
- копируются только **собственные перечисляемые** свойства (без прототипа и геттеров как функций — значения геттеров вычисляются);
- `{ ...null }` и `{ ...undefined }` дают `{}` без ошибки.

## Spread при вызове функции

```javascript
const numbers = [5, 1, 9];

Math.max(...numbers);         // 9 — вместо Math.max.apply(null, numbers)
console.log(...["a", "b"]);   // a b
new Date(...[2026, 0, 15]);   // spread работает и с new
```

## Поверхностное копирование

```javascript
const original = { user: { name: "Анна" } };
const copy = { ...original };

copy.user.name = "Мария";
console.log(original.user.name); // "Мария" — вложенный объект общий
```

Для глубокой копии — `structuredClone(original)`.

## Spread и rest

Синтаксис одинаковый, смысл противоположный:

| | Spread | Rest |
| --- | --- | --- |
| Что делает | раскладывает | собирает |
| Где | литералы, вызовы | параметры функции, деструктуризация |
| Пример | `fn(...args)` | `function fn(...args) {}` |

## Что важно помнить

- В React spread — основной способ иммутабельного обновления state: `setUser({ ...user, name })`.
- Spread огромного массива в аргументы (`Math.max(...hugeArray)`) может превысить лимит аргументов и стека — используйте `reduce`.
- Порядок важен: `{ ...props, disabled: true }` и `{ disabled: true, ...props }` дают разный результат.
- Spread вызывает итератор, поэтому для больших коллекций он медленнее, чем `slice()` или `Array.from` в горячем коде.

## Мини-шпаргалка

- `[...arr]`, `{ ...obj }`, `fn(...args)`.
- В массивах — любой итерируемый, в объектах — собственные свойства.
- Поздние свойства перезаписывают ранние.
- Копия поверхностная.
- Spread раскладывает, rest собирает.
