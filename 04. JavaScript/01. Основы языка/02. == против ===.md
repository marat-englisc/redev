# `==` против `===`

> [!NOTE]
> `==` сравнивает значения с приведением типов, а `===` сравнивает без приведения типов. В рабочем коде почти всегда лучше использовать `===`.

## Вопрос

В чем разница между операторами `==` и `===`?

## `===` - строгое равенство

`===` проверяет одновременно тип и значение.

```javascript
5 === 5;       // true
5 === "5";     // false
false === 0;   // false
null === undefined; // false
```

Если типы разные, результат сразу `false`. JavaScript не пытается "угадать", что вы имели в виду.

## `==` - нестрогое равенство

`==` перед сравнением может преобразовать значения к другому типу.

```javascript
5 == "5";      // true
false == 0;    // true
"" == 0;       // true
null == undefined; // true
```

Из-за этого `==` иногда выглядит удобным, но часто делает код менее очевидным.

## Наглядный пример

```javascript
const inputValue = "0";

if (inputValue == false) {
  console.log("Сработает");
}

if (inputValue === false) {
  console.log("Не сработает");
}
```

Почему первое условие сработает:

```javascript
"0";       // 0
false;     // 0
"0" == false; // true
```

## Особый случай `null` и `undefined`

```javascript
null == undefined;  // true
null === undefined; // false
```

Это специальное правило нестрогого сравнения. Иногда его используют осознанно:

```javascript
if (value == null) {
  // true для null и undefined
}
```

Но в большинстве случаев понятнее писать явно:

```javascript
if (value === null || value === undefined) {
  // значение отсутствует
}
```

## Практическое правило

- Используйте `===` и `!==` по умолчанию.
- Используйте `==` только тогда, когда точно хотите поведение с приведением типов.
- Не пытайтесь запоминать все странности `==`; лучше писать код так, чтобы они не были нужны.

## Что важно помнить

- `===` не приводит типы, `==` приводит по сложному алгоритму — в коде используйте `===`.
- Единственное общепринятое исключение — `value == null`, которое проверяет `null` и `undefined` сразу.
- `NaN !== NaN` даже при строгом сравнении; для NaN — `Number.isNaN()` или `Object.is()`.
- `Object.is(0, -0)` — `false`, а `0 === -0` — `true`; React сравнивает state через `Object.is`.

## Мини-шпаргалка

| Выражение | Результат | Почему |
| --- | --- | --- |
| `5 === "5"` | `false` | разные типы |
| `5 == "5"` | `true` | строка приводится к числу |
| `0 === false` | `false` | разные типы |
| `0 == false` | `true` | оба приводятся к `0` |
| `null == undefined` | `true` | специальное правило |
| `null === undefined` | `false` | разные типы |
