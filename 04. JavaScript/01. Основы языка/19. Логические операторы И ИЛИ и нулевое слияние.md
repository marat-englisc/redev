# Логические операторы &&, || и ??

> [!NOTE]
> `&&` возвращает первое falsy-значение или последнее значение, если все truthy. `||` возвращает первое truthy-значение или последнее. `??` (nullish coalescing) возвращает правую часть, только если левая равна `null` или `undefined`. Все три работают по короткой схеме: правая часть не вычисляется, если результат уже известен.

## Вопрос

Как работают операторы `&&` и `||`? Что делает оператор `??` и чем он отличается от `||`?

## && — логическое И

```javascript
true && "готово";    // "готово"
0 && "не дойдем";    // 0
null && user.name;   // null — user.name не вычисляется
"a" && "b" && "c";   // "c"
```

Возвращается **не boolean**, а одно из операндов. Используется для условного выполнения:

```javascript
isLoggedIn && showProfile();
```

```jsx
{error && <ErrorMessage text={error} />}
```

## || — логическое ИЛИ

```javascript
"" || "по умолчанию";       // "по умолчанию"
"Анна" || "Гость";          // "Анна"
0 || 10;                     // 10 ⚠️
null || undefined || "есть"; // "есть"
```

`||` подставляет значение по умолчанию для **любого falsy**, поэтому ломается на `0`, `""` и `false`.

## ?? — nullish coalescing

```javascript
0 ?? 10;          // 0
"" ?? "пусто";    // ""
false ?? true;    // false
null ?? "Гость";  // "Гость"
undefined ?? 5;   // 5
```

`??` реагирует только на `null` и `undefined` — «значения нет», а не «значение ложное».

```javascript
const pageSize = settings.pageSize ?? 20;   // 0 останется 0
const title = form.title || "Без названия"; // пустая строка заменится
```

## Сравнение

| Левая часть | `a \|\| b` | `a ?? b` | `a && b` |
| --- | --- | --- | --- |
| `0` | `b` | `0` | `0` |
| `""` | `b` | `""` | `""` |
| `false` | `b` | `false` | `false` |
| `null` | `b` | `b` | `null` |
| `undefined` | `b` | `b` | `undefined` |
| `"текст"` | `"текст"` | `"текст"` | `b` |

## Операторы присваивания

```javascript
options.timeout ??= 5000; // присвоить, только если null/undefined
user.name ||= "Гость";    // присвоить, если falsy
cache.ready &&= isValid;  // присвоить, если truthy
```

## Приоритет и комбинации

`&&` выполняется раньше `||`. Смешивать `??` с `&&` или `||` без скобок запрещено синтаксисом:

```javascript
a || b ?? c;      // SyntaxError
(a || b) ?? c;    // OK
```

## Что важно помнить

- `&&` и `||` возвращают операнд, а не `true`/`false` — для boolean оборачивайте в `Boolean()`.
- В JSX `{count && <Badge />}` выведет `0` при `count === 0` — используйте `count > 0 &&`.
- Для значений по умолчанию числовых и булевых настроек выбирайте `??`.
- Короткая схема важна для побочных эффектов: `ok && save()` вызовет `save` только при truthy `ok`.

## Мини-шпаргалка

- `&&` — первое falsy или последнее.
- `||` — первое truthy или последнее.
- `??` — правое, если левое `null`/`undefined`.
- `0 || 10 → 10`, `0 ?? 10 → 0`.
- `??=`, `||=`, `&&=` — логическое присваивание.
