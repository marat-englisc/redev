# Как проверить, что значение — массив?

> [!NOTE]
> Надежный способ — `Array.isArray(value)`. `typeof [] === "object"`, поэтому `typeof` не отличает массив от объекта. `instanceof Array` не работает для массивов из другого realm (iframe, worker), а `Array.isArray` работает всегда.

## Вопрос

Как проверить, является ли значение массивом? Почему `typeof` не подходит и чем `Array.isArray` лучше `instanceof Array`?

## Array.isArray

```javascript
Array.isArray([]);              // true
Array.isArray([1, 2, 3]);       // true
Array.isArray(new Array(3));    // true
Array.isArray({ length: 2 });   // false — псевдомассив
Array.isArray("abc");           // false
Array.isArray(arguments);       // false
Array.isArray(document.querySelectorAll("li")); // false — NodeList
```

## Почему не typeof

```javascript
typeof [];   // "object"
typeof {};   // "object"
typeof null; // "object"
```

Массив — специальный вид объекта, поэтому `typeof` его не различает.

## Почему не instanceof

```javascript
[] instanceof Array; // true
```

`instanceof` проверяет цепочку прототипов. Массив, созданный в iframe или worker, имеет **другой** `Array.prototype`, и проверка вернет `false`:

```javascript
const iframe = document.createElement("iframe");
document.body.append(iframe);
const ForeignArray = iframe.contentWindow.Array;
const arr = new ForeignArray(1, 2);

arr instanceof Array;   // false
Array.isArray(arr);     // true
```

Кроме того, прототип можно подменить: `Object.setPrototypeOf({}, Array.prototype) instanceof Array` вернет `true`, хотя это не массив.

## Другие способы (исторические)

```javascript
Object.prototype.toString.call([]); // "[object Array]"
```

Работает надежно, но читается хуже — так делали до ES5.

## Проверка на «похожесть» на массив

Если функции подходит любой итерируемый объект, проверяйте не тип, а возможности:

```javascript
const isIterable = (value) => value != null && typeof value[Symbol.iterator] === "function";

const toArray = (value) => Array.from(value); // NodeList, Set, arguments, строка
```

## Что важно помнить

- `Array.isArray` считает массивом и `Array.prototype` — это особенность спецификации.
- Типизированные массивы (`Uint8Array`) — не `Array`: `Array.isArray(new Uint8Array())` — `false`, для них есть `ArrayBuffer.isView()`.
- В TypeScript `Array.isArray` сужает тип до `any[]` — при необходимости уточняйте тип вручную.
- Пустой массив truthy: проверка «массив непустой» — `Array.isArray(v) && v.length > 0`.

## Мини-шпаргалка

- `Array.isArray(value)` — правильный способ.
- `typeof []` — `"object"`.
- `instanceof Array` ломается на других realm.
- Псевдомассивы и NodeList — не массивы, преобразуйте через `Array.from`.
