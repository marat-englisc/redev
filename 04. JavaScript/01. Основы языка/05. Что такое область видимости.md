# Что такое область видимости?

> [!NOTE]
> Область видимости (scope) — часть программы, где доступна переменная. В JavaScript есть глобальная, модульная, функциональная и блочная области. `let`, `const` и `class` видны только внутри блока `{}`, `var` — внутри всей функции. Внутренняя область видит внешние переменные, внешняя внутренние — нет.

## Вопрос

Что такое область видимости в JavaScript? Какие виды областей видимости бывают и чем отличается область видимости `var` от `let` и `const`?

## Виды областей видимости

| Область | Где возникает | Кто в ней живет |
| --- | --- | --- |
| Глобальная | вне функций и модулей в обычном скрипте | `var` и функции становятся свойствами `window` |
| Модульная | файл с `import`/`export` или `type="module"` | все верхнеуровневые объявления модуля |
| Функциональная | тело функции | параметры, `var`, `let`, `const`, вложенные функции |
| Блочная | `{}`, `if`, `for`, `while`, `try` | `let`, `const`, `class` |

```javascript
const appName = "Shop"; // модульная или глобальная

function showCart() {
  const total = 1500;   // функциональная

  if (total > 1000) {
    const discount = 10; // блочная
    console.log(appName, total, discount);
  }

  console.log(discount); // ReferenceError: discount is not defined
}
```

## var и блоки

`var` игнорирует блоки и «протекает» в функцию:

```javascript
function test() {
  if (true) {
    var a = 1;
    let b = 2;
  }
  console.log(a); // 1
  console.log(b); // ReferenceError
}
```

Классическая ловушка с циклом:

```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i)); // 3, 3, 3
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j)); // 0, 1, 2 — новая привязка на каждой итерации
}
```

## Вложенность и затенение

Внутренняя область видит внешние переменные. Если объявить переменную с тем же именем внутри, она **затеняет** (shadowing) внешнюю:

```javascript
const name = "Глобальное";

function greet() {
  const name = "Локальное";
  console.log(name); // "Локальное"
}
```

Поиск переменной идет изнутри наружу по цепочке областей видимости (scope chain) и останавливается на первом совпадении.

## Лексическая область видимости

Область видимости определяется местом **объявления** функции в коде, а не местом вызова:

```javascript
const x = "внешний";

function printX() {
  console.log(x);
}

function run() {
  const x = "внутри run";
  printX(); // "внешний"
}
```

Именно поэтому работают замыкания.

## Что важно помнить

- Объявление без `let`/`const`/`var` в нестрогом режиме создает глобальную переменную; в strict mode это `ReferenceError`.
- В модулях верхнеуровневые переменные не попадают в `window`.
- Функции, объявленные внутри блока, в strict mode имеют блочную область.
- Держите переменные в минимально необходимой области: это уменьшает конфликты имен и упрощает чтение.
- `try { } catch (error) { }` — `error` виден только внутри `catch`.

## Мини-шпаргалка

- Области: глобальная, модульная, функциональная, блочная.
- `let`/`const` — блочные, `var` — функциональный.
- Внутренняя область видит внешнюю, но не наоборот.
- Scope определяется местом объявления (лексически).
- Одинаковое имя внутри затеняет внешнее.
