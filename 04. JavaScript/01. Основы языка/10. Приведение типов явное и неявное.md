# Приведение типов: явное и неявное (type coercion)

> [!NOTE]
> **Приведение типов** — преобразование значения из одного типа в другой. **Явное** выполняет разработчик (`Number()`, `String()`, `Boolean()`), **неявное (coercion)** выполняет движок в операторах `+`, `==`, `-`, `if` и шаблонных строках. Существует три целевых преобразования: к строке, к числу и к логическому значению. Объекты сначала превращаются в примитив через `Symbol.toPrimitive`, `valueOf` или `toString`.

## Вопрос

Что такое type coercion? Чем явное приведение типов отличается от неявного? Почему `[] == false` равно `true`?

## Явное приведение

```javascript
String(123);        // "123"
Number("42");       // 42
Number("");         // 0
Number(" 12 ");     // 12
Number("12px");     // NaN
parseInt("12px");   // 12 — читает до первого нечислового символа
Boolean(0);         // false
Boolean("0");       // true
```

## Правила преобразования

**К числу:**

| Значение | Результат |
| --- | --- |
| `undefined` | `NaN` |
| `null` | `0` |
| `true` / `false` | `1` / `0` |
| `""`, `" "` | `0` |
| `"42"` | `42` |
| `"abc"` | `NaN` |
| `[]` | `0` (через `""`) |
| `[5]` | `5` |
| `{}` | `NaN` |

**К логическому:** `false` дают только `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN` и `false`. Всё остальное, включая `"0"`, `[]` и `{}`, — `true`.

**К строке:** `String(null)` → `"null"`, `String([1, 2])` → `"1,2"`, `String({})` → `"[object Object]"`.

## Неявное приведение

```javascript
"5" + 2;      // "52" — + со строкой склеивает
"5" - 2;      // 3    — остальные арифметические операторы приводят к числу
"5" * "2";    // 10
+"42";        // 42   — унарный плюс как Number()
true + 1;     // 2
[] + [];      // ""
[] + {};      // "[object Object]"
`Итого: ${10}`; // "Итого: 10"

if ("текст") {} // приведение к boolean
```

## Объекты → примитив

Для объекта движок вызывает `Symbol.toPrimitive`, а если его нет — `valueOf()` и `toString()` в порядке, зависящем от подсказки (`"number"` или `"string"`):

```javascript
const price = {
  valueOf() { return 1500; },
  toString() { return "1 500 ₽"; },
};

price * 2;      // 3000
`${price}`;     // "1 500 ₽"
```

## Почему [] == false — true

Алгоритм нестрогого равенства при сравнении с `boolean` сначала приводит всё к числам:

```text
[] == false
[] == 0          // false → 0
"" == 0          // [] → "" (toString)
0 == 0           // "" → 0
true
```

При этом `if ([])` выполнится, потому что в логическом контексте `[]` — truthy. Это показывает, почему `==` опасен.

## Что важно помнить

- Используйте `===`; единственное распространенное исключение — `value == null` для проверки на `null` и `undefined`.
- `NaN` не равен ничему, даже себе: проверяйте через `Number.isNaN()`.
- `null == 0` — `false`, но `null >= 0` — `true`: сравнения `<`, `>` приводят к числу, а `==` для `null` работает по особым правилам.
- `Number()` строже `parseInt()`: `Number("12px")` — `NaN`.
- В TypeScript неявное приведение во многих местах запрещено на уровне типов.

## Мини-шпаргалка

- Явное: `Number()`, `String()`, `Boolean()`, `+x`, `!!x`.
- `+` со строкой → конкатенация, `-`, `*`, `/` → число.
- Falsy: `0`, `""`, `null`, `undefined`, `NaN`, `false`, `0n`.
- Объект → примитив через `Symbol.toPrimitive` / `valueOf` / `toString`.
- `[] == false` → `true` из-за приведения к числу.
