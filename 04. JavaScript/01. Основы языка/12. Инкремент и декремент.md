# Инкремент и декремент

> [!NOTE]
> `++` увеличивает значение на 1, `--` уменьшает на 1. Префиксная форма (`++i`) возвращает новое значение, постфиксная (`i++`) возвращает старое.

## Вопрос

Что такое инкремент и декремент? Чем префиксная форма `++i` отличается от постфиксной `i++`?

## Инкремент

Инкремент увеличивает значение переменной на 1.

```javascript
let count = 1;

count++;

console.log(count); // 2
```

Это короткая форма:

```javascript
count = count + 1;
count += 1;
```

## Декремент

Декремент уменьшает значение переменной на 1.

```javascript
let count = 3;

count--;

console.log(count); // 2
```

## Префиксная форма

Префиксная форма сначала меняет значение, потом возвращает результат.

```javascript
let i = 5;
let result = ++i;

console.log(i);      // 6
console.log(result); // 6
```

## Постфиксная форма

Постфиксная форма сначала возвращает старое значение, потом меняет переменную.

```javascript
let i = 5;
let result = i++;

console.log(i);      // 6
console.log(result); // 5
```

## Когда разницы нет

Если результат выражения не используется, разницы почти нет.

```javascript
let i = 0;

i++;
++i;

console.log(i); // 2
```

В циклах часто пишут `i++`:

```javascript
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

## Когда разница важна

```javascript
let a = 10;
let b = a++ + 5;

console.log(a); // 11
console.log(b); // 15
```

```javascript
let x = 10;
let y = ++x + 5;

console.log(x); // 11
console.log(y); // 16
```

## Подводные камни

Инкремент и декремент изменяют переменную. Это side effect.

```javascript
let i = 1;

const result = i++ + ++i;

console.log(result); // 4
console.log(i);      // 3
```

Такой код лучше не писать в реальных проектах: он заставляет читателя вручную отслеживать порядок операций.

## Что важно помнить

- Префиксный `++x` возвращает новое значение, постфиксный `x++` — старое.
- Для `const` инкремент невозможен — `TypeError`.
- Инкремент строки приводит ее к числу: `let s = "5"; s++` → `6`.
- Многие стайлгайды (`no-plusplus`) предпочитают `x += 1` из-за неочевидности возвращаемого значения.

## Мини-шпаргалка

| Форма | Когда меняет | Что возвращает |
| --- | --- | --- |
| `++i` | до возврата | новое значение |
| `i++` | после возврата | старое значение |
| `--i` | до возврата | новое значение |
| `i--` | после возврата | старое значение |
