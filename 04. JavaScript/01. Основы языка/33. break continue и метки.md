# break, continue и метки (label)

> [!NOTE]
> `break` полностью прерывает ближайший цикл или `switch`. `continue` пропускает остаток текущей итерации и переходит к следующей. **Метка (label)** — имя перед циклом, которое позволяет выйти из внешнего цикла (`break outer`) или перейти к его следующей итерации (`continue outer`) из вложенного.

## Вопрос

Что делают `break` и `continue`? Что такое оператор label и когда он нужен?

## break

```javascript
const users = [{ id: 1 }, { id: 2 }, { id: 3 }];
let found = null;

for (const user of users) {
  if (user.id === 2) {
    found = user;
    break; // дальше искать не нужно
  }
}
```

`break` работает в `for`, `for...of`, `for...in`, `while`, `do...while` и `switch`.

## continue

```javascript
for (const product of products) {
  if (!product.inStock) continue; // пропустить и перейти к следующему
  render(product);
}
```

В `while` `continue` сразу проверяет условие — не забудьте изменить счетчик до него, иначе получится бесконечный цикл.

## Метки

Без метки `break` выходит только из **внутреннего** цикла:

```javascript
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
];

outer: for (const row of matrix) {
  for (const cell of row) {
    if (cell === 5) {
      console.log("Нашли 5");
      break outer; // выход из обоих циклов
    }
  }
}

rows: for (const row of matrix) {
  for (const cell of row) {
    if (cell < 0) continue rows; // следующая строка
  }
}
```

Метка — это идентификатор с двоеточием перед оператором. Ее можно поставить и перед блоком: `block: { ... break block; }`, но так почти не пишут.

## Методы массивов и break

`break` и `continue` не работают внутри `forEach`, `map`, `filter`: там это функции, а не цикл.

```javascript
items.forEach((item) => {
  if (item.done) return; // аналог continue
  // break здесь — SyntaxError
});
```

Для раннего выхода используйте:

- `for...of` с `break`;
- `find`, `findIndex`, `some`, `every` — они сами останавливаются.

## Что важно помнить

- Метки нужны редко; часто код понятнее, если вынести вложенный цикл в функцию и использовать `return`.
- `break` внутри `switch`, вложенного в цикл, выходит только из `switch`.
- `continue` нельзя использовать в `switch` без внешнего цикла.
- Метки не работают через границы функций.

## Мини-шпаргалка

- `break` — выйти из цикла или `switch`.
- `continue` — следующая итерация.
- `label:` + `break label` / `continue label` — управление внешним циклом.
- В `forEach` нет `break` — используйте `for...of`, `some`, `find`.
