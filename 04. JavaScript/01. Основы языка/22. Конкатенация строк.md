# Конкатенация строк

> [!NOTE]
> Конкатенация - это объединение строк. В JavaScript строки можно склеивать через `+`, `+=`, `concat()`, `join()` и template literals.

## Вопрос

Что такое конкатенация строк?

## Через `+`

Самый базовый способ:

```javascript
const firstName = "Anna";
const lastName = "Smith";

const fullName = firstName + " " + lastName;

console.log(fullName); // "Anna Smith"
```

Если хотя бы один операнд - строка, `+` часто превращает второй операнд в строку.

```javascript
"Age: " + 25; // "Age: 25"
"5" + 2;      // "52"
```

## Через `+=`

Можно накапливать строку:

```javascript
let message = "Hello";
message += ", ";
message += "Anna";

console.log(message); // "Hello, Anna"
```

Но для большого количества элементов чаще удобнее массив и `join()`.

## Через template literals

Обычно самый читаемый способ для строк с переменными:

```javascript
const name = "Anna";
const age = 25;

const text = `Имя: ${name}, возраст: ${age}`;
```

Внутри `${...}` можно использовать выражения:

```javascript
const result = `2 + 2 = ${2 + 2}`;
```

## Через `join()`

Для массива строк:

```javascript
const parts = ["Главная", "Каталог", "Ноутбуки"];

parts.join(" / "); // "Главная / Каталог / Ноутбуки"
```

Это удобно, когда количество частей динамическое.

## `concat()`

Метод строк:

```javascript
"Hello".concat(", ", "Anna"); // "Hello, Anna"
```

В современном коде используется реже, потому что `+` и template literals читаются привычнее.

## Подводные камни

Оператор `+` может быть сложением или конкатенацией.

```javascript
1 + 2 + "3"; // "33"
"1" + 2 + 3; // "123"
```

Операции выполняются слева направо:

```javascript
1 + 2 + "3"; // сначала 3, потом "33"
"1" + 2 + 3; // сначала "12", потом "123"
```

## Что важно помнить

- `+` со строкой приводит другой операнд к строке: `"1" + 2 + 3` → `"123"`, а `1 + 2 + "3"` → `"33"`.
- Шаблонные строки читаются лучше, чем цепочки `+`.
- Для сборки больших строк в цикле удобнее массив и `join`.
- Для форматирования чисел и дат используйте `Intl.NumberFormat` и `Intl.DateTimeFormat`, а не ручную конкатенацию.

## Мини-шпаргалка

```javascript
"a" + "b";              // "ab"
`Hello, ${name}`;       // шаблонная строка
parts.join(", ");       // склейка массива
str += "more";          // добавление к строке
"5" + 2;                // "52"
```
