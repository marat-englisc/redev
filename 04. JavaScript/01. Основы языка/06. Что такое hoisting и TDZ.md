# Что такое hoisting и TDZ?

> [!NOTE]
> **Hoisting (всплытие)** — поведение, при котором объявления обрабатываются до выполнения кода области видимости. Function Declaration доступна целиком до объявления, `var` — со значением `undefined`. `let`, `const` и `class` тоже регистрируются заранее, но до строки объявления находятся во **временной мертвой зоне (TDZ)**: обращение к ним бросает `ReferenceError`.

## Вопрос

Что такое всплытие (hoisting)? Что будет, если обратиться к переменной до объявления? Что такое TDZ?

## Как это работает

Перед выполнением функции или модуля движок создает лексическое окружение и регистрирует в нем все объявления. Код физически никуда не «поднимается» — это метафора.

```javascript
console.log(a); // undefined
var a = 5;

console.log(b); // ReferenceError: Cannot access 'b' before initialization
let b = 5;

console.log(c); // ReferenceError: c is not defined — переменной нет вовсе
```

Обратите внимание на разные сообщения: `b` существует, но в TDZ, а `c` не объявлена.

## Таблица поведения

| Объявление | Регистрируется заранее | Значение до строки объявления |
| --- | --- | --- |
| `function f() {}` | да | готовая функция |
| `var x` | да | `undefined` |
| `let x`, `const x` | да | TDZ → `ReferenceError` |
| `class A {}` | да | TDZ → `ReferenceError` |
| `const f = () => {}` | да (как `const`) | TDZ |
| `var f = function () {}` | да (как `var`) | `undefined`, вызов → `TypeError` |
| `import` | да, до выполнения модуля | готовая привязка |

## Функции

```javascript
sayHi(); // "Привет" — Function Declaration доступна заранее

function sayHi() {
  console.log("Привет");
}

sayBye(); // TypeError: sayBye is not a function — var есть, но undefined
var sayBye = function () {
  console.log("Пока");
};
```

## TDZ

Временная мертвая зона длится от начала области видимости до строки объявления:

```javascript
function demo() {
  // начало TDZ для value
  console.log(typeof value); // ReferenceError, даже typeof не спасает
  let value = 10;            // конец TDZ
  console.log(value);        // 10
}
```

TDZ работает и для параметров по умолчанию:

```javascript
function f(a = b, b = 1) {} // ReferenceError: b в TDZ при вычислении a
f();
```

Зачем TDZ: она ловит ошибки использования переменной до инициализации, которые с `var` молча давали `undefined`.

## Затенение и TDZ

```javascript
let x = 1;
{
  console.log(x); // ReferenceError — внутренний x уже существует и в TDZ
  let x = 2;
}
```

## Что важно помнить

- `typeof undeclaredVar` возвращает `"undefined"`, а `typeof` переменной в TDZ бросает ошибку.
- Классы не «всплывают» как функции: использовать класс до объявления нельзя.
- Взаимно рекурсивные Function Declaration работают благодаря hoisting.
- На практике объявляйте переменные до использования и предпочитайте `const`/`let` — тогда hoisting почти не влияет на код.

## Мини-шпаргалка

- Hoisting — регистрация объявлений до выполнения.
- FD доступна полностью, `var` — `undefined`.
- `let`/`const`/`class` — в TDZ до объявления.
- TDZ → `ReferenceError: Cannot access before initialization`.
- Function Expression ведет себя как переменная.
