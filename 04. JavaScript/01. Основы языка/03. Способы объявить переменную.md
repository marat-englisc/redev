# Способы объявить переменную

> [!NOTE]
> В современном JavaScript переменные объявляют через `const` и `let`. `const` используют по умолчанию, `let` - когда значение нужно переназначать, `var` почти всегда избегают.

## Вопрос

Какими способами можно объявить переменную? В чем отличия? Какой способ предпочтительнее?

## `const`

`const` создает переменную, которую нельзя переназначить.

```javascript
const userName = "Anna";
userName = "Kate"; // TypeError
```

Важно: `const` запрещает поменять саму привязку переменной, но не делает объект неизменяемым.

```javascript
const user = { name: "Anna" };
user.name = "Kate"; // можно

user = { name: "Max" }; // нельзя
```

## `let`

`let` создает переменную, которую можно переназначать.

```javascript
let count = 0;
count = count + 1;
count += 1;
```

`let` подходит для счетчиков, временных значений и случаев, где значение действительно меняется.

## `var`

`var` - старый способ объявления переменных.

```javascript
var message = "hello";
```

Главные проблемы `var`:

- имеет функциональную область видимости, а не блочную;
- допускает повторное объявление в одной области;
- всплывает и инициализируется значением `undefined`;
- в глобальной области браузера может стать свойством `window`.

```javascript
if (true) {
  var x = 10;
}

console.log(x); // 10
```

С `let` и `const` такое не пройдет:

```javascript
if (true) {
  const y = 10;
}

console.log(y); // ReferenceError
```

## Сравнение

| Способ | Можно переназначить | Область видимости | Повторное объявление |
| --- | --- | --- | --- |
| `const` | нет | блочная | нет |
| `let` | да | блочная | нет |
| `var` | да | функциональная | да |

## Хорошая практика

```javascript
const users = ["Anna", "Max"]; // ссылка не меняется
let selectedIndex = 0;         // индекс будет меняться

selectedIndex += 1;
```

Так код проще читать: если переменная объявлена через `const`, читатель сразу понимает, что ей не присвоят другое значение.

## Что важно помнить

- По умолчанию используйте `const`, `let` — если значение нужно переназначать, `var` — только в legacy-коде.
- `const` запрещает переназначение переменной, но не изменение объекта или массива.
- `var` имеет функциональную область видимости, всплывает со значением `undefined` и может быть объявлен повторно.
- Повторное объявление `let`/`const` в той же области — `SyntaxError`.

## Мини-шпаргалка

- `const` - выбор по умолчанию.
- `let` - когда нужно переназначение.
- `var` - для старого кода и понимания legacy-проектов.
