# Виды циклов в JavaScript

> [!NOTE]
> В JavaScript есть `for`, `while`, `do...while`, `for...of` и `for...in`. Для массивов часто используют `for`, `for...of` и методы массивов, для объектов - `Object.keys/values/entries`.

## Вопрос

Какие виды циклов есть в JavaScript? Чем они отличаются?

## `for`

Классический цикл со счетчиком.

```javascript
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

Удобен, когда нужен индекс или точный контроль итераций.

## `while`

Выполняется, пока условие truthy.

```javascript
let count = 3;

while (count > 0) {
  console.log(count);
  count--;
}
```

Подходит, когда заранее неизвестно количество повторений.

## `do...while`

Сначала выполняет тело, потом проверяет условие.

```javascript
let answer;

do {
  answer = prompt("Введите yes");
} while (answer !== "yes");
```

Тело выполнится минимум один раз.

## `for...of`

Перебирает значения iterable-объектов.

```javascript
for (const value of [10, 20, 30]) {
  console.log(value);
}
```

Работает с массивами, строками, `Set`, `Map`, NodeList и генераторами.

## `for...in`

Перебирает ключи перечисляемых свойств.

```javascript
const user = { name: "Anna", age: 25 };

for (const key in user) {
  console.log(key, user[key]);
}
```

Для массивов обычно не используют.

## Методы массивов

Вместо циклов часто применяют методы:

```javascript
items.forEach((item) => console.log(item));
const names = users.map((user) => user.name);
const active = users.filter((user) => user.isActive);
```

Они читаются декларативнее, когда нужно преобразование или фильтрация.

## Что важно помнить

- `for` — когда нужен индекс и ранний выход, `for...of` — значения, `for...in` — ключи объекта.
- `forEach` нельзя прервать `break`; для раннего выхода — `for...of`, `some`, `find`.
- `do...while` выполняет тело хотя бы один раз.
- Для асинхронных итераторов есть `for await...of`.

## Мини-шпаргалка

| Цикл | Что перебирает | Когда использовать |
| --- | --- | --- |
| `for` | по счетчику | нужен индекс/контроль |
| `while` | пока условие истинно | неизвестно число повторов |
| `do...while` | минимум один раз | сначала действие, потом проверка |
| `for...of` | значения iterable | массивы, строки, Set, Map |
| `for...in` | ключи объекта | объекты, редко массивы |
