# Циклы for...of и for...in: в чем разница

> [!NOTE]
> `for...of` перебирает **значения** итерируемого объекта: массива, строки, Map, Set, NodeList, генератора. `for...in` перебирает **ключи** (имена перечисляемых свойств) объекта, включая унаследованные. Для массивов почти всегда нужен `for...of` или методы массива, а `for...in` — для обхода ключей обычного объекта (лучше через `Object.keys`).

## Вопрос

Как работают циклы `for...of` и `for...in`? Чем они отличаются и почему `for...in` не рекомендуют для массивов?

## for...of — значения

```javascript
const colors = ["red", "green"];

for (const color of colors) {
  console.log(color); // "red", "green"
}

for (const char of "ok") console.log(char);              // "o", "k"
for (const [key, value] of new Map([["a", 1]])) {}      // пары Map
for (const [index, color] of colors.entries()) {}       // индекс и значение
```

Работает с любым объектом, у которого есть `Symbol.iterator`. Обычный объект не итерируем: `for (const x of { a: 1 })` → `TypeError`.

## for...in — ключи

```javascript
const user = { name: "Анна", age: 25 };

for (const key in user) {
  console.log(key, user[key]); // "name" "Анна", "age" 25
}
```

Перебирает **перечисляемые строковые** ключи, включая свойства из цепочки прототипов. Символы пропускаются.

## Почему не for...in для массивов

```javascript
const arr = [10, 20];
arr.extra = "x";
Array.prototype.custom = () => {};

for (const i in arr) {
  console.log(i, typeof i); // "0" string, "1" string, "extra", "custom"
}
```

- ключи — строки, а не числа;
- попадают собственные нечисловые свойства;
- попадают методы, добавленные в прототип;
- порядок для массивов исторически не гарантировался.

## Сравнение

| | `for...of` | `for...in` |
| --- | --- | --- |
| Что перебирает | значения | ключи |
| Требует | итерируемый объект | любой объект |
| Унаследованные свойства | нет | да |
| Для массивов | да | нет |
| Для объектов | через `Object.entries()` | да, но осторожно |
| `break` / `continue` | да | да |

## Обход объекта правильно

```javascript
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}

for (const key in user) {
  if (!Object.hasOwn(user, key)) continue; // защита от унаследованных
}
```

## Что важно помнить

- `for...of` поддерживает `await`: `for await (const chunk of stream)` — для асинхронных итераторов.
- В `for...of` используйте `const`: на каждой итерации создается новая привязка.
- Изменение массива во время `for...of` (добавление элементов) влияет на обход — избегайте этого.
- В горячем коде классический `for (let i = 0; ...)` может быть быстрее, но обычно читаемость важнее.

## Мини-шпаргалка

- `for...of` — значения итерируемых: массивы, строки, Map, Set.
- `for...in` — ключи объекта, включая унаследованные.
- Массивы — через `for...of`, не через `for...in`.
- Объекты — через `Object.entries()` + `for...of`.
- `for await...of` — для асинхронных итераторов.
