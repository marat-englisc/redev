# Типы данных в JavaScript

> [!NOTE]
> В JavaScript есть 8 типов данных: 7 примитивных и 1 объектный. Примитивы хранят простые значения, а объекты позволяют собирать данные и поведение в структуры.

## Вопрос

Какие типы данных существуют в JavaScript? Сколько их? Дайте краткое объяснение для каждого типа.

## Основная идея

Тип данных отвечает на вопрос: "какого рода значение лежит в переменной и какие операции с ним имеют смысл".

В JavaScript тип принадлежит не переменной, а значению:

```javascript
let value = 42; // сейчас number
value = "Привет"; // теперь string
value = true; // теперь boolean
```

## Примитивные типы

Примитивы обычно сравниваются и передаются по значению. Само примитивное значение нельзя изменить: можно только создать новое значение.

| Тип         | Что означает                                     | Пример                                |
| ----------- | ------------------------------------------------ | ------------------------------------- |
| `number`    | Обычные числа: целые, дробные, `Infinity`, `NaN` | `42`, `3.14`, `NaN`                   |
| `bigint`    | Большие целые числа без потери точности          | `9007199254740993n`                   |
| `string`    | Текстовые значения                               | `"hello"`, `'JS'`, `` `Hi ${name}` `` |
| `boolean`   | Логический тип                                   | `true`, `false`                       |
| `undefined` | Значение не было задано                          | `let x;`                              |
| `null`      | Явно заданное отсутствие значения                | `user = null`                         |
| `symbol`    | Уникальный идентификатор                         | `Symbol("id")`                        |

## Объектный тип

`object` - ссылочный тип. Он используется для сложных структур данных.

```javascript
const user = { name: "Anna", age: 25 };
const numbers = [1, 2, 3];
const date = new Date();
const map = new Map();
function greet() {}
```

Массивы, функции, даты, регулярные выражения и коллекции технически относятся к объектам, хотя имеют свое специальное поведение.

## Наглядный пример

```javascript
const values = [
  42,
  10n,
  "text",
  true,
  undefined,
  null,
  Symbol("key"),
  { id: 1 },
];

for (const value of values) {
  console.log(typeof value);
}
```

Результат будет почти ожидаемым, кроме `null`:

```javascript
typeof null; // "object"
```

Это историческая особенность JavaScript.

## Что важно помнить

- `typeof` возвращает строку с типом значения.
- `typeof null` возвращает `"object"`, но `null` не является объектом.
- Массивы дают `typeof [] === "object"`, поэтому массивы проверяют через `Array.isArray(value)`.
- Функции дают `typeof fn === "function"`, хотя в JavaScript функции тоже являются объектами.
- `NaN` имеет тип `number`.

## Мини-шпаргалка

```javascript
typeof 123; // "number"
typeof 123n; // "bigint"
typeof "hello"; // "string"
typeof true; // "boolean"
typeof undefined; // "undefined"
typeof null; // "object"
typeof Symbol("x"); // "symbol"
typeof {}; // "object"
typeof []; // "object"
typeof function () {}; // "function"
```
