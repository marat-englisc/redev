# Разница между `null` и `undefined`

> [!NOTE]
> `undefined` обычно означает "значение не было задано", а `null` - "значение специально отсутствует". `undefined` часто появляется автоматически, `null` обычно ставит сам разработчик.

## Вопрос

В чем разница между `null` и `undefined`? Когда использовать один тип, а когда другой?

## `undefined`

`undefined` появляется, когда JavaScript не находит значения.

```javascript
let name;
console.log(name); // undefined
```

Типичные ситуации:

```javascript
const user = {};

user.name; // undefined - свойства нет

function greet(name) {
  console.log(name);
}

greet(); // undefined - аргумент не передали

function getValue() {}

getValue(); // undefined - нет return
```

## `null`

`null` используют, когда нужно явно сказать: "значения нет".

```javascript
let selectedUser = null;

// позже
selectedUser = { id: 1, name: "Anna" };

// сбросили выбор
selectedUser = null;
```

`null` часто встречается в API, базах данных и JSON, потому что JSON поддерживает `null`, но не поддерживает `undefined`.

```javascript
JSON.stringify({ a: null, b: undefined });
// '{"a":null}'
```

## Сравнение

| Значение | Смысл | Кто обычно ставит |
| --- | --- | --- |
| `undefined` | не задано, не найдено, не вернули | JavaScript |
| `null` | специально пусто | разработчик |

## Проверки

```javascript
undefined === null; // false
undefined == null;  // true
```

Если нужно проверить оба варианта отсутствия значения:

```javascript
if (value === null || value === undefined) {
  console.log("Значения нет");
}
```

Короткая форма:

```javascript
if (value == null) {
  console.log("null или undefined");
}
```

Такой вариант допустим, если команда осознанно использует это правило.

## Подводные камни

```javascript
typeof undefined; // "undefined"
typeof null;      // "object"
```

`typeof null === "object"` - историческая особенность. Проверять `null` лучше так:

```javascript
value === null;
```

## Практическое правило

- Не присваивайте `undefined` вручную без необходимости.
- Используйте `null`, когда хотите явно показать отсутствие значения.
- Для параметров функций чаще используйте значения по умолчанию.

```javascript
function createUser(name = "Гость") {
  return { name };
}
```

## Что важно помнить

- `undefined` — значение по умолчанию от движка, `null` — явное «пусто» от разработчика.
- `null == undefined` — `true`, но `null === undefined` — `false`.
- `JSON.stringify` пропускает свойства с `undefined`, а `null` сохраняет — это важно для API.
- Параметры по умолчанию и деструктуризация с default срабатывают только на `undefined`, но не на `null`.
- `Number(null)` — `0`, `Number(undefined)` — `NaN`.

## Мини-шпаргалка

| Проверка | Результат |
| --- | --- |
| `typeof undefined` | `"undefined"` |
| `typeof null` | `"object"` |
| `null === undefined` | `false` |
| `null == undefined` | `true` |
| `value === null` | точная проверка на `null` |
| `value === undefined` | точная проверка на `undefined` |
| `value == null` | проверка на `null` или `undefined` |
