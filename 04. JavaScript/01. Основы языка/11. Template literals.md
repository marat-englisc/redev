# Template literals

> [!NOTE]
> Template literals - это строки в обратных кавычках. Они поддерживают интерполяцию через `${...}`, многострочный текст и tagged templates.

## Вопрос

Что такое шаблонные строки (template literals)? Что такое tagged templates?

## Обычные template literals

Шаблонная строка записывается в обратных кавычках:

```javascript
const name = "Anna";
const message = `Привет, ${name}!`;

console.log(message); // "Привет, Anna!"
```

Внутри `${...}` можно использовать любое выражение:

```javascript
const a = 5;
const b = 10;

console.log(`${a} + ${b} = ${a + b}`);
// "5 + 10 = 15"
```

## Многострочные строки

В template literals переносы строк сохраняются.

```javascript
const html = `
  <article>
    <h2>Заголовок</h2>
    <p>Текст статьи</p>
  </article>
`;
```

Без шаблонных строк такой код пришлось бы собирать через `\n` или конкатенацию.

## Сравнение с конкатенацией

```javascript
const firstName = "Anna";
const age = 25;

const oldWay = "Имя: " + firstName + ", возраст: " + age;
const newWay = `Имя: ${firstName}, возраст: ${age}`;
```

Второй вариант читается ближе к итоговой строке.

## Tagged templates

Tagged template - это вызов функции перед шаблонной строкой.

```javascript
function tag(strings, ...values) {
  console.log(strings);
  console.log(values);
}

const name = "Anna";
const age = 25;

tag`Пользователь ${name}, возраст ${age}`;
```

Функция получит:

```javascript
strings; // ["Пользователь ", ", возраст ", ""]
values;  // ["Anna", 25]
```

## Зачем нужны tagged templates

Tagged templates позволяют контролировать сборку строки:

- экранировать HTML;
- собирать SQL-запросы безопаснее;
- делать форматирование;
- создавать маленькие DSL;
- работать с локализацией.

Пример форматирования:

```javascript
function currency(strings, value) {
  return `${strings[0]}${value.toFixed(2)} ₽`;
}

const price = 1999;

currency`Цена: ${price}`; // "Цена: 1999.00 ₽"
```

## `strings.raw`

У массива `strings` есть свойство `raw`, где хранятся "сырые" части строки.

```javascript
function show(strings) {
  console.log(strings[0]);
  console.log(strings.raw[0]);
}

show`line\nbreak`;
```

`strings[0]` увидит настоящий перенос строки, а `strings.raw[0]` - символы `\` и `n`.

## Что важно помнить

- Внутри `${}` можно писать любое выражение, а результат приводится к строке.
- Теговые шаблоны (`` tag`...` ``) получают части строки и значения отдельно — на них построены styled-components, `graphql` и `String.raw`.
- Многострочные шаблоны сохраняют отступы и переносы — учитывайте это при генерации HTML и SQL.
- Интерполяция не экранирует HTML: вставка пользовательских данных в `innerHTML` через шаблон — XSS.

## Мини-шпаргалка

```javascript
`Hello`;                 // строка
`Hello, ${name}`;        // интерполяция
`2 + 2 = ${2 + 2}`;      // выражение
`first line
second line`;            // многострочность
tag`value: ${value}`;    // tagged template
```
