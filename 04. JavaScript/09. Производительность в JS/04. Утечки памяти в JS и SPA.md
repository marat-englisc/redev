# Утечки памяти в JS и SPA: таймеры, слушатели, замыкания

> [!NOTE]
> **Утечка памяти** — ситуация, когда объекты больше не нужны, но остаются достижимыми, и сборщик мусора не может их удалить. Память растет, страница замедляется и может упасть. В SPA утечки особенно опасны, потому что страница не перезагружается: незакрытые таймеры и интервалы, неудаленные обработчики событий, подписки, отсоединенные DOM-узлы, растущие кеши и замыкания, удерживающие большие данные.

## Вопрос

Что такое утечка памяти в JavaScript? Какие утечки типичны для SPA и как с ними связаны таймеры и слушатели событий?

## Почему возникают

Сборщик мусора удаляет объекты, недостижимые от корней (глобальный объект, стек, активные замыкания). Утечка — это случайная ссылка, которая держит объект «живым».

## Типичные источники

| Источник | Пример |
| --- | --- |
| Таймеры | `setInterval` не очищен после ухода со страницы |
| Слушатели событий | `window.addEventListener("resize", ...)` без удаления |
| Подписки | WebSocket, EventSource, store, observable без отписки |
| Отсоединенные DOM-узлы | удаленный элемент сохранен в переменной или Map |
| Растущие кеши | `Map` без лимита и очистки |
| Замыкания | колбэк держит ссылку на большой объект |
| Глобальные переменные | случайный `window.data = hugeArray` |
| Observers | `IntersectionObserver`, `ResizeObserver` без `disconnect()` |

## Таймеры и слушатели

```javascript
// утечка: интервал живет вечно и держит в замыкании компонент и данные
function startPolling(widget) {
  setInterval(() => widget.update(), 1000);
}

// правильно: возвращаем функцию очистки
function startPolling(widget) {
  const id = setInterval(() => widget.update(), 1000);
  return () => clearInterval(id);
}
```

```javascript
// React
useEffect(() => {
  const onResize = () => setWidth(window.innerWidth);
  window.addEventListener("resize", onResize);
  const id = setInterval(refresh, 5000);
  const controller = new AbortController();
  fetch(url, { signal: controller.signal });

  return () => {
    window.removeEventListener("resize", onResize);
    clearInterval(id);
    controller.abort();
  };
}, []);
```

Каждый эффект, который подписывается, должен отписываться в cleanup. В Strict Mode React специально монтирует эффекты дважды, чтобы выявить отсутствие очистки.

## Отсоединенные DOM-узлы

```javascript
const cache = [];
function openModal() {
  const modal = document.createElement("div");
  document.body.append(modal);
  cache.push(modal);     // ссылка сохраняется
  modal.remove();        // узел удален из DOM, но не из памяти
}
```

Используйте `WeakMap`/`WeakSet` для данных, привязанных к DOM, и очищайте ссылки при удалении.

## Кеши

```javascript
const cache = new Map();           // растет бесконечно
function getUser(id) {
  if (!cache.has(id)) cache.set(id, fetchUser(id));
  return cache.get(id);
}
```

Решения: лимит размера (LRU), TTL, `WeakMap` для ключей-объектов, библиотеки с управлением кешем (TanStack Query с `gcTime`).

## Как найти утечку

1. DevTools → **Memory** → Heap snapshot до и после сценария (открыть и закрыть страницу несколько раз).
2. Сравнить снимки (Comparison) — что выросло.
3. Найти **Detached** DOM-узлы и путь удержания (Retainers).
4. Вкладка **Performance** с галочкой Memory показывает график роста кучи.
5. `performance.measureUserAgentSpecificMemory()` — измерение памяти в production (cross-origin isolated страницы).

## Что важно помнить

- Рост памяти после действия — нормально; утечка — когда память не возвращается после сборки мусора (кнопка Collect garbage в DevTools).
- Замыкание держит не только используемые переменные, но иногда и весь контекст — не храните большие данные в долгоживущих колбэках.
- Опция `{ signal }` в `addEventListener` упрощает массовое удаление обработчиков.
- В Node.js утечки находят через `--inspect` и heap snapshots, а также следят за `process.memoryUsage()`.

## Мини-шпаргалка

- Утечка — ненужный объект остается достижимым.
- SPA: таймеры, слушатели, подписки, detached DOM, кеши.
- Каждой подписке — отписка, в React — cleanup в `useEffect`.
- Для данных по объектам — `WeakMap`/`WeakSet`.
- Поиск — Heap snapshots и Detached nodes в DevTools.
