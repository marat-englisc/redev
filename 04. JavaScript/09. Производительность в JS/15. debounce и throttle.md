# debounce и throttle

> [!NOTE]
> **Debounce** откладывает вызов функции, пока события не прекратятся на заданное время: при наборе текста запрос уйдет только через 300 мс после последнего нажатия. **Throttle** ограничивает частоту: функция вызывается не чаще одного раза за интервал, даже если события идут непрерывно — например, обработчик прокрутки раз в 100 мс. Оба приема защищают от лишних вызовов при частых событиях.

## Вопрос

Что делают debounce и throttle? Чем они отличаются, где применяются и как их реализовать?

## Debounce

```javascript
function debounce(fn, delay) {
  let timerId;
  return function (...args) {
    clearTimeout(timerId);
    timerId = setTimeout(() => fn.apply(this, args), delay);
  };
}

const search = debounce((query) => {
  fetch(`/api/search?q=${encodeURIComponent(query)}`);
}, 300);

input.addEventListener("input", (event) => search(event.target.value));
```

```text
события: x x x x x       x x
вызовы:            ✔          ✔   (через delay после последнего события)
```

Варианты: **trailing** (вызов в конце паузы, по умолчанию) и **leading** (вызов сразу, затем игнорирование до паузы).

## Throttle

```javascript
function throttle(fn, interval) {
  let lastCall = 0;
  let timerId;
  return function (...args) {
    const now = Date.now();
    const remaining = interval - (now - lastCall);
    if (remaining <= 0) {
      lastCall = now;
      fn.apply(this, args);
    } else {
      clearTimeout(timerId);
      timerId = setTimeout(() => {   // гарантированный последний вызов
        lastCall = Date.now();
        fn.apply(this, args);
      }, remaining);
    }
  };
}

window.addEventListener("scroll", throttle(updateProgressBar, 100), { passive: true });
```

```text
события: x x x x x x x x x x x
вызовы:  ✔     ✔     ✔     ✔      (не чаще раза в interval)
```

## Сравнение

| | Debounce | Throttle |
| --- | --- | --- |
| Когда вызывает | после паузы в событиях | регулярно, не чаще интервала |
| При непрерывных событиях | может не вызвать ни разу до остановки | вызывает периодически |
| Применение | поиск, автосохранение, валидация, resize-перерасчет | scroll, mousemove, drag, прогресс, бесконечная лента |

## Где применяются при запросах

- поиск и автодополнение — debounce, чтобы не отправлять запрос на каждую букву;
- автосохранение черновика — debounce;
- подгрузка ленты при прокрутке — throttle или `IntersectionObserver`;
- защита кнопки от двойного клика — блокировка кнопки или leading debounce.

Даже с debounce ответы могут прийти не по порядку — отменяйте предыдущий запрос через `AbortController`.

## React

```jsx
function SearchBox() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebouncedValue(query, 300);

  useEffect(() => {
    if (!debouncedQuery) return;
    const controller = new AbortController();
    fetch(`/api/search?q=${debouncedQuery}`, { signal: controller.signal });
    return () => controller.abort();
  }, [debouncedQuery]);

  return <input value={query} onChange={(e) => setQuery(e.target.value)} />;
}

function useDebouncedValue(value, delay) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}
```

Если создавать debounce-функцию прямо в теле компонента, она пересоздается при каждом рендере и перестает работать — оборачивайте в `useMemo`/`useRef` или используйте debounced value.

## Что важно помнить

- Реализации из lodash (`debounce`, `throttle`) поддерживают `leading`, `trailing`, `maxWait` и метод `cancel`.
- Для анимаций и измерений при прокрутке лучше `requestAnimationFrame` — естественный throttle по кадрам.
- `useDeferredValue` в React — альтернатива debounce для тяжелого рендера (без задержки по времени).
- Не забывайте отменять отложенный вызов при размонтировании.

## Мини-шпаргалка

- Debounce — после паузы; throttle — не чаще интервала.
- Debounce: поиск, автосохранение. Throttle: scroll, mousemove.
- Реализация на `setTimeout` и замыкании.
- В React — debounced value или `useMemo` для функции.
- Ответы запросов — отменяйте через `AbortController`.
