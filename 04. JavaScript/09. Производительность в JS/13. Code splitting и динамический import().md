# Code splitting и динамический import()

> [!NOTE]
> **Code splitting** — разделение бандла на части (чанки), которые загружаются по мере необходимости, а не все сразу. Основной механизм — **динамический `import()`**: он возвращает Promise с модулем, и сборщик (Vite, webpack) автоматически выносит этот модуль в отдельный файл. Так делят код по маршрутам, тяжелым компонентам и редким функциям, уменьшая объем JS при первой загрузке.

## Вопрос

Что такое code splitting? Как работает динамический `import()` и как разделить код в React и Next.js?

## Динамический import()

```javascript
// статический импорт — модуль попадет в основной бандл
import { formatDate } from "./utils/date.js";

// динамический — отдельный чанк, загрузка по требованию
button.addEventListener("click", async () => {
  const { exportToPdf } = await import("./export-pdf.js");
  exportToPdf(report);
});
```

- `import()` — выражение, а не инструкция: работает в любом месте кода, в условиях и обработчиках;
- возвращает Promise с объектом модуля (`{ default, ...named }`);
- путь может быть вычисляемым, но сборщику нужна подсказка (`import(\`./locales/${lang}.js\`)` создаст чанк на каждый файл папки);
- работает в обычных скриптах, не только в модулях.

## Стратегии разделения

| Стратегия | Пример |
| --- | --- |
| По маршрутам | каждая страница — свой чанк |
| По компонентам | модалка, редактор, график, карта |
| По функциям | экспорт в PDF, парсер Excel |
| По условиям | полифилы только для старых браузеров, локали по языку |
| Vendor chunks | редко меняющиеся библиотеки отдельно для кеша |

## React

```jsx
import { lazy, Suspense } from "react";

const Chart = lazy(() => import("./Chart"));
const Settings = lazy(() => import("./pages/Settings"));

function Dashboard() {
  return (
    <Suspense fallback={<Spinner />}>
      <Chart data={data} />
    </Suspense>
  );
}
```

`React.lazy` требует default-экспорт. Для именованных: `lazy(() => import("./Chart").then((m) => ({ default: m.Chart })))`.

## Next.js

```jsx
import dynamic from "next/dynamic";

const Map = dynamic(() => import("./Map"), {
  ssr: false,                       // только на клиенте (например, Leaflet)
  loading: () => <p>Загрузка карты...</p>,
});
```

App Router автоматически делит код по маршрутам; Server Components вообще не попадают в клиентский бандл.

## Предзагрузка

```javascript
// начать загрузку заранее, например при наведении
link.addEventListener("mouseenter", () => import("./pages/Settings"), { once: true });
```

```html
<link rel="modulepreload" href="/assets/settings.js">
```

Webpack поддерживает «магические комментарии»: `import(/* webpackPrefetch: true */ "./Settings")`.

## Что важно помнить

- Слишком мелкие чанки ухудшают загрузку: много запросов и водопады; делите по смысловым границам.
- Ленивая загрузка добавляет задержку при первом использовании — показывайте fallback и предзагружайте вероятные переходы.
- Ошибка загрузки чанка (новый деплой удалил старые файлы) — обрабатывайте через Error Boundary и предлагайте перезагрузку.
- Code splitting уменьшает стартовый JS и улучшает LCP и INP, но не заменяет удаление ненужного кода (tree shaking).

## Мини-шпаргалка

- Code splitting — делить бандл на чанки по требованию.
- `import()` → Promise с модулем, отдельный чанк.
- React: `lazy` + `Suspense`; Next.js: `next/dynamic`.
- Делить по маршрутам и тяжелым компонентам.
- Предзагрузка: `import()` по наведению, `modulepreload`.
