# Что такое “lazy loading”?

> [!NOTE]
> Lazy loading - отложенная загрузка ресурса до момента, когда он действительно нужен.

## Вопрос

Что такое lazy loading и зачем его используют?

## Определение

Lazy loading уменьшает начальную загрузку страницы. Вместо того чтобы сразу загружать все изображения, модули и данные, приложение загружает только необходимое для текущего экрана, а остальное - позже.

## Изображения

```html
<img src="photo.jpg" loading="lazy" alt="Photo">
```

Браузер может отложить загрузку изображения, пока оно не приблизится к области просмотра.

## JavaScript-модуль

```javascript
button.addEventListener('click', async () => {
  const module = await import('./heavy-module.js');

  module.run();
});
```

Код тяжелого модуля загрузится только после клика.

## Данные

```javascript
async function openDetails(id) {
  const details = await fetchDetails(id);
  renderDetails(details);
}
```

Подробности можно загрузить при открытии карточки, а не при первом рендере списка.

## Плюсы и минусы

| Плюсы | Минусы |
| --- | --- |
| быстрее старт | возможная задержка при первом открытии |
| меньше начальный JS | сложнее управление состоянием загрузки |
| экономия трафика | нужно обрабатывать loading/error |

## Что важно помнить

- Ленивая загрузка уменьшает стартовый объем, но не применяйте ее к контенту первого экрана.
- Для изображений — `loading="lazy"`, для кода — динамический `import()`, для данных — загрузка по прокрутке.
- Показывайте fallback и резервируйте место, чтобы не было layout shift.
- Предзагружайте то, что пользователь скорее всего откроет (prefetch при наведении).

## Мини-шпаргалка

```javascript
const module = await import('./module.js');
```
