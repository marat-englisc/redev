# re:front

SPA для чтения уроков из родительской папки (`../*.md`) с прогрессом и интервальным повторением FSRS.

**Стек:** Next.js 16 (static export) · TypeScript · Redux Toolkit · Tailwind CSS 4 · shadcn/ui (Base UI) · unified/remark/rehype + Shiki · ts-fsrs.

## Как это устроено

- При сборке `src/lib/content.ts` обходит папку конспекта и строит дерево разделов → тем → уроков.
  URL берётся из номеров в именах: `04. JavaScript/01. Основы языка/03. ….md` → `/l/04/01/03/`.
- `src/lib/markdown.ts` превращает markdown в HTML: GFM-таблицы, Obsidian-каллауты (`> [!NOTE]`, сворачиваемые `> [!TIP]-`),
  монохромная подсветка кода (Shiki + CSS-переменные), переписывание относительных ссылок между заметками.
- Каждый урок — карточка FSRS: вопрос = заголовок + секция «Вопрос», ответ = каллаут `[!NOTE]`. Все карточки собираются в `/cards.json`.
- Весь прогресс (изученные уроки, карточки, история повторений, настройки) — в Redux, сохраняется в `localStorage` (`konspekt:v1`).
  В «Настройках» есть экспорт/импорт JSON.
- id урока — хеш пути **без номеров**, поэтому перенумерация файлов не сбрасывает прогресс (переименование — сбрасывает).

## Команды

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # статический сайт в out/
npm run preview   # раздать out/ локально
```

Путь к конспекту можно переопределить переменной `CONTENT_DIR`.

## Деплой на GitHub Pages

1. Создайте репозиторий из папки `Frontend` (корень — папка с уроками, сайт — в `site/`).
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. Пуш в `main` запускает `.github/workflows/deploy.yml`: он сам подставит `NEXT_PUBLIC_BASE_PATH=/<repo>`.

Горячие клавиши: `Ctrl K` или `/` — поиск, на экране повторения `Space` — показать ответ / «Хорошо», `1–4` — оценка, `Ctrl Z` — отменить.
