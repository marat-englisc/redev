# Карта раздела Linux

> [!NOTE]
> Раздел ведёт от первого входа в терминал к самостоятельной работе с Linux-сервером на уровне Junior+ / pre-middle. Последовательность: среда → файлы и shell → текст и права → процессы и службы → ресурсы и сеть → SSH и автоматизация → безопасность и диагностика. В разделе 67 учебных уроков и эта карта; итог — работающий стенд, проверенный backup и объяснимые решения типовых инцидентов.

## Вопрос

В каком порядке изучать Linux с нуля и что нужно уметь для Junior+ / pre-middle?

## Как проходить раздел

Читай по порядку и повторяй примеры в собственной среде. Короткий ответ в начале — опора для карточки и устного интервью; основной текст объясняет механизм, а практика проверяет понимание. Сначала попробуй задание сам, затем сравни результат с разбором.

На сайте доступны обычные для проекта прогресс, поиск и повторение карточек. Блоки Bash выполняются в Linux-терминале: веб-песочница для JavaScript не заменяет ОС.

## Среда и границы курса

- Основной стенд — отдельная Ubuntu/Debian VM с Bash, GNU-утилитами и systemd. WSL 2 подходит для большей части курса; поддержку systemd проверяют отдельно.
- Рабочая папка — `~/linux-lab`; примеры по возможности создают собственные данные и показывают ожидаемый результат.
- Системные лабораторные требуют sudo, отдельной VM и возможности восстановить её состояние. Команды не нужно выполнять на рабочем production-сервере.
- Утилиты вроде dig, lsof, strace, rsync и ShellCheck могут требовать установки. Различия дистрибутивов отмечены в уроках.
- Уровень курса — разработчик или начинающий инженер, способный сопровождать свой сервис. Разработка ядра, сложная маршрутизация, глубокое администрирование SELinux и кластерных хранилищ остаются за рамками.

## Контрольные точки

### После основ

- [ ] Создаю и нахожу файлы с пробелами и дефисами в именах.
- [ ] Объясняю, что shell передаст программе после раскрытия переменных и glob.
- [ ] Разделяю stdout и stderr, проверяю результат конвейера.
- [ ] Получаю отчёт из простого лога и восстанавливаю tar-архив.

### После уровня Junior

- [ ] Проверяю UID, группы, права всех компонентов пути и umask.
- [ ] Нахожу нужный PID и выбираю корректный способ остановки.
- [ ] Различаю пакет, репозиторий, библиотеку и интерпретатор.
- [ ] Умею прочитать man и объяснить ошибку до применения sudo.

### После Junior+ / pre-middle

- [ ] Сопровождаю свою systemd-службу: unit, окружение, журнал и проверка HTTP.
- [ ] Локализую сетевую проблему по слоям и понимаю границы каждой команды.
- [ ] Разбираю расхождение df/du, давление памяти, OOM и высокий load.
- [ ] Пишу Bash без потери границ аргументов и проверяю сценарии отказа.
- [ ] Проверяю backup восстановлением и сохраняю способ отката изменения.
- [ ] Решаю лабораторные без копирования готового разбора.

## Если готовишься к интервью

Пройди итоговую подборку вопросов, отметь слабые темы и вернись к соответствующим урокам. Отвечай по схеме: понятие → пример → команда проверки → интерпретация → ограничение вывода. Для ситуационной задачи проговори гипотезу прежде, чем предлагать изменение системы.
