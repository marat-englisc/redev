# Как устроены каталоги Linux - FHS, proc, sys и dev

> [!NOTE]
> В Linux единое дерево путей с корнем `/`. `/etc` содержит системные настройки, `/home` — домашние каталоги, `/var` — изменяемые данные, `/usr` — установленное ПО. `/proc`, `/sys` и `/dev` предоставляют интерфейсы к процессам, ядру и устройствам; они не являются обычными папками документов на диске.

## Вопрос

Где искать конфигурацию службы, её логи, пользовательские файлы и информацию о процессе?

## Карта файловой системы

| Путь | Обычное назначение | Пример |
| --- | --- | --- |
| `/` | Корень всего дерева | Начало абсолютного пути |
| `/home/alex` | Личные файлы пользователя | Код, настройки shell |
| `/root` | Домашний каталог root | Не то же самое, что `/` |
| `/etc` | Системные настройки | `/etc/ssh/sshd_config` |
| `/usr/bin`, `/usr/lib` | Команды и библиотеки | `/usr/bin/grep` |
| `/var/log`, `/var/lib` | Логи и состояние служб | Журналы, данные БД |
| `/run` | Данные текущей загрузки | PID-файлы, сокеты |
| `/tmp` | Временные файлы | Данные могут очищаться |
| `/srv`, `/opt` | Данные сервисов, дополнительное ПО | Размещение учебного приложения |
| `/mnt`, `/media` | Точки монтирования | Подключённые файловые системы |

На многих системах `/bin`, `/sbin` и `/lib` — символические ссылки в `/usr`. Проверять структуру полезнее, чем предполагать, что все дистрибутивы полностью одинаковы.

## Псевдофайловые системы

```bash
cat /proc/meminfo | head -n 5
readlink /proc/self/exe
ls /sys/class/net
ls -l /dev/null
findmnt /proc
```

Чтение `/proc/meminfo` получает сведения о памяти от ядра. `/dev/null` принимает и отбрасывает записанные данные. `/sys/class/net` показывает сетевые интерфейсы. Многие такие объекты создаются динамически, а запись в некоторые из них меняет состояние системы.

## Важное следствие

Диск или раздел подключается **в каталог**. Например, домашние каталоги могут находиться на отдельной файловой системе, смонтированной в `/home`. Поэтому свободное место в `/` ещё не гарантирует свободное место в `/home`.

Не храни постоянные данные в `/tmp` и `/run`. Не редактируй файлы в `/usr` вручную без причины: ими обычно управляет менеджер пакетов.

## Практика

Найди свой домашний каталог через `printf '%s\n' "$HOME"`. Выполни `findmnt -T "$HOME"` и выясни, какая файловая система его содержит. Проверь `ls -ld /bin`, чтобы увидеть, является ли путь ссылкой.
