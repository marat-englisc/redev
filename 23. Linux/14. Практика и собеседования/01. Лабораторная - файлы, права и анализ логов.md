# Лабораторная - файлы, права и анализ логов

> [!NOTE]
> Итог базового блока — самостоятельно создать рабочую папку, обработать файлы с пробелами, ограничить доступ, построить отчёт по логу и проверить восстановление архива. Успех определяется наблюдаемым результатом, а не количеством введённых команд. Все действия этой лабораторной выполняются обычным пользователем в отдельном каталоге.

## Вопрос

Как собрать небольшой отчёт по запросам сервера и сохранить проверяемую копию результатов?

## Подготовка

Нужны Bash, GNU-утилиты и tar. Используй новый каталог `~/linux-lab/final-files`, чтобы результаты прошлых опытов не влияли на упражнение.

```bash
mkdir -p "$HOME/linux-lab/final-files/input" "$HOME/linux-lab/final-files/reports"
cd "$HOME/linux-lab/final-files"
cat > 'input/access sample.log' <<'EOF'
anna 200 10
ivan 500 70
anna 200 20
oleg 404 15
anna 502 90
EOF
```

Формат: пользователь, HTTP-статус, время в миллисекундах. Данные заранее корректны: это не универсальный парсер production-лога.

## Задания

1. Убедись, что создан **один** файл с пробелом в имени.
2. Установи `700` на reports, `600` на исходный лог.
3. Сохрани строки 5xx в `reports/errors.log`.
4. Построй частоты запросов по пользователям.
5. Посчитай среднее время всех запросов и среднее только ошибок 5xx.
6. Создай архив input и reports вне этих папок, восстанови в отдельный каталог и сравни.

## Ожидаемый результат

| Проверка | Результат |
| --- | --- |
| Число исходных строк | 5 |
| Число строк 5xx | 2 |
| Запросы anna / ivan / oleg | 3 / 1 / 1 |
| Среднее время всех | 41 мс |
| Среднее время 5xx | 80 мс |

## Разбор решения

```bash
chmod 700 reports
chmod 600 'input/access sample.log'
awk '$2 >= 500 && $2 < 600' 'input/access sample.log' > reports/errors.log
awk '{ print $1 }' 'input/access sample.log' | sort | uniq -c | sort -nr > reports/users.txt
awk '{ sum += $3 } END { if (NR) print sum / NR }' 'input/access sample.log'
awk '$2 >= 500 && $2 < 600 { sum += $3; count++ } END { if (count) print sum / count }' 'input/access sample.log'
tar -czf result.tar.gz input reports
mkdir restored
tar -xzf result.tar.gz -C restored
diff -r input restored/input
diff -r reports restored/reports
```

Для повторного запуска используй новый пустой каталог восстановления. `diff -r` проверяет содержимое, а сохранение прав проверь отдельно через `stat`.
