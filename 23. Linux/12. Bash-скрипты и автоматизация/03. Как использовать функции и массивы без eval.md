# Как использовать функции и массивы без eval

> [!NOTE]
> Функция Bash группирует команды, принимает аргументы как `$1` и `"$@"`, возвращает статус через return, а данные — через stdout или согласованный другой канал. `local` ограничивает область переменной функцией по правилам Bash. Массив хранит список аргументов; `"${args[@]}"` передаёт их без повторного разбора. Строка с командой и eval обычно создают лишнюю сложность и риск исполнения данных как кода.

## Вопрос

Как собрать команду с необязательными опциями и путями с пробелами? Почему return не подходит для возврата строки?

## Функция со статусом

```bash
require_file() {
  local file=$1
  if [[ ! -f "$file" ]]; then
    printf 'Not a regular file: %s\n' "$file" >&2
    return 1
  fi
}

if require_file 'report final.txt'; then
  printf 'Ready\n'
fi
```

Функция получает аргументы независимо от аргументов внешнего скрипта. `return 1` сообщает исход; для строки нужно, например, `printf`, который вызывающий код может получить через `$(...)`. При этом подстановка удалит завершающие переводы строк.

## Массив аргументов

```bash
pattern='ERROR'
files=('first app.log' 'second app.log')
args=(-n -F -- "$pattern")
grep "${args[@]}" "${files[@]}"
```

Даже если в имени есть пробел, оно остаётся одним аргументом. `--` заканчивает опции grep перед шаблоном. Команда не будет работать до создания обоих учебных файлов — это фрагмент построения аргументов, а не подготовка данных.

Склеивание `cmd="grep $options $pattern $files"` теряет границы. Последующий `eval "$cmd"` повторно трактует shell-синтаксис: данные способны превратиться в команды.

## Индексированные и ассоциативные массивы

```bash
names=('anna' 'ivan')
printf '%s\n' "${names[0]}"
printf '%s\n' "${names[@]}"
declare -A status=([api]=ok [db]=unknown)
printf '%s\n' "${status[api]}"
```

Ассоциативные массивы требуют Bash 4+; `/bin/sh` не поддерживает Bash-массивы. Если используешь эти возможности, укажи Bash в shebang и не запускай скрипт через `sh script.sh`.

## Практика

Сделай функцию печати списка аргументов. Передай обычное слово, строку с пробелом и буквальный `*`. Убедись, что вывод содержит три значения и ни одно не превратилось в список файлов.
