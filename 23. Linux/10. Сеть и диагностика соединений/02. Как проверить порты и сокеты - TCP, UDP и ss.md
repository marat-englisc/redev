# Как проверить порты и сокеты - TCP, UDP и ss

> [!NOTE]
> Сокет — endpoint обмена данными. TCP предоставляет упорядоченный поток с соединением, UDP передаёт отдельные датаграммы без такой гарантии доставки. Порт выбирает приложение на адресе узла, а bind-адрес определяет, на каких интерфейсах оно принимает запросы. `ss` показывает слушающие сокеты, соединения и, при достаточных правах, процессы.

## Вопрос

Почему сервер отвечает на `127.0.0.1:8080`, но недоступен с другой машины? Что означает `0.0.0.0:8080`?

## Проверка слушателей

```bash
ss -ltn
ss -lun
sudo ss -ltnp
ss -tn state established
```

`-l` — слушающие, `-t` — TCP, `-u` — UDP, `-n` — числовые адреса, `-p` — процессы. Для UDP вывод не интерпретируется как TCP handshake: транспорт работает иначе.

## Адрес привязки

| Слушатель | Значение |
| --- | --- |
| `127.0.0.1:8080` | Только IPv4 loopback этого namespace |
| `192.168.10.25:8080` | Только конкретный IPv4-адрес |
| `0.0.0.0:8080` | Все локальные IPv4-адреса |
| `[::]:8080` | IPv6 wildcard; поддержка IPv4 зависит от настроек |

`0.0.0.0` удобен как bind-адрес, но клиенту нужен реальный адрес сервера. Открытие на всех интерфейсах не публикует порт автоматически через NAT и не разрешает его в firewall.

## Локальная практика

При установленном Python 3, из каталога с учебным файлом:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

В другом терминале:

```bash
ss -ltn 'sport = :8080'
curl --fail http://127.0.0.1:8080/
```

После опыта останови сервер Ctrl C. Он предоставляет файлы текущего каталога, поэтому запускай его только в специально подготовленной папке и не привязывай к публичной сети без необходимости.

## Состояния TCP

`LISTEN` означает ожидание соединений, `ESTAB` — установленное соединение, `TIME-WAIT` — нормальная часть завершения. Много TIME-WAIT не является само по себе утечкой приложения; важны скорость создания соединений и другие симптомы.

## Практика

Объясни разницу между «процесс запущен», «порт слушается» и «HTTP вернул нужный ответ». Это три последовательные, но разные проверки готовности.
