# В чем преимущество flexbox перед float-версткой?

> [!NOTE]
> Flexbox был создан для layout, а `float` изначально предназначался для обтекания контента. Поэтому Flexbox проще, предсказуемее и удобнее для выравнивания, распределения пространства и адаптивных интерфейсов.

## Вопрос

В чем преимущество Flexbox перед версткой на float?

## Главное

Float хорошо подходит для сценария "картинка слева, текст обтекает справа".

```css
.avatar {
  float: left;
  margin-right: 16px;
}
```

Но для меню, карточек, колонок и тулбаров Flexbox намного удобнее.

```css
.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}
```

## Что было сложно с float

- Нужно было очищать поток через clearfix.
- Вертикальное выравнивание было неудобным.
- Распределение свободного пространства требовало костылей.
- Колонки легко ломались при разной высоте.
- Адаптивность становилась громоздкой.

## Что дает Flexbox

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 240px;
}
```

Flexbox умеет:

- выравнивать элементы по двум осям;
- переносить items;
- управлять свободным пространством;
- сжимать и растягивать элементы;
- задавать расстояния через `gap`;
- менять визуальный порядок.

## Float все еще нужен?

Иногда да, но редко: например для обтекания изображения текстом в статье.

```css
.article-image {
  float: inline-start;
  margin-inline-end: 16px;
}
```

Для основного layout лучше Flexbox или Grid.

## Что важно помнить

- Float создавался для обтекания текстом картинок, а не для раскладки; для этого он и остается актуальным.
- Float-раскладка требовала clearfix: родитель не учитывает высоту float-детей.
- Flexbox дает равную высоту колонок, вертикальное центрирование и `gap` без хаков.
- На собеседовании стоит знать clearfix и BFC, потому что они встречаются в legacy-коде.

## Мини-шпаргалка

- Float не создавался как основной layout-инструмент.
- Flexbox удобнее для строк, колонок, меню и карточек.
- Flexbox решает выравнивание и распределение пространства.
- `gap` проще старых margin-костылей.
- Float уместен для обтекания контента.
