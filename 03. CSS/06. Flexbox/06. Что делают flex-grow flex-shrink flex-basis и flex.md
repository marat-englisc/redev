# Что делают flex-grow, flex-shrink, flex-basis и шорткат flex?

> [!NOTE]
> `flex-basis` задает исходный размер элемента по главной оси до распределения места. `flex-grow` — какую долю **свободного** места элемент забирает, если оно есть (по умолчанию 0). `flex-shrink` — насколько элемент сжимается при нехватке места (по умолчанию 1). Шорткат `flex: grow shrink basis` задает все три; самые частые значения — `flex: 1`, `flex: auto`, `flex: none`.

## Вопрос

Что делают `flex-grow`, `flex-shrink` и `flex-basis`? Как браузер распределяет место и что означают `flex: 1`, `flex: auto` и `flex: none`?

## flex-basis

```css
.sidebar { flex-basis: 240px; }
.content { flex-basis: 0; }
```

- `auto` (по умолчанию) — взять `width` (или `height` в колонке), а если его нет — размер содержимого;
- `0` — начать с нуля и делить всё место только по `flex-grow`;
- длина или проценты — конкретный стартовый размер.

`flex-basis` имеет приоритет над `width`, но ограничивается `min-width` и `max-width`.

## flex-grow

```css
.a { flex-grow: 1; }
.b { flex-grow: 2; }
```

Свободное место = ширина контейнера − сумма `flex-basis` − `gap`. Оно делится пропорционально `flex-grow`:

```text
контейнер 600px, basis у обоих 100px, свободно 400px
a получит 400 × 1/3 ≈ 133px → 233px
b получит 400 × 2/3 ≈ 267px → 367px
```

Важно: делится **свободное** место, а не вся ширина. Поэтому при `basis: auto` элементы с разным контентом получат разные итоговые размеры даже при одинаковом `flex-grow`.

## flex-shrink

Если сумма `flex-basis` больше контейнера, элементы сжимаются. Нехватка делится пропорционально `flex-shrink × flex-basis` — большие элементы сжимаются сильнее.

```css
.logo { flex-shrink: 0; } /* логотип никогда не сжимается */
```

Сжатие останавливается на `min-width: auto` — минимальном размере контента. Чтобы разрешить сжатие длинного текста (например, с `text-overflow: ellipsis`), задают `min-width: 0`.

## Шорткат flex

| Значение | Расшифровка | Поведение |
| --- | --- | --- |
| `flex: 0 1 auto` | по умолчанию | размер по контенту, не растет, сжимается |
| `flex: 1` | `1 1 0%` | равные доли всего места, независимо от контента |
| `flex: auto` | `1 1 auto` | растет и сжимается от размера контента |
| `flex: none` | `0 0 auto` | жесткий размер по контенту |
| `flex: 0 0 240px` | | фиксированная колонка 240px |

```css
.layout { display: flex; gap: 24px; }
.layout__sidebar { flex: 0 0 240px; }
.layout__content { flex: 1; min-width: 0; }
```

Классическая раскладка: фиксированный sidebar и резиновый контент, который не переполняется длинными строками.

## Что важно помнить

- Рекомендуется использовать шорткат `flex`, а не отдельные свойства: он правильно выставляет значения по умолчанию.
- `flex: 1` и `flex-grow: 1` — не одно и то же: у первого `basis: 0`, у второго остается `auto`.
- `flex-grow` не превысит `max-width`: оставшееся место перераспределится между другими элементами.
- Для равных колонок с переносом надежнее Grid с `1fr`.

## Мини-шпаргалка

- `flex-basis` — стартовый размер.
- `flex-grow` — доля свободного места (по умолчанию 0).
- `flex-shrink` — степень сжатия (по умолчанию 1), `0` запрещает.
- `flex: 1` — равные доли, `auto` — от контента, `none` — жестко.
- `min-width: 0` — разрешить сжатие ниже контента.
