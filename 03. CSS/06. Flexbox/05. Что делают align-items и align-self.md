# Что делают align-items и align-self?

> [!NOTE]
> `align-items` задается на flex-контейнере и выравнивает всех детей по **поперечной оси**: `stretch` (по умолчанию), `flex-start`, `flex-end`, `center`, `baseline`. `align-self` задается на конкретном элементе и переопределяет `align-items` только для него. По главной оси индивидуально выравнивают через `margin: auto`.

## Вопрос

Что делает `align-items`? Как выровнять один элемент индивидуально, не трогая остальные?

## align-items

```css
.toolbar {
  display: flex;
  align-items: center;
  gap: 12px;
}
```

При `flex-direction: row` поперечная ось вертикальная, поэтому `center` выравнивает элементы по вертикальному центру.

| Значение | Поведение |
| --- | --- |
| `stretch` | растягивает элементы на высоту строки (если высота не задана) |
| `flex-start` / `start` | к началу поперечной оси |
| `flex-end` / `end` | к концу |
| `center` | по центру |
| `baseline` | по базовой линии первой строки текста |

`stretch` — причина, по которой колонки во Flexbox по умолчанию одинаковой высоты.

`baseline` полезен, когда в строке элементы с разным размером шрифта: заголовок и подпись встанут на одну линию текста.

## align-self

```css
.toolbar {
  display: flex;
  align-items: center;
}

.toolbar__avatar {
  align-self: flex-start; /* только аватар прижат к верху */
}
```

`align-self` принимает те же значения плюс `auto` (взять значение `align-items` родителя).

## Индивидуальное выравнивание по главной оси

`justify-self` во Flexbox **не работает**. Вместо него используют автоматические margin:

```css
.header {
  display: flex;
  gap: 16px;
}

.header__login {
  margin-left: auto; /* всё свободное место слева — кнопка прижата вправо */
}
```

`margin: auto` со всех сторон у единственного элемента центрирует его по обеим осям.

## Центрирование

```css
.center {
  display: flex;
  justify-content: center; /* главная ось */
  align-items: center;     /* поперечная ось */
  min-height: 100dvh;
}
```

## Что важно помнить

- При `flex-direction: column` оси меняются: `align-items` управляет горизонталью, а `stretch` растягивает элементы по ширине. Поэтому кнопки в колонке становятся на всю ширину — лечится `align-items: flex-start`.
- `stretch` не сработает, если у элемента задана высота (или ширина в колонке).
- Sticky-элемент во flex-контейнере не прилипает при `stretch` — ему нужен `align-self: start`.
- Значения `start`/`end` учитывают направление письма, `flex-start`/`flex-end` — направление flex-оси.

## Мини-шпаргалка

- `align-items` — все дети, поперечная ось.
- `align-self` — один элемент, поперечная ось.
- По главной оси один элемент — `margin-left: auto`.
- `stretch` по умолчанию дает равную высоту колонок.
- В колонке оси меняются местами.
