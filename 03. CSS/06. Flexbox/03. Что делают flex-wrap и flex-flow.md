# Что делают flex-wrap и flex-flow и как перенос влияет на выравнивание?

> [!NOTE]
> `flex-wrap` разрешает flex-элементам переноситься на новые строки: `nowrap` (по умолчанию) держит всех в одной строке и сжимает, `wrap` переносит, `wrap-reverse` переносит в обратном направлении. `flex-flow` — шорткат для `flex-direction` и `flex-wrap`. При переносе появляется несколько flex-строк, и их распределение по поперечной оси задает `align-content`.

## Вопрос

Что делает свойство `flex-wrap`? Как перенос влияет на выравнивание элементов? Что делает `flex-flow`?

## flex-wrap

```css
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
```

| Значение | Поведение |
| --- | --- |
| `nowrap` | одна строка, элементы сжимаются и могут переполнить контейнер |
| `wrap` | лишние элементы переносятся на следующую строку |
| `wrap-reverse` | перенос в обратную сторону: новые строки появляются сверху |

Без `wrap` теги, карточки и кнопки на узком экране сжимаются или вылезают за контейнер.

## flex-flow

```css
.list {
  flex-flow: row wrap;
  /* = flex-direction: row; flex-wrap: wrap; */
}

.stack {
  flex-flow: column nowrap;
}
```

## Как перенос влияет на выравнивание

Когда элементы переносятся, получается несколько **flex-строк**. Каждая строка — отдельная группа:

- `justify-content` распределяет элементы **внутри каждой строки** по главной оси;
- `align-items` выравнивает элементы **внутри своей строки** по поперечной оси;
- `align-content` распределяет **сами строки** внутри контейнера (работает только при `wrap` и наличии свободного места по поперечной оси).

```css
.gallery {
  display: flex;
  flex-wrap: wrap;
  align-content: flex-start; /* строки прижаты к верху, без растягивания */
  height: 600px;
}
```

По умолчанию `align-content: normal` ведет себя как `stretch`: строки растягиваются, и между ними появляются неожиданные промежутки.

## Проблема «последней строки»

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 240px;
}
```

Карточки последней неполной строки растянутся шире остальных, потому что делят всё оставшееся место. Если нужна ровная сетка, лучше Grid:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 16px;
}
```

## Что важно помнить

- Перенос происходит, когда сумма `flex-basis` (или ширин) и `gap` больше контейнера.
- При `nowrap` элементы сжимаются по `flex-shrink`, но не меньше `min-width: auto` — поэтому контейнер может переполниться.
- `gap` работает и между строками (`row-gap`), и между элементами (`column-gap`).
- В колонке (`flex-direction: column`) перенос сработает только при ограниченной высоте контейнера.

## Мини-шпаргалка

- `flex-wrap: wrap` — перенос на новые строки.
- `flex-flow: row wrap` — направление и перенос вместе.
- `justify-content` и `align-items` — внутри строки, `align-content` — между строками.
- Ровная сетка карточек — Grid с `auto-fill`.
