# Что делает свойство justify-content?

> [!NOTE]
> `justify-content` распределяет flex items вдоль main axis: в начало, центр, конец или с промежутками между элементами.

## Вопрос

Что делает `justify-content`? Чем отличаются `space-between`, `space-around` и `space-evenly`?

## Главное

```css
.toolbar {
  display: flex;
  justify-content: space-between;
}
```

Элементы распределятся по главной оси контейнера.

## Main axis

`justify-content` не всегда означает "горизонтально". Оно работает по main axis.

```css
.row {
  flex-direction: row;
  justify-content: center; /* горизонтально */
}

.column {
  flex-direction: column;
  justify-content: center; /* вертикально */
}
```

## Частые значения

| Значение | Поведение |
| --- | --- |
| `flex-start` | В начало main axis |
| `center` | По центру main axis |
| `flex-end` | В конец main axis |
| `space-between` | Первый и последний по краям, промежутки между |
| `space-around` | Равные поля вокруг элементов |
| `space-evenly` | Равные промежутки между всеми краями |

## Пример центрирования

```css
.actions {
  display: flex;
  justify-content: center;
  gap: 12px;
}
```

Для расстояния между элементами часто лучше использовать `gap`, а не пытаться заменить его `space-*`.

## Попробуйте

Шесть контейнеров с одинаковыми элементами и разными значениями `justify-content`. Поменяйте значения или добавьте `flex-direction: column` и высоту контейнеру — распределение пойдёт по вертикали.

```html run=justify
<div class="row start"><i></i><i></i><i></i></div>
<div class="row center"><i></i><i></i><i></i></div>
<div class="row end"><i></i><i></i><i></i></div>
<div class="row between"><i></i><i></i><i></i></div>
<div class="row around"><i></i><i></i><i></i></div>
<div class="row evenly"><i></i><i></i><i></i></div>
```

```css run=justify
body { font-family: system-ui, sans-serif; padding: 16px; }

.row {
  position: relative;
  display: flex;
  margin-top: 26px;
  padding: 8px;
  border: 1px dashed #9ca3af;
}
/* подпись с классом контейнера над каждой строкой */
.row::before { content: attr(class); position: absolute; top: -20px; left: 0; font-size: 11px; color: #6b7280; }
i { width: 40px; height: 32px; background: #111; border-radius: 4px; }

.start   { justify-content: flex-start; }
.center  { justify-content: center; }
.end     { justify-content: flex-end; }
.between { justify-content: space-between; }
.around  { justify-content: space-around; }
.evenly  { justify-content: space-evenly; }
```

## Что важно помнить

- `space-between` — края без отступов, `space-around` — по краям половина промежутка, `space-evenly` — все промежутки равны.
- `justify-content` работает только при наличии свободного места: если у элементов `flex-grow: 1`, оно ничего не сделает.
- Значение `safe center` не дает контенту уйти за левую границу при переполнении.
- В Grid `justify-content` выравнивает всю сетку внутри контейнера, а не элементы в ячейках.

## Мини-шпаргалка

- `justify-content` работает по main axis.
- Направление main axis задает `flex-direction`.
- `center` центрирует группу элементов.
- `space-between` разносит элементы к краям.
- `gap` задает фиксированное расстояние между items.
