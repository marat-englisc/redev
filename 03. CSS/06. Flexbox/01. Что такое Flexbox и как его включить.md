# Что такое Flexbox и как его включить?

> [!NOTE]
> **Flexbox** — модель одномерной раскладки: элементы выстраиваются в строку или колонку, распределяют свободное место, выравниваются и меняют размер. Включается свойством `display: flex` (или `inline-flex`) на контейнере — после этого все его прямые дети становятся flex-элементами.

## Вопрос

Что такое Flexbox и для чего он нужен? Как активировать Flexbox для контейнера и что меняется для дочерних элементов?

## Включение

```html
<nav class="toolbar">
  <a href="/">Главная</a>
  <a href="/catalog">Каталог</a>
  <button type="button">Войти</button>
</nav>
```

```css
.toolbar {
  display: flex;
  align-items: center;
  gap: 16px;
}
```

`display: flex` делает контейнер блочным, `inline-flex` — строчным (контейнер идет в строку с текстом, а внутри работает Flexbox).

## Что меняется для детей

- flex-элементами становятся только **прямые дети**, внуки ведут себя как обычно;
- элементы по умолчанию идут в строку (`flex-direction: row`), а не друг под другом;
- `float`, `clear` и `vertical-align` перестают действовать;
- у детей работают `margin: auto`, `order`, `flex-grow`, `flex-shrink`, `flex-basis`, `align-self`;
- inline-элементы (`span`, `a`) ведут себя как блоки: у них работают `width` и `height`;
- margin детей не схлопываются;
- текст, лежащий прямо в контейнере, оборачивается в анонимный flex-элемент.

## Свойства контейнера и элементов

| Контейнер | Элементы |
| --- | --- |
| `flex-direction` | `flex-grow` |
| `flex-wrap`, `flex-flow` | `flex-shrink` |
| `justify-content` | `flex-basis`, `flex` |
| `align-items` | `align-self` |
| `align-content` | `order` |
| `gap` | `margin: auto` |

## Где использовать Flexbox

- навигация, тулбары, группы кнопок;
- выравнивание иконки и текста;
- карточка: контент сверху, кнопка прижата вниз;
- центрирование;
- раскладка «sidebar + контент» с фиксированной и резиновой колонками.

```css
.card {
  display: flex;
  flex-direction: column;
}

.card__actions {
  margin-top: auto; /* прижимает кнопки к низу карточки */
}
```

Для двумерной сетки (строки и колонки одновременно) удобнее Grid.

## Что важно помнить

- `gap` во Flexbox поддерживается всеми современными браузерами — margin между элементами больше не нужен.
- Минимальная ширина flex-элемента по умолчанию `min-width: auto` — длинный текст или `pre` не дадут ему сжаться. Лечится `min-width: 0`.
- Flexbox работает от содержимого (content-first): размеры элементов зависят от их контента.
- `order` и `flex-direction: row-reverse` меняют только визуальный порядок, а фокус и скринридер идут по DOM.

## Мини-шпаргалка

- Flexbox — одномерная раскладка в строку или колонку.
- Включение: `display: flex` / `inline-flex` на контейнере.
- Действует на прямых детей.
- Отступы — `gap`, прижать элемент — `margin: auto`.
- `min-width: 0` спасает от переполнения.
