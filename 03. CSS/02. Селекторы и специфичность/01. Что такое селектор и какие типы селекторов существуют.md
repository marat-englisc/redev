# Что такое селектор в CSS и какие типы селекторов существуют?

> [!NOTE]
> **CSS-селектор** — часть правила, которая выбирает элементы для применения стилей. Бывают селекторы по тегу, классу, id, атрибуту, универсальный `*`, псевдоклассы и псевдоэлементы. Комбинаторы (пробел, `>`, `+`, `~`) описывают отношения между элементами.

## Вопрос

Что такое селектор в CSS и для чего он используется? Какие типы селекторов и комбинаторов существуют?

## Структура правила

```css
selector {
  property: value;
}
```

Селектор отвечает на вопрос: «К каким элементам применить эти объявления?»

## Основные типы

| Тип | Пример | Что выбирает | Специфичность |
| --- | --- | --- | --- |
| Универсальный | `*` | Все элементы | 0-0-0 |
| По тегу | `button` | Все кнопки | 0-0-1 |
| По классу | `.button` | Элементы с классом | 0-1-0 |
| По id | `#app` | Элемент с id | 1-0-0 |
| По атрибуту | `[disabled]` | Элементы с атрибутом | 0-1-0 |
| Псевдокласс | `:hover` | Состояние или условие | 0-1-0 |
| Псевдоэлемент | `::before` | Виртуальную часть элемента | 0-0-1 |

## Комбинаторы

```css
.card p { color: #374151; }        /* потомок на любой глубине */
.tabs > button { flex: 1; }         /* прямой ребенок */
h2 + p { margin-top: 0; }           /* следующий сосед */
.error ~ .hint { display: none; }   /* все следующие соседи */
```

| Комбинатор | Смысл |
| --- | --- |
| `A B` | B — потомок A |
| `A > B` | B — прямой ребенок A |
| `A + B` | B идет сразу после A |
| `A ~ B` | B идет после A (не обязательно сразу) |

Комбинаторы смотрят только вниз и вправо по дереву. Выбрать родителя или предыдущего соседа раньше было нельзя — теперь это делает `:has()`.

## Атрибутные селекторы

| Селектор | Совпадение |
| --- | --- |
| `[attr]` | атрибут есть |
| `[attr="v"]` | точное значение |
| `[attr^="v"]` | начинается с `v` |
| `[attr$="v"]` | заканчивается на `v` |
| `[attr*="v"]` | содержит `v` |
| `[attr~="v"]` | слово `v` в списке через пробел |
| `[attr|="v"]` | `v` или `v-...` (для `lang`) |
| `[attr="v" i]` | без учета регистра |

```css
a[href^="https://"]::after { content: " ↗"; }
input[type="email"] { border-color: #2563eb; }
[data-state="open"] { display: block; }
```

## Группировка

```css
h1,
h2,
h3 {
  line-height: 1.2;
}
```

Если один селектор в списке невалиден, браузер отбросит **всё правило**. `:is()` и `:where()` устойчивы к этому — невалидный аргумент просто игнорируется.

## Как браузер сопоставляет селекторы

Браузер читает селектор **справа налево**: для `.menu li a` он берет каждый `a`, затем проверяет предков. Поэтому правая часть (key selector) должна быть как можно более конкретной. На практике производительность селекторов редко бывает проблемой, но длинные цепочки ухудшают читаемость и повышают специфичность.

## Хорошая практика

В компонентах опирайтесь на классы, а не на длинные цепочки тегов:

```css
/* хрупко и специфично */
#sidebar ul li a.active { ... }

/* предсказуемо */
.nav-link--active { ... }
```

## Что важно помнить

- Стилизация по id дает высокую специфичность и мешает переопределению — для стилей используют классы.
- CSS Nesting позволяет писать вложенные селекторы нативно: `.card { & h2 { ... } }`.
- `document.querySelectorAll()` принимает тот же синтаксис селекторов — их полезно знать и для JS.
- Селекторы по классу из CSS Modules и CSS-in-JS генерируются автоматически, но правила специфичности те же.

## Мини-шпаргалка

- Типы: `*`, тег, `.class`, `#id`, `[attr]`, `:pseudo-class`, `::pseudo-element`.
- Комбинаторы: пробел (потомок), `>` (ребенок), `+` (сосед), `~` (все следующие).
- Атрибутные: `^=`, `$=`, `*=`, флаг `i`.
- Невалидный селектор в группе ломает всё правило.
- Стили — по классам.
