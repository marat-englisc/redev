# Как задать стили всем элементам на странице?

> [!NOTE]
> Чтобы задать стили всем элементам, используют универсальный селектор `*`. Чаще всего его применяют для базовых reset-правил, например для `box-sizing`.

## Вопрос

Как задать стили всем элементам на странице? Чем `*` отличается от `:root` и `body`?

## Главное

```css
* {
  box-sizing: border-box;
}
```

Универсальный селектор выбирает все элементы на странице.

## Частый reset

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Так правило применяется не только к обычным элементам, но и к псевдоэлементам.

## Почему не стоит писать слишком много через *

```css
* {
  margin: 0;
  padding: 0;
  color: red;
}
```

Такой подход может случайно сломать дефолтные стили форм, списков, заголовков и сторонних компонентов.

## Альтернативы

Для базовых стилей часто используют `body`.

```css
body {
  margin: 0;
  font-family: system-ui, sans-serif;
  color: #111827;
}
```

Текстовые свойства наследуются, поэтому не нужно назначать их через `*`.

## Что важно помнить

- `*` имеет нулевую специфичность, поэтому любой другой селектор его перебивает.
- `*` не выбирает псевдоэлементы — для них пишут `*::before, *::after`.
- `:root` — это `html`, но со специфичностью класса; его используют для глобальных CSS-переменных.
- `all: unset` или `all: revert` сбрасывает все свойства элемента сразу — полезно для кнопок без браузерных стилей.

## Мини-шпаргалка

- `*` выбирает все элементы.
- Частый сценарий: `box-sizing: border-box`.
- Для псевдоэлементов добавляют `*::before`, `*::after`.
- Не стоит задавать через `*` все подряд.
- Базовую типографику обычно задают на `body`.
