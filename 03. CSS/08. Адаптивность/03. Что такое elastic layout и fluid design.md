# Что такое elastic layout и fluid design?

> [!NOTE]
> **Fluid (резиновый) layout** задает размеры в процентах и долях (`%`, `fr`, `vw`), поэтому блоки тянутся вместе с шириной окна. **Elastic layout** задает размеры в `em`/`rem`, поэтому раскладка масштабируется вместе с размером шрифта. Современная адаптивная верстка комбинирует оба подхода с ограничениями `max-width`, `clamp()` и media или container queries.

## Вопрос

Что означает «elastic layout»? Что такое «fluid design»? Чем они отличаются от фиксированной и адаптивной верстки?

## Виды раскладки

| Подход | Единицы | Что происходит при изменении окна | При увеличении шрифта |
| --- | --- | --- | --- |
| Фиксированный | `px` | ничего, появляется прокрутка | ничего |
| Fluid (резиновый) | `%`, `fr`, `vw` | блоки тянутся | текст растет, блоки нет |
| Elastic | `em`, `rem`, `ch` | ничего | всё растет пропорционально |
| Адаптивный (responsive) | любые + media queries | раскладка перестраивается на брейкпоинтах | зависит от единиц |

## Fluid design

```css
.layout {
  display: grid;
  grid-template-columns: 25% 1fr;
  gap: 2%;
}

img {
  max-width: 100%;
  height: auto;
}
```

Минус чистой «резины»: на широком мониторе строки текста становятся слишком длинными, а на узком — колонки слишком тесными. Поэтому добавляют ограничения:

```css
.container {
  width: min(100% - 2rem, 1200px);
  margin-inline: auto;
}
```

## Elastic layout

```css
.article {
  max-width: 65ch;     /* оптимальная длина строки */
  padding: 1.5rem;
  font-size: 1.125rem;
}

.button {
  padding: 0.5em 1em;  /* растет вместе с шрифтом кнопки */
}
```

Если пользователь увеличит шрифт в настройках браузера, вся раскладка сохранит пропорции. Это важно для доступности.

## Fluid typography

Современное сочетание обоих подходов — плавное масштабирование через `clamp()`:

```css
h1 {
  font-size: clamp(1.75rem, 1.2rem + 2.5vw, 3rem);
}

.section {
  padding-block: clamp(2rem, 5vw, 6rem);
}
```

Минимум и максимум в `rem` уважают настройки пользователя, середина в `vw` дает плавность без брейкпоинтов. Такие шкалы удобно генерировать инструментом Utopia.

## Intrinsic design

Термин Джен Симмонс для раскладки, которая подстраивается под контент и контейнер, а не под фиксированные брейкпоинты:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(16rem, 100%), 1fr));
}
```

## Что важно помнить

- Чистый `vw` в `font-size` ломает зум — всегда комбинируйте с `rem` через `clamp()` или `calc()`.
- Проценты для `padding` и `margin` считаются от ширины родителя, даже вертикальные.
- Комфортная длина строки — 45–75 символов: `max-width: 65ch`.
- На собеседовании хороший ответ: «fluid — от ширины экрана, elastic — от шрифта, на практике сочетаю их с `clamp()` и брейкпоинтами».

## Мини-шпаргалка

- Fluid — `%`, `fr`, `vw`, тянется с окном.
- Elastic — `em`, `rem`, `ch`, масштабируется с шрифтом.
- Ограничения: `max-width`, `min()`, `clamp()`.
- Fluid typography: `clamp(min-rem, rem + vw, max-rem)`.
