# Что такое prefers-color-scheme, prefers-reduced-motion и другие пользовательские настройки

> [!NOTE]
> **User preference media features** — медиазапросы, которые читают настройки пользователя в ОС и браузере: `prefers-color-scheme` (светлая или темная тема), `prefers-reduced-motion` (уменьшить анимацию), `prefers-contrast` (повышенный контраст), `forced-colors` (режим высокой контрастности Windows). Они позволяют подстроить интерфейс под человека без отдельных настроек на сайте.

## Вопрос

Что такое `prefers-color-scheme` и `prefers-reduced-motion`? Как сделать темную тему и уважать настройку «уменьшить движение»?

## Темная тема: prefers-color-scheme

```css
:root {
  color-scheme: light dark;     /* браузер подстроит скроллбары, поля форм */
  --bg: #ffffff;
  --text: #111827;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0b1120;
    --text: #e5e7eb;
  }
}

body {
  background: var(--bg);
  color: var(--text);
}
```

Короче — функция `light-dark()`:

```css
:root { color-scheme: light dark; }
body {
  background: light-dark(#fff, #0b1120);
  color: light-dark(#111827, #e5e7eb);
}
```

Переключатель темы на сайте обычно ставит атрибут `data-theme` и сохраняет выбор, а системная настройка используется по умолчанию:

```css
:root[data-theme="dark"] { --bg: #0b1120; --text: #e5e7eb; }
```

```javascript
const dark = window.matchMedia("(prefers-color-scheme: dark)");
dark.addEventListener("change", (e) => console.log("тёмная тема:", e.matches));
```

## Меньше движения: prefers-reduced-motion

Анимации, параллакс и автоматическая прокрутка могут вызывать головокружение и тошноту у людей с вестибулярными нарушениями.

```css
.card {
  transition: transform 300ms ease;
}

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Лучше подход «анимация по согласию»: добавлять движение только тем, кто не просил его уменьшить.

```css
@media (prefers-reduced-motion: no-preference) {
  .hero { animation: float 6s ease-in-out infinite; }
}
```

```javascript
const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
element.scrollIntoView({ behavior: reduce ? "auto" : "smooth" });
```

## Другие медиафункции

| Медиафункция | Что сообщает |
| --- | --- |
| `prefers-contrast: more` | пользователь просит больше контраста |
| `forced-colors: active` | включен режим принудительных цветов (Windows High Contrast) |
| `prefers-reduced-transparency` | уменьшить прозрачность и размытие |
| `prefers-reduced-data` | экономить трафик (поддержка ограничена) |
| `hover: none`, `pointer: coarse` | сенсорный экран без наведения |

## Что важно помнить

- `color-scheme` в CSS или `<meta name="color-scheme" content="light dark">` нужен, чтобы браузер перекрасил системные элементы: поля ввода, скроллбары.
- Темная тема — это не инверсия цветов: проверяйте контраст текста и фона в обеих темах.
- `prefers-reduced-motion` — требование доступности (WCAG 2.3.3): «уменьшить» не всегда значит «убрать всё», плавное появление обычно допустимо.
- Чтобы избежать мигания светлой темы при загрузке, тему из `localStorage` применяют инлайн-скриптом в `<head>` до отрисовки.
- Медиафункции доступны и в JS через `matchMedia` с событием `change`.

## Мини-шпаргалка

`@media (prefers-color-scheme: dark)` + CSS-переменные или `light-dark()`, плюс `color-scheme: light dark`. `@media (prefers-reduced-motion: reduce)` — убрать или упростить анимации. В JS — `matchMedia`. Также `prefers-contrast`, `forced-colors`, `pointer: coarse`.
