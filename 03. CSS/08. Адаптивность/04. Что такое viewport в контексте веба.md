# Что такое viewport в контексте веба?

> [!NOTE]
> **Viewport** - это видимая область страницы в браузере. CSS использует viewport для media queries, viewport-единиц и адаптивного поведения интерфейса.

## Вопрос

Что такое viewport? Чем layout viewport отличается от visual viewport?

## Главное

Viewport - это не весь документ, а область, которую пользователь видит сейчас.

```text
document height: 5000px
viewport height: 800px
```

Пользователь прокручивает документ внутри viewport.

## Viewport и CSS

```css
.hero {
  min-height: 100vh;
}
```

`100vh` означает 100% высоты viewport.

```css
@media (max-width: 768px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
```

Media query проверяет ширину viewport.

## Meta viewport

Для мобильных страниц важен тег:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Без него мобильный браузер может отображать страницу как уменьшенную desktop-версию.

## Layout viewport и visual viewport

На мобильных устройствах есть нюансы: адресная строка браузера может появляться и исчезать, меняя видимую область. Поэтому современные единицы вроде `svh`, `lvh`, `dvh` иногда лучше обычного `vh`.

## Что важно помнить

- Layout viewport — область, по которой строится раскладка; visual viewport — видимая часть при зуме или открытой клавиатуре.
- Размеры: `window.innerWidth` (с полосой прокрутки), `document.documentElement.clientWidth` (без нее), `visualViewport.width`.
- Единицы `svh`, `lvh`, `dvh` решают проблему мобильной адресной строки.
- Без meta viewport мобильные браузеры используют layout viewport около 980px.

## Мини-шпаргалка

- Viewport - видимая область страницы.
- `vw` зависит от ширины viewport.
- `vh` зависит от высоты viewport.
- Media queries часто смотрят на viewport.
- Для мобильных нужен meta viewport.
- На мобильных высота viewport может меняться из-за UI браузера.
