# Что такое media queries и breakpoints?

> [!NOTE]
> **Media query** — условие `@media`, при выполнении которого применяются стили: ширина viewport, ориентация, тип устройства, способ ввода или пользовательские настройки (`prefers-color-scheme`, `prefers-reduced-motion`). **Breakpoint** — значение ширины, на котором раскладка перестраивается. Брейкпоинты выбирают там, где ломается контент, а не по моделям устройств.

## Вопрос

Что такое media query и для чего они используются? Что такое breakpoint и как их выбирать?

## Синтаксис

```css
/* mobile-first: базовые стили для узких экранов */
.cards {
  display: grid;
  gap: 16px;
}

@media (min-width: 48em) {   /* от 768px */
  .cards { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 64em) {   /* от 1024px */
  .cards { grid-template-columns: repeat(3, 1fr); }
}
```

Современный синтаксис диапазонов (Media Queries Level 4):

```css
@media (width >= 768px) { ... }
@media (480px <= width < 1024px) { ... }
```

## Что можно проверять

| Признак | Пример | Зачем |
| --- | --- | --- |
| Ширина / высота | `(min-width: 768px)` | раскладка |
| Ориентация | `(orientation: landscape)` | горизонтальный режим |
| Тип | `print`, `screen` | стили для печати |
| Указатель | `(hover: hover) and (pointer: fine)` | hover-эффекты только для мыши |
| Тема | `(prefers-color-scheme: dark)` | темная тема |
| Анимации | `(prefers-reduced-motion: reduce)` | отключить движение |
| Контраст | `(prefers-contrast: more)` | усиленный контраст |
| Плотность | `(min-resolution: 2dppx)` | изображения для Retina |

Условия комбинируют через `and`, `,` (или), `not`.

## Breakpoints

```text
типичный набор (ориентир, не правило):
  ≥ 480px  — крупные телефоны
  ≥ 768px  — планшеты
  ≥ 1024px — ноутбуки
  ≥ 1280px — десктоп
```

Как выбирать:

- начинать с самого узкого экрана и расширять окно, пока раскладка не «сломается» — там и брейкпоинт;
- держать небольшое общее множество брейкпоинтов в токенах или переменных (Tailwind: `sm`, `md`, `lg`, `xl`);
- писать брейкпоинты в `em`: они корректно реагируют на увеличение шрифта;
- использовать небольшие точечные media queries для отдельных компонентов, если нужно.

## mobile-first и desktop-first

```css
/* mobile-first — min-width, стили накапливаются */
@media (min-width: 768px) { ... }

/* desktop-first — max-width, стили отменяются */
@media (max-width: 767.98px) { ... }
```

Mobile-first обычно проще: базовые стили короче, а мобильные устройства не грузят лишние правила.

## Media и container queries

Media query реагирует на viewport, container query — на размер родителя. Компонент карточки в sidebar и в основной колонке должен выглядеть по-разному при одном и том же viewport — для этого `@container`.

## Что важно помнить

- Без `<meta name="viewport" content="width=device-width">` media queries на мобильных сработают неправильно.
- При `min-width` и `max-width` на одном значении (`768px`) оба условия истинны на ширине ровно 768px — используйте `767.98px` или синтаксис диапазонов.
- Hover-эффекты оборачивайте в `@media (hover: hover)`, иначе на touch-устройствах они «залипают» после тапа.
- Media queries можно использовать в JS: `window.matchMedia('(min-width: 768px)')`, и в `<picture>` / `srcset`.

## Мини-шпаргалка

- `@media (условие) { стили }`.
- Breakpoint — ширина, где перестраивается раскладка.
- Брейкпоинты — по контенту, в `em`, mobile-first через `min-width`.
- Кроме ширины: `hover`, `prefers-color-scheme`, `prefers-reduced-motion`, `print`.
- Для компонентов — container queries.
