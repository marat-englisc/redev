# Что такое адаптивный (responsive) дизайн?

> [!NOTE]
> **Адаптивный дизайн** - это подход, при котором интерфейс подстраивается под разные размеры экранов, устройства, плотность пикселей, способы ввода и пользовательские настройки.

## Вопрос

Что такое адаптивный (responsive) дизайн? Чем он отличается от adaptive design с отдельными версиями?

## Главное

Responsive-дизайн не означает "сделать отдельную мобильную версию". Это один интерфейс, который гибко перестраивается под условия.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}
```

Такая сетка сама меняет количество колонок.

## Из чего состоит адаптивность

- Гибкая сетка.
- Относительные единицы.
- Media queries.
- Responsive images.
- Удобные touch-цели.
- Текст, который нормально переносится.
- Сохранение доступности на разных экранах.

## Пример media query

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
}

@media (max-width: 768px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
```

На узком экране layout становится одноколоночным.

## Responsive не только про ширину

Важно учитывать:

- высоту экрана;
- ориентацию;
- плотность пикселей;
- hover/touch;
- zoom;
- предпочтения пользователя.

## Что важно помнить

- Термин ввел Итан Маркотт в 2010 году: гибкая сетка, гибкие изображения и media queries.
- Adaptive design — несколько фиксированных макетов под конкретные ширины; responsive — плавная раскладка.
- Современный responsive включает container queries, fluid typography и учет способа ввода (touch, мышь).
- Проверяйте адаптивность не только в эмуляторе DevTools, но и на реальных устройствах.

## Мини-шпаргалка

- Responsive-дизайн адаптируется под разные условия.
- Гибкие сетки важнее фиксированных ширин.
- Media queries меняют стили по условиям.
- Изображения тоже должны быть адаптивными.
- Доступность должна сохраняться на всех размерах.
