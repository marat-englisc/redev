# Что означает "mobile-first" подход?

> [!NOTE]
> **Mobile-first** - это подход, при котором базовые стили пишутся для маленьких экранов, а затем через media queries постепенно добавляются улучшения для больших экранов.

## Вопрос

Что такое подход mobile-first и почему его часто выбирают?

## Главное

```css
.layout {
  display: grid;
  gap: 16px;
}

@media (min-width: 768px) {
  .layout {
    grid-template-columns: 240px 1fr;
  }
}
```

Сначала одноколоночный мобильный layout, затем двухколоночный desktop.

## Почему это удобно

- Маленький экран требует более строгих приоритетов.
- Базовый CSS получается проще.
- Улучшения добавляются постепенно.
- Часто лучше сочетается с `min-width` breakpoints.
- Помогает избежать "сжатия desktop-макета до телефона".

## Mobile-first media queries

```css
.card {
  padding: 16px;
}

@media (min-width: 1024px) {
  .card {
    padding: 24px;
  }
}
```

Стили идут от меньшего к большему.

## Это не только про смартфоны

Mobile-first - это про прогрессивное усложнение. База должна работать в ограниченных условиях, а дополнительные возможности включаются там, где есть место и ресурсы.

## Что важно помнить

- В CSS mobile-first означает базовые стили для узких экранов и расширения через `min-width`.
- Подход заставляет выделить главное: на маленьком экране нет места второстепенному.
- Tailwind CSS построен на mobile-first: `md:grid-cols-2` означает «от md и шире».
- Mobile-first касается и производительности: мобильные пользователи не должны загружать тяжелые десктопные ресурсы.

## Мини-шпаргалка

- Mobile-first начинает с маленьких экранов.
- Для расширения используют `min-width`.
- Desktop-стили добавляются поверх базовых.
- Такой подход помогает расставить приоритеты контента.
- Не означает, что desktop менее важен.
