# Что делает clamp()?

> [!NOTE]
> `clamp()` ограничивает значение CSS между минимумом и максимумом, позволяя среднему значению быть гибким. Частый сценарий - fluid typography и адаптивные отступы.

## Вопрос

Что делает функция `clamp()` и чем она лучше комбинации media queries?

## Главное

```css
h1 {
  font-size: clamp(2rem, 5vw, 4rem);
}
```

Это означает:

```text
minimum: 2rem
preferred: 5vw
maximum: 4rem
```

Размер будет расти вместе с viewport, но не станет меньше `2rem` и больше `4rem`.

## Синтаксис

```css
clamp(min, preferred, max)
```

Пример для контейнера:

```css
.section {
  padding-block: clamp(2rem, 6vw, 6rem);
}
```

## Почему удобно

Без `clamp()` часто приходится писать несколько media queries.

```css
.title {
  font-size: clamp(1.75rem, 4vw, 3.5rem);
}
```

Значение меняется плавно, без резких скачков на breakpoints.

## Где использовать

- Размеры заголовков.
- Вертикальные отступы секций.
- Ширину контейнеров.
- Gap между элементами.
- Размеры декоративных элементов.

## Что важно помнить

- `clamp(MIN, VAL, MAX)` эквивалентен `max(MIN, min(VAL, MAX))`.
- Для доступности средняя часть должна содержать `rem`: `clamp(1rem, 0.8rem + 1vw, 1.5rem)`, иначе текст не масштабируется зумом.
- Если MIN больше MAX, побеждает MIN.
- `clamp()` подходит не только для шрифтов, но и для отступов, ширины контейнеров и `gap`.

## Мини-шпаргалка

- `clamp()` задает минимум, желаемое значение и максимум.
- Формат: `clamp(min, preferred, max)`.
- Помогает делать fluid design.
- Уменьшает количество media queries.
- Хорошо работает с `rem`, `vw`, `%`.
