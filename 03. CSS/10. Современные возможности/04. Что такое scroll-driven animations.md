# Что такое scroll-driven animations?

> [!NOTE]
> **Scroll-driven animations** - это CSS-анимации, прогресс которых связан со скроллом, а не только со временем. Элемент может изменяться по мере прокрутки страницы или контейнера.

## Вопрос

Что такое scroll-driven animations и как связать анимацию с прокруткой без JavaScript?

## Главное

Обычная CSS-анимация идет по времени.

```css
.box {
  animation: fade-in 300ms ease;
}
```

Scroll-driven animation привязывает прогресс к прокрутке.

```css
.progress {
  animation: grow linear;
  animation-timeline: scroll();
}

@keyframes grow {
  from {
    transform: scaleX(0);
  }

  to {
    transform: scaleX(1);
  }
}
```

## Где полезно

- Индикатор прогресса чтения.
- Появление элементов при прокрутке.
- Parallax-эффекты.
- Анимации внутри scroll-контейнера.
- Визуализация шага в длинной странице.

## Timeline

`animation-timeline` указывает, от чего зависит прогресс анимации.

```css
.section {
  view-timeline-name: --section;
}

.section__title {
  animation: reveal both linear;
  animation-timeline: --section;
}
```

Идея: движение связано с положением элемента в viewport.

## Доступность

Scroll-анимации нужно делать умеренными. Они не должны мешать чтению, вызывать укачивание или скрывать важный контент. Стоит учитывать `prefers-reduced-motion`.

## Что важно помнить

- Две временные шкалы: `scroll()` — прогресс прокрутки контейнера, `view()` — видимость элемента в области прокрутки.
- `animation-range` задает, на каком участке прокрутки идет анимация.
- Анимации выполняются вне основного потока и не дергаются, в отличие от обработчиков `scroll`.
- Поддержка пока не во всех браузерах — используйте как прогрессивное улучшение через `@supports (animation-timeline: scroll())`.

## Мини-шпаргалка

- Scroll-driven animation зависит от прокрутки.
- Использует `animation-timeline`.
- Полезна для progress, reveal и parallax.
- Лучше анимировать `transform` и `opacity`.
- Нужно учитывать `prefers-reduced-motion`.
- Поддержку и fallback стоит проверять под целевые браузеры.
