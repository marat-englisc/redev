# Что такое логические свойства CSS

> [!NOTE]
> **Логические свойства** описывают размеры и отступы не через физические стороны (`left`, `right`, `top`, `bottom`), а через направление текста: **inline** — направление строки, **block** — направление следования блоков. `margin-inline-start` в русском интерфейсе — это левый отступ, а в арабском (RTL) — правый. Так один CSS работает для любых языков и режимов письма.

## Вопрос

Что такое логические свойства в CSS? Чем `margin-inline-start` отличается от `margin-left` и зачем они нужны?

## Оси

| Ось | В горизонтальном письме (ru, en) | В вертикальном письме |
| --- | --- | --- |
| inline | горизонталь: слева направо (или справа налево в RTL) | вертикаль |
| block | вертикаль: сверху вниз | горизонталь |

`start` и `end` — начало и конец оси с учетом `direction` и `writing-mode`.

## Соответствие свойств

| Физическое | Логическое |
| --- | --- |
| `width` / `height` | `inline-size` / `block-size` |
| `margin-left` / `margin-right` | `margin-inline-start` / `margin-inline-end` |
| `margin-top` / `margin-bottom` | `margin-block-start` / `margin-block-end` |
| `padding-left` + `padding-right` | `padding-inline` |
| `border-left` | `border-inline-start` |
| `top` / `bottom` / `left` / `right` | `inset-block-start` / `inset-block-end` / `inset-inline-start` / `inset-inline-end` |
| `text-align: left` | `text-align: start` |
| `float: left` | `float: inline-start` |
| `border-top-left-radius` | `border-start-start-radius` |

## Пример

```css
.message {
  padding-inline: 16px;          /* слева и справа */
  padding-block: 8px;            /* сверху и снизу */
  margin-inline-start: auto;     /* прижать к концу строки */
  border-inline-start: 4px solid var(--accent);
  text-align: start;
  max-inline-size: 60ch;
}
```

```html
<p class="message">Привет!</p>              <!-- акцент слева -->
<p class="message" dir="rtl">مرحبا</p>      <!-- акцент автоматически справа -->
```

## Сокращения, которые удобны и без RTL

```css
.box {
  margin-inline: auto;       /* центрирование: вместо margin-left: auto; margin-right: auto */
  padding-block: 1rem 2rem;  /* сверху 1rem, снизу 2rem */
  inset: 0;                  /* top/right/bottom/left: 0 */
}
```

## Что важно помнить

- Логические свойства нужны для интернационализации: RTL-языки (арабский, иврит) и вертикальное письмо работают без отдельных стилей.
- Даже без RTL короткие `margin-inline`, `padding-block`, `inset` делают код компактнее.
- Направление задают атрибутом `dir="rtl"` в HTML, а не только CSS-свойством `direction`.
- Container queries и единицы `cqi`/`cqb`, `vi`/`vb` тоже используют логические оси.
- Flexbox и Grid уже логические: `justify-content: flex-start` в RTL прижимает к правому краю.

## Мини-шпаргалка

inline — вдоль строки, block — поперек. `margin-inline-start` вместо `margin-left`, `inline-size` вместо `width`, `inset` вместо `top/left`, `text-align: start`. Один CSS для LTR и RTL.
