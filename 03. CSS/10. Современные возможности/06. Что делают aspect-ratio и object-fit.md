# Что делают aspect-ratio и object-fit

> [!NOTE]
> `aspect-ratio` задает элементу **соотношение сторон**: браузер вычисляет одну сторону по другой (`aspect-ratio: 16 / 9`). `object-fit` определяет, **как содержимое** замещаемого элемента (`<img>`, `<video>`) вписывается в его рамку: растянуть, вписать целиком (`contain`) или заполнить с обрезкой (`cover`). Вместе они дают адаптивные карточки, превью и видео без «прыжков» верстки и искажений.

## Вопрос

Что делают `aspect-ratio` и `object-fit`? Как сделать адаптивную картинку или видео нужной пропорции без искажений и без CLS?

## aspect-ratio

```css
.video {
  width: 100%;
  aspect-ratio: 16 / 9;   /* высота = ширина × 9 / 16 */
}

.avatar {
  width: 64px;
  aspect-ratio: 1;        /* квадрат */
}
```

Раньше пропорцию держали «хаком» с `padding-top: 56.25%` у обертки. `aspect-ratio` делает то же без лишней разметки.

Правила:

- работает, если задана только одна сторона (или `auto`); если заданы и `width`, и `height`, пропорция игнорируется;
- `min-height` и содержимое могут растянуть блок сильнее пропорции;
- у `<img>` с атрибутами `width` и `height` браузер сам вычисляет `aspect-ratio` и резервирует место до загрузки — это предотвращает CLS.

## object-fit

| Значение | Что происходит |
| --- | --- |
| `fill` (по умолчанию) | растягивает содержимое по рамке, пропорции искажаются |
| `contain` | вписывает целиком, остаются пустые поля |
| `cover` | заполняет рамку целиком, лишнее обрезается |
| `none` | исходный размер, без масштабирования |
| `scale-down` | как `none` или `contain` — что меньше |

`object-position` задает точку привязки: что останется видно при обрезке.

```css
.card__image {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  object-position: center top;   /* при обрезке сохранить верх кадра (лица) */
}
```

```html
<img class="card__image" src="photo.jpg" width="800" height="600" alt="Команда на митапе" />
```

## Сравнение с background-size

| | `object-fit` | `background-size` |
| --- | --- | --- |
| Для чего | `<img>`, `<video>` | фоновые изображения |
| Семантика и `alt` | есть | нет |
| `loading="lazy"`, `srcset` | работают | нет |

Содержательные картинки — через `<img>` + `object-fit`; декоративные — через `background`.

## Что важно помнить

- `aspect-ratio` + атрибуты `width`/`height` у изображений — основной способ избежать CLS.
- `object-fit: cover` обрезает края — проверяйте, что важная часть кадра не пропадает, или настройте `object-position`.
- `object-fit` работает только с замещаемыми элементами (`img`, `video`, `iframe` частично), а не с `div`.
- `aspect-ratio` проигрывает явной высоте: не задавайте одновременно `height`, если нужна пропорция.

## Мини-шпаргалка

`aspect-ratio: 16 / 9` — пропорция из одной стороны. `object-fit: cover` — заполнить с обрезкой, `contain` — вписать целиком. `object-position` — что оставить при обрезке. `width`/`height` у `<img>` — резерв места и нет CLS.
