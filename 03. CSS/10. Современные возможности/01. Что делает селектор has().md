# Что делает селектор has()?

> [!NOTE]
> `:has()` - это CSS-псевдокласс, который выбирает элемент, если внутри него или рядом с ним есть элемент, подходящий под указанное условие. Его часто называют "родительским селектором".

## Вопрос

Что делает селектор `:has()` и почему его называют «родительским селектором»?

## Главное

```css
.field:has(input:invalid) {
  border-color: #b91c1c;
}
```

Правило выберет `.field`, если внутри него есть невалидный `input`.

## Пример формы

```html
<label class="field">
  <span>Email</span>
  <input type="email" required>
</label>
```

```css
.field:has(input:focus-visible) {
  outline: 2px solid #2563eb;
}

.field:has(input:invalid) {
  color: #b91c1c;
}
```

Родитель меняет стиль в зависимости от состояния дочернего поля.

## Пример карточки

```css
.card:has(.card__image) {
  display: grid;
  grid-template-columns: 160px 1fr;
}
```

Карточка получает другой layout, если внутри есть изображение.

## Почему важно

Раньше для таких сценариев часто нужен был JavaScript или дополнительный класс на родителе. `:has()` позволяет часть логики выразить в CSS.

## Что важно помнить

- `:has()` смотрит вниз и вправо: `h2:has(+ p)` выбирает заголовок, за которым идет абзац.
- Специфичность `:has()` равна самому специфичному аргументу.
- Внутри `:has()` нельзя использовать псевдоэлементы и другой `:has()`.
- Типичные применения: стили формы с ошибкой, карточка с картинкой, блокировка прокрутки `body:has(dialog[open])`.

## Мини-шпаргалка

- `:has()` выбирает элемент по условию внутри или рядом.
- Частый сценарий: стилизовать родителя по состоянию ребенка.
- Полезен для форм, карточек, меню и layout-условий.
- Может заменить часть JS-классов.
- Сложные `:has()`-селекторы нужно писать осторожно.
