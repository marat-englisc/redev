# Как выбрать каждый второй элемент списка?

> [!NOTE]
> Каждый второй элемент списка выбирают через структурный псевдокласс `:nth-child(2n)` или `:nth-child(even)`.

## Вопрос

Как выбрать каждый второй элемент списка? Чем `:nth-child()` отличается от `:nth-of-type()`?

## Главное

```css
li:nth-child(2n) {
  background: #f3f4f6;
}
```

Это правило выберет 2-й, 4-й, 6-й и все следующие четные элементы.

## Более читаемая запись

```css
li:nth-child(even) {
  background: #f3f4f6;
}
```

`even` означает четные элементы.

## Нечетные элементы

```css
li:nth-child(odd) {
  font-weight: 700;
}
```

`odd` выбирает 1-й, 3-й, 5-й элементы.

## Пример с таблицей

```css
tbody tr:nth-child(even) {
  background: #f9fafb;
}
```

Так часто делают "зебру" в таблицах.

## Формула nth-child

```css
li:nth-child(3n) {
  color: #2563eb;
}
```

Выберет каждый третий элемент.

```css
li:nth-child(3n + 1) {
  color: #b91c1c;
}
```

Выберет 1-й, 4-й, 7-й и так далее.

## Что важно помнить

- Формула `an+b`: `2n` — четные, `2n+1` — нечетные, `3n` — каждый третий, `-n+3` — первые три, `n+4` — начиная с четвертого.
- `:nth-child()` считает всех детей независимо от тега, `:nth-of-type()` — только элементы своего типа.
- `:nth-child(2n of .visible)` считает только элементы с классом — удобно для отфильтрованных списков.
- Для «зебры» в таблицах применяйте к `tr` внутри `tbody`, чтобы не учитывать строки заголовка.

## Мини-шпаргалка

- Каждый второй: `:nth-child(2n)`.
- Четные: `:nth-child(even)`.
- Нечетные: `:nth-child(odd)`.
- Каждый третий: `:nth-child(3n)`.
- `nth-child` считает элемент среди всех соседей.
