# Что делает root?

> [!NOTE]
> `:root` - это CSS-псевдокласс, который выбирает корневой элемент документа. В HTML это элемент `<html>`. Чаще всего `:root` используют для объявления глобальных CSS-переменных.

## Вопрос

Что делает псевдокласс `:root` и почему CSS-переменные объявляют в нем?

## Главное

```css
:root {
  --color-primary: #2563eb;
  --space-md: 16px;
  --radius-md: 8px;
}
```

В HTML-документе `:root` обычно соответствует тегу `<html>`.

```html
<html lang="ru">
  ...
</html>
```

## Почему не просто html

В обычном HTML `:root` и `html` выбирают один и тот же элемент, но `:root` имеет более высокую специфичность, потому что это псевдокласс.

```css
html {
  font-size: 16px;
}

:root {
  color-scheme: light dark;
}
```

`html` часто используют для базовых настроек документа, а `:root` - для дизайн-токенов.

## CSS-переменные

Переменные, объявленные в `:root`, доступны всему документу через наследование.

```css
:root {
  --surface: #ffffff;
  --text: #111827;
}

body {
  background: var(--surface);
  color: var(--text);
}
```

## Темизация

```css
:root {
  --page-bg: #ffffff;
  --text-color: #111827;
}

[data-theme="dark"] {
  --page-bg: #111827;
  --text-color: #f9fafb;
}
```

Так можно менять тему, переопределяя переменные.

## Что важно помнить

- `:root` в HTML — это `html`, но со специфичностью класса `0-1-0`.
- В SVG-документе `:root` — это элемент `svg`, поэтому `:root` универсальнее `html`.
- Внутри Shadow DOM `:root` не работает — для компонента используют `:host`.
- Темы удобно переключать атрибутом на корне: `:root[data-theme="dark"] { --bg: #111; }`.

## Мини-шпаргалка

- `:root` выбирает корневой элемент документа.
- В HTML это `<html>`.
- Частый сценарий - глобальные CSS-переменные.
- `:root` специфичнее селектора `html`.
- Переменные из `:root` удобно использовать для дизайн-токенов и тем.
