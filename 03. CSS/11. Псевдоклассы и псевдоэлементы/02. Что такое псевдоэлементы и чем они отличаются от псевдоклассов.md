# Что такое псевдоэлементы, какие они бывают и чем отличаются от псевдоклассов?

> [!NOTE]
> **Псевдоэлемент** — часть селектора с двумя двоеточиями, которая стилизует виртуальную часть элемента или создает сгенерированный контент: `::before`, `::after`, `::first-line`, `::first-letter`, `::placeholder`, `::selection`, `::marker`, `::backdrop`. Псевдокласс выбирает **состояние** элемента, а псевдоэлемент — его **часть**. Специфичность псевдоэлемента равна тегу — `0-0-1`.

## Вопрос

Что такое псевдоэлемент? Какие псевдоэлементы вы знаете? Чем псевдоэлемент отличается от псевдокласса?

## Отличие от псевдокласса

```css
button:hover { background: #2563eb; }      /* состояние кнопки */
button::before { content: "→ "; }          /* новая виртуальная часть */
```

| | Псевдокласс | Псевдоэлемент |
| --- | --- | --- |
| Синтаксис | одно двоеточие `:hover` | два двоеточия `::before` |
| Что выбирает | состояние или условие | часть элемента |
| Создает узел | нет | `::before`/`::after` создают блок в рендере |
| Специфичность | `0-1-0` | `0-0-1` |
| Количество в селекторе | сколько угодно | один, в конце |

Можно сочетать: `button:hover::after`. Старый синтаксис с одним двоеточием (`:before`) поддерживается для совместимости, но в новом коде пишут `::`.

## Основные псевдоэлементы

| Псевдоэлемент | Что делает |
| --- | --- |
| `::before` / `::after` | сгенерированный контент в начале / конце содержимого |
| `::first-line` | первая строка текста блока |
| `::first-letter` | первая буква (буквица) |
| `::placeholder` | текст placeholder в поле |
| `::selection` | выделенный пользователем текст |
| `::marker` | маркер или номер пункта списка |
| `::backdrop` | фон под `<dialog>` и полноэкранным элементом |
| `::file-selector-button` | кнопка в `input type="file"` |
| `::view-transition-*` | части View Transitions |

```css
p::first-letter {
  float: left;
  font-size: 3em;
  line-height: 1;
}

li::marker { color: #2563eb; }

::selection {
  background: #fde68a;
  color: #111827;
}

dialog::backdrop {
  background: rgb(0 0 0 / 0.5);
}

input[type="file"]::file-selector-button {
  border: 0;
  padding: 0.5em 1em;
}
```

## Ограничения

- `::first-line` и `::first-letter` работают только у блочных элементов и поддерживают ограниченный набор свойств (шрифт, цвет, фон, отступы для буквицы).
- `::selection` поддерживает только цвет, фон, тени текста и декорации.
- `::before` и `::after` не работают у replaced-элементов без содержимого: `img`, `input`, `br`, `iframe`.
- Псевдоэлементы нельзя выбрать через `querySelector`, но их стили можно прочитать: `getComputedStyle(el, "::before")`.

## Что важно помнить

- `::placeholder` по умолчанию бледный — проверяйте контраст.
- `::marker` поддерживает ограниченный набор свойств: `color`, `font`, `content`.
- Псевдоэлемент всегда пишется в самом конце составного селектора: `.a::before:hover` невалиден, нужно `.a:hover::before`.
- Сгенерированный контент озвучивается скринридерами, а скопировать его как текст нельзя.

## Мини-шпаргалка

- Псевдоэлемент — часть элемента, `::`.
- `::before`/`::after` — сгенерированный контент, нужен `content`.
- `::first-line`, `::first-letter`, `::placeholder`, `::selection`, `::marker`, `::backdrop`.
- Псевдокласс — состояние, псевдоэлемент — часть.
- Специфичность как у тега.
