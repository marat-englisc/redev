# Что делают ::before и ::after и где они располагаются в потоке?

> [!NOTE]
> `::before` и `::after` создают сгенерированный блок **внутри** элемента: `::before` — перед первым дочерним узлом, `::after` — после последнего. Без свойства `content` (хотя бы `content: ""`) они не появятся. По умолчанию это inline-элементы, которые участвуют в потоке как обычные дети и могут быть flex- и grid-элементами.

## Вопрос

Что делает `::before`? Где располагаются `::before` и `::after` в потоке документа?

## Положение в дереве рендера

```html
<p class="note">Текст заметки</p>
```

Браузер рендерит это так, как если бы разметка была:

```text
<p class="note">
  [::before]
  Текст заметки
  [::after]
</p>
```

Псевдоэлементы — **дети** элемента, а не соседи. Поэтому они наследуют его стили (`color`, `font`) и находятся внутри его padding box.

## content

```css
.required::after {
  content: " *";
  color: #b91c1c;
}

a[href^="http"]::after {
  content: " ↗";
}

.price::before {
  content: attr(data-currency) " ";
}

.chapter::before {
  counter-increment: chapter;
  content: "Глава " counter(chapter) ". ";
}

.icon::before {
  content: "";
  display: inline-block;
  width: 1em;
  height: 1em;
  background: url("/icons/check.svg") center / contain no-repeat;
}
```

Значения `content`: строка, `attr()`, `counter()`, `url()`, `open-quote` / `close-quote`, пустая строка. Альтернативный текст для скринридера: `content: "★" / "Избранное"`.

## Участие в потоке

- по умолчанию `display: inline` — встают в строку с текстом;
- с `display: block` занимают отдельную строку внутри элемента;
- во flex- или grid-контейнере становятся обычными flex/grid-элементами;
- с `position: absolute` выходят из потока и позиционируются относительно элемента (если у него `position: relative`).

```css
.tooltip {
  position: relative;
}

.tooltip::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 8px);
  left: 50%;
  transform: translateX(-50%);
  white-space: nowrap;
}
```

## Типичные применения

- декоративные иконки, стрелки, кавычки;
- маркеры обязательных полей и внешних ссылок;
- оверлеи и градиенты поверх изображений;
- clearfix (`::after { content: ""; display: table; clear: both; }`) в legacy-коде;
- увеличение области клика без изменения размера: `::before { position: absolute; inset: -8px; }`.

## Что важно помнить

- Не кладите в `content` важный текст: его нельзя выделить и скопировать, а поддержка скринридерами неодинакова.
- У `img`, `input`, `br` и других replaced/void-элементов `::before`/`::after` не работают.
- У каждого элемента только по одному `::before` и `::after`.
- Псевдоэлементы недоступны из JS как DOM-узлы, поэтому на них нельзя повесить обработчик события.

## Мини-шпаргалка

- `::before` — первым ребенком, `::after` — последним.
- Обязателен `content`, хотя бы `""`.
- По умолчанию inline, наследуют стили родителя.
- `position: absolute` + родитель с `relative` — для тултипов и оверлеев.
- Только декоративный контент.
