# Что такое БЭМ и как организовать стили на SCSS

> [!NOTE]
> **БЭМ (Блок, Элемент, Модификатор)** — методология именования CSS-классов от Яндекса: `block`, `block__element`, `block--modifier`. Она дает плоскую специфичность (один класс), понятную структуру и защиту от конфликтов имен. **SCSS** хорошо сочетается с БЭМ: вложенность через `&__` и `&--`, переменные, миксины и модули `@use` позволяют писать компактно, не увеличивая специфичность.

## Вопрос

Что такое БЭМ и зачем он нужен? Как с БЭМ использовать SCSS: вложенность, миксины, переменные? Какие у этого подхода подводные камни?

## Основная идея

| Сущность | Что это | Пример класса |
| --- | --- | --- |
| Блок | самостоятельный компонент | `card`, `search-form` |
| Элемент | часть блока, вне блока не используется | `card__title`, `card__image` |
| Модификатор | вариант внешнего вида или состояния | `card--featured`, `button--disabled` |

```html
<article class="card card--featured">
  <img class="card__image" src="..." alt="" />
  <h2 class="card__title">Заголовок</h2>
  <button class="button button--primary card__button">Купить</button>
</article>
```

Правила:

- стилизуем только по классам, не по тегам и id;
- нет элементов элементов: `card__body__title` — плохо, `card__title` — хорошо;
- модификатор всегда добавляется **вместе** с базовым классом: `button button--primary`;
- блок не задает себе внешние отступы и позицию — это делает родитель через **микс**: `card__button` на блоке `button`.

## БЭМ на SCSS

```scss
@use "sass:math";
@use "tokens" as t;          // переменные из модуля tokens.scss

@mixin focus-ring($color: t.$primary) {
  outline: 2px solid $color;
  outline-offset: 2px;
}

.card {
  padding: t.$space-4;
  border-radius: t.$radius;

  &__title {                 // → .card__title (специфичность одного класса)
    font-size: 1.25rem;
  }

  &__image {
    width: 100%;
    aspect-ratio: 16 / 9;
    object-fit: cover;
  }

  &--featured {              // → .card--featured
    border: 2px solid t.$primary;
  }

  &--featured &__title {     // → .card--featured .card__title
    color: t.$primary;
  }

  &:focus-within {
    @include focus-ring;
  }
}
```

`&__title` — это конкатенация строки, а не вложенный селектор: в итоговом CSS получается `.card__title`, без лишней вложенности.

## Возможности SCSS, которые спрашивают

| Возможность | Синтаксис | Для чего |
| --- | --- | --- |
| Переменные | `$primary: #2563eb;` | значения на этапе сборки |
| Вложенность | `&:hover`, `&__el`, `.parent &` | группировка правил |
| Миксины | `@mixin name($arg) {}` / `@include name` | переиспользуемые наборы свойств |
| Placeholder и `@extend` | `%btn-base {}` / `@extend %btn-base` | общие правила (осторожно, раздувает селекторы) |
| Функции | `@function rem($px) { @return math.div($px, 16) * 1rem; }` | вычисления |
| Модули | `@use`, `@forward` | вместо устаревшего `@import` |
| Циклы и условия | `@each`, `@for`, `@if` | генерация утилит |

## SCSS-переменные и CSS-переменные

| | `$var` (SCSS) | `--var` (CSS) |
| --- | --- | --- |
| Когда вычисляется | при сборке | в браузере |
| Меняется в рантайме и по media query | нет | да |
| Наследуется по DOM | нет | да |
| Применение | токены, вычисления | темы, дизайн-токены в рантайме |

Сегодня часто используют оба: SCSS для миксинов и функций, CSS-переменные для тем.

## Что важно помнить

- БЭМ держит специфичность плоской (один класс) — меньше войн специфичности и `!important`.
- Не вкладывайте глубже 2–3 уровней: `.a .b .c .d` в SCSS превращается в тяжелые селекторы с высокой специфичностью.
- `@import` в Sass устарел — используйте `@use` и `@forward`.
- `@extend` между разными файлами дает непредсказуемый CSS; для повторяющихся стилей обычно лучше миксин.
- В компонентном подходе (CSS Modules, CSS-in-JS) БЭМ менее нужен: изоляцию дает сборка, но идея «блок — элемент — модификатор» остается полезной для именования.
- Нативная вложенность CSS (`&`) уже поддерживается браузерами, но конкатенацию `&__title` она не умеет — это возможность Sass.

## Мини-шпаргалка

БЭМ: `block`, `block__element`, `block--modifier`, только классы, без элементов элементов. SCSS: `&__el`, `&--mod`, `$var`, `@mixin`/`@include`, `@use`. Вложенность — не глубже 2–3 уровней.
