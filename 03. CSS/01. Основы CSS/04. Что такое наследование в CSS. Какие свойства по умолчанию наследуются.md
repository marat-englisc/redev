# Что такое наследование в CSS. Какие свойства по умолчанию наследуются?

> [!NOTE]
> **Наследование в CSS** - это механизм, при котором некоторые свойства автоматически переходят от родительского элемента к дочерним. Чаще всего наследуются свойства текста, языка и видимости, но не размеры блоков и отступы.

## Вопрос

Что такое наследование в CSS? Какие свойства наследуются по умолчанию и как управлять наследованием?

## Главное

```css
body {
  font-family: system-ui, sans-serif;
  color: #111827;
}
```

```html
<body>
  <main>
    <p>Этот текст унаследует шрифт и цвет от body.</p>
  </main>
</body>
```

`p` получит `font-family` и `color`, если для него не задано другое значение.

## Что обычно наследуется

| Категория | Примеры |
| --- | --- |
| Текст | `color`, `font-family`, `font-size`, `font-weight`, `line-height` |
| Текстовое поведение | `text-align`, `letter-spacing`, `word-spacing` |
| Списки | `list-style` |
| Язык и направление | `direction`, `visibility` |

## Что обычно не наследуется

```css
.card {
  margin: 24px;
  padding: 16px;
  border: 1px solid #ddd;
}
```

`margin`, `padding`, `border`, `width`, `height`, `background` не переходят автоматически к детям. Иначе layout быстро стал бы хаотичным.

## Принудительное наследование

```css
.link {
  color: inherit;
}
```

`inherit` заставляет свойство взять значение у родителя.

## Сброс к начальному значению

```css
.box {
  color: initial;
}
```

`initial` возвращает свойство к начальному значению по спецификации.

## Что важно помнить

- `unset` ведет себя как `inherit` для наследуемых свойств и как `initial` для ненаследуемых, `revert` возвращает браузерный стиль.
- CSS-переменные наследуются всегда (если не зарегистрированы через `@property` с `inherits: false`).
- Унаследованное значение слабее любого правила, которое напрямую выбирает элемент, даже `*`.
- Элементы форм по умолчанию не наследуют шрифт — для них пишут `font: inherit`.
- Наследование идет по DOM-дереву, а не по визуальному положению: абсолютный ребенок наследует от DOM-родителя.

## Мини-шпаргалка

- Наследуются в основном текстовые свойства.
- Layout-свойства обычно не наследуются.
- `inherit` принудительно берет значение родителя.
- `initial` сбрасывает к начальному значению.
- Наследование помогает задавать базовую типографику на `body`.
