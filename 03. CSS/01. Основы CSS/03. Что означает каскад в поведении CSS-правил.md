# Что означает каскад в поведении CSS-правил?

> [!NOTE]
> **Каскад** - это механизм CSS, который решает, какое объявление применить к элементу, если на одно и то же свойство претендуют несколько правил.

## Вопрос

Что такое каскад в CSS? По каким критериям браузер выбирает итоговое значение свойства?

## Главное

CSS может получить несколько значений для одного свойства.

```css
p {
  color: black;
}

.lead {
  color: blue;
}
```

```html
<p class="lead">Важный абзац</p>
```

Для этого абзаца победит `color: blue`, потому что селектор класса специфичнее селектора тега.

## Что учитывает каскад

Упрощенный порядок:

1. Важность объявления: обычное или `!important`.
2. Источник стилей: браузер, пользователь, автор страницы.
3. Cascade layers, если используются `@layer`.
4. Специфичность селектора.
5. Порядок объявления в CSS.

## Специфичность

```css
button {
  color: black;
}

.button {
  color: blue;
}
```

Класс `.button` специфичнее тега `button`.

## Порядок правил

Если специфичность одинаковая, побеждает правило, которое написано позже.

```css
.button {
  color: black;
}

.button {
  color: red;
}
```

Итоговый цвет будет `red`.

## Почему каскад важен

Каскад позволяет писать базовые стили, переопределять их в компонентах, добавлять состояния и темы без дублирования всей таблицы стилей.

## Что важно помнить

- Порядок проверки: происхождение и важность → контекст (Shadow DOM) → cascade layers → специфичность → порядок в коде.
- `!important` переворачивает порядок происхождения и слоев: `!important` в нижнем слое сильнее, чем в верхнем.
- Стили вне `@layer` сильнее стилей в любых слоях — это удобно для переопределения сторонних библиотек.
- Итоговое значение и «проигравшие» правила видно в DevTools → Styles (зачеркнутые объявления).

## Мини-шпаргалка

- Каскад выбирает победившее CSS-объявление.
- `!important` резко повышает приоритет.
- Специфичность зависит от типа селектора.
- При равной специфичности побеждает правило ниже.
- Каскад делает CSS гибким, но требует дисциплины.
