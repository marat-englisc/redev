# Какие бывают единицы измерения в CSS: абсолютные и относительные?

> [!NOTE]
> **Абсолютные единицы** (`px`, `cm`, `mm`, `in`, `pt`) имеют фиксированный размер. **Относительные** (`%`, `em`, `rem`, `vw`, `vh`, `ch`, `cqi`) рассчитываются от другого значения: шрифта, родителя, viewport или контейнера. В интерфейсах чаще всего используют `px` для мелких точных деталей и `rem` для типографики и отступов.

## Вопрос

Какие абсолютные и относительные единицы измерения есть в CSS? Чем `em` отличается от `rem`? Когда использовать `px`, а когда относительные единицы?

## Абсолютные единицы

| Единица | Название | Соотношение |
| --- | --- | --- |
| `px` | CSS pixel | базовая единица |
| `in` | дюйм | `1in = 96px` |
| `cm` | сантиметр | `1cm ≈ 37.8px` |
| `mm` | миллиметр | `1mm ≈ 3.78px` |
| `Q` | четверть миллиметра | `1Q = 0.25mm` |
| `pt` | пункт | `1pt = 1/72in` |
| `pc` | пика | `1pc = 12pt` |

`px` в CSS — не физический пиксель экрана, а «эталонный» пиксель. На Retina-экране один CSS-пиксель занимает 2×2 или 3×3 физических (`window.devicePixelRatio`). Печатные единицы `cm`, `mm`, `pt` полезны в стилях для печати:

```css
@media print {
  @page { margin: 2cm; }
  body { font-size: 12pt; }
}
```

## Относительные единицы

| Единица | Относительно чего |
| --- | --- |
| `%` | Родителя или контекста свойства |
| `em` | `font-size` текущего элемента (для самого `font-size` — родителя) |
| `rem` | `font-size` корневого элемента `html` |
| `vw` / `vh` | 1% ширины / высоты viewport |
| `vmin` / `vmax` | 1% меньшей / большей стороны viewport |
| `svh` / `lvh` / `dvh` | малый, большой и динамический viewport на мобильных |
| `ch` | Ширина символа `0` |
| `ex` | Высота строчной буквы `x` |
| `lh` / `rlh` | `line-height` элемента / корня |
| `cqw` / `cqi` | 1% ширины / inline-размера контейнера (container queries) |

## rem и em

```css
html { font-size: 100%; } /* обычно 16px — уважаем настройки пользователя */

.title { font-size: 2rem; } /* 32px */

.button {
  font-size: 1rem;
  padding: 0.5em 1em; /* отступы растут вместе с размером шрифта кнопки */
}
```

`rem` предсказуем: всегда от корня. `em` компаундится: вложенный `font-size: 1.2em` в `1.2em` дает `1.44` от исходного размера. Поэтому `rem` удобен для типографики и отступов страницы, а `em` — для внутренних отступов компонента, которые должны масштабироваться вместе с его текстом.

## Проценты

Контекст `%` зависит от свойства:

- `width`, `padding`, `margin` (даже вертикальные!) — от **ширины** содержащего блока;
- `height` — от высоты родителя, только если она задана явно;
- `font-size` — от шрифта родителя;
- `transform: translate(50%)` — от размеров самого элемента.

## Viewport units

```css
.hero {
  min-height: 100dvh;
}
```

На мобильных `100vh` равен высоте при скрытой адресной строке, поэтому контент может уходить под нее. `dvh` подстраивается под текущую высоту, `svh` — под минимальную.

## Когда что использовать

| Задача | Единица |
| --- | --- |
| Границы, тонкие линии, тени | `px` |
| Размер шрифта, отступы, ширина контейнера | `rem` |
| Отступы внутри кнопки или бейджа | `em` |
| Ширина колонок | `%`, `fr` |
| Высота первого экрана | `dvh`, `svh` |
| Длина строки текста | `ch` (`max-width: 65ch`) |
| Fluid-типографика | `clamp()` с `rem` и `vw` |

## Что важно помнить

- Не задавайте `html { font-size: 10px }` или `62.5%` без нужды: это ломает пользовательские настройки шрифта и усложняет поддержку.
- Только `px` в `font-size` не масштабируется при изменении размера шрифта в настройках браузера (масштаб страницы при этом работает).
- `vw` в `font-size` без `clamp()` нарушает доступность: текст не увеличивается зумом пропорционально.
- В media queries `em` ведет себя одинаково во всех браузерах при изменении шрифта, поэтому брейкпоинты часто пишут в `em`.

## Мини-шпаргалка

- Абсолютные: `px` (основная), печатные `cm`, `mm`, `pt`.
- Относительные: `%`, `em`, `rem`, `vw`/`vh`, `dvh`, `ch`, `cqi`.
- `rem` — от корня, `em` — от текущего шрифта и компаундится.
- `%` для `padding`/`margin` считается от ширины родителя.
- Шрифты — в `rem`, линии — в `px`.
