# Что делает !important. Почему !important считается антипаттерном?

> [!NOTE]
> `!important` повышает приоритет CSS-объявления и заставляет его побеждать обычные правила каскада. Его считают антипаттерном, потому что он усложняет переопределение стилей и быстро превращает CSS в борьбу приоритетов.

## Вопрос

Что делает `!important` и почему его считают антипаттерном? Чем его заменить?

## Главное

```css
.button {
  color: red !important;
}
```

Такое объявление будет сильнее обычных объявлений, даже если у них выше специфичность.

## Почему это опасно

Если стиль с `!important` нужно переопределить, часто приходится писать еще один `!important`.

```css
.modal .button {
  color: blue !important;
}
```

Так CSS становится менее предсказуемым.

## Когда !important иногда оправдан

- Утилитарные классы, которые намеренно должны побеждать.
- Быстрый временный фикс в legacy-коде.
- Переопределение inline-стилей стороннего виджета.
- Accessibility-правила, которые нельзя случайно отключить.

```css
.visually-hidden {
  position: absolute !important;
  width: 1px !important;
  height: 1px !important;
}
```

Даже в этих случаях важно понимать причину.

## Чем заменить

- Улучшить порядок подключения CSS.
- Уменьшить лишнюю специфичность.
- Использовать понятные классы состояния.
- Разделить стили по компонентам.
- Применить cascade layers.

```css
.button.is-active {
  color: blue;
}
```

## Что важно помнить

- Inline-стиль с `!important` нельзя перебить из стилей, только другим inline-стилем или JS.
- `!important` в анимации (`@keyframes`) игнорируется.
- Cascade layers решают задачу «стили библиотеки сильнее моих» без `!important`: библиотеку кладут в нижний слой.
- Правило Stylelint `declaration-no-important` помогает контролировать использование `!important` в проекте.

## Мини-шпаргалка

- `!important` повышает приоритет объявления.
- Он ломает естественный каскад.
- Частое использование затрудняет поддержку.
- Лучше решать проблему структурой CSS и специфичностью.
- Иногда допустим в утилитах и legacy-переопределениях.
