# Что такое CSS и для чего он используется?

> [!NOTE]
> **CSS** (Cascading Style Sheets) - это язык стилей, который описывает внешний вид HTML-документа: цвета, шрифты, размеры, отступы, сетки, адаптивность, анимации и визуальные состояния интерфейса.

## Вопрос

Что такое CSS и для чего он используется? Как подключить стили к странице?

## Главное

HTML описывает структуру и смысл страницы, а CSS отвечает за то, как эта структура выглядит.

```html
<button class="button">Сохранить</button>
```

```css
.button {
  padding: 8px 12px;
  border: 0;
  background: #2563eb;
  color: white;
}
```

CSS не меняет семантику кнопки, но задает ее визуальный стиль.

## Что можно делать с CSS

- Управлять цветами, шрифтами и размерами текста.
- Настраивать отступы, рамки, тени и фон.
- Строить layout через Flexbox и Grid.
- Делать адаптивность через media queries.
- Описывать hover, focus, disabled и другие состояния.
- Создавать transitions и animations.
- Использовать переменные и современные функции.

## Где подключается CSS

```html
<link rel="stylesheet" href="/styles.css">
```

CSS обычно подключают в `head`, чтобы браузер мог применить стили до первого отображения страницы.

## CSS как каскад

В CSS может быть несколько правил для одного элемента. Итоговый стиль определяется каскадом: важностью, специфичностью, порядком, слоями и наследованием.

```css
p {
  color: black;
}

.lead {
  color: #2563eb;
}
```

Если абзац имеет `class="lead"`, победит более специфичное правило.

## Что важно помнить

- Три способа подключения: внешний файл через `<link>`, `<style>` в документе и атрибут `style`. Для проектов — внешние файлы: они кешируются.
- `@import` внутри CSS загружает файлы последовательно и замедляет рендеринг — в production его заменяет сборщик.
- CSS блокирует рендеринг: браузер не показывает страницу, пока не загрузит стили из `head`.
- Современный CSS развивается модулями (Selectors, Grid, Color и т. д.), а не версиями «CSS4».

## Мини-шпаргалка

- CSS отвечает за внешний вид страницы.
- Правило состоит из селектора и блока объявлений.
- CSS работает вместе с HTML и JavaScript.
- Каскад решает, какие стили победят.
- Layout чаще строят через Flexbox и Grid.
- Доступные состояния `:focus-visible`, `:hover`, `:disabled` тоже описываются CSS.
