# Что такое reset CSS и normalize.css?

> [!NOTE]
> **Reset CSS** сбрасывает браузерные стили по умолчанию почти до нуля, чтобы верстка начиналась с чистого листа. **normalize.css** мягче: сохраняет полезные дефолты и выравнивает различия между браузерами. Современные проекты чаще используют небольшой собственный «modern reset».

## Вопрос

Что такое reset CSS? Что делает normalize.css и чем он отличается от reset? Что выбрать в новом проекте?

## Зачем это нужно

У каждого браузера есть user agent stylesheet: отступы у `body` и заголовков, маркеры списков, стили кнопок и полей. Они немного различаются между браузерами и часто мешают дизайну.

```text
browser defaults
  -> reset / normalize / modern reset
  -> project styles
```

## Reset CSS

Классический reset (например, Eric Meyer's Reset) обнуляет почти всё:

```css
* {
  margin: 0;
  padding: 0;
}

ul, ol { list-style: none; }
h1, h2, h3 { font-size: inherit; font-weight: inherit; }
```

Плюс — полный контроль. Минус — приходится заново восстанавливать полезные стили: отступы абзацев, маркеры списков в статьях, видимость заголовков в тексте из CMS.

## normalize.css

normalize не обнуляет, а **выравнивает**:

- исправляет различия в отображении HTML5-элементов;
- делает одинаковыми шрифты и `line-height` у элементов форм;
- исправляет баги конкретных браузеров;
- сохраняет полезные дефолты: отступы заголовков и списков.

| Подход | Идея | Когда |
| --- | --- | --- |
| Reset | сбросить почти всё | дизайн-система, где всё стилизуется явно |
| normalize.css | сохранить дефолты и выровнять различия | контентные сайты, CMS |
| Modern reset | минимальный набор удобных правил | большинство современных проектов |

## Modern reset

Современные браузеры почти не различаются, поэтому часто хватает короткой базы:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100dvh;
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
}

input, button, textarea, select {
  font: inherit;
}

p, h1, h2, h3 {
  overflow-wrap: break-word;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

Похожие базы есть в популярных проектах: Josh Comeau's CSS Reset, `modern-normalize`, Preflight в Tailwind CSS.

## Что важно помнить

- `list-style: none` в Safari убирает семантику списка для VoiceOver — для навигации добавляйте `role="list"`.
- Не сбрасывайте `outline` у фокуса без замены: это ломает клавиатурную навигацию.
- `font: inherit` для полей формы нужен, потому что по умолчанию они не наследуют шрифт страницы.
- Reset подключают первым, до стилей проекта; с `@layer reset` его приоритет можно явно сделать самым низким.

## Мини-шпаргалка

- Reset — обнулить дефолты, normalize — выровнять их.
- Modern reset: `border-box`, `margin: 0` у `body`, адаптивные медиа, `font: inherit` у форм.
- Не убирайте фокус и семантику списков.
- Reset подключают первым или в низком `@layer`.
