# Что делают grid-template-columns, grid-template-rows и grid-template?

> [!NOTE]
> `grid-template-columns` задает количество и ширину колонок, `grid-template-rows` — количество и высоту явных строк. `grid-template` — шорткат для обоих свойств и `grid-template-areas`. Строки и колонки, которые не описаны явно, создаются автоматически и управляются `grid-auto-rows`, `grid-auto-columns` и `grid-auto-flow`.

## Вопрос

Что делают свойства `grid-template-columns`, `grid-template-rows` и `grid-template`? Чем явная сетка отличается от неявной?

## grid-template-columns

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;           /* sidebar + контент */
}

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);      /* три равные колонки */
  gap: 16px;
}

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); /* адаптивная сетка без media queries */
}
```

Каждое значение в списке — одна колонка. Можно смешивать `px`, `%`, `fr`, `auto`, `min-content`, `max-content`, `minmax()`, `fit-content()`.

## grid-template-rows

```css
.page {
  display: grid;
  grid-template-rows: auto 1fr auto; /* шапка, контент, подвал */
  min-height: 100dvh;
}
```

Классический sticky footer: средняя строка забирает всё свободное место, подвал прижат к низу.

## Именованные линии

```css
.layout {
  grid-template-columns: [full-start] 1fr [content-start] minmax(0, 720px) [content-end] 1fr [full-end];
}

.article { grid-column: content; }
.hero { grid-column: full; }
```

## grid-template-areas и шорткат grid-template

```css
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
}

/* то же самое одним свойством */
.layout {
  grid-template:
    "header  header" auto
    "sidebar main"   1fr
    "footer  footer" auto
    / 240px  1fr;
}
```

Шорткат читается как «картинка» сетки: строки с высотой справа, колонки после `/`.

## Явная и неявная сетка

**Явная сетка** — то, что описано в `grid-template-*`. Если элементов больше, браузер создает **неявные** строки (или колонки):

```css
.feed {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(120px, auto); /* высота автоматически созданных строк */
  grid-auto-flow: dense;               /* заполнять «дыры» */
}
```

| Свойство | Что задает |
| --- | --- |
| `grid-auto-rows` / `grid-auto-columns` | размер неявных треков |
| `grid-auto-flow: row` | добавлять строки (по умолчанию) |
| `grid-auto-flow: column` | добавлять колонки |
| `dense` | заполнять пропуски более поздними элементами |

## Что важно помнить

- `1fr` равен `minmax(auto, 1fr)`: колонка не сожмется меньше контента. Для гарантированно равных колонок используют `minmax(0, 1fr)`.
- `grid-template-areas` должен описывать прямоугольники: области в форме «Г» невалидны, и всё свойство игнорируется.
- Точка (`.`) в `grid-template-areas` обозначает пустую ячейку.
- `subgrid` (`grid-template-columns: subgrid`) позволяет вложенной сетке использовать колонки родителя — удобно выравнивать содержимое карточек.
- `grid-auto-flow: dense` меняет визуальный порядок — учитывайте доступность.

## Мини-шпаргалка

- `grid-template-columns` — колонки, `grid-template-rows` — строки.
- `grid-template` — шорткат для строк, колонок и областей.
- `auto 1fr auto` — шапка, контент, подвал.
- Неявные треки — `grid-auto-rows`, `grid-auto-flow`.
- `minmax(0, 1fr)` для честно равных колонок.
