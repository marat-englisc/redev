# Как размещать элементы в Grid: grid-column, grid-row и grid-area

> [!NOTE]
> Grid-элементы размещают по линиям сетки: `grid-column` и `grid-row` задают начальную и конечную линию (`1 / 3`) или растяжение (`span 2`). **Grid area** — прямоугольная область из одной или нескольких ячеек; ее можно назвать в `grid-template-areas` и указать у элемента через `grid-area: main`. Внутри ячейки элемент выравнивают `justify-self`, `align-self` и `place-self`.

## Вопрос

Что такое grid area? Какие свойства позиционируют элементы в Grid и как выровнять элемент внутри ячейки?

## Линии сетки

Сетка из 3 колонок имеет 4 вертикальные линии: `1 2 3 4`. Отрицательные номера считаются с конца: `-1` — последняя линия.

```css
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

.hero {
  grid-column: 1 / -1; /* от первой до последней линии — на всю ширину */
}

.featured {
  grid-column: span 2; /* две колонки от места авторазмещения */
  grid-row: span 2;
}

.sidebar {
  grid-column: 4;      /* только четвертая колонка */
  grid-row: 1 / 3;     /* две строки */
}
```

| Свойство | Значение |
| --- | --- |
| `grid-column-start` / `grid-column-end` | начальная и конечная вертикальная линия |
| `grid-row-start` / `grid-row-end` | начальная и конечная горизонтальная линия |
| `grid-column` | шорткат `start / end` |
| `grid-row` | шорткат `start / end` |
| `grid-area` | `row-start / column-start / row-end / column-end` или имя области |

## Grid area с именами

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

@media (max-width: 768px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  }
}
```

Меняя только шаблон областей, можно полностью перестроить раскладку под мобильный экран. Именованная область автоматически создает линии `header-start` и `header-end`.

## Наложение элементов

Элементы могут занимать одни и те же ячейки — так делают наложение без `position: absolute`:

```css
.card {
  display: grid;
}

.card > * {
  grid-area: 1 / 1; /* все дети в одной ячейке */
}

.card__caption {
  align-self: end;
  z-index: 1;
}
```

## Выравнивание внутри ячейки

| Свойство | Где | Ось |
| --- | --- | --- |
| `justify-items` | контейнер | inline (горизонталь) для всех |
| `align-items` | контейнер | block (вертикаль) для всех |
| `place-items` | контейнер | обе оси |
| `justify-self` / `align-self` / `place-self` | элемент | для одного элемента |
| `justify-content` / `align-content` | контейнер | выравнивание всей сетки, если она меньше контейнера |

```css
.center {
  display: grid;
  place-items: center; /* самый короткий способ центрирования */
}
```

## Что важно помнить

- Номер линии больше количества колонок создает неявные колонки — сетка неожиданно расширится.
- Явно размещенные элементы не меняют порядок в DOM: для клавиатуры и скринридера порядок остается исходным.
- `grid-area: 1 / 1` — короткая запись для «первая строка, первая колонка».
- В отличие от Flexbox, в Grid работает `justify-self`.

## Мини-шпаргалка

- Линии нумеруются с 1, `-1` — последняя.
- `grid-column: 1 / -1` — на всю ширину, `span 2` — на две ячейки.
- Grid area — прямоугольник ячеек, имена задаются в `grid-template-areas`.
- Наложение — одинаковый `grid-area` у нескольких элементов.
- `place-items: center` — центрирование.
