# Что означают fr, repeat() и minmax() в CSS Grid?

> [!NOTE]
> `fr` — доля свободного места в grid-контейнере: `1fr 2fr` делит остаток в соотношении 1:2. `repeat(n, size)` повторяет описание трека, а с `auto-fill` / `auto-fit` создает столько колонок, сколько помещается. `minmax(min, max)` задает диапазон размера трека. Вместе они дают адаптивную сетку без media queries: `repeat(auto-fill, minmax(220px, 1fr))`.

## Вопрос

Что означает единица `fr`? Что делают `repeat()` и `minmax()`? Чем `auto-fill` отличается от `auto-fit`?

## fr

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr 2fr;
  gap: 16px;
}
```

Сначала вычитаются фиксированные размеры и `gap`, затем остаток делится по `fr`:

```text
контейнер 1000px − 240px − 2 × 16px = 728px
1fr = 728 / 3 ≈ 243px, 2fr ≈ 485px
```

`fr` похож на `flex-grow`, но работает для сетки. В отличие от `%`, он учитывает `gap` и не вызывает переполнения.

## repeat()

```css
grid-template-columns: repeat(4, 1fr);           /* 1fr 1fr 1fr 1fr */
grid-template-columns: repeat(2, 100px 1fr);     /* 100px 1fr 100px 1fr */
grid-template-columns: 200px repeat(3, 1fr) 200px;
```

## minmax()

```css
grid-template-columns: minmax(200px, 300px) 1fr;
grid-auto-rows: minmax(120px, auto); /* минимум 120px, растет по контенту */
```

Трек не станет меньше `min` и больше `max`. В `max` можно указывать `fr`, а в `min` — нет.

## auto-fill и auto-fit

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}
```

Браузер создает столько колонок по 220px, сколько помещается, а остаток делит между ними. Разница проявляется, когда элементов мало:

| | `auto-fill` | `auto-fit` |
| --- | --- | --- |
| Пустые колонки | сохраняются | схлопываются в 0 |
| 2 карточки в широком контейнере | две колонки по ~220px + пустые | две растянутые колонки |
| Когда использовать | ровная сетка каталога | элементы должны заполнить ширину |

## Защита от переполнения

```css
grid-template-columns: repeat(auto-fill, minmax(min(220px, 100%), 1fr));
```

Без `min(220px, 100%)` на экране уже 220px колонка вылезет за контейнер.

## Ключевые слова размеров

| Значение | Смысл |
| --- | --- |
| `auto` | по контенту, растягивается при свободном месте |
| `min-content` | минимальная ширина контента (самое длинное слово) |
| `max-content` | контент без переносов |
| `fit-content(300px)` | по контенту, но не больше 300px |

## Попробуйте

Адаптивная сетка карточек без медиазапросов: `repeat(auto-fill, minmax(160px, 1fr))`. Переключитесь в режим «Просмотр» в песочнице или поменяйте ширину превью — колонки перестроятся сами. Замените `auto-fill` на `auto-fit` и удалите часть карточек, чтобы увидеть разницу.

```html run=grid
<ul class="grid">
  <li>1</li><li>2</li><li>3</li><li>4</li><li>5</li><li>6</li><li>7</li>
</ul>
```

```css run=grid
body { font-family: system-ui, sans-serif; padding: 16px; }

.grid {
  list-style: none;
  padding: 0;
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(160px, 1fr));
  gap: 12px;
}

.grid li {
  display: grid;
  place-items: center;
  height: 80px;
  border-radius: 8px;
  background: #111;
  color: #fff;
  font: 600 20px/1 ui-monospace, monospace;
}
```

## Что важно помнить

- `1fr` = `minmax(auto, 1fr)`: длинное слово или картинка растянет колонку. Для равных колонок — `repeat(3, minmax(0, 1fr))`.
- `fr` нельзя использовать в `calc()` и как минимальное значение `minmax()`.
- `repeat(auto-fill, ...)` требует фиксированного минимального размера, `repeat(auto-fill, 1fr)` невалидно.
- Внутри одного `repeat()` с `auto-fill` нельзя использовать другой `repeat()` с `auto-fill`.

## Мини-шпаргалка

- `fr` — доля свободного места после фиксированных размеров и `gap`.
- `repeat(n, x)` — повтор треков.
- `minmax(min, max)` — диапазон размера.
- `auto-fill` сохраняет пустые колонки, `auto-fit` схлопывает их.
- Адаптивная сетка: `repeat(auto-fill, minmax(min(220px, 100%), 1fr))`.
