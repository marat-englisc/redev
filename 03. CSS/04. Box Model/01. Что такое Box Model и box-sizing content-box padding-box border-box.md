# Что такое Box Model и box-sizing: content-box, padding-box, border-box

> [!NOTE]
> **Box Model** — модель, по которой браузер считает размеры элемента: каждый элемент — прямоугольник из content, padding, border и margin. Свойство `box-sizing` решает, к чему относятся `width` и `height`: при `content-box` (по умолчанию) — только к содержимому, при `border-box` — к содержимому вместе с padding и border.

## Вопрос

Что такое Box Model и из каких частей она состоит? Что такое content area, content-box, padding-box и border-box? Почему почти все проекты используют `border-box`?

## Состав Box Model

```text
┌──────────── margin ────────────┐
│  ┌────────── border ─────────┐ │
│  │  ┌─────── padding ──────┐ │ │
│  │  │     content area      │ │ │
│  │  └───────────────────────┘ │ │
│  └────────────────────────────┘ │
└─────────────────────────────────┘
```

| Часть | Что означает |
| --- | --- |
| content area | Текст, изображения, дочерние элементы |
| padding | Внутренний отступ между content и border, окрашивается фоном |
| border | Рамка вокруг padding |
| margin | Внешний отступ до соседей, прозрачный |

Каждой части соответствует «коробка»:

```text
content box -> только содержимое
padding box -> content + padding
border box  -> content + padding + border
margin box  -> всё вместе с margin
```

## content-box

Значение `box-sizing` по умолчанию: `width` и `height` задают размер **content area**, а padding и border добавляются сверху.

```css
.box {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 2px solid black;
}
```

```text
300 + 20 + 20 + 2 + 2 = 344px итоговая ширина
```

Отсюда классическая проблема: две колонки по `width: 50%` с `padding` не помещаются в одну строку.

## border-box

`width` и `height` включают content, padding и border. Content area сжимается, чтобы всё поместилось.

```css
.box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid black;
}
/* итоговая ширина — 300px, content area — 256px */
```

Поэтому в reset почти всегда есть:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

## padding-box

`padding-box` — не значение `box-sizing` (его убрали из спецификации), а **область** элемента. Она используется в свойствах:

```css
.box {
  border: 8px dashed black;
  padding: 16px;
  background: #bfdbfe;
  background-clip: padding-box;   /* фон не заходит под рамку */
  background-origin: padding-box; /* отсчет фонового изображения */
}
```

Относительно padding box также позиционируются абсолютные потомки: `top: 0; left: 0` — это внутренний край рамки родителя.

## Как посмотреть

В DevTools → Elements → вкладка Computed показывает диаграмму box model с реальными значениями content, padding, border и margin.

## Что важно помнить

- `margin` никогда не входит в `width`, даже при `border-box`.
- `min-width`, `max-width` и `height` подчиняются тому же `box-sizing`.
- Элементы форм (`input`, `button`, `select`) в разных браузерах исторически имели разный `box-sizing` — глобальное правило убирает эту разницу.
- `outline` и `box-shadow` рисуются снаружи border, но не занимают места в layout.
- Inline-элементы (`span`, `a`) игнорируют `width` и `height`, а вертикальные padding и margin не сдвигают соседние строки.

## Мини-шпаргалка

- Box Model: content → padding → border → margin.
- `content-box`: `width` = только content (по умолчанию).
- `border-box`: `width` = content + padding + border.
- `padding-box` — область для `background-clip` и абсолютного позиционирования.
- Margin в ширину не входит никогда.
