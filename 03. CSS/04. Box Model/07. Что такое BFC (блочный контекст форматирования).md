# Что такое BFC (блочный контекст форматирования)

> [!NOTE]
> **BFC (Block Formatting Context)** — изолированная область, внутри которой блоки раскладываются по своим правилам и не влияют на элементы снаружи. Новый BFC **содержит внутри себя float-элементы**, **не даёт схлопываться margin** своих детей с внешними и **не заходит под соседние float**. Самый современный способ создать BFC без побочных эффектов — `display: flow-root`.

## Вопрос

Что такое BFC? Как его создать и какие проблемы верстки он решает?

## Основная идея

Каждый блочный элемент живет в каком-то контексте форматирования. Корень страницы `<html>` создает первый BFC. Внутри одного BFC:

- блоки идут сверху вниз;
- вертикальные margin соседних блоков схлопываются;
- float-элементы «выпадают» из потока, и родитель их не учитывает при расчете высоты.

Когда элемент создает **новый** BFC, всё, что внутри, считается отдельно от внешнего мира.

## Что создает BFC

| Способ | Побочный эффект |
| --- | --- |
| `display: flow-root` | нет — создан специально для этого |
| `overflow: hidden / auto / scroll` (не `visible`) | обрезка содержимого, полосы прокрутки |
| `float: left / right` | элемент сам становится float |
| `position: absolute / fixed` | элемент выпадает из потока |
| `display: inline-block`, `table-cell`, `table-caption` | меняется тип отображения |
| `display: flex / grid` — их **дети** (flex и grid items) | контейнер создает flex/grid-контекст |
| `contain: layout / content / paint` | ограничение влияния на layout |
| `column-count`, `column-span: all` | многоколоночная раскладка |

## Задача 1: родитель не видит float

```html
<div class="card">
  <img class="card__img" src="cat.jpg" alt="Кот" />
  <p>Короткий текст.</p>
</div>
```

```css
.card__img {
  float: left;
  width: 200px;
}

/* без BFC высота .card меньше картинки — она «вылезает» за рамку */
.card {
  display: flow-root;
  border: 1px solid #ccc;
}
```

Раньше для этого писали clearfix (`::after { content: ""; display: table; clear: both; }`) или `overflow: hidden`.

## Задача 2: схлопывание margin

```css
.parent { background: #eee; }
.child { margin-top: 40px; }  /* отступ «вытекает» наружу родителя */

.parent { display: flow-root; } /* теперь отступ остается внутри */
```

Margin родителя и первого/последнего ребенка схлопываются, только если они в одном BFC и между ними нет border, padding или контента.

## Задача 3: колонка рядом с float

```css
.sidebar { float: left; width: 200px; }
.content { display: flow-root; } /* не заходит под float, занимает оставшееся место */
```

## Что важно помнить

- BFC — ответ на три вопроса собеседования: «почему родитель схлопнулся до нуля», «почему margin вылез наружу», «как сделать колонку рядом с float».
- `display: flow-root` — лучший способ: без обрезки и прокрутки, в отличие от `overflow: hidden`.
- Flex- и grid-контейнеры создают свои контексты форматирования: margin их детей не схлопываются, а float внутри не работает.
- Не путайте BFC и stacking context: BFC отвечает за раскладку (layout), stacking context — за порядок наложения (`z-index`).
- Есть и другие контексты: IFC (inline), FFC (flex), GFC (grid).

## Мини-шпаргалка

BFC = изолированный блок раскладки: содержит float, не дает margin схлопнуться наружу, не заходит под float. Создать: `display: flow-root` (лучше всего), `overflow` не `visible`, float, absolute, inline-block, flex/grid items.
