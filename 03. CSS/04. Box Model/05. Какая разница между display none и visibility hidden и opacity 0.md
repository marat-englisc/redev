# Какая разница между display none и visibility hidden и opacity 0?

> [!NOTE]
> `display: none` убирает элемент из layout, `visibility: hidden` скрывает его визуально, но оставляет место, а `opacity: 0` делает элемент прозрачным, но он продолжает занимать место и может оставаться интерактивным.

## Вопрос

Чем отличаются `display: none`, `visibility: hidden` и `opacity: 0`? Как скрыть элемент визуально, но оставить для скринридера?

## Сравнение

| Свойство | Видим | Занимает место | Может быть интерактивным |
| --- | --- | --- | --- |
| `display: none` | Нет | Нет | Нет |
| `visibility: hidden` | Нет | Да | Нет |
| `opacity: 0` | Нет | Да | Да, если не отключить |

## display none

```css
.menu {
  display: none;
}
```

Элемент полностью удаляется из визуального layout. Соседи ведут себя так, будто его нет.

## visibility hidden

```css
.placeholder {
  visibility: hidden;
}
```

Элемент не виден, но его место сохраняется.

## opacity 0

```css
.tooltip {
  opacity: 0;
}
```

Элемент прозрачный, но остается в layout. Если это кнопка или ссылка, она может продолжать получать клики и фокус.

Чтобы отключить взаимодействие:

```css
.tooltip[hidden] {
  opacity: 0;
  pointer-events: none;
}
```

## Accessibility

Для скрытия содержимого от всех обычно используют `hidden` или `display: none`. Для визуального скрытия, но сохранения для скринридера нужен специальный visually-hidden паттерн, а не `opacity: 0`.

## Что важно помнить

- У `visibility: hidden` дочерний элемент с `visibility: visible` будет виден — с `display: none` так нельзя.
- `opacity` и `visibility` анимируются, `display` — нет (без `allow-discrete`).
- Атрибут `hidden` равен `display: none`, но его перебьет любое правило с `display`.
- Паттерн visually-hidden: `position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); white-space: nowrap`.
- `content-visibility: hidden` скрывает содержимое, но сохраняет его состояние рендеринга для быстрого показа.

## Мини-шпаргалка

- `display: none` убирает элемент и место.
- `visibility: hidden` оставляет место.
- `opacity: 0` оставляет место и может сохранять клики.
- Для невидимого интерактивного элемента нужно осторожно управлять фокусом.
- Для accessibility важно понимать, скрыт ли элемент от screen reader.
