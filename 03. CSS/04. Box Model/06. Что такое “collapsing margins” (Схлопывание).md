# Что такое "collapsing margins" (Схлопывание)?

> [!NOTE]
> **Collapsing margins** - это поведение CSS, при котором вертикальные margin некоторых блочных элементов объединяются в один общий отступ вместо сложения.

## Вопрос

Что такое схлопывание margin? Когда оно происходит и как его предотвратить?

## Главное

```css
h2 {
  margin-bottom: 24px;
}

p {
  margin-top: 16px;
}
```

Между `h2` и `p` может получиться `24px`, а не `40px`, потому что вертикальные margin схлопнутся.

## Когда схлопывается

Чаще всего:

- между соседними блочными элементами по вертикали;
- между родителем и первым или последним ребенком;
- у пустого блочного элемента.

## Пример с родителем

```css
.section {
  margin-top: 40px;
}

.section h2 {
  margin-top: 24px;
}
```

Margin ребенка может схлопнуться с margin родителя, если нет padding, border или другого контекста форматирования.

## Как предотвратить

```css
.section {
  padding-top: 1px;
}
```

Или:

```css
.section {
  display: flow-root;
}
```

Также схлопывание обычно не происходит во flex/grid-контейнерах.

## Практический совет

В компонентной верстке часто проще задавать расстояния через `gap`, если элементы лежат во flex/grid-контейнере.

```css
.stack {
  display: grid;
  gap: 24px;
}
```

## Что важно помнить

- Схлопываются только вертикальные margin блоков в нормальном потоке; горизонтальные — никогда.
- Три случая: соседние блоки, родитель и первый/последний ребенок (margin «выпадает» из родителя), пустой блок.
- Схлопывания нет у flex- и grid-элементов, у float и absolute, а также если между родителем и ребенком есть padding, border или BFC.
- При положительном и отрицательном margin результат — их сумма.
- Многие команды используют margin только в одном направлении (например, только `margin-bottom`) или `gap`, чтобы избежать сюрпризов.

## Мини-шпаргалка

- Схлопываются вертикальные margin.
- Горизонтальные margin не схлопываются.
- Итоговый отступ часто равен большему margin.
- Padding, border, `flow-root`, flex/grid могут остановить схлопывание.
- `gap` часто предсказуемее для расстояний между элементами.
