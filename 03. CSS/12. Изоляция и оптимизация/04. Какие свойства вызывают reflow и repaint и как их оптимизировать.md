# Какие свойства вызывают reflow и repaint и как их оптимизировать?

> [!NOTE]
> **Reflow (layout)** — пересчет геометрии: размеров и позиций элементов. Его вызывают изменения `width`, `height`, `margin`, `padding`, `top`, `font-size`, `display` и контента, а также чтение геометрии после изменений. **Repaint (paint)** — перерисовка пикселей без изменения геометрии: `color`, `background`, `box-shadow`, `visibility`. Дешевле всего — изменения только на этапе composite: `transform` и `opacity`.

## Вопрос

Какие свойства вызывают relayout и repaint? Какие есть способы оптимизировать relayout?

## Конвейер рендеринга

```text
JavaScript -> Style -> Layout -> Paint -> Composite
```

| Что изменили | Какие этапы выполнятся | Стоимость |
| --- | --- | --- |
| Геометрию | Layout → Paint → Composite | высокая |
| Только внешний вид | Paint → Composite | средняя |
| `transform`, `opacity` | только Composite | низкая |

## Что вызывает reflow

- размеры и отступы: `width`, `height`, `min/max-*`, `padding`, `margin`, `border-width`;
- позиционирование: `top`, `left`, `position`, `float`;
- отображение: `display`, `flex`, `grid-template-*`;
- текст: `font-size`, `font-family`, `line-height`, `letter-spacing`, изменение текста;
- добавление и удаление элементов DOM;
- изменение размера окна, загрузка шрифтов и изображений без размеров;
- **чтение** геометрии после изменения: `offsetWidth`, `offsetHeight`, `clientWidth`, `scrollTop`, `getBoundingClientRect()`, `getComputedStyle()`.

## Что вызывает только repaint

`color`, `background-color`, `background-image`, `border-color`, `outline`, `box-shadow`, `border-radius`, `visibility`, `text-decoration`.

Тяжелые для отрисовки эффекты — большие `box-shadow` и `filter: blur()` — тоже могут тормозить, хотя геометрию не меняют.

## Layout thrashing

Самая частая проблема — чередование записи и чтения в цикле:

```js
// плохо: каждый offsetWidth заставляет пересчитать layout
items.forEach((item) => {
  item.style.width = `${container.offsetWidth / 3}px`;
});

// хорошо: сначала читаем, потом пишем
const width = container.offsetWidth / 3;
items.forEach((item) => {
  item.style.width = `${width}px`;
});
```

## Способы оптимизации

1. **Анимировать `transform` и `opacity`** вместо `top`, `left`, `width`, `height`.
2. **Группировать чтение и запись**: сначала все измерения, потом все изменения; изменения — в `requestAnimationFrame`.
3. **Менять классы, а не много inline-стилей** по отдельности.
4. **Batch-изменения DOM**: `DocumentFragment`, одна вставка вместо сотни.
5. **Ограничивать область пересчета**: `contain: layout paint` или `contain: content` у независимых компонентов.
6. **Пропускать рендер невидимого**: `content-visibility: auto` с `contain-intrinsic-size` для длинных списков.
7. **Резервировать место**: `width`/`height` у изображений, `aspect-ratio` — меньше reflow и CLS.
8. **Наблюдать вместо опроса**: `ResizeObserver` и `IntersectionObserver` вместо чтения размеров в `scroll`.
9. **Виртуализировать** длинные списки.
10. **`will-change: transform`** — только точечно и перед анимацией: каждый слой расходует память.

```css
.widget {
  contain: content;
}

.feed-item {
  content-visibility: auto;
  contain-intrinsic-size: auto 300px;
}
```

## Как измерить

Chrome DevTools → Performance: фиолетовые блоки Layout и зеленые Paint. Предупреждение «Forced reflow» указывает на layout thrashing. Rendering → Paint flashing подсвечивает перерисовываемые области.

## Что важно помнить

- Чтение геометрии само по себе дешево; дорого чтение после записи (forced synchronous layout).
- `display: none` → `block` вызывает layout, `visibility` и `opacity` — нет.
- Изменение элемента может вызвать reflow соседей и предков — отсюда польза `contain`.
- React и Vue группируют изменения DOM, но не защищают от thrashing в `useLayoutEffect` и обработчиках.

## Мини-шпаргалка

- Layout — геометрия, Paint — пиксели, Composite — слои.
- Reflow: размеры, отступы, позиции, шрифты, DOM, чтение `offset*`.
- Repaint: цвета, фон, тени, `visibility`.
- Только composite: `transform`, `opacity`.
- Оптимизация: батчинг чтения/записи, `rAF`, `contain`, `content-visibility`.
