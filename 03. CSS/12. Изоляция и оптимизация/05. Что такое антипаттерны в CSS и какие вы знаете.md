# Что такое антипаттерны в CSS и какие вы знаете?

> [!NOTE]
> **CSS-антипаттерн** - это привычный прием, который кажется быстрым решением, но ухудшает поддержку, предсказуемость, производительность или доступность стилей.

## Вопрос

Какие антипаттерны в CSS вы знаете и как их избежать?

## Частые антипаттерны

| Антипаттерн | Почему плохо |
| --- | --- |
| Частый `!important` | Ломает каскад и усложняет переопределение |
| Слишком высокая специфичность | Правила трудно переиспользовать и перебивать |
| Глобальные классы без соглашений | Конфликты между компонентами |
| Стили по id | Высокая специфичность и слабая переиспользуемость |
| Layout на `position: absolute` везде | Хрупкая адаптивность |
| Анимация `width`, `top`, `left` | Может вызывать relayout |
| Удаление `outline` без замены | Ломает клавиатурную доступность |

## !important как привычка

```css
.button {
  color: red !important;
}
```

Если `!important` используется постоянно, CSS превращается в борьбу приоритетов. Лучше разобраться со специфичностью, порядком и архитектурой.

## Слишком длинные селекторы

```css
.page .content .sidebar .widget ul li a span {
  color: #2563eb;
}
```

Такой селектор привязан к структуре DOM. Любой рефакторинг разметки может сломать стили.

## Невидимый focus

```css
button {
  outline: none;
}
```

Если убрать outline и не дать замену через `:focus-visible`, пользователь клавиатуры потеряет ориентир.

```css
button:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 2px;
}
```

## Layout не тем инструментом

```css
.card {
  position: absolute;
  left: 40px;
  top: 120px;
}
```

Для обычной раскладки страницы чаще подходят Flexbox и Grid.

## Как избегать

- Держать специфичность низкой.
- Использовать классы и понятные соглашения.
- Разделять base, components и utilities.
- Проверять доступность состояний.
- Для layout выбирать Flexbox/Grid.
- Для анимаций выбирать `transform`/`opacity`.
- Удалять мертвый CSS.

## Что важно помнить

- Частые антипаттерны: `!important` повсюду, стилизация по id, глубокая вложенность, магические числа, фиксированные высоты для текста.
- Удаление `outline` без замены ломает клавиатурную навигацию.
- Мертвый CSS накапливается — его ищут через вкладку Coverage в DevTools.
- Stylelint и code review помогают держать единые правила в команде.

## Мини-шпаргалка

- Антипаттерн ускоряет сейчас, но усложняет потом.
- `!important` не должен быть обычным способом решения.
- Глубокие селекторы хрупкие.
- `outline: none` без замены ломает a11y.
- Absolute-layout плохо масштабируется.
- CSS стоит проектировать как систему, а не набор случайных правок.
