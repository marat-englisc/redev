# Как указать шрифт и что такое fallback-шрифты?

> [!NOTE]
> Шрифт задается свойством `font-family` в виде цепочки (font stack): браузер берет первый доступный шрифт. **Fallback-шрифт** — запасной вариант, если основной не загрузился, не установлен или не содержит нужного символа. В конце цепочки всегда указывают generic family: `sans-serif`, `serif`, `monospace`.

## Вопрос

Как указать шрифт для текста? Что такое fallback-шрифт и как правильно составить font stack?

## font-family и font stack

```css
body {
  font-family: Inter, "Helvetica Neue", Arial, sans-serif;
}
```

Браузер пробует `Inter`, затем `Helvetica Neue`, затем `Arial`, и в крайнем случае — любой системный `sans-serif`. Имена с пробелами пишут в кавычках.

Fallback нужен, потому что:

- webfont может не загрузиться или еще загружается;
- пользователь offline или шрифт заблокирован;
- в шрифте нет кириллицы, emoji или спецсимвола — браузер возьмет символ из следующего шрифта цепочки (per-character fallback);
- нужного шрифта нет в системе.

## Generic families

| Семейство | Где подходит |
| --- | --- |
| `sans-serif` | Интерфейсы, кнопки, формы |
| `serif` | Длинные тексты, статьи |
| `monospace` | Код, технические значения |
| `system-ui` | Системный шрифт ОС |
| `ui-monospace` | Системный моноширинный |
| `cursive`, `fantasy` | Декоративные сценарии |

Системный стек — быстрый вариант без загрузки шрифтов:

```css
body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}

code, pre {
  font-family: ui-monospace, "JetBrains Mono", Consolas, monospace;
}
```

## Хороший font stack

Шрифты в цепочке должны быть похожи по характеру: если основной — геометрический sans-serif, запасной serif сломает визуальный ритм. Различия в ширине и высоте шрифтов вызывают layout shift при замене fallback на webfont.

Сгладить скачок помогают метрики fallback-шрифта:

```css
@font-face {
  font-family: "Inter Fallback";
  src: local("Arial");
  size-adjust: 107%;
  ascent-override: 90%;
}

body {
  font-family: Inter, "Inter Fallback", sans-serif;
}
```

Next.js (`next/font`) и инструменты вроде Fontaine генерируют такие правила автоматически.

## Шорткат font

```css
h1 {
  font: 700 2rem/1.2 Inter, sans-serif;
  /* weight size/line-height family */
}
```

`font` сбрасывает все неуказанные подсвойства (`font-style`, `font-variant` и др.), а `font-size` и `font-family` в нем обязательны.

## Что важно помнить

- `font-family` наследуется — задавайте его на `body`, а не на каждом элементе.
- Поля форм по умолчанию не наследуют шрифт: добавьте `input, button, textarea, select { font: inherit; }`.
- Чем больше webfont-ов и начертаний, тем медленнее загрузка: часто достаточно одного вариативного шрифта.
- Проверяйте, что шрифт поддерживает кириллицу (subset `cyrillic`), иначе русский текст отрисуется fallback-шрифтом.

## Мини-шпаргалка

- `font-family` — цепочка шрифтов, первый доступный побеждает.
- В конце — generic family.
- Fallback спасает при незагрузке и отсутствии символов.
- Похожие метрики fallback уменьшают CLS.
- `system-ui` — быстрый системный вариант.
