# Как задавать цвета в CSS: форматы, color, background и прозрачность

> [!NOTE]
> CSS поддерживает ключевые слова, HEX, `rgb()`, `hsl()`, современные пространства `oklch()` и `lab()`, а также `currentColor` и `transparent`. Цвет текста задает `color` (наследуется), фон — `background-color` (не наследуется). Прозрачность цвета задает альфа-канал (`rgb(0 0 0 / 0.5)`), а `opacity` делает прозрачным весь элемент вместе с детьми.

## Вопрос

Какие способы задания цвета поддерживает CSS? Как задать цвет текста и фона? Чем RGB отличается от RGBA и что делают альфа-канал и `transparent`?

## Форматы цвета

```css
.box {
  color: tomato;                        /* ключевое слово */
  border-color: #2563eb;                /* HEX */
  background: rgb(37 99 235);           /* RGB */
  outline-color: hsl(221 83% 53%);      /* HSL */
  accent-color: oklch(62% 0.19 260);    /* OKLCH */
}
```

| Формат | Пример | Когда удобен |
| --- | --- | --- |
| Ключевые слова | `red`, `transparent`, `currentColor` | быстрые значения и спецзначения |
| HEX | `#2563eb`, `#2563eb80` | макеты и дизайн-токены |
| RGB | `rgb(37 99 235 / 0.5)` | работа с каналами |
| HSL | `hsl(221 83% 53%)` | вариации оттенка и светлоты |
| OKLCH | `oklch(62% 0.19 260)` | равномерная светлота, палитры, широкий охват (P3) |

## RGB, RGBA и альфа-канал

```css
.overlay {
  background-color: rgba(0, 0, 0, 0.5); /* старый синтаксис */
  background-color: rgb(0 0 0 / 0.5);   /* современный — то же самое */
  background-color: #00000080;          /* HEX с альфой: 80 = 50% */
}
```

`rgba()` и `hsla()` сейчас — просто синонимы `rgb()` и `hsl()`: альфа-канал поддерживается в обоих. Значение от `0` (прозрачно) до `1` или `0%`–`100%`.

## transparent

`transparent` — полностью прозрачный черный (`rgb(0 0 0 / 0)`).

```css
.card {
  border: 1px solid transparent; /* место под рамку есть всегда */
}
.card:hover {
  border-color: #2563eb;         /* layout не прыгает при hover */
}
```

Прозрачный элемент по-прежнему занимает место и получает клики.

## Альфа-канал или opacity

```css
.card { background: rgb(255 255 255 / 0.8); } /* прозрачен только фон */
.card { opacity: 0.8; }                         /* прозрачно всё, включая текст и детей */
```

Для полупрозрачного фона используйте альфа-канал. `opacity` меньше 1 также создает новый stacking context.

## Цвет текста: color

```css
.article { color: #374151; }

a { color: #2563eb; }
a:hover { color: #1d4ed8; }
```

`color` наследуется, поэтому базовый цвет обычно задают на `body`. Он также становится значением `currentColor`, которое используют рамки, SVG-иконки и `text-decoration`.

```css
.icon-button {
  color: #2563eb;
  border: 1px solid currentColor;
}
```

## Цвет фона: background-color

```css
.notification {
  padding: 16px;
  background-color: #ecfdf5;
  color: #065f46;
}

.hero {
  background: #111827 url("/hero.jpg") center / cover no-repeat;
}
```

`background-color` — только цвет. Шорткат `background` задает цвет, изображение, позицию, размер и повтор сразу, но **сбрасывает** неуказанные подсвойства. По умолчанию фон рисуется под content, padding и border (`background-clip: border-box`).

## Современные функции

```css
:root {
  --brand: oklch(62% 0.19 260);
  --brand-hover: color-mix(in oklch, var(--brand), black 15%);
  --brand-soft: oklch(from var(--brand) l c h / 0.15); /* относительный цвет */
}

:root { color-scheme: light dark; }
body { background: light-dark(#fff, #111827); }
```

## Что важно помнить

- Контраст текста и фона должен соответствовать WCAG: 4.5:1 для обычного текста.
- HSL неравномерен по воспринимаемой светлоте: желтый и синий при одном `l` выглядят по-разному. OKLCH решает это.
- Если `background-color` не задан, он `transparent`, а не белый — виден фон родителя.
- Цвета в дизайн-системе храните в CSS-переменных: так проще темная тема.

## Мини-шпаргалка

- Форматы: ключевые слова, HEX, `rgb()`, `hsl()`, `oklch()`.
- `color` — текст, наследуется; `background-color` — фон, не наследуется.
- Альфа: `rgb(0 0 0 / 0.5)`, `rgba` = `rgb`.
- `transparent` — полностью прозрачный цвет.
- Альфа-канал — для фона, `opacity` — для всего элемента.
