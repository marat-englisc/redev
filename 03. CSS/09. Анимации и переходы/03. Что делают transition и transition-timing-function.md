# Что делают transition и transition-timing-function?

> [!NOTE]
> `transition` плавно анимирует изменение свойства между двумя состояниями — например, при `:hover` или смене класса. Задаются свойство, длительность, функция времени и задержка. `transition-timing-function` определяет кривую скорости: `ease`, `linear`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier()`, `steps()` и `linear()`.

## Вопрос

Что делает `transition`? Что такое `transition-timing-function` и какие кривые скорости бывают?

## transition

```css
.button {
  background: #2563eb;
  transform: translateY(0);
  transition:
    background-color 200ms ease,
    transform 150ms ease-out;
}

.button:hover {
  background: #1d4ed8;
  transform: translateY(-2px);
}
```

| Подсвойство | Что задает |
| --- | --- |
| `transition-property` | какое свойство анимировать (`all` — все) |
| `transition-duration` | длительность (`200ms`) |
| `transition-timing-function` | кривая скорости |
| `transition-delay` | задержка |
| `transition-behavior` | `allow-discrete` для дискретных свойств (`display`) |

Transition срабатывает при **любом** изменении значения: псевдокласс, класс из JS, media query. Обратный переход при уходе курсора тоже анимируется.

## Что можно анимировать

Только свойства с промежуточными значениями: числа, длины, цвета, `transform`, `opacity`, `box-shadow`. Нельзя плавно анимировать `display` или `height: auto` (кроме новых `interpolate-size: allow-keywords` и `calc-size()` в поддерживающих браузерах).

## transition-timing-function

| Значение | Поведение | Где подходит |
| --- | --- | --- |
| `ease` (по умолчанию) | быстрый старт, плавный конец | универсально |
| `linear` | постоянная скорость | вращение, прогресс-бар |
| `ease-in` | медленный старт | элемент уходит с экрана |
| `ease-out` | медленный конец | элемент появляется |
| `ease-in-out` | медленно в начале и конце | перемещение по экрану |
| `cubic-bezier(x1, y1, x2, y2)` | своя кривая | фирменный «характер» движения |
| `steps(n)` | ступеньки без плавности | спрайт-анимация, печатающийся текст |
| `linear(...)` | кривая из точек | пружины и bounce-эффекты |

```css
.drawer {
  transition: transform 300ms cubic-bezier(0.2, 0.8, 0.2, 1);
}

.sprite {
  animation: walk 1s steps(8) infinite;
}
```

Значения `y` в `cubic-bezier` могут выходить за 0–1 — так получается эффект «перелета» (overshoot).

## Transition или animation

| | `transition` | `animation` |
| --- | --- | --- |
| Запуск | смена значения | сама при применении стиля |
| Состояния | два (было → стало) | любое количество кадров |
| Повторы | нет | `infinite` |
| Типичное применение | hover, focus, открытие меню | лоадеры, появление, привлечение внимания |

## Попробуйте

Наведите курсор на дорожку: все шарики проходят одно расстояние за одно время, но с разными `transition-timing-function`.

```html run=easing
<div class="track">
  <span style="--ease: linear">linear</span>
  <span style="--ease: ease">ease</span>
  <span style="--ease: ease-in">ease-in</span>
  <span style="--ease: ease-out">ease-out</span>
  <span style="--ease: ease-in-out">ease-in-out</span>
  <span style="--ease: cubic-bezier(0.34, 1.56, 0.64, 1)">back</span>
  <span style="--ease: steps(5)">steps(5)</span>
</div>
```

```css run=easing
body { font-family: system-ui, sans-serif; padding: 24px; }

.track { display: grid; gap: 10px; padding: 12px; border: 1px dashed #9ca3af; border-radius: 8px; }

.track span {
  width: 110px;
  padding: 6px 10px;
  border-radius: 999px;
  background: #111;
  color: #fff;
  font: 12px/1.2 ui-monospace, monospace;
  transition: transform 1.2s var(--ease);
}

.track:hover span { transform: translateX(calc(100vw - 200px)); }
```

## Что важно помнить

- Избегайте `transition: all`: анимируются неожиданные свойства, и падает производительность.
- Анимация `width`, `height`, `top`, `left` вызывает layout на каждом кадре — используйте `transform`.
- Хорошая длительность UI-переходов — 150–300 ms; дольше — интерфейс кажется медленным.
- Событие `transitionend` срабатывает для каждого свойства отдельно.
- Появление из `display: none` анимируют через `@starting-style` и `transition-behavior: allow-discrete`.

## Мини-шпаргалка

- `transition: property duration timing delay`.
- Срабатывает при смене значения свойства.
- `ease-out` — появление, `ease-in` — исчезновение, `linear` — вращение.
- `cubic-bezier()` — своя кривая, `steps()` — ступеньки.
- Не используйте `all`, анимируйте `transform` и `opacity`.
