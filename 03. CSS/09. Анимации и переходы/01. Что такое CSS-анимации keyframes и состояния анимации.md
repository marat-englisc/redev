# Что такое CSS-анимации, @keyframes и состояния анимации?

> [!NOTE]
> CSS-анимация описывается правилом `@keyframes` — набором состояний (кадров) от `from`/`0%` до `to`/`100%` — и подключается к элементу свойством `animation`: имя, длительность, функция времени, задержка, количество повторов, направление, `fill-mode` и `play-state`. В отличие от transition, анимация не требует смены состояния и может запускаться сама, повторяться и иметь промежуточные кадры.

## Вопрос

Что такое анимации в CSS и как их задать? Что такое `@keyframes` и «состояния» в CSS-анимациях?

## @keyframes

```css
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(16px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.05); }
}
```

Каждый процент — **ключевой кадр** (состояние). Браузер интерполирует промежуточные значения между ними. Неуказанные `0%` и `100%` берутся из текущих стилей элемента.

## Подключение: animation

```css
.toast {
  animation: fade-in-up 300ms ease-out both;
}

.loader {
  animation: spin 1s linear infinite;
}
```

| Подсвойство | Что задает | Пример |
| --- | --- | --- |
| `animation-name` | имя `@keyframes` | `fade-in-up` |
| `animation-duration` | длительность | `300ms` |
| `animation-timing-function` | кривая скорости | `ease-out`, `steps(4)` |
| `animation-delay` | задержка | `150ms` (отрицательная — начать с середины) |
| `animation-iteration-count` | повторы | `3`, `infinite` |
| `animation-direction` | направление | `normal`, `reverse`, `alternate` |
| `animation-fill-mode` | состояние до и после | `none`, `forwards`, `backwards`, `both` |
| `animation-play-state` | пауза | `running`, `paused` |

## Состояния анимации

Под «состояниями» понимают:

1. **Ключевые кадры** — состояния внутри `@keyframes`.
2. **Состояние до и после** анимации — задается `animation-fill-mode`:

| Значение | До начала (во время delay) | После окончания |
| --- | --- | --- |
| `none` | исходные стили | возврат к исходным стилям |
| `forwards` | исходные стили | остается последний кадр |
| `backwards` | применяется первый кадр | возврат к исходным |
| `both` | первый кадр | последний кадр |

3. **Состояние воспроизведения** — `running` или `paused`:

```css
.marquee:hover { animation-play-state: paused; }
```

## Несколько анимаций

```css
.badge {
  animation:
    fade-in 200ms ease-out both,
    pulse 2s ease-in-out 200ms infinite;
}
```

## Управление из JavaScript

```js
el.addEventListener("animationend", () => el.remove());

// Web Animations API
el.animate(
  [{ opacity: 0 }, { opacity: 1 }],
  { duration: 300, easing: "ease-out", fill: "forwards" },
);
```

## Что важно помнить

- Анимируйте `transform` и `opacity`: они обрабатываются композитором и не вызывают layout и paint.
- Уважайте `prefers-reduced-motion`: отключайте или упрощайте движение для пользователей с вестибулярными нарушениями.
- `animation-fill-mode: both` — частое решение «мигания» перед стартом анимации с задержкой.
- Перезапустить CSS-анимацию можно сменой класса с принудительным reflow или через Web Animations API.
- Анимировать появление элемента из `display: none` теперь можно через `@starting-style` и `transition-behavior: allow-discrete`.

## Мини-шпаргалка

- `@keyframes name { from {} to {} }` — состояния.
- `animation: name duration timing delay count direction fill-mode`.
- `fill-mode: both` — сохранить первый и последний кадр.
- `infinite`, `alternate`, `paused`.
- Анимировать `transform` и `opacity`, учитывать reduced motion.
