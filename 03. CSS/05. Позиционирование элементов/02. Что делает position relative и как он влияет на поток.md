# Что делает position: relative и как он влияет на поток документа?

> [!NOTE]
> `position: relative` оставляет элемент в нормальном потоке и сохраняет его исходное место, но позволяет визуально сместить его через `top`, `right`, `bottom`, `left` относительно исходной позиции. Соседи при этом не двигаются. Главное практическое применение — сделать элемент точкой отсчета для абсолютно позиционированных детей.

## Вопрос

Что делает `position: relative`? Как он влияет на поток документа и соседние элементы?

## Смещение относительно себя

```css
.label {
  position: relative;
  top: 4px;
  left: 8px;
}
```

Элемент визуально сдвинется на 4px вниз и 8px вправо, но в потоке останется «дырка» на его исходном месте — соседи считают, что он не двигался.

```text
до:    [A][B][C]
после: [A][ ][C]   B нарисован со смещением, место осталось
           [B]
```

Если заданы `top` и `bottom` одновременно, побеждает `top`; если `left` и `right` — побеждает `left` (для направления письма слева направо).

## Влияние на поток

| Что | Поведение |
| --- | --- |
| Место в потоке | сохраняется |
| Соседи | не двигаются |
| Размеры | не меняются |
| Перекрытие | смещенный элемент может наложиться на соседей |
| Рисуется | поверх неспозиционированных соседей |

По сути, это то же, что `transform: translate()`, но `transform` не меняет порядок наложения и лучше анимируется.

## Главное применение: точка отсчета

```html
<article class="card">
  <span class="card__badge">Новинка</span>
  <h2>Ноутбук</h2>
</article>
```

```css
.card {
  position: relative; /* без смещений — просто containing block */
}

.card__badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Без `relative` у `.card` бейдж позиционировался бы относительно другого предка или всей страницы.

## z-index

`position: relative` включает работу `z-index`, а с `z-index` не `auto` создает новый stacking context:

```css
.dropdown-wrapper {
  position: relative;
  z-index: 10;
}
```

## Что важно помнить

- Сам `position: relative` без смещений визуально ничего не меняет — он нужен для детей и `z-index`.
- Для анимации сдвига используйте `transform`, а не `top`/`left`: изменение `top` вызывает layout на каждом кадре.
- Проценты в `top`/`bottom` считаются от высоты containing block, которая часто `auto` — тогда смещение не сработает.
- Лишний `relative` на многих элементах усложняет понимание, от чего позиционируются абсолютные дети.

## Мини-шпаргалка

- `relative` — смещение от своего исходного места.
- Место в потоке сохраняется, соседи не двигаются.
- Главная роль — containing block для `absolute`-детей.
- Включает `z-index`.
- Для анимации сдвига лучше `transform`.
