# Что делает position: absolute и почему элемент выпадает из потока?

> [!NOTE]
> `position: absolute` вынимает элемент из нормального потока: для соседей его больше нет, и они занимают освободившееся место. Элемент позиционируется через `top`, `right`, `bottom`, `left` относительно **containing block** — padding box ближайшего предка с `position` не `static` (или начального блока документа, если такого предка нет).

## Вопрос

Что делает `position: absolute`? Относительно чего позиционируется элемент и почему он выпадает из потока документа?

## Пример

```css
.card {
  position: relative;
}

.card__close {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Кнопка закрытия прикреплена к правому верхнему углу карточки, а текст карточки ведет себя так, будто кнопки нет.

## Почему выпадает из потока

Абсолютный элемент предназначен для наложения: бейджи, тултипы, выпадающие меню, иконки поверх картинок. Если бы он участвовал в потоке, то сдвигал бы контент — и наложение было бы невозможно. Поэтому браузер:

- не резервирует для него место;
- не учитывает его при расчете высоты родителя (родитель с одним абсолютным ребенком схлопнется в 0);
- не учитывает его в схлопывании margin.

```text
static/relative:  [A][B][C]
B absolute:       [A][C]     B рисуется отдельно, поверх
```

## Как определяется containing block

1. Ищем ближайшего предка с `position: relative | absolute | fixed | sticky`.
2. Также подходит предок с `transform`, `filter`, `perspective`, `contain: layout/paint`, `container-type`.
3. Если никого нет — начальный containing block (размер viewport у начала страницы, элемент прокручивается вместе со страницей).

Отсчет идет от **внутреннего края рамки** (padding box), а не от content.

## Размеры абсолютного элемента

- Без `width` элемент сжимается по содержимому (shrink-to-fit), даже если это `div`.
- `left: 0; right: 0` без `width` растягивает его на всю ширину containing block.
- `inset: 0` — на весь блок, удобно для оверлеев.
- `display` становится блочным: у `span` с `absolute` начинают работать `width` и `height`.

## Центрирование

```css
.modal {
  position: absolute;
  inset: 0;
  margin: auto;
  width: 400px;
  height: fit-content;
}

/* или классика */
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## Что важно помнить

- Абсолютный элемент без заданных `top`/`left` остается там, где был бы в потоке (static position), но место не занимает.
- `overflow: hidden` у containing block обрезает абсолютного ребенка; у промежуточного предка без позиционирования — нет.
- Абсолютная раскладка всей страницы — антипаттерн: она не адаптивна и ломается при изменении контента.
- Выпадающее меню внутри контейнера с `overflow: hidden` будет обрезано — его выносят в портал или используют Popover API.

## Мини-шпаргалка

- `absolute` убирает элемент из потока, соседи его не видят.
- Отсчет — от padding box ближайшего позиционированного предка.
- Родителю обычно ставят `position: relative`.
- Без `width` сжимается по содержимому, `inset: 0` растягивает.
- Используется для наложений: бейджи, тултипы, иконки.
