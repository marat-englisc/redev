# Что делает position: sticky и как работает прилипание при скролле?

> [!NOTE]
> `position: sticky` — гибрид `relative` и `fixed`. Элемент остается в потоке, но когда при прокрутке он доходит до порога (`top: 0`), он «прилипает» и остается на месте, пока не упрется в край своего родителя. Для работы нужен хотя бы один порог (`top`, `bottom`, `left`, `right`) и прокручиваемый предок без `overflow: hidden` между ними.

## Вопрос

Что делает `position: sticky`? Как работает механизм прилипания при скролле и почему sticky иногда «не работает»?

## Пример

```css
.table-header {
  position: sticky;
  top: 0;
  background: white;
  z-index: 1;
}
```

Заголовок прокручивается вместе с контентом, а дойдя до верхнего края области прокрутки, фиксируется там.

## Механизм прилипания

У sticky-элемента три участника:

1. **Сам элемент** и его порог — `top: 0` означает «прилипнуть на расстоянии 0 от верха».
2. **Ближайший прокручиваемый предок** (scroll container) — относительно его viewport считается порог. Если такого нет — окно браузера.
3. **Родитель** (containing block) — элемент прилипает только в его пределах. Когда родитель уходит вверх, sticky-элемент уезжает вместе с ним.

```text
scroll ↓
┌ scroll container ─────────┐
│ ┌ section ──────────────┐ │
│ │ [Header A] ← прилип   │ │
│ │ ...контент A...       │ │
│ └───────────────────────┘ │ ← A уезжает вместе с концом секции
│ ┌ section ──────────────┐ │
│ │ [Header B]            │ │
└───────────────────────────┘
```

Так делают алфавитные списки контактов: каждая буква прилипает, пока виден ее раздел.

## Почему sticky не работает

| Причина | Решение |
| --- | --- |
| Не задан порог `top`/`bottom` | добавить `top: 0` |
| У предка `overflow: hidden`, `auto` или `scroll` | sticky прилипает к этому предку, а не к окну; убрать overflow или использовать `overflow: clip` |
| Родитель такой же высоты, как элемент | прилипать некуда — нужен высокий родитель |
| Во flex-контейнере элемент растянут `align-items: stretch` | `align-self: start` |
| Элемент внутри `display: table` в старых браузерах | ставить sticky на `th`, а не на `tr` |

## Отличие от fixed

| | `sticky` | `fixed` |
| --- | --- | --- |
| Место в потоке | сохраняется | не сохраняется |
| Относительно чего | scroll container и родитель | viewport |
| Пределы | внутри родителя | всегда на экране |
| Типичное применение | заголовки таблиц и разделов, sidebar | шапка сайта, кнопка чата, cookie-баннер |

## Что важно помнить

- Sticky-элементу почти всегда нужен фон и `z-index`, иначе контент будет просвечивать сквозь него.
- Высокий sticky sidebar, который длиннее экрана, никогда не будет виден полностью — ограничьте высоту и добавьте свою прокрутку.
- Чтобы якоря не прятались под sticky-шапкой, задайте `scroll-padding-top` у `html` или `scroll-margin-top` у целевых элементов.
- Отследить момент прилипания можно через `IntersectionObserver` с отрицательным `rootMargin` — так меняют тень шапки.

## Мини-шпаргалка

- `sticky` = `relative`, который прилипает при достижении порога.
- Нужен порог: `top: 0`.
- Прилипает к ближайшему прокручиваемому предку, в пределах родителя.
- `overflow` у предка — частая причина поломки.
- Нужны фон и `z-index`.
