# Что такое позиционирование в CSS и как CSS управляет положением элементов?

> [!NOTE]
> По умолчанию элементы располагаются в **нормальном потоке**: блоки идут сверху вниз, inline-элементы — в строку. Положение меняют способы раскладки (Flexbox, Grid, float) и свойство `position` со значениями `static`, `relative`, `absolute`, `fixed`, `sticky` вместе со смещениями `top`, `right`, `bottom`, `left` и `z-index`.

## Вопрос

Что такое позиционирование элементов в CSS? Какие значения есть у `position` и как CSS вообще управляет положением элементов на странице?

## Нормальный поток

```html
<header>Шапка</header>
<main>Контент со <a href="#">ссылкой</a> внутри строки</main>
<footer>Подвал</footer>
```

- блочные элементы занимают всю ширину и идут друг под другом;
- inline-элементы идут в строку и переносятся;
- элементы «знают» друг о друге: изменение размера одного сдвигает остальные.

Нормальный поток — основа адаптивности, поэтому из него выводят только то, что действительно должно «парить»: модалки, тултипы, бейджи, фиксированные шапки.

## Инструменты раскладки

| Инструмент | Задача |
| --- | --- |
| Нормальный поток | документ, текст |
| Flexbox | одномерная раскладка: строка или колонка |
| Grid | двумерная раскладка: строки и колонки |
| `position` | точечное смещение и наложение |
| `float` | обтекание текстом (картинка в статье) |
| `transform` | визуальный сдвиг без влияния на поток |

## Значения position

| Значение | В потоке | Относительно чего смещается |
| --- | --- | --- |
| `static` | да | не смещается (по умолчанию), `top`/`z-index` не работают |
| `relative` | да, место сохраняется | своего исходного положения |
| `absolute` | нет | ближайшего позиционированного предка (containing block) |
| `fixed` | нет | viewport |
| `sticky` | да | ведет себя как `relative`, пока не достигнет порога прокрутки |

```css
.card { position: relative; }

.card__badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

## Смещения и inset

`top`, `right`, `bottom`, `left` работают для всех значений, кроме `static`. Шорткат `inset` задает их сразу:

```css
.overlay {
  position: fixed;
  inset: 0; /* top: 0; right: 0; bottom: 0; left: 0 */
}
```

Если заданы и `left`, и `right` у абсолютного элемента без `width`, он растягивается между ними.

## Containing block

Для `absolute` точкой отсчета служит **padding box ближайшего предка** с `position` не `static`. Если такого нет — начальный containing block (размер viewport в начале документа). Кроме того, containing block для `absolute` и `fixed` создает предок с `transform`, `filter`, `perspective`, `contain: paint` или `will-change: transform`.

## Что важно помнить

- `z-index` работает только у позиционированных элементов, а также у flex- и grid-детей.
- `position: fixed` внутри родителя с `transform` ведет себя как `absolute` — частая причина «сломанных» модалок. Решение — рендерить модалку в портал в конце `body`.
- Для центрирования современнее использовать Grid (`place-items: center`), а не `position` с `transform: translate(-50%, -50%)`.
- Новый CSS Anchor Positioning (`anchor-name`, `position-anchor`) позволяет привязывать тултипы к элементам без JS.

## Мини-шпаргалка

- По умолчанию — нормальный поток и `position: static`.
- Раскладка — Flexbox и Grid, точечные смещения — `position`.
- `relative` — от себя, `absolute` — от позиционированного предка, `fixed` — от viewport, `sticky` — прилипает при скролле.
- `inset: 0` — растянуть на весь containing block.
- `transform` у предка меняет containing block для `fixed`.
