# Карта раздела «Docker»

> [!NOTE]
> Раздел покрывает Docker в объёме, который нужен frontend- и fullstack-разработчику: устройство контейнеров, CLI, Dockerfile и кэш, сети и хранение данных, Compose, упаковку Node.js, Vite и Next.js, production-практики (размер, секреты, привилегии, сигналы), CI/CD и оркестрацию. Последняя глава — подготовка к вопросам и рассказу о своём проекте.

## Вопрос

С чего начать изучение Docker и в каком порядке читать раздел?

## Основная идея

На собеседовании Docker проверяют в трёх плоскостях: **модель** (образ, контейнер, слои, сети, volumes), **практика** (написать Dockerfile и `compose.yaml`, отладить падающий контейнер) и **production** (безопасность, размер, graceful shutdown, CI/CD). Главы идут в том же порядке.

Основной стек примеров: Node.js 24, PostgreSQL 18, Redis 8, Nginx, Docker Compose V2, BuildKit.

| Глава | Что внутри |
| --- | --- |
| 01. Основы | Docker, контейнер, VM, образ, Engine/Desktop/Hub, namespaces и cgroups, macOS и Windows |
| 02. CLI | `run`, логи и `exec`, остановка и очистка, `pull/build/tag/push`, лимиты и restart policy |
| 03. Dockerfile | Инструкции, слои и кэш, build context, multi-stage, `CMD`/`ENTRYPOINT`, `COPY`/`ADD`, `ARG`/`ENV`, buildx |
| 04. Сети и данные | Порты и `EXPOSE`, сети и DNS, volumes и bind mounts, данные БД, healthcheck |
| 05. Compose | Структура файла, `depends_on`, сети и volumes, profiles и override, `compose watch` |
| 06. Приложения | Node.js, React/Vite, Next.js, PostgreSQL и Redis, переменные окружения, миграции |
| 07. Production | Best practices, размер и CVE, секреты, отладка, CI/CD, PID 1 и сигналы, привилегии, оркестрация |
| 08. Собеседование | Список вопросов, разбор Dockerfile, works on my machine, fullstack-проект, рассказ о проекте |

## Что важно помнить

- Лучшая подготовка — упаковать свой пет-проект: Dockerfile, `compose.yaml` с базой и миграциями, сборка в CI.
- Самые частые ловушки: `localhost` между контейнерами, `EXPOSE` не публикует порт, `depends_on` не ждёт готовности, секреты в `ARG`/`ENV`, shell-форма `CMD`.
- Для PostgreSQL 18+ volume монтируется в `/var/lib/postgresql`.
