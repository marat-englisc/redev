# Как рисовать фигуры — прямоугольники, пути и дуги

> [!NOTE]
> Готовые методы есть только у прямоугольников: `fillRect`, `strokeRect`, `clearRect` (и `roundRect` для скруглённых). Всё остальное рисуется **путями**: `beginPath()` начинает новый путь, `moveTo`/`lineTo`/`arc`/`quadraticCurveTo`/`bezierCurveTo` добавляют в него отрезки, `closePath()` замыкает, а `fill()` или `stroke()` рисуют. Самая частая ошибка — забыть `beginPath()`: тогда новые фигуры добавляются к старому пути и каждая `fill()` перерисовывает всё накопленное. Для повторяющихся фигур удобен объект `Path2D` — путь создаётся один раз и рисуется много раз.

## Вопрос

Как на canvas нарисовать прямоугольник, линию, круг и произвольную фигуру? Что такое путь и `Path2D`?

## Прямоугольники

```ts
ctx.fillStyle = '#22c55e';
ctx.fillRect(20, 20, 120, 60);     // залитый

ctx.strokeStyle = '#0f172a';
ctx.lineWidth = 4;
ctx.strokeRect(160, 20, 120, 60);  // только контур

ctx.clearRect(40, 30, 20, 20);     // «дырка» — прозрачные пиксели

ctx.beginPath();
ctx.roundRect(300, 20, 120, 60, 12); // скруглённый — это уже путь
ctx.fill();
```

## Пути: линия и треугольник

```ts
// линия
ctx.beginPath();
ctx.moveTo(20, 120);   // перо в точку без рисования
ctx.lineTo(220, 160);  // линия до точки
ctx.lineWidth = 3;
ctx.lineCap = 'round'; // butt | round | square
ctx.stroke();

// треугольник — корабль игрока
ctx.beginPath();
ctx.moveTo(300, 120);
ctx.lineTo(330, 180);
ctx.lineTo(270, 180);
ctx.closePath();       // линия обратно в начало
ctx.fillStyle = '#38bdf8';
ctx.fill();
ctx.stroke();          // один путь можно и залить, и обвести
```

## Круги и дуги

`arc(x, y, radius, startAngle, endAngle, counterclockwise?)` — углы в **радианах**, отсчёт от оси `x` по часовой стрелке.

```ts
// мяч
ctx.beginPath();
ctx.arc(100, 260, 20, 0, Math.PI * 2);
ctx.fillStyle = '#f97316';
ctx.fill();

// «Пакман»: рот 60°
ctx.beginPath();
ctx.moveTo(220, 260);
ctx.arc(220, 260, 30, Math.PI / 6, -Math.PI / 6 + Math.PI * 2);
ctx.closePath();
ctx.fillStyle = '#facc15';
ctx.fill();

// эллипс: (x, y, rx, ry, rotation, start, end)
ctx.beginPath();
ctx.ellipse(340, 260, 40, 20, 0, 0, Math.PI * 2);
ctx.fill();
```

Градусы → радианы: `deg * Math.PI / 180`.

## Кривые

```ts
// квадратичная: одна контрольная точка
ctx.beginPath();
ctx.moveTo(20, 360);
ctx.quadraticCurveTo(120, 280, 220, 360);
ctx.stroke();

// кубическая Безье: две контрольные точки
ctx.beginPath();
ctx.moveTo(240, 360);
ctx.bezierCurveTo(280, 280, 380, 440, 420, 360);
ctx.stroke();
```

## Почему важен beginPath

```ts
// ❌ без beginPath
for (const enemy of enemies) {
  ctx.arc(enemy.x, enemy.y, 10, 0, Math.PI * 2);
  ctx.fill(); // заливает ВСЕ дуги, накопленные с начала, + соединяет их линиями
}

// ✅
for (const enemy of enemies) {
  ctx.beginPath();
  ctx.arc(enemy.x, enemy.y, 10, 0, Math.PI * 2);
  ctx.fill();
}
```

Если цвет у всех одинаковый, можно собрать **один** путь и сделать один `fill()` — это быстрее. Тогда перед каждой дугой нужен `moveTo`, иначе появятся соединительные линии:

```ts
ctx.beginPath();
for (const e of enemies) {
  ctx.moveTo(e.x + 10, e.y);
  ctx.arc(e.x, e.y, 10, 0, Math.PI * 2);
}
ctx.fill();
```

## Path2D — переиспользуемые фигуры

```ts
// путь задаётся один раз в локальных координатах
const ship = new Path2D();
ship.moveTo(0, -15);
ship.lineTo(10, 10);
ship.lineTo(-10, 10);
ship.closePath();

// можно и из SVG-строки
const heart = new Path2D('M10 30 A20 20 0 0 1 50 30 A20 20 0 0 1 90 30 Q90 60 50 90 Q10 60 10 30 Z');

ctx.translate(200, 150);
ctx.fill(ship);
ctx.stroke(ship);

// попадание точки в фигуру
ctx.isPointInPath(ship, mouseX, mouseY);
```

## Стиль линий

```ts
ctx.lineWidth = 2;
ctx.lineJoin = 'round';     // miter | round | bevel — углы
ctx.setLineDash([8, 4]);    // пунктир: 8 линия, 4 пробел
ctx.lineDashOffset = -time / 20; // «бегущий» пунктир
```

## Частые ошибки

- Забыть `beginPath()` — фигуры склеиваются, производительность падает с каждым кадром.
- Передавать в `arc` градусы вместо радианов.
- Ждать, что `closePath()` нарисует фигуру — он только замыкает путь, нужен `fill()`/`stroke()`.
- Линия толщиной 1px на целой координате выглядит размытой: она ложится между пикселями. Сдвиг на `0.5` делает её чёткой.

## Что важно помнить

- Прямоугольники рисуются напрямую, остальное — путями.
- `beginPath()` → построение → `fill()`/`stroke()`.
- Углы в радианах, полный круг — `Math.PI * 2`.
- `Path2D` — фигура, которую строят один раз и рисуют многократно.

## Мини-шпаргалка

```ts
ctx.fillRect(x, y, w, h); ctx.strokeRect(x, y, w, h);
ctx.beginPath(); ctx.moveTo(x, y); ctx.lineTo(x2, y2); ctx.stroke();
ctx.beginPath(); ctx.arc(x, y, r, 0, Math.PI * 2); ctx.fill();
const p = new Path2D(); ctx.fill(p);
```
