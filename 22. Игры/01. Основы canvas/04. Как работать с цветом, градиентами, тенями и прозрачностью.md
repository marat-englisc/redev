# Как работать с цветом, градиентами, тенями и прозрачностью

> [!NOTE]
> `fillStyle` и `strokeStyle` принимают CSS-цвет, **градиент** (`createLinearGradient`, `createRadialGradient`, `createConicGradient`) или **паттерн** (`createPattern` из картинки). Прозрачность задаётся цветом с альфой или глобально через `globalAlpha`. `globalCompositeOperation` меняет способ смешивания: `'lighter'` — свечение и частицы, `'destination-out'` — «стирание». Тени (`shadowBlur`, `shadowColor`) и `filter` красивые, но дорогие: в игре их включают точечно и обязательно возвращают настройки обратно через `save()`/`restore()`.

## Вопрос

Как на canvas задать цвет, градиент, текстуру, прозрачность и тень? Что такое `globalCompositeOperation`?

## Цвет

```ts
ctx.fillStyle = 'tomato';
ctx.fillStyle = '#ff6347';
ctx.fillStyle = 'rgb(255 99 71 / 0.5)';   // полупрозрачный
ctx.fillStyle = 'hsl(200 80% 50%)';

// HSL удобен для генерации: например, цвет врага по его здоровью
ctx.fillStyle = `hsl(${(enemy.hp / enemy.maxHp) * 120} 80% 50%)`; // 120 зелёный → 0 красный
```

## Градиенты

Градиент задаётся в координатах **холста**, а не фигуры: сначала создаём, потом заливаем фигуру внутри его области.

```ts
// небо: линейный сверху вниз
const sky = ctx.createLinearGradient(0, 0, 0, canvas.height);
sky.addColorStop(0, '#0f172a');
sky.addColorStop(1, '#1e3a8a');
ctx.fillStyle = sky;
ctx.fillRect(0, 0, canvas.width, canvas.height);

// свечение: радиальный (x0, y0, r0, x1, y1, r1)
const glow = ctx.createRadialGradient(200, 150, 0, 200, 150, 60);
glow.addColorStop(0, 'rgb(250 204 21 / 1)');
glow.addColorStop(1, 'rgb(250 204 21 / 0)');
ctx.fillStyle = glow;
ctx.fillRect(140, 90, 120, 120);

// конический — индикатор перезарядки
const cd = ctx.createConicGradient(-Math.PI / 2, 400, 150);
cd.addColorStop(0, '#22c55e');
cd.addColorStop(1, '#14532d');
```

Градиенты лучше создавать один раз, а не в каждом кадре.

## Паттерны (текстуры)

```ts
const img = new Image();
img.src = '/tiles/grass.png';
await img.decode();

const grass = ctx.createPattern(img, 'repeat')!;  // repeat | repeat-x | repeat-y | no-repeat
ctx.fillStyle = grass;
ctx.fillRect(0, 300, canvas.width, 100);
```

## Прозрачность

```ts
ctx.globalAlpha = 0.5;            // влияет на ВСЁ, что рисуется дальше
ctx.drawImage(ghostSprite, x, y);
ctx.globalAlpha = 1;              // не забыть вернуть

// мигание после получения урона
if (player.invulnerable) ctx.globalAlpha = Math.sin(time / 50) > 0 ? 1 : 0.3;
```

## Тени

```ts
ctx.save();
ctx.shadowColor = 'rgb(56 189 248 / 0.8)';
ctx.shadowBlur = 20;     // размытие
ctx.shadowOffsetX = 0;
ctx.shadowOffsetY = 0;
ctx.fillStyle = '#38bdf8';
ctx.fillRect(100, 100, 40, 40);  // «неоновый» квадрат
ctx.restore();           // тень выключена для остальных объектов
```

> [!WARNING]
> `shadowBlur` пересчитывается при каждом вызове рисования. Сотни объектов с тенью — заметное падение FPS. Для частиц и врагов лучше заранее нарисовать «светящийся» спрайт в offscreen-canvas и рисовать уже его.

## Режимы смешивания

```ts
// частицы взрыва: перекрытия становятся ярче
ctx.globalCompositeOperation = 'lighter';
for (const p of particles) drawParticle(p);
ctx.globalCompositeOperation = 'source-over'; // режим по умолчанию

// «туман войны»: заливаем темноту и вырезаем круг вокруг игрока
fog.fillStyle = 'black';
fog.fillRect(0, 0, w, h);
fog.globalCompositeOperation = 'destination-out';
fog.beginPath();
fog.arc(player.x, player.y, 120, 0, Math.PI * 2);
fog.fill();
fog.globalCompositeOperation = 'source-over';
```

| Режим | Эффект |
| --- | --- |
| `source-over` | обычное рисование поверх |
| `lighter` | сложение цветов — свет, огонь, искры |
| `multiply` | затемнение — тени, освещение |
| `destination-out` | стирает то, что под фигурой |
| `source-atop` | рисует только поверх уже нарисованного — вспышка белым по спрайту |

## Фильтры

```ts
ctx.filter = 'blur(4px) brightness(1.2)'; // синтаксис CSS filter
ctx.drawImage(bg, 0, 0);
ctx.filter = 'none';
```

## Частые ошибки

- Менять `globalAlpha`, `shadowBlur`, `globalCompositeOperation` и не возвращать обратно — эффект «расползается» на весь кадр.
- Создавать градиенты и паттерны в каждом кадре.
- Ожидать, что градиент привязан к фигуре: он в координатах холста (или текущей трансформации).
- Использовать `createPattern` до загрузки картинки.

## Что важно помнить

- `fillStyle`/`strokeStyle`: цвет, градиент или паттерн.
- `globalAlpha` и `globalCompositeOperation` действуют на всё последующее рисование.
- Тени и фильтры дорогие — заранее рендерите эффект в спрайт.
- Временные настройки оборачивайте в `save()`/`restore()`.

## Мини-шпаргалка

```ts
const g = ctx.createLinearGradient(x0, y0, x1, y1); g.addColorStop(0, c1);
ctx.createPattern(img, 'repeat');
ctx.globalAlpha = 0.5;
ctx.globalCompositeOperation = 'lighter';
ctx.shadowBlur = 10; ctx.shadowColor = 'cyan';
```
