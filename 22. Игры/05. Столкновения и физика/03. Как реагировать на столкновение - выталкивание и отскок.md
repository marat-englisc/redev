# Как реагировать на столкновение — выталкивание и отскок

> [!NOTE]
> Обнаружить столкновение мало — нужно его **разрешить**. Для стен и платформ объект **выталкивают** из препятствия на глубину проникновения по оси наименьшего перекрытия и обнуляют скорость по этой оси. В платформерах надёжнее двигать объект **по осям раздельно**: сначала по X и разрешить столкновения по X, затем по Y — так персонаж не «застревает» на стыках блоков и корректно определяется `onGround`. **Отскок** — отражение скорости относительно нормали, умноженное на коэффициент упругости (`restitution`). Для двух подвижных тел (бильярд) используют импульсы с учётом масс.

## Вопрос

Что делать, когда объекты столкнулись: как вытолкнуть персонажа из стены, приземлить на платформу и реализовать отскок?

## Вытолкнуть по оси минимального перекрытия

```ts
interface Box { x: number; y: number; w: number; h: number; vx: number; vy: number }

function resolve(a: Box, wall: { x: number; y: number; w: number; h: number }) {
  // глубина проникновения с каждой стороны
  const overlapX = Math.min(a.x + a.w - wall.x, wall.x + wall.w - a.x);
  const overlapY = Math.min(a.y + a.h - wall.y, wall.y + wall.h - a.y);
  if (overlapX <= 0 || overlapY <= 0) return;   // нет пересечения

  if (overlapX < overlapY) {
    // выталкиваем по X в сторону центра
    const dir = a.x + a.w / 2 < wall.x + wall.w / 2 ? -1 : 1;
    a.x += overlapX * dir;
    a.vx = 0;
  } else {
    const dir = a.y + a.h / 2 < wall.y + wall.h / 2 ? -1 : 1;
    a.y += overlapY * dir;
    a.vy = 0;
  }
}
```

Этого хватает для вида сверху. В платформере на стыке двух блоков пола этот способ иногда выталкивает персонажа вбок — «зацепился за шов».

## Платформер: движение по осям раздельно

```ts
function moveAndCollide(p: Box & { onGround: boolean }, solids: Box[], dt: number) {
  // 1. Горизонталь
  p.x += p.vx * dt;
  for (const s of solids) {
    if (!aabb(p, s)) continue;
    if (p.vx > 0) p.x = s.x - p.w;        // упёрлись правым боком
    else if (p.vx < 0) p.x = s.x + s.w;   // левым
    p.vx = 0;
  }

  // 2. Вертикаль
  p.y += p.vy * dt;
  p.onGround = false;
  for (const s of solids) {
    if (!aabb(p, s)) continue;
    if (p.vy > 0) {                       // падали → приземлились
      p.y = s.y - p.h;
      p.onGround = true;
    } else if (p.vy < 0) {                // ударились головой
      p.y = s.y + s.h;
    }
    p.vy = 0;
  }
}
```

Мы знаем направление движения по каждой оси, поэтому однозначно понимаем, с какой стороны произошло столкновение.

## Платформы «с проходом снизу» (one-way)

```ts
// разрешаем столкновение только если падаем и в прошлом кадре были выше платформы
if (p.vy > 0 && prevBottom <= platform.y && aabb(p, platform)) {

}
// спрыгнуть вниз: на несколько кадров игнорировать one-way платформы
```

## Отскок от стены

```ts
const RESTITUTION = 0.8; // 1 — абсолютно упругий, 0 — без отскока

// арканоид: отражение от горизонтальной/вертикальной поверхности
if (ball.x - ball.r < 0 || ball.x + ball.r > W) ball.vx *= -RESTITUTION;
if (ball.y - ball.r < 0) ball.vy *= -RESTITUTION;

// произвольная поверхность с нормалью n (единичный вектор)
const vn = ball.vx * n.x + ball.vy * n.y;   // скорость вдоль нормали
if (vn < 0) {                               // движемся в поверхность
  ball.vx -= (1 + RESTITUTION) * vn * n.x;
  ball.vy -= (1 + RESTITUTION) * vn * n.y;
}
```

Не забудьте также вытолкнуть мяч из стены, иначе в следующем кадре он снова «столкнётся» и начнёт дрожать.

## Управляемый отскок от ракетки

В арканоиде угол вылета зависит от места удара — это делает игру управляемой:

```ts
const hit = (ball.x - paddle.x) / (paddle.w / 2);   // -1 левый край … 1 правый
const angle = hit * (Math.PI / 3);                  // до ±60° от вертикали
const speed = Math.hypot(ball.vx, ball.vy);
ball.vx = Math.sin(angle) * speed;
ball.vy = -Math.cos(angle) * speed;
ball.y = paddle.y - ball.r;                          // вытолкнуть
```

## Столкновение двух подвижных кругов

```ts
function bounceCircles(a: Ball, b: Ball) {
  const dx = b.x - a.x, dy = b.y - a.y;
  const dist = Math.hypot(dx, dy);
  const overlap = a.r + b.r - dist;
  if (overlap <= 0 || dist === 0) return;

  const nx = dx / dist, ny = dy / dist;          // нормаль от a к b

  // 1. раздвинуть пропорционально массам
  const total = a.mass + b.mass;
  a.x -= nx * overlap * (b.mass / total);
  a.y -= ny * overlap * (b.mass / total);
  b.x += nx * overlap * (a.mass / total);
  b.y += ny * overlap * (a.mass / total);

  // 2. импульс
  const relVel = (b.vx - a.vx) * nx + (b.vy - a.vy) * ny;
  if (relVel > 0) return;                        // уже разлетаются
  const e = 0.9;
  const j = (-(1 + e) * relVel) / (1 / a.mass + 1 / b.mass);
  a.vx -= (j / a.mass) * nx;  a.vy -= (j / a.mass) * ny;
  b.vx += (j / b.mass) * nx;  b.vy += (j / b.mass) * ny;
}
```

Когда тел становится много, они стоят стопками или соединены шарнирами, — пора брать физический движок (Matter.js, Rapier, Planck.js).

## События столкновений

```ts
// «вход» в столкновение — один раз, а не каждый кадр, пока объекты касаются
const key = `${a.id}:${b.id}`;
if (touching && !prevContacts.has(key)) onCollisionEnter(a, b);
if (touching) contacts.add(key);
```

Иначе монетка подберётся 10 раз, а шип нанесёт урон каждый кадр. Альтернатива — неуязвимость на 0,5–1 с после урона.

## Частые ошибки

- Обнулять скорость, но не выталкивать объект — он остаётся внутри стены и дрожит.
- Двигать по обеим осям сразу и потом гадать, с какой стороны был удар.
- Считать `onGround` по координате, а не по факту разрешённого столкновения снизу.
- Отражать скорость при каждом кадре касания — объект «залипает» и вибрирует; проверяйте `vn < 0`.
- Писать свой физический движок для стопок ящиков и цепей.

## Что важно помнить

- Обнаружение → разрешение: выталкивание + изменение скорости.
- Платформер: сначала X, потом Y, каждый со своей проверкой.
- Отскок: `v -= (1 + e)(v·n)n`, только если `v·n < 0`.
- Для сложной физики — Matter.js, Rapier, Planck.js.

## Мини-шпаргалка

```ts
x += vx * dt; resolveX(); y += vy * dt; resolveY();
if (vy > 0) { y = top - h; vy = 0; onGround = true; }
vn = vx * nx + vy * ny; if (vn < 0) { vx -= (1 + e) * vn * nx; vy -= (1 + e) * vn * ny; }
```
