# Как проверять столкновения — AABB, круги и SAT

> [!NOTE]
> Большинство 2D-игр обходится двумя формами коллайдеров. **AABB** (axis-aligned bounding box) — прямоугольник без поворота: два прямоугольника пересекаются, если пересекаются их проекции по обеим осям. **Круг**: пересечение, если расстояние между центрами меньше суммы радиусов (сравнивают квадраты, без корня). Для повёрнутых прямоугольников и выпуклых многоугольников используют **SAT** (теорема о разделяющей оси): если есть ось, на которой проекции фигур не перекрываются, — столкновения нет. Коллайдер обычно **проще и чуть меньше** картинки — так игра ощущается честнее. Быстрые объекты могут «проскочить» сквозь препятствие (tunneling) — помогают маленький фиксированный шаг, подшаги или raycast.

## Вопрос

Как проверить столкновение двух объектов в 2D-игре? Что такое AABB, проверка кругов и SAT?

## AABB — прямоугольник с прямоугольником

```ts
interface AABB { x: number; y: number; w: number; h: number } // x, y — левый верхний угол

function aabb(a: AABB, b: AABB) {
  return a.x < b.x + b.w &&
         a.x + a.w > b.x &&
         a.y < b.y + b.h &&
         a.y + a.h > b.y;
}
```

```text
 a ┌──────┐
   │   ┌──┼───┐ b     пересекаются по X И по Y → столкновение
   └───┼──┘   │
       └──────┘
```

## Круг с кругом

```ts
interface Circle { x: number; y: number; r: number }

function circles(a: Circle, b: Circle) {
  const dx = b.x - a.x;
  const dy = b.y - a.y;
  const rr = a.r + b.r;
  return dx * dx + dy * dy < rr * rr;
}
```

Круги хорошо подходят для пуль, астероидов, персонажей вида сверху: их не нужно поворачивать, и выталкивание считается просто.

## Круг с прямоугольником

Находим ближайшую к центру круга точку прямоугольника и сравниваем расстояние:

```ts
function circleRect(c: Circle, r: AABB) {
  const nearestX = Math.max(r.x, Math.min(c.x, r.x + r.w));
  const nearestY = Math.max(r.y, Math.min(c.y, r.y + r.h));
  const dx = c.x - nearestX;
  const dy = c.y - nearestY;
  return dx * dx + dy * dy < c.r * c.r;
}
```

Классический случай — мяч и платформа в арканоиде.

## SAT — повёрнутые прямоугольники и многоугольники

Идея: две **выпуклые** фигуры не пересекаются, если существует прямая, на проекции на которую они не перекрываются. Проверять нужно только оси, перпендикулярные рёбрам фигур.

```ts
type Vec = { x: number; y: number };

function project(points: Vec[], axis: Vec) {
  let min = Infinity, max = -Infinity;
  for (const p of points) {
    const d = p.x * axis.x + p.y * axis.y;   // скалярное произведение = проекция
    if (d < min) min = d;
    if (d > max) max = d;
  }
  return { min, max };
}

function axesOf(points: Vec[]): Vec[] {
  return points.map((p, i) => {
    const q = points[(i + 1) % points.length];
    const edge = { x: q.x - p.x, y: q.y - p.y };
    const len = Math.hypot(edge.x, edge.y);
    return { x: -edge.y / len, y: edge.x / len };  // нормаль к ребру
  });
}

function sat(a: Vec[], b: Vec[]) {
  for (const axis of [...axesOf(a), ...axesOf(b)]) {
    const pa = project(a, axis);
    const pb = project(b, axis);
    if (pa.max < pb.min || pb.max < pa.min) return false; // нашли разделяющую ось
  }
  return true;
}

// вершины повёрнутого прямоугольника
function corners(cx: number, cy: number, w: number, h: number, angle: number): Vec[] {
  const c = Math.cos(angle), s = Math.sin(angle);
  return [[-w / 2, -h / 2], [w / 2, -h / 2], [w / 2, h / 2], [-w / 2, h / 2]]
    .map(([x, y]) => ({ x: cx + x * c - y * s, y: cy + x * s + y * c }));
}
```

Минимальное перекрытие среди всех осей даёт ещё и **вектор выталкивания** (MTV) — на сколько и куда раздвинуть фигуры. Невыпуклые фигуры разбивают на выпуклые части.

## Широкая и узкая фаза

Проверка «каждый с каждым» — O(n²): 1000 объектов = ~500 000 проверок за кадр.

```ts
// 1. broad phase — быстро отсекаем далёкие пары (AABB или сетка)
// 2. narrow phase — точная проверка (SAT, пиксели) только для кандидатов
for (const [a, b] of grid.candidatePairs()) {
  if (aabb(a.bounds, b.bounds) && sat(a.polygon, b.polygon)) onHit(a, b);
}
```

Про пространственную сетку — отдельный урок.

## Tunneling: быстрые объекты

```text
кадр 1: пуля ●         ┃ стена
кадр 2:                ┃        ● пуля — проверка не видит столкновения
```

Решения:

- фиксированный маленький шаг физики;
- **подшаги**: если объект за кадр проходит больше своего размера, делим перемещение на части;
- **raycast/swept AABB**: проверяем отрезок движения, а не конечную точку.

```ts
// подшаги
const steps = Math.ceil((Math.hypot(b.vx, b.vy) * dt) / b.r);
for (let i = 0; i < steps; i++) {
  b.x += (b.vx * dt) / steps;
  b.y += (b.vy * dt) / steps;
  if (hitsWall(b)) { onHit(b); break; }
}
```

## Хитбоксы

```ts
class Player {
  // картинка 32×32, но коллайдер меньше — прощает «почти попадания»
  get hitbox() { return { x: this.x - 10, y: this.y - 12, w: 20, h: 26 }; }
}
```

В шутерах «bullet hell» хитбокс игрока часто — несколько пикселей в центре спрайта. Для отладки полезно рисовать коллайдеры поверх игры по клавише.

## Частые ошибки

- Путать `x, y` как центр и как левый верхний угол у разных объектов.
- Использовать AABB для повёрнутых спрайтов — пустые углы «сталкиваются».
- Проверять каждую пару дважды (`a-b` и `b-a`) — двойной урон. Внутренний цикл от `i + 1`.
- Считать `Math.sqrt` для каждого сравнения расстояний.
- Применять SAT к невыпуклым многоугольникам.

## Что важно помнить

- AABB: перекрытие по X и по Y.
- Круги: квадрат расстояния < квадрат суммы радиусов.
- Круг–прямоугольник: ближайшая точка через `clamp`.
- SAT — для выпуклых повёрнутых фигур, даёт и вектор выталкивания.
- Broad phase + narrow phase; против tunneling — подшаги или raycast.
