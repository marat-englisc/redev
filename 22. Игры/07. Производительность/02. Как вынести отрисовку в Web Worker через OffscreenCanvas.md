# Как вынести отрисовку в Web Worker через OffscreenCanvas

> [!NOTE]
> `OffscreenCanvas` — canvas, не привязанный к DOM. У него два применения. Первое — **буфер в памяти** для предварительного рендера спрайтов (работает и в главном потоке). Второе — **перенос всей отрисовки в Web Worker**: `canvas.transferControlToOffscreen()` передаёт управление холстом воркеру, и тот рисует с собственным `requestAnimationFrame`, не мешая главному потоку. Тогда тяжёлая логика страницы (React, парсинг, GC) не роняет FPS игры, и наоборот. Цена — воркер не видит DOM и события: ввод пересылается через `postMessage`, а ресурсы грузятся внутри воркера через `fetch` + `createImageBitmap`.

## Вопрос

Что такое `OffscreenCanvas` и как перенести игровой цикл и рендеринг в Web Worker?

## OffscreenCanvas как буфер

```ts
const buffer = new OffscreenCanvas(256, 256);
const g = buffer.getContext('2d')!;
g.fillStyle = 'tomato';
g.fillRect(0, 0, 256, 256);

ctx.drawImage(buffer, 0, 0);            // рисуется как обычная картинка
const bitmap = buffer.transferToImageBitmap(); // или забрать как ImageBitmap
```

## Перенос отрисовки в воркер

```ts
// main.ts — главный поток
const canvas = document.querySelector<HTMLCanvasElement>('#game')!;
const offscreen = canvas.transferControlToOffscreen(); // после этого getContext в main недоступен

const worker = new Worker(new URL('./game.worker.ts', import.meta.url), { type: 'module' });

worker.postMessage(
  { type: 'init', canvas: offscreen, width: canvas.clientWidth, height: canvas.clientHeight, dpr: devicePixelRatio },
  [offscreen],                           // transferable: передаём владение, а не копию
);

// ввод — пересылаем сообщениями
addEventListener('keydown', (e) => worker.postMessage({ type: 'key', code: e.code, down: true }));
addEventListener('keyup', (e) => worker.postMessage({ type: 'key', code: e.code, down: false }));

canvas.addEventListener('pointermove', (e) => {
  const r = canvas.getBoundingClientRect();
  worker.postMessage({ type: 'pointer', x: e.clientX - r.left, y: e.clientY - r.top });
});

new ResizeObserver(([entry]) => {
  const { width, height } = entry.contentRect;
  worker.postMessage({ type: 'resize', width, height, dpr: devicePixelRatio });
}).observe(canvas);

// события из игры — в UI (React, DOM)
worker.addEventListener('message', (e) => {
  if (e.data.type === 'score') scoreEl.textContent = String(e.data.value);
});
```

```ts
// game.worker.ts — воркер
let ctx: OffscreenCanvasRenderingContext2D;
let canvas: OffscreenCanvas;
const keys = new Set<string>();
const player = { x: 100, y: 100 };
let last = 0;
let heroImg: ImageBitmap;

self.onmessage = async (e: MessageEvent) => {
  const msg = e.data;
  switch (msg.type) {
    case 'init':
      canvas = msg.canvas;
      ctx = canvas.getContext('2d')!;
      resize(msg.width, msg.height, msg.dpr);
      heroImg = await loadBitmap('/sprites/hero.png');
      requestAnimationFrame(loop);          // rAF доступен в dedicated worker
      break;
    case 'resize':
      resize(msg.width, msg.height, msg.dpr);
      break;
    case 'key':
      msg.down ? keys.add(msg.code) : keys.delete(msg.code);
      break;
  }
};

function resize(w: number, h: number, dpr: number) {
  canvas.width = w * dpr;                  // в воркере можно менять размер буфера
  canvas.height = h * dpr;
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
}

async function loadBitmap(url: string) {
  const blob = await fetch(url).then((r) => r.blob());
  return createImageBitmap(blob);          // Image() в воркере нет
}

function loop(now: number) {
  const dt = Math.min((now - last) / 1000, 0.1);
  last = now;

  if (keys.has('ArrowRight')) player.x += 200 * dt;
  if (keys.has('ArrowLeft')) player.x -= 200 * dt;

  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.drawImage(heroImg, player.x, player.y);

  requestAnimationFrame(loop);
}
```

## Что доступно в воркере

| Есть | Нет |
| --- | --- |
| `OffscreenCanvas`, 2D, WebGL, WebGPU | `document`, DOM, `window` |
| `requestAnimationFrame` (dedicated worker) | события мыши и клавиатуры |
| `fetch`, `createImageBitmap`, `FontFace` | `new Image()` |
| `performance.now()` | `localStorage` (есть IndexedDB) |

Звук (Web Audio) в воркере недоступен — `AudioContext` остаётся в главном потоке, воркер просит проиграть звук сообщением.

## Когда это нужно

- Игра встроена в тяжёлое SPA, и рендер React/Vue мешает плавности.
- Визуализация с тяжёлыми вычислениями (симуляции, графики на миллионы точек).
- Нужно, чтобы UI оставался отзывчивым во время тяжёлого кадра.

Для простой отдельной игры воркер добавляет сложности (сообщения, отладка) без заметной выгоды. PixiJS и Three.js тоже умеют работать с `OffscreenCanvas` в воркере.

## Вычисления в воркере без переноса canvas

Альтернатива — оставить отрисовку в главном потоке, а в воркер вынести тяжёлую физику или поиск пути и обмениваться данными через `Float32Array` (передаётся как transferable) или `SharedArrayBuffer` (требует cross-origin isolation).

```ts
// main → worker: позиции 10 000 частиц без копирования
const positions = new Float32Array(20_000);
worker.postMessage({ type: 'step', positions }, [positions.buffer]);
```

## Частые ошибки

- Вызывать `canvas.getContext()` в главном потоке после `transferControlToOffscreen()` — ошибка.
- Пытаться создать `new Image()` в воркере — используйте `createImageBitmap`.
- Пересылать каждое `pointermove` без троттлинга при сотнях событий в секунду — лишняя нагрузка (обычно терпимо, но можно отправлять раз в кадр).
- Забыть указать transferable-список — `OffscreenCanvas` не передастся.
- Ожидать, что воркер ускорит саму отрисовку — он лишь разгружает главный поток.

## Что важно помнить

- `OffscreenCanvas` — буфер в памяти и способ рисовать в воркере.
- `transferControlToOffscreen()` + `postMessage(…, [offscreen])`.
- В воркере: свой `rAF`, `createImageBitmap`, нет DOM и событий.
- Ввод и ресайз пересылаются сообщениями, звук остаётся в главном потоке.

## Мини-шпаргалка

```ts
const off = canvas.transferControlToOffscreen();
worker.postMessage({ canvas: off }, [off]);
// worker: const ctx = e.data.canvas.getContext('2d'); requestAnimationFrame(loop);
createImageBitmap(await (await fetch(url)).blob());
```
