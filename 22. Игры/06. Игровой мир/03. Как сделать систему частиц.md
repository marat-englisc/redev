# Как сделать систему частиц

> [!NOTE]
> **Частицы** — множество маленьких короткоживущих объектов: искры, дым, кровь, пыль из-под ног, звёзды. У каждой частицы есть позиция, скорость, время жизни и параметры внешнего вида, которые меняются с возрастом (размер уменьшается, прозрачность падает, цвет переходит из жёлтого в красный). **Эмиттер** создаёт частицы со случайным разбросом скорости, угла и размера. Частиц бывают тысячи, поэтому их хранят в пуле, обновляют простым циклом без аллокаций и рисуют дёшево: прямоугольниками или заранее подготовленным спрайтом, часто в режиме `'lighter'` для свечения. Для десятков тысяч частиц используют WebGL (`ParticleContainer` в PixiJS).

## Вопрос

Как реализовать систему частиц для взрывов, дыма и искр на canvas?

## Частица и эмиттер

```ts
interface Particle {
  x: number; y: number;
  vx: number; vy: number;
  life: number;        // сколько осталось, с
  maxLife: number;
  size: number;
  color: string;
  active: boolean;
}

interface EmitOptions {
  count: number;
  speed: [number, number];         // разброс скорости
  angle: [number, number];         // направление, рад
  life: [number, number];
  size: [number, number];
  colors: string[];
}

const rand = (min: number, max: number) => min + Math.random() * (max - min);

export class ParticleSystem {
  private particles: Particle[];
  private cursor = 0;
  gravity = 0;
  drag = 0.98;

  constructor(max = 3000) {
    this.particles = Array.from({ length: max }, () => ({
      x: 0, y: 0, vx: 0, vy: 0, life: 0, maxLife: 1, size: 1, color: '#fff', active: false,
    }));
  }

  emit(x: number, y: number, o: EmitOptions) {
    for (let i = 0; i < o.count; i++) {
      const p = this.particles[this.cursor];
      this.cursor = (this.cursor + 1) % this.particles.length; // кольцевой буфер

      const a = rand(o.angle[0], o.angle[1]);
      const s = rand(o.speed[0], o.speed[1]);
      p.x = x;
      p.y = y;
      p.vx = Math.cos(a) * s;
      p.vy = Math.sin(a) * s;
      p.maxLife = p.life = rand(o.life[0], o.life[1]);
      p.size = rand(o.size[0], o.size[1]);
      p.color = o.colors[(Math.random() * o.colors.length) | 0];
      p.active = true;
    }
  }

  update(dt: number) {
    const drag = Math.pow(this.drag, dt * 60);    // сопротивление воздуха, независимо от FPS
    for (const p of this.particles) {
      if (!p.active) continue;
      p.life -= dt;
      if (p.life <= 0) { p.active = false; continue; }
      p.vy += this.gravity * dt;
      p.vx *= drag;
      p.vy *= drag;
      p.x += p.vx * dt;
      p.y += p.vy * dt;
    }
  }

  draw(ctx: CanvasRenderingContext2D) {
    ctx.save();
    ctx.globalCompositeOperation = 'lighter';     // перекрытия светятся
    for (const p of this.particles) {
      if (!p.active) continue;
      const t = p.life / p.maxLife;               // 1 → 0 с возрастом
      const size = p.size * t;
      ctx.globalAlpha = t;
      ctx.fillStyle = p.color;
      ctx.fillRect(p.x - size / 2, p.y - size / 2, size, size);
    }
    ctx.restore();
  }
}
```

## Пресеты эффектов

```ts
const particles = new ParticleSystem();
particles.gravity = 400;

// взрыв: во все стороны
function explosion(x: number, y: number) {
  particles.emit(x, y, {
    count: 80,
    speed: [80, 360],
    angle: [0, Math.PI * 2],
    life: [0.3, 0.9],
    size: [2, 6],
    colors: ['#fde047', '#f97316', '#ef4444'],
  });
}

// пыль из-под ног при приземлении: веером вверх
function landingDust(x: number, y: number) {
  particles.emit(x, y, {
    count: 12,
    speed: [30, 90],
    angle: [-Math.PI, 0],              // верхняя полуокружность
    life: [0.2, 0.4],
    size: [2, 4],
    colors: ['#d6d3d1', '#a8a29e'],
  });
}

// след ракеты: каждый кадр по несколько частиц против движения
function rocketTrail(r: Rocket) {
  const back = Math.atan2(-r.vy, -r.vx);
  particles.emit(r.x, r.y, {
    count: 2,
    speed: [20, 60],
    angle: [back - 0.3, back + 0.3],
    life: [0.2, 0.5],
    size: [3, 5],
    colors: ['#fb923c', '#fef08a'],
  });
}
```

## Красивое свечение без shadowBlur

Круглые мягкие частицы рисуют из заранее подготовленной текстуры:

```ts
function makeGlowSprite(color: string, r = 16) {
  const c = new OffscreenCanvas(r * 2, r * 2);
  const g = c.getContext('2d')!;
  const grad = g.createRadialGradient(r, r, 0, r, r, r);
  grad.addColorStop(0, color);
  grad.addColorStop(1, 'transparent');
  g.fillStyle = grad;
  g.fillRect(0, 0, r * 2, r * 2);
  return c;
}

const glow = makeGlowSprite('rgb(255 200 80)');
// в draw: ctx.drawImage(glow, p.x - size, p.y - size, size * 2, size * 2);
```

`drawImage` готового спрайта в разы дешевле, чем `shadowBlur` или градиент на каждую частицу.

## Интерполяция цвета по возрасту

```ts
// огонь: жёлтый → оранжевый → красный → серый дым
const hue = 50 * t;                      // 50 (жёлтый) → 0 (красный)
const light = 30 + 30 * t;
ctx.fillStyle = `hsl(${hue} 100% ${light}%)`;
```

Строки создаются каждый вызов — для тысяч частиц лучше заранее подготовить палитру из 16–32 цветов и выбирать по индексу.

## Производительность

| Количество | Подход |
| --- | --- |
| до ~1–2 тыс. | canvas 2D, `fillRect` или `drawImage` спрайта |
| ~2–10 тыс. | пакетная отрисовка: одинаковые частицы одним путём, без смены стилей |
| 10 тыс.+ | WebGL: PixiJS `ParticleContainer`, Three.js `Points`, инстансинг |

Смена `fillStyle` и `globalAlpha` для каждой частицы — главный тормоз в 2D. Группируйте частицы по цвету.

## Частые ошибки

- Создавать `new Particle()` на каждую частицу и удалять через `splice` — сборщик мусора и O(n) удаления.
- Использовать `shadowBlur` для свечения частиц.
- Забыть `restore()` после `globalCompositeOperation = 'lighter'` — весь кадр «засвечивается».
- Не ограничивать общее число частиц — эффекты от 50 врагов одновременно кладут FPS.

## Что важно помнить

- Частица: позиция, скорость, время жизни; внешний вид зависит от `life / maxLife`.
- Эмиттер задаёт разброс параметров случайными диапазонами.
- Пул фиксированного размера, кольцевой буфер, никаких аллокаций в цикле.
- Свечение — `'lighter'` + готовый спрайт, тысячи частиц — WebGL.

## Мини-шпаргалка

```ts
p.vx = Math.cos(a) * speed; p.vy = Math.sin(a) * speed;
p.life -= dt; if (p.life <= 0) p.active = false;
const t = p.life / p.maxLife; ctx.globalAlpha = t;
ctx.globalCompositeOperation = 'lighter';
```
