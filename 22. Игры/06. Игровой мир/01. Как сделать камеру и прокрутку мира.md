# Как сделать камеру и прокрутку мира

> [!NOTE]
> Мир игры обычно больше экрана. **Камера** — это прямоугольник в мировых координатах, который сейчас виден. Отрисовка мира начинается с `ctx.translate(-camera.x, -camera.y)` (плюс `scale` для зума), а интерфейс (HUD) рисуется **после** `restore()` — в экранных координатах. Камера следует за игроком плавно (lerp), её ограничивают границами уровня, а для удобства добавляют «мёртвую зону», в которой игрок двигается без сдвига камеры. Объекты за пределами камеры не рисуют (**culling**) — это одна из самых дешёвых оптимизаций. Параллакс — фоновые слои, которые сдвигаются медленнее камеры, создают ощущение глубины.

## Вопрос

Как реализовать камеру, которая следует за игроком в мире больше экрана? Как сделать зум, параллакс и не рисовать то, что вне экрана?

## Камера

```ts
export class Camera {
  x = 0;            // левый верхний угол видимой области в мире
  y = 0;
  zoom = 1;

  constructor(public viewW: number, public viewH: number) {}

  get width() { return this.viewW / this.zoom; }   // видимая ширина мира
  get height() { return this.viewH / this.zoom; }

  follow(target: { x: number; y: number }, dt: number, world: { w: number; h: number }) {
    const tx = target.x - this.width / 2;
    const ty = target.y - this.height / 2;

    const k = 1 - Math.exp(-6 * dt);              // плавность, не зависит от FPS
    this.x += (tx - this.x) * k;
    this.y += (ty - this.y) * k;

    // не показываем пустоту за краями уровня
    this.x = Math.max(0, Math.min(this.x, world.w - this.width));
    this.y = Math.max(0, Math.min(this.y, world.h - this.height));
  }

  apply(ctx: CanvasRenderingContext2D) {
    ctx.scale(this.zoom, this.zoom);
    ctx.translate(-Math.round(this.x), -Math.round(this.y)); // округление — пиксель-арт не дрожит
  }

  isVisible(b: { x: number; y: number; w: number; h: number }, margin = 32) {
    return b.x + b.w > this.x - margin && b.x < this.x + this.width + margin &&
           b.y + b.h > this.y - margin && b.y < this.y + this.height + margin;
  }

  screenToWorld(sx: number, sy: number) {
    return { x: sx / this.zoom + this.x, y: sy / this.zoom + this.y };
  }
}
```

## Отрисовка кадра

```ts
function render() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  drawParallax();                      // фон — до камеры

  ctx.save();
  camera.apply(ctx);                   // дальше — мировые координаты
  drawTilemap();
  for (const e of entities) {
    if (camera.isVisible(e.bounds)) e.draw(ctx);   // culling
  }
  ctx.restore();

  drawHud();                           // экранные координаты: счёт, жизни, мини-карта
}
```

## Мёртвая зона

Камера двигается, только когда игрок выходит из центральной рамки — экран меньше «дёргается» при мелких движениях:

```ts
const DZ_W = 120, DZ_H = 80;

function followDeadzone(cam: Camera, p: { x: number; y: number }) {
  const left = cam.x + cam.width / 2 - DZ_W / 2;
  const right = left + DZ_W;
  const top = cam.y + cam.height / 2 - DZ_H / 2;
  const bottom = top + DZ_H;

  if (p.x < left) cam.x -= left - p.x;
  else if (p.x > right) cam.x += p.x - right;
  if (p.y < top) cam.y -= top - p.y;
  else if (p.y > bottom) cam.y += p.y - bottom;
}
```

В платформерах часто добавляют **look-ahead**: камера смещается в сторону взгляда персонажа, чтобы игрок видел, что впереди.

```ts
const lookAhead = player.facing * 60;
camera.follow({ x: player.x + lookAhead, y: player.y }, dt, level);
```

## Зум к точке под курсором

```ts
canvas.addEventListener('wheel', (e) => {
  e.preventDefault();
  const before = camera.screenToWorld(e.offsetX, e.offsetY);
  camera.zoom = Math.max(0.5, Math.min(4, camera.zoom * (e.deltaY < 0 ? 1.1 : 0.9)));
  const after = camera.screenToWorld(e.offsetX, e.offsetY);
  camera.x += before.x - after.x;     // точка под курсором остаётся на месте
  camera.y += before.y - after.y;
}, { passive: false });
```

## Параллакс

```ts
const layers = [
  { img: sky, factor: 0 },       // неподвижное небо
  { img: mountains, factor: 0.2 },
  { img: trees, factor: 0.5 },
];

function drawParallax() {
  for (const l of layers) {
    const w = l.img.width;
    // смещение слоя, зацикленное по ширине картинки
    const offset = -((camera.x * l.factor) % w);
    for (let x = offset - w; x < canvas.width; x += w) {
      ctx.drawImage(l.img, Math.round(x), 0);
    }
  }
}
```

Чем меньше `factor`, тем «дальше» слой. Слои **перед** игроком (туман, листья) получают `factor > 1`.

## Тряска камеры

Тряска добавляется смещением при `apply`, а не изменением `camera.x` — иначе она сломает следование:

```ts
apply(ctx: CanvasRenderingContext2D) {
  const sx = (Math.random() * 2 - 1) * this.shake * 8;
  const sy = (Math.random() * 2 - 1) * this.shake * 8;
  ctx.scale(this.zoom, this.zoom);
  ctx.translate(-Math.round(this.x + sx), -Math.round(this.y + sy));
}
```

## Частые ошибки

- Рисовать HUD внутри трансформации камеры — счёт «уезжает» вместе с миром.
- Не ограничивать камеру границами уровня — видна пустота.
- Не делать culling и рисовать весь уровень из тысяч тайлов каждый кадр.
- Не учитывать камеру и зум при переводе координат мыши.
- Дробные координаты камеры в пиксель-арте — тайлы «дрожат» и появляются щели между ними.

## Что важно помнить

- Камера — прямоугольник в мире; рисование мира — после `translate(-cam.x, -cam.y)`.
- HUD — после `restore()`, в экранных координатах.
- Плавное следование, ограничение границами, мёртвая зона, look-ahead.
- Culling: рисуем только то, что пересекается с камерой.
- Параллакс — слои со множителем смещения.

## Мини-шпаргалка

```ts
ctx.save(); ctx.scale(zoom, zoom); ctx.translate(-cam.x, -cam.y);
drawWorld(); ctx.restore(); drawHud();
cam.x += (target - cam.x) * (1 - Math.exp(-k * dt));
world = { x: sx / zoom + cam.x, y: sy / zoom + cam.y };
```
