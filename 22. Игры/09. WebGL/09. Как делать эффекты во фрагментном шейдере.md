# Как делать эффекты во фрагментном шейдере

> [!NOTE]
> Многие визуальные эффекты — фон с волнами, свечение, туман, переходы между сценами, «вода» — рисуются **одним прямоугольником на весь экран** и фрагментным шейдером, который для каждого пикселя вычисляет цвет как функцию от координаты и времени. Координату пикселя берут из `gl_FragCoord.xy` и нормируют: `uv = gl_FragCoord.xy / uResolution` (0..1). Дальше работают формы через функции расстояния (`length(uv - center)` — круг), плавные края через `smoothstep`, повторения через `fract`, анимация через `sin(uTime)`, случайность через хеш-функции и шум. Полноэкранный треугольник рисуется **без буферов** — вершины вычисляются из `gl_VertexID`. Этот же подход используют Shadertoy и фильтры PixiJS.

## Вопрос

Как в WebGL нарисовать процедурный эффект на весь экран с помощью фрагментного шейдера?

## Полноэкранный треугольник без буферов

Один треугольник, который перекрывает весь экран, проще и чуть быстрее двух треугольников квада:

```glsl
#version 300 es
// вершины считаются из номера: (-1,-1), (3,-1), (-1,3)
void main() {
  vec2 p = vec2((gl_VertexID << 1) & 2, gl_VertexID & 2);
  gl_Position = vec4(p * 2.0 - 1.0, 0.0, 1.0);
}
```

```ts
const program = createProgram(gl, fullscreenVS, effectFS);
const vao = gl.createVertexArray();           // пустой VAO — атрибутов нет

const uTime = gl.getUniformLocation(program, 'uTime');
const uResolution = gl.getUniformLocation(program, 'uResolution');

function frame(t: number) {
  gl.viewport(0, 0, canvas.width, canvas.height);
  gl.useProgram(program);
  gl.uniform1f(uTime, t / 1000);
  gl.uniform2f(uResolution, canvas.width, canvas.height);
  gl.bindVertexArray(vao);
  gl.drawArrays(gl.TRIANGLES, 0, 3);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
```

## Каркас фрагментного шейдера

```glsl
#version 300 es
precision highp float;
uniform float uTime;
uniform vec2 uResolution;
out vec4 outColor;

void main() {
  vec2 uv = gl_FragCoord.xy / uResolution;                              // 0..1
  vec2 p = (gl_FragCoord.xy - 0.5 * uResolution) / uResolution.y;       // центр (0,0), без искажения пропорций

  vec3 color = vec3(uv, 0.5 + 0.5 * sin(uTime));                        // градиент, меняющийся во времени
  outColor = vec4(color, 1.0);
}
```

Деление на `uResolution.y` сохраняет пропорции: круг остаётся кругом на широком экране.

## Формы через расстояние

```glsl
// круг со сглаженным краем
float d = length(p);                                  // расстояние до центра
float circle = 1.0 - smoothstep(0.30, 0.305, d);

// кольцо
float ring = 1.0 - smoothstep(0.0, 0.01, abs(d - 0.3));

// свечение: яркость обратно пропорциональна расстоянию
float glow = 0.02 / d;

vec3 color = vec3(0.1, 0.6, 1.0) * (circle + glow);
```

Функции расстояния (SDF) для прямоугольника, линии, звезды и сотен других форм собраны у Inigo Quilez.

## Повторения и узоры

```glsl
// шахматная доска
vec2 cell = floor(uv * 8.0);
float checker = mod(cell.x + cell.y, 2.0);

// сетка из кругов
vec2 g = fract(uv * 10.0) - 0.5;                     // локальные координаты внутри клетки
float dots = 1.0 - smoothstep(0.2, 0.21, length(g));

// полосы, движущиеся во времени
float stripes = step(0.5, fract(uv.x * 20.0 + uTime));
```

// «вода»: смещаем координаты синусом

## Случайность и шум

GLSL не имеет `random()`, поэтому используют хеш-функцию от координаты:

```glsl
float hash(vec2 p) {
  p = fract(p * vec2(123.34, 456.21));
  p += dot(p, p + 45.32);
  return fract(p.x * p.y);
}

// value noise: плавная интерполяция случайных значений в углах клетки
float noise(vec2 p) {
  vec2 i = floor(p), f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);                  // smoothstep-кривая
  return mix(mix(hash(i), hash(i + vec2(1, 0)), u.x),
             mix(hash(i + vec2(0, 1)), hash(i + vec2(1, 1)), u.x), u.y);
}

// фрактальный шум (fbm) — облака, дым, огонь
float fbm(vec2 p) {
  float v = 0.0, a = 0.5;
  for (int i = 0; i < 5; i++) { v += a * noise(p); p *= 2.0; a *= 0.5; }
  return v;
}

void main() {
  vec2 uv = gl_FragCoord.xy / uResolution;
  float n = fbm(uv * 4.0 + vec2(uTime * 0.2, 0.0));
  vec3 fire = mix(vec3(0.1, 0.0, 0.0), vec3(1.0, 0.6, 0.1), n * (1.0 - uv.y));
  outColor = vec4(fire, 1.0);
}
```

## Переход между сценами

```glsl
uniform sampler2D uFrom;
uniform sampler2D uTo;
uniform float uProgress;   // 0..1 — анимируем из JS

void main() {
  vec2 uv = gl_FragCoord.xy / uResolution;
  float edge = smoothstep(uProgress - 0.05, uProgress + 0.05, noise(uv * 10.0)); // «растворение»
  outColor = mix(texture(uTo, uv), texture(uFrom, uv), edge);
}
```

Сцены предварительно рисуются в текстуры (следующий урок).

## Виньетка и цветокоррекция

```glsl
vec3 c = texture(uScene, uv).rgb;
c *= 1.0 - 0.6 * length(uv - 0.5);                   // затемнение к краям
c = pow(c, vec3(0.9));                               // гамма
float gray = dot(c, vec3(0.299, 0.587, 0.114));      // яркость
c = mix(vec3(gray), c, 1.2);                         // насыщенность
```

## Производительность

- Фрагментный шейдер выполняется для **каждого пикселя**: на 4K-экране это 8 млн вызовов за кадр. Снижайте `dpr` или рендерите эффект в уменьшенный буфер.
- Тяжёлые циклы (`fbm` с 8 октавами, raymarching) — главный тормоз на мобильных.
- Чтение текстуры в цикле дороже арифметики.

## Частые ошибки

- Нормировать `uv` без учёта пропорций — круги превращаются в эллипсы.
- Забыть, что `gl_FragCoord.y` растёт снизу вверх.
- Передавать большое время (`Date.now()`) — потеря точности float, «ступенчатая» анимация.
- Использовать `if` для резких границ и получать «лесенку» — `smoothstep` даёт сглаживание.

## Что важно помнить

- Эффект на весь экран = полноэкранный треугольник + фрагментный шейдер.
- `uv = gl_FragCoord.xy / uResolution`, для форм — координаты с поправкой на пропорции.
- Формы — через расстояния, края — `smoothstep`, повторения — `fract`, время — `sin(uTime)`.
- Шум и хеш — основа огня, облаков, воды и переходов.
