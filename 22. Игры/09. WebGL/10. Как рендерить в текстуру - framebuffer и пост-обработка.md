# Как рендерить в текстуру — framebuffer и пост-обработка

> [!NOTE]
> По умолчанию WebGL рисует в canvas. **Framebuffer** (FBO) позволяет рисовать в **текстуру**: создаём текстуру нужного размера, прикрепляем её к framebuffer (`framebufferTexture2D`) и делаем `bindFramebuffer(FRAMEBUFFER, fbo)` — все следующие draw calls пишут в неё. Затем `bindFramebuffer(FRAMEBUFFER, null)` возвращает вывод на экран, а получившуюся текстуру можно использовать как обычную. Так устроены **пост-эффекты** (размытие, bloom, CRT, цветокоррекция — сцена рисуется в текстуру, затем на экран через шейдер эффекта), **фильтры PixiJS**, `RenderTexture`, мини-карты, отражения, переходы между сценами и тени. Для многопроходных эффектов используют два FBO и меняют их местами (**ping-pong**). При ресайзе текстуры FBO нужно пересоздавать.

## Вопрос

Что такое framebuffer в WebGL и как с его помощью сделать пост-обработку кадра?

## Создание framebuffer

```ts
function createRenderTarget(gl: WebGL2RenderingContext, width: number, height: number) {
  const texture = gl.createTexture()!;
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA8, width, height, 0, gl.RGBA, gl.UNSIGNED_BYTE, null); // пустая
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);

  const fbo = gl.createFramebuffer()!;
  gl.bindFramebuffer(gl.FRAMEBUFFER, fbo);
  gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, texture, 0);

  const status = gl.checkFramebufferStatus(gl.FRAMEBUFFER);
  if (status !== gl.FRAMEBUFFER_COMPLETE) throw new Error(`Framebuffer incomplete: ${status}`);

  gl.bindFramebuffer(gl.FRAMEBUFFER, null);
  return { fbo, texture, width, height };
}
```

Для 3D-сцены к framebuffer дополнительно прикрепляют буфер глубины — `createRenderbuffer` + `renderbufferStorage(RENDERBUFFER, DEPTH_COMPONENT24, w, h)` + `framebufferRenderbuffer(…, DEPTH_ATTACHMENT, …)`.

## Пост-обработка: сцена → текстура → экран

```ts
const scene = createRenderTarget(gl, canvas.width, canvas.height);
const postProgram = createProgram(gl, fullscreenVS, postFS);
const emptyVao = gl.createVertexArray();

function frame(t: number) {
  // 1. рисуем игру в текстуру
  gl.bindFramebuffer(gl.FRAMEBUFFER, scene.fbo);
  gl.viewport(0, 0, scene.width, scene.height);
  gl.clearColor(0, 0, 0, 1);
  gl.clear(gl.COLOR_BUFFER_BIT);
  drawGame();                                     // спрайты, частицы — как обычно

  // 2. рисуем текстуру на экран через шейдер эффекта
  gl.bindFramebuffer(gl.FRAMEBUFFER, null);
  gl.viewport(0, 0, canvas.width, canvas.height);
  gl.useProgram(postProgram);
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, scene.texture);
  gl.uniform1i(uScene, 0);
  gl.uniform1f(uTime, t / 1000);
  gl.uniform2f(uResolution, canvas.width, canvas.height);
  gl.bindVertexArray(emptyVao);
  gl.drawArrays(gl.TRIANGLES, 0, 3);              // полноэкранный треугольник

  requestAnimationFrame(frame);
}
```

## Шейдер эффекта: CRT

```glsl
#version 300 es
precision mediump float;
uniform sampler2D uScene;
uniform vec2 uResolution;
uniform float uTime;
out vec4 outColor;

void main() {
  vec2 uv = gl_FragCoord.xy / uResolution;

  // изгиб экрана
  vec2 c = uv * 2.0 - 1.0;
  c *= 1.0 + dot(c, c) * 0.05;
  uv = c * 0.5 + 0.5;
  if (any(lessThan(uv, vec2(0.0))) || any(greaterThan(uv, vec2(1.0)))) { outColor = vec4(0, 0, 0, 1); return; }

  // хроматическая аберрация: каналы со смещением
  float r = texture(uScene, uv + vec2(0.002, 0.0)).r;
  float g = texture(uScene, uv).g;
  float b = texture(uScene, uv - vec2(0.002, 0.0)).b;
  vec3 col = vec3(r, g, b);

  col *= 0.85 + 0.15 * sin(gl_FragCoord.y * 3.14159);  // строки развёртки
  col *= 1.0 - 0.4 * dot(c, c);                         // виньетка
  outColor = vec4(col, 1.0);
}
```

## Ping-pong: размытие в два прохода

Гауссово размытие делают двумя проходами (горизонтальным и вертикальным) — это в разы дешевле одного двумерного:

```ts
const a = createRenderTarget(gl, w / 2, h / 2);   // размытие в половинном разрешении — дешевле
const b = createRenderTarget(gl, w / 2, h / 2);

function blur(source: WebGLTexture, passes = 2) {
  let input = source;
  for (let i = 0; i < passes; i++) {
    renderPass(a, blurProgram, input, [1, 0]);    // горизонтально: source → a
    renderPass(b, blurProgram, a.texture, [0, 1]); // вертикально:   a → b
    input = b.texture;
  }
  return b.texture;
}
```

```glsl
uniform sampler2D uInput;
uniform vec2 uDirection;     // (1,0) или (0,1)
uniform vec2 uTexel;         // 1.0 / размер текстуры
void main() {
  vec2 uv = gl_FragCoord.xy * uTexel;
  vec4 sum = texture(uInput, uv) * 0.227;
  sum += texture(uInput, uv + uDirection * uTexel * 1.385) * 0.316;
  sum += texture(uInput, uv - uDirection * uTexel * 1.385) * 0.316;
  sum += texture(uInput, uv + uDirection * uTexel * 3.231) * 0.070;
  sum += texture(uInput, uv - uDirection * uTexel * 3.231) * 0.070;
  outColor = sum;
}
```

**Bloom** = выделить яркие пиксели (`max(col - threshold, 0.0)`) → размыть → сложить с исходной сценой.

> [!WARNING]
> Нельзя читать из текстуры и одновременно писать в неё (текстура прикреплена к текущему FBO и привязана к слоту) — это feedback loop, результат не определён. Поэтому нужны два буфера.

## Другие применения

| Задача | Как |
| --- | --- |
| Мини-карта | рисуем мир в маленький FBO другой камерой, текстуру показываем в углу |
| Кеш статичного слоя | рисуем фон в FBO один раз, каждый кадр — одной текстурой (`cacheAsTexture` в PixiJS) |
| Пиксель-арт в низком разрешении | вся игра в FBO 320×180, затем растягиваем на экран с `NEAREST` |
| Скриншот | рисуем в FBO и читаем `gl.readPixels` (медленно, не в каждом кадре) |
| Тени, отражения | рендер сцены с другой камеры в текстуру |

## Частые ошибки

- Забыть `gl.viewport` при переключении между FBO и экраном разного размера.
- Не пересоздавать текстуры FBO при ресайзе — эффект растягивается.
- Читать и писать одну и ту же текстуру в одном проходе.
- Делать полноэкранные пост-эффекты в полном разрешении на мобильных — для размытия хватает половины или четверти.
- Вызывать `readPixels` каждый кадр — синхронизация CPU и GPU убивает FPS.

## Что важно помнить

- Framebuffer + текстура = рисование в текстуру.
- `bindFramebuffer(fbo)` — в текстуру, `bindFramebuffer(null)` — на экран; каждый раз `viewport`.
- Пост-эффект: сцена → FBO → полноэкранный проход с шейдером.
- Многопроходные эффекты — ping-pong между двумя FBO.

## Мини-шпаргалка

```ts
gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, tex, 0);
gl.bindFramebuffer(gl.FRAMEBUFFER, fbo); gl.viewport(0, 0, w, h); drawScene();
gl.bindFramebuffer(gl.FRAMEBUFFER, null); gl.viewport(0, 0, cw, ch); drawPost(tex);
```
