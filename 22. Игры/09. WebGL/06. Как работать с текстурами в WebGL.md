# Как работать с текстурами в WebGL

> [!NOTE]
> Текстура — изображение на GPU, из которого шейдер читает цвет функцией `texture(uSampler, uv)`. **UV-координаты** — нормированные от 0 до 1 по ширине и высоте текстуры, их передают атрибутом вместе с вершинами. Загрузка: `createTexture` → `bindTexture(TEXTURE_2D)` → `texImage2D(…, image)` → параметры фильтрации и повтора через `texParameteri`. Для пиксель-арта фильтр `NEAREST`, для обычных картинок `LINEAR` (+ mipmaps при уменьшении). Шейдер получает текстуру не напрямую, а через **слот** (texture unit): `activeTexture(TEXTURE0 + n)` + `bindTexture`, а в uniform-сэмплер записывается номер слота `uniform1i(loc, n)`. Не забывайте: изображение должно быть загружено, а картинка с другого домена требует CORS.

## Вопрос

Как загрузить картинку в WebGL, нарисовать текстурированный прямоугольник и как настраивать фильтрацию, повтор и слоты текстур?

## Загрузка текстуры

```ts
async function loadTexture(gl: WebGL2RenderingContext, url: string, pixelArt = false) {
  const img = new Image();
  img.crossOrigin = 'anonymous';       // для картинок с CDN (нужны CORS-заголовки)
  img.src = url;
  await img.decode();

  const tex = gl.createTexture()!;
  gl.bindTexture(gl.TEXTURE_2D, tex);

  // Первая строка картинки (её верх) попадает в v = 0. Без переворота
  // UV (0, 0) — левый верхний угол изображения, как привычно в 2D.
  // true перевернёт картинку: (0, 0) станет левым нижним углом (так принято в 3D).
  gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, false);
  gl.pixelStorei(gl.UNPACK_PREMULTIPLY_ALPHA_WEBGL, true);

  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);

  const filter = pixelArt ? gl.NEAREST : gl.LINEAR;
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, filter);                // при увеличении
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER,
    pixelArt ? gl.NEAREST : gl.LINEAR_MIPMAP_LINEAR);                            // при уменьшении
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);         // по горизонтали
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);         // по вертикали

  if (!pixelArt) gl.generateMipmap(gl.TEXTURE_2D);
  return { tex, width: img.width, height: img.height };
}
```

В качестве источника `texImage2D` принимает `HTMLImageElement`, `ImageBitmap`, `HTMLCanvasElement`, `OffscreenCanvas`, `HTMLVideoElement`, `ImageData` или типизированный массив пикселей.

## Текстурированный прямоугольник

```ts
const vs = `#version 300 es
layout(location = 0) in vec2 aPosition;
layout(location = 1) in vec2 aUV;
out vec2 vUV;
void main() {
  vUV = aUV;
  gl_Position = vec4(aPosition, 0.0, 1.0);
}`;

const fs = `#version 300 es
precision mediump float;
in vec2 vUV;
uniform sampler2D uTexture;
uniform vec4 uTint;
out vec4 outColor;
void main() {
  outColor = texture(uTexture, vUV) * uTint;   // tint, как в PixiJS
}`;

// x, y, u, v — UV (0,0) в левом верхнем углу картинки, т.к. FLIP_Y выключен
const quad = new Float32Array([
  -0.5,  0.5,  0, 0,
   0.5,  0.5,  1, 0,
   0.5, -0.5,  1, 1,
  -0.5, -0.5,  0, 1,
]);
// ...VAO и индексы [0,1,2, 0,2,3] — как в уроке про буферы

const program = createProgram(gl, vs, fs);
const { tex } = await loadTexture(gl, '/sprites/hero.png');
const uTexture = gl.getUniformLocation(program, 'uTexture');
const uTint = gl.getUniformLocation(program, 'uTint');

gl.useProgram(program);
gl.activeTexture(gl.TEXTURE0);          // слот 0
gl.bindTexture(gl.TEXTURE_2D, tex);     // текстура в слоте 0
gl.uniform1i(uTexture, 0);              // сэмплер читает слот 0
gl.uniform4f(uTint, 1, 1, 1, 1);

gl.enable(gl.BLEND);                    // прозрачность PNG
gl.blendFunc(gl.ONE, gl.ONE_MINUS_SRC_ALPHA); // для премультиплицированной альфы
gl.bindVertexArray(vao);
gl.drawElements(gl.TRIANGLES, 6, gl.UNSIGNED_SHORT, 0);
```

## Фильтрация

| Параметр | Значение | Результат |
| --- | --- | --- |
| `MAG_FILTER` | `NEAREST` | чёткие пиксели при увеличении — пиксель-арт |
| `MAG_FILTER` | `LINEAR` | сглаживание при увеличении |
| `MIN_FILTER` | `LINEAR_MIPMAP_LINEAR` | качественное уменьшение без «ряби» (нужен `generateMipmap`) |
| `MIN_FILTER` | `LINEAR` / `NEAREST` | без mipmaps — мерцание на сильно уменьшенных текстурах |

По умолчанию `MIN_FILTER = NEAREST_MIPMAP_LINEAR`: если не сгенерировать mipmaps и не поменять фильтр, текстура будет **чёрной** («incomplete texture»).

## Повтор (wrap)

| `WRAP_S` / `WRAP_T` | Поведение за пределами 0..1 |
| --- | --- |
| `CLAMP_TO_EDGE` | растягивает крайний пиксель — для спрайтов |
| `REPEAT` | плитка — для фонов и тайлов (`uv * 4.0`) |
| `MIRRORED_REPEAT` | плитка с отражением |

## Спрайт из атласа

UV — это просто прямоугольник внутри текстуры. Кадр 32×32 в позиции (64, 32) атласа 256×256:

```ts
const u0 = 64 / 256, v0 = 32 / 256;
const u1 = (64 + 32) / 256, v1 = (32 + 32) / 256;
// подставляем в вершины квада вместо 0..1
```

Либо передаём прямоугольник кадра uniform-ом и считаем в шейдере:

```glsl
uniform vec4 uFrame;          // u0, v0, ширина, высота в UV
vUV = uFrame.xy + aUV * uFrame.zw;
```

Чтобы соседние кадры атласа не «просачивались» по краям при `LINEAR`, кадры в атласе разделяют отступами 1–2 пикселя (padding/extrude).

## Несколько текстур

```glsl
uniform sampler2D uDiffuse;
uniform sampler2D uMask;
// ...
float m = texture(uMask, vUV).r;
outColor = texture(uDiffuse, vUV) * m;
```

```ts
gl.activeTexture(gl.TEXTURE0); gl.bindTexture(gl.TEXTURE_2D, diffuseTex);
gl.activeTexture(gl.TEXTURE1); gl.bindTexture(gl.TEXTURE_2D, maskTex);
gl.uniform1i(uDiffuse, 0);
gl.uniform1i(uMask, 1);
```

Количество слотов ограничено: `gl.getParameter(gl.MAX_TEXTURE_IMAGE_UNITS)` — обычно 16. Батчеры (PixiJS) используют несколько слотов, чтобы рисовать спрайты с разных текстур одним вызовом.

## Обновление текстуры

```ts
// видео или canvas, которые меняются каждый кадр
gl.bindTexture(gl.TEXTURE_2D, videoTex);
gl.texSubImage2D(gl.TEXTURE_2D, 0, 0, 0, gl.RGBA, gl.UNSIGNED_BYTE, videoElement);
```

## Частые ошибки

- Текстура чёрная: нет mipmaps при фильтре по умолчанию, или картинка ещё не загружена.
- Картинка перевёрнута: перепутаны направление UV и `UNPACK_FLIP_Y_WEBGL`.
- Ошибка безопасности при `texImage2D`: картинка с другого домена без CORS.
- `uniform1i(loc, gl.TEXTURE0)` вместо номера слота `0`.
- Тёмные ореолы по краям спрайтов: смешивание не учитывает премультиплицированную альфу.

## Что важно помнить

- UV 0..1, читаем `texture(sampler, uv)`.
- Загрузка: `createTexture` → `bindTexture` → `texImage2D` → `texParameteri`.
- `NEAREST` — пиксель-арт, `LINEAR` + mipmaps — остальное.
- Слоты: `activeTexture(TEXTURE0 + n)` + `uniform1i(sampler, n)`.
- Атлас — это UV-прямоугольники внутри одной текстуры.

## Мини-шпаргалка

```ts
const t = gl.createTexture(); gl.bindTexture(gl.TEXTURE_2D, t);
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
gl.activeTexture(gl.TEXTURE0); gl.uniform1i(uTex, 0);
```
