# Как передавать параметры в шейдер — uniforms

> [!NOTE]
> **Uniform** — переменная шейдера, одинаковая для всех вершин и пикселей одного вызова отрисовки: время, разрешение экрана, цвет, матрица камеры, номер текстурного слота. Её адрес получают один раз через `gl.getUniformLocation(program, 'uTime')`, а значение задают функциями `gl.uniform*` **после** `gl.useProgram` — uniform принадлежит конкретной программе и сохраняет значение между кадрами. Суффикс функции описывает тип: `uniform1f` — один float, `uniform2f` — `vec2`, `uniform4fv` — `vec4` из массива, `uniformMatrix3fv` — матрица 3×3, `uniform1i` — int (в том числе слот текстуры). Неиспользуемый uniform компилятор удаляет, и `getUniformLocation` возвращает `null` — это не ошибка. Для больших наборов общих данных (камера, свет) в WebGL 2 есть **Uniform Buffer Objects**.

## Вопрос

Что такое uniform в WebGL, как его объявить и передать значение из JavaScript?

## Анимация через uniform

```ts
const vs = `#version 300 es
in vec2 aPosition;
uniform vec2 uOffset;        // смещение всего объекта
uniform float uScale;
void main() {
  gl_Position = vec4(aPosition * uScale + uOffset, 0.0, 1.0);
}`;

const fs = `#version 300 es
precision mediump float;
uniform vec3 uColor;
out vec4 outColor;
void main() {
  outColor = vec4(uColor, 1.0);
}`;

const program = createProgram(gl, vs, fs);

// адреса — один раз после линковки
const uOffset = gl.getUniformLocation(program, 'uOffset');
const uScale = gl.getUniformLocation(program, 'uScale');
const uColor = gl.getUniformLocation(program, 'uColor');

function frame(t: number) {
  const time = t / 1000;
  gl.clear(gl.COLOR_BUFFER_BIT);
  gl.useProgram(program);                                       // сначала программа

  gl.uniform2f(uOffset, Math.cos(time) * 0.5, Math.sin(time) * 0.5);
  gl.uniform1f(uScale, 0.5 + 0.2 * Math.sin(time * 3));
  gl.uniform3f(uColor, 0.2, 0.7, 1.0);

  gl.bindVertexArray(vao);
  gl.drawArrays(gl.TRIANGLES, 0, 3);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
```

Вершины в буфере не меняются — двигает их шейдер. Так же один и тот же квад можно нарисовать много раз в разных местах, меняя uniform между вызовами `drawArrays`.

## Функции uniform*

| GLSL-тип | JavaScript |
| --- | --- |
| `float` | `gl.uniform1f(loc, v)` |
| `vec2` / `vec3` / `vec4` | `gl.uniform2f(loc, x, y)` … `gl.uniform4f(loc, x, y, z, w)` |
| `vec4` из массива | `gl.uniform4fv(loc, [r, g, b, a])` или `Float32Array` |
| `int`, `bool`, `sampler2D` | `gl.uniform1i(loc, v)` |
| `ivec2`… | `gl.uniform2i(loc, x, y)` |
| `uint` (WebGL 2) | `gl.uniform1ui(loc, v)` |
| `mat2` / `mat3` / `mat4` | `gl.uniformMatrix3fv(loc, false, matrix)` — второй аргумент `transpose` всегда `false` |
| массив `vec2 uPoints[8]` | `gl.uniform2fv(loc, new Float32Array(16))` |

## Стандартный набор uniforms для эффектов

```glsl
uniform float uTime;        // секунды с начала
uniform vec2 uResolution;   // размер буфера в пикселях
uniform vec2 uMouse;        // позиция курсора в пикселях
```

```ts
gl.uniform1f(uTime, performance.now() / 1000);
gl.uniform2f(uResolution, canvas.width, canvas.height);
gl.uniform2f(uMouse, mouseX * dpr, canvas.height - mouseY * dpr); // y вверх, как в gl_FragCoord
```

Этот же набор используют Shadertoy и большинство примеров шейдерных эффектов.

## Удобный помощник

```ts
function getUniforms(gl: WebGL2RenderingContext, program: WebGLProgram) {
  const count = gl.getProgramParameter(program, gl.ACTIVE_UNIFORMS) as number;
  const map: Record<string, WebGLUniformLocation> = {};
  for (let i = 0; i < count; i++) {
    const info = gl.getActiveUniform(program, i)!;
    const name = info.name.replace(/\[0\]$/, '');   // массивы называются uArr[0]
    map[name] = gl.getUniformLocation(program, info.name)!;
  }
  return map;
}

const u = getUniforms(gl, program);
gl.uniform1f(u.uTime, time);
```

## Uniform Buffer Objects (WebGL 2)

Когда одни и те же данные (матрица камеры, параметры света) нужны многим программам, их кладут в общий буфер:

```glsl
layout(std140) uniform Camera {
  mat4 uViewProjection;
  vec4 uCameraPosition;
};
```

```ts
const blockIndex = gl.getUniformBlockIndex(program, 'Camera');
gl.uniformBlockBinding(program, blockIndex, 0);           // блок → точка привязки 0

const ubo = gl.createBuffer();
gl.bindBuffer(gl.UNIFORM_BUFFER, ubo);
gl.bufferData(gl.UNIFORM_BUFFER, 80, gl.DYNAMIC_DRAW);     // mat4 (64) + vec4 (16)
gl.bindBufferBase(gl.UNIFORM_BUFFER, 0, ubo);

// раз в кадр — обновили буфер, видят все программы
gl.bufferSubData(gl.UNIFORM_BUFFER, 0, cameraData);       // Float32Array(20)
```

Раскладка `std140` выравнивает данные по 16 байт: `vec3` занимает место как `vec4` — частая причина «сдвинутых» значений.

## Uniform или атрибут

| Данные | Чем передать |
| --- | --- |
| Одинаковы для всего объекта или кадра | uniform |
| Разные у каждой вершины | атрибут |
| Разные у каждого экземпляра при инстансинге | атрибут с `vertexAttribDivisor` |
| Большие таблицы данных | текстура (читается в шейдере через `texelFetch`) |

Рисовать 1000 спрайтов, меняя uniform и вызывая `drawArrays` 1000 раз, — это 1000 draw calls. Для этого есть батчинг и инстансинг (отдельный урок).

## Частые ошибки

- Вызывать `gl.uniform*` до `gl.useProgram` — значение уходит в другую программу или выдаёт ошибку `INVALID_OPERATION`.
- Получать `getUniformLocation` каждый кадр — дорого, кешируйте.
- Удивляться `null` от `getUniformLocation`: uniform объявлен, но не используется, и компилятор его выкинул.
- Передавать в `uniform1f` значение для `int` или в `uniform1i` — для `float`: типы должны совпадать.
- Передавать `Date.now()` как время — огромное число теряет точность во float; используйте секунды от старта.

## Что важно помнить

- Uniform одинаков для всех вершин и пикселей одного draw call.
- Адрес — `getUniformLocation` один раз; значение — `uniform*` после `useProgram`.
- Суффикс функции = тип: `1f`, `2f`, `4fv`, `1i`, `Matrix4fv`.
- Общие данные для многих программ — UBO.

## Мини-шпаргалка

```ts
const loc = gl.getUniformLocation(program, 'uTime');
gl.useProgram(program);
gl.uniform1f(loc, time);
gl.uniform2f(uRes, canvas.width, canvas.height);
gl.uniformMatrix3fv(uMatrix, false, m);
```
