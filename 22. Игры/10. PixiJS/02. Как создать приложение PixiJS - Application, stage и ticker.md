# Как создать приложение PixiJS — Application, stage и ticker

> [!NOTE]
> Точка входа — `Application`. В v8 он создаётся в два шага: `const app = new Application()` и асинхронный `await app.init({...})`, потому что инициализация рендерера (особенно WebGPU) асинхронна. После этого `app.canvas` — готовый `<canvas>`, который нужно вставить в DOM, `app.stage` — корневой контейнер сцены, `app.ticker` — игровой цикл на `requestAnimationFrame`, `app.screen` — размер видимой области. Колбэк тикера получает объект `Ticker`: `ticker.deltaTime` — множитель относительно 60 FPS (≈1 при 60 FPS, ≈0,5 при 120), `ticker.deltaMS` — миллисекунды кадра. При уходе со страницы приложение уничтожают через `app.destroy()`.

## Вопрос

Как создать и настроить приложение PixiJS, что такое `stage` и как работает `ticker`?

## Минимальное приложение

```ts
import { Application, Assets, Sprite } from 'pixi.js';

(async () => {
  const app = new Application();

  await app.init({
    background: '#1e293b',
    resizeTo: window,          // canvas всегда размером с окно
    antialias: true,
  });

  document.body.appendChild(app.canvas);

  const texture = await Assets.load('https://pixijs.com/assets/bunny.png');
  const bunny = new Sprite(texture);

  bunny.anchor.set(0.5);       // точка привязки — центр (по умолчанию левый верхний угол)
  bunny.position.set(app.screen.width / 2, app.screen.height / 2);
  app.stage.addChild(bunny);   // без addChild объект не рисуется

  app.ticker.add((ticker) => {
    bunny.rotation += 0.1 * ticker.deltaTime;
  });
})();
```

## Опции init

```ts
await app.init({
  width: 800,                      // фиксированный размер (если нет resizeTo)
  height: 450,
  resizeTo: containerElement,      // или подгонять под элемент
  background: 0x000000,
  backgroundAlpha: 1,
  antialias: true,                 // сглаживание краёв Graphics
  resolution: Math.min(devicePixelRatio, 2), // плотность пикселей
  autoDensity: true,               // CSS-размер = логический размер при resolution > 1
  preference: 'webgpu',            // 'webgl' | 'webgpu' — с фолбэком
  canvas: existingCanvas,          // использовать свой <canvas>
});
```

`resolution` + `autoDensity` решают проблему `devicePixelRatio` из урока про размеры canvas — вручную масштабировать не нужно.

## Фиксированное логическое разрешение

```ts
const GAME_W = 640, GAME_H = 360;
await app.init({ width: GAME_W, height: GAME_H, background: '#000' });

function fit() {
  const scale = Math.min(innerWidth / GAME_W, innerHeight / GAME_H);
  app.canvas.style.width = `${GAME_W * scale}px`;
  app.canvas.style.height = `${GAME_H * scale}px`;
}
addEventListener('resize', fit);
fit();
```

Альтернатива — `resizeTo: window` и масштабирование `world`-контейнера: `world.scale.set(scale)`.

## Ticker

```ts
app.ticker.add((ticker) => {
  ticker.deltaTime;   // ≈1 при 60 FPS — удобно для «пикселей за кадр при 60 FPS»
  ticker.deltaMS;     // миллисекунды с прошлого кадра
  ticker.elapsedMS;   // без учёта speed и ограничений
  ticker.FPS;         // текущий FPS
});

// скорость в пикселях в секунду — как в уроке про delta time
app.ticker.add((ticker) => {
  const dt = ticker.deltaMS / 1000;
  player.x += 300 * dt;
});

app.ticker.maxFPS = 60;    // ограничить частоту
app.ticker.speed = 0.5;    // slow-motion: deltaTime и deltaMS уменьшаются
app.ticker.stop();         // пауза всей отрисовки
app.ticker.start();
```

Порядок колбэков можно задать приоритетом: `app.ticker.add(fn, context, UPDATE_PRIORITY.HIGH)`. Фиксированный шаг физики ticker не даёт — делайте аккумулятор сами.

## Своя структура игры

```ts
import { Application, Container, type Ticker } from 'pixi.js';

export class Game {
  app = new Application();
  world = new Container();   // игровой мир — двигается камерой
  ui = new Container();      // интерфейс — поверх и неподвижен

  async init(parent: HTMLElement) {
    await this.app.init({ resizeTo: parent, background: '#0f172a' });
    parent.appendChild(this.app.canvas);

    this.app.stage.addChild(this.world, this.ui);
    this.app.ticker.add(this.update, this);
  }

  private update(ticker: Ticker) {
    const dt = ticker.deltaMS / 1000;
    // логика сущностей…
  }

  destroy() {
    this.app.ticker.remove(this.update, this);
    this.app.destroy(
      { removeView: true },                         // удалить canvas из DOM
      { children: true, texture: false },           // уничтожить объекты сцены
    );
  }
}
```

## Ресайз

```ts
app.renderer.on('resize', (width, height) => {
  ui.position.set(width - 160, 16);   // перестроить интерфейс
});

app.renderer.resize(1024, 576);       // изменить размер вручную
```

`app.screen` — прямоугольник видимой области (`app.screen.width`, `app.screen.height`), удобен для позиционирования и `hitArea`.

## Частые ошибки

- Забыть `await app.init()` — `app.canvas` и `renderer` ещё не существуют.
- Не добавить `app.canvas` в DOM — ничего не видно.
- Не вызвать `addChild` — объект создан, но не входит в сцену.
- Использовать `deltaTime` как секунды — это множитель (≈1), секунды — `deltaMS / 1000`.
- Не уничтожать приложение при размонтировании компонента — утечка WebGL-контекста (браузер позволяет их ограниченное число).

## Что важно помнить

- `new Application()` + `await app.init(options)`.
- `app.canvas` — в DOM, `app.stage` — корень сцены, `app.ticker` — цикл.
- `resizeTo`, `resolution`, `autoDensity` решают размеры и Retina.
- `ticker.deltaTime` — множитель, `ticker.deltaMS` — миллисекунды.
- `app.destroy()` при уходе со страницы.

## Мини-шпаргалка

```ts
const app = new Application();
await app.init({ resizeTo: window, background: '#000' });
document.body.appendChild(app.canvas);
app.stage.addChild(obj);
app.ticker.add((t) => obj.x += 5 * t.deltaTime);
app.destroy({ removeView: true }, { children: true });
```
