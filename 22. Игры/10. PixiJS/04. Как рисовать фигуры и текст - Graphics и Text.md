# Как рисовать фигуры и текст — Graphics и Text

> [!NOTE]
> **`Graphics`** рисует векторные фигуры: в v8 сначала описывается фигура (`rect`, `circle`, `roundRect`, `poly`, `moveTo/lineTo`…), затем вызывается `fill()` и/или `stroke()` — API похож на canvas 2D. Нарисованная фигура — объект сцены: её можно двигать, вращать, масштабировать без перерисовки. Если фигура меняется (полоска здоровья), её очищают `clear()` и рисуют заново. Одинаковые фигуры выгоднее рисовать через общий `GraphicsContext` или запечь в текстуру. Для текста есть три класса: **`Text`** (canvas-текст, любые шрифты, дорого обновлять), **`BitmapText`** (из атласа глифов, очень быстро — для часто меняющихся чисел: счёт, урон) и **`HTMLText`** (HTML/CSS-разметка внутри).

## Вопрос

Как нарисовать в PixiJS фигуры и вывести текст? Чем отличаются `Text`, `BitmapText` и `HTMLText`?

## Фигуры

```ts
import { Graphics } from 'pixi.js';

const g = new Graphics()
  .rect(0, 0, 120, 60)
  .fill(0x22c55e)                                // заливка
  .stroke({ width: 4, color: 0x0f172a });        // обводка

const ball = new Graphics()
  .circle(0, 0, 20)                              // центр в (0,0) — удобно вращать и двигать
  .fill({ color: 0xf97316, alpha: 0.9 });
ball.position.set(300, 200);

const ship = new Graphics()
  .poly([0, -15, 10, 10, -10, 10])               // треугольник по точкам
  .fill(0x38bdf8);

const panel = new Graphics()
  .roundRect(0, 0, 200, 80, 12)
  .fill({ color: 0x000000, alpha: 0.5 });

app.stage.addChild(g, ball, ship, panel);
```

Каждый `fill`/`stroke` относится к фигурам, описанным **до него**. Можно строить несколько фигур в одном `Graphics`:

```ts
const face = new Graphics()
  .circle(0, 0, 50).fill(0xfacc15)          // голова
  .circle(-18, -10, 6).fill(0x000000)       // глаза
  .circle(18, -10, 6).fill(0x000000)
  .arc(0, 10, 25, 0.2, Math.PI - 0.2)       // улыбка
  .stroke({ width: 4, color: 0x000000 });
```

## Линии и пути

```ts
const path = new Graphics()
  .moveTo(0, 0)
  .lineTo(100, 50)
  .quadraticCurveTo(150, 0, 200, 50)
  .bezierCurveTo(250, 100, 300, 0, 350, 50)
  .stroke({ width: 3, color: 0xffffff, cap: 'round', join: 'round' });

// SVG-путь
const icon = new Graphics().svg('<svg><path d="M10 10 L50 10 L30 40 Z" fill="red"/></svg>');
```

## Динамическая фигура: полоска здоровья

```ts
class HealthBar extends Graphics {
  constructor(private w = 40, private h = 5) { super(); }

  set(value: number, max: number) {
    const k = Math.max(0, value / max);
    this.clear()                                   // стереть прошлое состояние
      .rect(0, 0, this.w, this.h).fill(0x111827)
      .rect(0, 0, this.w * k, this.h).fill(k > 0.3 ? 0x22c55e : 0xef4444);
  }
}

const bar = new HealthBar();
bar.position.set(-20, -30);
enemySprite.addChild(bar);     // полоска двигается вместе с врагом
bar.set(enemy.hp, enemy.maxHp);
```

Вызывайте `clear()` и перерисовку только когда значение **изменилось**, а не каждый кадр.

## Общий GraphicsContext

```ts
import { GraphicsContext } from 'pixi.js';

// геометрия строится один раз
const bulletShape = new GraphicsContext().circle(0, 0, 4).fill(0xfde047);

// тысяча пуль используют одну геометрию
const bullets = Array.from({ length: 1000 }, () => new Graphics(bulletShape));
```

Ещё быстрее — превратить фигуру в текстуру и использовать `Sprite` (батчится с остальными спрайтами):

```ts
const tex = app.renderer.generateTexture(new Graphics().circle(0, 0, 4).fill(0xfde047));
const bullet = new Sprite(tex);
```

## Маски

```ts
const mask = new Graphics().circle(0, 0, 60).fill(0xffffff);
avatar.addChild(mask);
avatar.mask = mask;            // видна только часть внутри круга
```

## Text

```ts
import { Text, TextStyle } from 'pixi.js';

const style = new TextStyle({
  fontFamily: 'Inter, sans-serif',
  fontSize: 32,
  fontWeight: 'bold',
  fill: 0xffffff,
  stroke: { color: 0x000000, width: 4 },
  dropShadow: { color: 0x000000, blur: 4, distance: 2, alpha: 0.6 },
  wordWrap: true,
  wordWrapWidth: 400,
  align: 'center',
});

const title = new Text({ text: 'GAME OVER', style });
title.anchor.set(0.5);
title.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(title);

title.text = 'YOU WIN';   // изменение = перерисовка в canvas + загрузка новой текстуры на GPU
```

`Text` рендерится через скрытый canvas и загружается как текстура — для заголовков и редко меняющегося текста это нормально, но **менять каждый кадр дорого**.

## BitmapText

```ts
import { BitmapText, BitmapFont } from 'pixi.js';

// вариант 1: сгенерировать шрифт-атлас из системного/веб-шрифта
BitmapFont.install({
  name: 'ScoreFont',
  style: { fontFamily: 'monospace', fontSize: 28, fill: 0xffffff },
  chars: [['0', '9'], ' ', 'Score:'],
});

// вариант 2: загрузить готовый .fnt / .xml из Assets
// await Assets.load('/fonts/pixel.fnt');

const score = new BitmapText({ text: 'Score: 0', style: { fontFamily: 'ScoreFont', fontSize: 28 } });
app.stage.addChild(score);

app.ticker.add(() => {
  score.text = `Score: ${state.score}`;   // дёшево: просто другие глифы из атласа
});
```

| | `Text` | `BitmapText` | `HTMLText` |
| --- | --- | --- | --- |
| Как рисуется | canvas → текстура | глифы из атласа | HTML/CSS → SVG → текстура |
| Изменение | дорого | очень дёшево | дорого |
| Стили | богатые | ограничены атласом | любой CSS, `<b>`, `<i>`, разные цвета |
| Для чего | заголовки, диалоги | счёт, таймеры, урон | форматированный текст |

## Частые ошибки

- Использовать API v7: `beginFill()` / `drawRect()` / `endFill()` — в v8 это `rect().fill()`.
- Перерисовывать `Graphics` каждый кадр без необходимости.
- Менять `Text.text` каждый кадр (таймер, FPS) — используйте `BitmapText`.
- Рисовать фигуру со смещением (`rect(100, 100, …)`) и двигать `position` — точка вращения окажется не в центре. Рисуйте вокруг `(0, 0)`.
- Создавать тысячи `Graphics` с одинаковой геометрией без общего контекста или текстуры.

## Что важно помнить

- `Graphics`: описать фигуру → `fill`/`stroke`; `clear()` для перерисовки.
- Повторяющиеся фигуры — `GraphicsContext` или `generateTexture` + `Sprite`.
- `Text` — красиво, но дорого обновлять; `BitmapText` — для часто меняющихся чисел.
- Маски — через `obj.mask = graphics`.

## Мини-шпаргалка

```ts
new Graphics().rect(x, y, w, h).fill(0xff0000).stroke({ width: 2, color: 0xffffff });
new Graphics().circle(0, 0, r).fill({ color: 0x00ff00, alpha: 0.5 });
g.clear().rect(...).fill(...);
new Text({ text: 'Hi', style: { fill: 0xffffff, fontSize: 24 } });
new BitmapText({ text: '0', style: { fontFamily: 'ScoreFont' } });
```
