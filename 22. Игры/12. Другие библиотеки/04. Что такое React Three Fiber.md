# Что такое React Three Fiber

> [!NOTE]
> **React Three Fiber (R3F)** — React-рендерер для Three.js: сцена описывается JSX, где каждый тег соответствует классу Three.js (`<mesh>` → `new THREE.Mesh`, `<boxGeometry args={[1, 1, 1]} />` → `new THREE.BoxGeometry(1, 1, 1)`), а свойства — пропсами (`position={[0, 1, 0]}`). `<Canvas>` создаёт сцену, камеру, рендерер и цикл, хук **`useFrame`** вызывается каждый кадр — в нём через `ref` меняют объекты напрямую, **без `setState`**. Экосистема pmndrs даёт готовые компоненты: **drei** (камеры, `OrbitControls`, загрузка моделей `useGLTF`, текст, окружение), **@react-three/rapier** (физика), **@react-three/postprocessing** (эффекты), **zustand** (состояние игры). R3F не медленнее «чистого» Three.js: React управляет только структурой сцены, а кадры рисуются вне React.

## Вопрос

Что такое React Three Fiber и как делать на нём 3D-сцены и игры в React?

## Минимальная сцена

```bash
npm i three @react-three/fiber @react-three/drei
```

```tsx
'use client';
import { Canvas, useFrame } from '@react-three/fiber';
import { OrbitControls } from '@react-three/drei';
import { useRef, useState } from 'react';
import type { Mesh } from 'three';

function Box(props: { position: [number, number, number] }) {
  const ref = useRef<Mesh>(null);
  const [hovered, setHovered] = useState(false);
  const [active, setActive] = useState(false);

  // каждый кадр, вне цикла рендера React
  useFrame((_state, delta) => {
    ref.current!.rotation.x += delta;
    ref.current!.rotation.y += delta * 0.5;
  });

  return (
    <mesh
      {...props}
      ref={ref}
      scale={active ? 1.5 : 1}
      onClick={() => setActive((a) => !a)}          // raycasting встроен
      onPointerOver={() => setHovered(true)}
      onPointerOut={() => setHovered(false)}
      castShadow
    >
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial color={hovered ? 'hotpink' : '#38bdf8'} />
    </mesh>
  );
}

export function Scene() {
  return (
    <Canvas shadows camera={{ position: [3, 3, 5], fov: 60 }} style={{ height: 480 }}>
      <ambientLight intensity={0.4} />
      <directionalLight position={[5, 10, 7]} intensity={2} castShadow />
      <Box position={[-1.2, 0.5, 0]} />
      <Box position={[1.2, 0.5, 0]} />
      <mesh rotation-x={-Math.PI / 2} receiveShadow>   {/* rotation-x — «пронзающий» проп */}
        <planeGeometry args={[10, 10]} />
        <meshStandardMaterial color="#334155" />
      </mesh>
      <OrbitControls />
    </Canvas>
  );
}
```

Сравните с уроком про Three.js: рендерер, камера, цикл, ресайз и raycasting R3F настроил сам.

## Как JSX превращается в Three.js

| JSX | Three.js |
| --- | --- |
| `<mesh position={[0, 1, 0]}>` | `const m = new Mesh(); m.position.set(0, 1, 0)` |
| `<boxGeometry args={[1, 2, 3]} />` | `new BoxGeometry(1, 2, 3)` — `args` = аргументы конструктора |
| `<meshStandardMaterial color="red" />` | `new MeshStandardMaterial({ color: 'red' })` |
| `rotation-x={1}` | `m.rotation.x = 1` |
| `<primitive object={gltf.scene} />` | `scene.add(gltf.scene)` — готовый объект |
| удаление элемента из JSX | `remove` + `dispose()` автоматически |

## useFrame — игровой цикл

```tsx
import { Vector3 } from 'three';

const cameraTarget = new Vector3();         // создаём один раз, а не каждый кадр

function Player() {
  const ref = useRef<Mesh>(null);
  const keys = useKeyboard();               // свой хук: Set нажатых клавиш

  useFrame((state, delta) => {
    const p = ref.current!;
    if (keys.has('KeyW')) p.position.z -= 5 * delta;
    if (keys.has('KeyS')) p.position.z += 5 * delta;

    // камера плавно следует за игроком
    cameraTarget.set(p.position.x, p.position.y + 4, p.position.z + 8);
    state.camera.position.lerp(cameraTarget, 1 - Math.exp(-5 * delta));
    state.camera.lookAt(p.position);
  });

  return (
    <mesh ref={ref}>
      <capsuleGeometry args={[0.4, 1]} />
      <meshStandardMaterial color="orange" />
    </mesh>
  );
}
```

> [!WARNING]
> Никогда не вызывайте `setState` внутри `useFrame` для значений, которые меняются каждый кадр, — это 60+ ререндеров компонента в секунду. Меняйте объект через `ref`. Создавать объекты (`new Vector3()`) внутри `useFrame` тоже не стоит — заведите их один раз вне цикла.

## drei: готовые помощники

```tsx
import { useGLTF, Environment, Text, Html, Float, KeyboardControls, PerspectiveCamera } from '@react-three/drei';

function Robot() {
  const { scene } = useGLTF('/models/robot.glb');  // загрузка + кеш, работает с Suspense
  return <primitive object={scene} scale={0.5} />;
}

<Canvas>
  <Suspense fallback={null}>
    <Robot />
    <Environment preset="sunset" />                   {/* освещение по HDRI */}
  </Suspense>
  <Float speed={2}><Text fontSize={0.5}>Hello</Text></Float>   {/* парящий 3D-текст */}
  <Html position={[0, 2, 0]}><div className="label">HP 100</div></Html> {/* DOM поверх 3D */}
</Canvas>
```

## Физика: @react-three/rapier

```tsx
import { Physics, RigidBody, CuboidCollider } from '@react-three/rapier';

<Canvas>
  <Physics gravity={[0, -9.81, 0]}>
    <RigidBody colliders="cuboid" restitution={0.6}>
      <mesh position={[0, 5, 0]}>
        <boxGeometry />
        <meshStandardMaterial />
      </mesh>
    </RigidBody>

    <RigidBody type="fixed">
      <CuboidCollider args={[10, 0.1, 10]} />
    </RigidBody>
  </Physics>
</Canvas>
```

Через `ref` к `RigidBody` можно прикладывать импульсы (`applyImpulse`) и читать скорость — так делают управление персонажем.

## Состояние игры: zustand

```ts
import { create } from 'zustand';

export const useGame = create<{ score: number; addScore: (n: number) => void }>((set) => ({
  score: 0,
  addScore: (n) => set((s) => ({ score: s.score + n })),
}));

// в 3D-компоненте при событии: useGame.getState().addScore(10) — без подписки и ререндеров
// в HUD (обычный DOM поверх Canvas): const score = useGame((s) => s.score);
```

## Производительность

- Много одинаковых объектов — `<instancedMesh>` или `Instances` из drei.
- `frameloop="demand"` у `<Canvas>` для сцен без постоянной анимации — рендер только при изменениях (`invalidate()`).
- Переиспользуйте геометрии и материалы: объявите их один раз и передавайте через `geometry={...}`.
- `PerformanceMonitor` из drei понижает `dpr` на слабых устройствах.

## Частые ошибки

- `setState` в `useFrame` — сотни ререндеров.
- Вызывать хуки R3F (`useFrame`, `useThree`) вне `<Canvas>` — они работают только внутри.
- Ожидать DOM-элементы внутри `<Canvas>` — там только Three.js-объекты; DOM — через `<Html>` или поверх canvas.
- Забыть `<Suspense>` вокруг компонентов с `useGLTF`/`useTexture`.
- В Next.js рендерить `<Canvas>` на сервере — компонент должен быть клиентским (`'use client'`).

## Что важно помнить

- R3F — JSX-обёртка Three.js: теги = классы, `args` = аргументы конструктора.
- `<Canvas>` создаёт сцену, камеру, рендерер и цикл.
- `useFrame((state, delta) => …)` + `ref` — для анимации и логики каждого кадра.
- drei — готовые компоненты, rapier — физика, zustand — состояние.

## Мини-шпаргалка

```tsx
<Canvas camera={{ position: [0, 2, 5] }}>
  <ambientLight /><directionalLight position={[5, 5, 5]} />
  <mesh ref={ref}><boxGeometry /><meshStandardMaterial color="orange" /></mesh>
</Canvas>
useFrame((_, dt) => { ref.current.rotation.y += dt; });
```
