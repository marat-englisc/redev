# Какие ещё есть библиотеки для игр и как выбрать

> [!NOTE]
> Выбор зависит от трёх вопросов: **2D или 3D**, **нужен ли готовый движок** (сцены, физика, звук, загрузка) **или только рендерер**, и **где живёт игра** (отдельная страница или часть React/Vue-приложения). Для 2D: canvas 2D — учебные и простые игры, **PixiJS** — быстрый рендерер, **Phaser** — полноценный движок, **KAPLAY** (бывший Kaboom) — самый простой старт, **Excalibur** — движок на TypeScript, **LittleJS** — крошечный и быстрый, **Konva** — интерактивная 2D-графика и редакторы. Для 3D: **Three.js** и **React Three Fiber** — гибкость и экосистема, **Babylon.js** — полноценный 3D-движок с редактором и физикой, **PlayCanvas** — движок с облачным визуальным редактором. Если игра серьёзная и мультиплатформенная — **Godot**/**Unity**/**Defold** с экспортом в WebAssembly.

## Вопрос

Какие библиотеки и движки существуют для браузерных игр, чем они отличаются и как выбрать подходящий?

## 2D

| Библиотека | Что это | Когда выбирать |
| --- | --- | --- |
| Canvas 2D API | встроенный API браузера | обучение, простые игры, визуализации, нет зависимостей |
| **PixiJS** | 2D-рендерер WebGL/WebGPU | много спрайтов и эффектов, своя архитектура, встраивание в приложение |
| **Phaser** | полноценный 2D-движок | классические 2D-игры: платформеры, аркады, головоломки |
| **KAPLAY** | простая 2D-библиотека с компонентами | геймджемы, обучение, прототип за вечер |
| **Excalibur** | 2D-движок на TypeScript | строгий TS, ECS-подобная архитектура, встроенная физика |
| **LittleJS** | минималистичный быстрый движок | крошечный размер, retro и js13k-игры |
| **Konva** | интерактивный 2D canvas с объектами и событиями | редакторы, диаграммы, drag & drop, настольные игры |
| **melonJS** | лёгкий 2D-движок | тайловые игры с Tiled |

### KAPLAY — быстрый старт

```ts
import kaplay from 'kaplay';

const k = kaplay({ width: 640, height: 360, background: [15, 23, 42] });
k.setGravity(1600);
k.loadSprite('bean', 'https://play.kaplayjs.com/sprites/bean.png');

const player = k.add([k.sprite('bean'), k.pos(80, 40), k.area(), k.body()]);
k.add([k.rect(640, 40), k.pos(0, 320), k.area(), k.body({ isStatic: true }), k.color(100, 116, 139)]);

k.onKeyPress('space', () => { if (player.isGrounded()) player.jump(); });
```

Игровой объект собирается из компонентов (`sprite`, `pos`, `area`, `body`) — та же идея, что в уроке про ECS.

### Konva — объекты и события на canvas

```ts
import Konva from 'konva';

const stage = new Konva.Stage({ container: 'board', width: 600, height: 400 });
const layer = new Konva.Layer();
stage.add(layer);

const piece = new Konva.Circle({ x: 100, y: 100, radius: 30, fill: 'tomato', draggable: true });
piece.on('dragend', () => snapToGrid(piece));
layer.add(piece);
```

Konva делает hit testing и drag & drop за вас; есть `react-konva` и `vue-konva`. Для шахмат, карточных игр и редакторов уровней это удобнее, чем PixiJS.

## 3D

| Библиотека | Что это | Когда выбирать |
| --- | --- | --- |
| **Three.js** | 3D-библиотека (рендерер + сцена) | гибкость, огромная экосистема, 3D-сайты и игры |
| **React Three Fiber** | Three.js в JSX + pmndrs-экосистема | 3D в React-приложении |
| **Babylon.js** | полноценный 3D-движок (Microsoft) | 3D-игры «под ключ»: физика, GUI, инспектор, WebXR |
| **PlayCanvas** | движок с онлайн-редактором | командная разработка, визуальный редактор, есть open source engine |
| **TresJS** | аналог R3F для Vue | 3D в Vue/Nuxt |

```ts
// Babylon.js — для сравнения: камера с управлением и свет одной строкой
import { Engine, Scene, ArcRotateCamera, HemisphericLight, MeshBuilder, Vector3 } from '@babylonjs/core';

const engine = new Engine(canvas, true);
const scene = new Scene(engine);
const camera = new ArcRotateCamera('cam', Math.PI / 4, Math.PI / 3, 8, Vector3.Zero(), scene);
camera.attachControl(canvas, true);
new HemisphericLight('light', new Vector3(0, 1, 0), scene);
MeshBuilder.CreateBox('box', { size: 1 }, scene);
engine.runRenderLoop(() => scene.render());
```

## Полноценные движки с экспортом в веб

| Движок | Язык | Для веба |
| --- | --- | --- |
| **Godot** | GDScript, C# | экспорт в HTML5 (WebAssembly), бесплатный и open source |
| **Unity** | C# | WebGL/WebGPU-сборка, тяжёлая для веба |
| **Defold** | Lua | лёгкие HTML5-сборки, хорош для мобильных и веба |
| **Cocos Creator** | TypeScript | редактор + веб и мини-игры (WeChat и др.) |

Такие сборки весят мегабайты, долго загружаются и сложнее интегрируются со страницей, но дают редактор, анимации, UI и экспорт на все платформы.

## Как выбрать

```text
Нужна 3D?
├── да → React-приложение? → React Three Fiber
│        нужен движок «под ключ», GUI, редактор? → Babylon.js / PlayCanvas
│        иначе → Three.js
└── нет (2D)
    ├── учусь / простая игра / нет зависимостей → Canvas 2D
    ├── быстрый прототип, геймджем → KAPLAY
    ├── классическая игра с физикой, тайлами, сценами → Phaser
    ├── много спрайтов, эффекты, своя архитектура, встраивание → PixiJS
    └── редактор, доска, drag & drop → Konva
Игра для всех платформ, большая команда → Godot / Unity / Defold
```

## Частые ошибки

- Брать Unity для маленькой веб-игры — долгий старт и большой бандл.
- Писать свой движок для коммерческого проекта со сроками.
- Выбирать PixiJS и потом вручную писать сцены, тайлмапы и физику, которые есть в Phaser.
- Использовать 3D-движок для 2D-игры «на будущее».

## Что важно помнить

- 2D-рендерер (PixiJS) ≠ 2D-движок (Phaser, Excalibur, KAPLAY).
- 3D в вебе — Three.js/R3F или Babylon.js.
- Konva — для интерактивной 2D-графики и редакторов.
- Godot/Unity/Defold — когда нужен редактор и мультиплатформа, с ценой в размере сборки.

## Мини-шпаргалка

| Нужно | Бери |
| --- | --- |
