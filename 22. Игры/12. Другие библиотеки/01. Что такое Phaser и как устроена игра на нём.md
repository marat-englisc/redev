# Что такое Phaser и как устроена игра на нём

> [!NOTE]
> **Phaser** — самый популярный полноценный 2D-движок для браузерных игр. В отличие от PixiJS, в нём уже есть всё: **сцены** с жизненным циклом `preload → create → update`, загрузчик ресурсов, ввод (клавиатура, мышь, тач, геймпад), звук, камеры, твины, частицы, **тайлмапы из Tiled** и физика (**Arcade Physics** — быстрые AABB-тела, или **Matter.js** — реалистичная). Игра создаётся объектом `new Phaser.Game(config)`, в конфиге перечисляются размер, физика и сцены. Логика пишется в классах-наследниках `Phaser.Scene`. Phaser выбирают, когда нужно быстро сделать классическую 2D-игру — платформер, аркаду, головоломку — без сборки движка из отдельных библиотек.

## Вопрос

Что такое Phaser, чем он отличается от PixiJS и как устроена простая игра на нём?

## Установка

```bash
npm create @phaserjs/game@latest   # официальный шаблон: Vite, React, Vue, Next.js…
# или
npm i phaser
```

## Конфигурация игры

```ts
import Phaser from 'phaser';
import { GameScene } from './GameScene';
import { MenuScene } from './MenuScene';

new Phaser.Game({
  type: Phaser.AUTO,            // WebGL, если доступен, иначе Canvas
  width: 800,
  height: 450,
  parent: 'game',               // id элемента-контейнера
  backgroundColor: '#1e293b',
  pixelArt: true,               // nearest-фильтрация для пиксель-арта
  scale: { mode: Phaser.Scale.FIT, autoCenter: Phaser.Scale.CENTER_BOTH }, // вписать в окно
  physics: {
    default: 'arcade',
    arcade: { gravity: { x: 0, y: 900 }, debug: false },  // debug: true — рисует хитбоксы
  },
  scene: [MenuScene, GameScene], // первая запускается автоматически
});
```

## Жизненный цикл сцены

```ts
export class GameScene extends Phaser.Scene {
  private player!: Phaser.Types.Physics.Arcade.SpriteWithDynamicBody;
  private cursors!: Phaser.Types.Input.Keyboard.CursorKeys;
  private coins!: Phaser.Physics.Arcade.Group;
  private score = 0;
  private scoreText!: Phaser.GameObjects.Text;

  constructor() { super('game'); }

  // 1. загрузка ресурсов
  preload() {
    this.load.image('sky', 'assets/sky.png');
    this.load.image('ground', 'assets/platform.png');
    this.load.image('coin', 'assets/coin.png');
    this.load.spritesheet('hero', 'assets/hero.png', { frameWidth: 32, frameHeight: 48 });
    this.load.audio('pickup', 'assets/pickup.mp3');
  }

  // 2. создание объектов — один раз
  create() {
    this.add.image(400, 225, 'sky');

    const platforms = this.physics.add.staticGroup();     // неподвижные тела
    platforms.create(400, 440, 'ground').setScale(2).refreshBody();
    platforms.create(600, 300, 'ground');
    platforms.create(100, 220, 'ground');

    this.player = this.physics.add.sprite(100, 300, 'hero');
    this.player.setCollideWorldBounds(true);
    this.player.setBounce(0.1);

    this.anims.create({
      key: 'run',
      frames: this.anims.generateFrameNumbers('hero', { start: 0, end: 3 }),
      frameRate: 10,
      repeat: -1,
    });
    this.anims.create({ key: 'idle', frames: [{ key: 'hero', frame: 4 }], frameRate: 20 });

    this.coins = this.physics.add.group({
      key: 'coin',
      repeat: 10,
      setXY: { x: 20, y: 0, stepX: 70 },
    });

    // столкновения и пересечения
    this.physics.add.collider(this.player, platforms);
    this.physics.add.collider(this.coins, platforms);
    this.physics.add.overlap(this.player, this.coins, (_player, coin) => {
      (coin as Phaser.Physics.Arcade.Sprite).disableBody(true, true);
      this.sound.play('pickup');
      this.score += 10;
      this.scoreText.setText(`Score: ${this.score}`);
    });

    this.cursors = this.input.keyboard!.createCursorKeys();
    this.scoreText = this.add.text(16, 16, 'Score: 0', { fontSize: '24px', color: '#fff' })
      .setScrollFactor(0);                                  // HUD не двигается с камерой

    this.cameras.main.startFollow(this.player, true, 0.1, 0.1);
    this.cameras.main.setBounds(0, 0, 1600, 450);
    this.physics.world.setBounds(0, 0, 1600, 450);
  }

  // 3. каждый кадр
  update(_time: number, _delta: number) {
    const body = this.player.body;

    if (this.cursors.left.isDown) {
      this.player.setVelocityX(-200).setFlipX(true).anims.play('run', true);
    } else if (this.cursors.right.isDown) {
      this.player.setVelocityX(200).setFlipX(false).anims.play('run', true);
    } else {
      this.player.setVelocityX(0).anims.play('idle', true);
    }

    // прыжок только с земли; JustDown — «нажато в этом кадре»
    if (Phaser.Input.Keyboard.JustDown(this.cursors.up) && body.blocked.down) {
      this.player.setVelocityY(-480);
    }
  }
}
```

Сравните с уроками про canvas: гравитация, столкновения с платформами, `onGround`, анимации по состоянию, камера и HUD здесь — пара строк.

## Сцены

```ts
// переключение и наложение сцен
this.scene.start('game', { level: 2 });   // заменить текущую, данные в init(data)
this.scene.launch('pause');               // запустить поверх
this.scene.pause();                       // поставить текущую на паузу
this.scene.resume('game');
this.scene.stop('pause');

// общение сцен
this.events.emit('score-changed', this.score);
this.scene.get('ui').events.on('restart', () => this.scene.restart());
```

## Встроенные возможности

| Модуль | Пример |
| --- | --- |
| Твины | `this.tweens.add({ targets: coin, y: '-=20', yoyo: true, repeat: -1, ease: 'Sine.inOut' })` |
| Таймеры | `this.time.addEvent({ delay: 1000, loop: true, callback: spawnEnemy })` |
| Частицы | `this.add.particles(x, y, 'spark', { speed: 200, lifespan: 500, quantity: 20, emitting: false }).explode()` |
| Тайлмапы | `this.load.tilemapTiledJSON('map', 'level.json')`, `map.createLayer(...)`, `layer.setCollisionByProperty({ solid: true })` |
| Камеры | `shake`, `flash`, `fade`, `zoomTo`, несколько камер (мини-карта) |
| Ввод | `this.input.on('pointerdown')`, `this.input.gamepad`, `sprite.setInteractive()` |
| Группы и пулы | `this.physics.add.group({ maxSize: 50 })`, `group.get(x, y)` |

## Arcade или Matter

| | Arcade Physics | Matter.js |
| --- | --- | --- |
| Формы | AABB и круги, без вращения тел | многоугольники, вращение, шарниры |
| Скорость | очень высокая | ниже |

## Phaser в React/Vue/Next.js

Официальный шаблон создаёт игру в `useEffect`/`onMounted`, а связь между UI-фреймворком и сценами — через общий `EventBus` (Phaser.Events.EventEmitter). При размонтировании обязательно `game.destroy(true)`.

## Частые ошибки

- Создавать объекты в `update` — он вызывается каждый кадр; объекты создаются в `create`.
- Использовать ресурс до его загрузки в `preload`.
- Проверять прыжок через `isDown` — персонаж прыгает каждый кадр, пока клавиша зажата. Нужен `JustDown` и `body.blocked.down`.
- Двигать физическое тело через `x/y` вместо `setVelocity` — физика «не знает» о перемещении, столкновения ломаются.
- Забыть `setScrollFactor(0)` для HUD — он уезжает с камерой.

## Что важно помнить

- Phaser — полноценный движок: сцены, загрузчик, ввод, звук, физика, тайлмапы, камеры.
- `new Phaser.Game(config)`, сцены — классы с `preload`/`create`/`update`.
- Arcade Physics — быстро и просто, Matter — реалистично.
- `collider` — столкновение с отталкиванием, `overlap` — только событие пересечения.

## Мини-шпаргалка

```ts
new Phaser.Game({ type: Phaser.AUTO, width, height, physics: { default: 'arcade' }, scene: [Main] });
preload() { this.load.image('key', 'url'); }
create() { this.physics.add.sprite(x, y, 'key'); this.physics.add.collider(a, b); }
update() { sprite.setVelocityX(200); }
```
