# Renderer — render, extract и generateTexture

> [!NOTE]
> `app.renderer` — объект `WebGLRenderer` или `WebGPURenderer` с общим API. Главный метод **`render(options)`** рисует контейнер на экран или в текстуру: `render({ container, target, clear, clearColor, transform })`. **`generateTexture({ target, frame, resolution, antialias })`** превращает контейнер или Graphics в новую текстуру. Система **`extract`** забирает пиксели обратно на CPU: `extract.base64()`, `image()`, `canvas()`, `pixels()`, `texture()`, `download()` — для скриншотов, превью уровней и шаринга результатов. Рендерер хранит `screen`, `resolution`, `canvas`, `background`, `width`/`height`, сообщает о ресайзе событием `resize`, а `resetState()` восстанавливает состояние после стороннего WebGL-кода. Перед показом новых объектов их можно заранее загрузить на GPU через **`prepare`**, чтобы избежать фризов.

## Вопрос

Какие возможности даёт рендерер PixiJS: как рисовать в текстуру, делать скриншоты и управлять отрисовкой?

## Свойства

| Свойство | Описание |
| --- | --- |
| `name` | `'webgl'` или `'webgpu'` |
| `canvas` | элемент canvas |
| `screen` | `Rectangle` видимой области |
| `width`, `height` | размер в пикселях буфера |
| `resolution` | плотность пикселей (можно менять на лету) |
| `background` | `background.color`, `background.alpha`, `background.clearBeforeRender` |
| `roundPixels` | глобальное округление позиций |
| `lastObjectRendered` | последний отрисованный контейнер |
| `textureGenerator`, `extract`, `renderTarget`… | системы рендерера |

```ts
app.renderer.background.color = '#1e293b';   // поменять фон на лету
app.renderer.resolution = 1;                 // снизить нагрузку на слабом устройстве
app.renderer.resize(1280, 720);
app.renderer.on('resize', (w, h) => layoutUi(w, h));
```

## render

```ts
// на экран (так делает Application каждый кадр)
app.renderer.render(app.stage);
app.renderer.render({ container: app.stage });

// в текстуру
import { RenderTexture, Matrix } from 'pixi.js';
const rt = RenderTexture.create({ width: 256, height: 256 });

app.renderer.render({
  container: world,
  target: rt,
  clear: true,                         // false — дорисовать поверх
  clearColor: [0, 0, 0, 0],
  transform: new Matrix().scale(0.1, 0.1),   // мини-карта: мир в 10 раз меньше
});
```

## generateTexture

```ts
const tex = app.renderer.generateTexture({
  target: badge,                       // Container или Graphics
  resolution: 2,
  antialias: true,
  frame: new Rectangle(0, 0, 64, 64),  // только часть
  clearColor: [0, 0, 0, 0],
});
const sprite = new Sprite(tex);
```

Используйте для повторяющихся фигур, сложных групп, теней и «запекания» UI. Для части, которая меняется каждый кадр, — `RenderTexture` + `render`.

## extract: пиксели на CPU

```ts
// скриншот сцены
const dataUrl = await app.renderer.extract.base64({ target: app.stage, format: 'png' });

// <img> для превью
const img = await app.renderer.extract.image({ target: levelPreview, resolution: 0.5 });
document.body.appendChild(img);

// canvas — например, чтобы отправить на сервер как Blob
const canvas = app.renderer.extract.canvas({ target: card }) as HTMLCanvasElement;
canvas.toBlob((blob) => upload(blob!), 'image/webp', 0.9);

// пиксели — Uint8ClampedArray RGBA
const { pixels, width, height } = app.renderer.extract.pixels({ target: mask });

// скачать файлом
app.renderer.extract.download({ target: app.stage, filename: 'my-level.png' });
```

| Метод | Возвращает |
| --- | --- |
| `base64(options)` | `Promise<string>` — data URL |
| `image(options)` | `Promise<HTMLImageElement>` |
| `canvas(options)` | canvas |
| `pixels(options)` | `{ pixels, width, height }` |
| `texture(options)` | `Texture` |
| `download(options)` | скачивание файла |
| `log(options)` | вывести картинку в консоль — для отладки |

Общие опции: `target` (Container или Texture), `frame`, `resolution`, `clearColor`, `antialias`; для `base64`/`image` — `format` (`'png'`, `'jpg'`, `'webp'`) и `quality`.

> [!WARNING]
> Extract читает данные с GPU — это синхронизация и медленно. Не вызывайте его каждый кадр.

## prepare: загрузить на GPU заранее

Первое появление большой текстуры или сложного текста может вызвать фриз — данные загружаются на GPU в момент отрисовки. `prepare` делает это заранее, например во время экрана загрузки:

```ts
// prepare входит в основной пакет pixi.js; при ручной настройке расширений — import 'pixi.js/prepare'

await app.renderer.prepare.upload(bossContainer); // текстуры, графика и текст будут на GPU
showBoss();
```

## Сброс состояния

```ts
// свой WebGL-код на том же контексте
const gl = (app.renderer as WebGLRenderer).gl;
drawCustomStuff(gl);
app.renderer.resetState();                    // вернуть PixiJS его состояние
```

## Без Application

```ts
import { autoDetectRenderer, Container } from 'pixi.js';

const renderer = await autoDetectRenderer({ preference: 'webgpu', width: 800, height: 600, background: '#000' });
document.body.appendChild(renderer.canvas);

const stage = new Container();
renderer.render(stage);
```

Также можно явно создать `new WebGLRenderer()` + `await renderer.init(options)`.

## Частые ошибки

- Вызывать `extract` каждый кадр.
- Делать скриншот с `preserveDrawingBuffer: false` через `canvas.toDataURL()` — получится пустая картинка; используйте `extract`.
- Генерировать новую текстуру `generateTexture` в каждом кадре и не уничтожать старые — утечка памяти GPU.
- Забыть `resetState()` после своего WebGL-кода — PixiJS рисует с чужими настройками.
- Использовать `app.renderer.gl` при WebGPU-рендерере — его там нет; проверяйте `renderer.name`.

## Что важно помнить

- `render({ container, target, clear, transform })` — на экран или в `RenderTexture`.
- `generateTexture({ target, resolution })` — запечь объект в текстуру.
- `extract.base64/image/canvas/pixels/download` — скриншоты и превью, медленно.
- `prepare.upload` — загрузить ресурсы на GPU до показа.
- `resetState()` после стороннего WebGL-кода.

## Мини-шпаргалка

```ts
app.renderer.render({ container: world, target: rt, clear: false });
app.renderer.generateTexture({ target: g, resolution: 2 });
await app.renderer.extract.base64({ target: app.stage, format: 'png' });
app.renderer.extract.download({ target: app.stage, filename: 'shot.png' });
await app.renderer.prepare.upload(container);
```
