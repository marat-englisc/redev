# Texture, TextureSource и RenderTexture

> [!NOTE]
> В PixiJS v8 изображение на GPU разделено на два уровня. **`TextureSource`** — сами пиксели (картинка, canvas, видео, пустой буфер) и настройки сэмплинга: `scaleMode` (`'linear'`/`'nearest'`), `addressMode` (`'clamp-to-edge'`/`'repeat'`/`'mirror-repeat'`), `resolution`, mipmaps. **`Texture`** — «окно» в source: прямоугольник `frame` плюс опциональные `trim`, `orig`, поворот. Поэтому кадры атласа — это много `Texture` над одним `TextureSource`, и они батчатся вместе. **`RenderTexture`** — текстура, в которую можно рисовать сцену (`renderer.render({ container, target })`), а `renderer.generateTexture(container)` превращает контейнер или Graphics в обычную текстуру. Встроенные заглушки: `Texture.WHITE` (белый пиксель для цветных прямоугольников) и `Texture.EMPTY`.

## Вопрос

Как устроены текстуры в PixiJS v8: чем `Texture` отличается от `TextureSource`, как вырезать кадр, настроить фильтрацию и рисовать в `RenderTexture`?

## Создание текстур

```ts
import { Texture, Rectangle, Assets } from 'pixi.js';

const tex = await Assets.load('/img/hero.png');   // основной способ

Texture.from('hero');                             // из кеша Assets по алиасу или URL
Texture.from(canvasElement);                      // из canvas (например, нарисованного 2D-контекстом)
Texture.from(videoElement);                       // видео
Texture.WHITE;                                    // 1×1 белая — Sprite с tint = цветной прямоугольник
Texture.EMPTY;                                    // пустая
```

## Свойства Texture

| Свойство | Что это |
| --- | --- |
| `source` | `TextureSource` — пиксели и настройки сэмплинга |
| `frame` | `Rectangle` — видимая часть source в пикселях |
| `orig` | исходный размер кадра до обрезки (для атласов с trim) |
| `trim` | прямоугольник обрезанных прозрачных краёв |
| `width`, `height` | размер кадра |
| `label` | имя для отладки |
| `destroyed` | уничтожена ли |
| `update()` | применить изменения `frame` |
| `destroy(destroySource?)` | уничтожить (с source — освободить GPU-память) |

## Кадр из картинки

```ts
const sheet = await Assets.load('/img/explosion.png');   // 8 кадров 64×64 в ряд

const frames = Array.from({ length: 8 }, (_, i) =>
  new Texture({
    source: sheet.source,                                // общий source — батчится
    frame: new Rectangle(i * 64, 0, 64, 64),
  }),
);
```

## Свойства TextureSource

| Свойство | Значения | Назначение |
| --- | --- | --- |
| `scaleMode` | `'linear'` / `'nearest'` | сглаживание или чёткие пиксели |
| `addressMode` | `'clamp-to-edge'` / `'repeat'` / `'mirror-repeat'` | поведение за пределами UV |
| `resolution` | число | плотность (для `@2x`-картинок — 2) |
| `autoGenerateMipmaps` | `boolean` | mipmaps при уменьшении |
| `antialias` | `boolean` | MSAA для render-target |
| `width`, `height`, `pixelWidth`, `pixelHeight` | | логический и реальный размер |
| `alphaMode` | `'premultiply-alpha-on-upload'` и др. | как обрабатывать альфу |
| `update()` | | перезалить пиксели (например, после рисования в исходный canvas) |
| `unload()` / `destroy()` | | освободить GPU |

```ts
import { TextureStyle } from 'pixi.js';

// по умолчанию для всех новых текстур — до загрузки ресурсов
TextureStyle.defaultOptions.scaleMode = 'nearest';

// для конкретной
tex.source.scaleMode = 'nearest';
tex.source.addressMode = 'repeat';       // для TilingSprite и шейдеров с повтором
```

## Текстура из canvas 2D

Удобно для динамических картинок: миникарта, процедурные текстуры, текст со сложными эффектами.

```ts
const c = document.createElement('canvas');
c.width = c.height = 128;
const g = c.getContext('2d')!;
const tex = Texture.from(c);
const minimap = new Sprite(tex);

function updateMinimap() {
  g.clearRect(0, 0, 128, 128);
  for (const e of enemies) g.fillRect(e.x / 20, e.y / 20, 2, 2);
  tex.source.update();                 // загрузить новые пиксели на GPU
}
```

## generateTexture: контейнер → текстура

```ts
// фигура, которая повторяется сотни раз — запекаем в текстуру и используем как Sprite
const starTex = app.renderer.generateTexture({
  target: new Graphics().star(0, 0, 5, 16).fill(0xfde047),
  resolution: 2,
  antialias: true,
});
for (let i = 0; i < 500; i++) app.stage.addChild(new Sprite(starTex));

// часть контейнера
app.renderer.generateTexture({ target: world, frame: new Rectangle(0, 0, 400, 300) });
```

## RenderTexture: рисовать в текстуру

```ts
import { RenderTexture, Sprite } from 'pixi.js';

const rt = RenderTexture.create({ width: 512, height: 512, resolution: 1 });

// «холст» для рисования: следы шин, кровь, рисовалка — без накопления тысяч объектов
const brush = new Graphics().circle(0, 0, 6).fill(0x333333);
const paint = new Sprite(rt);
app.stage.addChild(paint);

app.stage.on('pointermove', (e) => {
  brush.position.copyFrom(paint.toLocal(e.global));
  app.renderer.render({ container: brush, target: rt, clear: false }); // дорисовываем, не очищая
});

// мини-карта: рисуем мир в маленькую текстуру
const mini = RenderTexture.create({ width: 200, height: 120 });
app.ticker.add(() => {
  app.renderer.render({ container: world, target: mini, transform: miniMatrix });
});

rt.resize(1024, 1024);                 // изменить размер
rt.destroy(true);                      // освободить вместе с source
```

## Видео

```ts
const videoTex = await Assets.load({ src: '/video/bg.mp4', data: { autoPlay: true, loop: true, muted: true } });
const bg = new Sprite(videoTex);
```

Автовоспроизведение видео со звуком без жеста пользователя браузер заблокирует — используйте `muted`.

## Частые ошибки

- Создавать `new Texture(...)` для одного и того же кадра в каждом кадре игры.
- Уничтожать `Texture` с `destroySource = true`, когда source общий (атлас) — пропадут все кадры.
- Менять `scaleMode` после того, как текстура уже нарисована, и удивляться отсутствию эффекта — при необходимости вызовите `source.update()` или задайте `TextureStyle.defaultOptions` заранее.
- Забыть `source.update()` после изменения исходного canvas.
- Использовать `generateTexture` каждый кадр — это рендер в новую текстуру; для повторов используйте `RenderTexture` и `render`.

## Что важно помнить

- `TextureSource` — пиксели и сэмплинг, `Texture` — прямоугольник над ними.
- Кадры атласа = много `Texture` над одним source → батчинг.
- `scaleMode: 'nearest'` для пиксель-арта, `addressMode: 'repeat'` для плиток.
- `generateTexture` — запечь объект, `RenderTexture` + `renderer.render` — рисовать в текстуру.

## Мини-шпаргалка

```ts
new Texture({ source: tex.source, frame: new Rectangle(x, y, w, h) });
tex.source.scaleMode = 'nearest';
app.renderer.generateTexture({ target: graphics, resolution: 2 });
const rt = RenderTexture.create({ width, height });
app.renderer.render({ container, target: rt, clear: false });
```
