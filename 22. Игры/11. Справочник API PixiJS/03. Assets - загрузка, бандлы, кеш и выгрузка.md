# Assets — загрузка, бандлы, кеш и выгрузка

> [!NOTE]
> `Assets` — глобальный загрузчик PixiJS с кешем. Он по расширению определяет тип ресурса и возвращает готовый объект: `.png/.webp/.avif/.jpg` → `Texture`, `.json` атласа → `Spritesheet`, `.fnt/.xml` → `BitmapFont`, `.woff2/.ttf` → загруженный шрифт, `.json` → объект, `.svg` → текстура или `GraphicsContext`, `.mp4` → видео-текстура. Повторный `load` того же ключа возвращает объект из кеша. Ресурсы описывают **алиасами** (`Assets.add`), группируют в **бандлы** (манифест или `addBundle`), загружают с прогрессом (`onProgress`) и стратегией ошибок, а будущие уровни — **фоном** (`backgroundLoad`). Синхронно получить уже загруженное — `Assets.get(alias)`. Освободить память — `Assets.unload`/`unloadBundle`. При инициализации можно указать предпочтительные форматы и разрешения — `Assets` сам выберет `@2x.avif` для Retina с поддержкой AVIF.

## Вопрос

Какие возможности есть у `Assets` в PixiJS v8: как загружать ресурсы, организовать бандлы и кеш, выбирать форматы и выгружать неиспользуемое?

## Методы

| Метод | Назначение |
| --- | --- |
| `Assets.init(options)` | настройка: `basePath`, `manifest`, `texturePreference`, `preferences` — вызвать до первой загрузки |
| `Assets.add({ alias, src, data })` | зарегистрировать ресурс под именем |
| `Assets.load(urlOrAlias \| array, onProgress?)` | загрузить один или несколько |
| `Assets.addBundle(name, assets)` | создать бандл в коде |
| `Assets.loadBundle(name \| names, onProgress?)` | загрузить бандл(ы) |
| `Assets.backgroundLoad(urls)` / `backgroundLoadBundle(names)` | загрузка фоном без ожидания |
| `Assets.get(alias)` | синхронно взять из кеша (или `undefined`) |
| `Assets.cache.has(alias)` | проверить, загружен ли |
| `Assets.unload(alias)` / `unloadBundle(name)` | выгрузить и освободить GPU-память |
| `Assets.setPreferences({...})` | изменить настройки загрузки после init |
| `Assets.reset()` | сбросить всё (тесты) |

## Загрузка

```ts
import { Assets, Sprite } from 'pixi.js';

// один файл
const tex = await Assets.load('/img/hero.png');

// несколько — объект с результатами по ключам
const { hero, enemy } = await Assets.load([
  { alias: 'hero', src: '/img/hero.png' },
  { alias: 'enemy', src: '/img/enemy.png' },
]);

// прогресс
await Assets.load(['/a.png', '/b.png', '/c.png'], (p) => console.log(`${Math.round(p * 100)}%`));

// уже загруженное — синхронно
const heroTex = Assets.get('hero');
const sprite = Sprite.from('hero');   // тоже из кеша
```

## Алиасы и дополнительные данные

```ts
Assets.add({
  alias: ['bg', 'background'],                 // несколько имён
  src: '/img/bg.png',
  data: { scaleMode: 'nearest' },              // опции для загрузчика текстуры
});

Assets.add({ alias: 'icon', src: '/img/icon.svg', data: { parseAsGraphicsContext: true } }); // SVG как векторная графика
Assets.add({ alias: 'level1', src: '/levels/1.json' });                                       // обычный JSON
Assets.add({ alias: 'intro', src: '/video/intro.mp4' });                                      // видео-текстура
```

## Форматы и разрешения

```ts
await Assets.init({
  basePath: '/assets/',
  texturePreference: {
    resolution: Math.min(devicePixelRatio, 2),   // предпочитать @2x на Retina
    format: ['avif', 'webp', 'png'],             // первый поддерживаемый браузером
  },
});

// шаблон src: PixiJS сам выберет лучший вариант из доступных файлов
Assets.add({ alias: 'hero', src: 'hero@{1,2}x.{avif,webp,png}' });
const hero = await Assets.load('hero');          // например, hero@2x.avif
```

Такие наборы файлов автоматически генерирует **AssetPack** (`@assetpack/core`) — он же собирает атласы, сжимает картинки и создаёт манифест.

## Манифест и бандлы

```ts
await Assets.init({
  basePath: '/assets/',
  manifest: {
    bundles: [
      { name: 'boot', assets: [{ alias: 'logo', src: 'logo.png' }] },
      {
        name: 'level-1',
        assets: [
          { alias: 'tiles', src: 'tiles.json' },
          { alias: 'music-1', src: 'music1.mp3' },   // с @pixi/sound
        ],
      },
      { name: 'level-2', assets: [{ alias: 'boss', src: 'boss.json' }] },
    ],
  },
});

await Assets.loadBundle('boot');                    // быстро — для экрана загрузки
showLoading();

const level = await Assets.loadBundle('level-1', (p) => bar.scale.x = p);
level.tiles;                                        // результат по алиасам

Assets.backgroundLoadBundle('level-2');             // пока игрок проходит уровень 1

// позже — загрузится мгновенно, если фоновая загрузка успела
await Assets.loadBundle('level-2');
```

Манифест можно передать URL-ом: `manifest: '/assets/manifest.json'`.

## Обработка ошибок

```ts
await Assets.init({
  loadOptions: {
    strategy: 'retry',       // 'throw' (по умолчанию) | 'skip' | 'retry'
    retryCount: 3,
    retryDelay: 500,
    onError: (error, asset) => console.warn('Не загрузилось', asset, error),
  },
});

try {
  await Assets.load('/missing.png');
} catch (e) {
  // при strategy: 'throw'
}
```

## Атласы, шрифты, Spine

```ts
const sheet = await Assets.load('/sprites/atlas.json'); // Spritesheet
sheet.textures['coin.png'];      // Texture кадра
sheet.animations['run'];         // Texture[] для AnimatedSprite

await Assets.load('/fonts/Inter.woff2');                 // шрифт регистрируется в document.fonts
new Text({ text: 'Hi', style: { fontFamily: 'Inter' } });

await Assets.load('/fonts/pixel.fnt');                   // BitmapFont
new BitmapText({ text: '123', style: { fontFamily: 'pixel' } });
```

Spine, звук (`@pixi/sound`), сжатые текстуры (KTX2, Basis) подключаются как расширения загрузчика.

## Выгрузка

```ts
await Assets.unloadBundle('level-1');   // текстуры уничтожаются, кеш очищается
await Assets.unload('boss');
```

Перед выгрузкой уберите со сцены все спрайты, которые используют эти текстуры, — иначе они станут пустыми.

## Частые ошибки

- Вызывать `Assets.init` после первого `load` — настройки не применятся.
- Использовать `Sprite.from(url)` или `Assets.get` до завершения загрузки.
- Загружать одни и те же файлы по разным URL (`/img/a.png` и `img/a.png`) — кеш их не объединит; используйте алиасы.
- Выгружать бандл, пока его текстуры на сцене.
- Хранить в памяти все уровни сразу в большой игре.

## Что важно помнить

- `Assets.load` — асинхронно, с кешем; `Assets.get` — синхронно из кеша.
- Алиасы + манифест с бандлами — порядок в ресурсах.
- `backgroundLoadBundle` — подгрузка следующего уровня заранее.
- `texturePreference` и шаблон `name@{1,2}x.{avif,webp,png}` — автоматический выбор формата.
- `unloadBundle` освобождает память GPU.

## Мини-шпаргалка

```ts
await Assets.init({ basePath: '/assets/', manifest });
const t = await Assets.load('hero.png');
const b = await Assets.loadBundle('game', (p) => {});
Assets.backgroundLoadBundle('level2');
Assets.get('hero'); await Assets.unloadBundle('game');
```
