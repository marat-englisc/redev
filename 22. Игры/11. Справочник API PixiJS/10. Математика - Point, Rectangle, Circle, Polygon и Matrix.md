# Математика — Point, Rectangle, Circle, Polygon и Matrix

> [!NOTE]
> В PixiJS есть набор геометрических классов, которые используются и внутри движка, и в игровой логике. **`Point`** — `{ x, y }` с методами `set`, `copyFrom`, `clone`, `equals`; **`ObservablePoint`** — точка, которая сообщает объекту об изменении (это `position`, `scale`, `pivot`, `anchor`). Фигуры **`Rectangle`**, **`Circle`**, **`Ellipse`**, **`Polygon`**, **`RoundedRectangle`**, **`Triangle`** умеют `contains(x, y)` — их используют как `hitArea` и для своих проверок попадания; у `Rectangle` есть ещё `intersects`, `pad`, `fit`, `enlarge`, `containsRect`. **`Matrix`** — 2D-аффинная матрица (`a, b, c, d, tx, ty`) с `translate`, `rotate`, `scale`, `append`, `invert`, `apply`/`applyInverse`. Подключаемый модуль **`pixi.js/math-extras`** добавляет векторную математику точкам: `add`, `subtract`, `multiplyScalar`, `magnitude`, `normalize`, `dot`, `reflect`, `rotate`.

## Вопрос

Какие математические и геометрические классы есть в PixiJS и как использовать их в игровой логике?

## Point и ObservablePoint

```ts
import { Point } from 'pixi.js';

const p = new Point(10, 20);
p.set(30, 40);             // set(x, y?) — один аргумент задаёт обе оси
p.copyFrom(sprite.position);
const q = p.clone();
p.equals(q);               // true

// ObservablePoint: изменение сразу обновляет трансформацию
sprite.position.set(100, 50);
sprite.scale.set(2);
sprite.anchor.copyFrom({ x: 0.5, y: 1 });
```

Во многих местах API принимает любой объект `{ x, y }` (`PointData`), необязательно `Point`.

## math-extras: векторная математика

```ts
import 'pixi.js/math-extras';      // добавляет методы в Point, ObservablePoint и Rectangle
import { Point } from 'pixi.js';

const toTarget = target.position.subtract(enemy.position);  // новый Point
const dist = toTarget.magnitude();
const dir = toTarget.normalize();
enemy.position.add(dir.multiplyScalar(speed * dt), enemy.position); // результат в enemy.position

const facing = new Point(Math.cos(enemy.rotation), Math.sin(enemy.rotation));
const inFront = facing.dot(dir) > 0.5;           // игрок в конусе ±60°

ball.velocity = ball.velocity.reflect(wallNormal); // отражение от стены
const rotated = aim.rotate(0.2);                   // поворот вектора
```

| Метод | Результат |
| --- | --- |
| `add(p, out?)`, `subtract(p, out?)` | сумма, разность |
| `multiply(p, out?)` | покомпонентное умножение |
| `multiplyScalar(k, out?)` | умножение на число |
| `dot(p)`, `cross(p)` | скалярное, «псевдовекторное» (z-компонента) произведение |
| `magnitude()`, `magnitudeSquared()` | длина, квадрат длины |
| `normalize(out?)` | единичный вектор |
| `project(onto, out?)` | проекция |
| `reflect(normal, out?)` | отражение |
| `rotate(radians, out?)` | поворот |
| `Rectangle#intersection(r, out?)`, `union(r, out?)` | пересечение и объединение прямоугольников |

Параметр `out` позволяет записать результат в существующий объект и не создавать мусор в горячем цикле.

## Rectangle

```ts
import { Rectangle } from 'pixi.js';

const r = new Rectangle(0, 0, 100, 50);      // x, y, width, height
r.left; r.right; r.top; r.bottom;            // геттеры краёв
r.contains(30, 20);                          // точка внутри
r.intersects(other);                         // пересечение прямоугольников (AABB)
r.containsRect(other);                       // полностью содержит
r.pad(10);                                   // расширить на 10 со всех сторон
r.enlarge(other);                            // расширить, чтобы вместить other
r.fit(bounds);                               // обрезать по bounds
r.isEmpty();
r.strokeContains(x, y, width);               // точка на контуре заданной толщины
Rectangle.EMPTY;
```

```ts
// AABB-столкновение через Rectangle
const a = new Rectangle(), b = new Rectangle();
function hit(p: Player, e: Enemy) {
  a.x = p.x - 10; a.y = p.y - 12; a.width = 20; a.height = 24;   // переиспользуем объекты
  b.x = e.x - 8;  b.y = e.y - 8;  b.width = 16; b.height = 16;
  return a.intersects(b);
}
```

## Circle, Ellipse, Polygon, RoundedRectangle

```ts
import { Circle, Ellipse, Polygon, RoundedRectangle } from 'pixi.js';

new Circle(0, 0, 30).contains(px, py);
new Ellipse(0, 0, 40, 20).contains(px, py);
new RoundedRectangle(0, 0, 200, 60, 12).contains(px, py);

const area = new Polygon([0, 0, 120, 0, 160, 80, 40, 80]);    // или массив Point
area.contains(px, py);           // точка в многоугольнике
area.isClockwise();
area.getBounds();                // Rectangle

// зона триггера на карте
if (area.contains(player.x, player.y)) startCutscene();

// hitArea любой формы
building.hitArea = area;
```

Все фигуры подходят для `hitArea` и для `Graphics`: `new Graphics().poly(area.points).fill(…)`.

## Matrix

Аффинная матрица 2D:

```text
| a  c  tx |
| b  d  ty |
| 0  0  1  |
```

```ts
import { Matrix, Point } from 'pixi.js';

const m = new Matrix()
  .scale(2, 2)
  .rotate(Math.PI / 4)
  .translate(100, 50);          // операции применяются в порядке вызова

const world = m.apply(new Point(10, 0));           // локальная точка → после трансформации
const local = m.applyInverse(new Point(120, 60));  // обратное преобразование

m.invert();                      // обратная матрица (in place)
m.append(other);                 // this = this × other
m.prepend(other);
m.identity();
m.decompose(transform);          // разложить на позицию, поворот, масштаб, наклон

sprite.worldTransform;           // итоговая матрица объекта (только чтение)
sprite.setFromMatrix(m);         // задать трансформацию матрицей
```

Матрицы нужны для текстурных заливок (`fill({ texture, matrix })`), рендера в текстуру с камерой (`renderer.render({ container, target, transform })`) и своих преобразований координат.

## Полезные утилиты

```ts
import { Color } from 'pixi.js';

const c = new Color('#ff6347');
c.toNumber();                    // 0xff6347
c.toRgbaString();                // 'rgba(255,99,71,1)'
c.setAlpha(0.5).toArray();       // [1, 0.388, 0.278, 0.5]
new Color([1, 0, 0]).toHex();    // '#ff0000'

// плавный переход цвета: смешиваем компоненты
const from = new Color(0x22c55e).toArray();
const to = new Color(0xef4444).toArray();
const k = 1 - hp / maxHp;
bar.tint = new Color(from.map((v, i) => v + (to[i] - v) * k) as [number, number, number, number]);
```

`Color` принимает все форматы `ColorSource`: число, `'#hex'`, `'red'`, `'rgb(…)'`, `'hsl(…)'`, массивы и объекты `{ r, g, b }`, `{ h, s, l }`.

## Частые ошибки

- Ожидать от `Point` методов `add`/`normalize` без импорта `pixi.js/math-extras`.
- Сохранять ссылку на `sprite.position` и думать, что это копия, — это живой `ObservablePoint`.
- Создавать `new Rectangle`/`new Point` для каждой проверки каждый кадр — переиспользуйте и передавайте `out`.
- Путать порядок операций `Matrix`: `scale().rotate().translate()` — сначала масштаб, потом поворот, потом перенос.

## Что важно помнить

- `Point`/`ObservablePoint`, `PointData` — любые `{ x, y }`.
- Фигуры с `contains` — для `hitArea` и триггеров; `Rectangle.intersects` — AABB.
- `Matrix` — `apply`/`applyInverse`, `invert`, `append`.
- `pixi.js/math-extras` — векторные операции для точек.
- `Color` — разбор и преобразование цветов.

## Мини-шпаргалка

```ts
new Point(x, y).set(1, 2); p.copyFrom(q); p.clone();
import 'pixi.js/math-extras'; a.subtract(b).normalize().multiplyScalar(s);

```
