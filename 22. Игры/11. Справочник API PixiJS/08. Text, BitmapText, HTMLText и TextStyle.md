# Text, BitmapText, HTMLText и TextStyle

> [!NOTE]
> В PixiJS три класса текста с общим API: `new X({ text, style, anchor, resolution })`. **`Text`** рисуется через canvas 2D и загружается как текстура — поддерживает любые шрифты, обводку, тени, градиенты, перенос строк и даже разметку цветами через `tagStyles`, но каждое изменение `text` или стиля — перерисовка и новая загрузка на GPU. **`BitmapText`** собирается из готовых глифов атласа — менять текст почти бесплатно (счёт, таймер, урон), шрифт берётся из `.fnt` или генерируется `BitmapFont.install`. **`HTMLText`** рендерит HTML/CSS через SVG — для форматированного текста с тегами. Стиль описывается `TextStyle` (или обычным объектом): `fontFamily`, `fontSize`, `fill`, `stroke`, `dropShadow`, `wordWrap`, `align`, `lineHeight`, `letterSpacing`. Один `TextStyle` можно разделить между многими надписями. Размеры строки без создания объекта даёт `CanvasTextMetrics.measureText`.

## Вопрос

Какие классы текста есть в PixiJS v8, какие у них свойства стиля и когда использовать каждый?

## Text

```ts
import { Text, TextStyle } from 'pixi.js';

const title = new Text({
  text: 'GAME OVER',
  anchor: 0.5,
  resolution: 2,                    // чётче на Retina (по умолчанию = renderer.resolution)
  style: {
    fontFamily: 'Inter, sans-serif',
    fontSize: 56,
    fontWeight: '800',
    fill: 0xffffff,
    stroke: { color: 0x000000, width: 6, join: 'round' },
    dropShadow: { color: 0x000000, alpha: 0.5, blur: 6, distance: 4, angle: Math.PI / 4 },
    letterSpacing: 2,
  },
});
title.position.set(app.screen.width / 2, 200);
app.stage.addChild(title);

title.text = 'YOU WIN';             // перерисовка текстуры
```

## Свойства TextStyle

| Свойство | Описание |
| --- | --- |
| `fontFamily` | строка или массив запасных шрифтов |
| `fontSize` | число (px) или строка (`'2em'`) |
| `fontWeight`, `fontStyle`, `fontVariant` | `'bold'`/`'700'`, `'italic'`, `'small-caps'` |
| `fill` | цвет, `FillGradient`, `FillPattern` или `{ color, alpha }` |
| `stroke` | `{ color, width, join, cap, alignment }` |
| `dropShadow` | `{ color, alpha, blur, distance, angle }` или `true` |
| `align` | `'left'` / `'center'` / `'right'` / `'justify'` — для многострочного |
| `wordWrap`, `wordWrapWidth`, `breakWords` | перенос строк по ширине |
| `lineHeight`, `leading` | высота строки и доп. интервал |
| `letterSpacing` | межбуквенный интервал |
| `whiteSpace` | `'normal'` / `'pre'` / `'pre-line'` — обработка пробелов |
| `textBaseline` | базовая линия |
| `padding` | запас по краям (если обрезаются тени или курсив) |
| `trim` | обрезать прозрачные края |
| `tagStyles` | стили для тегов в тексте: `<red>…</red>` |
| `filters` | фильтры, запекаемые в текстуру текста |

## Общий стиль

```ts
const labelStyle = new TextStyle({ fontFamily: 'Inter', fontSize: 18, fill: 0xe2e8f0 });

const a = new Text({ text: 'Сила', style: labelStyle });
const b = new Text({ text: 'Ловкость', style: labelStyle });

labelStyle.fill = 0xfacc15;   // изменятся обе надписи
```

## Цветные фрагменты: tagStyles

```ts
const log = new Text({
  text: 'Вы нанесли <dmg>24</dmg> урона, враг <crit>оглушён</crit>',
  style: {
    fontSize: 20,
    fill: 0xffffff,
    tagStyles: {
      dmg: { fill: 0xef4444, fontWeight: 'bold' },
      crit: { fill: 0xfacc15, fontStyle: 'italic' },
    },
  },
});
```

Без `tagStyles` символ `<` выводится как обычный текст.

## Градиентный текст

```ts
import { FillGradient } from 'pixi.js';

const gold = new FillGradient({
  type: 'linear',
  start: { x: 0, y: 0 }, end: { x: 0, y: 1 },
  colorStops: [{ offset: 0, color: '#fde68a' }, { offset: 1, color: '#b45309' }],
});
new Text({ text: 'LEVEL UP', style: { fontSize: 64, fill: gold, stroke: { color: 0x451a03, width: 4 } } });
```

## BitmapText

```ts
import { BitmapFont, BitmapText, Assets } from 'pixi.js';

// 1) сгенерировать атлас глифов из любого шрифта
BitmapFont.install({
  name: 'Damage',
  style: { fontFamily: 'Inter', fontSize: 32, fill: 0xffffff, stroke: { color: 0x000000, width: 4 } },
  chars: [['0', '9'], '+-!'],         // только нужные символы — меньше атлас
  resolution: 2,
});

// 2) или загрузить готовый .fnt / .xml (BMFont, Hiero, Glyph Designer)
await Assets.load('/fonts/pixel.fnt');

const dmg = new BitmapText({ text: '-24', style: { fontFamily: 'Damage', fontSize: 32 } });
dmg.text = '-31';                     // дёшево: другие квадраты из того же атласа
```

Если `BitmapText` использует шрифт, который не установлен, PixiJS сгенерирует его динамически из `fontFamily` при первом использовании.

## HTMLText

```ts
import { HTMLText } from 'pixi.js';

const rich = new HTMLText({
  text: '<b>Квест:</b> найти <i>древний меч</i><br>Награда: <span class="gold">500</span>',
  style: {
    fontFamily: 'Inter',
    fontSize: 20,
    fill: 0xffffff,
    wordWrap: true,
    wordWrapWidth: 360,
    cssOverrides: ['.gold { color: #facc15; font-weight: bold; }'],
  },
});
```

Обновление асинхронное и дорогое — для статичного форматированного текста.

## Сравнение

| | `Text` | `BitmapText` | `HTMLText` |
| --- | --- | --- | --- |
| Рендер | canvas 2D → текстура | глифы атласа | HTML → SVG → текстура |
| Изменение текста | дорого | очень дёшево | дорого, асинхронно |
| Стили | богатые, `tagStyles` | заданы при генерации атласа | любой CSS, теги |
| Масштабирование | мылится при увеличении (повышайте `resolution`) | чётко при `resolution`/MSDF | как Text |
| Для чего | заголовки, меню, диалоги | счёт, таймер, урон, FPS | описания, справка |

## Измерение текста

```ts
import { CanvasTextMetrics, TextStyle } from 'pixi.js';

const m = CanvasTextMetrics.measureText('Привет, мир', new TextStyle({ fontSize: 24 }));
m.width; m.height; m.lines; m.lineHeight;
```

Удобно, чтобы подогнать размер кнопки или фона под текст до создания объекта.

## Веб-шрифты

```ts
await Assets.load({ alias: 'Inter', src: '/fonts/Inter.woff2', data: { family: 'Inter' } });
new Text({ text: 'Готово', style: { fontFamily: 'Inter' } });
```

Если создать `Text` до загрузки шрифта, он отрисуется запасным шрифтом и сам не обновится.

## Частые ошибки

- Менять `Text.text` каждый кадр (таймер, FPS, координаты) — используйте `BitmapText`.
- Синтаксис v7 `new Text('hi', style)` — в v8 объект `{ text, style }`.
- Не загрузить шрифт до создания текста.
- Масштабировать `Text` через `scale` — мыло; увеличивайте `fontSize` или `resolution`.
- Обрезанные тени и курсив по краям — добавьте `padding`.

## Что важно помнить

- `Text` — красиво и гибко, но дорого обновлять.
- `BitmapText` — для часто меняющихся чисел; шрифт из `.fnt` или `BitmapFont.install`.
- `HTMLText` — CSS и теги.
- `TextStyle` можно разделять; `tagStyles` — цветные фрагменты; `CanvasTextMetrics` — измерение.

## Мини-шпаргалка

```ts
new Text({ text, style: { fontSize: 24, fill: 0xffffff, stroke: { color: 0, width: 4 } }, anchor: 0.5 });
BitmapFont.install({ name: 'Score', style: { fontSize: 24 }, chars: [['0', '9']] });
new BitmapText({ text: '0', style: { fontFamily: 'Score' } });
CanvasTextMetrics.measureText(text, style).width;
```
