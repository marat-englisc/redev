# Graphics и GraphicsContext — фигуры, заливки и градиенты

> [!NOTE]
> `Graphics` рисует векторные фигуры по схеме **«описать фигуру → залить/обвести»**: методы фигур (`rect`, `roundRect`, `circle`, `ellipse`, `poly`, `regularPoly`, `star`, `roundPoly`, `chamferRect`, `filletRect`, `arc`, пути `moveTo/lineTo/bezierCurveTo`) добавляют геометрию, затем `fill(style)` и/или `stroke(style)` применяют к ней стиль. Стиль — цвет, `{ color, alpha }`, `{ texture, matrix }` или градиент `FillGradient` (линейный и радиальный). `cut()` вырезает отверстие из предыдущей фигуры, `svg()` разбирает SVG-разметку, `clear()` стирает всё. Геометрия хранится в **`GraphicsContext`** — его можно создать один раз и разделить между многими `Graphics`. Методы возвращают `this`, поэтому вызовы сцепляются цепочкой.

## Вопрос

Какие фигуры, стили заливки и обводки, градиенты и приёмы работы есть у `Graphics` в PixiJS v8?

## Фигуры

| Метод | Аргументы | Что рисует |
| --- | --- | --- |
| `rect` | `x, y, w, h` | прямоугольник |
| `roundRect` | `x, y, w, h, radius` | скруглённый прямоугольник |
| `chamferRect` | `x, y, w, h, chamfer` | прямоугольник со срезанными углами |
| `filletRect` | `x, y, w, h, fillet` | со скруглёнными внутрь/наружу углами |
| `circle` | `x, y, r` | круг |
| `ellipse` | `x, y, rx, ry` | эллипс |
| `poly` | `[x1, y1, x2, y2, …]` или `PointData[]`, `close?` | многоугольник |
| `regularPoly` | `x, y, radius, sides, rotation?` | правильный многоугольник (шестиугольник для гекс-карты) |
| `roundPoly` | `x, y, radius, sides, corner` | правильный со скруглёнными углами |
| `star` | `x, y, points, radius, innerRadius?, rotation?` | звезда |
| `roundShape` | `points, radius` | произвольный многоугольник со скруглением |
| `arc` / `arcTo` | как в canvas 2D | дуга |
| `moveTo`, `lineTo`, `quadraticCurveTo`, `bezierCurveTo`, `closePath` | | произвольный путь |
| `svg(string)` | SVG-разметка | фигуры из SVG |
| `texture(tex, tint?, x?, y?, w?, h?)` | | вставить текстуру как часть графики |

```ts
import { Graphics } from 'pixi.js';

const shapes = new Graphics()
  .rect(0, 0, 100, 60).fill(0x3b82f6)
  .roundRect(120, 0, 100, 60, 12).fill(0x22c55e)
  .circle(280, 30, 30).fill(0xf97316)
  .regularPoly(360, 30, 30, 6).fill(0xa855f7)       // шестиугольник
  .star(440, 30, 5, 30, 14).fill(0xfacc15)
  .chamferRect(500, 0, 100, 60, 12).fill(0x64748b);
```

## Заливка: fill

```ts
g.rect(0, 0, 100, 100).fill(0xff0000);                         // цвет
g.rect(0, 0, 100, 100).fill('#ff000080');                     // CSS-строка с альфой
g.rect(0, 0, 100, 100).fill({ color: 0xff0000, alpha: 0.5 }); // объект стиля
g.rect(0, 0, 256, 256).fill({ texture: grassTex });            // текстурой
g.rect(0, 0, 100, 100).fill(gradient);                         // градиентом
```

| Поле FillStyle | Описание |
| --- | --- |
| `color` | любой `ColorSource`: число, `'#hex'`, `'red'`, `[r, g, b]`, `{ r, g, b }` |
| `alpha` | 0..1 |
| `texture` | текстура-заливка |
| `matrix` | трансформация текстуры (масштаб, смещение плитки) |
| `fill` | `FillGradient` или `FillPattern` |

## Обводка: stroke

```ts
g.circle(0, 0, 40).stroke({ width: 4, color: 0xffffff });
g.poly([0, 0, 50, 80, 100, 0]).stroke({ width: 6, color: 0x000000, join: 'round', cap: 'round' });
g.rect(0, 0, 100, 50).fill(0x1e293b).stroke({ width: 2, color: 0x38bdf8, alignment: 0 }); // обводка внутрь
```

| Поле StrokeStyle | Значения |
| --- | --- |
| `width` | толщина |
| `color`, `alpha`, `texture` | как у fill |
| `alignment` | `0.5` — по центру линии (по умолчанию), `0` — внутрь, `1` — наружу |
| `cap` | `'butt'` / `'round'` / `'square'` — концы линий |
| `join` | `'miter'` / `'round'` / `'bevel'` — углы |
| `miterLimit` | ограничение острых углов |
| `pixelLine` | `true` — линия ровно в 1 пиксель независимо от масштаба |

## Градиенты

```ts
import { FillGradient } from 'pixi.js';

// линейный: координаты 0..1 относительно фигуры (textureSpace: 'local' по умолчанию)
const sky = new FillGradient({
  type: 'linear',
  start: { x: 0, y: 0 },
  end: { x: 0, y: 1 },
  colorStops: [
    { offset: 0, color: '#0f172a' },
    { offset: 1, color: '#1e3a8a' },
  ],
});
new Graphics().rect(0, 0, 800, 450).fill(sky);

// радиальный: свечение
const glow = new FillGradient({
  type: 'radial',
  center: { x: 0.5, y: 0.5 },
  innerRadius: 0,
  outerCenter: { x: 0.5, y: 0.5 },
  outerRadius: 0.5,
  colorStops: [
    { offset: 0, color: 'rgba(250, 204, 21, 1)' },
    { offset: 1, color: 'rgba(250, 204, 21, 0)' },
  ],
});
new Graphics().circle(0, 0, 60).fill(glow);
```

`textureSpace: 'global'` задаёт координаты градиента в пикселях — тогда одна заливка тянется через несколько фигур. Градиенты подходят и для текста: `style.fill = gradient`.

## Отверстия: cut

```ts
// бублик
new Graphics().circle(0, 0, 50).fill(0xf59e0b).circle(0, 0, 20).cut();

// рамка
new Graphics().rect(0, 0, 200, 120).rect(10, 10, 180, 100).cut().fill(0xffffff);
```

`cut()` вырезает последнюю фигуру из предыдущей.

## Трансформация внутри Graphics

```ts
const g = new Graphics();
for (let i = 0; i < 12; i++) {
  g.save()
    .rotateTransform((i / 12) * Math.PI * 2)   // поворот системы координат графики
    .rect(40, -3, 20, 6)
    .fill(0xffffff)
    .restore();
}
// циферблат: 12 делений вокруг (0, 0)
```

Есть также `translateTransform`, `scaleTransform`, `setTransform`, `resetTransform`.

## GraphicsContext: общая геометрия

```ts
import { GraphicsContext, Graphics } from 'pixi.js';

const coinShape = new GraphicsContext()
  .circle(0, 0, 10).fill(0xfacc15)
  .circle(0, 0, 6).stroke({ width: 2, color: 0xca8a04 });

const coins = Array.from({ length: 200 }, (_, i) => {
  const c = new Graphics(coinShape);     // геометрия не копируется
  c.position.set(i * 24, 100);
  return c;
});

// анимация «по кадрам» — переключение контекстов
const frames = [ctxOpen, ctxClosed];
pacman.context = frames[(t / 100 | 0) % 2];
```

## SVG

```ts
const icon = new Graphics().svg(`
  <svg viewBox="0 0 24 24">
    <path d="M12 2 L22 22 L2 22 Z" fill="#ef4444" stroke="#000" stroke-width="2"/>
  </svg>
`);

// или через Assets как векторный контекст
const ctx = await Assets.load({ src: '/icons/logo.svg', data: { parseAsGraphicsContext: true } });
const logo = new Graphics(ctx);
```

## Производительность

- Статичная графика: нарисовать один раз и не трогать — PixiJS кеширует геометрию.
- Перерисовка `clear()` + новые фигуры каждый кадр — дорого для сложных форм; меняйте `position`/`scale`/`tint` вместо перестройки.
- Сотни одинаковых фигур: общий `GraphicsContext` или `renderer.generateTexture` → `Sprite`.
- `Graphics` прерывает батч спрайтов — группируйте графику отдельно.

## Частые ошибки

- Ждать, что `fill()` применится к фигурам, описанным **после** него, — стиль относится только к предыдущим.
- Писать в стиле v7: `beginFill`/`drawRect`/`endFill`/`lineStyle` — устарело.
- Рисовать фигуры со смещением от `(0, 0)` и потом вращать — вращение вокруг угла.
- Перестраивать сложный `Graphics` каждый кадр без нужды.
- Указывать радиус градиента в пикселях при `textureSpace: 'local'` — там координаты 0..1.

## Что важно помнить

- Схема: фигура → `fill`/`stroke`, всё цепочкой.
- Стили: цвет, `{ color, alpha }`, текстура, `FillGradient`; обводка — `width`, `alignment`, `cap`, `join`.
- `cut()` — отверстия, `svg()` — разбор SVG, `clear()` — перерисовка.
- `GraphicsContext` — общая геометрия для многих объектов.

```ts
new Graphics().roundRect(0, 0, w, h, 8).fill({ color: 0x000, alpha: 0.5 }).stroke({ width: 2, color: 0xfff });

```
