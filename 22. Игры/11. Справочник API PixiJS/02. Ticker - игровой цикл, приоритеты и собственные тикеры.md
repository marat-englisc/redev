# Ticker — игровой цикл, приоритеты и собственные тикеры

> [!NOTE]
> `Ticker` — обёртка над `requestAnimationFrame`, которая вызывает подписанные колбэки каждый кадр и передаёт им сам себя: `ticker.deltaTime` (≈1 при 60 FPS — множитель кадра), `ticker.deltaMS` (мс с прошлого кадра с учётом `speed` и ограничений), `ticker.elapsedMS` (сырое время), `ticker.lastTime`, `ticker.FPS`. Подписка — `add(fn, context, priority)`, однократно — `addOnce`, отписка — `remove(fn, context)`. Колбэки выполняются по **приоритету** (`UPDATE_PRIORITY.HIGH` раньше `NORMAL`, рендер `Application` — с `LOW`, поэтому логика успевает до отрисовки). Скорость времени задаёт `speed`, частоту — `maxFPS`/`minFPS`. Кроме `app.ticker` есть общий `Ticker.shared` и можно создавать свои тикеры — например, для UI, который работает во время паузы игры.

## Вопрос

Как устроен `Ticker` в PixiJS: какие у него свойства и методы, как работают приоритеты и как сделать паузу, slow-motion и отдельный цикл для интерфейса?

## Свойства

| Свойство | Значение |
| --- | --- |
| `deltaTime` | множитель относительно 60 FPS: ≈1 при 60, ≈0,5 при 120, ≈2 при 30 (с учётом `speed`) |
| `deltaMS` | миллисекунды с прошлого кадра (с учётом `speed` и `minFPS`) |
| `elapsedMS` | миллисекунды без `speed` и ограничений — реальное время |
| `lastTime` | timestamp последнего кадра |
| `FPS` | текущая частота кадров |
| `speed` | множитель времени: `0.5` — замедление, `0` — фактическая пауза |
| `maxFPS` | ограничить частоту вызовов (`0` — без ограничения) |
| `minFPS` | ограничивает максимальный `deltaMS` после лагов (по умолчанию 10 FPS) |
| `started` | запущен ли |
| `count` | количество подписчиков |
| `autoStart` | запускать при первой подписке |

## Методы

| Метод | Назначение |
| --- | --- |
| `add(fn, context?, priority?)` | вызывать каждый кадр |
| `addOnce(fn, context?, priority?)` | вызвать в следующем кадре один раз |
| `remove(fn, context?)` | отписаться (контекст должен совпадать) |
| `start()` / `stop()` | запустить / остановить |
| `update(time?)` | продвинуть вручную (для тестов или своего цикла) |
| `destroy()` | уничтожить |
| `Ticker.shared` | общий тикер (используют AnimatedSprite и др. по умолчанию) |
| `Ticker.system` | внутренний системный тикер (события, prepare) |

## Секунды или кадры

```ts
app.ticker.add((ticker) => {
  // «пиксели за кадр при 60 FPS» — удобно для простых анимаций
  sprite.rotation += 0.05 * ticker.deltaTime;

  // «пиксели в секунду» — как в уроках про delta time
  const dt = ticker.deltaMS / 1000;
  player.x += player.speed * dt;
});
```

## Приоритеты

```ts
import { UPDATE_PRIORITY } from 'pixi.js';

app.ticker.add(readInput, null, UPDATE_PRIORITY.INTERACTION); // 50 — первым
app.ticker.add(updatePhysics, null, UPDATE_PRIORITY.HIGH);    // 25
app.ticker.add(updateGame);                                   // 0  — NORMAL
app.ticker.add(updateCamera, null, UPDATE_PRIORITY.LOW);      // -25 — после логики
// рендер Application зарегистрирован с LOW и добавлен раньше — выполняется до камеры
```

Колбэки с одинаковым приоритетом выполняются в порядке добавления.

## Контекст и отписка

```ts
class Enemy {
  constructor(private ticker: Ticker) {
    ticker.add(this.update, this);         // this внутри update — экземпляр
  }
  update(ticker: Ticker) { /* ... */ }
  destroy() {
    this.ticker.remove(this.update, this); // тот же fn и тот же context
  }
}
```

Стрелочные функции, созданные «на месте», отписать нельзя — сохраните ссылку.

## Пауза и slow-motion

```ts
// пауза игры: логика стоит, рендер продолжается (меню паузы анимируется)
let paused = false;
app.ticker.add((t) => {
  if (paused) return;
  world.update(t.deltaMS / 1000);
});

// slow-motion: время замедляется для всего, что использует deltaTime/deltaMS
app.ticker.speed = 0.3;
gsap.to(app.ticker, { speed: 1, duration: 1, delay: 0.5 }); // плавный выход

// полная остановка, включая отрисовку
app.ticker.stop();
```

## Отдельный тикер для игрового мира

```ts
import { Ticker } from 'pixi.js';

const gameTicker = new Ticker();
gameTicker.add((t) => world.update(t.deltaMS / 1000));
gameTicker.start();

// app.ticker рисует и анимирует UI, gameTicker — только логика
function pause() { gameTicker.stop(); }
function resume() { gameTicker.start(); }
```

## Фиксированный шаг на тикере

```ts
const STEP = 1 / 60;
let acc = 0;

app.ticker.add((t) => {
  acc += Math.min(t.elapsedMS / 1000, 0.25);   // реальное время
  while (acc >= STEP) {
    physics.step(STEP);
    acc -= STEP;
  }
  syncSprites(acc / STEP);
});
```

## Ограничение FPS

```ts
app.ticker.maxFPS = 30;   // экономия батареи для простых сцен и фоновых анимаций
app.ticker.minFPS = 20;   // deltaMS не больше 50 мс — защита от «прыжка» после лага
```

## Частые ошибки

- Считать `deltaTime` секундами — это множитель кадра, секунды — `deltaMS / 1000`.
- Отписывать анонимную функцию — `remove` её не найдёт, колбэк продолжает работать после уничтожения объекта.
- Ставить `speed = 0` и ждать, что ticker перестанет вызывать колбэки, — вызовы идут, просто `deltaMS = 0`.
- Не отписывать колбэки уничтоженных объектов — ошибки при обращении к удалённым спрайтам.
- Использовать `elapsedMS` для игровой логики при включённом slow-motion — он игнорирует `speed`.

## Что важно помнить

- Колбэк получает `Ticker`: `deltaTime` — множитель, `deltaMS` — миллисекунды.
- `add(fn, ctx, priority)`, `remove(fn, ctx)`, `addOnce`.
- Приоритеты задают порядок: ввод → физика → логика → камера/рендер.
- `speed` — замедление и ускорение, `maxFPS`/`minFPS` — ограничения.
- Свой `new Ticker()` для независимых циклов (игра и UI).

## Мини-шпаргалка

```ts
app.ticker.add((t) => obj.x += 200 * t.deltaMS / 1000);
app.ticker.add(fn, ctx, UPDATE_PRIORITY.HIGH); app.ticker.remove(fn, ctx);
app.ticker.speed = 0.5; app.ticker.maxFPS = 30;
const t = new Ticker(); t.add(cb); t.start();
```
