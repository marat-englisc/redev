# Как определить, по какому объекту кликнули — hit testing

> [!NOTE]
> В canvas у фигур нет своих событий: клик приходит на весь холст, и игра сама определяет, в какой объект попала точка, — это **hit testing**. Для прямоугольника проверяют, что точка внутри границ, для круга — что расстояние до центра меньше радиуса, для повёрнутого объекта точку сначала переводят в его **локальные координаты** (обратная трансформация). Для произвольных форм есть `ctx.isPointInPath(path2d, x, y)`. Объекты перебирают **с конца** — от верхнего слоя к нижнему, чтобы кликнуть по тому, что видно сверху. Для тысяч объектов используют пространственную сетку или «picking» по цвету.

## Вопрос

Как в canvas определить, по какому объекту кликнул пользователь?

## Точка в прямоугольнике

```ts
interface Rect { x: number; y: number; w: number; h: number }

const pointInRect = (px: number, py: number, r: Rect) =>
  px >= r.x && px <= r.x + r.w && py >= r.y && py <= r.y + r.h;
```

## Точка в круге

```ts
const pointInCircle = (px: number, py: number, cx: number, cy: number, r: number) => {
  const dx = px - cx, dy = py - cy;
  return dx * dx + dy * dy <= r * r;   // без Math.sqrt — быстрее
};
```

## Выбор верхнего объекта

```ts
function pick(px: number, py: number): Entity | null {
  // рисуем от первого к последнему → верхний объект в конце массива
  for (let i = entities.length - 1; i >= 0; i--) {
    if (entities[i].contains(px, py)) return entities[i];
  }
  return null;
}

canvas.addEventListener('pointerdown', (e) => {
  const { x, y } = toWorld(e);           // экран → мир (масштаб, камера)
  const target = pick(x, y);
  if (target) target.onClick?.();
});
```

## Повёрнутый и масштабированный объект

Вместо того чтобы поворачивать прямоугольник, поворачиваем **точку** в обратную сторону:

```ts
class Card {
  x = 200; y = 150; w = 80; h = 120;
  angle = 0.3; scale = 1.2;

  contains(px: number, py: number) {
    // 1. перенос в центр объекта
    let dx = px - this.x;
    let dy = py - this.y;
    // 2. обратный поворот
    const cos = Math.cos(-this.angle), sin = Math.sin(-this.angle);
    const lx = (dx * cos - dy * sin) / this.scale;
    const ly = (dx * sin + dy * cos) / this.scale;
    // 3. теперь это обычный прямоугольник вокруг (0,0)
    return Math.abs(lx) <= this.w / 2 && Math.abs(ly) <= this.h / 2;
  }
}
```

То же через матрицы `DOMMatrix`, если трансформация сложная (вложенные контейнеры):

```ts
const m = new DOMMatrix().translate(card.x, card.y).rotate((card.angle * 180) / Math.PI).scale(card.scale);
const local = m.inverse().transformPoint(new DOMPoint(px, py));
```

## Произвольная форма: isPointInPath

```ts
const star = new Path2D('M50 0 L61 35 L98 35 L68 57 L79 91 L50 70 L21 91 L32 57 L2 35 L39 35 Z');

function hitStar(px: number, py: number, s: { x: number; y: number }) {
  ctx.save();
  ctx.translate(s.x, s.y);               // та же трансформация, что при рисовании
  const hit = ctx.isPointInPath(star, px, py); // px, py — в координатах буфера canvas
  ctx.restore();
  return hit;
}
```

`isPointInPath` учитывает текущую трансформацию контекста, а точку ждёт в «сырых» координатах canvas.

## Hover и курсор

```ts
canvas.addEventListener('pointermove', (e) => {
  const { x, y } = toWorld(e);
  hovered = pick(x, y);
  canvas.style.cursor = hovered ? 'pointer' : 'default';
});
```

## Перетаскивание (drag & drop)

```ts
let dragging: Entity | null = null;
let offset = { x: 0, y: 0 };

canvas.addEventListener('pointerdown', (e) => {
  const p = toWorld(e);
  dragging = pick(p.x, p.y);
  if (dragging) {
    offset = { x: p.x - dragging.x, y: p.y - dragging.y };   // чтобы объект не «прыгал» центром под курсор
    entities.push(entities.splice(entities.indexOf(dragging), 1)[0]); // поднять наверх
    canvas.setPointerCapture(e.pointerId);
  }
});
canvas.addEventListener('pointermove', (e) => {
  if (!dragging) return;
  const p = toWorld(e);
  dragging.x = p.x - offset.x;
  dragging.y = p.y - offset.y;
});
canvas.addEventListener('pointerup', () => (dragging = null));
```

## Color picking: много объектов сложной формы

Объекты рисуются второй раз в скрытый canvas, каждый своим уникальным цветом (`id → цвет`). Цвет пикселя под курсором даёт id объекта:

```ts
const hitCanvas = new OffscreenCanvas(w, h);
const hitCtx = hitCanvas.getContext('2d', { willReadFrequently: true })!;

const idToColor = (id: number) => `#${id.toString(16).padStart(6, '0')}`;

function pickByColor(px: number, py: number) {
  const [r, g, b] = hitCtx.getImageData(px, py, 1, 1).data;
  return byId.get((r << 16) | (g << 8) | b) ?? null;
}
```

Сглаживание краёв (antialiasing) на 2D-canvas отключить нельзя, поэтому на границах фигур появляются «полутона» — смешанные цвета, которые не совпадают ни с одним id. Такие пиксели просто считают промахом. Этот подход использует, например, Konva.

## Частые ошибки

- Перебирать объекты с начала массива — выбирается нижний объект вместо видимого.
- Забыть перевести координаты события с учётом масштаба canvas и камеры.
- Проверять повёрнутый спрайт по неповёрнутому прямоугольнику.
- Вызывать `isPointInPath` без той же трансформации, что была при рисовании.

## Что важно помнить

- Попадание считается вручную: прямоугольник, круг, многоугольник.
- Перебор сверху вниз — с конца массива.
- Для трансформированных объектов переводим точку в локальные координаты.
- `isPointInPath` — для произвольных `Path2D`.
- Konva, PixiJS и Phaser делают hit testing за вас и дают события на объектах.
