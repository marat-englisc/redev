# Как обрабатывать клавиатуру в игре

> [!NOTE]
> В игре нельзя двигать персонажа прямо в обработчике `keydown`: событие приходит с задержкой автоповтора и не синхронизировано с кадрами. Правильно — **хранить состояние клавиш** (`Set` нажатых) и опрашивать его в `update`. Для разовых действий (прыжок, выстрел, пауза) нужен признак «нажата именно в этом кадре» — `pressed`, который сбрасывается в конце кадра. Используйте `event.code` (физическая клавиша: `KeyW` на любой раскладке), а не `event.key` (символ: `'ц'` на русской раскладке). Не забудьте `preventDefault` для стрелок и пробела (иначе страница прокручивается) и сброс всех клавиш при `blur`, чтобы персонаж не «залип» при переключении окна.

## Вопрос

Как правильно обрабатывать нажатия клавиш в браузерной игре?

## Почему не двигать в обработчике

```ts
// ❌
addEventListener('keydown', (e) => {
  if (e.key === 'ArrowRight') player.x += 10;
});
// - после первого нажатия пауза ~500 мс до автоповтора
// - скорость = частота автоповтора ОС, а не dt
// - две клавиши одновременно (диагональ) работают плохо
```

## Класс ввода

```ts
export class Keyboard {
  private down = new Set<string>();        // зажаты сейчас
  private pressedNow = new Set<string>();  // нажаты в этом кадре
  private releasedNow = new Set<string>(); // отпущены в этом кадре

  private static readonly BLOCK = new Set(['ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight', 'Space']);

  constructor(target: Window | HTMLElement = window) {
    target.addEventListener('keydown', this.onDown as EventListener);
    target.addEventListener('keyup', this.onUp as EventListener);
    window.addEventListener('blur', this.reset);
  }

  private onDown = (e: KeyboardEvent) => {
    if (Keyboard.BLOCK.has(e.code)) e.preventDefault(); // без прокрутки страницы
    if (e.repeat) return;                                 // игнорируем автоповтор
    this.down.add(e.code);
    this.pressedNow.add(e.code);
  };

  private onUp = (e: KeyboardEvent) => {
    this.down.delete(e.code);
    this.releasedNow.add(e.code);
  };

  private reset = () => this.down.clear();

  isDown(code: string) { return this.down.has(code); }
  pressed(code: string) { return this.pressedNow.has(code); }
  released(code: string) { return this.releasedNow.has(code); }

  /** вызвать в конце каждого кадра */
  endFrame() {
    this.pressedNow.clear();
    this.releasedNow.clear();
  }
}
```

## Использование в цикле

```ts
const keys = new Keyboard();

function update(dt: number) {
  // непрерывное действие — пока зажата
  const dir = Number(keys.isDown('KeyD') || keys.isDown('ArrowRight'))
            - Number(keys.isDown('KeyA') || keys.isDown('ArrowLeft'));
  player.vx = dir * 200;

  // разовое — только в кадре нажатия
  if (keys.pressed('Space')) player.jump();
  if (keys.released('Space')) player.cutJump(); // прыжок переменной высоты
  if (keys.pressed('Escape')) togglePause();
}

function loop(now: number) {
  update(dt);
  render();
  keys.endFrame();          // ВАЖНО: после update
  requestAnimationFrame(loop);
}
```

> [!WARNING]
> Если используете фиксированный шаг и `update` может вызваться 0 раз за кадр, `pressed` нужно сбрасывать после первого `update`, который его обработал, иначе нажатие потеряется (при 0 вызовов) или сработает дважды (при 2 вызовах).

## event.code vs event.key

| Свойство | WASD на английской | WASD на русской | Для чего |
| --- | --- | --- | --- |
| `e.code` | `KeyW` | `KeyW` | управление в играх |
| `e.key` | `w` | `ц` | ввод текста (имя игрока, чат) |

На AZERTY-клавиатуре физическая `KeyW` подписана как `Z` — для подсказки игроку можно получить подпись через `navigator.keyboard?.getLayoutMap()` (есть не во всех браузерах).

## Переназначение клавиш

Игровой код оперирует **действиями**, а не клавишами — так легко сделать настройки управления и поддержать геймпад:

```ts
type Action = 'left' | 'right' | 'jump' | 'pause';

const bindings: Record<Action, string[]> = {
  left: ['KeyA', 'ArrowLeft'],
  right: ['KeyD', 'ArrowRight'],
  jump: ['Space', 'KeyW', 'ArrowUp'],
  pause: ['Escape', 'KeyP'],
};

const isAction = (a: Action) => bindings[a].some((c) => keys.isDown(c));
const actionPressed = (a: Action) => bindings[a].some((c) => keys.pressed(c));

if (actionPressed('jump')) player.jump();
```

## Фокус

Если игра встроена в страницу, слушайте клавиши на самом canvas, чтобы не мешать полям ввода:

```html
<canvas id="game" tabindex="0"></canvas>
```

```ts
const keys = new Keyboard(canvas);
canvas.focus();
```

## Частые ошибки

- Двигать объект в `keydown` вместо опроса состояния в `update`.
- Использовать `e.key` для WASD — у пользователей с русской раскладкой управление не работает.
- Не обрабатывать `blur` — при Alt+Tab `keyup` не приходит, и персонаж бежит бесконечно.
- Не вызывать `preventDefault` для стрелок и пробела — страница прокручивается вместе с игрой.
- Использовать устаревший `e.keyCode`.

## Что важно помнить

- Состояние клавиш в `Set`, опрос в `update`.
- `isDown` — удержание, `pressed`/`released` — события кадра.
- `e.code` для управления, `e.key` для текста.
- Игровой код работает с действиями, клавиши — в таблице привязок.

## Мини-шпаргалка

```ts
addEventListener('keydown', (e) => { if (!e.repeat) { down.add(e.code); pressed.add(e.code); } });
addEventListener('keyup', (e) => down.delete(e.code));
addEventListener('blur', () => down.clear());
// в конце кадра: pressed.clear()
```
