# Как обрабатывать мышь, касания и Pointer Events

> [!NOTE]
> Для мыши, пальца и стилуса используют единые **Pointer Events** (`pointerdown`, `pointermove`, `pointerup`) — один код для десктопа и мобильных. Координаты события (`clientX/clientY`) — в CSS-пикселях окна, а игре нужны координаты **внутри canvas** с учётом его положения, CSS-масштаба и камеры: `(clientX - rect.left) * (canvas.width / rect.width)`. На touch-устройствах обязательно `touch-action: none` на canvas, иначе браузер начнёт скроллить и зумить страницу. Для шутеров с мышью есть **Pointer Lock API** — курсор скрывается, и приходят относительные смещения `movementX/movementY`.

## Вопрос

Как обрабатывать клики, движение мыши и касания в canvas-игре и как перевести координаты события в координаты игры?

## Координаты: экран → canvas → мир

```ts
function toCanvas(e: PointerEvent, canvas: HTMLCanvasElement) {
  const rect = canvas.getBoundingClientRect();
  return {
    // CSS-пиксели относительно canvas → пиксели буфера (учёт масштаба и dpr)
    x: (e.clientX - rect.left) * (canvas.width / rect.width),
    y: (e.clientY - rect.top) * (canvas.height / rect.height),
  };
}
```

Если игра рисует в **логическом разрешении** (например, 320×180) с масштабом, удобнее сразу считать в нём:

```ts
const GAME_W = 320, GAME_H = 180;

function toGame(e: PointerEvent) {
  const rect = canvas.getBoundingClientRect();
  return {
    x: ((e.clientX - rect.left) / rect.width) * GAME_W,
    y: ((e.clientY - rect.top) / rect.height) * GAME_H,
  };
}

// с камерой: экранные → мировые
const world = { x: screen.x + camera.x, y: screen.y + camera.y };
```

## Класс указателя

```ts
export class Pointer {
  x = 0;
  y = 0;
  isDown = false;
  pressed = false;     // нажат в этом кадре
  released = false;

  constructor(private canvas: HTMLCanvasElement) {
    canvas.style.touchAction = 'none';            // без скролла и зума на мобильных
    canvas.addEventListener('pointerdown', this.onDown);
    canvas.addEventListener('pointermove', this.onMove);
    canvas.addEventListener('pointerup', this.onUp);
    canvas.addEventListener('pointercancel', this.onUp);
    canvas.addEventListener('contextmenu', (e) => e.preventDefault()); // ПКМ без меню
  }

  private update(e: PointerEvent) {
    const r = this.canvas.getBoundingClientRect();
    this.x = ((e.clientX - r.left) / r.width) * GAME_W;
    this.y = ((e.clientY - r.top) / r.height) * GAME_H;
  }

  private onDown = (e: PointerEvent) => {
    this.canvas.setPointerCapture(e.pointerId); // события придут, даже если ушли за canvas
    this.update(e);
    this.isDown = true;
    this.pressed = true;
  };
  private onMove = (e: PointerEvent) => this.update(e);
  private onUp = (e: PointerEvent) => {
    this.update(e);
    this.isDown = false;
    this.released = true;
  };

  endFrame() { this.pressed = this.released = false; }
}
```

`setPointerCapture` нужен для перетаскивания: если игрок увёл палец за край canvas, `pointerup` всё равно придёт.

## Использование

```ts
const pointer = new Pointer(canvas);

function update(dt: number) {
  // пушка следит за курсором
  turret.angle = Math.atan2(pointer.y - turret.y, pointer.x - turret.x);

  if (pointer.pressed) shoot(turret.angle);
  // или автоогонь при удержании:
  if (pointer.isDown && cooldown <= 0) shoot(turret.angle);
}
```

## Мультитач: виртуальный джойстик

```ts
const touches = new Map<number, { x: number; y: number; startX: number; startY: number }>();

canvas.addEventListener('pointerdown', (e) => {
  const p = toGame(e);
  touches.set(e.pointerId, { ...p, startX: p.x, startY: p.y });
});
canvas.addEventListener('pointermove', (e) => {
  const t = touches.get(e.pointerId);
  if (t) Object.assign(t, toGame(e));
});
canvas.addEventListener('pointerup', (e) => touches.delete(e.pointerId));

function joystick() {
  // первый палец в левой половине экрана — джойстик
  for (const t of touches.values()) {
    if (t.startX < GAME_W / 2) {
      const dx = t.x - t.startX, dy = t.y - t.startY;
      const len = Math.hypot(dx, dy);
      const max = 30;
      return len > 5 ? { x: dx / Math.max(len, max), y: dy / Math.max(len, max) } : { x: 0, y: 0 };
    }
  }
  return { x: 0, y: 0 };
}
```

## Pointer Lock для шутеров

```ts
canvas.addEventListener('click', () => canvas.requestPointerLock());

document.addEventListener('pointerlockchange', () => {
  locked = document.pointerLockElement === canvas;
});

document.addEventListener('mousemove', (e) => {
  if (!locked) return;
  camera.yaw -= e.movementX * 0.002;    // относительное смещение, курсор не упирается в край
  camera.pitch -= e.movementY * 0.002;
});
```

Захват курсора возможен только по жесту пользователя (клику), выход — `Esc`.

## Колесо мыши

```ts
canvas.addEventListener('wheel', (e) => {
  e.preventDefault();
  camera.zoom *= e.deltaY > 0 ? 0.9 : 1.1;
}, { passive: false });        // passive: false — иначе preventDefault не сработает
```

## Частые ошибки

- Использовать `e.offsetX` или `clientX` напрямую, не учитывая масштаб canvas, — клик «промахивается» на ресайзнутом холсте.
- Забыть `touch-action: none` — на телефоне вместо управления скроллится страница.
- Обрабатывать отдельно `mouse*` и `touch*` и получать двойные события на мобильных.
- Не учитывать камеру при выборе объекта в мире.
- Не обрабатывать `pointercancel` — палец «залипает» при системном жесте.

## Что важно помнить

- Pointer Events — единый API для мыши, касаний и пера.
- Координаты: `clientX - rect.left`, затем масштаб к размеру игры, затем камера.
- `touch-action: none` и `setPointerCapture` для мобильных и перетаскивания.
- Мультитач различают по `pointerId`.
- Pointer Lock — для управления камерой мышью.

## Мини-шпаргалка

```ts
const r = canvas.getBoundingClientRect();
const x = (e.clientX - r.left) * (canvas.width / r.width);
canvas.style.touchAction = 'none';
canvas.setPointerCapture(e.pointerId);
canvas.requestPointerLock(); // e.movementX
```
