# Задача: todo-лист

> [!NOTE]
> **Todo-лист** — самая частая практическая задача на React: добавить, отметить выполненной, удалить, отфильтровать (все / активные / выполненные), показать счетчик, иногда — редактирование и сохранение в `localStorage`. На ней проверяют базу: **иммутабельные обновления** массива, **стабильные `key`**, управляемые поля и форму, **производные данные** без дублирования state, разбиение на компоненты и доступность. Логику удобно вынести в `useReducer`.

## Вопрос

Напишите todo-лист на React: добавление (Enter и кнопка), переключение, удаление, фильтр, счетчик активных, очистка выполненных. Объясните, где хранить state и почему фильтрованный список не нужно хранить отдельно.

## Решение

```tsx
import { useMemo, useReducer, useState, type FormEvent } from "react";

type Todo = { id: string; text: string; done: boolean };
type Filter = "all" | "active" | "done";

type Action =
  | { type: "added"; text: string }
  | { type: "toggled"; id: string }
  | { type: "removed"; id: string }
  | { type: "edited"; id: string; text: string }
  | { type: "clearedDone" };

function todosReducer(todos: Todo[], action: Action): Todo[] {
  switch (action.type) {
    case "added":
      return [...todos, { id: crypto.randomUUID(), text: action.text, done: false }];
    case "toggled":
      return todos.map((t) => (t.id === action.id ? { ...t, done: !t.done } : t));
    case "removed":
      return todos.filter((t) => t.id !== action.id);
    case "edited":
      return todos.map((t) => (t.id === action.id ? { ...t, text: action.text } : t));
    case "clearedDone":
      return todos.filter((t) => !t.done);
  }
}

export function TodoApp() {
  const [todos, dispatch] = useReducer(todosReducer, []);
  const [filter, setFilter] = useState<Filter>("all");
  const [text, setText] = useState("");

  const visible = useMemo(                       // производные данные — вычисляем, не храним
    () => todos.filter((t) => (filter === "all" ? true : filter === "done" ? t.done : !t.done)),
    [todos, filter],
  );
  const activeCount = todos.filter((t) => !t.done).length;

  function handleSubmit(e: FormEvent) {
    e.preventDefault();
    const value = text.trim();
    if (!value) return;
    dispatch({ type: "added", text: value });
    setText("");
  }

  return (
    <section aria-labelledby="todo-title">
      <h1 id="todo-title">Задачи</h1>

      <form onSubmit={handleSubmit}>
        <label htmlFor="new-todo" className="visually-hidden">Новая задача</label>
        <input id="new-todo" value={text} onChange={(e) => setText(e.target.value)} placeholder="Что сделать?" />
        <button type="submit" disabled={!text.trim()}>Добавить</button>
      </form>

      <ul>
        {visible.map((todo) => (
          <TodoItem key={todo.id} todo={todo} dispatch={dispatch} />
        ))}
      </ul>

      {todos.length === 0 && <p>Задач пока нет</p>}

      <footer>
        <span role="status">Осталось: {activeCount}</span>
        <fieldset>
          <legend className="visually-hidden">Фильтр</legend>
          {(["all", "active", "done"] as const).map((f) => (
            <button key={f} type="button" aria-pressed={filter === f} onClick={() => setFilter(f)}>
              {{ all: "Все", active: "Активные", done: "Выполненные" }[f]}
            </button>
          ))}
        </fieldset>
        <button type="button" onClick={() => dispatch({ type: "clearedDone" })} disabled={activeCount === todos.length}>
          Очистить выполненные
        </button>
      </footer>
    </section>
  );
}

function TodoItem({ todo, dispatch }: { todo: Todo; dispatch: React.Dispatch<Action> }) {
  return (
    <li>
      <label>
        <input type="checkbox" checked={todo.done} onChange={() => dispatch({ type: "toggled", id: todo.id })} />
        <span style={{ textDecoration: todo.done ? "line-through" : "none" }}>{todo.text}</span>
      </label>
      <button type="button" onClick={() => dispatch({ type: "removed", id: todo.id })} aria-label={`Удалить «${todo.text}»`}>
        ×
      </button>
    </li>
  );
}
```

## Ключевые решения

| Решение | Почему |
| --- | --- |
| `useReducer` | логика обновлений в одном месте, легко тестировать чистую функцию |
| иммутабельные `map`/`filter`/spread | React сравнивает по ссылке; мутация не вызовет ререндер |
| `key={todo.id}`, а не индекс | при удалении и фильтре индексы смещаются — состояние чекбоксов «переедет» |
| `visible` вычисляется | отдельный state для фильтрованного списка рассинхронизируется |
| `<form onSubmit>` | Enter работает сам, доступно с клавиатуры |
| `aria-pressed`, `aria-label` | понятно скринридеру, какой фильтр активен и что удаляет кнопка |

## Расширения

- **Сохранение:** `useReducer(todosReducer, [], () => loadFromStorage())` + `useEffect` записи или хук `useLocalStorage`.
- **Редактирование по двойному клику:** локальный state `editing`, `onBlur`/Enter сохраняет, Escape отменяет.
- **Синхронизация с сервером:** оптимистичное добавление с временным id, откат при ошибке.
- **Перетаскивание порядка:** `dnd-kit`, иммутабельный `move`.
- **Тесты:** RTL — ввести текст, нажать Enter, проверить появление элемента и счетчик.

## Что важно помнить

- Никогда не мутируйте state (`todos.push`).
- Не используйте индекс как `key`, если список меняется.
- Не храните то, что можно вычислить: отфильтрованный список и счетчики.
- Пустое состояние и отключенные кнопки — признак продуманного UI.

## Мини-шпаргалка

`useReducer` с actions added/toggled/removed/edited/clearedDone, иммутабельные обновления. `key={id}`. Фильтр и счетчик — вычислять (`useMemo`). Форма с `onSubmit`, `trim`, очистка поля. a11y: label, `aria-pressed`, `aria-label` у иконок, `role="status"` для счетчика.
