# Задача: useOnClickOutside и useEventListener

> [!NOTE]
> **`useEventListener(event, handler, target)`** подписывается на событие и автоматически отписывается при размонтировании, а последняя версия обработчика хранится в `ref`, чтобы не переподписываться на каждый рендер. **`useOnClickOutside(ref, handler)`** вызывает `handler`, когда пользователь нажал **вне** элемента — для закрытия выпадающих меню, поповеров и модалок. Детали: проверка через `ref.current.contains(event.target)`, событие `pointerdown` вместо `click`, обработка тач-устройств и закрытие по `Escape`.

## Вопрос

Реализуйте хуки `useEventListener` и `useOnClickOutside` и используйте их в выпадающем меню, которое закрывается по клику снаружи и по клавише Escape.

## useEventListener

```tsx
import { useEffect, useRef } from "react";

export function useEventListener<K extends keyof WindowEventMap>(
  eventName: K,
  handler: (event: WindowEventMap[K]) => void,
  target: Window | Document | HTMLElement | null = typeof window !== "undefined" ? window : null,
  options?: AddEventListenerOptions,
) {
  const handlerRef = useRef(handler);

  useEffect(() => {
    handlerRef.current = handler;                     // свежий обработчик без переподписки
  });

  useEffect(() => {
    if (!target) return;
    const listener = (event: Event) => handlerRef.current(event as WindowEventMap[K]);
    target.addEventListener(eventName, listener, options);
    return () => target.removeEventListener(eventName, listener, options);
    // options сравнивается по ссылке — передавайте стабильный объект
  }, [eventName, target, options]);
}
```

## useOnClickOutside

```tsx
import { useEffect, useRef, type RefObject } from "react";

export function useOnClickOutside<T extends HTMLElement>(
  ref: RefObject<T | null>,
  handler: (event: PointerEvent) => void,
  enabled = true,
) {
  const handlerRef = useRef(handler);
  useEffect(() => { handlerRef.current = handler; });

  useEffect(() => {
    if (!enabled) return;
    function onPointerDown(event: PointerEvent) {
      const el = ref.current;
      if (!el || el.contains(event.target as Node)) return;   // клик внутри — игнорируем
      handlerRef.current(event);
    }
    document.addEventListener("pointerdown", onPointerDown);
    return () => document.removeEventListener("pointerdown", onPointerDown);
  }, [ref, enabled]);
}
```

`pointerdown` срабатывает для мыши, касания и пера и раньше, чем `click`, — меню закроется до того, как клик дойдет до элемента под ним.

## Выпадающее меню

```tsx
function Dropdown() {
  const [open, setOpen] = useState(false);
  const rootRef = useRef<HTMLDivElement>(null);
  const buttonRef = useRef<HTMLButtonElement>(null);

  useOnClickOutside(rootRef, () => setOpen(false), open);

  useEventListener("keydown", (e) => {
    if (open && e.key === "Escape") {
      setOpen(false);
      buttonRef.current?.focus();                  // вернуть фокус на кнопку
    }
  });

  return (
    <div ref={rootRef} className="dropdown">
      <button ref={buttonRef} aria-haspopup="menu" aria-expanded={open} onClick={() => setOpen((o) => !o)}>
        Действия
      </button>
      {open && (
        <ul role="menu">
          <li role="menuitem"><button onClick={() => setOpen(false)}>Переименовать</button></li>
          <li role="menuitem"><button onClick={() => setOpen(false)}>Удалить</button></li>
        </ul>
      )}
    </div>
  );
}
```

Кнопка-триггер внутри `rootRef`, поэтому клик по ней не считается «снаружи» и не конфликтует с `onClick`.

## Тонкие моменты

| Ситуация | Что учесть |
| --- | --- |
| Меню отрисовано через портал | `contains` не найдет его внутри `rootRef` — проверять оба узла (триггер и портал) |
| Несколько вложенных поповеров | закрывать только верхний (стек слоев) |
| Клик по скроллбару или вне окна | `pointerdown` на `document` не всегда приходит — это нормально |
| iframe внутри страницы | клики в iframe не всплывают в документ — слушать `blur` окна |
| Перетаскивание из меню наружу | сравнить, где начался `pointerdown`, а не где закончился `pointerup` |

## Доп. вопросы интервьюера

- **Зачем `handlerRef`?** чтобы не переподписываться при каждом рендере из-за новой функции-обработчика и при этом вызывать свежую версию.
- **Почему проверка `contains`, а не `stopPropagation` внутри меню?** `stopPropagation` ломает другие обработчики и делегирование.
- **Как сделать доступным?** Escape, возврат фокуса, `aria-expanded`, навигация стрелками для `role="menu"`; надежнее — headless-библиотека (Radix, React Aria).

## Что важно помнить

- Всегда отписывайтесь в cleanup.
- Обработчик храните в `ref` — эффект подписки зависит только от события и цели.
- Используйте `pointerdown` для поддержки тач-устройств.
- Связанные задачи: [модальное окно через портал](<06. Задача - модальное окно через портал.md>), [делегирование событий](<../07. DOM и браузер/01. Задача - делегирование событий.md>).

## Мини-шпаргалка

useEventListener: `handlerRef` + `addEventListener` в эффекте с зависимостями `[event, target]` + отписка. useOnClickOutside: `pointerdown` на `document`, `ref.current.contains(target)` → игнор, иначе handler; флаг `enabled`. Меню: закрыть снаружи и по Escape, вернуть фокус, учитывать порталы.
