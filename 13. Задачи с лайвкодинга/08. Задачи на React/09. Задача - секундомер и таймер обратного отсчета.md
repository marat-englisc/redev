# Задача: секундомер и таймер обратного отсчета

> [!NOTE]
> **Секундомер** (старт, пауза, сброс, круги) и **таймер обратного отсчета** проверяют работу с временем и эффектами в React. Главная идея правильного решения: **не считать тики**, а хранить **момент старта** и вычислять прошедшее время как `Date.now() - startedAt`. Интервал нужен только для перерисовки; он может задерживаться (фоновая вкладка, загруженный поток), а вычисление от метки времени остается точным. Обязательно — очистка интервала и форматирование `мм:сс.мс`.

## Вопрос

Реализуйте компонент секундомера со стартом, паузой, сбросом и кругами. Почему нельзя просто увеличивать счетчик в `setInterval` каждые 10 мс? Как сделать таймер обратного отсчета, который точно закончится вовремя?

## Секундомер

```tsx
import { useEffect, useRef, useState } from "react";

function format(ms: number) {
  const minutes = Math.floor(ms / 60000);
  const seconds = Math.floor((ms % 60000) / 1000);
  const centiseconds = Math.floor((ms % 1000) / 10);
  const pad = (n: number) => String(n).padStart(2, "0");
  return `${pad(minutes)}:${pad(seconds)}.${pad(centiseconds)}`;
}

export function Stopwatch() {
  const [elapsed, setElapsed] = useState(0);           // накопленное время при паузе
  const [running, setRunning] = useState(false);
  const [laps, setLaps] = useState<number[]>([]);
  const startedAtRef = useRef(0);                      // момент последнего старта
  const [now, setNow] = useState(0);                   // для перерисовки

  useEffect(() => {
    if (!running) return;
    let frame = requestAnimationFrame(function tick() {
      setNow(performance.now());
      frame = requestAnimationFrame(tick);
    });
    return () => cancelAnimationFrame(frame);
  }, [running]);

  const total = running ? elapsed + (now - startedAtRef.current) : elapsed;

  function start() {
    startedAtRef.current = performance.now();
    setNow(startedAtRef.current);
    setRunning(true);
  }

  function pause() {
    setElapsed(total);                                 // зафиксировать прошедшее
    setRunning(false);
  }

  function reset() {
    setRunning(false);
    setElapsed(0);
    setLaps([]);
  }

  return (
    <div>
      <p role="timer" aria-live="off" style={{ fontVariantNumeric: "tabular-nums" }}>{format(Math.max(0, total))}</p>
      {running ? <button onClick={pause}>Пауза</button> : <button onClick={start}>{elapsed ? "Продолжить" : "Старт"}</button>}
      <button onClick={() => setLaps((l) => [total, ...l])} disabled={!running}>Круг</button>
      <button onClick={reset} disabled={running || elapsed === 0}>Сброс</button>
      <ol>{laps.map((lap, i) => <li key={laps.length - i}>{format(lap)}</li>)}</ol>
    </div>
  );
}
```

- время считается от `performance.now()` — монотонные часы, не зависят от перевода системного времени;
- `requestAnimationFrame` обновляет экран раз в кадр и автоматически замирает в фоновой вкладке, а время при возвращении все равно будет верным;
- `tabular-nums` — цифры одинаковой ширины, текст не «прыгает».

## Почему не счетчик тиков

```tsx
useEffect(() => {
  const id = setInterval(() => setMs((m) => m + 10), 10);   // плохо
  return () => clearInterval(id);
}, []);
```

- браузер не гарантирует интервал 10 мс: задержки накапливаются, через минуту секундомер отстанет на секунды;
- в фоновой вкладке таймеры замедляются до раза в секунду и реже;
- 100 ререндеров в секунду без необходимости.

## Таймер обратного отсчета

```tsx
export function useCountdown(durationMs: number, onComplete?: () => void) {
  const [endAt, setEndAt] = useState<number | null>(null);
  const [left, setLeft] = useState(durationMs);
  const onCompleteRef = useRef(onComplete);
  useEffect(() => { onCompleteRef.current = onComplete; });

  useEffect(() => {
    if (endAt === null) return;
    const id = setInterval(() => {
      const remaining = Math.max(0, endAt - Date.now());   // от конечного момента
      setLeft(remaining);
      if (remaining === 0) {
        clearInterval(id);
        setEndAt(null);
        onCompleteRef.current?.();
      }
    }, 250);
    return () => clearInterval(id);
  }, [endAt]);

  return {
    left,
    running: endAt !== null,
    start: () => setEndAt(Date.now() + left),
    pause: () => setEndAt(null),
    reset: () => { setEndAt(null); setLeft(durationMs); },
  };
}

function Pomodoro() {
  const { left, running, start, pause, reset } = useCountdown(25 * 60 * 1000, () => new Notification("Перерыв!"));
  const totalSeconds = Math.ceil(left / 1000);              // 59,5 с → 60 → «01:00»
  const mm = String(Math.floor(totalSeconds / 60)).padStart(2, "0");
  const ss = String(totalSeconds % 60).padStart(2, "0");
  return (
    <>
      <p role="timer">{mm}:{ss}</p>
      <button onClick={running ? pause : start}>{running ? "Пауза" : "Старт"}</button>
      <button onClick={reset}>Сброс</button>
    </>
  );
}
```

Если таймер должен пережить перезагрузку страницы, храните `endAt` в `localStorage`.

## Доп. вопросы интервьюера

- **`Date.now()` или `performance.now()`?** `performance.now()` монотонный и точнее для измерения интервалов; `Date.now()` нужен для абсолютного времени (сохранение, сервер).
- **Как протестировать?** fake timers и мок `performance.now`/`Date.now` (`vi.setSystemTime`).
- **Доступность?** `role="timer"` с `aria-live="off"` — не зачитывать каждое изменение; объявить только завершение.

## Что важно помнить

- Время — от метки старта или окончания, интервал — только для перерисовки.
- Всегда очищайте интервал и кадр анимации в cleanup.
- Колбэк завершения храните в `ref`, чтобы не перезапускать эффект.
- Связанные задачи: [useInterval](<02. Задача - usePrevious, useToggle и useInterval.md>), [requestAnimationFrame](<../../04. JavaScript/05. Асинхронность и Event Loop/10. Что делает requestAnimationFrame().md>).

## Мини-шпаргалка

Хранить `startedAt`/`endAt` и накопленное время, показывать `now - startedAt`. Перерисовка — rAF или интервал с очисткой. Пауза — зафиксировать `elapsed`. Не суммировать тики: таймеры неточны и замедляются в фоне. `performance.now()` для интервалов, `tabular-nums` для цифр.
