# Задача: модальное окно через портал

> [!NOTE]
> **Портал** (`createPortal(children, domNode)`) рендерит JSX в другой DOM-узел — обычно в конец `document.body`, — но компонент остается в **React-дереве** на прежнем месте: контекст, события и состояние работают как обычно. Модалку выносят в портал, чтобы ее не обрезал `overflow: hidden` и не перекрывал `z-index`/stacking context родителя. Хорошая модалка: закрытие по Escape и клику на фон, **ловушка фокуса**, возврат фокуса на кнопку открытия, блокировка прокрутки страницы, `role="dialog"` и `aria-modal`. Современная альтернатива — нативный `<dialog>` с `showModal()`.

## Вопрос

Реализуйте компонент `Modal` с `createPortal`: открытие и закрытие, Escape и клик по фону, фокус внутри модалки, возврат фокуса, блокировка прокрутки и доступная разметка. Чем портал отличается от обычного рендера?

## Решение

```tsx
import { useEffect, useId, useRef, type ReactNode } from "react";
import { createPortal } from "react-dom";

type ModalProps = {
  open: boolean;
  onClose: () => void;
  title: string;
  children: ReactNode;
};

export function Modal({ open, onClose, title, children }: ModalProps) {
  const dialogRef = useRef<HTMLDivElement>(null);
  const titleId = useId();

  useEffect(() => {
    if (!open) return;
    const previouslyFocused = document.activeElement as HTMLElement | null;
    const { overflow } = document.body.style;
    document.body.style.overflow = "hidden";                // блокировать прокрутку страницы

    const dialog = dialogRef.current!;
    const focusable = () =>
      dialog.querySelectorAll<HTMLElement>(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])',
      );
    (focusable()[0] ?? dialog).focus();                    // фокус внутрь

    function onKeyDown(e: KeyboardEvent) {
      if (e.key === "Escape") onClose();
      if (e.key === "Tab") {                               // ловушка фокуса
        const items = [...focusable()];
        if (items.length === 0) return e.preventDefault();
        const first = items[0], last = items[items.length - 1];
        if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
        else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
      }
    }

    document.addEventListener("keydown", onKeyDown);
    return () => {
      document.removeEventListener("keydown", onKeyDown);
      document.body.style.overflow = overflow;
      previouslyFocused?.focus();                          // вернуть фокус
    };
  }, [open, onClose]);

  if (!open) return null;

  return createPortal(
    <div className="modal-backdrop" onMouseDown={(e) => e.target === e.currentTarget && onClose()}>
      <div ref={dialogRef} role="dialog" aria-modal="true" aria-labelledby={titleId} tabIndex={-1} className="modal">
        <h2 id={titleId}>{title}</h2>
        {children}
        <button type="button" onClick={onClose} aria-label="Закрыть">×</button>
      </div>
    </div>,
    document.body,
  );
}
```

```css
.modal-backdrop { position: fixed; inset: 0; display: grid; place-items: center; background: rgb(0 0 0 / 0.5); }
.modal { background: var(--color-bg); padding: 24px; border-radius: 12px; max-inline-size: min(90vw, 480px); }
```

## Использование

```tsx
function DeleteProject({ onDelete }: { onDelete: () => void }) {
  const [open, setOpen] = useState(false);
  const close = useCallback(() => setOpen(false), []);   // стабильный onClose — эффект не перезапускается

  return (
    <>
      <button onClick={() => setOpen(true)}>Удалить проект</button>
      <Modal open={open} onClose={close} title="Удалить проект?">
        <p>Действие нельзя отменить.</p>
        <button onClick={close}>Отмена</button>
        <button onClick={() => { onDelete(); close(); }}>Удалить</button>
      </Modal>
    </>
  );
}
```

## Что важно знать про порталы

| Аспект | Поведение |
| --- | --- |
| Где в DOM | в указанном узле (`document.body`) |
| Где в React-дереве | на месте вызова: контекст, Suspense и Error Boundary родителя работают |
| События | **всплывают по React-дереву**, а не по DOM: `onClick` родителя-компонента получит клик из модалки |
| SSR | `document` нет на сервере — рендерить портал после монтирования |
| Стили | не наследуют CSS-контекст родителя (`overflow`, `z-index`, `transform`) — в этом и смысл |

## Альтернатива: нативный dialog

```tsx
function NativeModal({ open, onClose, children }: { open: boolean; onClose: () => void; children: ReactNode }) {
  const ref = useRef<HTMLDialogElement>(null);

  useEffect(() => {
    const dialog = ref.current!;
    if (open && !dialog.open) dialog.showModal();          // top layer, ловушка фокуса, Escape — встроены
    if (!open && dialog.open) dialog.close();
  }, [open]);

  return (
    <dialog ref={ref} onClose={onClose} onClick={(e) => e.target === ref.current && onClose()}>
      {children}
    </dialog>
  );
}
```

`showModal()` выводит диалог в **top layer** — поверх всего, без `z-index`, делает остальную страницу инертной и закрывается по Escape.

## Доп. вопросы интервьюера

- **Зачем портал, если есть `position: fixed`?** родитель с `transform`, `filter` или `overflow: hidden` ломает `fixed` и обрезает содержимое; stacking context родителя ограничивает `z-index`.
- **Почему `onMouseDown` на фоне, а не `onClick`?** если пользователь начал выделять текст внутри модалки и отпустил мышь на фоне, `click` закрыл бы модалку.
- **Как сделать остальную страницу недоступной для скринридера?** `aria-modal="true"`, атрибут `inert` на основном контенте или нативный `<dialog>`.
- **Несколько модалок одновременно?** стек модалок; Escape закрывает верхнюю.

## Что важно помнить

- Портал меняет место в DOM, но не в React-дереве.
- Обязательный минимум доступности: `role="dialog"`, `aria-modal`, заголовок через `aria-labelledby`, фокус внутрь и обратно, Escape.
- Передавайте стабильный `onClose` (`useCallback`), иначе эффект будет перезапускаться и сбрасывать фокус.
- В production удобнее Radix Dialog, React Aria или нативный `<dialog>`.
- Связанные темы: [stacking context и z-index](<../../03. CSS/05. Позиционирование элементов/06. Что делает свойство z-index.md>), [доступность](<../../11. Frontend System Design/03. Нефункциональные требования/04. Как учесть доступность и интернационализацию.md>).

## Мини-шпаргалка

`createPortal(jsx, document.body)` — DOM в другом месте, React-дерево прежнее (контекст и события работают). Модалка: Escape, клик по фону (`mousedown` на самом фоне), фокус внутрь + Tab-ловушка, возврат фокуса, `overflow: hidden` на body, `role="dialog"` + `aria-modal` + `aria-labelledby`. Альтернатива — `<dialog>.showModal()`.
