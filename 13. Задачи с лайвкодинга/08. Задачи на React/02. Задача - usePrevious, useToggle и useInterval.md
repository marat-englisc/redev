# Задача: usePrevious, useToggle и useInterval

> [!NOTE]
> Три небольших хука, которые часто просят написать для разминки. **`usePrevious(value)`** возвращает значение из **предыдущего рендера** — через `useRef`, обновляемый в эффекте. **`useToggle(initial)`** возвращает булево состояние и стабильную функцию переключения. **`useInterval(callback, delay)`** — правильный интервал в React: колбэк хранится в `ref`, чтобы интервал видел **свежие** props и state, а `delay = null` ставит интервал на паузу. Главная ловушка `setInterval` в React — устаревшее замыкание.

## Вопрос

Реализуйте `usePrevious`, `useToggle` и `useInterval`. Почему `setInterval` внутри `useEffect` с пустыми зависимостями «застревает» на старом значении state?

## usePrevious

```tsx
import { useEffect, useRef } from "react";

export function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T | undefined>(undefined);
  useEffect(() => {
    ref.current = value;                // после рендера запоминаем текущее значение
  }, [value]);
  return ref.current;                   // во время рендера ref еще хранит предыдущее
}
```

```tsx
function Price({ value }: { value: number }) {
  const prev = usePrevious(value);
  const trend = prev === undefined ? "" : value > prev ? "▲" : value < prev ? "▼" : "";
  return <span>{value} ₽ {trend}</span>;
}
```

Вариант без эффекта (рекомендуемый в документации React для производных данных) — хранить предыдущее значение в state и сравнивать при рендере:

```tsx
const [prev, setPrev] = useState(value);
if (value !== prev) setPrev(value);   // React перерендерит сразу, до отрисовки
```

## useToggle

```tsx
import { useCallback, useState } from "react";

export function useToggle(initial = false) {
  const [value, setValue] = useState(initial);
  const toggle = useCallback(() => setValue((v) => !v), []);   // стабильная функция
  return [value, toggle, setValue] as const;
}

function Faq() {
  const [open, toggle] = useToggle();
  return (
    <>
      <button aria-expanded={open} onClick={toggle}>Как вернуть товар?</button>
      {open && <p>В течение 14 дней…</p>}
    </>
  );
}
```

`as const` дает кортеж с точными типами вместо массива `(boolean | Function)[]`.

## useInterval

Проблема:

```tsx
function BadCounter() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    const id = setInterval(() => setCount(count + 1), 1000);   // count всегда 0 — замыкание первого рендера
    return () => clearInterval(id);
  }, []);
  return <p>{count}</p>;   // 0 → 1 → 1 → 1…
}
```

Решение:

```tsx
import { useEffect, useRef } from "react";

export function useInterval(callback: () => void, delay: number | null) {
  const savedCallback = useRef(callback);

  useEffect(() => {
    savedCallback.current = callback;      // последняя версия колбэка со свежими state и props
  }, [callback]);

  useEffect(() => {
    if (delay === null) return;            // пауза
    const id = setInterval(() => savedCallback.current(), delay);
    return () => clearInterval(id);
  }, [delay]);                             // интервал пересоздается только при смене delay
}

function Counter() {
  const [count, setCount] = useState(0);
  const [running, setRunning] = useState(true);
  useInterval(() => setCount(count + 1), running ? 1000 : null);

  return (
    <>
      <p>{count}</p>
      <button onClick={() => setRunning((r) => !r)}>{running ? "Пауза" : "Старт"}</button>
    </>
  );
}
```

Для простого счетчика достаточно функционального обновления `setCount((c) => c + 1)`, но `useInterval` нужен, когда колбэк читает props и state.

## Доп. вопросы интервьюера

- **Почему в `usePrevious` используется `useRef`, а не `useState`?** изменение ref не вызывает ререндер — нам нужно только «запомнить».
- **Что вернет `usePrevious` на первом рендере?** `undefined`.
- **`setTimeout` вместо `setInterval`?** рекурсивный `setTimeout` не накапливает вызовы, если колбэк долгий.
- **Как протестировать `useInterval`?** fake timers + `renderHook` + `act`.

## Что важно помнить

- Устаревшее замыкание — главная проблема таймеров в React: решают через `ref` или функциональное обновление.
- Всегда очищайте интервал в cleanup.
- Стабильные функции из хуков (`useCallback`) не ломают `memo` и зависимости.
- Теория: [useRef](<../../06. React/04. Хуки/08. useRef - доступ к DOM и хранение значений между рендерами.md>), [кастомные хуки](<../../06. React/04. Хуки/21. Кастомные хуки - что это и как создать свой хук.md>).

## Мини-шпаргалка

usePrevious: `ref.current = value` в эффекте, вернуть `ref.current` в рендере. useToggle: `useState` + `useCallback(() => set(v => !v))`, `as const`. useInterval: колбэк в `ref`, `setInterval(() => ref.current())`, зависимость только `delay`, `null` — пауза.
