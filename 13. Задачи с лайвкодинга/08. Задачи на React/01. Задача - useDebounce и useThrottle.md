# Задача: useDebounce и useThrottle

> [!NOTE]
> Два варианта задачи. **`useDebouncedValue(value, delay)`** возвращает значение, которое обновляется только после паузы в изменениях — удобно для поиска: запрос зависит от отложенного значения. **`useDebouncedCallback(fn, delay)`** возвращает стабильную функцию-обертку, которая вызывает **актуальную** версию `fn` после паузы и отменяется при размонтировании. Ключевые детали: очистка таймера в cleanup эффекта, хранение последней версии колбэка в `ref` и стабильная ссылка через `useMemo`/`useCallback`.

## Вопрос

Реализуйте хуки `useDebouncedValue(value, delay)` и `useDebouncedCallback(callback, delay)`. Почему debounce, созданный прямо в теле компонента, не работает? Как сделать `useThrottle`?

## useDebouncedValue

```tsx
import { useEffect, useState } from "react";

export function useDebouncedValue<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);          // новое значение или размонтирование отменяют таймер
  }, [value, delay]);

  return debounced;
}
```

```tsx
function Search() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebouncedValue(query, 400);
  const { data } = useQuery({
    queryKey: ["search", debouncedQuery],
    queryFn: ({ signal }) => api.search(debouncedQuery, { signal }),
    enabled: debouncedQuery.length > 1,
  });

  return (
    <>
      <input value={query} onChange={(e) => setQuery(e.target.value)} aria-label="Поиск" />
      <Results items={data ?? []} />
    </>
  );
}
```

Поле обновляется мгновенно, а запрос уходит через 400 мс после остановки ввода.

## useDebouncedCallback

```tsx
import { useEffect, useMemo, useRef } from "react";

export function useDebouncedCallback<A extends unknown[]>(callback: (...args: A) => void, delay = 300) {
  const callbackRef = useRef(callback);
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

  useEffect(() => {
    callbackRef.current = callback;           // всегда последняя версия — без устаревших замыканий
  });

  useEffect(() => () => {
    if (timerRef.current) clearTimeout(timerRef.current);   // отмена при размонтировании
  }, []);

  return useMemo(() => {
    const debounced = (...args: A) => {
      if (timerRef.current) clearTimeout(timerRef.current);
      timerRef.current = setTimeout(() => callbackRef.current(...args), delay);
    };
    debounced.cancel = () => {
      if (timerRef.current) clearTimeout(timerRef.current);
    };
    return debounced;
  }, [delay]);                                // стабильная ссылка между рендерами
}
```

```tsx
function Editor({ docId }: { docId: string }) {
  const [text, setText] = useState("");
  const save = useDebouncedCallback((value: string) => api.saveDraft(docId, value), 1000);

  return <textarea value={text} onChange={(e) => { setText(e.target.value); save(e.target.value); }} />;
}
```

## Почему не работает «просто debounce»

```tsx
function Bad() {
  const [q, setQ] = useState("");
  const search = debounce((v: string) => api.search(v), 300);   // новый debounce на каждый рендер!
  return <input value={q} onChange={(e) => { setQ(e.target.value); search(e.target.value); }} />;
}
```

`setQ` вызывает ререндер, создается новая функция со своим таймером — старые таймеры не отменяются, и запросы уходят на каждый символ. Обертку нужно создавать один раз (`useMemo`, `useRef`) и чистить при размонтировании.

## useThrottledCallback

```tsx
export function useThrottledCallback<A extends unknown[]>(callback: (...args: A) => void, interval = 200) {
  const callbackRef = useRef(callback);
  const lastRef = useRef(0);
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

  useEffect(() => { callbackRef.current = callback; });
  useEffect(() => () => { if (timerRef.current) clearTimeout(timerRef.current); }, []);

  return useMemo(() => (...args: A) => {
    const now = Date.now();
    const remaining = interval - (now - lastRef.current);
    if (remaining <= 0) {
      lastRef.current = now;
      callbackRef.current(...args);
    } else {
      if (timerRef.current) clearTimeout(timerRef.current);
      timerRef.current = setTimeout(() => {          // trailing-вызов в конце окна
        lastRef.current = Date.now();
        callbackRef.current(...args);
      }, remaining);
    }
  }, [interval]);
}
```

## Доп. вопросы интервьюера

- **Значение или колбэк?** значение — когда от него зависит запрос или вычисление; колбэк — для действий (автосохранение, аналитика).
- **Чем отличается от `useDeferredValue`?** `useDeferredValue` не задерживает на фиксированное время и не уменьшает число запросов — он откладывает тяжелый рендер.
- **Как протестировать?** `vi.useFakeTimers()`, `renderHook`, `act(() => vi.advanceTimersByTime(300))`.

## Что важно помнить

- Очищайте таймер в cleanup — иначе вызов после размонтирования.
- Храните последнюю версию колбэка в `ref`, чтобы не было устаревших замыканий и не пересоздавать обертку.
- Возвращайте стабильную функцию — ее можно передавать в `memo`-компоненты и зависимости.
- Базовые задачи: [debounce](<../02. Функции и замыкания/01. Задача - debounce.md>), [throttle](<../02. Функции и замыкания/02. Задача - throttle.md>).

## Мини-шпаргалка

`useDebouncedValue`: `useEffect` с `setTimeout(setDebounced)` и `clearTimeout` в cleanup. `useDebouncedCallback`: `callbackRef` с последней версией, `timerRef`, `useMemo` для стабильной обертки, очистка при размонтировании. Не создавать debounce в теле компонента.
