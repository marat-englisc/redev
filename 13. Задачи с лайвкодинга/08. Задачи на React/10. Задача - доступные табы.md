# Задача: доступные табы

> [!NOTE]
> **Табы** — задача на проектирование переиспользуемого компонента: API через **compound components** (`<Tabs>`, `<Tabs.List>`, `<Tabs.Tab>`, `<Tabs.Panel>`) с общим состоянием в контексте, **controlled и uncontrolled** режимы (`value`/`onChange` или `defaultValue`) и доступность по паттерну WAI-ARIA: роли `tablist`/`tab`/`tabpanel`, связи `aria-controls`/`aria-labelledby`, **roving tabindex** (в табах Tab-ом попадаешь только в активную вкладку, а между вкладками двигаешься стрелками), клавиши Home и End.

## Вопрос

Реализуйте компонент табов с API на compound components, поддержкой controlled и uncontrolled режимов и полной клавиатурной доступностью.

## Решение

```tsx
import { createContext, useContext, useId, useRef, useState, type ReactNode, type KeyboardEvent } from "react";

type TabsContextValue = {
  value: string;
  setValue: (v: string) => void;
  baseId: string;
};

const TabsContext = createContext<TabsContextValue | null>(null);

function useTabs() {
  const ctx = useContext(TabsContext);
  if (!ctx) throw new Error("Компоненты Tabs.* должны быть внутри <Tabs>");
  return ctx;
}

type TabsProps = {
  value?: string;                       // controlled
  defaultValue?: string;                // uncontrolled
  onChange?: (value: string) => void;
  children: ReactNode;
};

export function Tabs({ value: controlled, defaultValue = "", onChange, children }: TabsProps) {
  const [inner, setInner] = useState(defaultValue);
  const isControlled = controlled !== undefined;
  const value = isControlled ? controlled : inner;
  const baseId = useId();

  const setValue = (next: string) => {
    if (!isControlled) setInner(next);
    onChange?.(next);
  };

  return <TabsContext value={{ value, setValue, baseId }}>{children}</TabsContext>;
}

function TabList({ label, children }: { label: string; children: ReactNode }) {
  const listRef = useRef<HTMLDivElement>(null);

  function onKeyDown(e: KeyboardEvent<HTMLDivElement>) {
    const tabs = [...(listRef.current?.querySelectorAll<HTMLButtonElement>('[role="tab"]:not([disabled])') ?? [])];
    const index = tabs.indexOf(document.activeElement as HTMLButtonElement);
    if (index === -1) return;

    const next =
      e.key === "ArrowRight" ? tabs[(index + 1) % tabs.length] :
      e.key === "ArrowLeft" ? tabs[(index - 1 + tabs.length) % tabs.length] :
      e.key === "Home" ? tabs[0] :
      e.key === "End" ? tabs[tabs.length - 1] : null;

    if (next) {
      e.preventDefault();
      next.focus();
      next.click();                     // автоматическая активация при перемещении
    }
  }

  return (
    <div ref={listRef} role="tablist" aria-label={label} onKeyDown={onKeyDown}>
      {children}
    </div>
  );
}

function Tab({ value, disabled, children }: { value: string; disabled?: boolean; children: ReactNode }) {
  const { value: active, setValue, baseId } = useTabs();
  const selected = active === value;
  return (
    <button
      type="button"
      role="tab"
      id={`${baseId}-tab-${value}`}
      aria-selected={selected}
      aria-controls={`${baseId}-panel-${value}`}
      tabIndex={selected ? 0 : -1}      // roving tabindex: в табах Tab-ом попадаешь только в активную
      disabled={disabled}
      onClick={() => setValue(value)}
    >
      {children}
    </button>
  );
}

function Panel({ value, children }: { value: string; children: ReactNode }) {
  const { value: active, baseId } = useTabs();
  if (active !== value) return null;
  return (
    <div role="tabpanel" id={`${baseId}-panel-${value}`} aria-labelledby={`${baseId}-tab-${value}`} tabIndex={0}>
      {children}
    </div>
  );
}

Tabs.List = TabList;
Tabs.Tab = Tab;
Tabs.Panel = Panel;
```

## Использование

```tsx
// uncontrolled
<Tabs defaultValue="description">
  <Tabs.List label="Информация о товаре">
    <Tabs.Tab value="description">Описание</Tabs.Tab>
    <Tabs.Tab value="specs">Характеристики</Tabs.Tab>
    <Tabs.Tab value="reviews">Отзывы (12)</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="description">Легкие кроссовки для бега…</Tabs.Panel>
  <Tabs.Panel value="specs">Вес: 250 г…</Tabs.Panel>
  <Tabs.Panel value="reviews"><Reviews /></Tabs.Panel>
</Tabs>

// controlled — вкладка в URL
const [searchParams, setSearchParams] = useSearchParams();
<Tabs value={searchParams.get("tab") ?? "description"} onChange={(tab) => setSearchParams({ tab })}>
  …
</Tabs>
```

## Решения в API

| Решение | Зачем |
| --- | --- |
| compound components + контекст | пользователь управляет разметкой, состояние общее |
| `value` / `defaultValue` / `onChange` | работает и как управляемый (URL, store), и как самостоятельный |
| `useId` | уникальные и SSR-стабильные id для ARIA-связей |
| roving tabindex | в табах Tab-ом попадаешь только в активную вкладку, по вкладкам — стрелками |
| ошибка вне `<Tabs>` | понятное сообщение при неправильном использовании |

## Доп. вопросы интервьюера

- **Скрывать неактивные панели или размонтировать?** размонтирование сбрасывает их state и экономит рендер; `hidden` сохраняет state (формы) — выбор по задаче.
- **Автоматическая или ручная активация?** автоматическая — при перемещении стрелками; ручная — стрелки только переводят фокус, а Enter/Space активирует (для тяжелых панелей).
- **Как добавить анимацию индикатора?** измерить активную вкладку (`getBoundingClientRect`) в `useLayoutEffect`.
- **Почему не `<a>` для вкладок?** если вкладки меняют URL и это навигация — используют ссылки и `nav`, а не роль `tab`.

## Что важно помнить

- `role="tablist"` с `aria-label`, у вкладок `aria-selected` и `aria-controls`, у панелей `aria-labelledby`.
- Стрелки, Home, End; Tab ведет из списка вкладок сразу в панель.
- Не смешивайте controlled и uncontrolled режим во время жизни компонента.
- Теория: [Compound Components](<../../06. React/08. Паттерны и подходы/09. Что делает “Compound Components” паттерн.md>), [Control Props](<../../06. React/08. Паттерны и подходы/14. Что делает “Control Props” паттерн.md>), [useId](<../../06. React/04. Хуки/19. Что делает useId().md>).

## Мини-шпаргалка

`<Tabs>` хранит `value` (controlled или нет) в контексте → `Tabs.List` (`role="tablist"`, стрелки/Home/End) → `Tabs.Tab` (`role="tab"`, `aria-selected`, `aria-controls`, `tabIndex` 0/-1) → `Tabs.Panel` (`role="tabpanel"`, `aria-labelledby`). `useId` для связей.
