# Задача: DeepPartial и DeepReadonly

> [!NOTE]
> Встроенные `Partial` и `Readonly` действуют только на **первый уровень** объекта. Рекурсивные версии `DeepPartial<T>` и `DeepReadonly<T>` применяют модификатор ко всем вложенным объектам — для патчей конфигурации, неизменяемого state, моков в тестах. Решение — **рекурсивный mapped type** с условием: если значение — объект, применить тип рекурсивно, иначе оставить как есть; отдельно обработать **функции** и **массивы**, чтобы не сломать их типы.

## Вопрос

Реализуйте `DeepPartial<T>` и `DeepReadonly<T>`. Как правильно обработать функции, массивы, `Date` и примитивы?

## DeepPartial

```typescript
type DeepPartial<T> =
  T extends (...args: any[]) => unknown ? T :                 // функции — без изменений
  T extends ReadonlyArray<infer Item> ? Array<DeepPartial<Item>> :  // массивы — по элементам
  T extends Date ? T :
  T extends object ? { [K in keyof T]?: DeepPartial<T[K]> } :
  T;                                                          // примитивы
```

```typescript
type Config = {
  server: { port: number; host: string; tls: { enabled: boolean; cert: string } };
  features: string[];
  onError: (e: Error) => void;
};

function mergeConfig(base: Config, patch: DeepPartial<Config>): Config {
  /* глубокое слияние */
  return base;
}

mergeConfig(defaultConfig, { server: { tls: { enabled: true } } });   // ok — можно передать часть
```

## DeepReadonly

```typescript
type DeepReadonly<T> =
  T extends (...args: any[]) => unknown ? T :
  T extends ReadonlyArray<infer Item> ? ReadonlyArray<DeepReadonly<Item>> :
  T extends Map<infer K, infer V> ? ReadonlyMap<DeepReadonly<K>, DeepReadonly<V>> :
  T extends Set<infer V> ? ReadonlySet<DeepReadonly<V>> :
  T extends object ? { readonly [K in keyof T]: DeepReadonly<T[K]> } :
  T;
```

```typescript
type State = { user: { name: string; tags: string[] }; settings: Map<string, { on: boolean }> };

const state: DeepReadonly<State> = {
  user: { name: "Анна", tags: ["admin"] },
  settings: new Map(),
};

state.user.name = "Мария";       // ошибка: только для чтения
state.user.tags.push("dev");     // ошибка: push нет у ReadonlyArray
state.settings.set("x", { on: true });   // ошибка: нет set у ReadonlyMap
```

## Почему важна обработка функций и массивов

```typescript
// наивная версия
type NaiveDeepPartial<T> = { [K in keyof T]?: NaiveDeepPartial<T[K]> };

type Broken = NaiveDeepPartial<{ items: string[]; fn: () => void }>;
// items превращается в объект с необязательными методами массива,
// fn теряет сигнатуру вызова — типы ломаются
```

Функция — тоже `object`, поэтому проверка на функцию должна идти **раньше** проверки на объект.

## Связанная задача: DeepRequired и Paths

```typescript
type DeepRequired<T> =
  T extends (...args: any[]) => unknown ? T :
  T extends object ? { [K in keyof T]-?: DeepRequired<T[K]> } :
  T;

// все пути к полям объекта: "server" | "server.port" | "server.tls" | "server.tls.enabled" | ...
type Paths<T> = T extends object
  ? { [K in keyof T & string]: T[K] extends object ? K | `${K}.${Paths<T[K]>}` : K }[keyof T & string]
  : never;

type ConfigPaths = Paths<{ server: { port: number; tls: { enabled: boolean } } }>;
// "server" | "server.port" | "server.tls" | "server.tls.enabled"
```

## Доп. вопросы интервьюера

- **`DeepReadonly` защищает в рантайме?** нет, только на этапе компиляции; для рантайма — `Object.freeze` рекурсивно.
- **Есть ли ограничение глубины рекурсии?** у компилятора есть лимит вложенности инстанцирования; на очень глубоких или рекурсивных типах возможна ошибка «Type instantiation is excessively deep».
- **Где это есть готовым?** `type-fest` (`PartialDeep`, `ReadonlyDeep`), `ts-essentials`.

## Что важно помнить

- Встроенные `Partial`/`Readonly` — поверхностные.
- Порядок проверок: функция → массив → специальные объекты → объект → примитив.
- `infer` позволяет достать тип элемента массива и параметры `Map`/`Set`.
- Теория: [mapped types](<../../05. TypeScript/09. Продвинутые типы/03. Что такое “mapped type”.md>), [conditional types](<../../05. TypeScript/09. Продвинутые типы/02. Conditional types и дистрибутивность.md>), [infer](<../../05. TypeScript/08. Дженерики/05. infer и извлечение типов.md>).

## Мини-шпаргалка

`DeepX<T> = T extends Function ? T : T extends ReadonlyArray<infer I> ? Array<DeepX<I>> : T extends object ? { [K in keyof T]?: DeepX<T[K]> } : T`. Readonly-версия — `readonly`, `ReadonlyArray`, `ReadonlyMap`, `ReadonlySet`. Функции проверять раньше объектов. Только compile time.
