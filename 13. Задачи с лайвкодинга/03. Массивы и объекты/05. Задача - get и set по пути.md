# Задача: get и set по пути

> [!NOTE]
> `get(obj, path, defaultValue)` безопасно достает вложенное значение по пути `"user.address[0].city"` или массиву `["user", "address", 0, "city"]` и возвращает `defaultValue`, если по пути чего-то нет. `set(obj, path, value)` записывает значение, создавая промежуточные объекты или массивы (массив — если следующий ключ число). Ключевые части решения: **разбор пути** в массив ключей и **обход с проверкой на `null`/`undefined`**.

## Вопрос

Реализуйте `get(obj, path, defaultValue)` и `set(obj, path, value)` как в lodash: путь строкой с точками и квадратными скобками или массивом.

## Разбор пути

```javascript
function toPath(path) {
  if (Array.isArray(path)) return path;
  return path
    .replace(/\[(\w+)\]/g, ".$1")       // a[0].b → a.0.b
    .split(".")
    .filter(Boolean);                    // убрать пустые части: ".a" → ["a"]
}

toPath("user.address[0].city");          // ["user", "address", "0", "city"]
```

## get

```javascript
function get(obj, path, defaultValue) {
  const keys = toPath(path);
  let current = obj;

  for (const key of keys) {
    if (current === null || current === undefined) return defaultValue;
    current = current[key];
  }

  return current === undefined ? defaultValue : current;
}
```

```javascript
const data = { user: { name: "Анна", address: [{ city: "Казань" }], age: 0 } };

get(data, "user.address[0].city");          // "Казань"
get(data, ["user", "name"]);                // "Анна"
get(data, "user.phone", "нет");             // "нет"
get(data, "user.address[5].city", "—");     // "—"
get(data, "user.age", 18);                  // 0 — не подменяем ложные значения, только undefined
get(null, "a.b", "x");                      // "x"
```

## set

```javascript
function set(obj, path, value) {
  const keys = toPath(path);
  let current = obj;

  keys.forEach((key, i) => {
    if (i === keys.length - 1) {
      current[key] = value;
      return;
    }
    const nextIsIndex = /^\d+$/.test(keys[i + 1]);
    if (current[key] === null || typeof current[key] !== "object") {
      current[key] = nextIsIndex ? [] : {};      // создать недостающий уровень
    }
    current = current[key];
  });

  return obj;
}
```

```javascript
const state = {};
set(state, "user.address[0].city", "Москва");
// { user: { address: [ { city: "Москва" } ] } }

set(state, "settings.theme", "dark");
// { user: {...}, settings: { theme: "dark" } }
```

## Иммутабельная версия set (как в React и Redux)

```javascript
function setIn(obj, path, value) {
  const [key, ...rest] = toPath(path);
  if (key === undefined) return value;

  const source = obj ?? (/^\d+$/.test(key) ? [] : {});
  const copy = Array.isArray(source) ? [...source] : { ...source };
  copy[key] = setIn(source[key], rest, value);
  return copy;
}

const next = setIn(state, "settings.theme", "light");
next !== state;                       // true
next.user === state.user;             // true — неизмененные ветки переиспользуются
```

## Доп. вопросы интервьюера

- **Защита от prototype pollution?** запретить ключи `__proto__`, `constructor`, `prototype` в `set`: иначе `set({}, "__proto__.isAdmin", true)` изменит все объекты.
- **Как поддержать ключи с точкой (`"a.b"`)?** через массив пути или экранирование.
- **Есть ли нативный аналог?** optional chaining для статического пути: `data?.user?.address?.[0]?.city ?? "—"`.
- **Сложность?** O(длина пути).

## Что важно помнить

- `defaultValue` возвращается только для `undefined`, а не для `0`, `""` или `false`.
- Проверяйте `null` на каждом шаге обхода.
- В `set` число в пути означает массив на этом уровне.
- Валидируйте ключи от пользователя — prototype pollution реальная уязвимость.

## Мини-шпаргалка

`toPath`: `[n]` → `.n`, `split(".")`. `get`: обход с остановкой на `null`/`undefined`, `defaultValue` только для `undefined`. `set`: создавать `[]` или `{}` по следующему ключу. Иммутабельный `setIn` копирует только путь. Блокировать `__proto__`.
