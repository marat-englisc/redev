# Задача: classnames и сравнение версий

> [!NOTE]
> Две короткие утилиты, которые часто дают в начале лайвкодинга. **`classNames(...args)`** собирает строку CSS-классов из строк, объектов `{ active: isActive }` и вложенных массивов, пропуская ложные значения — как библиотеки `classnames` и `clsx`. **`compareVersions(a, b)`** сравнивает версии вида `"1.10.2"` и `"1.9.0"` по числовым частям слева направо и возвращает `-1`, `0` или `1`; ловушка — сравнение строк, при котором `"1.10" < "1.9"`.

## Вопрос

Реализуйте `classNames(...args)`, принимающий строки, числа, объекты и массивы любой вложенности. Реализуйте `compareVersions(a, b)` для версий с разным количеством частей.

## classNames

```javascript
function classNames(...args) {
  const classes = [];

  for (const arg of args) {
    if (!arg) continue;                                  // false, null, undefined, 0, ""

    if (typeof arg === "string" || typeof arg === "number") {
      classes.push(String(arg));
    } else if (Array.isArray(arg)) {
      const inner = classNames(...arg);                  // рекурсия для вложенных массивов
      if (inner) classes.push(inner);
    } else if (typeof arg === "object") {
      for (const [key, value] of Object.entries(arg)) {
        if (value) classes.push(key);
      }
    }
  }

  return classes.join(" ");
}
```

```javascript
classNames("btn", { "btn--primary": true, "btn--disabled": false }, ["size-md", [null, "rounded"]], 0, undefined);
// "btn btn--primary size-md rounded"

const isActive = true;
classNames("tab", isActive && "tab--active");   // "tab tab--active"
```

Дополнительно можно убрать дубликаты: `[...new Set(classes)].join(" ")`.

## compareVersions

```javascript
function compareVersions(a, b) {
  const pa = a.split(".").map(Number);
  const pb = b.split(".").map(Number);
  const length = Math.max(pa.length, pb.length);

  for (let i = 0; i < length; i++) {
    const x = pa[i] ?? 0;                     // "1.2" == "1.2.0"
    const y = pb[i] ?? 0;
    if (x > y) return 1;
    if (x < y) return -1;
  }
  return 0;
}
```

```javascript
compareVersions("1.10.2", "1.9.0");   // 1   ("1.10.2" > "1.9.0" — строковое сравнение дало бы обратное)
compareVersions("2.0", "2.0.0");      // 0
compareVersions("0.9.9", "1.0.0");    // -1

["1.10.0", "1.2.0", "1.9.1", "2.0.0"].sort(compareVersions);
// ["1.2.0", "1.9.1", "1.10.0", "2.0.0"]
```

## Pre-release версии (продолжение)

```javascript
function compareSemver(a, b) {
  const [mainA, preA] = a.split("-");
  const [mainB, preB] = b.split("-");
  const main = compareVersions(mainA, mainB);
  if (main !== 0) return main;
  if (!preA && !preB) return 0;
  if (!preA) return 1;                         // 1.0.0 > 1.0.0-beta
  if (!preB) return -1;
  return preA.localeCompare(preB, undefined, { numeric: true });  // beta.2 < beta.10
}

compareSemver("1.0.0-beta.2", "1.0.0-beta.10");   // -1
compareSemver("1.0.0", "1.0.0-rc.1");             // 1
```

## Доп. вопросы интервьюера

- **Почему не `a > b` для версий?** строки сравниваются посимвольно: `"1.10" < "1.9"`, потому что `"1" < "9"`.
- **Как валидировать формат?** регулярка `/^\d+(\.\d+)*$/` или библиотека `semver`.
- **Зачем `clsx`, если есть шаблонные строки?** условные классы без «висящих» пробелов и `undefined` в строке.
- **Как объединять Tailwind-классы с конфликтами?** `tailwind-merge` поверх `clsx`.

## Что важно помнить

- `classNames` пропускает все ложные значения, включая `0`.
- Рекурсия по массивам позволяет передавать вложенные условия.
- В `compareVersions` недостающие части считаются нулем.
- Связанные темы: [semver](<../../12. Сборка и инструменты/05. Пакетные менеджеры и монорепозиторий/02. Что такое semver и как обновлять зависимости.md>), [БЭМ](<../../03. CSS/01. Основы CSS/10. Что такое БЭМ и как организовать стили на SCSS.md>).

## Мини-шпаргалка

classNames: пропуск ложных, строки и числа — как есть, массивы — рекурсия, объекты — ключи с истинным значением, `join(" ")`. compareVersions: `split(".").map(Number)`, сравнение по частям до максимальной длины, недостающие — 0, вернуть -1/0/1.
