# Задача: парсинг и сборка query string

> [!NOTE]
> Задача: разобрать строку запроса `?page=2&tag=js&tag=react&q=hello%20world` в объект `{ page: "2", tag: ["js", "react"], q: "hello world" }` и собрать обратно. Нужно **декодировать** значения (`decodeURIComponent`, `+` как пробел), собирать **повторяющиеся ключи в массив**, обрабатывать ключи без значения (`?debug`) и **кодировать** при сборке, пропуская `undefined` и `null`. В реальном коде используют встроенный `URLSearchParams`, но на собеседовании просят написать вручную.

## Вопрос

Реализуйте `parseQuery(query)` и `stringifyQuery(params)`. Повторяющиеся ключи — в массив, значения декодируются и кодируются, пустые значения пропускаются.

## parseQuery

```javascript
function parseQuery(query) {
  const result = {};
  const source = query.startsWith("?") ? query.slice(1) : query;
  if (!source) return result;

  for (const pair of source.split("&")) {
    if (!pair) continue;                                   // "a=1&&b=2"
    const [rawKey, ...rest] = pair.split("=");
    const rawValue = rest.join("=");                       // значение может содержать "="
    const decode = (s) => decodeURIComponent(s.replace(/\+/g, " "));
    const key = decode(rawKey);
    const value = rest.length ? decode(rawValue) : "";    // "?debug" → ""

    if (key in result) {
      result[key] = [].concat(result[key], value);         // второй и далее → массив
    } else {
      result[key] = value;
    }
  }

  return result;
}
```

```javascript
parseQuery("?page=2&tag=js&tag=react&q=hello%20world&sort=price+asc&debug&token=a=b");
// { page: "2", tag: ["js", "react"], q: "hello world", sort: "price asc", debug: "", token: "a=b" }
```

## stringifyQuery

```javascript
function stringifyQuery(params) {
  const parts = [];
  const encode = encodeURIComponent;

  for (const [key, value] of Object.entries(params)) {
    if (value === undefined || value === null) continue;
    const values = Array.isArray(value) ? value : [value];
    for (const v of values) {
      if (v === undefined || v === null) continue;
      parts.push(`${encode(key)}=${encode(String(v))}`);
    }
  }

  return parts.length ? `?${parts.join("&")}` : "";
}
```

```javascript
stringifyQuery({ page: 2, tag: ["js", "react"], q: "hello world", empty: undefined, ok: true });
// "?page=2&tag=js&tag=react&q=hello%20world&ok=true"
```

## С URLSearchParams

```javascript
const params = new URLSearchParams("?tag=js&tag=react&q=hello+world");
params.get("q");          // "hello world"
params.getAll("tag");     // ["js", "react"]
params.set("page", "3");
params.toString();        // "tag=js&tag=react&q=hello+world&page=3"

const url = new URL("https://shop.ru/catalog");
url.searchParams.append("brand", "nike");
url.toString();           // "https://shop.ru/catalog?brand=nike"
```

`URLSearchParams` кодирует пробел как `+`, `encodeURIComponent` — как `%20`; оба варианта корректны в query string.

## Доп. вопросы интервьюера

- **Почему `decodeURIComponent` может бросить?** некорректная последовательность (`%E0%A4%A`) → `URIError`; оберните в `try/catch`.
- **Вложенные объекты (`filter[price][min]=100`)?** нужен свой формат — как в библиотеке `qs`.
- **`encodeURI` vs `encodeURIComponent`?** первый не кодирует `&`, `=`, `?`, `/` — подходит для целого URL, второй — для отдельных значений.
- **Как хранить состояние фильтров в URL в React?** `useSearchParams` и `replace` при вводе.

## Что важно помнить

- Значения из URL — всегда строки; числа и булевы приводите явно.
- Значение может содержать `=` — делите только по первому.
- Кодируйте ключи и значения при сборке, иначе `&` в значении сломает строку.

## Мини-шпаргалка

parse: убрать `?`, `split("&")`, ключ до первого `=`, `decodeURIComponent` + `+` → пробел, повторный ключ → массив. stringify: пропуск `null`/`undefined`, массив → несколько пар, `encodeURIComponent`. В коде — `URLSearchParams` и `URL`.
