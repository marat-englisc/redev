# Задача: полифилы call, apply и bind

> [!NOTE]
> Задача «напишите свой `bind`» проверяет понимание `this`. Идея `call`/`apply`: временно положить функцию как метод в объект контекста (через уникальный `Symbol`), вызвать ее как метод — тогда `this` будет этим объектом — и удалить свойство. `bind` возвращает новую функцию, которая вызывает исходную с зафиксированным `this` и частью аргументов; продвинутая версия корректно работает с `new`.

## Вопрос

Реализуйте `Function.prototype.myCall`, `myApply` и `myBind`. Как `bind` должен вести себя при вызове результата через `new`?

## myCall и myApply

```javascript
Function.prototype.myCall = function (context, ...args) {
  if (typeof this !== "function") throw new TypeError("myCall вызван не у функции");

  const ctx = context === null || context === undefined ? globalThis : Object(context); // примитивы оборачиваем
  const key = Symbol("fn");             // уникальный ключ — не перезапишем свойства объекта
  ctx[key] = this;                      // this здесь — вызываемая функция
  try {
    return ctx[key](...args);           // вызов как метода → this === ctx
  } finally {
    delete ctx[key];
  }
};

Function.prototype.myApply = function (context, args = []) {
  return this.myCall(context, ...args);
};
```

```javascript
function greet(greeting, mark) {
  return `${greeting}, ${this.name}${mark}`;
}
const user = { name: "Анна" };

greet.myCall(user, "Привет", "!");      // "Привет, Анна!"
greet.myApply(user, ["Здравствуй", "."]); // "Здравствуй, Анна."
```

## myBind

```javascript
Function.prototype.myBind = function (context, ...boundArgs) {
  const fn = this;

  function bound(...args) {
    // при вызове через new this — новый объект, контекст bind игнорируется
    const isNew = this instanceof bound;
    return fn.apply(isNew ? this : context, [...boundArgs, ...args]);
  }

  if (fn.prototype) bound.prototype = Object.create(fn.prototype); // instanceof для new
  return bound;
}
```

```javascript
const hello = greet.myBind(user, "Привет");
hello("?");                              // "Привет, Анна?"

function Point(x, y) { this.x = x; this.y = y; }
const BoundPoint = Point.myBind(null, 10);
const p = new BoundPoint(20);
p;                                       // Point { x: 10, y: 20 }
p instanceof Point;                      // true
```

## Почему это работает

`this` в обычной функции определяется **способом вызова**: при `obj.method()` `this === obj`. Мы искусственно создаем такой вызов. Стрелочные функции так «привязать» нельзя: у них нет своего `this`, `call`/`bind` его не меняют.

## Доп. вопросы интервьюера

- **Что будет при повторном `bind`?** `fn.bind(a).bind(b)` — `this` останется `a`: связанная функция игнорирует новый контекст.
- **Зачем `Symbol`?** чтобы не перезаписать существующее свойство объекта с тем же именем.
- **Что с `null` в нестрогом режиме?** нативный `call` подставляет глобальный объект; в строгом режиме `this` остается `null`. В полифиле упрощенно используем `globalThis`.
- **Где нужен `bind` на практике?** передача метода как колбэка (`setTimeout(obj.method.bind(obj))`), частичное применение, классовые компоненты React.

## Что важно помнить

- `call(ctx, a, b)` — аргументы списком, `apply(ctx, [a, b])` — массивом, `bind` — возвращает новую функцию.
- Удаляйте временное свойство в `finally`, даже если функция бросила ошибку.
- Полифил не повторяет всех деталей спецификации (например, `name` и `length` связанной функции) — скажите об этом.

## Мини-шпаргалка

`myCall`: `ctx[Symbol] = this`, вызвать как метод, удалить в `finally`. `myApply` — через `myCall` с массивом. `myBind`: вернуть `bound`, склеить аргументы, при `this instanceof bound` (вызов через `new`) игнорировать контекст, `bound.prototype = Object.create(fn.prototype)`.
