# Что выведет: приведение типов и сравнения

> [!NOTE]
> Задачи на приведение типов проверяют несколько правил. Бинарный `+` склеивает строки, если **хотя бы один** операнд после приведения к примитиву — строка; остальные арифметические операторы (`-`, `*`, `/`) приводят к **числу**. Объекты приводятся к примитиву через `valueOf`/`toString`: `[]` → `""`, `[1, 2]` → `"1,2"`, `{}` → `"[object Object]"`. Нестрогое `==` приводит типы по сложным правилам (`null == undefined`, но `null != 0`), поэтому в коде используют `===`. `NaN` не равен ничему, включая себя.

## Вопрос

Что выведет каждая строка? Объясните, какое приведение типов происходит.

## Задача 1: сложение

```javascript
console.log([] + []);
console.log([] + {});
console.log(1 + "2");
console.log(true + 1);
console.log(null + 1);
console.log(undefined + 1);
console.log([1, 2] + [3]);
console.log("b" + "a" + +"a" + "a");
```

> [!TIP]- Ответ
> `""` (пустая строка), `"[object Object]"`, `"12"`, `2`, `1`, `NaN`, `"1,23"`, `"baNaNa"`.
> `[]` → `""`, `{}` → `"[object Object]"`. `true` → 1, `null` → 0, `undefined` → `NaN`. Унарный `+"a"` дает `NaN`, который склеивается в строку.

## Задача 2: другие операторы

```javascript
console.log("5" - 2);
console.log("5" * "2");
console.log("10" / "4");
console.log("abc" - 1);
console.log([] - 1);
console.log([5] * 2);
```

> [!TIP]- Ответ
> `3`, `10`, `2.5`, `NaN`, `-1`, `10`. Все, кроме `+`, приводят операнды к числам: `[]` → `""` → `0`, `[5]` → `"5"` → `5`.

## Задача 3: сравнения

```javascript
console.log(null == undefined, null === undefined);
console.log(null == 0, null >= 0);
console.log([] == false, !![]);
console.log(NaN === NaN, Object.is(NaN, NaN));
console.log("2" > "12", 2 > "12");
console.log(0 == "", 0 == "0", "" == "0");
```

> [!TIP]- Ответ
> - `true false`
> - `false true` — `==` с `null` особый (равен только `undefined`), а `>=` приводит `null` к 0
> - `true true` — `[] == false`: оба → 0; но `[]` — объект, поэтому в логическом контексте истинен
> - `false true`
> - `true false` — строки сравниваются посимвольно (`"2" > "1"`), число со строкой — численно
> - `true true false` — `==` не транзитивно

## Задача 4: числа

```javascript
console.log(0.1 + 0.2 === 0.3);
console.log(0.1 + 0.2);
console.log(typeof NaN);
console.log(9007199254740993 === 9007199254740992);
console.log(1 / 0, -1 / 0);
console.log(parseInt("08px"), Number("08px"));
console.log([10, 1, 2].sort());
```

> [!TIP]- Ответ
> `false`, `0.30000000000000004`, `"number"`, `true`, `Infinity -Infinity`, `8 NaN`, `[1, 10, 2]`.
> Числа с плавающей точкой (IEEE 754) неточны — сравнивают с допуском `Math.abs(a - b) < Number.EPSILON`. После `MAX_SAFE_INTEGER` целые теряют точность — нужен `BigInt`. `parseInt` читает до первого нечислового символа, `Number` требует корректную строку. `sort` без компаратора сравнивает строки.

## Задача 5: typeof

```javascript
console.log(typeof null);
console.log(typeof function () {});
console.log(typeof []);
console.log(typeof undefined, typeof undeclared);
console.log(typeof 10n, typeof Symbol());
```

> [!TIP]- Ответ
> `"object"` (историческая ошибка языка), `"function"`, `"object"` (для массивов — `Array.isArray`), `"undefined" "undefined"`, `"bigint" "symbol"`.

## Задача 6: ложные значения

```javascript
const values = [0, -0, "", " ", "0", null, undefined, NaN, [], {}, false, 0n];
console.log(values.filter(Boolean));
console.log(0 || "default", 0 ?? "default");
```

> [!TIP]- Ответ
> `[" ", "0", [], {}]` и `default 0`. Ложные значения: `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`, `false`. Строка с пробелом, `"0"`, пустые массив и объект — истинны. `||` заменяет любое ложное значение, `??` — только `null` и `undefined`.

## Правила приведения

| Значение | `Number(x)` | `String(x)` | `Boolean(x)` |
| --- | --- | --- | --- |
| `undefined` | `NaN` | `"undefined"` | `false` |
| `null` | `0` | `"null"` | `false` |
| `true` / `false` | `1` / `0` | `"true"` / `"false"` | — |
| `""` / `" "` | `0` / `0` | — | `false` / `true` |
| `"12px"` | `NaN` | — | `true` |
| `[]` | `0` | `""` | `true` |
| `[7]` | `7` | `"7"` | `true` |
| `{}` | `NaN` | `"[object Object]"` | `true` |

## Что важно помнить

- Используйте `===` и `Object.is`; `==` допустим только как `x == null` (проверка на `null` и `undefined`).
- `??` вместо `||` для значений по умолчанию, если `0` и `""` допустимы.
- Деньги не считайте во float — храните копейки целыми числами.

## Мини-шпаргалка

`+` со строкой → склейка, остальные операторы → число. `[]` → `""`/0, `{}` → `"[object Object]"`, `null` → 0, `undefined` → NaN. `null == undefined`, `null != 0`, `NaN !== NaN`. `0.1 + 0.2 !== 0.3`. `typeof null === "object"`. `??` vs `||`.
