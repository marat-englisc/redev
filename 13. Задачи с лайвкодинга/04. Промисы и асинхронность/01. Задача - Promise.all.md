# Задача: Promise.all

> [!NOTE]
> `Promise.all(iterable)` возвращает промис, который выполняется **массивом результатов в исходном порядке**, когда выполнились все промисы, и отклоняется **первой же ошибкой**. В реализации важно: сохранять порядок по индексу (а не по времени завершения), считать завершенные, оборачивать не-промисы через `Promise.resolve`, сразу выполнять промис для пустого массива и не ждать остальных после первой ошибки.

## Вопрос

Реализуйте `promiseAll(iterable)`, повторяющий поведение `Promise.all`: порядок результатов, отклонение при первой ошибке, поддержка не-промисов и пустого массива.

## Решение

```javascript
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const items = Array.from(iterable);
    const results = new Array(items.length);
    let completed = 0;

    if (items.length === 0) {
      resolve(results);                          // [] — сразу
      return;
    }

    items.forEach((item, index) => {
      Promise.resolve(item)                      // поддержка обычных значений и thenable
        .then((value) => {
          results[index] = value;                // порядок по индексу, а не по времени
          completed += 1;
          if (completed === items.length) resolve(results);
        })
        .catch(reject);                          // первая ошибка отклоняет общий промис
    });
  });
}
```

`.then(onFulfilled, reject)` вместо `.then().catch(reject)` чуть точнее: ошибка внутри `onFulfilled` не превратится в отклонение. Для задачи оба варианта приемлемы.

## Проверка

```javascript
const delay = (ms, value, fail = false) =>
  new Promise((res, rej) => setTimeout(() => (fail ? rej(new Error(value)) : res(value)), ms));

await promiseAll([delay(300, "a"), delay(100, "b"), 42]);
// ["a", "b", 42] — порядок исходный, хотя "b" завершился первым

await promiseAll([]);
// []

await promiseAll([delay(100, "ok"), delay(50, "boom", true)]).catch((e) => e.message);
// "boom" — через 50 мс, не дожидаясь первого
```

## Доп. вопросы интервьюера

- **Отменяются ли остальные промисы после ошибки?** нет: они продолжат выполняться, просто их результаты будут проигнорированы. Для отмены нужен `AbortController`.
- **Повторный `resolve`/`reject` после первой ошибки?** игнорируется — состояние промиса меняется один раз.
- **Чем отличается от `allSettled`?** `allSettled` всегда ждет все и возвращает статусы.
- **Как запустить 100 запросов, но не больше 5 одновременно?** это уже не `Promise.all`, а пул — см. задачу об ограничении параллельности.
- **Как реализовать через async/await?** нельзя просто `for` с `await` — это последовательное выполнение; запуск должен быть одновременным.

## Что важно помнить

- Результат — в порядке входа, а не завершения.
- Пустой вход выполняется сразу пустым массивом.
- `Promise.resolve(item)` поддерживает не-промисы и thenable-объекты.
- Вход — любой iterable (`Set`, генератор), поэтому `Array.from`.
- Теория: [Promise.all, allSettled, race, any](<../../04. JavaScript/05. Асинхронность и Event Loop/14. Promise.all allSettled race и any.md>).

## Мини-шпаргалка

`new Promise` → `Array.from(iterable)` → пустой → `resolve([])` → для каждого `Promise.resolve(item).then(v => { results[i] = v; if (++done === n) resolve(results) }, reject)`. Порядок по индексу, первая ошибка — reject, остальные не отменяются.
