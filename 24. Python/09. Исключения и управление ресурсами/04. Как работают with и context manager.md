# Как работают with и context manager

> [!NOTE]
> With управляет ресурсом через протокол входа и выхода: __enter__ подготавливает ресурс и возвращает значение для as, __exit__ выполняет завершение и получает сведения об исключении. Contextlib.contextmanager позволяет описать такой протокол генератором с одним yield. With не означает автоматически транзакцию, rollback или подавление ошибки: это определяет конкретный менеджер.

## Вопрос

Как гарантировать закрытие файла при ошибке? Что нужно понимать перед написанием своего context manager?

## Стандартный ресурс

```python
from io import StringIO

with StringIO("first\nsecond\n") as stream:
    print(stream.readline().strip())  # first

print(stream.closed)  # True
```

With задаёт видимую границу времени жизни ресурса. Закрытие происходит и при выходе из блока через исключение, если вход успешно состоялся и процесс продолжает исполнять Python-код.

## Менеджер через генератор

```python
from contextlib import contextmanager
from io import StringIO

@contextmanager
def text_stream(text):
    stream = StringIO(text)
    try:
        yield stream
    finally:
        stream.close()

with text_stream("hello") as source:
    print(source.read())  # hello
print(source.closed)  # True
```

Код до yield — вход, после и finally — выход. Yield должен произойти ровно один раз на вход. Если перехватить исключение вокруг yield и не выбросить дальше, менеджер может непреднамеренно подавить ошибку блока.

## Несколько ресурсов

`with first() as a, second() as b:` управляет вложенными контекстами и освобождает их в обратном порядке. Для динамического количества ресурсов подходит contextlib.ExitStack.

## Свой класс

В __exit__ truthy-результат означает подавление исключения; обычные None/False сохраняют распространение. Не возвращай True машинально. Для асинхронных ресурсов есть `async with` и отдельные async-методы.

## Практика

Брось ValueError внутри text_stream, перехвати снаружи и проверь closed. Объясни, почему библиотечный context manager часто надёжнее ручного open/close в разных ветках.
