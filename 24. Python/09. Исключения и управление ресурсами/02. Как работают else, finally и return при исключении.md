# Как работают else, finally и return при исключении

> [!NOTE]
> Else у try выполняется, когда try завершился нормально без исключения и управляющего выхода вроде return. Finally выполняется при выходе из конструкции, включая обработку ошибки и return, и подходит для очистки. Return или новое исключение в finally могут заменить исходный результат. При аварийном завершении процесса или принудительном убийстве гарантировать очистку нельзя.

## Вопрос

Зачем try/except/else/finally? Может ли finally скрыть исключение?

## Разделение успешного пути

```python
def parse_and_report(text):
    try:
        value = int(text)
    except ValueError:
        print("bad input")
        return None
    else:
        print("parsed")
        return value
    finally:
        print("finished")

print(parse_and_report("5"))  # parsed, finished, 5
print(parse_and_report("x"))  # bad input, finished, None
```

Код else не находится под действием preceding except для ошибок самого else. Так проще не перепутать ошибку парсинга с ошибкой последующей обработки.

## Сохранённый return

```python
def example():
    value = 1
    try:
        return value
    finally:
        value = 2

print(example())  # 1
```

Выражение return уже вычислено. Но если вернулся изменяемый объект и finally мутировал тот же объект, вызывающий увидит его новое содержимое.

## Опасная подмена

```python
def hidden_error():
    try:
        raise ValueError("important")
    finally:
        return "ok"  # антипаттерн: ошибка теряется

print(hidden_error())  # ok
```

Новые версии Python и инструменты могут дополнительно предупреждать о таком управляющем выходе. Не используй finally для выбора бизнес-результата.

## Ресурсы

Файл, соединение и lock лучше закрывать через context manager, если он поддерживается. Finally полезен для собственного протокола очистки, но и он должен учитывать возможную ошибку cleanup, чтобы не затереть исходную причину.

## Практика

Предскажи порядок вывода при успешном return, обработанной и необработанной ошибке. Отличи finally от else цикла: у них разные условия запуска.
