# Типичные антипаттерны Python и ошибки после JavaScript

> [!NOTE]
> Ошибки при переходе с JS часто возникают из-за похожего синтаксиса с другой семантикой: пустые коллекции false-like, dict сравнивается по содержимому, is проверяет идентичность, default вычисляется при определении функции. Для поддерживаемого Python нужны явные контракты, ограниченные побочные эффекты и понятная обработка ошибок, а не механический перенос привычек другого языка.

## Вопрос

Какие привычки JavaScript-разработчика особенно опасны в Python?

## Сравнение

| Ситуация | В Python |
| --- | --- |
| Пустые [] и {} в if | False-like |
| `==` двух обычных списков | Сравнение содержимого |
| `is` двух списков | Идентичность объекта |
| `"5" + 1` | TypeError |
| `a or default` | Заменяет и 0, и пустую строку |
| Цикл for | Обычно перебирает значения iterable |
| `a = b` для list | Копия не создаётся |
| `def f(items=[])` | Один default разделяется между вызовами |
| Вызов async def | Даёт coroutine, сам по себе не запускает Task |

## Изменяющий метод не возвращает коллекцию

```python
numbers = [3, 1, 2]
result = numbers.sort()
print(numbers)  # [1, 2, 3]
print(result)  # None
```

Если нужен новый список, используй sorted(numbers).

## Слишком широкая обработка

`except Exception: return []` может превратить отказ БД в «нет записей». Вызывающий код примет это за корректный результат. Различай пустые данные и недоступность источника.

## Лишнее усложнение

- Класс с единственным статическим методом вместо функции.
- Сложный comprehension с побочными эффектами.
- Generic-параметры, не сохраняющие полезную связь типов.
- Рекурсивный helper для простого линейного обхода.
- Ненужная материализация iterator «на всякий случай».
- Async def с блокирующим клиентом внутри loop.

## Что важно помнить

Встроенные имена вроде list, dict, str и id лучше не затенять переменными без необходимости. Для отсутствия значения не используй изменяемый пустой контейнер как неявную универсальную метку.

## Практика

Возьми небольшой JS-helper и перепиши его по Python-контракту. Отдельно проверь пустой вход, ноль, None, общие ссылки и код ошибки.
