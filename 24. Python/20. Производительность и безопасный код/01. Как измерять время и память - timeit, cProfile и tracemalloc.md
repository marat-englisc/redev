# Как измерять время и память - timeit, cProfile и tracemalloc

> [!NOTE]
> Оптимизация начинается с измерения реального bottleneck. Perf_counter измеряет длительность, timeit подходит для небольших повторяемых фрагментов, cProfile показывает затраты вызовов, tracemalloc — отслеживаемые выделения Python-памяти. Каждый инструмент имеет границы: микробенчмарк не заменяет end-to-end latency, а tracemalloc не описывает весь RSS и все нативные аллокации.

## Вопрос

Как понять, что именно тормозит программу, и проверить эффект оптимизации?

## Небольшое измерение

```python
from timeit import repeat

def calculate():
    return sum(value * value for value in range(100))

samples = repeat(calculate, number=1000, repeat=3)
print(len(samples))  # 3; сами времена зависят от машины
```

Измерение включает тысячу вызовов на образец. Не сравнивай числа с разных машин как абсолютное свойство языка. Прогрев, фоновые процессы, версия и вход влияют на результат.

## Профиль программы

```bash
python -m cProfile -s cumulative app.py
```

Смотри cumulative time, собственное время и число вызовов. Тысяча маленьких SQL-запросов может быть важнее локального выбора между двумя формами цикла.

## Отслеживание памяти

```python
import tracemalloc

tracemalloc.start()
before = tracemalloc.take_snapshot()
values = [str(number) for number in range(1000)]
after = tracemalloc.take_snapshot()
stats = after.compare_to(before, "lineno")
print(bool(stats))  # True
tracemalloc.stop()
```

Снимки показывают разницу удерживаемых отслеживаемых выделений. Они не доказывают, что каждый рост — утечка: список values намеренно остаётся жив.

## Порядок работы

1. Зафиксировать симптом, вход и ожидаемую метрику.
2. Найти дорогой этап и число операций.
3. Изменить алгоритм, I/O или структуру данных.
4. Проверить корректность и повторить измерение на сопоставимом входе.

## Практика

Сравни повторный membership в list и заранее построенном set, включив стоимость построения там, где она реально возникает. Объясни, для какого количества поисков решение меняется.
