# Как работают dataclass, field, frozen и slots

> [!NOTE]
> Dataclass генерирует типовые методы класса по объявленным полям: обычно __init__, __repr__ и __eq__. Field с default_factory создаёт независимый изменяемый default. Frozen ограничивает обычное присваивание полей, но не делает вложенные объекты глубоко неизменяемыми. Аннотации dataclass сами не валидируют типы во время исполнения.

## Вопрос

Как описать небольшую модель данных без ручного конструктора? Что даёт frozen и чего он не гарантирует?

## Модель

```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    tags: list[str] = field(default_factory=list)

first = User("Anna")
second = User("Ivan")
first.tags.append("python")
print(first)  # User(name='Anna', tags=['python'])
print(second.tags)  # []
print(User("Anna") == User("Anna"))  # True
```

Передаём фабрику list, а не результат list(). Сгенерированное равенство сравнивает поля экземпляров соответствующего класса, но не проверяет предметные ограничения.

## Валидация и frozen

```python
from dataclasses import dataclass

@dataclass(frozen=True, slots=True)
class Product:
    name: str
    quantity: int

    def __post_init__(self):
        if self.quantity < 0:
            raise ValueError("quantity must be non-negative")

print(Product("book", 2))  # Product(name='book', quantity=2)
```

Post-init запускается после сгенерированной инициализации. Проверка `quantity < 0` не является полной проверкой типа: для внешнего ввода нужны все требуемые условия.

Slots обычно убирает обычный __dict__ экземпляра и ограничивает набор динамических атрибутов, что может уменьшить расход памяти. Это не доступ private и не доказательство безопасности.

## Вложенная изменяемость

Frozen dataclass с list-полем всё ещё позволяет менять содержимое этого list. Хешируемость зависит от полей и настроек eq/frozen; `unsafe_hash=True` не исправляет логическую изменяемость ключа.

## Практика

Создай dataclass события с timestamp и набором тегов. Реши, нужна ли глубокая неизменяемость; при необходимости выбери tuple/frozenset вместо list/set.
