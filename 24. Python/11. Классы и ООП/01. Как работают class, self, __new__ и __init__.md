# Как работают class, self, __new__ и __init__

> [!NOTE]
> Class создаёт класс, экземпляр объединяет состояние и поведение. Self — обычное соглашение об имени первого параметра instance method; при вызове через экземпляр Python передаёт его автоматически. __new__ создаёт экземпляр, __init__ инициализирует уже созданный. В прикладном коде обычно достаточно __init__, который должен возвращать None.

## Вопрос

Что такое self? Почему __init__ не совсем корректно называть методом создания объекта?

## Экземпляр со своим состоянием

```python
class Counter:
    def __init__(self, initial=0):
        self.value = initial

    def increment(self):
        self.value += 1
        return self.value

first = Counter()
second = Counter(10)
print(first.increment(), second.increment())  # 1 11
print(first.value)  # 1
```

Состояние записано в атрибутах конкретного экземпляра. `first.increment()` концептуально похож на `Counter.increment(first)`.

## Этапы создания

```text
Counter(...) → __new__ создаёт объект
             → __init__ настраивает объект
             → вызывающий получает экземпляр
```

У __new__ есть специальные сценарии, например создание подклассов неизменяемых типов. Переписывать его ради обычного набора полей не нужно.

## Граница ответственности

Класс полезен, когда есть связанное состояние, инварианты и операции. Для простого вычисления без состояния обычная функция может быть яснее. ООП не требует превращать каждый JSON-словарь в иерархию классов.

## Инкапсуляция

`_name` обозначает внутреннюю деталь по соглашению. `__name` запускает name mangling для уменьшения конфликтов в наследовании; это не механизм защиты секрета от чтения. Проверки доступа уровня private, как в некоторых других языках, здесь устроены иначе.

## Частые ошибки

- Забывать self в instance method.
- Возвращать значение из __init__.
- Хранить независимый изменяемый state в общем атрибуте класса.
- Делать сетевые запросы прямо при создании объекта без ясного контракта ошибок.

## Практика

Создай класс корзины с независимым списком товаров в каждом экземпляре. Проверь, что добавление в одну корзину не меняет вторую.
