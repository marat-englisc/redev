# Функции как объекты, lambda и функции высшего порядка

> [!NOTE]
> Функции в Python можно присваивать, передавать и возвращать как другие объекты. Функция высшего порядка принимает или возвращает функцию. Lambda создаёт функцию из одного выражения; это короткая форма, а не отдельная модель выполнения. Для именованной сложной логики лучше def, а для короткого key или callback lambda часто уместна.

## Вопрос

Что значит «функция — объект первого класса»? Чем передача функции отличается от её вызова?

## Передать поведение

```python
def apply_twice(function, value):
    return function(function(value))

def double(value):
    return value * 2

print(apply_twice(double, 3))  # 12
```

`double` передаёт объект функции, `double(3)` вызывает её и передаёт результат. Такая ошибка часто встречается при регистрации обработчиков.

## Lambda

```python
users = [{"name": "Ivan"}, {"name": "Anna"}]
print(sorted(users, key=lambda user: user["name"]))
# [{'name': 'Anna'}, {'name': 'Ivan'}]
```

Lambda поддерживает выражение, но не обычный блок с for/try/return. Короткость не оправдывает сложные вложенные условные выражения.

## Map и filter

```python
numbers = [1, 2, 3]
print(list(map(double, numbers)))  # [2, 4, 6]
print([double(number) for number in numbers])  # [2, 4, 6]
```

Map возвращает ленивый iterator. Comprehension часто понятнее для простого преобразования, особенно с фильтром. Reduce уместен для настоящего свёртывания, но для суммы есть sum, для all/any — соответствующие встроенные функции.

## Чистота и побочные эффекты

Чистая функция зависит от входа и не меняет внешний мир. Функция, читающая часы или изменяющая общий список, имеет дополнительные зависимости. Python не требует чистоты, но явное отделение расчёта от I/O упрощает тесты.
