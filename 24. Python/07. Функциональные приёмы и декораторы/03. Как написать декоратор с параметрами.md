# Как написать декоратор с параметрами

> [!NOTE]
> Декоратор с параметрами обычно имеет три уровня: фабрика принимает настройки, декоратор принимает функцию, wrapper принимает аргументы вызова. `@configure(x)` сначала вычисляет configure(x), а затем применяет полученный декоратор. Настройки и состояние могут сохраняться в замыкании, поэтому важно понимать, что разделяется между вызовами.

## Вопрос

Почему у параметризованного декоратора три вложенные функции? На каком этапе проверять его настройки?

## Пример ограничения результата

```python
from functools import wraps

def require_minimum(minimum):
    def decorate(function):
        @wraps(function)
        def wrapper(*args, **kwargs):
            result = function(*args, **kwargs)
            if result < minimum:
                raise ValueError(f"result must be >= {minimum}")
            return result
        return wrapper
    return decorate

@require_minimum(0)
def balance(income, expense):
    return income - expense

print(balance(10, 4))  # 6
try:
    balance(4, 10)
except ValueError as error:
    print(error)  # result must be >= 0
```

Смысл проверки относится к этому примеру: в реальном финансовом приложении отрицательный баланс может быть допустим, и это должно определяться доменом.

## Эквивалент без синтаксического сахара

```text
decorator = require_minimum(0)
balance = decorator(balance)
```

Minimum вычислен при создании декоратора, а проверка результата выполняется при вызове wrapper.

## Осторожно с retry-декораторами

Повторение функции после любого Exception может повторно списать деньги или создать дубликат записи. Для retry нужны конкретные временные ошибки, лимит попыток, задержка, timeout и идемпотентность операции. Декоратор — только способ организации кода, не доказательство надёжности.

## Что важно помнить

- Аргументы фабрики не равны аргументам обёрнутой функции.
- Ошибочные настройки удобно отклонять заранее при создании декоратора.
- Изменяемое замкнутое состояние может быть общим для всех вызовов одной обёртки.

## Практика

Сделай декоратор допустимого диапазона результата. Проверь границы и объясни порядок двух применённых декораторов.
