# Как управлять зависимостями, версиями и воспроизводимостью

> [!NOTE]
> Прямые зависимости нужны приложению непосредственно, транзитивные приходят через них. Диапазон версий описывает совместимость, а lock или точно закреплённый набор фиксирует выбранное разрешение. Воспроизводимость зависит также от Python, платформы, источников и сборочных артефактов. `pip freeze` полезен как снимок, но не является универсальным решателем всех этих задач.

## Вопрос

Чем pyproject-зависимости отличаются от requirements и lock? Почему «на моей машине работает» не гарантирует воспроизводимую установку?

## Два разных уровня

```text
Намерение проекта: нужна библиотека совместимого диапазона
         ↓ resolver
Конкретная среда: выбранные версии прямых и транзитивных пакетов
```

Библиотека обычно не должна навязывать всем потребителям весь случайный снимок своей dev-среды. Приложение при развёртывании часто требует более строгого закрепления.

## Базовые проверки pip

```bash
python -m pip list
python -m pip freeze
python -m pip check
```

Check проверяет согласованность заявленных зависимостей установленной среды, но не отсутствие уязвимостей и не корректность приложения. Requirements-файл — формат входа pip; его можно подготовить вручную или сгенерировать выбранным инструментом.

## Современные менеджеры

Uv, Poetry и другие инструменты помогают управлять окружениями и lock-файлами. Конкретный формат и команды различаются: следуй выбранной системе проекта, а не смешивай несколько lock-файлов без причины.

Wheel — готовый формат установки пакета, sdist — исходная поставка для сборки. Наличие зависимости с C-расширением может сделать результат чувствительным к ОС, архитектуре и системным библиотекам.

## Доверие к пакетам

Проверяй точное имя: опечатка может установить другой пакет. Установка способна выполнять сборочный код. Для контролируемой доставки полезны доверенный индекс, закрепление, проверка хешей и CI на целевой платформе.

## План обновления

Меняй зависимости осознанно: обновить lock → собрать чистую среду → тесты и smoke-проверка → выпуск. Простой downgrade не откатывает автоматически схему БД или внешние данные.

## Практика

Для проекта выпиши прямые зависимости отдельно от установленных транзитивных. Опиши, как другой разработчик восстановит среду с нужной версией Python.
