# Как работают Protocol, narrowing и TypeGuard

> [!NOTE]
> Protocol описывает структурный статический интерфейс: класс подходит, если имеет нужные методы с совместимыми сигнатурами, даже без явного наследования. Narrowing уточняет тип после проверок. TypeGuard позволяет функции сообщить анализатору результат собственной проверки, но корректность этой функции остаётся ответственностью автора.

## Вопрос

Как описать duck typing для type checker и безопасно сузить object до списка строк?

## Структурный контракт

```python
from typing import Protocol

class Sender(Protocol):
    def send(self, message: str) -> None: ...

class ConsoleSender:
    def send(self, message: str) -> None:
        print(message)

def notify(sender: Sender, message: str) -> None:
    sender.send(message)

notify(ConsoleSender(), "ready")  # ready
```

ConsoleSender не наследуется от Sender, но его поведение соответствует контракту. Protocol полезен для зависимости сервиса от интерфейса и простых fake в тестах.

## Собственная проверка

```python
from typing import TypeGuard

def is_string_list(value: object) -> TypeGuard[list[str]]:
    return isinstance(value, list) and all(isinstance(item, str) for item in value)

def join_names(value: object) -> str:
    if is_string_list(value):
        return ", ".join(value)
    raise ValueError("expected a list of strings")

print(join_names(["Anna", "Ivan"]))  # Anna, Ivan
```

`all` для пустого list возвращает True, что соответствует list[str]. Если нужен непустой вход, добавляется отдельное предметное условие.

## Границы гарантии

TypeGuard не проверяет своё обещание автоматически: неверная реализация обманет анализатор. Изменение общего mutable-объекта после проверки тоже может нарушить предположение.

`@runtime_checkable` позволяет ограниченный isinstance с Protocol, но не полноценную проверку типов параметров и результата. TypeIs, доступный в typing с Python 3.13, имеет другие правила сужения обеих веток; его нельзя считать просто новым именем TypeGuard.

## Практика

Опиши Protocol Reader с read() и два независимых класса. Затем проверь входной JSON отдельным runtime-парсером, не подменяя его isinstance по Protocol.
