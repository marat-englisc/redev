# Как работают threading, Lock и разделяемое состояние

> [!NOTE]
> Потоки одного процесса разделяют память. Lock защищает выбранный критический участок от одновременного выполнения, но только если все участники соблюдают один протокол. GIL не заменяет синхронизацию прикладных инвариантов. Для передачи работ между threads подходит queue.Queue; asyncio.Queue предназначена для другого контекста и не является thread-safe-очередью.

## Вопрос

Как безопасно обновить общий счётчик? Почему «на моём запуске не сломалось» не доказывает отсутствие race condition?

## Критическая секция

```python
from concurrent.futures import ThreadPoolExecutor
from threading import Lock

lock = Lock()
state = {"count": 0}

def increment_many():
    for _ in range(100):
        with lock:
            state["count"] += 1

with ThreadPoolExecutor(max_workers=4) as pool:
    futures = [pool.submit(increment_many) for _ in range(4)]
    for future in futures:
        future.result()

print(state["count"])  # 400
```

Мы получаем result каждого Future, чтобы не потерять исключение worker. With освобождает lock при выходе, включая исключение.

## Размер участка

Защищай весь инвариант, а не одну случайную строку. Если нужно проверить остаток и списать количество, оба действия должны быть согласованы. При этом длительную сеть под одним общим lock лучше избегать: она сериализует работу.

## Deadlock

Два потока могут ждать друг друга, взяв locks в разном порядке. Договорённость об одном порядке захвата и уменьшение разделяемого состояния часто проще сложной системы блокировок. Обычный Lock не предназначен для повторного захвата тем же потоком; для соответствующего сценария есть RLock.

## Координация

Event сигнализирует состояние, Semaphore ограничивает число участников, Queue передаёт элементы. Они не взаимозаменяемы. Отмена Future не способна надёжно принудительно остановить уже исполняющийся произвольный thread-код.

## Практика

Переделай счётчик так, чтобы каждый worker возвращал локальный результат, а главный поток суммировал их. Сравни объём общего изменяемого состояния.
