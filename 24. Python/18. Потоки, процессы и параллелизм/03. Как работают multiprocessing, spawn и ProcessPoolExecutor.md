# Как работают multiprocessing, spawn и ProcessPoolExecutor

> [!NOTE]
> Процессы имеют отдельную память и позволяют распределять чистые Python-вычисления по ядрам независимо от обычного GIL одного интерпретатора. ProcessPoolExecutor управляет пулом и передачей результатов. Для spawn worker импортирует модуль, поэтому функции должны быть импортируемыми, аргументы сериализуемыми, а создание процессов защищено main guard.

## Вопрос

Зачем `if __name__ == "__main__"` при multiprocessing? Почему lambda или соединение с БД плохо подходят аргументами worker?

## Полный файл

Сохрани как `process_demo.py` и запускай как файл, не как фрагмент REPL:

```python
from concurrent.futures import ProcessPoolExecutor
from multiprocessing import get_context

def sum_squares(limit):
    return sum(value * value for value in range(limit))

def main():
    with ProcessPoolExecutor(max_workers=2, mp_context=get_context("spawn")) as pool:
        results = list(pool.map(sum_squares, [5, 10]))
    print(results)  # [30, 285]

if __name__ == "__main__":
    main()
```

Spawn выбран явно, чтобы не полагаться на меняющиеся defaults платформы и версии. Для таких маленьких задач пул медленнее обычного цикла; пример показывает механизм.

## Передача данных

Объекты обычно сериализуются и копируются между процессами. Это стоит CPU и памяти. Данные, изменённые в worker, не становятся автоматически изменёнными в родителе. Для обмена используют результаты, queues, shared memory и другие явные механизмы.

Открытое соединение, lock, локальная вложенная функция и lambda часто не имеют подходящего контракта сериализации. Создавай необходимые ресурсы внутри правильного процесса и закрывай там же.

## Стоимость и пакетирование

Для тысяч крошечных задач накладные расходы способны съесть выигрыш. Группируй работу, оцени размер передаваемых объектов и время старта. Не загружай гигантский файл полностью только для отправки каждому worker.

## Практика

Сравни локальные результаты с пулом на небольших входах. Затем объясни, как выбрать достаточно крупную CPU-задачу для осмысленного измерения ускорения.
