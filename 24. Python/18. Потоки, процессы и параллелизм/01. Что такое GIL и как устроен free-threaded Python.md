# Что такое GIL и как устроен free-threaded Python

> [!NOTE]
> В обычной GIL-сборке CPython глобальная блокировка ограничивает одновременное выполнение Python-кода потоками одного интерпретатора. Это не запрещает перекрывать I/O и не делает приложение автоматически потокобезопасным. Начиная с Python 3.13 существуют free-threaded-сборки, поэтому утверждение «в Python всегда есть GIL» неверно. Нужно учитывать конкретную реализацию и сборку.

## Вопрос

Почему threads помогают ожиданию сети, но часто не ускоряют чистые Python-вычисления? Отменяет ли GIL необходимость Lock?

## Что ограничивается

```text
Обычная GIL-сборка:
thread A → выполняет Python-код
thread B → ждёт возможности выполнения Python-кода

Ожидание I/O и некоторые нативные операции могут освобождать GIL.
```

Библиотеки с C/Rust-реализацией могут выполнять часть работы вне ограничения. Поэтому нельзя судить о параллелизме конкретного численного алгоритма только по наличию Python-обёртки.

## Это не прикладная транзакция

Последовательность «проверить наличие → добавить», инкремент общего счётчика и изменение связанных полей требуют согласования. Даже если отдельная операция в конкретной версии выглядит атомарной, бизнес-инвариант обычно шире неё.

## Определяем среду

```python
import sys
import sysconfig

print(sys.implementation.name)
print(sys.version)
print(sysconfig.get_config_var("Py_GIL_DISABLED"))
if hasattr(sys, "_is_gil_enabled"):
    print(sys._is_gil_enabled())
```

`_is_gil_enabled` зависит от версии и относится к CPython. В free-threaded-сборке некоторые несовместимые расширения способны включить GIL снова. Проверка сборки и проверка фактического режима — разные вопросы.

## Выбор инструмента

| Задача | Типовой кандидат |
| --- | --- |
| Синхронное I/O с небольшой конкуренцией | ThreadPoolExecutor |
| Много async I/O | asyncio с ограничением нагрузки |
| Чистый CPU Python в обычной GIL-сборке | ProcessPoolExecutor |
| Нативные численные вычисления | Возможности конкретной библиотеки |

## Практика

Объясни, почему GIL не защищает правило «баланс не может стать отрицательным». Назови, какие данные и операции нужно синхронизировать независимо от сборки.
