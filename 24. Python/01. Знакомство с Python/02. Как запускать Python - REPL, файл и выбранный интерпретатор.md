# Как запускать Python - REPL, файл и выбранный интерпретатор

> [!NOTE]
> Python можно использовать интерактивно в REPL или запускать сохранённый `.py`-файл. Команды `python`, `python3` и Windows `py` зависят от установки и PATH. Надёжная проверка среды — версия и `sys.executable`. Редактор, терминал и менеджер пакетов должны использовать один выбранный интерпретатор проекта.

## Вопрос

Как запустить первый файл и выяснить, почему библиотека установлена, но IDE её не видит?

## Запуск

На Windows часто доступны:

```powershell
py --version
py -3.12 hello.py
```

На Linux/macOS часто используют `python3 --version` и `python3 hello.py`. Это примеры команд, а не гарантия имени на каждой машине. Устанавливай интерпретатор из официального источника или средствами своего дистрибутива.

Содержимое `hello.py`:

```python
import sys

print("Привет, Python!")
print(sys.version)
print(sys.executable)
```

Последняя строка показывает конкретный исполняемый файл. Если pip устанавливает пакет в другую среду, простая повторная установка «куда-нибудь» не решает проблему.

## REPL

Запуск интерпретатора без имени файла открывает интерактивный режим. Приглашение `>>>` вводить не нужно. В REPL результат выражения обычно показывается автоматически, в скрипте для вывода используют `print`.

```python
2 + 3  # в скрипте само по себе ничего не напечатает
print(2 + 3)  # 5
```

`exit()` завершает интерактивную сессию. В IDE выбирай интерпретатор созданного виртуального окружения. Расширение файла `.py` помогает инструментам, но не подтверждает, какая версия его запускает.

## Ошибка и traceback

Если программа падает, читай тип исключения, сообщение и цепочку вызовов. Номер строки помогает найти место, но реальная причина иногда выше: например, функция получила неожиданные данные.

## Мини-шпаргалка

| Нужно узнать | Проверка |
| --- | --- |
| Версию | `python --version` для выбранной команды |
| Исполняемый файл | `sys.executable` |
| Рабочий каталог | `Path.cwd()` из pathlib |
| Откуда импортирован модуль | `module.__file__`, если атрибут существует |

## Практика

Запусти hello.py из терминала и IDE, сравни `sys.executable`. Они должны соответствовать одной выбранной среде проекта.
