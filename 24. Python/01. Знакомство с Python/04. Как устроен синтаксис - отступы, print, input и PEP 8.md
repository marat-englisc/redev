# Как устроен синтаксис - отступы, print, input и PEP 8

> [!NOTE]
> В Python отступы задают блоки кода, двоеточие начинает многие составные конструкции, комментарий начинается с `#`. PEP 8 рекомендует четыре пробела на уровень. `print` выводит значения, `input` возвращает строку. Удобочитаемость важнее уплотнения программы в одну строку: стиль помогает увидеть структуру и ошибки.

## Вопрос

Для чего нужны отступы? Как получить число из пользовательского ввода и почему input не возвращает int автоматически?

## Первый блок

```python
age = 20

if age >= 18:
    print("Вход разрешён")
    print("Добро пожаловать")

print("Проверка завершена")
```

Последний print находится вне if. Отступ — часть синтаксиса, а не только оформление. Не смешивай табуляцию и пробелы; редактор лучше настроить на пробелы.

## Ввод и преобразование

Интерактивный фрагмент для запуска в терминале:

```python
text = input("Возраст: ")
age = int(text)
print(f"Через год: {age + 1}")
```

Для `20` получим `21`, для `двадцать` — ValueError на преобразовании. Позже обработаем этот сценарий через try/except. `input` может также получить EOFError, если ввод закрыт.

## Многострочные выражения

```python
total = sum(
    [10, 20, 30]
)
print(total)  # 60
```

Внутри скобок выражение можно переносить без обратного слеша. Для имен функций и переменных обычно выбирают `snake_case`, для классов — `PascalCase`, для условных констант — `UPPER_CASE`. Регистр сам по себе не делает значение неизменяемым.

## Комментарий и docstring

```python
def double(value):
    """Возвращает удвоенное значение."""
    return value * 2

print(double(4))  # 8
print(double.__doc__)
```

Docstring — строка в определённой позиции определения, доступная инструментам документации. Тройные кавычки не являются специальным синтаксисом многострочного комментария.

## Что важно помнить

- `=` связывает имя, `==` сравнивает значения.
- `True`, `False`, `None` пишутся с заглавной буквы.
- Точка с запятой не нужна для обычного завершения строки.
- Кодировка исходника по умолчанию — UTF-8.
