# Что такое Python и как выполняется программа

> [!NOTE]
> **Python** — язык общего назначения с динамической типизацией и автоматическим управлением памятью. **CPython** — его основная реализация: она компилирует исходник в байткод и исполняет его интерпретатором. Python применяют в backend, автоматизации, обработке данных и тестировании. Язык, конкретный интерпретатор и установленные библиотеки — разные части среды.

## Вопрос

Что такое Python? Он компилируемый или интерпретируемый? Чем Python отличается от CPython?

## Основная идея

Программа описывает действия над объектами. Установка Python даёт интерпретатор и стандартную библиотеку; Django, pandas и pytest устанавливаются отдельно.

```python
prices = [100, 200, 300]
total = sum(prices)
print(total)  # 600
```

Python читает структуру программы, связывает имена с объектами и выполняет операции. В CPython путь упрощённо выглядит так:

```text
исходник .py → разбор и компиляция → байткод → выполнение
```

Файлы в `__pycache__` кешируют байткод импортируемых модулей. Это не самостоятельный машинный бинарник и не механизм защиты исходного кода. «Интерпретируемый» не означает «совсем без стадии компиляции».

## Важные свойства

| Свойство | Практический смысл |
| --- | --- |
| Динамическая типизация | Имя может последовательно ссылаться на объекты разных типов |
| Строгие правила операций | Строка не складывается с числом без явного преобразования |
| Автоматическая память | Обычно не нужно вручную освобождать объекты |
| Большая стандартная библиотека | Есть файлы, JSON, даты, HTTP, SQLite, процессы |

Python не работает как JavaScript в браузере без отдельной среды. Показанные в разделе блоки запускаются локальным Python; существующая JS-песочница сайта их не исполняет.

## Версии курса

Основные примеры рассчитаны на **Python 3.12+**. Возможности более новых версий отмечены отдельно. Детали вроде GIL и подсчёта ссылок описываются с оговоркой о CPython: не все реализации обязаны вести себя одинаково.

## Что важно помнить

- Знать Python — не то же самое, что знать конкретный web-фреймворк.
- Аннотации типов помогают инструментам, но не превращают язык в TypeScript.
- Уверенная база нужна и для API, и для скрипта обработки файлов.
