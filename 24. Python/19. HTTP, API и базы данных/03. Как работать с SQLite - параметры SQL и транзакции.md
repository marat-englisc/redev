# Как работать с SQLite - параметры SQL и транзакции

> [!NOTE]
> Sqlite3 — стандартный DB-API-клиент встроенной SQLite. Значения передают параметрами запроса, а не f-строкой. Транзакция объединяет изменения с commit/rollback. Контекст connection управляет транзакцией по выбранному режиму, но не закрывает соединение автоматически. Режим autocommit нужно понимать явно, особенно при переносе кода между версиями.

## Вопрос

Как защититься от SQL-инъекции и откатить несколько операций при ошибке?

## Полный пример Python 3.12+

```python
import sqlite3
from contextlib import closing

with closing(sqlite3.connect(":memory:", autocommit=False)) as connection:
    connection.execute("CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT NOT NULL)")
    connection.commit()

    try:
        with connection:
            connection.execute("INSERT INTO users VALUES (?, ?)", (1, "Anna"))
            connection.execute("INSERT INTO users VALUES (?, ?)", (1, "Duplicate"))
    except sqlite3.IntegrityError:
        pass

    print(connection.execute("SELECT COUNT(*) FROM users").fetchone()[0])  # 0

    with connection:
        connection.execute("INSERT INTO users VALUES (?, ?)", (2, "Ivan"))
    print(connection.execute("SELECT name FROM users WHERE id = ?", (2,)).fetchone()[0])
    # Ivan
```

Первую вставку откатили вместе со второй после нарушения уникальности. Таблица создана и закоммичена заранее, чтобы rollback примера не убрал саму схему.

## Почему параметры

SQL-строка задаёт структуру, tuple передаёт значения отдельно. Строка вида `"x'; DROP TABLE users; --"` должна оставаться данными. Параметры обычно не заменяют имена таблиц и колонок: динамическую структуру выбирают из allowlist.

## Границы

SQLite не полностью воспроизводит PostgreSQL по типам, конкурентности и SQL-диалекту. Проверка на SQLite не доказывает корректность production-запроса к другой СУБД. ORM также не отменяет понимание транзакций и ограничений.

## Практика

Добавь тест на rollback и вставку имени с кавычкой. Объясни, зачем нужны `(2,)` и closing вокруг connection.
