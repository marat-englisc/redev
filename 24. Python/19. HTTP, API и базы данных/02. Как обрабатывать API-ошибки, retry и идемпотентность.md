# Как обрабатывать API-ошибки, retry и идемпотентность

> [!NOTE]
> Retry повторяет только согласованные временные отказы и должен иметь предел попыток, задержки и общий временной бюджет. Идемпотентность определяет, безопасно ли повторять действие. Timeout клиента не доказывает, что сервер ничего не сделал. Ошибка валидации обычно требует исправления входа, а не бесконечного повторения.

## Вопрос

Когда можно повторять запрос после timeout? Как избежать повторной записи при неизвестном результате первой попытки?

## Контролируемый retry

```python
class TransientError(Exception):
    pass

def retry(operation, *, attempts=3):
    if attempts < 1:
        raise ValueError("attempts must be positive")
    for attempt in range(attempts):
        try:
            return operation()
        except TransientError:
            if attempt == attempts - 1:
                raise

state = {"calls": 0}
def unstable_read():
    state["calls"] += 1
    if state["calls"] < 2:
        raise TransientError("temporary")
    return "ok"

print(retry(unstable_read), state["calls"])  # ok 2
```

Это учебное ядро: в реальном клиенте между попытками нужны backoff с jitter, timeout и общий deadline. Исключение TransientError — часть контракта адаптера, не автоматическая классификация всех сетевых ошибок.

## Повторная запись

```text
Клиент отправил create → сервер создал запись → ответ потерялся
Клиент видит timeout → повторный create без защиты может создать дубль
```

Idempotency key или уникальный предметный ключ позволяет серверу связать попытки. Для чтения повторение часто проще, но также учитывают rate limits и нагрузку.

## Контракт ответа

Проверяй status, структуру, обязательные поля и диапазоны. Обработка 429 может учитывать Retry-After; 400 из-за неправильного входа обычно не станет успешным от десяти повторов. Не сохраняй токены и полный payload в сообщении ошибки.

## Практика

Проверь успешную первую попытку, временную ошибку с успехом, исчерпание попыток и постоянную ValueError без retry. Опиши, какие операции требуют серверной идемпотентности.
