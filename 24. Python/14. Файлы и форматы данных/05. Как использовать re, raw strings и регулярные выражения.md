# Как использовать re, raw strings и регулярные выражения

> [!NOTE]
> Re ищет и преобразует текст по регулярным выражениям. Search ищет совпадение внутри строки, match — в начале, fullmatch требует совпадения всего входа. Raw string удобна для шаблонов с обратными слешами. Regex не заменяет парсеры JSON/CSV и может иметь плохую производительность на специально подобранном входе.

## Вопрос

Чем search отличается от fullmatch? Как получить группы из строки и безопасно вставить буквальный текст в шаблон?

## Поиск и группы

```python
import re

pattern = re.compile(r"user=(?P<name>[A-Za-z]+) status=(?P<status>\d{3})")
match = pattern.fullmatch("user=Anna status=200")
if match is not None:
    print(match.group("name"))  # Anna
    print(int(match.group("status")))  # 200
```

`\d` в Python учитывает Unicode-цифры, если не выбран соответствующий ASCII-режим. Если формат разрешает только ASCII, используй `[0-9]` или нужные флаги. Raw string отключает обычную обработку большинства escape-последовательностей строкой, но не отменяет regex-синтаксис.

## Буквальный пользовательский текст

```python
import re

literal = "a+b"
pattern = re.compile(re.escape(literal))
print(bool(pattern.search("value=a+b")))  # True
```

Без re.escape плюс стал бы квантификатором. Для обычного поиска подстроки `literal in text` часто проще и понятнее любого regex.

## Замена и ленивые совпадения

Re.sub заменяет совпадения. Finditer выдаёт match-объекты постепенно, findall собирает результаты в list. При больших данных выбор влияет на память.

```python
import re

print(re.sub(r"\s+", " ", "a   b\nc"))  # a b c
```

## Частые ошибки

- Забывать проверить match на None.
- Использовать match, когда нужна проверка всей строки.
- Пытаться разобрать произвольную вложенную структуру простым regex.
- Принимать неограниченный вход и сложный шаблон с катастрофическим backtracking.

## Практика

Проверь формат `ORD-` и шесть ASCII-цифр через fullmatch. Добавь тест на лишний префикс, суффикс и Unicode-цифры.
