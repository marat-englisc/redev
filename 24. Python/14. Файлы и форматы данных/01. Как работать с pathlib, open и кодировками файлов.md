# Как работать с pathlib, open и кодировками файлов

> [!NOTE]
> Pathlib представляет путь объектом и предоставляет операции над файлами. Относительный путь считается от рабочего каталога процесса, а не автоматически от файла с кодом. Open различает текстовый и бинарный режим; для текстовых данных явно задавай encoding. With закрывает ресурс, а режим `w` обнуляет существующий файл.

## Вопрос

Почему файл находится при запуске из одной папки и не находится из другой? Как читать большой текст построчно?

## Самостоятельный пример

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "notes.txt"
    path.write_text("первая\nвторая\n", encoding="utf-8")
    with path.open("r", encoding="utf-8") as stream:
        for line in stream:
            print(line.rstrip("\n"))
```

Ресурс закрывается до удаления временного каталога. `read_text()` удобно для небольшого файла, но загружает весь текст. Цикл читает строки постепенно; одна чрезвычайно длинная строка всё равно может быть большой.

## Режимы

| Режим | Назначение |
| --- | --- |
| `r` | Чтение, файл должен существовать |
| `w` | Создание или обнуление и запись |
| `a` | Дописывание |
| `x` | Создание с отказом, если файл существует |
| `rb`, `wb` | Байты без текстового decode/encode |

`seek` и `tell` управляют позицией, но смещения в текстовом режиме имеют особые правила. Для произвольной побайтовой адресации выбирай бинарный режим.

## Пути

```python
from pathlib import Path

print(Path.cwd())
print(Path("data") / "input.csv")
```

Если нужен путь относительно модуля, в обычном файловом модуле применяют `Path(__file__).resolve().parent`; в REPL __file__ обычно нет. Для ресурсов установленного пакета полезен importlib.resources, а не предположение о расположении исходников.

## Что важно помнить

- Проверка exists перед open не устраняет race condition.
- Path не очищает пользовательский путь от traversal автоматически.
- Запись временного файла с последующей заменой может быть полезна для атомарного обновления, но учитывает ФС и требования к durability.

## Практика

Прочитай файл с русским текстом построчно и посчитай непустые строки. Проверь отсутствие файла и отказ кодировки отдельно.
