# Как читать и записывать CSV без split по запятой

> [!NOTE]
> CSV допускает разделители и переводы строк внутри quoted-полей, поэтому обычный split(',') не является корректным CSV-парсером. Модуль csv учитывает quoting и диалект, DictReader сопоставляет колонки заголовкам. Значения обычно приходят строками и требуют отдельного преобразования и проверки. Файлы для csv открывают с newline="" и явной кодировкой.

## Вопрос

Как разобрать CSV с запятой внутри имени? Почему чтение CSV ещё не даёт типизированные числа?

## Корректное чтение

```python
import csv
from io import StringIO

source = StringIO('name,age\n"Anna, Maria",25\nIvan,30\n', newline="")
rows = list(csv.DictReader(source))
print(rows[0]["name"])  # Anna, Maria
print(type(rows[0]["age"]).__name__)  # str
ages = [int(row["age"]) for row in rows]
print(ages)  # [25, 30]
```

Мы материализовали маленький пример для вывода. Для большого файла перебирай reader напрямую и обрабатывай записи по одной.

## Запись

```python
import csv
from io import StringIO

target = StringIO(newline="")
writer = csv.DictWriter(target, fieldnames=["name", "age"])
writer.writeheader()
writer.writerow({"name": "Anna, Maria", "age": 25})
print(target.getvalue())
```

Writer сам добавит нужное quoting. Для реального файла: `open(path, "w", newline="", encoding="utf-8")`. Заголовок, delimiter и кодировка должны соответствовать договорённости с источником.

## Валидация строк

Проверь обязательные колонки, лишние значения, пустые ячейки и диапазоны. `int("")` упадёт; реши, означает ли пустота отсутствие, ошибку или значение по умолчанию. Для идентификаторов ведущие нули могут быть значимы, поэтому автоматическое преобразование не всегда уместно.

## Безопасность экспорта

CSV сам по себе не выполняет формулы, но spreadsheet-приложение при открытии может интерпретировать значения, начинающиеся с `=`, `+` и других маркеров. Для экспорта недоверенных данных в таблицы нужна отдельная политика обработки формульных значений.

## Практика

Добавь quoted-поле с переводом строки и убедись, что это одна запись. Опиши, как сообщить номер проблемной записи без потери всех остальных данных.
