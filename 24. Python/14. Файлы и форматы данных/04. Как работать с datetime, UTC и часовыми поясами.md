# Как работать с datetime, UTC и часовыми поясами

> [!NOTE]
> Datetime бывает naive без достаточной информации о timezone и aware с ней. Для конкретных моментов времени часто используют aware UTC, а отображение переводят в нужную зону через astimezone. ZoneInfo учитывает правила IANA, включая переходы времени. `replace(tzinfo=...)` назначает интерпретацию, а не переводит уже известный момент в другую зону.

## Вопрос

Почему нельзя бездумно смешивать naive и aware даты? Как хранить время события и переводить его для пользователя?

## Момент в UTC

```python
from datetime import datetime, timezone, timedelta

event = datetime(2026, 1, 15, 12, 0, tzinfo=timezone.utc)
later = event + timedelta(minutes=30)
print(event.isoformat())  # 2026-01-15T12:00:00+00:00
print((later - event).total_seconds())  # 1800.0
```

Для текущего времени — `datetime.now(timezone.utc)`. Naive-значение от устаревающих привычек вроде utcnow не несёт timezone, несмотря на название.

## Региональная зона

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

event = datetime(2026, 1, 15, 12, tzinfo=timezone.utc)
local = event.astimezone(ZoneInfo("Europe/Berlin"))
print(local.hour)  # 13 для этой даты и правил зоны
```

На системах без IANA-базы, в частности некоторых Windows-установках, может понадобиться пакет tzdata. Не подменяй региональную зону фиксированным UTC+1, если нужен и летний период.

## Неоднозначное локальное время

При осеннем переводе часов одно и то же локальное время может соответствовать двум моментам; fold помогает их различать. При весеннем переводе некоторые локальные времена не существуют. Бизнес-правило планировщика должно явно определить поведение.

## Измерение длительности

Для продолжительности выполнения подходит time.perf_counter, а не разность настенных часов, которые могут корректироваться синхронизацией. Для календарного «через месяц» timedelta(days=30) не всегда соответствует требованию.

## Практика

Распарсь ISO-строку со смещением, переведи в UTC, затем в выбранную зону. Проверь зимнюю и летнюю даты и объясни отличие смещения от названия зоны.
