# Как работают positional-only, keyword-only и args-kwargs

> [!NOTE]
> `/` в сигнатуре отделяет positional-only параметры, `*` — начало keyword-only. `*args` собирает дополнительные позиционные аргументы в tuple, `**kwargs` — именованные в dict. Имена args/kwargs условны; специальный смысл задают звёздочки. При вызове звёздочки распаковывают iterable и mapping в аргументы.

## Вопрос

Как запретить передачу параметра по имени или, наоборот, потребовать явное имя? Чем параметры args отличаются от распаковки при вызове?

## Сигнатура как интерфейс

```python
def connect(host, /, port=5432, *, timeout=5):
    return host, port, timeout

print(connect("db.local", timeout=2))  # ('db.local', 5432, 2)
print(connect("db.local", 5433, timeout=1))  # ('db.local', 5433, 1)
# connect(host="db.local") — TypeError
# connect("db.local", 5432, 5) — TypeError
```

Timeout только по имени уменьшает неоднозначность вызова. Host positional-only позволяет считать имя параметра внутренней деталью интерфейса.

## Сбор и распаковка

```python
def describe(*args, **kwargs):
    return args, kwargs

values = [1, 2]
options = {"mode": "safe"}
print(describe(*values, **options))
# ((1, 2), {'mode': 'safe'})
```

Сбор происходит в определении, распаковка — при вызове. Одна и та же звёздочка читается по контексту.

## Ошибки вызова

Один параметр нельзя передать дважды — позиционно и по имени или через конфликтующие keyword-наборы. Для `**mapping` ключи должны быть строками; неизвестные имена отклоняются, если функция не принимает kwargs.

Не делай все функции интерфейсом `*args, **kwargs`: это скрывает контракт и затрудняет автодополнение. Обёрткам такой интерфейс нужен, обычным функциям часто полезнее явные параметры.

## Мини-шпаргалка

| Синтаксис в def | Роль |
| --- | --- |
| До `/` | Только позиционно |
| После `*` или `*args` | Только по имени |
| `*args` | Остальные позиционные |
| `**kwargs` | Остальные именованные |

## Практика

Спроектируй `read_records(path, *, limit=None, strict=True)`. Объясни, почему `read_records(path, 10, False)` хуже читается и отклоняется такой сигнатурой.
