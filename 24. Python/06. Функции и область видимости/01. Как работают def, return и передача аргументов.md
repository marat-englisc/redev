# Как работают def, return и передача аргументов

> [!NOTE]
> Def создаёт функцию и связывает её с именем. Вызов связывает параметры с переданными объектами. Return завершает функцию и возвращает значение; без явного return возвращается None. Мутация переданного list видна снаружи, переприсваивание параметра — нет. Эту модель часто называют передачей через совместное использование объектов.

## Вопрос

Как функция получает аргументы? Чем возвращаемое значение отличается от print внутри функции?

## Результат и вывод

```python
def double(value):
    return value * 2

result = double(5)
print(result + 1)  # 11

def show(value):
    print(value)

print(show(5))  # сначала 5, затем None
```

Print нужен для отображения, return — для передачи результата вызывающему коду. Функцию с возвращаемым значением проще комбинировать и тестировать.

## Мутация против перепривязки

```python
def change(items):
    items.append(3)
    items = [9]
    return items

original = [1, 2]
returned = change(original)
print(original)  # [1, 2, 3]
print(returned)  # [9]
```

Входной list изменён первым действием. Второе действие связало локальный параметр с другим list. Это не «всегда передача по значению» и не возможность перепривязать переменную вызывающей стороны.

## Контракт функции

Определи вход, результат, допустимые пустые значения, возможные исключения и побочные эффекты. Например, для среднего пустого списка можно выбрать ValueError или None, но решение должно быть предсказуемым.

```python
def average(values):
    if not values:
        raise ValueError("values must not be empty")
    return sum(values) / len(values)

print(average([10, 20]))  # 15.0
```

Ранний return помогает уменьшить вложенность. Возврат нескольких значений — обычно возврат одного tuple.
