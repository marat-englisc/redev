# Как работают замыкания и late binding

> [!NOTE]
> Замыкание сохраняет доступ функции к именам внешней функции после её завершения. В Python значение свободного имени обычно читается при вызове, а не копируется при создании callback. Поэтому функции, созданные в одном цикле, могут увидеть последнее значение переменной. Для фиксации отдельного значения используют фабрику или параметр по умолчанию.

## Вопрос

Что выведут lambda-функции, созданные в цикле? Как сохранить своё значение на каждую итерацию?

## Фабрика функций

```python
def multiply_by(factor):
    def multiply(value):
        return value * factor
    return multiply

double = multiply_by(2)
triple = multiply_by(3)
print(double(5), triple(5))  # 10 15
```

У двух вызовов multiply_by разные внешние окружения. Factor остаётся доступен, пока нужен возвращённой функции.

## Позднее связывание

```python
callbacks = [lambda: number for number in range(3)]
print([callback() for callback in callbacks])  # [2, 2, 2]
```

Функции читают общее имя number позже, когда цикл уже завершён. Comprehension изолирует это имя от внешнего namespace, но не создаёт независимую копию для каждого callback.

## Фиксируем значение

```python
callbacks = [lambda number=number: number for number in range(3)]
print([callback() for callback in callbacks])  # [0, 1, 2]
```

Default вычисляется при создании каждой функции. Здесь это намеренное использование правила, которое ранее объясняло ловушку изменяемых default.

Для более сложной логики яснее фабрика:

```python
def make_callback(number):
    def callback():
        return number
    return callback

callbacks = [make_callback(number) for number in range(3)]
print([callback() for callback in callbacks])  # [0, 1, 2]
```

## Что важно помнить

- Замыкание не обязательно должно возвращаться из функции: его могут сохранить в обработчике или передать дальше.
- Чтение внешнего имени и перепривязка различаются; для второго нужен nonlocal.
- Фиксация ссылки на изменяемый объект не замораживает его содержимое.
- Callback способен удерживать большой объект в памяти дольше ожидаемого.

## Практика

Создай callbacks для трёх имён пользователей. Проверь позднее связывание и два способа исправления.
