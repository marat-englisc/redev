# Как работают dunder-методы и протоколы Python

> [!NOTE]
> Специальные методы вроде __len__, __iter__ и __repr__ подключают объект к стандартным операциям языка. Протокол описывает ожидаемое поведение: iterable, context manager, callable и другие. Обычно вызывают len(obj), iter(obj), str(obj), а не специальные методы напрямую. Это позволяет пользовательским типам работать с привычным синтаксисом.

## Вопрос

Как сделать свой объект совместимым с len и for? Чем __str__ отличается от __repr__?

## Минимальная коллекция

```python
class Bag:
    def __init__(self, items):
        self._items = list(items)

    def __len__(self):
        return len(self._items)

    def __iter__(self):
        return iter(self._items)

    def __repr__(self):
        return f"Bag({self._items!r})"

bag = Bag([1, 2])
print(len(bag))  # 2
print(list(bag))  # [1, 2]
print(repr(bag))  # Bag([1, 2])
```

Bag здесь iterable, но не iterator: каждый вызов iter получает отдельный обход внутреннего списка.

## Представления

`__repr__` ориентирован на диагностику и по возможности однозначность, `__str__` — на удобное чтение пользователем. Если __str__ не определён, используется fallback к repr. Ни один метод не обязан раскрывать пароль или весь большой payload.

## Другие протоколы

| Операция | Типичный метод |
| --- | --- |
| `obj[index]` | __getitem__ |
| `obj(...)` | __call__ |
| `with obj` | __enter__, __exit__ |
| `a + b` | __add__ и связанные методы |
| `bool(obj)` | __bool__, иначе __len__ |

Для неподдерживаемого сочетания операндов бинарный метод часто возвращает **NotImplemented**, позволяя интерпретатору попробовать отражённую операцию. Это специальный маркер, не исключение NotImplementedError.

## Что важно помнить

Специальные методы для неявных операций часто ищутся на типе объекта. Добавление `obj.__len__ = ...` отдельному экземпляру обычно не меняет поведение len(obj). Не нужно реализовывать все методы модели данных ради одного удобного объекта.

## Практика

Добавь Bag.__contains__ или проверь membership через имеющийся iterator. Объясни, какой контракт должен выполнять собственный тип коллекции.
