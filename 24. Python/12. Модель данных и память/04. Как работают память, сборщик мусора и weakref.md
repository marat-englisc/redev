# Как работают память, сборщик мусора и weakref

> [!NOTE]
> CPython в обычных сценариях использует подсчёт ссылок и сборщик циклического мусора. Недостижимый объект может быть освобождён, но удерживаемый коллекцией объект остаётся живым, даже если он больше не нужен по смыслу. Weakref позволяет ссылаться на поддерживаемый объект без обычного удержания его жизни. Управление внешними ресурсами лучше делать через with, а не надеяться на момент финализации.

## Вопрос

Почему del не обязательно освобождает объект и почему после удаления большого списка RSS процесса может не уменьшиться сразу?

## Удаляется связь

```python
first = [1, 2]
second = first
del first
print(second)  # [1, 2]
```

Объект всё ещё достижим через second. В больших приложениях аналогичную ссылку могут сохранять кеш, global, callback, traceback или приостановленный generator.

## Циклы

Два объекта способны ссылаться друг на друга и остаться с ненулевыми счётчиками после исчезновения внешних ссылок. Циклический GC предназначен для таких достижимостных проблем в поддерживаемых объектах; это отдельный механизм, а не «периодическое удаление всего старого».

## Слабая ссылка

```python
import gc
import weakref

class User:
    pass

user = User()
reference = weakref.ref(user)
print(reference() is user)  # True
del user
gc.collect()
print(reference() is None)  # True при отсутствии других сильных ссылок
```

Не все встроенные типы напрямую поддерживают weakref. Полученный через reference() объект нужно сохранить в локальное имя, если далее используется: он мог уже исчезнуть.

## Память процесса

Аллокатор может оставить освобождённые области для дальнейшего переиспользования. Поэтому «объект больше не жив» и «ОС немедленно получила все страницы назад» — разные утверждения. `sys.getsizeof` обычно не считает рекурсивно всю вложенную структуру.

Для поиска роста используют tracemalloc, профилирование и проверку владельцев ссылок. Регулярный ручной gc.collect не является универсальным исправлением утечки.

## Практика

Найди, какие объекты удерживает кеш результата функции. Объясни, почему неограниченный кеш способен расти при полностью исправном GC.
