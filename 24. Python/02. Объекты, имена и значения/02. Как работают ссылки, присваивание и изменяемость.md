# Как работают ссылки, присваивание и изменяемость

> [!NOTE]
> Присваивание связывает имя с объектом и не копирует его автоматически. List, dict и set изменяемы; int, str и tuple неизменяемы. Мутация общего объекта видна через все ссылки, перепривязка одного имени не меняет остальные. Эта модель объясняет передачу аргументов и многие ошибки с вложенными коллекциями.

## Вопрос

Почему изменение списка видно через вторую переменную, а присваивание нового списка — нет?

## Два имени — один объект

```python
first = [1, 2]
second = first
second.append(3)
print(first)  # [1, 2, 3]

second = [9]
print(first)  # [1, 2, 3]
print(second)  # [9]
```

```text
first ──┐
        ├── список [1, 2, 3]
second ─┘   до перепривязки second
```

`append` меняет список, `second = [9]` меняет связь имени second. Это не две формы одной операции.

## Неизменяемость контейнера не равна неизменяемости содержимого

```python
record = ([1, 2], "active")
record[0].append(3)
print(record)  # ([1, 2, 3], 'active')
```

Tuple не позволяет заменить свой элемент, но этот элемент может быть изменяемым объектом. Поэтому такой tuple нельзя использовать как ключ dict: вложенный list не хешируем.

## Повторение списка

```python
bad = [[]] * 3
bad[0].append("x")
print(bad)  # [['x'], ['x'], ['x']]

good = [[] for _ in range(3)]
good[0].append("x")
print(good)  # [['x'], [], []]
```

Умножение повторило ссылки, а comprehension создал три отдельных списка. Числовая матрица `[[0] * columns] * rows` имеет ту же ловушку общих строк.

## Передача в функцию

Параметр — ещё одно имя для переданного объекта. Функция может изменить изменяемый объект, но переприсваивание параметра не перепривязывает имя вызывающей стороны. Позже это подробно разберём на функциях.

## Мини-шпаргалка

- `a = b` — общая ссылка.
- `a.append(x)` — мутация.
- `a = другой_объект` — перепривязка.
- Копия внешнего контейнера ещё не обязательно копирует вложенные объекты.

## Практика

Предскажи результат для списка словарей, созданного как `[{}] * 2`. Исправь создание так, чтобы изменение первого словаря не затрагивало второй.
