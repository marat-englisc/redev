# Какие типы есть в Python и что значит динамическая типизация

> [!NOTE]
> В Python тип принадлежит объекту, а имя связывается с объектом. Основные типы: int, float, bool, str, bytes, list, tuple, dict, set, frozenset и NoneType. Динамическая типизация позволяет перепривязать имя к другому типу, но не делает все сочетания операций допустимыми. Функции и классы тоже являются объектами.

## Вопрос

Какие типы данных нужны в повседневном Python? Чем динамическая типизация отличается от неявного приведения любых значений?

## Тип принадлежит объекту

```python
value = 42
print(type(value).__name__)  # int
value = "hello"
print(type(value).__name__)  # str
```

Число не превратилось в строку: имя value стало ссылаться на другой объект.

| Тип | Назначение | Пример |
| --- | --- | --- |
| int, float | Целые и приближённые вещественные числа | `42`, `0.5` |
| bool | Логические значения | `True`, `False` |
| str, bytes | Текст и байты | `"hello"`, `b"hello"` |
| list, tuple | Последовательности | `[1, 2]`, `(1, 2)` |
| dict | Ключ → значение | `{"name": "Anna"}` |
| set, frozenset | Уникальные элементы | `{1, 2}`, `frozenset({1})` |
| NoneType | Отсутствие значения | `None` |

## Проверка типа

```python
print(isinstance(10, int))  # True
print(isinstance(True, int))  # True
print(type(True) is int)  # False
```

bool является подклассом int. `isinstance` учитывает наследование, точная проверка через type — нет. На границе ввода, где True не должен считаться идентификатором 1, это имеет значение.

## Операции не угадывают намерение

```python
print("10" + "2")  # 102
print(int("10") + 2)  # 12
# "10" + 2 вызовет TypeError
```

Не переноси правила JavaScript: Python не складывает строку и число таким способом. Для пользовательских объектов поведение операторов определяется методами модели данных.

## Что важно помнить

- Объект имеет тип, значение и идентичность.
- Не нужно объявлять тип переменной перед первым присваиванием.
- Аннотация `age: int` сама не проверяет вход во время исполнения.
- Часто полезнее проверять требуемое поведение, чем жёстко требовать конкретный класс.

## Практика

Создай по одному значению каждого типа и выведи type. Объясни разницу пустых `{}` и `set()`: первое создаёт словарь.
