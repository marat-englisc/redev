# Чем отличаются ==, is и id

> [!NOTE]
> `==` сравнивает значения по правилам типа, `is` проверяет, один ли это объект. `id` возвращает идентификатор объекта, уникальный среди одновременно живущих объектов в этой реализации. Для None обычно пишут `value is None`. Интернирование строк и кеширование некоторых чисел — детали реализации, на которых нельзя строить сравнение значений.

## Вопрос

Когда использовать is вместо ==? Почему два равных списка могут иметь разные id?

## Значение и идентичность

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True
print(a is b)  # False
print(a is c)  # True
print(id(a) == id(c))  # True
```

У a и b одинаковые элементы, но это независимые контейнеры. У a и c одна идентичность: мутация будет видна через оба имени.

## Почему сравнение строк через is неверно

Интерпретатор может переиспользовать некоторые строковые объекты. Результат способен зависеть от способа создания строки, версии и контекста компиляции.

```python
expected = "ready"
actual = "".join(["rea", "dy"])
print(actual == expected)  # True — нужная проверка значения
```

Не пытайся добиться определённого результата `actual is expected`: для этой задачи идентичность не важна.

## None и sentinel

```python
MISSING = object()
settings = {"timeout": None}

value = settings.get("timeout", MISSING)
print(value is MISSING)  # False
print(value is None)  # True
```

Отдельный sentinel различает «ключа нет» и «значение явно None». Проверка identity не вызывает пользовательский `__eq__`, что полезно для служебного маркера.

## Границы id

В CPython id обычно соответствует адресу памяти, но язык не требует такого представления. После уничтожения объекта идентификатор может быть переиспользован. Поэтому id не подходит как постоянный ID записи, пользователя или ключ сериализации.

## Что важно помнить

| Задача | Проверка |
| --- | --- |
| Равны ли данные | `a == b` |
| Это один объект | `a is b` |
| Отсутствует значение | `value is None` |
| Служебный уникальный маркер | `value is MISSING` |

## Практика

Создай два равных dict и третье имя для первого. Проверь оба вида сравнения, затем измени один словарь и объясни результат.
