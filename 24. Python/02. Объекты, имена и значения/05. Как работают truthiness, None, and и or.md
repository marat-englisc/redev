# Как работают truthiness, None, and и or

> [!NOTE]
> В условии Python получает логическое значение объекта. False-like значения включают None, False, нули и пустые стандартные коллекции. `and` и `or` возвращают один из операндов с коротким замыканием, а не обязательно bool. Для отсутствия значения используй `is None`, если ноль, пустая строка или пустой список допустимы как данные.

## Вопрос

Чем `if value` отличается от `if value is not None`? Почему `0 or 10` возвращает 10?

## Истинность

```python
values = [None, False, 0, 0.0, "", [], {}, set(), "0", [0]]
print([bool(value) for value in values])
# [False, False, False, False, False, False, False, False, True, True]
```

Строка `"False"` тоже истинна: это непустой текст, а не логическое значение False. Поэтому `bool(input())` не является парсером человеческого ответа «да/нет».

## Операторы возвращают значения

```python
print("" or "guest")  # guest
print("anna" and "allowed")  # allowed
print(0 or 10)  # 10
```

Правый операнд вычисляется только при необходимости. Это позволяет сначала проверить объект, а затем обращаться к нему, но слишком длинные логические цепочки хуже читаются, чем if.

## Значение по умолчанию

```python
timeout = 0
wrong = timeout or 30
correct = 30 if timeout is None else timeout
print(wrong, correct)  # 30 0
```

Если ноль означает «не ждать», подмена на 30 секунд меняет смысл. Конструкция or подходит только когда **все** false-like значения действительно должны заменяться.

## Пользовательские объекты

Истинность можно определить через `__bool__` или `__len__`. Не все сторонние контейнеры допускают однозначную проверку: например, массиву значений может требоваться явное «все» или «хотя бы один». Не переносите поведение обычного list на любую библиотеку.

## Мини-шпаргалка

- `value is None` — проверка конкретного отсутствующего значения.
- `not value` — проверка всей категории false-like.
- `and/or` — короткое замыкание и возврат операнда.
- `bool(value)` — преобразование по правилам типа, а не валидация строки.

## Практика

Для параметра limit, где 0 допустим, реализуй значение по умолчанию только при None. Проверь None, 0 и 5.
