# Чем отличаются поверхностная и глубокая копии

> [!NOTE]
> Поверхностная копия создаёт новый внешний контейнер и сохраняет ссылки на вложенные объекты. `copy.deepcopy` рекурсивно копирует поддерживаемый граф с учётом повторных ссылок и циклов. Глубокая копия полезна не всегда: соединения, файлы и общие сервисы нельзя осмысленно дублировать как обычные данные. Часто лучше явно скопировать нужные уровни структуры.

## Вопрос

Почему `dict.copy()` не защищает вложенный список от изменений? Когда нужен deepcopy?

## Поверхностная копия

```python
original = {"name": "Anna", "tags": ["python"]}
shallow = original.copy()
shallow["name"] = "Ivan"
shallow["tags"].append("sql")

print(original["name"])  # Anna
print(original["tags"])  # ['python', 'sql']
print(shallow is original)  # False
print(shallow["tags"] is original["tags"])  # True
```

Изменили имя в новом dict независимо, но вложенный list общий. `list.copy()`, `items[:]` и `{**mapping}` тоже обычно дают поверхностное копирование соответствующего внешнего контейнера.

## Глубокая копия

```python
from copy import deepcopy

source = {"tags": ["python"]}
cloned = deepcopy(source)
cloned["tags"].append("sql")
print(source)  # {'tags': ['python']}
print(cloned)  # {'tags': ['python', 'sql']}
```

Deepcopy ведёт таблицу уже обработанных объектов, поэтому не просто бесконечно обходит циклы. Пользовательские классы могут настраивать копирование; не следует считать его универсальным снимком любого состояния.

## Явное обновление

```python
source = {"tags": ["python"], "enabled": True}
updated = {**source, "tags": [*source["tags"], "sql"]}
print(source["tags"])  # ['python']
```

Здесь мы намеренно заменили только изменяемый список. Другие вложенные объекты, если бы они были, могли бы остаться общими. Такой подход делает стоимость и смысл операции заметнее.

## Частые ошибки

- Путать `copy = original` с копированием.
- Применять JSON round-trip как универсальный deepcopy: теряются типы, ссылки и часть значений.
- Копировать большие структуры без оценки времени и памяти.
- Ожидать отдельную базу данных после копирования объекта соединения.

## Практика

Скопируй список словарей через `.copy()`, измени поле внутри первого словаря и объясни, что осталось общим. Затем скопируй именно нужный словарь.
