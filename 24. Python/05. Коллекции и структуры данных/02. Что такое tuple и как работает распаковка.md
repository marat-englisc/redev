# Что такое tuple и как работает распаковка

> [!NOTE]
> Tuple — неизменяемая последовательность ссылок. Кортеж создаёт запятая, поэтому одноэлементный вариант пишут `(value,)`. Распаковка связывает элементы iterable с именами; starred-цель собирает остаток в list. Неизменяемость tuple не делает его вложенные объекты неизменяемыми и не гарантирует хешируемость.

## Вопрос

Чем tuple отличается от list? Что создают `(1)` и `(1,)`?

## Кортеж как небольшая запись

```python
point = (10, 20)
x, y = point
print(x, y)  # 10 20
print(type((1)).__name__)  # int
print(type((1,)).__name__)  # tuple
```

Для координат или пары «значение, ошибка» tuple выражает фиксированную структуру. Если полей много и их смысл неочевиден, dataclass или NamedTuple с именами полей читается лучше.

## Распаковка

```python
first, *middle, last = [1, 2, 3, 4]
print(first, middle, last)  # 1 [2, 3] 4

a, b = 1, 2
a, b = b, a
print(a, b)  # 2 1
```

Без звёздочки количество элементов должно совпасть, иначе ValueError. Starred-часть может быть пустой, но нельзя бесконечно распаковывать бесконечный iterator: операция пытается потребить вход.

## Несколько возвращаемых значений

```python
def bounds(values):
    return min(values), max(values)

low, high = bounds([5, 1, 9])
print(low, high)  # 1 9
```

Функция вернула один объект tuple, который затем распакован. Для пустого входа min/max здесь выбросят ValueError — это нужно учесть в контракте функции.

## Сравнение и ключи

Tuple сравниваются лексикографически, если соответствующие элементы допускают сравнение. `(1, "a")` и `(1, 2)` могут дать TypeError при упорядочивании. В dict допустим tuple из хешируемых элементов, но не tuple с list внутри.

## Практика

Распакуй строку `"AB"` в два имени. Объясни, почему распаковка работает не только с tuple. Создай одноэлементный кортеж и проверь тип.
