# Когда нужны deque, Counter, defaultdict и namedtuple

> [!NOTE]
> Collections содержит структуры под типовые задачи: deque — двусторонняя очередь, Counter — счётчик, defaultdict — словарь с фабрикой отсутствующего значения, namedtuple — tuple с именованными полями. Они уменьшают ручной код, но имеют свои контракты: например, defaultdict создаёт значение при обращении через [], а не при get.

## Вопрос

Как посчитать частоты, сгруппировать записи и сделать очередь без постоянного сдвига list?

## Очередь

```python
from collections import deque

queue = deque(["first", "second"])
queue.append("third")
print(queue.popleft())  # first
```

Append/popleft эффективны на концах. Случайный доступ в середине deque не заменяет O(1)-индексацию list. `deque(maxlen=3)` автоматически вытесняет старые элементы при переполнении: это удобно для последних событий, но опасно как очередь задач без права потери.

## Частоты

```python
from collections import Counter

counts = Counter(["python", "sql", "python"])
print(counts["python"], counts["missing"])  # 2 0
print(counts.most_common(1))  # [('python', 2)]
```

Counter умеет хранить и нулевые/отрицательные значения после операций. Не принимай его автоматически за множество только положительных частот.

## Группировка

```python
from collections import defaultdict

groups = defaultdict(list)
for team, name in [("backend", "Anna"), ("backend", "Ivan")]:
    groups[team].append(name)
print(dict(groups))  # {'backend': ['Anna', 'Ivan']}
print(groups.get("frontend"))  # None; ключ не создаётся
```

Передаётся фабрика `list`, а не готовый `list()`. Для каждого нового ключа нужен отдельный объект.

## Именованные поля

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
point = Point(10, 20)
print(point.x, point[1])  # 10 20
```

Для новых моделей с аннотациями удобны typing.NamedTuple или dataclass. Класс namedtuple остаётся tuple-подобным: он поддерживает позиционную распаковку.

## Практика

Построй частоты статусов и список пользователей по командам. Объясни, какую часть ручного if/append заменил defaultdict.
