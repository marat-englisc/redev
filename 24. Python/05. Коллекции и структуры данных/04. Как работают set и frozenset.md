# Как работают set и frozenset

> [!NOTE]
> Set хранит уникальные хешируемые элементы и поддерживает операции множеств. Frozenset — неизменяемый вариант, который может быть ключом dict или элементом другого set. Порядок перебора set не является контрактом; для упорядоченного результата нужна отдельная сортировка или структура с сохранением порядка. Пустое множество создают через set(), потому что `{}` — dict.

## Вопрос

Как найти общие значения и разницу наборов? Как убрать дубликаты, сохранив порядок?

## Операции множеств

```python
python_users = {"Anna", "Ivan"}
sql_users = {"Ivan", "Oleg"}
print(sorted(python_users & sql_users))  # ['Ivan']
print(sorted(python_users | sql_users))  # ['Anna', 'Ivan', 'Oleg']
print(sorted(python_users - sql_users))  # ['Anna']
print(sorted(python_users ^ sql_users))  # ['Anna', 'Oleg']
```

Сортировка здесь нужна для воспроизводимого вывода, а не для правильности математических операций.

## Добавление и удаление

```python
tags = {"python"}
tags.add("sql")
tags.add("sql")
print(len(tags))  # 2
tags.discard("missing")  # нет ошибки
```

`remove` выбросит KeyError для отсутствующего элемента, discard — нет. Выбирай по контракту: отсутствие иногда должно быть заметной ошибкой.

## Дедупликация с порядком

```python
names = ["Ivan", "Anna", "Ivan"]
unique = list(dict.fromkeys(names))
print(unique)  # ['Ivan', 'Anna']
```

Здесь сохраняется порядок первого появления благодаря dict. Входные значения всё равно должны быть хешируемыми. Если предметная область считает имена разного регистра одинаковыми, сначала нужна осмысленная нормализация.

## Неизменяемое множество

```python
permissions = frozenset({"read", "write"})
cache = {permissions: "editor"}
print(cache[frozenset({"write", "read"})])  # editor
```

Порядок для равенства множества не важен. Как и у dict-ключей, `1` и `True` считаются равными элементами.
