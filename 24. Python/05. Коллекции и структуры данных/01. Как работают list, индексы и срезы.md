# Как работают list, индексы и срезы

> [!NOTE]
> List — изменяемая последовательность ссылок на объекты. Индексация начинается с нуля, отрицательный индекс отсчитывается с конца. Срез `items[start:stop:step]` создаёт новый list с выбранными элементами, правая граница не включается. Это поверхностная копия: вложенные изменяемые объекты остаются общими.

## Вопрос

Как получить часть списка, развернуть его и изменить элементы? Чем append отличается от extend?

## Индексы и срезы

```python
items = [10, 20, 30, 40, 50]
print(items[0], items[-1])  # 10 50
print(items[1:4])  # [20, 30, 40]
print(items[::2])  # [10, 30, 50]
print(items[::-1])  # [50, 40, 30, 20, 10]
print(items[100:200])  # []
```

Один неверный индекс вызывает IndexError, а срез за границами корректируется. Шаг 0 недопустим. Разворот через срез создаёт копию, `reverse()` меняет сам list.

## Изменяющие методы

```python
items = [1, 2]
items.append([3, 4])
print(items)  # [1, 2, [3, 4]]
items.extend([5, 6])
print(items)  # [1, 2, [3, 4], 5, 6]
last = items.pop()
print(last)  # 6
```

Append добавляет один объект, extend перебирает вход и добавляет его элементы. Поэтому extend от строки добавит отдельные символы.

`remove(value)` удаляет первое равное значение и бросает ValueError, если его нет. `pop(index)` возвращает удалённый элемент. Методы вроде append и reverse возвращают None: `items = items.append(x)` потеряет ссылку на список в этом имени.

## Присваивание срезу

```python
items = [1, 2, 3, 4]
items[1:3] = [20]
print(items)  # [1, 20, 4]
```

Это меняет исходный list. Для расширенного среза с шагом длина замены должна соответствовать числу заменяемых позиций.

## Что важно помнить

- Получение среза стоит времени и памяти пропорционально числу выбранных элементов.
- List может содержать разные типы, но однородные данные обычно проще обрабатывать.
- Удаление из начала list сдвигает элементы; для очереди удобнее deque.

## Практика

Получи последние три элемента без изменения исходника, затем удали их через срез. Проверь список длиной меньше трёх.
