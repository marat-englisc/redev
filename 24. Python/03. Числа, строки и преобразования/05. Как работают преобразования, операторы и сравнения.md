# Как работают преобразования, операторы и сравнения

> [!NOTE]
> Преобразование типа — явная операция, которая может завершиться ошибкой или изменить смысл данных. `int` не парсит произвольную дробную строку, `bool("False")` возвращает True. Сравнения можно соединять цепочкой, а приоритет операторов влияет на результат. Для понятности сложного выражения лучше добавить скобки или промежуточное имя.

## Вопрос

Что вернут int("10"), int(2.9) и bool("False")? Как читается `0 < x < 10`?

## Преобразование не угадывает формат

```python
print(int("10"))  # 10
print(int("ff", 16))  # 255
print(int(2.9))  # 2 — усечение к нулю
print(float("2.5"))  # 2.5
print(str(10))  # '10' при представлении результата
print(bool("False"))  # True
```

`int("2.9")` вызывает ValueError. Переход через float может внести округление и потерю точности: не превращай входной идентификатор в float ради удобства.

## Цепочки сравнений

```python
x = 5
print(0 < x < 10)  # True
print(0 < x and x < 10)  # True
```

В цепочке среднее выражение вычисляется один раз. Операторы `in`/`not in` проверяют принадлежность; для dict по умолчанию проверяются ключи.

```python
user = {"name": "Anna"}
print("name" in user)  # True
print("Anna" in user)  # False
```

## Приоритет

```python
print(2 + 3 * 4)  # 14
print((2 + 3) * 4)  # 20
print(-2 ** 2)  # -4
print((-2) ** 2)  # 4
```

Степень связывается сильнее унарного минуса в этой записи. `&`/`|` — не синонимы `and`/`or`: у них другие правила, приоритет и отсутствие такого же короткого замыкания.

## Что важно помнить

- Для нормального парсинга нужны правила диапазона и допустимого формата, а не один cast.
- Конструктор list из строки создаёт список символов, не список чисел.
- Преобразование в set убирает дубликаты и не сохраняет контракт порядка.
- Проверку None не заменяют общей truthiness-проверкой, если 0 допустим.
