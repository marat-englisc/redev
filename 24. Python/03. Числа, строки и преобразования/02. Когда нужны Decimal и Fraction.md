# Когда нужны Decimal и Fraction

> [!NOTE]
> Decimal предоставляет десятичную арифметику с настраиваемой точностью и округлением; Fraction хранит рациональную дробь как целые числитель и знаменатель. Decimal обычно создают из строки, чтобы не перенести погрешность float. Выбор числовой модели зависит от требований, а не от желания всегда использовать самый сложный тип.

## Вопрос

Как считать суммы денег без неожиданностей float? Почему `Decimal(0.1)` отличается от `Decimal("0.1")`?

## Десятичные значения

```python
from decimal import Decimal, ROUND_HALF_UP

price = Decimal("19.99")
total = price * 3
print(total)  # 59.97
print(Decimal("2.675").quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))
# 2.68
```

Число знаков и правило округления задаются явно. Decimal не знает автоматически валюту, налоговые правила или момент округления: это часть бизнес-требований.

```python
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))  # True
print(Decimal(0.1) == Decimal("0.1"))  # False
```

Во втором случае сначала возник приближённый float, а Decimal лишь точно представил это приближение.

## Точные дроби

```python
from fractions import Fraction

value = Fraction(1, 3) + Fraction(1, 6)
print(value)  # 1/2
print(value.numerator, value.denominator)  # 1 2
```

Fraction удобен для рациональных коэффициентов. При сложных вычислениях числители и знаменатели способны сильно вырасти, поэтому точность имеет стоимость.

## Сравнение

| Тип | Когда подходит | Ограничение |
| --- | --- | --- |
| int | Счётчики, целые единицы, иногда минимальные единицы денег | Нужно явно определить масштаб |
| float | Приближённые измерения и многие численные алгоритмы | Двоичные погрешности |
| Decimal | Десятичные правила расчёта | Контекст точности и округления |
| Fraction | Точные рациональные отношения | Рост размера чисел |

## Практика

Рассчитай три позиции с Decimal и округли итог до сотых. Сравни подход «округлить каждую позицию» с «округлить только итог»: правила должны определяться задачей.
