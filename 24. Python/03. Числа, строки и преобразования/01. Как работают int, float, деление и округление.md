# Как работают int, float, деление и округление

> [!NOTE]
> Python int хранит целые произвольной точности в пределах памяти. Float обычно представляет число в двоичном формате IEEE 754 double, поэтому многие десятичные дроби приближённые. `/` делит с float-результатом для обычных int, `//` округляет частное вниз, `%` даёт соответствующий остаток. Для сравнения приближённых результатов подходит math.isclose с осмысленным допуском.

## Вопрос

Почему `0.1 + 0.2 != 0.3`? Что вернут `-7 // 3` и `-7 % 3`?

## Целые и дробные

```python
print(10 ** 30 + 1)  # большое целое без потери младшего разряда
print(7 / 3)  # 2.3333333333333335
print(7 // 3, 7 % 3)  # 2 1
print(-7 // 3, -7 % 3)  # -3 2
```

Floor division идёт к минус бесконечности, а не просто отбрасывает дробь. Для целых сохраняется `a == (a // b) * b + a % b`, если b не ноль.

## Приближённость

```python
import math

print(0.1 + 0.2 == 0.3)  # False
print(math.isclose(0.1 + 0.2, 0.3))  # True
print(math.isclose(1e-12, 0.0, abs_tol=1e-9))  # True
```

Допуск зависит от предметной области. Рядом с нулём часто нужен абсолютный допуск; один относительный может не решить задачу. Для денег не стоит выбирать float только потому, что в интерфейсе видны два знака.

## Округление

```python
print(round(2.5), round(3.5))  # 2 4
print(round(2.675, 2))  # 2.67
```

Для точно представленных половин round выбирает ближайшее чётное. Но 2.675 хранится приближённо, поэтому результат нельзя объяснять как точную десятичную арифметику. Форматирование `f"{number:.2f}"` возвращает строку для отображения, а не меняет тип числа.

## Что важно помнить

- Деление на ноль вызывает исключение.
- Бесконечности и NaN возможны во float; `nan != nan`.
- У int нет фиксированного 32-битного переполнения, но операции над огромными числами не бесплатны.
- Нельзя применять один допуск ко всем научным и финансовым задачам.

## Практика

Проверь формулу деления для положительных и отрицательных a и b. Объясни различие int(-2.9) и floor(-2.9).
