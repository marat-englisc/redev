# Карта раздела Python

> [!NOTE]
> Раздел охватывает Python от первого запуска до базы Junior+ / pre-middle: модель объектов, коллекции, функции, ООП, итераторы, ошибки, типизация, I/O, тестирование, async и параллелизм. Внутри 96 учебных уроков и эта карта, сгруппированные в 21 тему. Результат — способность написать, протестировать и объяснить небольшое приложение, а не только воспроизвести синтаксис.

## Вопрос

В каком порядке изучать Python и что нужно уметь на уровне Junior+ / pre-middle?

## Как устроен материал

Формат совпадает с разделами JavaScript и TypeScript: краткий ответ для карточки, вопрос с интервью, объяснение механизма, примеры с результатом, ловушки и ссылки на документацию. Примеры следует сначала разобрать самостоятельно, затем запустить и сравнить с ожиданием.

Знание JS/TS необязательно, но сравнения помогают увидеть различия: truthiness пустых коллекций, идентичность, общие ссылки, default-аргументы, generator и запуск coroutine.

## Среда

- Основные примеры рассчитаны на Python 3.12+. Использование возможностей более новых версий отмечено отдельно.
- Сначала создай отдельную папку проекта и `.venv`, проверь `sys.executable` в терминале и IDE.
- Блоки Python запускаются локальным интерпретатором. JS-песочница сайта Python не исполняет; кнопка копирования остаётся доступной.
- Стандартная библиотека не требует отдельной установки. Pytest, mypy, Ruff и другие сторонние инструменты устанавливаются в выбранное dev-окружение.
- Если пример состоит из нескольких файлов, их имена указаны в уроке. Системные команды и результат вывода не нужно вставлять как Python-код.
- Для `zoneinfo` на некоторых системах нужна база tzdata; multiprocessing-пример запускается из сохранённого файла с main guard.

## Контрольные точки

### После основ

- [ ] Объясняю различие имени и объекта, мутации и перепривязки.
- [ ] Предсказываю результат `is`, `==`, среза и shallow copy.
- [ ] Работаю с числами, Unicode, bytes и кодировкой.
- [ ] Выбираю подходящую коллекцию и не теряю порядок случайно.

### После Junior+

- [ ] Пишу функцию с ясным контрактом и тестами на границы.
- [ ] Понимаю default-аргументы, LEGB, late binding и декораторы.
- [ ] Различаю iterator и iterable, знаю, когда вход исчерпан.
- [ ] Управляю файлами и соединениями через понятный lifecycle.
- [ ] Отделяю type hints от реальной проверки данных.
- [ ] Создаю пакет, CLI и dev-окружение, умею читать traceback.

### На подходе к pre-middle

- [ ] Разбираю причину расхода RAM и лишнего I/O.
- [ ] Выбираю asyncio/threads/processes по API и характеру нагрузки.
- [ ] Ограничиваю конкурентность и знаю границы отмены.
- [ ] Проверяю SQL-параметры, транзакции и идемпотентность повторов.
- [ ] Могу объяснить поведение MRO, hash и model protocols без заученной фразы.
- [ ] Решаю мини-проекты и задачи самостоятельно, затем сверяю разбор.

## Итоговая практика

Первый проект — CLI-отчёт по CSV с валидацией, JSON-результатом и pytest. Второй — потоковое преобразование JSONL с Decimal и понятной политикой ошибок. В задачах с лайвкодинга нужно объяснить порядок, дубликаты и память, а в подборке интервью — связать ответ с механизмом и ограничениями.

## Границы раздела и продолжение

Это курс языка, стандартной библиотеки и повседневных инженерных приёмов. Django/FastAPI, pandas/Polars/PyArrow, Airflow/Spark и ML-стек требуют отдельных материалов под выбранное направление. База Python нужна для них, но не подменяет их изучение.
