# Как использовать debugger, Ruff, mypy и проверки в CI

> [!NOTE]
> Тесты проверяют примеры поведения, type checker — совместимость аннотаций, линтер — отдельные ошибки и правила, formatter — единый стиль. Эти инструменты решают разные задачи и не заменяют друг друга. Breakpoint помогает исследовать реальное состояние процесса. CI запускает согласованный набор проверок в воспроизводимой среде.

## Вопрос

Что найдёт mypy, чего не найдёт formatter? Как отлаживать ошибку без случайных print во всех функциях?

## Инструменты

| Инструмент | Назначение |
| --- | --- |
| pytest | Поведение на выбранных сценариях |
| mypy / Pyright | Статические типовые контракты |
| Ruff check | Выбранные lint-правила |
| Ruff format | Форматирование |
| pdb / debugger IDE | Состояние во время выполнения |

После установки инструментов в dev-окружение:

```bash
python -m pytest -q
python -m mypy src
python -m ruff check .
python -m ruff format --check .
```

Настройки и набор правил фиксируются проектом. Не включай вслепую все возможные правила в существующем репозитории.

## Отладчик

```python
def normalize(value):
    cleaned = value.strip()
    breakpoint()  # интерактивно: посмотреть cleaned и стек
    return cleaned.casefold()
```

Pdb понимает команды n — следующий шаг, s — войти, c — продолжить, p expression — посмотреть значение, where — стек. Не оставляй breakpoint в unattended-задаче или production-сервисе.

## Что статическая проверка не знает

JSON может не соответствовать обещанному типу, база — вернуть неожиданные данные, а сеть — завершиться timeout. Даже идеальный отчёт mypy не отменяет runtime-валидацию и обработку отказов.

## CI

Обычно CI выбирает поддерживаемую версию Python, устанавливает закреплённые зависимости, запускает проверки и сохраняет результат. Для кроссплатформенного кода полезно тестировать несколько ОС; поведение путей и multiprocessing может различаться.

## Практика

Сделай одну ошибку типа, одну неиспользуемую переменную/импорт по включённому правилу и одну логическую ошибку. Зафиксируй, какой инструмент обнаруживает каждую.
