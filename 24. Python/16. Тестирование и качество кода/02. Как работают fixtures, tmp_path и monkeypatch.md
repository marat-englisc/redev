# Как работают fixtures, tmp_path и monkeypatch

> [!NOTE]
> Fixture готовит зависимость теста и может управлять её очисткой через yield. Scope задаёт время жизни: function, class, module, package или session. Tmp_path даёт отдельный временный каталог, monkeypatch временно меняет окружение и атрибуты с восстановлением. Чем шире scope изменяемой зависимости, тем выше риск влияния тестов друг на друга.

## Вопрос

Как проверить файловую функцию без записи в реальные пользовательские данные и временно задать env?

## Временный файл

Файл `test_files.py`:

```python
def count_nonempty(path):
    with path.open(encoding="utf-8") as stream:
        return sum(1 for line in stream if line.strip())

def test_count_nonempty(tmp_path):
    path = tmp_path / "input.txt"
    path.write_text("first\n\nsecond\n", encoding="utf-8")
    assert count_nonempty(path) == 2

def test_environment(monkeypatch):
    import os

    monkeypatch.setenv("APP_MODE", "study")
    assert os.environ["APP_MODE"] == "study"
```

Tmp_path — pathlib.Path, поэтому можно использовать обычный файловый API. Тест не зависит от текущей директории и существующих файлов проекта.

## Собственная fixture

```python
import pytest

@pytest.fixture
def records():
    return [{"id": 1}, {"id": 2}]

def test_record_count(records):
    assert len(records) == 2
```

Имя аргумента теста запрашивает fixture. При стандартном scope function каждый тест получает отдельный вызов фабрики, поэтому мутация списка в одном тесте не должна перейти в следующий.

## Очистка

Fixture с yield выполняет подготовку до yield, отдаёт значение и затем делает cleanup. Если ресурс уже поддерживает with, его удобно использовать внутри fixture. Уборка должна учитывать частично выполненную подготовку и ошибки.

## Что важно помнить

- Autouse-fixtures удобны, но скрывают зависимости теста.
- Session scope ускоряет дорогую подготовку, но требует изоляции состояния.
- Monkeypatch не гарантирует контроль над внешними процессами и уже созданными клиентами.

## Практика

Добавь тест пустого файла и файла без последнего перевода строки. Проверь, что оба выполняются в независимых временных каталогах.
