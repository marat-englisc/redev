# Как работают comprehensions и оператор присваивания :=

> [!NOTE]
> Comprehension создаёт list, dict или set из iterable по выражению и условиям. Это удобный способ выразить преобразование данных; для побочных эффектов лучше обычный for. Generator expression с круглыми скобками вычисляет элементы лениво. `:=` присваивает значение внутри выражения, но не должен превращать читаемый код в головоломку.

## Вопрос

Чем list comprehension отличается от generator expression? Когда условие находится после for, а когда перед ним?

## Преобразование и фильтрация

```python
numbers = [-2, -1, 0, 1, 2]
squares = [number ** 2 for number in numbers if number > 0]
print(squares)  # [1, 4]

labels = ["positive" if number > 0 else "other" for number in numbers]
print(labels)  # ['other', 'other', 'other', 'positive', 'positive']
```

`if` после for исключает элементы. Условное выражение перед for выбирает значение и сохраняет число элементов.

## Dict и set

```python
names = ["Anna", "Ivan", "Anna"]
lengths = {name: len(name) for name in names}
initials = {name[0] for name in names}
print(lengths)  # {'Anna': 4, 'Ivan': 4}
print(sorted(initials))  # ['A', 'I']
```

Повторный ключ dict перезаписывает предыдущее значение. Set удаляет дубликаты и не обещает порядок перебора.

## Ленивый вариант

```python
values = (number ** 2 for number in range(4))
print(sum(values))  # 14
print(list(values))  # [] — генератор исчерпан
```

Круглые скобки здесь не создают tuple. Ленивая форма полезна для одного прохода без хранения промежуточного списка.

## Walrus

```python
lines = ["  apple  ", " ", "pear"]
cleaned = [text for line in lines if (text := line.strip())]
print(cleaned)  # ['apple', 'pear']
```

Операция strip вычисляется один раз. Но важнее ясный смысл: если выражение становится длинным или имеет несколько уровней вложенности, вынеси шаги в обычный цикл или функцию.

## Частые ошибки

- `[print(x) for x in items]` создаёт бесполезный список из None.
- Огромный list comprehension не становится потоковым.
- Сложные вложенные comprehension скрывают порядок и стоимость работы.

## Практика

Получить квадраты положительных чисел, уникальные нормализованные теги и словарь id → имя. Для каждого решения объясни, где возможна потеря дубликатов.
