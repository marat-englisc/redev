# Как работают for, range, enumerate и zip

> [!NOTE]
> For перебирает iterable, а не требует числовой индекс. Range описывает арифметическую последовательность без создания списка всех чисел. Enumerate добавляет счётчик, zip объединяет элементы нескольких iterable. По умолчанию zip останавливается на коротком входе; `strict=True` помогает обнаружить неожиданную разницу длин.

## Вопрос

Как перебирать значения вместе с индексом? Что будет, если передать zip списки разной длины?

## Перебор значений

```python
names = ["Anna", "Ivan"]
for number, name in enumerate(names, start=1):
    print(number, name)
# 1 Anna
# 2 Ivan

print(list(range(2, 8, 2)))  # [2, 4, 6]
```

Правая граница range не включается. Сам range не хранит отдельный объект для каждого числа; в list мы материализовали последовательность только ради показа результата.

## Объединение входов

```python
names = ["Anna", "Ivan"]
scores = [90, 80]
for name, score in zip(names, scores, strict=True):
    print(name, score)
```

С strict при несовпадении длин возникает ValueError **во время потребления** zip. Это полезнее молчаливой потери хвоста, когда строки действительно должны соответствовать друг другу.

## Словарь

```python
scores = {"Anna": 90, "Ivan": 80}
for name, score in scores.items():
    print(f"{name}: {score}")
```

Без items перебираются ключи. Не меняй размер dict во время такого обхода. Для фильтрации создай новый dict или сначала зафиксируй отдельный список нужных ключей.

## Изменение списка при обходе

Удаление элементов из того же list сдвигает индексы и может пропустить значения. Если задача — оставить подходящие элементы, обычно яснее comprehension, чем ручное удаление во время for.

## Мини-шпаргалка

| Нужно | Подход |
| --- | --- |
| Значение | `for item in items` |
| Номер и значение | enumerate |
| Несколько последовательностей | zip |
| Ключ и значение dict | items |

## Практика

Объедини имена и оценки, затем убери одну оценку. Сравни обычный zip со strict и объясни, какой вариант соответствует контракту задачи.
