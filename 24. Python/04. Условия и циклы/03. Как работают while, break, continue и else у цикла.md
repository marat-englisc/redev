# Как работают while, break, continue и else у цикла

> [!NOTE]
> While повторяет блок, пока условие истинно. Break завершает ближайший цикл, continue начинает следующую итерацию. Else у for/while выполняется при нормальном завершении без break: после исчерпания iterable или ложного условия. Это не else последнего if, несмотря на частую ошибку чтения.

## Вопрос

Когда выполняется else у цикла? Как оформить поиск, где нужно различить «нашли» и «дошли до конца»?

## Поиск без отдельного флага

```python
numbers = [1, 3, 5]
for number in numbers:
    if number % 2 == 0:
        print("found", number)
        break
else:
    print("Чётных нет")
# Чётных нет
```

Если заменить 3 на 4, будет `found 4`, а else не выполнится. Пустой iterable тоже завершается без break, поэтому else выполняется.

## While

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
else:
    print("done")
# 3, 2, 1, затем done — каждый результат с новой строки
```

Нужно обеспечить изменение состояния или реальное событие выхода. `while True` допустим для явного бесконечного цикла с break, но сетевой retry требует лимита попыток и задержек, а не бесконечного повторения.

## Continue

```python
for value in [-1, 2, -3, 4]:
    if value < 0:
        continue
    print(value)  # 2, затем 4
```

Во while легко случайно сделать continue до обновления счётчика и получить вечный цикл. Для обычного перебора коллекции for часто безопаснее.

## Границы управления

Break действует только на ближайший цикл. Return завершает всю функцию, исключение меняет поток через обработчики. При таких выходах else цикла не становится гарантированным блоком очистки — для очистки используют finally или with.

## Практика

Напиши поиск пользователя по id с for/else. Проверь найденного, отсутствующего и пустой вход. Затем перепиши с функцией и return, сравни читаемость.
