# Вопросы Python на собеседовании - Junior+ и pre-middle

> [!NOTE]
> Для Junior+ / pre-middle важно объяснять модель объектов, контракты функций, коллекции, исключения, ООП, типы, I/O и конкурентность на конкретном примере. Сильный ответ включает результат, причину, ограничение и способ проверки. Названия уровней различаются между компаниями; эта подборка проверяет базу языка и инженерную самостоятельность, а не все требования любой вакансии.

## Вопрос

Как проверить, что я понимаю Python достаточно глубоко для Junior+ / pre-middle?

## Основы и объекты

| Вопрос | Опорная мысль |
| --- | --- |
| Python и CPython — одно и то же? | Язык и его реализация; байткод не отменяет стадию компиляции |
| Что делает присваивание? | Связывает имя с объектом, не копирует автоматически |
| Is против ==? | Идентичность против сравнения значений |
| Почему `[[]] * 3` опасно? | Повторяются ссылки на один внутренний list |
| Tuple всегда хешируем? | Только если хешируемы его элементы |
| Shallow против deep copy? | Новый внешний контейнер против рекурсивного копирования поддерживаемого графа |
| Почему `0 or 10` может быть багом? | Значение 0 подменяется default |
| Почему float не подходит для точных десятичных правил? | Двоичное приближение; Decimal из строки и явное округление |
| Str против bytes? | Текст против байтов; encode/decode с выбранной кодировкой |

## Итерация, ошибки и классы

| Вопрос | Опорная мысль |
| --- | --- |
| Iterable против iterator? | Предоставление обхода против состояния next |
| Когда выполняется generator? | При потреблении, с приостановкой на yield |
| Groupby как SQL GROUP BY? | Только соседние одинаковые ключи |
| Что делает with? | Протокол управления ресурсом, не универсальная транзакция |
| Может finally скрыть ошибку? | Да, через новый управляющий выход или исключение |
| Raise from зачем? | Явная цепочка технической причины и прикладной ошибки |
| __new__ против __init__? | Создание экземпляра против инициализации |
| Super — это родитель? | Продолжение поиска по MRO |
| Classmethod против staticmethod? | Получает cls против отсутствия автоматического self/cls |
| Dataclass валидирует аннотации? | Нет, нужны отдельные проверки |
| Frozen глубоко неизменяем? | Нет, вложенный list может изменяться |
| Eq и hash связаны как? | Равные объекты обязаны иметь одинаковый hash |

## Типы, I/O и конкурентность

| Вопрос | Опорная мысль |
| --- | --- |
| Any против object? | Ослабленная проверка против необходимости сузить общий тип |
| Optional означает необязательный аргумент? | Нет, только возможность None; default решает способ вызова |
| Generic против Any? | Сохраняет связь типов |
| Protocol против ABC? | Структурный статический контракт против номинального базового класса |
| JSON loads уже валидирует запись? | Только формат; схему и диапазоны проверяют отдельно |
| Почему нельзя split CSV по запятой? | Quoting, разделители и переносы внутри поля |
| На что влияет timezone? | Интерпретация момента, переводы и неоднозначности DST |
| Async def запускает задачу сразу? | Нет, возвращает coroutine; нужен await/планирование |
| Gather и TaskGroup одинаково обрабатывают ошибку? | Нет, политика соседних задач различается |
| Cancel гарантирует остановку внешней операции? | Нет, отмена кооперативна и не равна rollback |
| GIL убирает race conditions? | Нет; состояние требует согласования |
| GIL есть во всех Python? | Нет, учитываем реализацию и free-threaded-сборки |
| Почему процессы могут быть медленнее? | Старт, сериализация и копирование данных |
| Генератор гарантирует постоянную память? | Нет, есть размер записи, буферы и накопители |
| Почему не f-string для SQL? | Значения передают отдельно параметрами |
| Patch где применять? | В namespace, где код ищет имя |

## Ситуационная задача

«Скрипт читает 10 ГБ данных, постепенно увеличивает RAM и повторно пишет записи после timeout. Как разбирать?»

Отдели симптомы: измерить память и найти материализацию/кеш; определить размер записи и число уникальных ключей; проверить batch/очереди; выяснить, был ли запрос выполнен до timeout; организовать идемпотентную запись и проверяемое восстановление. Добавь тесты и повтори измерение на сопоставимом входе.

## Критерии готовности

- Объясняешь результат примера до запуска.
- Умеешь собрать и протестировать оба мини-проекта.
- Различаешь контракт типов и реальную валидацию.
- Выбираешь модель конкурентности по bottleneck и измерениям.
- Читаешь traceback и находишь причину, не скрывая ошибку общим except.

Для конкретного направления отдельно изучаются framework и инфраструктура: backend, data engineering и автоматизация имеют разные дополнительные требования.
