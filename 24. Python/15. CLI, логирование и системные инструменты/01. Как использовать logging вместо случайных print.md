# Как использовать logging вместо случайных print

> [!NOTE]
> Logging отделяет событие от способа доставки: уровни, logger, handlers и formatters позволяют управлять журналом без переписывания всей программы. Модуль обычно получает logger через getLogger(__name__), а конфигурацию задаёт приложение. Exception внутри except добавляет traceback. Секреты и полные входные payload не должны попадать в лог автоматически.

## Вопрос

Зачем logging, если есть print? Чем logger.exception отличается от logger.error?

## Базовый пример

```python
import logging

logging.basicConfig(level=logging.INFO, format="%(levelname)s %(name)s %(message)s")
logger = logging.getLogger(__name__)

def process(identifier):
    logger.info("Processing record id=%s", identifier)
    return identifier * 2

print(process(7))  # 14; отдельно появится INFO-событие
```

По умолчанию стандартный handler часто пишет в stderr, а print — в stdout. Это удобно для CLI, где stdout содержит машинный результат.

## Уровни

| Уровень | Типичный смысл |
| --- | --- |
| DEBUG | Подробная диагностика |
| INFO | Нормальные значимые события |
| WARNING | Необычный, но обработанный исход |
| ERROR | Операция не выполнена |
| CRITICAL | Серьёзный отказ системы |

Уровень — политика проекта, а не обязанность логировать каждую строку кода.

## Исключения

```python
import logging

logger = logging.getLogger(__name__)
try:
    int("bad")
except ValueError:
    logger.exception("Cannot parse configured integer")
```

Exception используй в обработчике, когда нужен текущий traceback. Не логируй одну ошибку на каждом уровне и затем ещё в entry point: это создаёт дубли без новой информации.

## Отложенное форматирование

`logger.debug("value=%s", value)` откладывает форматирование до решения о выводе. Но выражение аргумента, например `expensive()` вместо value, всё равно вычисляется до вызова. Для дорогого расчёта может потребоваться isEnabledFor.

## Практика

Сделай CLI с JSON в stdout и журналом в stderr. Перенаправь их в разные файлы и проверь, что лог не ломает JSON-парсер.
