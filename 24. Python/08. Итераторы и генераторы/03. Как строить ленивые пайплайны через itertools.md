# Как строить ленивые пайплайны через itertools

> [!NOTE]
> Itertools предоставляет комбинаторы iterator: chain объединяет входы, islice ограничивает обход, batched группирует элементы, groupby объединяет соседние одинаковые ключи. Пайплайн остаётся экономным по памяти, только если каждый этап не материализует весь вход. У некоторых операций есть внутреннее накопление, например tee может буферизовать отстающую ветку.

## Вопрос

Как обработать данные пакетами? Почему itertools.groupby не равен SQL GROUP BY?

## Ограничение и объединение

```python
from itertools import chain, islice

combined = chain([1, 2], [3, 4])
print(list(islice(combined, 3)))  # [1, 2, 3]
```

Islice потребляет вход до нужной позиции. Он не обеспечивает произвольный доступ как list-срез и не поддерживает отрицательные индексы.

## Пакеты

```python
from itertools import batched

print(list(batched(range(5), 2)))  # [(0, 1), (2, 3), (4,)]
```

Batched доступен с Python 3.12. Последний пакет может быть короче — обработчик должен это учитывать. Размер пакета ограничивает число элементов, но не их суммарный размер в байтах.

## Только соседние группы

```python
from itertools import groupby

values = ["a", "a", "b", "a"]
print([(key, list(group)) for key, group in groupby(values)])
# [('a', ['a', 'a']), ('b', ['b']), ('a', ['a'])]
```

Чтобы собрать все одинаковые ключи, часто нужна предварительная сортировка по тому же ключу. Но сортировка требует данных в памяти или внешнего алгоритма. Для несортированного потока альтернативой бывает Counter/defaultdict с памятью по числу уникальных ключей.

Итератор группы разделяет исходный поток с groupby. Сохранять группу «на потом» без потребления нельзя считать независимым снимком.

## Частые ошибки

- Передать бесконечный count в list без ограничения.
- Использовать tee как бесплатное копирование потока при разной скорости потребителей.
- Забыть, что product/combinations могут создавать очень много результатов и хранить исходные наборы.

## Практика

Разбей семь записей на пакеты по три. Объясни, сколько элементов в последнем пакете, и посчитай сумму без промежуточного полного list.
