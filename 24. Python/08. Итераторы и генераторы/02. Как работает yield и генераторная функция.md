# Как работает yield и генераторная функция

> [!NOTE]
> Функция с yield при вызове создаёт generator, а её тело начинает выполняться при потреблении. Yield отдаёт элемент и приостанавливает выполнение, сохраняя локальное состояние. Следующий next продолжает с этой точки. Генератор полезен для потоковой обработки и последовательностей, которые не нужно хранить целиком.

## Вопрос

Чем yield отличается от return? Когда фактически выполняется тело генераторной функции?

## Пошаговый запуск

```python
def numbers():
    print("start")
    yield 1
    print("continue")
    yield 2

values = numbers()
print("created")
print(next(values))
print(next(values))
# created
# start
# 1
# continue
# 2
```

Сам вызов numbers не напечатал start. В отличие от yield, обычный return завершает генератор. После окончания новых значений не будет.

## Поток преобразований

```python
def positive_squares(values):
    for value in values:
        if value > 0:
            yield value * value

print(list(positive_squares([-2, 1, 3])))  # [1, 9]
```

List здесь нужен только для показа. В реальном пайплайне можно сразу передать generator в sum или следующую функцию.

## Ленивая ошибка

Ошибка внутри тела возникает при потреблении, а не обязательно при создании generator. Поэтому try вокруг одного вызова функции может не перехватить ошибку, которая случится позже в for.

```python
def parse(values):
    for value in values:
        yield int(value)

try:
    print(list(parse(["1", "bad"])))
except ValueError:
    print("Ошибка возникла во время обхода")
```

## Что важно помнить

- Generator одноразовый и удерживает локальное состояние между yield.
- Ленивость снижает хранение промежуточных данных, но не размер одного элемента.
- `list(generator)` материализует результат и может исчерпать RAM.
- Открытый ресурс внутри приостановленного генератора может оставаться открытым.

## Практика

Сделай генератор нормализованных непустых строк. Прочитай только первый результат и объясни, какая часть входа уже обработана.
