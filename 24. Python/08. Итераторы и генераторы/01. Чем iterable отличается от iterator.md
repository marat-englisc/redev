# Чем iterable отличается от iterator

> [!NOTE]
> Iterable умеет предоставить iterator через iter(). Iterator хранит состояние обхода, выдаёт элементы через next() и сообщает об окончании StopIteration. List можно обходить заново: каждый iter(list) создаёт отдельный iterator. Генератор — iterator, обычно одноразовый; после исчерпания он не начинает работу сначала.

## Вопрос

Что происходит внутри for? Почему второе чтение generator даёт пустой результат?

## Механизм for

```python
items = [10, 20]
iterator = iter(items)
print(next(iterator))  # 10
print(next(iterator))  # 20
print(next(iterator, "finished"))  # finished
```

Без второго аргумента next после конца выбросил бы StopIteration. For получает iterator и сам завершает цикл при этом сигнале.

```text
iter(items) → next → значение → тело цикла
                   → ...
                   → StopIteration → конец
```

## Повторный и одноразовый обход

```python
items = [1, 2, 3]
print(sum(items), sum(items))  # 6 6

iterator = iter(items)
print(sum(iterator))  # 6
print(sum(iterator))  # 0
```

Sum получил уже исчерпанный iterator во втором вызове. Проверка или логирование через `list(iterator)` тоже потребляет вход.

## Что считать контрактом

Если функции нужно два прохода, ей нужен повторяемый вход, явная материализация или иной алгоритм. Аннотация Iterable не обещает повторяемость. Для файлов обход также связан с текущей позицией: второй цикл не обязан автоматически делать seek(0).

## Ручной класс

Свой iterator реализует `__iter__`, возвращающий self, и `__next__`. Но генераторная функция обычно проще и читабельнее, если не нужны дополнительные методы и состояние интерфейса.

## Частые ошибки

- Проверять непустоту iterator через bool: объект может быть truthy даже после исчерпания.
- Потреблять вход для диагностики и затем передавать его основной логике.
- Обещать постоянную память только потому, что используется iterator: следующий этап может собрать list.

Передай list и iter(list) в одну функцию с двумя проходами. Найди различие и явно определи допустимый тип входа.
