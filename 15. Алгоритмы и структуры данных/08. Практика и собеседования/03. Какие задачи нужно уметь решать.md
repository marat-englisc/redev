# Какие задачи нужно уметь решать?

> [!NOTE]
> Для frontend/fullstack собеседований на JavaScript/TypeScript важно уверенно решать базовые задачи на массивы, строки, Map/Set, стек, очередь, linked list, trees, graphs, recursion, DP и сортировку.

## Вопрос

Какие типы задач нужно уметь решать для собеседования frontend-разработчика?

## Что отвечать на собеседовании?

Для подготовки нужно не заучить сотни задач, а освоить паттерны: two pointers, sliding window, prefix sums, hash map, stack, BFS/DFS, recursion, backtracking, DP и greedy. Тогда новые задачи становятся вариациями знакомых схем.

## Что важно помнить: частые ошибки

- Решать задачи случайно без паттернов.
- Не повторять старые задачи.
- Не проговаривать сложность.
- Не писать тесты руками.
- Игнорировать linked list и graphs.
- Учить только решения, а не идеи.

## Мини-шпаргалка

- Arrays/strings - база.
- Map/Set - частоты и lookup.
- Stack - вложенность.
- Queue - BFS.
- Trees - recursion.
- Graphs - visited.
- DP - state/transition.
