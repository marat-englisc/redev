# Чем greedy отличается от dynamic programming?

> [!NOTE]
> Greedy делает локально лучший выбор и не пересматривает его. Dynamic Programming хранит ответы подзадач и рассматривает варианты. Greedy быстрее и проще, но работает только если локальный выбор гарантирует глобальный оптимум.

## Вопрос

Чем greedy отличается от dynamic programming и как понять, что жадный подход корректен?

## Greedy example

Задача: максимум активностей без пересечений.

Идея: сортируем по времени окончания и берем первую совместимую.

```ts
type Interval = [number, number]

function maxNonOverlapping(intervals: Interval[]): number {
  intervals.sort((a, b) => a[1] - b[1])

  let count = 0
  let lastEnd = -Infinity

  for (const [start, end] of intervals) {
    if (start >= lastEnd) {
      count++
      lastEnd = end
    }
  }

  return count
}
```

## DP example

Knapsack нельзя надежно решить greedy по value/weight, потому что локально лучший предмет может испортить глобальный ответ.

Там нужны варианты:

```text
take item
skip item
```

## Как отличить?

Greedy подходит, если:

- есть доказуемое greedy choice property;
- локальный выбор не мешает будущему;
- можно обменным аргументом доказать оптимальность.

DP подходит, если:

- есть повторяющиеся подзадачи;
- нужно сравнивать варианты;
- состояние можно описать параметрами.

## Что отвечать на собеседовании?

Greedy выбирает лучший вариант прямо сейчас и не хранит все подзадачи. DP систематически перебирает состояния и сохраняет результаты. Greedy обычно быстрее, но требует доказательства, что локальный выбор ведет к глобальному оптимуму. Если такого свойства нет, часто нужен DP.

## Что важно помнить: частые ошибки

- Использовать greedy без доказательства.
- Решать 0/1 knapsack greedy.
- Называть любое быстрое решение greedy.
- Не объяснять, почему локальный выбор безопасен.
- Использовать DP там, где достаточно greedy.

## Мини-шпаргалка

- Greedy = локальный выбор.
- DP = состояния и варианты.
- Greedy needs proof.
- DP needs state/transition.
- Greedy часто `O(n log n)` из-за сортировки.
- Knapsack 0/1 обычно DP.
