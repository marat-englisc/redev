# Как решать DP по строкам и таблицам?

> [!NOTE]
> DP по строкам и таблицам часто строится на двумерном состоянии `dp[i][j]`: префикс первой строки и префикс второй строки, или клетка `i,j` в grid. Классика: LCS, edit distance, unique paths.

## Вопрос

Как решать DP-задачи по строкам и таблицам: LCS, edit distance, пути в сетке?

## Longest Common Subsequence

State:

```text
dp[i][j] = LCS длина для text1[0..i) и text2[0..j)
```

```ts
function longestCommonSubsequence(a: string, b: string): number {
  const dp = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0))

  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1])
      }
    }
  }

  return dp[a.length][b.length]
}
```

## Grid DP

Unique paths:

```ts
function uniquePaths(rows: number, cols: number): number {
  const dp = Array.from({ length: rows }, () => new Array(cols).fill(1))

  for (let r = 1; r < rows; r++) {
    for (let c = 1; c < cols; c++) {
      dp[r][c] = dp[r - 1][c] + dp[r][c - 1]
    }
  }

  return dp[rows - 1][cols - 1]
}
```

## Как думать?

1. Что означает `dp[i][j]`?
2. Какие base cases?
3. От каких соседей зависит state?
4. В каком порядке заполнять таблицу?
5. Где лежит answer?

## Что отвечать на собеседовании?

В строковых и grid DP часто используется двумерная таблица. Для строк `dp[i][j]` обычно означает ответ на префиксах двух строк. Для grid `dp[r][c]` означает лучший/количество способов дойти до клетки. Важно четко определить state, transition, base cases и порядок заполнения.

## Что важно помнить: частые ошибки

- Не добавлять extra row/column для пустого префикса.
- Путать `i` и `i - 1` в строке.
- Заполнять таблицу в неправильном порядке.
- Не понимать, что именно хранит `dp[i][j]`.
- Сразу оптимизировать память до понимания 2D решения.

## Мини-шпаргалка

- Strings -> prefixes.
- Grid -> cells.
- `dp[i][j]` должен иметь смысл.
- Base row/column часто нули или единицы.
- Transition from neighbors.
- Answer usually bottom-right.
