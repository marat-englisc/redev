# Что такое array и dynamic array?

> [!NOTE]
> Array - индексируемая последовательность элементов. Dynamic array может менять размер: при добавлении элементов он иногда выделяет больше памяти и копирует данные, поэтому `push` обычно считается amortized `O(1)`.

## Вопрос

Что такое array и dynamic array и почему push в среднем работает за O(1)?

## Array как структура данных

Array дает быстрый доступ по индексу:

```ts
const nums = [10, 20, 30]

console.log(nums[1]) // 20
```

Доступ:

```text
O(1)
```

## Почему dynamic?

В JavaScript массивы изменяемые:

```ts
const nums: number[] = []

nums.push(1)
nums.push(2)
nums.push(3)
```

Внутри движок сам управляет памятью. Модель dynamic array полезна для понимания:

- быстрый доступ по индексу;
- быстрый push в конец;
- дорогие вставки в начало/середину;
- сдвиги элементов при `shift`, `unshift`, `splice`.

## Типичные сложности

| Операция | Сложность |
| --- | --- |
| access by index | `O(1)` |
| update by index | `O(1)` |
| search by value | `O(n)` |
| push end | amortized `O(1)` |
| pop end | `O(1)` |
| insert/delete middle | `O(n)` |

## Что отвечать на собеседовании?

Массив - линейная структура с доступом по индексу. Dynamic array умеет расти, поэтому добавление в конец обычно amortized `O(1)`, но вставка или удаление в начале/середине требует сдвига элементов и стоит `O(n)`.

## Что важно помнить: частые ошибки

- Считать любые операции массива `O(1)`.
- Использовать массив как очередь через `shift` на больших данных.
- Не учитывать копии через `slice`.
- Забывать, что поиск по значению линейный.
- Мутировать input без согласования.

## Мини-шпаргалка

- Индекс - `O(1)`.
- Поиск - `O(n)`.
- `push/pop` - быстро.
- `shift/unshift` - дорого.
- Вставка в середину - `O(n)`.
- Dynamic array растет автоматически.
