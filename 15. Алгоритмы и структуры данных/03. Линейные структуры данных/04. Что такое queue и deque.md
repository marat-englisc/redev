# Что такое queue и deque?

> [!NOTE]
> Queue работает по принципу FIFO: first in, first out. Deque позволяет добавлять и удалять элементы с обеих сторон. В алгоритмах очередь нужна для BFS, задач по уровням, simulation и sliding window.

## Вопрос

Что такое queue и deque и как реализовать очередь в JavaScript без O(n) на shift?

## Queue

Очередь:

```text
enqueue -> [1, 2, 3] -> dequeue gives 1
```

На массиве без `shift`:

```ts
class Queue<T> {
  private items: T[] = []
  private head = 0

  enqueue(value: T): void {
    this.items.push(value)
  }

  dequeue(): T | undefined {
    if (this.head >= this.items.length) return undefined
    return this.items[this.head++]
  }

  get size(): number {
    return this.items.length - this.head
  }
}
```

## Почему не shift?

```ts
queue.shift()
```

Для больших массивов может быть `O(n)`, потому что элементы сдвигаются.

## Deque

Deque, double-ended queue, поддерживает:

- push back;
- pop back;
- push front;
- pop front.

В JavaScript нет встроенного Deque. Для интервью часто хватает массива с индексами или собственной реализации.

## BFS

```ts
function bfs(start: string, graph: Map<string, string[]>): string[] {
  const result: string[] = []
  const visited = new Set([start])
  const queue = [start]
  let head = 0

  while (head < queue.length) {
    const node = queue[head++]
    result.push(node)

    for (const next of graph.get(node) ?? []) {
      if (!visited.has(next)) {
        visited.add(next)
        queue.push(next)
      }
    }
  }

  return result
}
```

## Что отвечать на собеседовании?

Queue - FIFO-структура, где первым выходит самый старый элемент. Она нужна для BFS, обработки задач по порядку и level-order traversal. В JS для большой очереди лучше не использовать `shift`, а хранить индекс `head`. Deque расширяет очередь и позволяет работать с двумя концами.

## Что важно помнить: частые ошибки

- Использовать `shift()` в BFS на больших данных.
- Не отмечать вершину visited при добавлении в очередь.
- Путать stack DFS и queue BFS.
- Не очищать старые элементы при долгой жизни очереди.
- Ожидать встроенный Deque в JS.

## Мини-шпаргалка

- Queue = FIFO.
- Stack = LIFO.
- BFS использует queue.
- В JS лучше `head` index.
- Deque работает с двумя концами.
- Sliding window иногда использует deque.
