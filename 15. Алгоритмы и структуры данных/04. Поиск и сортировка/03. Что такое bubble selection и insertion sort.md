# Что такое bubble selection и insertion sort?

> [!NOTE]
> Bubble, selection и insertion sort - простые сортировки с `O(n^2)`. В production их почти не используют для больших данных, но они помогают понять сравнения, swaps, in-place сортировку и базовую сложность.

## Вопрос

Как работают bubble, selection и insertion sort и когда простые сортировки полезны?

## Bubble sort

```ts
function bubbleSort(nums: number[]): number[] {
  for (let i = 0; i < nums.length; i++) {
    for (let j = 0; j < nums.length - 1 - i; j++) {
      if (nums[j] > nums[j + 1]) {
        ;[nums[j], nums[j + 1]] = [nums[j + 1], nums[j]]
      }
    }
  }

  return nums
}
```

Большие элементы "всплывают" вправо.

## Selection sort

```ts
function selectionSort(nums: number[]): number[] {
  for (let i = 0; i < nums.length; i++) {
    let minIndex = i

    for (let j = i + 1; j < nums.length; j++) {
      if (nums[j] < nums[minIndex]) minIndex = j
    }

    ;[nums[i], nums[minIndex]] = [nums[minIndex], nums[i]]
  }

  return nums
}
```

На каждом шаге ищем минимум в оставшейся части.

## Insertion sort

```ts
function insertionSort(nums: number[]): number[] {
  for (let i = 1; i < nums.length; i++) {
    const current = nums[i]
    let j = i - 1

    while (j >= 0 && nums[j] > current) {
      nums[j + 1] = nums[j]
      j--
    }

    nums[j + 1] = current
  }

  return nums
}
```

Хорош для маленьких или почти отсортированных массивов.

## Что отвечать на собеседовании?

Это учебные `O(n^2)` сортировки. Bubble меняет соседние элементы, selection ищет минимум для текущей позиции, insertion вставляет текущий элемент в уже отсортированную левую часть. Insertion sort может быть эффективен на маленьких или почти отсортированных данных.

## Что важно помнить: частые ошибки

- Использовать bubble sort как реальное решение для больших данных.
- Ошибаться в границах вложенного цикла.
- Не понимать, какие алгоритмы in-place.
- Забывать, что insertion sort имеет хороший best case на почти sorted data.
- Не уметь объяснить идею без кода.

## Мини-шпаргалка

- Bubble - swap соседей.
- Selection - ищет минимум.
- Insertion - вставляет в sorted prefix.
- Все обычно `O(n^2)`.
- In-place memory `O(1)`.
- Useful for learning, not large production data.
