# Что такое binary search tree?

> [!NOTE]
> Binary Search Tree, BST, - бинарное дерево, где для каждого узла значения слева меньше, а значения справа больше. Это позволяет искать, вставлять и удалять элементы в среднем за `O(log n)`, если дерево сбалансировано.

## Вопрос

Что такое binary search tree и почему без балансировки он может выродиться?

## Правило BST

```text
left subtree < node < right subtree
```

Для каждого узла, не только для root.

## Поиск

```ts
type TreeNode = {
  value: number
  left: TreeNode | null
  right: TreeNode | null
}

function search(root: TreeNode | null, target: number): TreeNode | null {
  let current = root

  while (current) {
    if (current.value === target) return current
    current = target < current.value ? current.left : current.right
  }

  return null
}
```

## Сложность

Balanced BST:

```text
O(log n)
```

Degenerate tree:

```text
O(n)
```

Если дерево превратилось в список, преимуществ почти нет.

## Проверка BST

```ts
function isValidBST(root: TreeNode | null, min = -Infinity, max = Infinity): boolean {
  if (!root) return true
  if (root.value <= min || root.value >= max) return false

  return (
    isValidBST(root.left, min, root.value) &&
    isValidBST(root.right, root.value, max)
  )
}
```

## Что отвечать на собеседовании?

BST - binary tree с порядковым invariant: все значения слева меньше текущего, справа больше. Если дерево сбалансировано, поиск/вставка/удаление занимают `O(log n)`. В худшем случае несбалансированное BST становится похожим на linked list и операции деградируют до `O(n)`.

## Что важно помнить: частые ошибки

- Проверять только прямых детей, а не весь диапазон subtree.
- Не учитывать duplicates.
- Считать BST всегда balanced.
- Не понимать inorder traversal.
- Забывать worst case `O(n)`.

## Мини-шпаргалка

- Left < node < right.
- Inorder дает sorted order.
- Balanced -> `O(log n)`.
- Worst -> `O(n)`.
- Validate через min/max.
- Duplicates нужно оговаривать.
