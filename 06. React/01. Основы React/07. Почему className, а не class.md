# Почему в React используют className вместо class

> [!NOTE]
> Для обычных DOM-элементов React использует prop **className**. React DOM записывает его значение в HTML-атрибут class.

## Вопрос

Почему в JSX пишут className? Связано ли это с тем, что class - ключевое слово JavaScript?

## Объяснение

В HTML CSS-классы задают атрибутом `class`, а в DOM API соответствующее свойство называется `className`. React исторически использует имена многих DOM-свойств: `className`, `htmlFor`, `tabIndex`.

Нельзя объяснять это запретом ключевого слова `class` в объектах JavaScript. Запись `const options = { class: "card" }` корректна в современном JavaScript. Причина - выбранный интерфейс React DOM и его соглашения об именах.

JSX не переименовывает все атрибуты подряд. Например, `aria-label` и `data-testid` сохраняют дефисы. События обычно имеют camelCase-имена: `onClick`, `onChange`.

## Пример: класс зависит от состояния

```jsx
import { useState } from "react";

export default function ThemePreview() {
  const [isDark, setIsDark] = useState(false);

  return (
    <section className={isDark ? "preview dark" : "preview light"}>
      <label htmlFor="dark-mode">Темная тема</label>
      <input
        id="dark-mode"
        type="checkbox"
        checked={isDark}
        onChange={event => setIsDark(event.currentTarget.checked)}
      />
      <p>Здесь будет пример текста.</p>
    </section>
  );
}
```

Первоначально у секции будут классы `preview light`. После переключения - `preview dark`. CSS-правила для этих классов нужно определить отдельно: сам `className` не создает стили.

В браузерном HTML результат выглядит так:

```html
<section class="preview dark">...</section>
```

## Как запомнить соответствия

| В HTML | В JSX для React DOM |
| --- | --- |
| class | className |
| for у label | htmlFor |
| tabindex | tabIndex |
| aria-label | aria-label |
| data-id | data-id |

## Частые ошибки

Указание `className` на собственном компоненте еще не гарантирует класс на DOM-узле. Компонент должен прочитать prop и передать его подходящему HTML-элементу.

Несколько классов передаются одной строкой с пробелами. Массив строк напрямую вместо `className` использовать не следует.

## Что важно помнить

- `class` — зарезервированное слово JavaScript, а JSX компилируется в JS-объект props.
- React использует имена DOM-свойств: `className`, `htmlFor`, `tabIndex`.
- Атрибуты `data-*` и `aria-*` пишутся как в HTML, через дефис.
- Для условных классов удобны утилиты `clsx` или `classnames`.

## Мини-шпаргалка

- JSX: `className="card"`.
- HTML после рендера: `class="card"`.
- Имена props React DOM не полностью совпадают с HTML.
- Зарезервированное слово JavaScript здесь не объясняет ограничение.
