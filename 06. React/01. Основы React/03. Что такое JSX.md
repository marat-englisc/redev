# Что такое JSX

> [!NOTE]
> **JSX** - расширение синтаксиса JavaScript, которое позволяет записывать описание интерфейса с помощью похожих на HTML тегов.

## Вопрос

Что такое JSX, как он связан с JavaScript и какие правила нужно помнить?

## Как это работает

JSX не является HTML-строкой и не выполняется браузером напрямую. Инструмент сборки преобразует его в JavaScript-вызовы, создающие React-элементы - описания будущего интерфейса.

При современном JSX transform используются функции из `react/jsx-runtime`. В старом варианте преобразования применялся `React.createElement`. Поэтому утверждение «JSX всегда превращается именно в createElement» слишком узкое. При современном transform импорт `React` только ради JSX обычно не нужен.

В фигурных скобках можно вставлять JavaScript-выражения: переменные, вызовы функций, тернарные операторы. Инструкции вроде `if` или `for` туда напрямую не помещаются.

## Пример: карточка курса

```jsx
function CourseCard({ title, lessons, isNew }) {
  return (
    <article className="course-card">
      <h2>{title}</h2>
      <p>Уроков: {lessons}</p>
      {isNew && <span>Новинка</span>}
      <button disabled={lessons === 0}>Начать обучение</button>
    </article>
  );
}

export default function App() {
  return <CourseCard title="React с нуля" lessons={12} isNew />;
}
```

`title="..."` передает строку, `lessons={12}` - число, а `isNew` без значения равносильно `isNew={true}`. Надпись «Новинка» появится только при истинном условии.

## Основные правила

- Закрывай все теги: `<input />`, `<img />`, `<br />`.
- Объединяй соседние теги в одно выражение: например, фрагмент `<>...</>`.
- Встроенные элементы пиши со строчной буквы, свои компоненты - с заглавной.
- Для CSS-класса DOM-элемента используй `className`, для связи label и input - `htmlFor`.
- Inline-стиль передавай объектом: `style={{ color: "red" }}`.

Двойные скобки у `style` - это вставка JavaScript-выражения и обычный объект внутри него.

## Частые ошибки

Обычный объект `{ name: "Анна" }` нельзя показать как текст через `{user}`; нужно выбрать поле, например `{user.name}`. Строковый контент React экранирует, но это не делает произвольные URL или сырой HTML автоматически безопасными.

## Что важно помнить

- JSX компилируется в вызовы `jsx()` / `React.createElement()` — это JavaScript-выражения, а не HTML.
- В `{}` можно вставлять только выражения, не инструкции (`if`, `for`).
- Значения в `{}` экранируются — это защита от XSS; `dangerouslySetInnerHTML` отключает ее.
- Атрибуты пишутся в camelCase: `className`, `htmlFor`, `onClick`, `tabIndex`.

## Мини-шпаргалка

- JSX описывает элементы, а не создает DOM напрямую.
- Скобки `{}` вставляют выражения JavaScript.
- Преобразование JSX выполняет сборка.
- TSX добавляет к такому коду TypeScript-проверку.
