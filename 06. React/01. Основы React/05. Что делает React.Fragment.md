# Что делает React.Fragment

> [!NOTE]
> **Fragment** группирует несколько React-узлов и позволяет вернуть их вместе без дополнительного контейнера в DOM.

## Вопрос

Для чего нужен Fragment, чем отличаются полная и короткая записи и когда нужен key?

## Основная идея

Допустим, компонент возвращает две ячейки таблицы. Если обернуть их в `div`, получится неправильная структура: непосредственными детьми `tr` должны быть ячейки. Fragment позволяет объединить JSX, сохранив корректный HTML.

Обычная короткая запись - `<>...</>`. Полная запись - `<Fragment>...</Fragment>` после импорта из React. При необходимости задать `key` используют полную запись.

Fragment не заменяет смысловой HTML-контейнер. Если нужен раздел документа, общая область стилей или элемент для обработки событий, стоит выбрать подходящий тег.

## Пример: ячейки таблицы

```jsx
function UserCells({ name, score }) {
  return (
    <>
      <td>{name}</td>
      <td>{score}</td>
    </>
  );
}

export default function Results() {
  return (
    <table>
      <caption>Результаты тренировки</caption>
      <tbody>
        <tr><UserCells name="Анна" score={8} /></tr>
      </tbody>
    </table>
  );
}
```

Внутри `tr` будут две ячейки `td`; промежуточный `div` не появится.

## Пример: несколько узлов на одну запись списка

```jsx
import { Fragment } from "react";

const terms = [
  { id: "props", title: "Props", description: "Входные данные" },
  { id: "state", title: "State", description: "Память компонента" },
];

function Glossary() {
  return (
    <dl>
      {terms.map(term => (
        <Fragment key={term.id}>
          <dt>{term.title}</dt>
          <dd>{term.description}</dd>
        </Fragment>
      ))}
    </dl>
  );
}
```

Ключ относится ко всей паре `dt + dd`. React сможет сопоставить такую группу между обновлениями.

## Нюансы

Короткому фрагменту нельзя добавить `key`. Обычная группировка через Fragment не предоставляет CSS-класс или DOM-контейнер для оформления: такие свойства нужно задавать конкретным элементам.

Не путай отсутствие контейнера в DOM с отсутствием группировки в React: группа по-прежнему участвует в описании интерфейса и сопоставлении детей.

## Что важно помнить

- Fragment группирует элементы без добавления узла в DOM.
- Короткая запись `<>` не принимает атрибуты; для `key` в списках нужен `<Fragment key={id}>`.
- Fragment полезен внутри `<table>`, `<ul>`, flex- и grid-контейнеров, где обертка нарушит разметку.
- В DevTools Fragment не отображается как отдельный DOM-узел.

## Мини-шпаргалка

- `<>` - короткая запись Fragment.
- `<Fragment key={id}>` - группа с ключом.
- Полезен для таблиц, списков определений и соседних элементов.
- Для оформления общего блока нужен HTML-контейнер.
