# Для чего нужен React DevTools

> [!NOTE]
> **React DevTools** - инструменты для изучения дерева React-компонентов, их props и состояния, а также анализа работы рендера.

## Вопрос

Чем React DevTools отличается от обычной панели Elements и как использовать его для отладки?

## Что можно увидеть

Панель браузера Elements показывает реальный DOM: `div`, `button`, текстовые узлы. React DevTools показывает компоненты приложения: `CoursePage`, `LessonCard`, `ProgressBar`. Это помогает найти место в исходном коде, которое отвечает за видимый элемент.

Во вкладке Components можно выбрать компонент и изучить его props, state и хуки. В поддерживаемом режиме разработки некоторые значения можно временно изменить, чтобы проверить разные состояния интерфейса. Такая правка не сохраняет исходный код и не заменяет нормальный сценарий воспроизведения ошибки.

Profiler записывает работу React во время выбранного взаимодействия. Он помогает увидеть, какие компоненты участвовали в обновлениях и сколько времени заняли вычисления.

## Пример: почему не обновляется прогресс

```jsx
import { useState } from "react";

function ProgressBar({ completed, total }) {
  return <p>Пройдено: {completed} из {total}</p>;
}

export default function Course() {
  const [completed, setCompleted] = useState(0);

  return (
    <>
      <ProgressBar completed={completed} total={10} />
      <button onClick={() => setCompleted(n => Math.min(n + 1, 10))}>
        Завершить урок
      </button>
    </>
  );
}
```

Порядок проверки:

1. Выбрать `Course` во вкладке Components.
2. Нажать кнопку и проверить изменение state.
3. Выбрать `ProgressBar` и проверить входящий `completed`.
4. Если значение пришло верное, искать ошибку в отображении.
5. Если взаимодействие тормозит, записать его во вкладке Profiler.

Так можно проследить путь данных от владельца состояния к потребителю.

## Нюансы измерений

Время одного рендера зависит от компьютера, сборки и режима разработки. StrictMode может добавлять диагностические вызовы. Сравнивай одинаковые сценарии и используй production profiling, когда нужны более реалистичные измерения.

Profiler React не заменяет Network и Performance браузера: задержка может быть вызвана сетью, layout, большим изображением или сторонним скриптом.

## Что важно помнить

- Вкладка Components показывает дерево компонентов, props, state, хуки и контекст.
- Вкладка Profiler записывает рендеры и показывает, что и почему перерендерилось.
- Опция «Highlight updates» подсвечивает перерисованные компоненты.
- В продакшен-сборке имена компонентов могут быть минифицированы, а профилирование отключено.

## Мини-шпаргалка

- Elements показывает DOM, Components - дерево React.
- Props и state помогают проверить поток данных.
- Profiler помогает найти дорогие обновления.
- Сначала измеряй проблему, затем выбирай оптимизацию.
