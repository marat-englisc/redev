# React Router и пакет react-router-dom

> [!NOTE]
> React Router добавляет маршрутизацию к React. В версии 7 основные API, включая BrowserRouter и Link, доступны из `react-router`; `react-router-dom` сохраняет совместимые реэкспорты.

## Вопрос

За что отвечает React Router и почему совет «всегда устанавливайте react-router-dom» зависит от версии?

## Версия и режим определяют API

В React Router 6 браузерные приложения обычно импортировали API из `react-router-dom`. В v7 пакеты упростили, поэтому для показанного ниже подхода достаточно `react-router`. Старый импорт из `react-router-dom` v7 поддерживается для совместимости, но смешивать произвольные версии двух пакетов нельзя.

React Router предоставляет сопоставление адресов, ссылки, программную навигацию, параметры URL, вложенные страницы и layouts. Сам React продолжает отвечать за компоненты и обновление UI. Маршрутизатор не является встроенной частью React и не обязателен для небольшого виджета без страниц.

У библиотеки есть несколько режимов. В **declarative mode** используют `BrowserRouter`, `Routes` и `Route`. Data mode добавляет router-конфигурацию и интеграцию загрузки данных. Framework mode включает более широкий стек. Нельзя брать любой пример loader из другого режима и ожидать, что он заработает в обычном `<Routes>` автоматически.

## Пример

Установка для примера: `npm install react-router@7`. Ниже — **React Router 7, декларативный режим**.

```jsx
import { BrowserRouter, NavLink, Route, Routes } from 'react-router';

function Menu() {
  return (
    <nav>
      <NavLink to="/" end>
        Главная
      </NavLink>{' '}
      <NavLink to="/catalog">Каталог</NavLink>
    </nav>
  );
}

export default function App() {
  return (
    <BrowserRouter>
      <Menu />
      <Routes>
        <Route path="/" element={<h1>Добро пожаловать</h1>} />
        <Route path="/catalog" element={<h1>Книги</h1>} />
        <Route path="*" element={<h1>Такой страницы нет</h1>} />
      </Routes>
    </BrowserRouter>
  );
}
```

`NavLink` позволяет оформить активную ссылку и добавляет соответствующую доступную семантику. `end` ограничивает совпадение корневой ссылки ее собственным путем. `Routes` выбирает подходящую ветку, а не просто отображает все `Route` сразу.

## Нюансы

- Не вкладывайте несколько `BrowserRouter` друг в друга.
- Используйте `element={<Page />}` в этих примерах; старый prop `component={Page}` относится к прежнему API.
- Клиентская страница «не найдено» не устанавливает HTTP-статус сервера автоматически.
- Версия 7 здесь выбрана явно для согласованного материала; ссылка на документацию также закреплена за v7.

## Что важно помнить

- Начиная с v7 основной пакет — `react-router`; `react-router-dom` оставлен для совместимости.
- Есть декларативный режим (`<BrowserRouter>` + `<Routes>`) и data-режим (`createBrowserRouter` с loaders и actions).
- React Router v7 также может работать как фреймворк (бывший Remix).
- Для ссылок используйте `<Link>` и `<NavLink>`, а не `<a>`.

## Мини-шпаргалка

```text
react-router@7 → достаточно для declarative mode
BrowserRouter → контекст и история
Routes/Route → сопоставление
Link/NavLink → переходы
```
