# Controller и подключение кастомных полей

> [!NOTE]
> `register` работает с нативными полями, у которых есть ref и событие `onChange` с `event.target.value`. Кастомные компоненты UI-библиотек (select, date picker, слайдер, маска телефона) часто управляемые и сообщают значение напрямую: `onChange(value)`. Для них в react-hook-form есть **`Controller`** и хук **`useController`**: они превращают поле RHF в пару `value` + `onChange` и передают состояние ошибки.

## Вопрос

Когда в react-hook-form нужен `Controller` вместо `register`? Как подключить поле из UI-библиотеки и сделать собственный переиспользуемый компонент поля?

## Controller

```tsx
import { Controller, useForm } from "react-hook-form";
import Select from "react-select";
import DatePicker from "react-datepicker";

type Order = { city: { value: string; label: string } | null; date: Date | null };

export function OrderForm() {
  const { control, handleSubmit } = useForm<Order>({ defaultValues: { city: null, date: null } });

  return (
    <form onSubmit={handleSubmit(console.log)}>
      <Controller
        name="city"
        control={control}
        rules={{ required: "Выберите город" }}
        render={({ field, fieldState }) => (
          <>
            <Select {...field} options={cities} aria-invalid={fieldState.invalid} />
            {fieldState.error && <p role="alert">{fieldState.error.message}</p>}
          </>
        )}
      />

      <Controller
        name="date"
        control={control}
        render={({ field }) => (
          <DatePicker selected={field.value} onChange={field.onChange} onBlur={field.onBlur} ref={field.ref} />
        )}
      />
      <button>Оформить</button>
    </form>
  );
}
```

`field` содержит `value`, `onChange`, `onBlur`, `name`, `ref`, `disabled`. `fieldState` — `invalid`, `error`, `isDirty`, `isTouched`.

## Свое переиспользуемое поле: useController

```tsx
import { useController, type Control, type FieldPath, type FieldValues } from "react-hook-form";

type TextFieldProps<T extends FieldValues> = {
  control: Control<T>;
  name: FieldPath<T>;
  label: string;
  type?: string;
};

export function TextField<T extends FieldValues>({ control, name, label, type = "text" }: TextFieldProps<T>) {
  const { field, fieldState } = useController({ control, name });
  const errorId = `${name}-error`;

  return (
    <div>
      <label htmlFor={name}>{label}</label>
      <input
        id={name}
        type={type}
        {...field}
        value={field.value ?? ""}
        aria-invalid={fieldState.invalid}
        aria-describedby={fieldState.error ? errorId : undefined}
      />
      {fieldState.error && <p id={errorId} role="alert">{fieldState.error.message}</p>}
    </div>
  );
}

// использование — типобезопасно по имени поля
<TextField control={control} name="email" label="Email" type="email" />
```

## FormProvider: без передачи control через props

```tsx
const methods = useForm<Profile>();

<FormProvider {...methods}>
  <form onSubmit={methods.handleSubmit(onSubmit)}>
    <AddressSection />          {/* внутри: const { register } = useFormContext<Profile>() */}
  </form>
</FormProvider>
```

Удобно для больших форм, разбитых на секции-компоненты.

## register или Controller

| | `register` | `Controller` / `useController` |
| --- | --- | --- |
| Подходит для | `input`, `select`, `textarea`, компоненты с `forwardRef` и нативным `onChange` | управляемые компоненты с `value` / `onChange(value)` |
| Ререндеры | минимальные (неуправляемое поле) | ререндер поля при изменении значения |
| Кода | меньше | больше |

## Что важно помнить

- Сначала пробуйте `register`: если компонент прокидывает `ref` и `onChange(event)` до нативного `input`, `Controller` не нужен.
- Не используйте одновременно `register` и `Controller` для одного поля.
- Передавайте `field.ref`, чтобы работали `setFocus` и фокус на первое поле с ошибкой.
- `value={field.value ?? ""}` защищает от переключения между управляемым и неуправляемым состоянием.
- `useFormContext` удобен, но скрывает зависимость — для маленьких форм проще передать `control` явно.

## Мини-шпаргалка

Нативное поле — `register`. Кастомное управляемое (react-select, date picker, маска) — `<Controller name control rules render={({ field, fieldState }) => ...} />` или `useController`. Большие формы — `FormProvider` + `useFormContext`. Пробрасывайте `field.ref`.
