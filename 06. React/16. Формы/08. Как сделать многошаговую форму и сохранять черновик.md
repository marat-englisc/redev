# Как сделать многошаговую форму и сохранять черновик

> [!NOTE]
> **Многошаговая форма (wizard)** делит длинную форму на шаги: «Контакты → Доставка → Оплата». Основные решения: хранить значения **всех шагов в одном месте** (одна форма react-hook-form или общий store), валидировать **только поля текущего шага** перед переходом (`trigger`), хранить номер шага в URL, чтобы работали «Назад» и обновление страницы, и сохранять **черновик** (в `localStorage` или на сервере), чтобы пользователь не потерял данные.

## Вопрос

Как реализовать многошаговую форму в React? Как валидировать отдельный шаг, сохранить данные между шагами и восстановить черновик?

## Одна форма — несколько шагов

```tsx
import { FormProvider, useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";

const steps = [
  { id: "contacts", title: "Контакты", fields: ["name", "email", "phone"] },
  { id: "delivery", title: "Доставка", fields: ["city", "address"] },
  { id: "payment", title: "Оплата", fields: ["method"] },
] as const;

export function CheckoutWizard() {
  const [searchParams, setSearchParams] = useSearchParams();
  const step = Math.min(Number(searchParams.get("step") ?? 0), steps.length - 1);

  const methods = useForm<Checkout>({
    resolver: zodResolver(checkoutSchema),          // общая схема для всех шагов
    defaultValues: loadDraft() ?? emptyCheckout,
    shouldUnregister: false,                        // значения скрытых шагов сохраняются
  });

  useDraft(methods.watch);                          // автосохранение черновика

  async function next() {
    const ok = await methods.trigger(steps[step].fields as unknown as (keyof Checkout)[]); // только поля шага
    if (ok) setSearchParams({ step: String(step + 1) });
  }

  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(submitOrder)}>
        <ol aria-label="Шаги оформления">
          {steps.map((s, i) => (
            <li key={s.id} aria-current={i === step ? "step" : undefined}>{s.title}</li>
          ))}
        </ol>

        <h2 tabIndex={-1}>{steps[step].title}</h2>
        {step === 0 && <ContactsStep />}
        {step === 1 && <DeliveryStep />}
        {step === 2 && <PaymentStep />}

        {step > 0 && <button type="button" onClick={() => setSearchParams({ step: String(step - 1) })}>Назад</button>}
        {step < steps.length - 1
          ? <button type="button" onClick={next}>Далее</button>
          : <button type="submit">Оформить заказ</button>}
      </form>
    </FormProvider>
  );
}
```

Компоненты шагов берут `register` из `useFormContext()`.

## Черновик в localStorage

```tsx
const DRAFT_KEY = "checkout-draft";

function loadDraft(): Checkout | null {
  try {
    const raw = localStorage.getItem(DRAFT_KEY);
    return raw ? checkoutSchema.partial().parse(JSON.parse(raw)) as Checkout : null;  // проверить старые данные
  } catch {
    return null;
  }
}

function useDraft(watch: UseFormWatch<Checkout>) {
  useEffect(() => {
    let timer: number | undefined;
    const sub = watch((values) => {
      clearTimeout(timer);
      timer = window.setTimeout(() => {
        const { cardNumber, ...safe } = values as Checkout & { cardNumber?: string };  // не сохранять чувствительное
        localStorage.setItem(DRAFT_KEY, JSON.stringify(safe));
      }, 500);
    });
    return () => { sub.unsubscribe(); clearTimeout(timer); };
  }, [watch]);
}

// после успешной отправки
localStorage.removeItem(DRAFT_KEY);
```

## Архитектурные варианты

| Вариант | Когда |
| --- | --- |
| Одна форма RHF на все шаги | шаги — части одного объекта, общая схема |
| Отдельная форма на шаг + общий store (Zustand, context) | шаги независимы, разные экраны и маршруты |
| Черновик на сервере | долгие формы (анкеты, заявки), работа с разных устройств |
| Шаг в URL | нужны «Назад» браузера, ссылки и обновление страницы |

## Что важно помнить

- Валидируйте только текущий шаг (`trigger(fields)`), а на последнем — всю форму целиком.
- Не позволяйте перейти на шаг по URL, если предыдущие не заполнены: проверяйте и перенаправляйте на первый невалидный шаг.
- Не сохраняйте в `localStorage` пароли, данные карт и чувствительные персональные данные.
- Черновик из хранилища — недоверенные данные: валидируйте его схемой при загрузке, учитывайте смену версии формы.
- При смене шага переводите фокус на заголовок шага — иначе пользователь скринридера не поймет, что экран изменился.
- Показывайте прогресс («Шаг 2 из 3») и дайте вернуться назад без потери данных.

## Мини-шпаргалка

Одна форма + `FormProvider`, шаги через `useFormContext`. Переход — `await trigger(stepFields)`. `shouldUnregister: false` — значения скрытых шагов сохраняются. Шаг в URL. Черновик — `watch` + debounce + `localStorage` (без чувствительных данных), проверка схемой при загрузке, удаление после отправки. Фокус на заголовок шага.
