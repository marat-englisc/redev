# Как делать динамические поля через useFieldArray

> [!NOTE]
> **Динамические поля** — список однотипных групп полей, которые пользователь добавляет и удаляет: телефоны, участники, позиции заказа, опыт работы. В react-hook-form для этого есть `useFieldArray`: он возвращает `fields` (элементы со стабильным `id` для `key`) и методы `append`, `remove`, `insert`, `move`, `swap`, `update`, `replace`. Поля регистрируют по пути с индексом: `register(\`items.${index}.name\`)`.

## Вопрос

Как в React сделать форму с динамическим списком полей? Как работает `useFieldArray` и почему в `key` нельзя использовать индекс?

## Пример: позиции заказа

```tsx
import { useFieldArray, useForm, useWatch } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";

const orderSchema = z.object({
  items: z
    .array(
      z.object({
        title: z.string().min(1, "Укажите товар"),
        qty: z.coerce.number().int().min(1, "Минимум 1"),
        price: z.coerce.number().min(0),
      }),
    )
    .min(1, "Добавьте хотя бы одну позицию"),
});
type Order = z.infer<typeof orderSchema>;

export function OrderForm() {
  const { control, register, handleSubmit, formState: { errors } } = useForm<Order>({
    resolver: zodResolver(orderSchema),
    defaultValues: { items: [{ title: "", qty: 1, price: 0 }] },
  });

  const { fields, append, remove, move } = useFieldArray({ control, name: "items" });

  return (
    <form onSubmit={handleSubmit(console.log)}>
      {fields.map((field, index) => (
        <fieldset key={field.id}>                 {/* id от RHF, не index */}
          <legend>Позиция {index + 1}</legend>
          <input {...register(`items.${index}.title`)} placeholder="Товар" />
          {errors.items?.[index]?.title && <p role="alert">{errors.items[index].title.message}</p>}
          <input type="number" {...register(`items.${index}.qty`)} />
          <input type="number" {...register(`items.${index}.price`)} />
          <button type="button" onClick={() => remove(index)} disabled={fields.length === 1}>Удалить</button>
          <button type="button" onClick={() => move(index, index - 1)} disabled={index === 0}>Выше</button>
        </fieldset>
      ))}

      {errors.items?.root && <p role="alert">{errors.items.root.message}</p>}

      <button type="button" onClick={() => append({ title: "", qty: 1, price: 0 })}>
        Добавить позицию
      </button>
      <Total control={control} />
      <button type="submit">Оформить</button>
    </form>
  );
}

function Total({ control }: { control: Control<Order> }) {
  const items = useWatch({ control, name: "items" });   // ререндерится только этот компонент
  const total = items.reduce((sum, i) => sum + Number(i.qty) * Number(i.price), 0);
  return <p>Итого: {total} ₽</p>;
}
```

## Методы useFieldArray

| Метод | Что делает |
| --- | --- |
| `append(value)` / `prepend(value)` | добавить в конец / начало |
| `insert(index, value)` | вставить по индексу |
| `remove(index?)` | удалить один, массив или все |
| `move(from, to)` / `swap(a, b)` | переставить |
| `update(index, value)` | заменить элемент целиком |
| `replace(values)` | заменить весь массив |

## Почему key={field.id}

Если использовать `key={index}`, после удаления первой строки React переиспользует DOM-узлы по позиции: значения неуправляемых полей «съедут» в соседние строки. `field.id` — стабильный идентификатор, который RHF генерирует для каждого элемента.

## Без библиотеки

```tsx
const [phones, setPhones] = useState([{ id: crypto.randomUUID(), value: "" }]);

const add = () => setPhones((p) => [...p, { id: crypto.randomUUID(), value: "" }]);
const removeAt = (id: string) => setPhones((p) => p.filter((x) => x.id !== id));
const change = (id: string, value: string) => setPhones((p) => p.map((x) => (x.id === id ? { ...x, value } : x)));
```

Принцип тот же: у каждой строки стабильный id для `key`, обновления иммутабельные.

## Что важно помнить

- Кнопки «Добавить» и «Удалить» должны иметь `type="button"`, иначе они отправят форму.
- Передавайте в `append` полный объект со всеми полями — частичные значения ломают `defaultValues` строки.
- Ошибка уровня массива (`min(1)`) лежит в `errors.items.root`, ошибки строк — в `errors.items[index]`.
- Для подсчета итогов используйте `useWatch` в отдельном компоненте, чтобы не ререндерить всю форму.
- После удаления строки переводите фокус на соседнюю строку или кнопку добавления — это важно для клавиатуры и скринридеров.

## Мини-шпаргалка

`useFieldArray({ control, name })` → `fields`, `append`, `remove`, `insert`, `move`, `update`. `key={field.id}`, не index. `register(\`items.${i}.title\`)`. Кнопки — `type="button"`. Итоги — `useWatch`. Ошибка массива — `errors.items.root`.
