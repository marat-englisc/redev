# Middleware в SSR

> [!NOTE]
> Middleware выполняет общую обработку HTTP-запроса до, вокруг или после обработчика маршрута: авторизацию, логирование, заголовки и другие задачи.

## Вопрос

Какова роль middleware и чем оно отличается от React-компонента?

## Основная идея

Каждой приватной странице нужна проверка сессии. Копировать её в десятки обработчиков неудобно. Middleware получает запрос и ответ, выполняет общую проверку и решает, продолжать обработку или завершить ответ, например редиректом на вход.

Это часть серверной цепочки, а не React-дерева. В Express промежуточный обработчик вызывает `next()`, чтобы передать управление следующему. Если он не вызывает `next` и не отправляет ответ, запрос зависнет. Порядок регистрации важен: проверка доступа должна стоять до маршрута, который выводит приватные данные.

В разных фреймворках middleware имеет разные API и ограничения среды выполнения. Нельзя автоматически переносить Express-код в edge-обработчик. Независимо от названия проверка на внешнем слое не заменяет авторизацию непосредственно при доступе к защищённым данным.

## Пример

Самостоятельный учебный Express-сервер в JSX-модуле; зависимости установлены и серверная сборка преобразует JSX.

```jsx
import express from 'express';
import { renderToString } from 'react-dom/server';

const app = express();
app.use((request, response, next) => {
  response.setHeader('X-Content-Type-Options', 'nosniff');
  console.log(request.method, request.path);
  next();
});
app.get('/guide', (request, response) => {
  const html = renderToString(<main><h1>Гид по React</h1></main>);
  response.type('html').send('<!doctype html>' + html);
});
app.listen(3000);
```

Сначала middleware добавляет заголовок и логирует запрос, затем маршрут создаёт HTML. Это пример общей обработки; он не реализует сессию или авторизацию.

## Что важно помнить

- Пример требует Express, Node.js и преобразование JSX для сервера.
- Не вызывайте `next()` после отправки окончательного ответа без конкретной необходимости.
- В streaming заголовки настраивают до начала отправки.
- Логи не должны включать токены и конфиденциальное содержимое запроса.

## Мини-шпаргалка

Middleware → общие правила HTTP. Route → данные страницы. React → представление.
