# useLayoutEffect при SSR

> [!NOTE]
> useLayoutEffect не выполняется на сервере: там нет DOM и раскладки браузера. На клиенте он может измерить DOM до следующей отрисовки.

## Вопрос

Почему измерение layout нельзя выполнить при SSR и что делать с таким компонентом?

## Основная идея

Всплывающая подсказка хочет узнать свою высоту, чтобы появиться над кнопкой. На сервере есть только описание HTML: неизвестны реальная ширина окна, шрифт, масштаб и окончательные размеры. Поэтому сервер не может выполнить `getBoundingClientRect` так, как это делает браузер.

`useLayoutEffect` запускается после клиентского изменения DOM и до показа соответствующего кадра. Это полезно для измерений, но не помогает серверному HTML сразу иметь окончательную позицию. React может сообщать, что хук не делает ничего на сервере.

Если точное измерение не критично, используйте CSS или обычный эффект. Если блок без него выглядит неправильно, показывайте его только после клиентского монтирования с подходящей заглушкой. Цена такого решения — блок не участвует в полезном первом SSR. Важно выбрать поведение осознанно.

## Пример

Универсальное SSR-приложение с клиентской гидрацией; измеряемый компонент появляется только после монтирования в браузере.

```jsx
import { useEffect, useLayoutEffect, useRef, useState } from 'react';

function MeasuredNote() {
  const ref = useRef(null);
  const [height, setHeight] = useState(0);
  useLayoutEffect(() => {
    setHeight(ref.current.getBoundingClientRect().height);
  }, []);
  return <div ref={ref}>Высота заметки: {height.toFixed(0)} px</div>;
}
export default function ClientNote() {
  const [mounted, setMounted] = useState(false);
  useEffect(() => setMounted(true), []);
  return mounted ? <MeasuredNote /> : <p>Готовим заметку...</p>;
}
```

Сервер и первый клиентский рендер показывают одинаковую заглушку. Только после эффекта монтируется `MeasuredNote`, где DOM уже существует и можно измерить высоту.

## Что важно помнить

- Не делайте layout-измерения в render.
- `useLayoutEffect` блокирует браузерную отрисовку; тяжёлая работа внутри ухудшает отзывчивость.
- Если содержимое меняется после измерения, одного `[]` недостаточно; иногда нужен ResizeObserver.
- Заглушка должна резервировать место, если важна стабильность layout.

## Мини-шпаргалка

SSR → DOM/layout нет. Клиентский commit → layout effect → измерение → кадр. Можно решить CSS → предпочтительнее.
