# useFormStatus

> [!NOTE]
> useFormStatus из react-dom читает состояние ближайшей родительской формы. Он удобен для переиспользуемой кнопки отправки.

## Вопрос

Почему useFormStatus должен находиться в дочернем компоненте формы?

## Основная идея

Компонент кнопки хочет сам узнать, отправляется ли форма, не получая флаг через цепочку props. `useFormStatus` возвращает `pending`, `data`, `method` и `action` ближайшей формы выше в дереве. Поэтому одинаковую кнопку можно использовать в разных формах без ручной передачи состояния.

Ключевой нюанс — расположение вызова. Хук читает родительскую форму, а не ту, которую тот же компонент только собирается вернуть. Если вызвать его в `ProfileForm`, а затем вернуть `<form>`, эта форма не станет его родителем. Вынесите кнопку в `SubmitButton` и разместите её внутри формы.

Хук не хранит результат сохранения и не выполняет валидацию. Для сообщений об успехе и ошибке подходит `useActionState` либо другой state. `pending` описывает процесс отправки конкретной формы, а `data` позволяет прочитать FormData текущей отправки, если это действительно нужно интерфейсу.

## Пример

Самодостаточная учебная форма React 19; задержка имитирует сеть без реального сохранения.

```jsx
import { useActionState } from 'react';
import { useFormStatus } from 'react-dom';

function SubmitButton() {
  const { pending } = useFormStatus();
  return <button disabled={pending}>
    {pending ? 'Отправляем отзыв...' : 'Отправить'}
  </button>;
}
async function sendFeedback(previous, formData) {
  const message = String(formData.get('message') ?? '').trim();
  if (!message) return 'Введите текст отзыва';
  await new Promise(resolve => setTimeout(resolve, 800));
  return `Учебный отзыв принят: ${message}`;
}
export default function FeedbackForm() {
  const [result, action] = useActionState(sendFeedback, '');
  return <form action={action}>
    <label>Отзыв <input name="message" required /></label>
    <SubmitButton />
    <p role="status">{result}</p>
  </form>;
}
```

Кнопка находится под формой и видит её pending. Функция использует учебную задержку, поэтому пример работает без API. Результат действия отображает отдельный useActionState.

## Что важно помнить

- Пример требует React 19 и соответствующую версию react-dom.
- Вне родительской формы статус не описывает соседние формы.
- Наличие pending не заменяет серверную защиту от дубликатов.
- Для имени поля в FormData нужен атрибут name; одного id недостаточно.

## Мини-шпаргалка

useFormStatus → процесс родительской формы. useActionState → результат действия. Хук в дочернем компоненте, форма выше.
