# Как типизировать обработчики событий

> [!NOTE]
> Для событий React используют типы вроде ChangeEvent<HTMLInputElement> или ChangeEventHandler<HTMLInputElement>. Generic указывает элемент, на котором установлен обработчик.

## Вопрос

Чем тип события отличается от типа обработчика и что означают target и currentTarget?

## Основная идея

`ChangeEvent<HTMLInputElement>` описывает объект события. `ChangeEventHandler<HTMLInputElement>` описывает функцию, которая принимает такое событие.

Для inline-обработчика TypeScript обычно выводит тип из JSX-prop. Если вынести функцию отдельно, понадобится аннотация или явный тип обработчика.

`currentTarget` - элемент, на котором установлен обработчик. `target` - исходная цель события, например вложенная иконка внутри кнопки. Поэтому для свойств самого элемента удобно использовать currentTarget.

## Пример: форма профиля

```tsx
import { useState } from "react";
import type { ChangeEventHandler, FormEventHandler } from "react";

export default function ProfileForm() {
  const [name, setName] = useState("");

  const handleChange: ChangeEventHandler<HTMLInputElement> = event => {
    setName(event.currentTarget.value);
  };

  const handleSubmit: FormEventHandler<HTMLFormElement> = event => {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    console.log("Сохраняем:", data.get("name"));
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>Имя <input name="name" value={name} onChange={handleChange} /></label>
      <button type="submit">Сохранить</button>
    </form>
  );
}
```

Событие input дает доступ к строковому `value`, а событие формы - к форме, подходящей для `FormData`.

## Частые типы

| Событие | Тип обработчика |
| --- | --- |
| Клик | MouseEventHandler<HTMLButtonElement> |
| Изменение input | ChangeEventHandler<HTMLInputElement> |
| Клавиатура | KeyboardEventHandler<HTMLInputElement> |
| Фокус | FocusEventHandler<HTMLInputElement> |
| Отправка формы | FormEventHandler<HTMLFormElement> |
| Вставка | ClipboardEventHandler<HTMLInputElement> |

Для собственного компонента можно переиспользовать нативный контракт: `ComponentProps<"input">["onChange"]`. Если наружу нужен только текст, проще принять `onValueChange: (value: string) => void`.

## Нюансы

Браузерный `MouseEvent` и `React.MouseEvent` - разные типы. Импортируй нужный React-тип через `import type`.

После асинхронной паузы не полагайся на `event.currentTarget`: сохрани нужное значение или элемент заранее. Отсутствие старого event pooling не отменяет правил жизненного цикла currentTarget.

## Что важно помнить

- Используйте типы React: `React.ChangeEvent<HTMLInputElement>`, `React.MouseEvent<HTMLButtonElement>`, `React.FormEvent<HTMLFormElement>`.
- Для props-обработчиков есть готовые типы: `React.ChangeEventHandler<HTMLInputElement>`.
- Инлайн-обработчик в JSX получает тип события автоматически.
- `e.target` и `e.currentTarget` различаются: типизирован надежно именно `currentTarget`.

## Мини-шпаргалка

- Event - объект события.
- EventHandler - функция.
- Inline-функции часто типизируются автоматически.
- CurrentTarget соответствует элементу обработчика.
- Any отключает полезную проверку.
