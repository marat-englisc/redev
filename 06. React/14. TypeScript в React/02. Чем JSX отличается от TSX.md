# Чем JSX отличается от TSX

> [!NOTE]
> **JSX** - синтаксис описания интерфейса. **TSX** - TypeScript-код с поддержкой JSX, обычно в файле с расширением .tsx.

## Вопрос

Что добавляет TSX и как JSX превращается в JavaScript?

## Объяснение

В `.jsx` пишут JavaScript с JSX-разметкой. В `.tsx` дополнительно можно описать типы props, параметров и результатов, а TypeScript проверит совместимость.

JSX сам по себе не является системой проверки типов. Например, компонент с `label={42}` не обязан упасть в браузере: число вполне может отобразиться как текст. Ошибка появится только относительно контракта приложения, если такой контракт задан.

JSX transform может выполняться TypeScript, Babel, SWC или другим инструментом. Современный режим часто создает вызовы из `react/jsx-runtime`; при `jsx: "preserve"` преобразование JSX остается следующему этапу сборки.

## Пример: типизированная кнопка

```tsx
type ButtonProps = {
  label: string;
  disabled?: boolean;
};

function Button({ label, disabled = false }: ButtonProps) {
  return <button disabled={disabled}>{label}</button>;
}

export default function App() {
  return <Button label="Начать тренировку" />;
}

// Намеренная ошибка типа, если раскомментировать:
// const invalid = <Button label={42} />;
```

В JavaScript-варианте аннотацию `ButtonProps` убирают. Отображение остается тем же, но статический контракт теряется.

## Сравнение

| Признак | JSX в JavaScript | TSX |
| --- | --- | --- |
| Типичный файл | .jsx | .tsx |
| Аннотации TypeScript | Нет | Да |
| Статическая проверка props | Возможна отдельными средствами | Через TypeScript |
| Итог браузерной сборки | JavaScript | JavaScript |

## Нюансы синтаксиса

В `.tsx` утверждение типа записывают через `as`, поскольку форма `<Type>value` конфликтует с JSX.

У generic-стрелки часто добавляют запятую: `const identity = <T,>(value: T) => value;`. Это помогает парсеру отличить параметр типа от тега.

Файл `.ts` предназначен для TypeScript без JSX. Одного переименования файла недостаточно, если в проекте не настроена поддержка JSX.

## Что важно помнить

- `.tsx` — файлы TypeScript с JSX; в `.ts` JSX писать нельзя.
- В `.tsx` синтаксис приведения `<T>value` недоступен — используйте `value as T`.
- Дженерик-стрелку в `.tsx` пишут как `<T,>(x: T) => x`, чтобы не путать с тегом.
- Режим трансформации задается опцией `jsx` в `tsconfig` (обычно `react-jsx`).

## Мини-шпаргалка

- JSX - синтаксис, TSX - TypeScript с JSX.
- Типы исчезают из итогового JavaScript.
- Не вся некорректная по контракту передача падает в runtime.
- Сборка и проверка типов могут быть разными этапами.
