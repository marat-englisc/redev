# Что происходит при монтировании, обновлении и размонтировании

> [!NOTE]
> **Монтирование** — React впервые вызывает компонент, создает fiber-узел, инициализирует state, создает DOM-узлы, вставляет их в документ, подключает ref и запускает эффекты. **Обновление** — React снова вызывает компонент с новыми props/state, сравнивает результат с предыдущим, применяет только изменения к DOM, очищает старые эффекты и запускает новые для измененных зависимостей. **Размонтирование** — React вызывает cleanup всех эффектов, обнуляет ref, удаляет DOM-узлы и выбрасывает state.

## Вопрос

Что происходит при монтировании, обновлении и размонтировании компонента?

## Монтирование

```text
1. Вызов функции компонента (render)
   - useState/useReducer: берется начальное значение
   - useMemo/useRef: создаются значения
2. Reconciliation: создание fiber-узлов для детей
3. Commit:
   - создание и вставка DOM-узлов
   - подключение ref (ref.current = node)
   - useLayoutEffect (синхронно)
4. Браузер рисует
5. useEffect
```

## Обновление

Причины: изменился state, родитель перерендерился, изменился контекст.

```text
1. Повторный вызов компонента со свежими props/state
2. Reconciliation: сравнение нового дерева с прошлым
3. Commit:
   - точечные изменения DOM
   - cleanup layout-эффектов с измененными deps → новые layout-эффекты
4. Браузер рисует
5. cleanup эффектов с измененными deps → новые эффекты
```

Если результат не изменился, DOM не трогается, но функция компонента всё равно вызывается (если не сработал `memo`/bailout).

## Размонтирование

Причины: условный рендер вернул `false`, изменился `key`, изменился тип элемента на этой позиции, родитель размонтирован.

```text
1. Cleanup useLayoutEffect и useEffect
2. Обнуление ref (ref.current = null)
3. Удаление DOM-узлов
4. Удаление fiber-узла и всего state
```

```jsx
function App() {
  const [show, setShow] = useState(true);
  return (
    <>
      <button onClick={() => setShow(!show)}>Переключить</button>
      {show && <Timer />} {/* скрытие → Timer размонтирован, его state потерян */}
    </>
  );
}
```

## Что важно помнить

- Порядок: эффекты детей запускаются раньше эффектов родителя, cleanup при размонтировании — от родителя к детям.
- Скрыть компонент без размонтирования можно CSS-ом или `<Activity mode="hidden">` (React 19.2) — state сохранится.
- Смена `key` — способ намеренно перемонтировать компонент и сбросить его state.
- Если после размонтирования прилетит ответ запроса, обновление state будет проигнорировано — но запрос лучше отменять в cleanup.

## Мини-шпаргалка

Монтирование: init state → DOM → ref → layout-эффекты → отрисовка → эффекты. Обновление: render → diff → точечный DOM → cleanup + новые эффекты. Размонтирование: cleanup → ref = null → удаление DOM и state.
