# Компонент в React и компонентный подход

> [!NOTE]
> **Компонент** — функция (или класс), которая принимает props и возвращает описание интерфейса в виде JSX. Компоненты — строительные блоки приложения: их переиспользуют, вкладывают друг в друга и составляют из них страницы. **Компонентный подход** — разбивать интерфейс на независимые части с понятной ответственностью, собственным состоянием и явным интерфейсом через props.

## Вопрос

Что такое компонент в React? Что означает компонентный подход и как правильно делить интерфейс на компоненты?

## Основная идея

Компонент — это обычная функция с именем **с большой буквы**: React отличает компоненты от HTML-тегов по регистру (`<button>` — тег, `<Button>` — компонент). Функция получает объект props и возвращает JSX, строку, число, `null` или массив элементов.

```jsx
function ProductCard({ title, price, onAdd }) {
  return (
    <article className="card">
      <h3>{title}</h3>
      <p>{price} ₽</p>
      <button onClick={onAdd}>В корзину</button>
    </article>
  );
}
```

Компонентный подход переносит в интерфейс идеи модульности:

- **инкапсуляция** — компонент скрывает внутреннюю разметку и состояние;
- **переиспользование** — одна `ProductCard` в каталоге, избранном и рекомендациях;
- **композиция** — сложные экраны собираются из простых частей;
- **явный контракт** — props описывают, что компонент принимает;
- **изолированная разработка и тестирование** — в Storybook и юнит-тестах.

## Как делить на компоненты

1. Нарисовать рамки вокруг частей макета, у каждой должна быть одна понятная задача.
2. Выделить повторяющиеся элементы (карточка, кнопка, поле формы).
3. Выделить части со своим состоянием (выпадающее меню, вкладки).
4. Построить иерархию: страница → секции → карточки → кнопки.
5. Решить, где живет состояние: в ближайшем общем родителе компонентов, которым оно нужно.

## Пример

```jsx
export default function CatalogPage({ products }) {
  const [cart, setCart] = useState([]);
  return (
    <main>
      <Header cartCount={cart.length} />
      <ProductGrid>
        {products.map((p) => (
          <ProductCard key={p.id} {...p} onAdd={() => setCart([...cart, p])} />
        ))}
      </ProductGrid>
    </main>
  );
}
```

## Что важно помнить

- Компонент должен быть чистым при рендере: одинаковые props и state — одинаковый JSX, без побочных эффектов.
- Не объявляйте компонент внутри другого компонента — каждый рендер создаст новый тип и сбросит состояние.
- Слишком мелкое дробление тоже вредит: компонент на 3 строки, используемый один раз, редко оправдан.
- Признаки, что компонент пора разделить: много несвязанного состояния, длинный JSX, сложно назвать одним словом.

## Мини-шпаргалка

Компонент = функция props → JSX, имя с большой буквы. Компонентный подход: инкапсуляция, переиспользование, композиция, явный контракт. Делим по ответственности, state — в ближайшем общем родителе.
