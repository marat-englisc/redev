# Props и значения props по умолчанию

> [!NOTE]
> **Props** — входные данные компонента: объект, который родитель передает ребенку через атрибуты JSX. Через props передают значения, объекты, функции-обработчики и JSX (`children`). Значения по умолчанию задают параметрами деструктуризации: `function Button({ variant = "primary" })`. Старый способ `Component.defaultProps` для функциональных компонентов в React 19 удален.

## Вопрос

Что такое props в компоненте? Как задать значение props по умолчанию?

## Основная идея

Props — единственный способ родителя настроить ребенка. Данные текут **сверху вниз**: родитель решает, что передать, ребенок только читает.

```jsx
function Avatar({ src, name, size = 48 }) {
  return <img src={src} alt={name} width={size} height={size} />;
}

function Profile({ user }) {
  return (
    <section>
      <Avatar src={user.avatar} name={user.name} />
      <Avatar src={user.avatar} name={user.name} size={96} />
    </section>
  );
}
```

Через props можно передать что угодно:

| Что | Пример |
| --- | --- |
| Строки и числа | `<Avatar size={48} name="Анна" />` |
| Boolean | `<Button disabled />` (= `disabled={true}`) |
| Объекты и массивы | `<UserCard user={user} />` |
| Функции | `<Button onClick={handleSave} />` |
| JSX | `<Card header={<h2>Заголовок</h2>}>...</Card>` |
| Компоненты | `<List renderItem={Item} />` |

## Значения по умолчанию

```jsx
function Button({ variant = "primary", size = "md", type = "button", children, ...rest }) {
  return (
    <button type={type} className={`btn btn--${variant} btn--${size}`} {...rest}>
      {children}
    </button>
  );
}
```

- значение по умолчанию применяется, если prop **не передан** или равен `undefined`;
- при `null` дефолт **не** применяется;
- объект или массив по умолчанию в параметре создается заново на каждом рендере — это ломает мемоизацию: выносите константу наружу компонента.

```jsx
const EMPTY = [];
function List({ items = EMPTY }) {}
```

## Передача всех props

```jsx
function Input({ label, ...inputProps }) {
  return (
    <label>
      {label}
      <input {...inputProps} />
    </label>
  );
}
```

Spread удобен для оберток, но скрывает, какие props поддерживаются, — в TypeScript типизируйте их через `ComponentProps<"input">`.

## Что важно помнить

- Props только для чтения — менять их внутри ребенка нельзя.
- `key` и (в React 18) `ref` не попадают в props; в React 19 `ref` доступен как обычный prop у функциональных компонентов.
- Имя prop-обработчика по соглашению начинается с `on`: `onSelect`, а функция в родителе — с `handle`: `handleSelect`.
- Слишком много props — сигнал разделить компонент или использовать композицию через `children`.

## Мини-шпаргалка

Props — данные от родителя, только чтение. Передаются любые значения, функции и JSX. Default — в деструктуризации, срабатывает на `undefined`. `defaultProps` для функций — устарел.
