# children и передача JSX внутрь другого компонента

> [!NOTE]
> `children` — специальный prop, в который попадает всё, что написано между открывающим и закрывающим тегом компонента: `<Card>Содержимое</Card>`. Через `children` создают обертки — карточки, модалки, layout. Если нужно передать несколько «слотов» JSX, используют обычные props: `<Layout header={<Header />} sidebar={<Menu />}>`. JSX — обычное значение, поэтому его можно передавать в любом prop.

## Вопрос

Что такое `children`? Как передать JSX внутрь другого компонента?

## Основная идея

```jsx
function Card({ title, children }) {
  return (
    <section className="card">
      <h2>{title}</h2>
      <div className="card__body">{children}</div>
    </section>
  );
}

<Card title="Профиль">
  <p>Анна Петрова</p>
  <button>Редактировать</button>
</Card>;
```

`Card` не знает, что внутри, — она только оформляет контейнер. Это основа композиции: универсальные обертки без десятков настроек.

## Несколько слотов

```jsx
function PageLayout({ header, sidebar, children }) {
  return (
    <div className="layout">
      <header>{header}</header>
      <aside>{sidebar}</aside>
      <main>{children}</main>
    </div>
  );
}

<PageLayout header={<SiteHeader />} sidebar={<Filters />}>
  <ProductGrid />
</PageLayout>;
```

## Что может быть в children

- JSX-элемент или несколько элементов;
- строка, число;
- массив элементов;
- `null`, `undefined`, `false` — ничего не рендерится;
- функция — паттерн «function as child», если компонент вызывает `children(data)`.

```jsx
<DataLoader url="/api/users">
  {(users) => <UserList users={users} />}
</DataLoader>
```

## children и производительность

Элементы, переданные через `children`, создаются в **родителе**. Если обертка перерендерится из-за своего состояния, `children` не пересоздаются, и вложенные компоненты могут не рендериться заново:

```jsx
function Expandable({ children }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button onClick={() => setOpen(!open)}>Toggle</button>
      {open && children} {/* children не перерендериваются при каждом toggle */}
    </>
  );
}
```

## Что важно помнить

- `React.Children` и `cloneElement` — устаревающие API для манипуляции детьми; вместо них передавайте данные через props или контекст.
- Не мутируйте и не «перебирайте» `children` без крайней необходимости — структура детей непредсказуема (фрагменты, условия).
- В TypeScript тип — `children: React.ReactNode`.
- Поиск по `children` нужного типа (`child.type === Tab`) ломается при обертках — используйте compound components с контекстом.

## Мини-шпаргалка

`children` — содержимое между тегами компонента. Обертки и layout через `children`. Несколько слотов — обычные props с JSX. JSX — обычное значение. Тип — `ReactNode`.
