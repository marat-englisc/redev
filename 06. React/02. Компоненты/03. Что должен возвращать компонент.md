# Что должен возвращать React-компонент

> [!NOTE]
> Компонент возвращает **значение, которое React умеет отображать**: например, JSX, текст, число, коллекцию узлов или null. Один DOM-элемент не обязателен.

## Вопрос

Какие результаты допустимы у компонента и чем React-узел отличается от DOM-узла?

## Допустимые результаты

Самый распространенный результат - React-элемент, созданный JSX. Он описывает интерфейс, а не является готовым DOM-узлом браузера.

Строки и числа отображаются как текст. `null`, `undefined` и boolean-значения не добавляют видимого содержимого. Для явного отказа от отображения обычно выбирают `null`: так проще понять намерение.

Массив или другая поддерживаемая коллекция может содержать несколько узлов. Fragment тоже группирует несколько детей без дополнительного HTML-контейнера. Правило «компонент обязан вернуть один React-элемент» слишком ограничительное.

## Пример: сообщение и список

```jsx
function Warning({ visible }) {
  if (!visible) return null;
  return <p role="alert">Сначала завершите предыдущий урок.</p>;
}

function Score({ value }) {
  return value;
}

function TopicNames() {
  return [
    <li key="react">React</li>,
    <li key="ts">TypeScript</li>,
  ];
}

export default function App() {
  return (
    <section>
      <h1>Результат: <Score value={8} /></h1>
      <Warning visible={false} />
      <ul><TopicNames /></ul>
    </section>
  );
}
```

На странице будет заголовок с числом и список тем. `Warning` существует в дереве компонентов, но возвращает `null` и ничего видимого не добавляет.

## Что нельзя показывать напрямую

Обычный объект данных, например `{ name: "Анна" }`, нельзя вернуть как содержимое. Нужно отобразить поле или преобразовать данные в узлы. Функция тоже не превращается в интерфейс сама по себе: ее вызывают или передают как callback согласно контракту.

Соседние JSX-теги без объединения - синтаксическая ошибка. Объединять их можно фрагментом; общий DOM-контейнер нужен только по смыслу.

## Нюанс с async

Server Components в поддерживающем фреймворке могут быть асинхронными. Из этого не следует, что обычный клиентский компонент можно сделать `async` и произвольно загружать данные при каждом рендере. Среду и механизм загрузки нужно учитывать отдельно.

## Что важно помнить

- Компонент возвращает React-узел: JSX, строку, число, массив, Fragment, `null` или Portal.
- `undefined` из компонента в React 18+ допустим, но обычно это признак забытого `return`.
- Объект (не JSX) вернуть нельзя — будет ошибка «Objects are not valid as a React child».
- Возврат `null` скрывает компонент, но его хуки и эффекты продолжают работать.

## Мини-шпаргалка

- Возвращаем описание UI, а не созданный через document DOM-узел.
- JSX - наиболее частый, но не единственный результат.
- Null явно обозначает отсутствие отображения.
- Коллекции узлов нуждаются в корректных ключах.
