# useCallback и передача callback-функций дочерним компонентам

> [!NOTE]
> `useCallback(fn, deps)` возвращает **ту же ссылку на функцию** между рендерами, пока не изменились зависимости. Это `useMemo(() => fn, deps)`. Сам по себе `useCallback` не ускоряет код: функция всё равно создается при каждом рендере, React лишь возвращает старую. Польза появляется, когда стабильная ссылка важна: функция передается в `memo`-компонент, используется в зависимостях эффекта или другого хука, или возвращается из кастомного хука.

## Вопрос

Что делает `useCallback()`? Когда его использовать и как правильно передавать колбэки дочерним компонентам?

## Проблема: новая функция при каждом рендере

```jsx
const TodoItem = memo(function TodoItem({ todo, onToggle }) {
  return <li onClick={() => onToggle(todo.id)}>{todo.title}</li>;
});

function TodoList() {
  const [todos, setTodos] = useState([]);
  const [filter, setFilter] = useState("all");

  // новая функция при каждом рендере → memo у TodoItem не работает
  const handleToggle = (id) => { /* ... */ };

  return todos.map((t) => <TodoItem key={t.id} todo={t} onToggle={handleToggle} />);
}
```

## Решение

```jsx
const handleToggle = useCallback((id) => {
  setTodos((prev) => prev.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));
}, []); // функциональное обновление → зависимостей нет
```

Теперь при смене `filter` строки списка не перерендериваются.

## Когда использовать

| Нужен | Не нужен |
| --- | --- |
| колбэк идет в `memo`-компонент | колбэк идет в обычный DOM-элемент (`<button onClick>`) |
| функция — зависимость `useEffect`/`useMemo` | дочерний компонент не обернут в `memo` |
| кастомный хук возвращает функцию | компонент и так рендерится редко |

## Передача колбэков: приемы

- **Функциональное обновление** убирает state из зависимостей: `setCount(c => c + 1)`.
- **Передавайте id, а не замыкание**: `onToggle={handleToggle}` и вызов `onToggle(todo.id)` внутри, вместо `onToggle={() => toggle(todo.id)}` в цикле.
- **`dispatch` из `useReducer`** стабилен — можно передавать без `useCallback`.
- **Функция внутри эффекта**: если функция нужна только эффекту, объявите ее внутри — не придется мемоизировать.
- **`useEffectEvent`** (React 19.2) — для обработчиков, которые читают свежие значения, но не должны перезапускать эффект.

## Что важно помнить

- `useCallback` без `memo` у ребенка почти всегда бесполезен.
- Неполные зависимости → функция видит устаревшие значения (stale closure).
- Стрелочная функция в JSX — нормальная практика, пока нет проблем с производительностью.
- React Compiler мемоизирует колбэки автоматически.

## Мини-шпаргалка

`useCallback(fn, deps)` = стабильная ссылка на функцию. Нужен для `memo`-детей, зависимостей хуков и возвращаемых из хуков функций. Без `memo` — лишний. Функциональные обновления сокращают зависимости.
