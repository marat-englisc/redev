# Всё о useState: объявление, начальное значение и обновление по предыдущему

> [!NOTE]
> `const [value, setValue] = useState(initialValue)` объявляет переменную состояния: возвращает текущее значение и сеттер. Начальное значение используется **только при первом рендере**; дорогое вычисление передают функцией-инициализатором `useState(() => compute())`. Обновление на основе предыдущего значения делают функциональной формой `setValue(prev => prev + 1)` — она получает актуальное значение из очереди обновлений.

## Вопрос

Как объявить состояние с помощью `useState`? Как работает начальное значение и как обновить состояние на основе предыдущего?

## Объявление

```jsx
import { useState } from "react";

function Form() {
  const [name, setName] = useState("");
  const [age, setAge] = useState(0);
  const [tags, setTags] = useState([]);
  const [user, setUser] = useState(null);
  // ...
}
```

Деструктуризация массива позволяет назвать значение и сеттер как угодно; по соглашению сеттер — `setЧтоТо`.

## Начальное значение

```jsx
const [items, setItems] = useState(loadFromStorage());       // вызывается при КАЖДОМ рендере
const [items2, setItems2] = useState(() => loadFromStorage()); // вызывается только один раз
const [items3, setItems3] = useState(loadFromStorage);        // то же: передана функция
```

- начальное значение читается только при монтировании, изменение prop, из которого оно взято, state не обновит;
- функция-инициализатор должна быть чистой и без аргументов;
- если нужно «перезапустить» state по изменению prop — смените `key` компонента.

## Обновление на основе предыдущего

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  const addThree = () => {
    setCount(count + 1);
    setCount(count + 1);
    setCount(count + 1); // итог +1: каждый раз count из снимка = 0
  };

  const addThreeCorrect = () => {
    setCount((c) => c + 1);
    setCount((c) => c + 1);
    setCount((c) => c + 1); // итог +3: функции применяются по очереди
  };
}
```

Функциональная форма нужна, когда новое значение зависит от старого и обновление происходит:

- несколько раз подряд;
- в асинхронном коде, таймерах, подписках, где замыкание может устареть;
- в `useCallback`/`useEffect`, чтобы не добавлять state в зависимости.

## Сеттер

- стабилен между рендерами — его можно не указывать в зависимостях хуков;
- заменяет значение целиком (в отличие от `this.setState` в классах, который сливает объекты);
- при равном значении (`Object.is`) React может пропустить рендер.

```jsx
setUser((prev) => ({ ...prev, name: "Мария" })); // объект — с копированием
```

## Попробуйте

Две кнопки делают «+3», но одна передаёт в сеттер значение, а другая — функцию от предыдущего состояния. Нажмите обе и сравните результат.

```tsx run
import { useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);

  function addThreeWrong() {
    // все три вызова видят одно и то же count из текущего рендера
    setCount(count + 1);
    setCount(count + 1);
    setCount(count + 1);
  }

  function addThreeRight() {
    // каждая функция получает актуальное значение после предыдущего обновления
    setCount((c) => c + 1);
    setCount((c) => c + 1);
    setCount((c) => c + 1);
  }

  return (
    <main style={{ fontFamily: "system-ui", padding: 24 }}>
      <h1>{count}</h1>
      <button onClick={addThreeWrong}>+3 значением</button>{" "}
      <button onClick={addThreeRight}>+3 функцией</button>{" "}
      <button onClick={() => setCount(0)}>Сброс</button>
    </main>
  );
}
```

## Что важно помнить

- Не храните в state то, что можно вычислить из других значений в рендере.
- Несколько связанных значений иногда удобнее держать в одном объекте или в `useReducer`.
- Хранить функцию в state можно только через инициализатор: `useState(() => myFn)`, иначе React ее вызовет.
- В TypeScript тип выводится из начального значения; для `null` и пустых массивов указывайте тип явно: `useState<User | null>(null)`.

## Мини-шпаргалка

`useState(init)` → `[value, setValue]`. Init — только при первом рендере, дорогой — функцией. По предыдущему — `setValue(prev => ...)`. Сеттер стабилен и заменяет значение целиком.
