# Что такое хук в React и что делают хуки

> [!NOTE]
> **Хук** — функция, имя которой начинается с `use`, которая позволяет функциональному компоненту «подключиться» к возможностям React: состоянию (`useState`, `useReducer`), эффектам (`useEffect`, `useLayoutEffect`), контексту (`useContext`), ссылкам (`useRef`), мемоизации (`useMemo`, `useCallback`), конкурентным обновлениям (`useTransition`, `useDeferredValue`). Хуки хранят данные в fiber-узле компонента между рендерами и позволяют выносить логику с состоянием в переиспользуемые **кастомные хуки**.

## Вопрос

Что такое хук в React? Что делают хуки и какие встроенные хуки бывают?

## Основная идея

Функциональный компонент — обычная функция, которая вызывается при каждом рендере. Сама по себе она ничего не «помнит». Хуки дают ей память и доступ к жизненному циклу:

```jsx
import { useState, useEffect, useRef } from "react";

function Timer() {
  const [seconds, setSeconds] = useState(0);      // состояние
  const startedAt = useRef(Date.now());           // значение без ререндера

  useEffect(() => {                               // побочный эффект
    const id = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(id);               // очистка
  }, []);

  return <p>Прошло {seconds} c</p>;
}
```

## Группы встроенных хуков

| Группа | Хуки | Для чего |
| --- | --- | --- |
| Состояние | `useState`, `useReducer` | данные, вызывающие ререндер |
| Контекст | `useContext`, `use` | чтение данных провайдера |
| Ссылки | `useRef`, `useImperativeHandle` | DOM-узлы и мутируемые значения |
| Эффекты | `useEffect`, `useLayoutEffect`, `useInsertionEffect` | синхронизация с внешним миром |
| Производительность | `useMemo`, `useCallback`, `useTransition`, `useDeferredValue` | мемоизация и приоритеты |
| Прочие | `useId`, `useSyncExternalStore`, `useDebugValue` | id для a11y, внешние store |
| React 19 | `useActionState`, `useFormStatus`, `useOptimistic` | формы и Actions |

## Как хуки работают внутри

React хранит хуки компонента связным списком в его fiber-узле. При каждом рендере хуки вызываются в том же порядке, и React сопоставляет вызов с ячейкой по **порядковому номеру**. Поэтому хуки нельзя вызывать в условиях и циклах — см. правила хуков.

## Что важно помнить

- Хуки работают только в функциональных компонентах и кастомных хуках.
- Префикс `use` — не формальность: по нему линтер и React Compiler распознают хуки.
- Кастомный хук переиспользует **логику**, а не состояние: каждый вызов получает свое состояние.
- Хуки появились в React 16.8 и заменили классы, HOC и render props для большинства задач.

## Мини-шпаргалка

Хук = функция `use*`, подключающая компонент к возможностям React. State, эффекты, контекст, ref, мемоизация, конкурентность. Хранятся в fiber по порядку вызова. Свои хуки — для переиспользования логики.
