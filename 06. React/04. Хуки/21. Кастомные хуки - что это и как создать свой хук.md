# Кастомные хуки: что это и как создать свой хук

> [!NOTE]
> **Кастомный хук** — функция с именем `use*`, которая вызывает другие хуки и инкапсулирует переиспользуемую логику с состоянием: загрузку данных, подписку на события, работу с формой, localStorage, медиазапросы. Кастомный хук делится **логикой, а не состоянием**: каждый компонент, который его вызывает, получает свои независимые state и эффекты. Внутри можно использовать любые хуки, включая другие кастомные.

## Вопрос

Что такое кастомный хук? Как создать свой хук и можно ли использовать другие хуки внутри?

## Создание хука

```jsx
import { useState, useEffect } from "react";

export function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved !== null ? JSON.parse(saved) : initialValue;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

// использование
function Settings() {
  const [theme, setTheme] = useLocalStorage("theme", "light");
  return <button onClick={() => setTheme(theme === "light" ? "dark" : "light")}>{theme}</button>;
}
```

Шаги:

1. Найти повторяющуюся логику с хуками в нескольких компонентах.
2. Вынести ее в функцию `useЧтоТо`.
3. Принимать параметры и возвращать то, что нужно компоненту: значение, кортеж или объект.

## Хуки внутри хуков

```jsx
function useFetch(url) {
  const [state, setState] = useState({ data: null, error: null, loading: true });

  useEffect(() => {
    const controller = new AbortController();
    setState((s) => ({ ...s, loading: true }));
    fetch(url, { signal: controller.signal })
      .then((r) => r.json())
      .then((data) => setState({ data, error: null, loading: false }))
      .catch((error) => {
        if (error.name !== "AbortError") setState({ data: null, error, loading: false });
      });
    return () => controller.abort();
  }, [url]);

  return state;
}

function useUser(id) {
  const result = useFetch(`/api/users/${id}`); // кастомный хук внутри кастомного
  const isOnline = useOnlineStatus();
  return { ...result, isOnline };
}
```

Правила хуков действуют и здесь: вызовы только на верхнем уровне функции хука.

## Кастомные хуки как паттерн

Кастомные хуки заменили большинство HOC и render props:

| Подход | Минусы |
| --- | --- |
| HOC | «обертки» в дереве, конфликты имен props, неявные зависимости |
| Render props | вложенность, «callback hell» в JSX |
| Кастомный хук | явный вызов, обычные значения, легко комбинировать |

Хорошие хуки:

- делают одну вещь (`useDebounce`, `useMediaQuery`, `useCart`);
- возвращают стабильные функции (`useCallback`) — их могут использовать в зависимостях;
- не знают о разметке — только логика;
- тестируются через `renderHook` из Testing Library.

## Что важно помнить

- Имя обязано начинаться с `use` — так React и линтер понимают, что внутри хуки.
- Если функция не вызывает хуки, это обычная утилита — не называйте ее `use*`.
- Два компонента с одним хуком не делят состояние; для общего состояния нужен контекст или store.
- Для загрузки данных в продакшене лучше TanStack Query или SWR, чем самописный `useFetch`.

## Мини-шпаргалка

Кастомный хук = функция `use*` с другими хуками внутри. Переиспользует логику, не state. Возвращает значения и функции. Заменил HOC и render props. Правила хуков действуют.
