# Правила хуков и почему хук нельзя вызывать в условии

> [!NOTE]
> Два правила хуков: 1) вызывать хуки **только на верхнем уровне** — не в условиях, циклах, вложенных функциях и после раннего `return`; 2) вызывать их **только из React-функций** — компонентов и кастомных хуков. Причина — React идентифицирует хуки по порядку вызова. Если в одном рендере хук пропущен, все следующие хуки «съедут» на чужие ячейки состояния. Соблюдение правил проверяет `eslint-plugin-react-hooks`.

## Вопрос

Какие есть правила хуков? Что будет, если вызвать хук внутри условия?

## Основная идея

React не знает имен переменных состояния — только номер вызова хука:

```jsx
function Form() {
  const [name, setName] = useState("Анна");   // ячейка 1
  const [age, setAge] = useState(25);         // ячейка 2
  useEffect(() => { document.title = name; }); // ячейка 3
}
```

При каждом рендере React идет по списку и выдает значение ячейки по порядку.

## Что ломается при хуке в условии

```jsx
function Form({ showAge }) {
  const [name, setName] = useState("Анна");
  if (showAge) {
    const [age, setAge] = useState(25);       // нельзя
  }
  const [email, setEmail] = useState("");
}
```

| Рендер | Ячейка 1 | Ячейка 2 | Ячейка 3 |
| --- | --- | --- | --- |
| `showAge = true` | name | age | email |
| `showAge = false` | name | email ← получает age | — |

Итог — неправильные значения или ошибка «Rendered fewer hooks than expected».

## Как сделать правильно

```jsx
function Form({ showAge }) {
  const [name, setName] = useState("Анна");
  const [age, setAge] = useState(25);         // хук всегда вызывается
  const [email, setEmail] = useState("");

  return (
    <>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      {showAge && <input value={age} onChange={(e) => setAge(+e.target.value)} />}
    </>
  );
}

// условие внутри эффекта, а не вокруг него
useEffect(() => {
  if (!userId) return;
  fetchUser(userId);
}, [userId]);
```

Если части компонента нужны разные хуки — вынесите их в отдельный компонент и рендерьте его условно.

## Где хуки вызывать нельзя

- в условиях, циклах, `switch`;
- после раннего `return`;
- в обработчиках событий и колбэках `useMemo`/`useEffect`;
- в классовых компонентах и обычных функциях;
- в `try/catch/finally`.

## Что важно помнить

- Исключение — `use` в React 19: его можно вызывать в условиях и циклах.
- Правило `react-hooks/rules-of-hooks` в ESLint ловит нарушения до запуска.
- Имя кастомного хука обязано начинаться с `use`, иначе линтер не проверит правила внутри.
- Порядок хуков должен быть одинаковым при каждом рендере компонента.

## Мини-шпаргалка

Хуки — только на верхнем уровне и только в компонентах или хуках. React связывает хуки с ячейками по порядку вызова. Хук в условии → сдвиг ячеек и неверное состояние. Условие — внутрь хука или в отдельный компонент.
