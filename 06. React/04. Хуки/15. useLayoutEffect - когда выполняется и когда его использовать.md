# useLayoutEffect: когда выполняется и когда его использовать

> [!NOTE]
> `useLayoutEffect` работает как `useEffect`, но выполняется **синхронно после изменения DOM и до того, как браузер нарисует кадр**. Пока эффект не завершится, пользователь ничего не увидит. Это нужно, когда надо измерить DOM (размеры, позицию) и сразу поправить разметку — например, расположить тултип — без мигания. Цена — блокировка отрисовки, поэтому по умолчанию используют `useEffect`.

## Вопрос

Что делает `useLayoutEffect`? Когда React его выполняет и в каких случаях его стоит использовать?

## Порядок выполнения

```text
render → commit: DOM обновлен
       → useLayoutEffect (синхронно, браузер ждет)
       → браузер рисует кадр
       → useEffect (асинхронно)
```

Если внутри `useLayoutEffect` обновить state, React перерендерит компонент **до отрисовки** — пользователь увидит только итоговый результат.

## Пример: позиционирование тултипа

```jsx
import { useLayoutEffect, useRef, useState } from "react";

function Tooltip({ targetRect, children }) {
  const ref = useRef(null);
  const [height, setHeight] = useState(0);

  useLayoutEffect(() => {
    setHeight(ref.current.getBoundingClientRect().height);
  }, []);

  const top = targetRect.top - height < 0 ? targetRect.bottom : targetRect.top - height;

  return <div ref={ref} style={{ position: "absolute", top }}>{children}</div>;
}
```

С `useEffect` тултип сначала отрисовался бы в неправильном месте, а потом «прыгнул».

## useEffect и useLayoutEffect

| | `useEffect` | `useLayoutEffect` |
| --- | --- | --- |
| Когда | после отрисовки | после изменения DOM, до отрисовки |
| Блокирует отрисовку | нет | да |
| Для чего | запросы, подписки, логирование | измерение DOM, синхронная правка layout, скролл |
| SSR | не выполняется на сервере | не выполняется, в старых версиях — предупреждение |

## Когда использовать

- измерить элемент и сразу изменить положение или размер;
- восстановить позицию прокрутки до отрисовки;
- синхронизировать анимацию с DOM;
- избежать видимого мигания при правке layout.

## Что важно помнить

- Тяжелая работа в `useLayoutEffect` замедляет отрисовку каждого кадра.
- На сервере эффекты не выполняются; для SSR-безопасного кода используют `useEffect` или проверяют окружение.
- Для CSS-in-JS библиотек, вставляющих стили, есть `useInsertionEffect` — он срабатывает еще раньше.
- Cleanup `useLayoutEffect` тоже выполняется синхронно.

## Мини-шпаргалка

`useLayoutEffect` — после DOM, до отрисовки, синхронно. Для измерений и правок layout без мигания. Блокирует отрисовку — по умолчанию `useEffect`.
