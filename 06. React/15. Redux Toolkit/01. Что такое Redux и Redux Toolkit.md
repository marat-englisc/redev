# Что такое Redux и Redux Toolkit

> [!NOTE]
> **Redux** — библиотека для управления глобальным состоянием по принципу однонаправленного потока данных: всё состояние лежит в одном **store**, изменить его можно только отправив **action** (`dispatch`), а новое состояние вычисляет чистая функция-**reducer**. **Redux Toolkit (RTK)** — официальный и рекомендуемый способ писать на Redux: он убирает boilerplate (`configureStore`, `createSlice`, `createAsyncThunk`), включает Immer, DevTools и проверки по умолчанию, а для серверных данных дает **RTK Query**.

## Вопрос

Что такое Redux и какие проблемы он решает? Из чего состоит поток данных Redux и зачем нужен Redux Toolkit?

## Поток данных

```text
UI ──dispatch(action)──▶ store ──reducer(state, action)──▶ новый state
 ▲                                                            │
 └──────────── useSelector подписан на нужную часть ◀─────────┘
```

| Понятие | Что это |
| --- | --- |
| Store | единственный объект с состоянием приложения |
| Action | объект `{ type, payload }`, описывающий **что произошло** |
| Reducer | чистая функция `(state, action) => newState` |
| Dispatch | способ отправить action в store |
| Selector | функция, достающая данные из state |
| Middleware | перехватывает actions между dispatch и reducer (логирование, async) |

## Три принципа Redux

1. **Single source of truth** — одно дерево состояния.
2. **State is read-only** — менять только через actions.
3. **Изменения — чистыми функциями**: reducer не мутирует state и не делает побочных эффектов.

## Классический Redux и Redux Toolkit

```javascript
// классический Redux: константы, action creators, switch, ручная иммутабельность
const ADD_TODO = "todos/add";
const addTodo = (text) => ({ type: ADD_TODO, payload: text });

function todosReducer(state = [], action) {
  switch (action.type) {
    case ADD_TODO:
      return [...state, { id: Date.now(), text: action.payload, done: false }];
    default:
      return state;
  }
}
```

```typescript
// Redux Toolkit: то же самое
import { createSlice, type PayloadAction } from "@reduxjs/toolkit";

const todosSlice = createSlice({
  name: "todos",
  initialState: [] as Todo[],
  reducers: {
    todoAdded(state, action: PayloadAction<string>) {
      state.push({ id: crypto.randomUUID(), text: action.payload, done: false }); // Immer
    },
  },
});

export const { todoAdded } = todosSlice.actions;
export default todosSlice.reducer;
```

## Что входит в Redux Toolkit

| API | Для чего |
| --- | --- |
| `configureStore` | создание store с DevTools, thunk и проверками |
| `createSlice` | reducer + actions в одном месте |
| `createAsyncThunk` | асинхронная логика с pending/fulfilled/rejected |
| `createSelector` | мемоизированные селекторы (reselect) |
| `createEntityAdapter` | нормализованные коллекции |
| `createListenerMiddleware` | реакции на actions (побочные эффекты) |
| RTK Query (`createApi`) | загрузка и кеширование серверных данных |

## Когда Redux нужен

- много глобального клиентского состояния, которое меняется из разных частей приложения;
- важны предсказуемость, история изменений и отладка через Redux DevTools (time-travel);
- большая команда и нужен единый строгий подход;
- в проекте уже есть Redux — частый случай в вакансиях.

Для небольшого состояния достаточно `useState`, контекста или Zustand, а для серверных данных — TanStack Query или RTK Query.

## Что важно помнить

- Классический Redux без Toolkit считается устаревшим способом; пакет `redux` теперь помечает `createStore` как deprecated, рекомендуя `configureStore`.
- Redux — не часть React: связку дает пакет `react-redux` (`Provider`, `useSelector`, `useDispatch`).
- Reducer должен быть чистым: без запросов, `Date.now()`, `Math.random()` — такие значения готовят в action creator или `prepare`.
- В store кладут сериализуемые данные: без классов, функций, Promise, DOM-узлов.
- Имена actions в RTK — события в прошедшем времени: `todoAdded`, а не `addTodo` (рекомендация Redux Style Guide).

## Мини-шпаргалка

Redux: store → dispatch(action) → reducer → новый state → useSelector. Принципы: один store, state только для чтения, чистые reducers. RTK: `configureStore`, `createSlice` (+Immer), `createAsyncThunk`, `createSelector`, `createEntityAdapter`, RTK Query.
