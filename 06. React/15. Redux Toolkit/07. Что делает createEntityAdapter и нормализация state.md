# Что делает createEntityAdapter и нормализация state

> [!NOTE]
> **Нормализация** — хранение коллекции не массивом, а как `{ ids: [...], entities: { [id]: item } }`: каждый элемент лежит в одном месте и находится по id за O(1). `createEntityAdapter` генерирует такое начальное состояние, готовые reducers для CRUD (`addOne`, `upsertMany`, `updateOne`, `removeOne`, `setAll`) и селекторы (`selectAll`, `selectById`, `selectIds`), а также может поддерживать порядок через `sortComparer`.

## Вопрос

Что такое нормализация state в Redux и зачем она нужна? Как работает `createEntityAdapter`?

## Проблема массива

```typescript
// поиск и обновление по id — O(n), легко ошибиться с иммутабельностью
state.items = state.items.map((t) => (t.id === id ? { ...t, done: true } : t));
```

Если один и тот же пользователь встречается в постах и комментариях, при денормализованных данных его придется обновлять в нескольких местах.

## Нормализованная форма

```typescript
{
  ids: ["a1", "b2"],
  entities: {
    a1: { id: "a1", text: "Купить хлеб", done: false },
    b2: { id: "b2", text: "Позвонить", done: true },
  },
}
```

## createEntityAdapter

```typescript
import { createEntityAdapter, createSlice, type PayloadAction } from "@reduxjs/toolkit";

type Todo = { id: string; text: string; done: boolean; createdAt: string };

const todosAdapter = createEntityAdapter<Todo>({
  sortComparer: (a, b) => b.createdAt.localeCompare(a.createdAt), // новые сверху
});

const todosSlice = createSlice({
  name: "todos",
  initialState: todosAdapter.getInitialState({ status: "idle" as "idle" | "loading" }),
  reducers: {
    todoAdded: todosAdapter.addOne,
    todoRemoved: todosAdapter.removeOne,
    todoUpdated: todosAdapter.updateOne,          // payload: { id, changes }
    todoToggled(state, action: PayloadAction<string>) {
      const todo = state.entities[action.payload];
      if (todo) todo.done = !todo.done;
    },
  },
  extraReducers: (builder) => {
    builder.addCase(fetchTodos.fulfilled, (state, action) => {
      todosAdapter.setAll(state, action.payload);
      state.status = "idle";
    });
  },
});

export const { selectAll: selectAllTodos, selectById: selectTodoById, selectIds: selectTodoIds, selectTotal: selectTodosCount } =
  todosAdapter.getSelectors((state: RootState) => state.todos);
```

```tsx
dispatch(todoUpdated({ id: "a1", changes: { text: "Купить молоко" } }));
const todo = useAppSelector((state) => selectTodoById(state, "a1"));
```

## Методы адаптера

| Метод | Что делает |
| --- | --- |
| `addOne` / `addMany` | добавить, существующие id не трогает |
| `setOne` / `setMany` / `setAll` | заменить целиком |
| `upsertOne` / `upsertMany` | добавить или слить поля с существующим |
| `updateOne` / `updateMany` | частичное обновление `{ id, changes }` |
| `removeOne` / `removeMany` / `removeAll` | удалить |

## Список и элемент: меньше ререндеров

```tsx
function TodoList() {
  const ids = useAppSelector(selectTodoIds);         // массив id меняется только при добавлении/удалении
  return <ul>{ids.map((id) => <TodoItem key={id} id={id} />)}</ul>;
}

const TodoItem = memo(function TodoItem({ id }: { id: string }) {
  const todo = useAppSelector((state) => selectTodoById(state, id)); // ререндер только этого элемента
  return <li>{todo?.text}</li>;
});
```

## Что важно помнить

- Нормализуйте коллекции, по которым часто ищут и которые обновляют по id; для маленьких статичных списков массив проще.
- Связанные сущности храните отдельно и ссылайтесь по id (`post.authorId`), а не вкладывайте копии.
- Если id не в поле `id`, задайте `selectId: (book) => book.isbn`.
- Для ответов API с вложенными данными нормализацию делают при сохранении в store (вручную или через `normalizr`).
- RTK Query хранит ответы по запросам и сам нормализацию не делает; при необходимости ее выполняют в `transformResponse`.

## Мини-шпаргалка

Нормализация: `{ ids, entities }`, элемент по id за O(1), одно место хранения. `createEntityAdapter({ sortComparer, selectId })` → `getInitialState`, CRUD-reducers (`addOne`, `upsertMany`, `updateOne`, `removeOne`, `setAll`), `getSelectors` (`selectAll`, `selectById`, `selectIds`).
