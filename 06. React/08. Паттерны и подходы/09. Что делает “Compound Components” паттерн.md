# Compound Components: семейство компонентов с общей логикой

> [!NOTE]
> Compound Components — набор согласованных компонентов, которые вместе реализуют один виджет, сохраняя гибкость его JSX-композиции.

## Вопрос

Как связать корень виджета и его части, не передавая множество внутренних props вручную?

## Один договор для нескольких частей

У аккордеона есть корень, заголовки и панели. Пользователь библиотеки хочет самостоятельно выбирать их содержание и порядок, а не описывать весь интерфейс большим объектом конфигурации. При этом открытое состояние должно оставаться согласованным.

Корневой компонент может хранить состояние и предоставлять его дочерним частям через Context. Части знают общий контракт и выполняют свою роль. Это позволяет вставлять между ними дополнительную разметку: Context передает данные через дерево, а не только непосредственным детям.

Название вида `Accordion.Item` — удобное API, но сама точечная запись не создает связь. Важны реализованный контекст, общие правила и понятная ошибка при использовании части вне корня. Некоторые библиотеки строят подобные договоры иначе; Context — распространенный вариант, а не обязательное определение паттерна.

## Пример

```jsx
import { createContext, useContext, useId, useState } from 'react';

const AccordionContext = createContext(null);

function Accordion({ children }) {
  const [activeId, setActiveId] = useState(null);
  return (
    <AccordionContext.Provider value={{ activeId, setActiveId }}>
      {children}
    </AccordionContext.Provider>
  );
}

function Item({ id, title, children }) {
  const context = useContext(AccordionContext);
  const panelId = useId();
  if (!context) throw new Error('Item должен находиться внутри Accordion');
  const open = context.activeId === id;
  return (
    <section>
      <h2>
        <button
          aria-expanded={open}
          aria-controls={panelId}
          onClick={() => context.setActiveId(open ? null : id)}
        >
          {title}
        </button>
      </h2>
      <div id={panelId} hidden={!open}>
        {children}
      </div>
    </section>
  );
}

Accordion.Item = Item;

export default function FAQ() {
  return (
    <Accordion>
      <Accordion.Item id="delivery" title="Как доставляют?">
        Курьером.
      </Accordion.Item>
      <p>Ниже — другой частый вопрос.</p>
      <Accordion.Item id="payment" title="Как оплатить?">
        Картой.
      </Accordion.Item>
    </Accordion>
  );
}
```

Открытие одного раздела закрывает другой: состояние принадлежит корню. Содержимое и промежуточный абзац задает вызывающая сторона.

## Нюансы

- Для Tabs и Menu нужны дополнительные клавиатурные правила, фокус и соответствующая семантика; одного Context недостаточно.
- Изменение контекста обновляет его потребителей: учитывайте размер сложного виджета.
- Стабильные идентификаторы лучше не выводить из случайного порядка детей.
- Простая форма с двумя полями не обязательно требует такого API.

## Что важно помнить

- Compound Components — набор связанных компонентов, которые делят состояние через контекст: `<Tabs>`, `<Tabs.List>`, `<Tabs.Panel>`.
- Пользователь управляет структурой разметки, а логика остается внутри.
- Проверяйте наличие родителя в хуке контекста и бросайте понятную ошибку.
- Паттерн используют Radix UI, Headless UI, Reach UI.

## Мини-шпаргалка

```text
Root → общее состояние
Parts → согласованные роли
Потребитель → композиция и содержимое
```
