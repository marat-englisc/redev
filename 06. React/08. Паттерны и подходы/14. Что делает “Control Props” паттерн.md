# Control Props: компонент с внешним или внутренним состоянием

> [!NOTE]
> Control Props позволяют пользователю компонента управлять его значением через props, сохраняя возможность автономного режима с внутренним state.

## Вопрос

Как реализовать один переключатель для controlled и uncontrolled использования?

## Владелец значения определяется контрактом

Простой переключатель может хранить `on` внутри. Но форме может потребоваться одновременно сбрасывать несколько переключателей, синхронизировать их или запретить изменение до проверки. Тогда текущее значение должно принадлежать родителю.

Control Props обычно используют пару `value`/`onChange`, `open`/`onOpenChange` или `checked`/`onCheckedChange`. Если контролирующий prop передан, компонент берет значение из него и сообщает о намерении изменить его. Если prop отсутствует, компонент обновляет внутреннее состояние, первоначально заданное через `defaultValue` или аналог.

Не следует копировать controlled-prop во внутренний state и синхронизировать копию эффектом: появляются два владельца и промежуточные расхождения. Вместо этого вычисляют отображаемое значение из выбранного режима. Проверять присутствие boolean-prop нужно через `!== undefined`, иначе переданное `false` ошибочно сочтется отсутствием.

## Пример

```jsx
import { useState } from 'react';

function Toggle({ checked, defaultChecked = false, onCheckedChange }) {
  const [internal, setInternal] = useState(defaultChecked);
  const controlled = checked !== undefined;
  const current = controlled ? checked : internal;

  function toggle() {
    const next = !current;
    if (!controlled) setInternal(next);
    onCheckedChange?.(next);
  }

  return (
    <button type="button" aria-pressed={current} onClick={toggle}>
      {current ? 'Включено' : 'Выключено'}
    </button>
  );
}

export default function App() {
  const [notifications, setNotifications] = useState(false);
  return (
    <>
      <p>Автономный переключатель:</p>
      <Toggle defaultChecked />
      <p>Управляется формой:</p>
      <Toggle checked={notifications} onCheckedChange={setNotifications} />
      <button onClick={() => setNotifications(false)}>
        Отключить уведомления
      </button>
    </>
  );
}
```

Первый экземпляр сам хранит состояние. Второй только предлагает следующее значение родителю; кнопка сброса меняет его через `notifications`. Если родитель не применит callback, controlled-переключатель останется в прежнем состоянии.

## Нюансы

- Режим лучше не менять в течение жизни экземпляра; определите этот договор явно.
- `defaultChecked` — начальная настройка, а не команда постоянно синхронизировать значение.
- Для controlled-режима обычно обязателен обработчик, либо явно предусмотрен read-only API.
- Паттерн относится ко всем управляемым значениям, не только к HTML-формам.

## Что важно помнить

- Control Props позволяет компоненту работать и как управляемый (`value` + `onChange`), и как неуправляемый (`defaultValue`).
- Не переключайте компонент между режимами во время жизни — React предупредит об этом.
- Часто реализуют хуком `useControllableState`.
- Паттерн используют библиотеки компонентов: Radix, MUI, Chakra.

## Мини-шпаргалка

```text
checked !== undefined → значение извне
Иначе → внутренний state
onCheckedChange(next) → намерение изменить
```
