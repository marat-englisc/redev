# Function as Child: функция в children

> [!NOTE]
> Function as Child, FaCC, — вариант render props, в котором функция отображения передается через `children`, а компонент явно ее вызывает.

## Вопрос

Как React-компонент может принять функцию между открывающим и закрывающим тегами?

## Children — часть контракта компонента

Когда записано `<Tracker>{data => <p>{data}</p>}</Tracker>`, `Tracker` получает функцию в `props.children`. React не должен сам догадываться, с какими аргументами ее вызвать. Реализация `Tracker` делает это явно: `children(data)`.

Такой API отделяет владельца поведения от способа отображения. Владелец вычисляет, например, координаты указателя, состояние загрузки или прогресс. Потребитель выбирает JSX для этих данных. Это особенно удобно в библиотеке, которая предоставляет поведение, но не навязывает внешний вид.

От обычной композиции отличие в моменте создания содержимого. Обычные `children` — уже переданное содержимое. FaCC — рецепт содержимого, который можно вызвать с внутренними данными компонента. Если дополнительная компонентная граница не нужна, кастомный hook может дать ту же гибкость без вложенного callback.

## Пример

```jsx
import { useState } from 'react';

function PointerArea({ children }) {
  const [position, setPosition] = useState({ x: 0, y: 0 });
  return (
    <div
      style={{ minHeight: 180, border: '1px solid #999' }}
      onPointerMove={(event) => {
        const rect = event.currentTarget.getBoundingClientRect();
        setPosition({
          x: Math.round(event.clientX - rect.left),
          y: Math.round(event.clientY - rect.top),
        });
      }}
    >
      {children(position)}
    </div>
  );
}

export default function App() {
  return (
    <PointerArea>
      {({ x, y }) => (
        <p>
          Координаты в области: {x}, {y}
        </p>
      )}
    </PointerArea>
  );
}
```

`PointerArea` владеет координатами и обработчиком. Вызывающая сторона получает данные и показывает текст. Она могла бы вернуть другой UI, не меняя механизм измерения.

## Нюансы

- Если передать функцию обычному DOM-тегу как дочерний контент, она не превратится в интерфейс. Нужен компонент, который выполняет контракт FaCC.
- Hooks нельзя вызывать прямо в callback `children`: верните отдельный компонент, если ему нужна собственная логика.
- Частое движение указателя вызывает частые обновления; сложное содержимое стоит профилировать.
- В TypeScript контракт описывают как `children: (data: Data) => ReactNode`.

## Что важно помнить

- Function as Child — вариант render props, где функция передается через `children`.
- Пример: `<Mouse>{({ x, y }) => <Cursor x={x} y={y} />}</Mouse>`.
- Сегодня чаще заменяется кастомным хуком.
- Типизируйте `children` как функцию: `children: (state: State) => ReactNode`.

## Мини-шпаргалка

```text
FaCC = render prop с именем children
Принимающий компонент: children(data)
Вызывающая сторона: data => JSX
```
