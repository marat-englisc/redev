# Как использовать gestures hover, press, focus и drag

> [!NOTE]
> Motion добавляет к элементам **жесты** с временными состояниями: `whileHover` (пока курсор над элементом — эмулированные «hover» от касаний на тач-экранах отфильтрованы), `whilePress` (пока элемент нажат мышью, пальцем или клавишей Enter на фокусируемом элементе), `whileFocus` (пока элемент в фокусе), `whileDrag` (во время перетаскивания), `whileInView` (в зоне видимости). Когда жест заканчивается, элемент возвращается к состоянию `animate`. Есть события: `@hoverStart`/`@hoverEnd`, `@pressStart`/`@press`/`@pressCancel`, `@panStart`/`@pan`/`@panEnd`, `@dragStart`/`@drag`/`@dragEnd`. **Перетаскивание** включается пропом `drag` (`true`, `'x'` или `'y'`) и настраивается: `dragConstraints` (границы в пикселях или ref элемента-контейнера), `dragElastic` (упругость за пределами границ, 0–1), `dragMomentum` (инерция после отпускания), `dragSnapToOrigin` (возврат в начало), `dragTransition`. Для жестов на тач-устройствах нужен `touch-action: none` (или `pan-y` для горизонтального drag), иначе браузер воспримет движение как прокрутку. Доступность: жесты не заменяют семантику — кликабельный элемент должен быть `<button>`/`<a>`, у фокуса должен оставаться видимый индикатор, а drag-взаимодействиям нужна альтернатива с клавиатуры.

## Вопрос

Как использовать жесты hover, press, focus и drag в Motion for Vue?

## Hover и press

```vue
<script setup lang="ts">
import { motion } from 'motion-v';
</script>

<template>
  <motion.button
    class="rounded-lg bg-indigo-600 px-4 py-2 text-white"
    :whileHover="{ scale: 1.04 }"
    :whilePress="{ scale: 0.96 }"
    :transition="{ type: 'spring', stiffness: 400, damping: 24 }"
    @press="addToCart"
  >
    В корзину
  </motion.button>
</template>
```

`@press` срабатывает при успешном завершении нажатия; для обычной логики достаточно и `@click`.

## События жестов

```vue
<motion.div
  :whileHover="{ y: -4 }"
  @hoverStart="prefetchDetails"
  @hoverEnd="cancelPrefetch"
/>
```

## Focus

```vue
<motion.input
  class="rounded-lg border px-3 py-2 focus-visible:outline-2 focus-visible:outline-indigo-500"
  :whileFocus="{ scale: 1.02 }"
/>
```

Анимация фокуса — дополнение к видимому outline, а не его замена.

## Drag

```vue
<script setup lang="ts">
const area = useTemplateRef<HTMLElement>('area');
</script>

<template>
  <div ref="area" class="relative h-64 rounded-xl bg-slate-100">
    <motion.div
      class="size-20 touch-none rounded-xl bg-violet-600"
      drag
      :dragConstraints="area"
      :dragElastic="0.2"
      :whileDrag="{ scale: 1.08, cursor: 'grabbing' }"
      @dragEnd="(event, info) => savePosition(info.point)"
    />
  </div>
</template>
```

```vue
<!-- горизонтальный слайдер: только ось x, без инерции -->
<motion.div drag="x" :dragConstraints="{ left: -600, right: 0 }" :dragMomentum="false" class="flex touch-pan-y" />

<!-- «свайп для удаления» с возвратом -->
<motion.li drag="x" dragSnapToOrigin @dragEnd="(e, info) => Math.abs(info.offset.x) > 120 && remove(item.id)" />
```

| Проп | Смысл |
| --- | --- |
| `drag` | `true`, `'x'`, `'y'` |
| `dragConstraints` | `{ top, left, right, bottom }` или ref контейнера |
| `dragElastic` | Упругость за границами (0 — жёстко) |
| `dragMomentum` | Инерция после отпускания |
| `dragSnapToOrigin` | Вернуть в исходную позицию |
| `dragListener` + `useDragControls` | Начинать drag с другого элемента (ручка) |

## Touch

```css
.draggable { touch-action: none; }          /* drag в обе стороны */
.slider    { touch-action: pan-y; }         /* горизонтальный drag, вертикальная прокрутка страницы работает */
```

## Доступность

| Проблема | Решение |
| --- | --- |
| `div` с `whilePress` вместо кнопки | `motion.button` / `motion.a` |
| Drag — единственный способ изменить порядок | Кнопки «вверх/вниз» или клавиши |
| Скрытый outline ради анимации фокуса | Оставить `focus-visible` стиль |
| Сильные движения при hover | Учитывать `useReducedMotion` |

## Частые ошибки

- Без `touch-action` drag на телефоне конфликтует с прокруткой.
- `dragConstraints` с ref, который ещё не смонтирован — передавайте ref, а не `.value`.
- Жесты на некликабельных элементах без роли и клавиатурной поддержки.
- Слишком сильные масштабирования (`scale: 1.2`) — «прыгающий» интерфейс.

## Что важно помнить

- `whileHover`, `whilePress`, `whileFocus`, `whileDrag` — временные состояния поверх `animate`.
- `drag` + `dragConstraints`/`dragElastic`/`dragMomentum`; `touch-action` для тач-устройств.
- Жесты дополняют семантику и доступность, а не заменяют их.

## Мини-шпаргалка

- `:whileHover="{ scale: 1.04 }" :whilePress="{ scale: 0.96 }"`.
- `@hoverStart`, `@press`, `@dragEnd="(e, info) => ..."`.
- `drag="x" :dragConstraints="containerRef" :dragElastic="0.2"`.
- `dragSnapToOrigin`, `:dragMomentum="false"`.
- `touch-action: none | pan-y`.
