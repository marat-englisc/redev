# Что такое Motion for Vue и зачем нужен motion-v

> [!NOTE]
> **Motion for Vue** (пакет **`motion-v`**) — библиотека анимаций из экосистемы Motion (ранее Framer Motion) с Vue-ориентированным API. Она позволяет описывать анимации **декларативно** через состояния: элемент `<motion.div>` получает `initial` (откуда), `animate` (куда), `transition` (как: длительность, easing, **пружины**), а при изменении реактивных данных Motion сам плавно переводит элемент в новое состояние и **корректно прерывает** текущую анимацию. Кроме этого: **жесты** (`whileHover`, `whilePress`, `whileFocus`, `drag`), анимации **удаления** (`AnimatePresence` + `exit`), **layout-анимации** (`layout`, `layoutId` для «перетекания» элемента между местами), анимации при **прокрутке** (`whileInView`, `useScroll` + `useTransform`), **variants** с оркестровкой детей (`staggerChildren`), директива `v-motion` и composables (`useAnimate`, `useMotionValue`, `useSpring`, `useReducedMotion`). Анимации transform и opacity выполняются аппаратно ускоренно (Web Animations API, где возможно). Когда Motion не нужен: простые hover-эффекты, смена цвета, подчёркивания — их проще и дешевле сделать CSS/Tailwind-переходами или встроенным во Vue `<Transition>`. Хорошая анимация объясняет изменение (откуда появилось, куда исчезло, что можно перетащить), а не украшает.

## Вопрос

Что такое Motion for Vue и когда стоит использовать `motion-v`?

## Пример

```vue
<script setup lang="ts">
import { motion, AnimatePresence } from 'motion-v';
const open = ref(false);
</script>

<template>
  <motion.button :whileHover="{ scale: 1.03 }" :whilePress="{ scale: 0.97 }" @click="open = !open">
    Фильтры
  </motion.button>

  <AnimatePresence>
    <motion.aside
      v-if="open"
      key="filters"
      :initial="{ opacity: 0, x: -24 }"
      :animate="{ opacity: 1, x: 0 }"
      :exit="{ opacity: 0, x: -24 }"
      :transition="{ type: 'spring', stiffness: 300, damping: 30 }"
    >
      ...
    </motion.aside>
  </AnimatePresence>
</template>
```

## Что умеет motion-v

| Возможность | API |
| --- | --- |
| Анимация состояния | `<motion.div :initial :animate :transition>` |
| Именованные состояния, каскады | `variants`, `staggerChildren` |
| Жесты | `whileHover`, `whilePress`, `whileFocus`, `drag`, `whileDrag` |
| Удаление с анимацией | `AnimatePresence` + `exit` |
| Изменение раскладки | `layout`, `layoutId` |
| Прокрутка | `whileInView`, `useScroll`, `useTransform` |
| Директива | `v-motion`, пресеты `MotionPlugin` |
| Императивно | `useAnimate`, `animate()` |
| Значения вне рендера | `useMotionValue`, `useSpring` |
| Доступность | `useReducedMotion` |

## Что выбрать

| Задача | Инструмент |
| --- | --- |
| Hover-цвет, подчёркивание, простая смена opacity | CSS / Tailwind `transition` |
| Появление/исчезновение по `v-if`, переходы страниц | Vue `<Transition>` или Motion |
| Анимация списков при перестановке | Vue `<TransitionGroup>` или Motion `layout` |
| Пружины, прерываемые анимации от состояния | Motion |
| Drag, жесты | Motion |
| Shared layout (подчёркивание вкладки, карточка → детали) | Motion `layoutId` |
| Прогресс и параллакс от прокрутки | Motion `useScroll` |

## Частые ошибки

- Ставить Motion ради одного hover-эффекта, который решается CSS.
- Анимировать всё подряд — интерфейс утомляет и отвлекает.
- Игнорировать `prefers-reduced-motion`.
- Путать `motion-v` с `@vueuse/motion` — это разные библиотеки с разным API.

## Что важно помнить

- `motion-v` — декларативные анимации состояний, жесты, exit, layout и scroll.
- Простые эффекты — CSS/Tailwind и Vue `<Transition>`.
- Анимация должна объяснять изменение интерфейса.

## Мини-шпаргалка

- `npm i motion-v`.
- `<motion.div :initial :animate :transition>`.
- `AnimatePresence` + `exit`, `layout`/`layoutId`, `whileInView`.
- `useReducedMotion()`.
