# Как использовать variants в Motion for Vue

> [!NOTE]
> **Variants** — именованные состояния анимации (`hidden`, `visible`, `active`, `disabled`), описанные объектом и переданные в проп `variants`. Тогда `initial`, `animate`, `exit`, `whileHover`, `whileInView` принимают не объект значений, а **имя** варианта (или массив имён), а шаблон читается по смыслу: `:animate="isActive ? 'active' : 'inactive'"`. Главная возможность — **распространение по дереву**: если у родителя меняется вариант, дочерние `motion`-элементы с собственными `variants` автоматически переходят в одноимённые состояния, даже без своих `initial`/`animate`. Это позволяет **оркестровать** анимацию: в `transition` варианта родителя задаются `staggerChildren` (задержка между детьми — каскадное появление списка), `delayChildren`, `when: 'beforeChildren' | 'afterChildren'` (порядок родителя и детей). Вариант может быть **функцией** от параметра `custom` (например, индекса или направления) для индивидуальных значений. Используйте variants, когда состояния повторяются, анимация большая, нужно координировать родителя и детей или шаблон стал нечитаемым; для одного элемента с одним эффектом они не обязательны.

## Вопрос

Как использовать variants в Motion for Vue и как с их помощью анимировать списки?

## Именованные состояния

```vue
<script setup lang="ts">
import { motion } from 'motion-v';

const card = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0, transition: { duration: 0.3 } },
};
</script>

<template>
  <motion.article :variants="card" initial="hidden" animate="visible" />
</template>
```

```vue
<motion.div
  :variants="{ active: { scale: 1, opacity: 1 }, inactive: { scale: 0.96, opacity: 0.6 } }"
  :animate="isActive ? 'active' : 'inactive'"
/>
```

## Каскадное появление списка

```vue
<script setup lang="ts">
const list = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { staggerChildren: 0.06, delayChildren: 0.1 } },
};
const item = {
  hidden: { opacity: 0, y: 12 },
  visible: { opacity: 1, y: 0 },
};
</script>

<template>
  <motion.ul :variants="list" initial="hidden" animate="visible">
    <motion.li v-for="p in products" :key="p.id" :variants="item">   <!-- без своих initial/animate -->
      {{ p.title }}
    </motion.li>
  </motion.ul>
</template>
```

## Порядок родителя и детей

```ts
const menu = {
  closed: { opacity: 0, transition: { when: 'afterChildren', staggerChildren: 0.03, staggerDirection: -1 } },
  open: { opacity: 1, transition: { when: 'beforeChildren', staggerChildren: 0.05 } },
};
```

| Параметр | Смысл |
| --- | --- |
| `staggerChildren` | Задержка между детьми (сек.) |
| `delayChildren` | Задержка перед первым ребёнком |
| `staggerDirection` | `1` — по порядку, `-1` — с конца |
| `when` | Родитель до (`beforeChildren`) или после (`afterChildren`) детей |

## Динамические варианты

```vue
<script setup lang="ts">
const slide = {
  enter: (direction: number) => ({ x: direction > 0 ? 300 : -300, opacity: 0 }),
  center: { x: 0, opacity: 1 },
  exit: (direction: number) => ({ x: direction > 0 ? -300 : 300, opacity: 0 }),
};
</script>

<template>
  <AnimatePresence :custom="direction">
    <motion.img :key="current.id" :src="current.url" :custom="direction" :variants="slide" initial="enter" animate="center" exit="exit" />
  </AnimatePresence>
</template>
```

`custom` передаёт параметр в функции вариантов; у `AnimatePresence` он нужен, чтобы удаляемый элемент получил **актуальное** направление.

## Варианты для жестов

```vue
<motion.button :variants="{ rest: { scale: 1 }, hover: { scale: 1.04 }, press: { scale: 0.96 } }" initial="rest" whileHover="hover" whilePress="press">
  Купить
</motion.button>
```

## Частые ошибки

- Задавать детям собственные `initial`/`animate` — они перестают наследовать варианты родителя.
- Разные имена вариантов у родителя и детей — дети не анимируются.
- `staggerChildren` в варианте ребёнка вместо родителя.
- Забыть `custom` у `AnimatePresence` для направленных переходов — exit идёт в старую сторону.

## Что важно помнить

- Variants — именованные состояния; пропсы принимают их имена.
- Варианты распространяются на детей → `staggerChildren`, `delayChildren`, `when`.
- Функции-варианты + `custom` для параметров.

## Мини-шпаргалка

- `:variants="v" initial="hidden" animate="visible"`.
- Родитель: `transition: { staggerChildren: 0.05 }`; ребёнок: только `:variants`.
- `when: 'beforeChildren'`.
- `variants: { enter: (d) => ({...}) }` + `:custom="d"`.
