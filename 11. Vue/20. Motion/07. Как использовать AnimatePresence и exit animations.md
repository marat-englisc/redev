# Как использовать AnimatePresence и exit animations

> [!NOTE]
> Когда условие `v-if` становится ложным, Vue сразу удаляет элемент из DOM — анимации исчезновения просто негде выполниться. **`AnimatePresence`** решает это: удаляемый прямой потомок остаётся в DOM, пока не проиграет анимацию из пропа **`exit`**, и только потом удаляется. Так делают закрытие модалок и выпадающих меню, исчезновение уведомлений, удаление элементов списка, смену слайдов и переходы между страницами. Требования: у прямых детей — **уникальный и стабильный `key`** (по нему Motion понимает, какой элемент входит, а какой уходит; смена `key` у одного элемента — способ анимировать замену контента), а сам `AnimatePresence` должен оставаться в дереве (не ставить `v-if` на него). Режим **`mode`**: `'sync'` (по умолчанию — вход и выход одновременно), `'wait'` (новый элемент появляется после ухода старого — слайды, шаги мастера), `'popLayout'` (уходящий элемент вынимается из потока, и соседи сразу занимают место — удобно со списками и `layout`). `:initial="false"` у `AnimatePresence` отключает анимацию появления детей при первом рендере. Встроенный во Vue `<Transition>` решает похожую задачу CSS-классами; `AnimatePresence` удобнее, когда остальная анимация уже на Motion (пружины, варианты, жесты, layout).

## Вопрос

Как с помощью `AnimatePresence` анимировать удаление элементов в Motion for Vue?

## Модальное окно

```vue
<script setup lang="ts">
import { AnimatePresence, motion } from 'motion-v';
const open = ref(false);
</script>

<template>
  <button @click="open = true">Открыть</button>

  <Teleport to="body">
    <AnimatePresence>
      <motion.div
        v-if="open"
        key="overlay"
        class="fixed inset-0 grid place-items-center bg-black/50"
        :initial="{ opacity: 0 }"
        :animate="{ opacity: 1 }"
        :exit="{ opacity: 0 }"
        @click.self="open = false"
      >
        <motion.div
          role="dialog"
          aria-modal="true"
          class="w-full max-w-md rounded-2xl bg-white p-6"
          :initial="{ opacity: 0, scale: 0.95, y: 8 }"
          :animate="{ opacity: 1, scale: 1, y: 0 }"
          :exit="{ opacity: 0, scale: 0.95, y: 8 }"
          :transition="{ duration: 0.2 }"
        >
          <slot />
        </motion.div>
      </motion.div>
    </AnimatePresence>
  </Teleport>
</template>
```

Вложенные `motion`-элементы тоже проигрывают свои `exit` перед удалением родителя.

## Список уведомлений

```vue
<AnimatePresence mode="popLayout">
  <motion.li
    v-for="toast in toasts"
    :key="toast.id"
    layout
    :initial="{ opacity: 0, y: 20 }"
    :animate="{ opacity: 1, y: 0 }"
    :exit="{ opacity: 0, x: 80 }"
  >
    {{ toast.text }}
  </motion.li>
</AnimatePresence>
```

## Замена контента по key

```vue
<!-- шаги мастера: старый шаг уходит, затем приходит новый -->
<AnimatePresence mode="wait">
  <motion.section
    :key="step"
    :initial="{ opacity: 0, x: 40 }"
    :animate="{ opacity: 1, x: 0 }"
    :exit="{ opacity: 0, x: -40 }"
  >
    <component :is="steps[step]" />
  </motion.section>
</AnimatePresence>
```

## Режимы

| `mode` | Поведение | Когда |
| --- | --- | --- |
| `sync` | Вход и выход одновременно | Независимые элементы |
| `wait` | Сначала выход, затем вход | Слайды, шаги, смена контента в одном месте |
| `popLayout` | Уходящий элемент вынимается из потока | Списки с `layout`-анимацией |

## Переходы страниц

```vue
<RouterView v-slot="{ Component, route }">
  <AnimatePresence mode="wait">
    <motion.div :key="route.path" :initial="{ opacity: 0 }" :animate="{ opacity: 1 }" :exit="{ opacity: 0 }">
      <component :is="Component" />
    </motion.div>
  </AnimatePresence>
</RouterView>
```

## AnimatePresence или Vue Transition

| Vue `<Transition>` | `AnimatePresence` |
| --- | --- |
| Встроен, без зависимостей | Нужен `motion-v` |
| CSS-классы или JS-хуки | Объекты состояний, пружины, варианты |
| Достаточно для простых fade/slide | Удобнее вместе с жестами, `layout`, вариантами |

## Частые ошибки

- Нет `key` у прямого потомка — exit не срабатывает.
- `v-if` на самом `AnimatePresence` — он удаляется вместе с детьми, exit не проигрывается.
- Индекс массива как `key` в списке — анимируется не тот элемент.
- `mode="wait"` для списков — элементы появляются по одному с задержкой.
- Обёртка (`div`) между `AnimatePresence` и `motion`-элементом — Motion не видит удаляемого потомка.

## Что важно помнить

- `AnimatePresence` задерживает удаление прямого потомка до окончания `exit`.
- Стабильный уникальный `key`; смена `key` — анимация замены.
- `mode`: `sync`, `wait`, `popLayout`.

## Мини-шпаргалка

- `<AnimatePresence><motion.div v-if key :exit /></AnimatePresence>`.
- `mode="wait"` — слайды и шаги; `mode="popLayout"` + `layout` — списки.
- `:initial="false"` — без анимации при первом рендере.
- `:key="route.path"` — переходы страниц.
