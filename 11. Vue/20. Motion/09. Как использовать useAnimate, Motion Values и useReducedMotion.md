# Как использовать useAnimate, Motion Values и useReducedMotion

> [!NOTE]
> Помимо декларативных пропсов, `motion-v` даёт composables для случаев, где удобнее управлять анимацией из кода. **`useAnimate()`** возвращает `[scope, animate]`: `scope` вешается как `ref` на элемент-корень, а `animate(selectorOrElement, keyframes, options)` запускает анимацию, причём **селекторы ограничены областью** `scope`; можно передать **последовательность** (массив шагов с `at` для таймлайна); результат — управляемый объект (`await`, `.pause()`, `.play()`, `.stop()`, `.speed`), а все анимации области автоматически останавливаются при размонтировании. Подходит для последовательностей, реакции на ответ API, интеграции со сторонним DOM. **Motion values** (`useMotionValue`) — значения, которые обновляют стиль элемента **напрямую, минуя рендер Vue**: идеальны для частых изменений (положение курсора, прокрутка, drag) — `x.set(100)`, `x.get()`, подписка `x.on('change', cb)`; производные значения создают `useTransform` (преобразование диапазонов или функция), `useSpring` (сглаживание пружиной), `useVelocity`, `useMotionTemplate` (строка из значений, например `blur(${b}px)`). **`useReducedMotion()`** возвращает реактивный флаг системной настройки «уменьшить движение» — при ней убирают параллакс, большие перемещения, автопроигрывание и вращения, оставляя короткие fade-эффекты; глобально это можно задать через `MotionConfig` с `reducedMotion="user"`.

## Вопрос

Как использовать `useAnimate`, motion values и `useReducedMotion` в Motion for Vue?

## useAnimate

```vue
<script setup lang="ts">
import { useAnimate, stagger } from 'motion-v';

const [scope, animate] = useAnimate();

async function celebrate() {
  await animate('li', { opacity: [0, 1], y: [12, 0] }, { delay: stagger(0.05) });   // селектор внутри scope
  await animate('.badge', { scale: [1, 1.3, 1] }, { duration: 0.4 });
}

onMounted(celebrate);
</script>

<template>
  <ul ref="scope">
    <li v-for="item in items" :key="item.id" style="opacity: 0">{{ item.title }}</li>
    <span class="badge">Готово</span>
  </ul>
</template>
```

## Последовательности

```ts
const controls = animate([
  ['.overlay', { opacity: 1 }, { duration: 0.2 }],
  ['.panel', { x: [-300, 0] }, { type: 'spring', stiffness: 300, damping: 30 }],
  ['.panel li', { opacity: [0, 1] }, { delay: stagger(0.04), at: '-0.1' }],   // начать на 0,1 с раньше конца предыдущего шага
]);

controls.speed = 0.5;     // замедлить
controls.pause();
controls.play();
```

## Motion values

```vue
<script setup lang="ts">
import { motion, useMotionValue, useTransform, useSpring } from 'motion-v';

const mouseX = useMotionValue(0);
const mouseY = useMotionValue(0);

const rotateY = useSpring(useTransform(mouseX, [-0.5, 0.5], [-10, 10]), { stiffness: 200, damping: 20 });
const rotateX = useSpring(useTransform(mouseY, [-0.5, 0.5], [10, -10]), { stiffness: 200, damping: 20 });

function onPointerMove(e: PointerEvent) {
  const rect = (e.currentTarget as HTMLElement).getBoundingClientRect();
  mouseX.set((e.clientX - rect.left) / rect.width - 0.5);   // без перерендера компонента
  mouseY.set((e.clientY - rect.top) / rect.height - 0.5);
}
</script>

<template>
  <motion.div
    class="rounded-2xl bg-white p-6 shadow-xl"
    :style="{ rotateX, rotateY, transformPerspective: 800 }"
    @pointermove="onPointerMove"
    @pointerleave="mouseX.set(0); mouseY.set(0)"
  >
    3D-карточка
  </motion.div>
</template>
```

| API | Для чего |
| --- | --- |
| `useMotionValue(v)` | Значение для `:style`, `.set()`/`.get()` |
| `useTransform(v, input, output)` / `useTransform(() => ...)` | Производное значение |
| `useSpring(v, options)` | Сглаживание пружиной |
| `useVelocity(v)` | Скорость изменения |
| `useMotionTemplate` | Строка из значений (`filter`, `background`) |
| `v.on('change', cb)` | Подписка (например, для логики) |

## Ref или motion value

| `ref` | `useMotionValue` |
| --- | --- |
| Значение нужно в шаблоне, computed, логике | Значение нужно только для стиля |
| Меняется редко | Меняется каждый кадр (курсор, прокрутка) |
| Вызывает перерендер | Обновляет стиль напрямую |

## useReducedMotion

```vue
<script setup lang="ts">
import { motion, useReducedMotion } from 'motion-v';

const reduce = useReducedMotion();
const initial = computed(() => (reduce.value ? { opacity: 0 } : { opacity: 0, y: 32 }));
</script>

<template>
  <motion.section :initial="initial" :animate="{ opacity: 1, y: 0 }" />
</template>
```

```vue
<!-- глобально: при системной настройке Motion отключает transform-анимации, оставляя opacity -->
<MotionConfig reducedMotion="user">
  <RouterView />
</MotionConfig>
```

## Частые ошибки

- Хранить часто меняющееся значение в `ref` и привязывать к `:style` — перерендер на каждый кадр.
- Селектор в `animate()` без `scope` на элементе — ничего не находится.
- Запускать `useAnimate` до монтирования (селекторы ещё не в DOM).
- Игнорировать «уменьшить движение» для параллакса и автопроигрывания.

## Что важно помнить

- `useAnimate` — императивные анимации и таймлайны в области компонента с автоочисткой.
- Motion values обновляют стиль без рендера Vue; производные — `useTransform`, `useSpring`.
- `useReducedMotion` и `MotionConfig reducedMotion="user"` — уважать системную настройку.

## Мини-шпаргалка

- `const [scope, animate] = useAnimate()`, `ref="scope"`.
- `animate('li', { opacity: 1 }, { delay: stagger(0.05) })`.
- `const x = useMotionValue(0); x.set(10)`.
- `useTransform(x, [0, 1], [0, 100])`, `useSpring(x)`.
- `useReducedMotion()`, `<MotionConfig reducedMotion="user">`.
