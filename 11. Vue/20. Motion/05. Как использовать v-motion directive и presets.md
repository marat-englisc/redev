# Как использовать v-motion directive и presets

> [!NOTE]
> Директива **`v-motion`** добавляет возможности Motion к обычному HTML/SVG-элементу **без замены тега** на `<motion.div>` — удобно, когда нужно оживить существующую разметку или чужой компонент-обёртку не хочется переделывать. Подключается локальным импортом `vMotion` или глобально через `app.use(MotionPlugin)`. Пропсы анимации можно передать двумя способами: **рядом с директивой** (`v-motion :initial="..." :animate="..."`) или **объектом-значением** (`v-motion="{ initial, animate, transition }"`); при одновременном использовании отдельные пропсы **приоритетнее** объекта. Поддерживаются те же возможности: `transition`, `variants`, жесты (`whileHover`, `whilePress`), `whileInView`, `layout`. **Пресеты** регистрируются в `MotionPlugin` (`presets: { 'fade-in': {...} }`) и становятся отдельными директивами (`v-fade-in`) — так в проекте появляется единый набор повторяющихся эффектов. `<motion.*>` удобнее, когда активно используются `AnimatePresence`, `layoutId`, motion values и композиция компонентов.

## Вопрос

Как использовать директиву `v-motion` и пресеты в Motion for Vue?

## Пропсы рядом с директивой

```vue
<script setup lang="ts">
import { vMotion } from 'motion-v';
</script>

<template>
  <div v-motion :initial="{ opacity: 0, y: 24 }" :animate="{ opacity: 1, y: 0 }" :transition="{ duration: 0.35 }">
    Появление
  </div>
</template>
```

## Объект-значение

```vue
<div
  v-motion="{
    initial: { opacity: 0, x: -30 },
    animate: { opacity: 1, x: 0 },
    transition: { duration: 0.4 },
  }"
>
  Слева
</div>
```

```vue
<!-- пропс приоритетнее объекта: итоговый initial — { opacity: 0 } -->
<div v-motion="{ initial: { opacity: 0.5 } }" :initial="{ opacity: 0 }" />
```

## Пресеты

```ts
// main.ts
app.use(MotionPlugin, {
  presets: {
    'fade-in': { initial: { opacity: 0 }, animate: { opacity: 1 }, transition: { duration: 0.3 } },
    'slide-up': { initial: { opacity: 0, y: 32 }, whileInView: { opacity: 1, y: 0 }, inViewOptions: { once: true } },
  },
});
```

```vue
<section v-fade-in>...</section>
<article v-slide-up>...</article>
```

## Жесты и прокрутка

```vue
<button v-motion :whileHover="{ scale: 1.03 }" :whilePress="{ scale: 0.97 }">Купить</button>
<section v-motion :initial="{ opacity: 0 }" :whileInView="{ opacity: 1 }" :inViewOptions="{ once: true }" />
```

## Директива или компонент

| `v-motion` | `<motion.*>` |
| --- | --- |
| Существующая разметка, без смены тега | Новый код с активными анимациями |
| Пресеты для повторяющихся эффектов | `AnimatePresence`, `layoutId`, motion values |
| Простые появления и жесты | Сложная композиция и варианты по дереву |

## Частые ошибки

- Одновременно объект и пропсы с одинаковыми ключами — неожиданный результат из-за приоритета пропсов.
- Пресеты с разными параметрами для одинаковых по смыслу эффектов — интерфейс выглядит несогласованно.
- Ожидать exit-анимацию по `v-if` от одной директивы — нужен `AnimatePresence` с `motion`-элементом.

## Что важно помнить

- `v-motion` — анимации без замены тега; `vMotion` локально или `MotionPlugin`.
- Пропсы приоритетнее объекта директивы.
- Пресеты — единые эффекты проекта как `v-имя`.

## Мини-шпаргалка

- `<div v-motion :initial :animate>`.
- `v-motion="{ initial, animate, transition }"`.
- `app.use(MotionPlugin, { presets: { 'fade-in': {...} } })` → `v-fade-in`.
