# Какие ошибки бывают при работе с motion-v

> [!NOTE]
> Ошибки с Motion for Vue бывают трёх типов. **UX**: анимировать всё подряд (интерфейс утомляет и отвлекает — анимация должна объяснять появление, исчезновение, направление, связь между состояниями или подсказывать интерактивность), слишком долгие анимации (для UI обычно 150–300 мс), игнорирование настройки «уменьшить движение» (`useReducedMotion`, `MotionConfig reducedMotion="user"`). **Технические**: нет стабильного `key` у прямых детей `AnimatePresence` (exit не срабатывает), `v-if` на самом `AnimatePresence`, `motion.create()` внутри рендера (новый компонент каждый раз — состояние анимации теряется), анимация дорогих свойств (`width`, `height`, `top`, `left`, большие тени и `blur`) вместо `transform`/`opacity` или `layout`, частые значения в `ref` вместо motion values, **конфликт с CSS** — когда Tailwind-класс `transition-all` и Motion управляют одним свойством (у каждого свойства должен быть один «владелец» анимации), drag без `touch-action`. **Архитектурные**: смешивание логики и визуального движения — **Vue-состояние решает, есть ли элемент, Motion — как он появляется и исчезает**; нельзя считать элемент удалённым, потому что он «улетел» за экран. Также важно не забывать про доступность: жесты на `div` без семантики, скрытый outline ради анимации фокуса, drag без альтернативы с клавиатуры.

## Вопрос

Какие ошибки чаще всего допускают при работе с `motion-v`?

## Избыточная анимация

```vue
<!-- ✗ -->
<motion.div :whileHover="{ scale: 1.2, rotate: 20, y: -20 }" :transition="{ duration: 1.2 }" />

<!-- ✓ лёгкая обратная связь -->
<motion.div :whileHover="{ y: -2 }" :transition="{ duration: 0.15 }" />
```

## key в AnimatePresence

```vue
<!-- ✗ -->
<AnimatePresence>
  <motion.div v-if="open" :exit="{ opacity: 0 }" />
</AnimatePresence>

<!-- ✓ -->
<AnimatePresence>
  <motion.div v-if="open" key="panel" :exit="{ opacity: 0 }" />
</AnimatePresence>
```

## motion.create в рендере

```vue
<!-- ✗ новый компонент на каждый рендер -->
<component :is="motion.create(BaseCard)" />
```

```ts
// ✓ один раз на уровне модуля
export const MotionCard = motion.create(BaseCard);
```

## Дорогие свойства

```vue
<!-- ✗ пересчёт раскладки каждый кадр -->
<motion.aside :animate="{ left: open ? 0 : -320 }" />

<!-- ✓ transform -->
<motion.aside :animate="{ x: open ? 0 : -320 }" />

<!-- ✓ изменение размеров — через layout -->
<motion.div layout :class="expanded ? 'w-96' : 'w-48'" />
```

## Конфликт с CSS

```vue
<!-- ✗ CSS-переход и Motion управляют transform одновременно -->
<motion.button class="transition-all duration-300 hover:scale-105" :whilePress="{ scale: 0.95 }" />

<!-- ✓ CSS — цвет, Motion — масштаб -->
<motion.button class="transition-colors hover:bg-indigo-500" :whileHover="{ scale: 1.03 }" :whilePress="{ scale: 0.97 }" />
```

## Частые значения в ref

```ts
// ✗ перерендер компонента на каждое движение мыши
const x = ref(0);
onPointerMove((e) => { x.value = e.clientX; });

// ✓ стиль обновляется напрямую
const x = useMotionValue(0);
onPointerMove((e) => x.set(e.clientX));
```

## Состояние и движение

```text
✗ «элемент визуально улетел за экран — значит удалён»
✓ Vue-состояние удаляет элемент (v-if / массив) → Motion анимирует exit
```

## Reduced motion

```vue
<MotionConfig reducedMotion="user">
  <App />
</MotionConfig>
```

## Чек-лист

| Проверка | Почему |
| --- | --- |
| Анимация объясняет изменение? | Иначе отвлекает |
| Длительность 150–300 мс для UI? | Долгие анимации тормозят работу |
| `transform`/`opacity` или `layout`? | Плавность |
| У каждого свойства один владелец? | Нет конфликтов CSS и Motion |
| `key` у детей `AnimatePresence`? | Работает exit |
| Учтено «уменьшить движение»? | Доступность |
| Есть семантика и клавиатура? | Доступность жестов |

## Что важно помнить

- Анимация — для понимания интерфейса, коротко и умеренно.
- `key` в `AnimatePresence`, `motion.create` вне рендера, `transform` вместо layout-свойств, motion values для частых изменений.
- Vue управляет состоянием, Motion — движением; одно свойство — один владелец анимации.

## Мини-шпаргалка

- `key` у прямых детей `AnimatePresence`.
- `x/y/scale/opacity`, `layout` для размеров.
- `transition-colors` в CSS + transform в Motion.
- `useMotionValue` для курсора/прокрутки.
- `<MotionConfig reducedMotion="user">`.
