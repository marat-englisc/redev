# Как делать layout и scroll animations в motion-v

> [!NOTE]
> **Layout-анимации**: проп **`layout`** заставляет Motion плавно анимировать любое изменение размера и позиции элемента, вызванное перестройкой раскладки (раскрытие блока, смена `flex-direction`, перестановка элементов списка, изменение сетки) — при этом используется техника FLIP через `transform`, поэтому даже изменение `width`/`height` анимируется дешёво. `layout="position"` анимирует только позицию, `layout="size"` — только размер. **`layoutId`** создаёт **shared layout**: когда один элемент с этим id исчезает, а другой с тем же id появляется в другом месте, Motion анимирует переход между ними — так делают «скользящее» подчёркивание активной вкладки или раскрытие карточки в детальный вид. `LayoutGroup` связывает layout-анимации соседних компонентов. Для текста и радиусов внутри масштабируемого элемента может появиться искажение — его компенсируют `layout` на детях или `borderRadius` в стилях. **Анимации прокрутки** двух видов: **запускаемые прокруткой** — `whileInView` (элемент попал во viewport) с `inViewOptions` (`once`, `amount`, `margin`); **связанные с прокруткой** — `useScroll()` возвращает motion values `scrollY`, `scrollYProgress` (0–1) для окна, контейнера (`container`) или элемента (`target` + `offset`), а `useTransform` и `useSpring` превращают прогресс в любые значения (opacity, x, scale, цвет) для прогресс-баров и параллакса — без перерендера компонента.

## Вопрос

Как делать layout-анимации и анимации прокрутки в `motion-v`?

## layout

```vue
<script setup lang="ts">
import { motion } from 'motion-v';
const expanded = ref(false);
</script>

<template>
  <motion.div layout class="rounded-xl bg-white p-4 shadow" @click="expanded = !expanded">
    <motion.h3 layout="position" class="font-semibold">Доставка</motion.h3>
    <p v-if="expanded" class="mt-2 text-slate-600">Курьером за 1–2 дня…</p>
  </motion.div>
</template>
```

```vue
<!-- перестановка списка анимируется автоматически -->
<motion.li v-for="item in sorted" :key="item.id" layout :transition="{ type: 'spring', stiffness: 500, damping: 40 }">
  {{ item.title }}
</motion.li>
```

## layoutId — shared layout

```vue
<template>
  <nav class="flex gap-2">
    <button v-for="tab in tabs" :key="tab.id" class="relative px-3 py-2" @click="active = tab.id">
      {{ tab.title }}
      <motion.span
        v-if="active === tab.id"
        layoutId="tab-underline"
        class="absolute inset-x-0 -bottom-px h-0.5 bg-indigo-600"
      />
    </button>
  </nav>
</template>
```

```vue
<!-- карточка → развёрнутый вид -->
<motion.img v-if="!selected" :layoutId="`product-${p.id}`" :src="p.image" @click="selected = p" />
<AnimatePresence>
  <motion.div v-if="selected" :key="selected.id" class="fixed inset-8">
    <motion.img :layoutId="`product-${selected.id}`" :src="selected.image" />
  </motion.div>
</AnimatePresence>
```

## whileInView

```vue
<motion.section
  :initial="{ opacity: 0, y: 32 }"
  :whileInView="{ opacity: 1, y: 0 }"
  :inViewOptions="{ once: true, amount: 0.3 }"
  :transition="{ duration: 0.4 }"
>
  Тарифы
</motion.section>
```

| `inViewOptions` | Смысл |
| --- | --- |
| `once` | Сработать один раз |
| `amount` | Доля видимости: `'some'`, `'all'` или число 0–1 |
| `margin` | Расширить/сузить зону (`'-100px 0px'`) |
| `root` | Контейнер прокрутки вместо окна |

## useScroll + useSpring — прогресс чтения

```vue
<script setup lang="ts">
import { motion, useScroll, useSpring } from 'motion-v';

const { scrollYProgress } = useScroll();
const scaleX = useSpring(scrollYProgress, { stiffness: 100, damping: 30, restDelta: 0.001 });
</script>

<template>
  <motion.div class="fixed inset-x-0 top-0 h-1 origin-left bg-indigo-600" :style="{ scaleX }" />
</template>
```

## useTransform — параллакс элемента

```vue
<script setup lang="ts">
import { motion, useScroll, useTransform } from 'motion-v';

const hero = useTemplateRef<HTMLElement>('hero');
const { scrollYProgress } = useScroll({ target: hero, offset: ['start start', 'end start'] });

const y = useTransform(scrollYProgress, [0, 1], [0, 150]);
const opacity = useTransform(scrollYProgress, [0, 0.8], [1, 0]);
</script>

<template>
  <section ref="hero" class="relative h-[80vh] overflow-hidden">
    <motion.img src="/hero.jpg" class="absolute inset-0 size-full object-cover" :style="{ y, opacity }" alt="" />
  </section>
</template>
```

`offset: ['start start', 'end start']` — прогресс от момента, когда верх элемента у верха окна, до момента, когда низ элемента у верха окна.

## Частые ошибки

- `layout` на элементе без стабильного `key` в списке.
- Повторяющийся `layoutId` у нескольких одновременно видимых элементов.
- Слушать `scroll` вручную и писать в ref — перерендер на каждый кадр; motion values обновляют стиль напрямую.
- Параллакс и большие сдвиги без учёта `useReducedMotion`.
- Искажение текста при `layout`-масштабировании — добавьте `layout` детям.

## Что важно помнить

- `layout` — анимация изменений раскладки через transform; `layoutId` — переход между элементами.
- `whileInView` — анимация при появлении в зоне видимости.
- `useScroll` + `useTransform`/`useSpring` — анимации, связанные с прокруткой, без перерендера.

## Мини-шпаргалка

- `<motion.div layout>`, `layout="position"`.
- `layoutId="tab-underline"`.
- `:whileInView :inViewOptions="{ once: true, amount: 0.3 }"`.
- `const { scrollYProgress } = useScroll({ target, offset })`.
- `useTransform(progress, [0, 1], [0, 150])`, `useSpring(progress)`.
