# Как установить и подключить motion-v

> [!NOTE]
> Пакет ставится командой `npm i motion-v`. Для компонентного API глобальная настройка **не нужна**: импортируйте `motion` (фабрика элементов `motion.div`, `motion.button`, `motion.svg`…), `AnimatePresence`, `Motion` (универсальный компонент с пропом `as`) и composables прямо в `<script setup>` — в бандл попадёт только используемое. Для **директивы** `v-motion` есть два пути: импортировать `vMotion` локально (в `<script setup>` переменная с префиксом `v` автоматически становится директивой) или подключить **`MotionPlugin`** глобально через `app.use(MotionPlugin)` — плагин также позволяет зарегистрировать **пресеты** (короткие директивы вроде `v-fade-in`). Своё компонентное API для собственных компонентов создаётся через `motion.create(Component)` — на уровне модуля, а не в рендере. В Nuxt есть модуль `motion-v/nuxt` с автоимпортом. Автоимпорт через `unplugin-vue-components` поддерживается резолвером, но точечные `motion.*`-компоненты надёжнее импортировать явно.

## Вопрос

Как установить и подключить `motion-v` во Vue-проекте?

## Установка

```bash
npm i motion-v
```

## Компонентный API (без настройки)

```vue
<script setup lang="ts">
import { motion, AnimatePresence, Motion } from 'motion-v';
</script>

<template>
  <motion.div :initial="{ opacity: 0 }" :animate="{ opacity: 1 }" />
  <Motion as="section" :animate="{ y: 0 }" :initial="{ y: 20 }" />   <!-- тег через проп as -->
</template>
```

## Директива локально

```vue
<script setup lang="ts">
import { vMotion } from 'motion-v';      // vMotion → v-motion в шаблоне
</script>

<template>
  <div v-motion :initial="{ opacity: 0 }" :animate="{ opacity: 1 }">Привет</div>
</template>
```

## Директива глобально и пресеты

```ts
// main.ts
import { createApp } from 'vue';
import { MotionPlugin } from 'motion-v';
import App from './App.vue';

createApp(App)
  .use(MotionPlugin, {
    presets: {
      'fade-in': { initial: { opacity: 0 }, animate: { opacity: 1 }, transition: { duration: 0.3 } },
    },
  })
  .mount('#app');
```

```vue
<section v-fade-in>...</section>
```

## Свои компоненты

```ts
// components/motion.ts — один раз на уровне модуля
import { motion } from 'motion-v';
import BaseCard from './BaseCard.vue';

export const MotionCard = motion.create(BaseCard);
```

```vue
<MotionCard :whileHover="{ y: -4 }" />
```

Компонент должен передавать атрибуты и ref на корневой DOM-элемент, чтобы Motion мог его анимировать.

## Nuxt

```ts
// nuxt.config.ts
export default defineNuxtConfig({ modules: ['motion-v/nuxt'] });
```

## Частые ошибки

- Вызывать `motion.create()` в шаблоне или computed — новый компонент на каждый рендер, анимации сбрасываются.
- Использовать `v-motion` без `vMotion`-импорта или `MotionPlugin` — директива не найдена.
- Ожидать автоимпорт `motion.div` без настройки — импортируйте явно.

## Что важно помнить

- `npm i motion-v`; компоненты и composables импортируются по месту.
- `v-motion` — локальный `vMotion` или глобальный `MotionPlugin` (+ пресеты).
- `motion.create(Component)` — на уровне модуля.

## Мини-шпаргалка

- `import { motion, AnimatePresence } from 'motion-v'`.
- `import { vMotion } from 'motion-v'`.
- `app.use(MotionPlugin, { presets })`.
- `motion.create(Comp)`, `modules: ['motion-v/nuxt']`.
