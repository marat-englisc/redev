# Как использовать motion component, initial, animate и transition

> [!NOTE]
> `<motion.div>` (и любой другой тег: `motion.button`, `motion.li`, `motion.svg`, `motion.path`) рендерит обычный элемент, но принимает анимационные пропсы. **`initial`** — стартовое состояние при монтировании (`false` — без анимации появления, элемент сразу в состоянии `animate`). **`animate`** — целевое состояние; если оно зависит от реактивных данных, при каждом изменении Motion анимирует к новым значениям, плавно продолжая с текущего положения, даже если предыдущая анимация не закончилась. **`transition`** описывает движение: по умолчанию для физических свойств (`x`, `scale`) используется **пружина**, для opacity/цветов — tween; `type: 'tween'` с `duration` (в **секундах**) и `ease` (`'easeOut'`, `'easeInOut'`, кубическая кривая `[0.4, 0, 0.2, 1]`), или `type: 'spring'` со `stiffness`/`damping`/`mass` либо `bounce`/`visualDuration`; `delay`, `repeat`, `repeatType`; отдельные настройки для свойств (`transition: { opacity: { duration: 0.2 } }`). Анимировать можно transform-сокращения (`x`, `y`, `scale`, `rotate`, `skew`), `opacity`, цвета, размеры, `borderRadius`, CSS-переменные, SVG-атрибуты (`pathLength` для «рисования» линии) и **ключевые кадры** массивом (`x: [0, 20, -20, 0]`). Для плавности предпочитайте `transform` и `opacity` — они не вызывают пересчёта раскладки.

## Вопрос

Как работают `initial`, `animate` и `transition` в Motion for Vue?

## Появление

```vue
<script setup lang="ts">
import { motion } from 'motion-v';
</script>

<template>
  <motion.article
    class="rounded-xl bg-white p-4 shadow"
    :initial="{ opacity: 0, y: 24 }"
    :animate="{ opacity: 1, y: 0 }"
    :transition="{ duration: 0.35, ease: 'easeOut' }"
  >
    Карточка
  </motion.article>
</template>
```

## Анимация от состояния

```vue
<script setup lang="ts">
const expanded = ref(false);
</script>

<template>
  <button @click="expanded = !expanded">Подробнее</button>
  <motion.div
    class="overflow-hidden"
    :initial="false"
    :animate="{ height: expanded ? 'auto' : 0, opacity: expanded ? 1 : 0 }"
    :transition="{ duration: 0.25 }"
  >
    Подробное описание товара…
  </motion.div>

  <motion.span :animate="{ rotate: expanded ? 180 : 0 }">▾</motion.span>
</template>
```

`initial: false` — при первом рендере без анимации; анимация только при изменениях.

## Виды transition

```vue
<!-- tween -->
<motion.div :animate="{ opacity: 1 }" :transition="{ duration: 0.3, ease: [0.4, 0, 0.2, 1] }" />

<!-- пружина по физике -->
<motion.div :animate="{ x: 100 }" :transition="{ type: 'spring', stiffness: 400, damping: 25 }" />

<!-- пружина по длительности и упругости -->
<motion.div :animate="{ scale: 1 }" :transition="{ type: 'spring', visualDuration: 0.3, bounce: 0.25 }" />

<!-- разные настройки для свойств -->
<motion.div
  :animate="{ x: 0, opacity: 1 }"
  :transition="{ x: { type: 'spring', stiffness: 300 }, opacity: { duration: 0.2 } }"
/>
```

| Параметр | Смысл |
| --- | --- |
| `duration` | Длительность (секунды) |
| `ease` | Кривая: `'linear'`, `'easeIn'`, `'easeOut'`, `'easeInOut'`, массив Безье |
| `delay` | Задержка |
| `type: 'spring'` | Пружина: `stiffness`, `damping`, `mass` или `visualDuration`, `bounce` |
| `repeat`, `repeatType` | Повторы: `Infinity`, `'loop'`, `'reverse'`, `'mirror'` |

## Ключевые кадры

```vue
<!-- «встряхнуть» поле при ошибке -->
<motion.input :animate="hasError ? { x: [0, -8, 8, -4, 4, 0] } : { x: 0 }" :transition="{ duration: 0.4 }" />

<!-- рисование SVG-линии -->
<motion.svg viewBox="0 0 24 24" class="size-6">
  <motion.path d="M5 13l4 4L19 7" fill="none" stroke="currentColor" :initial="{ pathLength: 0 }" :animate="{ pathLength: 1 }" />
</motion.svg>
```

## Что анимировать

| Дёшево (композитинг) | Дороже (layout/paint) |
| --- | --- |
| `x`, `y`, `scale`, `rotate`, `opacity` | `width`, `height`, `top`, `left`, `padding` |
| | Большие `boxShadow`, `filter: blur()` |

Для изменения размеров и позиции без дорогих свойств используйте [layout-анимации](<08. Как делать layout и scroll animations в motion-v.md>).

## Частые ошибки

- Указывать `duration` в миллисекундах (`300`) — получится пять минут.
- Анимировать `width/height/top/left` там, где хватает `transform`.
- Забыть `initial: false` у элементов, которые не должны «влетать» при загрузке страницы.
- Одновременно CSS-класс `transition-all` и Motion на тех же свойствах — конфликт.

## Что важно помнить

- `initial` → `animate` с параметрами `transition`; `animate` реагирует на состояние.
- Пружины — для физических свойств, tween — для opacity/цвета.
- Предпочитайте `transform` и `opacity`.

## Мини-шпаргалка

- `:initial="{ opacity: 0, y: 24 }" :animate="{ opacity: 1, y: 0 }"`.
- `:initial="false"`.
- `:transition="{ duration: 0.3, ease: 'easeOut' }"` / `{ type: 'spring', stiffness, damping }`.
- Ключевые кадры: `x: [0, 10, 0]`; SVG: `pathLength`.
