# Как работает v-on и модификаторы событий

> [!NOTE]
> `v-on` (сокращение `@`) подписывает элемент на **DOM-событие** или компонент на его **событие** (`emit`). Значение — имя метода (`@click="save"`, получает объект события), inline-выражение (`@click="count++"`) или вызов с аргументами (`@click="remove(item.id)"`, событие доступно как `$event`); поддерживаются и стрелочные функции. **Модификаторы событий** избавляют от рутины в обработчиках: `.prevent` — `preventDefault()`, `.stop` — `stopPropagation()`, `.self` — только если событие произошло на самом элементе, `.capture` — фаза перехвата, `.once` — один раз, `.passive` — пассивный слушатель (для `scroll`/`touch`, улучшает плавность). **Клавиатурные модификаторы**: `.enter`, `.esc`, `.tab`, `.space`, `.delete`, `.up/.down/.left/.right` и любые имена клавиш в kebab-case (`.page-down`); **системные**: `.ctrl`, `.alt`, `.shift`, `.meta`, `.exact` (точная комбинация); **мышь**: `.left`, `.right`, `.middle`. Порядок модификаторов имеет значение (`@click.prevent.self` ≠ `@click.self.prevent`). Объектный синтаксис `v-on="{ mouseenter: a, mouseleave: b }"` вешает несколько обработчиков.

## Вопрос

Как работает `v-on` во Vue и какие есть модификаторы событий?

## Обработчики

```vue
<script setup lang="ts">
const count = ref(0);
function save(e: MouseEvent) { /* e — объект события */ }
function remove(id: string, e?: Event) { /* ... */ }
</script>

<template>
  <button @click="save">Сохранить</button>                  <!-- ссылка на метод -->
  <button @click="count++">+1</button>                       <!-- inline-выражение -->
  <button @click="remove(item.id, $event)">Удалить</button>   <!-- аргументы + $event -->
  <input @input="(e) => (query = (e.target as HTMLInputElement).value)" />
  <div v-on="{ mouseenter: showTip, mouseleave: hideTip }" />
</template>
```

## Модификаторы событий

```vue
<form @submit.prevent="onSubmit">                       <!-- без перезагрузки страницы -->
<a @click.stop="track">                                 <!-- не всплывает к родителю -->
<div class="backdrop" @click.self="close">               <!-- клик по фону, не по содержимому -->
<button @click.once="activateTrial">                    <!-- один раз -->
<div @scroll.passive="onScroll">                         <!-- пассивный слушатель -->
<div @click.capture="log">                               <!-- фаза перехвата -->
```

| Модификатор | Эквивалент |
| --- | --- |
| `.prevent` | `event.preventDefault()` |
| `.stop` | `event.stopPropagation()` |
| `.self` | `if (event.target !== event.currentTarget) return` |
| `.capture` | `addEventListener(..., { capture: true })` |
| `.once` | `{ once: true }` |
| `.passive` | `{ passive: true }` — нельзя сочетать с `.prevent` |

## Клавиатура

```vue
<input @keyup.enter="submit" />
<input @keydown.esc="cancel" />
<input @keydown.ctrl.enter="sendMessage" />       <!-- Ctrl+Enter -->
<input @keydown.meta.k.prevent="openSearch" />     <!-- Cmd+K -->
<button @click.ctrl.exact="selectOne">           <!-- только Ctrl, без других модификаторов -->
<input @keydown.page-down="next" />                <!-- имя клавиши в kebab-case -->
```

Системные модификаторы на `keyup` срабатывают, только если системная клавиша удерживается в момент отпускания основной.

## Мышь

```vue
<div @click.right.prevent="openContextMenu" />
<div @mousedown.middle="openInNewTab" />
```

## Порядок модификаторов

```vue
<a @click.prevent.self="x">   <!-- предотвращает действие для всех кликов, обработчик — только на self -->
<a @click.self.prevent="x">   <!-- предотвращает действие только для кликов по самому элементу -->
```

## События компонентов

```vue
<SearchBox @search="onSearch" />          <!-- emit('search', query) → onSearch(query) -->
<BaseModal @close.once="onClose" />       <!-- once работает и для событий компонентов -->
```

Нативные модификаторы `.stop`/`.prevent` к событиям компонентов неприменимы (это не DOM-события).

## Частые ошибки

- `.passive` вместе с `.prevent` — `preventDefault` проигнорируется.
- `@click="save()"` и ожидание объекта события в `save` — без `$event` он не передаётся.
- Тяжёлые вычисления в обработчике `scroll`/`input` без debounce/throttle.
- Использовать клавиатурные модификаторы на кодах (`.13`) — устаревший синтаксис.

## Что важно помнить

- `@event="handler"`; `$event` — объект события или первый аргумент `emit`.
- Модификаторы: `.prevent`, `.stop`, `.self`, `.once`, `.passive`, `.capture`.
- Клавиши и комбинации: `.enter`, `.esc`, `.ctrl.enter`, `.exact`.

## Мини-шпаргалка

- `@click="fn"`, `@click="fn(arg, $event)"`.
- `@submit.prevent`, `@click.stop`, `@click.self`.
- `@keyup.enter`, `@keydown.ctrl.s.prevent`.
- `v-on="{ a: fn1, b: fn2 }"`.
