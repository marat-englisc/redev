# Как создать пользовательскую директиву

> [!NOTE]
> **Пользовательская директива** — объект с хуками, которые Vue вызывает на этапах жизни **элемента**: `created`, `beforeMount`, `mounted`, `beforeUpdate`, `updated`, `beforeUnmount`, `unmounted`. Каждый хук получает `el` (DOM-элемент), `binding` (`value`, `oldValue`, `arg`, `modifiers`, `instance`), `vnode` и `prevVNode`. Директивы предназначены для **низкоуровневой работы с DOM**, которую неудобно выразить декларативно: автофокус, клик вне элемента, ленивые изображения через `IntersectionObserver`, tooltip, маска ввода, автоизменение высоты `textarea`. В `<script setup>` любая переменная с именем `vXxx` автоматически становится директивой `v-xxx`; глобально — `app.directive('xxx', dir)`; в Options API — опция `directives`. Если нужны только `mounted` и `updated` с одинаковой логикой, директиву можно записать функцией. Для логики с состоянием и переиспользованием между компонентами чаще подходит **composable**, а директиву оставляют для «прикрепления» поведения к конкретному элементу. На компонентах директива применяется к корневому элементу (с несколькими корнями — не рекомендуется).

## Вопрос

Как создать собственную директиву во Vue и когда она уместна?

## Автофокус

```vue
<script setup lang="ts">
const vFocus = { mounted: (el: HTMLElement) => el.focus() };
</script>

<template>
  <input v-focus />
</template>
```

## Клик вне элемента

```ts
// directives/clickOutside.ts
import type { Directive } from 'vue';

type Handler = (e: PointerEvent) => void;
const handlers = new WeakMap<HTMLElement, (e: PointerEvent) => void>();

export const vClickOutside: Directive<HTMLElement, Handler> = {
  mounted(el, binding) {
    const listener = (e: PointerEvent) => {
      if (!el.contains(e.target as Node)) binding.value(e);
    };
    handlers.set(el, listener);
    document.addEventListener('pointerdown', listener);
  },
  unmounted(el) {
    const listener = handlers.get(el);
    if (listener) document.removeEventListener('pointerdown', listener);
    handlers.delete(el);
  },
};
```

```vue
<div v-click-outside="() => (open = false)" class="dropdown">...</div>
```

## Ленивая загрузка изображений с аргументом и модификатором

```ts
export const vLazy: Directive<HTMLImageElement, string> = {
  mounted(el, { value, modifiers }) {
    const io = new IntersectionObserver(([entry]) => {
      if (!entry.isIntersecting) return;
      el.src = value;
      if (modifiers.fade) el.classList.add('fade-in');
      io.disconnect();
    }, { rootMargin: '200px' });
    io.observe(el);
    (el as any)._io = io;
  },
  updated(el, { value, oldValue }) {
    if (value !== oldValue && el.src) el.src = value;
  },
  unmounted(el) {
    (el as any)._io?.disconnect();
  },
};
```

```vue
<img v-lazy.fade="product.image" alt="" />
```

Для изображений в современных браузерах часто достаточно нативного `loading="lazy"`.

## Функциональная форма

```ts
// mounted и updated — одно и то же
const vColor: Directive<HTMLElement, string> = (el, binding) => {
  el.style.color = binding.value;
};
```

## binding

| Поле | Пример `v-tooltip:top.delay="'Подсказка'"` |
| --- | --- |
| `value` | `'Подсказка'` |
| `oldValue` | Предыдущее значение (в `beforeUpdate`/`updated`) |
| `arg` | `'top'` |
| `modifiers` | `{ delay: true }` |
| `instance` | Экземпляр компонента, где используется |

## Регистрация

```ts
// глобально
app.directive('click-outside', vClickOutside);

// script setup — имя vXxx
import { vClickOutside } from '@/directives/clickOutside';

// Options API
export default { directives: { focus: vFocus } };
```

## Директива или composable

| Директива | Composable |
| --- | --- |
| Поведение привязано к элементу в шаблоне | Логика с состоянием, используемая в скрипте |
| `v-focus`, `v-click-outside`, `v-tooltip` | `useClickOutside(target, cb)`, `useIntersectionObserver` |
| Нет реактивного результата | Возвращает ref-ы |

Многие задачи (`onClickOutside`, `useIntersectionObserver`) уже решены в VueUse и в виде composables, и в виде директив.

## Частые ошибки

- Не снимать слушатели и наблюдатели в `unmounted` — утечки памяти.
- Использовать директиву для того, что решается `v-bind`/`v-on` или компонентом.
- Директива на компоненте с несколькими корнями.
- Хранить состояние директивы в глобальной переменной, общей для всех элементов.

## Что важно помнить

- Директива — хуки жизненного цикла элемента с доступом к `el` и `binding`.
- В `<script setup>` — переменная `vName`; глобально — `app.directive`.
- Всегда освобождайте ресурсы в `unmounted`.

## Мини-шпаргалка

- `const vX = { mounted(el, binding) {}, unmounted(el) {} }`.
- `binding.value`, `binding.arg`, `binding.modifiers`.
- `Directive<HTMLElement, T>` — типизация.
- `app.directive('x', vX)`.
