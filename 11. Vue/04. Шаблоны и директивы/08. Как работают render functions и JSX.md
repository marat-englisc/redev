# Как работают render functions и JSX

> [!NOTE]
> Шаблон Vue компилируется в **render-функцию**, но её можно написать и вручную. Render-функция возвращает дерево VNode, созданное функцией **`h(type, props, children)`**: `type` — тег или компонент, `props` — атрибуты, props и обработчики (`onClick`), `children` — строка, массив VNode или объект слотов. В `<script setup>` render-функции не используются — их задают через `setup()`, возвращающий функцию, или `defineComponent`. Вместо `h()` можно писать **JSX/TSX** (плагин `@vitejs/plugin-vue-jsx`), где `v-if` → тернарный оператор или `&&`, `v-for` → `map`, `v-model` → поддержка плагина или пара `modelValue`/`onUpdate:modelValue`, слоты → объект функций. Render-функции нужны редко: **высокодинамичные** компоненты (рендер по схеме, рекурсивные деревья с разными тегами, генерация заголовка `h1`–`h6` по prop), библиотеки компонентов, функциональные компоненты-обёртки. Шаблоны остаются предпочтительными: они читабельнее и лучше оптимизируются компилятором (patch flags, hoisting), а в render-функциях эти оптимизации теряются.

## Вопрос

Что такое render-функции во Vue, как писать их через `h()` и JSX и когда это нужно?

## h()

```ts
import { h, defineComponent } from 'vue';

export default defineComponent({
  props: { level: { type: Number, required: true } },
  setup(props, { slots }) {
    return () => h(`h${props.level}`, { class: 'heading' }, slots.default?.());
  },
});
```

```vue
<AnchoredHeading :level="2">Раздел</AnchoredHeading>   <!-- <h2 class="heading">Раздел</h2> -->
```

## Аргументы h

```ts
h('div');                                             // тег
h('div', { id: 'app', class: ['a', { b: isB }], style: { color: 'red' } });
h('button', { onClick: () => count.value++ }, `Счёт: ${count.value}`);
h(MyComponent, { title: 'x', 'onUpdate:modelValue': (v) => (model.value = v) });
h(MyComponent, null, {
  default: () => 'контент',
  header: (props: { title: string }) => h('h3', props.title),   // слоты — функции
});
```

## Директивы в render-функции

```ts
// v-if
() => (loading.value ? h(Spinner) : h(List, { items: items.value }));

// v-for
() => h('ul', items.value.map((i) => h('li', { key: i.id }, i.title)));

// пользовательская директива
import { withDirectives } from 'vue';
() => withDirectives(h('input'), [[vFocus]]);
```

## JSX/TSX

```ts
// vite.config.ts
import vueJsx from '@vitejs/plugin-vue-jsx';
export default defineConfig({ plugins: [vue(), vueJsx()] });
```

```tsx
// DataTable.tsx
export default defineComponent({
  props: { columns: { type: Array as PropType<Column[]>, required: true }, rows: { type: Array as PropType<Row[]>, required: true } },
  setup(props, { slots }) {
    return () => (
      <table>
        <thead>
          <tr>{props.columns.map((c) => <th key={c.key}>{c.title}</th>)}</tr>
        </thead>
        <tbody>
          {props.rows.length === 0
            ? <tr><td colspan={props.columns.length}>{slots.empty?.() ?? 'Нет данных'}</td></tr>
            : props.rows.map((row) => (
                <tr key={row.id}>
                  {props.columns.map((c) => <td key={c.key}>{slots[`cell-${c.key}`]?.({ row }) ?? row[c.key]}</td>)}
                </tr>
              ))}
        </tbody>
      </table>
    );
  },
});
```

## Функциональные компоненты

```ts
import type { FunctionalComponent } from 'vue';

const Badge: FunctionalComponent<{ tone: 'ok' | 'warn' }> = (props, { slots }) =>
  h('span', { class: ['badge', `badge--${props.tone}`] }, slots.default?.());

Badge.props = ['tone'];
```

Без состояния и экземпляра — просто функция от props к VNode.

## Шаблон или render-функция

| Шаблон | Render-функция / JSX |
| --- | --- |
| Читабельнее, привычнее | Полная гибкость JavaScript |
| Оптимизации компилятора | Оптимизации компилятора недоступны |
| Подходит почти всегда | Динамические теги, рендер по схеме, библиотеки |

## Частые ошибки

- Вызов `h()` вне функции рендера — VNode создаются один раз и не обновляются.
- Передача слотов как VNode вместо функций.
- Одинаковый VNode, переиспользованный дважды в дереве (каждый узел должен быть уникален).
- Писать в JSX то, что проще и быстрее выразить шаблоном.

## Что важно помнить

- Шаблон компилируется в render-функцию; `h(type, props, children)` создаёт VNode.
- JSX — удобный синтаксис для тех же render-функций.
- Используйте точечно: шаблоны оптимизируются лучше.

## Мини-шпаргалка

- `setup() { return () => h('div', props, children) }`.
- Обработчики — `onClick`, модель — `modelValue` + `'onUpdate:modelValue'`.
- Слоты — `{ default: () => ..., name: (p) => ... }`.
- `withDirectives(vnode, [[dir, value]])`.
- `@vitejs/plugin-vue-jsx`.
