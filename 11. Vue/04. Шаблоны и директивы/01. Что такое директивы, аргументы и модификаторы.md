# Что такое директивы, аргументы и модификаторы

> [!NOTE]
> **Директива** — специальный атрибут шаблона с префиксом `v-`, который применяет к элементу **реактивное поведение**: значение директивы — JavaScript-выражение, и при изменении данных Vue заново применяет эффект. В отличие от обычного HTML-атрибута, значение не строка, а выражение (`v-if="user.isAdmin"`). Синтаксис: `v-name:argument.modifier="value"` — **аргумент** уточняет цель (`v-bind:href`, `v-on:submit`, `v-slot:header`), может быть **динамическим** (`:[attrName]="v"`), **модификаторы** задают особое поведение (`.prevent`, `.stop`, `.once`, `.trim`, `.lazy`). У частых директив есть сокращения: `:` для `v-bind`, `@` для `v-on`, `#` для `v-slot`. Встроенные директивы: `v-bind`, `v-on`, `v-model`, `v-if`/`v-else-if`/`v-else`, `v-show`, `v-for`, `v-slot`, `v-text`, `v-html`, `v-once`, `v-memo`, `v-pre`, `v-cloak`. Можно создавать и [свои директивы](<07. Как создать пользовательскую директиву.md>) для низкоуровневой работы с DOM.

## Вопрос

Что такое директивы во Vue и как устроены их аргументы и модификаторы?

## Анатомия

```text
v-on:submit.prevent="onSubmit"
│    │      │        └ значение — выражение
│    │      └ модификатор
│    └ аргумент
└ имя директивы
```

## Сокращения

```vue
<a v-bind:href="url">    ≡  <a :href="url">
<form v-on:submit.prevent="save">   ≡  <form @submit.prevent="save">
<template v-slot:header>  ≡  <template #header>
<img :src />             <!-- 3.4+: :src="src" -->
```

## Динамические аргументы

```vue
<script setup>
const attr = ref('href');
const eventName = ref('focus');
</script>

<template>
  <a :[attr]="url">ссылка</a>
  <input @[eventName]="onEvent" />
</template>
```

Значение аргумента должно быть строкой или `null` (снять); пробелы и кавычки внутри недопустимы — сложную логику вынесите в `computed`.

## Встроенные директивы

| Директива | Назначение |
| --- | --- |
| `v-bind` / `:` | Привязка атрибута или prop |
| `v-on` / `@` | Обработчик события |
| `v-model` | Двусторонняя привязка значения |
| `v-if`, `v-else-if`, `v-else` | Условный рендеринг (создание/удаление) |
| `v-show` | Условная видимость (`display: none`) |
| `v-for` | Рендер списка |
| `v-slot` / `#` | Слоты |
| `v-text`, `v-html` | Текст / сырой HTML (опасно — XSS) |
| `v-once` | Отрендерить один раз |
| `v-memo` | Мемоизация поддерева |
| `v-pre` | Пропустить компиляцию |
| `v-cloak` | Скрыть некомпилированный шаблон |

## Модификаторы

| Директива | Модификаторы |
| --- | --- |
| `v-on` | `.stop`, `.prevent`, `.self`, `.capture`, `.once`, `.passive`; клавиши `.enter`, `.esc`; мышь `.left`, `.right` |
| `v-model` | `.lazy`, `.number`, `.trim` |
| `v-bind` | `.prop` (как DOM-свойство), `.attr` (как атрибут), `.camel` |

```vue
<form @submit.prevent="save">            <!-- preventDefault -->
<div @click.self="close">                <!-- только клик по самому элементу -->
<input v-model.trim.lazy="name" />       <!-- модификаторы комбинируются -->
<div :scroll-top.prop="pos" />           <!-- установить DOM-свойство -->
```

## Директива или атрибут

```vue
<input disabled="false" />            <!-- HTML: атрибут есть → поле отключено -->
<input :disabled="false" />           <!-- Vue: выражение false → атрибут не добавится -->
<input :disabled="isSaving" />        <!-- реактивно -->
```

## v-html и безопасность

```vue
<div v-html="article.body" />          <!-- только для доверенного или санитизированного HTML -->
```

Пользовательский контент через `v-html` — XSS-уязвимость; санитизируйте (DOMPurify) или рендерьте как текст.

## Частые ошибки

- Писать строку вместо выражения: `:count="5"` vs `count="5"` (строка).
- `v-html` с пользовательскими данными.
- Сложная логика в значении директивы вместо `computed`/метода.
- Динамический аргумент с пробелами или кавычками.

## Что важно помнить

- Директивы — `v-` атрибуты с реактивными выражениями.
- `v-name:arg.mod="value"`, сокращения `:`, `@`, `#`.
- `v-html` — только для безопасного HTML.

## Мини-шпаргалка

- `:attr`, `@event`, `#slot`.
- `:[name]="v"` — динамический аргумент.
- `.prevent`, `.stop`, `.once`, `.trim`, `.lazy`, `.number`.
- `v-if`/`v-show`/`v-for`/`v-model`/`v-slot`.
