# Как работают v-if и v-show

> [!NOTE]
> `v-if` — **условный рендеринг**: при ложном условии элемент или компонент **не создаётся** вовсе (нет в DOM, хуки не вызываются), при переходе в `true` — создаётся заново, при переходе в `false` — уничтожается вместе с состоянием. Поддерживаются цепочки `v-else-if` / `v-else` (должны идти сразу за `v-if`) и группировка нескольких элементов через `<template v-if>`. `v-show` — **условная видимость**: элемент рендерится всегда, а переключается только CSS `display: none`; состояние сохраняется, но начальный рендер «дороже», и `v-show` не работает с `<template>` и `v-else`. Правило выбора: `v-show` — для частых переключений (вкладки, раскрывающиеся панели, тултипы), `v-if` — для редко меняющихся условий, тяжёлых блоков и когда содержимое не должно существовать (права доступа, отсутствие данных). `v-if` и `v-for` на одном элементе не совмещают: в Vue 3 `v-if` выполняется первым и не видит переменную цикла.

## Вопрос

Как работают `v-if` и `v-show` и чем они отличаются?

## v-if, v-else-if, v-else

```vue
<template>
  <Spinner v-if="status === 'loading'" />
  <ErrorState v-else-if="status === 'error'" :error="error" @retry="load" />
  <EmptyState v-else-if="items.length === 0" />
  <ProductGrid v-else :items="items" />
</template>
```

## template как невидимая обёртка

```vue
<template v-if="user">
  <h2>{{ user.name }}</h2>
  <p>{{ user.email }}</p>
</template>
```

## v-show

```vue
<button @click="open = !open">Фильтры</button>
<FiltersPanel v-show="open" />      <!-- не пересоздаётся, выбранные фильтры сохраняются -->
```

## Сравнение

| | `v-if` | `v-show` |
| --- | --- | --- |
| Механизм | Создание/удаление элемента | `display: none` |
| Начальный рендер при `false` | Ничего не рендерится | Рендерится и скрывается |
| Переключение | Дорогое (создание, хуки) | Дешёвое |
| Состояние компонента | Теряется при скрытии | Сохраняется |
| `v-else`, `<template>` | Да | Нет |
| Ленивость | Да | Нет |
| Когда | Редкие изменения, права, тяжёлые блоки | Частые переключения |

## Жизненный цикл

```text
v-if: false → true   →  setup / onMounted
v-if: true  → false  →  onUnmounted (состояние потеряно)
v-show: true ↔ false →  хуки не вызываются
```

## v-if и v-for

```vue
<!-- ✗ в Vue 3 v-if выполняется первым: todo не определён -->
<li v-for="todo in todos" v-if="!todo.done" :key="todo.id">

<!-- ✓ фильтровать в computed -->
<li v-for="todo in activeTodos" :key="todo.id">

<!-- ✓ или template-обёртка -->
<template v-for="todo in todos" :key="todo.id">
  <li v-if="!todo.done">{{ todo.title }}</li>
</template>
```

## Переиспользование элементов

```vue
<input v-if="loginType === 'email'" placeholder="Email" key="email" />
<input v-else placeholder="Телефон" key="phone" />
```

Без разных `key` Vue переиспользует `<input>`, и введённый текст «переедет» в другое поле.

## Анимации

И `v-if`, и `v-show` работают с `<Transition>` — анимации появления и исчезновения.

## Частые ошибки

- `v-show` для блоков, которые почти никогда не показываются, но тяжелы при рендере.
- `v-if` на вкладках с формами — состояние сбрасывается при каждом переключении.
- `v-if` + `v-for` на одном элементе.
- `v-if` для защиты данных: скрытый в UI блок не защищает API — проверка прав на сервере обязательна.

## Что важно помнить

- `v-if` — создаёт/уничтожает, `v-show` — только скрывает.
- `v-show` для частых переключений, `v-if` для редких и тяжёлых.
- Фильтрация списков — в `computed`, не через `v-if` в `v-for`.

## Мини-шпаргалка

- `v-if` / `v-else-if` / `v-else`.
- `<template v-if>` — группа без обёртки.
- `v-show` — `display: none`.
- Разные `key` для переключаемых однотипных элементов.
