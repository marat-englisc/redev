# Как работает v-bind и привязка class и style

> [!NOTE]
> `v-bind` (сокращение `:`) связывает **атрибут** HTML-элемента или **prop** компонента с выражением: `:href="url"`, `:disabled="isSaving"`, `:user="currentUser"`. При значениях `null`/`undefined` атрибут удаляется, у булевых атрибутов (`disabled`, `checked`) — удаляется и при `false`. Без аргумента `v-bind="obj"` передаёт все свойства объекта как атрибуты/props. С Vue 3.4 работает сокращение `:id` вместо `:id="id"`. Особая поддержка у **`class`** и **`style`**: в `:class` можно передать строку, **объект** (`{ active: isActive, 'is-error': hasError }`), **массив** (в том числе со вложенными объектами), а обычный `class` и `:class` объединяются; в `:style` — объект со стилями в camelCase или kebab-case, массив объектов; Vue сам добавляет вендорные префиксы. CSS-переменные можно задавать через `:style="{ '--progress': value + '%' }"` или `v-bind()` в `<style>`. Модификаторы `.prop` и `.attr` принудительно задают DOM-свойство или атрибут.

## Вопрос

Как работает `v-bind` и как привязывать `class` и `style` во Vue?

## Атрибуты и props

```vue
<a :href="product.url" :target="external ? '_blank' : undefined">{{ product.title }}</a>
<img :src="avatar" :alt="`Аватар ${user.name}`" />
<button :disabled="isSaving" :aria-busy="isSaving">Сохранить</button>
<UserCard :user="user" :compact="true" />

<input v-bind="{ type: 'email', required: true, placeholder: 'Email' }" />   <!-- объект -->
<img :src :alt />                                                            <!-- 3.4+ -->
```

## class: объект

```vue
<li
  class="item"
  :class="{ active: item.id === activeId, done: item.done, 'is-disabled': !item.enabled }"
>
```

## class: массив и computed

```vue
<script setup lang="ts">
const props = defineProps<{ variant: 'primary' | 'ghost'; size: 'sm' | 'md'; loading?: boolean }>();
const classes = computed(() => ['btn', `btn--${props.variant}`, `btn--${props.size}`, { 'btn--loading': props.loading }]);
</script>

<template>
  <button :class="classes"><slot /></button>
</template>
```

## class на компоненте

```vue
<BaseButton class="w-full" />    <!-- добавится к корневому элементу BaseButton (fallthrough) -->
```

## style

```vue
<div :style="{ color: textColor, fontSize: size + 'px', 'background-color': bg }" />
<div :style="[baseStyles, isActive && activeStyles]" />

<!-- CSS-переменные -->
<div class="progress" :style="{ '--value': `${percent}%` }" />
```

```css
.progress::after { width: var(--value); }
```

## v-bind() в CSS

```vue
<script setup>
const theme = reactive({ accent: '#2563eb' });
</script>

<style scoped>
.title { color: v-bind('theme.accent'); }
</style>
```

## Удаление атрибутов

| Значение | Результат |
| --- | --- |
| `null`, `undefined` | Атрибут не рендерится |
| `false` у boolean-атрибута (`disabled`) | Атрибут удаляется |
| `false` у обычного атрибута (`aria-hidden`) | `aria-hidden="false"` |
| `''` у boolean-атрибута | Атрибут есть (`true`) |

## .prop и .attr

```vue
<div :inner-html.prop="safeHtml" />      <!-- DOM-свойство -->
<my-element .config="config" />           <!-- сокращение .prop для custom elements -->
<input :value.attr="v" />                 <!-- именно атрибут -->
```

## Частые ошибки

- Конкатенация классов строками с условиями вместо объекта или массива.
- `:class="'btn-' + variant"` для Tailwind — динамически собранные имена классов не попадут в сборку (нужны полные имена).
- Забыть единицы измерения в `:style` (`width: 100` → игнорируется).
- `:aria-hidden="false"` ожидая удаления атрибута.

## Что важно помнить

- `:attr="expr"` — реактивная привязка; `null`/`undefined` удаляют атрибут.
- `:class` и `:style` принимают объекты и массивы и объединяются со статическими значениями.
- CSS-переменные — через `:style` или `v-bind()` в `<style>`.

## Мини-шпаргалка

- `:href`, `:disabled`, `v-bind="obj"`, `:id` (3.4+).
- `:class="{ a: cond }"`, `:class="[x, { y: cond }]"`.
- `:style="{ fontSize: n + 'px' }"`, `'--var': v`.
- `.prop`, `.attr`.
