# Что такое Vue.js

> [!NOTE]
> **Vue.js** — прогрессивный JavaScript-фреймворк для построения пользовательских интерфейсов. Его ядро — **декларативный рендеринг** (шаблон описывает, как UI выглядит при текущем состоянии) и **реактивность** (при изменении данных Vue сам находит и обновляет зависимые части DOM). Интерфейс собирается из **компонентов** — обычно в формате Single File Component (`.vue`: `<template>`, `<script setup>`, `<style scoped>`). «Прогрессивный» значит, что Vue можно подключить к странице как библиотеку для одного виджета, а можно строить полноценное SPA с официальными инструментами: **Vue Router** (маршрутизация), **Pinia** (состояние), **Vite** (сборка), **Vitest** и Vue Test Utils (тесты), **Vue DevTools**, а для SSR/SSG — **Nuxt**. Актуальная версия — **Vue 3.5**; Vue 2 достиг конца поддержки в конце 2023 года. Компоненты пишут через **Composition API** (`<script setup>`, рекомендуется для новых проектов) или **Options API**.

## Вопрос

Что такое Vue.js и какие задачи он решает?

## Минимальный компонент

```vue
<script setup lang="ts">
import { ref, computed } from 'vue';

const count = ref(0);
const isEven = computed(() => count.value % 2 === 0);
</script>

<template>
  <button @click="count++">Нажато: {{ count }}</button>
  <p>{{ isEven ? 'чётное' : 'нечётное' }}</p>
</template>

<style scoped>
button { padding: 8px 16px; }
</style>
```

Мы не трогаем DOM вручную: меняем `count`, и Vue обновляет текст кнопки и абзаца.

## Создание приложения

```ts
// main.ts
import { createApp } from 'vue';
import { createPinia } from 'pinia';
import App from './App.vue';
import { router } from './router';

createApp(App).use(createPinia()).use(router).mount('#app');
```

```bash
npm create vue@latest     # официальный шаблон на Vite: TypeScript, Router, Pinia, Vitest, ESLint
```

## Ключевые идеи

| Идея | Что даёт |
| --- | --- |
| Декларативный шаблон | UI = функция от состояния |
| Реактивность | Автоматические точечные обновления DOM |
| Компоненты | Переиспользуемые изолированные части UI |
| SFC | Шаблон, логика и стили в одном файле |
| Компилятор шаблонов | Оптимизации на этапе сборки (статические узлы, patch flags) |
| Экосистема | Router, Pinia, Vite, Nuxt, DevTools — официальные |

## Экосистема

| Инструмент | Роль |
| --- | --- |
| Vue Router | Маршрутизация SPA |
| Pinia | Глобальное состояние |
| Vite | Dev-сервер и сборка |
| Vitest + Vue Test Utils | Тесты |
| Nuxt | SSR, SSG, файловая маршрутизация, fullstack |
| VueUse | Готовые composables |
| Vuetify, PrimeVue, Element Plus, Naive UI | UI-библиотеки компонентов |

## Vue, React, Angular

| | Vue | React | Angular |
| --- | --- | --- | --- |
| Тип | Прогрессивный фреймворк | Библиотека UI | Полный фреймворк |
| Шаблоны | HTML-шаблоны (можно JSX) | JSX | HTML-шаблоны + TypeScript |
| Реактивность | Встроенная, на Proxy (точечные обновления) | Перерендер компонента по `setState` | Zone.js / signals |
| Официальные роутер и стор | Да | Нет (сообщество) | Да |
| Порог входа | Низкий | Средний | Высокий |

## Когда Vue — хороший выбор

- SPA и админки любой сложности.
- Постепенное внедрение в существующие страницы.
- SSR и контентные сайты — через Nuxt.
- Команды, которым важны HTML-подобные шаблоны и официальная экосистема.

## Частые ошибки

- Манипулировать DOM напрямую (`document.querySelector`) вместо изменения состояния.
- Начинать новые проекты на Vue 2 или Vuex.
- Смешивать Options и Composition API в одном проекте без правил.

## Что важно помнить

- Vue = декларативный рендеринг + реактивность + компоненты.
- Официальная экосистема: Router, Pinia, Vite, Nuxt, DevTools.
- Актуальна Vue 3; для новых компонентов — `<script setup>` и Composition API.

## Мини-шпаргалка

- `createApp(App).use(plugin).mount('#app')`.
- `.vue` = `<template>` + `<script setup>` + `<style scoped>`.
- `ref`, `computed`, `{{ }}`, `@click`.
- `npm create vue@latest`.
