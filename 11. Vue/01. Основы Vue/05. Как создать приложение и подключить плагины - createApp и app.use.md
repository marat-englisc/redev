# Как создать приложение и подключить плагины - createApp и app.use

> [!NOTE]
> Vue-приложение создаётся вызовом **`createApp(RootComponent)`**, который возвращает **экземпляр приложения** — контекст для всего дерева компонентов. Через него регистрируют **плагины** (`app.use(router)`, `app.use(createPinia())`), глобальные компоненты (`app.component`), директивы (`app.directive`), значения для всех компонентов (`app.provide`, `app.config.globalProperties`), обработчики ошибок и предупреждений (`app.config.errorHandler`, `warnHandler`), а затем монтируют его в DOM — **`app.mount('#app')`** (возвращает корневой экземпляр компонента; плагины подключаются **до** монтирования). **Плагин** — объект с методом `install(app, options)` или функция с той же сигнатурой: внутри он может регистрировать компоненты и директивы, вызывать `app.provide` и добавлять глобальные свойства. На одной странице может существовать несколько независимых приложений. В SSR вместо `createApp` используют `createSSRApp`, и для каждого запроса создаётся новый экземпляр приложения, чтобы состояние не «протекало» между пользователями.

## Вопрос

Как создать Vue-приложение и что такое плагины?

## main.ts

```ts
import { createApp } from 'vue';
import { createPinia } from 'pinia';
import App from './App.vue';
import { router } from './router';
import { i18n } from './i18n';
import BaseButton from './components/base/BaseButton.vue';
import { vFocus } from './directives/focus';

const app = createApp(App);

app.use(createPinia());
app.use(router);
app.use(i18n);

app.component('BaseButton', BaseButton);   // глобальный компонент
app.directive('focus', vFocus);            // глобальная директива

app.config.errorHandler = (err, instance, info) => {
  reportError(err, { component: instance?.$options.name, info });
};

app.mount('#app');
```

## Свой плагин

```ts
// plugins/toast.ts
import type { App, InjectionKey } from 'vue';
import ToastContainer from './ToastContainer.vue';

export interface ToastApi { show(text: string, type?: 'info' | 'error'): void }
export const ToastKey: InjectionKey<ToastApi> = Symbol('toast');

export const toastPlugin = {
  install(app: App, options: { duration?: number } = {}) {
    const api: ToastApi = { show: (text, type = 'info') => { /* добавить в очередь с options.duration */ } };

    app.provide(ToastKey, api);              // useToast() через inject
    app.component('ToastContainer', ToastContainer);
    app.config.globalProperties.$toast = api; // для Options API (this.$toast)
  },
};

// использование
app.use(toastPlugin, { duration: 3000 });

export function useToast() {
  const api = inject(ToastKey);
  if (!api) throw new Error('toastPlugin is not installed');
  return api;
}
```

```ts
// типизация globalProperties
declare module 'vue' {
  interface ComponentCustomProperties { $toast: ToastApi }
}
```

## API приложения

| Метод / свойство | Назначение |
| --- | --- |
| `app.use(plugin, options)` | Подключить плагин (повторный вызов игнорируется) |
| `app.component(name, comp)` | Глобальный компонент |
| `app.directive(name, dir)` | Глобальная директива |
| `app.provide(key, value)` | Значение, доступное через `inject` во всём приложении |
| `app.config.errorHandler` | Обработчик необработанных ошибок компонентов |
| `app.config.globalProperties` | Свойства `this.$x` для Options API |
| `app.mount(selector)` / `app.unmount()` | Монтирование / размонтирование |
| `app.runWithContext(fn)` | Выполнить код с доступом к `inject` вне компонента |

## Несколько приложений

```ts
createApp(SearchWidget).mount('#search');
createApp(CartWidget).use(createPinia()).mount('#cart');   // независимые контексты
```

## SSR

```ts
export function createAppInstance() {
  const app = createSSRApp(App);
  const pinia = createPinia();
  app.use(pinia).use(createRouter(...));
  return { app, pinia };         // новый экземпляр на каждый запрос
}
```

## Частые ошибки

- `app.use(...)` после `app.mount()`.
- Синглтон-стор или роутер в SSR, общие для всех запросов.
- Злоупотребление `globalProperties` вместо `provide`/composables в Composition API.
- Регистрировать глобально все компоненты — хуже tree shaking и непонятно, где они используются.

## Что важно помнить

- `createApp` → `use`/`component`/`directive`/`provide` → `mount`.
- Плагин — объект с `install(app, options)`.
- В Composition API глобальные сервисы отдают через `app.provide` + composable с `inject`.

## Мини-шпаргалка

- `createApp(App).use(pinia).use(router).mount('#app')`.
- `{ install(app, options) { ... } }`.
- `app.config.errorHandler`.
- `declare module 'vue' { interface ComponentCustomProperties }`.
