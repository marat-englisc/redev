# Чем Vue 3 отличается от Vue 2

> [!NOTE]
> **Vue 3** — переписанное ядро с новой реактивностью и рядом изменений API; **Vue 2** достиг конца жизни 31 декабря 2023 года и больше не получает обновлений. Главные отличия: реактивность на **`Proxy`** вместо `Object.defineProperty` (отслеживаются добавление и удаление свойств, индексы массивов, `Map`/`Set` — `Vue.set`/`$set` больше не нужны); **Composition API** и `<script setup>`; **`createApp`** вместо глобального `new Vue()` и мутаций глобального `Vue.use` — у каждого приложения свой контекст; **фрагменты** (несколько корневых узлов), **Teleport**, **Suspense**; переработанный `v-model` на компонентах (`modelValue`/`update:modelValue`, несколько моделей, `defineModel`); `emits` как явная опция; удалены filters, `$on`/`$off`/`$once` (event bus), `$listeners` (слиты в `$attrs`), `$children`, inline-template; изменены хуки `beforeDestroy`/`destroyed` → `beforeUnmount`/`unmounted`; лучшая поддержка TypeScript и tree shaking; Pinia вместо Vuex, Vite вместо Vue CLI. Для миграции существовала сборка совместимости `@vue/compat`.

## Вопрос

Чем Vue 3 отличается от Vue 2 и что важно при миграции?

## Сравнение

| Тема | Vue 2 | Vue 3 |
| --- | --- | --- |
| Реактивность | `Object.defineProperty` | `Proxy` |
| Новые свойства объекта | `Vue.set(obj, 'k', v)` | Просто `obj.k = v` |
| Массивы по индексу | `this.$set(arr, i, v)` | `arr[i] = v` |
| Создание приложения | `new Vue({ render })` | `createApp(App).mount()` |
| Глобальная конфигурация | `Vue.use`, `Vue.component` — общие для всех | `app.use`, `app.component` — на приложение |
| API компонентов | Options API | Options + Composition API, `<script setup>` |
| Корневые узлы | Один | Несколько (фрагменты) |
| Порталы | Сторонние библиотеки | `<Teleport>` |
| Асинхронность | — | `<Suspense>` (экспериментально) |
| `v-model` на компоненте | `value` + `input`, один | `modelValue` + `update:modelValue`, несколько, `defineModel` |
| Хуки удаления | `beforeDestroy`, `destroyed` | `beforeUnmount`, `unmounted` |
| Фильтры | `{{ price \| currency }}` | Удалены — функции или `computed` |
| Event bus | `$on`, `$off`, `$once` | Удалены — `mitt`, store, provide/inject |
| `$listeners` | Отдельно | Часть `$attrs` |
| TypeScript | Ограниченно | Первоклассная поддержка |
| Состояние | Vuex | Pinia |
| Сборка | Vue CLI (webpack) | Vite |

## Реактивность: почему Proxy

```js
// Vue 2: новое свойство не реактивно
this.user.age = 30;               // UI не обновится
this.$set(this.user, 'age', 30);  // нужно так

// Vue 3
user.age = 30;                    // реактивно
delete user.age;                  // тоже отслеживается
items[3] = 'x';                   // отслеживается
```

## v-model на компонентах

```vue
<!-- Vue 2 -->
<MyInput :value="text" @input="text = $event" />

<!-- Vue 3 -->
<MyInput v-model="text" />                         <!-- modelValue / update:modelValue -->
<UserForm v-model:first-name="first" v-model:last-name="last" />
```

```ts
// Vue 3.4+ — внутри компонента
const model = defineModel<string>();
```

## Вместо фильтров и event bus

```vue
<!-- было: {{ price | currency }} -->
<span>{{ formatCurrency(price) }}</span>
```

```ts
// было: this.$root.$on('logout', ...)
import mitt from 'mitt';
export const bus = mitt<{ logout: void }>();
```

## Стратегия миграции

1. Обновить зависимости: Vue Router 4, Pinia (или Vuex 4), библиотеки компонентов с поддержкой Vue 3.
2. Перейти на сборку `@vue/compat` — она выдаёт предупреждения о несовместимом коде.
3. Исправить предупреждения: фильтры, event bus, `v-model`, хуки, `$listeners`, функциональные компоненты.
4. Отключить compat-режим.
5. Постепенно переписывать сложные компоненты на Composition API (не обязательно сразу).

## Частые ошибки

- Тащить `Vue.set` и `$set` в код Vue 3.
- Использовать `beforeDestroy`/`destroyed` — в Vue 3 они не вызываются.
- Пытаться найти аналог фильтров вместо обычных функций.
- Event bus через пустой экземпляр Vue — в Vue 3 `$on` отсутствует.

## Что важно помнить

- Vue 2 завершён; новые проекты — только Vue 3.
- Главные изменения: Proxy-реактивность, Composition API, `createApp`, новый `v-model`, удалённые фильтры и `$on`.
- Миграция — через `@vue/compat` и обновление экосистемы.

## Мини-шпаргалка

- `Vue.set` → обычное присваивание.
- `new Vue` → `createApp`.
- `value`/`input` → `modelValue`/`update:modelValue`, `defineModel`.
- `destroyed` → `unmounted`.
- Фильтры → функции, event bus → `mitt`/store.
