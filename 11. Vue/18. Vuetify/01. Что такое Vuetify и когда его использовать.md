# Что такое Vuetify и когда его использовать

> [!NOTE]
> **Vuetify** — большая UI-библиотека компонентов для Vue 3, реализующая **Material Design** (в версии 4 — Material Design 3: новая типографика, уровни тени 0–5, системная тема по умолчанию). Она даёт готовую систему: layout приложения (`VApp`, `VAppBar`, `VNavigationDrawer`, `VMain`), сетку (`VContainer`, `VRow`, `VCol`), десятки компонентов (кнопки, карточки, поля форм с валидацией, селекты и автокомплиты, диалоги, меню, вкладки, таблицы данных с сортировкой и серверной пагинацией, date picker, уведомления), **темы** (светлая/тёмная/свои цвета через CSS-переменные), **глобальные defaults** компонентов, адаптивность (`useDisplay`), i18n и RTL, доступность (ARIA, клавиатурная навигация), SSR и интеграцию с Nuxt. Когда подходит: **админки, внутренние инструменты, дашборды, CRM**, B2B-продукты, где важна скорость разработки и единообразие, а Material-стиль приемлем. Когда хуже: маркетинговые сайты и продукты с уникальным дизайном (бороться со стилями Material дороже, чем сверстать с Tailwind), критичный размер бандла и минималистичные интерфейсы. Альтернативы: **PrimeVue** (несколько тем, unstyled-режим), **Quasar** (фреймворк с Material и сборкой под мобильные/десктоп), **Naive UI**, **Element Plus**, headless-библиотеки **Reka UI** и **shadcn-vue** (поведение и доступность без навязанного дизайна, стили — свои, часто Tailwind).

## Вопрос

Что такое Vuetify и в каких проектах его стоит использовать?

## Пример: каркас админки

```vue
<template>
  <v-app>
    <v-navigation-drawer v-model="drawer">
      <v-list nav>
        <v-list-item prepend-icon="mdi-view-dashboard" title="Дашборд" :to="{ name: 'dashboard' }" />
        <v-list-item prepend-icon="mdi-package-variant" title="Заказы" :to="{ name: 'orders' }" />
      </v-list>
    </v-navigation-drawer>

    <v-app-bar>
      <v-app-bar-nav-icon @click="drawer = !drawer" />
      <v-app-bar-title>Shop Admin</v-app-bar-title>
    </v-app-bar>

    <v-main>
      <v-container>
        <RouterView />
      </v-container>
    </v-main>
  </v-app>
</template>
```

Без единой строки CSS получается адаптивный layout с навигацией, темой и доступной разметкой.

## Что даёт библиотека

| Возможность | Пример |
| --- | --- |
| Layout | `VApp`, `VAppBar`, `VNavigationDrawer`, `VMain`, `VFooter` |
| Сетка | `VContainer`, `VRow`, `VCol` |
| Формы | `VForm`, `VTextField`, `VSelect`, `VAutocomplete`, `VCheckbox`, `VFileInput` |
| Данные | `VDataTable`, `VDataTableServer`, `VDataIterator`, `VVirtualScroll` |
| Оверлеи | `VDialog`, `VMenu`, `VTooltip`, `VSnackbar`, `VBottomSheet` |
| Навигация | `VTabs`, `VBreadcrumbs`, `VPagination`, `VStepper` |
| Темы и defaults | `createVuetify({ theme, defaults })` |
| Адаптивность | `useDisplay()`, responsive-пропсы `cols`/`md` |

## Vuetify или Tailwind

| Vuetify | Tailwind CSS |
| --- | --- |
| Готовые компоненты с поведением | Утилиты для стилей, компоненты — свои |
| Быстрый старт, единообразие | Полная свобода дизайна |
| Material Design | Любой дизайн |
| Больше JS и CSS | Только используемые классы |
| Админки, внутренние инструменты | Продуктовые и маркетинговые интерфейсы |

Их можно совмещать (Tailwind для своих блоков), но нужно настроить порядок CSS-слоёв — см. [совмещение Tailwind с компонентными библиотеками](<../19. Tailwind CSS/06. Как совмещать Tailwind с компонентными библиотеками.md>).

## Частые ошибки

- Брать Vuetify для проекта с уникальным брендовым дизайном и переопределять почти всё.
- Подключать все компоненты (`import * as components`) в production без автоимпорта — лишний бандл.
- Смешивать несколько UI-библиотек — разные стили, дублирование кода.
- Переносить примеры из Vuetify 2 или 3 в Vuetify 4 без учёта изменений (сетка, типографика, тема по умолчанию).

## Что важно помнить

- Vuetify — полноценная Material-система: layout, компоненты, темы, defaults, a11y.
- Лучше всего подходит для админок и внутренних инструментов.
- Для уникального дизайна — Tailwind или headless-библиотеки.

## Мини-шпаргалка

- `<v-app>` → `<v-app-bar>`, `<v-navigation-drawer>`, `<v-main>`.
- Vuetify 4 — Material Design 3.
- Альтернативы: PrimeVue, Quasar, Naive UI, Reka UI, shadcn-vue.
