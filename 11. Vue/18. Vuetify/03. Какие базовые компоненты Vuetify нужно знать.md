# Какие базовые компоненты Vuetify нужно знать

> [!NOTE]
> Базовый набор Vuetify делится на группы. **Layout**: `VApp` (корень), `VAppBar`, `VNavigationDrawer`, `VMain` (основной контент с автоматическими отступами под панели), `VFooter`. **Сетка**: `VContainer` → `VRow` → `VCol` с колонками из 12 (`cols="12" md="6"`); в Vuetify 4 расстояния задаются CSS `gap` (проп `gap`, `density="compact"` вместо `dense`), а выравнивание — утилитарными классами (`align-center`, `justify-space-between`). **Кнопки и контейнеры**: `VBtn` (варианты `elevated`, `flat`, `tonal`, `outlined`, `text`, `plain`; `loading`, `block`, `to` для роутера), `VCard` (+ `VCardTitle`, `VCardText`, `VCardActions` или пропсы `title`/`subtitle`/`text`), `VChip`, `VAlert`, `VDivider`, `VIcon`, `VImg`, `VAvatar`. **Формы**: `VForm`, `VTextField`, `VTextarea`, `VSelect`, `VAutocomplete`, `VCombobox`, `VCheckbox`, `VSwitch`, `VRadioGroup`, `VFileInput`, `VDatePicker`. **Списки и навигация**: `VList`/`VListItem`, `VTabs`, `VBreadcrumbs`, `VPagination`, `VStepper`. **Оверлеи**: `VDialog`, `VMenu`, `VTooltip`, `VSnackbar` (и `VSnackbarQueue`), `VBottomSheet`. **Данные**: `VDataTable` (клиентская сортировка, поиск, пагинация), `VDataTableServer` (серверная), `VDataTableVirtual`, `VVirtualScroll`, `VSkeletonLoader`, `VProgressLinear`. Утилитарные классы (`pa-4`, `mb-2`, `d-flex`, `text-medium-emphasis`, `bg-primary`, MD3-типографика `text-headline-small`) покрывают отступы и простое оформление без своего CSS.

## Вопрос

Какие базовые компоненты Vuetify нужно знать и как их применять?

## Сетка

```vue
<v-container>
  <v-row :gap="16">
    <v-col cols="12" md="8">
      <ProductList />
    </v-col>
    <v-col cols="12" md="4">
      <CartSummary />
    </v-col>
  </v-row>
</v-container>
```

| Проп `VCol` | Смысл |
| --- | --- |
| `cols="12"` | Ширина на всех экранах (из 12) |
| `sm`, `md`, `lg`, `xl`, `xxl` | Ширина с брейкпоинта |
| `offset`, `offset-md` | Сдвиг |

## Кнопки, карточки, чипы

```vue
<v-card title="Клавиатура" :subtitle="`${product.price} ₽`" max-width="360">
  <v-img :src="product.image" height="180" cover />
  <v-card-text>
    <v-chip v-if="product.isNew" color="success" size="small">Новинка</v-chip>
    {{ product.description }}
  </v-card-text>
  <v-card-actions>
    <v-btn variant="tonal" :to="{ name: 'product', params: { id: product.id } }">Подробнее</v-btn>
    <v-spacer />
    <v-btn color="primary" prepend-icon="mdi-cart" :loading="adding" @click="add">В корзину</v-btn>
  </v-card-actions>
</v-card>
```

## Поля форм

```vue
<v-text-field v-model="form.email" label="Email" type="email" :rules="[rules.required, rules.email]" autocomplete="email" />
<v-select v-model="form.city" :items="cities" item-title="name" item-value="id" label="Город" />
<v-autocomplete v-model="form.tags" :items="tags" label="Теги" multiple chips closable-chips />
<v-checkbox v-model="form.agree" label="Согласен с условиями" :rules="[rules.required]" />
```

## Диалог и уведомление

```vue
<script setup lang="ts">
const confirmOpen = ref(false);
const snackbar = ref({ show: false, text: '' });

async function remove() {
  await api.deleteOrder(props.id);
  confirmOpen.value = false;
  snackbar.value = { show: true, text: 'Заказ удалён' };
}
</script>

<template>
  <v-dialog v-model="confirmOpen" max-width="420">
    <template #activator="{ props: activatorProps }">
      <v-btn v-bind="activatorProps" color="error" variant="text">Удалить</v-btn>
    </template>
    <v-card title="Удалить заказ?" text="Действие нельзя отменить.">
      <v-card-actions>
        <v-spacer />
        <v-btn @click="confirmOpen = false">Отмена</v-btn>
        <v-btn color="error" @click="remove">Удалить</v-btn>
      </v-card-actions>
    </v-card>
  </v-dialog>

  <v-snackbar v-model="snackbar.show" timeout="3000">{{ snackbar.text }}</v-snackbar>
</template>
```

## Таблица данных

```vue
<script setup lang="ts">
const headers = [
  { title: 'Номер', key: 'id' },
  { title: 'Клиент', key: 'customer.name' },
  { title: 'Сумма', key: 'total', align: 'end' },
  { title: '', key: 'actions', sortable: false },
] as const;
</script>

<template>
  <v-data-table :headers="headers" :items="orders" :search="search" :items-per-page="20" item-value="id">
    <template #item.total="{ value }">{{ formatPrice(value) }}</template>
    <template #item.actions="{ item }">
      <v-btn icon="mdi-pencil" variant="text" size="small" :to="{ name: 'order', params: { id: item.id } }" />
    </template>
  </v-data-table>
</template>
```

```vue
<!-- серверная пагинация и сортировка -->
<v-data-table-server
  :headers="headers"
  :items="page.items"
  :items-length="page.total"
  :loading="loading"
  @update:options="loadOrders"
/>
```

`loadOrders({ page, itemsPerPage, sortBy })` получает параметры для запроса к API.

## Утилитарные классы

| Класс | Смысл |
| --- | --- |
| `pa-4`, `px-2`, `mt-6`, `mb-n2` | Отступы (шаг 4px) |
| `d-flex`, `align-center`, `justify-space-between`, `ga-2` | Flex и gap |
| `text-primary`, `bg-surface-variant` | Цвета темы |
| `text-headline-small`, `text-body-medium` | Типографика MD3 (Vuetify 4) |
| `text-medium-emphasis` | Приглушённый текст |
| `d-none d-md-flex` | Показ по брейкпоинту |

## Частые ошибки

- Свой CSS для отступов и flex там, где хватает утилитарных классов.
- `VDataTable` с десятками тысяч строк на клиенте — используйте `VDataTableServer` или `VDataTableVirtual`.
- Vuetify 3-классы типографики (`text-h5`) и `dense` в `VRow` в проекте на Vuetify 4.
- Не передать `activatorProps` в активатор диалога/меню — ломаются доступность и позиционирование.
- `VSelect` с объектами без `item-title`/`item-value`.

## Что важно помнить

- Layout + сетка + кнопки/карточки + поля форм + оверлеи + таблицы — базовый набор.
- Responsive-пропсы и утилитарные классы вместо своего CSS.
- Большие данные — серверная или виртуальная таблица.

## Мини-шпаргалка

- `<v-row :gap="16"><v-col cols="12" md="6">`.
- `<v-btn variant="tonal" :loading :to>`.
- `<v-select :items item-title item-value>`.
- `<v-dialog v-model><template #activator="{ props }">`.
- `<v-data-table :headers :items>` / `<v-data-table-server @update:options>`.
