# Какие ошибки бывают при работе с Vuetify и что изменилось в Vuetify 4

> [!NOTE]
> Типичные ошибки с Vuetify: **подключение** — нет `<v-app>`, забыт `vuetify/styles` или иконки, вся библиотека в бандле без `autoImport`; **стилизация** — борьба с Material через `!important` и глубокие селекторы вместо темы, `defaults` и Sass-переменных, хардкод цветов, ломающий тёмную тему, конфликты CSS с Tailwind или глобальными стилями; **компоненты** — не переданы `props` из слота `#activator`, `VSelect` с объектами без `item-title`/`item-value`/`return-object`, клиентская `VDataTable` на десятках тысяч строк, правила валидации, возвращающие `false` вместо текста, синхронная проверка `form.validate()`; **SSR/Nuxt** — `useDisplay` на сервере не знает ширину экрана (hydration mismatch; задайте `ssr: { clientWidth }` или рендерьте адаптивные части на клиенте); **Vite** — в dev оверлеи внутри диалогов могут отображаться позади (дубли модулей при pre-bundling — добавьте `vuetify/components/VOverlay`, `VDialog`, `VMenu`, `VSelect`, `VTooltip` в `optimizeDeps.include` и очистите `.vite`). **Vuetify 4** (Material Design 3) принёс заметные изменения: CSS разделён на несколько каскадных слоёв (`vuetify-core`, `vuetify-components`, `vuetify-overrides`, `vuetify-utilities`, `vuetify-final`), и стили вне слоёв теперь **сильнее** Vuetify; убран глобальный CSS-reset; тема по умолчанию — `system`; новая типографика (`text-h4` → `text-headline-large` и т. д.) и тени 0–5; кнопки без `uppercase`; сетка на CSS `gap` (`dense` → `density="compact"`, выравнивание — классами); новые брейкпоинты; слот `#item` селектов — `internalItem`; значения слота `VForm` развёрнуты. Для миграции есть `vuetify-codemods`.

## Вопрос

Какие ошибки чаще всего встречаются при работе с Vuetify и что нужно учесть при переходе на Vuetify 4?

## Подключение

```vue
<!-- ✗ без v-app: нет темы, layout и оверлеи ведут себя неправильно -->
<template><RouterView /></template>

<!-- ✓ -->
<template>
  <v-app><v-main><RouterView /></v-main></v-app>
</template>
```

```ts
import 'vuetify/styles';                              // ✓ без этого — компоненты без стилей
import '@mdi/font/css/materialdesignicons.css';       // ✓ иначе пустые иконки
```

## Стилизация

```css
/* ✗ борьба с внутренней разметкой */
.my-page .v-btn .v-btn__content { text-transform: none !important; }
```

```ts
// ✓ через defaults или Sass-переменные
createVuetify({ defaults: { VBtn: { class: 'text-none' } } });
```

```vue
<!-- ✗ цвет не меняется в тёмной теме -->
<v-card style="background: #fff; color: #111" />
<!-- ✓ -->
<v-card color="surface" />
```

## Селекты с объектами

```vue
<!-- items: [{ id: 1, name: 'Москва' }] -->
<!-- ✗ в v-model окажется объект, в списке — [object Object] -->
<v-select v-model="cityId" :items="cities" />

<!-- ✓ -->
<v-select v-model="cityId" :items="cities" item-title="name" item-value="id" />
<!-- или v-model хранит весь объект -->
<v-select v-model="city" :items="cities" item-title="name" return-object />
```

## SSR и useDisplay

```ts
createVuetify({ ssr: { clientWidth: 1280 } });   // предположение о ширине для серверного рендера
```

```vue
<ClientOnly><MobileOnlyToolbar v-if="mobile" /></ClientOnly>
```

## Оверлеи в dev-режиме Vite

```ts
// vite.config.ts
optimizeDeps: {
  include: [
    'vuetify/components/VOverlay',
    'vuetify/components/VDialog',
    'vuetify/components/VMenu',
    'vuetify/components/VSelect',
    'vuetify/components/VTooltip',
  ],
},
```

## Vuetify 4: CSS-слои и Tailwind

```css
/* src/styles/layers.css — порядок слоёв (подключить в index.html до остальных стилей) */
@layer vuetify-core, vuetify-components, vuetify-overrides, vuetify-utilities, vuetify-final;
```

Стили вне слоёв теперь перекрывают Vuetify — свои CSS-правила работают без `!important`, но и случайные глобальные стили (`button { ... }`) тоже повлияют на компоненты.

## Vuetify 4: что изменилось

| Область | Vuetify 3 | Vuetify 4 |
| --- | --- | --- |
| Тема по умолчанию | `light` | `system` (`defaultTheme: 'light'` вернёт старое) |
| CSS-reset | Глобальный `* { margin: 0; padding: 0 }` | Удалён |
| CSS-слои | Один слой `vuetify` | Пять слоёв, стили вне слоёв сильнее |
| Типографика | `text-h1`…`text-h6`, `text-body-1`, `text-caption` | `text-display-*`, `text-headline-*`, `text-title-*`, `text-body-*`, `text-label-*` |
| Тени | `elevation` 0–24 | 0–5 |
| `VBtn` | `uppercase` | Без трансформации текста |
| Сетка | Отрицательные margin, `dense` | CSS `gap`, `density="compact"`, проп `gap` |
| Выравнивание `VRow`/`VCol` | Пропсы `align`, `justify`, `order` | Утилитарные классы |
| Брейкпоинты | md 960, lg 1280, xl 1920 | md 840, lg 1145, xl 1545, xxl 2138 |
| Слот `#item` селектов | `item` | `internalItem` (+ `item` как алиас raw) |
| Слот `VForm` | `isValid.value` | `isValid` |
| Цвета темы в CSS | `rgba(var(--v-theme-x), a)` | `color-mix()`/`rgb(from ...)` |

npx vuetify-codemods

## Частые ошибки (сводка)

- Нет `<v-app>`, стилей или иконок.
- `!important` и глубокие селекторы вместо темы/defaults.
- Объекты в `VSelect` без `item-title`/`item-value`.
- Не передан `props` активатора.
- Клиентская таблица на огромных данных.
- Копирование примеров Vuetify 2/3 в проект на Vuetify 4.

## Что важно помнить

- Настраивайте библиотеку через тему, defaults, aliases и Sass, а не переопределением CSS.
- Учитывайте SSR (`useDisplay`) и особенности pre-bundling в Vite.
- Vuetify 4: MD3-типографика, `system`-тема, CSS-слои, сетка на `gap`, новые брейкпоинты; есть codemods.

## Мини-шпаргалка

- `<v-app>` + `vuetify/styles` + иконки.
- `item-title`, `item-value`, `return-object`.
- `ssr: { clientWidth }`.
- `optimizeDeps.include` для оверлеев в dev.
- `npx vuetify-codemods` при миграции на v4.
