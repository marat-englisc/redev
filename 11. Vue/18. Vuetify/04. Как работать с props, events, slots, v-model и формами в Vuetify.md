# Как работать с props, events, slots, v-model и формами в Vuetify

> [!NOTE]
> Компоненты Vuetify — обычные Vue-компоненты и подчиняются тем же правилам. **Props** управляют видом и поведением: общие для многих компонентов — `variant`, `color`, `density` (`default`/`comfortable`/`compact`), `size`, `rounded`, `elevation`, `disabled`, `loading`; навигационные (`to`, `href`, `replace`) делают из кнопки/элемента списка ссылку роутера. **`v-model`** — основное состояние: значение поля, открытость диалога/меню/drawer, активная вкладка, выбранные строки таблицы; дополнительные модели — через `v-model:имя` (`v-model:search`, `v-model:page`, `v-model:sort-by`, `v-model:expanded`). **События** — `update:modelValue` и специфичные (`click:clear`, `click:append-inner`, `update:options` у серверной таблицы, `update:focused`). **Слоты** позволяют заменить части компонента: `#prepend`/`#append`/`#prepend-inner`/`#append-inner` у полей, `#activator` у диалога/меню/тултипа (получает `props` — их нужно передать в элемент через `v-bind`), `#item`/`#chip`/`#selection` у селектов, `#item.<key>`/`#header.<key>`/`#loading`/`#no-data` у таблиц. **Формы**: `VForm` собирает валидацию полей; правило — функция, возвращающая `true` или текст ошибки; `form.validate()` возвращает `Promise<{ valid, errors }>`, `reset()`/`resetValidation()`; режим — `validate-on` (`input`, `blur`, `submit`, `lazy`). В Vuetify 4 значения слота `VForm` (`isValid`, `errors`) разворачиваются — в шаблоне без `.value`. Для сложных схем валидацию лучше вынести в Zod/VeeValidate и передать ошибки в `error-messages`.

## Вопрос

Как работать с props, событиями, слотами, `v-model` и формами в Vuetify?

## Props

```vue
<v-btn color="primary" variant="outlined" size="large" rounded="lg" :loading="saving" :disabled="!valid">Сохранить</v-btn>
<v-text-field label="Поиск" density="compact" variant="solo-filled" prepend-inner-icon="mdi-magnify" clearable hide-details />
<v-list-item :to="{ name: 'orders' }" title="Заказы" prepend-icon="mdi-package-variant" />
```

## v-model и дополнительные модели

```vue
<script setup lang="ts">
const drawer = ref(true);
const tab = ref<'info' | 'reviews'>('info');
const selected = ref<number[]>([]);
const search = ref('');
const page = ref(1);
</script>

<template>
  <v-navigation-drawer v-model="drawer" />
  <v-tabs v-model="tab">
    <v-tab value="info">Описание</v-tab>
    <v-tab value="reviews">Отзывы</v-tab>
  </v-tabs>
  <v-tabs-window v-model="tab">
    <v-tabs-window-item value="info">...</v-tabs-window-item>
    <v-tabs-window-item value="reviews">...</v-tabs-window-item>
  </v-tabs-window>

  <v-data-table v-model="selected" v-model:search="search" v-model:page="page" :items="orders" show-select item-value="id" />
</template>
```

## События

```vue
<v-text-field
  v-model="query"
  clearable
  append-inner-icon="mdi-send"
  @click:clear="reset"
  @click:append-inner="submit"
  @keydown.enter="submit"
/>
```

## Слоты

```vue
<!-- поле с кастомным суффиксом -->
<v-text-field v-model="price" label="Цена" type="number">
  <template #append-inner><span class="text-medium-emphasis">₽</span></template>
</v-text-field>

<!-- кастомный элемент списка в автокомплите (Vuetify 4: internalItem) -->
<v-autocomplete v-model="userId" :items="users" item-title="name" item-value="id" label="Ответственный">
  <template #item="{ props: itemProps, item }">
    <v-list-item v-bind="itemProps" :subtitle="item.email" :prepend-avatar="item.avatar" />
  </template>
</v-autocomplete>

<!-- меню с активатором -->
<v-menu>
  <template #activator="{ props: menuProps }">
    <v-btn v-bind="menuProps" icon="mdi-dots-vertical" aria-label="Действия" />
  </template>
  <v-list>
    <v-list-item title="Редактировать" @click="edit" />
    <v-list-item title="Удалить" base-color="error" @click="remove" />
  </v-list>
</v-menu>
```

В Vuetify 4 в слоте `#item` селектов есть `internalItem`, а `item` — алиас для исходного объекта (`internalItem.raw`).

## Формы и валидация

```vue
<script setup lang="ts">
import type { VForm } from 'vuetify/components';

const form = useTemplateRef<VForm>('form');
const model = reactive({ name: '', email: '', age: null as number | null });
const submitting = ref(false);
const serverErrors = ref<Record<string, string[]>>({});

const rules = {
  required: (v: unknown) => (v !== null && v !== '' && v !== undefined) || 'Обязательное поле',
  email: (v: string) => /.+@.+\..+/.test(v) || 'Некорректный email',
  adult: (v: number) => v >= 18 || 'Только с 18 лет',
};

async function submit() {
  const { valid } = await form.value!.validate();
  if (!valid) return;
  submitting.value = true;
  try {
    await api.createCustomer(model);
    form.value!.reset();
  } catch (e) {
    serverErrors.value = parseValidationErrors(e);     // { email: ['Уже занят'] }
  } finally {
    submitting.value = false;
  }
}
</script>

<template>
  <v-form ref="form" validate-on="blur lazy" @submit.prevent="submit">
    <template #default="{ isValid }">
      <v-text-field v-model="model.name" label="Имя" :rules="[rules.required]" />
      <v-text-field v-model="model.email" label="Email" :rules="[rules.required, rules.email]" :error-messages="serverErrors.email" />
      <v-text-field v-model.number="model.age" label="Возраст" type="number" :rules="[rules.required, rules.adult]" />
      <v-btn type="submit" color="primary" :loading="submitting" :disabled="isValid === false">Создать</v-btn>
    </template>
  </v-form>
</template>
```

| API `VForm` | Смысл |
| --- | --- |
| `validate()` | `Promise<{ valid, errors }>` |
| `reset()` | Сбросить значения и ошибки |
| `resetValidation()` | Только ошибки |
| `validate-on` | `input` (по умолчанию), `blur`, `submit`, `lazy` и комбинации |
| `v-model` формы | `true`/`false`/`null` (ещё не проверялась) |

## Частые ошибки

- Не передать `props` из слота `#activator` — меню/диалог не открывается или недоступен с клавиатуры.
- Правило возвращает `false` вместо текста ошибки — сообщение пустое.
- Проверять `form.validate()` синхронно — он асинхронный.
- В Vuetify 4 писать `isValid.value` в слоте `VForm`.
- Дублировать проверку сервера только на клиенте — серверные ошибки нужно показать через `error-messages`.

## Что важно помнить

- Props для вида, `v-model` (и `v-model:x`) для состояния, события `update:*` и `click:*`.
- Слоты `#activator`, `#prepend/#append`, `#item`, `#item.<key>` для кастомизации.
- `VForm` + правила-функции + `validate()`; серверные ошибки — `error-messages`.

## Мини-шпаргалка

- `<v-btn variant color size density :loading :to>`.
- `v-model:search`, `v-model:page`, `v-model:sort-by`.
- `<template #activator="{ props }"><v-btn v-bind="props" /></template>`.
- `rules: [(v) => !!v || 'Обязательно']`.
- `const { valid } = await form.value.validate()`.
