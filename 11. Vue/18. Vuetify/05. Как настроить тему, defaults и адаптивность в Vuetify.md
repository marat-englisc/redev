# Как настроить тему, defaults и адаптивность в Vuetify

> [!NOTE]
> **Тема** Vuetify — набор цветов (`primary`, `secondary`, `error`, `success`, `warning`, `info`, `background`, `surface` и их `on-*` пары для текста) и переменных, описанных в `createVuetify({ theme: { defaultTheme, themes } })`. Цвета превращаются в **CSS-переменные** (`--v-theme-primary`), поэтому доступны в своих стилях и меняются без пересборки; классы `bg-primary`, `text-error` и проп `color="primary"` используют их же. Встроенные темы — `light` и `dark`; в **Vuetify 4 тема по умолчанию — `system`** (следует настройке ОС), а цвета поддерживают прозрачность (в CSS — через `color-mix()` или `rgb(from ...)` вместо старого `rgba(var(--v-theme-x), a)`). В рантайме тема переключается через `useTheme()` (`theme.change('dark')`, `theme.toggle()`), а `v-theme-provider` или проп `theme` меняет тему для части страницы. **Глобальные defaults** (`defaults: { VBtn: { variant: 'flat' } }`) задают пропсы по умолчанию для всех экземпляров — это главный способ привести библиотеку к дизайн-системе проекта без обёрток; `VDefaultsProvider` переопределяет их локально, а **aliases** создают «свои» компоненты (`MyPrimaryButton` на основе `VBtn`). Более глубокая настройка — **Sass-переменные** (`styles.configFile`). **Адаптивность**: `useDisplay()` даёт реактивные `mobile`, `name`, `mdAndUp`, `width` и др.; брейкпоинты в Vuetify 4 изменены под MD3 (md 840, lg 1145, xl 1545, xxl 2138) и настраиваются `display.thresholds`.

## Вопрос

Как настроить тему, глобальные defaults и адаптивность в Vuetify?

## Темы

```ts
import { createVuetify, type ThemeDefinition } from 'vuetify';

const brandLight: ThemeDefinition = {
  dark: false,
  colors: {
    primary: '#4f46e5',
    secondary: '#0ea5e9',
    background: '#f8fafc',
    surface: '#ffffff',
    error: '#dc2626',
    success: '#16a34a',
  },
  variables: { 'border-opacity': 0.12 },
};

const brandDark: ThemeDefinition = {
  dark: true,
  colors: { primary: '#818cf8', secondary: '#38bdf8', background: '#020617', surface: '#0f172a' },
};

export const vuetify = createVuetify({
  theme: {
    defaultTheme: 'system',                    // Vuetify 4: следовать ОС; 'brandLight' — фиксированная
    themes: { brandLight, brandDark },
  },
});
```

## Переключение темы

```vue
<script setup lang="ts">
import { useTheme } from 'vuetify';
const theme = useTheme();
</script>

<template>
  <v-btn :icon="theme.current.value.dark ? 'mdi-weather-sunny' : 'mdi-weather-night'" @click="theme.toggle(['brandLight', 'brandDark'])" />
  <p>Текущая: {{ theme.name.value }}</p>

  <!-- тёмный блок на светлой странице -->
  <v-theme-provider theme="brandDark" with-background class="pa-6">
    <PromoBanner />
  </v-theme-provider>
</template>
```

## Цвета темы в своих стилях

```css
.price-tag {
  color: rgb(var(--v-theme-primary));
  background: color-mix(in srgb, rgb(var(--v-theme-primary)) 12%, transparent);   /* Vuetify 4 */
}
```

## Defaults

```ts
createVuetify({
  defaults: {
    global: { ripple: false },
    VBtn: { variant: 'flat', rounded: 'lg', class: 'text-none' },
    VTextField: { variant: 'outlined', density: 'comfortable', color: 'primary' },
    VCard: { rounded: 'xl', elevation: 1 },
    VDataTable: { density: 'compact', itemsPerPage: 25 },
    VCardActions: { VBtn: { variant: 'text' } },   // вложенные defaults: кнопки внутри VCardActions
  },
});
```

```vue
<!-- локальное переопределение -->
<v-defaults-provider :defaults="{ VBtn: { size: 'small' } }">
  <Toolbar />
</v-defaults-provider>
```

В Vuetify 4 при слиянии defaults значения `undefined` пропускаются — чтобы «убрать» глобальный default, передайте `null`.

## Aliases — свои компоненты на базе Vuetify

```ts
import { VBtn } from 'vuetify/components';

createVuetify({
  aliases: { VBtnPrimary: VBtn, VBtnDanger: VBtn },
  defaults: {
    VBtnPrimary: { color: 'primary', variant: 'flat' },
    VBtnDanger: { color: 'error', variant: 'tonal', prependIcon: 'mdi-delete' },
  },
});
```

```vue
<v-btn-primary>Сохранить</v-btn-primary>
<v-btn-danger>Удалить</v-btn-danger>
```

## Адаптивность

```vue
<script setup lang="ts">
import { useDisplay } from 'vuetify';
const { mobile, mdAndUp, name, width } = useDisplay();
</script>

<template>
  <v-navigation-drawer :permanent="mdAndUp" :temporary="mobile" />
  <v-dialog :fullscreen="mobile" max-width="600">...</v-dialog>
  <p class="d-none d-md-block">Только на md и шире</p>
</template>
```

```ts
// вернуть брейкпоинты Vuetify 3 или задать свои
createVuetify({
  display: {
    mobileBreakpoint: 'md',
    thresholds: { xs: 0, sm: 600, md: 960, lg: 1280, xl: 1920, xxl: 2560 },
  },
});
```

## Sass-переменные

```scss
// src/styles/settings.scss (подключается через vite-plugin-vuetify styles.configFile)

  $button-text-transform: none,

```

## Что где настраивать

| Задача | Инструмент |
| --- | --- |
| Фирменные цвета, светлая/тёмная | `theme.themes` |
| Единый вид компонентов | `defaults` |
| Варианты компонентов (`Primary`, `Danger`) | `aliases` + `defaults` |
| Шрифты, радиусы, размеры | Sass-переменные |
| Локальные отличия | `v-defaults-provider`, `v-theme-provider` |
| Адаптивная логика | `useDisplay`, классы `d-*`, пропсы `md`/`lg` |

## Частые ошибки

- Хардкод HEX-цветов в компонентах вместо цветов темы — тёмная тема ломается.
- Обёртка над каждым компонентом ради одинаковых пропсов вместо `defaults`.
- `!important`-переопределения CSS вместо Sass-переменных и defaults.
- Не учитывать смену брейкпоинтов в Vuetify 4 при миграции.
- `rgba(var(--v-theme-x), 0.8)` в Vuetify 4 — используйте `color-mix()`.

## Что важно помнить

- Тема = цвета → CSS-переменные; `useTheme()` для переключения.
- `defaults` и `aliases` — приведение компонентов к дизайн-системе.
- `useDisplay` и responsive-пропсы; брейкпоинты настраиваются.

## Мини-шпаргалка

- `theme: { defaultTheme, themes: { light: { colors } } }`.
- `useTheme().change('dark')`, `.toggle()`.
- `defaults: { VBtn: { variant: 'flat' } }`, `<v-defaults-provider>`.
- `aliases: { VBtnPrimary: VBtn }`.
- `const { mobile, mdAndUp } = useDisplay()`.
