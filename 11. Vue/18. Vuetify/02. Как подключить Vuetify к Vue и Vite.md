# Как подключить Vuetify к Vue и Vite

> [!NOTE]
> Новый проект проще всего создать командой **`npm create vuetify@latest`** (Vite + Vuetify + опционально TypeScript, роутер, Pinia). В существующем проекте: установить `vuetify`, набор иконок (`@mdi/font` или SVG-иконки `@mdi/js`) и **`vite-plugin-vuetify`**, создать плагин `createVuetify({...})`, импортировать стили `vuetify/styles` и подключить `app.use(vuetify)`. Плагин Vite с `autoImport: true` **импортирует только используемые компоненты и директивы** (tree shaking) — пример с `import * as components from 'vuetify/components'` удобен для песочницы, но тянет в бандл всю библиотеку. Через опцию плагина `styles.configFile` подключается свой SCSS-файл настроек для переопределения Sass-переменных Vuetify. Всё приложение должно быть обёрнуто в **`<v-app>`** — он задаёт тему, layout-систему и контекст для оверлеев. Для **Nuxt** есть модуль `vuetify-nuxt-module` или ручная настройка с `vite-plugin-vuetify` и `build.transpile: ['vuetify']`.

## Вопрос

Как подключить Vuetify к Vue-проекту на Vite?

## Новый проект

```bash
npm create vuetify@latest
```

## Существующий проект

```bash
npm i vuetify @mdi/font
npm i -D vite-plugin-vuetify sass-embedded    # sass нужен только для настройки Sass-переменных
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import vuetify, { transformAssetUrls } from 'vite-plugin-vuetify';

export default defineConfig({
  plugins: [
    vue({ template: { transformAssetUrls } }),     // <v-img src="@/assets/x.png"> обрабатывается как ассет
    vuetify({
      autoImport: true,                             // только используемые компоненты
      styles: { configFile: 'src/styles/settings.scss' },   // необязательно: Sass-переменные
    }),
  ],
});
```

```ts
// plugins/vuetify.ts
import '@mdi/font/css/materialdesignicons.css';
import 'vuetify/styles';
import { createVuetify } from 'vuetify';
import { ru, en } from 'vuetify/locale';

export const vuetify = createVuetify({
  locale: { locale: 'ru', fallback: 'en', messages: { ru, en } },
  theme: {
    defaultTheme: 'light',                  // в Vuetify 4 по умолчанию 'system'
    themes: {
      light: { colors: { primary: '#4f46e5', secondary: '#0ea5e9' } },
    },
  },
  defaults: {
    VBtn: { variant: 'flat' },
    VTextField: { variant: 'outlined', density: 'comfortable' },
  },
});
```

```ts
// main.ts
import { createApp } from 'vue';
import App from './App.vue';
import { vuetify } from './plugins/vuetify';
import { router } from './router';

createApp(App).use(vuetify).use(router).mount('#app');
```

```vue
<!-- App.vue -->
<template>
  <v-app>
    <v-main>
      <RouterView />
    </v-main>
  </v-app>
</template>
```

## Иконки

```ts
// SVG-иконки вместо шрифта — в бандл попадают только используемые
import { aliases, mdi } from 'vuetify/iconsets/mdi-svg';
import { mdiAccount, mdiCart } from '@mdi/js';

createVuetify({ icons: { defaultSet: 'mdi', aliases, sets: { mdi } } });
```

```vue
<v-icon :icon="mdiCart" />
```

## Без плагина (песочница)

```ts
import * as components from 'vuetify/components';
import * as directives from 'vuetify/directives';
createVuetify({ components, directives });     // вся библиотека в бандле
```

## Sass-переменные

```scss
// src/styles/settings.scss
@use 'vuetify/settings' with (
  $button-height: 40px,
  $card-border-radius: 12px,
);
```

## Nuxt

```ts
// nuxt.config.ts — через модуль
export default defineNuxtConfig({
  modules: ['vuetify-nuxt-module'],
  vuetify: { vuetifyOptions: { theme: { defaultTheme: 'light' } } },
});
```

## Частые ошибки

- Забыть `import 'vuetify/styles'` — компоненты без стилей.
- Нет обёртки `<v-app>` — сломанный layout, тема и оверлеи.
- `import * as components` в production — лишние сотни килобайт.
- Не подключить иконки — пустые места вместо `mdi-*`.
- Ожидать светлую тему по умолчанию в Vuetify 4 — теперь `'system'`.

## Что важно помнить

- `vuetify` + `vite-plugin-vuetify({ autoImport: true })` + `vuetify/styles` + иконки.
- `createVuetify({ theme, defaults, locale, icons })` и `app.use(vuetify)`.
- Всё приложение — внутри `<v-app>`.

## Мини-шпаргалка

- `npm create vuetify@latest`.
- `vuetify({ autoImport: true, styles: { configFile } })`.
- `createVuetify({ theme: { defaultTheme }, defaults: { VBtn: {...} } })`.
- `vuetify/iconsets/mdi-svg` + `@mdi/js`.
