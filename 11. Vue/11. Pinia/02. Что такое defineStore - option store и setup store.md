# Что такое defineStore - option store и setup store

> [!NOTE]
> `defineStore(id, definition)` объявляет стор и возвращает функцию-composable `useXxxStore()`. Первый аргумент — **уникальный id** (используется DevTools, плагинами, SSR-гидрацией). Второй — определение в одном из двух официальных стилей. **Option store** — объект `{ state, getters, actions }`: `state` — функция, возвращающая начальное состояние, `getters` — вычисляемые значения (аналог `computed`, получают `state` аргументом или используют `this`), `actions` — методы с доступом к стору через `this`, могут быть async. **Setup store** — функция в стиле Composition API: `ref`/`reactive` становятся **state**, `computed` — **getters**, функции — **actions**; можно использовать `watch`, другие composables, `inject` (на уровне приложения). Важное правило setup store: **вернуть все** свойства state, иначе они не попадут в DevTools, SSR и плагины (это будет приватное, несериализуемое состояние). У option store есть встроенный `$reset()`, в setup store сброс пишут вручную. Выбор — по стилю команды: setup store гибче, option store проще для старта.

## Вопрос

Что делает `defineStore` и чем отличаются option store и setup store?

## Option store

```ts
export const useCartStore = defineStore('cart', {
  state: () => ({
    items: [] as CartItem[],
    promoCode: null as string | null,
  }),

  getters: {
    count: (state) => state.items.reduce((s, i) => s + i.qty, 0),
    subtotal: (state) => state.items.reduce((s, i) => s + i.price * i.qty, 0),
    total(): number {                                   // getter через this — явный тип возврата
      return this.promoCode ? Math.round(this.subtotal * 0.9) : this.subtotal;
    },
  },

  actions: {
    add(product: Product) {
      const item = this.items.find((i) => i.id === product.id);
      item ? item.qty++ : this.items.push({ id: product.id, title: product.title, price: product.price, qty: 1 });
    },
    async applyPromo(code: string) {
      await api.validatePromo(code);
      this.promoCode = code;
    },
  },
});
```

## Setup store

```ts
export const useCartStore = defineStore('cart', () => {
  const items = ref<CartItem[]>([]);
  const promoCode = ref<string | null>(null);

  const count = computed(() => items.value.reduce((s, i) => s + i.qty, 0));
  const subtotal = computed(() => items.value.reduce((s, i) => s + i.price * i.qty, 0));
  const total = computed(() => (promoCode.value ? Math.round(subtotal.value * 0.9) : subtotal.value));

  function add(product: Product) {
    const item = items.value.find((i) => i.id === product.id);
    item ? item.qty++ : items.value.push({ id: product.id, title: product.title, price: product.price, qty: 1 });
  }

  async function applyPromo(code: string) {
    await api.validatePromo(code);
    promoCode.value = code;
  }

  function $reset() {                       // сброс вручную
    items.value = [];
    promoCode.value = null;
  }

  watch(items, (v) => analytics.track('cart_changed', { count: v.length }), { deep: true });

  return { items, promoCode, count, subtotal, total, add, applyPromo, $reset };   // вернуть ВСЁ состояние
});
```

## Соответствие

| Option store | Setup store |
| --- | --- |
| `state: () => ({ x })` | `const x = ref()` |
| `getters: { y: (s) => ... }` | `const y = computed(() => ...)` |
| `actions: { z() {} }` | `function z() {}` |
| `this.x` | `x.value` |
| `$reset()` встроен | Писать самому |
| — | `watch`, composables, `inject` |

## Что выбрать

| Ситуация | Стиль |
| --- | --- |
| Команда начинает с Pinia, простой CRUD | Option store |
| Проект на Composition API | Setup store |
| Нужны `watch`, VueUse, другие composables внутри | Setup store |
| Нужен встроенный `$reset` | Option store |

## Когда стор создаётся

```ts
import { useCartStore } from '@/stores/cart';   // импорт ничего не создаёт

const cart = useCartStore();                     // первый вызов создаёт стор, следующие возвращают тот же
```

## Частые ошибки

- Одинаковые id у разных сторов — один перезапишет другой.
- В setup store не вернуть часть state — пропадёт из DevTools и SSR.
- Стрелочные функции в `actions` option store — нет `this`.
- Getter через `this` без явного типа возврата в TypeScript.
- Побочные эффекты в getters.

## Что важно помнить

- `defineStore(id, def)` → composable `useXxxStore()`.
- Option store: `state/getters/actions`; setup store: `ref/computed/функции`.
- В setup store возвращайте всё состояние и пишите `$reset` сами.

## Мини-шпаргалка

- `defineStore('id', { state, getters, actions })`.
- `defineStore('id', () => { ...; return {...} })`.
- `ref` → state, `computed` → getter, функция → action.
- Уникальный id.
