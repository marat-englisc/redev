# Как подключить Pinia к Vue проекту

> [!NOTE]
> Pinia подключается как **Vue-плагин**: установить пакет `pinia`, создать экземпляр **`createPinia()`** и зарегистрировать его **`app.use(pinia)`** до `app.mount()`. Экземпляр pinia — это контейнер всех сторов приложения: каждый стор создаётся **лениво** при первом вызове `useXxxStore()` и затем переиспользуется (singleton в пределах pinia). Сторы объявляют функцией `defineStore` в отдельных файлах (обычно `src/stores/`, один стор — один файл, имя `useXxxStore`). Pinia интегрируется с **Vue DevTools** (просмотр и редактирование state, timeline действий), поддерживает **HMR** (`acceptHMRUpdate`), **плагины** (`pinia.use(plugin)` — например, сохранение в localStorage) и **SSR**. В Nuxt Pinia подключают модулем `@pinia/nuxt`, который сам создаёт экземпляр на каждый запрос. Проект, созданный через `npm create vue@latest` с опцией Pinia, уже содержит эту настройку.

## Вопрос

Как подключить Pinia к Vue-проекту и создать первый стор?

## Установка и подключение

```bash
npm install pinia
```

```ts
// main.ts
import { createApp } from 'vue';
import { createPinia } from 'pinia';
import App from './App.vue';

const app = createApp(App);
const pinia = createPinia();

app.use(pinia);          // до mount и до использования сторов в роутере
app.use(router);
app.mount('#app');
```

## Первый стор

```ts
// src/stores/counter.ts
import { defineStore, acceptHMRUpdate } from 'pinia';
import { ref, computed } from 'vue';

export const useCounterStore = defineStore('counter', () => {
  const count = ref(0);
  const double = computed(() => count.value * 2);
  function increment() { count.value++; }
  return { count, double, increment };
});

if (import.meta.hot) {
  import.meta.hot.accept(acceptHMRUpdate(useCounterStore, import.meta.hot));   // HMR без перезагрузки страницы
}
```

## Использование

```vue
<script setup lang="ts">
import { storeToRefs } from 'pinia';
import { useCounterStore } from '@/stores/counter';

const counter = useCounterStore();
const { count, double } = storeToRefs(counter);   // реактивные ref-ы
</script>

<template>
  <button @click="counter.increment()">{{ count }} (×2 = {{ double }})</button>
</template>
```

## Плагины

```ts
pinia.use(({ store }) => {
  store.$onAction(({ name, after, onError }) => {
    const started = performance.now();
    after(() => metrics.timing(`store.${store.$id}.${name}`, performance.now() - started));
    onError((e) => reportError(e));
  });
});
```

## Частые ошибки

- Вызов `useStore()` до `app.use(pinia)` — ошибка «getActivePinia was called with no active Pinia».
- Создавать новый `createPinia()` в нескольких местах — разные контейнеры состояния.
- Один файл со всеми сторами.
- Деструктурировать стор без `storeToRefs`.

## Что важно помнить

- `createPinia()` + `app.use(pinia)` до `mount`.
- Стор создаётся лениво при первом `useXxxStore()` и переиспользуется.
- DevTools, HMR (`acceptHMRUpdate`), плагины и SSR — из коробки.

## Мини-шпаргалка

- `npm i pinia`.
- `app.use(createPinia())`.
- `export const useXStore = defineStore('x', () => {...})`.
- `storeToRefs(store)`.
- Nuxt: `@pinia/nuxt`.
