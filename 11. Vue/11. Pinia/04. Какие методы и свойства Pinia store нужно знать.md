# Какие методы и свойства Pinia store нужно знать

> [!NOTE]
> Помимо собственных state, getters и actions, у каждого стора есть служебный API с префиксом `$`. **`$patch(obj | fn)`** — пакетное изменение state одной операцией (функциональная форма удобна для массивов). **`$reset()`** — сброс к начальному state (встроен только в option store). **`$subscribe((mutation, state) => …, { detached, flush })`** — подписка на изменения state (для сохранения, логирования, синхронизации между вкладками); по умолчанию снимается при размонтировании компонента, с `detached: true` — живёт дольше. **`$onAction(({ name, store, args, after, onError }) => …)`** — перехват вызовов actions (метрики, логирование, обработка ошибок). **`$state`** — всё state (присваивание заменяет его через `$patch`), **`$id`** — id стора, **`$dispose()`** — остановить эффекты стора. Для компонентов ключевая утилита — **`storeToRefs(store)`**: превращает state и getters в ref-ы, чтобы их можно было деструктурировать без потери реактивности (actions деструктурируют напрямую). Для Options API есть хелперы `mapState`, `mapWritableState`, `mapActions`.

## Вопрос

Какие служебные методы и свойства есть у Pinia store и как ими пользоваться?

## storeToRefs

```ts
const cart = useCartStore();

const { items, total } = cart;                 // ✗ значения на момент деструктуризации
const { items, total } = storeToRefs(cart);    // ✓ ref-ы: state и getters
const { add, remove } = cart;                  // ✓ actions привязаны к стору
```

## $patch

```ts
cart.$patch({ promoCode: 'SALE', note: '' });

cart.$patch((state) => {
  state.items.push(newItem);
  state.items = state.items.filter((i) => i.qty > 0);
});
```

## $reset

```ts
// option store
cart.$reset();

// setup store — объявить самостоятельно
function $reset() { items.value = []; promoCode.value = null; }
```

Полезно при выходе пользователя: сбросить все сторы с его данными.

## $subscribe

```ts
cart.$subscribe((mutation, state) => {
  // mutation.type: 'direct' | 'patch object' | 'patch function'
  localStorage.setItem('cart', JSON.stringify(state.items));
}, { detached: true });          // не отписываться при размонтировании компонента
```

```ts
// следить за конкретным полем — обычный watch
watch(() => cart.items.length, (n) => updateTitle(n));
```

## $onAction

```ts
const unsubscribe = cart.$onAction(({ name, args, after, onError }) => {
  const start = Date.now();
  after((result) => console.debug(`${name} ok in ${Date.now() - start}ms`, result));
  onError((error) => reportError(error, { action: name, args }));
});

// позже
unsubscribe();
```

## $state, $id, $dispose

```ts
cart.$id;                    // 'cart'
cart.$state;                 // всё состояние
cart.$state = { items: [], promoCode: null };   // заменяет через $patch
cart.$dispose();             // остановить эффекты стора (редко: тесты, микрофронтенды)
```

## Options API

```js
import { mapState, mapWritableState, mapActions } from 'pinia';

export default {
  computed: {
    ...mapState(useCartStore, ['items', 'total']),
    ...mapWritableState(useCartStore, ['promoCode']),
  },
  methods: {
    ...mapActions(useCartStore, ['add', 'remove']),
  },
};
```

## Сводка

| API | Назначение |
| --- | --- |
| `storeToRefs(store)` | Деструктуризация state/getters без потери реактивности |
| `$patch` | Пакетное изменение |
| `$reset` | Сброс (option store) |
| `$subscribe` | Реакция на изменения state |
| `$onAction` | Перехват actions |
| `$state`, `$id` | Всё состояние, id |
| `$dispose` | Остановка стора |

## Частые ошибки

- Деструктуризация стора без `storeToRefs`.
- `storeToRefs` для actions (они не ref-ы — берите напрямую).
- `$reset` в setup store без собственной реализации.
- Бизнес-логика в `$subscribe`, скрытая от остального кода.
- Подписки без `detached` в компоненте, ожидая, что они переживут размонтирование.

## Что важно помнить

- `storeToRefs` — для state и getters, actions — напрямую.
- `$patch` — пакетно, `$subscribe`/`$onAction` — наблюдение за стором.
- `$reset` встроен только в option store.

## Мини-шпаргалка

- `const { a, b } = storeToRefs(store); const { act } = store`.
- `store.$patch({...})`, `store.$patch((s) => {...})`.
- `store.$subscribe(cb, { detached: true })`.
- `store.$onAction(({ name, after, onError }) => {})`.
