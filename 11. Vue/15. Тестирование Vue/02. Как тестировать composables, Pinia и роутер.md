# Как тестировать composables, Pinia и роутер

> [!NOTE]
> **Composables** без lifecycle-хуков и `inject` — обычные функции: их вызывают прямо в тесте и проверяют возвращаемые ref-ы. Если composable использует `onMounted`/`onUnmounted` или `inject`, ему нужен экземпляр компонента — его вызывают внутри **тестового компонента-хоста** (или хелпера `withSetup`), а для чистых реактивных эффектов достаточно `effectScope()`. **Pinia** в unit-тестах стора: перед каждым тестом `setActivePinia(createPinia())` — новый изолированный стор, затем вызываются actions и проверяются state и getters (API-модули мокают). В компонентных тестах используют **`createTestingPinia()`** из `@pinia/testing`: actions по умолчанию заменены шпионами `vi.fn` (`stubActions: false` — выполнять настоящие), начальное состояние задаётся через `initialState`, а getters можно переопределять напрямую. **Роутер**: либо создать **настоящий роутер** с `createMemoryHistory()`, тестовыми маршрутами и дождаться `router.isReady()` — тогда проверяются реальная навигация и guards; либо **замокать** `useRoute`/`useRouter` через `vi.mock('vue-router')` для изолированных компонентов; `RouterLink` в простых случаях заменяют заглушкой. Guards тестируют как функции или через настоящий роутер с проверкой `router.currentRoute.value`.

## Вопрос

Как тестировать composables, Pinia stores и компоненты, использующие Vue Router?

## Простой composable

```ts
// useCounter.ts
export function useCounter(initial = 0) {
  const count = ref(initial);
  const double = computed(() => count.value * 2);
  const increment = () => count.value++;
  return { count, double, increment };
}

// useCounter.test.ts
it('увеличивает счётчик', () => {
  const { count, double, increment } = useCounter(2);
  increment();
  expect(count.value).toBe(3);
  expect(double.value).toBe(6);
});
```

## Composable с хуками жизненного цикла

```ts
// test-utils/withSetup.ts
import { createApp, type App } from 'vue';

export function withSetup<T>(composable: () => T, plugins: Array<(app: App) => void> = []) {
  let result!: T;
  const app = createApp({
    setup() {
      result = composable();
      return () => null;
    },
  });
  plugins.forEach((install) => install(app));
  app.mount(document.createElement('div'));
  return [result, app] as const;
}
```

```ts
it('снимает слушатель при размонтировании', () => {
  const remove = vi.spyOn(window, 'removeEventListener');
  const [{ width }, app] = withSetup(() => useWindowWidth());

  expect(width.value).toBe(window.innerWidth);
  app.unmount();
  expect(remove).toHaveBeenCalledWith('resize', expect.any(Function));
});
```

```ts
// только реактивность (watch, computed) — effectScope
it('debounce-поиск', async () => {

  const scope = effectScope();
```

## Unit-тесты Pinia store

```ts
import { setActivePinia, createPinia } from 'pinia';
import { useCartStore } from '@/stores/cart';
import * as api from '@/api/cart';

vi.mock('@/api/cart');

describe('cart store', () => {
  beforeEach(() => setActivePinia(createPinia()));       // новый стор на каждый тест

  it('считает итог', () => {
    const cart = useCartStore();
    cart.items = [{ id: 1, price: 100, qty: 2 }, { id: 2, price: 50, qty: 1 }];
    expect(cart.total).toBe(250);
  });

  it('добавляет товар через API', async () => {
    vi.mocked(api.addItem).mockResolvedValue({ id: 3, price: 30, qty: 1 });
    const cart = useCartStore();
    await cart.add(3);
    expect(cart.items).toHaveLength(1);
    expect(api.addItem).toHaveBeenCalledWith(3);
  });
});
```

## Pinia в компонентных тестах

```ts
import { createTestingPinia } from '@pinia/testing';

it('кнопка вызывает action', async () => {
  const wrapper = mount(AddToCartButton, {
    props: { productId: 7 },
    global: {
      plugins: [createTestingPinia({ createSpy: vi.fn, initialState: { cart: { items: [] } } })],
    },
  });

  const cart = useCartStore();                       // тот же тестовый стор
  await wrapper.get('button').trigger('click');
  expect(cart.add).toHaveBeenCalledWith(7);          // action — шпион, не выполняется
});

it('показывает счётчик из getter', () => {
  const wrapper = mount(CartBadge, { global: { plugins: [createTestingPinia({ createSpy: vi.fn })] } });
  const cart = useCartStore();
  // @ts-expect-error — переопределение getter в тестах
  cart.count = 5;
  // ...
});
```

| Опция `createTestingPinia` | Смысл |
| --- | --- |
| `createSpy: vi.fn` | Функция-шпион (с `globals: true` не нужна) |
| `initialState` | Начальное состояние сторов по id |
| `stubActions: false` | Выполнять настоящие actions |
| `plugins` | Подключить плагины Pinia (persisted state и т. п.) |

## Настоящий роутер

```ts
import { createRouter, createMemoryHistory } from 'vue-router';

function makeRouter() {
  return createRouter({
    history: createMemoryHistory(),
    routes: [
      { path: '/', component: { template: '<div>home</div>' } },
      { path: '/product/:id', name: 'product', component: ProductPage, props: true },
      { path: '/login', name: 'login', component: { template: '<div>login</div>' } },
    ],
  });
}

it('открывает страницу товара по ссылке', async () => {
  const router = makeRouter();
  router.push('/');
  await router.isReady();

  const wrapper = mount(App, { global: { plugins: [router] } });
  await wrapper.get('a[href="/product/42"]').trigger('click');
  await flushPromises();

  expect(router.currentRoute.value.params.id).toBe('42');
});
```

## Тест guard-а

```ts
it('перенаправляет гостя на login', async () => {
  const router = makeRouter();
  setActivePinia(createPinia());
  installAuthGuard(router);                          // функция, регистрирующая beforeEach

  await router.push('/account');
  expect(router.currentRoute.value.name).toBe('login');
  expect(router.currentRoute.value.query.redirect).toBe('/account');
});
```

## Мок useRoute / useRouter

```ts
const push = vi.fn();
vi.mock('vue-router', async (importOriginal) => ({
  ...(await importOriginal<typeof import('vue-router')>()),
  useRoute: () => ({ params: { id: '42' }, query: {} }),
  useRouter: () => ({ push }),
}));

it('переходит в корзину после добавления', async () => {
  const wrapper = mount(ProductPage, { global: { plugins: [createTestingPinia({ createSpy: vi.fn })] } });
  await wrapper.get('[data-testid="buy"]').trigger('click');
  expect(push).toHaveBeenCalledWith({ name: 'cart' });
});
```

| Подход | Когда |
| --- | --- |
| Настоящий роутер + `createMemoryHistory` | Навигация, guards, интеграция страниц |
| Мок `useRoute`/`useRouter` | Изолированный компонент, нужен только params или проверка `push` |
| Заглушка `RouterLink` | Компонент со ссылками, навигация не важна |

## Частые ошибки

- Один экземпляр Pinia на все тесты — состояние «протекает» между тестами.
- Ждать выполнения action при `createTestingPinia` без `stubActions: false`.
- Не дождаться `router.isReady()` перед монтированием.
- Вызывать composable с `onMounted` вне компонента — предупреждение и хук не сработает.
- Мокать то, что проще использовать по-настоящему (небольшой роутер, реальные утилиты).

## Что важно помнить

- Простые composables — как функции; с хуками — через хост-компонент.
- Pinia: `setActivePinia(createPinia())` для сторов, `createTestingPinia` для компонентов.
- Роутер: настоящий с memory history или мок `useRoute`/`useRouter`.

## Мини-шпаргалка

- `withSetup(() => useX())`, `effectScope().run(...)`.
- `beforeEach(() => setActivePinia(createPinia()))`.
- `createTestingPinia({ createSpy: vi.fn, initialState, stubActions })`.
- `createRouter({ history: createMemoryHistory(), routes })` + `await router.isReady()`.
- `vi.mock('vue-router', ...)`.
