# Как использовать TypeScript во Vue

> [!NOTE]
> Vue 3 написан на TypeScript и хорошо его поддерживает. В SFC включают `<script setup lang="ts">`; проверку типов выполняет **`vue-tsc`** (обёртка над `tsc`, понимающая `.vue`), а в редакторе — расширение **Vue (Official)** (Volar). Vite только **транспилирует** TS без проверки типов, поэтому `vue-tsc --noEmit` запускают в CI и в скрипте сборки. Основные приёмы: props и события типизируются **в макросах** (`defineProps<{...}>()`, `defineEmits<{...}>()`, `defineModel<T>()`), `ref<T>()` — для значений, тип которых нельзя вывести (`ref<User | null>(null)`), `computed` выводит тип сам, template refs — `useTemplateRef<HTMLInputElement>()` или `InstanceType<typeof Comp>` для компонентов, provide/inject — `InjectionKey<T>`, события DOM — явный тип параметра (`(e: KeyboardEvent)`), generic-компоненты — `<script setup generic="T">`, глобальные свойства и компоненты — расширение модуля `vue` (`ComponentCustomProperties`, `GlobalComponents`). Pinia и Vue Router также полностью типизированы (типизированные маршруты — через `unplugin-vue-router`/Vue Router 4.4+ или Nuxt).

## Вопрос

Как использовать TypeScript во Vue-проекте?

## Настройка

```bash
npm create vue@latest     # выбрать TypeScript
```

```json
// package.json
{
  "scripts": {
    "dev": "vite",
    "build": "vue-tsc --build && vite build",
    "type-check": "vue-tsc --build --force"
  }
}
```

`tsconfig` от `create-vue` наследует `@vue/tsconfig/tsconfig.dom.json` — с `strict`, `verbatimModuleSyntax`, `moduleResolution: bundler`.

## Компонент

```vue
<script setup lang="ts">
import type { Product } from '@/types';

const props = defineProps<{ product: Product; quantity?: number }>();
const emit = defineEmits<{ add: [id: string, qty: number] }>();
const note = defineModel<string>('note', { default: '' });

const qty = ref(props.quantity ?? 1);                  // Ref<number> — выведено
const user = ref<User | null>(null);                   // явный тип
const total = computed(() => props.product.price * qty.value);   // ComputedRef<number>

const input = useTemplateRef<HTMLInputElement>('qtyInput');

function onKey(e: KeyboardEvent) {
  if (e.key === 'Enter') emit('add', props.product.id, qty.value);
}
</script>
```

## Импорт типов в макросы

```ts
import type { ButtonProps } from './types';
const props = defineProps<ButtonProps & { loading?: boolean }>();   // 3.3+
```

## Типы ref на компоненты

```ts
import Modal from './Modal.vue';
const modal = useTemplateRef<InstanceType<typeof Modal>>('modal');
modal.value?.open();                    // типы из defineExpose
```

## provide / inject

```ts
export const UserKey: InjectionKey<Ref<User | null>> = Symbol('user');
provide(UserKey, user);
const injected = inject(UserKey);       // Ref<User | null> | undefined
```

## Generic-компонент

```vue
<script setup lang="ts" generic="T extends { id: string }">
defineProps<{ items: T[]; selected?: T }>();
defineEmits<{ select: [item: T] }>();
</script>
```

```vue
<ItemList :items="products" @select="(p) => p.price" />   <!-- p: Product -->
```

## Глобальные расширения

```ts
// src/types/vue.d.ts
import type { ToastApi } from '@/plugins/toast';

declare module 'vue' {
  interface ComponentCustomProperties { $toast: ToastApi }
  interface GlobalComponents { BaseButton: typeof import('@/components/BaseButton.vue')['default'] }
}

// типизированные meta маршрутов
declare module 'vue-router' {
  interface RouteMeta { requiresAuth?: boolean; layout?: 'default' | 'blank' }
}
export {};
```

## Типизированные props для Options API

```ts
export default defineComponent({
  props: { items: { type: Array as PropType<Product[]>, required: true } },
  computed: {
    total(): number { return this.items.reduce((s, p) => s + p.price, 0); },   // явный тип возврата
  },
});
```

## Утилиты типов

```ts
import type { ComponentProps, ComponentExposed } from 'vue-component-type-helpers';
type ModalProps = ComponentProps<typeof Modal>;
```

```ts
import type { MaybeRefOrGetter, Ref, ComputedRef, PropType } from 'vue';
```

## Частые ошибки

- Не запускать `vue-tsc` — ошибки типов в `.vue` не ловятся сборкой Vite.
- `ref(null)` без типа.
- `any` в событиях DOM вместо конкретных типов.
- Слишком сложные условные типы в `defineProps`.
- Импортировать тип без `import type` при `verbatimModuleSyntax`.

## Что важно помнить

- `lang="ts"` + `vue-tsc` в CI + Vue (Official) в редакторе.
- Типы — в макросах, явные дженерики для `ref` без вывода.
- `InjectionKey`, `InstanceType<typeof C>`, `generic`, расширение модулей `vue` и `vue-router`.

## Мини-шпаргалка

- `defineProps<P>()`, `defineEmits<{ e: [T] }>()`, `defineModel<T>()`.
- `ref<T | null>(null)`, `useTemplateRef<HTMLElement>('x')`.
- `InjectionKey<T>`, `PropType<T>`.
- `vue-tsc --build`.
