# Как сделать компонент-обёртку и layout component

> [!NOTE]
> **Компонент-обёртка (wrapper)** добавляет поведение или оформление вокруг другого компонента или элемента, сохраняя его интерфейс: `AppButton` поверх `<button>` или UI-библиотеки, `FormInput` поверх `<input>` с подписью и ошибкой, `RouterButton` поверх `RouterLink`. Чтобы обёртка была «прозрачной», она **пробрасывает** атрибуты и события (`v-bind="$attrs"`, `inheritAttrs: false`), **модель** (`defineModel`), **слоты** (в том числе все слоты обёрнутого компонента через `v-for="(_, name) in $slots"`) и, если нужно, методы через `defineExpose`. **Layout-компонент** задаёт **структуру страницы** (шапка, боковая панель, контент, подвал) через именованные слоты и не содержит бизнес-логики; в SPA layout обычно выбирается в зависимости от маршрута (`route.meta.layout`), в Nuxt есть встроенная система `layouts/`. Обёртки позволяют один раз зафиксировать дизайн-систему и заменить библиотеку компонентов, не переписывая всё приложение.

## Вопрос

Как сделать прозрачный компонент-обёртку и layout-компонент во Vue?

## Обёртка над компонентом библиотеки

```vue
<!-- AppTextField.vue — обёртка над VTextField -->
<script setup lang="ts">
defineOptions({ inheritAttrs: false });
const model = defineModel<string>();
const props = withDefaults(defineProps<{ label: string; dense?: boolean }>(), { dense: true });
</script>

<template>
  <VTextField
    v-model="model"
    :label="label"
    :density="props.dense ? 'compact' : 'default'"
    variant="outlined"
    v-bind="$attrs"
  >
    <!-- пробросить все слоты обёрнутого компонента -->
    <template v-for="(_, name) in $slots" #[name]="slotProps">
      <slot :name="name" v-bind="slotProps ?? {}" />
    </template>
  </VTextField>
</template>
```

```vue
<AppTextField v-model="email" label="Email" type="email" :rules="[required]" @blur="touch">
  <template #prepend-inner><IconMail /></template>
</AppTextField>
```

`type`, `rules`, `@blur` и слот `prepend-inner` дойдут до `VTextField`, а дизайн-решения (`variant`, `density`) зафиксированы в обёртке.

## Обёртка над нативным элементом

```vue
<!-- AppButton.vue -->
<script setup lang="ts">
const props = withDefaults(defineProps<{ variant?: 'primary' | 'ghost'; loading?: boolean; to?: RouteLocationRaw }>(), {
  variant: 'primary',
});
const tag = computed(() => (props.to ? RouterLink : 'button'));
</script>

<template>
  <component :is="tag" :to="to" class="btn" :class="[`btn--${variant}`, { 'is-loading': loading }]" :disabled="loading || undefined">
    <Spinner v-if="loading" class="btn__spinner" />
    <slot />
  </component>
</template>
```

## Проброс методов

```ts
const inner = useTemplateRef<InstanceType<typeof VTextField>>('inner');
defineExpose({ focus: () => inner.value?.focus() });
```

## Layout-компонент

```vue
<!-- layouts/DefaultLayout.vue -->
<template>
  <div class="layout">
    <AppHeader />
    <div class="layout__body">
      <aside v-if="$slots.sidebar" class="layout__sidebar"><slot name="sidebar" /></aside>
      <main class="layout__main"><slot /></main>
    </div>
    <AppFooter />
  </div>
</template>
```

## Layout по маршруту

```ts
// router
{ path: '/login', component: () => import('@/pages/Login.vue'), meta: { layout: 'blank' } },
{ path: '/admin', component: () => import('@/pages/Admin.vue'), meta: { layout: 'admin' } },
```

```vue
<!-- App.vue -->
<script setup lang="ts">
const layouts = {
  default: DefaultLayout,
  blank: BlankLayout,
  admin: defineAsyncComponent(() => import('@/layouts/AdminLayout.vue')),
};
const route = useRoute();
const layout = computed(() => layouts[(route.meta.layout as keyof typeof layouts) ?? 'default']);
</script>

<template>
  <component :is="layout">
    <RouterView />
  </component>
</template>
```

Альтернатива — вложенные маршруты: родительский маршрут с layout-компонентом и `<RouterView />` внутри. В Nuxt — `layouts/` и `definePageMeta({ layout })`.

## Что пробросить в прозрачной обёртке

| Что | Как |
| --- | --- |
| Атрибуты и события | `inheritAttrs: false` + `v-bind="$attrs"` |
| Модель | `defineModel()` → `v-model` на внутреннем компоненте |
| Слоты | `v-for="(_, name) in $slots"` + `#[name]` |
| Методы | `defineExpose` |
| Типы props | Расширить props обёрнутого компонента (`ComponentProps<typeof X>`) |

## Частые ошибки

- Обёртка «съедает» атрибуты и события — нет `v-bind="$attrs"`.
- Пробрасывать слоты вручную по одному и забывать новые.
- Бизнес-логика в layout-компоненте.
- Layout пересоздаётся при каждом переходе из-за нового объекта компонента в `computed` (используйте стабильные ссылки).

## Что важно помнить

- Прозрачная обёртка пробрасывает атрибуты, модель, слоты и методы.
- Обёртки фиксируют дизайн-систему и изолируют библиотеку компонентов.
- Layout — структура страницы через слоты, выбор — по маршруту.

## Мини-шпаргалка

- `defineOptions({ inheritAttrs: false })` + `v-bind="$attrs"`.
- `<template v-for="(_, name) in $slots" #[name]="p"><slot :name="name" v-bind="p ?? {}" /></template>`.
- `route.meta.layout` + `<component :is="layout">`.
- `defineExpose({ focus })`.
