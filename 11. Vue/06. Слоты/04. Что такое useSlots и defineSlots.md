# Что такое useSlots и defineSlots

> [!NOTE]
> **`useSlots()`** возвращает в `<script setup>` объект слотов компонента — тот же, что `$slots` в шаблоне: каждый переданный слот — функция, которая при вызове возвращает массив VNode (`slots.default?.()`); непереданные слоты отсутствуют. Его используют, чтобы **проверить наличие** слота (рендерить обёртку, отступы, разделители только при наличии содержимого), чтобы **вызвать слот в render-функции** или чтобы проанализировать содержимое (редко, например для компонентов-групп). Объект слотов **не реактивен** для `watch`, но всегда актуален при рендере. **`defineSlots<T>()`** (Vue 3.3+) — макрос компилятора, который **объявляет типы** слотов и их props: родитель получает автодополнение и проверку slot props, а внутри компонента — типизированный объект слотов (это то же, что возвращает `useSlots`). Макрос не влияет на рантайм. Вместе с generic-компонентами (`<script setup generic="T">`) он позволяет строить полностью типизированные списки, таблицы и селекты.

## Вопрос

Что делают `useSlots()` и `defineSlots()` и когда они нужны?

## useSlots: условная разметка

```vue
<!-- FormField.vue -->
<script setup lang="ts">
defineProps<{ label: string; error?: string }>();
const slots = useSlots();
const hasHint = computed(() => !!slots.hint);    // вычисляется при рендере
</script>

<template>
  <div class="field" :class="{ 'field--with-hint': hasHint }">
    <label>{{ label }}</label>
    <slot />
    <p v-if="slots.hint" class="field__hint"><slot name="hint" /></p>
    <p v-if="error" class="field__error">{{ error }}</p>
  </div>
</template>
```

В шаблоне то же самое доступно как `$slots.hint`.

## Вызов слота в render-функции

```ts
const ButtonGroup = defineComponent({
  setup(_, { slots }) {
    return () => {
      const buttons = slots.default?.() ?? [];
      return h('div', { class: 'group' }, buttons.flatMap((vnode, i) => (i ? [h('span', { class: 'sep' }), vnode] : [vnode])));
    };
  },
});
```

## Проверка «пустого» содержимого

```ts
import { Comment, Text, type VNode } from 'vue';

function hasContent(vnodes: VNode[] = []): boolean {
  return vnodes.some((v) => v.type !== Comment && !(v.type === Text && !String(v.children).trim()));
}

const showFooter = computed(() => hasContent(slots.footer?.()));
```

Нужно, если родитель может передать слот с одним `v-if="false"` или пробелами.

## defineSlots: типизация

```vue
<!-- SelectList.vue -->
<script setup lang="ts" generic="T extends { id: string | number }">
const props = defineProps<{ options: T[] }>();
const selected = defineModel<T | null>({ default: null });

const slots = defineSlots<{
  option(props: { option: T; selected: boolean; select: () => void }): any;
  empty?(): any;                                   // необязательный слот
}>();
</script>

<template>
  <ul role="listbox">
    <li v-for="o in options" :key="o.id" role="option" :aria-selected="selected?.id === o.id">
      <slot name="option" :option="o" :selected="selected?.id === o.id" :select="() => (selected = o)" />
    </li>
  </ul>
  <slot v-if="!options.length" name="empty" />
</template>
```

```vue
<SelectList v-model="city" :options="cities">
  <template #option="{ option, selected, select }">   <!-- option: City — тип выведен -->
    <button :class="{ active: selected }" @click="select">{{ option.name }}</button>
  </template>
</SelectList>
```

## useSlots и defineSlots

| | `useSlots()` | `defineSlots<T>()` |
| --- | --- | --- |
| Что даёт | Объект слотов в рантайме | Типы слотов + тот же объект |
| Влияет на рантайм | — (просто доступ) | Нет (макрос) |
| Версия | 3.0+ | 3.3+ |
| Когда | Проверить наличие, render-функции | Типизировать API слотов компонента |

## Частые ошибки

- Вызывать слоты (`slots.default()`) в `setup` вне рендера — содержимое не будет обновляться.
- `watch(slots.default, ...)` — объект слотов не отслеживается.
- `slots.footer` без `?.` — слот может отсутствовать.
- Ожидать, что `defineSlots` проверит что-то в рантайме.

## Что важно помнить

- `useSlots()` = `$slots`: функции слотов, отсутствуют, если не переданы.
- Проверки наличия — при рендере (шаблон или computed).
- `defineSlots` — типы слотов и slot props, вместе с `generic`.

## Мини-шпаргалка

- `const slots = useSlots()`, `v-if="slots.x"`.
- `slots.default?.()` в render-функции.
- `defineSlots<{ name(props: P): any; opt?(): any }>()`.
- `<script setup generic="T">`.
