# Что такое именованные слоты

> [!NOTE]
> Если компоненту нужно несколько мест для вставки содержимого — шапка, тело, подвал, иконка, действия, — используют **именованные слоты**: `<slot name="header" />`, `<slot name="footer" />` и default-слот без имени. Родитель передаёт содержимое через `<template v-slot:header>` или короче **`<template #header>`**; всё, что лежит вне `<template #...>`, попадает в default-слот. Имя слота может быть **динамическим** (`<template #[slotName]>`) — удобно для таблиц с кастомизируемыми колонками (`#cell-price`) и мастеров с шагами. У каждого слота может быть свой fallback. Именованные слоты делают компоненты-«каркасы» (модальное окно, карточка, layout страницы, поле формы с подписью и подсказкой) гибкими без десятков props. Наличие конкретного слота проверяют через `useSlots()` / `$slots.name`, чтобы не рендерить пустые обёртки.

## Вопрос

Для чего нужны именованные слоты и как их использовать?

## Модальное окно

```vue
<!-- BaseModal.vue -->
<script setup lang="ts">
const open = defineModel<boolean>('open', { default: false });
const slots = useSlots();
</script>

<template>
  <Teleport to="body">
    <div v-if="open" class="backdrop" @click.self="open = false">
      <div class="modal" role="dialog" aria-modal="true">
        <header class="modal__header">
          <slot name="header"><h2>Подтверждение</h2></slot>
          <button aria-label="Закрыть" @click="open = false">×</button>
        </header>

        <div class="modal__body"><slot /></div>

        <footer v-if="slots.footer" class="modal__footer">
          <slot name="footer" :close="() => (open = false)" />
        </footer>
      </div>
    </div>
  </Teleport>
</template>
```

```vue
<BaseModal v-model:open="confirmOpen">
  <template #header><h2>Удалить заказ?</h2></template>

  Действие нельзя отменить.                    <!-- default-слот -->

  <template #footer="{ close }">
    <button @click="close">Отмена</button>
    <button class="danger" @click="removeOrder(); close()">Удалить</button>
  </template>
</BaseModal>
```

## Layout страницы

```vue
<!-- PageLayout.vue -->
<template>
  <div class="layout">
    <header><slot name="header" /></header>
    <aside v-if="$slots.sidebar"><slot name="sidebar" /></aside>
    <main><slot /></main>
    <footer><slot name="footer">© 2026</slot></footer>
  </div>
</template>
```

```vue
<PageLayout>
  <template #header><AppNav /></template>
  <template #sidebar><CatalogFilters /></template>
  <ProductGrid :items="items" />
</PageLayout>
```

## Динамические имена

```vue
<!-- DataTable.vue: слот для ячейки каждой колонки -->
<td v-for="col in columns" :key="col.key">
  <slot :name="`cell-${col.key}`" :row="row" :value="row[col.key]">{{ row[col.key] }}</slot>
</td>
```

```vue
<DataTable :columns="columns" :rows="orders">
  <template #cell-status="{ value }"><StatusBadge :status="value" /></template>
  <template #[`cell-${moneyColumn}`]="{ value }">{{ formatMoney(value) }}</template>
</DataTable>
```

## Синтаксис

| Запись | Значение |
| --- | --- |
| `<template v-slot:header>` | Полная форма |
| `<template #header>` | Сокращение |
| `<template #[name]>` | Динамическое имя |
| `<template #footer="{ close }">` | Именованный scoped slot |
| Содержимое вне `<template #...>` | Default-слот |

## Именованные слоты или props

```vue
<!-- prop для простого текста -->
<BaseCard title="Профиль" />

<!-- слот для сложного заголовка -->
<BaseCard>
  <template #title><Avatar :src="u.avatar" /> {{ u.name }} <Badge>PRO</Badge></template>
</BaseCard>
```

Часто компонент поддерживает оба варианта: prop `title` и слот `#title` с prop в качестве fallback.

## Частые ошибки

- `v-slot`/`#` на обычном элементе (`<div #header>`) — допустимо только на `<template>` или на самом компоненте (для default/единственного слота).
- Смешивать содержимое default-слота и `<template #default>` одновременно.
- Пустые обёртки `<header>`, когда слот не передан.
- Опечатка в имени слота — содержимое молча не отрисуется.

## Что важно помнить

- `<slot name="x" />` в ребёнке ↔ `<template #x>` в родителе.
- Содержимое вне именованных шаблонов идёт в default.
- Динамические имена — `#[name]`; проверка наличия — `$slots.x`.

## Мини-шпаргалка

- `<slot name="header">fallback</slot>`.
- `<template #header>...</template>`.
- `<template #[dynamic]>`.
- `v-if="$slots.footer"`.
