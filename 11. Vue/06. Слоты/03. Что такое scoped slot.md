# Что такое scoped slot

> [!NOTE]
> **Scoped slot** (слот с областью видимости) позволяет дочернему компоненту **передать данные в содержимое слота**, которое предоставляет родитель. Ребёнок передаёт их как атрибуты слота — `<slot :item="item" :index="i" />`, — а родитель получает объект **slot props** через `v-slot="props"` / `#default="{ item, index }"` (с деструктуризацией). Так разделяются обязанности: ребёнок владеет **данными и логикой** (загрузка, сортировка, пагинация, состояние открытия, выбор), а родитель решает, **как отрисовать** каждый элемент. Классические примеры — список/таблица с кастомной строкой, `RouterLink` (`v-slot="{ href, navigate, isActive }"`), `RouterView` (`v-slot="{ Component }"`), компоненты-поставщики логики без собственной разметки (renderless components), headless UI-библиотеки. Во многих случаях renderless-компоненты сегодня заменяют **composables**, но scoped slots остаются лучшим способом настроить разметку внутри чужого компонента.

## Вопрос

Что такое scoped slot и когда его использовать?

## Список с кастомной разметкой элемента

```vue
<!-- PaginatedList.vue -->
<script setup lang="ts" generic="T extends { id: string }">
const props = defineProps<{ items: T[]; pageSize?: number }>();
const page = ref(1);
const size = computed(() => props.pageSize ?? 10);
const pageItems = computed(() => props.items.slice((page.value - 1) * size.value, page.value * size.value));
const pages = computed(() => Math.ceil(props.items.length / size.value));

defineSlots<{
  default(props: { item: T; index: number }): any;
  empty(): any;
}>();
</script>

<template>
  <ul v-if="items.length">
    <li v-for="(item, index) in pageItems" :key="item.id">
      <slot :item="item" :index="index" />
    </li>
  </ul>
  <slot v-else name="empty">Пусто</slot>

  <nav v-if="pages > 1">
    <button :disabled="page === 1" @click="page--">Назад</button>
    {{ page }} / {{ pages }}
    <button :disabled="page === pages" @click="page++">Вперёд</button>
  </nav>
</template>
```

```vue
<PaginatedList :items="users" :page-size="20">
  <template #default="{ item, index }">
    <UserRow :user="item" :striped="index % 2 === 1" />
  </template>
  <template #empty>Пользователей нет — <a @click="invite">пригласить</a></template>
</PaginatedList>
```

Пагинация живёт в компоненте, разметка строки — у родителя.

## Сокращение для единственного default-слота

```vue
<MouseTracker v-slot="{ x, y }">
  Курсор: {{ x }}, {{ y }}
</MouseTracker>
```

## Renderless-компонент

```vue
<!-- MouseTracker.vue -->
<script setup>
const x = ref(0);
const y = ref(0);
useEventListener(window, 'mousemove', (e) => { x.value = e.pageX; y.value = e.pageY; });
</script>

<template>
  <slot :x="x" :y="y" />
</template>
```

То же самое как composable: `const { x, y } = useMouse()` — короче и без лишнего компонента. Renderless-компонент оправдан, когда логика тесно связана с местом в шаблоне.

## Встроенные scoped slots

```vue
<RouterLink v-slot="{ href, navigate, isActive }" to="/cart" custom>
  <a :href="href" :class="{ active: isActive }" @click="navigate">Корзина</a>
</RouterLink>

<RouterView v-slot="{ Component, route }">
  <Transition :name="route.meta.transition ?? 'fade'">
    <component :is="Component" />
  </Transition>
</RouterView>
```

## Именованный scoped slot

```vue
<!-- ребёнок -->
<slot name="actions" :item="item" :remove="() => remove(item.id)" />

<!-- родитель -->
<template #actions="{ item, remove }">
  <button @click="edit(item)">Изменить</button>
  <button @click="remove">Удалить</button>
</template>
```

## Типизация

`defineSlots<{ default(props: { item: T }): any }>()` (Vue 3.3+) даёт типы slot props в родителе; с `generic="T"` тип элемента выводится из переданных props.

## Частые ошибки

- Ожидать, что slot props доступны вне `<template #...>`.
- Передавать в слот изменяемое состояние и мутировать его у родителя вместо функций (`remove`, `toggle`).
- Делать renderless-компонент там, где хватит composable.
- Атрибут `name` среди slot props — он зарезервирован под имя слота.

## Что важно помнить

- Scoped slot передаёт данные ребёнка в разметку родителя.
- Ребёнок — данные и логика, родитель — отображение.
- `defineSlots` + `generic` — типобезопасные slot props.

## Мини-шпаргалка

- Ребёнок: `<slot :item="item" :index="i" />`.
- Родитель: `<template #default="{ item, index }">`.
- Единственный слот: `<Comp v-slot="{ x }">`.
- `defineSlots<{ default(p: { item: T }): any }>()`.
