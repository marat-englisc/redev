# Что такое слоты и default слот

> [!NOTE]
> **Слот** — место в шаблоне компонента, куда родитель вставляет **свою разметку**. Компонент объявляет `<slot />`, а всё, что родитель поместил между открывающим и закрывающим тегом компонента, отрендерится на этом месте. Так строят гибкие компоненты: карточки, модальные окна, кнопки с иконками, layout-обёртки — компонент отвечает за структуру и поведение, родитель — за содержимое. Слот без имени — **default** (неявно `#default`); содержимое внутри `<slot>...</slot>` — **fallback**, показывается, если родитель ничего не передал. Важное правило **области видимости**: содержимое слота компилируется в **контексте родителя** — оно видит данные родителя, но не внутреннее состояние ребёнка; чтобы передать данные ребёнка в слот, используют [scoped slots](<03. Что такое scoped slot.md>). Для нескольких мест вставки — [именованные слоты](<02. Что такое именованные слоты.md>). Проверить, передан ли слот, можно через `$slots.default` / `useSlots()`.

## Вопрос

Что такое слоты во Vue и как работает слот по умолчанию?

## Базовый слот

```vue
<!-- BaseButton.vue -->
<template>
  <button class="btn">
    <slot>Нажмите</slot>       <!-- fallback, если содержимое не передано -->
  </button>
</template>
```

```vue
<BaseButton>Сохранить</BaseButton>                       <!-- «Сохранить» -->
<BaseButton><IconSave /> Сохранить</BaseButton>          <!-- любая разметка и компоненты -->
<BaseButton />                                            <!-- «Нажмите» -->
```

## Область видимости

```vue
<!-- родитель -->
<script setup>
const userName = ref('Анна');
</script>

<template>
  <BaseCard>
    Привет, {{ userName }}         <!-- ✓ данные родителя -->
    {{ internalState }}            <!-- ✗ состояние BaseCard здесь недоступно -->
  </BaseCard>
</template>
```

## Карточка со слотом

```vue
<!-- BaseCard.vue -->
<script setup lang="ts">
defineProps<{ title: string; padded?: boolean }>();
</script>

<template>
  <section class="card" :class="{ 'card--padded': padded }">
    <h3>{{ title }}</h3>
    <div class="card__body">
      <slot />
    </div>
  </section>
</template>
```

```vue
<BaseCard title="Доставка" padded>
  <p>Курьером — завтра.</p>
  <DeliveryMap :address="address" />
</BaseCard>
```

## Явный default

```vue
<BaseCard title="Отзывы">
  <template #default>
    <ReviewList :items="reviews" />
  </template>
</BaseCard>
```

Явный `#default` нужен, когда в компоненте есть и именованные слоты, а также для scoped default-слота.

## Условная обёртка

```vue
<!-- BaseCard.vue -->
<script setup>
const slots = useSlots();
</script>

<template>
  <section class="card">
    <slot />
    <footer v-if="slots.footer" class="card__footer">   <!-- футер только если слот передан -->
      <slot name="footer" />
    </footer>
  </section>
</template>
```

## Слоты и props

| Props | Слот |
| --- | --- |
| Данные (строка, число, объект) | Разметка и компоненты |
| Компонент сам решает, как отобразить | Родитель решает, что отобразить |
| `title="Доставка"` | `<template #title><Icon /> Доставка</template>` |

Если вариантов отображения много и они непредсказуемы — слот; если формат фиксирован — prop.

## Частые ошибки

- Пытаться использовать в содержимом слота переменные ребёнка без scoped slot.
- Передавать разметку строками через prop + `v-html` вместо слота.
- Оборачивать слот в элемент, который отрисуется пустым, когда содержимого нет (проверяйте `slots.x`).
- Ожидать, что fallback покажется при пустой строке или комментарии — пробелы и комментарии считаются отсутствием содержимого, но текст — нет.

## Что важно помнить

- `<slot />` — место для разметки родителя; без имени — default.
- Содержимое слота видит данные родителя, не ребёнка.
- Fallback — внутри `<slot>`, проверка наличия — `useSlots()`.

## Мини-шпаргалка

- Ребёнок: `<slot>fallback</slot>`.
- Родитель: `<Comp>содержимое</Comp>` или `<template #default>`.
- `useSlots()`, `$slots.default`.
- Данные ребёнка → scoped slot.
