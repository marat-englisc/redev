# Как настроить storage, key и pick в persisted state

> [!NOTE]
> Объект `persist` позволяет точно контролировать, **что, где и под каким ключом** сохраняется. **`key`** — имя записи в хранилище (по умолчанию id стора; удобно задавать префикс приложения и версию схемы: `myapp:settings:v2`). **`storage`** — синхронное хранилище с интерфейсом `getItem/setItem` (`localStorage` по умолчанию, `sessionStorage`, своё — например, обёртка над cookies или зашифрованное хранилище). **`pick`** — список путей (в том числе вложенных через точку: `'filters.sort'`), которые нужно сохранять; `pick: []` — не сохранять ничего. **`omit`** — пути, которые нужно исключить. **`serializer`** — свои `serialize`/`deserialize` (по умолчанию `JSON.stringify` и `destr`) — например, для `Date`, `Set` или сжатия. Через **массив** конфигураций одни поля можно хранить в `localStorage`, а другие — в `sessionStorage`. Явный `pick` лучше, чем сохранять весь стор: новые поля (флаги загрузки, ошибки, чувствительные данные) не попадут в хранилище случайно.

## Вопрос

Как настроить ключ, хранилище и набор сохраняемых полей в `pinia-plugin-persistedstate`?

## pick и key

```ts
export const useCatalogUiStore = defineStore('catalogUi', {
  state: () => ({
    view: 'grid' as 'grid' | 'list',
    filters: { sort: 'price', inStock: false, q: '' },
    isLoading: false,
    error: null as string | null,
  }),
  persist: {
    key: 'shop:catalog-ui:v1',
    pick: ['view', 'filters.sort', 'filters.inStock'],   // q, isLoading, error — не сохраняются
  },
});
```

```text
localStorage['shop:catalog-ui:v1'] = {"view":"list","filters":{"sort":"price","inStock":true}}
```

## omit

```ts
persist: {
  omit: ['isLoading', 'error', 'draft.attachments'],   // всё, кроме перечисленного
}
```

`pick` безопаснее для сторов, которые растут: по умолчанию ничего лишнего не сохранится.

## Разные хранилища

```ts
export const useEditorStore = defineStore('editor', () => {
  const fontSize = ref(14);
  const draft = ref('');
  return { fontSize, draft };
}, {
  persist: [
    { key: 'editor:prefs', pick: ['fontSize'], storage: localStorage },   // навсегда
    { key: 'editor:draft', pick: ['draft'], storage: sessionStorage },     // до закрытия вкладки
  ],
});
```

## Свой serializer

```ts
persist: {
  serializer: {
    serialize: (state) => JSON.stringify({ ...state, savedAt: Date.now() }),
    deserialize: (raw) => {
      const data = JSON.parse(raw);
      return Date.now() - data.savedAt > 7 * 24 * 3600_000 ? {} : data;   // устарело через неделю — не восстанавливать
    },
  },
}
```

## Своё хранилище

```ts
const cookieStorage = {
  getItem: (key: string) => getCookie(key),
  setItem: (key: string, value: string) => setCookie(key, value, { maxAge: 31536000, sameSite: 'Lax' }),
};

persist: { storage: cookieStorage, pick: ['locale'] }   // язык доступен серверу с запросом
```

Хранилище должно быть **синхронным** (IndexedDB напрямую не подойдёт).

## Опции

| Опция | По умолчанию | Назначение |
| --- | --- | --- |
| `key` | `store.$id` | Ключ записи |
| `storage` | `localStorage` | Где хранить |
| `pick` | весь state | Что сохранять (пути через точку) |
| `omit` | ничего | Что исключить |
| `serializer` | `JSON.stringify` / `destr` | Сериализация |
| `beforeHydrate` / `afterHydrate` | — | Хуки гидрации |
| `debug` | `false` | Логировать ошибки чтения/записи |

## Частые ошибки

- Сохранять весь стор, куда позже добавят токен или персональные данные.
- Без версии в `key` менять структуру state — старые данные ломают новые типы.
- `sessionStorage` для настроек, которые должны пережить закрытие браузера, и наоборот.
- Асинхронное хранилище в опции `storage`.
- Сохранять `Date`/`Map` без своего сериализатора — восстановятся как строки/объекты.

## Что важно помнить

- `key` — с префиксом и версией; `pick` — явный список полей.
- Массив конфигураций — разные хранилища для разных полей.
- `serializer` и своё `storage` — для особых типов, TTL и cookies.

## Мини-шпаргалка

- `persist: { key, pick: ['a', 'b.c'] }`.
- `persist: { omit: ['loading'] }`.
- `persist: [{ pick, storage: localStorage }, { pick, storage: sessionStorage }]`.
- `serializer: { serialize, deserialize }`.
