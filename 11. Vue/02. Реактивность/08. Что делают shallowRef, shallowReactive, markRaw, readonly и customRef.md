# Что делают shallowRef, shallowReactive, markRaw, readonly и customRef

> [!NOTE]
> Эти API управляют **глубиной и характером** реактивности. **`shallowRef(value)`** реактивен только на уровне `.value`: замена значения отслеживается, а мутации внутри — нет; подходит для больших неизменяемых структур (ответ API, который всегда заменяется целиком, большие списки, экземпляры сторонних объектов) и экономит затраты на глубокие Proxy; после мутации можно вызвать `triggerRef(r)`. **`shallowReactive(obj)`** отслеживает только свойства первого уровня. **`markRaw(obj)`** помечает объект как **никогда не реактивный** — для экземпляров карт, графиков, редакторов, классов SDK, которые не должны оборачиваться в Proxy. **`readonly(obj)`** возвращает глубокий read-only Proxy (запись выдаёт предупреждение) — чтобы отдать состояние наружу без возможности изменения (например, из composable или стора). **`customRef((track, trigger) => ({ get, set }))`** — ref с собственной логикой отслеживания и уведомления: debounce, валидация, синхронизация с внешним источником. **`effectScope()`** собирает эффекты (`computed`, `watch`) в группу для совместной остановки.

## Вопрос

Для чего нужны `shallowRef`, `shallowReactive`, `markRaw`, `readonly`, `customRef` и `effectScope`?

## shallowRef

```ts
const rows = shallowRef<Row[]>([]);

rows.value = await api.getRows();           // ✓ обновит UI
rows.value.push(newRow);                    // ✗ не обновит — вложенные изменения не отслеживаются
rows.value = [...rows.value, newRow];       // ✓ заменяем целиком

// или вручную уведомить
rows.value.push(newRow);
triggerRef(rows);
```

На списке из 10 000 объектов `shallowRef` избавляет от создания Proxy на каждый элемент и их отслеживания.

## shallowReactive

```ts
const state = shallowReactive({ page: 1, meta: { total: 0 } });
state.page = 2;              // реактивно
state.meta.total = 100;      // не реактивно (второй уровень)
```

## markRaw

```ts
import maplibregl from 'maplibre-gl';

const map = shallowRef<maplibregl.Map | null>(null);   // или markRaw
onMounted(() => {
  map.value = markRaw(new maplibregl.Map({ container: el.value!, style }));
});

const state = reactive({ chart: markRaw(new Chart(canvas, config)) });   // Proxy не создаётся
```

Proxy вокруг таких объектов ломает их внутреннюю работу (сравнения `===`, приватные поля `#x`) и тратит память.

## readonly

```ts
export function useCart() {
  const state = reactive({ items: [] as Item[] });

  function add(item: Item) { state.items.push(item); }

  return {
    state: readonly(state),     // компоненты читают, но изменяют только через add
    add,
  };
}

const { state } = useCart();
state.items.push(x);            // предупреждение: target is readonly
```

`shallowReadonly` делает read-only только первый уровень.

## customRef: debounce

```ts
import { customRef } from 'vue';

export function useDebouncedRef<T>(value: T, delay = 300) {
  let timer: ReturnType<typeof setTimeout>;
  return customRef<T>((track, trigger) => ({
    get() {
      track();
      return value;
    },
    set(newValue) {
      clearTimeout(timer);
      timer = setTimeout(() => {
        value = newValue;
        trigger();
      }, delay);
    },
  }));
}

const query = useDebouncedRef('');
// <input v-model="query" /> — эффекты сработают через 300 мс после последнего ввода
```

## effectScope

```ts
const scope = effectScope();

scope.run(() => {
  const double = computed(() => count.value * 2);
  watch(double, (v) => console.log(v));
  watchEffect(() => console.log('count', count.value));
});

scope.stop();    // все эффекты внутри остановлены
```

Используется в библиотеках composables (VueUse, Pinia) для управления эффектами вне компонента; `getCurrentScope()` + `onScopeDispose()` — очистка ресурсов в composable.

## Сводка

| API | Глубина | Применение |
| --- | --- | --- |
| `shallowRef` | Только `.value` | Большие данные, заменяемые целиком; сторонние объекты |
| `shallowReactive` | Первый уровень | Объект с плоскими реактивными полями |
| `markRaw` | Без реактивности | Экземпляры библиотек, классы SDK |
| `readonly` / `shallowReadonly` | Запрет записи | Публичное API composables и сторов |
| `customRef` | Своя логика | Debounce, валидация, внешние источники |
| `effectScope` | — | Групповая остановка эффектов |

## Частые ошибки

- `shallowRef` + мутация внутри без `triggerRef` — «UI не обновляется».
- Класть экземпляры карт/графиков в `ref`/`reactive` без `markRaw`/`shallowRef`.
- Ожидать, что `readonly` защищает исходный объект (его можно менять напрямую).
- `customRef` без `track()` в `get` — значение не будет отслеживаться.

## Что важно помнить

- `shallow*` экономят ресурсы на больших структурах, но не видят вложенных изменений.
- `markRaw` — для объектов, которые не должны становиться Proxy.
- `readonly` — для безопасного публичного состояния, `customRef` — для своей логики ref.

## Мини-шпаргалка

- `shallowRef(x)` + `triggerRef(r)`.
- `markRaw(instance)`.
- `readonly(state)`.
- `customRef((track, trigger) => ({ get, set }))`.
- `effectScope().run(...)` / `.stop()`, `onScopeDispose`.
