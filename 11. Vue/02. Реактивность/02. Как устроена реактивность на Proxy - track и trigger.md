# Как устроена реактивность на Proxy - track и trigger

> [!NOTE]
> Реактивность Vue 3 построена на двух операциях. **`track`** — при **чтении** реактивного значения внутри выполняющегося эффекта Vue записывает зависимость «этот эффект зависит от `obj.key`» в глобальную структуру `WeakMap<target, Map<key, Set<effect>>>`. **`trigger`** — при **записи** Vue находит все эффекты, зависящие от изменённого ключа, и планирует их перезапуск. `reactive()` реализует это через **`Proxy`** с ловушками `get` (track), `set`/`deleteProperty` (trigger), `has`, `ownKeys`; вложенные объекты оборачиваются лениво — при первом обращении. `ref()` реализует то же через getter/setter свойства `.value` (поэтому ref работает и с примитивами). Эффект — это функция, обёрнутая в `ReactiveEffect`: перед каждым запуском её старые зависимости очищаются и собираются заново, поэтому учитываются только реально прочитанные значения (важно для условных веток). Proxy, в отличие от `defineProperty` во Vue 2, перехватывает добавление и удаление свойств, индексы массивов и коллекции `Map`/`Set`.

## Вопрос

Как реактивность Vue 3 устроена внутри?

## Упрощённая модель

```js
let activeEffect = null;
const targetMap = new WeakMap();      // target → key → Set(effects)

function track(target, key) {
  if (!activeEffect) return;
  let deps = targetMap.get(target);
  if (!deps) targetMap.set(target, (deps = new Map()));
  let dep = deps.get(key);
  if (!dep) deps.set(key, (dep = new Set()));
  dep.add(activeEffect);
}

function trigger(target, key) {
  targetMap.get(target)?.get(key)?.forEach((effect) => effect());
}

function reactive(obj) {
  return new Proxy(obj, {
    get(target, key, receiver) {
      track(target, key);
      const value = Reflect.get(target, key, receiver);
      return typeof value === 'object' && value !== null ? reactive(value) : value;   // ленивая глубина
    },
    set(target, key, value, receiver) {
      const result = Reflect.set(target, key, value, receiver);
      trigger(target, key);
      return result;
    },
  });
}

function watchEffect(fn) {
  const effect = () => { activeEffect = effect; fn(); activeEffect = null; };
  effect();
}

// использование
const state = reactive({ count: 0 });
watchEffect(() => console.log('count =', state.count));   // track(state, 'count')
state.count++;                                           // trigger → лог «count = 1»
```

В реальном Vue добавлены: очистка зависимостей, планировщик (батчинг), вложенные эффекты, кеширование Proxy, обработка массивов и коллекций, `computed` как ленивый эффект с флагом «грязный».

## ref

```js
class RefImpl {
  constructor(value) { this._value = toReactive(value); }
  get value() { track(this, 'value'); return this._value; }
  set value(v) {
    if (Object.is(v, this._value)) return;      // без изменений — без trigger
    this._value = toReactive(v);
    trigger(this, 'value');
  }
}
```

## Динамические зависимости

```ts
watchEffect(() => {
  if (showDetails.value) {
    console.log(user.address);      // зависимость появляется только когда showDetails = true
  }
});
```

При каждом запуске зависимости собираются заново — эффект не перезапускается от `user.address`, пока ветка не активна.

## Proxy и defineProperty

| | `Object.defineProperty` (Vue 2) | `Proxy` (Vue 3) |
| --- | --- | --- |
| Добавление/удаление свойств | Не отслеживается (`Vue.set`) | Отслеживается |
| Индексы и длина массива | Не отслеживается | Отслеживается |
| `Map`, `Set`, `WeakMap` | Нет | Да |
| Инициализация больших объектов | Обход всех свойств сразу | Лениво при доступе |
| Поддержка браузерами | Везде, включая IE | Нет IE11 |

## Проверки и утилиты

```ts
isReactive(state);   isRef(count);   isProxy(state);   isReadonly(ro);
toRaw(state);        // исходный объект без Proxy
reactive(obj) === reactive(obj);   // true — Proxy кешируется
reactive(obj) === obj;             // false — Proxy ≠ оригинал
```

## Частые ошибки

- Менять исходный объект (`obj`) вместо Proxy — изменения не отслеживаются.
- Сравнивать Proxy с оригиналом по `===`.
- Ожидать реактивности от значений, прочитанных вне эффекта и сохранённых в переменную.
- Класть в реактивное состояние тяжёлые объекты сторонних библиотек (карты, графики) — лишние Proxy (используйте `markRaw`/`shallowRef`).

## Что важно помнить

- Чтение в эффекте → `track`, запись → `trigger`.
- `reactive` — Proxy с ленивой глубиной, `ref` — getter/setter `.value`.
- Зависимости собираются заново при каждом запуске эффекта.

## Мини-шпаргалка

- `WeakMap<target, Map<key, Set<effect>>>`.
- `get` → track, `set`/`delete` → trigger.
- `toRaw`, `isReactive`, `isRef`.
- Proxy: свойства, индексы, Map/Set.
