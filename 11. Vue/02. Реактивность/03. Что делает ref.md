# Что делает ref

> [!NOTE]
> `ref(value)` создаёт **реактивную ссылку** — объект с единственным свойством **`.value`**: чтение `.value` отслеживается, запись — запускает зависимые эффекты. `ref` подходит для **любого** значения: примитивов (`ref(0)`, `ref('')`), объектов и массивов (тогда содержимое делается глубоко реактивным через `reactive`), `null` для отложенных данных. В скрипте обращаются через `.value`, а в **шаблоне** ref на верхнем уровне **разворачивается автоматически** (`{{ count }}`, `count++`). Ref также разворачивается, когда лежит свойством внутри `reactive`-объекта (но не внутри массивов и `Map`). Главное преимущество ref — его можно **передавать** в функции и composables, возвращать из них и деструктурировать результат, не теряя реактивности: это «контейнер», а не значение. Для типизации — `ref<User | null>(null)` или тип `Ref<T>`. Отдельно `ref` используется для **template refs** (доступа к DOM-элементам) — в 3.5+ для этого есть `useTemplateRef`.

## Вопрос

Что делает `ref()` и как с ним работать?

## Базовое использование

```vue
<script setup lang="ts">
import { ref } from 'vue';

const count = ref(0);                         // Ref<number>
const user = ref<User | null>(null);          // явный тип для null
const tags = ref<string[]>([]);

function increment() {
  count.value++;                              // в скрипте — .value
}

async function load() {
  user.value = await api.getUser();           // замена значения целиком
  tags.value.push('new');                     // мутация вложенного массива тоже реактивна
}
</script>

<template>
  <button @click="count++">{{ count }}</button>   <!-- в шаблоне без .value -->
  <p v-if="user">{{ user.name }}</p>
</template>
```

## Где ref разворачивается

| Место | Нужен `.value`? |
| --- | --- |
| Скрипт | Да |
| Шаблон, ref верхнего уровня | Нет |
| Шаблон, ref внутри обычного объекта (`obj.count`) | Да (не разворачивается) |
| Свойство `reactive`-объекта | Нет |
| Элемент `reactive`-массива или `Map` | Да |

```ts
const count = ref(1);
const state = reactive({ count });
state.count;            // 1 — развернулся
state.count = 2;        // count.value === 2

const list = reactive([ref(1)]);
list[0].value;          // в массиве не разворачивается
```

```vue
<script setup>
const obj = { foo: ref(1) };
</script>
<template>
  {{ obj.foo + 1 }}       <!-- "[object Object]1" — foo не развернулся; деструктурируйте: const { foo } = obj -->
</template>
```

## ref передаётся без потери реактивности

```ts
function useCounter(initial = 0) {
  const count = ref(initial);
  const double = computed(() => count.value * 2);
  return { count, double };                 // возвращаем ref-ы
}

const { count, double } = useCounter();     // деструктуризация безопасна
```

## Глубокая реактивность

```ts
const form = ref({ name: '', address: { city: '' } });
form.value.address.city = 'Москва';         // реактивно (вложенный объект — reactive)
```

Для больших неизменяемых структур, которые заменяются целиком, лучше `shallowRef` — см. [shallowRef и др.](<08. Что делают shallowRef, shallowReactive, markRaw, readonly и customRef.md>).

## Утилиты

```ts
isRef(x);                       // это ref?
unref(x);                       // x.value, если ref, иначе x
toValue(x);                     // как unref + вызывает функцию-геттер (3.3+)
const r = toRef(props, 'id');   // ref на свойство reactive/props
```

## Типизация

```ts
import type { Ref } from 'vue';

const year = ref<string | number>('2026');
function useTitle(title: Ref<string>) { /* ... */ }
```

## Частые ошибки

- Забыть `.value` в скрипте (`if (count > 5)` сравнивает объект).
- Писать `.value` в шаблоне.
- `ref(null)` без типа — TypeScript выведет `Ref<null>`.
- Ожидать разворачивания ref внутри обычного объекта в шаблоне.

## Что важно помнить

- `ref` — контейнер с реактивным `.value` для любого значения.
- В шаблоне верхнеуровневые ref разворачиваются, в скрипте — нет.
- Ref можно передавать и деструктурировать — поэтому composables возвращают ref-ы.

## Мини-шпаргалка

- `const x = ref(v)` → `x.value`.
- `ref<T | null>(null)`.
- `isRef`, `unref`, `toValue`, `toRef`.
- Объект в ref — глубоко реактивен.
