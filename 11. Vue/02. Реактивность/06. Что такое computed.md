# Что такое computed

> [!NOTE]
> `computed(getter)` создаёт **вычисляемое значение** — read-only ref, которое зависит от реактивных данных и **кешируется**: геттер выполняется только при первом чтении и после изменения его зависимостей, а при повторных чтениях без изменений возвращается сохранённый результат (это «memoized getter»). Вычисление **ленивое** — если значение никто не читает, оно не пересчитывается. В этом отличие от **метода**, который выполняется при каждом рендере и вызове. Геттер должен быть **чистым**: без побочных эффектов (запросов, мутаций состояния, DOM) — для них есть `watch`. Можно создать **записываемый** computed с `get`/`set` (например, для `v-model` над преобразованным значением). В Vue 3.4+ computed не запускает зависимые эффекты, если новое значение равно предыдущему, а геттер получает предыдущее значение аргументом. В Options API аналог — опция `computed`, в шаблоне используется без вызова: `{{ total }}`.

## Вопрос

Что такое `computed`, чем он отличается от метода и от `watch`?

## Базовый пример

```vue
<script setup lang="ts">
import { ref, computed } from 'vue';

const items = ref<CartItem[]>([]);
const promo = ref<number>(0);

const subtotal = computed(() => items.value.reduce((sum, i) => sum + i.price * i.qty, 0));
const total = computed(() => Math.max(0, subtotal.value - promo.value));
const isEmpty = computed(() => items.value.length === 0);
</script>

<template>
  <p v-if="isEmpty">Корзина пуста</p>
  <p v-else>Итого: {{ total }} ₽</p>
</template>
```

## computed и метод

```vue
<script setup>
const now = () => Date.now();
const cachedNow = computed(() => Date.now());   // никогда не обновится: нет реактивных зависимостей
</script>

<template>
  {{ subtotal }} {{ subtotal }}       <!-- геттер выполнится один раз -->
  {{ calcSubtotal() }} {{ calcSubtotal() }}   <!-- метод выполнится дважды и при каждом рендере -->
</template>
```

| | `computed` | Метод |
| --- | --- | --- |
| Кеширование | Да, по зависимостям | Нет |
| Когда выполняется | Лениво, при изменении зависимостей | При каждом вызове/рендере |
| Аргументы | Нет | Да |
| Для чего | Производные данные | Действия, вычисления с параметрами |

## computed и watch

| | `computed` | `watch` |
| --- | --- | --- |
| Результат | Значение | Побочный эффект |
| Синхронность | Синхронный геттер | Может быть async |
| Пример | Отфильтрованный список, сумма | Запрос к API при смене id, сохранение в localStorage |

```ts
// ✗ побочный эффект в computed
const user = computed(() => { fetchUser(id.value); return null; });

// ✓
watch(id, (v) => fetchUser(v), { immediate: true });
```

## Записываемый computed

```ts
const props = defineProps<{ modelValue: string }>();
const emit = defineEmits<{ 'update:modelValue': [value: string] }>();

const value = computed({
  get: () => props.modelValue,
  set: (v) => emit('update:modelValue', v.trim()),
});
// <input v-model="value" />
```

```ts
const firstName = ref('Анна');
const lastName = ref('Иванова');
const fullName = computed({
  get: () => `${firstName.value} ${lastName.value}`,
  set: (v) => { [firstName.value, lastName.value] = v.split(' '); },
});
```

## Стабильность значения (3.4+)

```ts
const isEven = computed(() => count.value % 2 === 0);
// count: 0 → 2 → 4 — isEven остаётся true, зависимые эффекты не перезапускаются

const list = computed((previous) => {
  const next = items.value.filter((i) => i.visible);
  return previous && shallowEqual(previous, next) ? previous : next;   // вернуть старый объект, если не изменился
});
```

## Отладка

```ts
const total = computed(() => ..., {
  onTrack(e) { console.log('track', e.key); },
  onTrigger(e) { console.log('trigger', e.key); },   // только в dev
});
```

## Частые ошибки

- Побочные эффекты в геттере.
- Мутация исходных данных внутри computed (`items.value.sort()` сортирует оригинал — используйте `toSorted()`/копию).
- Запись в read-only computed.
- `computed` без реактивных зависимостей (`Date.now()`) — значение не обновится.
- Дорогие вычисления в методах шаблона вместо computed.

## Что важно помнить

- `computed` — ленивое кешируемое производное значение.
- Геттер чистый; побочные эффекты — в `watch`.
- Записываемый computed — `get`/`set`, удобно для `v-model`.

## Мини-шпаргалка

- `const x = computed(() => ...)` → `x.value`.
- `computed({ get, set })`.
- Без мутаций и запросов в геттере.
- `toSorted()`, `[...arr].sort()` вместо `arr.sort()`.
