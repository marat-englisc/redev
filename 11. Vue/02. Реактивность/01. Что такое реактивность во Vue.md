# Что такое реактивность во Vue

> [!NOTE]
> **Реактивность** — механизм, при котором Vue **автоматически отслеживает**, какие данные использует код (рендер компонента, `computed`, `watch`), и **автоматически перезапускает** этот код, когда данные меняются. Реактивное состояние создают функции `ref()` (для любого значения, доступ через `.value`) и `reactive()` (для объектов, через Proxy). Код, зависящий от состояния, называется **эффектом**: рендер-функция компонента — эффект, `computed` — ленивый кешируемый эффект, `watch`/`watchEffect` — эффекты для побочных действий. Благодаря реактивности не нужно вручную синхронизировать UI с данными или вызывать «перерисовку»: достаточно изменить состояние. Отличие от простого «связывания данных» в том, что Vue строит граф зависимостей и обновляет **только** то, что зависит от изменившихся данных, причём DOM-обновления группируются и применяются асинхронно.

## Вопрос

Что такое реактивность во Vue и как она проявляется в коде?

## Пример

```vue
<script setup lang="ts">
import { ref, reactive, computed, watch } from 'vue';

const quantity = ref(1);
const product = reactive({ title: 'Клавиатура', price: 4990 });

const total = computed(() => quantity.value * product.price);    // пересчитается при изменении quantity или price

watch(total, (value) => {
  localStorage.setItem('cart-total', String(value));             // побочный эффект
});
</script>

<template>
  <p>{{ product.title }} × {{ quantity }} = {{ total }} ₽</p>
  <button @click="quantity++">+1</button>
  <button @click="product.price -= 500">Скидка</button>
</template>
```

Клик меняет `quantity` или `price` → пересчитывается `total` → обновляется текст и срабатывает `watch`.

## Что реактивно, а что нет

| Реактивно | Не реактивно |
| --- | --- |
| `ref(x)`, `reactive(obj)` | Обычные `let`/`const` |
| Свойства `reactive`-объекта, вложенные объекты | Значение, «вынутое» деструктуризацией из `reactive` |
| `computed(...)` | Результат функции, вызванной один раз |
| `props` компонента | Примитив, скопированный из props в локальную переменную |
| Объекты в `ref` (глубокая реактивность) | Объект, помеченный `markRaw` |

```ts
let count = 0;                 // изменение не обновит UI
const state = reactive({ count: 0 });
const { count: c } = state;    // c — просто число, связь потеряна
```

Подробнее — [ref vs reactive и потеря реактивности](<05. Чем ref отличается от reactive и как не потерять реактивность.md>).

## Эффекты

| Эффект | Когда выполняется | Зачем |
| --- | --- | --- |
| Рендер компонента | При изменении прочитанных данных (батчинг) | Обновить DOM |
| `computed` | Лениво при чтении, если зависимости изменились | Производное значение |
| `watch` | При изменении указанного источника | Побочное действие (запрос, сохранение) |
| `watchEffect` | Сразу и при изменении всего прочитанного | Эффект с автоматическими зависимостями |

## Реактивность и декларативность

Декларативный шаблон описывает UI как функцию от состояния, а реактивность обеспечивает, что эта функция пересчитывается при изменении состояния. Вместе они заменяют ручные `element.textContent = ...`.

## Реактивность и двустороннее связывание

`v-model` — лишь синтаксический сахар: `:value` (данные → UI) + `@input` (UI → данные). Реактивность — более общий механизм: она работает и без шаблонов (в composables, Pinia, `watch`).

## Частые ошибки

- Хранить состояние в обычных переменных.
- Деструктурировать `reactive` или props и ожидать реактивности.
- Заменять `reactive`-объект целиком (`state = {...}`) — ссылка на Proxy теряется.
- Выполнять побочные эффекты внутри `computed`.

## Что важно помнить

- Реактивность = отслеживание зависимостей + автоматический перезапуск эффектов.
- Состояние — через `ref`/`reactive`, производные — `computed`, побочные действия — `watch`.
- Vue обновляет только то, что зависит от изменившихся данных.

## Мини-шпаргалка

- `ref(v)` → `.value`.
- `reactive(obj)` → свойства напрямую.
- `computed(() => ...)`.
- `watch(source, cb)`, `watchEffect(fn)`.
