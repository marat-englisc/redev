# Когда использовать debounce и throttle

> [!NOTE]
> Обе техники ограничивают частоту вызова функции при частых событиях. **Debounce** откладывает вызов, пока события не прекратятся на заданное время: функция выполнится **один раз** после паузы (например, через 300 мс после последнего нажатия клавиши). Подходит, когда важен **итоговый** результат: поиск/автодополнение с запросом к API, валидация поля после ввода, автосохранение черновика, пересчёт layout после окончания ресайза. **Throttle** выполняет функцию **не чаще одного раза за интервал**, пока события продолжаются: подходит, когда нужны **промежуточные** обновления с ограниченной частотой — обработка скролла (прогресс чтения, подгрузка), движение мыши/drag, ресайз с живым обновлением, отправка аналитики. Для визуальных обновлений, синхронизированных с отрисовкой, используют `requestAnimationFrame` (по сути throttle до частоты кадров). Во Vue готовые реализации есть в VueUse: `useDebounceFn`, `useThrottleFn`, `refDebounced`, `watchDebounced`, `watchThrottled`; они автоматически очищают таймеры при размонтировании. Важно: debounce не отменяет уже отправленные запросы — для поиска добавляйте `AbortController`, иначе старый ответ может прийти позже нового.

## Вопрос

Чем отличаются debounce и throttle и когда что использовать во Vue?

## Разница на временной шкале

```text
События:   | | | | |       | | |         |
Debounce:              ✓          ✓          ✓      (после паузы 300 мс)
Throttle:  ✓     ✓     ✓   ✓     ✓        ✓         (не чаще раза в 300 мс)
```

| | Debounce | Throttle |
| --- | --- | --- |
| Когда вызывается | После паузы в событиях | Регулярно во время событий |
| Сколько раз | Один раз на серию | Раз в интервал |
| Примеры | Поиск, валидация, автосохранение | Скролл, mousemove, drag, resize с живым UI |

## Поиск с debounce и отменой запросов

```vue
<script setup lang="ts">
import { watchDebounced } from '@vueuse/core';

const query = ref('');
const results = ref<Product[]>([]);
let controller: AbortController | undefined;

watchDebounced(query, async (q) => {
  controller?.abort();                               // отменить предыдущий запрос
  if (q.trim().length < 2) { results.value = []; return; }
  controller = new AbortController();
  try {
    results.value = await api.searchProducts(q, { signal: controller.signal });
  } catch (e) {
    if ((e as Error).name !== 'AbortError') throw e;
  }
}, { debounce: 300, maxWait: 1000 });                // maxWait — выполнить хотя бы раз в секунду при непрерывном вводе
</script>

<template>
  <input v-model="query" type="search" placeholder="Поиск" />
</template>
```

## Скролл с throttle

```ts
import { useThrottleFn, useEventListener } from '@vueuse/core';

const progress = ref(0);
const onScroll = useThrottleFn(() => {
  const max = document.documentElement.scrollHeight - window.innerHeight;
  progress.value = max > 0 ? window.scrollY / max : 0;
}, 100);

useEventListener(window, 'scroll', onScroll, { passive: true });   // слушатель снимется при размонтировании
```

## Отложенное значение

```ts
import { refDebounced } from '@vueuse/core';

const search = ref('');
const debouncedSearch = refDebounced(search, 300);   // для запросов и тяжёлых computed
const filtered = computed(() => filterProducts(products.value, debouncedSearch.value));
```

## Простая реализация

```ts
export function debounce<T extends (...args: any[]) => void>(fn: T, ms: number) {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const debounced = (...args: Parameters<T>) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
  debounced.cancel = () => clearTimeout(timer);
  return debounced;
}

export function throttle<T extends (...args: any[]) => void>(fn: T, ms: number) {
  let last = 0;
  return (...args: Parameters<T>) => {
    const now = Date.now();
    if (now - last >= ms) { last = now; fn(...args); }
  };
}
```

```ts
// в компоненте — создавать один раз в setup и отменять при размонтировании
const save = debounce(saveDraft, 1000);
onBeforeUnmount(() => save.cancel());
```

## requestAnimationFrame

```ts
let frame = 0;
function onPointerMove(e: PointerEvent) {
  cancelAnimationFrame(frame);
  frame = requestAnimationFrame(() => { position.value = { x: e.clientX, y: e.clientY }; });
}
```

## Частые ошибки

- Создавать debounce-функцию в шаблоне или внутри обработчика — каждый раз новый таймер, debounce не работает.
- Не очищать таймер при размонтировании — вызов после ухода со страницы.
- Debounce на клике по кнопке «Оплатить» вместо блокировки кнопки на время запроса.
- Без `AbortController` — гонка ответов в поиске.
- Слишком большая задержка — интерфейс кажется «тормозным» (для поиска обычно 200–400 мс).

## Что важно помнить

- Debounce — итоговое значение после паузы; throttle — регулярные промежуточные обновления.
- Используйте VueUse-утилиты: они чистят таймеры сами.
- Debounce уменьшает число запросов, но гонки ответов решает отмена.

## Мини-шпаргалка

- `watchDebounced(src, cb, { debounce: 300 })`.
- `useDebounceFn(fn, 300)`, `useThrottleFn(fn, 100)`.
- `refDebounced(ref, 300)`.
- `AbortController` для поиска.
- `requestAnimationFrame` для визуальных обновлений.
