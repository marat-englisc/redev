# Что такое VueUse и зачем он нужен

> [!NOTE]
> **VueUse** — самая популярная коллекция готовых [composables](<../08. Composition API и composables/02. Что такое composables и как их писать.md>) для Vue (сотни функций): браузерные API (`useLocalStorage`, `useClipboard`, `useGeolocation`, `usePermission`), сенсоры (`useMouse`, `useWindowSize`, `useScroll`, `useElementVisibility`, `useIdle`), события и наблюдатели (`useEventListener`, `onClickOutside`, `useIntersectionObserver`, `useResizeObserver`), состояние (`useToggle`, `useCounter`, `useRefHistory`, `createGlobalState`), время (`useNow`, `useTimeAgo`, `useIntervalFn`), сеть (`useFetch`, `useWebSocket`, `useEventSource`), утилиты реактивности (`refDebounced`, `watchDebounced`, `until`, `syncRef`) и анимацию (`useTransition`). Ценность библиотеки — не в сложности отдельных функций, а в том, что они **сразу корректны**: возвращают реактивные ref-ы, принимают реактивные аргументы (`MaybeRefOrGetter`), **сами снимают слушатели и таймеры** при размонтировании или остановке effect scope, безопасны для **SSR** (проверяют наличие `window`), tree-shakable и типизированы. Пакеты: `@vueuse/core` (основной), `@vueuse/components` (те же возможности как компоненты-рендерлесс), `@vueuse/integrations` (обёртки над axios, Fuse.js, focus-trap, Sortable и др.), `@vueuse/router`, `@vueuse/motion`, `@vueuse/nuxt`. Текущая линейка (v14–15) требует **Vue 3.5+**.

## Вопрос

Что такое VueUse и зачем он нужен во Vue-проекте?

## Без VueUse и с ним

```ts
// вручную: состояние + подписка + отписка + SSR-проверка
const width = ref(typeof window !== 'undefined' ? window.innerWidth : 0);
function onResize() { width.value = window.innerWidth; }
onMounted(() => window.addEventListener('resize', onResize, { passive: true }));
onBeforeUnmount(() => window.removeEventListener('resize', onResize));
```

```ts
// VueUse
import { useWindowSize } from '@vueuse/core';
const { width, height } = useWindowSize();
```

## Установка

```bash
npm i @vueuse/core
```

```ts
// Nuxt: автоимпорт всех функций
// nuxt.config.ts
export default defineNuxtConfig({ modules: ['@vueuse/nuxt'] });
```

## Реактивные аргументы

```ts
import { useTitle, useDateFormat } from '@vueuse/core';

const page = ref('Каталог');
useTitle(() => `${page.value} — Shop`);           // геттер: заголовок обновится при смене page

const createdAt = ref(new Date());
const formatted = useDateFormat(createdAt, 'DD.MM.YYYY HH:mm');
```

Большинство функций принимают `MaybeRefOrGetter<T>` — значение, ref или геттер — и реагируют на изменения.

## Компоненты-рендерлесс

```vue
<script setup lang="ts">
import { OnClickOutside, UseWindowSize } from '@vueuse/components';
</script>

<template>
  <OnClickOutside @trigger="closeMenu">
    <DropdownMenu />
  </OnClickOutside>

  <UseWindowSize v-slot="{ width }">Ширина: {{ width }}</UseWindowSize>
</template>
```

## Интеграции

```ts
import { useFuse } from '@vueuse/integrations/useFuse';          // нечёткий поиск (нужен fuse.js)
import { useFocusTrap } from '@vueuse/integrations/useFocusTrap'; // фокус внутри модалки (нужен focus-trap)

const { results } = useFuse(query, products, { fuseOptions: { keys: ['title'] } });
```

## Когда VueUse полезен, а когда нет

| Полезен | Не нужен |
| --- | --- |
| Браузерные API с подпиской/отпиской | Одна строчка без побочных эффектов |
| Нужна SSR-безопасность | Бизнес-логика приложения |
| Реактивные таймеры, observers, storage | Когда уже есть аналог в UI-библиотеке |
| Прототипирование и единый стиль кода | Если нужна функция с другой семантикой — проще написать свою |

## Частые ошибки

- Вызывать composables VueUse вне `setup`/effect scope — автоматическая очистка не сработает.
- Деструктурировать `reactive`-результат без `toRefs` (большинство функций возвращают объект ref-ов — его деструктурировать можно).
- Импортировать устаревшие алиасы функций — в v14 они объявлены устаревшими в пользу оригинальных имён.
- Не проверить breaking changes при обновлении мажорной версии (например, `useThrottleFn` в v15 по умолчанию вызывает trailing).

## Что важно помнить

- VueUse — готовые composables для браузерных API, событий, состояния, времени и сети.
- Функции реактивны, принимают ref/геттеры, сами чистят ресурсы и SSR-безопасны.
- `@vueuse/core` + при необходимости `components`, `integrations`, `nuxt`.

## Мини-шпаргалка

- `npm i @vueuse/core`.
- `useWindowSize()`, `useLocalStorage()`, `useEventListener()`, `onClickOutside()`.
- Аргументы — `MaybeRefOrGetter`.
- `@vueuse/nuxt` — автоимпорт в Nuxt.
