# Какие composables VueUse нужно знать

> [!NOTE]
> Из сотен функций VueUse в повседневной разработке чаще всего нужны несколько групп. **Состояние**: `useToggle` (булев флаг с переключателем), `useCounter`, `useCycleList` (перебор вариантов), `useRefHistory` (undo/redo), `createGlobalState` и `createSharedComposable` (общее состояние без стора), `useVModel` (проксирование `v-model`, сейчас чаще заменяется `defineModel`). **Хранилище и предпочтения**: `useLocalStorage`, `useSessionStorage`, `useDark`, `useColorMode`, `usePreferredReducedMotion`, `useMediaQuery`, `useBreakpoints`. **DOM и события**: `useEventListener`, `onClickOutside`, `onKeyStroke`, `useFocus`, `useElementSize`, `useElementVisibility`, `useIntersectionObserver`, `useResizeObserver`, `useScroll`, `useInfiniteScroll`, `useScrollLock`. **Браузерные API**: `useClipboard`, `useShare`, `useOnline`, `useNetwork`, `usePermission`, `useGeolocation`, `useFileDialog`, `useDropZone`, `useTitle`, `useFavicon`, `useWakeLock`. **Время**: `useNow`, `useTimeAgo`, `useDateFormat`, `useIntervalFn`, `useTimeoutFn`, `useIdle`. **Сеть**: `useFetch`, `useWebSocket`, `useEventSource`. **Утилиты реактивности**: `refDebounced`, `watchDebounced`, `watchThrottled`, `useDebounceFn`, `useThrottleFn`, `until`, `whenever`, `watchOnce`, `syncRef`, `computedAsync`. Выбор: сначала понять, какой браузерный ресурс нужен и требует ли он очистки, SSR-проверок и реактивности, — именно там VueUse экономит больше всего.

## Вопрос

Какие composables VueUse стоит знать для повседневной разработки?

## Состояние

```ts
import { useToggle, useCycleList, useRefHistory, createGlobalState, useLocalStorage } from '@vueuse/core';

const [isOpen, toggleOpen] = useToggle(false);
toggleOpen();          // true
toggleOpen(false);     // явно

const { state: view, next } = useCycleList(['grid', 'list', 'table'] as const);

const text = ref('');
const { undo, redo, canUndo } = useRefHistory(text, { capacity: 50 });

// общее состояние без Pinia — один экземпляр на приложение
export const useSidebarState = createGlobalState(() => useLocalStorage('sidebar-collapsed', false));
```

## Адаптивность

```ts
import { useBreakpoints, breakpointsTailwind, useMediaQuery } from '@vueuse/core';

const bp = useBreakpoints(breakpointsTailwind);
const isMobile = bp.smaller('md');            // < 768px
const isDesktop = bp.greaterOrEqual('lg');

const prefersReducedMotion = useMediaQuery('(prefers-reduced-motion: reduce)');
```

## DOM и элементы

```vue
<script setup lang="ts">
import { onClickOutside, onKeyStroke, useElementSize, useScrollLock } from '@vueuse/core';

const panel = useTemplateRef<HTMLElement>('panel');
const open = defineModel<boolean>('open');

onClickOutside(panel, () => { open.value = false; });
onKeyStroke('Escape', () => { open.value = false; });

const { width } = useElementSize(panel);
const locked = useScrollLock(document.body);
watch(open, (v) => { locked.value = !!v; });
</script>

<template>
  <aside v-if="open" ref="panel">Ширина панели: {{ width }}px</aside>
</template>
```

`document.body` в SSR недоступен — в Nuxt передавайте геттер или используйте внутри `onMounted`.

## Браузерные API

```ts
import { useClipboard, useOnline, useTitle, useFileDialog } from '@vueuse/core';

const { copy, copied, isSupported } = useClipboard({ copiedDuring: 1500 });
await copy(location.href);                     // copied.value === true на 1,5 с

const online = useOnline();                    // реактивный navigator.onLine

const title = useTitle();
title.value = 'Корзина (3)';

const { open: openFiles, files } = useFileDialog({ accept: 'image/*', multiple: true });
```

## Время

```ts
import { useNow, useTimeAgo, useIntervalFn, useIdle } from '@vueuse/core';

const now = useNow({ interval: 1000 });
const ago = useTimeAgo(() => comment.createdAt);       // «5 minutes ago» — английский по умолчанию, есть messages для локализации

const { pause, resume } = useIntervalFn(refreshPrices, 30_000);

const { idle } = useIdle(5 * 60_000);
whenever(idle, () => auth.lock());                     // через 5 минут бездействия
```

## Утилиты реактивности

```ts
import { until, whenever, watchOnce, computedAsync } from '@vueuse/core';

await until(isReady).toBe(true);                       // дождаться значения
whenever(() => cart.count > 0, () => showCartHint());  // watch, срабатывающий на истинное значение
watchOnce(user, (u) => analytics.identify(u.id));

const preview = computedAsync(async () => renderMarkdown(text.value), '');
```

Debounce и throttle — в уроке [Когда использовать debounce и throttle](<../14. Оптимизация и производительность/06. Когда использовать debounce и throttle.md>).

## Карта функций

| Задача | Функция |
| --- | --- |
| Флаг открыто/закрыто | `useToggle` |
| Закрыть по клику снаружи / Esc | `onClickOutside`, `onKeyStroke` |
| Брейкпоинты | `useBreakpoints`, `useMediaQuery` |
| Подгрузка при скролле | `useInfiniteScroll`, `useIntersectionObserver` |
| Сохранить в браузере | `useLocalStorage` |
| Тема | `useDark`, `useColorMode` |
| Копирование | `useClipboard` |
| Таймер с паузой | `useIntervalFn` |
| Undo/redo | `useRefHistory` |
| Общее состояние без стора | `createGlobalState`, `createSharedComposable` |

## Частые ошибки

- Тащить VueUse ради функции, которую уже даёт фреймворк (`defineModel` вместо `useVModel`, `useTemplateRef` вместо `templateRef`, удалённого в v15).
- `createGlobalState` для серверного рендеринга — состояние станет общим для всех запросов (используйте Pinia/`useState` в Nuxt).
- Не проверять `isSupported` для API, которых нет во всех браузерах.
- Ожидать локализацию `useTimeAgo` без передачи `messages` (или используйте `Intl.RelativeTimeFormat`).

## Что важно помнить

- Основные группы: состояние, предпочтения, DOM/события, браузерные API, время, сеть, утилиты реактивности.
- Функции сами очищают ресурсы — главный выигрыш на подписках, observers и таймерах.
- Учитывайте SSR и поддержку API в браузерах.

## Мини-шпаргалка

- `useToggle`, `useCycleList`, `useRefHistory`.
- `useBreakpoints(breakpointsTailwind)`, `useMediaQuery`.
- `onClickOutside`, `onKeyStroke`, `useElementSize`, `useScrollLock`.
- `useClipboard`, `useOnline`, `useTitle`, `useFileDialog`.
- `useNow`, `useIntervalFn`, `useIdle`, `until`, `whenever`.
