# Как работать с событиями, observers и очисткой - useEventListener, onClickOutside и useIntersectionObserver

> [!NOTE]
> Подписки на события DOM, наблюдатели и таймеры — главный источник **утечек памяти** во Vue-приложениях: слушатель на `window` или `IntersectionObserver`, не отключённый при размонтировании, продолжает держать компонент в памяти и вызывать устаревший код. VueUse решает это единообразно: функции регистрируют очистку через `tryOnScopeDispose` — она срабатывает при **размонтировании компонента** или остановке **effect scope**, а также при смене цели. **`useEventListener(target, event, handler, options)`** принимает ref элемента (слушатель перевешивается при его смене), `window`/`document` по умолчанию, массивы событий и возвращает функцию ручной отписки. **`onClickOutside(target, handler, { ignore })`** — закрытие меню, поповеров и модалок по клику снаружи. **`onKeyStroke(key, handler)`** — горячие клавиши. Наблюдатели: **`useIntersectionObserver`** (элемент виден во viewport — ленивая загрузка, бесконечная прокрутка, аналитика показов) и упрощённый `useElementVisibility`, **`useResizeObserver`**/`useElementSize` (размер элемента, а не окна), **`useMutationObserver`**. Таймеры: `useIntervalFn`, `useTimeoutFn` с `pause`/`resume`. Если нужен собственный composable с ресурсами — используйте те же приёмы: `onScopeDispose`/`onWatcherCleanup` и `effectScope` для группировки эффектов вне компонентов. Debounce и throttle разобраны в [отдельном уроке](<../14. Оптимизация и производительность/06. Когда использовать debounce и throttle.md>).

## Вопрос

Как с помощью VueUse подписываться на события и наблюдатели так, чтобы ресурсы автоматически освобождались?

## useEventListener

```ts
import { useEventListener } from '@vueuse/core';

// window по умолчанию; снимется при размонтировании
useEventListener('keydown', (e) => {
  if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
    e.preventDefault();
    openSearch();
  }
});

useEventListener(document, 'visibilitychange', () => {
  if (document.visibilityState === 'visible') refresh();
});

// ref элемента: слушатель перевесится при смене элемента и снимется, если элемент исчезнет
const area = useTemplateRef<HTMLElement>('area');
useEventListener(area, ['dragenter', 'dragover'], (e) => e.preventDefault());

// ручная отписка
const stop = useEventListener(window, 'scroll', onScroll, { passive: true });
stop();
```

## onClickOutside и onKeyStroke

```vue
<script setup lang="ts">
import { onClickOutside, onKeyStroke } from '@vueuse/core';

const open = ref(false);
const menu = useTemplateRef<HTMLElement>('menu');
const trigger = useTemplateRef<HTMLElement>('trigger');

onClickOutside(menu, () => { open.value = false; }, { ignore: [trigger] });   // клик по кнопке не закрывает
onKeyStroke('Escape', () => { open.value = false; trigger.value?.focus(); });
</script>

<template>
  <button ref="trigger" :aria-expanded="open" @click="open = !open">Меню</button>
  <ul v-if="open" ref="menu" role="menu">...</ul>
</template>
```

## useIntersectionObserver

```vue
<script setup lang="ts">
import { useIntersectionObserver } from '@vueuse/core';

const props = defineProps<{ productId: number }>();
const card = useTemplateRef<HTMLElement>('card');

const { stop } = useIntersectionObserver(card, ([entry]) => {
  if (entry?.isIntersecting) {
    analytics.track('product_impression', { id: props.productId });
    stop();                                      // засчитать показ один раз
  }
}, { threshold: 0.5 });
</script>

<template>
  <article ref="card">...</article>
</template>
```

```ts
// бесконечная прокрутка
import { useInfiniteScroll } from '@vueuse/core';

const list = useTemplateRef<HTMLElement>('list');
useInfiniteScroll(list, loadMore, { distance: 200, canLoadMore: () => hasMore.value });
```

## Размеры элемента

```ts
import { useElementSize, useResizeObserver } from '@vueuse/core';

const chart = useTemplateRef<HTMLElement>('chart');
const { width, height } = useElementSize(chart);            // реактивные размеры
useResizeObserver(chart, () => chartInstance?.resize());    // реакция на изменение размера контейнера
```

## Таймеры

```ts
import { useIntervalFn, useTimeoutFn } from '@vueuse/core';

const { pause, resume, isActive } = useIntervalFn(pollStatus, 5000);
useEventListener(document, 'visibilitychange', () => (document.hidden ? pause() : resume()));

const { start: showHintLater, stop: cancelHint } = useTimeoutFn(() => (hint.value = true), 3000, { immediate: false });
```

## Очистка в собственных composables

```ts
export function useWebSocketChannel(url: MaybeRefOrGetter<string>) {
  const messages = ref<string[]>([]);

  watch(() => toValue(url), (u) => {
    const ws = new WebSocket(u);
    ws.onmessage = (e) => messages.value.push(e.data);
    onWatcherCleanup(() => ws.close());          // Vue 3.5+: при смене url и остановке watch
  }, { immediate: true });

  return { messages };
}
```

```ts
// вне компонента: сгруппировать эффекты и остановить разом
const scope = effectScope();
scope.run(() => {
  useEventListener('online', syncQueue);
  useIntervalFn(flushLogs, 10_000);
});
// позже
scope.stop();                                     // все слушатели и таймеры сняты
```

## Ручной код и VueUse

| Ручная реализация | VueUse |
| --- | --- |
| `addEventListener` в `onMounted` + `removeEventListener` в `onBeforeUnmount` | `useEventListener` |
| Слушатель `document` + проверка `contains` | `onClickOutside` |
| `new IntersectionObserver` + `disconnect` | `useIntersectionObserver` |
| `setInterval` + `clearInterval` + пауза | `useIntervalFn` |

## Частые ошибки

- Вызывать composable в обработчике или после `await` в setup — очистка не привяжется к компоненту.
- Передавать `ref.value` вместо ref — VueUse не увидит смену элемента (и получит `null` до монтирования).
- `onClickOutside` без `ignore` для кнопки-триггера — меню закрывается и сразу открывается.
- Не останавливать `effectScope`, созданный вне компонента.
- Интервальный опрос в фоновой вкладке без паузы.

## Что важно помнить

- VueUse снимает слушатели, observers и таймеры при размонтировании или `scope.stop()`.
- Передавайте ref-ы элементов, а не их значения.
- В своих composables — `onScopeDispose`, `onWatcherCleanup`, `effectScope`.

## Мини-шпаргалка

- `useEventListener(target, 'event', handler, { passive: true })`.
- `onClickOutside(el, cb, { ignore: [trigger] })`, `onKeyStroke('Escape', cb)`.
- `useIntersectionObserver(el, ([e]) => ..., { threshold })`, `useInfiniteScroll`.
- `useElementSize`, `useResizeObserver`.
- `useIntervalFn` → `pause`/`resume`; `effectScope().run(...)` + `stop()`.
