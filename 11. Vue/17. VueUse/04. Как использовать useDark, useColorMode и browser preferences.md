# Как использовать useDark, useColorMode и browser preferences

> [!NOTE]
> **`useDark()`** возвращает булев ref «тёмная тема включена»: начальное значение берётся из сохранённого выбора пользователя (localStorage, ключ `vueuse-color-scheme`) или из системной настройки `prefers-color-scheme`, а при изменении Vue добавляет/убирает класс `dark` на `<html>` (настраивается: `selector`, `attribute`, `valueDark`, `valueLight`, `storageKey`). Сам по себе `useDark` **не задаёт стили** — их дают CSS-переменные, вариант `dark:` в Tailwind или тема UI-библиотеки. **`useColorMode()`** — более общий вариант: режимы `'light' | 'dark' | 'auto'` и свои (`'sepia'`, `'high-contrast'`), раздельно `store` (выбор пользователя, включая `auto`) и `system` (что предпочитает ОС). Другие предпочтения браузера: `usePreferredDark`, `usePreferredColorScheme`, `usePreferredReducedMotion` (уважать отключение анимаций), `usePreferredContrast`, `usePreferredLanguages`, `useMediaQuery` для произвольных запросов. Нюанс SSR и CSR: тема применяется после загрузки JS, поэтому возможна **вспышка светлой темы** — её устраняют инлайн-скриптом в `<head>`, который ставит класс до отрисовки, или cookie в SSR (в Nuxt — модуль `@nuxtjs/color-mode`).

## Вопрос

Как управлять тёмной темой и учитывать предпочтения пользователя с помощью VueUse?

## useDark

```vue
<script setup lang="ts">
import { useDark, useToggle } from '@vueuse/core';

const isDark = useDark();               // html.dark + localStorage + prefers-color-scheme
const toggleDark = useToggle(isDark);
</script>

<template>
  <button type="button" :aria-pressed="isDark" @click="toggleDark()">
    {{ isDark ? 'Светлая тема' : 'Тёмная тема' }}
  </button>
</template>
```

```ts
// атрибут вместо класса (например, для DaisyUI или своих CSS-переменных)
const isDark = useDark({
  selector: 'html',
  attribute: 'data-theme',
  valueDark: 'dark',
  valueLight: 'light',
  storageKey: 'theme',
});
```

## Стили для темы

```css
:root {
  --bg: #ffffff;
  --text: #0f172a;
}
:root.dark {
  --bg: #020617;
  --text: #e2e8f0;
  color-scheme: dark;            /* тёмные полосы прокрутки и поля форм */
}
body { background: var(--bg); color: var(--text); }
```

```vue
<!-- Tailwind v4: вариант dark по классу -->
<div class="bg-white text-slate-900 dark:bg-slate-950 dark:text-slate-100">...</div>
```

```css
/* Tailwind v4: включить dark по классу вместо media */
@custom-variant dark (&:where(.dark, .dark *));
```

## useColorMode — несколько режимов

```ts
import { useColorMode } from '@vueuse/core';

const mode = useColorMode({
  modes: { sepia: 'sepia', contrast: 'high-contrast' },   // дополнительные классы
});

mode.value = 'sepia';
const { store, system } = mode;    // store: выбор ('auto' | 'light' | ...), system: предпочтение ОС
```

```vue
<select v-model="mode.store.value">
  <option value="auto">Как в системе</option>
  <option value="light">Светлая</option>
  <option value="dark">Тёмная</option>
  <option value="sepia">Сепия</option>
</select>
```

## Синхронизация с UI-библиотекой

```ts
// Vuetify
import { useTheme } from 'vuetify';
const theme = useTheme();
const isDark = useDark();
watch(isDark, (dark) => theme.change(dark ? 'dark' : 'light'), { immediate: true });
```

## Другие предпочтения

```ts
import { usePreferredReducedMotion, usePreferredLanguages, useMediaQuery } from '@vueuse/core';

const motion = usePreferredReducedMotion();          // 'reduce' | 'no-preference'
const animate = computed(() => motion.value !== 'reduce');

const languages = usePreferredLanguages();           // ['ru-RU', 'en-US']
const isPrint = useMediaQuery('print');
const hasHover = useMediaQuery('(hover: hover)');
```

## Без вспышки темы

```html
<!-- index.html, до загрузки бандла -->
<script>
  (function () {
    const saved = localStorage.getItem('vueuse-color-scheme');
    const dark = saved === 'dark' || ((!saved || saved === 'auto') && matchMedia('(prefers-color-scheme: dark)').matches);
    document.documentElement.classList.toggle('dark', dark);
  })();
</script>
```

## Частые ошибки

- Ожидать, что `useDark` сам перекрасит интерфейс без CSS.
- Не учитывать вспышку светлой темы при загрузке.
- Хранить только `dark/light` и терять вариант «как в системе».
- Игнорировать `prefers-reduced-motion` в анимациях.
- Разные ключи/механизмы темы в VueUse и UI-библиотеке — темы «расходятся».

## Что важно помнить

- `useDark` — булев флаг + класс/атрибут + хранение выбора + системная настройка.
- `useColorMode` — несколько режимов, `store` и `system`.
- Стили задаёт CSS/Tailwind/UI-библиотека; вспышку убирает инлайн-скрипт или SSR-cookie.

## Мини-шпаргалка

- `const isDark = useDark(); const toggle = useToggle(isDark)`.
- `useDark({ attribute: 'data-theme', valueDark, valueLight })`.
- `useColorMode({ modes: { sepia: 'sepia' } })`, `mode.store`.
- `usePreferredReducedMotion()`, `useMediaQuery('(hover: hover)')`.
- `color-scheme: dark`.
