## Вопрос

С чего начать изучение Vue и в каком порядке читать раздел?

## Основная идея

Почти всё во Vue вытекает из **реактивности**: шаблон — это функция от состояния, Vue сам отслеживает, какие данные прочитал компонент, и перерисовывает только то, что от них зависит. Отсюда правила, которые иначе кажутся случайными: не деструктурировать `reactive`, не мутировать props, следить за геттером в `watch`, ждать `nextTick` перед чтением DOM, выбирать `computed` вместо методов. Раздел построен так, чтобы сначала понять эту модель, затем компоненты и поток данных, а потом — инструменты вокруг.

## Что важно помнить

- Сначала модель реактивности, потом API: без неё ошибки Vue выглядят случайными.
- Новый код пишите на Composition API и `<script setup>`; Options API нужен для чтения существующих проектов.
- Экосистема меняется быстро: Vue Router 5, Vite 8, Vuetify 4 и Tailwind v4 отличаются от старых статей — сверяйтесь с документацией.
