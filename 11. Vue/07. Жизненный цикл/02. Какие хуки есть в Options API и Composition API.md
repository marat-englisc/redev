# Какие хуки есть в Options API и Composition API

> [!NOTE]
> Оба API используют одни и те же этапы жизненного цикла, но по-разному их записывают. В **Options API** хуки — методы объекта компонента с доступом к `this`: `beforeCreate`, `created`, `beforeMount`, `mounted`, `beforeUpdate`, `updated`, `beforeUnmount`, `unmounted`, `activated`, `deactivated`, `errorCaptured`, `serverPrefetch`, `renderTracked`, `renderTriggered`. В **Composition API** — функции с префиксом `on`, вызываемые внутри `setup`: `onBeforeMount`, `onMounted`, `onBeforeUpdate`, `onUpdated`, `onBeforeUnmount`, `onUnmounted`, `onActivated`, `onDeactivated`, `onErrorCaptured`, `onServerPrefetch`, `onRenderTracked`, `onRenderTriggered`. Аналогов `beforeCreate` и `created` нет: их роль играет **сам код `setup`**, который выполняется до создания экземпляра Options API. Преимущества функциональных хуков: их можно вызывать **несколько раз** (выполнятся по порядку) и **внутри composables** — логика подписки и отписки живёт рядом. В Vue 2 хуки удаления назывались `beforeDestroy`/`destroyed`.

## Вопрос

Какие хуки жизненного цикла есть в Options API и Composition API и как они соотносятся?

## Соответствие

| Options API | Composition API | Когда |
| --- | --- | --- |
| `beforeCreate` | — (код `setup`) | До инициализации опций |
| `created` | — (код `setup`) | Состояние готово, DOM нет |
| `beforeMount` | `onBeforeMount` | Перед вставкой DOM |
| `mounted` | `onMounted` | DOM вставлен |
| `beforeUpdate` | `onBeforeUpdate` | Перед патчем DOM |
| `updated` | `onUpdated` | После патча DOM |
| `beforeUnmount` | `onBeforeUnmount` | Перед удалением |
| `unmounted` | `onUnmounted` | После удаления |
| `activated` / `deactivated` | `onActivated` / `onDeactivated` | KeepAlive |
| `errorCaptured` | `onErrorCaptured` | Ошибка в потомке |
| `serverPrefetch` | `onServerPrefetch` | SSR |
| `renderTracked` / `renderTriggered` | `onRenderTracked` / `onRenderTriggered` | Отладка (dev) |

## Один компонент в двух стилях

```js
// Options API
export default {
  data: () => ({ width: window.innerWidth }),
  created() {
    this.loadSettings();                       // данные готовы
  },
  mounted() {
    window.addEventListener('resize', this.onResize);
  },
  beforeUnmount() {
    window.removeEventListener('resize', this.onResize);
  },
  methods: {
    onResize() { this.width = window.innerWidth; },
    loadSettings() { /* ... */ },
  },
};
```

```ts
// Composition API
const width = ref(window.innerWidth);
loadSettings();                                // вместо created

const onResize = () => (width.value = window.innerWidth);
onMounted(() => window.addEventListener('resize', onResize));
onBeforeUnmount(() => window.removeEventListener('resize', onResize));
```

## Хуки в composables

```ts
// composables/useWindowWidth.ts
export function useWindowWidth() {
  const width = ref(0);
  const update = () => (width.value = window.innerWidth);

  onMounted(() => {
    update();
    window.addEventListener('resize', update, { passive: true });
  });
  onUnmounted(() => window.removeEventListener('resize', update));

  return { width: readonly(width) };
}

// в любом компоненте
const { width } = useWindowWidth();
```

В Options API для этого потребовался бы mixin, а подписка и отписка разошлись бы по разным опциям.

## Несколько регистраций

```ts
onMounted(() => console.log('first'));
onMounted(() => console.log('second'));     // оба выполнятся по порядку
```

## Смешанный компонент

Если компонент использует и `setup()`, и Options API, хуки Composition API вызываются **раньше** одноимённых опций.

## Частые ошибки

- Искать `onCreated` — его нет, код пишется прямо в `setup`.
- Стрелочные функции в хуках Options API (`mounted: () => this.x`) — `this` не экземпляр.
- Вызов `onMounted` вне `setup` или после `await`.
- `beforeDestroy`/`destroyed` в коде Vue 3.

## Что важно помнить

- Этапы одинаковы; Options — методы с `this`, Composition — функции `onXxx` в `setup`.
- `beforeCreate`/`created` ⇒ код `setup`.
- Функциональные хуки можно вызывать многократно и внутри composables.

## Мини-шпаргалка

- `mounted` ↔ `onMounted`, `beforeUnmount` ↔ `onBeforeUnmount`.
- `created` ↔ тело `setup`.
- `activated` ↔ `onActivated`.
- Vue 2 `destroyed` ↔ Vue 3 `unmounted`.
