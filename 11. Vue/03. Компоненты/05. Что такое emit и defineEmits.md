# Что такое emit и defineEmits

> [!NOTE]
> **Emit** — механизм, через который дочерний компонент сообщает родителю о событии: ребёнок вызывает `emit('select', id)`, родитель подписывается `@select="onSelect"`. В `<script setup>` события объявляют макросом **`defineEmits`**, лучше с типами (`defineEmits<{ select: [id: string]; close: [] }>()`) — тогда TypeScript проверяет имена и аргументы, а IDE подсказывает их в родителе. Объявление обязательно по смыслу: оно документирует контракт компонента, позволяет Vue отличить события компонента от нативных DOM-событий (необъявленные слушатели попадают в `$attrs` и вешаются на корневой элемент) и включает runtime-валидацию. В отличие от DOM-событий, события компонентов **не всплывают** по дереву — слушать их может только непосредственный родитель (для дальних связей — provide/inject или стор). Имена — в camelCase при объявлении, в шаблоне родителя можно писать в kebab-case. Пара `update:xxx` используется `v-model`. В Options API — опция `emits` и `this.$emit`.

## Вопрос

Что такое emit во Vue и как объявлять события компонента?

## Объявление и вызов

```vue
<!-- TodoItem.vue -->
<script setup lang="ts">
const props = defineProps<{ todo: Todo }>();

const emit = defineEmits<{
  toggle: [id: string];
  rename: [id: string, title: string];
  remove: [id: string];
}>();

function onTitleBlur(e: FocusEvent) {
  const title = (e.target as HTMLInputElement).value.trim();
  if (title && title !== props.todo.title) emit('rename', props.todo.id, title);
}
</script>

<template>
  <li>
    <input type="checkbox" :checked="todo.done" @change="emit('toggle', todo.id)" />
    <input :value="todo.title" @blur="onTitleBlur" />
    <button @click="emit('remove', todo.id)">×</button>
  </li>
</template>
```

```vue
<!-- TodoList.vue -->
<TodoItem
  v-for="t in todos"
  :key="t.id"
  :todo="t"
  @toggle="store.toggle"
  @rename="(id, title) => store.rename(id, title)"
  @remove="store.remove"
/>
```

## Runtime-валидация

```ts
const emit = defineEmits({
  submit: (payload: { email: string }) => payload.email.includes('@'),   // false → предупреждение в dev
  cancel: null,                                                         // без проверки
});
```

## Обработчики в шаблоне

```vue
<SearchBox @search="onSearch" />                    <!-- функция получит аргументы emit -->
<SearchBox @search="(q) => (query = q)" />          <!-- inline-стрелка -->
<SearchBox @search="track('search', $event)" />     <!-- $event — первый аргумент -->
<BaseModal @close.once="onFirstClose" />            <!-- модификатор once работает и для компонентов -->
```

## События и колбэк-props

```vue
<!-- emit -->
<Uploader @done="onDone" />

<!-- колбэк-prop (как в React) — возможно, но менее идиоматично -->
<Uploader :on-done="onDone" />
```

Событие лучше документирует контракт и не требует проверки «передан ли колбэк». Колбэк-prop уместен, когда нужен **возврат значения** от родителя (например, асинхронная валидация).

## Не всплывают

```text
Page ─► List ─► Item: emit('remove')
                 ↑ слушает только List; до Page событие само не дойдёт
```

Пробрасывать события через несколько уровней (`@remove="$emit('remove', $event)"`) неудобно — используйте provide/inject или стор.

## Events и $attrs

Если событие **не объявлено** в `defineEmits`, слушатель `@click` из родителя считается fallthrough-атрибутом и вешается на корневой элемент ребёнка как нативный обработчик. Объявляйте все события компонента, чтобы не получать двойных срабатываний (нативный `click` + свой `emit('click')`).

## Частые ошибки

- Не объявлять события — конфликты с нативными событиями и непонятный контракт.
- Ожидать всплытия события к дальнему предку.
- Использовать event bus (`$on`/`$off`) — в Vue 3 удалён.
- Вызывать `emit` с другим числом аргументов, чем объявлено.
- Изменять props вместо отправки события.

## Что важно помнить

- `defineEmits` с типами — контракт событий компонента.
- События идут только к непосредственному родителю.
- `update:xxx` — основа `v-model` компонентов.

## Мини-шпаргалка

- `const emit = defineEmits<{ name: [arg: T] }>()`.
- `emit('name', arg)`.
- Родитель: `@name="handler"`, `$event`.
- Options API: `emits: [...]`, `this.$emit(...)`.
