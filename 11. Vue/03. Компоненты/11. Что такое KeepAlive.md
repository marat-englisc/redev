# Что такое KeepAlive

> [!NOTE]
> `<KeepAlive>` — встроенный компонент, который **кеширует экземпляры** переключаемых дочерних компонентов вместо их уничтожения. Без него при переключении вкладки или маршрута компонент размонтируется, и его состояние (введённый текст, позиция прокрутки, загруженные данные) теряется; с ним — компонент **деактивируется** (DOM убирается, экземпляр остаётся в памяти) и при возврате **активируется** снова без повторного создания. Для реакции на эти переходы есть хуки **`onActivated`** и **`onDeactivated`** (вызываются и при первом монтировании, и при каждом возврате/уходе) — в них обновляют устаревшие данные, останавливают таймеры и подписки. Управлять кешем можно через `include` / `exclude` (по **имени** компонента: строка, RegExp или массив) и `max` — максимальное число экземпляров (LRU: при переполнении удаляется давно не использованный). С Vue Router кеширование страниц делают через слот `<RouterView v-slot="{ Component }">`. KeepAlive экономит загрузки и сохраняет UX, но расходует память — кешируют только то, к чему пользователь часто возвращается.

## Вопрос

Что такое `<KeepAlive>` и когда его использовать?

## Вкладки

```vue
<template>
  <KeepAlive :max="5">
    <component :is="tabs[activeTab]" />
  </KeepAlive>
</template>
```

Текст в форме на вкладке «Профиль» сохранится после перехода на «Безопасность» и обратно.

## С Vue Router

```vue
<!-- App.vue -->
<template>
  <RouterView v-slot="{ Component, route }">
    <KeepAlive :include="['ProductList', 'SearchResults']">
      <component :is="Component" :key="route.name" />
    </KeepAlive>
  </RouterView>
</template>
```

```vue
<!-- ProductList.vue -->
<script setup lang="ts">
defineOptions({ name: 'ProductList' });     // include/exclude сопоставляются по имени компонента
</script>
```

Список товаров сохранит загруженные данные и фильтры при возврате со страницы товара. Позицию прокрутки окна восстанавливает `scrollBehavior` роутера.

## Хуки активации

```ts
let timer: ReturnType<typeof setInterval> | undefined;

onActivated(() => {
  refreshIfStale();                        // данные могли устареть, пока компонент был скрыт
  timer = setInterval(poll, 30_000);
});

onDeactivated(() => {
  clearInterval(timer);                    // не тратим ресурсы в фоне
});
```

`onMounted`/`onUnmounted` при этом вызываются только при реальном создании и удалении экземпляра (в том числе при вытеснении из кеша по `max`).

## include, exclude, max

```vue
<KeepAlive include="ProductList,Search">        <!-- строка через запятую -->
<KeepAlive :include="/^Report/">                 <!-- RegExp -->
<KeepAlive :exclude="['Checkout']">              <!-- не кешировать -->
<KeepAlive :max="10">                            <!-- LRU-кеш на 10 экземпляров -->
```

Для `<script setup>` имя выводится из имени файла; явно — `defineOptions({ name })`.

## Когда использовать

| Хорошо | Плохо |
| --- | --- |
| Вкладки с формами | Страницы с чувствительными данными (оплата) |
| Список → детальная страница → назад | Тяжёлые страницы без ограничения `max` |
| Дорогие по загрузке дашборды | Данные, которые обязаны быть всегда свежими |

## Частые ошибки

- `include` по имени, которое не совпадает с именем компонента.
- Таймеры и подписки продолжают работать в деактивированном компоненте (нет `onDeactivated`).
- Неограниченный кеш — рост памяти.
- Ожидать `onMounted` при каждом возврате на вкладку.
- KeepAlive вокруг нескольких прямых детей — он работает с одним активным ребёнком.

## Что важно помнить

- KeepAlive кеширует экземпляры, сохраняя состояние между переключениями.
- `onActivated`/`onDeactivated` — обновить данные и остановить фоновые процессы.
- `include`/`exclude` по имени, `max` — ограничение памяти.

## Мини-шпаргалка

- `<KeepAlive><component :is="X" /></KeepAlive>`.
- `<RouterView v-slot="{ Component }"><KeepAlive>...</KeepAlive></RouterView>`.
- `include`, `exclude`, `max`.
- `onActivated`, `onDeactivated`, `defineOptions({ name })`.
