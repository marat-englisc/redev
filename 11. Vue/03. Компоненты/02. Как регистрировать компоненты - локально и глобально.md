# Как регистрировать компоненты - локально и глобально

> [!NOTE]
> Чтобы использовать компонент в шаблоне, его нужно **зарегистрировать**. **Локальная регистрация** — компонент доступен только там, где импортирован: в `<script setup>` достаточно `import ProductCard from './ProductCard.vue'` (импорт сразу доступен в шаблоне), в Options API — перечислить в опции `components`. **Глобальная регистрация** — `app.component('BaseButton', BaseButton)` в `main.ts` делает компонент доступным во всём приложении без импорта. Локальная регистрация предпочтительна: зависимости видны явно, неиспользуемые компоненты удаляются при сборке (tree shaking), IDE и TypeScript лучше понимают код. Глобально регистрируют лишь действительно повсеместные базовые компоненты — или используют **автоимпорт** (`unplugin-vue-components`, в Nuxt — встроенный), который даёт удобство глобальной регистрации без её недостатков. В шаблонах SFC компоненты обычно пишут в **PascalCase** (`<ProductCard />`), в DOM-шаблонах (HTML на странице) — только **kebab-case**.

## Вопрос

Как регистрировать компоненты во Vue и чем локальная регистрация отличается от глобальной?

## Локальная регистрация

```vue
<!-- script setup -->
<script setup lang="ts">
import ProductCard from '@/components/ProductCard.vue';
import { defineAsyncComponent } from 'vue';

const ReviewsBlock = defineAsyncComponent(() => import('@/components/ReviewsBlock.vue'));   // ленивый
</script>

<template>
  <ProductCard :product="product" />
  <ReviewsBlock v-if="showReviews" :product-id="product.id" />
</template>
```

```js
// Options API
import ProductCard from './ProductCard.vue';

export default {
  components: { ProductCard },
};
```

## Глобальная регистрация

```ts
// main.ts
import BaseButton from './components/base/BaseButton.vue';
import BaseIcon from './components/base/BaseIcon.vue';

app.component('BaseButton', BaseButton).component('BaseIcon', BaseIcon);
```

```ts
// регистрация всех base-компонентов через Vite glob
const modules = import.meta.glob('./components/base/*.vue', { eager: true });
for (const [path, mod] of Object.entries(modules)) {
  const name = path.split('/').pop()!.replace('.vue', '');
  app.component(name, (mod as any).default);
}
```

```ts
// типизация глобальных компонентов
declare module 'vue' {
  interface GlobalComponents {
    BaseButton: typeof import('./components/base/BaseButton.vue')['default'];
  }
}
```

## Сравнение

| | Локальная | Глобальная |
| --- | --- | --- |
| Видимость | Только в импортировавшем компоненте | Везде |
| Tree shaking | Да | Нет — попадает в бандл, даже если не используется |
| Явность зависимостей | Видно по импортам | Неясно, откуда компонент |
| Типизация | Автоматически | Нужно объявить `GlobalComponents` |
| Где уместна | По умолчанию | UI-кит, повсеместные базовые компоненты, плагины |

## Автоимпорт

```ts
// vite.config.ts
import Components from 'unplugin-vue-components/vite';

export default defineConfig({
  plugins: [vue(), Components({ dirs: ['src/components'], dts: 'src/components.d.ts' })],
});
```

Плагин сам добавляет импорты используемых компонентов при сборке и генерирует типы — tree shaking сохраняется.

## Именование

| Где | Как писать |
| --- | --- |
| Имя файла и импорт | `ProductCard.vue`, `import ProductCard` |
| Шаблон SFC | `<ProductCard />` или `<product-card />` |
| DOM-шаблон (in-DOM HTML) | Только `<product-card></product-card>` (HTML нечувствителен к регистру, нет самозакрывающихся тегов) |
| Имена из нескольких слов | `TodoItem`, а не `Todo` — чтобы не конфликтовать с HTML-элементами |

## Частые ошибки

- Глобально регистрировать все компоненты «для удобства» — раздутый бандл.
- Использовать компонент без импорта в `<script setup>` и без автоимпорта — «Failed to resolve component».
- Однословные имена компонентов (`Header`, `Button`) — конфликт с HTML.
- PascalCase и самозакрывающиеся теги в DOM-шаблонах.

## Что важно помнить

- По умолчанию — локальная регистрация через импорт.
- Глобальная — только для повсеместных компонентов; удобная альтернатива — автоимпорт.
- PascalCase в SFC, kebab-case в DOM-шаблонах, имена из нескольких слов.

## Мини-шпаргалка

- `<script setup>`: `import X from './X.vue'`.
- Options API: `components: { X }`.
- `app.component('X', X)`.
- `defineAsyncComponent(() => import('./X.vue'))`.
- `unplugin-vue-components`.
