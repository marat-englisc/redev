# Что такое props

> [!NOTE]
> **Props** — входные параметры компонента, через которые родитель передаёт ему данные. В `<script setup>` они объявляются макросом **`defineProps`**: с TypeScript-типом (`defineProps<{ title: string; count?: number }>()`) или runtime-объектом (`{ title: { type: String, required: true } }`). Значения по умолчанию задаются через **`withDefaults`** или, в Vue 3.5+, через **деструктуризацию** с умолчаниями (`const { size = 'md' } = defineProps<...>()`). Props **реактивны** и доступны в шаблоне напрямую; в скрипте — через объект `props` (или деструктурированные переменные в 3.5+). Передаются через атрибуты: статические (`title="Привет"`), динамические (`:count="n"`), объект целиком (`v-bind="obj"`), булевы (`<Btn disabled />` = `true`). Имена объявляют в camelCase, в шаблонах родителя пишут в kebab-case или camelCase. Props **только для чтения** — ребёнок не должен их менять; для изменения отправляет событие. Всё, что передано, но не объявлено как prop, попадает в `$attrs` (fallthrough-атрибуты).

## Вопрос

Что такое props во Vue и как их объявлять и передавать?

## Объявление с TypeScript

```vue
<script setup lang="ts">
interface Props {
  title: string;
  count?: number;
  size?: 'sm' | 'md' | 'lg';
  tags?: string[];
  user: { id: string; name: string };
}

// Vue 3.5+: деструктуризация с умолчаниями (реактивна)
const { title, count = 0, size = 'md', tags = () => [], user } = defineProps<Props>();
</script>

<template>
  <h2 :class="`title-${size}`">{{ title }} ({{ count }})</h2>
  <span v-for="t in tags" :key="t">{{ t }}</span>
</template>
```

```ts
// до 3.5 / без деструктуризации
const props = withDefaults(defineProps<Props>(), {
  count: 0,
  size: 'md',
  tags: () => [],              // объекты и массивы — фабрикой
});
props.title;
```

## Runtime-объявление

```ts
const props = defineProps({
  title: { type: String, required: true },
  count: { type: Number, default: 0 },
  size: { type: String as PropType<'sm' | 'md' | 'lg'>, default: 'md', validator: (v: string) => ['sm', 'md', 'lg'].includes(v) },
  tags: { type: Array as PropType<string[]>, default: () => [] },
});
```

Runtime-валидация (`type`, `required`, `validator`) выдаёт предупреждения в dev-режиме.

## Передача props

```vue
<UserCard
  title="Профиль"                    <!-- строка -->
  :count="unread"                    <!-- выражение -->
  :tags="['vip', 'beta']"
  :user="currentUser"
  is-online                          <!-- boolean prop = true -->
/>

<UserCard v-bind="cardProps" />      <!-- все свойства объекта как props -->
<UserCard :title />                  <!-- 3.4+: сокращение для :title="title" -->
```

## Реактивность props

```ts
const props = defineProps<{ userId: string }>();

const userIdCopy = props.userId;               // ✗ копия, не обновится
watch(() => props.userId, load);               // ✓ геттер
const isMine = computed(() => props.userId === me.id);   // ✓

// 3.5+
const { userId } = defineProps<{ userId: string }>();
watch(() => userId, load);                     // ✓ компилятор превращает в props.userId
useUser(() => userId);                         // ✓ геттер; useUser(userId) передаст значение
```

## Boolean casting

```ts
defineProps<{ disabled?: boolean }>();
```

| В шаблоне | Значение |
| --- | --- |
| `<Btn />` | `false` |
| `<Btn disabled />` | `true` |
| `<Btn :disabled="false" />` | `false` |

## Что передавать через props

- Данные для отображения и настройки поведения.
- Колбэки обычно заменяют событиями (`emit`) — так понятнее контракт.
- Большие объекты — по ссылке (это дёшево), но не мутируйте их в ребёнке.

## Частые ошибки

- Изменять prop в ребёнке (`props.count++`) — предупреждение и рассинхронизация.
- Мутировать объект/массив из prop — технически работает, но ломает однонаправленный поток.
- Значение по умолчанию для массива/объекта без фабрики.
- Копировать prop в локальную переменную и ждать обновлений.
- Передавать число строкой: `count="5"` вместо `:count="5"`.

## Что важно помнить

- `defineProps` с типами; умолчания — `withDefaults` или деструктуризация 3.5+.
- Props реактивны, но только для чтения.
- В watch и composables передают геттер, а не значение.

## Мини-шпаргалка

- `defineProps<{ a: string; b?: number }>()`.
- `withDefaults(defineProps<P>(), { b: 0, list: () => [] })`.
- `:prop="expr"`, `v-bind="obj"`, `:prop` (3.4+).
- `watch(() => props.x, cb)`.
