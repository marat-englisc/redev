# Что такое fallthrough attributes - attrs и inheritAttrs

> [!NOTE]
> **Fallthrough attributes** — атрибуты и слушатели событий, переданные компоненту, но **не объявленные** им как props или emits: `class`, `style`, `id`, `aria-*`, `data-*`, `@click` и любые другие. По умолчанию Vue **автоматически добавляет** их к **корневому элементу** компонента; `class` и `style` при этом **объединяются** с собственными классами корня, а слушатели — добавляются к существующим. Это удобно для обёрток: `<BaseButton class="wide" aria-label="Сохранить" @click="save">` работает «как обычная кнопка». Если корней несколько (фрагмент) или атрибуты нужно передать **не на корень** (например, на `<input>` внутри `<label>`), автоматическое наследование отключают **`defineOptions({ inheritAttrs: false })`** и привязывают атрибуты вручную через **`v-bind="$attrs"`** (в скрипте — `useAttrs()`). `$attrs` не реактивен для отслеживания в `watch` — для этого используют props. В Vue 3 слушатели (`$listeners` из Vue 2) входят в `$attrs`.

## Вопрос

Что такое fallthrough-атрибуты, `$attrs` и `inheritAttrs` во Vue?

## Наследование на корень

```vue
<!-- BaseButton.vue -->
<script setup lang="ts">
defineProps<{ variant?: 'primary' | 'ghost' }>();
</script>

<template>
  <button class="btn" :class="variant"><slot /></button>
</template>
```

```vue
<BaseButton variant="primary" class="wide" type="submit" aria-label="Сохранить" @click="save">
  Сохранить
</BaseButton>
```

```html
<!-- результат -->
<button class="btn primary wide" type="submit" aria-label="Сохранить">Сохранить</button>
<!-- @click навешен на <button> -->
```

## Передача на внутренний элемент

```vue
<!-- BaseInput.vue -->
<script setup lang="ts">
defineOptions({ inheritAttrs: false });
const model = defineModel<string>();
defineProps<{ label: string; error?: string }>();
</script>

<template>
  <label class="field" :class="$attrs.class">
    <span>{{ label }}</span>
    <input v-model="model" v-bind="{ ...$attrs, class: undefined }" :aria-invalid="!!error" />
    <small v-if="error">{{ error }}</small>
  </label>
</template>
```

```vue
<BaseInput v-model="email" label="Email" type="email" placeholder="you@example.com" autocomplete="email" class="mb-4" />
<!-- type, placeholder, autocomplete → на <input>, class → на <label> -->
```

## useAttrs в скрипте

```ts
import { useAttrs } from 'vue';

const attrs = useAttrs();
const hasClickListener = computed(() => 'onClick' in attrs);   // слушатели — как onXxx
```

`attrs` всегда актуален, но **не реактивен** для `watch`/`computed` в смысле отслеживания; если поведение зависит от значения — объявите prop.

## Несколько корней

```vue
<template>
  <header>...</header>
  <main v-bind="$attrs">...</main>     <!-- явно указать, куда; иначе предупреждение -->
  <footer>...</footer>
</template>
```

## Вложенные компоненты

Если корень компонента — другой компонент, атрибуты пробрасываются **дальше** к его корню (за вычетом того, что он объявил как props/emits).

## Что попадает в $attrs

| Передано родителем | Объявлено в ребёнке | Где окажется |
| --- | --- | --- |
| `title="x"` | `defineProps(['title'])` | `props.title` |
| `title="x"` | Не объявлено | `$attrs.title` → корень |
| `@close` | `defineEmits(['close'])` | Событие компонента |
| `@close` | Не объявлено | `$attrs.onClose` → нативный слушатель корня |
| `class`, `style` | — | Объединяются с классами корня |

## Частые ошибки

- Обёртка над `<input>`, где атрибуты попадают на `<label>` вместо поля.
- Необъявленный `@click`, который срабатывает дважды (нативный + свой `emit('click')`).
- Фрагмент без `v-bind="$attrs"` — предупреждение и потерянные атрибуты.
- `inheritAttrs: false`, но забыли привязать `$attrs` — `aria-*` и `data-testid` пропадают.

## Что важно помнить

- Необъявленные атрибуты и слушатели наследуются корнем, `class`/`style` объединяются.
- `inheritAttrs: false` + `v-bind="$attrs"` — передать на нужный элемент.
- Объявляйте props и emits, чтобы контролировать, что «проваливается».

## Мини-шпаргалка

- `defineOptions({ inheritAttrs: false })`.
- `v-bind="$attrs"`.
- `useAttrs()`.
- Слушатели в `$attrs` — `onClick`, `onUpdate:modelValue`.
