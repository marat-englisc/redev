# Что такое template refs, useTemplateRef и defineExpose

> [!NOTE]
> **Template ref** — прямая ссылка на DOM-элемент или экземпляр дочернего компонента, нужная там, где декларативности не хватает: фокус поля, прокрутка, измерение размеров, интеграция со сторонними библиотеками (карты, графики, редакторы), вызов метода дочернего компонента. В шаблоне элемент помечают атрибутом **`ref="name"`**, а в скрипте получают ссылку через **`useTemplateRef<HTMLInputElement>('name')`** (Vue 3.5+) или, по-старому, через `const name = ref<HTMLInputElement | null>(null)` с тем же именем переменной. Ссылка заполняется **после монтирования** (в `onMounted`; до этого `null`) и обнуляется при удалении элемента (`v-if`). В `v-for` ref содержит **массив** элементов (порядок не гарантирован). Компоненты на `<script setup>` **закрыты по умолчанию**: родитель через ref видит только то, что ребёнок явно открыл макросом **`defineExpose({ focus, reset })`**. Используйте template refs точечно: данные и состояние передаются через props/события, а не через вызовы методов ребёнка.

## Вопрос

Как получить доступ к DOM-элементу или дочернему компоненту во Vue?

## useTemplateRef (Vue 3.5+)

```vue
<script setup lang="ts">
import { useTemplateRef, onMounted } from 'vue';

const input = useTemplateRef<HTMLInputElement>('search');

onMounted(() => input.value?.focus());
</script>

<template>
  <input ref="search" type="search" />
</template>
```

## Классический способ

```vue
<script setup lang="ts">
const search = ref<HTMLInputElement | null>(null);   // имя переменной = значение атрибута ref
onMounted(() => search.value?.focus());
</script>

<template>
  <input ref="search" />
</template>
```

## Когда ref доступен

```ts
const box = useTemplateRef<HTMLDivElement>('box');

console.log(box.value);           // null — ещё не смонтировано
onMounted(() => console.log(box.value));         // элемент
watch(box, (el) => { if (el) observe(el); });    // реакция на появление/исчезновение (v-if)
```

После изменения данных, влияющих на DOM, — `await nextTick()` перед чтением размеров.

## ref в v-for

```vue
<script setup lang="ts">
const items = useTemplateRef<HTMLLIElement[]>('items');
</script>

<template>
  <li v-for="m in messages" :key="m.id" ref="items">{{ m.text }}</li>
</template>
```

## Функциональный ref

```vue
<li v-for="m in messages" :key="m.id" :ref="(el) => setItemRef(m.id, el as HTMLElement | null)" />
```

Удобно, когда нужен `Map` по id вместо массива.

## Ref на компонент и defineExpose

```vue
<!-- SearchField.vue -->
<script setup lang="ts">
const input = useTemplateRef<HTMLInputElement>('input');
const model = defineModel<string>({ default: '' });

function focus() { input.value?.focus(); }
function clear() { model.value = ''; }

defineExpose({ focus, clear });     // только это видно родителю
</script>

<template>
  <input ref="input" v-model="model" />
</template>
```

```vue
<!-- родитель -->
<script setup lang="ts">
import SearchField from './SearchField.vue';

const field = useTemplateRef<InstanceType<typeof SearchField>>('field');
// или: ComponentExposed<typeof SearchField> из vue-component-type-helpers

function onShortcut() { field.value?.focus(); }
</script>

<template>
  <SearchField ref="field" v-model="q" />
</template>
```

## Интеграция со сторонними библиотеками

```ts
const el = useTemplateRef<HTMLDivElement>('chart');
let chart: Chart | null = null;

onMounted(() => { chart = new Chart(el.value!, config); });
watch(data, (d) => chart?.update(d), { deep: true });
onBeforeUnmount(() => chart?.destroy());      // освободить ресурсы
```

## Когда template refs — неправильный инструмент

| Вместо | Используйте |
| --- | --- |
| `childRef.value.items = [...]` | Prop `items` |
| `childRef.value.open()` для каждого действия | `v-model:open` |
| `document.querySelector` внутри компонента | Template ref |
| Чтение значения поля через ref | `v-model` |

## Частые ошибки

- Обращаться к ref до `onMounted` или в `setup` синхронно.
- Ожидать доступа к внутренним переменным `<script setup>` ребёнка без `defineExpose`.
- Не освобождать ресурсы сторонних библиотек при размонтировании.
- Управлять дочерним компонентом через ref там, где хватит props/событий.

## Что важно помнить

- `ref="name"` в шаблоне + `useTemplateRef('name')` (3.5+) в скрипте.
- Значение доступно после монтирования, при `v-if` может стать `null`.
- `<script setup>` закрыт; родитель видит только `defineExpose`.

## Мини-шпаргалка

- `useTemplateRef<HTMLElement>('x')`.
- `onMounted(() => x.value?.focus())`.
- `defineExpose({ method })`.
- `InstanceType<typeof Comp>`.
- `:ref="(el) => ..."`.
