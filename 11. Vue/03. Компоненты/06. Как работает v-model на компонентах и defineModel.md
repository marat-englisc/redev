# Как работает v-model на компонентах и defineModel

> [!NOTE]
> На компоненте `v-model="value"` — синтаксический сахар для пары **`:modelValue="value"`** + **`@update:modelValue="v => value = v"`**. Компонент должен принять prop `modelValue` и отправлять событие `update:modelValue` с новым значением. С **Vue 3.4** это делается одной строкой — макросом **`defineModel()`**: он возвращает ref, чтение которого отдаёт текущий prop, а запись — эмитит событие (при отсутствии `v-model` у родителя работает как локальное состояние). Поддерживаются **несколько моделей** с аргументами (`v-model:title`, `v-model:content` → `defineModel('title')`), опции `required`, `default`, `type`, а также **модификаторы**: встроенные `.trim`, `.number`, `.lazy` для нативных полей и свои (`v-model.capitalize`), которые компонент получает и применяет через `get`/`set` в `defineModel`. До 3.4 то же писали вручную: `defineProps` + `defineEmits` + записываемый `computed`. В Vue 2 модель называлась `value`/`input` — это изменение важно при миграции.

## Вопрос

Как реализовать `v-model` в собственном компоненте и что делает `defineModel`?

## defineModel (Vue 3.4+)

```vue
<!-- BaseInput.vue -->
<script setup lang="ts">
const model = defineModel<string>({ required: true });
defineProps<{ label: string }>();
</script>

<template>
  <label>
    {{ label }}
    <input v-model="model" />
  </label>
</template>
```

```vue
<!-- родитель -->
<BaseInput v-model="email" label="Email" />
<!-- ≡ <BaseInput :modelValue="email" @update:modelValue="v => email = v" /> -->
```

## Вручную (до 3.4)

```vue
<script setup lang="ts">
const props = defineProps<{ modelValue: string }>();
const emit = defineEmits<{ 'update:modelValue': [value: string] }>();

const value = computed({
  get: () => props.modelValue,
  set: (v) => emit('update:modelValue', v),
});
</script>

<template>
  <input v-model="value" />
</template>
```

## Несколько моделей

```vue
<!-- UserName.vue -->
<script setup lang="ts">
const firstName = defineModel<string>('firstName');
const lastName = defineModel<string>('lastName');
</script>

<template>
  <input v-model="firstName" />
  <input v-model="lastName" />
</template>
```

```vue
<UserName v-model:first-name="form.first" v-model:last-name="form.last" />
```

## Свои модификаторы

```vue
<!-- родитель -->
<BaseInput v-model.capitalize="title" />
```

```vue
<script setup lang="ts">
const [model, modifiers] = defineModel<string, 'capitalize'>({
  set(value) {
    return modifiers.capitalize ? value.charAt(0).toUpperCase() + value.slice(1) : value;
  },
});
</script>
```

## Не только инпуты

```vue
<!-- Toggle, Modal, Tabs — любой компонент со «значением» -->
<BaseModal v-model:open="isDialogOpen" />
<TabsBar v-model="activeTab" :tabs="tabs" />
<RatingStars v-model="rating" :max="5" />
```

```vue
<!-- BaseModal.vue -->
<script setup lang="ts">
const open = defineModel<boolean>('open', { default: false });
</script>

<template>
  <Teleport to="body">
    <div v-if="open" class="backdrop" @click.self="open = false">
      <slot />
    </div>
  </Teleport>
</template>
```

## Как это компилируется

| Родитель | Ребёнок получает |
| --- | --- |
| `v-model="x"` | prop `modelValue`, событие `update:modelValue` |
| `v-model:title="x"` | prop `title`, событие `update:title` |
| `v-model.trim="x"` | prop `modelModifiers: { trim: true }` |
| `v-model:title.upper="x"` | prop `titleModifiers: { upper: true }` |

## Частые ошибки

- Менять `props.modelValue` напрямую.
- Объект в `defineModel` и мутация его полей (`model.value.name = 'x'`) — событие не эмитится, а родительский объект меняется «молча»; лучше заменять целиком (`model.value = { ...model.value, name }`).
- Ожидать `value`/`input` как в Vue 2.
- Разное название модели у родителя и ребёнка (`v-model:open` vs `defineModel('isOpen')`).

## Что важно помнить

- `v-model` на компоненте = `modelValue` + `update:modelValue`.
- `defineModel()` (3.4+) — ref, запись в который эмитит событие.
- Несколько моделей — аргументы; модификаторы — через `set` в `defineModel`.

## Мини-шпаргалка

- `const model = defineModel<T>({ required, default })`.
- `defineModel<T>('name')` ↔ `v-model:name`.
- `const [model, mods] = defineModel({ set })`.
- Вручную: `modelValue` + `emit('update:modelValue')` + `computed({ get, set })`.
