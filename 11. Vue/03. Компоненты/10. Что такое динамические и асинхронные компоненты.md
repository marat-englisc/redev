# Что такое динамические и асинхронные компоненты

> [!NOTE]
> **Динамический компонент** — специальный элемент `<component :is="X" />`, который рендерит компонент, выбранный во время выполнения: `:is` принимает объект компонента (импорт), зарегистрированное имя или строку HTML-тега. Так делают вкладки, шаги мастера, рендер блоков контента из CMS по типу, полиморфные обёртки (`<component :is="href ? 'a' : 'button'">`). При смене `:is` старый компонент **размонтируется** (состояние теряется), если не обернуть его в `<KeepAlive>`. **Асинхронный компонент** создаётся через **`defineAsyncComponent(() => import('./X.vue'))`**: его код загружается отдельным чанком только при первом рендере — это **code splitting** на уровне компонентов (тяжёлые редакторы, графики, модальные окна, редко используемые разделы). Расширенная форма принимает `loadingComponent`, `errorComponent`, `delay`, `timeout`, а в SSR — стратегии **ленивой гидрации** (`hydrate: hydrateOnVisible()` и др., Vue 3.5+). Асинхронные компоненты также работают с `<Suspense>`.

## Вопрос

Что такое динамические и асинхронные компоненты во Vue и когда их использовать?

## Динамический компонент

```vue
<script setup lang="ts">
import ProfileTab from './tabs/ProfileTab.vue';
import SecurityTab from './tabs/SecurityTab.vue';
import BillingTab from './tabs/BillingTab.vue';

const tabs = { profile: ProfileTab, security: SecurityTab, billing: BillingTab } as const;
const current = ref<keyof typeof tabs>('profile');
</script>

<template>
  <nav>
    <button v-for="(_, key) in tabs" :key="key" @click="current = key">{{ key }}</button>
  </nav>

  <KeepAlive>
    <component :is="tabs[current]" />      <!-- KeepAlive сохраняет состояние вкладок -->
  </KeepAlive>
</template>
```

## Рендер блоков из CMS

```vue
<script setup lang="ts">
const registry: Record<string, Component> = {
  hero: HeroBlock,
  text: TextBlock,
  gallery: defineAsyncComponent(() => import('./blocks/GalleryBlock.vue')),
};
defineProps<{ blocks: { id: string; type: string; data: unknown }[] }>();
</script>

<template>
  <component
    v-for="block in blocks"
    :key="block.id"
    :is="registry[block.type] ?? UnknownBlock"
    v-bind="block.data"
  />
</template>
```

## Полиморфный элемент

```vue
<script setup lang="ts">
const props = defineProps<{ href?: string; to?: RouteLocationRaw }>();
const tag = computed(() => (props.to ? RouterLink : props.href ? 'a' : 'button'));
</script>

<template>
  <component :is="tag" :href="href" :to="to" class="btn"><slot /></component>
</template>
```

## Асинхронный компонент

```ts
import { defineAsyncComponent } from 'vue';

const RichEditor = defineAsyncComponent(() => import('./RichEditor.vue'));

const Chart = defineAsyncComponent({
  loader: () => import('./SalesChart.vue'),
  loadingComponent: ChartSkeleton,
  errorComponent: LoadError,
  delay: 200,          // показать loading только если загрузка дольше 200 мс
  timeout: 10_000,     // после — errorComponent
});
```

```vue
<RichEditor v-if="isEditing" v-model="content" />   <!-- чанк загрузится при первом isEditing = true -->
```

## Ленивая гидрация (SSR, Vue 3.5+)

```ts
import { defineAsyncComponent, hydrateOnVisible, hydrateOnIdle, hydrateOnInteraction } from 'vue';

const Comments = defineAsyncComponent({
  loader: () => import('./Comments.vue'),
  hydrate: hydrateOnVisible(),           // гидрировать, когда блок попадёт в viewport
});
```

Варианты: `hydrateOnIdle()`, `hydrateOnVisible()`, `hydrateOnMediaQuery('(max-width: 768px)')`, `hydrateOnInteraction('click')`. В Nuxt есть сокращения `hydrate-on-visible` на компонентах.

## Когда использовать

| Задача | Решение |
| --- | --- |
| Переключаемые вкладки/шаги | `<component :is>` (+ `KeepAlive`) |
| Блоки страницы по данным | Реестр компонентов + `:is` |
| Тяжёлый, редко нужный компонент | `defineAsyncComponent` |
| Страницы | Ленивые маршруты в Vue Router (`component: () => import(...)`) |
| Модальные окна | Асинхронный компонент + `v-if` |

## Частые ошибки

- Передавать в `:is` строку с именем незарегистрированного компонента в `<script setup>` — нужен объект.
- Хранить компонент в `ref` (лишний глубокий Proxy) — используйте `shallowRef` или `markRaw`.
- Не обрабатывать ошибку загрузки чанка (`errorComponent`, повтор).
- Делать асинхронными мелкие компоненты — накладные расходы на запросы больше выигрыша.

## Что важно помнить

- `<component :is>` выбирает компонент во время выполнения; при смене состояние теряется без `KeepAlive`.
- `defineAsyncComponent` — отдельный чанк, загрузка при первом рендере.
- В SSR (3.5+) — стратегии ленивой гидрации.

## Мини-шпаргалка

- `<component :is="Comp" v-bind="props" />`.
- `const current = shallowRef(Comp)`.
- `defineAsyncComponent(() => import('./X.vue'))`.
- `{ loader, loadingComponent, errorComponent, delay, timeout, hydrate }`.
