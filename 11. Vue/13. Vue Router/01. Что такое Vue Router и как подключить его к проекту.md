# Что такое Vue Router и как подключить его к проекту

> [!NOTE]
> **Vue Router** — официальный роутер Vue для SPA: он сопоставляет URL с компонентами и меняет содержимое страницы **без полной перезагрузки**, используя History API браузера. Приложение описывает таблицу маршрутов (`routes`: путь → компонент), создаёт роутер `createRouter({ history, routes })` и подключает его плагином `app.use(router)`. В шаблоне `<RouterView />` — место, куда рендерится компонент текущего маршрута, `<RouterLink to="...">` — ссылка, которая перехватывает клик и выполняет клиентскую навигацию (с активными классами, prefetch-логикой оставляется приложению). Режимы истории: **`createWebHistory()`** — «чистые» URL (`/products/42`), требует, чтобы сервер отдавал `index.html` на любые пути (fallback); **`createWebHashHistory()`** — URL с `#` (`/#/products/42`), работает без настройки сервера, но хуже для SEO; **`createMemoryHistory()`** — для SSR и тестов. Актуальная версия — **Vue Router 5**: API совместим с v4 и дополнен встроенной файловой маршрутизацией (`vue-router/vite`).

## Вопрос

Что такое Vue Router и как подключить его к Vue-проекту?

## Как работает SPA-навигация

```text
Клик по <RouterLink to="/cart">
  → preventDefault (без перезагрузки)
  → router.push('/cart')
  → navigation guards
  → history.pushState('/cart')
  → <RouterView> рендерит CartPage
Кнопка «назад» → событие popstate → роутер рендерит предыдущий маршрут
```

## Подключение

```bash
npm install vue-router
```

```ts
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router';
import HomePage from '@/pages/HomePage.vue';

export const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', name: 'home', component: HomePage },
    { path: '/catalog', name: 'catalog', component: () => import('@/pages/CatalogPage.vue') },
    { path: '/product/:id', name: 'product', component: () => import('@/pages/ProductPage.vue'), props: true },
    { path: '/:pathMatch(.*)*', name: 'not-found', component: () => import('@/pages/NotFound.vue') },
  ],
  scrollBehavior: (to, from, saved) => saved ?? { top: 0 },
});

// main.ts
app.use(createPinia()).use(router).mount('#app');
```

```vue
<!-- App.vue -->
<template>
  <nav>
    <RouterLink to="/">Главная</RouterLink>
    <RouterLink :to="{ name: 'catalog' }">Каталог</RouterLink>
  </nav>
  <RouterView />
</template>
```

## RouterLink

```vue
<RouterLink :to="{ name: 'product', params: { id: p.id } }" active-class="is-active">{{ p.title }}</RouterLink>
<RouterLink to="/cart" replace>Корзина</RouterLink>          <!-- replace вместо push -->
<RouterLink to="/docs" exact-active-class="current">Docs</RouterLink>
```

| Класс | Когда добавляется |
| --- | --- |
| `router-link-active` | Текущий маршрут начинается с этого пути (вложенные) |
| `router-link-exact-active` | Полное совпадение |

## Режимы истории

| Режим | URL | Сервер | SEO |
| --- | --- | --- | --- |
| `createWebHistory` | `/product/42` | Нужен fallback на `index.html` | Хорошо |
| `createWebHashHistory` | `/#/product/42` | Не нужен | Плохо |
| `createMemoryHistory` | Не меняет URL | — | SSR, тесты |

```nginx
location / {
  try_files $uri $uri/ /index.html;    # fallback для history mode
}
```

Без fallback прямой переход на `/product/42` вернёт 404 от сервера.

## Vue Router 5

```ts
// vite.config.ts — файловая маршрутизация (бывший unplugin-vue-router)
import VueRouter from 'vue-router/vite';
export default defineConfig({ plugins: [VueRouter(), vue()] });

// router/index.ts
import { routes } from 'vue-router/auto-routes';
export const router = createRouter({ history: createWebHistory(), routes });
```

## Частые ошибки

- `<a href="/cart">` вместо `RouterLink` — полная перезагрузка страницы.
- History mode без серверного fallback.
- Нет маршрута 404 (`/:pathMatch(.*)*`).
- Импортировать все страницы статически — большой начальный бандл.

## Что важно помнить

- Роутер сопоставляет URL с компонентами без перезагрузки страницы.
- `createRouter({ history, routes })` + `app.use(router)` + `RouterView`/`RouterLink`.
- History mode требует fallback на сервере.

## Мини-шпаргалка

- `createRouter({ history: createWebHistory(), routes })`.
- `<RouterView />`, `<RouterLink :to="{ name, params }">`.
- `/:pathMatch(.*)*` — 404.
- `try_files ... /index.html`.
