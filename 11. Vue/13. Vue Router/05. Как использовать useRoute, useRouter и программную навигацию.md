# Как использовать useRoute, useRouter и программную навигацию

> [!NOTE]
> В Composition API к роутеру обращаются через два composable. **`useRoute()`** возвращает **реактивный объект текущего маршрута**: `path`, `fullPath`, `name`, `params`, `query`, `hash`, `meta`, `matched`. Его свойства отслеживаются в `computed`/`watch` (следите за конкретным полем через геттер, а не за объектом целиком). **`useRouter()`** возвращает **экземпляр роутера** для навигации и управления: `push` (новая запись в истории), `replace` (замена текущей), `go(n)`/`back()`/`forward()`, `resolve` (получить URL без перехода), `addRoute`/`removeRoute`, `isReady`. Навигация **асинхронна**: `push` возвращает промис, который разрешается после прохождения guards и может вернуть **ошибку навигации** (`NavigationFailure`) — переход отменён guard-ом, дублирует текущий маршрут или прерван новым. В Options API те же объекты доступны как `this.$route` и `this.$router`. Вне компонентов используют импортированный экземпляр `router` (`router.currentRoute.value` — текущий маршрут).

## Вопрос

Как работать с текущим маршрутом и программной навигацией через `useRoute` и `useRouter`?

## useRoute

```vue
<script setup lang="ts">
const route = useRoute();

const productId = computed(() => route.params.id as string);
const tab = computed(() => (route.query.tab as string) ?? 'description');
const requiresAuth = computed(() => route.meta.requiresAuth === true);

watch(() => route.params.id, (id) => load(id as string), { immediate: true });   // геттер, не весь route
</script>

<template>
  <p>Путь: {{ route.fullPath }}</p>
</template>
```

## useRouter и навигация

```ts
const router = useRouter();

await router.push('/cart');
await router.push({ name: 'product', params: { id: '42' } });
await router.push({ name: 'catalog', query: { q: 'клавиатура', page: 1 } });
await router.push({ path: '/docs', hash: '#install' });

await router.replace({ name: 'login', query: { redirect: route.fullPath } });   // без записи в истории

router.back();       // = go(-1)
router.go(2);
```

## Переход после действия

```ts
async function submitOrder() {
  const order = await checkout.placeOrder();
  await router.push({ name: 'order-success', params: { id: order.id } });
}

async function login() {
  await auth.login(form);
  const redirect = typeof route.query.redirect === 'string' && route.query.redirect.startsWith('/') ? route.query.redirect : '/';
  await router.replace(redirect);           // проверка: только внутренние пути (защита от open redirect)
}
```

## Ошибки навигации

```ts
import { isNavigationFailure, NavigationFailureType } from 'vue-router';

const failure = await router.push('/admin');
if (isNavigationFailure(failure, NavigationFailureType.aborted)) {
  toast.info('Недостаточно прав');            // guard вернул false
}
if (isNavigationFailure(failure, NavigationFailureType.duplicated)) {
  // уже на этой странице
}
```

`push` не бросает исключение при отменённой навигации — проверяйте результат, если это важно.

## resolve

```ts
const { href } = router.resolve({ name: 'product', params: { id: '42' } });
window.open(href, '_blank');                   // открыть в новой вкладке
navigator.clipboard.writeText(location.origin + href);
```

## Вне компонентов

```ts
import { router } from '@/router';

export function handleUnauthorized() {
  const current = router.currentRoute.value;
  router.replace({ name: 'login', query: { redirect: current.fullPath } });
}
```

## Options API

```js
export default {
  computed: { id() { return this.$route.params.id; } },
  methods: { goToCart() { this.$router.push('/cart'); } },
};
```

## RouterLink или push

| `<RouterLink>` | `router.push` |
| --- | --- |
| Навигация по клику пользователя | После действия (отправка формы, логин) |
| Настоящая ссылка: открыть в новой вкладке, SEO, доступность | Условная логика, редиректы |
| Активные классы | — |

## Частые ошибки

- `watch(route, ...)` на весь объект — срабатывает на любое изменение; следите за конкретным полем.
- `@click="router.push(...)"` на `<div>` вместо `RouterLink` — нет ссылки для Ctrl+клик и доступности.
- Редирект на `route.query.redirect` без проверки — open redirect.
- Деструктурировать `const { params } = useRoute()` — потеря реактивности.
- Ожидать синхронный переход после `push` без `await`.

## Что важно помнить

- `useRoute` — реактивный текущий маршрут, `useRouter` — экземпляр для навигации.
- `push` добавляет запись в историю, `replace` — заменяет; оба асинхронны.
- Проверяйте результат навигации и безопасность редиректов.

## Мини-шпаргалка

- `const route = useRoute(); route.params.id`.
- `const router = useRouter(); await router.push({ name, params, query })`.
- `router.replace`, `router.back()`, `router.resolve()`.
- `isNavigationFailure(failure, NavigationFailureType.aborted)`.
