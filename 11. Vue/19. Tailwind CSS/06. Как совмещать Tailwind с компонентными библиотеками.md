# Как совмещать Tailwind с компонентными библиотеками

> [!NOTE]
> С Tailwind хорошо сочетаются три вида библиотек. **Headless-библиотеки** (Reka UI, Headless UI for Vue, Ark UI) дают поведение, управление фокусом, клавиатурную навигацию и ARIA для сложных виджетов (диалог, меню, combobox, tabs, popover), но не навязывают стилей — внешний вид полностью задаётся классами Tailwind; состояния компонентов отражаются в `data-*`-атрибутах (`data-[state=open]:`). **Готовые компоненты-исходники** вроде **shadcn-vue** копируются в проект (`npx shadcn-vue add button`) как обычные `.vue`-файлы на Reka UI + Tailwind + `cva` — это ваш код, который можно менять. **Стилизованные библиотеки** (Vuetify, PrimeVue, Element Plus) имеют собственный CSS, и совмещение с Tailwind требует решения конфликтов: **порядок каскада** (в Tailwind v4 стили лежат в слоях `theme`, `base`, `components`, `utilities`; объявите порядок `@layer` так, чтобы утилиты шли после стилей библиотеки, или подключайте CSS библиотеки внутри нужного слоя), **reset-стили** Preflight могут ломать внешний вид компонентов (отключается импортом частей Tailwind без `preflight.css`), **общие токены** — цвета темы библиотеки и `@theme` Tailwind лучше синхронизировать через CSS-переменные. Правило: Tailwind для своей раскладки и оформления, библиотека — для сложных компонентов; не переопределяйте внутренности стилизованных компонентов утилитами — используйте их API тем и props. PrimeVue предлагает **unstyled-режим** с passthrough-классами, где Tailwind становится основным источником стилей.

## Вопрос

Как использовать Tailwind вместе с компонентными UI-библиотеками во Vue?

## Headless: Reka UI

```vue
<script setup lang="ts">
import { DialogRoot, DialogTrigger, DialogPortal, DialogOverlay, DialogContent, DialogTitle, DialogDescription, DialogClose } from 'reka-ui';
</script>

<template>
  <DialogRoot>
    <DialogTrigger class="rounded-lg bg-indigo-600 px-4 py-2 text-white">Удалить</DialogTrigger>
    <DialogPortal>
      <DialogOverlay class="fixed inset-0 bg-black/50 data-[state=open]:animate-in data-[state=open]:fade-in" />
      <DialogContent class="fixed top-1/2 left-1/2 w-full max-w-md -translate-x-1/2 -translate-y-1/2 rounded-2xl bg-white p-6 shadow-xl">
        <DialogTitle class="text-lg font-semibold">Удалить заказ?</DialogTitle>
        <DialogDescription class="mt-2 text-sm text-slate-600">Действие нельзя отменить.</DialogDescription>
        <div class="mt-6 flex justify-end gap-2">
          <DialogClose class="rounded-lg px-4 py-2 hover:bg-slate-100">Отмена</DialogClose>
          <button class="rounded-lg bg-rose-600 px-4 py-2 text-white" @click="remove">Удалить</button>
        </div>
      </DialogContent>
    </DialogPortal>
  </DialogRoot>
</template>
```

Фокус-ловушка, закрытие по Esc, блокировка прокрутки, `aria-*` — уже внутри компонента. Классы `animate-in`/`fade-in` — из плагина `tw-animate-css`, который ставит shadcn-vue; без него используйте Vue `<Transition>` или свои анимации.

## shadcn-vue

```bash
npx shadcn-vue@latest init
npx shadcn-vue@latest add button dialog dropdown-menu
```

```text
src/components/ui/button/Button.vue      ← ваш код: cva-варианты + Tailwind
src/components/ui/dialog/...
src/lib/utils.ts                         ← cn() = twMerge(clsx())
```

## Vuetify + Tailwind

```css
/* main.css — порядок слоёв: сначала Vuetify, затем утилиты Tailwind */
@layer theme, base, vuetify-core, vuetify-components, vuetify-overrides, components, utilities, vuetify-utilities, vuetify-final;

@import "tailwindcss/theme.css" layer(theme);
@import "tailwindcss/utilities.css" layer(utilities);
/* preflight не подключаем — у Vuetify свои базовые стили */
```

```vue
<!-- Tailwind — для своей раскладки; компоненты — через их API -->
<div class="grid gap-6 lg:grid-cols-[1fr_20rem]">
  <v-card title="Заказы"><OrdersTable /></v-card>
  <v-card title="Фильтры" class="h-fit"><OrderFilters /></v-card>
</div>
```

Точный порядок слоёв зависит от того, должны ли утилиты Tailwind перекрывать утилиты Vuetify (`pa-4`); проверьте результат в DevTools.

## PrimeVue unstyled + Tailwind

```ts
import PrimeVue from 'primevue/config';

app.use(PrimeVue, {
  unstyled: true,
  pt: {
    button: {
      root: 'inline-flex items-center gap-2 rounded-lg bg-indigo-600 px-4 py-2 text-white hover:bg-indigo-500',
    },
  },
});
```

## Общие токены

```css
@theme {
  --color-primary: var(--brand-primary);       /* bg-primary в Tailwind */
}
:root { --brand-primary: #4f46e5; }            /* то же значение отдаём в тему библиотеки */
```

```ts
createVuetify({ theme: { themes: { light: { colors: { primary: '#4f46e5' } } } } });
```

## Что выбрать

| Подход | Когда |
| --- | --- |
| Tailwind + Reka UI / shadcn-vue | Свой дизайн, нужны доступные сложные виджеты |
| Tailwind + PrimeVue unstyled | Много готовых сложных компонентов, свой стиль |
| Vuetify + немного Tailwind | Админка в Material, Tailwind для раскладки |
| Только Vuetify | Быстрая внутренняя система без своего дизайна |

## Частые ошибки

- Preflight Tailwind ломает базовые стили стилизованной библиотеки.
- Неуправляемый порядок каскада — утилиты то работают, то нет.
- Переопределять внутренние классы компонентов (`.v-field__input`) утилитами.
- Две системы цветов без синхронизации — разные «primary» в одном интерфейсе.
- Писать сложные виджеты (combobox, dialog) с нуля на Tailwind без headless-библиотеки — ломается доступность.

## Что важно помнить

- Headless + Tailwind — максимум контроля над дизайном с готовой доступностью.
- Со стилизованными библиотеками — управлять слоями каскада и Preflight, синхронизировать токены.
- Tailwind для раскладки, библиотека — для компонентов через их API.

## Мини-шпаргалка

- `reka-ui`: `DialogRoot`, `DialogContent` + классы, `data-[state=open]:`.
- `npx shadcn-vue@latest add button`.
- `@layer ...;` + `@import "tailwindcss/utilities.css" layer(utilities)`.
- PrimeVue `{ unstyled: true, pt: {...} }`.
