# Что такое Tailwind CSS и зачем он во Vue

> [!NOTE]
> **Tailwind CSS** — utility-first CSS-фреймворк: вместо придумывания классов (`.product-card__title`) и написания CSS вы собираете стили из маленьких **утилит** прямо в разметке (`text-lg font-semibold text-slate-900`). Каждая утилита — одно-два CSS-свойства из **дизайн-системы** (шкалы отступов, цветов, размеров шрифта, радиусов), поэтому интерфейс получается единообразным без отдельного стайлгайда. Tailwind сканирует исходники и генерирует CSS **только для использованных классов** — итоговый файл обычно небольшой и почти не растёт с проектом. Варианты (`hover:`, `focus-visible:`, `md:`, `dark:`, `disabled:`, `group-hover:`) описывают состояния и адаптивность без отдельных селекторов. Во Vue это сочетается особенно хорошо: **компонент сам является единицей переиспользования** — повторяющийся набор классов выносится не в CSS-класс, а в компонент (`BaseButton.vue`), а динамика задаётся привязкой `:class`. Текущая версия — **Tailwind CSS v4**: движок на Rust, конфигурация в CSS (`@import "tailwindcss"` + `@theme`), автоматический поиск исходников, официальный плагин Vite `@tailwindcss/vite`, тема как CSS-переменные. Минусы: длинные строки классов, порог входа в словарь утилит, необходимость дисциплины (компоненты, сортировка классов, без «магических» значений).

## Вопрос

Что такое Tailwind CSS и почему его часто используют во Vue-проектах?

## Классический CSS и utility-first

```vue
<!-- Классический подход -->
<template>
  <article class="product-card">
    <h3 class="product-card__title">{{ product.title }}</h3>
  </article>
</template>

<style scoped>
.product-card { padding: 1rem; border-radius: 0.75rem; background: white; box-shadow: 0 1px 3px rgb(0 0 0 / 0.1); }
.product-card__title { font-size: 1.125rem; font-weight: 600; }
</style>
```

```vue
<!-- Tailwind -->
<template>
  <article class="rounded-xl bg-white p-4 shadow-sm">
    <h3 class="text-lg font-semibold">{{ product.title }}</h3>
  </article>
</template>
```

## Что даёт Tailwind

| Преимущество | Почему |
| --- | --- |
| Скорость | Не нужно придумывать имена и переключаться между файлами |
| Единообразие | Значения из шкалы темы, а не произвольные пиксели |
| Маленький CSS | Генерируются только используемые утилиты |
| Нет «мёртвого» CSS | Удалили разметку — исчезли и стили |
| Безопасные изменения | Стили локальны элементу, нет каскадных сюрпризов |
| Состояния и адаптивность | `hover:`, `md:`, `dark:` прямо в классе |

## Повторы — в компоненты

```vue
<!-- BaseButton.vue -->
<script setup lang="ts">
withDefaults(defineProps<{ variant?: 'primary' | 'ghost' }>(), { variant: 'primary' });
</script>

<template>
  <button
    class="inline-flex items-center gap-2 rounded-lg px-4 py-2 text-sm font-medium transition focus-visible:outline-2 focus-visible:outline-offset-2 disabled:opacity-50"
    :class="variant === 'primary' ? 'bg-indigo-600 text-white hover:bg-indigo-500' : 'text-slate-700 hover:bg-slate-100'"
  >
    <slot />
  </button>
</template>
```

```vue
<BaseButton>Сохранить</BaseButton>
<BaseButton variant="ghost">Отмена</BaseButton>
```

## Когда Tailwind подходит

| Подходит | Сомнительно |
| --- | --- |
| Собственный дизайн, дизайн-система | Нужен готовый набор сложных компонентов (таблицы, date picker) «из коробки» |
| Продуктовые и маркетинговые интерфейсы | Команда против классов в разметке |
| Компонентные фреймворки (Vue, Nuxt) | Контент из CMS с произвольным HTML (нужен плагин typography) |
| В паре с headless-библиотеками (Reka UI, shadcn-vue) | |

## Частые ошибки

- Копировать длинные наборы классов по проекту вместо компонента.
- Повсеместные произвольные значения `w-[437px]` — теряется дизайн-система.
- Собирать имена классов строками динамически (`bg-${color}-500`) — Tailwind их не найдёт.
- Использовать `@apply` для всего — получается обычный CSS с лишним шагом.

## Что важно помнить

- Utility-first: стили из утилит дизайн-системы прямо в разметке.
- Генерируются только использованные классы.
- Во Vue повторы выносятся в компоненты; актуальная версия — v4 с CSS-конфигурацией.

## Мини-шпаргалка

- `p-4 rounded-xl bg-white shadow-sm text-lg font-semibold`.
- Варианты: `hover:`, `focus-visible:`, `md:`, `dark:`, `disabled:`.
- Повторы → компонент, динамика → `:class`.
- v4: `@import "tailwindcss"`, `@theme`, `@tailwindcss/vite`.
