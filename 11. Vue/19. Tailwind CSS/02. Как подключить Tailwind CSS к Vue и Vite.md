# Как подключить Tailwind CSS к Vue и Vite

> [!NOTE]
> В **Tailwind CSS v4** подключение сводится к трём шагам: установить `tailwindcss` и официальный плагин **`@tailwindcss/vite`**, добавить плагин в `vite.config.ts` и написать в главном CSS-файле **`@import "tailwindcss";`**. Файл `tailwind.config.js` и директивы `@tailwind base/components/utilities` из v3 больше не нужны: **конфигурация пишется в CSS** — `@theme` (токены дизайна: цвета, шрифты, брейкпоинты, радиусы, которые одновременно становятся CSS-переменными и генерируют утилиты), `@custom-variant` (свои варианты, например `dark` по классу), `@utility` (свои утилиты), `@source` (дополнительные пути для сканирования, если классы есть вне проекта — например, в UI-пакете из `node_modules`), `@plugin` (плагины вроде `@tailwindcss/typography`). Исходники ищутся **автоматически** (с учётом `.gitignore`). В `<style>` блоках Vue-компонентов, где нужен `@apply` или `theme()`, добавляют **`@reference "../styles/main.css";`** — чтобы получить доступ к теме без дублирования CSS. Для удобства ставят расширение **Tailwind CSS IntelliSense** и `prettier-plugin-tailwindcss` для автоматической сортировки классов. Для Nuxt используется тот же `@tailwindcss/vite` в `vite.plugins` или модуль `@nuxtjs/tailwindcss`. Миграцию с v3 автоматизирует `npx @tailwindcss/upgrade`.

## Вопрос

Как подключить Tailwind CSS v4 к Vue-проекту на Vite?

## Установка

```bash
npm i tailwindcss @tailwindcss/vite
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [vue(), tailwindcss()],
});
```

```css
/* src/styles/main.css */
@import "tailwindcss";
```

```ts
// main.ts
import './styles/main.css';
```

## Конфигурация в CSS

```css
/* src/styles/main.css */
@import "tailwindcss";

@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;

  --color-brand-50: oklch(0.97 0.02 270);
  --color-brand-500: oklch(0.58 0.22 270);
  --color-brand-600: oklch(0.51 0.23 270);

  --breakpoint-3xl: 120rem;          /* новый брейкпоинт 3xl: */
  --radius-card: 1rem;               /* утилита rounded-card */
}

@custom-variant dark (&:where(.dark, .dark *));   /* dark: по классу .dark вместо prefers-color-scheme */

@utility scrollbar-hidden {
  scrollbar-width: none;
  &::-webkit-scrollbar { display: none; }
}

@plugin "@tailwindcss/typography";                 /* класс prose для контента из CMS/Markdown */

@source "../../node_modules/@acme/ui-kit";         /* сканировать классы во внешнем пакете */
```

```vue
<button class="rounded-card bg-brand-500 px-4 py-2 font-sans text-white hover:bg-brand-600">Купить</button>
<div class="scrollbar-hidden overflow-x-auto">...</div>
```

Токены `@theme` доступны и как CSS-переменные: `var(--color-brand-500)`.

## @apply и @reference в SFC

```vue
<template>
  <div class="markdown" v-html="html" />
</template>

<style scoped>
@reference "../styles/main.css";      /* доступ к теме и утилитам без повторной генерации CSS */

.markdown :deep(h2) {
  @apply mt-8 mb-3 text-2xl font-semibold text-slate-900;
}
.markdown :deep(a) {
  color: var(--color-brand-600);
}
</style>
```

Без `@reference` в отдельном `<style>`-блоке утилиты и тема недоступны: каждый блок обрабатывается изолированно.

## Инструменты

```bash
npm i -D prettier prettier-plugin-tailwindcss
```

```json
// .prettierrc
{ "plugins": ["prettier-plugin-tailwindcss"], "tailwindStylesheet": "./src/styles/main.css" }
```

## v3 и v4

| Tailwind v3 | Tailwind v4 |
| --- | --- |
| `tailwind.config.js` | `@theme` в CSS |
| `@tailwind base; @tailwind components; @tailwind utilities;` | `@import "tailwindcss";` |
| `content: [...]` | Автоматический поиск + `@source` |
| PostCSS-плагин + autoprefixer | `@tailwindcss/vite` (префиксы встроены) |
| `darkMode: 'class'` | `@custom-variant dark (...)` |
| `plugins: [require(...)]` | `@plugin "..."` |

```bash
npx @tailwindcss/upgrade
```

## Частые ошибки

- Ставить v3-инструкции (`tailwind.config.js`, `@tailwind`) в проект на v4.
- `@apply` в `<style>` компонента без `@reference` — ошибка «unknown utility».
- Динамические имена классов (`` `text-${color}-600` ``) — не попадают в сборку; используйте полные имена в объекте.
- Классы во внешнем пакете без `@source` — стили отсутствуют.
- Подключать CSS-файл Tailwind несколько раз — дублирование стилей.

## Что важно помнить

- v4: `@tailwindcss/vite` + `@import "tailwindcss"`.
- Конфигурация в CSS: `@theme`, `@custom-variant`, `@utility`, `@plugin`, `@source`.
- В SFC для `@apply` нужен `@reference`.

## Мини-шпаргалка

- `npm i tailwindcss @tailwindcss/vite`.
- `plugins: [vue(), tailwindcss()]`.
- `@theme { --color-brand-500: ...; }` → `bg-brand-500`.
- `@custom-variant dark (&:where(.dark, .dark *));`.
- `@reference "../styles/main.css";`.
