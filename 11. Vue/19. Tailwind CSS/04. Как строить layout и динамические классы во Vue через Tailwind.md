# Как строить layout и динамические классы во Vue через Tailwind

> [!NOTE]
> Раскладку в Tailwind строят двумя инструментами: **Flexbox** (`flex`, `flex-col`, `items-center`, `justify-between`, `gap-4`, `flex-1`, `shrink-0`, `flex-wrap`) — для одномерных рядов и столбцов (шапка, панель действий, карточка с иконкой), и **Grid** (`grid`, `grid-cols-12`, `col-span-8`, `grid-cols-[240px_1fr]`, `grid-rows-[auto_1fr_auto]`) — для двумерных макетов (страница с боковой панелью, сетка карточек, дашборд). Типовые приёмы: центрированный контейнер `mx-auto max-w-7xl px-4 sm:px-6 lg:px-8`, «липкая» шапка `sticky top-0 z-10`, полная высота `min-h-dvh`, адаптивная сетка карточек `grid-cols-[repeat(auto-fill,minmax(16rem,1fr))]`, `min-w-0` для обрезки текста внутри flex-ребёнка (`truncate`). Во Vue **динамические классы** задаются через `:class` с объектом или массивом, а варианты компонента — через **словарь полных имён классов** (`const variants = { primary: 'bg-indigo-600 text-white', ... }`): Tailwind находит классы статическим сканированием исходников, поэтому имена нельзя собирать конкатенацией (`` `bg-${color}-600` ``). Для компонентов с множеством вариантов используют **`cva`** (class-variance-authority) или `tailwind-variants`, а для корректного слияния классов из props и `$attrs` — **`tailwind-merge`** (`twMerge('px-2', 'px-4')` → `px-4`), обычно через хелпер `cn()`.

## Вопрос

Как строить layout во Vue с Tailwind и правильно работать с динамическими классами?

  <div class="grid min-h-dvh grid-rows-[auto_1fr_auto]">
    <header class="sticky top-0 z-10 border-b border-slate-200 bg-white/80 backdrop-blur">

## Flex-карточка с обрезкой текста

```vue
<div class="flex items-center gap-3">
  <img class="size-10 shrink-0 rounded-full" :src="user.avatar" alt="" />
  <div class="min-w-0 flex-1">                      <!-- min-w-0 — иначе truncate не сработает -->
    <p class="truncate font-medium">{{ user.name }}</p>
    <p class="truncate text-sm text-slate-500">{{ user.email }}</p>
  </div>
  <button class="shrink-0">…</button>
</div>
```

## Динамические классы во Vue

```vue
<script setup lang="ts">
const props = defineProps<{ status: 'new' | 'paid' | 'cancelled'; compact?: boolean }>();

// ✓ полные имена классов — Tailwind их найдёт
const statusClasses = {
  new: 'bg-sky-100 text-sky-800',
  paid: 'bg-emerald-100 text-emerald-800',
  cancelled: 'bg-rose-100 text-rose-800',
} as const;
</script>

<template>
  <span
    class="inline-flex items-center rounded-full font-medium"
    :class="[statusClasses[status], compact ? 'px-2 text-xs' : 'px-3 py-1 text-sm']"
  >
    <slot />
  </span>
</template>
```

```vue
<!-- ✗ классы собираются в рантайме — в CSS их не будет -->
<span :class="`bg-${color}-100 text-${color}-800`" />
```

## cva + tailwind-merge

```ts
// lib/cn.ts
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';
export const cn = (...inputs: ClassValue[]) => twMerge(clsx(inputs));
```

```vue
<!-- BaseButton.vue -->
<script setup lang="ts">
import { cva, type VariantProps } from 'class-variance-authority';
import { cn } from '@/lib/cn';

const button = cva(
  'inline-flex items-center justify-center gap-2 rounded-lg font-medium transition focus-visible:outline-2 focus-visible:outline-offset-2 disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        primary: 'bg-indigo-600 text-white hover:bg-indigo-500',
        outline: 'border border-slate-300 hover:bg-slate-50',
        ghost: 'hover:bg-slate-100',
      },
      size: { sm: 'h-8 px-3 text-sm', md: 'h-10 px-4', lg: 'h-12 px-6 text-lg' },
    },
    defaultVariants: { variant: 'primary', size: 'md' },
  },
);

type ButtonProps = VariantProps<typeof button>;
const props = defineProps<{ variant?: ButtonProps['variant']; size?: ButtonProps['size']; class?: string }>();
</script>

<template>
  <button :class="cn(button({ variant: props.variant, size: props.size }), props.class)">
    <slot />
  </button>
</template>
```

```vue
<BaseButton size="sm" class="w-full px-8">Купить</BaseButton>   <!-- px-8 заменит px-3, а не конфликтует -->
```

## Fallthrough-классы

Vue объединяет `class` родителя с корневым элементом компонента, но не разрешает конфликты Tailwind (`px-4` + `px-8` — победит тот, что раньше в CSS). Поэтому в базовых компонентах принимают `class` явно и сливают через `twMerge`, как выше.

## Частые ошибки

- Конкатенация имён классов — стили не генерируются.
- Забыть `min-w-0` во flex-ребёнке — `truncate` не работает, вёрстка «распирается».
- Grid там, где хватает flex, и наоборот — избыточные классы.
- Переопределение классов компонента снаружи без `twMerge` — непредсказуемый результат.
- Фиксированные высоты (`h-[600px]`) вместо `min-h-*` — контент обрезается.

## Что важно помнить

- Flex — для рядов, Grid — для двумерных макетов; контейнер `mx-auto max-w-* px-*`.
- Динамика — `:class` с **полными** именами классов из словаря.
- `cva` для вариантов, `tailwind-merge` для слияния классов.

## Мини-шпаргалка

- `mx-auto max-w-7xl px-4 sm:px-6 lg:px-8`.
- `grid grid-cols-[16rem_1fr]`, `grid-cols-[repeat(auto-fill,minmax(16rem,1fr))]`.
- `min-w-0 flex-1 truncate`.
- `:class="[variants[variant], { 'opacity-50': disabled }]"`.
- `cn = (...c) => twMerge(clsx(c))`.
