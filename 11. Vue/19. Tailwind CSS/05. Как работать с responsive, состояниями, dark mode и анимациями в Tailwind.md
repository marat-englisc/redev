# Как работать с responsive, состояниями, dark mode и анимациями в Tailwind

> [!NOTE]
> **Адаптивность** в Tailwind — mobile-first: классы без префикса действуют на всех экранах, а `sm:`, `md:`, `lg:` переопределяют их **от** указанной ширины; диапазоны задаются комбинацией (`md:max-lg:`), а `max-md:` — «до md». Для компонентов, которые зависят от ширины **контейнера**, а не окна (карточка в узкой колонке и на всю ширину), используют встроенные в v4 **контейнерные запросы** (`@container` на родителе, `@sm:`/`@lg:` на детях). **Состояния**: `hover:` (в v4 срабатывает только на устройствах с hover), `focus-visible:` (фокус с клавиатуры — основной вариант для колец фокуса), `active:`, `disabled:`, `invalid:`, `checked:`, `aria-*:`, `data-*:`, связи `group-*`/`peer-*`, `has-*` (родитель по содержимому), `first:`/`last:`/`odd:`, `motion-safe:`/`motion-reduce:`. **Тёмная тема**: по умолчанию `dark:` следует `prefers-color-scheme`; для ручного переключателя переопределяют вариант на класс (`@custom-variant dark (&:where(.dark, .dark *))`) и ставят класс `dark` на `<html>` (например, через `useDark` из VueUse). Удобнее всего строить тему на **семантических токенах** — CSS-переменных в `@theme` (`--color-surface`, `--color-text`), значения которых меняются в `.dark`, — тогда в разметке не нужно дублировать `dark:` у каждого элемента. **Анимации**: `transition`, `duration-200`, `ease-out`, готовые `animate-spin`/`animate-pulse`, `starting:` для анимации появления; во Vue они сочетаются с `<Transition>` через пропсы `enter-active-class` и др.

## Вопрос

Как в Tailwind работать с адаптивностью, состояниями, тёмной темой и анимациями во Vue?

## Адаптивность

```vue
<!-- 1 колонка на телефоне, 2 от sm, 4 от lg -->
<div class="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-4">

<!-- мобильное меню скрыто на md+ -->
<button class="md:hidden" aria-label="Меню" @click="open = !open">☰</button>
<nav class="hidden md:flex md:gap-6">...</nav>

<!-- только диапазон md–lg -->
<p class="hidden md:max-lg:block">Планшет</p>
```

## Контейнерные запросы

```vue
<!-- ProductCard работает и в узкой колонке, и в широкой -->
<article class="@container rounded-xl border p-4">
  <div class="flex flex-col gap-4 @md:flex-row">
    <img class="aspect-square w-full rounded-lg object-cover @md:w-40" :src="product.image" alt="" />
    <div>
      <h3 class="text-base font-semibold @lg:text-xl">{{ product.title }}</h3>
    </div>
  </div>
</article>
```

## Состояния

```vue
<input
  v-model="email"
  type="email"
  required
  class="w-full rounded-lg border border-slate-300 px-3 py-2 outline-none
         focus-visible:border-indigo-500 focus-visible:ring-3 focus-visible:ring-indigo-500/30
         user-invalid:border-rose-500 disabled:bg-slate-100"
/>

<!-- has-*: стиль родителя по состоянию ребёнка -->
<label class="flex items-center gap-2 rounded-lg border p-3 has-checked:border-indigo-500 has-checked:bg-indigo-50">
  <input type="radio" name="delivery" value="courier" class="accent-indigo-600" />
  Курьер
</label>

<!-- data-атрибут из Vue-состояния -->
<div :data-active="isActive || undefined" class="opacity-60 data-active:opacity-100" />
```

`user-invalid:` срабатывает только после взаимодействия пользователя — в отличие от `invalid:`, который подсвечивает пустое обязательное поле сразу.

## Тёмная тема по классу

```css
/* main.css */
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));
```

```ts
// переключатель
import { useDark, useToggle } from '@vueuse/core';
const isDark = useDark();               // класс dark на <html>
const toggle = useToggle(isDark);
```

```vue
<div class="bg-white text-slate-900 dark:bg-slate-950 dark:text-slate-100">...</div>
```

## Семантические токены

```css
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));

@theme {
  --color-surface: #ffffff;
  --color-surface-muted: #f1f5f9;
  --color-text: #0f172a;
  --color-text-muted: #64748b;
}

@layer base {
  .dark {
    --color-surface: #020617;
    --color-surface-muted: #0f172a;
    --color-text: #e2e8f0;
    --color-text-muted: #94a3b8;
  }
}
```

```vue
<!-- без dark: на каждом элементе -->
<section class="bg-surface text-text">
  <p class="text-text-muted">Подпись</p>
</section>
```

## Анимации и Vue Transition

```vue
<Transition
  enter-active-class="transition duration-200 ease-out"
  enter-from-class="translate-y-2 opacity-0"
  leave-active-class="transition duration-150 ease-in"
  leave-to-class="translate-y-2 opacity-0"
>
  <div v-if="open" class="absolute right-0 mt-2 w-56 rounded-xl bg-white shadow-lg">...</div>
</Transition>
```

```vue
<svg class="size-5 animate-spin motion-reduce:hidden" />
<div class="h-4 w-40 animate-pulse rounded bg-slate-200" />    <!-- скелетон -->

<!-- starting: анимация появления без Vue Transition (для элементов, появляющихся в DOM, @starting-style) -->
<div v-if="toast" class="transition duration-300 starting:translate-y-4 starting:opacity-0">{{ toast }}</div>
```

## Частые ошибки

- Начинать с десктопа и «отменять» стили на мобильных — пишите базу для мобильных.
- `focus:` вместо `focus-visible:` — кольцо фокуса появляется при клике мышью.
- `outline-none` без видимого фокуса.
- Дублировать пары `bg-white dark:bg-slate-950` по всему проекту вместо семантических токенов.
- Анимации без `motion-reduce:`/`motion-safe:` для пользователей с отключённой анимацией.

## Что важно помнить

- Mobile-first брейкпоинты и контейнерные запросы `@container`.
- Состояния: `focus-visible:`, `disabled:`, `aria-*`, `data-*`, `group-*`, `peer-*`, `has-*`.
- Тёмная тема по классу + семантические токены; анимации — `transition` и Vue `<Transition>`.

## Мини-шпаргалка

- `sm: md: lg:`, `max-md:`, `md:max-lg:`.
- `@container` + `@md:`.
- `focus-visible:ring-3`, `user-invalid:`, `has-checked:`.
- `@custom-variant dark (&:where(.dark, .dark *));`.
- `enter-active-class="transition duration-200"`, `motion-reduce:`.
