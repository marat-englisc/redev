# Как читать utility classes Tailwind

> [!NOTE]
> Утилиты Tailwind строятся по предсказуемой схеме **`[варианты:]свойство-значение`**. Сокращения свойств: `p`/`m` — padding/margin (`px`, `py`, `pt`, `mx-auto`, `-mt-2` — отрицательный), `w`/`h`/`size` — размеры (`w-full`, `h-screen`, `size-10`, `min-w-0`, `max-w-prose`), `gap`, `space-x`, `text` — размер **или** цвет текста (`text-sm`, `text-slate-600`), `font` — насыщенность или семейство (`font-semibold`, `font-mono`), `leading`/`tracking` — межстрочный и межбуквенный интервал, `bg`, `border` (`border`, `border-2`, `border-slate-200`), `rounded`, `shadow`, `opacity`, `z`, `inset`/`top`/`left`. Шкала отступов кратна **0,25rem** (`p-1` = 4px, `p-4` = 16px, `p-6` = 24px) и в v4 принимает любое число (`p-13`). Цвета — палитра с оттенками 50–950 (`bg-indigo-600`) и модификатором прозрачности (`bg-black/50`). Раскладка: `flex`, `grid`, `grid-cols-3`, `items-center`, `justify-between`, `col-span-2`, `hidden`, `block`. **Варианты** — префиксы через двоеточие: состояния (`hover:`, `focus-visible:`, `active:`, `disabled:`, `aria-expanded:`, `data-[state=open]:`), брейкпоинты mobile-first (`sm:`, `md:`, `lg:` — «от этой ширины и шире»), `dark:`, родитель/сосед (`group-hover:`, `peer-invalid:`), контейнерные запросы (`@container` + `@md:`), псевдоэлементы (`before:`, `placeholder:`). Произвольные значения — в квадратных скобках (`top-[117px]`, `grid-cols-[200px_1fr]`, `bg-(--brand)` для CSS-переменной), `!` в конце — `!important`.

## Вопрос

Как читать и понимать классы Tailwind CSS?

## Разбор строки

```vue
<button class="inline-flex items-center gap-2 rounded-lg bg-indigo-600 px-4 py-2 text-sm font-medium text-white shadow-sm hover:bg-indigo-500 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-indigo-600 disabled:cursor-not-allowed disabled:opacity-50 md:px-6">
```

| Класс | CSS |
| --- | --- |
| `inline-flex items-center gap-2` | `display: inline-flex; align-items: center; gap: 0.5rem` |
| `rounded-lg` | `border-radius: 0.5rem` |
| `bg-indigo-600` | Фон из палитры |
| `px-4 py-2` | `padding-inline: 1rem; padding-block: 0.5rem` |
| `text-sm font-medium text-white` | Размер, насыщенность, цвет текста |
| `hover:bg-indigo-500` | Фон при наведении |
| `focus-visible:outline-2 ...` | Видимый фокус с клавиатуры |
| `disabled:opacity-50` | Стиль для `:disabled` |
| `md:px-6` | Отступ 1,5rem от брейкпоинта `md` (48rem) |

## Шкалы

| Шкала | Пример | Значение |
| --- | --- | --- |
| Отступы, размеры | `p-1`, `p-4`, `w-64` | 0,25rem × число |
| Доли | `w-1/2`, `basis-1/3` | 50%, 33,33% |
| Текст | `text-xs` … `text-9xl` | Размер + line-height |
| Радиусы | `rounded-sm` … `rounded-3xl`, `rounded-full` | |
| Тени | `shadow-xs` … `shadow-2xl` | |
| Цвета | `slate`, `gray`, `red` … 50–950 | `bg-red-500/20` — 20% прозрачности |

## Брейкпоинты (mobile-first)

```vue
<div class="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-4">
```

| Префикс | Мин. ширина |
| --- | --- |
| (нет) | Все экраны |
| `sm:` | 40rem (640px) |
| `md:` | 48rem (768px) |
| `lg:` | 64rem (1024px) |
| `xl:` | 80rem (1280px) |
| `2xl:` | 96rem (1536px) |
| `max-md:` | Только меньше md |

## Состояния и связи

```vue
<!-- group: стиль ребёнка при наведении на родителя -->
<a class="group flex items-center gap-3 rounded-lg p-3 hover:bg-slate-50">
  <img class="size-12 rounded-full" :src="user.avatar" alt="" />
  <span class="font-medium group-hover:text-indigo-600">{{ user.name }}</span>
</a>

<!-- peer: стиль соседа по состоянию поля -->
<input class="peer rounded border px-3 py-2 invalid:border-red-500" type="email" required />
<p class="hidden text-sm text-red-600 peer-invalid:block">Некорректный email</p>

<!-- ARIA и data-атрибуты -->
<button :aria-expanded="open" class="aria-expanded:bg-slate-100">Меню</button>
<div :data-state="open ? 'open' : 'closed'" class="data-[state=open]:block data-[state=closed]:hidden" />
```

## Контейнерные запросы (встроены в v4)

```vue
<div class="@container">
  <article class="flex flex-col gap-3 @md:flex-row">   <!-- по ширине контейнера, а не окна -->
    ...
  </article>
</div>
```

## Произвольные значения

```vue
<div class="top-[117px] grid-cols-[240px_1fr] bg-[#0b1020] text-(--brand-color)" />
<p class="mt-13 w-[42ch]">Шкала v4 принимает любые числа: mt-13 = 3.25rem</p>
```

Произвольные значения — для исключений; повторяющиеся значения добавляют в `@theme`.

## Частые ошибки

- Думать, что `md:` означает «только на планшетах» — это «от md и шире».
- `text-` для размера и цвета одновременно путает — читайте значение (`text-lg` vs `text-slate-700`).
- Писать стили для мобильных с префиксом `sm:` — базовые классы уже для мобильных.
- `outline-none` без замены фокусного стиля — ломается доступность.
- Конфликтующие классы (`p-2 p-4`) — побеждает не последний в строке, а порядок в CSS.

## Что важно помнить

- Схема `вариант:свойство-значение`, шкала отступов 0,25rem.
- Mobile-first брейкпоинты, состояния, `group`/`peer`, контейнерные запросы.
- Произвольные значения в `[]` — исключение, не правило.

## Мини-шпаргалка

- `p-4 = 1rem`, `gap-2 = 0.5rem`, `size-10 = 2.5rem`.
- `sm: md: lg: xl: 2xl:` — от ширины; `max-md:` — до.
- `hover: focus-visible: disabled: aria-*: data-[...]:`.
- `group-hover:`, `peer-invalid:`, `@container` + `@md:`.
- `bg-black/50`, `w-[42ch]`, `text-(--var)`.
