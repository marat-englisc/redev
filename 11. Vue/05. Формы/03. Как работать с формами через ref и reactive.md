# Как работать с формами через ref и reactive

> [!NOTE]
> Состояние формы хранят одним объектом: **`reactive({...})`** удобен, когда поля меняются по отдельности и объект не заменяется целиком; **`ref({...})`** — когда форму нужно полностью **заменять** (загрузка данных для редактирования, сброс к исходным значениям) — `form.value = {...}`. Рядом держат служебное состояние: `isSubmitting`, `errors` (по полям), `touched`/`dirty`, ошибку отправки. Хорошие практики: `@submit.prevent` на `<form>` (работает Enter, доступность), блокировка повторной отправки, **копия** данных при редактировании (`structuredClone(toRaw(...))`), чтобы не менять исходный объект до сохранения, сброс к **начальным** значениям через фабрику `createEmptyForm()`, вычисляемый `isDirty`, и вынос логики в composable (`useForm`). Для сложных форм с правилами валидации, асинхронными проверками и вложенными массивами полей используют библиотеки (VeeValidate, FormKit) со схемами Zod/Yup — см. [валидация форм](<04. Как валидировать формы во Vue.md>).

## Вопрос

Как организовать состояние и отправку формы во Vue через `ref` и `reactive`?

## Форма на reactive

```vue
<script setup lang="ts">
interface SignupForm { name: string; email: string; password: string; agree: boolean }

const createEmpty = (): SignupForm => ({ name: '', email: '', password: '', agree: false });

const form = reactive(createEmpty());
const errors = reactive<Partial<Record<keyof SignupForm, string>>>({});
const isSubmitting = ref(false);
const submitError = ref<string | null>(null);

function validate() {
  Object.keys(errors).forEach((k) => delete errors[k as keyof SignupForm]);
  if (form.name.trim().length < 2) errors.name = 'Минимум 2 символа';
  if (!/^\S+@\S+\.\S+$/.test(form.email)) errors.email = 'Некорректный email';
  if (form.password.length < 10) errors.password = 'Минимум 10 символов';
  if (!form.agree) errors.agree = 'Нужно согласие';
  return Object.keys(errors).length === 0;
}

async function onSubmit() {
  if (isSubmitting.value || !validate()) return;
  isSubmitting.value = true;
  submitError.value = null;
  try {
    await api.signup({ ...form, email: form.email.trim().toLowerCase() });
    Object.assign(form, createEmpty());          // сброс
  } catch (e) {
    submitError.value = 'Не удалось зарегистрироваться';
  } finally {
    isSubmitting.value = false;
  }
}
</script>

<template>
  <form novalidate @submit.prevent="onSubmit">
    <label>Имя <input v-model.trim="form.name" :aria-invalid="!!errors.name" /></label>
    <small v-if="errors.name">{{ errors.name }}</small>

    <label>Email <input v-model.trim="form.email" type="email" autocomplete="email" /></label>
    <small v-if="errors.email">{{ errors.email }}</small>

    <label>Пароль <input v-model="form.password" type="password" autocomplete="new-password" /></label>
    <small v-if="errors.password">{{ errors.password }}</small>

    <label><input v-model="form.agree" type="checkbox" /> Согласен с условиями</label>

    <p v-if="submitError" role="alert">{{ submitError }}</p>
    <button type="submit" :disabled="isSubmitting">{{ isSubmitting ? 'Отправка…' : 'Зарегистрироваться' }}</button>
  </form>
</template>
```

## Редактирование: ref и копия

```ts
const props = defineProps<{ product: Product }>();
const emit = defineEmits<{ save: [Product] }>();

const draft = ref<Product>(structuredClone(toRaw(props.product)));
const isDirty = computed(() => JSON.stringify(draft.value) !== JSON.stringify(props.product));

watch(() => props.product, (p) => { draft.value = structuredClone(toRaw(p)); });   // новые данные — новая копия

function reset() { draft.value = structuredClone(toRaw(props.product)); }
function save() { emit('save', draft.value); }
```

`toRaw` нужен, потому что `structuredClone` не копирует Proxy.

## Динамические поля (массив)

```vue
<script setup lang="ts">
const form = reactive({ phones: [{ id: crypto.randomUUID(), value: '' }] });
const addPhone = () => form.phones.push({ id: crypto.randomUUID(), value: '' });
const removePhone = (id: string) => (form.phones = form.phones.filter((p) => p.id !== id));
</script>

<template>
  <div v-for="(phone, i) in form.phones" :key="phone.id">
    <input v-model="phone.value" :aria-label="`Телефон ${i + 1}`" />
    <button type="button" @click="removePhone(phone.id)">×</button>
  </div>
  <button type="button" @click="addPhone">Добавить телефон</button>
</template>
```

`type="button"` у вспомогательных кнопок — иначе они отправляют форму.

## Предупреждение о несохранённых изменениях

```ts
onBeforeRouteLeave(() => {
  if (isDirty.value && !confirm('Есть несохранённые изменения. Уйти?')) return false;
});
```

## ref или reactive для формы

| `reactive` | `ref` |
| --- | --- |
| Поля меняются по отдельности | Форма заменяется целиком |
| Сброс — `Object.assign(form, empty())` | Сброс — `form.value = empty()` |
| Нет `.value` в скрипте | `.value` в скрипте |

## Частые ошибки

- Редактировать объект из props/стора напрямую — изменения видны до сохранения.
- `form = reactive(...)` для сброса — связь с шаблоном теряется.
- Кнопки внутри формы без `type="button"`.
- Нет блокировки повторной отправки.
- Ключ `index` в динамических полях.

## Что важно помнить

- Одно состояние формы + служебные флаги (`isSubmitting`, `errors`).
- Редактирование — через копию, сброс — через фабрику начальных значений.
- `@submit.prevent`, блокировка повторной отправки, доступные ошибки.

## Мини-шпаргалка

- `reactive(createEmpty())` / `ref(createEmpty())`.
- `Object.assign(form, createEmpty())`.
- `structuredClone(toRaw(obj))`.
- `<form @submit.prevent>`, `<button type="button">`.
