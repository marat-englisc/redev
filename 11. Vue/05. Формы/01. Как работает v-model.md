# Как работает v-model

> [!NOTE]
> `v-model` создаёт **двустороннюю привязку** между состоянием и элементом формы: значение из состояния попадает в поле, а ввод пользователя — обратно в состояние. Это синтаксический сахар: на элементе Vue сам выбирает нужную пару «свойство + событие» в зависимости от типа поля — `value` + `input` для `<input type="text">` и `<textarea>`, `checked` + `change` для чекбоксов и радиокнопок, `value` + `change` для `<select>`. Для **чекбокса** с массивом в `v-model` значение каждого отмеченного поля добавляется в массив; `true-value`/`false-value` задают свои значения вместо `true`/`false`; для радиокнопок и `<option>` значение берётся из `value` (может быть объектом через `:value`). `v-model` игнорирует атрибуты `value`, `checked`, `selected` в разметке — источник истины только состояние. Для композиции (IME, ввод иероглифов) Vue обновляет значение после завершения набора. На **компонентах** `v-model` разворачивается в `modelValue` + `update:modelValue` — см. [v-model на компонентах](<../03. Компоненты/06. Как работает v-model на компонентах и defineModel.md>).

## Вопрос

Как работает `v-model` на элементах формы?

## Типы полей

```vue
<script setup lang="ts">
const form = reactive({
  name: '',
  bio: '',
  agree: false,
  plan: 'free' as 'free' | 'pro',
  tags: [] as string[],
  city: '',
  country: null as Country | null,
  skills: [] as string[],
  newsletter: 'no' as 'yes' | 'no',
});
</script>

<template>
  <input v-model="form.name" />                            <!-- value + input -->
  <textarea v-model="form.bio" />                          <!-- не <textarea>{{ bio }}</textarea> -->

  <input v-model="form.agree" type="checkbox" />           <!-- boolean -->
  <input v-model="form.newsletter" type="checkbox" true-value="yes" false-value="no" />

  <label><input v-model="form.tags" type="checkbox" value="vue" /> Vue</label>   <!-- массив -->
  <label><input v-model="form.tags" type="checkbox" value="ts" /> TS</label>

  <label><input v-model="form.plan" type="radio" value="free" /> Free</label>
  <label><input v-model="form.plan" type="radio" value="pro" /> Pro</label>

  <select v-model="form.city">
    <option disabled value="">Выберите город</option>
    <option v-for="c in cities" :key="c" :value="c">{{ c }}</option>
  </select>

  <select v-model="form.country">                           <!-- объект как значение -->
    <option v-for="c in countries" :key="c.code" :value="c">{{ c.name }}</option>
  </select>

  <select v-model="form.skills" multiple>...</select>     <!-- массив -->
</template>
```

## Во что разворачивается

| Элемент | Свойство | Событие |
| --- | --- | --- |
| `input` (text, email, …), `textarea` | `value` | `input` |
| `input[type=checkbox]` | `checked` | `change` |
| `input[type=radio]` | `checked` | `change` |
| `select` | `value` | `change` |
| Компонент | prop `modelValue` | `update:modelValue` |

```vue
<input v-model="name" />
<!-- ≈ -->
<input :value="name" @input="name = ($event.target as HTMLInputElement).value" />
```

## Источник истины — состояние

```vue
<input v-model="name" value="Анна" />    <!-- value игнорируется; начальное значение задаётся в ref -->
```

## v-model и computed

```ts
const props = defineProps<{ filters: Filters }>();
const emit = defineEmits<{ change: [Filters] }>();

const query = computed({
  get: () => props.filters.q,
  set: (q) => emit('change', { ...props.filters, q }),
});
// <input v-model="query" />
```

## Файлы

```vue
<input type="file" @change="onFile" />   <!-- v-model с type="file" не работает: значение только для чтения -->
```

```ts
function onFile(e: Event) {
  file.value = (e.target as HTMLInputElement).files?.[0] ?? null;
}
```

## Частые ошибки

- `v-model` на prop внутри дочернего компонента.
- `v-model` на `type="file"`.
- Ожидать число из `<input type="number">` — без `.number` приходит строка.
- `<option>` без пустого варианта — при `''` в состоянии iOS не даёт выбрать первый пункт.
- Мутировать объект-значение `<option>` и удивляться выбору.

## Что важно помнить

- `v-model` = свойство + событие, выбранные по типу поля.
- Чекбоксы с массивом, `true-value`/`false-value`, объекты через `:value`.
- Источник истины — состояние, а не атрибуты разметки.

## Мини-шпаргалка

- `<input v-model="x" />`, `<textarea v-model="x" />`.
- `type="checkbox"` + массив → список значений.
- `<select v-model="x">`, `multiple` → массив.
- `type="file"` — через `@change`.
