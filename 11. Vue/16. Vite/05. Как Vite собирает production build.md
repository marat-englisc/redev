# Как Vite собирает production build

> [!NOTE]
> `vite build` собирает приложение в папку `dist`: начиная с `index.html`, **Rolldown** (в Vite 8; раньше Rollup) обходит граф модулей, применяет плагины, удаляет неиспользуемый код (**tree shaking**), выносит динамические `import()` в отдельные **чанки** (code splitting), минифицирует JS (Oxc) и CSS (Lightning CSS), извлекает CSS в отдельные файлы (по чанкам), обрабатывает ассеты и добавляет **хеш содержимого** в имена файлов (`index-B3x9aQ.js`). Хеш позволяет отдавать файлы с долгим кешем (`Cache-Control: max-age=31536000, immutable`): изменился код — изменилось имя. Vite также генерирует `<link rel="modulepreload">` для зависимостей начального чанка и предзагружает зависимости ленивых чанков при их импорте. Целевые браузеры по умолчанию — **Baseline Widely Available** (для Vite 8 — версии примерно середины 2023 года), меняются через `build.target`; для старых браузеров есть `@vitejs/plugin-legacy`. **`vite preview`** запускает локальный статический сервер для проверки собранного `dist` — это не production-сервер. Итог деплоится на любой статический хостинг или CDN; для SPA с history mode нужен fallback на `index.html`. `build.sourcemap` включает карты кода для отладки ошибок — публиковать их или загружать только в сервис мониторинга (Sentry), решают по политике безопасности.

## Этапы

```text
index.html → граф модулей (Rolldown)
  → плагины (vue, tailwind, ...)
  → tree shaking
  → разбиение на чанки по import()
  → минификация (Oxc, Lightning CSS)
  → хеши в именах, modulepreload в index.html
  → dist/
```

## Настройки build

```ts
export default defineConfig({
  build: {
    outDir: 'dist',
    assetsDir: 'assets',
    target: 'baseline-widely-available',   // по умолчанию; 'es2022', ['chrome110', 'safari16'] и т. п.
    sourcemap: 'hidden',                    // карты без ссылки в бандле — для загрузки в Sentry
    cssCodeSplit: true,
    assetsInlineLimit: 4096,                // ассеты < 4 КБ инлайнятся как data URL
    chunkSizeWarningLimit: 600,
    reportCompressedSize: true,
    rolldownOptions: {
      output: {
        codeSplitting: {
          groups: [{ name: 'vendor-charts', test: /node_modules[\\/](chart\.js|vue-chartjs)/ }],
        },
      },
    },
  },
});
```

| Опция | Смысл |
| --- | --- |
| `target` | Синтаксис JS для целевых браузеров |
| `sourcemap` | `true`, `'hidden'`, `'inline'`, `false` |
| `minify` | `'oxc'` (по умолчанию), `false` |
| `rolldownOptions` | Низкоуровневые опции сборщика (бывший `rollupOptions`) |
| `manifest` | `manifest.json` для серверной интеграции (бэкенд генерирует HTML) |

## preview

```bash
npm run build && npm run preview     # http://localhost:4173
```

Проверяет реальную сборку: пути ассетов, `base`, ленивые чанки, env production-режима.

## Кеширование и деплой

```nginx
location /assets/ {
  add_header Cache-Control "public, max-age=31536000, immutable";   # файлы с хешем
}
location / {
  add_header Cache-Control "no-cache";                             # index.html всегда проверять
  try_files $uri $uri/ /index.html;                                # fallback для SPA
}
```

## Library mode

```ts
build: {
  lib: { entry: 'src/index.ts', name: 'MyUiKit', fileName: 'my-ui-kit', formats: ['es'] },
  rolldownOptions: { external: ['vue'] },   // vue не включать в библиотеку — это peer-зависимость
},
```

## Устаревшие браузеры

```ts
import legacy from '@vitejs/plugin-legacy';
plugins: [vue(), legacy({ targets: ['defaults', 'not IE 11'] })],
```

## Частые ошибки

- Проверять только `npm run dev` — ошибки путей, регистра имён файлов и env проявляются в сборке.
- Кешировать `index.html` надолго — пользователи не получают новую версию.
- Публичные source maps с исходным кодом без осознанного решения.
- Игнорировать предупреждения о больших чанках.
- Копировать старые примеры с `build.rollupOptions`/`manualChunks` в Vite 8 без учёта переименований.

## Что важно помнить

- `vite build` → `dist` с хешированными чанками; Vite 8 — Rolldown + Oxc.
- `vite preview` — локальная проверка сборки.
- Долгий кеш для `/assets`, `no-cache` для `index.html`, fallback для SPA.

## Мини-шпаргалка

- `vite build`, `vite preview`.
- `build.target`, `build.sourcemap: 'hidden'`.
- `build.rolldownOptions.output.codeSplitting.groups`.
- `build.lib` — библиотеки.
- `@vitejs/plugin-legacy` — старые браузеры.
