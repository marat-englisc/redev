# Как работают перенаправления, tee и heredoc

> [!NOTE]
> `>` открывает файл с обнулением, `>>` дописывает, `<` подаёт файл на stdin, `2>` перенаправляет stderr. Порядок важен: `>out 2>&1` отправляет оба потока в out, а `2>&1 >out` оставляет stderr в прежнем stdout. Файлы перенаправления открывает shell ещё до запуска команды.

## Вопрос

Чем отличаются два порядка `2>&1` и `>file`? Почему `sudo echo text > /etc/file` может не иметь прав на запись?

## Сохранение результата

```bash
mkdir -p "$HOME/linux-lab/redirect"
cd "$HOME/linux-lab/redirect"
printf 'first\n' > result.txt
printf 'second\n' >> result.txt
wc -l < result.txt
cat result.txt | tee copy.txt
```

`tee` пишет и в stdout, и в файл. В примере файл содержит две строки; `wc` с вводом через `<` показывает число без имени файла. `tee -a` дописывает вместо перезаписи.

## Почему порядок имеет значение

```bash
bash -c 'printf "data\n"; printf "error\n" >&2' > all.log 2>&1
bash -c 'printf "data\n"; printf "error\n" >&2' 2>&1 > data.log
```

В первой строке stdout сначала направлен в файл, затем stderr дублирует **его текущее назначение**. Во второй stderr сначала копирует терминал, после чего перенаправляется только stdout.

`sudo` повышает права запущенной команды, но не родительского shell. Поэтому для системного файла применяют осознанно `printf ... | sudo tee /конкретный/путь`, либо редактор через `sudoedit`. Здесь `tee`, который открывает файл, уже работает с нужными правами.

## Многострочный ввод

```bash
cat > example.conf <<'EOF'
name=demo
literal=$HOME
EOF
```

Кавычки в `<<'EOF'` запрещают подстановки в теле heredoc: в файле останется буквальный `$HOME`. Без кавычек переменные и подстановки команд будут вычисляться. Закрывающий маркер записывают отдельной строкой.

## Ошибка, уничтожающая исходник

Не выполняй `sort file > file`: shell обнулит файл до того, как `sort` его прочитает. Сохраняй результат в отдельный файл, проверяй и лишь затем заменяй исходный. Для конфигурации учитывай также права и владельца нового файла.

## Практика

Повтори пример с двумя потоками, прочитай оба файла и объясни, куда ушла каждая строка. Сделай heredoc с кавычками и без них и сравни `$HOME` в результате.
