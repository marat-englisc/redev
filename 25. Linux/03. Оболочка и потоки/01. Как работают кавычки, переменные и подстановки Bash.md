# Как работают кавычки, переменные и подстановки Bash

> [!NOTE]
> Одинарные кавычки сохраняют текст буквально. Двойные позволяют раскрывать переменные и `$(команду)`, но защищают результат от разбиения на слова и glob. Без кавычек значение переменной может превратиться в несколько аргументов. Базовое правило для Bash: передавай строковые значения как `"$value"`, а список аргументов — как `"$@"` или `"${array[@]}"`.

## Вопрос

Чем отличаются `'$name'`, `"$name"` и `$name`? Почему файл с пробелом ломает скрипт без кавычек?

## Один пример — три результата

```bash
name='my project'
printf '<%s>\n' '$name'
printf '<%s>\n' "$name"
printf '<%s>\n' $name
```

```text
<$name>
<my project>
<my>
<project>
```

Последняя команда получила два аргумента вместо одного. Если значение содержит `*`, после разбиения shell может дополнительно подставить имена файлов. Поэтому проблема не ограничивается пробелами.

## Присваивание и подстановка

```bash
project='api'
filename="${project}.log"
today=$(date +%F)
printf '%s: %s\n' "$today" "$filename"
```

В присваивании нет пробелов вокруг `=`: `project = api` пытается запустить команду `project`. Фигурные скобки отделяют имя переменной от соседнего текста. `$(...)` выполняет команду и подставляет её stdout, удаляя завершающие переводы строки.

```bash
unset APP_PORT
printf '%s\n' "${APP_PORT:-8080}"
```

`:-` задаёт значение по умолчанию, если переменная не задана или пуста. Это не проверка допустимости порта: валидация выполняется отдельно.

## Кавычки не отменяют смысл данных

`"$value"` гарантирует один аргумент, но сама программа всё ещё может интерпретировать его как опцию или шаблон. Например, для имени файла `-n` нужен и разделитель опций `--`, если команда его поддерживает.

Не используй `eval` для запуска строки из пользовательского ввода. Обычно нужна команда с отдельными аргументами или Bash-массив, а не повторный разбор текста оболочкой.

## Практика

Создай `file='report final.txt'` и сравни `touch "$file"` с выводом `printf '<%s>\n' $file`. Затем объясни разницу между `"*.log"` и `*.log`.
