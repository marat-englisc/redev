# Как работают терминал, shell и команды

> [!NOTE]
> Терминал передаёт ввод оболочке и показывает вывод программ. Shell разбирает строку, раскрывает переменные и шаблоны, настраивает потоки и запускает команду. Команда бывает встроенной в shell, функцией, alias или отдельным исполняемым файлом. `type` помогает выяснить, что именно будет вызвано.

## Вопрос

Что происходит после Enter в терминале? Почему `cd` должна менять каталог самой оболочки?

## Из чего состоит команда

```bash
ls -lah /etc
```

Здесь `ls` — имя команды, `-lah` — краткие опции, `/etc` — аргумент-путь. Не у каждой программы одинаковый синтаксис опций: смотри её справку.

```bash
type cd
type ls
command -v bash
printf '%s\n' "$SHELL"
```

`cd` встроена в оболочку, потому что должна изменить **её** рабочий каталог. Внешний процесс может изменить только свой каталог: после его завершения родительская оболочка останется на прежнем месте. `$SHELL` обычно сообщает настроенную login shell, а не доказывает, какая оболочка исполняет текущую строку.

## Как shell видит аргументы

```bash
printf '<%s>\n' one 'two words'
```

```text
<one>
<two words>
```

Кавычки группируют слова и не передаются программе как часть аргумента. Это объясняет, почему `mkdir 'my project'` создаёт одну папку, а `mkdir my project` — две.

## Полезные действия в терминале

| Действие | Клавиши | Что происходит |
| --- | --- | --- |
| Дополнить путь или команду | Tab | Оболочка предлагает дополнение |
| Найти прежнюю команду | Ctrl R | Поиск в истории Bash |
| Прервать foreground-процесс | Ctrl C | Обычно отправляется SIGINT |
| Завершить ввод | Ctrl D | На пустой строке может закрыть shell |
| Очистить отображение | Ctrl L | Экран перерисовывается; история остаётся |

При вводе пароля `sudo` символы часто не показываются вообще. Это ожидаемое поведение: вводи пароль и нажимай Enter.

## Частые ошибки

- Копировать знак приглашения `$` вместе с командой.
- Думать, что закрытие окна гарантированно завершит все запущенные процессы.
- Вставлять секреты в командную строку: она может попасть в историю и список процессов.

## Практика

Проверь `type echo`, `type pwd`, `type bash`. Передай в `printf` аргумент с пробелами и объясни число получившихся строк.
