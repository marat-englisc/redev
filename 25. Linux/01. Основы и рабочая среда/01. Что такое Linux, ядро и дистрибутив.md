# Что такое Linux, ядро и дистрибутив

> [!NOTE]
> **Linux** — ядро операционной системы: оно управляет процессами, памятью, устройствами и доступом к ресурсам. **Дистрибутив** объединяет ядро, системные программы, менеджер пакетов и настройки в готовую ОС. Ubuntu, Debian и Fedora — дистрибутивы; Bash — оболочка; терминал — интерфейс для работы с оболочкой.

## Вопрос

Чем Linux отличается от дистрибутива? Где в этой системе находятся Bash, терминал и приложение?

## Основная идея

Когда разработчик запускает сервер, приложение не управляет диском напрямую. Оно просит ОС открыть файл, выделить память или принять сетевое соединение. Граница между программой и ядром проходит через **системные вызовы**, например `openat`, `read` и `socket`.

```text
Терминал → Bash → команда или приложение
                        ↓ системные вызовы
                    Ядро Linux
                        ↓
               CPU, память, диск, сеть
```

Большинство привычных команд работает в **user space**, то есть вне ядра. Ошибка в отдельной программе обычно завершает её процесс; ошибка в ядре способна затронуть всю машину.

## Что входит в дистрибутив

| Компонент | Назначение | Пример |
| --- | --- | --- |
| Ядро | Управление ресурсами и устройствами | Linux |
| Библиотеки | Общие функции для программ | glibc, musl |
| Утилиты | Работа с файлами и текстом | GNU coreutils |
| Оболочка | Разбор команд и запуск процессов | Bash |
| Система инициализации | Запуск и сопровождение служб | systemd во многих дистрибутивах |
| Менеджер пакетов | Установка ПО и зависимостей | APT, DNF |

Графическая среда на сервере необязательна. Один и тот же Linux может обслуживать API без рабочего стола или работать на ноутбуке с графическим интерфейсом.

## Как узнать свою среду

```bash
cat /etc/os-release
uname -r
uname -m
ps -p 1 -o comm=
```

Первая команда показывает дистрибутив, вторая — версию ядра, третья — архитектуру, последняя — имя процесса PID 1. Например, `x86_64` описывает архитектуру, а `systemd` — запущенный процесс, а не название дистрибутива.

## Практика

Выпиши название своей ОС, ядра, архитектуры и PID 1. Объясни, почему инструкция `apt install` для Ubuntu не обязана работать в Fedora или Alpine.

## Частые ошибки

- Называть Bash операционной системой.
- Считать, что все Linux-системы используют systemd и одинаковые пакеты.
- Переносить команды из macOS без проверки: там другие версии многих утилит.
