# Как проверять HTTP и TLS через curl и openssl

> [!NOTE]
> `curl` позволяет отдельно наблюдать DNS, соединение, TLS и HTTP-ответ. Успешная передача HTTP 500 без специальных опций может дать exit code 0; `--fail` делает многие HTTP-ошибки неуспешным исходом. TLS проверяет сертификат и имя сервера. Отключение проверки через `-k` скрывает важную часть проблемы и не исправляет доверие.

## Вопрос

Как отличить ошибку сертификата от HTTP 403? Почему запрос к IP вместо имени меняет результат HTTPS?

## Полезные команды

```bash
curl -I --connect-timeout 3 --max-time 10 https://example.com/
curl -v --connect-timeout 3 --max-time 10 https://example.com/
curl --fail --silent --show-error --max-time 10 https://example.com/ -o /dev/null
```

`-I` выполняет HEAD, который приложение может обрабатывать иначе, чем GET. `-v` показывает этапы протокола, но может раскрыть чувствительные заголовки: проверь вывод перед публикацией. `--connect-timeout` ограничивает фазу соединения, `--max-time` — всю операцию.

## Слои ошибки

```text
Имя не разрешилось → DNS
Соединение не установлено → TCP/маршрут/firewall/listener
TLS не прошёл → доверие, имя, срок, протокол, время системы
HTTP 403/404/500 → ответил HTTP-уровень, проверяем приложение/proxy
```

Ответ 502 часто приходит от reverse proxy, который не получил подходящий ответ upstream; он не доказывает конкретную причину вроде «процесс остановлен».

## SNI и Host

Для HTTPS имя участвует и в TLS SNI, и в проверке сертификата, а затем в HTTP Host. Поэтому `https://IP/` не равнозначен запросу домена. Для проверки заданного сервера без изменения DNS используют `curl --resolve домен:443:IP https://домен/` с реальными значениями: имя URL сохраняется.

```bash
openssl s_client -connect example.com:443 -servername example.com -verify_hostname example.com -verify_return_error < /dev/null
```

Команда показывает цепочку и результат проверки. Доверенные CA, proxy и версии OpenSSL могут различаться между машинами. Сервер обычно должен отдавать нужные промежуточные сертификаты.

## Практика

Сними HTTP-код и времена через `curl -o /dev/null -sS -w 'code=%{http_code} total=%{time_total}\n' https://example.com/`. Сравни с запросом к локальному учебному серверу. Не отключай TLS-проверку для обычного использования.
