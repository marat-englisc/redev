# Как искать файлы - find, locate и безопасная обработка имён

> [!NOTE]
> `find` обходит файловое дерево и проверяет имя, тип, размер, время и другие свойства. `locate` ищет по заранее построенной базе: быстро, но сведения могут устареть. Для передачи произвольных имён используй `find -exec ... {} +` или NUL-разделение `-print0` с `xargs -0`, а не разбиение по пробелам.

## Вопрос

Как найти большие логи и корректно обработать файлы с пробелами? Чем `find` отличается от `locate`?

## Поиск по нескольким признакам

```bash
mkdir -p "$HOME/linux-lab/search"
cd "$HOME/linux-lab/search"
printf 'error\n' > 'my app.log'
touch notes.txt
find . -type f -name '*.log'
find . -type f -name '*.log' -size +1M
find . -type f -mmin -10
```

Условия без явного оператора соединяются логическим И. Второй поиск здесь ничего не найдёт: маленький лог не больше 1 MiB. Кавычки вокруг `*.log` нужны, чтобы шаблон обработал `find`, а не текущая оболочка.

| Условие | Смысл |
| --- | --- |
| `-type f` | Обычный файл |
| `-type d` | Каталог |
| `-iname` | Имя без учёта регистра |
| `-mtime +7` | Более семи полных 24-часовых интервалов по правилам округления find |
| `-mmin -10` | Изменён меньше десяти минут назад |
| `-maxdepth 2` | Ограничить глубину обхода в GNU find |

## Передача имён другой команде

```bash
find . -type f -name '*.log' -exec wc -l -- {} +
find . -type f -name '*.log' -print0 | xargs -0 -r wc -l --
```

`{}` заменяется найденными путями, `+` группирует их в вызовы команды. Во втором варианте разделитель NUL не путается с пробелами и переводами строки внутри имени. `-r` — опция GNU xargs, запрещающая пустой запуск.

`for f in $(find ...)` неправильно разбивает имена. Вывод `ls` тоже не предназначен для такого разбора.

## Сначала посмотреть

Перед массовым изменением сначала запусти тот же поиск с обычным выводом. Особенно внимательно проверяй начальный каталог и условия `-o`: логическое И имеет больший приоритет, поэтому альтернативы часто требуют скобок `\( ... -o ... \)`.

## Практика

Найди только `.log` и `.txt` внутри учебной папки через `find . -type f \( -name '*.log' -o -name '*.txt' \)`. Посчитай строки без потери пробела в `my app.log`.
