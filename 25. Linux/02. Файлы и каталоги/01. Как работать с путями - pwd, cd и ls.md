# Как работать с путями - pwd, cd и ls

> [!NOTE]
> Абсолютный путь начинается с `/`, относительный отсчитывается от текущего рабочего каталога. `pwd` показывает этот каталог, `cd` меняет его, `ls` выводит содержимое. `.` означает текущий каталог, `..` — родительский, `~` раскрывается оболочкой в домашний каталог в подходящем контексте.

## Вопрос

Чем отличаются `/var/log`, `var/log` и `../log`? Почему одна и та же команда с относительным путём работает из одной папки и не работает из другой?

## Воспроизводимый пример

```bash
mkdir -p "$HOME/linux-lab/paths/app/logs"
cd "$HOME/linux-lab/paths"
pwd
cd app
printf 'started\n' > logs/app.log
ls -lah logs
cat ./logs/app.log
cd ..
cat app/logs/app.log
```

Оба `cat` читают один файл, но относительно разных рабочих каталогов. Для процесса рабочий каталог — отдельное свойство; приложение, запущенное службой, может иметь другой cwd, чем твой терминал.

## Чтение вывода ls

```text
-rw-r--r-- 1 alex alex 8 Oct 27 10:00 app.log
```

Слева направо: тип и права, число жёстких ссылок, владелец, группа, размер, дата и имя. Формат времени зависит от локали и возраста файла.

| Опция | Что делает |
| --- | --- |
| `-l` | Подробный формат |
| `-a` | Показывает и имена, начинающиеся с точки |
| `-h` | Удобные единицы размера при подробном выводе |
| `-d` | Показывает сам каталог вместо содержимого |

## Нюансы путей

Linux обычно различает `Readme.md` и `README.md`; конкретное поведение зависит и от файловой системы. Точка в начале имени скрывает файл из обычного `ls`, но не защищает доступ к нему.

```bash
cd "$HOME"
cd -
```

`cd -` возвращает в предыдущий рабочий каталог. Запись `"~/linux-lab"` не раскрывает тильду: в кавычках используй `"$HOME/linux-lab"`.

## Практика

Из `~/linux-lab/paths/app/logs` доберись до `paths` через `../..`, затем прочитай лог без смены каталога. Проверь результат `realpath app/logs/app.log`.

## Частые ошибки

- Путать корень `/` и домашний каталог root `/root`.
- Судить о наличии файла только по `ls` без `-a`.
- Парсить форматированный `ls` в скриптах вместо `find` или glob.
