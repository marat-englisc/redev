# Как создавать, копировать и удалять файлы - glob и двойной дефис

> [!NOTE]
> `mkdir` создаёт каталоги, `touch` создаёт пустой файл или меняет его временные метки, `cp` копирует, `mv` перемещает или переименовывает, `rm` удаляет. Шаблоны `*` и `?` раскрывает shell до запуска команды. `--` завершает разбор опций у поддерживающих его программ и помогает работать с именами, начинающимися с дефиса.

## Вопрос

Кто раскрывает `*.log`? Как безопасно обработать имя `-report.txt` и что произойдёт при `cp` поверх существующего файла?

## Пример в отдельной папке

```bash
mkdir -p "$HOME/linux-lab/files/backup"
cd "$HOME/linux-lab/files"
touch first.log second.log .hidden.log
printf 'draft\n' > 'my notes.txt'
cp -i -- 'my notes.txt' backup/
mv -i -- 'my notes.txt' 'ready notes.txt'
printf '<%s>\n' *.log
touch -- -report.txt
ls -l -- -report.txt
```

Последний `printf` показывает, какие имена оболочка подставила вместо `*.log`. По умолчанию Bash не включает скрытый `.hidden.log` в этот шаблон. `?` соответствует одному символу, `[0-9]` — символу из набора. Это **glob**, а не регулярное выражение.

Если совпадений нет, Bash по умолчанию оставляет шаблон буквальным; настройки вроде `nullglob` меняют это поведение. Проверяй раскрытие перед массовой операцией.

## Копирование и перезапись

`cp source target` может перезаписать target. `-i` запрашивает подтверждение; это удобно для ручной работы. Для дерева каталогов полезен `cp -a source backup/`: он старается сохранить атрибуты и ссылки. Возможность сохранить владельца зависит от прав пользователя и файловой системы.

`mv` внутри одной файловой системы обычно переименовывает запись, а между разными может фактически копировать данные и удалять исходник. Поэтому перемещение большого файла не всегда мгновенно.

## Удаление

```bash
rm -i -- first.log
rm -i -- -report.txt
rmdir backup
```

`rmdir backup` в этом примере откажется удалять непустой каталог — там копия заметки. `rm` не переносит файл в корзину. Для учебного удаления дерева сначала проверь `pwd` и список объектов; не используй `sudo` для обхода непонятной ошибки.

## Практика

Создай имена с пробелом и дефисом, скопируй их в `backup` и объясни разницу между `*.log` и `'*.log'`. Во втором случае программе передаётся буквальная строка.
