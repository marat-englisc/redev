# Как разбирать поля и считать значения через awk

> [!NOTE]
> `awk` обрабатывает записи по правилу «условие → действие». `$0` — вся строка, `$1`, `$2` — поля, `NR` — номер записи, `NF` — число полей. По умолчанию поля разделяются последовательностями пробельных символов. `BEGIN` выполняется до чтения, `END` — после; они удобны для настройки и итоговых отчётов.

## Вопрос

Как посчитать ошибки и среднее время ответа в простом текстовом логе без отдельной программы на Python?

## Учебный формат

```bash
mkdir -p "$HOME/linux-lab/awk"
cd "$HOME/linux-lab/awk"
cat > requests.log <<'EOF'
anna 200 12
ivan 500 80
anna 502 40
EOF
awk '$2 >= 500 { print $1, $2 }' requests.log
awk '{ total += $3 } END { if (NR > 0) print total / NR }' requests.log
```

В первой программе фильтруем числовое второе поле, затем выводим имя и статус. Во второй суммируем третье поле и делим на число записей: результат — `44`. Проверка `NR > 0` защищает от деления на ноль для пустого файла.

## Группировка

```bash
awk '{ count[$1]++ } END { for (user in count) print user, count[user] }' requests.log
```

`count` — ассоциативный массив: ключ — имя, значение — число запросов. Порядок обхода не гарантирован; для стабильного отчёта передай результат в `sort`.

## Другой разделитель и внешнее значение

```bash
printf 'anna:200\nivan:500\n' | awk -F: '$2 >= 500 { print $1 }'
awk -v threshold=50 '$3 > threshold { print $0 }' requests.log
```

`-F:` задаёт разделитель полей, `-v` передаёт значение без склеивания кода awk со строкой shell. Всю программу удобно заключать в одинарные кавычки, чтобы `$1` не раскрывала оболочка.

## Ограничения

Пример предполагает ровно три корректных поля, а последняя колонка содержит миллисекунды. В рабочем скрипте проверяют формат и единицы. Не вычисляй среднее по заголовкам таблицы или ошибочным строкам.

`awk` удобен для простых разделённых полей. Он не превращается автоматически в JSON- или CSV-парсер. Разные реализации поддерживают разные расширения; показанные базовые конструкции переносимее специальных функций GNU awk.

## Практика

Посчитай число ответов со статусом не меньше 500 и сумму их времени. Проверь вручную: в примере две ошибки и 120 мс суммарно. Затем повтори на пустом файле.
