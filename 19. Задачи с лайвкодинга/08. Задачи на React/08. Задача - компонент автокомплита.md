# Задача: компонент автокомплита

> [!NOTE]
> **Автокомплит на React** собирает несколько тем сразу: управляемое поле, **debounce** запроса, **отмена устаревших запросов**, кеш результатов, состояния загрузки, пустого результата и ошибки, навигация **стрелками** и выбор по Enter, закрытие по Escape и клику снаружи, **подсветка совпадения** без `innerHTML` и доступная разметка по паттерну **WAI-ARIA combobox**. Это одна из самых частых задач на позицию middle.

## Вопрос

Напишите компонент `Autocomplete`, который ищет варианты через API по мере ввода, поддерживает клавиатуру и мышь, показывает состояния загрузки и ошибки и доступен для скринридера.

## Решение

```tsx
import { useEffect, useId, useRef, useState } from "react";

type Option = { id: string; label: string };

type Props = {
  label: string;
  fetchOptions: (query: string, signal: AbortSignal) => Promise<Option[]>;
  onSelect: (option: Option) => void;
  minChars?: number;
  debounceMs?: number;
};

const cache = new Map<string, Option[]>();

export function Autocomplete({ label, fetchOptions, onSelect, minChars = 2, debounceMs = 250 }: Props) {
  const [query, setQuery] = useState("");
  const [options, setOptions] = useState<Option[]>([]);
  const [status, setStatus] = useState<"idle" | "loading" | "error" | "done">("idle");
  const [open, setOpen] = useState(false);
  const [active, setActive] = useState(-1);
  const rootRef = useRef<HTMLDivElement>(null);
  const listId = useId();
  const inputId = useId();

  useEffect(() => {
    const q = query.trim().toLowerCase();
    if (q.length < minChars) {
      setOptions([]);
      setStatus("idle");
      return;
    }
    if (cache.has(q)) {
      setOptions(cache.get(q)!);
      setStatus("done");
      return;
    }

    const controller = new AbortController();
    const timer = setTimeout(async () => {
      setStatus("loading");
      try {
        const result = await fetchOptions(q, controller.signal);
        cache.set(q, result);
        setOptions(result);
        setStatus("done");
        setActive(-1);
      } catch (e) {
        if (!controller.signal.aborted) setStatus("error");
      }
    }, debounceMs);

    return () => {
      clearTimeout(timer);              // debounce
      controller.abort();               // отмена устаревшего запроса
    };
  }, [query, minChars, debounceMs, fetchOptions]);

  useEffect(() => {
    function onPointerDown(e: PointerEvent) {
      if (!rootRef.current?.contains(e.target as Node)) setOpen(false);
    }
    document.addEventListener("pointerdown", onPointerDown);
    return () => document.removeEventListener("pointerdown", onPointerDown);
  }, []);

  function select(option: Option) {
    setQuery(option.label);
    setOpen(false);
    setActive(-1);
    onSelect(option);
  }

  function onKeyDown(e: React.KeyboardEvent<HTMLInputElement>) {
    if (e.key === "ArrowDown") {
      e.preventDefault();
      setOpen(true);
      setActive((i) => Math.min(i + 1, options.length - 1));
    } else if (e.key === "ArrowUp") {
      e.preventDefault();
      setActive((i) => Math.max(i - 1, 0));
    } else if (e.key === "Enter" && open && active >= 0) {
      e.preventDefault();
      select(options[active]);
    } else if (e.key === "Escape") {
      setOpen(false);
    }
  }

  const showList = open && query.trim().length >= minChars;

  return (
    <div ref={rootRef} className="autocomplete">
      <label htmlFor={inputId}>{label}</label>
      <input
        id={inputId}
        role="combobox"
        aria-expanded={showList}
        aria-controls={listId}
        aria-autocomplete="list"
        aria-activedescendant={active >= 0 ? `${listId}-${active}` : undefined}
        value={query}
        onChange={(e) => { setQuery(e.target.value); setOpen(true); }}
        onFocus={() => setOpen(true)}
        onKeyDown={onKeyDown}
        autoComplete="off"
      />

      {showList && (
        <ul id={listId} role="listbox">
          {status === "loading" && <li role="presentation">Загрузка…</li>}
          {status === "error" && <li role="presentation">Ошибка поиска, попробуйте еще раз</li>}
          {status === "done" && options.length === 0 && <li role="presentation">Ничего не найдено</li>}
          {options.map((option, i) => (
            <li
              key={option.id}
              id={`${listId}-${i}`}
              role="option"
              aria-selected={i === active}
              className={i === active ? "active" : undefined}
              onMouseEnter={() => setActive(i)}
              onMouseDown={(e) => e.preventDefault()}     // не терять фокус поля до выбора
              onClick={() => select(option)}
            >
              <Highlight text={option.label} query={query} />
            </li>
          ))}
        </ul>
      )}

      <div aria-live="polite" className="visually-hidden">
        {status === "done" ? `Найдено вариантов: ${options.length}` : ""}
      </div>
    </div>
  );
}

function Highlight({ text, query }: { text: string; query: string }) {
  const index = text.toLowerCase().indexOf(query.trim().toLowerCase());
  if (!query.trim() || index === -1) return <>{text}</>;
  const end = index + query.trim().length;
  return (
    <>
      {text.slice(0, index)}
      <mark>{text.slice(index, end)}</mark>
      {text.slice(end)}
    </>
  );
}
```

## Использование

```tsx
const fetchCities = (q: string, signal: AbortSignal) =>
  fetch(`/api/cities?q=${encodeURIComponent(q)}`, { signal }).then((r) => {
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return r.json();
  });

<Autocomplete label="Город" fetchOptions={fetchCities} onSelect={(c) => console.log(c)} />
```

`fetchCities` объявлена вне компонента — стабильная ссылка, эффект не перезапускается на каждый рендер.

## Что обсуждают на собеседовании

- **Гонки:** без `abort` ответ на «мо» может прийти после «москва» и перезаписать список.
- **Debounce:** запрос не на каждую букву; `clearTimeout` в cleanup.
- **Кеш:** повторный ввод того же запроса мгновенный; ограничить размер (LRU).
- **Клавиатура и ARIA:** фокус остается в поле, активный вариант — через `aria-activedescendant`.
- **`onMouseDown` + `preventDefault`:** иначе поле потеряет фокус до `click` и список закроется.
- **Подсветка без `dangerouslySetInnerHTML`:** защита от XSS.

## Что важно помнить

- Стабильный `fetchOptions` (вне компонента или `useCallback`), иначе бесконечные перезапуски эффекта.
- Сбрасывайте `active` при новых результатах.
- Состояния загрузки, пустого результата и ошибки — внутри списка.
- Проектирование этой задачи целиком: [автокомплит в system design](<../../17. Frontend System Design/04. Разбор задач/01. Как спроектировать автокомплит (typeahead).md>).

## Мини-шпаргалка

Эффект на `query`: `minChars` → кеш → `setTimeout` (debounce) + `AbortController` → результаты/ошибка → cleanup `clearTimeout` + `abort`. Клавиатура: ↓ ↑ Enter Esc. Combobox ARIA: `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`, listbox/option, `aria-live`. Подсветка через `<mark>` без innerHTML.
