# Что выведет: hoisting, TDZ и замыкания

> [!NOTE]
> Задачи этой группы проверяют, как работают области видимости. **Hoisting**: объявления `var` поднимаются и инициализируются `undefined`, объявления функций (`function f() {}`) поднимаются целиком. `let`, `const` и `class` тоже поднимаются, но до строки объявления находятся во **временной мертвой зоне (TDZ)** — обращение к ним дает `ReferenceError`, даже через `typeof`. **Замыкание** хранит ссылку на переменную, а не ее значение на момент создания, поэтому классика — `var` в цикле с `setTimeout`.

## Вопрос

Что выведет каждый фрагмент? Объясните через подъем объявлений, TDZ и замыкания.

## Задача 1: var, function, let

```javascript
console.log(a);
var a = 1;

console.log(typeof foo);
function foo() {}

console.log(typeof bar);
var bar = function () {};

try { console.log(b); } catch (e) { console.log(e.constructor.name); }
let b = 2;

console.log(typeof undeclaredVar);
try { console.log(typeof c); } catch (e) { console.log(e.constructor.name); }
let c = 3;
```

> [!TIP]- Ответ
> `undefined`, `function`, `undefined`, `ReferenceError`, `undefined`, `ReferenceError`.
> Function declaration поднимается целиком, function expression в `var` — только переменная. `typeof` для необъявленной переменной безопасен, но для переменной в TDZ — нет.

## Задача 2: затенение внутри функции

```javascript
var x = 1;
function f() {
  console.log(x);
  var x = 2;
}
f();
```

> [!TIP]- Ответ
> `undefined`. Внутри `f` есть свой `var x`, поднятый в начало функции, — он затеняет внешний `x`, но еще не присвоен.

## Задача 3: функция после return

```javascript
function g() {
  return h();
  function h() { return "h"; }
}
console.log(g());
```

> [!TIP]- Ответ
> `h`. Объявление `h` поднимается в начало `g`, поэтому доступно до строки, где оно написано.

## Задача 4: var и let в цикле

```javascript
for (var i = 0; i < 3; i++) setTimeout(() => console.log("var", i), 0);
for (let j = 0; j < 3; j++) setTimeout(() => console.log("let", j), 0);
```

> [!TIP]- Ответ
> `var 3`, `var 3`, `var 3`, `let 0`, `let 1`, `let 2`. У `var` одна переменная на всю функцию — к моменту срабатывания таймеров цикл закончился, `i === 3`. У `let` на каждую итерацию создается новая переменная.
>
> Исправления для `var`: заменить на `let`; IIFE `((n) => setTimeout(() => console.log(n)))(i)`; третий аргумент `setTimeout(console.log, 0, i)`.

## Задача 5: счетчики и замыкание на переменную

```javascript
function makeCounter() {
  let count = 0;
  return { inc: () => ++count, get: () => count };
}
const c1 = makeCounter();
const c2 = makeCounter();
c1.inc(); c1.inc(); c2.inc();
console.log(c1.get(), c2.get());

let x = 1;
function show() { return x; }
x = 2;
console.log(show());
```

> [!TIP]- Ответ
> `2 1`, затем `2`. Каждый вызов `makeCounter` создает новое лексическое окружение. Замыкание видит **текущее** значение переменной, а не значение на момент объявления функции.

## Задача 6: const и мутация

```javascript
const arr = [1, 2];
arr.push(3);
console.log(arr);

try {
  arr = [];
} catch (e) {
  console.log(e.constructor.name);
}
```

> [!TIP]- Ответ
> `[1, 2, 3]`, затем `TypeError`. `const` запрещает переприсваивание переменной, но не изменение объекта, на который она указывает.

## Задача 7: блочная область

```javascript
if (true) {
  var fromVar = "var";
  let fromLet = "let";
}
console.log(fromVar);
try { console.log(fromLet); } catch (e) { console.log(e.constructor.name); }
```

> [!TIP]- Ответ
> `var`, затем `ReferenceError`. `var` имеет функциональную область и «протекает» из блока, `let` — блочную.

## Сводка

| Объявление | Поднимается | До объявления | Область |
| --- | --- | --- | --- |
| `var` | да, со значением `undefined` | `undefined` | функция |
| `function f() {}` | да, целиком | можно вызвать | функция (в блоке — особые правила) |
| `let`, `const` | да, без инициализации | `ReferenceError` (TDZ) | блок |
| `class` | да, без инициализации | `ReferenceError` (TDZ) | блок |
| function expression / стрелка в `var` | только переменная | `undefined`, вызов → `TypeError` | как у переменной |

## Что важно помнить

- TDZ действует от начала блока до строки объявления — даже для `typeof`.
- `var` в цикле с асинхронными колбэками — одна общая переменная.
- Замыкание хранит ссылку на переменную; изменения после создания функции видны внутри.
- В современном коде используйте `const` по умолчанию, `let` — когда нужно переприсваивание, `var` — не используйте.
- Теория: [замыкания](<../../04. JavaScript/02. Функции/04. Замыкания.md>), [scope chain](<../../04. JavaScript/10. Дополнительные темы/04. Scope chain и лексическая область видимости.md>), [execution context](<../../04. JavaScript/10. Дополнительные темы/03. Execution context.md>).

## Мини-шпаргалка

`var` → `undefined` до присваивания, функция целиком, `let/const/class` → TDZ и `ReferenceError` (даже `typeof`). `var` в цикле — одна переменная (3, 3, 3), `let` — новая на итерацию. Замыкание видит текущее значение. `const` — нельзя переприсвоить, можно мутировать.
