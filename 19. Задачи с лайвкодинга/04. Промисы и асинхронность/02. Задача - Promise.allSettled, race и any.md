# Задача: Promise.allSettled, race и any

> [!NOTE]
> Три других комбинатора промисов часто дают как продолжение задачи про `Promise.all`. **`allSettled`** ждет все промисы и возвращает массив `{ status: "fulfilled", value }` / `{ status: "rejected", reason }` — никогда не отклоняется. **`race`** завершается так же, как **первый завершившийся** промис (успехом или ошибкой). **`any`** выполняется **первым успешным** результатом и отклоняется `AggregateError`, только если все отклонились.

## Вопрос

Реализуйте `promiseAllSettled`, `promiseRace` и `promiseAny`. Чем они отличаются от `Promise.all` и где применяются?

## allSettled

```javascript
function promiseAllSettled(iterable) {
  const items = Array.from(iterable);
  return Promise.all(
    items.map((item) =>
      Promise.resolve(item).then(
        (value) => ({ status: "fulfilled", value }),
        (reason) => ({ status: "rejected", reason }),
      ),
    ),
  );
}
```

Каждый промис превращается в «всегда успешный» с описанием результата, а затем используется `Promise.all`. Если просят без `Promise.all` — та же схема со счетчиком, что в задаче про `Promise.all`, но без `reject`.

```javascript
await promiseAllSettled([Promise.resolve(1), Promise.reject(new Error("x")), 3]);
// [
//   { status: "fulfilled", value: 1 },
//   { status: "rejected", reason: Error("x") },
//   { status: "fulfilled", value: 3 }
// ]
```

## race

```javascript
function promiseRace(iterable) {
  return new Promise((resolve, reject) => {
    for (const item of iterable) {
      Promise.resolve(item).then(resolve, reject);   // первый вызов побеждает, остальные игнорируются
    }
  });
}
```

```javascript
await promiseRace([delay(200, "медленный"), delay(50, "быстрый")]);   // "быстрый"
promiseRace([]);   // навсегда pending — как и нативный Promise.race
```

## any

```javascript
function promiseAny(iterable) {
  return new Promise((resolve, reject) => {
    const items = Array.from(iterable);
    const errors = new Array(items.length);
    let rejected = 0;

    if (items.length === 0) {
      reject(new AggregateError([], "All promises were rejected"));
      return;
    }

    items.forEach((item, index) => {
      Promise.resolve(item).then(resolve, (error) => {
        errors[index] = error;
        rejected += 1;
        if (rejected === items.length) reject(new AggregateError(errors, "All promises were rejected"));
      });
    });
  });
}
```

```javascript
await promiseAny([Promise.reject(new Error("a")), delay(100, "ok")]);   // "ok"
await promiseAny([Promise.reject(new Error("a"))]).catch((e) => e.errors.length); // 1
```

## Сравнение

| Метод | Выполняется | Отклоняется | Пустой вход |
| --- | --- | --- | --- |
| `all` | все успешны → массив значений | первая ошибка | `[]` |
| `allSettled` | все завершились → массив статусов | никогда | `[]` |
| `race` | первый завершившийся успешно | первый завершившийся с ошибкой | вечный pending |
| `any` | первый успешный | все отклонены → `AggregateError` | `AggregateError` |

## Применение

| Задача | Метод |
| --- | --- |
| загрузить данные дашборда, где виджеты независимы | `allSettled` — показать то, что загрузилось |
| таймаут запроса | `race([fetch(url), timeout(5000)])` |
| взять ответ с самого быстрого зеркала / CDN | `any` |
| все данные обязательны для экрана | `all` |

## Что важно помнить

- `race` с таймаутом не отменяет исходный запрос — используйте `AbortSignal.timeout`.
- `any` отклоняется `AggregateError` с массивом `errors`.
- `allSettled` удобен для массовых операций с отчетом об ошибках.
- Теория: [Promise.all, allSettled, race и any](<../../04. JavaScript/05. Асинхронность и Event Loop/14. Promise.all allSettled race и any.md>).

## Мини-шпаргалка

allSettled — каждый промис → `{ status, value | reason }`, затем `all`. race — `Promise.resolve(x).then(resolve, reject)` для всех, побеждает первый. any — resolve первым успехом, счетчик ошибок → `AggregateError`. Пустой race — pending, пустой any — AggregateError.
