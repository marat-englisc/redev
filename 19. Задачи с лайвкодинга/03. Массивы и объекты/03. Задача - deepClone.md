# Задача: deepClone

> [!NOTE]
> **Глубокое копирование** создает независимую копию объекта со всеми вложенными объектами и массивами. Базовое решение — рекурсия по ключам; на собеседовании ждут обработки **примитивов и `null`**, **массивов**, **`Date`, `RegExp`, `Map`, `Set`**, **циклических ссылок** (через `WeakMap` уже скопированных объектов) и сохранения **прототипа**. В реальном коде есть встроенный `structuredClone`, но он не копирует функции, DOM-узлы и прототипы классов.

## Вопрос

Реализуйте `deepClone(value)`. Как обработать `Date`, `Map`, `Set`, циклические ссылки и прототип? Чем плох `JSON.parse(JSON.stringify(obj))`?

## Решение

```javascript
function deepClone(value, seen = new WeakMap()) {
  if (value === null || typeof value !== "object") return value;   // примитивы и функции — как есть

  if (seen.has(value)) return seen.get(value);                     // циклическая ссылка

  if (value instanceof Date) return new Date(value.getTime());
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  if (value instanceof Map) {
    const copy = new Map();
    seen.set(value, copy);
    value.forEach((v, k) => copy.set(deepClone(k, seen), deepClone(v, seen)));
    return copy;
  }

  if (value instanceof Set) {
    const copy = new Set();
    seen.set(value, copy);
    value.forEach((v) => copy.add(deepClone(v, seen)));
    return copy;
  }

  const copy = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value)); // сохраняем прототип
  seen.set(value, copy);

  for (const key of Reflect.ownKeys(value)) {                      // строковые и символьные ключи
    copy[key] = deepClone(value[key], seen);
  }

  return copy;
}
```

## Проверка

```javascript
const original = {
  name: "Анна",
  birth: new Date("1995-05-01"),
  tags: new Set(["admin"]),
  meta: new Map([["role", { level: 2 }]]),
  address: { city: "Казань", geo: [55.8, 49.1] },
  [Symbol("id")]: 1,
};
original.self = original;                    // цикл

const copy = deepClone(original);
copy.address.city = "Москва";
copy.meta.get("role").level = 5;

original.address.city;                       // "Казань"
original.meta.get("role").level;             // 2
copy.self === copy;                          // true — цикл сохранен
copy.birth instanceof Date;                  // true
```

## Почему не JSON

```javascript
JSON.parse(JSON.stringify({ d: new Date(), u: undefined, f() {}, n: NaN, m: new Map([[1, 2]]) }));
// { d: "2026-...Z", n: null, m: {} } — дата стала строкой, undefined и функция пропали, NaN → null, Map → {}
```

Плюс `JSON.stringify` бросает ошибку на циклических ссылках и на `BigInt`.

## structuredClone

```javascript
const copy = structuredClone(original);
```

| | `structuredClone` | наш `deepClone` |
| --- | --- | --- |
| Date, Map, Set, RegExp, циклы | да | да |
| ArrayBuffer, typed arrays, Blob, File | да | нет (можно добавить) |
| Функции | ошибка `DataCloneError` | копирует ссылку |
| Прототип класса | теряется — получится обычный объект | сохраняется |
| Символьные ключи | не копируются | копируются |
| DOM-узлы | ошибка | копирует как объект (неправильно) |

## Доп. вопросы интервьюера

- **Чем поверхностная копия отличается от глубокой?** `{ ...obj }` и `Object.assign` копируют только первый уровень, вложенные объекты остаются общими.
- **Зачем `WeakMap`, а не `Map`?** не удерживает исходные объекты от сборки мусора, ключи — только объекты.
- **Как сделать без рекурсии?** очередь или стек пар `[исходный, копия]` — защита от переполнения стека на глубокой вложенности.
- **Как копировать геттеры и неперечисляемые свойства?** `Object.getOwnPropertyDescriptors` + `Object.defineProperties`.

## Что важно помнить

- Сначала проверка на примитивы и `null` (`typeof null === "object"`).
- Запоминайте копию в `seen` **до** рекурсивного обхода — иначе цикл не разорвется.
- В production используйте `structuredClone` или проверенную библиотеку, а не самописную функцию.
- Теория: [поверхностное и глубокое копирование](<../../04. JavaScript/03. Объекты и прототипы/07. Как копировать объекты и массивы поверхностно и глубоко.md>).

## Мини-шпаргалка

Примитив/`null` → вернуть. `seen` (`WeakMap`) для циклов. `Date`, `RegExp`, `Map`, `Set` — отдельные ветки. Массив или `Object.create(proto)` → записать в `seen` → `Reflect.ownKeys` + рекурсия. JSON теряет Date, undefined, функции, Map и падает на циклах. Нативно — `structuredClone`.
