# Задача: deepEqual

> [!NOTE]
> `deepEqual(a, b)` сравнивает значения **по содержимому**, а не по ссылке: `deepEqual({ x: [1, 2] }, { x: [1, 2] }) === true`. Алгоритм: если значения строго равны (или оба `NaN`) — `true`; если хотя бы одно не объект — `false`; если различаются прототипы или наборы ключей — `false`; иначе рекурсивно сравнить значения каждого ключа. Продвинутые части — `Date`, `RegExp`, `Map`, `Set` и циклические ссылки.

## Вопрос

Реализуйте `deepEqual(a, b)` для примитивов, массивов и объектов любой вложенности. Как учесть `NaN`, `Date`, разные прототипы и циклические ссылки?

## Решение

```javascript
function deepEqual(a, b, seen = new WeakMap()) {
  if (Object.is(a, b)) return true;                       // одинаковые ссылки, примитивы, NaN === NaN

  if (typeof a !== "object" || typeof b !== "object" || a === null || b === null) {
    return false;                                         // разные примитивы или объект vs примитив
  }

  if (Object.getPrototypeOf(a) !== Object.getPrototypeOf(b)) return false; // [] vs {}, Date vs {}

  if (a instanceof Date) return a.getTime() === b.getTime();
  if (a instanceof RegExp) return a.source === b.source && a.flags === b.flags;

  // циклы: если эту пару уже сравниваем — считаем равной
  if (seen.get(a) === b) return true;
  seen.set(a, b);

  if (a instanceof Map) {
    if (a.size !== b.size) return false;
    for (const [key, value] of a) {
      if (!b.has(key) || !deepEqual(value, b.get(key), seen)) return false;
    }
    return true;
  }

  if (a instanceof Set) {
    if (a.size !== b.size) return false;
    for (const value of a) if (!b.has(value)) return false;   // упрощенно: по ссылкам/примитивам
    return true;
  }

  const keysA = Reflect.ownKeys(a);
  const keysB = Reflect.ownKeys(b);
  if (keysA.length !== keysB.length) return false;

  for (const key of keysA) {
    if (!Object.prototype.hasOwnProperty.call(b, key)) return false;
    if (!deepEqual(a[key], b[key], seen)) return false;
  }

  return true;
}
```

## Проверка

```javascript
deepEqual(1, 1);                                     // true
deepEqual(NaN, NaN);                                 // true
deepEqual("1", 1);                                   // false
deepEqual({ a: [1, { b: 2 }] }, { a: [1, { b: 2 }] }); // true
deepEqual({ a: 1 }, { a: 1, b: undefined });         // false — разное число ключей
deepEqual([1, 2], { 0: 1, 1: 2 });                   // false — разные прототипы
deepEqual(new Date(0), new Date(0));                 // true
deepEqual(new Map([[1, { x: 1 }]]), new Map([[1, { x: 1 }]])); // true

const x = { v: 1 }; x.self = x;
const y = { v: 1 }; y.self = y;
deepEqual(x, y);                                      // true, без бесконечной рекурсии
```

## Минимальная версия для начала

```javascript
function deepEqualBasic(a, b) {
  if (a === b) return true;
  if (typeof a !== "object" || typeof b !== "object" || !a || !b) return false;
  if (Array.isArray(a) !== Array.isArray(b)) return false;

  const keys = Object.keys(a);
  if (keys.length !== Object.keys(b).length) return false;
  return keys.every((k) => deepEqualBasic(a[k], b[k]));
}
```

Начните с нее, затем по вопросам интервьюера добавляйте `NaN`, `Date`, циклы.

## Доп. вопросы интервьюера

- **Почему не `JSON.stringify(a) === JSON.stringify(b)`?** зависит от порядка ключей, теряет `undefined`, функции, `Date`, `Map`, падает на циклах.
- **`Object.is` vs `===`?** `Object.is(NaN, NaN) === true`, `Object.is(0, -0) === false`.
- **Сравнение Set с объектами внутри?** для глубокого сравнения нужно искать пару для каждого элемента — O(n²).
- **Где используется?** тесты (`toEqual`), мемоизация по значению, сравнение props, определение «форма изменилась».

## Что важно помнить

- Не забудьте `null`: `typeof null === "object"`.
- Сравнивайте количество ключей, иначе `{ a: 1 }` будет «равен» `{ a: 1, b: 2 }`.
- Проверка прототипа отличает массив от похожего объекта.
- Глубокое сравнение дорогое — не вызывайте его на каждый рендер для больших структур.

## Мини-шпаргалка

`Object.is` → не объекты → `false` → разные прототипы → `false` → Date/RegExp по значению → `seen` для циклов → Map/Set → одинаковое число ключей и рекурсия по каждому. JSON-сравнение ненадежно.
