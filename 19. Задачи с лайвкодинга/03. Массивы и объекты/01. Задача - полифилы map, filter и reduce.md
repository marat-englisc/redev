# Задача: полифилы map, filter и reduce

> [!NOTE]
> Полифилы методов массива проверяют знание их контракта: колбэк получает `(element, index, array)`, вторым аргументом метода можно передать `thisArg`, **дырки в разреженных массивах пропускаются**, а `reduce` без начального значения берет первый элемент и бросает `TypeError` на пустом массиве. Методы пишут в `Array.prototype` через обычную функцию, где `this` — исходный массив.

## Вопрос

Реализуйте `Array.prototype.myMap`, `myFilter` и `myReduce` так, чтобы они вели себя как встроенные: аргументы колбэка, `thisArg`, разреженные массивы, `reduce` без начального значения.

## myMap

```javascript
Array.prototype.myMap = function (callback, thisArg) {
  if (typeof callback !== "function") throw new TypeError(`${callback} is not a function`);

  const result = new Array(this.length);
  for (let i = 0; i < this.length; i++) {
    if (i in this) {                                  // пропускаем дырки
      result[i] = callback.call(thisArg, this[i], i, this);
    }
  }
  return result;
};

[1, 2, 3].myMap((x, i) => x * 10 + i);   // [10, 21, 32]
[1, , 3].myMap((x) => x * 2);            // [2, <empty>, 6]
```

## myFilter

```javascript
Array.prototype.myFilter = function (callback, thisArg) {
  if (typeof callback !== "function") throw new TypeError(`${callback} is not a function`);

  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this && callback.call(thisArg, this[i], i, this)) {
      result.push(this[i]);
    }
  }
  return result;
};

[1, 2, 3, 4].myFilter((x) => x % 2 === 0);   // [2, 4]
```

## myReduce

```javascript
Array.prototype.myReduce = function (callback, ...rest) {
  if (typeof callback !== "function") throw new TypeError(`${callback} is not a function`);

  let i = 0;
  let acc;

  if (rest.length > 0) {
    acc = rest[0];                                     // начальное значение передано (даже undefined)
  } else {
    while (i < this.length && !(i in this)) i++;       // найти первый существующий элемент
    if (i >= this.length) throw new TypeError("Reduce of empty array with no initial value");
    acc = this[i++];
  }

  for (; i < this.length; i++) {
    if (i in this) acc = callback(acc, this[i], i, this);
  }
  return acc;
};

[1, 2, 3].myReduce((sum, x) => sum + x);         // 6
[1, 2, 3].myReduce((sum, x) => sum + x, 10);     // 16
[].myReduce((s, x) => s + x, 0);                 // 0
[].myReduce((s, x) => s + x);                    // TypeError
```

`...rest` позволяет отличить «начальное значение не передано» от «передано `undefined`».

## Бонус: map и filter через reduce

```javascript
const mapViaReduce = (arr, fn) => arr.reduce((acc, x, i) => (acc.push(fn(x, i, arr)), acc), []);
const filterViaReduce = (arr, fn) => arr.reduce((acc, x, i) => (fn(x, i, arr) && acc.push(x), acc), []);
```

## Доп. вопросы интервьюера

- **Почему не стрелочная функция в `Array.prototype.myMap`?** нужен `this` — массив, у которого вызван метод.
- **Почему не `forEach` внутри?** можно, но полифил обычно пишут без других методов массива.
- **Что если колбэк меняет массив?** встроенный `map` фиксирует длину в начале — наш цикл по `this.length` тоже берет ее на каждой итерации; для точного поведения сохраните `const len = this.length` до цикла.
- **Нужно ли расширять `Array.prototype` в реальном коде?** нет — это ломает совместимость; в задаче это допустимо.

## Что важно помнить

- Колбэк вызывается с `(element, index, array)` и `thisArg`.
- `i in this` пропускает дырки разреженного массива, как нативные методы.
- `reduce` без начального значения на пустом массиве — `TypeError`.

## Мини-шпаргалка

Функция (не стрелка) в `Array.prototype`, `this` — массив. Проверка колбэка → цикл по индексам → `i in this` для дыр → `callback.call(thisArg, el, i, arr)`. `reduce`: начальное значение через `rest.length`, иначе первый существующий элемент, пустой массив → TypeError.
