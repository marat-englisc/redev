# Задача: делегирование событий

> [!NOTE]
> **Делегирование событий** — один обработчик на общем родителе вместо обработчиков на каждом элементе. Событие всплывает от целевого элемента вверх, и в обработчике по `event.target.closest(selector)` определяют, по какому элементу кликнули. Это экономит память, автоматически работает для **динамически добавленных** элементов и упрощает код списков и таблиц. Задача: написать функцию `delegate(parent, eventType, selector, handler)` и использовать ее для списка задач.

## Вопрос

Реализуйте `delegate(parent, eventType, selector, handler)`, которая вызывает `handler` только для событий на элементах, подходящих под `selector` внутри `parent`. Как работает всплытие и почему нужен `closest`, а не `target.matches`?

## Решение

```javascript
function delegate(parent, eventType, selector, handler, options) {
  function listener(event) {
    const target = event.target.closest(selector);     // клик мог быть по вложенному <span> или <svg>
    if (target && parent.contains(target)) {           // элемент внутри нашего родителя
      handler.call(target, event, target);
    }
  }

  parent.addEventListener(eventType, listener, options);
  return () => parent.removeEventListener(eventType, listener, options);
}
```

## Пример: список задач

```html
<ul id="todos">
  <li data-id="1">
    <span>Купить хлеб</span>
    <button class="toggle" type="button">✓</button>
    <button class="remove" type="button" aria-label="Удалить"><svg>…</svg></button>
  </li>
</ul>
<button id="add" type="button">Добавить</button>
```

```javascript
const list = document.querySelector("#todos");

delegate(list, "click", ".remove", (event, button) => {
  button.closest("li").remove();
});

delegate(list, "click", ".toggle", (event, button) => {
  button.closest("li").classList.toggle("done");
});

document.querySelector("#add").addEventListener("click", () => {
  const li = document.createElement("li");
  li.dataset.id = String(Date.now());
  li.innerHTML = `<span></span><button class="toggle" type="button">✓</button><button class="remove" type="button" aria-label="Удалить">×</button>`;
  li.querySelector("span").textContent = "Новая задача";   // текст — через textContent, не innerHTML
  list.append(li);                                          // обработчики уже работают
});
```

## Почему closest, а не matches

```html
<button class="remove"><svg><path /></svg></button>
```

Клик по иконке делает `event.target` элементом `<path>`. `target.matches(".remove")` вернет `false`, а `target.closest(".remove")` поднимется до кнопки.

## Фазы события

```text
capture: window → document → … → родитель → target
target
bubble:  target → родитель → … → document → window
```

- по умолчанию обработчики работают на фазе всплытия;
- `{ capture: true }` — на фазе погружения;
- `event.stopPropagation()` останавливает распространение — используйте осторожно, это ломает делегирование выше;
- `event.target` — где произошло событие, `event.currentTarget` — где висит обработчик.

## Какие события не всплывают

`focus`, `blur`, `mouseenter`, `mouseleave`, `load`, `scroll` (на элементах) не всплывают. Для делегирования используют всплывающие аналоги: `focusin`/`focusout`, `mouseover`/`mouseout`, или capture-фазу.

```javascript
delegate(form, "focusin", "input", (e, input) => input.closest(".field").classList.add("focused"));
```

## Доп. вопросы интервьюера

- **Плюсы?** один обработчик, работа с динамическими элементами, меньше памяти.
- **Минусы?** обработчик срабатывает на каждый клик в контейнере; сложнее логика для вложенных интерактивных элементов.
- **Как это делает React?** React вешает обработчики на корень приложения и сам эмулирует всплытие (синтетические события) — это и есть делегирование.

## Что важно помнить

- Используйте `closest` + `contains`, чтобы не поймать элемент выше контейнера.
- Возвращайте функцию отписки.
- Для текста пользователя — `textContent`, а не `innerHTML` (защита от XSS).
- Теория: [события в DOM](<../../04. JavaScript/06. DOM и браузер/09. Что такое событие в DOM.md>), [делегирование событий](<../../04. JavaScript/06. DOM и браузер/13. Делегирование событий (Event Delegation).md>).

## Мини-шпаргалка

Один обработчик на родителе, `event.target.closest(selector)` + `parent.contains(el)`. Работает для новых элементов. Всплытие: target → вверх. Не всплывают: focus, blur, mouseenter — берите focusin, focusout, mouseover. React использует делегирование.
