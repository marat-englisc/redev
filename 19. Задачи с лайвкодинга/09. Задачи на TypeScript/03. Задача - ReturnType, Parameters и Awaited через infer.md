# Задача: ReturnType, Parameters и Awaited через infer

> [!NOTE]
> Ключевое слово **`infer`** внутри условного типа «вытаскивает» часть другого типа в новую переменную: `T extends (...args: infer P) => infer R ? ...`. Через него реализуются встроенные `ReturnType`, `Parameters`, `Awaited`, `InstanceType`, а также задачи вроде «тип первого элемента кортежа», «тип элемента массива», «разбор шаблонной строки». На собеседовании просят написать несколько таких типов и объяснить, как работает `infer`.

## Вопрос

Реализуйте `MyReturnType`, `MyParameters`, `MyAwaited`, `First`, `Last`, `ElementType` и `TupleToUnion` с помощью `infer`.

## Решения

```typescript
type MyReturnType<T extends (...args: any) => any> = T extends (...args: any) => infer R ? R : never;

type MyParameters<T extends (...args: any) => any> = T extends (...args: infer P) => any ? P : never;

type MyAwaited<T> =
  T extends null | undefined ? T :
  T extends PromiseLike<infer V> ? MyAwaited<V> :      // рекурсивно для Promise<Promise<T>>
  T;

type First<T extends readonly unknown[]> = T extends readonly [infer F, ...unknown[]] ? F : never;

type Last<T extends readonly unknown[]> = T extends readonly [...unknown[], infer L] ? L : never;

type ElementType<T> = T extends readonly (infer E)[] ? E : never;

type TupleToUnion<T extends readonly unknown[]> = T[number];

type MyInstanceType<T extends abstract new (...args: any) => any> =
  T extends abstract new (...args: any) => infer I ? I : never;
```

## Проверка

```typescript
function createUser(name: string, age: number) {
  return { id: crypto.randomUUID(), name, age };
}

type R = MyReturnType<typeof createUser>;     // { id: string (шаблонный тип UUID); name: string; age: number }
type P = MyParameters<typeof createUser>;     // [name: string, age: number]

type A1 = MyAwaited<Promise<Promise<number>>>; // number
type F = First<[1, "a", true]>;               // 1
type L = Last<[1, "a", true]>;                // true
type E = ElementType<string[]>;               // string
type U = TupleToUnion<["a", "b", "c"]>;       // "a" | "b" | "c"

class ApiClient { constructor(public baseUrl: string) {} }
type I = MyInstanceType<typeof ApiClient>;    // ApiClient
```

`typeof createUser` превращает значение-функцию в ее тип.

## Практическое применение

```typescript
// тип ответа async-функции без ручного описания
async function fetchProfile(id: string) {
  const res = await fetch(`/api/profile/${id}`);
  return (await res.json()) as { name: string; avatar: string };
}
type Profile = Awaited<ReturnType<typeof fetchProfile>>;   // { name: string; avatar: string }

// тип props компонента из сторонней библиотеки
import type { ComponentProps } from "react";
type ButtonProps = ComponentProps<typeof Button>;

// значения константы как union
const ROLES = ["admin", "editor", "viewer"] as const;
type Role = (typeof ROLES)[number];                        // "admin" | "editor" | "viewer"
```

## infer в шаблонных строках

```typescript
type RouteParams<Path extends string> =
  Path extends `${string}:${infer Param}/${infer Rest}` ? Param | RouteParams<`/${Rest}`> :
  Path extends `${string}:${infer Param}` ? Param :
  never;

type Params = RouteParams<"/users/:userId/posts/:postId">;   // "userId" | "postId"

function buildPath<P extends string>(path: P, params: Record<RouteParams<P>, string>) {
  return path.replace(/:(\w+)/g, (_, key: string) => params[key as RouteParams<P>]);
}

buildPath("/users/:userId/posts/:postId", { userId: "1", postId: "42" });   // ok
// buildPath("/users/:userId", {});   — ошибка: нет userId
```

## Доп. вопросы интервьюера

- **Где можно использовать `infer`?** только в `extends`-части условного типа.
- **Почему `Awaited` рекурсивный?** `await` разворачивает вложенные промисы до конечного значения.
- **Чем `T[number]` отличается от `ElementType<T>`?** результат тот же для массивов и кортежей; индексный доступ проще.
- **Как получить тип ключей объекта-константы?** `keyof typeof obj`.

## Что важно помнить

- `infer X` объявляет переменную типа, которая «подбирается» при сопоставлении.
- `typeof` переводит из мира значений в мир типов.
- `as const` делает литералы узкими и массивы — кортежами `readonly`.
- Теория: [infer](<../../05. TypeScript/08. Дженерики/05. infer и извлечение типов.md>), [conditional types](<../../05. TypeScript/09. Продвинутые типы/02. Conditional types и дистрибутивность.md>), [Utility Types](<../../05. TypeScript/07. Utility типы/01. Что такое Utility Types в TypeScript.md>).

## Мини-шпаргалка

ReturnType `T extends (...a: any) => infer R ? R : never`, Parameters `(...a: infer P)`, Awaited — рекурсивно по `PromiseLike<infer V>`, First `[infer F, ...unknown[]]`, Last `[...unknown[], infer L]`, кортеж → union `T[number]`. Шаблонные строки + infer — разбор путей.
