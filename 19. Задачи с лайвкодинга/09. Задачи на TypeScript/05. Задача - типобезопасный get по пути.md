# Задача: типобезопасный get по пути

> [!NOTE]
> Продвинутая задача на TypeScript: функция `get(obj, "user.address.city")` должна **проверять путь** на этапе компиляции (опечатка — ошибка) и **выводить тип результата**. Решение строится на **шаблонных литеральных типах** и рекурсии: тип `Paths<T>` перечисляет все допустимые пути объекта, а тип `PathValue<T, P>` разбирает строку по точкам через `infer` и спускается по типу. Это демонстрирует понимание рекурсивных условных типов и связи типов со значениями через дженерики.

## Вопрос

Типизируйте функцию `get<T, P>(obj: T, path: P)` так, чтобы путь проверялся на этапе компиляции и тип результата выводился автоматически.

## Решение

```typescript
type Primitive = string | number | boolean | bigint | symbol | null | undefined | Date;

// все пути: "user" | "user.name" | "user.address" | "user.address.city" | ...
type Paths<T> = T extends Primitive | readonly unknown[]
  ? never
  : {
      [K in keyof T & string]: T[K] extends Primitive | readonly unknown[]
        ? K
        : K | `${K}.${Paths<T[K]>}`;
    }[keyof T & string];

// тип значения по пути
type PathValue<T, P extends string> =
  P extends `${infer Head}.${infer Rest}`
    ? Head extends keyof T
      ? PathValue<T[Head], Rest>
      : never
    : P extends keyof T
      ? T[P]
      : never;

function get<T, P extends Paths<T>>(obj: T, path: P): PathValue<T, P> {
  return path.split(".").reduce<unknown>((acc, key) => (acc as Record<string, unknown>)?.[key], obj) as PathValue<T, P>;
}
```

## Проверка

```typescript
const data = {
  user: {
    name: "Анна",
    age: 30,
    address: { city: "Казань", zip: 420000 },
    tags: ["admin"],
  },
  active: true,
};

const city = get(data, "user.address.city");   // string
const zip = get(data, "user.address.zip");     // number
const address = get(data, "user.address");     // { city: string; zip: number }
const tags = get(data, "user.tags");           // string[]

// get(data, "user.adress.city");   — ошибка: такого пути нет (опечатка)
// get(data, "user.age.value");     — ошибка: age — число
```

Редактор подсказывает все допустимые пути в автодополнении.

## Как работает разбор пути

```text
PathValue<Data, "user.address.city">
  "user.address.city" = `${"user"}.${"address.city"}`   → Head = "user", Rest = "address.city"
  → PathValue<Data["user"], "address.city">
  → Head = "address", Rest = "city" → PathValue<Data["user"]["address"], "city">
  → "city" extends keyof ... → string
```

## Применение в реальном коде

- типобезопасные ключи переводов i18n: `t("cart.title")`;
- `react-hook-form`: `register("address.city")` и `watch("address.city")` используют такие же типы (`Path<T>`, `PathValue<T, P>`);
- конфигурация и feature flags по путям;
- `lodash.get` с типами из `@types/lodash`.

## Ограничения

- глубокие и рекурсивные типы (дерево `{ children: Node[] }`) могут вызвать ошибку «Type instantiation is excessively deep» — ограничивают глубину счетчиком-кортежем;
- массивы с индексами (`"items.0.name"`) требуют дополнительной ветки для `number`-ключей;
- сложные типы замедляют проверку в больших проектах.

## Доп. вопросы интервьюера

- **Зачем `keyof T & string`?** ключи могут быть `number | symbol`, а в шаблонной строке нужны строки.
- **Как ограничить глубину?** дополнительный параметр-счетчик `D extends unknown[] = []` и остановка при `D["length"] extends 5`.
- **Как поддержать массивы?** ветка `T extends readonly (infer E)[] ? \`${number}\` | \`${number}.${Paths<E>}\``.

## Что важно помнить

- Шаблонные литеральные типы + `infer` позволяют разбирать строки на уровне типов.
- Дженерик `P extends Paths<T>` связывает путь с объектом и включает автодополнение.
- В рантайме это обычный `reduce` — типы исчезают после компиляции.
- Рантайм-версия задачи: [get и set по пути](<../03. Массивы и объекты/05. Задача - get и set по пути.md>).

## Мини-шпаргалка

`Paths<T>`: для каждого строкового ключа — `K` или `` `${K}.${Paths<T[K]>}` `` для объектов. `PathValue<T, P>`: `` P extends `${infer H}.${infer R}` `` → рекурсия по `T[H]`, иначе `T[P]`. Функция `get<T, P extends Paths<T>>(obj, path): PathValue<T, P>`.
