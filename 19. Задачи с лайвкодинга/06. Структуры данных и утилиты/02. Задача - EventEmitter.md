# Задача: EventEmitter

> [!NOTE]
> **EventEmitter** — объект, на события которого можно подписаться (`on`), отписаться (`off`), подписаться один раз (`once`) и которые можно вызвать (`emit`) с аргументами. Это реализация паттерна Observer и одна из самых частых задач лайвкодинга. Важные детали: хранить обработчики в `Map` событие → массив или `Set`, **копировать список перед `emit`** (обработчик может отписаться во время вызова), корректно отписывать `once`-обработчик через `off(event, originalHandler)` и возвращать из `on` функцию отписки.

## Вопрос

Реализуйте класс `EventEmitter` с методами `on`, `off`, `once`, `emit`. `on` должен возвращать функцию отписки, `once`-обработчик — сниматься после первого вызова и через `off` с исходной функцией.

## Решение

```javascript
class EventEmitter {
  #events = new Map();     // event → массив обработчиков (сохраняем порядок и дубликаты)

  on(event, handler) {
    if (!this.#events.has(event)) this.#events.set(event, []);
    this.#events.get(event).push(handler);
    return () => this.off(event, handler);
  }

  off(event, handler) {
    const handlers = this.#events.get(event);
    if (!handlers) return;
    const index = handlers.findIndex((h) => h === handler || h.original === handler);
    if (index !== -1) handlers.splice(index, 1);        // удаляем одну подписку
    if (handlers.length === 0) this.#events.delete(event);
  }

  once(event, handler) {
    const wrapper = (...args) => {
      this.off(event, wrapper);
      handler.apply(this, args);
    };
    wrapper.original = handler;                          // чтобы off(event, handler) работал
    return this.on(event, wrapper);
  }

  emit(event, ...args) {
    const handlers = this.#events.get(event);
    if (!handlers) return false;
    for (const handler of [...handlers]) {               // копия: список может измениться во время emit
      handler.apply(this, args);
    }
    return true;
  }

  listenerCount(event) {
    return this.#events.get(event)?.length ?? 0;
  }
}
```

## Проверка

```javascript
const emitter = new EventEmitter();

const unsubscribe = emitter.on("message", (text, from) => console.log(`${from}: ${text}`));
emitter.once("message", () => console.log("первое сообщение!"));

emitter.emit("message", "Привет", "Анна");
// Анна: Привет
// первое сообщение!
emitter.emit("message", "Как дела?", "Анна");
// Анна: Как дела?

unsubscribe();
emitter.emit("message", "Есть кто?", "Анна");   // ничего, вернет false

const handler = () => console.log("никогда");
emitter.once("x", handler);
emitter.off("x", handler);                       // снимает once-обработчик по исходной функции
emitter.emit("x");                               // ничего
```

## Расширения, которые просят

- **Обработка ошибок:** если обработчик бросил, остальные должны выполниться — `try/catch` вокруг вызова и событие `"error"`.
- **Подписка на все события:** `on("*", handler)` — вызывать с именем события.
- **Асинхронный emit:** `emitAsync` с `await Promise.all(handlers.map(...))`.
- **Типизация в TypeScript:** карта событий `{ message: [text: string, from: string] }` — см. задачу о типизированном EventEmitter.
- **Ограничение утечек:** предупреждение, если обработчиков больше N (как `setMaxListeners` в Node.js).

## Доп. вопросы интервьюера

- **Почему копировать массив перед `emit`?** `once`-обработчик удаляет себя через `splice` во время обхода — без копии следующий обработчик будет пропущен.
- **Массив или `Set`?** `Set` не допускает дубликатов одной функции; массив повторяет поведение Node.js (одна функция может быть подписана дважды).
- **Где применяется?** шина событий, Node.js-стримы и серверы, DOM `EventTarget`, store-менеджеры.

## Что важно помнить

- `on` возвращает функцию отписки — удобно для cleanup в `useEffect`.
- Отписывайтесь, иначе — утечки памяти и лишние вызовы.
- В браузере для пользовательских событий есть встроенные `EventTarget` и `CustomEvent`.
- Теория паттерна: [Observer и Pub/Sub](<../../04. JavaScript/11. Принципы и паттерны проектирования/03. Что такое паттерн Observer и Pub-Sub.md>).

## Мини-шпаргалка

`Map event → handlers[]`. `on` → push + вернуть отписку. `off` → найти `h === fn || h.original === fn` и `splice`. `once` → обертка, которая снимает себя, `wrapper.original = fn`. `emit` → обход **копии** массива с `apply`.
