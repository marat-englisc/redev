# Что такое stdin, stdout и stderr?

> [!NOTE]
> `stdin`, `stdout` и `stderr` - стандартные потоки процесса. Через `stdin` программа получает ввод, через `stdout` выводит обычный результат, а через `stderr` пишет ошибки и диагностические сообщения.

## Вопрос

Что такое stdin, stdout и stderr и как с ними работать в Node.js?

## Три стандартных потока

| Поток | В Node.js | Назначение |
|---|---|---|
| stdin | `process.stdin` | ввод |
| stdout | `process.stdout` | обычный вывод |
| stderr | `process.stderr` | ошибки |

```js
process.stdout.write('Обычный результат\n');
process.stderr.write('Ошибка или лог\n');
```

## Почему stderr отдельно?

В CLI важно отделять результат от диагностических сообщений.

```bash
node cli.js > result.txt 2> errors.txt
```

`stdout` попадет в `result.txt`, а `stderr` - в `errors.txt`.

## stdin как stream

```js
process.stdin.setEncoding('utf8');

process.stdin.on('data', (chunk) => {
  console.log('Ввод:', chunk);
});
```

Так можно читать данные, которые пользователь вводит в терминал или передает pipe-ом.

## Пример pipe

```bash
echo "hello" | node upper.js
```

```js
process.stdin.setEncoding('utf8');

process.stdin.on('data', (chunk) => {
  process.stdout.write(chunk.toUpperCase());
});
```

## Что важно помнить

- stdout — для результата программы, stderr — для логов и ошибок; их можно перенаправлять отдельно.
- `console.log` пишет в stdout, `console.error` — в stderr.
- `process.stdin` — readable stream, его можно читать через `for await`.
- Конвейеры Unix (`cat file | node app.js`) передают данные через stdin.

## Мини-шпаргалка

- `stdin` - входной поток.
- `stdout` - результат программы.
- `stderr` - ошибки и диагностика.
- CLI-программы должны писать данные в stdout, ошибки в stderr.
- Все три потока являются streams.
