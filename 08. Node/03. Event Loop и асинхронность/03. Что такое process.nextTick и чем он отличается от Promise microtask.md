# Что такое process.nextTick и чем он отличается от Promise microtask

> [!NOTE]
> `process.nextTick()` планирует callback в специальную очередь Node.js, которая выполняется очень рано после текущего стека. Promise callbacks попадают в очередь microtasks движка JavaScript.

## Вопрос

Что такое `process.nextTick` и чем он отличается от Promise microtask?

## Главное

```js
process.nextTick(() => {
  console.log("nextTick");
});

Promise.resolve().then(() => {
  console.log("promise");
});

console.log("sync");
```

Обычно сначала выполнится синхронный код, затем `nextTick`, затем promise callback.

## Зачем нужен nextTick

`process.nextTick()` используют для отложенного выполнения callback сразу после текущей операции, но до продолжения event loop.

```js
function createResource(callback) {
  const resource = {};

  process.nextTick(() => {
    callback(null, resource);
  });
}
```

Так API остается асинхронным, даже если результат уже готов.

## Почему опасно злоупотреблять

Если постоянно добавлять новые `nextTick`, можно не дать event loop перейти к I/O.

```js
function loop() {
  process.nextTick(loop);
}

loop();
```

Такой код может заблокировать обработку timers и I/O.

## Promise microtasks

```js
Promise.resolve()
  .then(() => console.log("microtask"));
```

Promise microtasks - стандартный механизм JavaScript, знакомый и браузеру, и Node.js.

## Практический совет

В обычном приложении чаще используют `Promise`, `async/await`, `queueMicrotask` или timers. `process.nextTick` нужен редко и обычно в библиотеках.

## Что важно помнить

- Очередь `nextTick` выполняется раньше очереди Promise microtasks.
- Рекурсивный `nextTick` может «заморить голодом» event loop — I/O не получит управления.
- Для новых задач обычно рекомендуют `queueMicrotask` или `setImmediate`.
- `nextTick` используют в библиотеках, чтобы вызвать callback асинхронно, но до любого I/O.

## Мини-шпаргалка

- `process.nextTick` - специальная очередь Node.js.
- Promise callbacks - microtasks JS-движка.
- `nextTick` выполняется очень рано.
- Злоупотребление `nextTick` может голодать event loop.
- В прикладном коде чаще выбирают `async/await`.
