# Что такое Buffer в Node.js?

> [!NOTE]
> `Buffer` - специальный объект Node.js для работы с бинарными данными. Он нужен, когда данные представлены не как JavaScript-строка, а как последовательность байтов: файл, изображение, сетевой пакет, архив или часть stream.

## Вопрос

Что такое Buffer в Node.js и зачем он нужен?

## Зачем нужен Buffer?

JavaScript-строки удобны для текста, но не для произвольных байтов. Node.js часто работает с низкоуровневыми источниками данных: диском, сетью, криптографией, сжатием. Поэтому ему нужен тип для бинарных данных.

```js
const buffer = Buffer.from('Hello', 'utf8');

console.log(buffer); // <Buffer 48 65 6c 6c 6f>
console.log(buffer.toString('utf8')); // Hello
```

## Buffer и кодировки

Один и тот же набор байтов можно интерпретировать по-разному.

```js
const text = 'Привет';
const buffer = Buffer.from(text, 'utf8');

console.log(buffer.length); // количество байтов, а не символов
console.log(text.length); // количество UTF-16 code units в JS-строке
```

## Где встречается Buffer?

| Ситуация | Пример |
|---|---|
| Чтение файла без кодировки | `await readFile('image.png')` |
| HTTP body | чанки запроса |
| Streams | куски данных |
| Crypto | хэши и ключи |
| TCP/UDP | сетевые пакеты |

## Безопасное создание

```js
Buffer.alloc(10); // заполненный нулями буфер
Buffer.from('data'); // буфер из существующих данных
```

Обычно не стоит использовать `Buffer.allocUnsafe`, если нет точного понимания, зачем это нужно.

## Что важно помнить

- Buffer — последовательность байтов фиксированной длины, подкласс `Uint8Array`.
- Создавайте через `Buffer.from` и `Buffer.alloc`; `allocUnsafe` может содержать старые данные памяти.
- Кодировку указывайте явно: `buf.toString('utf8')`, `'base64'`, `'hex'`.
- Память Buffer находится вне JS heap — учитывайте это при поиске утечек.

## Мини-шпаргалка

- `Buffer` хранит байты.
- `Buffer.from(text, 'utf8')` превращает строку в байты.
- `buffer.toString('utf8')` превращает байты в строку.
- `buffer.length` - размер в байтах.
- Для новых буферов безопаснее `Buffer.alloc`.
