# Когда использовать worker_threads?

> [!NOTE]
> `worker_threads` позволяют запускать JavaScript-код в отдельных потоках внутри одного Node.js-процесса. Их используют для CPU-bound задач, которые иначе заблокировали бы event loop.

## Вопрос

Когда использовать worker_threads и чем они отличаются от child_process и cluster?

## Проблема

Node.js хорошо справляется с I/O: HTTP, файлами, БД, сетью. Но тяжелые вычисления выполняются в JavaScript-потоке и могут блокировать сервер.

```js
function heavyTask() {
  while (true) {
    // имитация бесконечной CPU-задачи
  }
}
```

Пока такая задача работает, Node.js не сможет быстро отвечать на запросы.

## Worker thread

Основной файл:

```js
import { Worker } from 'node:worker_threads';

const worker = new Worker(new URL('./worker.js', import.meta.url));

worker.on('message', (result) => {
  console.log('Результат:', result);
});

worker.postMessage({ from: 1, to: 1000000 });
```

Файл worker:

```js
import { parentPort } from 'node:worker_threads';

parentPort.on('message', ({ from, to }) => {
  let sum = 0;

  for (let i = from; i <= to; i += 1) {
    sum += i;
  }

  parentPort.postMessage(sum);
});
```

## worker_threads vs child_process

| Инструмент | Когда выбирать |
|---|---|
| `worker_threads` | Тяжелые вычисления на JS внутри процесса |
| `child_process` | Запуск отдельной программы или команды |
| `cluster` | Несколько процессов сервера для использования CPU-ядер |

## Что важно помнить

- Workers нужны для CPU-тяжелых задач: парсинг, сжатие, обработка изображений, криптография на JS.
- У каждого worker свой event loop и свой экземпляр V8; память общая только через `SharedArrayBuffer`.
- Данные между потоками копируются (structured clone) или передаются через transferable-объекты.
- Для I/O workers не нужны — асинхронный I/O и так не блокирует поток; для пула используют Piscina.

## Мини-шпаргалка

- Worker нужен для CPU-bound задач.
- I/O-задачи обычно не требуют worker.
- Worker не делает код автоматически быстрее: есть стоимость передачи данных.
- Для больших бинарных данных изучи `Transferable` и `SharedArrayBuffer`.
- Не используй worker для каждого маленького действия.
