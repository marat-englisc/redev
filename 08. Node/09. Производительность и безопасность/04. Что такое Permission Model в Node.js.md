# Что такое Permission Model в Node.js?

> [!NOTE]
> Permission Model - механизм Node.js, который ограничивает доступ процесса к опасным возможностям: файловой системе, child processes, worker threads и другим ресурсам. Он нужен как дополнительный слой защиты, особенно для запуска недоверенного или ограниченного кода.

## Вопрос

Что такое Permission Model в Node.js и от чего она защищает?

## Идея

Обычно Node.js-процесс имеет столько прав, сколько ему дала операционная система. Если код может читать диск, запускать процессы и открывать файлы, уязвимость в приложении может стать очень опасной.

Permission Model позволяет запускать Node.js с ограничениями.

```bash
node --permission app.js
```

После включения модели разрешения нужно выдавать явно.

## Доступ к файлам

```bash
node --permission --allow-fs-read=./public app.js
```

Так процесс сможет читать только разрешенную область.

```bash
node --permission --allow-fs-read=./public --allow-fs-write=./tmp app.js
```

## Другие разрешения

В модели разрешений есть флаги для разных возможностей Node.js, например:

- чтение файлов;
- запись файлов;
- запуск child process;
- создание worker threads;
- использование некоторых native addons.

Точный набор флагов зависит от версии Node.js, поэтому перед production-использованием нужно сверяться с официальной документацией.

## Важно понимать

Permission Model не заменяет:

- валидацию input;
- права ОС;
- контейнеризацию;
- секреты в безопасном хранилище;
- обновление зависимостей.

Это дополнительный слой защиты, а не магический щит от всех уязвимостей.

## Что важно помнить

- Включается флагом `--permission` и ограничивает доступ к файловой системе, дочерним процессам и workers.
- Разрешения выдаются явно: `--allow-fs-read`, `--allow-fs-write`, `--allow-child-process`.
- Это слой защиты в глубину, а не полноценная песочница для недоверенного кода.
- Проверить разрешение из кода можно через `process.permission.has()`.

## Мини-шпаргалка

- Permission Model ограничивает возможности Node.js-процесса.
- Включается флагом `--permission`.
- Доступы выдаются отдельными `--allow-*` флагами.
- Особенно полезна для запуска ограниченного кода.
- Всегда проверяй поддержку и флаги в документации своей версии Node.js.
