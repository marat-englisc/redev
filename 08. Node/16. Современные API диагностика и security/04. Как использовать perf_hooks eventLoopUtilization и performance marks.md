# Как использовать perf_hooks, eventLoopUtilization и performance marks?

> [!NOTE]
> `node:perf_hooks` помогает измерять производительность Node.js: duration операций, event loop utilization, resource timing и custom performance marks. Это полезно для диагностики latency, CPU pressure и деградаций.

## Вопрос

Как использовать perf_hooks, eventLoopUtilization и performance marks?

## Зачем нужны performance marks?

`Date.now()` подходит для грубых измерений, но `performance` API лучше для точных runtime measurements.

```js
import { performance } from 'node:perf_hooks';

performance.mark('db-start');

await loadUsers();

performance.mark('db-end');
performance.measure('db-query', 'db-start', 'db-end');

const [measure] = performance.getEntriesByName('db-query');

console.log(measure.duration);
```

## Как измерять функцию?

```js
import { performance } from 'node:perf_hooks';

async function measure(name, fn) {
  const start = performance.now();

  try {
    return await fn();
  } finally {
    const durationMs = performance.now() - start;
    console.log({ name, durationMs });
  }
}
```

## Что такое event loop utilization?

Event loop utilization показывает, насколько event loop был занят между измерениями.

```js
import { performance } from 'node:perf_hooks';

let previous = performance.eventLoopUtilization();

setInterval(() => {
  const current = performance.eventLoopUtilization(previous);
  previous = performance.eventLoopUtilization();

  console.log({
    utilization: current.utilization,
  });
}, 1000);
```

Если utilization стабильно высок и latency растет, вероятно, процесс перегружен CPU-bound работой или тяжелыми sync операциями.

## Что еще смотреть?

- request latency;
- event loop delay;
- CPU usage;
- heap usage;
- active handles;
- DB pool wait time;
- queue lag;
- GC pauses.

## Когда использовать?

- profiling endpoint;
- custom metrics;
- debug slow route;
- production observability;
- load testing.

## Что важно помнить

- `performance.mark()` и `performance.measure()` измеряют длительность участков кода.
- `performance.eventLoopUtilization()` показывает долю времени, когда event loop был занят.
- `monitorEventLoopDelay()` дает гистограмму задержек event loop.
- Высокая загрузка event loop — сигнал к профилированию и выносу CPU-работы.

## Мини-шпаргалка

- `performance.now()` - точное время.
- `performance.mark()` - точка измерения.
- `performance.measure()` - duration между marks.
- `performance.eventLoopUtilization()` - занятость event loop.
- Метрики нужно отправлять в monitoring, а не только логировать.
