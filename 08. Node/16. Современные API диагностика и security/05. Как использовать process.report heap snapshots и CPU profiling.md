# Как использовать process.report, heap snapshots и CPU profiling?

> [!NOTE]
> Для production-диагностики Node.js важно уметь собрать diagnostic report, heap snapshot и CPU profile. Эти артефакты помогают понять crashes, memory leaks, event loop stalls и CPU-bound bottlenecks.

## Вопрос

Как использовать process.report, heap snapshots и CPU profiling для диагностики?

## Что такое diagnostic report?

Diagnostic report - JSON-снимок состояния процесса:

- версия Node.js;
- platform;
- command line;
- stack traces;
- resource usage;
- handles;
- environment summary;
- native stack.

Создать вручную:

```js
process.report.writeReport();
```

CLI:

```bash
node --report-on-fatalerror app.js
node --report-on-signal app.js
```

## Когда нужен report?

- process crash;
- fatal error;
- worker завис;
- подозрение на leak handles;
- incident после OOM;
- debugging в staging/production.

## Heap snapshot

Heap snapshot помогает найти memory leak.

Способы:

```bash
node --inspect app.js
```

Затем открыть Chrome DevTools и снять snapshot.

Также можно использовать `node:v8`:

```js
import { writeHeapSnapshot } from 'node:v8';

writeHeapSnapshot();
```

Осторожно: heap snapshot может быть большим и на время заморозить процесс.

## CPU profiling

CPU profile показывает, где процесс тратит CPU.

```bash
node --cpu-prof app.js
```

После нагрузки Node.js создаст profile-файл, который можно открыть в DevTools.

## Что искать?

Memory:

- растущие arrays/maps;
- listeners;
- timers;
- closures с большими объектами;
- caches без лимита.

CPU:

- sync JSON processing;
- crypto/compression на event loop;
- regex backtracking;
- большие loops;
- serialization;
- template rendering.

## Что важно помнить

- `process.report` формирует JSON-отчет о процессе: стек, ресурсы, нативные модули.
- Heap snapshot (`--heapsnapshot-signal`, `v8.writeHeapSnapshot()`) помогает искать утечки памяти.
- CPU-профиль (`--cpu-prof`) показывает горячие функции; открывается в Chrome DevTools.
- Снимок кучи приостанавливает процесс и требует памяти — в production делайте его осторожно.

## Мини-шпаргалка

- `process.report.writeReport()` - diagnostic JSON.
- `writeHeapSnapshot()` - heap snapshot.
- `--cpu-prof` - CPU profile.
- Снимать snapshots в production нужно осторожно.
- Артефакты могут содержать sensitive data.
