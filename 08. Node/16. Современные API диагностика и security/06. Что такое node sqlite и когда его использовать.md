# Что такое node:sqlite и когда его использовать?

> [!NOTE]
> `node:sqlite` - встроенный модуль Node.js для работы с SQLite. Он полезен для локальных инструментов, CLI, embedded storage, тестов и маленьких приложений, но не заменяет PostgreSQL для многопользовательского production backend.

## Вопрос

Что такое `node:sqlite` и когда его использовать?

## Зачем SQLite в Node.js?

SQLite хорош, когда нужна база:

- без отдельного сервера;
- в одном файле;
- для CLI;
- для desktop/local tool;
- для тестов;
- для prototyping;
- для embedded cache/state.

## Минимальный пример

```js
import { DatabaseSync } from 'node:sqlite';

const db = new DatabaseSync(':memory:');

db.exec(`
  CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    email TEXT NOT NULL UNIQUE
  )
`);

const insert = db.prepare('INSERT INTO users (email) VALUES (?)');
insert.run('admin@example.com');

const select = db.prepare('SELECT * FROM users WHERE email = ?');
const user = select.get('admin@example.com');

console.log(user);
```

## Что важно понимать?

- SQLite embedded, а не отдельный server;
- запись ограничена моделью SQLite locking;
- для serverless/edge storage поведение зависит от filesystem;
- для больших backend-систем чаще PostgreSQL/MySQL;
- API Node.js может иметь sync и async варианты в зависимости от версии.

## Где использовать?

Хорошие сценарии:

- local-first app;
- migration helper;
- dev tool;
- cache metadata;
- temporary test DB;
- single-user app.

Плохие сценарии:

- high write concurrency;
- много backend-инстансов пишут в один файл;
- нужна SQL-репликация как у PostgreSQL;
- multi-tenant SaaS с серьезными гарантиями.

## Что важно помнить

- `node:sqlite` — встроенный синхронный клиент SQLite, импортируется только с префиксом `node:`.
- Подходит для CLI, тестов, прототипов и локальных данных.
- Синхронные запросы блокируют event loop — для нагруженного сервера это ограничение.
- Используйте подготовленные выражения с параметрами, а не конкатенацию строк.

## Мини-шпаргалка

- `node:sqlite` дает встроенный доступ к SQLite.
- `:memory:` полезен для тестов.
- Prepared statements обязательны для пользовательского input.
- Для production web backend чаще выбирают PostgreSQL.
- SQLite силен как embedded/local database.
