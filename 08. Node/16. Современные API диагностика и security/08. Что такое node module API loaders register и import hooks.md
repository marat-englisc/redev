# Что такое node:module API, loaders, register и import hooks?

> [!NOTE]
> `node:module` дает APIs для работы с модульной системой Node.js: customization hooks, register hooks, source maps, compile cache и низкоуровневые операции загрузки. Это advanced-тема, но она важна для tooling: TypeScript loaders, instrumentation, test runners и bundler-like behavior.

## Вопрос

Что такое `node:module` API, loaders, `register` и import hooks?

## Зачем нужны module hooks?

Module hooks позволяют вмешаться в загрузку модулей:

- изменить resolution;
- загрузить нестандартный формат;
- инструментировать код;
- подключить TypeScript/coverage tooling;
- управлять source maps;
- сделать observability-интеграцию.

В обычном backend-коде это почти не нужно. В tooling - очень нужно.

## Что такое `module.register()`?

Идея: зарегистрировать hooks, которые будут участвовать в loading pipeline.

```js
import { register } from 'node:module';

register('./hooks.mjs', import.meta.url);
```

Дальше `hooks.mjs` может экспортировать hooks для загрузки.

## Какие hooks бывают?

Типично встречаются:

- `resolve` - как specifier превращается в URL;
- `load` - как URL превращается в source/module format.

Конкретные детали зависят от версии Node.js, поэтому tooling должен внимательно следить за документацией и stability.

## Source maps

Node.js умеет работать с source maps, чтобы stack traces указывали на исходные файлы после трансформаций.

Для backend это важно, если:

- есть TypeScript build;
- есть bundling;
- есть minification;
- ошибки летят в Sentry/monitoring;
- нужно дебажить production stack.

## Когда не использовать hooks?

Не используй module hooks для:

- обычной бизнес-логики;
- динамического выбора service implementation;
- plugin system без реальной нужды в loader pipeline;
- обхода нормального build process.

## Что важно помнить

- Хуки модулей перехватывают разрешение (`resolve`) и загрузку (`load`) модулей.
- Используются для трансформации TypeScript, моков в тестах и инструментирования.
- Регистрируются через `module.register()` или флаг `--import`; есть синхронный вариант `registerHooks`.
- Хуки замедляют загрузку и усложняют отладку — применяйте точечно.

## Мини-шпаргалка

- `node:module` - advanced API модульной системы.
- Hooks полезны для tooling и instrumentation.
- `resolve` отвечает за поиск модуля.
- `load` отвечает за загрузку исходника.
- В прикладном backend-е лучше избегать custom loaders без сильной причины.
