# Как глубже работать с crypto, Web Crypto, hashing, signing и random?

> [!NOTE]
> `node:crypto` и Web Crypto API нужны для hashing, random values, signatures, encryption и key derivation. Ошибки в crypto обычно опасны, поэтому важно знать границы: что можно делать самому, а где нужна проверенная библиотека.

## Вопрос

Как работать с crypto и Web Crypto: хеширование, подпись и случайные значения?

## Random values

Для токенов:

```js
import { randomBytes, randomUUID } from 'node:crypto';

const sessionId = randomBytes(32).toString('base64url');
const requestId = randomUUID();
```

Не используй `Math.random()` для security tokens.

## Hashing

```js
import { createHash } from 'node:crypto';

const hash = createHash('sha256')
  .update('hello')
  .digest('hex');
```

Hash подходит для integrity/fingerprint, но не для паролей.

## Password hashing

Для паролей нужны slow KDF/password hashing algorithms:

- Argon2;
- bcrypt;
- scrypt;
- PBKDF2.

В Node.js есть `scrypt` и `pbkdf2`, но для auth часто берут библиотеку/фреймворк, который уже правильно хранит salt, parameters и migration strategy.

```js
import { scrypt, randomBytes } from 'node:crypto';
import { promisify } from 'node:util';

const scryptAsync = promisify(scrypt);
const salt = randomBytes(16).toString('hex');
const key = await scryptAsync('password', salt, 64);
```

## HMAC

HMAC используют для подписи payload общим secret:

```js
import { createHmac } from 'node:crypto';

const signature = createHmac('sha256', process.env.WEBHOOK_SECRET)
  .update(rawBody)
  .digest('hex');
```

Важно подписывать raw body, а не уже распарсенный JSON.

## Web Crypto

```js
const bytes = new TextEncoder().encode('hello');
const digest = await crypto.subtle.digest('SHA-256', bytes);
```

Web Crypto удобен для cross-runtime кода и стандартного API, но `node:crypto` часто богаче для Node-specific задач.

## Что важно помнить

- Пароли хешируют медленными алгоритмами: `scrypt`, argon2, bcrypt — не SHA-256.
- Для токенов и id используйте `crypto.randomUUID()` и `randomBytes()`, а не `Math.random()`.
- Подписи проверяют с помощью `timingSafeEqual`, чтобы избежать timing-атак.
- `globalThis.crypto.subtle` (Web Crypto) совместим с браузером и edge-runtime.

## Мини-шпаргалка

- Security random: `randomBytes`, `randomUUID`, `crypto.getRandomValues`.
- Hash не подходит для паролей.
- Password hashing требует salt и slow algorithm.
- HMAC - подпись shared secret.
- Не изобретай encryption protocol сам.
