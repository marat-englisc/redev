# Что такое Babel и SWC

> [!NOTE]
> **Транспилятор** переводит код с одного варианта JavaScript на другой: TypeScript и JSX — в обычный JS, современный синтаксис (`?.`, `??`, классовые поля) — в более старый для целевых браузеров. **Babel** — исторический стандарт на JavaScript с огромной экосистемой плагинов. **SWC** — аналог на Rust, в 20–70 раз быстрее; его используют Next.js, Rspack, `@vitejs/plugin-react-swc`, Jest (через `@swc/jest`). Транспилятор меняет **синтаксис**, но не добавляет отсутствующие **API** — для этого нужны полифилы.

## Вопрос

Что такое Babel и SWC и зачем они нужны? Чем транспиляция отличается от полифилов и чем SWC отличается от Babel?

## Что делает транспилятор

```tsx
// до
const name = user?.profile?.name ?? "Гость";
const Greeting = ({ name }: { name: string }) => <h1>Привет, {name}</h1>;
```

```javascript
// после (для старых браузеров, упрощенно)
var _user$profile$name, _user$profile;
var name =
  (_user$profile$name =
    user === null || user === void 0
      ? void 0
      : (_user$profile = user.profile) === null || _user$profile === void 0
        ? void 0
        : _user$profile.name) !== null && _user$profile$name !== void 0
    ? _user$profile$name
    : "Гость";

var Greeting = function (_ref) {
  var name = _ref.name;
  return _jsxs("h1", { children: ["Привет, ", name] });
};
```

Типичные задачи:

- удаление типов TypeScript;
- JSX → вызовы `jsx()` (новый JSX transform, без импорта React в каждом файле);
- понижение синтаксиса под `browserslist`;
- плагины: styled-components, Emotion, React Compiler, удаление `console`, макросы.

## Конфигурация Babel

```json
// babel.config.json
{
  "presets": [
    ["@babel/preset-env", { "useBuiltIns": "usage", "corejs": "3.40" }],
    ["@babel/preset-react", { "runtime": "automatic" }],
    "@babel/preset-typescript"
  ],
  "plugins": ["babel-plugin-react-compiler"]
}
```

- **preset** — набор плагинов (`preset-env` выбирает нужные трансформации по целевым браузерам);
- **plugin** — одна трансформация;
- **AST**: Babel парсит код в дерево, плагины меняют дерево, затем код генерируется обратно.

## SWC

```json
// .swcrc
{
  "jsc": {
    "parser": { "syntax": "typescript", "tsx": true },
    "transform": { "react": { "runtime": "automatic" } },
    "target": "es2020"
  }
}
```

Где SWC уже внутри: Next.js (компилятор и минификатор), Rspack (`builtin:swc-loader`), Vite (`@vitejs/plugin-react-swc`), Deno, Parcel.

## Babel и SWC

| | Babel | SWC |
| --- | --- | --- |
| Язык | JavaScript | Rust |
| Скорость | базовая | в десятки раз быстрее |
| Плагины | огромная экосистема | меньше, плагины на Rust/WASM |
| Где используется | старые проекты, Jest (`babel-jest`), особые плагины | Next.js, Rspack, новые проекты |

Также есть **esbuild** (Go) и **oxc** (Rust) — Vite использует их для трансформации TS и JSX.

## Транспиляция и полифилы

| | Транспиляция | Полифил |
| --- | --- | --- |
| Что решает | новый **синтаксис** (`?.`, `class #private`, `async`) | отсутствующие **API** (`Array.prototype.at`, `Promise.withResolvers`, `structuredClone`) |
| Как | переписывает код при сборке | добавляет реализацию в рантайме |
| Инструмент | Babel, SWC, esbuild | core-js, отдельные полифилы |

## Что важно помнить

- Транспилятор не проверяет типы TypeScript — только удаляет их; проверка — `tsc --noEmit`.
- Чем современнее целевые браузеры, тем меньше трансформаций и меньше бандл.
- Babel-плагины (например, для styled-components или React Compiler) иногда держат проект на Babel; для React Compiler есть и SWC-вариант.
- Транспиляция `node_modules` обычно отключена для скорости — если библиотека поставляет новый синтаксис, а нужны старые браузеры, ее включают явно.
- Связанные темы: [полифилы и browserslist](<02. Что такое полифилы, core-js и browserslist.md>), [TypeScript в сборке](<03. Как TypeScript работает в сборке.md>).

## Мини-шпаргалка

Транспилятор: TS/JSX → JS, новый синтаксис → старый под browserslist. Babel — JS, плагины и presets (`preset-env`, `preset-react`, `preset-typescript`). SWC — Rust, быстрый, в Next.js и Rspack. Синтаксис — транспиляция, API — полифилы (core-js). Типы не проверяет.
