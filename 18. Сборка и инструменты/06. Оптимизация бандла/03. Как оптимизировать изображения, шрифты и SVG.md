# Как оптимизировать изображения, шрифты и SVG

> [!NOTE]
> Изображения и шрифты обычно весят больше, чем JavaScript, и определяют LCP и CLS. Основные приемы: **современные форматы** (AVIF, WebP), **адаптивные размеры** (`srcset` + `sizes`), **ленивая загрузка** невидимых картинок и **приоритет** для главной, **явные размеры** против сдвигов, **CDN с ресайзом** вместо одной огромной картинки; для шрифтов — `woff2`, **subset**, `font-display` и preload; для SVG — оптимизация SVGO и выбор между инлайном, спрайтом и файлом.

## Вопрос

Как оптимизировать изображения, шрифты и SVG во фронтенд-проекте? Как они влияют на LCP и CLS и что можно автоматизировать на этапе сборки?

## Изображения

```html
<img
  src="/img/hero-800.avif"
  srcset="/img/hero-400.avif 400w, /img/hero-800.avif 800w, /img/hero-1600.avif 1600w"
  sizes="(max-width: 768px) 100vw, 50vw"
  width="1600"
  height="900"
  alt="Команда на конференции"
  fetchpriority="high"
  decoding="async"
/>

<img src="/img/avatar.webp" width="64" height="64" alt="" loading="lazy" />
```

| Прием | Что дает |
| --- | --- |
| AVIF / WebP | в 2–3 раза меньше JPEG/PNG при том же качестве |
| `srcset` + `sizes` | браузер выбирает размер под экран и плотность пикселей |
| `width` / `height` или `aspect-ratio` | резерв места → нет CLS |
| `loading="lazy"` | невидимые картинки не грузятся сразу |
| `fetchpriority="high"` для LCP-картинки | главная картинка загружается раньше (не делайте ее lazy) |
| `<picture>` | разные форматы и кадрирование |
| CDN-ресайз (imgproxy, Cloudinary, Next.js Image) | нужный размер и формат на лету |

Next.js `<Image>` делает большую часть автоматически: форматы, `srcset`, ленивую загрузку, размеры.

## Сборка

- `vite-imagetools` — генерация размеров и форматов при импорте: `import hero from "./hero.jpg?w=400;800&format=avif;webp&as=picture"`;
- `vite-plugin-image-optimizer`, `image-minimizer-webpack-plugin` — сжатие при сборке;
- маленькие файлы (обычно до 4 КБ) Vite инлайнит в base64 (`build.assetsInlineLimit`).

## Шрифты

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter-cyrillic-var.woff2") format("woff2");
  font-weight: 100 900;                 /* вариативный шрифт: один файл на все начертания */
  font-display: swap;                   /* показать текст системным шрифтом сразу */
  unicode-range: U+0400-04FF;           /* загружать только для кириллицы */
}
```

```html
<link rel="preload" href="/fonts/inter-cyrillic-var.woff2" as="font" type="font/woff2" crossorigin />
```

- только `woff2`, subset под нужные языки, вариативный шрифт вместо 6 файлов;
- self-hosting вместо стороннего домена (нет лишнего DNS и TLS-соединения);
- `size-adjust` и метрики fallback-шрифта уменьшают сдвиг при подмене;
- Next.js `next/font` делает это автоматически.

## SVG

| Способ | Плюсы | Минусы |
| --- | --- | --- |
| `<img src="icon.svg">` | кешируется, не раздувает JS | нельзя менять цвет через CSS |
| Инлайн / React-компонент (svgr) | `currentColor`, анимации | попадает в JS-бандл, не кешируется отдельно |
| Спрайт `<use href="/sprite.svg#cart">` | один запрос, `currentColor` | нужна сборка спрайта |

Все SVG прогоняют через **SVGO** (удаление метаданных, лишних атрибутов). Для сотен иконок спрайт или `<img>` лучше, чем сотни React-компонентов в бандле.

## Что важно помнить

- LCP-изображение не делайте `lazy`; добавьте `fetchpriority="high"` или preload.
- Всегда задавайте размеры изображений и встраиваемых блоков (видео, iframe, баннеров) — это основная причина CLS.
- Декоративные картинки — `alt=""`, содержательные — понятный `alt`.
- Шрифты — частая скрытая причина медленного LCP и CLS: preload одного основного файла, `font-display: swap`.
- Связанные темы: [aspect-ratio и object-fit](<../../03. CSS/10. Современные возможности/06. Что делают aspect-ratio и object-fit.md>), [производительность в system design](<../../17. Frontend System Design/03. Нефункциональные требования/01. Как обеспечить производительность.md>).

## Мини-шпаргалка

Изображения: AVIF/WebP, `srcset` + `sizes`, `width`/`height`, `loading="lazy"` кроме LCP, `fetchpriority="high"`, CDN-ресайз, Next Image. Шрифты: `woff2`, subset, вариативные, `font-display: swap`, preload, self-host, `next/font`. SVG: SVGO, `<img>`/спрайт для множества иконок, svgr для управляемых.
