# Generic-типы через type и interface, тип по умолчанию и вложенные дженерики

> [!NOTE]
> Дженериками бывают не только функции, но и типы: `type ApiResponse<T> = { data: T; error: string | null }`, `interface Repository<T> { ... }`. Параметру можно задать **тип по умолчанию**: `<T = unknown>` — тогда его можно не указывать. Дженерики можно вкладывать друг в друга (`Promise<ApiResponse<User[]>>`) и передавать один дженерик в другой.

## Вопрос

Как объявить generic-тип через `type`? Как задать тип по умолчанию в дженерике? Что такое вложенные дженерики?

## Generic type и interface

```typescript
type ApiResponse<T> = {
  data: T;
  error: string | null;
  status: number;
};

type Paginated<T> = {
  items: T[];
  page: number;
  total: number;
};

interface Repository<T, TId = string> {
  findById(id: TId): Promise<T | null>;
  findAll(): Promise<T[]>;
  save(entity: T): Promise<void>;
}

const response: ApiResponse<User> = { data: anna, error: null, status: 200 };
```

## Тип по умолчанию

```typescript
type Result<T = void, E = Error> =
  | { ok: true; value: T }
  | { ok: false; error: E };

const done: Result = { ok: true, value: undefined };        // T = void, E = Error
const parsed: Result<number> = { ok: true, value: 42 };     // E = Error
const failed: Result<number, string> = { ok: false, error: "Ошибка" };

function createStore<TState = Record<string, unknown>>(initial?: TState) {}
```

Правила:

- параметры с дефолтом идут после обязательных;
- дефолт должен удовлетворять ограничению: `<T extends object = {}>`;
- при вызове функции дефолт используется, только если `T` нельзя вывести из аргументов.

## Вложенные дженерики

```typescript
type UsersResponse = Promise<ApiResponse<Paginated<User>>>;

async function loadUsers(): UsersResponse {
  const res = await fetch("/api/users");
  return res.json();
}

type Cache<T> = Map<string, { value: T; expiresAt: number }>;
type Handlers<TEvent> = Record<string, Array<(event: TEvent) => void>>;
```

Вложенность читается изнутри наружу: `Paginated<User>` — страница пользователей, `ApiResponse<...>` — ответ с ней, `Promise<...>` — асинхронный результат.

## Generic-тип для функции

```typescript
type Mapper<T, R> = (item: T, index: number) => R;
type AsyncFn<TArgs extends unknown[], TResult> = (...args: TArgs) => Promise<TResult>;

const toLabel: Mapper<User, string> = (user) => user.name;
```

## Что важно помнить

- `type Box<T> = ...` — дженерик на уровне типа, `type Box = <T>(x: T) => T` — тип generic-функции; это разные вещи.
- Глубокая вложенность дженериков затрудняет чтение — вводите промежуточные псевдонимы с понятными именами.
- Дефолты удобны в библиотеках: пользователь указывает только важные параметры.
- Generic-интерфейсы поддерживают declaration merging, generic type alias — нет.

## Мини-шпаргалка

- `type Name<T> = ...`, `interface Name<T> { ... }`.
- Дефолт: `<T = unknown>`, после обязательных параметров.
- Вложенность: `Promise<ApiResponse<User[]>>`.
- Тип функции: `type Fn<T, R> = (x: T) => R`.
- Давайте промежуточным типам имена.
