# Рекурсивные типы и рекурсивные дженерики

> [!NOTE]
> **Рекурсивный тип** ссылается сам на себя: так описывают деревья, вложенные меню, комментарии с ответами и JSON. **Рекурсивный дженерик** обрабатывает вложенную структуру на уровне типов: `DeepPartial<T>`, `DeepReadonly<T>`, разворачивание вложенных промисов. У рекурсии в типах есть лимит глубины, поэтому слишком сложные рекурсивные типы замедляют компилятор.

## Вопрос

Что такое рекурсивный тип? Что такое рекурсивный generic-тип и где он применяется?

## Рекурсивные структуры данных

```typescript
type TreeNode = {
  id: string;
  label: string;
  children: TreeNode[];
};

interface Comment {
  id: number;
  text: string;
  replies?: Comment[];
}

type Json =
  | string
  | number
  | boolean
  | null
  | Json[]
  | { [key: string]: Json };

const config: Json = { theme: "dark", features: ["a", "b"], limits: { max: 10 } };
```

## Рекурсивные дженерики

```typescript
type Tree<T> = {
  value: T;
  children: Tree<T>[];
};

const categories: Tree<string> = {
  value: "Каталог",
  children: [{ value: "Ноутбуки", children: [] }],
};
```

## Рекурсивные utility-типы

```typescript
type DeepPartial<T> = T extends object
  ? { [K in keyof T]?: DeepPartial<T[K]> }
  : T;

type DeepReadonly<T> = T extends (infer U)[]
  ? ReadonlyArray<DeepReadonly<U>>
  : T extends object
    ? { readonly [K in keyof T]: DeepReadonly<T[K]> }
    : T;

type Settings = { ui: { theme: string; font: { size: number } } };
const patch: DeepPartial<Settings> = { ui: { font: { size: 16 } } }; // OK
```

Пути к вложенным полям (как в формах `react-hook-form`):

```typescript
type Path<T> = T extends object
  ? { [K in keyof T & string]: T[K] extends object ? K | `${K}.${Path<T[K]>}` : K }[keyof T & string]
  : never;

type SettingsPath = Path<Settings>; // "ui" | "ui.theme" | "ui.font" | "ui.font.size"
```

Рекурсивное разворачивание:

```typescript
type Flatten<T> = T extends (infer U)[] ? Flatten<U> : T;
type F = Flatten<number[][][]>; // number

type MyAwaited<T> = T extends Promise<infer V> ? MyAwaited<V> : T;
```

## Функции с рекурсивными типами

```typescript
function countNodes<T>(node: Tree<T>): number {
  return 1 + node.children.reduce((sum, child) => sum + countNodes(child), 0);
}
```

## Ограничения

- глубина рекурсии ограничена (около 50 уровней для обычных условных типов, ~1000 для хвостовой рекурсии); при превышении — ошибка «Type instantiation is excessively deep and possibly infinite»;
- сложные рекурсивные типы заметно замедляют проверку и автодополнение;
- функции, `Date`, `Map` в `DeepPartial` нужно обрабатывать отдельно, иначе их методы станут опциональными.

## Что важно помнить

- Рекурсивные type alias для объектов работают без ограничений; для union с массивами TS 3.7+ тоже поддерживает прямую рекурсию.
- В React рекурсивный тип комментариев или меню хорошо сочетается с рекурсивным компонентом.
- Готовые рекурсивные утилиты есть в `type-fest`: `PartialDeep`, `ReadonlyDeep`, `Paths`.
- Если тип слишком сложен для чтения, возможно, проще описать структуру явно.

## Мини-шпаргалка

- Рекурсивный тип ссылается на себя: деревья, комментарии, JSON.
- Рекурсивный дженерик обрабатывает вложенность: `DeepPartial`, `Flatten`, `Awaited`.
- Есть лимит глубины и цена для компилятора.
- Обрабатывайте массивы, функции и встроенные объекты отдельно.
