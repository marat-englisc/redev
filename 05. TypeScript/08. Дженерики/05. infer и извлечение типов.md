# infer в TypeScript: как извлекать типы, включая аргументы функции

> [!NOTE]
> `infer` объявляет переменную типа **внутри условия** условного типа: «если `T` подходит под этот шаблон, запомни такую-то его часть как `R`». Так извлекают тип результата функции, ее аргументов, элемента массива, значения промиса. На `infer` построены встроенные `ReturnType`, `Parameters`, `Awaited`, `InstanceType`.

## Вопрос

Что означает `infer` в TypeScript? Как с его помощью достать тип аргументов функции и другие вложенные типы?

## Синтаксис

```typescript
type ElementType<T> = T extends (infer U)[] ? U : never;

type A = ElementType<string[]>;           // string
type B = ElementType<Array<User>>;        // User
type C = ElementType<number>;             // never — не массив
```

`infer U` можно использовать только в части `extends` условного типа.

## Аргументы и результат функции

```typescript
type Args<T> = T extends (...args: infer P) => any ? P : never;
type Return<T> = T extends (...args: any[]) => infer R ? R : never;
type FirstArg<T> = T extends (first: infer F, ...rest: any[]) => any ? F : never;

function createOrder(userId: string, items: string[], promo?: string) {
  return { id: 1, userId, items };
}

type OrderArgs = Args<typeof createOrder>;      // [userId: string, items: string[], promo?: string]
type OrderResult = Return<typeof createOrder>;  // { id: number; userId: string; items: string[] }
type UserIdType = FirstArg<typeof createOrder>; // string
```

Встроенные аналоги: `Parameters<F>` и `ReturnType<F>`.

## Промисы

```typescript
type Unwrap<T> = T extends Promise<infer V> ? V : T;

type U1 = Unwrap<Promise<User>>;  // User
type U2 = Unwrap<number>;         // number

type DeepUnwrap<T> = T extends Promise<infer V> ? DeepUnwrap<V> : T; // рекурсивно, как Awaited
```

## Строки и кортежи

```typescript
type GetterName<T> = T extends `get${infer Name}` ? Name : never;
type N = GetterName<"getUser">; // "User"

type First<T extends unknown[]> = T extends [infer F, ...unknown[]] ? F : never;
type Last<T extends unknown[]> = T extends [...unknown[], infer L] ? L : never;

type F = First<[1, 2, 3]>; // 1
type L = Last<[1, 2, 3]>;  // 3

type RouteParams<T> = T extends `${string}:${infer Param}/${infer Rest}`
  ? Param | RouteParams<`/${Rest}`>
  : T extends `${string}:${infer Param}`
    ? Param
    : never;

type P = RouteParams<"/users/:userId/posts/:postId">; // "userId" | "postId"
```

## Ограничение infer

```typescript
type NumericId<T> = T extends { id: infer I extends number } ? I : never;

type X = NumericId<{ id: 42 }>;    // 42
type Y = NumericId<{ id: "a" }>;   // never
```

Синтаксис `infer X extends C` (TS 4.7+) сразу проверяет найденный тип.

## Что важно помнить

- `infer` работает только внутри условного типа и только в части `extends`.
- Для перегруженных функций `infer` берет последнюю сигнатуру.
- Если в шаблоне несколько `infer` с одним именем в контравариантной позиции, результат будет пересечением, в ковариантной — union.
- `infer` — инструмент для библиотек и utility-типов; в прикладном коде обычно хватает встроенных `ReturnType`, `Parameters`, `Awaited`.

## Мини-шпаргалка

- `T extends Pattern<infer X> ? X : never` — извлечь часть типа.
- Аргументы: `(...args: infer P) => any`.
- Результат: `(...args: any) => infer R`.
- Промис: `Promise<infer V>`, строки: `` `get${infer N}` ``.
- `infer X extends C` — с проверкой.
