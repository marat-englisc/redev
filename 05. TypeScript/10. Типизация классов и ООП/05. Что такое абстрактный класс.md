# Что такое абстрактный класс?

> [!NOTE]
> Абстрактный класс нельзя создать напрямую. Он задает общую базу для наследников и может содержать как готовые методы, так и абстрактные методы без реализации.

## Вопрос

Что такое абстрактный класс?

## Базовый пример

```typescript
abstract class Animal {
  constructor(public name: string) {}

  abstract speak(): string;

  move(): string {
    return `${this.name} moves`;
  }
}

class Dog extends Animal {
  speak(): string {
    return "woof";
  }
}

// new Animal("x"); // ошибка
new Dog("Rex");
```

## Абстрактный метод

Абстрактный метод описывает контракт: наследник обязан реализовать его.

```typescript
abstract class Repository<T> {
  abstract findById(id: string): Promise<T>;
}
```

## Чем отличается от interface

Интерфейс описывает форму. Абстрактный класс может еще и хранить состояние, конструктор, protected-методы и готовую реализацию.

```typescript
abstract class ApiService {
  constructor(protected baseUrl: string) {}

  protected buildUrl(path: string): string {
    return `${this.baseUrl}${path}`;
  }
}
```

## Что важно помнить

- Абстрактный класс нельзя создать через `new`, он задает общую реализацию и абстрактные методы для наследников.
- `abstract` — конструкция TypeScript, в JavaScript остается обычный класс.
- Отличие от интерфейса: абстрактный класс содержит реализацию и существует в runtime.
- Тип конструктора абстрактного класса — `abstract new (...args) => T`.

## Мини-шпаргалка

- `abstract class` нельзя создать через `new`.
- Наследники обязаны реализовать `abstract`-методы.
- Может содержать готовую общую логику.
- Подходит для базовых классов с общей реализацией.
