# Примитивные типы: string, number, boolean, bigint, symbol, null, undefined

> [!NOTE]
> Примитивные типы TypeScript соответствуют примитивам JavaScript: `string`, `number`, `boolean`, `bigint`, `symbol`, `null` и `undefined`. Типы пишутся **с маленькой буквы** — `String`, `Number`, `Boolean` с большой обозначают объекты-обертки и почти никогда не нужны. Для каждого примитива есть литеральные подтипы (`"admin"`, `42`, `true`) и `unique symbol`.

## Вопрос

Какие примитивные типы есть в TypeScript? Что такое типы `string`, `number`, `boolean`, `bigint` и `symbol`?

## Обзор

```typescript
const name: string = "Анна";
const age: number = 25;
const isAdmin: boolean = false;
const big: bigint = 9007199254740993n;
const id: symbol = Symbol("id");
const nothing: null = null;
const notSet: undefined = undefined;
```

На практике аннотации для таких констант не нужны — TypeScript выводит тип сам: `const age = 25` получит литеральный тип `25`, а `let age = 25` — тип `number`.

## string

```typescript
let title: string = "Чайник";
title = `Товар: ${title}`; // шаблонные строки тоже string
```

Литеральные строковые типы ограничивают допустимые значения: `type Status = "idle" | "loading" | "done"`. Template literal types строят строки по шаблону: `` type EventName = `on${string}` ``.

## number

```typescript
let price: number = 1500;
price = 0.1 + 0.2;   // number
price = NaN;         // тоже number
price = Infinity;    // тоже number
```

Целых и дробных типов нет: все числа — `number` (IEEE 754). TypeScript не защищает от `NaN` и потери точности.

## boolean

```typescript
let isOpen: boolean = true;
isOpen = Boolean(value);
```

`boolean` — это union `true | false`. Truthy-значения (`1`, `"yes"`) не совместимы с `boolean` без приведения.

## bigint

```typescript
const huge: bigint = 2n ** 64n;
const mixed = huge + 1; // ошибка: нельзя смешивать bigint и number
```

Требует `target` не ниже ES2020.

## symbol

```typescript
const key: symbol = Symbol("key");
const TOKEN: unique symbol = Symbol("token"); // уникальный тип, только в const

const obj = { [TOKEN]: 42 };
```

`unique symbol` позволяет использовать символ как ключ с точным типом.

## null и undefined

С `strictNullChecks` (часть `strict`) `null` и `undefined` — отдельные типы и не входят в другие:

```typescript
let email: string = null;           // ошибка
let maybeEmail: string | null = null; // явно разрешили
```

## Типы с большой буквы

```typescript
let a: String = "text";    // объектный тип-обертка — не используйте
let b: string = "text";    // правильно
```

`String`, `Number`, `Boolean`, `Symbol`, `Object` с большой буквы описывают объекты, а не примитивы. Линтер `@typescript-eslint/no-wrapper-object-types` запрещает их.

## Что важно помнить

- `const` получает литеральный тип, `let` — расширенный (`widening`); `as const` фиксирует литералы в объектах и массивах.
- TypeScript не отличает целые числа от дробных и не проверяет диапазоны.
- `typeof x === "string"` в условии сужает тип до `string`.
- Для денег и точных вычислений нужен не `number`, а целые копейки или библиотека decimal.

## Мини-шпаргалка

- Примитивы: `string`, `number`, `boolean`, `bigint`, `symbol`, `null`, `undefined`.
- Пишутся с маленькой буквы.
- `boolean` = `true | false`.
- `bigint` и `number` не смешиваются.
- `null`/`undefined` отдельно при `strictNullChecks`.
