# Одинаковое имя интерфейсов

> [!NOTE]
> Если объявить несколько интерфейсов с одним именем, TypeScript объединит их свойства.

## Вопрос

Что будет, если два интерфейса имеют одинаковое имя?

## Определение

В TypeScript интерфейсы поддерживают declaration merging. Это значит, что несколько объявлений одного интерфейса в одной области видимости объединяются в один контракт.

## Пример

```typescript
interface User {
  id: number;
}

interface User {
  name: string;
}

const user: User = {
  id: 1,
  name: 'Ann',
};
```

Итоговый `User` требует оба поля: `id` и `name`.

## Конфликт типов

```typescript
interface User {
  id: number;
}

interface User {
  id: string; // ошибка
}
```

Одинаковые свойства должны иметь совместимые типы.

## Отличие от type

```typescript
type User = {
  id: number;
};

type User = {
  name: string;
}; // ошибка: duplicate identifier
```

`type` нельзя повторно объявить с тем же именем.

## Где это полезно

- расширение типов библиотек;
- declaration files;
- добавление свойств к глобальным интерфейсам;
- интеграция с существующими API.

## Что важно помнить

- Одноименные интерфейсы в одной области видимости объединяются (declaration merging).
- Так расширяют глобальные типы (`Window`) и типы библиотек через module augmentation.
- Поля с одинаковым именем должны иметь одинаковый тип, иначе ошибка.
- Type alias с повторным именем объединять нельзя — будет ошибка «Duplicate identifier».

## Мини-шпаргалка

```typescript
interface A { x: number }
interface A { y: number }
// A = { x: number; y: number }
```
