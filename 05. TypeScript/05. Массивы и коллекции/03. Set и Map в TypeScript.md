# Set и Map в TypeScript

> [!NOTE]
> `Set<T>` — типизированная коллекция уникальных значений типа `T`, `Map<K, V>` — словарь с ключами типа `K` и значениями типа `V`. Типы можно указать явно (`new Map<string, User>()`) или они выводятся из начальных данных. `map.get(key)` всегда возвращает `V | undefined`, поэтому результат нужно проверять. Есть readonly-версии: `ReadonlySet<T>` и `ReadonlyMap<K, V>`.

## Вопрос

Как типизировать `Set` и `Map` в TypeScript? Чем `Map` лучше `Record` для словарей?

## Set

```typescript
const tags = new Set<string>();
tags.add("js");
tags.add(42);            // ошибка: number не string

const ids = new Set([1, 2, 3]);   // Set<number> — выведено

const unique: string[] = [...new Set(["a", "a", "b"])];

function hasRole(roles: ReadonlySet<string>, role: string) {
  return roles.has(role);
}
```

Пустой `new Set()` без параметра типа получит тип `Set<unknown>` — указывайте тип явно.

## Map

```typescript
type User = { id: string; name: string };

const users = new Map<string, User>();
users.set("u1", { id: "u1", name: "Анна" });

const anna = users.get("u1");     // User | undefined
anna.name;                        // ошибка: 'anna' is possibly 'undefined'
anna?.name;                       // OK

if (users.has("u1")) {
  users.get("u1")!.name;          // has не сужает тип get — нужен ! или повторная проверка
}

const cached = users.get("u2") ?? (await fetchUser("u2"));
```

## Ключи-объекты

```typescript
const visits = new Map<HTMLElement, number>();
visits.set(document.body, 1);

const metadata = new WeakMap<object, { seen: Date }>();
```

## Map или Record

| | `Map<K, V>` | `Record<K, V>` |
| --- | --- | --- |
| Тип ключей | любой | `string`, `number`, `symbol` |
| `get` возвращает `V \| undefined` | да | только с `noUncheckedIndexedAccess` |
| Частые добавления и удаления | эффективно | медленнее |
| Порядок | порядок вставки | особые правила для числовых ключей |
| JSON | нужно преобразовать | напрямую |
| Подходит для | кешей, индексов, динамических словарей | конфигураций, известных наборов ключей |

## Преобразования

```typescript
const record: Record<string, number> = { tea: 120 };
const map = new Map(Object.entries(record));      // Map<string, number>
const back = Object.fromEntries(map);             // { [k: string]: number }

const byId = new Map(users.map((u) => [u.id, u] as const));
```

`as const` нужен, чтобы `[u.id, u]` вывелся кортежем, а не массивом `(string | User)[]`.

## Что важно помнить

- `ReadonlyMap` и `ReadonlySet` скрывают методы `set`, `add`, `delete` на уровне типов.
- В React state коллекции нужно заменять новыми: `new Map(prev).set(key, value)`.
- Сериализация в JSON требует преобразования в массив или объект.
- Для перебора используйте `for (const [key, value] of map)` — типы выводятся автоматически.

## Мини-шпаргалка

- `Set<T>`, `Map<K, V>` — указывайте типы или передавайте начальные данные.
- `map.get()` → `V | undefined`.
- `has` не сужает тип результата `get`.
- Для произвольных ключей и частых изменений — `Map`, для известных ключей — `Record`.
- `ReadonlySet`, `ReadonlyMap` — без мутирующих методов.
