# Массивы в TypeScript: string[] и Array<string>, разные типы, readonly и двумерные массивы

> [!NOTE]
> Массив объявляют как `string[]` или `Array<string>` — это одно и то же. Массив с элементами разных типов описывают union-типом в скобках: `(string | number)[]`, а массив фиксированной длины с разными типами по позициям — кортежем `[string, number]`. Неизменяемые массивы — `readonly string[]` или `ReadonlyArray<string>`. Двумерный массив — `number[][]`.

## Вопрос

Как объявить массив в TypeScript? Чем `string[]` отличается от `Array<string>`? Как типизировать массив разных типов, readonly-массив и двумерный массив?

## Объявление

```typescript
const names: string[] = ["Анна", "Иван"];
const scores: Array<number> = [95, 87];

const empty: string[] = [];   // без аннотации пустой массив может получить тип never[] или any[]
const inferred = [1, 2, 3];   // number[] — выведено
```

## string[] и Array<string>

Полностью эквивалентны. Обычно выбирают `T[]` для простых типов и `Array<T>` для сложных:

```typescript
const a: (string | number)[] = [];
const b: Array<string | number> = [];        // читается проще для union

const users: Array<{ id: number; name: string }> = [];
```

Правило `@typescript-eslint/array-type` задает единый стиль в проекте.

## Разные типы в массиве

```typescript
const mixed: (string | number)[] = ["a", 1, "b"];  // любой порядок и длина

const pair: [string, number] = ["Анна", 25];       // кортеж: позиции фиксированы
const [name, age] = pair;                          // name: string, age: number
```

Скобки важны: `string | number[]` — это «строка ИЛИ массив чисел».

## Readonly-массивы

```typescript
const roles: readonly string[] = ["admin", "user"];
const ids: ReadonlyArray<number> = [1, 2];

roles.push("guest");   // ошибка: Property 'push' does not exist on type 'readonly string[]'
roles[0] = "root";     // ошибка
roles.map((r) => r.toUpperCase()); // OK — немутирующие методы доступны

function printAll(items: readonly string[]) {} // принимает и обычные, и readonly массивы
```

`as const` делает массив readonly-кортежем литералов:

```typescript
const sizes = ["s", "m", "l"] as const;  // readonly ["s", "m", "l"]
type Size = (typeof sizes)[number];       // "s" | "m" | "l"
```

## Двумерные массивы

```typescript
const matrix: number[][] = [
  [1, 2, 3],
  [4, 5, 6],
];

const board: Array<Array<"X" | "O" | null>> = Array.from({ length: 3 }, () => Array(3).fill(null));
```

## Доступ по индексу

```typescript
const list: string[] = [];
const first = list[0];          // тип string, но в runtime undefined!
first.toUpperCase();            // упадет

// с noUncheckedIndexedAccess: first — string | undefined
const safe = list.at(0);        // string | undefined
```

## Что важно помнить

- Параметры функций, которые не меняют массив, типизируйте как `readonly T[]` — так функция примет и обычные, и readonly массивы.
- `readonly` массивы — только проверка компилятора; для runtime-защиты — `Object.freeze`.
- `filter(Boolean)` не сужает тип `(T | null)[]` до `T[]` (до TS 5.5) — используйте type guard.
- Кортежи удобны для возвращаемых значений хуков: `[value, setValue]`.

## Мини-шпаргалка

- `T[]` = `Array<T>`.
- Разные типы: `(A | B)[]`, по позициям — кортеж `[A, B]`.
- `readonly T[]` / `ReadonlyArray<T>` — без мутаций.
- `as const` — readonly кортеж литералов.
- Двумерный: `T[][]`.
