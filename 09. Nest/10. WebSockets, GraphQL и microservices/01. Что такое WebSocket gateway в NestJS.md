# Что такое WebSocket gateway в NestJS

> [!NOTE]
> **Gateway** — класс с декоратором `@WebSocketGateway()`, который обрабатывает **двустороннее постоянное соединение** с клиентом: чаты, уведомления в реальном времени, совместное редактирование, live-дашборды, игры. По умолчанию Nest использует **Socket.IO** (`@nestjs/platform-socket.io`) с комнатами, автоматическим переподключением и fallback-транспортами; альтернатива — «чистый» `ws` (`@nestjs/platform-ws`), легче и совместимый с нативным `WebSocket` браузера. Обработчики событий помечаются `@SubscribeMessage('event')`, данные извлекаются `@MessageBody()` и `@ConnectedSocket()`, а сервер — `@WebSocketServer()`. Gateway — обычный провайдер: регистрируется в `providers` модуля, получает зависимости через DI и поддерживает guards, pipes, interceptors и filters (но не HTTP-middleware). Хуки `OnGatewayInit`, `OnGatewayConnection`, `OnGatewayDisconnect` позволяют аутентифицировать подключение и следить за клиентами.

## Вопрос

Что такое WebSocket gateway в NestJS и как его создать?

## Установка

```bash
npm install @nestjs/websockets @nestjs/platform-socket.io socket.io
```

## Gateway

```ts
@WebSocketGateway({
  namespace: '/chat',
  cors: { origin: ['https://app.example.com'], credentials: true },
})
export class ChatGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  private readonly logger = new Logger(ChatGateway.name);

  constructor(private readonly auth: WsAuthService, private readonly chat: ChatService) {}

  async handleConnection(client: Socket) {
    try {
      const user = await this.auth.verify(client.handshake.auth?.token);   // токен из handshake
      client.data.user = user;
      await client.join(`user:${user.id}`);
    } catch {
      client.disconnect(true);                                          // без токена — отключаем
    }
  }

  handleDisconnect(client: Socket) {
    this.logger.debug(`disconnected ${client.data.user?.id}`);
  }

  @SubscribeMessage('message:send')
  async onMessage(@MessageBody() dto: SendMessageDto, @ConnectedSocket() client: Socket) {
    const message = await this.chat.save(client.data.user.id, dto);
    this.server.to(`room:${dto.roomId}`).emit('message:new', message);
    return { ok: true, id: message.id };                                // ack клиенту
  }
}

@Module({ providers: [ChatGateway, ChatService, WsAuthService] })
export class ChatModule {}
```

## Клиент

```ts
import { io } from 'socket.io-client';

const socket = io('https://api.example.com/chat', { auth: { token: accessToken } });
socket.emit('message:send', { roomId: 'r1', text: 'Привет' }, (ack) => console.log(ack));
socket.on('message:new', (m) => render(m));
```

## Отправка из других частей приложения

```ts
@Injectable()
export class OrdersNotifier {
  constructor(private readonly gateway: NotificationsGateway) {}

  orderShipped(userId: string, orderId: string) {
    this.gateway.server.to(`user:${userId}`).emit('order:shipped', { orderId });
  }
}
```

## Socket.IO или ws

| | Socket.IO | ws |
| --- | --- | --- |
| Протокол | Свой поверх WebSocket | Чистый WebSocket |
| Клиент | Нужна библиотека `socket.io-client` | Нативный `WebSocket` |
| Комнаты, namespaces, ack, переподключение | Из коробки | Реализовать самим |
| Масштабирование | Redis adapter | Своя pub/sub-шина |

## Конвейер в gateway

```ts
@UseGuards(WsJwtGuard)
@UsePipes(new ValidationPipe({ whitelist: true, exceptionFactory: (e) => new WsException(e) }))
@SubscribeMessage('message:send')
onMessage(@MessageBody() dto: SendMessageDto) {}
```

Ошибки — через `WsException`, клиент получает событие `exception`.

## Частые ошибки

- Не аутентифицировать подключение — любой может подписаться на события.
- `cors` не настроен — браузер не подключится с фронтенда.
- Хранить состояние комнат в памяти одного инстанса при нескольких репликах — см. [масштабирование WebSocket](<../11. Production, архитектура и собеседования/09. Как масштабировать NestJS WebSocket.md>).
- Отправлять в событиях данные без проверки, что пользователь имеет доступ к комнате.

## Что важно помнить

- Gateway — провайдер для двусторонней связи; по умолчанию Socket.IO.
- `@SubscribeMessage` + `@MessageBody` + `@ConnectedSocket`, сервер — `@WebSocketServer`.
- Аутентификация — в `handleConnection` или guard; ошибки — `WsException`.

## Мини-шпаргалка

- `@WebSocketGateway({ namespace, cors })`.
- `@WebSocketServer() server: Server`.
- `@SubscribeMessage('evt') handler(@MessageBody() dto, @ConnectedSocket() client)`.
- `server.to(room).emit(evt, data)`.
