# Как настроить global prefix, CORS и versioning

> [!NOTE]
> **Global prefix** (`app.setGlobalPrefix('api')`) добавляет общий префикс ко всем маршрутам — `/api/users`; отдельные маршруты (health check, вебхуки) можно исключить через `exclude`. **CORS** (`app.enableCors()`) разрешает браузеру обращаться к API с другого origin; в проде указывают **явный список** доверенных origin, а при cookie-авторизации — `credentials: true` (с ним нельзя `origin: '*'`). **Versioning** (`app.enableVersioning()`) позволяет держать несколько версий API одновременно: по URI (`/v1/users`) — самый наглядный, по заголовку, по media type (`Accept: application/json;v=2`) или своей функцией; версию задают на контроллере или методе через `@Version()` и `version` в `@Controller`.

## Вопрос

Как настроить глобальный префикс, CORS и версионирование API в NestJS?

## Global prefix

```ts
app.setGlobalPrefix('api', {
  exclude: [
    { path: 'health', method: RequestMethod.GET },
    'webhooks/stripe',
  ],
});
// GET /api/users, но GET /health и POST /webhooks/stripe
```

## CORS

```ts
app.enableCors({
  origin: ['https://app.example.com', 'https://admin.example.com'],
  credentials: true,                         // cookies и Authorization с фронтенда
  methods: ['GET', 'POST', 'PATCH', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  exposedHeaders: ['X-Total-Count'],         // какие заголовки ответа видит JS
  maxAge: 600,                               // кеш preflight на 10 минут
});
```

```ts
// динамическая проверка (например, превью-окружения)
app.enableCors({
  origin: (origin, cb) => {
    if (!origin || /\.example\.com$/.test(new URL(origin).hostname)) return cb(null, true);
    cb(new Error('Not allowed by CORS'), false);
  },
  credentials: true,
});
```

| Ошибка | Последствие |
| --- | --- |
| `origin: '*'` + `credentials: true` | Браузер отклонит ответ |
| `origin: true` в проде | Отражает любой origin — фактически отключает защиту |
| Не указан `exposedHeaders` | Фронтенд не видит `X-Total-Count` |

CORS — защита **браузера**, а не API: curl и серверы его игнорируют. Авторизация всё равно обязательна.

## Versioning по URI

```ts
app.enableVersioning({
  type: VersioningType.URI,      // /v1/...
  defaultVersion: '1',
});

@Controller({ path: 'users', version: '1' })
export class UsersV1Controller {
  @Get() findAll() { ... }       // GET /api/v1/users
}

@Controller({ path: 'users', version: '2' })
export class UsersV2Controller {
  @Get() findAll() { ... }       // GET /api/v2/users
}
```

```ts
// версия на уровне метода
@Controller('users')
export class UsersController {
  @Version('2')
  @Get(':id')
  findOneV2() { ... }

  @Version(['1', VERSION_NEUTRAL])   // и /v1, и без версии
  @Get(':id')
  findOne() { ... }
}
```

## Другие типы

| Тип | Как передаётся | Пример |
| --- | --- | --- |
| `URI` | В пути | `/v2/users` |
| `HEADER` | Свой заголовок | `X-API-Version: 2` (`header: 'X-API-Version'`) |
| `MEDIA_TYPE` | В `Accept` | `Accept: application/json;v=2` (`key: 'v='`) |
| `CUSTOM` | Функция-экстрактор | Из любого места запроса |

## Когда вводить новую версию

- Ломающие изменения: удаление или переименование полей, смена типов, другая семантика.
- Неломающие (новое опциональное поле, новый эндпоинт) — без новой версии.
- Старую версию поддерживают ограниченное время и сообщают о депрекейте (заголовки `Deprecation`, `Sunset`).

## Частые ошибки

- Хардкодить `/api/v1` в каждом `@Controller` вместо prefix и versioning.
- `enableCors()` без параметров в проде.
- Забыть исключить health check из префикса, а проверку в Kubernetes настроить на `/health`.
- Делать новую версию API на каждое мелкое изменение.

## Что важно помнить

- `setGlobalPrefix` + `exclude` для служебных маршрутов.
- CORS — явный allowlist, `credentials` несовместим с `*`.
- Versioning — для ломающих изменений; URI-версии наиболее наглядны.

## Мини-шпаргалка

- `app.setGlobalPrefix('api', { exclude: [...] })`.
- `app.enableCors({ origin: [...], credentials: true })`.
- `app.enableVersioning({ type: VersioningType.URI })`.
- `@Controller({ path, version })`, `@Version('2')`, `VERSION_NEUTRAL`.
