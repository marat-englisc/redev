# Как делать nested writes в Prisma

> [!NOTE]
> **Nested writes** позволяют одним вызовом `create`/`update` изменить запись **вместе со связанными**: создать заказ с позициями, связать пост с существующими тегами, отвязать профиль, обновить или удалить дочерние записи. Операции для связей: `create`, `createMany` (для one-to-many), `connect` (связать существующую по уникальному полю), `connectOrCreate`, `disconnect`, `set` (заменить весь набор связей many-to-many), `update`, `updateMany`, `upsert`, `delete`, `deleteMany`. Вся вложенная запись выполняется **в одной транзакции** — если что-то упадёт, ничего не сохранится. Ограничения: нельзя использовать результат одной вложенной операции для вычислений в другой и нельзя вставить внешний вызов между ними — для этого нужен interactive `$transaction`. При изменении many-to-many через `set` важно помнить, что связи, которых нет в списке, будут удалены.

## Вопрос

Как создавать и изменять связанные записи одним запросом в Prisma?

## Создание с вложенными записями

```ts
const order = await prisma.order.create({
  data: {
    user: { connect: { id: userId } },                 // существующий пользователь
    status: 'PENDING',
    total: totalAmount,
    items: {
      create: items.map((i) => ({ productId: i.productId, qty: i.qty, unitPrice: i.unitPrice })),
    },
    shippingAddress: { create: { city: dto.city, street: dto.street, zip: dto.zip } },
  },
  include: { items: true },
});
```

## connect, connectOrCreate, set

```ts
// связать пост с тегами; создать теги, которых ещё нет
await prisma.post.update({
  where: { id: postId },
  data: {
    tags: {
      connectOrCreate: names.map((name) => ({ where: { name }, create: { name } })),
    },
  },
});

// заменить набор тегов полностью
await prisma.post.update({
  where: { id: postId },
  data: { tags: { set: tagIds.map((id) => ({ id })) } },
});

// отвязать один тег
await prisma.post.update({ where: { id: postId }, data: { tags: { disconnect: [{ id: tagId }] } } });
```

## Обновление дочерних записей

```ts
await prisma.project.update({
  where: { id: projectId },
  data: {
    name: dto.name,
    tasks: {
      updateMany: { where: { status: 'OPEN' }, data: { status: 'ARCHIVED' } },
      deleteMany: { status: 'DRAFT' },
      create: { title: 'Ретроспектива', status: 'OPEN' },
    },
  },
});
```

## Явная модель-связка

```ts
// добавить участника проекта с ролью
await prisma.project.update({
  where: { id: projectId },
  data: { members: { create: { user: { connect: { id: userId } }, role: 'MEMBER' } } },
});

// или напрямую
await prisma.projectMember.create({ data: { projectId, userId, role: 'MEMBER' } });
```

## Операции

| Операция | Для чего |
| --- | --- |
| `create` / `createMany` | Новые связанные записи |
| `connect` | Связать существующую (по уникальному полю) |
| `connectOrCreate` | Связать или создать |
| `disconnect` | Отвязать (для необязательных связей и M:N) |
| `set` | Заменить весь набор M:N-связей |
| `update` / `updateMany` / `upsert` | Изменить связанные |
| `delete` / `deleteMany` | Удалить связанные |

## Nested write или $transaction

| Nested write | Interactive `$transaction` |
| --- | --- |
| Одна запись с деревом связанных данных | Несколько независимых операций и условия между ними |
| Нельзя использовать результат одной операции в другой | Можно: прочитать, проверить, записать |
| Атомарно, один вызов | Атомарно, нужен таймаут |

Подробнее — [транзакции Prisma](<13. Как работать с транзакциями Prisma.md>).

## Частые ошибки

- `set` с неполным списком — удаляются существующие связи.
- `connect` к несуществующей записи — ошибка P2025 (или P2018), которую нужно обработать.
- Передавать FK (`userId`) и `user: { connect }` одновременно — нельзя смешивать «checked» и «unchecked» формы ввода.
- `connectOrCreate` при конкурентных запросах может упасть на уникальности — нужен повтор или `upsert`.

## Что важно помнить

- Nested writes — дерево изменений одним атомарным вызовом.
- `connect`, `connectOrCreate`, `disconnect`, `set` для связей; `create`/`update`/`delete` для дочерних.
- Логика между шагами — interactive `$transaction`.

## Мини-шпаргалка

- `items: { create: [...] }`.
- `user: { connect: { id } }`.
- `tags: { connectOrCreate: [{ where, create }] }`.
- `tags: { set: [...] }`, `{ disconnect: [...] }`.
