# Как установить и инициализировать Prisma в NestJS

> [!NOTE]
> В Prisma 7 нужны три вещи: CLI `prisma` (dev-зависимость), runtime-пакет `@prisma/client` той же мажорной версии и **driver adapter** для своей СУБД (`@prisma/adapter-pg` + `pg` для PostgreSQL). Устанавливайте мажорную версию **явно** (`prisma@7`): документация NestJS предупреждает, что тег `latest` пакета `prisma` может указывать на пре-релиз следующей мажорной версии с другим CLI. `prisma init` создаёт `prisma/schema.prisma` и файл конфигурации Prisma в корне (`prisma.config.ts`; в релизах 7.10+ он по умолчанию называется `prisma7.config.ts`, старое имя по-прежнему распознаётся). В конфиге задаются путь к схеме, миграции и URL базы, а `.env` **не загружается автоматически** — его подключают через `import 'dotenv/config'`. Генератор `prisma-client` требует `output` (например, `../src/generated/prisma`); для CommonJS-проекта Nest указывают `moduleFormat = "cjs"`. После изменения схемы клиент генерируют явно: `prisma generate` (миграции его больше не запускают).

## Вопрос

Как установить и настроить Prisma 7 в NestJS-проекте?

## Установка

```bash
npm install -D prisma@7
npm install @prisma/client@7 @prisma/adapter-pg pg dotenv
```

```bash
npx prisma init --output ../src/generated/prisma
```

## Файлы

```text
my-api/
├── prisma/
│   ├── schema.prisma
│   └── migrations/
├── prisma.config.ts         # (prisma7.config.ts в 7.10+)
├── src/
│   └── generated/prisma/    # сгенерированный клиент — добавить в .gitignore
└── .env
```

## Конфигурация Prisma

```ts
// prisma.config.ts
import 'dotenv/config';
import { defineConfig, env } from 'prisma/config';

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
    seed: 'tsx prisma/seed.ts',
  },
  datasource: {
    url: env('DATABASE_URL'),          // для миграций; при пулере — прямой URL к БД
  },
});
```

## schema.prisma

```prisma
generator client {
  provider     = "prisma-client"
  output       = "../src/generated/prisma"
  moduleFormat = "cjs"                // Nest-проект на CommonJS
}

datasource db {
  provider = "postgresql"
}
```

URL подключения в `datasource` больше не указывают — он в конфиге (для CLI) и в адаптере (для приложения).

## .env

```env
DATABASE_URL="postgresql://app:secret@localhost:5432/app?schema=public"
```

## Генерация клиента

```bash
npx prisma generate            # после изменения схемы, в CI перед сборкой, после свежего clone
```

```json
// package.json
{
  "scripts": {
    "prisma:generate": "prisma generate",
    "build": "prisma generate && nest build"
  }
}
```

## Создание клиента в приложении

```ts
import { PrismaClient } from '../generated/prisma/client';   // в ESM-проекте — '.../client.js'
import { PrismaPg } from '@prisma/adapter-pg';

const adapter = new PrismaPg({ connectionString: process.env.DATABASE_URL });
const prisma = new PrismaClient({ adapter });
```

В Nest это делается внутри `PrismaService` — см. [PrismaService и PrismaModule](<06. Что такое PrismaService и PrismaModule.md>).

## Что изменилось по сравнению с Prisma 6

| Prisma 6 | Prisma 7 |
| --- | --- |
| `provider = "prisma-client-js"`, клиент в `node_modules` | `provider = "prisma-client"`, обязательный `output` |
| `import { PrismaClient } from '@prisma/client'` | Импорт из сгенерированного пути |
| `url = env("DATABASE_URL")` в схеме | URL в `prisma.config.ts` и в адаптере |
| Встроенный query engine | Обязательный driver adapter |
| `.env` загружается автоматически | `import 'dotenv/config'` |
| `migrate dev` запускал `generate` и seed | Нужно вызывать `prisma generate` и `prisma db seed` явно |
| `$use` middleware | `$extends` |

## Частые ошибки

- Разные мажорные версии `prisma` и `@prisma/client`.
- Установка `prisma` без версии и неожиданный пре-релиз.
- Забыть `prisma generate` в CI — сборка падает на отсутствующем `generated/prisma`.
- ESM-клиент в CommonJS-проекте Nest без `moduleFormat = "cjs"` — ошибка `import.meta`.
- Коммитить `src/generated/prisma` (обычно его генерируют при сборке).

## Что важно помнить

- `prisma@7`, `@prisma/client@7`, адаптер `@prisma/adapter-pg`.
- Генератор `prisma-client` + `output` (+ `moduleFormat = "cjs"` для CJS).
- Конфиг Prisma в корне, `.env` — через `dotenv/config`, `generate` — явно.

## Мини-шпаргалка

- `npx prisma init --output ../src/generated/prisma`.
- `defineConfig({ schema, migrations, datasource: { url: env('DATABASE_URL') } })`.
- `new PrismaClient({ adapter: new PrismaPg({ connectionString }) })`.
- `npx prisma generate`.
