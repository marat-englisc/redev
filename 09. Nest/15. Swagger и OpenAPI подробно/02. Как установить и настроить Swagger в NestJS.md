# Как установить и настроить Swagger в NestJS

> [!NOTE]
> Установка — пакет `@nestjs/swagger`. Настройка выполняется в `main.ts` после создания приложения: `DocumentBuilder` задаёт общие сведения (название, описание, версия, серверы, теги, схемы авторизации), `SwaggerModule.createDocument(app, config, options)` строит документ по зарегистрированным маршрутам (поэтому вызывать его нужно **после** `setGlobalPrefix` и `enableVersioning`), а `SwaggerModule.setup(path, app, documentFactory, options)` раздаёт Swagger UI и JSON/YAML документа (по умолчанию `/<path>-json` и `/<path>-yaml`, пути меняются опциями `jsonDocumentUrl`/`yamlDocumentUrl`). Документ передают **фабрикой**, чтобы он строился лениво. Полезные опции: `operationIdFactory` (читаемые id операций для генераторов клиентов), `include` (документировать только выбранные модули — например, отдельные документы для публичного и админского API), `swaggerOptions.persistAuthorization`. В продакшене UI отключают или закрывают авторизацией; иногда вместо Swagger UI подключают Scalar или Redoc поверх того же документа.

## Вопрос

Как установить и настроить Swagger в NestJS-приложении?

## Установка

```bash
npm install @nestjs/swagger
```

## Настройка

```ts
// swagger.ts
export function setupSwagger(app: INestApplication) {
  const config = new DocumentBuilder()
    .setTitle('Shop API')
    .setDescription('API интернет-магазина')
    .setVersion('1.0.0')
    .addServer('http://localhost:3000', 'Local')
    .addServer('https://api.example.com', 'Production')
    .addTag('products', 'Каталог товаров')
    .addBearerAuth({ type: 'http', scheme: 'bearer', bearerFormat: 'JWT' }, 'access-token')
    .addCookieAuth('session', { type: 'apiKey', in: 'cookie' }, 'session')
    .build();

  const documentFactory = () =>
    SwaggerModule.createDocument(app, config, {
      operationIdFactory: (controllerKey, methodKey) => `${controllerKey.replace('Controller', '')}_${methodKey}`,
    });

  SwaggerModule.setup('docs', app, documentFactory, {
    jsonDocumentUrl: 'docs/openapi.json',
    swaggerOptions: { persistAuthorization: true, displayRequestDuration: true },
    customSiteTitle: 'Shop API Docs',
  });
}

// main.ts
const app = await NestFactory.create(AppModule);
app.setGlobalPrefix('api');
app.enableVersioning({ type: VersioningType.URI, defaultVersion: '1' });
if (config.get('SWAGGER_ENABLED')) setupSwagger(app);       // после prefix и versioning
await app.listen(3000);
```

UI — `/docs`, документ — `/docs/openapi.json`.

## Несколько документов

```ts
const publicDoc = () => SwaggerModule.createDocument(app, publicConfig, { include: [CatalogModule, OrdersModule] });
const adminDoc = () => SwaggerModule.createDocument(app, adminConfig, { include: [AdminModule] });

SwaggerModule.setup('docs', app, publicDoc);
SwaggerModule.setup('admin/docs', app, adminDoc);
```

## Защита в продакшене

```ts
// вариант 1: не подключать
if (process.env.SWAGGER_ENABLED === 'true') setupSwagger(app);

// вариант 2: basic auth перед UI (Express)
app.use(['/docs', '/docs/openapi.json'], basicAuth({ users: { [user]: pass }, challenge: true }));
```

## CLI-плагин

```json
// nest-cli.json
{ "compilerOptions": { "plugins": ["@nestjs/swagger"] } }
```

Плагин избавляет от `@ApiProperty` на каждом поле — см. [Swagger CLI plugin](<10. Что такое Swagger CLI plugin.md>).

## Альтернативный UI

```ts
// Scalar поверх того же документа
app.use('/reference', apiReference({ url: '/docs/openapi.json' }));   // @scalar/nestjs-api-reference
```

## Частые ошибки

- `createDocument` до `setGlobalPrefix`/`enableVersioning` — пути в документе без префикса.
- Открытый Swagger на проде.
- Нет `operationIdFactory` — генераторы клиентов создают имена вроде `ProductsController_create`.
- Свой `@nestjs/swagger` несовместимой мажорной версии с `@nestjs/core`.

## Что важно помнить

- `DocumentBuilder` + `createDocument` + `setup` в `main.ts`.
- Документ строится после настройки prefix/versioning, передаётся фабрикой.
- В проде — отключить или защитить.

## Мини-шпаргалка

- `npm i @nestjs/swagger`.
- `new DocumentBuilder().setTitle().setVersion().addBearerAuth().build()`.
- `SwaggerModule.setup('docs', app, () => SwaggerModule.createDocument(app, config))`.
- `include: [Module]` — отдельные документы.
