# Как документировать file upload

> [!NOTE]
> Загрузка файлов — запрос с телом `multipart/form-data`. Чтобы Swagger UI показал поле выбора файла, операцию помечают **`@ApiConsumes('multipart/form-data')`** и описывают тело через **`@ApiBody`**: поле файла — `type: 'string', format: 'binary'`, массив файлов — `type: 'array', items: { type: 'string', format: 'binary' }`, остальные поля формы — обычными свойствами (они приходят строками, что важно для валидации). Описание можно задать схемой в `@ApiBody({ schema })` или DTO-классом с `@ApiProperty({ type: 'string', format: 'binary' })`. Ограничения (максимальный размер, допустимые типы) документация сама не проверяет — их указывают в `description` и обязательно реализуют в коде (`limits` у Multer, `ParseFilePipe`). Для схемы с presigned URL документируют два шага: запрос URL и подтверждение загрузки.

## Вопрос

Как описать в Swagger эндпоинт загрузки файлов?

## Один файл

```ts
@ApiTags('users')
@ApiConsumes('multipart/form-data')
@ApiBody({
  description: 'Аватар: PNG/JPEG/WebP, до 2 МБ',
  schema: {
    type: 'object',
    required: ['file'],
    properties: {
      file: { type: 'string', format: 'binary' },
    },
  },
})
@ApiCreatedResponse({ type: AvatarDto })
@ApiPayloadTooLargeResponse({ type: ErrorResponseDto })
@ApiUnprocessableEntityResponse({ type: ErrorResponseDto, description: 'Недопустимый тип файла' })
@Post('me/avatar')
@UseInterceptors(FileInterceptor('file', { limits: { fileSize: 2 * 1024 * 1024 } }))
uploadAvatar(@UploadedFile(avatarFilePipe) file: Express.Multer.File) {}
```

## Файл и поля формы через DTO

```ts
export class UploadDocumentDto {
  @ApiProperty({ type: 'string', format: 'binary', description: 'PDF до 10 МБ' })
  file: Express.Multer.File;

  @ApiProperty({ example: 'Договор поставки' })
  @IsString() @MaxLength(200)
  title: string;

  @ApiPropertyOptional({ enum: ['contract', 'invoice'] })
  @IsOptional() @IsIn(['contract', 'invoice'])
  kind?: 'contract' | 'invoice';
}

@ApiConsumes('multipart/form-data')
@ApiBody({ type: UploadDocumentDto })
@Post('documents')
@UseInterceptors(FileInterceptor('file'))
upload(@UploadedFile(pdfPipe) file: Express.Multer.File, @Body() dto: Omit<UploadDocumentDto, 'file'>) {}
```

## Несколько файлов

```ts
@ApiConsumes('multipart/form-data')
@ApiBody({
  schema: {
    type: 'object',
    properties: {
      photos: { type: 'array', items: { type: 'string', format: 'binary' }, maxItems: 10 },
      albumId: { type: 'string', format: 'uuid' },
    },
  },
})
@Post('gallery')
@UseInterceptors(FilesInterceptor('photos', 10))
gallery(@UploadedFiles() photos: Express.Multer.File[], @Body('albumId') albumId: string) {}
```

## Скачивание файла

```ts
@ApiProduces('application/pdf')
@ApiOkResponse({ schema: { type: 'string', format: 'binary' }, description: 'PDF-файл' })
@Get('reports/:id')
download(): Promise<StreamableFile> {}
```

## Presigned URL

```ts
@ApiOperation({ summary: 'Шаг 1: получить URL для загрузки', description: 'Клиент делает PUT по `url` с заголовком Content-Type, затем вызывает шаг 2.' })
@ApiCreatedResponse({ type: PresignedUploadDto })
@Post('uploads')
createUpload(@Body() dto: CreateUploadDto) {}

@ApiOperation({ summary: 'Шаг 2: подтвердить загрузку' })
@Post('uploads/:key/complete')
complete() {}
```

## Частые ошибки

- Нет `@ApiConsumes('multipart/form-data')` — в UI нет выбора файла.
- Имя поля в `@ApiBody` не совпадает с `FileInterceptor('file')`.
- Ограничения размера и типа указаны только в документации, а не в коде.
- Поля формы документированы как числа/boolean без учёта, что они приходят строками.

## Что важно помнить

- `@ApiConsumes('multipart/form-data')` + `@ApiBody` с `format: 'binary'`.
- Имена полей совпадают с interceptor-ом.
- Лимиты — в описании и в коде.

## Мини-шпаргалка

- `{ type: 'string', format: 'binary' }` — файл.
- `{ type: 'array', items: { type: 'string', format: 'binary' } }` — файлы.
- `@ApiProduces('application/pdf')` — скачивание.
- `@ApiPayloadTooLargeResponse`.
