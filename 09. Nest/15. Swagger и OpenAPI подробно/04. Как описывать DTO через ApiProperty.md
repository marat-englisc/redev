# Как описывать DTO через ApiProperty

> [!NOTE]
> `@ApiProperty()` и `@ApiPropertyOptional()` описывают поле DTO-класса в OpenAPI-схеме: тип (`type`, для массивов `type: [ItemDto]` или `isArray`), обязательность (`required`), `description`, `example`, ограничения (`minLength`, `maxLength`, `minimum`, `maximum`, `pattern`, `format: 'email' | 'uuid' | 'date-time'`), `enum` вместе с `enumName` (тогда enum станет переиспользуемой схемой), `nullable`, `default`, `readOnly`/`writeOnly`, `deprecated`. Swagger видит **только классы** — DTO-интерфейсы и `type`-алиасы в документацию не попадают. Производные DTO создают **mapped types из `@nestjs/swagger`** (`PartialType`, `PickType`, `OmitType`, `IntersectionType`) — так метаданные Swagger наследуются корректно (версии из `@nestjs/mapped-types` их теряют). С **CLI-плагином** большую часть `@ApiProperty` можно не писать: тип, обязательность и даже ограничения `class-validator` выводятся автоматически, а описание берётся из JSDoc-комментариев.

## Вопрос

Как описывать DTO для Swagger через `@ApiProperty`?

## DTO запроса

```ts
export enum ProductStatus { Draft = 'draft', Published = 'published' }

export class OrderItemDto {
  @ApiProperty({ format: 'uuid', example: '0192f0a1-...' })
  @IsUUID() productId: string;

  @ApiProperty({ minimum: 1, maximum: 100, example: 2 })
  @IsInt() @Min(1) @Max(100) qty: number;
}

export class CreateProductDto {
  @ApiProperty({ description: 'Название товара', minLength: 2, maxLength: 120, example: 'Клавиатура Keychron K2' })
  @IsString() @Length(2, 120)
  title: string;

  @ApiProperty({ description: 'Цена в рублях', minimum: 0, example: 7990 })
  @IsNumber() @Min(0)
  price: number;

  @ApiProperty({ enum: ProductStatus, enumName: 'ProductStatus', default: ProductStatus.Draft })
  @IsEnum(ProductStatus)
  status: ProductStatus = ProductStatus.Draft;

  @ApiPropertyOptional({ type: [String], maxItems: 10, example: ['wireless', 'mechanical'] })
  @IsOptional() @IsArray() @ArrayMaxSize(10)
  tags?: string[];

  @ApiPropertyOptional({ type: () => [OrderItemDto] })     // вложенный массив DTO; функция — против циклов
  @IsOptional() @ValidateNested({ each: true }) @Type(() => OrderItemDto)
  bundle?: OrderItemDto[];

  @ApiProperty({ writeOnly: true, minLength: 8 })
  @IsString() secret: string;
}
```

## DTO ответа

```ts
export class ProductDto {
  @ApiProperty({ format: 'uuid', readOnly: true }) id: string;
  @ApiProperty() title: string;
  @ApiProperty({ type: Number, example: 7990 }) price: number;
  @ApiProperty({ nullable: true, type: String, example: null }) description: string | null;
  @ApiProperty({ type: String, format: 'date-time' }) createdAt: Date;
}
```

## Mapped types из @nestjs/swagger

```ts
import { PartialType, OmitType, PickType, IntersectionType } from '@nestjs/swagger';

export class UpdateProductDto extends PartialType(OmitType(CreateProductDto, ['secret'] as const)) {}
export class ProductPreviewDto extends PickType(ProductDto, ['id', 'title', 'price'] as const) {}
```

## Ключевые опции

| Опция | Назначение |
| --- | --- |
| `type`, `isArray`, `type: [X]` | Тип и массивы |
| `required` / `@ApiPropertyOptional` | Обязательность |
| `description`, `example`, `examples` | Описание и примеры |
| `enum`, `enumName` | Перечисления (переиспользуемые) |
| `minLength/maxLength/minimum/maximum/pattern/format` | Ограничения |
| `nullable`, `default` | `null` и значение по умолчанию |
| `readOnly`, `writeOnly`, `deprecated` | Направление и устаревание |

## С CLI-плагином

```ts
export class CreateProductDto {
  /** Название товара */
  @Length(2, 120)
  title: string;          // тип string, required, minLength/maxLength (при introspectComments и classValidatorShim)

  tags?: string[];        // optional массив строк — без декораторов
}
```

## Частые ошибки

- DTO-интерфейс — схема пустая.
- `PartialType` из `@nestjs/mapped-types` в проекте со Swagger.
- `enum` без `enumName` — enum дублируется в каждой схеме.
- `Date` без `format: 'date-time'` (без плагина) — тип неверный.
- Расхождение `@ApiProperty` и правил `class-validator` (документировано 120 символов, валидируется 100).

## Что важно помнить

- Swagger описывает классы: `@ApiProperty`/`@ApiPropertyOptional`.
- Mapped types — из `@nestjs/swagger`.
- CLI-плагин убирает большую часть ручных декораторов.

## Мини-шпаргалка

- `@ApiProperty({ description, example, minLength, maximum, format })`.
- `@ApiPropertyOptional()`.
- `@ApiProperty({ enum: E, enumName: 'E' })`.
- `@ApiProperty({ type: () => [ItemDto] })`.
- `PartialType/PickType/OmitType/IntersectionType` из `@nestjs/swagger`.
