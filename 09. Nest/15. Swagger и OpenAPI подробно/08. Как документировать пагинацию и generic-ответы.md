# Как документировать пагинацию и generic-ответы

> [!NOTE]
> TypeScript-дженерики стираются при компиляции, поэтому `Paginated<ProductDto>` сам по себе в OpenAPI не попадёт. Стандартный приём в `@nestjs/swagger`: описать общий класс метаданных (`PaginationMetaDto`), зарегистрировать модели через **`@ApiExtraModels(PaginatedDto, ProductDto)`** (или `extraModels` в `createDocument`) и собрать схему ответа через **`allOf`** + **`getSchemaPath()`**, переопределив поле `items` массивом нужной модели. Удобно оформить это в **композиционный декоратор** `@ApiPaginatedResponse(ProductDto)` — тогда каждый списочный эндпоинт документируется одной строкой. Тот же подход применяют для обёрток ответа (`{ data: T }`, если их добавляет interceptor) и для cursor-пагинации (`{ items, nextCursor }`). Параметры пагинации, фильтрации и сортировки документируют через **query-DTO** с `@ApiPropertyOptional` (default, minimum/maximum, enum разрешённых полей сортировки) — документация и валидация остаются одним классом.

## Вопрос

Как документировать в Swagger пагинированные и обобщённые (generic) ответы?

## Модели

```ts
export class PaginationMetaDto {
  @ApiProperty({ example: 2 }) page: number;
  @ApiProperty({ example: 20 }) limit: number;
  @ApiProperty({ example: 134 }) total: number;
  @ApiProperty({ example: 7 }) totalPages: number;
}

export class PaginatedDto<T> {
  items: T[];                                  // тип задаётся в декораторе
  @ApiProperty({ type: PaginationMetaDto }) meta: PaginationMetaDto;
}
```

## Декоратор

```ts
export const ApiPaginatedResponse = <TModel extends Type<unknown>>(model: TModel) =>
  applyDecorators(
    ApiExtraModels(PaginatedDto, model),
    ApiOkResponse({
      schema: {
        allOf: [
          { $ref: getSchemaPath(PaginatedDto) },
          { properties: { items: { type: 'array', items: { $ref: getSchemaPath(model) } } }, required: ['items'] },
        ],
      },
    }),
  );
```

```ts
@ApiPaginatedResponse(ProductDto)
@Get()
list(@Query() query: ListProductsQueryDto): Promise<PaginatedDto<ProductDto>> {
  return this.products.list(query);
}
```

## Cursor-пагинация

```ts
export class CursorPageDto<T> {
  items: T[];
  @ApiProperty({ nullable: true, type: String, example: 'eyJpZCI6IjAxOTJmIn0' }) nextCursor: string | null;
}

export const ApiCursorPaginatedResponse = <TModel extends Type<unknown>>(model: TModel) =>
  applyDecorators(
    ApiExtraModels(CursorPageDto, model),
    ApiOkResponse({
      schema: {
        allOf: [
          { $ref: getSchemaPath(CursorPageDto) },
          { properties: { items: { type: 'array', items: { $ref: getSchemaPath(model) } } } },
        ],
      },
    }),
  );
```

## Обёртка { data }

```ts
export class ApiEnvelopeDto<T> {
  data: T;
}

export const ApiEnvelopeResponse = <TModel extends Type<unknown>>(model: TModel, isArray = false) =>
  applyDecorators(
    ApiExtraModels(ApiEnvelopeDto, model),
    ApiOkResponse({
      schema: {
        allOf: [
          { $ref: getSchemaPath(ApiEnvelopeDto) },
          { properties: { data: isArray ? { type: 'array', items: { $ref: getSchemaPath(model) } } : { $ref: getSchemaPath(model) } } },
        ],
      },
    }),
  );
```

Используйте, если [interceptor оборачивает ответы](<../07. Middleware, interceptors и request lifecycle/05. Как трансформировать response через interceptor.md>) — документация должна показывать реальную форму.

## Параметры списка

```ts
export class ListProductsQueryDto {
  @ApiPropertyOptional({ minimum: 1, default: 1 }) @Type(() => Number) @IsInt() @Min(1) page = 1;
  @ApiPropertyOptional({ minimum: 1, maximum: 100, default: 20 }) @Type(() => Number) @IsInt() @Min(1) @Max(100) limit = 20;
  @ApiPropertyOptional({ maxLength: 100, description: 'Поиск по названию' }) @IsOptional() @MaxLength(100) search?: string;
  @ApiPropertyOptional({ format: 'uuid' }) @IsOptional() @IsUUID() categoryId?: string;
  @ApiPropertyOptional({ enum: ['createdAt', 'price', 'title'], default: 'createdAt' })
  @IsIn(['createdAt', 'price', 'title']) sortBy: 'createdAt' | 'price' | 'title' = 'createdAt';
  @ApiPropertyOptional({ enum: ['asc', 'desc'], default: 'desc' }) @IsIn(['asc', 'desc']) sortOrder: 'asc' | 'desc' = 'desc';
}
```

## Полиморфные ответы

```ts
@ApiExtraModels(CardPaymentDto, InvoicePaymentDto)
@ApiOkResponse({
  schema: {
    oneOf: [{ $ref: getSchemaPath(CardPaymentDto) }, { $ref: getSchemaPath(InvoicePaymentDto) }],
    discriminator: { propertyName: 'method' },
  },
})
```

## Частые ошибки

- `type: PaginatedDto` без указания типа элементов — клиент видит `items: any[]`.
- `getSchemaPath(Model)` без `@ApiExtraModels(Model)` — битая ссылка `$ref`.
- Документация без обёртки `{ data }`, хотя interceptor её добавляет.
- Поля сортировки в документации шире белого списка в валидации.

## Что важно помнить

- Дженерики документируют через `@ApiExtraModels` + `allOf` + `getSchemaPath`.
- Композиционный декоратор `@ApiPaginatedResponse(Model)` — одна строка на эндпоинт.
- Query-DTO — общий источник для валидации и документации параметров.

## Мини-шпаргалка

- `ApiExtraModels(PaginatedDto, Model)`.
- `schema: { allOf: [{ $ref: getSchemaPath(PaginatedDto) }, { properties: { items: { type: 'array', items: { $ref } } } }] }`.
- `oneOf` + `discriminator` для вариантов.
- `@ApiPropertyOptional({ enum, default, minimum, maximum })` в query-DTO.
