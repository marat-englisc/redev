# Что такое Swagger и OpenAPI в NestJS

> [!NOTE]
> **OpenAPI** — стандарт машиночитаемого описания HTTP API (JSON или YAML): пути, методы, параметры, тела запросов, ответы, схемы данных, способы авторизации. **Swagger** — исторически исходное название спецификации и набор инструментов вокруг неё: **Swagger UI** (интерактивная документация с «Try it out»), Swagger Editor, генераторы. В NestJS пакет **`@nestjs/swagger`** генерирует OpenAPI-документ **из кода**: маршрутов контроллеров, DTO-классов и декораторов (`@ApiTags`, `@ApiOperation`, `@ApiProperty`, `@ApiResponse`, `@ApiBearerAuth`), а **CLI-плагин** выводит большую часть метаданных из TypeScript-типов автоматически. Документ используют для документации и ручного тестирования, **генерации типизированных клиентов** для фронтенда (`openapi-typescript`, Orval, `@hey-api/openapi-ts`), контрактных тестов и импорта в Postman/Insomnia. Ценность документации — в точности: она должна генерироваться из того же кода, что обрабатывает запросы, и проверяться в CI.

## Вопрос

Что такое Swagger и OpenAPI и как они используются в NestJS?

## Термины

| Термин | Что это |
| --- | --- |
| OpenAPI Specification | Формат описания API (версии 3.0, 3.1) |
| OpenAPI document | Конкретное описание вашего API (`openapi.json`) |
| Swagger UI | Веб-интерфейс для просмотра и вызова API |
| `@nestjs/swagger` | Генерация документа из кода Nest + раздача Swagger UI |
| CLI-плагин | Автоматическое описание DTO и ответов по TS-типам |

## Минимальный пример

```ts
const config = new DocumentBuilder()
  .setTitle('Shop API')
  .setVersion('1.0')
  .addBearerAuth()
  .build();

const documentFactory = () => SwaggerModule.createDocument(app, config);
SwaggerModule.setup('docs', app, documentFactory);   // UI: /docs, JSON: /docs-json
```

```ts
@ApiTags('products')
@Controller('products')
export class ProductsController {
  @ApiOperation({ summary: 'Создать товар' })
  @ApiCreatedResponse({ type: ProductDto })
  @Post()
  create(@Body() dto: CreateProductDto) {}
}
```

## Фрагмент результата

```json
{
  "openapi": "3.0.0",
  "paths": {
    "/products": {
      "post": {
        "tags": ["products"],
        "summary": "Создать товар",
        "requestBody": { "content": { "application/json": { "schema": { "$ref": "#/components/schemas/CreateProductDto" } } } },
        "responses": { "201": { "content": { "application/json": { "schema": { "$ref": "#/components/schemas/ProductDto" } } } } }
      }
    }
  }
}
```

## Зачем это фронтенду

```bash
npx openapi-typescript http://localhost:3000/docs-json -o src/api/schema.d.ts
```

```ts
import createClient from 'openapi-fetch';
import type { paths } from './api/schema';

const api = createClient<paths>({ baseUrl: '/api' });
const { data, error } = await api.POST('/products', { body: { title: 'Клавиатура', price: 4990 } });   // типизировано
```

Изменение DTO на бэкенде сразу ломает компиляцию фронтенда в местах, которые нужно обновить.

## Code-first и design-first

| Code-first (NestJS по умолчанию) | Design-first |
| --- | --- |
| Документ генерируется из кода | Сначала пишется спецификация, затем код |
| Всегда соответствует реализации (при дисциплине) | Удобно для согласования контракта до разработки |
| Меньше ручной работы | Нужна проверка соответствия кода спецификации |

## Частые ошибки

- Считать Swagger и OpenAPI разными стандартами конкурентами — это инструменты и спецификация.
- Документация, написанная вручную отдельно от кода, — быстро устаревает.
- Открытый Swagger UI в продакшене без авторизации.
- DTO-интерфейсы вместо классов — Swagger не видит схему.

## Что важно помнить

- OpenAPI — спецификация, Swagger UI — интерфейс, `@nestjs/swagger` — генерация из кода.
- Документ полезен для UI, клиентов, тестов и интеграций.
- Ценность — в точности и автоматической проверке.

## Мини-шпаргалка

- `DocumentBuilder` → `SwaggerModule.createDocument` → `SwaggerModule.setup('docs', app, ...)`.
- `@ApiTags`, `@ApiOperation`, `@ApiProperty`, `@ApiResponse`, `@ApiBearerAuth`.
- `/docs` — UI, `/docs-json` — документ.
- `openapi-typescript` — типы для фронтенда.
