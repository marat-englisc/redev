# Что такое ArgumentsHost и ExecutionContext

> [!NOTE]
> **`ArgumentsHost`** — абстракция над аргументами текущего обработчика, независимая от транспорта: в HTTP это `[request, response, next]`, в WebSocket — `[client, data]`, в микросервисах — `[data, context]`. Метод `getType()` возвращает `'http' | 'ws' | 'rpc'` (и `'graphql'` через `GqlExecutionContext`), а `switchToHttp()`, `switchToWs()`, `switchToRpc()` дают типизированный доступ к нужным объектам. `ArgumentsHost` получают **exception filters**. **`ExecutionContext`** расширяет `ArgumentsHost` двумя методами: `getClass()` — класс контроллера и `getHandler()` — вызываемый метод. Именно поэтому **guards и interceptors**, получающие `ExecutionContext`, могут читать **метаданные** маршрута через `Reflector`. Благодаря этой абстракции один guard или filter может работать для HTTP, WebSocket и RPC.

## Вопрос

Что такое `ArgumentsHost` и `ExecutionContext` и чем они отличаются?

## Кто что получает

| Компонент | Получает |
| --- | --- |
| Exception filter | `ArgumentsHost` |
| Guard | `ExecutionContext` |
| Interceptor | `ExecutionContext` |
| Custom param decorator (`createParamDecorator`) | `ExecutionContext` |
| Middleware | Нет — только `req`, `res`, `next` |

## ArgumentsHost

```ts
@Catch()
export class AnyFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    switch (host.getType()) {
      case 'http': {
        const ctx = host.switchToHttp();
        const res = ctx.getResponse<Response>();
        const req = ctx.getRequest<Request>();
        res.status(500).json({ path: req.url });
        break;
      }
      case 'ws': {
        const client = host.switchToWs().getClient<Socket>();
        client.emit('error', { message: 'Internal error' });
        break;
      }
      case 'rpc':
        // host.switchToRpc().getData(), getContext()
        break;
    }
  }
}
```

## ExecutionContext

```ts
@Injectable()
export class AuditGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(ctx: ExecutionContext) {
    const handler = ctx.getHandler();       // метод, например OrdersController.prototype.cancel
    const controller = ctx.getClass();      // класс OrdersController

    const action = this.reflector.get(AuditAction, handler);
    console.log(`${controller.name}.${handler.name} → ${action}`);
    return true;
  }
}
```

## GraphQL

```ts
canActivate(context: ExecutionContext) {
  const gql = GqlExecutionContext.create(context);
  const { req } = gql.getContext();         // request в контексте GraphQL
  const args = gql.getArgs();
}
```

Для GraphQL `getType()` возвращает `'graphql'` (типизированно — `context.getType<GqlContextType>()`).

## Универсальный guard

```ts
@Injectable()
export class WsOrHttpAuthGuard implements CanActivate {
  canActivate(ctx: ExecutionContext) {
    const token =
      ctx.getType() === 'ws'
        ? ctx.switchToWs().getClient<Socket>().handshake.auth?.token
        : ctx.switchToHttp().getRequest<Request>().headers.authorization?.split(' ')[1];
    return this.verify(token);
  }
}
```

## Сравнение

| | `ArgumentsHost` | `ExecutionContext` |
| --- | --- | --- |
| Доступ к аргументам | Да | Да (наследует) |
| `getType()`, `switchTo*()` | Да | Да |
| `getClass()`, `getHandler()` | Нет | Да |
| Метаданные через `Reflector` | Нет | Да |

## Частые ошибки

- Использовать `switchToHttp()` в guard, подключённом к WebSocket-gateway.
- Пытаться читать метаданные в filter — у `ArgumentsHost` нет `getHandler()`.
- Забыть `GqlExecutionContext` — в GraphQL `switchToHttp().getRequest()` вернёт не то.

## Что важно помнить

- `ArgumentsHost` — аргументы обработчика для любого транспорта.
- `ExecutionContext` = `ArgumentsHost` + класс и метод → метаданные.
- `getType()` + `switchTo*()` делают компоненты транспортно-независимыми.

## Мини-шпаргалка

- `host.switchToHttp().getRequest()/getResponse()`.
- `host.switchToWs().getClient()/getData()`.
- `host.switchToRpc().getData()/getContext()`.
- `ctx.getHandler()`, `ctx.getClass()`.
- `GqlExecutionContext.create(ctx)`.
