# Что такое metadata и Reflector

> [!NOTE]
> **Метаданные** — данные, прикреплённые декораторами к классам и методам, которые не меняют их поведение, но могут быть прочитаны позже. В Nest это способ сказать guard-у или interceptor-у **«как обрабатывать этот маршрут»**: `@Roles(['admin'])`, `@Public()`, `@CacheTTL(60)`, `@AuditAction('order.cancel')`. Современный способ создать такой декоратор — **`Reflector.createDecorator<T>()`**, который возвращает типизированный декоратор-«ключ»; старый — `SetMetadata(key, value)` + строковый ключ. Читает метаданные **`Reflector`** (внедряется как провайдер): `get(Decorator, target)` — с одного уровня, `getAllAndOverride` — первое найденное значение по списку целей (метод важнее класса), `getAllAndMerge` — объединение значений с разных уровней. Цели берут из `ExecutionContext`: `context.getHandler()` (метод) и `context.getClass()` (контроллер).

## Вопрос

Что такое метаданные в NestJS и как с ними работать через `Reflector`?

## Создание декоратора

```ts
// современный способ — типизированный
export const Roles = Reflector.createDecorator<string[]>();
export const Public = Reflector.createDecorator<boolean>({ transform: (v) => v ?? true });

// классический способ
export const IS_PUBLIC_KEY = 'isPublic';
export const PublicLegacy = () => SetMetadata(IS_PUBLIC_KEY, true);
```

## Использование

```ts
@Controller('reports')
@Roles(['analyst'])
export class ReportsController {
  @Get('daily')
  daily() {}                          // требуется analyst (с контроллера)

  @Get('admin')
  @Roles(['admin'])
  admin() {}                          // admin (метод переопределяет)

  @Get('public-summary')
  @Public()
  summary() {}
}
```

## Чтение

```ts
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(ctx: ExecutionContext) {
    if (this.reflector.getAllAndOverride(Public, [ctx.getHandler(), ctx.getClass()])) return true;

    const roles = this.reflector.getAllAndOverride(Roles, [ctx.getHandler(), ctx.getClass()]);
    // ...
    return true;
  }
}
```

| Метод | Что возвращает |
| --- | --- |
| `reflector.get(Roles, ctx.getHandler())` | Значение только с метода |
| `reflector.getAllAndOverride(Roles, [handler, class])` | Первое не-`undefined` (метод → класс) |
| `reflector.getAllAndMerge(Roles, [handler, class])` | Объединённый массив/объект |
| `reflector.get(IS_PUBLIC_KEY, target)` | Для ключей `SetMetadata` |

## Метаданные в interceptor

```ts
export const AuditAction = Reflector.createDecorator<string>();

@Injectable()
export class AuditInterceptor implements NestInterceptor {
  constructor(private readonly reflector: Reflector, private readonly audit: AuditService) {}

  intercept(ctx: ExecutionContext, next: CallHandler) {
    const action = this.reflector.get(AuditAction, ctx.getHandler());
    if (!action) return next.handle();
    const req = ctx.switchToHttp().getRequest();
    return next.handle().pipe(tap(() => this.audit.log(action, req.user?.id)));
  }
}

@AuditAction('order.cancel')
@Post(':id/cancel')
cancel() {}
```

## Композиция декораторов

```ts
export function Auth(...roles: Role[]) {
  return applyDecorators(
    Roles(roles),
    UseGuards(JwtAuthGuard, RolesGuard),
    ApiBearerAuth(),
    ApiUnauthorizedResponse({ description: 'Unauthorized' }),
  );
}

@Auth(Role.Admin)
@Delete(':id')
remove() {}
```

## Частые ошибки

- Читать метаданные только с `getHandler()` и игнорировать контроллер.
- Опечатка в строковом ключе `SetMetadata` — guard молча не видит метаданные (типизированный `createDecorator` от этого защищает).
- Использовать `Reflector` в middleware — там нет `ExecutionContext` с обработчиком.
- Ожидать, что декоратор метаданных сам что-то делает без guard/interceptor.

## Что важно помнить

- Декоратор записывает метаданные, guard/interceptor их читает.
- `Reflector.createDecorator` — типизированный и без строковых ключей.
- `getAllAndOverride` — метод важнее класса, `getAllAndMerge` — объединение.

## Мини-шпаргалка

- `export const X = Reflector.createDecorator<T>()`.
- `this.reflector.getAllAndOverride(X, [ctx.getHandler(), ctx.getClass()])`.
- `SetMetadata(key, value)` — классический вариант.
- `applyDecorators(...)` — композиция.
