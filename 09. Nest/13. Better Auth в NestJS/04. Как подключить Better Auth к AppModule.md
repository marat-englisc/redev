# Как подключить Better Auth к AppModule

> [!NOTE]
> Интеграция подключается в два шага. В `main.ts` нужно **отключить встроенный body parser Nest** (`NestFactory.create(AppModule, { bodyParser: false })`) — Better Auth должен сам прочитать «сырое» тело запроса; модуль интеграции затем заново подключает JSON- и urlencoded-парсеры для остальных маршрутов (настраивается опцией `bodyParser`; сырое тело для вебхуков — `bodyParser.rawBody`, поскольку `rawBody: true` в `NestFactory.create` при отключённом парсере не действует). В `AppModule` импортируют **`AuthModule.forRoot({ auth })`** из `@thallesp/nestjs-better-auth`: он монтирует обработчик Better Auth на `basePath` (по умолчанию `/api/auth/*`), регистрирует **глобальный `AuthGuard`**, CORS для `trustedOrigins` на auth-маршрутах и `AuthService`. Опции модуля: `disableGlobalAuthGuard` (подключать guard вручную), `disableTrustedOriginsCors`, `disableControllers`, `bodyParser`, `middleware` (обёртка обработчика, например для контекста MikroORM). Поддержка Fastify в интеграции помечена как **beta**.

## Вопрос

Как подключить Better Auth к NestJS-приложению?

## main.ts

```ts
import 'dotenv/config';                         // auth.ts читает process.env до ConfigModule
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule, {
    bodyParser: false,                          // обязательно для Better Auth
  });

  app.enableCors({ origin: [process.env.FRONTEND_URL!], credentials: true });   // для остальных маршрутов API
  app.enableShutdownHooks();
  await app.listen(process.env.PORT ?? 3000);
}
bootstrap();
```

## AppModule

```ts
import { AuthModule } from '@thallesp/nestjs-better-auth';
import { auth } from './auth/auth';

@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true, validationSchema: envSchema }),
    PrismaModule,
    AuthModule.forRoot({
      auth,
      bodyParser: {
        json: { enabled: true },
        urlencoded: { enabled: true },
        rawBody: true,                          // req.rawBody для проверки подписи вебхуков
      },
    }),
    UsersModule,
    OrdersModule,
  ],
})
export class AppModule {}
```

## Что регистрирует модуль

| Элемент | Назначение |
| --- | --- |
| Обработчик `basePath/*` | `/api/auth/sign-in/email`, `/sign-up/email`, `/get-session`, OAuth callback, эндпоинты плагинов |
| Глобальный `AuthGuard` | Все маршруты требуют сессию, если не помечены `@AllowAnonymous()` / `@OptionalAuth()` |
| CORS для `trustedOrigins` | На auth-маршрутах (можно отключить) |
| `AuthService` | Доступ к `auth.api` через DI |
| Декораторы | `@Session`, `@AllowAnonymous`, `@OptionalAuth`, `@Roles`, `@OrgRoles`, `@RequireActiveOrg`, хуки |

## Опции AuthModule.forRoot

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `disableGlobalAuthGuard` | `false` | Не регистрировать guard глобально |
| `disableTrustedOriginsCors` | `false` | Не включать CORS для auth-маршрутов |
| `disableControllers` | `false` | Не регистрировать контроллеры модуля |
| `bodyParser` | JSON и urlencoded включены | Какие парсеры вернуть после отключения встроенного |
| `middleware` | — | Обёртка `(req, res, next)` вокруг обработчика |

## Global prefix

Если в приложении задан `app.setGlobalPrefix('api')`, следите, чтобы путь auth-маршрутов не стал `/api/api/auth`: либо исключите их из префикса, либо согласуйте `basePath` в `auth.ts`. Проверяется запросом `GET /api/auth/get-session` после старта.

## Частые ошибки

- Не отключить body parser — Better Auth не может прочитать тело (ошибки на `sign-in`).
- Ожидать, что `rawBody: true` в `NestFactory.create` сработает — нужен `bodyParser.rawBody` в модуле.
- Забыть, что guard глобальный, и получить 401 на health check и публичных маршрутах.
- Двойной префикс пути из-за `setGlobalPrefix`.

## Что важно помнить

- `bodyParser: false` в `main.ts` + `AuthModule.forRoot({ auth })` в `AppModule`.
- Модуль монтирует `/api/auth/*`, глобальный guard и `AuthService`.
- Fastify — beta; основной сценарий — Express.

## Мини-шпаргалка

- `NestFactory.create(AppModule, { bodyParser: false })`.
- `AuthModule.forRoot({ auth, bodyParser: { rawBody: true } })`.
- `disableGlobalAuthGuard: true` — подключать guard вручную.
- `GET /api/auth/get-session` — проверка.
