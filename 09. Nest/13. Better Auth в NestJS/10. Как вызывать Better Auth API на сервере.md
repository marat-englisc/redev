# Как вызывать Better Auth API на сервере

> [!NOTE]
> Экземпляр `auth` содержит объект **`auth.api`** — серверные функции для тех же операций, что и HTTP-эндпоинты: `getSession`, `signUpEmail`, `signInEmail`, `signOut`, `listSessions`, `revokeSession`, `changePassword`, а также методы плагинов (`setRole`, `banUser`, `createOrganization`, `createApiKey`…). Аргументы передаются объектом: тело — в `body`, заголовки текущего запроса (с cookie сессии) — в **`headers`**; в Node.js/Express их преобразуют через **`fromNodeHeaders(req.headers)`** из `better-auth/node`. С флагом `returnHeaders: true` вызов вернёт ещё и заголовки ответа (например, `Set-Cookie`), а `asResponse: true` — полный `Response`. Ошибки — исключения `APIError` (проверка — `isAPIError(e)`) с `status` и `message`, которые в NestJS переводят в HTTP-исключения. В Nest удобнее внедрять **`AuthService<typeof auth>`** из интеграции: `this.authService.api.*` типизирован с учётом подключённых плагинов.

## Вопрос

Как вызывать методы Better Auth из серверного кода NestJS?

## AuthService в сервисе

```ts
import { AuthService } from '@thallesp/nestjs-better-auth';
import { fromNodeHeaders } from 'better-auth/node';
import type { Request } from 'express';
import { auth } from '../auth/auth';

@Injectable()
export class AccountService {
  constructor(private readonly authService: AuthService<typeof auth>) {}

  listSessions(req: Request) {
    return this.authService.api.listSessions({ headers: fromNodeHeaders(req.headers) });
  }

  revokeOtherSessions(req: Request) {
    return this.authService.api.revokeOtherSessions({ headers: fromNodeHeaders(req.headers) });
  }
}
```

## Получить сессию вручную

```ts
const session = await auth.api.getSession({ headers: fromNodeHeaders(req.headers) });
if (!session) throw new UnauthorizedException();
```

Обычно это не нужно — сессию даёт `@Session()`; ручной вызов полезен в WebSocket-handshake, в своём guard или middleware.

## Действия администратора (плагин admin)

```ts
@Roles(['admin'])
@Post('admin/users/:id/ban')
async ban(@Param('id') userId: string, @Req() req: Request) {
  await this.authService.api.banUser({
    headers: fromNodeHeaders(req.headers),            // проверка, что вызывающий — admin
    body: { userId, banReason: 'Spam', banExpiresIn: 60 * 60 * 24 * 7 },
  });
}
```

## Регистрация с сервера и cookies

```ts
const { headers, response } = await auth.api.signUpEmail({
  body: { email, password, name },
  returnHeaders: true,
});
const cookies = headers.getSetCookie();             // переслать клиенту, если нужно
```

```ts
// полный Response
const res = await auth.api.signInEmail({ body: { email, password }, asResponse: true });
```

## Обработка ошибок

```ts
import { isAPIError } from 'better-auth/api';

try {
  await this.authService.api.changePassword({
    headers: fromNodeHeaders(req.headers),
    body: { currentPassword, newPassword, revokeOtherSessions: true },
  });
} catch (e) {
  if (isAPIError(e)) {
    // e.status — HTTP-статус ('BAD_REQUEST', 'UNAUTHORIZED' или число в зависимости от версии), e.message — текст
    throw new BadRequestException(e.message);
  }
  throw e;
}
```

## Хуки в стиле Nest

```ts
// auth.ts: hooks: {} — минимум, чтобы включить хуки
@Hook()
@Injectable()
export class SignUpHook {
  constructor(private readonly blocklist: EmailBlocklistService) {}

  @BeforeHook('/sign-up/email')
  async check(ctx: { body: { email: string } }) {
    if (await this.blocklist.isBlocked(ctx.body.email)) {
      throw new APIError('BAD_REQUEST', { message: 'Email domain not allowed' });
    }
  }
}
```

## Частые ошибки

- Не передать `headers` — Better Auth не видит сессию вызывающего.
- Передавать `req.headers` из Express без `fromNodeHeaders`.
- Пробрасывать `APIError` как 500.
- Дублировать логику Better Auth (своя проверка пароля, свои таблицы сессий) вместо вызова `auth.api`.

## Что важно помнить

- `auth.api.*` — серверный доступ к функциям Better Auth и плагинов.
- `{ body, headers: fromNodeHeaders(req.headers) }`, `returnHeaders`, `asResponse`.
- В Nest — `AuthService<typeof auth>`; ошибки `APIError` → HTTP-исключения.

## Мини-шпаргалка

- `auth.api.getSession({ headers })`.
- `fromNodeHeaders(req.headers)` из `better-auth/node`.
- `returnHeaders: true` → `{ headers, response }`.
- `APIError`, `isAPIError` из `better-auth/api`.
- `@Hook()`, `@BeforeHook('/path')`.
